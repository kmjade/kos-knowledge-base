# 学习管理 详细设计

> 数据模型 · 查询库 · 工作流 · 边界处理

---

## 1. 数据模型

### 1.1 读书笔记

**路径：** `数据/读书/{书名}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `title` | string | ✅ | 书名 |
| `author` | string | ✅ | 作者 |
| `status` | enum | ✅ | `reading` / `done` / `paused` |
| `started` | date | ✅ | 开始阅读日期 |
| `finished` | date | — | 读完日期 |
| `rating` | number | — | 1-5 星 |
| `tags` | list | — | 主题标签 |

正文区域自由书写：摘录、感想、思维导图。

### 1.2 技能学习

**路径：** `数据/技能/{技能名}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `skill` | string | ✅ | 技能名称 |
| `level` | enum | ✅ | `beginner` / `intermediate` / `advanced` |
| `progress` | number | ✅ | 0-100 |
| `hours` | number | ✅ | 累计小时 |
| `started` | date | ✅ | 开始日期 |
| `next` | text | — | 下一步行动 |
| `tags` | list | — | 分类标签 |

### 1.3 课程记录

**路径：** `数据/课程/{课程名}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `title` | string | ✅ | 课程名称 |
| `platform` | string | ✅ | 学习平台 |
| `instructor` | string | — | 讲师 |
| `status` | enum | ✅ | `in_progress` / `done` / `paused` |
| `started` | date | ✅ | 开始日期 |
| `hours` | number | ✅ | 累计投入小时 |

正文区域用 Task 列表跟踪课程章节进度。

### 1.4 月度回顾

**路径：** `数据/回顾/{YYYY-MM}.md`

| 字段 | 类型 | 说明 |
|:----|:----|:-----|
| `month` | string | YYYY-MM |
| `读书数量` | number | 本月读完 |
| `技能学习小时` | number | 技能练习总时 |
| `课程小时` | number | 课程学习总时 |
| `总投入` | number | 以上合计 |
| `笔记产出` | number | 本月产出笔记数 |

## 2. 查询库

### Q1 — 在读清单

```dataview
TABLE author, started, progress
FROM "2 Areas/学习/数据/读书"
WHERE status = "reading"
SORT started ASC
```

### Q2 — 本月学习总投入

```dataview
TABLE 读书数量, 技能学习小时, 课程小时, 总投入, 笔记产出
FROM "2 Areas/学习/数据/回顾"
WHERE month = "2026-06"
```

### Q3 — 技能进度一览

```dataview
TABLE skill, level, progress, hours
FROM "2 Areas/学习/数据/技能"
SORT progress DESC
```

### Q4 — 今年读完的书

```dataview
TABLE author, rating, finished
FROM "2 Areas/学习/数据/读书"
WHERE status = "done" AND finished >= date(2026-01-01)
SORT finished DESC
```

## 3. 边界处理

| 场景 | 处理方式 |
|:----|:---------|
| 多本书并行 | 各自独立文件，各自 `status: reading` |
| 重读 | 读完标记 `done`，重读新建文件或追加笔记 |
| 技能停滞 | 不删除文件，`status` 保持原样，回顾时标记 |
| 读书笔记与 KOS 笔记 | 读书笔记在 `数据/读书/`，KOS 概念页在 `wiki/concepts/` |
