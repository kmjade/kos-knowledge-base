# 学习管理 架构设计

> 三支柱中的学习支柱
> 分支：`Life+AI` | 定位 `2 Areas/学习/`

---

## 1. 分层架构

```
体系层 (公开)            数据层 (私有)
┌────────────────┐      ┌──────────────────┐
│  学习分类       │←────│  读书清单与笔记    │
│  学习模板       │      │  技能学习进度     │
│                │      │  课程记录         │
│                │      │  知识回顾         │
└────────────────┘      └──────────────────┘
       ↑                       ↑
    版本控制              .gitignore
```

## 2. 模块结构

```
2 Areas/学习/
├── 学习.md                  ← 索引页
├── 体系/
│   ├── 学习分类.md           ← 学科/技能分类 + UDC 映射
│   └── 模板/
│       ├── 读书笔记模板.md
│       ├── 技能学习模板.md
│       └── 知识回顾模板.md
└── 数据/                    ← gitignored
    ├── 读书/                ← 在读/已读 + 笔记
    ├── 技能/                ← 技能进度跟踪
    ├── 课程/                ← 课程记录
    └── 回顾/                ← 周/月知识回顾
```

## 4. 数据模型

### 读书笔记

| 字段 | 类型 | 说明 |
|:----|:----|:-----|
| `title` | string | 书名 |
| `author` | string | 作者 |
| `status` | enum | `reading` / `done` / `paused` |
| `started` | date | 开始阅读日期 |
| `finished` | date | 读完日期 |
| `rating` | number | 1-5 星 |
| `tags` | list | 主题标签 |

### 技能学习

| 字段 | 类型 | 说明 |
|:----|:----|:-----|
| `skill` | string | 技能名称 |
| `level` | enum | `beginner` / `intermediate` / `advanced` |
| `progress` | number | 0-100% |
| `hours` | number | 累计投入小时 |
| `next` | text | 下一步行动 |

## 5. 与三支柱联动

```
学习系统 → 产出知识笔记 → 索引到 KOS 知识库
        → 阅读收获 → 三支柱速写 学习: 行记录
        → 技能提升 → 间接影响 工作 和 生活 支柱
```

## 6. 数据流

```
日常
├── 开始读书 → 数据/读书/ 新建记录
├── 技能练习 → 数据/技能/ 更新进度
├── 上课/看视频 → 数据/课程/ 记录
└── 学完总结 → 写笔记 → 标记完成

月末 → 回顾本月学习投入（小时/本/技能进度）
季末 → 知识回顾 + 下季度学习计划
```
