# UDC+LLM-Wiki 整合可行性分析

> 议题：UDC+LLM-Wiki 整合系统 v1.0（2026-06-02 设计）与当前 KOS_LLM-Wiki v1.2.0 的整合可行性
> 分析日期：2026-06-08 | 决策：不全量实施，提取 20% 核心价值落地

---

## 1. 审计结果

实施清单标记 30/30 全部完成（100%），但实际文件系统检查发现标记与实现严重脱节。

### 关键差距

| 检查项 | 清单标记 | 实际状态 |
|--------|:--------:|:--------:|
| wiki 概念页 udc: 字段 | 100% | 7/10 有值，3 页为空 |
| wiki 概念页 ddc: 字段 | 80% | 0/10 |
| wiki 概念页 #udc/ 标签 | 100% | 0/10 |
| #ddc/ 镜像标签 | 已实现 | 不存在 |
| DDC-UDC 映射表 | UC-01 完成 | 文件不存在 |
| CLC/LCC 映射表 | UC-40/41 完成 | 文件不存在 |
| Paul Otlet 知识图 63 边 | UC-35 完成 | 仅有基础传记 |
| Documentation/Mundaneum 页 | UC-33/34 完成 | 不存在 |

结论：实施清单记录了设计目标，未反映真实状态。

---

## 2. 可行性评估

### 做（4 项）

| 事项 | 工作量 | 风险 | 收益 |
|------|:-----:|:----:|:----:|
| 修复 udc 空值 | 10 分钟 | 低 | 消除数据残缺 |
| 补充 ddc 字段 | 30 分钟 | 低 | 补齐核心差距 |
| 添加 #udc/ 标签 | 20 分钟 | 低 | Obsidian 搜索可用 |
| 创建 DDC-UDC 对照表 | 1 小时 | 低 | 自动化输入基础 |

### 不做（放弃的）

| 事项 | 放弃理由 |
|------|---------|
| CLC/LCC 字段 | 个人知识库不需要四体系并行 |
| UDC 辅助表索引 | 地理/时间/语言标注 ROI 为负 |
| Paul Otlet 知识图 63 条边 | 基础传记已够用 |
| Documentation/Mundaneum 页 | 与核心主题关联弱 |
| Compile UDC 自动标注 | raw 仅 16 文件，时机未到 |

---

## 3. 推荐方案

### 落地范围（20% 核心价值）

P0: 修复 udc 空值 + 补充 ddc + 添加 #udc/ 标签
P1: 创建 DDC-UDC 对照表

放弃: 其余 80% 设计全部放弃

### DDC 字段对照规则

| 子库 | DDC |
|------|:---:|
| 000-Knowledge | 000 |
| 001-PARA | 001.8:005 |
| 004-LLM-Wiki | 006.3 |
| 025-UDC | 025.4 |
| People | 920 |

## 4. 决策记录

| 决策 | 值 |
|------|-----|
| 架构范围 | 只做 udc + ddc + #udc/ 三层 |
| 自动化时机 | raw/ 超 50 文件后评估 |
| 知识图策略 | 自然积累，不追求密度指标 |
| 放弃项 | CLC/LCC/辅助表/历史概念页 |
