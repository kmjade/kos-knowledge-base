# KOS 系统实战教材

> 基于真实操作案例的 KOS_LLM-Wiki 知识系统教学材料。
> 本教材记录了一次完整的知识域导入、系统配置、查询实战的全过程。

---

## 第一课：知识域导入

### 场景
外部知识域「300 Social 社会科学」（226 文件 / 573 MB）需要导入 KOS 体系。

### 操作流程

```
0 Inbox/300 Social/  ──→  3 Resources/300-Social/
                              ├── 310-统计学/
                              ├── 330-经济学/
                              ├── 332.6-Investment-and-Trading/
                              ├── 658-Marketing/
                              ├── raw/
                              └── wiki/
```

### 关键决策

| 问题 | 选择 | 理由 |
|:----|:-----|:------|
| 归属位置 | `3 Resources/` 与 `000-Knowledge` 同级 | 独立的知识域，非 000 子集 |
| 项目文档 | 提取到 `1 Projects/` | 按 UDC 分类，与知识域分离管理 |
| 索引显示 | 显示二层子域（310/330/332.6/658）| _index.md 直接展示结构 |

### 技术要点

1. **目录移动**：`Move-Item` 从 Inbox 到 3 Resources
2. **项目提取**：识别项目文档（原型/工单/设计/需求说明书）→ 按 UDC 分类 → 自动编号
3. **来源标记**：`frontmatter` 加 `origin: imported`

## 第二课：分类体系转换

### 场景
导入的知识域用 DDC 分类，KOS 系统用 UDC 分类，需要批量转换。

### DDC → UDC 映射表

| DDC | UDC | 领域 |
|:---:|:---:|:------|
| 300 | 3 | 社会科学总论 |
| 310 | 311 | 统计学 |
| 330 | 33 | 经济学 |
| 332.6 | 336.76 | 投资与交易 |
| 658.8 | 339.138 | 市场营销 |

### 操作内容

| 操作 | 数量 |
|:----|:----:|
| `ddc:` frontmatter 字段移除 | 60 文件 |
| `udc:` 字段补充（缺失文件） | 2 文件 |
| `ddc-XXX` 标签 → `udc/XXX` | 68 文件 |
| 标题/info 框 DDC→UDC | 22 文件 |
| 别名更新 | 68 文件 |

### 常见问题

**编码问题**：中文文件名 + PowerShell 管道导致编码丢失。
解决方案：将 Python 脚本写入临时文件后执行，避免 stdin 管道传输中文。

## 第三课：双库同步机制

### 拓扑

```
商铺地下室（4台服务器）
      ↕  笔记本/平板 插 U 盘使用
  J:（U盘主库） ←── AI 操作
      │  即时同步
      ↓
  F:（家里台式机） ←── 用户 Obsidian 查看
```

### 同步策略

| 层级 | 方式 | 方向 |
|:----|:-----|:-----|
| 架构层 | `sync-vaults.py`（SHA-256 增量） | J: → F: |
| 内容层 | 手动同步（即时） | AI 写 J: → 同步到 F: |

### 关键教训

用户看不到文件？检查文件在哪台设备上。
→ 根因：文件在 J:（U盘），用户 Obsidian 开的是 F:（本机）。

## 第四课：查询系统

### 三级查询对比

| 模式 | 范围 | Token | 演示主题 |
|:----|:-----|:-----:|:---------|
| **Quick** | hot.md 仅 | ~500 | 当前活跃项目 |
| **Standard** | 索引 + 3-5 页 | ~3,000 | UDC 336.76 / UDC 33 |
| **Deep** | 全库遍历 | ~8,000 | 交易系统设计决策 / 经纬（知识空白）|

### 查询日志

| 模式 | 查询内容 | 结果 |
|:----|:---------|:-----|
| Quick | 当前活跃项目 | ✅ 4 个项目 + 活跃线程 |
| Standard | UDC 336.76 | ✅ 35 concepts, 16 entities, 7 sources |
| Standard | UDC 33 | ✅ 9 章体系 + 核心概念 |
| Deep | 交易系统设计决策 | ✅ 6 页综合，已归档 |
| Deep | 经纬 | ❌ 知识空白，建议收录 |

### 空白处理协议

当知识库无答案时：
1. 明确说明资料不足
2. 识别具体空白
3. 建议找来源或手动录入
4. 不编造

```
│   ├── 系统配置.md        ← 路径常量、UDC 体系、标签规则

```

### 编码规范

| 格式 | 状态 | 说明 |
|:----|:----:|:------|
| UTF-8 无 BOM | ✅ 推荐 | Obsidian 兼容最佳 |
| UTF-8 + BOM | ❌ | PowerShell `Out-File -Encoding utf8` 默认行为 |
| UTF-16 LE | ❌ | 某些 .NET 操作导致，Obsidian 显示空白 |
| CRLF 换行 | ✅ | Windows 标准 |
| LF 换行 | ✅ | 同样兼容 |
