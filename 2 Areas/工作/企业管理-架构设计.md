# 企业管理 架构设计

> 工作支柱下的个体户管理子系统
> 分支：`Life+AI` | 定位 `2 Areas/工作/企业管理/`

---

## 1. 分层架构

```
体系层 (公开)            数据层 (私有)
┌────────────────┐      ┌──────────────────┐
│  管理分类       │←────│  客户/供应商       │
│  业务模板       │      │  合同与文档        │
│                │      │  项目/任务         │
│                │      │  经营财务          │
│                │      │  周/月复盘         │
└────────────────┘      └──────────────────┘
       ↑                       ↑
    版本控制              .gitignore
```

## 2. 模块结构

```
2 Areas/工作/企业管理/
├── 企业管理.md              ← 索引页
├── 体系/
│   ├── 经营分类.md           ← 业务分类 + UDC 映射
│   └── 模板/                ← 合同模板、记账模板
└── 数据/                    ← gitignored
    ├── 客户/                ← 客户与供应商名录
    ├── 合同/                ← 合同归档
    ├── 经营财务/             ← 对公收支、发票记录
    ├── 项目/                ← 项目与任务跟踪
    └── 复盘/                ← 周/月经营回顾
```

## 4. 与个人财务的边界

| 维度 | 个人财务 | 企业管理 |
|:----|:--------|:---------|
| 目录 | `2 Areas/生活/个人财务/` | `2 Areas/工作/企业管理/` |
| 范围 | 生活收支、家庭资产 | 对公收支、客户合同 |
| UDC 前缀 | 336.* | 334.* / 339.* / 658.* |
| 数据隔离 | `数据/` gitignored | `数据/` gitignored |
| 交叉场景 | 个人←→企业资金往来（备注说明） | 同上 |

## 5. 数据流

```
日常经营
  ├── 客户沟通 → 数据/客户/ 更新
  ├── 合同签署 → 数据/合同/ 归档
  ├── 对公收付 → 数据/经营财务/ 记账
  └── 任务推进 → 数据/项目/ 更新
       ↓
月末 → 经营财务汇总 + 项目状态确认
       ↓
季末 → 经营复盘 + 税务准备
```
