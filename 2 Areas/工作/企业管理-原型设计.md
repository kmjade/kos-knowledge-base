# 企业管理 原型设计

> 闭环体验：客户 → 合同 → 记账 → 项目 → 复盘

---

## 1. 经营记账 — 日常流程

### 操作步骤

1. 打开 `2 Areas/工作/企业管理/数据/经营财务/`
2. 新建 `biz-YYYY-MM-DD.md`（或复制 `<体系/模板/经营记账模板.md>`）
3. 填入内容后保存

### 示例

```yaml
---
date: 2026-06-08
type: 收入
category: 主营业务收入
amount: 5000.00
method: 对公账户
client: XXX 公司
note: 6 月项目首款
---
```

> 对公收支用 `biz-` 前缀，与个人财务的 `txn-` 区分。

---

## 2. 客户管理

### 操作步骤

1. 打开 `2 Areas/工作/企业管理/数据/客户/`
2. 新建 `客户名.md`

### 示例

```yaml
---
name: XXX 科技有限公司
type: 客户
contact: 张经理
tel: 138xxxx
wechat: zhangxxx
since: 2026-01
status: active
note: 长期合作客户，季度结算
---
```

---

## 3. 项目管理

### 示例

```yaml
---
project: 官网改版
status: active
started: 2026-06-01
deadline: 2026-07-15
income: 15000
cost: 3000
note: 包含前端+后端+部署
---

## 任务

- [x] 需求确认
- [ ] UI 设计稿
- [ ] 前端开发
- [ ] 后端开发
- [ ] 部署上线
```

## 4. 经营复盘

### 月度示例

```yaml
---

收入: 15000
支出: 4500
利润: 10500
客户数: 3
项目数: 2
---
```
