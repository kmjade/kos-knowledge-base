# 企业管理 详细设计

> 数据模型 · 查询库 · 工作流 · 边界处理

---

## 1. 数据模型

### 1.1 经营记账

**路径：** `数据/经营财务/biz-{YYYY-MM-DD}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `date` | date | ✅ | 交易日期 |
| `type` | enum | ✅ | `收入` / `支出` / `转账` |
| `category` | string | ✅ | 取自 `体系/经营分类.md` |
| `amount` | number | ✅ | 金额（正数） |
| `method` | string | ✅ | `对公账户` / `现金` / `支付宝` / `微信` |
| `client` | string | — | 对方名称 |
| `note` | text | — | 备注说明 |

### 1.2 客户记录

**路径：** `数据/客户/{客户名}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `name` | string | ✅ | 名称 |
| `type` | enum | ✅ | `客户` / `供应商` |
| `contact` | string | — | 联系人 |
| `tel` | string | — | 电话 |
| `wechat` | string | — | 微信 |
| `since` | date | — | 合作起始 |
| `status` | enum | ✅ | `active` / `inactive` |

### 1.3 项目

**路径：** `数据/项目/{项目名}.md`

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `project` | string | ✅ | 项目名称 |
| `status` | enum | ✅ | `active` / `completed` / `paused` |
| `started` | date | ✅ | 开始日期 |
| `deadline` | date | — | 截止日期 |
| `income` | number | — | 项目收入 |
| `cost` | number | — | 项目成本 |

## 2. 查询库

### Q1 — 本月经营收入

```dataview
TABLE sum(rows.amount) AS 合计
FROM "2 Areas/工作/企业管理/数据/经营财务"
WHERE type = "收入" AND date >= date(2026-06-01) AND date < date(2026-07-01)
GROUP BY category
```

### Q2 — 本月经营支出

```dataview
TABLE sum(rows.amount) AS 合计
FROM "2 Areas/工作/企业管理/数据/经营财务"
WHERE type = "支出" AND date >= date(2026-06-01) AND date < date(2026-07-01)
GROUP BY category
```

### Q3 — 活跃项目

```dataview
TABLE project, deadline, income, cost
FROM "2 Areas/工作/企业管理/数据/项目"
WHERE status = "active"
```

### Q4 — 本月利润

```dataview
TABLE 
  sum(choice(type="收入", amount, 0)) AS 收入,
  sum(choice(type="支出", amount, 0)) AS 支出,
  sum(choice(type="收入", amount, -amount)) AS 利润
FROM "2 Areas/工作/企业管理/数据/经营财务"
WHERE date >= date(2026-06-01) AND date < date(2026-07-01)
```

## 3. 边界处理

| 场景 | 处理方式 |
|:----|:---------|
| 对公/对私混合 | 分开记账，在 `note` 中注明关联 |
| 分期收款 | 每期一笔记录，`note` 注明"第 N 期" |
| 客户名称变更 | 修改客户文件 `name` 字段，旧记录不动 |
| 项目亏损 | `income < cost` 正常记录，复盘时分析原因 |
