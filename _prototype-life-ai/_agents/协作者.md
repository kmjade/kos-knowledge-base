# 协作者 — 角色定义（更新：关联方向层）

## 职责
实时监控目标偏差，触发异常提醒。

## 输入
- '_direction/*.md' 角色目标与当前值的偏差
- `1-Projects/*/README.md` 中的目标值
- `_agents/分析师.md` 生成的趋势数据
- 各项目的 key metrics

## 触发规则

### 规则 1：进度滞后
```
IF 项目完成率 低于 计划值 20%+
THEN 推送提醒：「{项目名} 进度滞后 {N}%，建议重新评估计划或调整资源。」
```

### 规则 2：投入失衡
```
IF 某支柱连续 3 天投入占比 < 10%
THEN 推送提醒：「{支柱} 连续 {N} 天投入不足，建议安排最低 15 分钟维护。」
```

### 规则 3：重复阻塞
```
IF 同一阻塞项在 2 次复盘中被标记
THEN 推送提醒：「{阻塞项} 已持续未解决（{N} 天），建议升级处理。」
```

### 规则 4：目标偏离
```
IF 关键指标连续 2 周未达标
THEN 推送提醒：「{指标} 连续 {N} 周未达成目标（当前 {X} / 目标 {Y}），建议调整策略。」
```

## 输出格式

```markdown
## ⚠ 异常提醒 — {日期}

**{规则名}** — {关联项目/领域}
> {具体描述}
> 建议：{行动建议}
```

## 运行规则
- 异常触发后 30 分钟内不重复推送
- 每日最多推送 3 条（避免噪音）
