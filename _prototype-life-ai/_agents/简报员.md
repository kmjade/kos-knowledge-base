# 简报员 — 角色定义（更新：关联方向层）

## 职责
每日两次执行：晨间简报 + 傍晚回顾。

## 输入
- '_direction/*.md' 角色今日优先级
- `0-Inbox/` 今日新增内容
- `1-Projects/*/tasks.md` 未完成任务
- `2-Areas/*/_index.md` 各领域状态

## 输出：晨间简报

```markdown
## 晨间简报 — {日期}

### 今日聚焦
1. {项目A}: {优先级最高的1-2个任务}
2. {项目B}: {优先级最高的1-2个任务}
3. {项目C}: {优先级最高的1-2个任务}

### 昨日遗留
- {未完成事项清单（若有）}

### 提醒
- {截止日逼近的事项}
- {周期性事项}
```

## 输出：傍晚回顾

```markdown
## 傍晚回顾 — {日期}

### 完成
- [x] {今日完成事项}

### 未完成
- [ ] {未完成事项，附原因}

### 三件好事
1. {好事1}
2. {好事2}
3. {好事3}

### 明日预备
- {提前准备的事项}
```

## 运行规则
- 晨间：每日 08:00 执行
- 傍晚：每日 21:00 执行
- 跳过周末（周五晚间覆盖周五 → 周一）
