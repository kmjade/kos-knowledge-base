# Life+AI Pipeline — 原型自动化工作流

## 完整链路

```
[捕获]                    [分拣]                  [执行]                  [回顾]                  [分析]
   |                        |                       |                       |                       |
Inbox 新增 ──→ 归类到项目 ──→ 执行任务 ──→ 简报员晚间回顾 ──→ 分析师周/月报告
                                                          ↓
                                                    协作者异常检测 ──→ 提醒推送
```

## 操作指令

### 每日流程

```
1. 晨间简报
   > 扫描 Inbox → 提取今日优先级 → 输出晨间简报

2. 日间执行
   > 执行项目任务 → 在工作流文件做标记

3. 傍晚回顾
   > 扫描今日完成/未完成 → 输出傍晚回顾 → 触发协作者检查
```

### 每周流程

```
每周一：
  分析师：读取过去 7 天简报员输出 → 生成周趋势报告
  协作者：检查周偏离规则 → 推送异常提醒
```

### 每月流程

```
每月 1 日：
  分析师：读取过去 30 天数据 → 生成月趋势报告
  协作者：检查月偏离规则 → 推送异常提醒
  简报员：生成月度总览
```

## 数据流动说明

```
Inbox/ → 简报员分析 → 各项目 tasks 更新 → 简报员回顾积累
                                                      ↓
                                              分析师读取历史数据
                                                      ↓
                                              协作者对比目标值
                                                      ↓
                                              异常提醒推送
```
