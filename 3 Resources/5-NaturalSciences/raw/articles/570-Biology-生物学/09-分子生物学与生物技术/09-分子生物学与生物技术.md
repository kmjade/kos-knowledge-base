# 09-分子生物学与生物技术

> 在分子水平上理解并改造生命——现代生物学的前沿。

## 核心分子技术

| 技术 | 原理 | 用途 |
|------|------|------|
| PCR | DNA 体外扩增 | 检测、克隆 |
| DNA 测序 | 读取碱基序列 | 基因组、诊断 |
| 凝胶电泳 | 分离 DNA 片段 | 鉴定、分析 |
| 分子克隆 | 插入载体 | 表达蛋白 |
| 杂交 | 互补配对 | 检测序列 |

## 基因工程

- 工具酶：限制酶（切）、连接酶（接）
- 载体：质粒、病毒
- 转基因生物（GMO）

## CRISPR-Cas9

- 基因编辑技术（2020 诺贝尔化学奖）
- 原理：向导 RNA 定位 + Cas9 切割 DNA
- 应用：基因治疗、农业改良、基础研究

## 生物技术应用

| 领域 | 应用 |
|------|------|
| 医药 | 胰岛素、抗体、基因治疗、mRNA 疫苗 |
| 农业 | 抗虫、抗除草剂、改良品种 |
| 工业 | 酶制剂、生物燃料 |
| 环境 | 生物修复、固碳 |

## 伦理与安全

- 基因编辑的伦理边界（人类胚胎编辑争议）
- 生物安全、双重用途
- 遗传隐私
