# 02-细胞生物学

> 研究细胞结构与功能——生命活动的基本单位。

## 细胞类型

| 类型 | 特征 | 代表 |
|------|------|------|
| 原核细胞 | 无核膜、无膜性细胞器 | 细菌 |
| 真核细胞 | 有核膜、膜性细胞器 | 动植物、真菌 |

## 主要细胞器

| 细胞器 | 功能 |
|------|------|
| 细胞核 | 储存 DNA、调控 |
| 线粒体 | 有氧呼吸（产能） |
| 叶绿体 | 光合作用（植物） |
| 核糖体 | 蛋白质合成 |
| 内质网 | 脂质合成、蛋白加工 |
| 高尔基体 | 包装、分泌 |
| 溶酶体 | 消化分解 |

## 细胞膜

- 流动镶嵌模型：磷脂双分子层 + 膜蛋白
- 物质运输：扩散、协助扩散、主动运输、胞吞/胞吐

## 细胞周期

```
G1（生长）→ S（DNA 复制）→ G2（准备）→ M（分裂：前期→中期→后期→末期）
```

- 有丝分裂：体细胞，2n → 2n
- 减数分裂：生殖细胞，2n → n
- 细胞周期调控异常 → 癌症

## 细胞凋亡 vs 坏死

- 凋亡（程序性死亡）：主动、有序
- 坏死：被动、炎症反应
