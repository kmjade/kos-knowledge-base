# 04-进化生物学

> 研究生命如何演化——自然选择是生物学的统一理论。

## 达尔文自然选择

1. 变异：个体间存在可遗传差异
2. 过度繁殖：资源有限，生存竞争
3. 适者生存：有利变异者更易存活繁殖
4. 累积：有利变异代代累积

## 进化证据

| 证据 | 说明 |
|------|------|
| 化石 | 地层中的过渡类型 |
| 比较解剖学 | 同源器官 |
| 分子生物学 | DNA 序列相似性 |
| 生物地理 | 岛屿物种分布 |
| 胚胎发育 | 早期胚胎相似 |

## 物种形成

- **地理隔离** → 生殖隔离 → 新物种
- 异域成种（地理隔离）、同域成种

## 进化机制

| 机制 | 说明 |
|------|------|
| 突变 | 遗传变异的来源 |
| 基因流 | 种群间基因交流 |
| 遗传漂变 | 随机频率变化（小种群） |
| 自然选择 | 非随机、方向性 |

## 现代综合进化论

- 达尔文自然选择 + 孟德尔遗传学
- 种群基因频率的变化 = 进化
