# 01-生物学概述

> 关于生命的科学——从细胞到生态系统。

## 生命的特征

| 特征 | 说明 |
|------|------|
| 新陈代谢 | 物质与能量交换 |
| 生长与发育 | 从小到大、分化成熟 |
| 繁殖 | 产生后代 |
| 遗传与变异 | 性状传递与改变 |
| 应激性 | 对环境作出反应 |
| 进化 | 种群随时间改变 |

## 细胞学说

1. 一切生物都由细胞构成
2. 细胞是生命的基本单位
3. 细胞来自已有的细胞

## 生物分类（界）

| 界 | 特征 | 代表 |
|------|------|------|
| 原核生物 | 无细胞核 | 细菌 |
| 原生生物 | 单细胞真核 | 草履虫 |
| 真菌 | 吸收营养 | 蘑菇、酵母 |
| 植物 | 光合作用 | 树木、花草 |
| 动物 | 摄食营养 | 昆虫、哺乳类 |

## 分类等级

```
界 → 门 → 纲 → 目 → 科 → 属 → 种
```

- 二名法：*Homo sapiens*（属名 + 种加词）
