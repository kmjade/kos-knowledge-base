# 07-微生物学

> 研究肉眼不可见的生命——细菌、病毒、真菌与原生生物。

## 微生物分类

| 类型 | 特征 | 代表 |
|------|------|------|
| 细菌 | 原核、无核膜 | 大肠杆菌、乳酸菌 |
| 古菌 | 原核、极端环境 | 嗜热菌 |
| 病毒 | 非细胞、需宿主 | 流感、HIV |
| 真菌 | 真核、吸收营养 | 酵母、霉菌 |
| 原生生物 | 单细胞真核 | 阿米巴 |

## 细菌

- 形态：球菌、杆菌、螺旋菌
- 结构：细胞壁、细胞膜、鞭毛
- 繁殖：二分裂（快，可每 20 分钟一代）
- 革兰氏染色：阳性/阴性

## 病毒

- 结构：核酸 + 蛋白质外壳（无细胞结构）
- 复制：吸附 → 注入 → 复制 → 组装 → 释放
- 争议：病毒是否是生命

## 微生物与人类

| 作用 | 说明 |
|------|------|
| 致病 | 细菌感染、病毒感染 |
| 有益 | 肠道菌群、发酵、固氮 |
| 工业 | 抗生素、疫苗、酶生产 |

## 免疫基础

- 先天免疫（非特异）：皮肤、吞噬细胞
- 适应性免疫（特异）：抗体、T 细胞
- 疫苗：激活免疫记忆
