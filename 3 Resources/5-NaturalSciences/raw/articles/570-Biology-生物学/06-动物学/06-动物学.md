# 06-动物学

> 研究动物的分类、生理与行为——从无脊椎到脊椎动物。

## 动物主要门类

| 门 | 特征 | 代表 |
|------|------|------|
| 腔肠动物 | 辐射对称 | 水母、珊瑚 |
| 扁形/线形动物 | 两侧对称 | 涡虫、蛔虫 |
| 环节动物 | 分节 | 蚯蚓 |
| 软体动物 | 软体、壳 | 蜗牛、章鱼 |
| 节肢动物 | 外骨骼、分节 | 昆虫、蜘蛛、虾 |
| 脊索动物 | 脊索/脊椎 | 鱼类、鸟类、哺乳类 |

## 脊椎动物五大类

| 类群 | 特征 |
|------|------|
| 鱼类 | 水生、鳃呼吸 |
| 两栖类 | 幼体水生、成体陆生 |
| 爬行类 | 羊膜卵、鳞片 |
| 鸟类 | 羽毛、恒温、飞行 |
| 哺乳类 | 哺乳、毛发、恒温 |

## 动物生理

- 循环系统（开放式 vs 闭合式）
- 呼吸（鳃、肺、皮肤）
- 消化、排泄（肾脏）、神经调控

## 动物行为

| 类型 | 说明 |
|------|------|
| 本能 | 先天行为（迁徙、求偶） |
| 学习 | 后天获得（条件反射） |
| 社会行为 | 群体协作（蜜蜂、蚂蚁、狼群） |
