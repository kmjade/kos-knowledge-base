# 08-生态学

> 研究生物与环境的相互作用——从个体到生物圈。

## 生态层次

```
个体 → 种群 → 群落 → 生态系统 → 生物圈
```

## 生态系统

- 组成：非生物环境 + 生产者 + 消费者 + 分解者
- 食物链、食物网

## 能量流动

- 能量单向流动，逐级递减
- 生态效率 ~10%（十分之一定律）
- 能量金字塔

## 物质循环

| 循环 | 关键过程 |
|------|------|
| 碳循环 | 光合、呼吸、燃烧 |
| 氮循环 | 固氮、硝化、反硝化 |
| 水循环 | 蒸发、降水、径流 |
| 磷循环 | 风化、沉积 |

## 生物多样性

- 三个层次：基因、物种、生态系统
- 价值：直接、间接、存在价值
- 威胁：栖息地破坏、污染、气候变化、入侵物种

## 种群动态

- 逻辑斯蒂增长：$\frac{dN}{dt} = rN\left(1-\frac{N}{K}\right)$
- 环境容纳量 K
- r-对策 vs K-对策
