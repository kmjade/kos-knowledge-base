# 03-遗传学

> 研究遗传与变异——基因如何决定性状并传递。

## DNA 结构

- 双螺旋（Watson & Crick, 1953）
- 碱基配对：A-T、G-C
- 基因 = 一段编码蛋白质的 DNA 序列

## 中心法则

```
DNA →（转录）→ RNA →（翻译）→ 蛋白质
        ↑（逆转录）
```

## 孟德尔遗传定律

| 定律 | 内容 |
|------|------|
| 分离定律 | 等位基因在配子形成时分离 |
| 自由组合定律 | 不同性状的基因独立分配 |

- 基因型 vs 表现型
- 显性、隐性、共显性

## 染色体与遗传

| 概念 | 说明 |
|------|------|
| 染色体 | DNA 高度折叠 |
| 二倍体 | 2n（人有 23 对染色体） |
| 性染色体 | XY（男）、XX（女） |
| 突变 | 基因突变、染色体变异 |

## 遗传病

- 单基因病：色盲（X 连锁隐性）、镰刀型贫血
- 染色体病：唐氏综合征（21 三体）
- 多基因病：高血压、糖尿病易感性
