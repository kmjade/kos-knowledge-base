# 05-植物学

> 研究植物的科学——从藻类到被子植物，从光合作用到生态系统。

## 植物分类

| 类群 | 特征 | 代表 |
|------|------|------|
| 藻类 | 水生、无维管 | 海带 |
| 苔藓 | 无维管、矮小 | 地钱 |
| 蕨类 | 维管、孢子繁殖 | 蕨 |
| 裸子植物 | 种子裸露 | 松、柏 |
| 被子植物 | 种子包被、花 | 绝大多数开花植物 |

## 光合作用

$$6CO_2 + 6H_2O \xrightarrow{\text{光}} C_6H_{12}O_6 + 6O_2$$

- 光反应：光能 → ATP + NADPH（类囊体）
- 暗反应（卡尔文循环）：CO₂ → 糖（叶绿体基质）

## 植物结构

| 器官 | 功能 |
|------|------|
| 根 | 吸收、固定 |
| 茎 | 运输、支撑 |
| 叶 | 光合作用 |
| 花 | 繁殖 |
| 果实/种子 | 传播、萌发 |

## 植物的运输

- 木质部：水和无机盐（向上）
- 韧皮部：有机物（双向）
- 蒸腾作用：拉动水分上升

## 植物激素

- 生长素（向光性）、赤霉素、细胞分裂素、脱落酸、乙烯
