# 09-天文历史与文化

> 天文学是人类最古老的科学——从历法到导航，从神话到现代宇宙观。

## 古代天文学

| 文明 | 成就 |
|------|------|
| 巴比伦 | 60 进制、日月食周期（沙罗周期） |
| 古埃及 | 天狼星偕日升定历法 |
| 古希腊 | 托勒密地心体系、本轮-均轮 |
| 中国 | 浑天说、圭表测影、精确星表 |
| 玛雅 | 精密历法、金星周期 |

## 历法

| 历法 | 基础 |
|------|------|
| 太阳历（公历） | 回归年 ~365.2422 天 |
| 太阴历 | 朔望月 ~29.53 天 |
| 阴阳历（农历） | 闰月调和两者 |

## 科学革命

| 人物 | 贡献 |
|------|------|
| 哥白尼 | 日心说（1543） |
| 第谷·布拉赫 | 精密观测 |
| 开普勒 | 行星运动三定律 |
| 伽利略 | 望远镜观测（1609） |
| 牛顿 | 万有引力定律（1687） |

## 天文文化

- **星座**：88 个国际标准星座，源于希腊神话
- **占星 vs 天文**：前者是文化现象，后者是科学
- **天文导航**：北极星定纬度，六分仪测高度
