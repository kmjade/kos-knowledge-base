# 04-太阳

> 太阳系唯一的恒星——一颗 G2V 型主序星，地球生命的能量源泉。

## 基本参数

| 参数 | 数值 |
|------|------|
| 质量 | $1.989 \times 10^{30}$ kg |
| 半径 | $6.96 \times 10^5$ km |
| 表面温度 | ~5778 K |
| 核心温度 | ~$1.5 \times 10^7$ K |
| 年龄 | ~46 亿年 |

## 内部结构

```
核心（核聚变）→ 辐射层 → 对流层 → 光球层 → 色球层 → 日冕
```

- **核心**：氢聚变为氦（质子-质子链），$4H \to He + \text{能量}$
- **日冕**：温度高达百万 K（尚未完全解释的「日冕加热问题」）

## 太阳活动

| 现象 | 说明 |
|------|------|
| 太阳黑子 | 强磁场抑制对流，11 年周期 |
| 耀斑 | 磁场重联释放能量 |
| 日冕物质抛射 (CME) | 抛射带电粒子，引发空间天气 |

> **空间天气**：CME 影响地球磁场，可干扰卫星、电网、通讯。
