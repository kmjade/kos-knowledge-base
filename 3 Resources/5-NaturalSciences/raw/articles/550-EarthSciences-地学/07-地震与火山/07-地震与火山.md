# 07-地震与火山

> 地球内部能量的释放——板块运动最直观的体现。

## 板块构造

- 岩石圈分为 7 大板块 + 若干小板块
- 板块边界是地震与火山的集中带
- 环太平洋火山带（"火环"）分布全球 75% 火山

## 地震

| 概念 | 说明 |
|------|------|
| 震源 | 地震发生的位置 |
| 震中 | 震源在地表的投影 |
| 震级 | 释放能量（里氏/矩震级） |
| 烈度 | 地表破坏程度 |

- **地震波**：P 波（纵波，快）、S 波（横波）、面波
- 汶川地震 (2008) 8.0 级、东日本地震 (2011) 9.0 级

## 火山

| 类型 | 特征 | 示例 |
|------|------|------|
| 盾状火山 | 低缓、玄武岩 | 夏威夷 |
| 层状火山 | 陡峭、爆炸性 | 富士山、维苏威 |
| 破火山口 | 塌陷形成 | 黄石 |

- 火山喷发物：熔岩、火山灰、火山气体
- 火山喷发影响气候（火山灰遮挡阳光）

## 灾害防治

- 地震预警（P 波先于 S 波）
- 抗震建筑、应急预案
- 火山监测（地震、形变、气体）
