# 09-气候变化与环境

> 人类世的核心议题——全球变暖与环境危机。

## 温室效应

- 温室气体（CO₂、CH₄）吸收地面红外辐射
- 自然温室效应使地球适宜生存（~15°C）
- 人为增强 → 全球变暖

## 全球变暖的证据

| 证据 | 数据 |
|------|------|
| 温度上升 | 工业革命以来 +1.1°C |
| 海平面上升 | 冰川融化 + 热膨胀 |
| 极端天气 | 热浪、洪水、干旱增多 |
| 冰川退缩 | 全球冰川普遍消退 |

## IPCC 报告

- 联合国气候变化专门委员会（IPCC）
- 每 5–7 年发布评估报告
- 结论：人类活动是变暖的"明确"原因

## 环境影响

| 问题 | 表现 |
|------|------|
| 生物多样性丧失 | 物种灭绝加速 |
| 海洋酸化 | CO₂ 溶入海水 |
| 荒漠化 | 干旱区退化 |
| 污染 | 空气、水、塑料 |

## 应对

- **减缓**：减排（碳中和、新能源）
- **适应**：应对已发生的变化
- 国际协议：《巴黎协定》（1.5°C/2°C 目标）
