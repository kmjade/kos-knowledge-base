# 04-大气科学

> 研究大气及其现象——天气与气候。

## 大气圈层

| 圈层 | 高度 | 特征 |
|------|------|------|
| 对流层 | 0–12 km | 天气现象，温度随高度降低 |
| 平流层 | 12–50 km | 臭氧层 |
| 中间层 | 50–85 km | 温度最低 |
| 热层 | 85–600 km | 电离层、极光 |

## 气压与风

- 风从高压吹向低压（科里奥利力偏转）
- 全球环流：信风带、西风带、极地东风带

## 天气系统

| 系统 | 特征 |
|------|------|
| 气旋（低压） | 上升气流、多雨 |
| 反气旋（高压） | 下沉气流、晴朗 |
| 锋面 | 冷锋、暖锋、准静止锋 |
| 台风/飓风 | 热带气旋，强风暴雨 |

## 气候分类（柯本分类）

| 气候带 | 特征 |
|------|------|
| 热带 | 高温多雨 |
| 干旱 | 降水少 |
| 温带 | 四季分明 |
| 寒带 | 低温 |
| 极地 | 冰雪覆盖 |

## 大气成分

- 氮 78%、氧 21%、氩 0.9%、二氧化碳 0.04%
- 温室气体：CO₂、CH₄、水汽、N₂O
