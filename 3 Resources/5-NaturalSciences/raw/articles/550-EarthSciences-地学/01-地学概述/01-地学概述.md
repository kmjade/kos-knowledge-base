# 01-地学概述

> 研究地球的科学——从圈层结构到地质时间。

## 地球圈层

```
大气圈 → 水圈 → 生物圈 → 岩石圈 → 地幔 → 外核 → 内核
```

| 圈层 | 组成 | 厚度 |
|------|------|------|
| 地壳 | 岩石 | 5–70 km |
| 地幔 | 硅酸盐矿物 | ~2900 km |
| 外核 | 液态铁镍 | ~2200 km |
| 内核 | 固态铁镍 | ~1200 km |

## 地质年代

| 宙 | 代 | 关键事件 |
|------|------|------|
| 冥古宙-太古宙 | — | 地球形成、生命起源 |
| 元古宙 | — | 大气氧化、真核生物 |
| 显生宙 | 古生代 | 寒武纪大爆发 |
| | 中生代 | 恐龙、裸子植物 |
| | 新生代 | 哺乳动物、人类 |

- 地质学、地貌学、大气科学、海洋科学、水文学
