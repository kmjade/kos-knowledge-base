# 06-水文学

> 研究水的分布、循环与运动——水是生命与文明的命脉。

## 水循环

```
海洋 → 蒸发 → 大气水汽 → 降水 → 地表径流/下渗 → 地下水 → 回归海洋
```

## 河流

| 概念 | 说明 |
|------|------|
| 流域 | 河流集水区域 |
| 流量 | 单位时间过水体积 |
| 含沙量 | 水体中的泥沙 |
| 洪峰 | 洪水最高流量 |

- 河流补给：雨水、冰雪融水、地下水
- 洪涝与干旱的防治

## 地下水

| 类型 | 特征 |
|------|------|
| 潜水 | 第一个隔水层之上的水 |
| 承压水 | 两层隔水层之间的水 |
| 泉 | 地下水自然出露 |

- 含水层、隔水层
- 过度开采 → 地面沉降、海水入侵

## 水资源

- 地球淡水资源仅占 2.5%，可利用的更少
- 冰川是最大淡水储存
- 水资源分布不均 → 缺水与调水工程

## 冰川

- 高山冰川、大陆冰盖（格陵兰、南极）
- 冰川退缩 = 气候变暖的重要指标
