# 06-狭义相对论

> 爱因斯坦 1905 年的革命——在光速不变的基础上重建时间与空间。

## 两条基本假设

1. **光速不变原理**：真空光速对所有惯性系都是 $c$
2. **相对性原理**：物理定律在所有惯性系中形式相同

## 核心效应

| 效应 | 公式 |
|------|------|
| 时间膨胀 | $\Delta t' = \gamma \Delta t$，$\gamma = \frac{1}{\sqrt{1-v^2/c^2}}$ |
| 长度收缩 | $L' = L/\gamma$ |
| 质能方程 | $E = mc^2$ |
| 相对论动量 | $p = \gamma mv$ |

## 能量-动量关系

$$E^2 = (pc)^2 + (mc^2)^2$$

- 静质量 $m$：$E = mc^2$
- 无质量粒子（光子）：$E = pc$

## 时空观变革

- 时间与空间不再是绝对的，统一为**四维时空**
- 同时性是相对的
- 因果律由光锥界定

> 应用：GPS 卫星需修正相对论时间膨胀（否则定位误差累计）。
