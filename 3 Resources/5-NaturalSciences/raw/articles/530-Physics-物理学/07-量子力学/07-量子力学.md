# 07-量子力学

> 微观世界的物理——波粒二象性、概率诠释与不确定性。

## 波粒二象性

$$E = h\nu, \quad p = \frac{h}{\lambda}$$

- 光既是波又是粒子（光电效应、康普顿散射）
- 德布罗意：物质也有波动性

## 薛定谔方程

$$i\hbar\frac{\partial}{\partial t}\Psi = \hat{H}\Psi$$

- $\Psi$ 是波函数，$|\Psi|^2$ 是概率密度
- 定态方程：$\hat{H}\Psi = E\Psi$

## 海森堡不确定性原理

$$\Delta x \cdot \Delta p \ge \frac{\hbar}{2}$$

- 位置与动量无法同时精确测量
- 能量与时间也有类似关系

## 核心概念

| 概念 | 说明 |
|------|------|
| **量子化** | 能量、角动量取离散值 |
| **叠加态** | 量子态可以是多个态的线性叠加 |
| **测量坍缩** | 测量使叠加态坍缩到本征态 |
| **量子纠缠** | 粒子间非局域关联 |

## 应用

- 半导体与晶体管（能带论）
- 激光、量子计算、量子密码
- 化学键的量子解释
