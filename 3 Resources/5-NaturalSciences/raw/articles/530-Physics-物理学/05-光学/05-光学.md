# 05-光学

> 光的传播、干涉、衍射与偏振——从几何光学到波动光学。

## 几何光学

| 定律 | 内容 |
|------|------|
| 反射定律 | $\theta_i = \theta_r$ |
| 折射定律（斯涅尔） | $n_1\sin\theta_1 = n_2\sin\theta_2$ |
| 全反射 | 从光密到光疏，入射角 > 临界角 |

## 波动光学

| 现象 | 条件 |
|------|------|
| **干涉** | 相干光叠加（杨氏双缝） |
| **衍射** | 光遇障碍物弯曲（单缝、光栅） |
| **偏振** | 横波特性（马吕斯定律 $I = I_0\cos^2\theta$） |

## 关键公式

- 杨氏双缝：$d\sin\theta = m\lambda$（亮纹）
- 单缝衍射：$a\sin\theta = m\lambda$（暗纹）
- 光栅方程：$d\sin\theta = m\lambda$

## 应用

- 光纤通信（全反射）
- 干涉仪（精密测距、引力波探测 LIGO）
- 偏振太阳镜、液晶显示
