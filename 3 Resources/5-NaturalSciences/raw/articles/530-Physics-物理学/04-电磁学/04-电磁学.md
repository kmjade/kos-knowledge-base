# 04-电磁学

> 电与磁的统一——麦克斯韦方程组是经典物理的最高成就之一。

## 库仑定律

$$F = k\frac{q_1 q_2}{r^2}$$

- 电荷间的力与距离平方成反比

## 麦克斯韦方程组

| 定律 | 微分形式 |
|------|------|
| 高斯定律（电） | $\nabla\cdot\vec{E} = \frac{\rho}{\varepsilon_0}$ |
| 高斯定律（磁） | $\nabla\cdot\vec{B} = 0$（无磁单极） |
| 法拉第定律 | $\nabla\times\vec{E} = -\frac{\partial\vec{B}}{\partial t}$ |
| 安培-麦克斯韦定律 | $\nabla\times\vec{B} = \mu_0\vec{J} + \mu_0\varepsilon_0\frac{\partial\vec{E}}{\partial t}$ |

## 电磁波

$$c = \frac{1}{\sqrt{\mu_0\varepsilon_0}}$$

- 麦克斯韦预言：变化的电场产生磁场，变化的磁场产生电场 → 电磁波
- 光就是电磁波（频率决定类型：无线电、红外、可见光、X 射线）

## 电路基础

| 定律 | 内容 |
|------|------|
| 欧姆定律 | $V = IR$ |
| 基尔霍夫电流定律 | 节点电流和为 0 |
| 基尔霍夫电压定律 | 回路电压和为 0 |
