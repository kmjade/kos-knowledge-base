# 08-广义相对论与引力

> 爱因斯坦 1915 年的杰作——引力不是力，而是时空的弯曲。

## 等效原理

- 引力质量 = 惯性质量（弱等效原理）
- 局部无法区分均匀引力场与加速参考系

## 爱因斯坦场方程

$$G_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$$

- 左侧：时空几何（曲率）
- 右侧：物质能量分布
- 「物质告诉时空如何弯曲，时空告诉物质如何运动」

## 三大经典验证

| 验证 | 现象 |
|------|------|
| 水星近日点进动 | 每世纪 43 角秒的额外进动 |
| 光线偏折 | 太阳附近光线弯曲（1919 爱丁顿观测） |
| 引力红移 | 光逃离引力场频率降低 |

## 黑洞

| 概念 | 说明 |
|------|------|
| 事件视界 | $r_s = \frac{2GM}{c^2}$（史瓦西半径） |
| 奇点 | 曲率无穷大的中心点 |
| 霍金辐射 | 黑洞因量子效应缓慢蒸发 |

## 引力波

- 时空涟漪，以光速传播
- **2015 LIGO 首次直接探测**（GW150914 双黑洞并合）
- 2017 引力波 + 电磁对应体（GW170817 双中子星）
