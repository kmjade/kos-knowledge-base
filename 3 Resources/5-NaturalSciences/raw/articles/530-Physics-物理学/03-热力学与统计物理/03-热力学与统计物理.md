# 03-热力学与统计物理

> 从宏观（热力学）与微观（统计力学）两个视角理解热现象。

## 热力学定律

| 定律 | 内容 |
|------|------|
| 第零定律 | 热平衡的传递性（温度的定义） |
| 第一定律 | 能量守恒：$\Delta U = Q - W$ |
| 第二定律 | 熵增：孤立系统熵不减 $dS \ge 0$ |
| 第三定律 | 绝对零度不可达 |

## 熵

$$S = k_B \ln \Omega$$

- **玻尔兹曼熵公式**：熵 = 微观状态数的对数
- 熵是「无序度」的度量
- 第二定律 = 孤立系统自发走向最概然（无序）状态

## 统计分布

| 分布 | 适用 | 公式 |
|------|------|------|
| 玻尔兹曼 | 经典粒子 | $P \propto e^{-E/k_BT}$ |
| 玻色-爱因斯坦 | 玻色子 | $\frac{1}{e^{E/kT}-1}$ |
| 费米-狄拉克 | 费米子 | $\frac{1}{e^{E/kT}+1}$ |

## 热力学过程

| 过程 | 特征 |
|------|------|
| 等温 | $T$ 恒定，$PV = \text{const}$ |
| 绝热 | 无热交换，$PV^\gamma = \text{const}$ |
| 等容 / 等压 | 体积/压强恒定 |
