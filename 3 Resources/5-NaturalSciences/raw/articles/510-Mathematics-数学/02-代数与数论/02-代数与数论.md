# 02-代数与数论

> 从数系到方程，从多项式到同余——代数是研究符号运算的学科。

## 数系

```
自然数 ℕ ⊂ 整数 ℤ ⊂ 有理数 ℚ ⊂ 实数 ℝ ⊂ 复数 ℂ
```

| 数系 | 符号 | 关键性质 |
|------|:--:|------|
| 自然数 | ℕ | 0, 1, 2, … |
| 整数 | ℤ | 可作减法 |
| 有理数 | ℚ | 可作除法（分母非零） |
| 实数 | ℝ | 完备性（无「洞」） |
| 复数 | ℂ | $i^2 = -1$，代数封闭 |

## 方程与多项式

- 一元二次方程：$ax^2 + bx + c = 0$，根公式 $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$
- 韦达定理：$x_1 + x_2 = -b/a$，$x_1 x_2 = c/a$
- 多项式因式分解、最大公因式（欧几里得算法）

## 数论要点

| 概念       | 说明                                      |
| -------- | --------------------------------------- |
| **素数**   | 只有 1 和自身两个正因子                           |
| **同余**   | $a \equiv b \pmod{n}$ 表示 $n \mid (a-b)$ |
| **模运算**  | 密码学与哈希的数学基础                             |
| **欧拉函数** | $\varphi(n)$ = 小于 n 且与 n 互素的数的个数        |
