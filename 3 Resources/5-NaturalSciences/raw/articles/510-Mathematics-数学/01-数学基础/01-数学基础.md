# 01-数学基础

> 数学的「语法」——逻辑、集合与证明，是理解一切更高等数学的前提。

## 命题逻辑

| 联结词 | 符号 | 真值 |
|------|:--:|------|
| 合取（且） | ∧ | 两者皆真才真 |
| 析取（或） | ∨ | 至少一真即真 |
| 蕴含 | → | 前真后假才假 |
| 否定 | ¬ | 取反 |

## 集合论

> 集合论是现代数学的「地基」——几乎所有数学对象（数、函数、空间）都能被定义为集合。它也是「从朴素到公理化」的经典范例。

### 集合的表示

| 方法 | 形式 | 示例 |
|------|------|------|
| **列举法** | 逐一列出元素 | $A = \{1, 2, 3, 4\}$ |
| **描述法** | 用性质描述 | $B = \{x \mid x \text{ 是偶数}\}$ |
| **空集** | 无元素的集合 | $\varnothing = \{\}$ |

### 集合关系

| 关系 | 符号 | 定义 |
|------|:--:|------|
| **元素属于** | $\in$ | $a \in A$ |
| **子集** | $\subseteq$ | $A$ 的每个元素都在 $B$ 中 |
| **真子集** | $\subsetneq$ | $A \subseteq B$ 且 $A \neq B$ |
| **相等** | $=$ | $A \subseteq B$ 且 $B \subseteq A$（外延公理） |

### 集合运算

| 运算 | 符号 | 定义 |
|------|:--:|------|
| **并** | $\cup$ | $A \cup B = \{x \mid x\in A \text{ 或 } x\in B\}$ |
| **交** | $\cap$ | $A \cap B = \{x \mid x\in A \text{ 且 } x\in B\}$ |
| **补** | $\complement$ | $\complement_U A = \{x \in U \mid x \notin A\}$ |
| **差** | $-$ | $A - B = \{x \mid x\in A \text{ 且 } x\notin B\}$ |
| **对称差** | $\triangle$ | $A \triangle B = (A-B) \cup (B-A)$ |
| **笛卡尔积** | $\times$ | $A \times B = \{(a,b) \mid a\in A, b\in B\}$ |

### 运算律（集合代数）

| 定律 | 形式 |
|------|------|
| **交换律** | $A\cup B = B\cup A$；$A\cap B = B\cap A$ |
| **结合律** | $(A\cup B)\cup C = A\cup(B\cup C)$ |
| **分配律** | $A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$ |
| **德摩根定律** | $\complement(A\cup B) = \complement A \cap \complement B$；$\complement(A\cap B) = \complement A \cup \complement B$ |
| **吸收律** | $A \cup (A\cap B) = A$；$A \cap (A\cup B) = A$ |

### 幂集

$$\mathcal{P}(A) = \{S \mid S \subseteq A\}$$

- 若 $|A| = n$，则 $|\mathcal{P}(A)| = 2^n$
- 例：$\mathcal{P}(\{a,b\}) = \{\varnothing, \{a\}, \{b\}, \{a,b\}\}$

### 基数与可数性

| 概念 | 含义 | 示例 |
|------|------|------|
| **基数** | 集合「大小」的度量 | $\|A\|$ |
| **可数集** | 能与自然数建立一一对应 | ℕ、ℤ、ℚ |
| **不可数集** | 不能与自然数一一对应 | ℝ、$\mathcal{P}(\mathbb{N})$ |

> **康托对角线法**：证明实数不可数——假设 ℝ 可数，构造一个不在列表中的实数，导出矛盾。

### 罗素悖论与公理化集合论

- **罗素悖论**：令 $R = \{x \mid x \notin x\}$（所有不自含的集合）。若 $R \in R$ 则 $R \notin R$；若 $R \notin R$ 则 $R \in R$ —— 矛盾。
- **教训**：朴素集合论（「任意性质都定义一个集合」）导致悖论。
- **解决**：ZFC 公理化集合论——通过公理（分离、正则、选择等）限制集合的构造方式。

## 证明方法

| 方法 | 思路 |
|------|------|
| **直接证明** | 由条件直接推出结论 |
| **反证法** | 假设结论不成立，导出矛盾 |
| **数学归纳法** | 证 $n=1$ 成立，再证 $n \Rightarrow n+1$ |
| **构造性证明** | 直接构造满足条件的对象 |
