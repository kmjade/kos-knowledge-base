# 06-统计学与推断

> 从数据到结论——估计、检验与回归。与 DDC 310 统计学共享方法，此处侧重数学理论根基。

## 估计

| 概念 | 说明 |
|------|------|
| **点估计** | 用样本统计量估计总体参数（均值、方差） |
| **区间估计** | 置信区间：$\bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$ |
| **极大似然估计 (MLE)** | 找使数据出现概率最大的参数 |

## 假设检验

| 概念 | 说明 |
|------|------|
| **零假设 H₀** | 待检验的默认假设（无差异） |
| **p 值** | 在 H₀ 为真时观察到当前数据的概率 |
| **两类错误** | I 类（拒真）· II 类（存伪） |
| **功效** | $1 - \beta$，正确拒绝 H₀ 的能力 |

## 回归

| 类型 | 模型 |
|------|------|
| **线性** | $y = \beta_0 + \beta_1 x + \varepsilon$ |
| **多元** | $y = X\beta + \varepsilon$，$\hat{\beta} = (X^TX)^{-1}X^Ty$ |
| **逻辑** | $P(y=1) = \sigma(\beta^T x)$ |

## 贝叶斯推断

$$P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)}$$

- **先验** $P(\theta)$ → **似然** $P(D|\theta)$ → **后验** $P(\theta|D)$
- 后验是「更新后的信念」
