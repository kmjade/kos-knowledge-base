# 03-线性代数

> 向量、矩阵与特征分解——机器学习、计算机图形学与量化模型的数学基石。

## 向量与矩阵

| 运算 | 定义 |
|------|------|
| **点积** | $\mathbf{a}\cdot\mathbf{b} = \sum a_i b_i$ |
| **矩阵乘法** | $(AB)_{ij} = \sum_k a_{ik} b_{kj}$ |
| **转置** | $(A^T)_{ij} = a_{ji}$ |
| **逆矩阵** | $A A^{-1} = I$（方阵且行列式非零） |

## 关键概念

- **线性无关 / 基 / 维数**：向量空间的「坐标系」
- **秩**：矩阵中最大线性无关列数
- **行列式**：$\det(A)$，刻画「体积缩放」与可逆性
- **特征值 / 特征向量**：$A\mathbf{v} = \lambda \mathbf{v}$

## 特征分解（ML 核心）

```
A = Q Λ Q⁻¹     （Q 为特征向量矩阵，Λ 为特征值对角矩阵）
```

应用：
- **PCA 降维** — 主成分 = 最大特征值对应的特征向量
- **SVD 分解** — 推荐系统、潜在语义分析
- **协方差矩阵** — 投资组合风险结构
