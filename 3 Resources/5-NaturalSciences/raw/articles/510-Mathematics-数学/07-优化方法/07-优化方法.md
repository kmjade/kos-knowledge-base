# 07-优化方法

> 在约束下寻找最优解——机器学习训练、投资组合构建与参数调优的核心引擎。

## 基本问题形式

$$\min_{x} f(x) \quad \text{s.t.} \quad g_i(x) \le 0,\; h_j(x) = 0$$

## 关键方法

| 方法 | 适用 | 要点 |
|------|------|------|
| **梯度下降** | 光滑函数 | $x_{t+1} = x_t - \eta \nabla f(x_t)$ |
| **牛顿法** | 二次收敛 | $x_{t+1} = x_t - H^{-1}\nabla f(x_t)$ |
| **拉格朗日乘数** | 等式约束 | $\nabla f = \lambda \nabla g$ |
| **KKT 条件** | 一般约束 | 不等式约束下的最优性条件 |
| **线性规划** | 线性目标+约束 | 单纯形法 |

## 凸优化

- **凸函数**：$\forall x,y$，$f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$
- **凸优化 = 局部最优即全局最优**，这是「好优化问题」的标准

## 交易/金融应用

| 应用 | 优化目标 |
|------|------|
| **均值-方差组合** | 最大化夏普比率 $\max_w \frac{\mu^T w - r_f}{\sqrt{w^T\Sigma w}}$ |
| **凯利准则** | 最大化长期增长率 $E[\ln(1 + f \cdot R)]$ |
| **参数寻优** | 回测中调 EA 参数（注意过拟合） |
