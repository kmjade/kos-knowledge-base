# 09-应用数学

> 数学的「落地」——把前八章的工具应用到交易、机器学习与金融建模中。

## 交易数学

| 概念 | 公式 | 用途 |
|------|------|------|
| **凯利公式** | $f^* = \frac{p(b+1)-1}{b}$ | 最优仓位比例 |
| **期望值** | $E = p \cdot W - (1-p) \cdot L$ | 策略评估 |
| **夏普比率** | $S = \frac{\bar{R} - r_f}{\sigma_R}$ | 风险调整收益 |
| **最大回撤** | $\max\left(\frac{\text{peak} - \text{trough}}{\text{peak}}\right)$ | 风险评估 |
| **VaR** | $VaR_\alpha = -\Phi^{-1}(1-\alpha)\sigma$ | 尾部风险 |

## 机器学习中的数学

| 模型 | 数学核心 |
|------|------|
| **线性回归** | 最小二乘（投影） |
| **逻辑回归** | 交叉熵损失 + 梯度下降 |
| **神经网络** | 链式法则（反向传播）+ 矩阵乘法 |
| **PCA** | 特征分解 |
| **SVM** | 凸优化 + 核技巧 |

## 金融建模

- **Black-Scholes 期权定价**：偏微分方程 + 布朗运动
- **随机微积分**：Itô 引理、鞅
- **利率模型**：Vasicek、CIR
- **投资组合理论**：Markowitz 均值-方差
