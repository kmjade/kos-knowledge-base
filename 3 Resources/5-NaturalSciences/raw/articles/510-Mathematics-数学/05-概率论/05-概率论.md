# 05-概率论

> 量化和驾驭不确定性的数学——交易、风险管理与机器学习的核心语言。

## 概率公理

| 公理 | 内容 |
|------|------|
| **非负性** | $P(A) \ge 0$ |
| **规范性** | $P(\Omega) = 1$ |
| **可加性** | 互斥事件：$P(A\cup B) = P(A) + P(B)$ |

## 核心规则

| 规则 | 公式 |
|------|------|
| 条件概率 | $P(A|B) = \frac{P(A\cap B)}{P(B)}$ |
| **贝叶斯定理** | $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$ |
| 独立性 | $P(A\cap B) = P(A)P(B)$ |

## 关键分布

| 分布 | 适用场景 | 参数 |
|------|------|------|
| **正态** | 收益、测量误差、CLT 极限 | μ, σ |
| **对数正态** | 资产价格（非负、右偏） | μ, σ |
| **二项** | 胜负次数、交易盈亏 | n, p |
| **泊松** | 事件到达（跳空、订单流） | λ |
| **指数** | 等待时间、持仓时长 | λ |

## 大数定律与中心极限定理

| 定理 | 内容 | 交易启示 |
|------|------|------|
| **大数定律** | 样本均值 → 总体均值 | 样本越大，统计越可靠 |
| **中心极限定理** | 样本均值 → 正态分布 | 回测结果的置信区间 |

## 随机过程

- **随机游走** — 有效市场假说的数学基础
- **布朗运动** — Black-Scholes 期权定价的底层
- **马尔可夫链** — 状态转移、市场 regime 切换
