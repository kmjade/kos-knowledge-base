# 04-微积分与分析

> 研究「变化」与「累积」的学科——导数量化瞬时变化率，积分量化累积量。

## 核心概念

| 概念 | 符号 | 意义 |
|------|:--:|------|
| **极限** | $\lim_{x\to a} f(x)$ | 趋近但不必到达 |
| **导数** | $f'(x) = \frac{df}{dx}$ | 瞬时变化率（切线斜率） |
| **积分** | $\int f(x)\,dx$ | 累积量（曲线下面积） |
| **级数** | $\sum a_n$ | 无穷求和 |

## 微积分基本定理

$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$$

导数与积分互为逆运算——这是微积分的核心枢纽。

## 关键公式

| 函数 | 导数 |
|------|------|
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |

## 泰勒展开

$$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n$$

- 用多项式逼近任意光滑函数
- 金融中的久期/凸性近似、期权定价都依赖它
