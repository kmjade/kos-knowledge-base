# 07-物理化学

> 用物理定律解释化学现象——热力学、动力学与电化学。

## 化学热力学

| 概念 | 说明 |
|------|------|
| 焓变 ΔH | 反应热（放热 ΔH<0，吸热 ΔH>0） |
| 熵变 ΔS | 无序度变化 |
| 吉布斯自由能 | $\Delta G = \Delta H - T\Delta S$ |

- 自发反应：$\Delta G < 0$
- 平衡时：$\Delta G = 0$

## 化学动力学

| 概念 | 说明 |
|------|------|
| 反应速率 | 浓度变化率 $v = -\frac{d[A]}{dt}$ |
| 速率方程 | $v = k[A]^m[B]^n$ |
| 阿伦尼乌斯方程 | $k = Ae^{-E_a/RT}$ |
| 催化剂 | 降低活化能，不改变平衡 |

## 电化学

| 概念 | 说明 |
|------|------|
| 原电池 | 化学能 → 电能 |
| 电解池 | 电能 → 化学能 |
| 能斯特方程 | $E = E^\circ - \frac{RT}{nF}\ln Q$ |

- 电池、电镀、金属防腐都依赖电化学
