# 02-原子结构与元素周期表

> 原子的内部世界与元素的排列规律。

## 原子结构

| 粒子 | 电荷 | 质量 |
|------|:--:|------|
| 质子 | +1 | 1 u |
| 中子 | 0 | 1 u |
| 电子 | -1 | ~0 |

## 电子构型

- 电子按能级排布：1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p…
- 泡利不相容原理、洪特规则、能量最低原理

## 元素周期表

| 区域 | 元素 |
|------|------|
| s 区 | 碱金属、碱土金属 |
| p 区 | 非金属、卤素、稀有气体 |
| d 区 | 过渡金属 |
| f 区 | 镧系、锕系 |

## 周期律（周期趋势）

| 性质 | 同周期（左→右） | 同族（上→下） |
|------|:--:|:--:|
| 原子半径 | 减小 | 增大 |
| 电离能 | 增大 | 减小 |
| 电负性 | 增大 | 减小 |
| 金属性 | 减弱 | 增强 |
