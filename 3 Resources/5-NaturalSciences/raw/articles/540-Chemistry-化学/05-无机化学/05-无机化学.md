# 05-无机化学

> 研究所有元素及其化合物（除碳的复杂化合物外）。

## 主族元素

| 族 | 名称 | 特征 |
|------|------|------|
| 1 (IA) | 碱金属 | 极活泼，与水反应 |
| 2 (IIA) | 碱土金属 | 较活泼 |
| 17 (VIIA) | 卤素 | 强氧化性，非金属 |
| 18 (VIIIA) | 稀有气体 | 惰性、稳定 |

## 过渡金属

- d 区元素，多价态、可形成配合物
- 常见：铁 Fe、铜 Cu、锌 Zn、铬 Cr、锰 Mn
- 有色离子、催化性能

## 配合物

- 中心金属离子 + 配体
- 例：$[Cu(NH_3)_4]^{2+}$、$[Fe(CN)_6]^{4-}$
- 配位数、几何构型（四面体、平面正方、八面体）

## 重要化合物

| 类别 | 示例 |
|------|------|
| 酸 | HCl, H₂SO₄, HNO₃ |
| 碱 | NaOH, Ca(OH)₂ |
| 盐 | NaCl, CaCO₃ |
| 氧化物 | CO₂, SiO₂, Fe₂O₃ |
