# 01-化学概述

> 化学的「地图」——物质、原子与基本概念。

## 物质的分类

```
物质
├── 纯净物
│   ├── 单质（同种元素）
│   └── 化合物（不同元素）
└── 混合物（两种以上纯净物）
```

## 基本概念

| 概念 | 定义 |
|------|------|
| 原子 | 化学变化的最小粒子 |
| 分子 | 保持物质化学性质的最小粒子 |
| 元素 | 具有相同质子数的原子总称 |
| 化合物 | 由不同元素组成的纯净物 |

## 化学变化 vs 物理变化

| 类型 | 特征 |
|------|------|
| 物理变化 | 无新物质生成（状态改变） |
| 化学变化 | 有新物质生成（原子重组） |

## 化学的五大分支

1. 无机化学、2. 有机化学、3. 物理化学、4. 分析化学、5. 生物化学
