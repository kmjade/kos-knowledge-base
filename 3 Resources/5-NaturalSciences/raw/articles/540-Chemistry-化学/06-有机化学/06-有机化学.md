# 06-有机化学

> 碳化合物的化学——生命、药物、材料与能源的基础。

## 官能团

| 官能团 | 结构 | 化合物类别 |
|------|------|------|
| 羟基 | -OH | 醇 |
| 羰基 | >C=O | 醛、酮 |
| 羧基 | -COOH | 羧酸 |
| 氨基 | -NH₂ | 胺 |
| 酯基 | -COOR | 酯 |
| 醚键 | -O- | 醚 |
| 双键/三键 | C=C / C≡C | 烯烃/炔烃 |

## 常见反应类型

| 反应 | 说明 |
|------|------|
| 加成反应 | 双键/三键断裂，加入原子 |
| 取代反应 | 一个原子/基团被替换 |
| 消除反应 | 脱去小分子形成双键 |
| 酯化 | 醇 + 酸 → 酯 + 水 |
| 聚合 | 单体连接成高分子 |

## 同分异构体

- **结构异构**：碳链、位置、官能团不同
- **立体异构**：顺反异构、对映异构（手性）

## 重要有机分子

- 烷烃（甲烷 CH₄）、烯烃（乙烯 C₂H₄）
- 醇（乙醇）、醛（甲醛）、羧酸（乙酸）
- 芳香烃（苯）、生物大分子（糖、脂、蛋白）
