# 逻辑学 — Logic (UDC 16)

> [!info] UDC 16 — 逻辑学
> 研究推理有效性形式与思维规律的科学，追问「什么使一个论证有效？正确的推理形式是什么？」。涵盖形式逻辑、命题逻辑、谓词逻辑、模态逻辑、归纳逻辑、数理逻辑与非经典逻辑，是哲学、数学与计算机科学的共同根基。
