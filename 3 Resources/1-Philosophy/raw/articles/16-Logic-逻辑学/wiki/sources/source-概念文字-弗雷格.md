# 《概念文字》· 弗雷格

《概念文字》（Begriffsschrift, 1879）是弗雷格的奠基之作，建立了第一个完整的谓词逻辑系统，引入量词理论，被誉为「现代数理逻辑的开端」。

| 概念与对象 | 概念是函数 |
| 逻辑主义 | 算术可还原为逻辑 |
