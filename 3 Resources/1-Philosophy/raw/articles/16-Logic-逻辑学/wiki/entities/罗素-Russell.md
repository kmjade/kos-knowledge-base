# 罗素 Russell

伯特兰·罗素（1872–1970），英国哲学家、逻辑学家与数学家。他提出罗素悖论动摇朴素集合论，并与怀特海合著《数学原理》（Principia Mathematica），推动逻辑主义纲领。

| 类型论 | 分层解决悖论 |
| 《数学原理》 | 逻辑主义纲领的里程碑 |
| 摹状词理论 | 分析「现在的法国国王是秃子」 |
