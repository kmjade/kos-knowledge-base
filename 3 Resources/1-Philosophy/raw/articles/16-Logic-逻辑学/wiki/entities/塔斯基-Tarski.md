# 塔斯基 Tarski

阿尔弗雷德·塔斯基（1901–1983），波兰逻辑学家与数学家，模型论与语义学奠基人。他提出形式化语义真理理论，澄清「真」概念的逻辑结构。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 语义真理理论 | 「雪是白的」为真当且仅当雪是白的 |
| 模型论 | 形式语言与解释的关系 |
| T-模式 | 真理的形式化定义 |
| 逻辑后承 | 有效性的语义刻画 |
