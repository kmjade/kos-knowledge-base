# 弗雷格 Frege

戈特洛布·弗雷格（1848–1925），德国数学家、逻辑学家与哲学家，现代数理逻辑的奠基人。他在《概念文字》（Begriffsschrift, 1879）中首次建立完整的谓词逻辑，被誉为「分析哲学之父」。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 《概念文字》 | 第一个完整的谓词逻辑系统 |
| 量词理论 | 引入全称与存在量词 |
| 涵义与指称 | 区分 Sinn 与 Bedeutung |
| 逻辑主义 | 试图将算术还原为逻辑 |
