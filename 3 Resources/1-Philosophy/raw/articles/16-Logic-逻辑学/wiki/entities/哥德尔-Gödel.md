# 哥德尔 Gödel

库尔特·哥德尔（1906–1978），奥地利逻辑学家、数学家，20 世纪最重要的逻辑学家之一。1931 年证明不完备定理，彻底改变了数学基础研究的方向。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 不完备定理 | 一致系统存在真而不可证命题 |
| 完备性定理 | 一阶逻辑的完备性 |
| 递归函数 | 可计算性理论的先驱 |
| 连续统假设 | 与 ZFC 的一致性证明 |
