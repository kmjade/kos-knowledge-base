# 谬误 Fallacy

## 定义

「谬误」（Fallacy）是看似有效、实则错误的推理方式，分为形式谬误（违反推理形式规则）与非形式谬误（违反论证内容或语境规则）。

## 形式谬误

| 谬误 | 形式 |
|------|------|
| 肯定后件 | p→q, q ⊢ p |
| 否定前件 | p→q, ¬p ⊢ ¬q |

## 非形式谬误

| 谬误 | 说明 |
|------|------|
| 诉诸人身 | 攻击论者而非论点 |
| 稻草人 | 曲解对方观点再反驳 |
| 滑坡 | 夸大连锁后果 |
| 循环论证 | 结论预设于前提 |
