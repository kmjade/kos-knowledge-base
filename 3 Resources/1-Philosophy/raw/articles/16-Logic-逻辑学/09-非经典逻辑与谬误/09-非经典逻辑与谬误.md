# 09-非经典逻辑与谬误

> 经典逻辑建立在二值原则（命题非真即假）与实质蕴涵之上。非经典逻辑质疑这些预设，拓展了逻辑的表达力；谬误则刻画了推理失效的典型方式。

## 非经典逻辑谱系

| 逻辑 | 质疑的预设 | 主张 |
|------|-----------|------|
| 多值逻辑 | 二值原则 | 命题可取第三值（如「不确定」） |
| 模糊逻辑 | 精确边界 | 真值可以是 [0,1] 连续区间 |
| 直觉主义逻辑 | 排中律 | 拒斥「p∨¬p」的普遍有效性 |
| 相关逻辑 | 实质蕴涵悖论 | 前件与结论必须相关 |
| 弗协调逻辑 | 爆炸原理 | 容忍矛盾而不推出一切 |
| 非单调逻辑 | 单调性 | 新增信息可推翻旧结论 |

## 经典逻辑的三大预设

| 预设 | 内容 | 挑战者 |
|------|------|--------|
| 二值原则 | 命题非真即假 | 多值·模糊逻辑 |
| 排中律 | p∨¬p 恒真 | 直觉主义 |
| 爆炸原理 | 从矛盾推出一切 | 弗协调逻辑 |

## 逻辑谬误（Fallacy）分类

### 形式谬误（Formal Fallacies）

| 谬误 | 形式 |
|------|------|
| 肯定后件 | p→q, q ⊢ p |
| 否定前件 | p→q, ¬p ⊢ ¬q |
| 中项不周延 | 三段论结构错误 |

### 非形式谬误（Informal Fallacies）

| 谬误 | 说明 |
|------|------|
| 诉诸人身（Ad Hominem） | 攻击论者而非论点 |
| 稻草人（Straw Man） | 曲解对方观点再反驳 |
| 诉诸权威（Ad Verecundiam） | 以权威代替论证 |
| 滑坡（Slippery Slope） | 夸大连锁后果 |
| 循环论证（Begging the Question） | 结论预设于前提 |
| 虚假两难（False Dilemma） | 只给两个选项 |
