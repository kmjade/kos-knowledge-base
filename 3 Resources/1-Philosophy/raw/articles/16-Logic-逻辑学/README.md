# 逻辑学 (Logic / UDC 16)

> 关于「推理有效性」的科学——什么使一个论证有效？正确的思维形式是什么？从亚里士多德的三段论到哥德尔的不完备定理，逻辑学为一切理性论证提供形式根基。
