# 🗺️ MOC · 逻辑学总览

> 逻辑学（Logic）的核心问题可归结为两类：**「推理如何有效？」（演绎/归纳）** 与 **「有效性的形式基础是什么？」（形式系统/元逻辑）**。

## 历史脉络

```
亚里士多德「三段论」（《工具论》）→ 中世纪经院逻辑 → 莱布尼茨「普遍字符」
→ 布尔代数（逻辑数学化）→ 弗雷格/罗素（现代数理逻辑）→ 哥德尔不完备定理
→ 塔斯基模型论 → 20 世纪模态逻辑复兴（克里普克可能世界语义）→ 非经典逻辑扩展
```

## 三大传统（推理类型）

| 类型 | 主张 | 代表 |
|------|------|------|
| 演绎 | 前提真则结论必然真（保真性） | 亚里士多德·弗雷格 |
| 归纳 | 从经验证据支持一般结论（概然性） | 培根·穆勒 |
| 溯因 | 最佳解释推理（从结果追溯原因） | 皮尔士 |

## 两大流派（20 世纪）

| 流派 | 主张 | 代表 |
|------|------|------|
| 逻辑主义 | 数学可还原为逻辑 | 弗雷格·罗素 |
| 形式主义 | 数学是符号操作的形式系统 | 希尔伯特 |
