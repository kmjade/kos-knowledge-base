# 06-归纳逻辑

> 归纳逻辑（Inductive Logic）从经验证据推出一般结论，结论超出前提的内容，因此不具有演绎的保真性，只提供概然性支持。它是科学方法的核心。

## 演绎 vs 归纳

| 维度 | 演绎 | 归纳 |
|------|------|------|
| 方向 | 一般 → 个别 | 个别 → 一般 |
| 保真性 | 前提真则结论必真 | 前提真结论仅概然 |
| 新信息 | 结论不超出前提 | 结论超出前提 |
| 典型 | 三段论 | 科学定律的建立 |

## 归纳推理的类型

| 类型 | 方法 | 例 |
|------|------|----|
| 枚举归纳 | 从样本到全体 | 「所见天鹅皆白，故天鹅皆白」 |
| 类比推理 | 从相似到相似 | 「火星像地球，故可能有生命」 |
| 统计归纳 | 从样本比例到总体概率 | 民意调查 |
| 溯因推理 | 最佳解释 | 「地面湿，故可能下过雨」 |

## 穆勒五法（求因果）

| 方法 | 规则 |
|------|------|
| 求同法 | 结果共同出现的前因即原因 |
| 求异法 | 唯一差异的前因即原因 |
| 求同求异并用法 | 结合上述两者 |
| 共变法 | 随因变化而变的结果 |
| 剩余法 | 排除已知原因后剩余者 |

## 归纳问题（休谟问题）

休谟指出：归纳无法被逻辑或经验证明——「未来将像过去一样」本身就是一个无法证明的假设。这一怀疑至今仍是科学哲学的难题（见 [[3 Resources/1-Philosophy/raw/articles/11-Metaphysics-形而上学/05-因果与必然性/05-因果与必然性\|因果与必然性]]）。

## 概率与确证

现代归纳逻辑用贝叶斯方法刻画证据对假说的确证程度：P(H|E) = P(E|H)·P(H)/P(E)。
