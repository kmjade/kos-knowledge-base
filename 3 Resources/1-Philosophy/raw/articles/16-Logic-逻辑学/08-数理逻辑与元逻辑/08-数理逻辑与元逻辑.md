# 08-数理逻辑与元逻辑

> 数理逻辑用数学方法研究逻辑系统本身，元逻辑（Metalogic）则追问这些系统自身的一致性、完备性与可判定性。哥德尔不完备定理是这一领域的最高成就。

## 数理逻辑的四大分支

| 分支 | 研究对象 |
|------|---------|
| 集合论 | 集合、序数、无穷与公理化 |
| 证明论 | 形式证明的结构与一致性 |
| 模型论 | 形式语言与其解释（模型） |
| 递归论 | 可计算性、图灵机、算法 |

## 形式系统三要素

| 要素 | 说明 |
|------|------|
| 语法 | 符号与合式公式（wff）的规则 |
| 公理 | 不加证明即接受的出发点 |
| 推理规则 | 从公理推出定理的规则 |

## 元逻辑三大性质

| 性质 | 含义 | 一阶逻辑 |
|------|------|---------|
| 一致性（Soundness） | 可证的皆真 | ✅ 成立 |
| 完备性（Completeness） | 真的皆可证 | ✅ 哥德尔完备定理 |
| 可判定性（Decidability） | 有算法判定真假 | ⚠️ 半可判定 |

## 哥德尔不完备定理（1931）

| 定理 | 内容 |
|------|------|
| 第一不完备定理 | 任何包含算术的一致形式系统，必存在「真但不可证」的命题 |
| 第二不完备定理 | 这样的系统无法证明自身的一致性 |

> 这一结果终结了希尔伯特「证明数学一致性与完备性」的纲领，揭示形式系统的内在局限。

## 罗素悖论与集合论危机

罗素发现：令 R = {x | x∉x}，则 R∈R ↔ R∉R，导致矛盾。这一悖论推动了公理化集合论（ZF/ZFC）与类型论的发展。
