# 07-易经的哲学思想

> 易经的哲学思想围绕「变易」「阴阳」「中和」「天人」四大核心展开，是中国哲学（尤其儒家与道家）共同的思想源泉。

## 四大核心思想

| 思想 | 内容 |
|------|------|
| 变易 | 生生之谓易·万物变化不已 |
| 阴阳 | 一阴一阳之谓道 |
| 中和 | 适中和谐·执两用中 |
| 天人 | 天人之道相通·观物取象 |

## 变化观

| 命题 | 含义 |
|------|------|
| 穷则变，变则通，通则久 | 事物穷尽则变，变则通达 |
| 物极必反 | 阴阳转化的规律 |
| 时中 | 因时制宜·把握时机 |

## 中和观

| 概念 | 说明 |
|------|------|
| 中 | 不偏不倚·恰到好处 |
| 和 | 和谐·平衡·统一 |
| 时中 | 随时而中的动态智慧 |

## 天人观

| 命题 | 含义 |
|------|------|
| 观物取象 | 圣人仰观俯察·立象以尽意 |
| 天行健，君子以自强不息 | 效法天道·刚健有为 |
| 地势坤，君子以厚德载物 | 效法地道·宽厚包容 |
