# 08-易学发展史

> 易学历经两千年演进，形成象数与义理两大传统交替发展的格局。从汉代象数易，到魏晋义理易，再到宋代图书易，每一阶段都重塑了易经的诠释方向。

## 发展阶段

| 时期 | 特征 | 代表 |
|------|------|------|
| 先秦 | 经传形成 | 伏羲·文王·孔子 |
| 汉代 | 象数易兴盛 | 京房·郑玄·荀爽 |
| 魏晋 | 义理易奠基 | 王弼·韩康伯 |
| 唐代 | 注疏整理 | 孔颖达《周易正义》 |
| 宋代 | 图书易·理学易 | 邵雍·程颐·朱熹 |
| 清代 | 朴学易 | 惠栋·焦循 |

## 三大转折

| 转折 | 意义 |
|------|------|
| 王弼扫象数 | 以义理取代象数的主导 |
| 邵雍先天易 | 以数理重构易学体系 |
| 朱熹《周易本义》 | 象数与义理的综合 |

## 象数与义理的消长

| 时期 | 主导 |
|------|------|
| 汉代 | 象数派 |
| 魏晋–宋明 | 义理派 |
| 宋（邵雍） | 象数复兴 |
| 朱熹后 | 综合 |
