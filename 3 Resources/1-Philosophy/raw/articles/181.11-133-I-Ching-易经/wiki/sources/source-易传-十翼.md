# 《易传》· 十翼

《易传》（又称「十翼」）是对《周易》本经的哲学阐释，相传为孔子所作。它将易经从卜筮之书提升为哲学经典，是理解易经义理思想的关键文本。

## 关键主题

| 篇目 | 内容 |
|------|------|
| 系辞传 | 总论易道·哲学纲领 |
| 彖传 | 断卦义 |
| 象传 | 解卦象与爻象 |
| 文言传 | 专释乾坤 |
