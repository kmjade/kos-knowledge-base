# 《周易》· 易经

《周易》（又称《易经》）是中国哲学的源头经典、五经之首。它以八卦、六十四卦与卦爻辞为核心，既是卜筮之书，也是穷究阴阳变易的哲学经典，相传历经伏羲、文王、周公而渐成。

## 关键主题

| 主题 | 内容 |
|------|------|
| 八卦 | 阴阳三叠而成的八种基本符号 |
| 六十四卦 | 八卦相重而成的卦象体系 |
| 卦爻辞 | 解释吉凶休咎的文字 |
| 变易 | 生生之谓易 |
