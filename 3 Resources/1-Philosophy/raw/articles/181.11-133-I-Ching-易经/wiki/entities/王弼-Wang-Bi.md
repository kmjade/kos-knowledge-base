# 王弼 Wang Bi

王弼（226–249），三国魏国玄学家，义理派易学的奠基者。他提出「得意忘象」「扫象数」，以玄学义理诠释《周易》，扭转了汉代象数易的主导地位。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 得意忘象 | 得义理则忘卦象 |
| 扫象数 | 超越繁琐象数推演 |
| 《周易注》 | 义理派经典诠释 |
| 玄学奠基 | 有无之辩·贵无 |
