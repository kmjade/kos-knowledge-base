# 朱熹 Zhu Xi

朱熹（1130–1200），南宋理学家，理学集大成者。他著《周易本义》，主张「易本卜筮之书」，综合象数与义理，是宋代易学的权威诠释。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 《周易本义》 | 易学权威诠释 |
| 易本卜筮 | 还原易经的本义 |
| 综合象数义理 | 两大传统的融合 |
| 理学集大成 | 理气论·格物致知 |
