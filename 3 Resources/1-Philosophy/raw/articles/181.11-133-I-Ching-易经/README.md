# 易经 (I Ching / Book of Changes / UDC 181.11:133)

> 中国哲学的源头经典、五经之首——「易」既是卜筮之书（133），更是穷究天人之变的哲学经典（181.11）。它以阴阳、八卦、六十四卦的符号体系，揭示宇宙万物「变易」的规律与「中和」的智慧。
