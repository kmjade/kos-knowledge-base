# 06-象数与义理

> 象数与义理是易学的两大传统：象数派侧重卦象、爻数与占筮之术，义理派侧重卦爻辞所蕴含的哲学义理与人事智慧。两派此消彼长，共同塑造了易学的丰富面貌。

## 两大传统对照

| 维度 | 象数派 | 义理派 |
|------|--------|--------|
| 焦点 | 卦象·数理·占筮 | 哲学义理·人事 |
| 方法 | 取象·纳甲·卦变 | 诠释·引申·格义 |
| 代表 | 京房·邵雍 | 王弼·程颐 |
| 时期 | 汉代兴盛 | 魏晋奠基 |

## 象数派的关键概念

| 概念 | 说明 |
|------|------|
| 取象 | 从卦象取自然人事之象 |
| 纳甲 | 以天干配卦 |
| 卦变 | 卦之间的相互转化 |
| 先天易学 | 邵雍的先天八卦方位 |

## 义理派的关键主张

| 主张 | 说明 |
|------|------|
| 得意忘象 | 王弼：得义理则忘卦象 |
| 扫象数 | 超越繁琐的象数推演 |
| 以传解经 | 以《易传》诠释本经 |
