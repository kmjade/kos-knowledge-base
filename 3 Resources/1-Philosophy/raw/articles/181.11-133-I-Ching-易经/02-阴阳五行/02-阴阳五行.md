# 02-阴阳五行

> 阴阳与五行是易经的宇宙论基础。阴阳揭示对立统一的两种基本力量，五行（金木水火土）则描述万物相互生克的关系，共同构成中国哲学解释宇宙的基本框架。

## 阴阳

| 维度 | 阴 | 阳 |
|------|----|----|
| 性质 | 柔·静·暗·冷 | 刚·动·明·热 |
| 象征 | 月·女·水·地 | 日·男·火·天 |
| 关系 | 对立·依存·转化 | 相反相成 |

## 太极与两仪

| 概念 | 说明 |
|------|------|
| 太极 | 宇宙未分的原始状态 |
| 两仪 | 太极分而为阴阳 |
| 四象 | 阴阳再分（太阳·少阴·少阳·太阴） |
| 八卦 | 四象再分而成 |

「易有太极，是生两仪，两仪生四象，四象生八卦。」——《系辞传》

## 五行

| 行 | 性质 | 方位 | 季节 |
|----|------|------|------|
| 木 | 生发 | 东 | 春 |
| 火 | 炎上 | 南 | 夏 |
| 土 | 承载 | 中 | 长夏 |
| 金 | 收敛 | 西 | 秋 |
| 水 | 润下 | 北 | 冬 |

## 五行生克

| 关系 | 说明 |
|------|------|
| 相生 | 木生火·火生土·土生金·金生水·水生木 |
| 相克 | 木克土·土克水·水克火·火克金·金克木 |
