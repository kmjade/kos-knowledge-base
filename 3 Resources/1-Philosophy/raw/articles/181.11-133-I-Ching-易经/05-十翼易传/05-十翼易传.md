# 05-十翼易传

> 十翼（又称《易传》）是对《周易》本经的哲学阐释，相传为孔子所作。它将易经从卜筮之书提升为哲学经典，是理解易经义理思想的关键。

## 十翼的构成

| 篇名 | 内容 |
|------|------|
| 彖传（上、下） | 解释卦辞·断卦义 |
| 象传（上、下） | 解释卦象与爻象 |
| 系辞传（上、下） | 总论易道·哲学纲领 |
| 文言传 | 专释乾坤两卦 |
| 说卦传 | 八卦的取象与性质 |
| 序卦传 | 六十四卦的排列次序 |
| 杂卦传 | 错综卦义的概括 |

## 系辞传的哲学

| 命题 | 含义 |
|------|------|
| 易有太极，是生两仪 | 宇宙生成论 |
| 一阴一阳之谓道 | 阴阳为道之根本 |
| 生生之谓易 | 变化与生生的本质 |
| 穷则变，变则通 | 变化的规律 |

## 彖传与象传

| 传 | 功能 |
|----|------|
| 彖传 | 判断一卦的总体意义 |
| 大象 | 从卦象引申人事修养 |
| 小象 | 解释每一爻的爻辞 |
