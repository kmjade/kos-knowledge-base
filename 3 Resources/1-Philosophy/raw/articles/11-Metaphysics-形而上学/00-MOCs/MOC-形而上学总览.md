# 🗺️ MOC · 形而上学总览

> 形而上学（Metaphysics）的核心问题可归结为两类：**「有什么存在？」（本体论）** 与 **「存在如何运作？」（模态/因果/时空/自由）**。

## 历史脉络

```
亚里士多德「第一哲学」→ 中世纪（存在与本质）→ 笛卡尔/斯宾诺莎/莱布尼茨（理性主义）
→ 休谟/康德（经验批判与先验转向）→ 逻辑实证主义拒斥 → 20 世纪形而上学复兴
（蒯因、克里普克、刘易斯）
```

## 三大立场（本体论）

| 立场 | 主张 | 代表 |
|------|------|------|
| 实在论 | 共相/抽象对象独立于心灵存在 | 柏拉图·亚里士多德 |
| 唯名论 | 只有个体存在，共相是名称 | 奥卡姆·蒯因 |
| 概念论 | 共相存在于心灵之中 | 阿伯拉尔·洛克 |
