# 05-因果与必然性（Causality）

> 因果关系是「必然联系」吗？还是仅仅是恒常连结？休谟的这一追问构成了因果形而上学的地基。

## 因果关系的要素

| 要素 | 说明 |
|------|------|
| 原因 | 产生结果的先行事件/状态 |
| 结果 | 由原因导致的事件/状态 |
| 必然性 | 因果联系是否「必然」（而非偶然） |
| 反事实 | 若无原因，则无结果 |

## 亚里士多德的四因说

| 因 | 回答 | 例子（雕像） |
|----|------|-------------|
| 质料因 | 由什么构成 | 青铜 |
| 形式因 | 是什么样式 | 雕像的形状 |
| 动力因 | 由什么推动 | 雕刻家 |
| 目的因 | 为了什么 | 纪念 |

## 休谟的因果怀疑论

| 论点 | 内容 |
|------|------|
| 恒常连结 | 我们只能经验到「A 后随 B」，观察不到「必然联系」 |
| 习惯 | 「因果必然性」只是心灵的习惯性联想 |
| 后果 | 因果的必然性无法由经验或理性证明 |

## 当代因果理论

| 理论 | 主张 | 代表 |
|------|------|------|
| 规律理论 | 因果 = 在自然律下的演绎覆盖 | 亨佩尔 |
| 反事实理论 | A 导致 B ⟺ 若 A 不发生则 B 不发生 | 刘易斯 |
| 概率理论 | 原因提高结果的概率 | 萨普斯 |
| 干预主义 | 因果 = 通过干预能改变结果 | 伍德沃德 |

## 自然律与必然性

| 问题 | 追问 |
|------|------|
| 自然律是什么？ | 是规律性（休谟式）还是必然关系（必然主义） |
| 律与偶通概括 | 「所有黄金球直径 < 1 米」是巧合，非定律 |
