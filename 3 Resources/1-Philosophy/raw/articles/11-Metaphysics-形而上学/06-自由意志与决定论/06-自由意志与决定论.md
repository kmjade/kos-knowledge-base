# 06-自由意志与决定论（Free Will & Determinism）

> 如果世界是被决定的，我们还能自由行动并承担道德责任吗？这是形而上学与伦理学的交汇点。

## 基本概念

| 概念 | 定义 |
|------|------|
| 决定论 | 一切事件（含人的行动）皆由先前状态 + 自然律必然决定 |
| 自由意志 | 在相同条件下，行动者本可另有选择 |
| 道德责任 | 行动者对其行动负有责任，是褒贬的前提 |
| 相容性 | 自由与决定论能否同时为真 |

## 四大立场

| 立场 | 决定论 | 自由 | 代表 |
|------|:------:|:----:|------|
| 硬决定论 | 真 | 无 | 霍尔巴赫·拉普拉斯 |
| 自由主义（libertarianism） | 假 | 有 | 康德·利德 |
| 相容论（soft determinism） | 真 | 有（相容） | 霍布斯·休谟·法兰克福 |
| 不相容论 | 二者不可兼得 | — | 范·因瓦根 |

## 经典论证

| 论证 | 内容 |
|------|------|
| 结果论证 | 若决定论为真，则行动者不能「另有选择」→ 不自由、无责任 |
| 法兰克福反例 | 即使不能另有选择，仍可承担责任（挑战「另有选择原则」） |
| 拉普拉斯之妖 | 全知者由当前状态即可推出一切未来 → 无自由空间 |

## 当代争论焦点

| 焦点 | 追问 |
|------|------|
| 自由是否需要「另有选择」？ | 不相容论的基石是否成立 |
| 自由与因果「源」 | 相容论诉诸行动源于行动者自身（而非外力） |
| 神经科学挑战 | 利贝特实验：行动先于意识决定？ |
