# 形而上学 (Metaphysics / UDC 11)

> 关于「存在本身」的追问——有什么存在？实在的结构是什么？因果、时空、模态与自由如何交织？
> 形而上学是哲学的根基，本体论（存在论）是其中最核心的板块。
