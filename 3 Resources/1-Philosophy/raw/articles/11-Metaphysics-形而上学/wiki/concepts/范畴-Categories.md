# 范畴 Categories

## 定义

范畴（category）是对存在者的最高层级的分类，回答「存在者有哪些基本种类」。亚里士多德在《范畴篇》提出十范畴，以「实体」为首。

## 亚里士多德十范畴

| 范畴 | 例子 |
|------|------|
| 实体 | 人、马 |
| 量 | 二尺长 |
| 质 | 白色 |
| 关系 | 更大、双重 |
| 位置 | 在广场 |
| 时间 | 昨天 |
| 姿态 | 坐着 |
| 状态 | 穿着鞋 |
| 动作 | 切割 |
| 受动 | 被切割 |

## 范畴的形而上意义

| 要点 | 说明 |
|------|------|
| 本体论分类 | 范畴不是语法，而是实在的划分 |
| 实体优先 | 其他范畴皆依附于实体 |
| 当代争论 | 事件、事态、关系是否应入范畴表 |
