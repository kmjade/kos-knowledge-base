# 存在 Being

## 定义

「存在」（Being / 希腊语 *to on*）是形而上学最根本的概念，指一切「有」——即任何可被说成「是」或「存在」的东西。亚里士多德称之为「存在作为存在」（being qua being）的研究对象。

## 核心区分

| 区分 | 说明 |
|------|------|
| 存在 vs 虚无 | 有（something）与无（nothing）的对立 |
| 存在 vs 本质 | 某物「实际存在」vs「是什么」 |
| 存在 vs 存在者 | 存在本身（Sein）vs 具体存在物（Seiendes）——海德格尔 |

## 多义性

| 含义 | 例子 |
|------|------|
| 系词「是」 | S 是 P（判断） |
| 实存 | 独角兽不存在 |
| 同一 | A 就是 B |
| 谓述 | 他是聪明的 |
