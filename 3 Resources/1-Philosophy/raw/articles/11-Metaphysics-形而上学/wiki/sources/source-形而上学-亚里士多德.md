# 《形而上学》· 亚里士多德

亚里士多德《形而上学》（Metaphysics）是形而上学的奠基之作，书名源于其著作在「物理学之后」的编目位置。本书确立了「第一哲学」——对「存在作为存在」（being qua being）的研究。

## 关键主题

| 主题 | 内容 |
|------|------|
| 第一哲学 | 研究存在本身及其最高原理 |
| 实体 | 第一实体/第二实体、质料与形式 |
| 四因说 | 质料·形式·动力·目的 |
| 十范畴 | 存在者的最高分类 |
| 不动的推动者 | 运动与因果的终极根据 |
