# 《纯粹理性批判》· 康德

康德《纯粹理性批判》（Critique of Pure Reason，1781/1787）是形而上学史上「哥白尼式革命」，追问形而上学作为科学如何可能。

## 关键主题

| 主题 | 内容 |
|------|------|
| 先验哲学 | 追问经验可能性的先天条件 |
| 现象/物自体 | 只能认识现象，物自体不可知 |
| 先天综合判断 | 使数学、自然科学、形而上学得以可能 |
| 时空 | 不是物自体属性，而是先验感性形式 |
| 二律背反 | 理性在宇宙论问题上自相矛盾 |
