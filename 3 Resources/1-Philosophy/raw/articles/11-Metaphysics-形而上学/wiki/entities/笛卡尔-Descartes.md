# 笛卡尔 Descartes

勒内·笛卡尔（1596–1650），法国哲学家，近代哲学之父，提出「我思故我在」与心物二元论。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 我思故我在 | 从普遍怀疑中确立不可怀疑的「我」 |
| 心物二元论 | 心灵与物质是两类独立实体 |
| 清晰分明观念 | 真理的标准是观念的清楚分明 |
| 上帝存在证明 | 由「我心中的完满观念」推出上帝 |

## 心物二元论的问题

心灵（无广延）与物质（有广延）如何相互作用，构成后世「心身问题」的形而上学难题。
