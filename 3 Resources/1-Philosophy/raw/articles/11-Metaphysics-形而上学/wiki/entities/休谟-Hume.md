# 休谟 Hume

大卫·休谟（1711–1776），苏格兰经验主义哲学家，其对因果必然性的怀疑论深刻塑造了现代形而上学与认识论。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 因果怀疑论 | 因果必然性不可经验亦不可理性证明 |
| 恒常连结 | 我们只经验到「A 后随 B」，观察不到必然联系 |
| 习惯 | 因果信念源于心灵的习惯性联想 |
| 归纳问题 | 归纳推理无法由理性辩护 |
| 束理论 | 自我只是知觉的「束」，无底层实体 |

## 对形而上学的意义

休谟的怀疑论是康德「先验转向」的直接动因，也是[[因果性-Causality|因果性]]当代讨论的出发点。
