# 莱布尼茨 Leibniz

戈特弗里德·威廉·莱布尼茨（1646–1716），德国哲学家、数学家，提出单子论、充足理由律，并是「可能世界」概念的先驱。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 单子论 | 世界由无数不可分、无窗的单子构成 |
| 充足理由律 | 一切事实皆有充足理由，终极理由在宇宙之外 |
| 可能世界 | 上帝在无限可能世界中选择最好的一个现实化 |
| 前定和谐 | 心身各自独立却由上帝预设而同步 |
| 关系空间 | 空间是物体间关系（反对牛顿绝对空间） |
