# 柏拉图 Plato

柏拉图（约前 428–前 348），古希腊哲学家，理念论（Theory of Forms）的创立者，共相实在论（超越式）的源头。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 理念论 | 永恒、不变、超越的理念（Form）是真正的实在 |
| 两个世界 | 可感世界（流变）vs 可知世界（理念） |
| 洞穴比喻 | 感官世界只是理念世界的影子 |
| 分有说 | 具体事物因「分有」理念而具有其性质 |

## 与共相问题

柏拉图式的实在论主张共相（理念）独立、超越于个体存在，构成[[共相-Universals|共相问题]]的经典立场。
