# 康德 Kant

伊曼努尔·康德（1724–1804），德国哲学家，通过「哥白尼式革命」将形而上学重建为先验哲学，区分现象与物自体。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 先验转向 | 形而上学追问「经验可能性的条件」 |
| 现象/物自体 | 我们只能认识现象，物自体不可知 |
| 先天综合判断 | 使知识（如因果、时空）得以可能 |
| 时空先验感性 | 空间与时间不是物自体属性，而是感性形式 |
| 二律背反 | 理性在宇宙论问题上陷入自相矛盾 |

## 对形而上学的意义

康德既「限制」了传统形而上学（物自体不可知），又为其奠定新基础（先验论证），是形而上学的关键转折点。
