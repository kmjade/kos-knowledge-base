# 亚里士多德 Aristotle

亚里士多德（前 384–前 322），古希腊哲学家，形而上学的奠基者，提出「第一哲学」即对「存在作为存在」（being qua being）的研究。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 第一哲学 | 形而上学 = 研究存在的最终原理 |
| 实体理论 | 第一实体/第二实体、质料与形式 |
| 四因说 | 质料因·形式因·动力因·目的因 |
| 十范畴 | 存在者的最高分类 |
| 不动的推动者 | 运动链的第一因 |
