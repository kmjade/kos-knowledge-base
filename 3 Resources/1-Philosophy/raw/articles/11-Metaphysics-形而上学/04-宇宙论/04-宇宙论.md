# 04-宇宙论（Cosmology）

> 宇宙论的形而上学维度：宇宙的起源、结构、目的与第一因——「为什么有宇宙，而非一无所有？」

## 核心问题

| 问题 | 追问 |
|------|------|
| 宇宙有开端吗？ | 时间是否有限，是否有第一时刻 |
| 什么是第一因？ | 因果链条的最终根据 |
| 宇宙有目的吗？ | 目的论 vs 机械论 |
| 宇宙是必然还是偶然？ | 充足理由律的追问 |

## 第一因论证（宇宙论论证）

| 论证 | 提出者 | 逻辑 |
|------|--------|------|
| 不动的推动者 | 亚里士多德 | 运动链须有一不动的第一推动者 |
| 第一因论证 | 阿奎那（五路中的第二路） | 因果链不能无穷回溯，须有第一因 |
| 充足理由律 | 莱布尼茨 | 一切存在皆有理由，终极理由在宇宙之外 |
| 卡拉姆论证 | 中世纪伊斯兰 | 凡有开端者必有原因；宇宙有开端，故有原因 |

## 时间有无开端（康德二律背反）

| 正题 | 反题 |
|------|------|
| 世界在时间上有开端 | 世界在时间上没有开端（永恒） |
| 二者皆可证 → 揭示理性在此的「二律背反」 |

## 目的论 vs 机械论

| 立场 | 主张 |
|------|------|
| 目的论 | 宇宙趋向某目的（亚里士多德的终极因） |
| 机械论 | 宇宙由盲目的机械规律支配（近代科学） |

## 与自然科学的边界

形而上学宇宙论与物理宇宙学（大爆炸、膨胀宇宙）不同：前者追问「为什么有宇宙」这一终极根据问题，后者描述宇宙的物理演化。二者在「时间开端」「宇宙微调」等问题上交叉。
