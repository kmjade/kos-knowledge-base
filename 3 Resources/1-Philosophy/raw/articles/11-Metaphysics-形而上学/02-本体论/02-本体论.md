# 02-本体论（Ontology）

> 本体论研究「存在是什么」——存在者的分类（范畴）、最基本的存在者（实体），以及实在的最终性质。

## 核心问题

| 问题 | 追问 |
|------|------|
| 什么是实体（substance）？ | 能独立存在而不依赖他物之物 |
| 存在有哪些范畴？ | 实体、性质、关系、事件、事态…… |
| 抽象对象存在吗？ | 数、命题、共相是否真实存在 |
| 实在论 vs 反实在论 | 世界是否独立于心灵而存在 |

## 实体理论

| 理论 | 主张 | 代表 |
|------|------|------|
| 实体—属性理论 | 世界由实体及其属性构成 | 亚里士多德 |
| 束理论（bundle） | 事物只是属性的集合，无「底层实体」 | 休谟·罗素 |
| 基底理论（substratum） | 属性的承载者是「裸殊相」 | 洛克 |
| 过程本体论 | 存在的基本单元是事件/过程 | 怀特海 |

## 范畴表

亚里士多德的十范畴：

| 范畴 | 例子 |
|------|------|
| 实体 | 人、马 |
| 量 | 二尺长 |
| 质 | 白色 |
| 关系 | 更大、双重 |
| 位置 | 在广场 |
| 时间 | 昨天 |
| 姿态 | 坐着 |
| 状态 | 穿着鞋 |
| 动作 | 切割 |
| 受动 | 被切割 |

## 存在与本质（中世纪区分）

| 概念 | 含义 |
|------|------|
| 存在（existence） | 某物「实际存在」 |
| 本质（essence） | 某物「是什么」的规定性 |
| 区分意义 | 本质不蕴含存在——「是什么」≠「确实有」 |

## 本体论承诺（蒯因）

> 「存在就是成为约束变量的值。」（To be is to be the value of a bound variable）

一个理论承诺了某类实体存在，当且仅当这些实体是其量词辖域内的值。
