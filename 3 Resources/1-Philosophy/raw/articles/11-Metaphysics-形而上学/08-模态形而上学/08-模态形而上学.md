# 08-模态形而上学（Modal Metaphysics）

> 模态词——「必然」「可能」「偶然」——指涉的是怎样的实在？「可能世界」是真实存在，还是仅仅是说话方式？

## 模态概念

| 概念 | 定义 |
|------|------|
| 必然（necessary） | 在所有可能世界中为真 |
| 可能（possible） | 在至少一个可能世界中为真 |
| 偶然（contingent） | 可能真且可能假 |
| 不可能（impossible） | 在所有可能世界中为假 |

## 可能世界理论

| 理论 | 主张 | 代表 |
|------|------|------|
| 模态实在论 | 可能世界与其他世界一样真实存在 | 大卫·刘易斯 |
| 抽象主义 | 可能世界是抽象的「世界之书」/事态 | 普兰廷加·亚当斯 |
| 虚构主义 | 可能世界是方便的虚构/说话方式 | 罗森 |
| 温和实在论 | 世界是「世界能够如何」的最大描述 | 斯托纳克 |

## 本质主义（克里普克）

| 概念 | 说明 |
|------|------|
| 必然同一 | 若 a = b，则必然 a = b（同一物跨世界不可分） |
| 严格指示词 | 名称在所有可能世界中指同一对象 |
| 本质属性 | 对象在所有存在它的世界中都具有的属性（如水 = H₂O） |
| 后天必然 | 「晨星 = 暮星」是经验发现却是必然真理 |
