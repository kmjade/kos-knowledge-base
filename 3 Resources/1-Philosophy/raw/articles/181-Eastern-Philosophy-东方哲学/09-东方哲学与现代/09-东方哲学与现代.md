# 09-东方哲学与现代

> 东方哲学在现代并非静止的传统，而是在与西方的相遇中不断自我更新——从京都学派的东西对话，到新儒家与全球化的交融，东方智慧持续回应着现代性挑战。

## 京都学派

| 哲学家 | 贡献 |
|--------|------|
| 西田几多郎 | 「场所」逻辑·绝对无 |
| 西谷启治 | 空与虚无主义 |
| 田边元 | 忏悔道·社会哲学 |

京都学派融合禅宗与西方哲学（海德格尔、黑格尔），是东西方哲学对话的重要成果。

## 新儒家（现代新儒家）

| 哲学家 | 贡献 |
|--------|------|
| 熊十力 | 体用不二 |
| 牟宗三 | 道德形而上学·会通康德 |
| 唐君毅 | 人文精神重建 |

## 东方哲学与全球议题

| 议题 | 东方资源的回应 |
|------|--------------|
| 生态危机 | 天人合一·自然观 |
| 精神焦虑 | 正念·禅修·心性修养 |
| 伦理困境 | 仁·慈悲·中道 |

## 东西对话的意义

东方哲学为现代世界提供了不同于西方分析传统的资源：整体论思维、实践智慧、身心修养与和谐伦理。
