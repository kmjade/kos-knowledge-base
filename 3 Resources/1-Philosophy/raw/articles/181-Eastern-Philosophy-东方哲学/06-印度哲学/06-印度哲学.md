# 06-印度哲学

> 印度哲学以「解脱」（moksha）为终极关切，围绕轮回、业与梵我等概念展开，历经吠陀、奥义书与六派哲学的演变，是东方哲学最古老的体系之一。

## 核心概念

| 概念 | 含义 |
|------|------|
| 梵（Brahman） | 宇宙的终极实在 |
| 我（Atman） | 个体的真实自我 |
| 轮回（Samsara） | 生死的循环 |
| 业（Karma） | 行为及其果报 |
| 解脱（Moksha） | 从轮回中解放 |

## 历史分期

| 时期 | 特征 |
|------|------|
| 吠陀时期 | 吠陀经典·祭祀·多神 |
| 奥义书时期 | 梵我合一·内在转向 |
| 史诗时期 | 《摩诃婆罗多》·《薄伽梵歌》 |
| 六派哲学 | 系统的哲学学派 |

## 六派哲学（正统）

| 学派 | 核心 |
|------|------|
| 数论（Samkhya） | 二元：自性与神我 |
| 瑜伽（Yoga） | 修行方法·八支 |
| 正理（Nyaya） | 逻辑·认识论 |
| 胜论（Vaisheshika） | 原子论·范畴 |
| 弥曼差（Mimamsa） | 祭祀与经文诠释 |
| 吠檀多（Vedanta） | 梵我合一·不二论 |

## 核心洞见：梵我合一

奥义书的最高洞见是「梵我一如」（Tat tvam asi，汝即彼）：个体自我（Atman）与宇宙终极实在（Brahman）本质同一。
