# 🗺️ MOC · 东方哲学总览

> 东方哲学（Eastern Philosophy）的核心问题可归结为两类：**「如何安身立命？」（修养与境界）** 与 **「万物的根本是什么？」（本体与宇宙论）**。

## 三大传统

| 传统 | 地域 | 核心关切 |
|------|------|---------|
| 中国哲学 | 中国 | 入世伦理·修养·天人关系（儒道墨法） |
| 印度哲学 | 印度 | 解脱（moksha）·轮回·梵我 |
| 佛教哲学 | 印度→东亚 | 缘起·空·涅槃·中道 |

## 东西方哲学对照

| 维度 | 东方哲学 | 西方哲学 |
|------|---------|---------|
| 核心 | 实践智慧·修养 | 理论分析·论证 |
| 路径 | 直觉·体悟·践行 | 逻辑·定义·系统 |
| 关切 | 安身立命·解脱 | 知识·真理·本质 |

## 历史脉络

```
先秦诸子（儒道墨法）→ 两汉经学 → 魏晋玄学 → 隋唐佛学（禅宗兴盛）
→ 宋明理学/心学 → 印度吠陀·奥义书 → 佛教兴起（原始·部派·大乘·中观·唯识）
→ 近现代东西对话（京都学派）
```
