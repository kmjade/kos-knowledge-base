# 04-道家哲学

> 道家哲学（Daoism）以「道」为宇宙万物的根本，主张「无为」「自然」与「返璞归真」，追求与道合一的逍遥境界。老子与庄子是其奠基者与集大成者。

## 核心概念

| 概念 | 含义 |
|------|------|
| 道 | 宇宙的本源与规律（不可名状） |
| 德 | 道在万物中的体现 |
| 无为 | 顺应自然·不强加妄为 |
| 自然 | 自己如此·本然状态 |
| 阴阳 | 对立统一的两种基本力量 |

## 老子：道与无为

| 要点 | 内容 |
|------|------|
| 道 | 「道可道，非常道」 |
| 无为 | 「无为而无不为」 |
| 柔弱 | 「柔弱胜刚强」 |
| 反者道之动 | 对立面的相互转化 |

## 庄子：齐物与逍遥

| 要点 | 内容 |
|------|------|
| 齐物论 | 是非、物我、生死的相对性 |
| 逍遥游 | 精神的绝对自由 |
| 心斋坐忘 | 修养工夫 |
| 寓言 | 庖丁解牛·庄周梦蝶 |

## 儒道对照

| 维度 | 儒家 | 道家 |
|------|------|------|
| 核心 | 仁·礼 | 道·自然 |
| 态度 | 入世有为 | 出世无为 |
| 理想 | 君子·圣王 | 真人·逍遥 |
