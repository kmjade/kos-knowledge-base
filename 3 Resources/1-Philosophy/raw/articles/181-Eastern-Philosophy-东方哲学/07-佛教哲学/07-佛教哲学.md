# 07-佛教哲学

> 佛教哲学以「缘起」「空」「涅槃」为核心，追问苦的根源与解脱之道。释迦牟尼以四圣谛与八正道开示中道，龙树以「空」深化大乘哲学，是东方哲学中思辨最精微的传统。

## 四圣谛

| 圣谛 | 内容 |
|------|------|
| 苦谛 | 人生皆苦（生老病死） |
| 集谛 | 苦因：渴爱（tanha） |
| 灭谛 | 苦可止息：涅槃 |
| 道谛 | 解脱之道：八正道 |

## 八正道

| 分类 | 内容 |
|------|------|
| 慧 | 正见·正思 |
| 戒 | 正语·正业·正命 |
| 定 | 正精进·正念·正定 |

## 核心概念

| 概念 | 含义 |
|------|------|
| 缘起（Pratityasamutpada） | 万法因缘和合而生 |
| 空（Sunyata） | 万法无自性 |
| 无常 | 诸行无常 |
| 无我 | 诸法无我 |
| 涅槃 | 苦的止息·解脱境界 |

## 佛教哲学的发展

| 阶段 | 代表 | 核心 |
|------|------|------|
| 原始佛教 | 释迦牟尼 | 四圣谛·缘起 |
| 部派佛教 | 说一切有部 | 法的分析 |
| 大乘中观 | 龙树 | 空·中道 |
| 大乘唯识 | 世亲 | 万法唯识 |
