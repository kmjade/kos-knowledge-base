# 03-儒家哲学

> 儒家哲学（Confucianism）以「仁」为核心，主张通过「礼」的规范与「忠恕」之道，成就君子人格并实现「内圣外王」的理想。它是中国哲学最具影响力的传统。

## 核心概念

| 概念 | 含义 |
|------|------|
| 仁 | 爱人·人我相通的最高的德 |
| 礼 | 社会规范与仪式秩序 |
| 义 | 正当·合宜 |
| 忠恕 | 尽己（忠）·推己及人（恕） |
| 孝悌 | 家庭伦理的根基 |

## 孔子：仁与礼

| 要点 | 内容 |
|------|------|
| 仁的本质 | 「仁者爱人」 |
| 恕道 | 「己所不欲，勿施于人」 |
| 正名 | 「君君臣臣父父子子」 |
| 教育 | 「有教无类」 |

## 孟子 vs 荀子

| 维度 | 孟子 | 荀子 |
|------|------|------|
| 人性 | 性善论 | 性恶论 |
| 修养 | 扩充四端 | 化性起伪 |
| 政治 | 仁政·民本 | 隆礼重法 |

## 四端之心（孟子）

| 四端 | 对应德性 |
|------|---------|
| 恻隐之心 | 仁 |
| 羞恶之心 | 义 |
| 辞让之心 | 礼 |
| 是非之心 | 智 |
