# 东方哲学 (Eastern Philosophy / UDC 181)

> 关于「如何安身立命」的智慧传统——从先秦诸子到印度佛教，东方哲学以不同的方式追问：何为道？何为仁？何为解脱？它注重实践智慧、内在修养与天人关系的和谐，与西方哲学的分析传统形成互补。
