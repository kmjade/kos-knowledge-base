# 02-中国哲学导论

> 中国哲学肇始于先秦诸子百家的「百家争鸣」（约前 6–前 3 世纪），以入世伦理、修养工夫与天人关系为核心关切，是东方哲学最重要的传统之一。

## 先秦诸子百家

| 学派 | 创始人/代表 | 核心主张 |
|------|-----------|---------|
| 儒家 | 孔子·孟子·荀子 | 仁·礼·忠恕·仁政 |
| 道家 | 老子·庄子 | 道·无为·自然 |
| 墨家 | 墨子 | 兼爱·非攻·尚贤 |
| 法家 | 韩非·商鞅 | 法治·权术·势 |
| 名家 | 公孙龙·惠施 | 名实之辨 |
| 阴阳家 | 邹衍 | 阴阳五行 |

## 中国哲学的基本关切

| 关切 | 说明 |
|------|------|
| 天人关系 | 天与人如何统一（天人合一） |
| 内圣外王 | 内在修养与外在事功 |
| 知行合一 | 道德知识与实践的统一 |
| 古今之变 | 传统与变革的关系 |

## 历史分期

| 时期 | 特征 |
|------|------|
| 先秦 | 百家争鸣·诸子原创 |
| 两汉 | 经学·董仲舒天人感应 |
| 魏晋 | 玄学·有无之辩 |
| 隋唐 | 佛学兴盛·禅宗 |
| 宋明 | 理学·心学 |
| 近现代 | 中西汇通 |
