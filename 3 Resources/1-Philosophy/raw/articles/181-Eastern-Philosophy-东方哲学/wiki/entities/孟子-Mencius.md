# 孟子 Mencius

孟子（约前 372–前 289），名轲，战国时期思想家，儒家学派的重要代表，被尊为「亚圣」。他提出「性善论」与「仁政」学说，发展孔子的仁学思想。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 性善论 | 人性本善·四端之心 |
| 四端 | 恻隐·羞恶·辞让·是非 |
| 仁政 | 民为贵·君为轻 |
| 养气 | 浩然之气 |
