# 孔子 Confucius

孔子（前 551–前 479），名丘，字仲尼，春秋时期思想家、教育家，儒家学派的创始人。他提出以「仁」为核心的伦理思想，主张「礼」的规范与「忠恕」之道，对中国乃至东亚文明影响深远。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 仁 | 「仁者爱人」·最高德性 |
| 礼 | 克己复礼·正名 |
| 忠恕 | 己所不欲，勿施于人 |
| 教育 | 有教无类·因材施教 |
