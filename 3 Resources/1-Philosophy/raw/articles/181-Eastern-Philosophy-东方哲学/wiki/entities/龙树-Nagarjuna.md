# 龙树 Nagarjuna

龙树（约 2–3 世纪），印度大乘佛教中观学派（Madhyamaka）的奠基者，被尊为「八宗共祖」。他以《中论》系统阐述「空」与「中道」，是大乘佛教哲学的最高代表。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 空性 | 万法无自性 |
| 中道 | 超越有与无二边 |
| 二谛 | 世俗谛与胜义谛 |
| 缘起性空 | 缘起即性空 |
