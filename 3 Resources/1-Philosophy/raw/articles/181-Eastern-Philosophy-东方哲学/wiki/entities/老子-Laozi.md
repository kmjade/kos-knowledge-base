# 老子 Laozi

老子（约前 6 世纪），道家学派创始人，相传为《道德经》作者。他提出「道」为宇宙本源的形而上思想，主张「无为」「自然」，是东方哲学最重要的形而上学家之一。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 道 | 宇宙的本源与规律 |
| 无为 | 无为而无不为 |
| 自然 | 顺应本然·返璞归真 |
| 辩证 | 反者道之动·柔弱胜刚强 |
