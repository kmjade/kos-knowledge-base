# 庄子 Zhuangzi

庄子（约前 369–前 286），名周，战国时期哲学家，道家思想的集大成者。他发展老子的思想，提出「齐物」「逍遥」「心斋坐忘」，以寓言与诗化语言表达深刻的相对主义与精神自由思想。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 齐物论 | 是非·物我·生死的相对性 |
| 逍遥游 | 精神的绝对自由 |
| 心斋坐忘 | 修养工夫 |
| 寓言 | 庖丁解牛·庄周梦蝶 |
