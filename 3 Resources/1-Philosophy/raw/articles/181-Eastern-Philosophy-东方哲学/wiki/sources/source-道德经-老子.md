# 《道德经》· 老子

《道德经》（又称《老子》）是道家哲学的奠基经典，分「道经」与「德经」上下篇，以诗化的语言阐述「道」「无为」「自然」等核心思想，是东方形而上学最重要的文本之一。

## 关键主题

| 主题 | 内容 |
|------|------|
| 道 | 道可道，非常道 |
| 无为 | 无为而无不为 |
| 自然 | 道法自然 |
| 辩证 | 反者道之动·柔弱胜刚强 |
