# 空 Emptiness

## 定义

「空」（Sunyata）是大乘佛教的核心概念，指万法无自性（svabhava）——一切事物因缘和合而生，没有独立不变的本质。龙树中观学派以「空」超越有无二边。

## 空的层次

| 层次 | 含义 |
|------|------|
| 我空 | 个体无独立自性（无我） |
| 法空 | 一切法无独立自性 |
| 空空 | 空本身亦不可执着 |

## 空 ≠ 虚无

| 辨析 | 说明 |
|------|------|
| 空不是无 | 空是「无自性」，非「不存在」 |
| 空与缘起 | 正因为缘起，所以性空 |
| 中道 | 空超越有与无二边 |
