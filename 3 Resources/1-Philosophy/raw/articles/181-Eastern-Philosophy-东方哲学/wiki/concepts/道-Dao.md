# 道 Dao

## 定义

「道」（Dao）是道家哲学的最高概念，指宇宙万物的本源与根本规律，不可名状、不可言说（「道可道，非常道」），既是形而上的本体，也是人生的准则。

## 道的多义性

| 含义 | 说明 |
|------|------|
| 本体 | 宇宙的终极根源 |
| 规律 | 万物运行的法则 |
| 方法 | 人生的道路与准则 |
| 境界 | 与道合一的理想 |

## 核心特征

| 特征 | 内容 |
|------|------|
| 不可名状 | 超越语言与概念 |
| 自然无为 | 生而不有·为而不恃 |
| 周行不殆 | 循环往复·生生不息 |
