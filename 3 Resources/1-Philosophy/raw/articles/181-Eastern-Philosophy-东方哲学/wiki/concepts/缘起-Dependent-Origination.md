# 缘起 Dependent Origination

## 定义

「缘起」（Pratityasamutpada，因缘和合而生起）是佛教哲学的根本法则：一切现象依因缘条件而生起，无独立自性。「此有故彼有，此生故彼生」。

## 十二因缘

| 环节 | 内容 |
|------|------|
| 无明 | 根本无知的迷妄 |
| 行 | 造作的行为 |
| 识·名色·六入 | 心识与身心形成 |
| 触·受·爱·取·有 | 感受与执取 |
| 生·老死 | 轮回的展现 |

## 缘起与空

| 关系 | 说明 |
|------|------|
| 缘起故性空 | 因缘和合故无自性 |
| 性空故缘起 | 因无自性故能生起 |
