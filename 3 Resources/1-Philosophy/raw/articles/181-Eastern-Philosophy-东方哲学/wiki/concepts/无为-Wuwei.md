# 无为 Wuwei

## 定义

「无为」（Wuwei）是道家哲学的核心实践原则，指顺应自然、不强加妄为的处世方式，而非消极不作为。「无为而无不为」——因不妄为，故能成就一切。

## 无为的层次

| 层次 | 含义 |
|------|------|
| 自然无为 | 顺应事物的本然 |
| 政治无为 | 无为而治·小国寡民 |
| 修养无为 | 涤除玄览·致虚守静 |

## 关键辨析

| 概念 | 说明 |
|------|------|
| 无为 ≠ 不为 | 是不妄为，非不作为 |
| 无为 → 无不为 | 顺应自然故能成就 |
