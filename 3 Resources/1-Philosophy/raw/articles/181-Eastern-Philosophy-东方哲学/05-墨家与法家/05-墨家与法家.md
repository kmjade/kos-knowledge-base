# 05-墨家与法家

> 墨家以「兼爱」「非攻」提倡普遍平等之爱，法家以「法治」「势术」主张以法强国。两者与儒道并立，构成先秦思想的完整光谱。

## 墨家核心主张

| 主张 | 内容 |
|------|------|
| 兼爱 | 无差别的普遍之爱 |
| 非攻 | 反对侵略战争 |
| 尚贤 | 任人唯贤 |
| 节用 | 反对奢侈浪费 |
| 天志·明鬼 | 以天意与鬼神规范行为 |

## 墨家 vs 儒家

| 维度 | 墨家 | 儒家 |
|------|------|------|
| 爱 | 兼爱（无差别） | 仁爱（有差等） |
| 礼乐 | 非乐·节葬 | 礼乐教化 |
| 逻辑 | 三表法·重视逻辑 | 正名 |

## 法家核心主张

| 主张 | 内容 |
|------|------|
| 法 | 成文法律·赏罚分明 |
| 术 | 君主驾驭群臣的权术 |
| 势 | 君主权威与权力 |
| 耕战 | 以农战强国 |

## 法家代表人物

| 人物 | 贡献 |
|------|------|
| 商鞅 | 变法·耕战政策 |
| 韩非 | 集法家大成·法势术 |
| 李斯 | 秦统一实践 |
