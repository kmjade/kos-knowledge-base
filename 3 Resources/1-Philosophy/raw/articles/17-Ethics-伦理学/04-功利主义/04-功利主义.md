# 04-功利主义

> 功利主义（Utilitarianism）是后果论的核心形态：一个行为是否正确，取决于它是否产生最大总量的幸福（或效用）。它由边沁创立，密尔发展，是现代最具影响力的伦理理论之一。

## 基本原理

| 原则 | 内容 |
|------|------|
| 后果原则 | 行为的道德性由后果决定 |
| 效用原则 | 善 = 幸福/快乐的最大化 |
| 最大幸福原则 | 「最多数人的最大幸福」 |

## 边沁 vs 密尔

| 维度 | 边沁 | 密尔 |
|------|------|------|
| 快乐 | 只有量的差别 | 有质的差别 |
| 标准 | 快乐主义计算 | 「宁做不满足的苏格拉底」 |
| 规则 | 行为功利主义 | 规则功利主义倾向 |

## 行为功利主义 vs 规则功利主义

| 类型 | 判定 |
|------|------|
| 行为功利主义 | 每次行为直接计算效用 |
| 规则功利主义 | 遵守能最大化效用的规则 |

## 关键批评

| 批评 | 说明 |
|------|------|
| 功利计算不可行 | 幸福难以量化比较 |
| 侵犯少数人权利 | 可能为多数牺牲无辜个体 |
| 与正义冲突 | 「替罪羊」问题 |
| 与特殊关系冲突 | 忽视亲情、友谊等偏私义务 |
