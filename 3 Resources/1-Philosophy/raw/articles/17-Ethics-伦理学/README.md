# 伦理学 (Ethics / UDC 17)

> 关于「应当如何生活」的哲学追问——什么是善？什么是对的？我们为何应当道德地行动？伦理学（道德哲学）研究价值、善恶、义务与幸福，是哲学最古老的实践分支。
