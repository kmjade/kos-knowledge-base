# 07-价值论

> 价值论（Axiology）研究价值的本质、种类与层级，追问「什么是善」「什么是内在价值」，是伦理学的理论根基，也为美学与政治哲学提供基础。

## 价值的基本区分

| 区分 | 说明 |
|------|------|
| 内在价值 | 因其自身而有价值（幸福·知识） |
| 工具价值 | 作为手段而有价值（金钱·工具） |
| 内在价值 vs 外在价值 | 目的性 vs 手段性 |

## 价值类型

| 类型 | 例 |
|------|----|
| 道德价值 | 善良·正义·诚实 |
| 认知价值 | 真理·知识·理解 |
| 审美价值 | 美·崇高·优雅 |
| 实用价值 | 效用·便利 |

## 关于善的理论

| 理论 | 主张 |
|------|------|
| 快乐主义 | 善 = 快乐 |
| 欲望满足论 | 善 = 欲望的满足 |
| 客观列表论 | 善 = 客观有价值的事物清单（知识·友谊） |
| 完美主义 | 善 = 人性潜能的卓越实现 |

## 价值主观主义 vs 客观主义

| 立场 | 主张 |
|------|------|
| 主观主义 | 价值依赖于主体的情感/欲望 |
| 客观主义 | 价值独立于主体而存在 |
| 关系主义 | 价值存在于主体与客体的关系中 |
