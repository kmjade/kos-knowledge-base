# 08-应用伦理学

> 应用伦理学（Applied Ethics）将伦理理论应用于具体实践难题，如生命、商业、环境、科技等领域的道德困境。它标志着 20 世纪后期伦理学从抽象转向实践的复兴。

## 主要分支

| 分支 | 核心问题 |
|------|---------|
| 生命伦理学 | 堕胎·安乐死·基因编辑·医疗资源分配 |
| 商业伦理学 | 企业责任·公平交易·员工权益 |
| 环境伦理学 | 动物权利·生态责任·气候正义 |
| 科技伦理学 | AI 伦理·隐私·算法偏见 |
| 职业伦理学 | 医生·律师·记者的职业操守 |

## 经典困境

| 困境 | 争论 |
|------|------|
| 电车难题 | 是否牺牲一人救五人 |
| 堕胎争议 | 胎儿权利 vs 女性自主 |
| 安乐死 | 尊严死亡 vs 生命神圣 |
| AI 自动驾驶 | 事故中优先保护谁 |

## 应用方法

| 方法 | 说明 |
|------|------|
| 原则主义 | 用「自主·不伤害·行善·公正」四原则分析（比彻姆） |
| 案例法 | 从典型案例归纳道德判断 |
| 反思平衡 | 在原则与直觉间调适 |
