# 《道德形而上学奠基》· 康德

《道德形而上学奠基》（Groundwork of the Metaphysics of Morals, 1785）是康德义务论的奠基之作，提出「绝对命令」作为道德的最高原则，确立「对先于善」的义务论框架。

## 关键主题

| 主题 | 内容 |
|------|------|
| 绝对命令 | 无条件道德律令 |
| 普遍法则公式 | 依可普遍化的准则行动 |
| 目的公式 | 人是目的而非手段 |
| 自律 | 理性自我立法 |
