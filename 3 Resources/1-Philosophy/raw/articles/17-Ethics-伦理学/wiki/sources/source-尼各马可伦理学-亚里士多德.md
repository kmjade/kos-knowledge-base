# 《尼各马可伦理学》· 亚里士多德

《尼各马可伦理学》（Nicomachean Ethics）是亚里士多德伦理学与德性伦理学的奠基之作，系统论述了幸福（eudaimonia）、德性、中道与实践智慧，是西方伦理思想最重要的经典之一。

## 关键主题

| 主题 | 内容 |
|------|------|
| 幸福论 | 幸福是灵魂合乎德性的活动 |
| 德性 | 理智德性与道德德性 |
| 中道 | 德性处于过度与不足之间 |
| 实践智慧 | 明智指导道德行动 |
