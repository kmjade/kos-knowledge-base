# 价值 Value

## 定义

「价值」（Value）是价值论的核心概念，指事物值得追求、珍视或肯定的性质。价值论追问价值的本质、种类与层级。

## 核心区分

| 区分 | 说明 |
|------|------|
| 内在价值 | 因其自身而有价值 |
| 工具价值 | 作为手段而有价值 |
| 道德价值 | 与善恶相关 |
| 非道德价值 | 审美·认知等 |

## 价值理论

| 理论 | 主张 |
|------|------|
| 主观主义 | 价值依赖主体 |
| 客观主义 | 价值独立存在 |
| 关系主义 | 价值存在于关系之中 |
