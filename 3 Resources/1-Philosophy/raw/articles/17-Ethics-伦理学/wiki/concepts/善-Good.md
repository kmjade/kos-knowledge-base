# 善 Good

## 定义

「善」（Good）是伦理学的核心价值概念，指值得追求与珍视的性质或状态。它是价值论的出发点，也是「对」与「应当」的最终根据。

## 核心区分

| 区分 | 说明 |
|------|------|
| 内在善 vs 工具善 | 因其自身而善 vs 作为手段而善 |
| 道德善 vs 非道德善 | 行为/品格的善 vs 事物/状态的善 |
| 善 vs 对 | 价值概念 vs 规范概念 |

## 关于善的理论

| 理论 | 主张 |
|------|------|
| 快乐主义 | 善 = 快乐 |
| 欲望满足论 | 善 = 欲望满足 |
| 客观列表论 | 善 = 知识·友谊等客观价值 |
| 完美主义 | 善 = 人性卓越实现 |
