# 边沁 Bentham

杰里米·边沁（1748–1832），英国哲学家、法学家，功利主义的创始人。他提出「最多数人的最大幸福」原则，主张以「快乐主义计算」衡量行为的道德性，奠定后果论伦理学的经典形态。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 功利主义 | 最大幸福原则 |
| 快乐主义计算 | 量化快乐与痛苦 |
| 后果论 | 行为道德性由后果决定 |
| 法律改革 | 以效用原则改革法律 |
