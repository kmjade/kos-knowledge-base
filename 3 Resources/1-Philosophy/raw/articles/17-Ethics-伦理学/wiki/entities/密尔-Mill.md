# 密尔 Mill

约翰·斯图亚特·密尔（1806–1873），英国哲学家，功利主义的集大成者。他在《功利主义》中发展边沁的理论，引入快乐的质量区分，提出「宁做不满足的苏格拉底，不做满足的猪」。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 功利主义发展 | 快乐有质的差别 |
| 高等/低等快乐 | 精神快乐高于肉体快乐 |
| 自由论 | 伤害原则 |
| 规则功利主义 | 倾向规则而非逐次计算 |
