# 亚里士多德 Aristotle

亚里士多德（前 384–前 322），古希腊哲学家，德性伦理学的奠基者。他在《尼各马可伦理学》中建立幸福论（eudaimonism），主张幸福是「灵魂合乎德性的活动」，为德性伦理学奠定经典范式。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 幸福论 | 幸福是人生的终极目的 |
| 德性理论 | 德性是中道·习惯养成 |
| 功能论证 | 人的功能是理性活动 |
| 实践智慧 | 明智（phronesis）指导行动 |
