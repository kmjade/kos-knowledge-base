# 康德 Kant

伊曼努尔·康德（1724–1804），德国哲学家，义务论（道义论）的奠基者。他在《道德形而上学奠基》中提出「绝对命令」，主张道德源自理性自我立法，义务是行为道德性的唯一根据。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 绝对命令 | 无条件道德律令 |
| 义务论 | 对先于善 |
| 目的公式 | 人是目的而非手段 |
| 自律 | 理性存在者的自我立法 |
