# 休谟 Hume

大卫·休谟（1711–1776），苏格兰哲学家，道德情感论与元伦理学的先驱。他提出「是/应当」之分（is-ought gap），主张道德判断由情感（同情）而非理性驱动——「理性是激情的奴隶」。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 是/应当之分 | 事实推不出规范 |
| 道德情感论 | 同情是道德的基础 |
| 理性是激情的奴隶 | 情感驱动道德判断 |
| 对理性主义的批判 | 质疑道德客观性 |
