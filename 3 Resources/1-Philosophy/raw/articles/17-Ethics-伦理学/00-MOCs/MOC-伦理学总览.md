# 🗺️ MOC · 伦理学总览

> 伦理学（Ethics）的核心问题可归结为两类：**「什么是善/对？」（价值与规范）** 与 **「道德判断的本质是什么？」（元伦理）**。

## 历史脉络

```
苏格拉底「认识你自己」→ 柏拉图/亚里士多德（德性与幸福）→ 中世纪（神学德性）
→ 休谟（道德情感·是/应当之分）→ 康德（义务论·绝对命令）→ 边沁/密尔（功利主义）
→ 20 世纪元伦理学转向（摩尔·直觉主义·情感主义）→ 罗尔斯（正义论）→ 应用伦理学复兴
```

## 三大规范理论

| 理论 | 判定标准 | 代表 |
|------|---------|------|
| 后果论（功利主义） | 行为后果的效用 | 边沁·密尔 |
| 义务论 | 行为是否符合规则/义务 | 康德 |
| 德性伦理学 | 行为者的品格与德性 | 亚里士多德 |

## 元伦理三问

| 问题 | 立场 |
|------|------|
| 道德判断能否为真？ | 实在论 vs 反实在论 |
| 道德是否客观？ | 客观主义 vs 相对主义 |
| 「应当」从何而来？ | 自然主义 vs 直觉主义 vs 情感主义 |
