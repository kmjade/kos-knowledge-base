# 08 视图出图与明细表

> 从模型**自动生成**图纸与统计 —— BIM 的交付形态。

## 标注与注释

- 尺寸标注 · 高程点 · 文字 · 符号 · 标记（Tag）。
- 详图（详图线 / 详图构件）· 图例。

## 图纸（Sheets）

- **图框（Titleblock）** + 视图布置。
- 视图参照 · 图纸列表 · 修订（Revision）。

## 明细表（Schedule）

| 类型 | 用途 |
| --- | --- |
| 构件明细表 | 门窗 / 设备清单 |
| **材质提取** | 用量统计 |
| **工程量** | 算量（5D 基础） |
| 图纸列表 / 视图列表 | 管理 |

- 明细表**与模型联动**（改模型 → 表更新）。
- 导出 Excel / CSV。

## 出图与交付

- 打印 / 导出 PDF · DWG · **IFC**（→ [[03-IFC与数据标准|IFC]]）。
