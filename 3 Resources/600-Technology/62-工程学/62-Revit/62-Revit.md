# 62-Revit 建筑信息建模（Autodesk Revit）

> **Revit** = Autodesk 的 **BIM 建模平台** —— 建筑 · 结构 · 机电 **一体化**建模 / 出图 / 协同。
> 隶属 [[62-工程学|62 工程学]]（**工具深库**），置 `62-工程学/62-Revit/`。

## 定位

- **类型**：BIM **作者工具**（authoring）—— 建「**模型**」而非画「**线**」。
- **专业**：建筑 / 结构 / 机电（MEP）一体（原 Revit Architecture / Structure / MEP）。
- **与 AutoCAD 之别**：对象化 · 参数化 · 联动（→ [[62-AutoCAD|62-AutoCAD]]）。
