# 04 建筑建模

> 用**建筑构件**搭出空间模型（墙 · 门窗 · 楼板 · 屋顶 · 楼梯）。

## 主要构件

| 构件 | 要点 |
| --- | --- |
| **墙** | 基本墙 / 复合墙（分层）· **幕墙** · 叠层墙 |
| **门 / 窗** | 宿主于墙 · 类型参数 |
| **楼板** | 建筑楼板 · 开洞 · 坡度 |
| **屋顶** | 迹线屋顶 · 拉伸屋顶 · 坡度 |
| **天花板** | 吊顶 |
| **楼梯 / 坡道** | 参数化 · 栏杆 |
| **柱** | 建筑柱（装饰） |
| **房间 / 面积** | 房间边界 · 面积方案 · 色彩方案 |

## 建模流程

`标高轴网 → 墙 → 门窗 → 楼板 → 屋顶 → 楼梯 → 房间 → 标注`

## 幕墙

- 幕墙系统 · 幕墙网格 / 竖梃 · 嵌板。

## 与出图

- 构件即**信息**（明细表可统计门窗 / 面积）（→ [[08-视图出图与明细表]]）。
