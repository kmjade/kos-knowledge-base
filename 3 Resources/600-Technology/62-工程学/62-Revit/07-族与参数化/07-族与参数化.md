# 07 族与参数化

> **族（Family）** 是 Revit 的「构件模板」—— 参数化驱动形态与信息。

## 族类型

| 类型 | 说明 |
| --- | --- |
| **系统族** | 墙 · 楼板 · 管道（内置，不可新建） |
| **可载入族** (.rfa) | 门窗 · 家具 · 设备（可自制 / 下载） |
| **内建族** | 项目内一次性 |

- 族按**类别（Category）**归类（决定明细表 / 可见性）。

## 参数

| 参数 | 作用域 |
| --- | --- |
| **类型参数** | 同类型共用（如同一型号） |
| **实例参数** | 单个实例（如具体尺寸） |

- 参数类型：长度 / 面积 / 材质 / 文字 / 公式。
- **公式驱动** · 约束 · 查表。

## 族编辑器

- 参照平面 + 参数 + 几何 → **参数化构件**。
- 类型目录（Type Catalog）· 嵌套族。

## 意义

- 族 = Revit 的「**可复用知识单元**」；参数化 = 一次定义、多处自适应。
