# 02 界面与项目基础

> 认识 Revit 的**项目组织**与**工作界面**。

## 界面组成

- **功能区（Ribbon）**：建筑 / 结构 / 系统 / 注释 / 视图 / 管理 / 修改。
- **属性面板**：类型 / 实例参数。
- **项目浏览器**：视图 · 图纸 · 族 · 组。
- **绘图区** · **状态栏** · **选项栏**。

## 项目（Project, .rvt）

- 一个项目 = 一个模型（含所有专业视图）。
- **视图类型**：平面（楼层 / 天花板）· 立面 · 剖面 · 三维 · 详图。
- **视图范围 / 可见性替换（V/G）**。
- **图元选择 / 过滤器**。

## 基础操作

| 操作 | 说明 |
| --- | --- |
| 选择 / 过滤 | 按类别 / 属性 |
| 移动 / 复制 / 阵列 | 修改工具 |
| 对齐 / 锁定 | 精确定位 |
| 临时尺寸 | 快速定位 |

## 工作集与阶段

- **工作集（Worksets）**：团队分工（→ [[09-协同与工作流程]]）。
- **阶段（Phases）**：新建 / 既有 / 拆除。
