# 06 MEP 建模

> 用 **MEP**（机电）工具建**管道 · 风管 · 电气**系统（暖通 / 给排水 / 电气）。

## 系统分类

| 专业 | 构件 |
| --- | --- |
| 给排水 | 管道 · 管件 · 卫浴 · 消防 |
| 暖通 | **风管** · 风阀 · 设备 · 末端（风口） |
| 电气 | 电缆桥架 · 线管 · 配电箱 · 照明 · 弱电 |

## 关键概念

- **系统（System）**：管路 / 风管系统（按介质 / 用途）。
- **连接**：自动连接 · 布管路线 · 坡度。
- **占位 / 空间预留**：净高 · 支吊架。

## 管线综合

- 与建筑 / 结构**合模** → 碰撞检测 → 排布（→ [[articles/08-机电管线综合/08-机电管线综合|696 机电管线综合]]）。
- 净高分析 · 预留预埋。
