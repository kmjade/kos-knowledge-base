# 01 Revit 概述

> Revit 是 Autodesk 的 **BIM 建模平台**：用**对象**（墙 / 门 / 管）而非**线**来建模。

## 是什么

- **BIM 作者工具**（authoring）—— 创建、深化、协同建筑信息模型。
- 三个专业集成：**建筑 · 结构 · 机电（MEP）**（现统一为一个 Revit）。
- 产出：三维模型 + 平立剖图纸 + 明细表 / 算量 + 数据。

## 与 AutoCAD 之别

| | AutoCAD | Revit |
| --- | --- | --- |
| 对象 | 线 / 图元 | **构件对象** |
| 关系 | 无 | **参数化联动** |
| 修改 | 逐图修改 | 改模型 → 全图更新 |
| 产出 | 图纸 | 模型 + 图 + 表 |

## 核心概念预览

- **构件 / 族（Family）**· **参数** · **标高 / 轴网** · **视图** · **明细表** · **工作集**。

## 版本与生态

- Revit LT（简化）· 完整版；**Autodesk Construction Cloud / BIM 360**（云协同）。
- 与 [[62-004-BIM|BIM（62:004）]]、[[62-AutoCAD|AutoCAD]]、[[62-SolidWorks|SolidWorks]] 相邻。
