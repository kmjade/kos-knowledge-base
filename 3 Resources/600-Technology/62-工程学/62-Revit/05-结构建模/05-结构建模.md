# 05 结构建模

> 用**结构构件**建承重体系，并可对接结构分析。

## 主要构件

| 构件 | 说明 |
| --- | --- |
| **结构柱** | 混凝土 / 钢 |
| **结构梁** | 框架梁 / 次梁 |
| **结构墙** | 剪力墙 / 结构墙 |
| **结构楼板** | 结构板 |
| **基础** | 独立基础 · 条形 · 筏板 |
| **支撑** | 交叉支撑 |

## 钢筋与配筋

- **钢筋**（Rebar）· 箍筋 · 钢筋网；可生成**钢筋明细表**。
- 与混凝土构件关联。

## 分析对接

- 结构模型 → 导出分析模型（→ [[05-桥梁工程|624 土木]] · 结构分析软件）。
- 与 [[624.01-结构与结构件|624.01 结构与结构件]] 概念呼应。

## 荷载（简要）

- 在 Revit 中定义荷载 → 分析软件计算。
