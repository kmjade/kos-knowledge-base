# 03 标高轴网与参照

> **标高（Level）** 与 **轴网（Grid）** 是模型的**定位骨架**。

## 标高

- 定义**竖向**位置（楼层 / 屋面）。
- 类型 / 实例 · 名称（F1 / 1F / 屋架层）。
- 所有平面视图基于标高。
- 应用：楼层平面 · 立面标注 · 明细表。

## 轴网

- 定义**平面**定位（柱网 / 墙轴）。
- 编号（1-2-3 / A-B-C）· 圆弧轴网。
- 影响：定位 · 尺寸 · 图纸。

## 参照平面

- **参照平面（Reference Plane）**：辅助定位 / 驱动（族中大量使用）。
- 与尺寸标注 / 参数关联。

## 定位与坐标

- **项目基点 / 测量点**（共享坐标）。
- 多专业（建筑 / 结构 / 机电）**统一坐标系**（协同基础）。
