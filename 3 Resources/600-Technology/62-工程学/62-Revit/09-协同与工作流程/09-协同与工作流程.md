# 09 协同与工作流程

> Revit 的威力在**多专业协同**：工作共享 + 链接 + 云。

## 工作共享（Worksharing）

- **中心模型（Central）+ 本地副本**：多人同时编辑。
- **工作集（Worksets）**：分工（如建筑 / 结构 / 机电 / 场地）。
- **同步（Synchronize）** · 借入 / 放出（Borrow / Grant）。
- 规则：各专业建**自己的模型**，不越界。

## 链接模型（Link）

- 建筑 / 结构 / 机电互相**链接** → 合模查看。
- **复制 / 监视**（Copy/Monitor）：同步标高轴网。
- 链接 vs 工作共享：跨专业用**链接**，同专业用**工作共享**。

## 碰撞与协调

- Revit **碰撞检测** · 导出到 **Navisworks** 复核（→ [[05-协同与CDE|BIM 协同与 CDE]]）。

## 云协同

- **Autodesk Construction Cloud / BIM 360** · 云工作共享 · 版本。
- 与 CDE（ISO 19650）对应（→ [[62-004-BIM|62:004 BIM]]）。

## 正向设计流程

`建筑模型 → 结构 / 机电链接 → 合模 → 碰撞 → 出图 → 交付 → 施工 / 运维模型`
