# 07 船舶与海洋工程

> 水上的载具与结构 —— 船 · 平台（UDC 629.5）。

## 船型

| 类型 | 用途 |
| --- | --- |
| 货船 | 散货 · 集装箱 · 油轮 |
| 客船 | 客轮 · 邮轮 |
| 工程船 | 拖轮 · 挖泥 · 起重 |
| 渔船 · 公务船 | — |
| 特种 | 潜艇 · 军舰（→ `623`） |

## 船舶设计

- **船体**：线型 · 结构（框架 · 板）。
- **稳性与浮性**：吃水 · 干舷 · 复原力矩。
- **阻力与推进**：螺旋桨 · 泵喷 · 节能。
- 关键：载重吨 · 航速 · 耐波性。

## 海洋工程

- 平台：固定式 · 浮式（FPSO · 半潜）· 海上风电基础。
- 海底管线 · 系泊。
