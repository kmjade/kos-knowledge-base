# 05 陆上交通工具

> 除铁路外的陆上载具 —— 汽车 · 摩托 · 自行车（UDC 629.3）。

## 汽车

| 类别 | 说明 |
| --- | --- |
| 乘用车 | 轿车 / SUV |
| 商用车 | 卡车 · 客车 |
| 专用车 | 工程 · 消防 · 救护 |
| 新能源 | 纯电 BEV · 插混 PHEV · 燃料电池 FCV |

- 关键子系统：动力总成 · 底盘 · 车身 · 电气。
- 趋势：**电动化 · 智能化 · 网联化 · 共享化**。

## 两轮 / 非机动车

- 摩托车 · 电动自行车 · 自行车（人力 + 电动助力）。

## 发展与法规

- 排放法规（国六等）· 安全（碰撞 · 主动安全）· 汽车电子。
