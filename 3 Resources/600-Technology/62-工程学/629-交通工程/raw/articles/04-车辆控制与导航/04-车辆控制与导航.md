# 04 车辆控制与导航

> 让载具「听指挥、走对路」—— 控制（转向 / 制动 / 稳定）+ 导航（定位 / 引导）（UDC 629.05 · 629.06）。

## 运动控制

| 子系统 | 功能 |
| --- | --- |
| 转向 | 改变行进方向 |
| 制动 | 减速 / 停车（含 ABS） |
| 悬架 | 减振 · 承载 · 姿态 |
| 稳定控制 | ESP / 电子稳定 |

- 飞控是航空器的控制核心（→ [[629.7-FlightControl-飞控|629.7 飞控]]）。

## 导航与引导

- 传统：罗盘 · 地图 · 惯性导航（INS）。
- 卫星：**GPS / 北斗 / GLONASS / Galileo**。
- 组合导航：GNSS + INS。
- 自动驾驶 / 辅助驾驶：感知（雷达 · 激光雷达 · 视觉）+ 决策 + 控制。
