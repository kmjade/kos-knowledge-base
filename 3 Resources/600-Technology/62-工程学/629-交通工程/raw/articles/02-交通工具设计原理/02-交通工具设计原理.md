# 02 交通工具设计原理

> 载运工具设计是**多目标折衷**：性能 · 安全 · 能耗 · 成本 · 舒适（UDC 629.01 · 629.02）。

## 设计原则

- **功能**：载重 / 航程 / 速度 / 通过性。
- **结构**：轻量化（材料 + 拓扑）· 强度刚度 · 疲劳。
- **推进**：动力源选型与效率。
- **人机**：布局（629.04）· 视野 · 操作（629.07）。
- **安全**：被动（结构吸能）+ 主动（控制）。

## 总体设计流程

`需求 → 概念方案 → 总体布置 → 参数优化 → 仿真 / 试验 → 定型`

## 关键约束

| 约束 | 影响 |
| --- | --- |
| 能量 / 续航 | 动力与轻量化 |
| 法规 / 标准 | 安全 · 排放 · 噪声 |
| 成本 | 材料 · 工艺 |
| 环境 | 排放 · 回收 |
