# 03 车辆结构与推进

> 载具的「骨架」与「心脏」—— 结构承载、推进提供动力（UDC 629.02 · 629.03）。

## 结构

- **车身 / 机体**：承载 + 气动外形。
- **底盘 / 车架**：承载 · 悬架连接。
- 材料：钢 · 铝合金 · 碳纤维（轻量化）。

## 推进系统

| 类型 | 原理 | 应用 |
| --- | --- | --- |
| 内燃机 | 燃料爆燃 | 汽车 · 船 · 小型机 |
| **电动机** | 电磁力 | 电动车 · 城轨 |
| 混合动力 | 内燃 + 电 | 汽车 |
| 燃气轮机 | 燃气膨胀 | 飞机 · 舰船 |
| 喷气 / 火箭 | 反作用推力 | 航空 · 航天 |
| 螺旋桨 / 泵喷 | 流体反作用 | 船 / 潜 |

- 能效与排放是核心指标（→ [[620.9-能源经济|620.9 能源经济]]）。

## 传动

- 变速器 · 传动轴 · 差速器（机械）· 电传动（电机直驱 / 轮毂电机）。
