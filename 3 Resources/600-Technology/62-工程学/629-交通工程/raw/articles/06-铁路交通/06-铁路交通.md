# 06 铁路交通

> 铁路载具 = 机车 + 车辆 —— 「在钢轨上跑」（UDC 629.4）。

## 牵引方式

| 方式 | 说明 |
| --- | --- |
| 蒸汽 | 历史 |
| 内燃 | 内燃机车 |
| **电力** | 电力机车 · 动车组（接触网供电） |
| 磁浮 | 无接触 · 高速 |

## 车辆类型

- **动车组**（高铁）：动力分散 · 高速。
- 机车牵引客车 / 货车。
- 客车 · 货车（敞车 · 棚车 · 罐车 · 平车）。
- 城轨车辆（地铁 · 轻轨）。

## 关键系统

- 走行部（转向架）· 制动 · 车体 · 受电弓 / 牵引变流 · 列车控制。
- 与基础设施（轨道 · 供电 · 信号）配合（→ [[625-陆运工程|625 陆运工程]]）。
