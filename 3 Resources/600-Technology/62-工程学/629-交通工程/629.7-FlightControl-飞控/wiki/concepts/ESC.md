# ESC 电调

## 定义

电调（Electronic Speed Controller）把飞控的 PWM / DShot 信号转换为无刷电机的驱动电流。DShot 是当前主流数字协议：免校准、CRC 校验、支持电机转速回传（RPM），便于 RPM 滤波与失效检测。
