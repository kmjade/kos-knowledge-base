# 06 公路勘测与选线

> 公路建设始于**勘测与选线** —— 在满足技术标准下兼顾经济与环境（UDC 625.7）。

## 公路等级（中国）

| 等级 | 特点 |
| --- | --- |
| 高速公路 | 全封闭 · 全立交 · 专用 · 多车道 |
| 一级 | 多车道 · 部分控制出入 |
| 二级 | 双车道为主 |
| 三 / 四级 | 低交通量 |

## 勘测设计阶段

`预可 → 工可 → 初步设计 → 施工图设计`

- 外业：踏勘 · 测量 · 地质勘察。

## 线形设计

| 要素 | 内容 |
| --- | --- |
| 平面 | 直线 · 圆曲线 · 缓和曲线 |
| 纵断面 | 坡度 · 竖曲线 |
| 横断面 | 车道 · 路肩 · 边坡 · 路拱 |
| **视距** | 停车 / 超车视距 |
