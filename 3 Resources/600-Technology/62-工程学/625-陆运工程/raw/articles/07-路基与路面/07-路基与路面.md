# 07 路基与路面

> 路基是「基础」，路面是「表层」—— 共同承受车轮反复荷载（UDC 625.8）。

## 路基

- 填方 / 挖方 · 压实（压实度）· 排水（边沟 · 盲沟）。
- 特殊路基处理（软土 · 膨胀土）。

## 路面结构（层状体系）

| 层 | 作用 |
| --- | --- |
| **面层** | 直接承磨耗 · 抗滑 · 平整 |
| **基层 / 底基层** | 主要承重 |
| **垫层** | 排水 · 隔温 · 整平 |

## 路面类型

| 类型 | 特点 |
| --- | --- |
| **沥青路面** | 柔性 · 行车舒适 · 易修补 |
| **水泥混凝土路面** | 刚性 · 耐久 · 接缝 |
| 复合式 | 组合 |

## 材料

- 沥青（基质 / 改性）· 集料级配 · 水泥混凝土。
