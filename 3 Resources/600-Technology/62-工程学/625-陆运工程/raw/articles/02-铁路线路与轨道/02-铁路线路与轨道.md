# 02 铁路线路与轨道

> 铁路线路提供**平顺、耐磨、可导向**的行驶面（UDC 625.1）。

## 线路

- **平面**：直线 + 曲线（曲线半径 · 超高 · 缓和曲线）。
- **纵断面**：坡度（限制坡度 · 坡长）· 竖曲线。
- **限界**：建筑限界 · 机车车辆限界。

## 轨距

| 轨距 | 尺寸 |
| --- | --- |
| **标准轨距** | 1435 mm（多数国家 · 中国） |
| 宽轨 | 1520 / 1524 mm |
| 窄轨 | 1000 / 1067 mm |

## 轨道结构

| 部件 | 作用 |
| --- | --- |
| **钢轨** | 承载 + 导向（导向面） |
| **轨枕** | 保持轨距 · 传力（木 / 混凝土） |
| **道床** | 排水 · 弹性 · 传力（碎石） |
| **扣件** | 固定钢轨 |
| **道岔** | 线路转换 |

## 无缝线路

- 焊接长钢轨 · 减少接头冲击 —— 降噪 · 延长寿命。
- **无砟轨道**（板式）—— 高铁常用（稳定性好）。
