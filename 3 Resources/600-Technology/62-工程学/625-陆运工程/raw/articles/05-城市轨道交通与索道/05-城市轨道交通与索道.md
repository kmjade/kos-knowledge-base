# 05 城市轨道交通与索道

> 城市里的大运量公共运输 —— 地下 / 高架 / 地面（UDC 625.5）。

## 城市轨道交通

| 制式 | 特点 |
| --- | --- |
| **地铁** | 地下为主 · 大运量 · 独立路权 |
| 轻轨 | 中等运量 · 可地面 / 高架 |
| 单轨 | 跨座 / 悬挂 —— 爬坡强 · 占地小 |
| 有轨电车 / BRT | 中低运量 · 地面 |
| 市域 / 城际铁路 | 都市圈通勤 |

- 关键：线路（盾构 / 明挖 / 高架）· 车站 · 供电（直流 / 交流）· 信号。
- 与 `624` 地下工程 · `621` 电气交叉。

## 索道 / 缆车

- **架空索道**（客运 / 货运）· **缆索铁道 / 缆车** · 悬挂铁路。
- 适用：山地 · 景区 · 大坡度。
- 原理：钢索牵引 + 支架导向。
