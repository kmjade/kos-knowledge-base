# 08 道路交叉与附属设施

> 交叉口是道路的「瓶颈与节点」—— 平交 / 立交决定通行效率与安全（UDC 625.7）。

## 交叉类型

| 类型 | 特点 |
| --- | --- |
| **平面交叉** | 同平面相交（信号 / 环岛 / 渠化） |
| **立体交叉** | 上跨 / 下穿（匝道连接）—— 高速常用 |
| 互通式立交 | 匝道实现各向转向 |
| 分离式立交 | 仅跨线不互通 |

## 附属设施

- **排水**：边沟 · 涵洞 · 雨水口。
- **安全设施**：护栏 · 标志 · 标线 · 防眩 · 隔离栅。
- **照明** · 服务区 · 收费站（→ 智能化）。
- **人行 / 非机动车**：人行道 · 天桥 · 地道。

## 交通组织

- 渠化 · 信号配时 · 慢行优先 · 无障碍。
