# 04 受拉构件与索

> 以**拉力**为主的构件 —— 最高效的受力形式（UDC 624.07）。

## 类型

| 构件 | 说明 |
| --- | --- |
| 拉杆 | 桁架中的受拉杆 |
| **索 / 缆** | 悬索桥主缆 · 斜拉索 · 预应力筋 |
| 支撑 | 交叉支撑的受拉杆 |
| 吊杆 / 拉杆 | 悬挂结构 |

## 受力

- 只需抵抗**强度**（无稳定问题）→ 材料利用最充分。
- 关键：**连接**（锚固 · 索夹）· 疲劳。
- 索：只受拉（不能受压）—— 需预张力维持形状。

## 材料

- 钢索（钢丝绳 · 平行钢丝束）· 高强钢（→ [[05-建筑钢材|691 建筑钢材]]）。
- 预应力筋 · CFRP 索（轻质 · 耐蚀）。

## 应用

- 悬索 / 斜拉桥 · 张弦结构 · 索膜 · 悬挂屋盖。
