# 05 受扭与复合受力

> 实际构件常**同时受多种内力** —— 弯 · 剪 · 扭 · 压 / 拉组合（UDC 624.07）。

## 受扭

- 来源：偏心荷载 · 曲线梁 · 空间作用。
- 类型：**平衡扭转**（受荷需要）· **协调扭转**（变形引起）。
- 混凝土：抗扭靠纵筋 + 箍筋；钢：抗扭刚度（闭口截面优）。

## 复合受力

| 组合 | 示例 |
| --- | --- |
| 压弯 | 柱（偏心受压） |
| 拉弯 | 拉杆受横向荷载 |
| 弯剪扭 | 曲梁 · 边梁 |
| 双向弯 | 板 · 角柱 |

## 分析方法

- 内力叠加（弹性）· 相关曲线（`N–M` 图）。
- 强度准则：复杂应力状态（如 Von Mises）。

## 设计要点

- 截面选择：**闭口 / 箱形**抗扭效率高。
- 构造加强（抗扭箍筋 · 纵筋）。
