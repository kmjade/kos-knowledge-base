# 06 楼盖与屋盖

> 水平承重体系 —— 把楼面 / 屋面荷载传给竖向构件，并**联结成整体**（UDC 624.07）。

## 楼盖

| 类型 | 特点 |
| --- | --- |
| 现浇梁板 | 整体好 |
| 无梁楼盖（板柱） | 空间净高 · 需抗冲切 |
| 密肋 / 井字梁 | 大跨 |
| **叠合楼板** | 预制 + 现浇（装配式） |
| 压型钢板组合楼板 | 钢构常用 |

- 关键：**刚度**（挠度 / 振动）· 隔声 · 平面内刚度（刚性楼板假定）。

## 屋盖

- 平面屋盖（梁板）· 网架 / 网壳 / 张弦（大跨 → [[04-空间结构|624.03 空间结构]]）。
- 需考虑：屋面荷载 · 排水 · 温度作用。

## 作用

- 楼盖 = 结构的「水平隔板」，**协调各竖向构件变形**（整体性关键）。
