# 08 承重基础构件

> 把上部荷载**传给地基**的构件 —— 承重链的最后一环（UDC 624.07）。

## 类型

| 类型 | 说明 |
| --- | --- |
| 独立基础 | 柱下（浅） |
| 条形基础 | 墙下 |
| **筏板基础** | 整体（软 / 多柱） |
| **桩基础** | 深基础（摩擦 / 端承） |
| 沉井 / 地下连续墙 | 深基础 / 挡土 |

## 桩

- 按成桩：预制桩 · 灌注桩（钻孔 / 冲孔）。
- 按受力：摩擦桩 · 端承桩 · 抗拔桩。
- 关键：承载力 · 沉降 · 完整性检测。

## 受力与设计

- 基础底面积 → 地基承载力 / 变形。
- 冲切 · 抗弯 · 抗剪（扩展基础）。
- 与 [[03-基础与土方工程|624 基础与土方]] 配合。
