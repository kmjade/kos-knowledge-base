# 03 受压构件

> 以**压力**为主的竖向构件 —— 柱与承重墙（UDC 624.07）。

## 受力

- **轴心受压** · **偏心受压（压弯）**（弯矩 + 轴力）。
- 关键：**稳定**（长细比）· 强度。

## 柱

| 类型 | 说明 |
| --- | --- |
| 钢筋混凝土柱 | 纵筋 + 箍筋（约束） |
| 钢柱 | 实腹 / 格构（缀条） |
| 钢管 / 型钢混凝土 | 组合（→ 624.01 组合） |
| 短柱 / 长柱 | 长细比 → 失稳 |

- 大 / 小偏心受压 → 破坏形态不同。

## 墙

- **承重墙**（砌体 · 混凝土）· **剪力墙**（抗侧）。
- 高厚比 · 稳定性。

## 设计要点

- 长细比 λ · 稳定系数 φ · 配筋 / 构造。
- 抗震：轴压比限制 · 强柱弱梁。
