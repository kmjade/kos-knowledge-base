# 02 受弯构件

> 以**弯曲**为主要受力的水平构件 —— 梁与板（UDC 624.07）。

## 受力

- 弯矩 M（拉 / 压应力）· 剪力 V（剪应力）→ 弯剪破坏。
- 控制：**承载力**（正截面 / 斜截面）· **挠度** · **裂缝**。

## 梁

| 类型 | 说明 |
| --- | --- |
| 简支 / 连续 / 悬臂 | 支座 |
| 钢筋混凝土 / 预应力 | 材料 |
| 钢梁 / 组合梁 | 材料 |
| 深梁 / 扁梁 | 尺度 |

- 截面效率：加大高度（`I ∝ h³`）· 工形截面。

## 板

- **单向板**（长边/短边 ≥ 2）· **双向板**。
- 无梁楼盖（板柱）· 密肋板 · 叠合板。

## 设计

- 混凝土：适筋 / 少筋 / 超筋；配筋率。
- 钢：整体稳定 · 局部稳定（→ [[07-稳定性分析|624.04 稳定性]]）。
