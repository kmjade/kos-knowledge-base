# 07 支撑与抗侧体系

> 抵抗**水平荷载**（风 · 地震）的构件体系 —— 结构的「方向盘」（UDC 624.07）。

## 抗侧元件

| 元件 | 机制 |
| --- | --- |
| **支撑**（中心 / 偏心） | 桁架作用 · 最经济 |
| **剪力墙** | 混凝土墙抗剪 |
| **框架** | 梁柱弯曲抗侧（柔） |
| **筒体** | 空间抗侧（高层） |
| 阻尼器 / 消能 | 耗能减震 |

## 支撑布置

- 竖向连续 · 对称 · 平面内双向布置。
- 中心支撑（CBF）· 偏心支撑（EBF · 耗能）· 屈曲约束支撑（BRB）。

## 体系组合

- 框-剪 · 框-支撑 · 筒中筒 · 巨型框架。
- 目标：足够**抗侧刚度** + **延性**（抗震）。

## 与稳定

- 支撑为柱 / 梁提供**侧向支撑**，提高稳定（→ [[07-稳定性分析|624.04 稳定性]]）。
