# 09 连接件与锚固

> 构件之间的「关节」—— 传力是否可靠决定整体安全（UDC 624.07）。

## 连接件

| 连接件 | 应用 |
| --- | --- |
| 高强螺栓 | 钢结构 |
| 焊缝 | 钢结构 |
| 栓钉 | 组合结构 |
| 灌浆套筒 | 装配式混凝土 |
| 预埋件 / 锚栓 | 连接主体与附属 |
| 索夹 · 锚具 | 索 / 预应力 |

## 锚固

- 钢筋**锚固长度** L_a · 搭接 · 弯钩。
- 后锚固（化学锚栓 · 膨胀螺栓）—— 既有结构改造。
- 预应力锚具（夹片 · 锚杯）。

## 设计要点

- 传力路径清晰 · 强度 ≥ 被连接构件（**强连接**）。
- 抗震：**强节点弱构件** · 延性 · 焊接质量等级。
- 与 [[08-结构连接与节点|624.01 连接与节点]] 配合。
