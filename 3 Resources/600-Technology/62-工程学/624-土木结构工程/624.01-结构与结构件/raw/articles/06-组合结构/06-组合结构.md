# 06 组合结构

> 让**不同材料各展所长** —— 钢受拉、混凝土受压（UDC 624.01）。

## 主要体系

| 体系 | 说明 |
| --- | --- |
| **钢-混凝土组合梁** | 钢梁 + 混凝土翼板（栓钉连接） |
| **钢管混凝土** | 钢管约束混凝土（抗压高 · 延性好） |
| 型钢混凝土（SRC） | 型钢 + 钢筋混凝土 |
| 压型钢板组合楼板 | 钢板作模板 + 受拉筋 |

## 关键

- **剪力连接件**（栓钉）—— 保证协同工作。
- 抗火（钢需保护 · 混凝土自防火）· 施工快（钢板作模板）。

## 应用

- 高层 · 大跨 · 桥（钢-混组合梁）· 地下（钢管柱）。
