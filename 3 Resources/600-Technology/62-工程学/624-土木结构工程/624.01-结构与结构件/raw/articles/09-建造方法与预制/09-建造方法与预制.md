# 09 建造方法与预制

> 同一结构可用不同**建造方法**实现 —— 现浇 vs 预制（UDC 624.01）。

## 方法对比

| 方法 | 特点 |
| --- | --- |
| **现浇** | 整体性好 · 现场湿作业多 |
| **预制 / 装配式（PC）** | 工厂化 · 快 · 质量稳定 · 需可靠连接 |
| 装配整体 | 预制 + 后浇 / 叠合 |
| 钢结构装配 | 吊装 + 连接 |

## 预制构件

- 预制梁 / 柱 / 墙板 / 楼梯 / 叠合板。
- 关键：**连接**（灌浆套筒 · 后浇带）· 运输吊装 · 节点（→ [[08-结构连接与节点]]）。

## 现浇关键技术

- 模板 · 钢筋 · 混凝土浇筑与养护。
- 滑模 / 爬模（高耸）· 顶升（大跨）。

## 工业化与低碳

- 装配式 = 减少现场作业 · 降低浪费。
- 与 BIM（→ `621.38` / `004`）· 建筑工业（→ [[693-砌筑与建筑工艺|693 砌筑与建筑工艺]]）联动。
