# 02 混凝土结构

> 混凝土（受压）与钢筋（受拉）组合 —— 当今最主流的结构材料（UDC 624.01）。

## 分类

| 类型 | 说明 |
| --- | --- |
| **钢筋混凝土** | 普通钢筋承拉 |
| **预应力混凝土** | 预先施加压应力（先张 / 后张） |
| 素混凝土 | 无筋（受压构件） |

## 受力与设计

- 构件：受弯（梁 / 板）· 受压（柱）· 受剪 · 受扭。
- **极限状态设计** · 配筋率 · 裂缝与挠度控制。
- 规范：**GB 50010**（混凝土结构设计规范）· GB 50011（抗震）。

## 材料

- 混凝土：强度等级 C15–C80（见 [[03-混凝土|691 混凝土]]）。
- 钢筋：HPB300 · HRB400 / 500 / 600（见 [[05-建筑钢材|691 建筑钢材]]）。

## 构造

- 保护层 · 锚固 · 搭接 · 箍筋。
- 抗震构造（延性）。
