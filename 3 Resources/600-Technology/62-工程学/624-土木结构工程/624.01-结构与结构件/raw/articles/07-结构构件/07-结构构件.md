# 07 结构构件

> 结构的「零件」—— 按受力分工（UDC 624.01）。

## 水平构件

| 构件 | 受力 |
| --- | --- |
| **梁** | 受弯 + 受剪 |
| **板** | 受弯（双向 / 单向） |
| 楼盖 / 屋盖 | 水平传力 |

- 形式：简支 · 连续 · 悬臂 · 井字梁 · 密肋。

## 竖向构件

| 构件 | 受力 |
| --- | --- |
| **柱** | 受压 / 压弯 |
| **墙** | 承重（砌体）· 抗侧（剪力墙） |
| 支撑 | 抗侧 / 稳定 |

## 基础构件

- 独立基础 · 条形 · 筏板 · 桩（见 [[03-基础与土方工程|624 基础与土方]]）。
