# 08 结构连接与节点

> 节点是结构的「关节」—— 传力是否可靠，决定整体安全（UDC 624.01）。

## 连接方式

| 方式 | 应用 |
| --- | --- |
| **焊接** | 钢节点（质量 · 残余应力） |
| **螺栓**（含高强螺栓） | 钢 / 装配式节点 |
| 铆接 | 历史 / 特殊 |
| 锚固 · 搭接 | 混凝土钢筋 |
| 灌浆套筒 | 装配式混凝土（PC） |
| 榫卯 · 金属件 | 木结构 |

## 节点类型

- **刚接**（传弯矩）· **铰接**（仅传剪力）· 半刚接。
- 梁柱节点 · 柱脚 · 支撑节点 · 索 / 节点。

## 设计要点

- 传力路径清晰 · 延性（抗震「强节点弱构件」）。
- 规范构造（焊缝质量等级 · 螺栓排布）。
