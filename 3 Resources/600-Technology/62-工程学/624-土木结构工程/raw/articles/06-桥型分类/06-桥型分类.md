# 06 桥型分类

> 按**受力体系**分桥型 —— 跨度与地形决定选择（UDC 624.3 · 624.5 · 624.6 · 624.8）。

## 基本桥型

| 桥型 | 受力 | 经济跨度（量级） |
| --- | --- | --- |
| **梁桥** | 受弯 | 小–中 |
| **刚构桥** | 梁柱刚接 | 中 |
| **拱桥** | 受压 | 中–大 |
| **桁架桥** | 杆件轴力 | 中–大 |
| **斜拉桥** | 索拉 + 塔压弯 | 大 |
| **悬索桥** | 主缆受拉 | 超大 |

## 其他

- **开启桥**（`624.8`）：通航需要时开启。
- 浮桥 · 组合体系（斜拉 + 悬索 · 拱 + 梁）。
- 按材料：钢桥 · 混凝土桥 · 钢-混组合 · 木桥。

## 选型要点

- 跨度 · 地质 · 通航 · 造价 · 施工条件 · 景观。
