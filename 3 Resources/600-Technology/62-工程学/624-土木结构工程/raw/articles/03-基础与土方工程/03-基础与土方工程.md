# 03 基础与土方工程

> 基础把**上部荷载**传给地基 —— 「万丈高楼平地起」（UDC 624.1）。

## 地基与勘察

- **地基**：支承基础的土层 / 岩层。
- 岩土工程勘察：钻探 · 原位测试（CPT · SPT）· 室内试验。
- 承载力 · 沉降 · 液化。

## 基础类型

| 类型 | 适用 |
| --- | --- |
| **浅基础** | 独立 / 条形 / 筏板 / 箱形（浅层好土） |
| **深基础** | **桩基**（预制桩 / 灌注桩）· 沉井 · 地下连续墙 |
| 处理地基 | 换填 · 强夯 · 复合地基 |

## 基坑工程

- 支护：排桩 · 地连墙 · 土钉 · 内支撑 · 锚索。
- 降水 · 监测 · 变形控制。

## 土方

- 开挖 / 回填 · 压实（压实度）· 边坡稳定。
