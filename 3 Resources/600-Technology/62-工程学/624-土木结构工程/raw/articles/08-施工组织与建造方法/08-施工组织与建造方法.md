# 08 施工组织与建造方法

> 把图纸变成实体 —— **施工组织 · 工艺 · 工业化**（UDC 624.05）。

## 施工组织设计

- 施工部署 · 进度计划（关键路径 CPM）· 资源配置 · 平面布置。
- 质量 / 安全 / 成本 / 进度「四控」。

## 主要工序

`土方 → 基础 → 主体（模板 / 钢筋 / 混凝土 / 钢构）→ 围护 → 装饰 → 机电安装`

## 建造方式

| 方式 | 特点 |
| --- | --- |
| 现浇 | 整体性好 · 现场湿作业 |
| **装配式（PC）** | 工厂预制 + 现场装配 · 快 · 环保 |
| 钢结构装配 | 工期短 · 可回收 |
| 滑模 / 爬模 | 高耸结构 |

## 技术要点

- 模板与脚手架 · 混凝土浇筑与养护（见 [[693-砌筑与建筑工艺|693 砌筑与建筑工艺]]）。
- 冬期 / 雨期施工 · 大体积混凝土温控。
- 施工机械与吊装。
