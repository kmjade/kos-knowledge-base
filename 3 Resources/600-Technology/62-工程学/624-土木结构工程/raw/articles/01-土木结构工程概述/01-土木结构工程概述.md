# 01 土木结构工程概述

> 土木结构工程 = 用**结构**安全承载荷载、构筑**基础设施** —— 是「与大地打交道」的工程学。

## 领域

| 领域 | 典型 |
| --- | --- |
| 建筑工程 | 房屋 · 高层结构 |
| 桥梁工程 | 梁 / 拱 / 斜拉 / 悬索 |
| 地下工程 | 隧道 · 地铁 · 基坑 |
| 道路交通 | 路基 · 路面（→ `625`） |
| 水工 | 坝 · 堤（→ `626/627`） |

## 全生命周期

`规划 → 设计 → 施工 → 运营 → 维护 / 加固 → 拆除`

- 结构工程关注**安全 · 适用 · 耐久 · 经济**。

## 与「建筑」的区别

- **土木 / 结构**：**承载与安全**（结构体系 · 受力）。
- **建筑（设计）**：**空间与形式**（→ [[72-建筑|72 建筑]]）。
