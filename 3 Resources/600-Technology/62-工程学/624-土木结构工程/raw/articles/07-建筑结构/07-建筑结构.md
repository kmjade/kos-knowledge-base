# 07 建筑结构

> 房屋的**承重骨架** —— 决定承载力、刚度与抗震性能（UDC 624.9）。

## 结构体系

| 体系 | 特点 |
| --- | --- |
| 砌体结构 | 砖 / 砌块 + 圈梁构造柱（多层） |
| 框架结构 | 梁柱刚接（灵活） |
| 剪力墙结构 | 抗侧刚度大（住宅） |
| 框架-剪力墙 | 二者结合 |
| 筒体 / 束筒 | 高层 / 超高层 |
| 钢结构 | 轻 · 快 · 大跨 / 高层 |

## 高层结构

- 控制指标：**位移（层间位移角）· 刚度 · 舒适度（风振）**。
- 抗侧体系 · 加强层 · 伸臂桁架。
- 核心筒 + 外框（常见超高层方案）。

## 楼盖与屋盖

- 现浇楼板 · 叠合板 · 压型钢板组合楼板。
- 大跨屋盖：网架 · 网壳 · 膜结构 · 张弦梁。
