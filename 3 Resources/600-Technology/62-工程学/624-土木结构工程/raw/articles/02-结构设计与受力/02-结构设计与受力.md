# 02 结构设计与受力

> 结构设计 = 让结构在**各种荷载**下**安全、适用、耐久**（UDC 624.04）。

## 荷载

| 类型 | 说明 |
| --- | --- |
| 永久（恒） | 自重 · 固定设备 |
| 可变（活） | 人员 · 家具 · 车辆 · 雪 |
| 偶然 | 地震 · 风 · 撞击 · 爆炸 |
| 温度 / 沉降 | 间接作用 |

## 结构体系

| 体系 | 受力特点 |
| --- | --- |
| 梁 / 板 | 受弯 |
| 柱 / 墙 | 受压（+ 压弯） |
| 框架 | 梁柱刚接 |
| 桁架 | 杆件轴力 |
| 拱 | 受压抑弯 |
| 索 / 悬索 | 受拉 |

## 设计方法

- **极限状态设计**：承载力极限状态（ULS）+ 正常使用极限状态（SLS）。
- 分项系数 · 荷载组合 · 可靠度。
- 混凝土 / 钢 / 砌体 / 木各有规范（见 [[07-工程标准与规范|07 工程标准与规范]]）。
