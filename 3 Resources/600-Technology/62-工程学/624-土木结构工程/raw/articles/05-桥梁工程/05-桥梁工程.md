# 05 桥梁工程

> 桥梁 = 跨越**障碍**（河 · 谷 · 路）的承重结构（UDC 624.2/.8）。

## 组成

| 部分 | 作用 |
| --- | --- |
| **上部结构** | 主梁 / 拱 / 索 —— 跨越 |
| **下部结构** | 桥墩 · 桥台 —— 支承 |
| **基础** | 传力至地基 |
| 附属 | 桥面 · 支座 · 伸缩缝 · 栏杆 |

## 荷载与设计

- 恒载 + 车辆 / 人群活载 + 风 · 地震 · 温度。
- 支座 · 伸缩缝 · 变形协调。
- 规范：公路桥涵设计通用规范等（**待核**）。

## 施工方法

| 方法 | 适用 |
| --- | --- |
| 满堂支架 | 低矮 · 现浇 |
| 悬臂浇筑 / 拼装 | 大跨连续梁 / 斜拉 |
| 顶推 | 跨线桥 |
| 转体 | 跨铁路 / 峡谷 |
| 缆索吊装 | 拱桥 · 峡谷 |
