# 04 隧道与地下工程

> 在地下**开挖并支护**空间 —— 隧道 · 地铁 · 地下空间（UDC 624.1）。

## 施工方法

| 方法 | 特点 |
| --- | --- |
| **矿山法 / 新奥法 NATM** | 钻爆开挖 + 锚喷支护 + 量测 |
| **盾构法** | 盾构机掘进 + 管片衬砌（软土 / 地铁） |
| **明挖法** | 开挖 + 支撑 + 回填（浅埋） |
| **沉管法** | 预制管段沉放（水下隧道） |
| TBM | 全断面岩石掘进机 |

## 支护与衬砌

- 初期支护（锚杆 · 喷射混凝土 · 钢拱）。
- 二次衬砌（模筑混凝土）· 防水层。

## 地下空间

- 地铁 · 地下车库 · 综合管廊 · 人防。
- 通风 · 照明 · 排水 · 消防（与 `69` · `696` 交叉）。

## 风险

- 塌方 · 涌水 · 地面沉降 · 邻近建筑影响。
