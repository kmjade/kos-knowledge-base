# 01 结构设计与分析概述

> 结构分析 = 用**力学模型 + 计算**求出结构在荷载下的**内力 · 变形 · 稳定 · 动力响应**，支撑设计决策。

## 分析在设计中

`确定荷载 → 建立模型 → 选方法 → 计算 → 验算（极限状态）→ 配筋 / 选型`

- 与设计规范（GB 50010 / 50017 …）配合：分析得内力 → 构件验算。

## 方法谱系

| 类别 | 方法 |
| --- | --- |
| 经典手算 | 静定分析 · 力法 · 位移法 · 弯矩分配 |
| 计算机 | 矩阵位移法 · **有限元 FEM** |
| 动力 | 振型分解 · 时程分析 |
| 稳定 | 欧拉屈曲 · 二阶分析 |
| 概率 | 可靠度 · 极限状态 |
