# 09 可靠度与统计分析

> 荷载与抗力都是**随机变量** —— 用概率论保证结构安全（UDC 624.04「统计」）。

## 极限状态设计

| 状态 | 含义 |
| --- | --- |
| **承载能力极限状态**（ULS） | 强度 / 稳定失效 |
| **正常使用极限状态**（SLS） | 变形 / 裂缝 / 振动 |

- 设计式：`R_d ≥ S_d`（抗力设计值 ≥ 作用效应设计值）。
- **分项系数**（荷载 γ · 材料 γ_m）来自校准。

## 可靠度

- **可靠指标 β** → 失效概率 P_f。
- 目标可靠度按**安全等级 / 破坏后果**设定（GB 50068）。
- 一次二阶矩法（FORM）。

## 荷载组合与统计

- 恒 + 活 + 风 + 地震 → 组合系数。
- 统计：分布类型 · 均值 / 标准差 · 重现期。
- 结构可靠度 = 多随机变量联合概率问题。
