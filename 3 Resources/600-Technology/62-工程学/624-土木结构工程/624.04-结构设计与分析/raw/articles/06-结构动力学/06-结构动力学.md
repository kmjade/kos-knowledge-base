# 06 结构动力学

> 动荷载（地震 · 风 · 机械）下结构会**振动** —— 需动力学分析（UDC 624.04）。

## 基本概念

- 自由度 · **自振频率 / 周期** · 振型 · 阻尼。
- 共振（激励频率 ≈ 自振频率）。
- 单自由度 → 多自由度（振型叠加）。

## 地震反应分析

| 方法 | 说明 |
| --- | --- |
| 底部剪力法 | 简化（规则低层） |
| **振型分解反应谱法** | 常用 |
| 时程分析 | 逐步积分（重要 / 复杂） |

- 反应谱：由地震记录统计得到（→ **统计**）。
- 与 [[09-结构耐久与防灾|624 结构耐久与防灾]] · GB 50011 配合。

## 风工程

- 顺风向 / 横风向 · 涡激振动 · 舒适度（加速度）。
- 风洞试验 · 气动措施 · 阻尼器（TMD / TLD）。
