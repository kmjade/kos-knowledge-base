# 08 结构试验与检测

> 分析之外，用**试验 / 检测**验证与调查结构（UDC 624.04「结构调查」）。

## 结构试验

| 类型 | 目的 |
| --- | --- |
| 模型试验 | 验证理论 / 机理（缩尺） |
| **静载试验** | 承载力 · 变形 |
| **拟动力 / 振动台** | 抗震性能 |
| 风洞试验 | 风效应 |
| 疲劳试验 | 循环荷载 |

- 量测：应变片 · 位移计 · 加速度计 · 力传感器。
- 加载：液压作动器 · 反力架。

## 结构检测与调查

- 既有结构：材料强度（回弹 / 钻芯）· 钢筋（扫描）· 缺陷（超声）。
- 结构现状调查 → 鉴定 → 加固依据（→ [[09-结构耐久与防灾|624 耐久与防灾]]）。
- 健康监测 SHM（长期传感）。
