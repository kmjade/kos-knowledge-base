# 02 结构建模与计算简图

> 把真实的建筑**简化**为可计算的「杆件 + 节点 + 支座 + 荷载」（UDC 624.04）。

## 简化内容

| 简化  | 处理                                                                                                                           |     |
| --- | ---------------------------------------------------------------------------------------------------------------------------- | --- |
| 构件  | 杆 / 板 / 壳单元                                                                                                                  |     |
| 节点  | 刚接 / 铰接                                                                                                                      |     |
| 支座  | 固定 / 铰 / 滚动（→ [[07-位置与支承条件\|624.03 支承]]） |     |
| 荷载  | 恒 / 活 / 风 / 地震 → 分布 / 集中                                                                                                     |     |
| 材料  | 线弹性 / 非线性                                                                                                                    |     |

## 平面 vs 空间

- 平面简化（规则结构）· 空间整体模型（不规则 / 高层）。
- 楼板**刚性假定**（平面内无限刚）。

## 建模要点

- 传力路径清晰 · 与实际受力一致。
- 计算机模型：单元划分 · 边界施加 · 荷载工况组合。
