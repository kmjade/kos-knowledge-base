# 07 稳定性分析

> 受压 / 受弯构件的失效常不是「强度不够」而是「**失稳**」（UDC 624.04）。

## 屈曲类型

| 类型 | 说明 |
| --- | --- |
| **分支屈曲** | 理想直杆分岔（欧拉临界力） |
| 极值屈曲 | 非线性（壳） |
| 跃越屈曲 | 突跳（扁壳） |

## 欧拉压杆

- 临界力 `P_cr = π²EI / (μl)²`。
- 计算长度 `μl` 由**支承条件**决定（→ [[07-位置与支承条件|624.03 支承]]）。
- 长细比 λ 越大越易失稳。

## 整体稳定 · 局部稳定

- 钢：**整体稳定**（侧向支撑）· **局部稳定**（板件宽厚比）。
- 薄壳：对缺陷敏感。

## 分析

- 特征值屈曲（线性）· **二阶分析（P-Δ / P-δ）**（考虑变形）。
- 几何非线性。
