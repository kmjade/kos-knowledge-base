# 05 矩阵位移法与有限元

> 现代结构分析的主力 —— 把结构离散为**单元矩阵**，计算机求解（UDC 624.04）。

## 矩阵位移法

- 位移法 + 矩阵运算 → 系统方程：

  `[K]{u} = {F}`（K 刚度矩阵 · u 位移 · F 荷载）

- 求解 → 位移 → 单元内力。

## 有限元法（FEM）

- 思想：连续体 → 有限个**单元**（杆 · 梁 · 板 · 壳 · 实体）→ 节点自由度。
- 步骤：离散 → 单元刚度 → 组装 → 施加边界 / 荷载 → 求解 → 后处理。
- 非线性：几何（大变形 / 稳定）· 材料（塑性）· 接触。
