# 624.03 结构尺寸与形态

> **UDC 624.03** — 结构的大小 · 永久性 · 位置和形状（Size, permanence, position and shape of structures）。隶属 [[624-土木结构工程|624 土木结构工程]]。
> 本类关注结构的**四要素**：尺度 · 形状 · 位置（支承）· 永久性。

## 四个要素

| 要素 | 含义 |
| --- | --- |
| **大小** | 跨度 · 高度 · 长细比 · 尺度 |
| **形状** | 结构形式与体型（梁 / 拱 / 壳 / 索） |
| **位置** | 支承条件 · 边界 · 支承位置 |
| **永久性** | 临时 / 永久 · 设计使用年限 · 耐久 |
