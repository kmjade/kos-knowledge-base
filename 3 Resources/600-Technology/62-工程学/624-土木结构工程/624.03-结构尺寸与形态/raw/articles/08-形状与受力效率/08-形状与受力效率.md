# 08 形状与受力效率

> 「**形是力的表达**」—— 合理形态让材料效率最大化（UDC 624.03）。

## 形态效率原理

- 让构件以**轴向力**工作（拉 / 压）→ 比受弯高效。
- 例：拱 / 壳把弯曲转为**面内受压**；索用**受拉**。
- 截面效率：截面惯性矩 `I ∝ 高度³` → 加大高度比加宽更有效。

## 经典形态

| 形态 | 效率来源 |
| --- | --- |
| 桁架 | 杆件轴力 |
| 拱 / 壳 | 受压圆拱作用 |
| 悬索 | 纯受拉 |
| 薄壳 / 网壳 | 薄膜力 |
| 仿生（树 / 骨） | 力流连续 |

## 形态与美学

- 结构与建筑形态统一（如「**结构即艺术**」）。
- 找形（Form-finding）：悬链线 · 极小曲面。
