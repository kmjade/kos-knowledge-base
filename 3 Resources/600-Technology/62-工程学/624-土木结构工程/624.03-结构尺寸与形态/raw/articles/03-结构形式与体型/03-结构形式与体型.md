# 03 结构形式与体型

> 结构形式 = 力流的「形状」—— 不同形式适合不同跨度与荷载（UDC 624.03）。

## 基本形式

| 形式 | 受力 | 特点 |
| --- | --- | --- |
| **梁式** | 受弯 | 简单 · 中小跨 |
| **桁架** | 杆件轴力 | 省材 · 中大跨 |
| **刚架 / 框架** | 梁柱刚接 | 空间灵活 |
| **拱** | 受压 | 中大跨 · 需抗推力 |
| **壳体** | 面内受压 | 覆盖 · 大跨 |
| **悬索 / 斜拉** | 索受拉 | 超大跨 |

## 体型（整体形态）

- 规则 vs 不规则（平面 / 竖向）。
- 抗侧体系：框架 · 剪力墙 · 筒体 · 支撑（→ [[07-建筑结构|624 建筑结构]]）。
- 体型规则性是抗震设计的重要指标。
