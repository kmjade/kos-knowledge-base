# 07 位置与支承条件

> 结构「怎么被托住」决定它怎么受力 —— 支承就是**边界条件**（UDC 624.03）。

## 支承类型

| 支承 | 约束 | 简图 |
| --- | --- | --- |
| 固定铰 | 位移 | 铰支座 |
| 固定端 | 位移 + 转动 | 固支 |
| 滚动 | 仅单向 | 辊轴 |
| 弹性 | 部分约束 | 弹簧 |

- 支承 → 计算长度 · 弯矩分布 · 内力重分布。

## 位置与约束

- 支承**位置**改变 → 受力路径改变（如连续 vs 简支）。
- 基础约束：沉降差 → 次内力。
- 温度 / 收缩 → 约束应力。

## 工程意义

- 实际支承常介于「理想铰 / 固支」之间 → 需判断。
- 抗震：**延性** + 耗能机制与支承 / 约束相关。
