# 05 高层与大跨

> 尺度跨过某阈值后，**主导荷载与失效模式**都会变（UDC 624.03）。

## 高层结构

- 主导荷载：**侧向荷载**（风 · 地震）> 竖向自重。
- 控制：**层间位移角** · 刚度 · 舒适度（风振加速度）。
- 体系：框架 → 框-剪 → 剪力墙 → 筒体 → 束筒 / 巨型。
- 竖向：各种「悬挂 / 伸臂 / 腰桁架」提高整体性。

## 大跨结构

- 主导：**自重** + 稳定（屈曲）· 挠度。
- 体系：桁架 / 网架 → 拱 / 壳 → 悬索 / 斜拉。
- 关键：轻质高强材料 · 合理形态 · 施工（提升 / 顶推 / 悬拼）。

## 尺度阈值

- 超高层 → 风工程 / 阻尼器。
- 超大跨 → 形态找形 / 非线性 / 施工控制。
