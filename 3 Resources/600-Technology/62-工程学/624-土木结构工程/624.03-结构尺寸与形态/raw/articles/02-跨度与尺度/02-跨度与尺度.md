# 02 跨度与尺度

> 尺度是结构最根本的约束 —— **跨度**与**高度**决定选型与受力（UDC 624.03）。

## 跨度

| 跨度量级 | 常用结构 |
| --- | --- |
| 小（< 10 m） | 梁 / 板 |
| 中（10–40 m） | 梁 · 桁架 · 刚架 |
| 大（40–200 m） | 拱 · 斜拉 · 网架 |
| 超大（> 200 m） | 悬索 · 壳体 |

- 跨度越大，**自重占比越高**，需轻质高强与合理形态。

## 高度与长细比

- **长细比** λ（受压杆件）—— 影响稳定与承载。
- 层高 · 高宽比（高层）。
- 细长结构：风致振动 · 稳定敏感。

## 高宽比与抗侧

- 高层结构的高宽比 → 抗侧刚度 · 位移限值。

## 尺度效应

- 尺度放大 → 自重与风 / 地震荷载规律变化 → **不能简单等比例放大**。
