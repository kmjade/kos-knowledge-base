# 04 空间结构

> 三维受力、覆盖大跨的结构体系（UDC 624.03）。

## 类型

| 类型 | 受力 | 应用 |
| --- | --- | --- |
| **网架** | 空间杆系 | 体育馆 · 厂房 |
| **网壳** | 曲面杆系 | 大跨屋面 / 穹顶 |
| **壳体** | 面内薄膜力 | 大跨屋盖 / 冷却塔 |
| **膜结构** | 张力膜 | 景观 · 体育场 |
| **索结构** | 索受拉 | 悬索 · 张弦 / 弦支 |
| **充气结构** | 内压支撑 | 临时 / 特殊 |

## 特点

- **三维受力** → 高效利用材料 · 自重轻。
- 关键：**形态确定**（找形）· 稳定性（网壳屈曲）· 节点。
- 施工：分段吊装 / 整体提升 / 滑移。
