# 03 施工平面布置

> 工地的「空间规划」—— 在有限场地里安排物、机、人、路（UDC 624.05）。

## 布置内容

| 设施 | 关注 |
| --- | --- |
| 临时道路 | 环形 · 承载力 · 消防通道 |
| 材料堆场 | 靠近使用点 · 分类 |
| 加工场 | 钢筋 / 模板 / 混凝土 |
| 临时设施 | 办公 · 生活 · 仓库 |
| **临时水电** | 配电（三级配电两级保护）· 供水 |
| 大型机械 | 塔吊 · 施工电梯布置 |

## 塔吊布置

- 覆盖范围 · 与建筑距离 · 附墙 · 群塔防碰撞。
- 起重能力（力矩）校核。

## 原则

- 物流短 · 干扰少 · 安全（消防 · 临电）· 符合文明施工。
