# 04 施工进度与流水施工

> 让工序**有序、连续、均衡**地推进（UDC 624.05）。

## 进度计划工具

| 工具 | 特点 |
| --- | --- |
| 横道图（甘特图） | 直观 · 简单 |
| **网络计划**（CPM / PERT） | 逻辑清晰 · 找关键线路 |
| 关键线路法 | 总时差 = 0 的工序链 |

- 概念：工序 · 时差 · **关键线路** · 工期优化。

## 流水施工

- 把工程划为**施工段**，各工种（工作队）依次连续作业。
- 参数：施工段数 m · 流水节拍 t · 流水步距 K。
- 效果：均衡资源 · 缩短工期 · 提高效率。

## 资源与优化

- 资源均衡 · 工期-成本优化 · 赶工。
