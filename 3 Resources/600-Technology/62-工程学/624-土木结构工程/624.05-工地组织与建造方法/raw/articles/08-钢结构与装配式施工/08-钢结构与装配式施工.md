# 08 钢结构与装配式施工

> 从「现场湿作业」走向「**工厂 + 装配**」（UDC 624.05）。

## 钢结构施工

- 流程：制作（工厂）→ 运输 → **吊装** → 校正 → 连接（焊接 / 高强螺栓）→ 涂装 / 防火。
- 关键：吊装方案（分段 / 整体提升 / 滑移）· 变形控制 · 焊接质量。
- 与 [[03-钢结构|624.01 钢结构]] 配合。

## 装配式（PC）施工

| 环节 | 要点 |
| --- | --- |
| 预制生产 | 工厂模具 · 养护 |
| 运输 | 保护 · 顺序 |
| 吊装 | 起重选型 · 就位 |
| **连接** | 灌浆套筒 · 后浇区（关键） |
| 精度 | 测量 · 标高轴线 |

- 优点：快 · 少湿作业 · 质量稳定（→ [[09-建造方法与预制|624.01 建造方法与预制]]）。
