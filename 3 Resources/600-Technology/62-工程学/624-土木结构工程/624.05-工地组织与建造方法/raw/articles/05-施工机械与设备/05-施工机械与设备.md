# 05 施工机械与设备

> 机械化决定施工的**效率与安全**（UDC 624.05「厂房 / plant」）。

## 主要类别

| 类别   | 代表                                                                          |
| ---- | --------------------------------------------------------------------------- |
| 土方   | 挖机 · 装载机 · 自卸车 · 压路机                                                        |
| 起重   | **塔式起重机** · 履带吊 · 汽车吊                                                       |
| 垂直运输 | 施工电梯 · 井架                                                                   |
| 混凝土  | 泵车 / 布料机 · 搅拌车 · 振捣器                                                        |
| 桩工   | 旋挖钻 · 打桩机                                                                   |
| 装修   | 抹灰机器人（如 [[抹灰机器人\|抹灰机器人]]） |

## 选型原则

- 匹配工程量 / 工期 · 场地条件 · 经济性。
- 起重机械：起重量 · 幅度 · 高度（性能曲线）。

## 安全

- 机械进场验收 · 定期检查 · 特种设备管理（塔吊 · 施工电梯）。
