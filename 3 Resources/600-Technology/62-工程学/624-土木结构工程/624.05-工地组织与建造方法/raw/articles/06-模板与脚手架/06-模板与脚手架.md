# 06 模板与脚手架

> 现浇混凝土的「模具」与作业平台 —— 是**临时结构**但要承重（UDC 624.05）。

## 模板（Formwork）

| 类型 | 特点 |
| --- | --- |
| 木模板 | 灵活 · 周转少 |
| 钢模板 | 周转多 · 平整 |
| 铝模板 | 轻 · 精度高 · 装配式住宅 |
| 爬模 / 滑模 | 高耸结构 |
| 免拆（压型钢板） | 组合楼板 |

- 关键：**强度 · 刚度 · 稳定性**（新浇混凝土侧压 / 自重）· 周转次数 · 脱模。

## 脚手架（Scaffolding）

- 类型：扣件式 · 碗扣式 · 盘扣式 · 附着式升降（爬架）。
- 关键：**承载力 · 稳定 · 连墙件 · 防护**。
- 高危作业：搭拆方案 · 验收。
