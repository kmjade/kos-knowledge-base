# 07 混凝土工程施工

> 混凝土「拌 · 运 · 浇 · 振 · 养」—— 过程控制决定最终质量（UDC 624.05）。

## 工艺流程

`配合比 → 搅拌 → 运输 → 浇筑 → 振捣 → 养护 → 拆模`

- 与 [[03-混凝土|691 混凝土]] · GB 50666 配合。

## 关键控制

| 环节 | 要点 |
| --- | --- |
| 运输 | 不离析 · 初凝前 |
| 浇筑 | 分层 · 连续 · 施工缝处理 |
| 振捣 | 密实 · 不漏振 / 过振 |
| **养护** | 保湿保温 · 强度 / 耐久关键 |
| 拆模 | 达到强度 · 避免损伤 |

## 大体积混凝土

- 温升 → 内外温差 → 裂缝。
- 措施：低热水泥 · 掺合料 · 冷却水管 · 测温 · 分层浇筑。
- 如大坝 / 基础底板。

## 冬季 / 雨期施工

- 冬期：防冻 · 蓄热 / 加热养护。
- 雨期：防雨排水 · 坍落度控制。
