# 09 施工安全与质量

> 施工的**底线**：不出事故（安全）· 交付合格工程（质量）（UDC 624.05）。

## 施工安全

| 风险 | 对策 |
| --- | --- |
| 高处坠落 | 防护 · 安全带 · 临边洞口 |
| 坍塌 | 基坑 / 模板支撑 / 脚手架验算 |
| 起重伤害 | 塔吊 / 吊装方案 · 限位 |
| 触电 | 临电三级配电两级保护 |
| 物体打击 | 防护棚 · 交叉作业管理 |

- 制度：安全生产责任制 · 专项方案 · 教育交底 · 应急预案。
- 危大工程（深基坑 · 高支模 · 起重吊装）专项管理。

## 质量管理

- 三检制（自检 · 互检 · 交接检）· 隐蔽验收 · 见证取样。
- **检验批 → 分项 → 分部 → 单位工程** 验收（GB 50300）。
- 缺陷处理 · 质量通病防治。
