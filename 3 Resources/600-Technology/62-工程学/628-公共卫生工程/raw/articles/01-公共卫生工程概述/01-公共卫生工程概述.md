# 01 公共卫生工程概述

> 公共卫生工程 = 用**工程手段**切断疾病传播链、改善人居环境 —— 给排水 · 固废 · 室内环境 · 照明。

## 领域

| 领域 | 目标 |
| --- | --- |
| 给水 | 供应安全饮用水（→ [[02-给水与水质处理]]） |
| 排水 / 污水 | 收集处理污水 · 防污染（→ [[03-排水与污水处理]]） |
| 固废 | 垃圾收运处理（→ [[04-固废与环卫]]） |
| 建筑给排水 | 建筑内水系统（→ [[05-建筑给排水与卫生设施]]） |
| 室内环境 | 空气 · 通风 · 照明（→ [[06-室内空气与通风空调]] · [[07-照明工程]]） |
| 工业污染 | 三废治理（→ [[08-工业污染防治]]） |

## 公共卫生视角

- 历史上，**饮水与排污**是降低传染病（霍乱 · 伤寒）的关键。
- 「**水 · 卫生 · 环境**」三位一体 —— 工程与公共卫生的交叉（→ [[09-环境健康与公共卫生]]）。
