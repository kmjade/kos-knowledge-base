# 06 室内空气与通风空调

> 人 80%–90% 时间在室内 —— 室内空气品质（IAQ）是公共卫生的「最后一道工程」（UDC 628.8）。

## 室内空气品质（IAQ）

- 污染物：CO₂（换气指标）· 甲醛 / VOC（装修）· 颗粒物 PM · 微生物 · 氡。
- 污染源：建材 · 家具 · 人员 · 设备。

## 通风

| 方式 | 说明 |
| --- | --- |
| 自然通风 | 靠热压 / 风压 |
| 机械通风 | 送风 / 排风 · 新风系统 |
| 局部排风 | 厨房 · 卫生间 · 实验室 |

- 指标：换气次数 · 新风量（人 · 面积）。

## 空调与供暖

- 空调：温度 · 湿度 · 洁净 · 气流。
- 供暖：散热器 / 地暖（→ `697`）。
- 与 `696`/`697` 建筑设备交叉。
