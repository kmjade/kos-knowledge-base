# 02 给水与水质处理

> 给水工程把**原水**变成**安全饮用水**并输配到用户（UDC 628.1）。

## 系统组成

`水源 → 取水 → 水处理 → 输配水（管网 · 泵站 · 水塔）→ 用户`

## 水源与取水

- 地表水（河 · 湖 · 库）· 地下水（井）。
- 取水构筑物：取水头部 · 泵站。

## 常规净水工艺

| 工序 | 作用 |
| --- | --- |
| 混凝 | 加药使胶体脱稳 |
| 沉淀 / 澄清 | 去除悬浮物 |
| 过滤 | 截留细小颗粒 |
| **消毒** | 灭活病原（氯 · 臭氧 · 紫外） |

- 深度处理：活性炭 · 膜（超滤 / 反渗透）· 高级氧化。

## 水质标准

- **GB 5749**《生活饮用水卫生标准》—— 微生物 · 毒理 · 感官 · 消毒副产物指标。
- 管网二次污染防控 · 水质监测。
