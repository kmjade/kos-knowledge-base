# 62 SolidWorks 三维 CAD

> SolidWorks 是达索系统（Dassault Systèmes）旗下的三维 CAD / 产品开发套件，聚焦机械设计与建模。核心覆盖零件、装配体、工程图与仿真，广泛用于机械、消费电子、工业设备等领域。
