# 01 水力工程概述

> 水力工程 = 对**水**进行**调控、利用与防护**的工程 —— 防洪 · 供水 · 发电 · 航运 · 港工。

## 领域

| 领域 | 目标 |
| --- | --- |
| 防洪 | 挡、泄、蓄 · 保障安全 |
| 供水 / 灌溉 | 蓄水调蓄 · 输配 |
| 水力发电 | 水能 → 电能（→ [[04-水电站与水力机械]]） |
| 航运 / 港口 | 通航 · 泊靠（→ [[05-通航建筑物]] · [[06-港口与码头工程]]） |
| 海岸 / 围垦 | 防护 · 造地 |

## 水循环

`降水 → 径流 / 下渗 → 汇流（河 / 湖 / 海）→ 蒸发 → 降水`

- 工程着眼**时空不均**：丰枯调节 · 跨流域调水。
