# 05 通航建筑物

> 船要「翻坝过闸」—— 通航建筑物解决**水位落差**与**航道连通**（UDC 626.1 · 626.4 · 626.5）。

## 船闸

- 原理：**闸室 + 上下游闸门** —— 充 / 泄水调节水位，船只逐级升降。
- 组成：闸首 · 闸室 · 输水系统 · 引航道。
- 指标：闸室尺寸 · 门槛水深 · 一次过闸时间。

## 升船机

- **垂直升船机 / 斜面升船机** —— 直接提升船舶（如三峡升船机）。

## 运河与航道

- **运河**：人工水道（连接水系 / 绕行）。
- 航道整治：疏浚 · 渠化（梯级船闸）· 航标。
- 通航标准：航道等级 · 通航净空。
