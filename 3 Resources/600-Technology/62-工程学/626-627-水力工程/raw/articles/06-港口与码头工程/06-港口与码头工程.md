# 06 港口与码头工程

> 港口 = 船舶停泊、装卸与中转的水陆枢纽（UDC 627.2 · 627.3）。

## 组成

| 部分 | 作用 |
| --- | --- |
| **码头** | 停靠 + 装卸（前沿） |
| **防波堤** | 挡浪 · 形成掩护水域 |
| 港池 / 航道 | 水域 |
| 陆域 | 堆场 · 仓库 · 道路 |
| 装卸设备 | 岸桥 · 场桥 · 皮带 / 管道 |

## 码头结构型式

| 型式 | 特点 |
| --- | --- |
| 重力式（沉箱 / 方块） | 靠自重 · 岩基好 |
| 高桩式（桩基 + 承台） | 软基 · 常用 |
| 板桩式 | 挡土 + 靠泊 |

## 水域与荷载

- 泊位 · 水深（按船型）· 回旋水域。
- 荷载：船舶撞击 · 系缆力 · 堆货。
