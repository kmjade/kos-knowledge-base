# 09 灌溉排水与围垦

> 农业水利 = 把水**送到田里**、把多余水**排走**，并**围涂造田**（UDC 626.8）。

## 灌溉系统

`水源 → 渠首 → 干渠 → 支渠 → 斗农渠 → 田间`

- 取水：自流引水 · 扬水（泵站）。
- 方式：地面灌（畦灌 / 沟灌）· 喷灌 · 滴灌（节水）。
- 指标：灌溉保证率 · 灌溉定额 · 渠系水利用系数。

## 排水

- 排除多余地表水 + 控制地下水位（防盐碱 · 防涝）。
- 明沟 · 暗管（农田排水）· 泵站强排。

## 围垦 / 圩垸

- 圩垸（南方）：筑堤围田 + 排涝。
- 围涂（沿海）：促淤 → 围堤 → 垦殖。
- 生态约束：湿地保护 · 退田还湖。
