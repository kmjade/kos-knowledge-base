# 07 海岸与河口工程

> 海岸带是**水动力最活跃**的工程环境 —— 波浪 · 潮汐 · 泥沙（UDC 627.4 · 627.5）。

## 海岸动力

- **波浪**：风浪 · 涌浪 → 冲击与爬高。
- **潮汐**：潮差 → 水位变化（潮汐发电潜力）。
- **泥沙运动**：输沙 → 淤积 / 冲刷 · 岸线演变。

## 海岸防护

| 措施 | 作用 |
| --- | --- |
| 海堤 / 护岸 | 挡潮防浪 |
| 丁坝 / 离岸堤 | 拦沙促淤 · 消浪 |
| 防波堤 | 掩护港湾 |
| 软防护 | 沙滩养护 · 红树林 / 湿地 |

## 河口整治

- 拦门沙 · 航道整治 · 盐水入侵。
- 河口枢纽（挡潮闸 · 船闸）。

## 填海与围涂

- 吹填造地 · 软基处理（沉降控制）—— 与环境评估紧密相关。
