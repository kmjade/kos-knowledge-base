# 03 水坝与水库

> 坝挡水、库蓄水 —— 是防洪 · 发电 · 供水的枢纽（UDC 627.8）。

## 坝型

| 坝型 | 受力 / 材料 |
| --- | --- |
| **重力坝** | 靠自重抗滑稳定（混凝土） |
| **拱坝** | 拱作用传力至两岸（混凝土） |
| **土石坝** | 土石填筑（最常用 · 适应性强） |
| 支墩坝 / 面板堆石坝 | 组合 |

## 枢纽组成

- 挡水坝段 · **泄洪**设施（溢流坝 / 泄洪洞）· 引水 / 发电 / 通航建筑物。

## 泄洪与消能

- 泄流量按设计洪水。
- 消能：挑流 · 底流 · 面流 —— 防冲刷。

## 水库

- **库容**：总库容 · 兴利库容 · 防洪库容。
- **调度**：防洪 / 兴利（发电供水）调度。
- 库区：淹没 · 移民 · 泥沙淤积 · 生态（环境议题）。

## 安全

- 坝工安全 · 渗流控制 · 监测（变形 · 渗压）· 溃坝风险。
