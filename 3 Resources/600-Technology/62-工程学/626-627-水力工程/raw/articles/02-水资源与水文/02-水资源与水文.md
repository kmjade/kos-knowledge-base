# 02 水资源与水文

> 水文是水力工程的「输入」—— 不知道来多少水，就谈不上调蓄与设计（UDC 626）。

## 水资源

- 总量 · 可用量 · 人均占有量。
- 时空分布不均 → 调蓄 · 节水 · 调水。
- 分类：地表水（河湖）· 地下水。

## 水文循环与要素

- 降水 · 蒸发 · 下渗 · 径流。
- 流量（Q）· 水位（Z）· 流速 · 含沙量。

## 水文计算

| 内容 | 用途 |
| --- | --- |
| 设计洪水（频率 P） | 泄洪 · 堤防标准 |
| 设计枯水 | 供水保证率 |
| 径流调节 | 库容 · 发电 |
| 频率分析 | 重现期（如百年一遇） |

## 洪与枯

- 洪水：洪峰 · 洪量 · 洪水过程线。
- 枯水：最小流量 · 保证率。
- 泥沙：淤积 · 冲刷（影响库容与河床）。
