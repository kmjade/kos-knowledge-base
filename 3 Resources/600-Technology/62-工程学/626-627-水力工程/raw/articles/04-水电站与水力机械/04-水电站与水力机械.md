# 04 水电站与水力机械

> 水电站把**水能**（位能 + 动能）转为电能（UDC 627.8）。

## 电站类型

| 类型 | 特点 |
| --- | --- |
| 坝式（坝后 / 河床式） | 抬高水头 |
| 引水式 | 引水道集中落差 |
| **抽水蓄能** | 上 / 下库 · 储能调峰（「充电电池」） |
| 潮汐 / 波浪 | 新能源 |

## 水轮机

| 机型 | 水头 |
| --- | --- |
| 混流式 | 中高水头 |
| 轴流式（含贯流） | 低水头 |
| 冲击式（水斗） | 高水头 |

- 出力 `P = ηρgQH`（水头 H · 流量 Q · 效率 η）。

## 电站组成

- 引水 / 尾水 · 厂房 · 机组（水轮机 + 发电机）· 变配电（→ `621`）。
