# 08 快捷键与效率

## 通用

| 快捷键 | 功能 |
|:--|:--|
| `Shift+F` | 搜索/放置器件 |
| `Esc` | 关闭对话框 / 取消 |

## 原理图

| 快捷键 | 功能 |
|:--|:--|
| `W` | 导线 |
| `B` | 总线 |
| `N` | 网络标签 |
| `T` | 文本 |
| `Tab` | 设置元件属性 |

## PCB

| 快捷键 | 功能 |
|:--|:--|
| `W` | 走线 |
| `V` | 过孔 |
| `*` | 换层 |
| `+` / `-` | 调线宽 |
| `H` | 高亮网络 |
| `Shift+S` | 单层显示 |
| `Shift+B` | 重建铺铜 |
| `F8` | DRC |

## 自定义

- 「设置 → 快捷键」搜索 + 修改
- 支持导入/导出快捷键方案
