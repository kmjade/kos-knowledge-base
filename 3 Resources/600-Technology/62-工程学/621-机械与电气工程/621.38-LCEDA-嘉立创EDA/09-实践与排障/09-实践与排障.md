# 09 实践与排障

## 浏览器相关

| 问题 | 解决 |
|:--|:--|
| 提示 indexedDB 不支持 | 使用最新版 Chrome/Firefox；检查隐私模式是否禁用本地存储 |
| WebGL 报错/卡顿 | 启用浏览器硬件加速；更新显卡驱动；专业版依赖 WebGL |
| 文件丢失 | 工程保存在线/本地，注意「另存为」时机；定期导出备份 |

## 阻焊开窗常见错误

- **只画阻焊层、无铜区域** → 不会露铜。正确做法：先有铜对象（铜皮/走线/实心区域），再在阻焊层画覆盖区域，或用「Expose Copper」
- 露铜用于焊盘扩展、散热、天线净空、大电流加锡

## 板框问题

- 板框未闭合 → PCB 尺寸异常；确认线段/圆弧首尾相接
- 异形/开槽：先画板框再「Convert to Board Cutout」

## 封装与器件

- 子部件位号误用 `U1.A` → 应为 `U1.1`
- 符号有紫色虚线框 → 库有更新，执行「更新工程库」
- 元件不参与 PCB → 检查「转到 PCB」属性

## 下单排障

- SMT 无法配单 → 元件未绑定立创商城 SKU
- Gerber 缺层 → 确认钻孔文件、丝印层输出
