# 02 环境与界面

## 网页版 vs 客户端

| 方式 | 说明 |
|:--|:--|
| 网页版 | 免安装，浏览器即用（标准版 lceda.cn/editor） |
| 离线客户端 | 桌面客户端，支持本地工程 |

## 工作区组成

| 区域 | 功能 |
|:--|:--|
| 顶部菜单 | 放置、设计、工具、设置等 |
| 左侧 Libraries | 器件库（`Shift+F` 搜索） |
| 右侧属性面板 | 元件属性、层属性、Expose Copper 等 |
| 底部面板 | 层切换、封装管理器、设计管理器 |

## 工程管理

- 新建工程：原理图 + PCB + 库
- 保存到本地：在线「工程另存为本地」/ 客户端「文件 → 工程另存为」
- 工程成员/版本管理（专业版）

## 设置

| 设置项 | 说明 |
|:--|:--|
| 原理图符号-通用 | 移动符号时导线是否跟随 |
| 快捷键 | 搜索 + 自定义 |
| 栅格 | 布线/摆放对齐 |
