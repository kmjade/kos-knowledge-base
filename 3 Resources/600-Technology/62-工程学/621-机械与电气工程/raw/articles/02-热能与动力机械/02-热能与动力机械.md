# 02 热能与动力机械

> 动力机械 = 把**热能 / 化学能**转换为**机械功**的机器（UDC 621.1 · 621.4）。

## 类型

| 类型 | 转换 | 代表 |
| --- | --- | --- |
| 蒸汽动力 | 燃料 → 蒸汽 → 汽轮机 | 电站锅炉 + 汽轮机 |
| 燃气轮机 | 燃料 → 高温燃气 → 叶轮 | 燃气发电 · 航空发动机 |
| 内燃机 | 燃料爆燃 → 活塞 | 汽油机 · 柴油机 |
| 联合循环 | 燃气轮机 + 余热锅炉 + 汽轮机 | 效率最高的火电 |

## 锅炉与蒸汽

- **锅炉**：燃料燃烧加热水 → 蒸汽（电站 / 工业）。
- 关键：压力 · 温度 · 效率（超超临界参数提升效率）。
- 蒸汽循环（朗肯循环）：锅炉 → 汽轮机 → 凝汽器 → 给水泵。

## 内燃机

- 四冲程：进气 → 压缩 → 做功 → 排气。
- 汽油机（火花点火）· 柴油机（压燃，热效率更高）。
- 应用：汽车 · 船舶 · 工程机械 · 发电机组。

## 效率与趋势

- 内燃机热效率 ~**30–45%**；联合循环 ~**55–62%**。
- 趋势：高效 · 低排放 · 燃料多元（天然气 / 氢 / 生物燃料）· 与电动化互补。
