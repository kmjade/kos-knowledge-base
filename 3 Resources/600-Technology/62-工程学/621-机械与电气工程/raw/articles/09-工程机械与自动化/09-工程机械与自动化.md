# 09 工程机械与自动化

> 机械的**系统化应用**：物料搬运 · 施工装备 · 生产线自动化 · 机器人。

## 物料搬运与工程机械

| 类型 | 示例 |
| --- | --- |
| 起重 | 塔吊 · 汽车吊 · 桥式起重机 |
| 输送 | 带式 / 链式 / 螺旋输送机 |
| 土方 | 挖掘机 · 装载机 · 推土机 |
| 路面 | 摊铺机 · 压路机 |
| 混凝土 | 搅拌站 · 泵车 · 布料机 |

> 工程机械是「机械 + 液压 + 电控」的集成体（见 [[03-流体机械与液压气动]]）。

## 自动化与机器人

- **组成**：传感 → 控制器（PLC）→ 执行器（电机 / 液压）。
- **工业机器人**：关节型 · SCARA · 直角坐标 · 协作机器人。
- **应用**：焊接 · 装配 · 搬运 · 喷涂 · 建筑（抹灰机器人等）。
- 与 [[007.52-Robotics-机器人|007.52 机器人]] 交叉。
