# 03 流体机械与液压气动

> 以**流体**为工作介质的机械：泵 · 风机 · 压缩机 · 水轮机 · 液压 / 气动系统（UDC 621.22 · 621.5 · 621.6）。

## 流体机械分类

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| 泵 | 输送液体 · 增压 | 离心泵 · 容积泵 |
| 风机 / 压缩机 | 输送 / 压缩气体 | 离心风机 · 螺杆空压机 |
| 水轮机 | 水能 → 机械能 | 混流式 · 轴流式 |
| 涡轮 | 流体动能 → 功 | 汽轮机 · 燃气涡轮 |

## 液压传动

- 原理：**帕斯卡定律** —— 液体传压，实现大力矩 / 精密控制。
- 组成：泵 → 阀（方向 / 压力 / 流量）→ 执行器（缸 / 马达）→ 油箱 / 冷却。
- 优点：功率密度高 · 无级调速 · 过载保护；缺点：泄漏 · 效率。

## 气动传动

- 以压缩空气为介质：洁净 · 快速 · 简单；出力较小、可压缩。
- 应用：自动化产线 · 夹持 · 包装。

## 制冷与热泵

- 蒸汽压缩循环：压缩 → 冷凝 → 节流 → 蒸发。
- 制冷剂（环保替代：R32 / R290 / CO₂）· 能效比 COP。
- 应用：空调（→ 697）· 冷链 · 热泵供暖。
