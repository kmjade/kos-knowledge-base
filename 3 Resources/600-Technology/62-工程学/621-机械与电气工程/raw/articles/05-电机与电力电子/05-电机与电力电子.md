# 05 电机与电力电子

> 电机实现**电能 ↔ 机械能**的转换；电力电子实现**电能的变换与控制** —— 两者构成现代驱动与自动化的基础。

## 电机分类

| 类型 | 转换 | 应用 |
| --- | --- | --- |
| 发电机 | 机械 → 电 | 电站 · 汽车 |
| 变压器 | 电压变换 | 输配电 |
| 交流电机 | 电 → 机械 | 异步（感应）/ 同步电机 |
| 直流电机 | 电 → 机械 | 调速 · 伺服 |
| 永磁电机 | 电 → 机械 | 高效 · 电动车辆 · 机器人 |

## 关键概念

- **转矩 · 转速 · 功率**：`P = T·ω`。
- **异步电机**：转子转速略低于同步转速（滑差）。
- **变频调速（VFD）**：改变频率 → 调速节能（风机 / 泵）。

## 电力电子

| 器件 | 功能 |
| --- | --- |
| 二极管 / 晶闸管 | 整流 |
| MOSFET / IGBT / SiC / GaN | 开关（高频 · 高效） |
| 变流器 | AC-DC · DC-DC · DC-AC（逆变）· AC-AC |

- 应用：变频器 · 光伏逆变器 · 电动车驱动 · 电源 · 牵引。
