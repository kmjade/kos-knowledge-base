# 08 核技术

> 核技术利用**原子核**释放的巨大能量（UDC 621 含核技术）—— 发电 · 动力 · 医用 · 科研。

## 基本原理

- **裂变**：重核（U-235）吸收中子分裂，释放能量 + 中子 → 链式反应。
- **聚变**：轻核（氘氚）结合，能量更大；尚在攻关。
- 能量密度极高：1 kg 铀 ≈ 数百万倍同质量化石燃料。

## 反应堆

| 类型 | 慢化 / 冷却 |
| --- | --- |
| 压水堆 PWR | 轻水慢化 + 冷却（主流） |
| 沸水堆 BWR | 直接沸腾 |
| 重水堆 | 重水慢化 |
| 高温气冷堆 | 氦冷 · 高温 |
| 快堆 | 无慢化 · 增殖 |

- **小型模块化反应堆 SMR**：灵活 · 工厂制造。
- 燃料循环：铀浓缩 → 燃料 → 乏燃料处理 / 后处理。

## 核安全

- 三道屏障 · 纵深防御 · 停堆 / 冷却 / 包容。
- 事故（三哩岛 · 切尔诺贝利 · 福岛）的教训 → 安全标准提升。
- 放射性废物：分类 · 地质处置。

## 非发电应用

- 医用同位素 · 辐照 · 中子成像 · 同位素电源（航天）。
