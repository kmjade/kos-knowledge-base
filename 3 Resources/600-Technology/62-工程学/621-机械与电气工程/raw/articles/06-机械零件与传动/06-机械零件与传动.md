# 06 机械零件与传动

> 机械零件 = 构成机器的最小单元；传动 = 在动力与执行之间传递运动与力（UDC 621.8）。

## 常见零件

| 零件 | 功能 |
| --- | --- |
| 轴 | 支撑旋转件 · 传递扭矩 |
| 轴承 | 支承 · 减摩（滚动 / 滑动） |
| 齿轮 | 传动比 · 传递扭矩 |
| 联轴器 / 离合器 | 连接 / 分离 |
| 弹簧 | 储能 · 缓冲 · 复位 |
| 紧固件 | 螺栓 · 键 · 销 |

## 传动方式

| 方式 | 特点 |
| --- | --- |
| 齿轮传动 | 精度高 · 传动比准 |
| 带传动 | 平稳 · 过载打滑 |
| 链传动 | 适合远距离 · 高温 |
| 蜗杆 / 行星 | 大减速比 / 高功率密度 |
| 丝杠 | 旋转 → 直线（滚珠丝杠） |

## 设计与强度

- 强度（弯曲 / 接触疲劳）· 刚度 · 寿命。
- 失效形式：疲劳断裂 · 点蚀 · 磨损 · 胶合。

## 润滑与密封

- 润滑降低摩擦磨损；润滑方式：油 / 脂 / 油气 / 喷油。
- 密封防泄漏与污染（O 圈 · 油封 · 机械密封）。
