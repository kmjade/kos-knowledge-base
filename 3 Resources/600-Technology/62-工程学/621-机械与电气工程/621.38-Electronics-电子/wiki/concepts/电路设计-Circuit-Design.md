# 电路设计 Circuit Design

## 定义

电路设计是把电子元件组织成功能电路的过程：从原理图（schematic）到仿真验证，再到 PCB 布局与制造。分为模拟电路设计（放大、滤波、电源）与数字电路设计（逻辑、时序、MCU 外设）。

## 流程

| 阶段 | 说明 |
|------|------|
| 原理图 | 元件选型与连接 |
| 仿真 | SPICE 验证 |
| PCB 布局 | 布线、EMC、热设计 |
| 打样/制造 | 制板、贴片 |
| 调试 | 测量与修正 |
