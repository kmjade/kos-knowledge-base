# 07 矿山机械与智能化

> 矿山装备支撑「采 · 装 · 运 · 提 · 选」全流程；智能化正把矿工从危险面撤出（UDC 622 装备面）。

## 主要装备

| 环节 | 装备 |
| --- | --- |
| 穿孔 | 潜孔钻机 · 牙轮钻机 |
| 铲装 | 电铲 · 铲运机（LHD）· 装载机 |
| 运输 | 矿用卡车 · 带式输送机 · 电机车 |
| 提升 | 提升机 · 箕斗 / 罐笼 |
| 采煤 | 采煤机 · 液压支架（综采） |

## 液压与传动

- 工程机械高度依赖**液压系统**（见 [[03-流体机械与液压气动|621 流体机械与液压气动]]）。

## 智能化 / 智慧矿山

- **无人化**：无人驾驶矿卡 · 遥控 / 自动化采掘。
- **感知**：传感器 · 视频 · 人员定位。
- **管控**：矿山物联网 · 数字孪生 · 智能调度。
- 与 `004`（计算机）· `621.38`（电子）融合。
