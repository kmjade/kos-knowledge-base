# 05 矿井排水与运输提升

> 井下必须**排干涌水、运出矿石与人员** —— 排水、运输、提升是矿井的「循环系统」（UDC 622.5 · 622.6）。

## 矿井排水

- 水源：地下水涌水 · 生产用水 · 突水。
- 系统：水仓 → 水泵 → 排水管 → 地面（分级排水）。
- 关键：**防水治水**（探放水 · 注浆 · 防水闸门）· 突水预警。

## 井下运输

| 方式 | 适用 |
| --- | --- |
| 轨道运输 | 矿车 + 机车 |
| 带式输送 | 连续 · 大运量（煤炭） |
| 无轨运输 | 铲运机 · 矿用卡车 |
| 溜井 / 溜槽 | 自重下放 |

## 提升

- **竖井提升**：提升机 + 箕斗 / 罐笼（提升矿石 / 人员）。
- 关键：钢丝绳（安全系数）· 防坠 · 过卷保护。
- 与 `621` 机械交叉（提升机 · 钢丝绳）。
