# 03 采矿方法与开采工艺

> 采矿方法 = 在特定矿体条件下**安全高效采出矿石**的工艺组合（UDC 622.2 · 622.3）。

## 露天开采

- 步骤：**穿孔 → 爆破 → 铲装 → 运输**。
- 台阶式开采 · 边坡稳定 · 剥离比（剥采比）。
- 适用：浅埋 · 厚大矿体。

## 地下开采

- 开拓：竖井 / 斜井 / 平硐 + 巷道。
- 采准 / 切割 → 回采。
- 主要采矿方法：

| 方法 | 原理 |
| --- | --- |
| 空场法 | 采后留空场（矿柱支撑） |
| 崩落法 | 采后矿岩自然 / 强制崩落 |
| 充填法 | 采后充填（保护地表 · 减少沉降） |

## 爆破

- 钻孔 → 装药 → 起爆 → 破碎。
- 控制爆破（预裂 · 光面）减少损伤。
- 安全：盲炮处理 · 警戒。

## 特种开采

- 溶浸采矿（原地浸出）· 砂矿开采 · 海洋采矿。
