# 09 绿色矿山与环境修复

> 采矿的环境代价必须被**治理与修复** —— 绿色矿山是行业转型方向。

## 主要环境问题

- **地表沉陷 / 破坏**：地下开采引起。
- **尾矿与废石**：占地 · 溃坝风险 · 重金属。
- **水污染**：酸性矿井水（AMD）· 选矿废水。
- **粉尘 / 扬尘** · 生态破坏。

## 治理与修复

| 措施 | 说明 |
| --- | --- |
| 充填采矿 | 采空区充填 → 减少沉陷 · 消纳尾矿 |
| 尾矿库治理 | 防渗 · 排洪 · 在线监测 |
| 废水处理 | 中和 · 沉淀 · 回用 |
| 土地复垦 | 边坡复绿 · 土壤重建 |
| 生态修复 | 植被恢复 · 生物多样性 |

## 绿色矿山

- 资源利用高效 · 开采方式科学 · 生态环境友好 · 企业管理规范。
- 「**边开采、边治理**」· 矿山全生命周期管理。
