# 02 矿床勘探与地质

> 勘探 = 查明**矿体的位置、规模、品位与产状**，为开采设计提供地质依据（UDC 622.1）。

## 矿床类型

- 内生矿床（岩浆 / 热液）· 外生矿床（沉积 / 风化）· 变质矿床。
- 矿体形态：层状 · 脉状 · 透镜状 · 浸染状。

## 勘探方法

| 方法 | 作用 |
| --- | --- |
| 地质填图 | 地表地质与构造 |
| 物探 | 重力 / 磁法 / 电法 / 地震 |
| 化探 | 元素异常圈定 |
| 钻探 / 坑探 | 取样 · 验证 |
| 遥感 | 大范围普查 |

## 储量与品位

- **品位**：有用组分含量。
- **储量分级**：探明 / 控制 / 推断（可靠性递减）。
- 边界品位 · 工业指标 —— 决定可采性。

## 矿图与建模

- 地质图 · 剖面图 · 储量计算。
- 三维地质建模 → 采矿设计基础。
