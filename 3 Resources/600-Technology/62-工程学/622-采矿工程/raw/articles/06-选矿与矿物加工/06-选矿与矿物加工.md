# 06 选矿与矿物加工

> 选矿 = 把**采出矿石**中的有用矿物与脉石分离、富集，得到合格精矿（UDC 622.7）。

## 流程

`破碎 → 磨矿 → 分选 → 精矿 / 尾矿`

- **破碎 / 磨矿**：使矿物**单体解离**（粒度减小）。
- **分选**：按物理 / 化学性质差异分离。
- **脱水**：浓缩 · 过滤 · 干燥。

## 分选方法

| 方法 | 原理 | 适用 |
| --- | --- | --- |
| 重选 | 密度差 | 钨 · 锡 · 金 |
| 磁选 | 磁性差 | 铁 · 锰 |
| 浮选 | 表面润湿性差（药剂） | 铜 · 铅锌 · 硫化矿 |
| 电选 | 电性差 | 稀有金属 |
| 化学选 | 浸出 · 沉淀 | 金 · 铀 · 稀土 |

## 指标

- **品位** · **回收率** · **富集比** · 选矿比。
- 尾矿 → 尾矿库（环境议题，见 [[09-绿色矿山与环境修复]]）。
