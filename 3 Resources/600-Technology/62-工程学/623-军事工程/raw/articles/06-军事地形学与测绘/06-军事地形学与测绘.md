# 06 军事地形学与测绘

> 地形影响**机动、观察、射界与部署** —— 军事地形学是「读懂战场」的工程 / 地理工具（UDC 623.6）。

## 地形要素

- 地貌 · 水系 · 植被 · 道路 · 居民地 · 地质（通行性）。
- 分析：制高 · 通视 · 隐蔽 · 机动走廊。

## 地图与测绘

| 手段 | 说明 |
| --- | --- |
| 地形图 | 等高线 · 比例尺 · 图式 |
| 沙盘 / 模型 | 立体地形 |
| 航空 / 卫星影像 | 侦察 · 更新 |
| 数字地图 / GIS | 空间分析 · 态势 |

- **军事地理**：地缘 · 气候 · 资源对作战的影响。

## 定位与导航

- 传统：地图 + 罗盘 + 方位判定。
- 现代：**卫星导航（GPS / 北斗 / GLONASS / Galileo）** · 惯性导航。
