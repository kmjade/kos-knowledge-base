# 05 军用桥梁与渡河

> 渡河是军事工程的经典难题 —— 目标是**快速、可重复、能承重**地跨越水域（UDC 623.6）。

## 桥型

| 类型 | 特点 |
| --- | --- |
| **舟桥（浮桥）** | 舟 / 浮箱支撑 · 快速架设 · 可分解 |
| **机械化桥** | 车载液压展开 · 短跨快速 |
| **拼装桥** | 预制桁架 · 中长跨 |
| **固定桥** | 永备 · 承载力高（也属土木工程） |

## 舟桥系统

- 组成：**桥脚舟（浮箱）+ 桥面 + 岸边过渡**。
- 关键：**漕渡**（浮桥通载）· 抗流 · 载重等级 · 架设时间。

## 其他渡河手段

- **两栖 / 渡驳** · 潜渡 · 门桥（分段摆渡）· 索道。
- 渡河保障：侦察 · 烟幕 · 防空 · 工程勤务。
