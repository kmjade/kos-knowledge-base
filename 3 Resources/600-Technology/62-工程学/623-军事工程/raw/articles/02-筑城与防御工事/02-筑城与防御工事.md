# 02 筑城与防御工事

> 筑城 = 用土木与结构手段构筑**防御体系**（UDC 623.1 · 623.2）—— 从古代城池到现代掩体。

## 历史形态

| 时期 | 形态 |
| --- | --- |
| 古代 | 城墙 · 壕沟 · 塔楼 · 城堡 |
| 火药时代 | 棱堡（低矮厚重 · 交叉火力）· 要塞 |
| 近代 | 永备工事 · 混凝土炮台 · 防线 |
| 现代 | 地下工事 · 掩蔽部 · 机动防护 |

## 工事分类

- **永备工事**：混凝土 / 钢结构 · 长期 · 固定。
- **野战工事**：土工 / 沙袋 / 预制件 · 临时 · 快速。
- **掩体 / 掩蔽部**：抗冲击 · 防破片 · 三防（核生化）。

## 设计要点

- **地形利用**：制高 · 死角 · 射界。
- **结构防护**：覆土厚度 · 材料抗侵彻。
- **伪装与疏散**：降低被发现概率。
