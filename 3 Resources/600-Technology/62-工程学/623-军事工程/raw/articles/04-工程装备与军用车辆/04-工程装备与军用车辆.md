# 04 工程装备与军用车辆

> 工程装备把工程作业**机动化、机械化**（UDC 623.6）—— 是工兵的「工具臂」。

## 主要类别

| 类别 | 功能 |
| --- | --- |
| 推土 / 挖掘 | 土工作业 · 开辟通路 |
| 舟桥 / 架桥 | 渡河 · 跨越（见 [[05-军用桥梁与渡河]]） |
| 扫雷 / 破障 | 扫雷犁 · 爆破索 · 破障车 |
| 起重 / 牵引 | 抢修 · 救援 |
| 特种 | 钻探 · 发电 · 净水 · 喷涂（快速硬化） |

## 平台基础

- 多采用**履带 / 轮式军用底盘**（装甲化 · 三防）。
- 依赖**液压系统**（见 [[03-流体机械与液压气动|621 流体机械与液压气动]]）。

## 趋势

- 无人化（遥控 / 自主工程车辆）· 模块化 · 快速部署。
