# 巴雷特 M82A1

> **实体** — Barrett M82A1，美国巴雷特枪械公司（Barrett Firearms）研制的 **.50 BMG（12.7×99mm NATO）半自动反器材狙击步枪**（"特殊用途狙击步枪" SASR），是使用最广泛的 12.7mm 大口径步枪之一。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 类型 | 半自动反器材狙击步枪（SASR） |
| 原产地 | 美国 · Barrett Firearms Company |
| 设计者 | 朗尼·巴雷特（Ronnie Barrett） |
| 研发 | 1980s（1982 首支样枪 M82；1986 改进定型 M82A1） |
| 弹药 | **.50 BMG（12.7×99mm NATO）**；另有 .416 Barrett 型 |
| 口径 | 12.7 mm |
| 自动方式 | **短行程后座 + 转栓式** · 半自动 |
| 全长 | 1,448 mm（57″，29″ 管）/ 1,219 mm（48″，20″ 管理论配置） |
| 枪管长 | 737 mm（29″）/ 508 mm（20″） |
| 枪管缠距 | 1:15″（381 mm） |
| 空枪重 | ≈12.9–14.8 kg |
| 弹匣容量 | 10 发 |
| 枪口初速 | ≈853 m/s（660 gr 弹头） |
| 有效射程 | ≈1,850 m |
| 最大射程 | ≈6,800 m |

## 命名与衍生

- 昵称 **Light Fifty（轻 50）** —— 与其共用 .50 BMG 的勃朗宁 M2 重机枪相比口径相同、更"轻"。
- 衍生型：`M82` · `M82A1` · `M82A1A` · `M82A1M` · `M82A2`（无托肩射）· `M82A3` · `XM107 / M107` · `M107A1`。
- 美军采用改良版（加全长皮卡汀尼导轨等）命名为 **M107**。

## 工程特点

| 维度 | 说明 |
| ---- | ---- |
| 后坐控制 | **短后坐** + 高效**枪口制退器**（V 形制退器约减 69% 后坐力）· 枪托缓冲垫 |
| 用途定位 | **反器材**：对轻装甲 · 器材 · 雷达站 · 未爆弹药排除（EOD）等；亦可远距精确射击 |
| 精度 | 一般约 **≤2 MOA**（逊于同口径栓动式狙击步枪） |
| 人机 | 可调两脚架（与 M60 通用）· 可加装载具架座（后坐缓冲） |
| 战技 | 大口径重量大 → 多以两脚架 / 载具依托射击 |

## 使用

- 1989 年**瑞典陆军**率先采购；此后装备多国军队 / 警察部队。
- 参与多场冲突（海湾战争起），成为 12.7mm 反器材步枪的代表型号之一。
