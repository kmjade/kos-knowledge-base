# 02 能源资源与结构

> 能源结构 = 一国 / 全球能源消费中各类能源的占比 —— 由**资源禀赋**、成本、技术与政策共同塑造。

## 化石能源

- **煤**：储量丰富、分布广、碳强度最高（≈ 电力的 0.8–1.0 kgCO₂/kWh）。
- **石油**：交通主导，全球贸易品，价格受地缘影响大。
- **天然气**：较清洁化石能源，发电 / 供热 / 化工；LNG 贸易增长。

## 核能

- 铀裂变发电 —— 低碳、高能量密度、稳定基荷；争议在安全与废料。
- 新兴：小型模块化反应堆（SMR）；聚变仍在攻关。

## 可再生能源

| 类型 | 特点 |
| --- | --- |
| 水电 | 成熟 · 灵活 · 受资源 / 生态约束 |
| 风电 | 陆上 / 海上；间歇性 |
| 光伏 | 成本快速下降；间歇性 · 占地 |
| 生物质 | 可调 · 碳中性（条件性） |
| 地热 / 海洋 | 局地资源 |

## 中国禀赋

> 「**富煤 · 贫油 · 少气**」—— 煤为基础，油气进口依赖高，风光资源西部丰富。

- 煤电仍为主体电源，但占比下降。
- 油气对外依存度高（安全议题，见 [[08-能源安全与地缘]]）。
- 风光装机高速增长（转型议题，见 [[07-能源转型与可再生]]）。
