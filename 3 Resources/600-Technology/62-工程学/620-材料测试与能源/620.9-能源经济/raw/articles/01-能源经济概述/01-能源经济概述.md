# 01 能源经济概述

> 能源经济 = 用经济学方法研究**能源系统**：资源如何变成可用能、如何定价、如何配置、如何影响经济与环境。

## 能源链

`资源 → 转换（发电 / 炼化）→ 输配（电网 / 管网 / 运输）→ 终端消费（工业 / 建筑 / 交通）`

- 每一环都有**投入产出 · 效率 · 成本 · 排放**。
- 能源经济关心**全链条的成本与外部性**，而非单一环节技术。

## 能源分类

| 维度 | 类别 |
| --- | --- |
| 来源 | 化石（煤 · 油 · 气）· 核 · 可再生（水 · 风 · 光 · 生物质 · 地热） |
| 加工 | **一次能源**（自然存在）· **二次能源**（电 · 汽柴油 · 氢 · 热） |
| 属性 | 商品能源 / 非商品能源 · 清洁 / 高碳 |

## 常用单位

| 单位 | 含义 |
| --- | --- |
| **tce** | 吨标准煤（中国常用） |
| **toe** | 吨油当量（国际常用） |
| **kWh / MWh** | 电量 |
| **EJ / 亿千瓦时** | 宏观总量 |

## 核心指标

- **能源强度**：单位 GDP 能耗 —— 衡量效率与结构。
- **能源弹性**：能源消费增速 / 经济增速（<1 表示脱钩）。
- **LCOE**：平准化度电成本 —— 跨技术比较标尺。
- **碳强度**：单位能源 / 电力的 CO₂ 排放。

## 学科交叉

经济学（微观 / 宏观 / 计量）· 工程（能源系统）· 环境（排放）· 政策（监管）。是典型的**交叉应用学科**。
