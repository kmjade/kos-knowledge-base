# 04 能源价格与市场

> 能源价格是资源配置的**信号**：既反映边际成本与稀缺，也受管制、税收与外部性（碳）影响。

## 定价机制

| 机制 | 说明 |
| --- | --- |
| 成本加成 | 管制价格（传统电价） |
| 边际成本 | 竞争市场出清 |
| 市场竞价 | 供需撮合（现货） |
| 外部性内部化 | 碳税 / 碳交易（见下） |

## 各能源市场

- **煤**：区域市场 · 长协 + 现货。
- **石油**：全球市场 · 期货基准（Brent / WTI）· OPEC+ 影响。
- **天然气**：管道气 / LNG · 区域价差（如 TTF / Henry Hub）。
- **电力**：特殊 —— 难储存 · 实时平衡 · 需容量与辅助服务。

## 电力市场

- **中长期交易**：锁定电量 / 价格。
- **现货市场**：日前 / 实时 · 分时价格。
- **辅助服务 / 容量市场**：保障频率、备用与可靠性。
- **绿电 / 绿证**：可再生环境价值交易。

## 碳市场

- **总量控制与交易（ETS）**：配额 → 市场定价。
- **中国**：全国碳排放权交易市场（发电行业起步）+ CCER 自愿减排。
- 与电价联动：碳成本向终端传导 → 推动转型。
