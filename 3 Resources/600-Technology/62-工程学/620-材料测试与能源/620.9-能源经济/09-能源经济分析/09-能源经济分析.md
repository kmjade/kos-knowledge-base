# 09 能源经济分析

> 能源经济分析 = 用**成本 · 模型 · 情景**量化不同技术 / 政策路径的经济性，支撑决策。

## 常用工具与方法

| 工具 | 用途 |
| --- | --- |
| **LCOE** 平准化度电成本 | 跨电源 / 技术比较（含储能 **LCOS**） |
| 成本效益分析（CBA） | 项目 / 政策净收益 |
| NPV / IRR / 回收期 | 投资评估 |
| 投入产出分析 | 能源与经济的部门关联 |
| 学习曲线 | 技术成本随累计产量下降 |

## 模型

| 模型 | 类型 | 特点 |
| --- | --- | --- |
| MARKAL / TIMES | 能源系统优化 | 自下而上 · 技术细节 |
| CGE | 可计算一般均衡 | 自上而下 · 经济反馈 |
| 情景 / 综合评估（IAM） | 耦合气候-经济 | 政策评估 |

## 情景分析

- 对比 **基准情景 vs 政策 / 转型情景**（如 IEA 的 STEPS / NZE）。
- 输出：能源结构 · 排放路径 · 成本 · 投资需求。

## 局限

- 参数不确定 · 技术学习率假设敏感。
- 外部性、系统成本（调节 / 电网）易被低估。
