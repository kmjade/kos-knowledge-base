# 620.9 能源经济

> **UDC 620.9** — 能源经济总论（Energy economics, general）。隶属 [[62-工程学|62 工程学]] › `620` 材料测试 / 工业材料 / 发电站 / 能源经济。
> 能源经济 = 研究**能源的生产、转换、输配、消费**及其与**经济、环境、政策**相互关系的学科。

## 范围

- **能源链**：资源 → 转换（发电 / 炼化）→ 输配 → 终端消费。
- **对象**：一次 / 二次能源 · 化石 / 可再生 · 能源市场与价格 · 能源政策。
- **核心指标**：能源强度 · 弹性系数 · **LCOE**（平准化度电成本）· 碳强度。

## 关键概念

| 概念 | 说明 |
| --- | --- |
| 一次 / 二次能源 | 自然存在（煤油气 · 风光水）vs 加工转换（电 · 汽柴油 · 氢） |
| 能源强度 | 单位 GDP 能耗 —— 效率与结构指标 |
| 能源弹性 | 能源消费增速 / 经济增速 |
| LCOE | 全生命周期平准化成本，跨技术比较标尺 |
| 碳强度 | 单位能源 / 电力的 CO₂ 排放 |

## 主要议题

- **供需与结构**：资源禀赋 · 需求预测 · 峰值。
- **市场与价格**：煤 / 油 / 气 / 电价 · 电力市场 · 碳市场。
- **政策与监管**：补贴 · 税收 · 双碳目标 · 电力体制改革。
- **转型与环境**：可再生替代 · 电气化 · 能效 · 碳减排。

## 边界

- **技术侧**（发电 · 电网 · 设备）归 `621` / `697`；本库聚焦**经济、市场与政策**。
- **环境科学**侧归 `628` / `502-504`；本库聚焦**能源-经济-碳的耦合**。
