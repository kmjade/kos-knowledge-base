# 07 能源转型与可再生

> 能源转型 = 从**化石主导**走向**清洁低碳**的系统性重构 —— 三个抓手：清洁替代、电能替代、能效提升。

## 三个方向

| 方向 | 含义 |
| --- | --- |
| **清洁替代** | 可再生 / 核替代化石（供给侧） |
| **电能替代** | 以电代煤 / 油 / 气（终端侧 · 电气化） |
| **能效提升** | 单位产出耗能下降（「第一能源」） |

## 关键支撑

- **风光储一体化**：光伏 + 风电 + 储能（电化学 / 抽蓄）平抑间歇性。
- **新型电力系统**：高比例可再生 + 灵活调节 + 数字化调度。
- **氢能**：绿氢（电解水）用于难脱碳行业（钢铁 · 化工 · 重卡 · 储能）。
- **CCUS**：碳捕集利用与封存 —— 化石 / 工业的兜底手段。

## 转型的成本与公平

- **成本**：初期资本密集、系统成本（调节 / 储能 / 电网）。
- **系统价值**：可再生边际成本近零 → 价格机制与容量充裕度挑战。
- **公正转型**：煤电退出与从业人员、区域经济的安置。
