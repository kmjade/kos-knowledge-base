# 05 纳米复合材料

> 纳米复合材料 = **纳米填料**（<100 nm）分散于**基体**（聚合物 / 金属 / 陶瓷 / 水泥）中，以少量添加显著提升性能。

## 增强机制

- **界面面积巨大**：纳米填料比表面积极大 → 强界面结合 · 应力传递高效。
- **分散是关键**：团聚 → 应力集中 / 性能不升反降（须表面改性 / 超声 / 原位聚合）。
- **典型增益**：强度 · 模量 · 韧性 · 阻隔 · 导热 / 导电 · 阻燃。

## 典型体系

| 基体 | 纳米填料 | 效果 |
| --- | --- | --- |
| 聚合物 | 纳米黏土（蒙脱土） | 阻隔 · 阻燃 · 增强 |
| 聚合物 | CNT / 石墨烯 | 导电 · 导热 · 增强 |
| 陶瓷 / 金属 | 纳米颗粒 | 韧性 · 耐磨 |
| **水泥 / 混凝土** | 纳米 SiO₂ / TiO₂ / CNT | 密实 · 早强 · 光催化 · 耐久 |
| 涂层 | 纳米 SiO₂ / Al₂O₃ | 耐磨 · 硬度 |

## 建材关联

- **纳米 SiO₂** 改性混凝土：填充微孔 → 提升强度与抗渗。
- **纳米 TiO₂**：自洁 / 净化空气路面与立面。
- **石墨烯 / CNT** 增强水泥基材料：导电（自监测）· 增韧（研究阶段）。
