# 03 纳米表征

> 纳米表征 = 「看见」并量化 **1–100 nm** 的结构、成分与性质 —— 纳米技术的「眼睛」。

## 显微（形貌 / 结构）

| 手段 | 分辨率 | 给出 |
| --- | --- | --- |
| **光学显微镜** | ~200 nm（衍射极限） | 宏观定位（不足分辨纳米） |
| **SEM** 扫描电镜 | ~1 nm | 表面形貌 · 成分（EDS） |
| **TEM / HRTEM** 透射电镜 | <0.1 nm（原子级） | 内部结构 · 晶格 · 衍射 |
| **STM** 扫描隧道显微镜 | 原子级 | 表面电子态 · 可操纵原子 |
| **AFM** 原子力显微镜 | ~1 nm | 三维形貌 · 力学 / 电学（不需导电） |

## 衍射 / 散射

- **XRD**：晶体物相 · 晶粒尺寸（谢乐公式）。
- **SAXS / SANS**：纳米尺度粒径分布。
- **电子衍射**：选区结构（TEM 内）。

## 谱学（成分 / 化学态）

| 手段 | 信息 |
| --- | --- |
| **拉曼 Raman** | 分子振动 · 石墨烯层数 / 缺陷 |
| **XPS** | 表面元素 · 化学态 |
| **EDS / EELS** | 元素成分（配 SEM / TEM） |
| **UV-Vis** | 吸收 · 量子点带隙 · 等离子体共振 |
