# 06 纳米能源

> 纳米技术改写能源器件：**更大的界面 · 更短的扩散路径 · 更高的活性位密度**。

## 电池与储能

- **纳米电极**：缩短锂离子扩散路径 · 缓解体积膨胀（如硅负极纳米化）。
- **硅纳米线 / 纳米硅碳**：高容量负极方向。
- **固态电池**：纳米 / 界面工程改善离子导通。
- **超级电容**：多孔碳（石墨烯 · CNT · 纳米多孔碳）→ 高比表面 · 高功率。

## 催化

- **析氢 / 析氧（HER/OER）**：纳米 / 单原子催化剂降低贵金属用量。
- **燃料电池**：纳米 Pt / 合金催化剂。
- **光催化**：纳米 TiO₂ 分解水 / 降解污染物。

## 光伏

- **量子点太阳能电池**：带隙可调 · 多激子效应。
- **钙钛矿电池**：纳米 / 界面工程推动效率跃升。
- 纳米减反射 / 透明电极（银纳米线 · 石墨烯）。
