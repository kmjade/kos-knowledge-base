# 09 安全与标准

> 纳米材料的「小」带来新风险，也呼唤新标准 —— 安全与标准化是纳米产业化的前提。

## 纳米安全（EHS）

- **暴露途径**：吸入（> 皮肤 / 食入）—— 纳米颗粒可深入肺泡。
- **风险来源**：高比表面 / 活性 · 难降解（如 CNT 类似石棉形态的担忧）· 生物蓄积。
- **防护**：工程控制（通风 · 密闭）· 个人防护 · 全生命周期评价（LCA）。

## 标准体系

| 组织 | 范围 |
| --- | --- |
| **ISO/TC 229** | 纳米技术国际标准（术语 · 表征 · EHS） |
| **IEC/TC 113** | 电工产品纳米技术 |
| **SAC/TC 279**（全国纳米技术标准化技术委员会） | 中国纳米技术标准 |
| 各国纳米计划（NNI 等） | 研发 + 监管框架 |

> 常用方向：术语（ISO 80004 / GB/T 30544 系列）· 表征方法 · 材料规范 · 职业暴露限值。**具体标准号以最新目录为准**（待核）。

## 监管趋势

- 欧盟 REACH 对「纳米形态」单独登记 / 评估。
- 食品 / 化妆品 / 医疗器械的纳米成分标识与安全评估。
- 中国：纳米材料标准 + 新化学物质环境管理。
