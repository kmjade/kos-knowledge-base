# 01 纳米技术概述

> 纳米技术 = 在 **1–100 nm** 尺度上**观测、操纵与制造**物质，以获得宏观块体不具备的**尺度 / 表面 / 量子效应**。

## 什么是纳米技术

- **尺度**：1–100 nm —— 介于单个分子（~0.1 nm）与宏观器件（>1 µm）之间。
- **内核**：不是「更小」，而是**小到性能发生突变** —— 比表面积骤增、能带分裂、表面原子占比高。
- **三个层次**：纳米材料 → 纳米结构 → 纳米器件 / 系统。

## 尺度效应（为什么特殊）

| 效应 | 机理 | 表现 |
| --- | --- | --- |
| 表面 / 界面效应 | 比表面积 ∝ 1/d，表面原子占比激增 | 活性高 · 熔点降 · 催化 / 吸附强 |
| 量子限域 | 尺寸 ≲ 激子玻尔半径 → 能级分立 | 量子点发光波长随尺寸可调 |
| 表面等离子体 | 金属纳米颗粒自由电子共振 | 金 / 银胶体呈红 / 黄，用于传感 |
| 隧穿 / 单电子 | 尺度接近电子相干长度 | 单电子晶体管 · 隧穿器件 |

## 两条技术路线

| 路线 | 思路 | 代表 |
| --- | --- | --- |
| Top-down 自上而下 | 由大到小「雕刻」 | 光刻 · 电子束 · 纳米压印 |
| Bottom-up 自下而上 | 由小到大「自组装」 | 化学合成 · 分子自组装 · DNA 折纸 |

## 与工程的关系

纳米技术是**使能技术（enabling technology）** —— 不改学科，改**材料与器件的性能上限**，渗透材料、电子、能源、生物、建材。
