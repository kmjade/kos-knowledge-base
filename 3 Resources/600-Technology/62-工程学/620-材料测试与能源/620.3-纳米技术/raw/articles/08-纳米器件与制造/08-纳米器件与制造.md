# 08 纳米器件与制造

> 纳米器件 = 功能由**纳米尺度结构**决定的元件；制造由 **top-down 微纳加工** 与 **bottom-up 自组装** 两条腿走路。

## 微纳加工（Top-down）

| 工艺 | 用途 |
| --- | --- |
| 光刻（深紫外 / EUV） | 集成电路图形 |
| 电子束 / 离子束刻蚀 | 纳米图形 · 掩模 |
| 纳米压印 | 低成本批量纳米图形 |
| 薄膜沉积（CVD / PVD / ALD） | 原子层精度薄膜 |

## 自组装（Bottom-up）

- 分子自组装 · 嵌段共聚物微相分离 · **DNA 折纸** —— 自发形成有序纳米结构。

## 典型器件

- **晶体管**：从平面 → FinFET → **GAA 环栅**，特征尺寸进入数纳米。
- **传感器**：纳米线 / 石墨烯 / CNT 高灵敏（气体 · 生物 · 应变）。
- **MEMS / NEMS**：微纳机电（谐振 · 传感 · 执行）。
- **单电子器件 · 自旋电子**：量子 / 自旋自由度。

## 关键挑战

- 量产：EUV 光刻成本 · 良率。
- 器件一致性 · 热耗散 · 量子 / 界面效应控制。
