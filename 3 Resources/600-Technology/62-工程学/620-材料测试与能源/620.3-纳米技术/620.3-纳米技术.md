# 620.3 纳米技术

> **UDC 620.3** — 纳米技术（Nanotechnology）。隶属 [[62-工程学|62 工程学]] › `620` 材料测试 / 工业材料 / 发电站 / 能源经济。
> 纳米技术 = 在 **1–100 nm** 尺度操纵物质，以获得宏观块体不具备的**尺度 / 表面 / 量子效应**。

## 范围

- **尺度**：1–100 nm —— 纳米材料 · 纳米结构 · 纳米器件。
- **核心**：尺度效应 → 高比表面积 · 量子限域 · 表面等离子体。
- **对象**：纳米颗粒（TiO₂ · SiO₂ · 碳纳米管 CNT · 石墨烯）· 纳米涂层 · 纳米复合材料 · 纳米器件。

## 关键概念

| 概念 | 说明 |
| --- | --- |
| 纳米尺度 | 1–100 nm；介于分子 / 原子与宏观之间 |
| 尺度效应 | 比表面积、表面能、量子限域 → 性能突变 |
| 材料维数 | 0D 颗粒 · 1D 管 / 线 · 2D 薄膜 / 石墨烯 |
| 表征 | SEM / TEM · AFM · XRD · 拉曼 |

## 工程应用

- **材料**：纳米增强复合材料 · 超疏水 / 自清洁涂层 · 高强轻质。
- **建材关联**：纳米 TiO₂ 光催化自洁 · 纳米 SiO₂ 改性（混凝土 / 涂层）。
- **能源**：锂电池电极 · 催化剂 · 光伏。
- **生物 / 医疗**：靶向递送 · 抗菌。
