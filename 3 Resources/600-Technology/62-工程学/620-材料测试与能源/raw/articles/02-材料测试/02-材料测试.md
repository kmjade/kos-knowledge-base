# 02 材料测试

> 材料测试 = 用标准化的方法**测定材料性能**，验证其是否满足设计与规范 —— 工程质量与安全的守门人。

## 力学性能试验

| 试验 | 指标 |
| --- | --- |
| 拉伸 | 屈服强度 · 抗拉强度 · 伸长率 · 弹性模量 |
| 压缩 / 弯曲 | 抗压 / 抗弯强度 |
| 冲击（夏比） | 冲击韧性（低温脆性） |
| 硬度 | 布氏 HB · 洛氏 HRC · 维氏 HV |
| 疲劳 | S-N 曲线 · 疲劳极限 |
| 蠕变 / 持久 | 高温长期性能 |

## 无损检测（NDT）

| 方法 | 原理 | 适用 |
| --- | --- | --- |
| 超声 UT | 声波反射 | 内部缺陷 |
| 射线 RT | X/γ 透射 | 内部缺陷 · 焊缝 |
| 磁粉 MT | 漏磁场吸附磁粉 | 铁磁材料表面 / 近表面 |
| 渗透 PT | 毛细吸附 | 表面开口缺陷 |
| 涡流 ET | 电磁感应 | 导电材料表面 · 管材 |

## 成分与组织

- **光谱**（OES / XRF）：化学成分。
- **金相**：显微组织 · 晶粒度。
- **XRD**：物相。

## 标准与流程

- 依据 **GB/T**（如拉伸 GB/T 228.1 · 冲击 GB/T 229 等，**具体版本待核**）· 国际 ISO / ASTM。
- 流程：取样 → 制样 → 试验 → 数据 → 报告；重要工程需**第三方 / 见证试验**。
