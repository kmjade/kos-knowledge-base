# 03 工业用材料

> 工业用材料 = 工程中实际采购、加工、使用的材料 —— 本类关注**品种 · 性能 · 选用**，而非制造工艺。

## 分类

| 大类 | 代表 |
| --- | --- |
| 金属 | 碳钢 / 合金钢 · 不锈钢 · 铝 / 铜 / 钛合金 |
| 无机非金属 | 陶瓷 · 玻璃 · 水泥 / 混凝土（→ 691） |
| 高分子 | 塑料（PE/PP/PVC/ABS）· 橡胶 · 纤维 |
| 复合材料 | 纤维增强（CFRP/GFRP）· 纳米复合（→ 620.3） |

## 选用原则

- **力学**：强度 · 韧性 · 硬度 · 疲劳。
- **加工**：可焊性 · 切削性 · 成形性。
- **环境**：耐蚀 · 耐温 · 耐候。
- **经济 / 合规**：成本 · 供应 · 标准 · 环保。

> 选材是**多目标权衡**：没有最好，只有最合适。
