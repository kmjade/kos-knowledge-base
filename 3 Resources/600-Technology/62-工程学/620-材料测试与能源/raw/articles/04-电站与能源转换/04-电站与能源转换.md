# 04 电站与能源转换

> 电站 = 把**一次能源**转换为**电能**的工程设施；能源转换效率与结构决定能源系统的碳与成本。

## 电站类型

| 类型 | 转换链 | 备注 |
| --- | --- | --- |
| 火电（煤 / 气） | 化学能 → 热 → 机械 → 电 | 煤电 / 燃气联合循环 |
| 水电 | 势能 → 机械 → 电 | 效率高 · 可调 |
| 核电 | 核裂变热 → 蒸汽 → 电 | 低碳基荷 |
| 风电 | 动能 → 电 | 间歇 |
| 光伏 | 光 → 电 | 间歇 · 无转动部件 |
| 储能 | 电 ↔ 化学 / 势能 / 热 | 平抑波动 |

## 转换效率（量级）

- 煤电：~**35–45%**（超超临界更高）。
- 燃气联合循环：~**55–62%**。
- 水电：~**85–90%**。
- 光伏：组件 ~**20–25%**（在提升）。

## 电力系统

`发电 → 输电（高压）→ 变电 → 配电 → 用电`

- 需**实时平衡**（发电 = 负荷）。
- 可再生高占比 → 需要**灵活调节 + 储能 + 电网升级**（见 [[07-能源转型与可再生|620.9 转型]]）。
