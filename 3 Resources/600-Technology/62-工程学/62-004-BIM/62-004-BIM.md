# 62:004 BIM 建筑信息模型

> **UDC 62:004** — 工程（`62`）× 计算机科学（`004`）＝ **建筑信息模型**（Building Information Modeling）。隶属 [[62-工程学|62 工程学]]（工程数字化侧）。
> BIM = 建筑的**数字化信息模型 + 协同过程 + 信息管理**，贯穿设计 → 施工 → 运维**全生命周期**。

## 三个含义

| 层面 | 含义 |
| --- | --- |
| **模型 Model** | 数字化信息模型（几何 + 属性：材料 · 规格 · 成本 · 时间 · 维护） |
| **过程 Process** | 设计 / 施工 / 运维的**协同工作流**（非单一软件） |
| **管理** | 信息交付 · 标准 · 合同（ISO 19650） |

> 与 CAD 之别：CAD 画「**线**」；BIM 建「**物**」（**对象化 · 参数化 · 关联**）。
