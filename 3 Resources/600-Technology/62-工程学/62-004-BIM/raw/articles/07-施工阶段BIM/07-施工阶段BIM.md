# 07 施工阶段 BIM

> 模型驱动施工：**模拟 → 深化 → 预制 → 装配 → 竣工**。

## 主要应用

| 应用 | 维度 |
| --- | --- |
| **施工模拟**（工序 / 进度） | 4D |
| **场地布置**（塔吊 / 道路 · 临设） | 3D |
| **工程量 / 造价** | 5D |
| **深化设计**（机电 · 幕墙 · 钢结构） | 3D |
| **预制加工**（装配式 · 模块化） | DfMA |
| 安全 / 质量 / 交底 | 3D |
| 竣工模型（as-built） | → 运维 |

## 深化与预制

- 机电深化（碰撞 → 支吊架 → 预留预埋，LOD400）（→ [[articles/08-机电管线综合/08-机电管线综合|696 机电管线综合]]）。
- 装配式：模型 → 拆分 → 工厂预制 → 现场装配（→ [[08-钢结构与装配式施工|624.05 钢结构与装配式施工]]）。
