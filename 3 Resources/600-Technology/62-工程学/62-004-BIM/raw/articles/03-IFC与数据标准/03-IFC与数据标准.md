# 03 IFC 与数据标准

> 让不同软件**互通**的开放标准 —— BIM 的「通用语言」。

## openBIM 与 IFC

- **buildingSMART**：推动 **openBIM**（厂商中立）。
- **IFC**（Industry Foundation Classes）：**开放数据模型**，描述建筑构件与关系。
- 配套：
  - **IDM**（信息交付手册）· **MVD**（模型视图定义）。
  - **BCF**（BIM 协作格式，问题交换）。
  - **bsDD**（数据字典）。

## 信息管理标准

- **ISO 19650**：BIM 信息管理（概念 · 交付 · 全生命周期）。
- 与 ISO 55000（资产管理）· ISO 9001 衔接。
