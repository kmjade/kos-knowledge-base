# 09 BIM 标准与实施

> 标准让 BIM **可交付 · 可协同 · 可追责**；实施决定其**能否落地**。

## 标准体系

| 层级 | 标准 |
| --- | --- |
| 国际 | **ISO 19650**（信息管理）· buildingSMART **IFC / IDM / BCF** |
| 中国（**待核**） | GB/T 51212（BIM 应用统一标准）· GB/T 51301（设计交付标准）· 施工 / 运维应用标准 |
| 地方 / 行业 | 各省市 BIM 标准 · 行业规程 |

## LOD（模型细度）

- **LOD 100 → 500**（概念 → 竣工 / 运维）。
- 或中国 **LOD 1.0–4.0** 分级。
- 各阶段模型应达到约定细度。

## 实施要点

- **BIM 实施规划**（BEP：目标 · 范围 · 流程 · 责任 · 交付物）。
- 组织与角色（BIM 经理 · 协调员）· 软硬件 · 培训。
- 常用合同 / 交付：信息交付规范（EIR）· BIM 执行计划。

## 效益与挑战

| 效益 | 挑战 |
| --- | --- |
| 减少返工 · 缩短工期 · 控制成本 | 前期投入 · 人才 · 流程变革 |
| 协同 · 可视化 · 数据资产 | 标准落地 · 模型维护 · 责任界定 |
