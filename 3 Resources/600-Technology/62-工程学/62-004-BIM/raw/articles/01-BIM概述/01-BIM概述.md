# 01 BIM 概述

> BIM = 用**信息模型**描述建筑，并让各方在**同一模型**上协同工作。

## 定义（三重）

| 层面 | 含义 |
| --- | --- |
| **Model** | 数字化建筑信息模型（几何 + 非几何属性） |
| **Modeling** | 建模 / 应用**过程**（设计-施工-运维协同） |
| **Management** | 信息交付 · 标准 · 合同（信息管理） |

## 与 CAD 的本质区别

| | CAD | BIM |
| --- | --- | --- |
| 对象 | 线 / 图元 | **构件对象** |
| 性质 | 绘图 | **建模 + 信息** |
| 关联 | 无 | **参数化 · 联动** |
| 产出 | 图纸 | 模型 + 图纸 + 数据 |

> 一句话：**CAD 画「线」，BIM 建「物」**。

## 核心价值

- **信息共享**（设计-施工-运维同一数据源）。
- **变更联动**（改一处，自动更新）。
- **可视化 · 碰撞检查 · 算量 · 模拟**。
- 减少**返工**与信息断层（→ [[05-协同与CDE]]）。
