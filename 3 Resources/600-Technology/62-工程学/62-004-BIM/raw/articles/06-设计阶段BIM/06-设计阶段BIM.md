# 06 设计阶段 BIM

> 用模型**而非图纸**做设计 —— 「**正向设计**」。

## 正向设计 vs 翻模

| 方式 | 说明 |
| --- | --- |
| **正向设计** | 从模型出发 → 出图（信息驱动） |
| 翻模（逆向） | 先画 2D 图 → 再建模型（补课式） |

- 正向设计 = BIM 的应有形态；翻模是过渡。

## 设计应用

- **参数化 / 生成设计**（Grasshopper · Dynamo）。
- **性能分析**：能耗 · 日照 · 采光 · 气流 · 疏散（与模型联动）。
- **多专业协同**（建筑 / 结构 / 机电）。
- 可视化 · 虚拟现实（VR）评审。
