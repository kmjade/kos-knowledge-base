# 02 nD 维度

> BIM 从**几何**出发，逐维叠加**时间 · 成本 · 运维 · 可持续**信息。

## 维度谱

| 维 | 名称 | 内容 |
| --- | --- | --- |
| **3D** | 几何模型 | 构件 · 空间 · 碰撞 |
| **4D** | + 进度 | 施工顺序 / 模拟（甘特 ↔ 模型） |
| **5D** | + 成本 | 工程量 · 造价 · 资金流 |
| **6D** | + 运维 | 设施管理 FM · 资产 / 空间 |
| **7D** | + 可持续 | 能耗 · 绿建 · 碳 |
| **nD** | 其他 | 安全 · 预制 · 可施工性 … |

## 全生命周期

`规划 → 设计 → 施工 → 竣工 → 运维 → 拆除 / 改造`

- 各阶段模型**逐步深化**（→ LOD，见 [[09-BIM标准与实施]]）。
- 竣工模型（as-built）→ 运维模型（→ [[08-运维BIM与数字孪生]]）。
