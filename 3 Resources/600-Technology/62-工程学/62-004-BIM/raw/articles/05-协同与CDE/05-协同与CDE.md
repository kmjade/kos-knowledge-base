# 05 协同与 CDE

> BIM 的威力在**协同**：多专业在同一模型上分工、碰撞、出图。

## CDE（公共数据环境）

- **Common Data Environment** —— 统一数据源（ISO 19650）。
- 状态机：`进行中 → 共享 → 发布 → 归档`。
- 权限 · 版本 · 审批 · 审计。

## 协同方式

| 方式 | 说明 |
| --- | --- |
| 中心模型 | 团队基于中心文件协作（Revit 工作集） |
| 链接 / 集成 | 各专业模型链接 → 总装 |
| 模型合模 | 建筑 + 结构 + 机电 合并 |

## 碰撞检测

- **硬碰撞**（实体冲突）· **软碰撞**（净距 / 空间）。
- 流程：合模 → 碰撞报告 → 协调 → 复检。
- 机电**管线综合**：净高 · 支吊架 · 预留预埋（→ [[articles/08-机电管线综合/08-机电管线综合|696 机电管线综合]] · [[管线综合|管线综合]]）。

## 出图与交付

- 模型 → 施工图 · 明细表（算量）· 交付标准。
