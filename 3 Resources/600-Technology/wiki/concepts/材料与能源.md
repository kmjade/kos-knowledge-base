# 材料与能源

> **材料**是「造物」的物质基础，**能源**是「做功」的动力基础 —— 全部应用科学的**共同底座**。
> 编译自 [[07-材料与能源基础|07 材料与能源基础]]。

## 材料四要素

```
成分 → 结构 → 工艺 → 性能
（Composition → Structure → Processing → Properties）
```

> 改**工艺**就能改**结构**，改**结构**就能改**性能** —— 这是材料工程的全部杠杆。

## 材料家族

- **金属**（结构 / 导电导热）· **陶瓷**（耐高温 / 硬）· **高分子**（轻 / 易成型）· **复合材料**（各向异性 / 比强度）
- 新材料 → 新工艺 → 新产品：材料是技术演化的**使能者**（如半导体之于信息革命）。
