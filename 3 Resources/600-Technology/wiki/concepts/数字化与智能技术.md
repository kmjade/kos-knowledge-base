# 数字化与智能技术

> 把物理世界变成**可计算的信息**，并让系统**自主地感知、决策与执行**。
> 编译自 [[09-数字化与智能技术|09 数字化与智能技术]]。

## 三步链

```
感知（Sensor/IoT） → 连接（网络/云） → 决策（计算/AI） → 执行（执行器/CPS）
```

## 关键技术

| 层 | 技术 | 作用 |
|:--|:--|:--|
| 感知 | 传感器 · IoT | 物理量 → 数据 |
| 连接 | 5G · 工业互联网 | 数据传输 |
| 建模 | 数字孪生 · CAE | 虚实映射 |
| 计算 | 云 / 边缘计算 | 算力供给 |
| 智能 | AI · CPS · 机器人 | 自主决策与执行 |
| 制造 | 智能制造 · MES | 贯通设计—生产 |
