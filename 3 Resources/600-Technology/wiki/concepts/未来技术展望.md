# 未来技术展望

> 预测未来的最好方式，是理解「技术**如何**演化」并推出可能路径；但要警惕**线性外推**与**炒作**。
> 编译自 [[13-未来技术展望|13 未来技术展望]]。

## 如何展望（方法）

| 原则 | 说明 |
|:--|:--|
| 慎用线性外推 | 技术走 **S 曲线**：慢→快→饱和 |
| 区分层级 | **可能 · 可行 · 可用 · 可负担** 是四回事 |
| 技术就绪度（TRL） | 实验室（1）→ 成熟（9） |
| 情景法 | 给多条未来，不押单一 |
| 警惕炒作 | Gartner 曲线：期望膨胀 → 幻灭 → 爬坡 |

> **不确定性**：反身性（预测影响行为）· 路径依赖（历史锁定）—— 使「精确预测」基本不可能。

## 下一代通用目的技术（GPT）

**AI · 量子 · 生物 · 能源** —— 不只是单项技术，而是**重塑所有行业**的底座。

## 关键技术族（时间尺度）

按「近期（现–5 年）· 中期（5–15 年）· 远期（15 年+ · 不确定）」分层评估。
