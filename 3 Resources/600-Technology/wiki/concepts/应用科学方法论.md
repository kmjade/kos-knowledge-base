# 应用科学方法论

> 在真实约束下，用一套**可复现**的方法，把「想法」变成「可靠产物」。
> 编译自 [[03-应用科学方法论|03 应用科学方法论]]。

## 主干流程

```
问题 → 需求 → 设计 → 实现 → 验证 → 运维/退役
```

> 十壳都走这条主干，只是领域词汇不同（医学 = 诊断—治疗方案—疗效评估；化工 = 小试—中试—放大）。

## 通用方法族

| 方法族 | 代表方法 | 解决什么 |
|:--|:--|:--|
| 需求与问题 | 需求工程 · 问题定义 | **做对的事** |
| 设计 | 概念设计 · 权衡 · TRIZ · DFX | 把需求变方案 |
| 建模与仿真 | 数学模型 · CAE · 数字孪生 | **先算再造** |
| 实验与测量 | DOE · 误差分析 · 标定 | 让数据说得清 |
| 验证与确认 | [[标准化与规范\|V&V]] · 型式试验 | 装对了 + 做对了 |
| 质量与可靠性 | FMEA · 六西格玛 · SPC | 稳定复现 |
| 标准化与合规 | 标准 · 认证 · 法规 | 互通与信任 |
| 系统工程 | V 模型 · MBSE | 复杂系统集成 |
| 安全与风险 | HAZOP · LOPA · 冗余 | **不出事** |

## 五条纪律（不变式）

1. **可复现** 2. **可验证** 3. **约束下取舍** 4. **安全优先** 5. **小步迭代**
