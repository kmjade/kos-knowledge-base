# 可持续技术

> 技术既是问题的一部分（排放 · 耗竭），也是解药的一部分（减排 · 循环）—— 把造物 / 用能 / 制造 / 数字化放进「**地球边界**」里看。
> 编译自 [[10-可持续技术与绿色转型|10 可持续技术与绿色转型]]。

## 可持续是什么

- **三支柱**：环境 · 社会 · 经济（缺一不可）。
- **布伦特兰定义**：满足当代需求，**不损害后代**满足其需求的能力。
- **地球边界（Planetary Boundaries）**：气候 · 生物多样性 · 氮磷 · 土地利用的安全阈值。

## 碳：核心度量

```
碳源 → 大气 → 碳汇（森林 / 海洋 / CCUS）
```

- 碳中和 = 排放 − 吸收 = 0；碳达峰 → 碳中和路径。

## 绿色技术族

可再生能源 · 储能 · 电动车 · 氢能 · CCUS · 循环经济（减量 → 再用 → 再生）。
