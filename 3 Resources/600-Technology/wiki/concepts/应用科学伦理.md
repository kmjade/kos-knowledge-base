# 应用科学伦理

> 技术是**放大器**：功率越大、外溢越广、越不可逆，就越需要伦理 —— 不只问「**能不能做**」，更问「**该不该做 · 谁负责**」。
> 编译自 [[04-应用科学伦理|04 应用科学伦理]]。

## 为什么技术需要伦理

| 特征 | 伦理含义 |
|:--|:--|
| 力量 | 能改世界 → 就有责任 |
| 外溢 | 影响第三方与后代 |
| 不可逆 | 核 · 基因 · 环境的后果无法撤回 |
| 信息不对称 | 专家 vs 公众 |
| 双重用途 | 同一技术可善用也可恶用 |

## 七原则

**善行 / 不伤害** · **责任** · **自主与知情同意** · **公正** · **预防原则** · **可持续 / 代际正义** · **透明与可解释**。

## 三类框架

| 框架 | 判据 | 追问 |
|:--|:--|:--|
| 后果论 | 看结果 | 谁受益 / 受损？ |
| 义务论 | 看责任 | 有无权利被侵犯？ |
| 美德论 | 看品格 | 正直的人会怎么做？ |

> **自检三问**：① 谁受益、谁受损？② 有权利被侵犯吗？③ 我愿意被这样对待吗？
