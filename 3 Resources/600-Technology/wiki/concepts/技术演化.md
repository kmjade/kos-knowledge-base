# 技术演化

> 应用科学的历史 = 「人如何把自然规律变成可用的东西」的历史。
> 编译自 [[02-应用科学史与技术演化|02 应用科学史与技术演化]]。

## 九段历程

| 时期 | 标志技术 | 关键跃迁 |
|:--|:--|:--|
| 史前 | 石器 · 用火 · 种植 · 制陶 | 采集 → 生产 |
| 古代 | 冶金 · 文字 · 灌溉 · 建筑 · 医学 | 专业化 · 城市 |
| 古典–中世纪 | 造纸 · 印刷 · 火药 · 指南针 · 机械钟 | **知识可复制** |
| 科学革命（16–17C） | 望远镜 · 显微镜 · 大气压 · 力学 | **科学反哺技术** |
| 工业 1.0（18C 末） | 蒸汽机 · 纺织机械 · 铁路 | 动力替代人力 |
| 工业 2.0（19–20C） | 电力 · 内燃机 · 化工 · 电报 | 能源与化工体系 |
| 工业 3.0（20C 中后） | 计算机 · 半导体 · 航天 · 核能 | 信息与自动化 |
| 工业 4.0（21C） | 互联网 · 移动 · 生物技术 · AI | 智能与融合 |
| 当代 | 新能源 · 机器人 · 合成生物 · 生成式 AI | 跨域收敛 |

## 演化逻辑（五律）

| 规律 | 含义 |
|:--|:--|
| **组合进化** | 新技术 ≈ 既有技术的重新组合（[[布莱恩·阿瑟]]《技术的本质》） |
| **S 曲线** | 每项技术经历「诞生 → 加速 → 饱和 → 被替换」 |
| **通用目的技术（GPT）** | 蒸汽 · 电力 · 计算机 · AI 重塑全部行业 |
| **科学 ↔ 技术双向** | 古代技术先行；19C 起科学引领；当代交织 |
| **路径依赖与锁定** | 历史选择（QWERTY · 轨距）塑造今天 |
