# 科学技术双向关系

> 「科学 → 技术」是流行印象，但真实历史是**双向**的：**技术给科学造仪器，科学给技术立原理**。
> 编译自 [[11-科学↔技术：双向关系|11 科学↔技术：双向关系]]。

## 破除线性模型

- **线性模型**（Vannevar Bush）：「基础研究 → 应用研究 → 开发 → 产品」。
- **现实**：三者互相激发、并行、循环；技术常**先于**科学（蒸汽机早于热力学）。

## 科学 → 技术（原理驱动）

| 科学原理 | 催生的技术 |
|:--|:--|
| 电磁学 | 电动机 · 发电机 · 无线电 |
| 量子力学 | 半导体 · 激光 · 核能 · 量子计算 |
| 分子生物学 | 基因工程 · 测序 · 合成生物 |
| 热力学 | 热机 · 制冷 · 能效 |

## 技术 → 科学（工具驱动）

| 技术工具 | 打开的科学 |
|:--|:--|
| 望远镜 | 近代天文学 |
| 显微镜 | 微生物学 · 细胞学 |
| 粒子加速器 | 高能物理 |
| 测序仪 | 基因组学 |

> **巴斯德象限**（Pasteur's Quadrant）：既追求**基础理解**又面向**应用**的研究（如巴斯德的微生物学）。
