# 标准化与规范

> 标准是「让**不同的人 · 不同的地方 · 不同的时间**，做出彼此可兼容的东西」的**公共语言** —— 把「一次性做对」升级为「**可复制地做对**」。
> 编译自 [[05-标准化与规范导论|05 标准化与规范导论]]。

## 为什么需要标准

| 目的 | 说明 |
|:--|:--|
| **互通 / 互操作** | 螺母与螺栓 · 插座 · 通信协议 |
| **安全底线** | 强制规范护住生命财产 |
| **规模经济** | 通用件 → 低成本 · 可替换 |
| **信任与贸易** | 认证即信任 · 降低交易成本 |
| **知识固化** | 把经验写成可传承的规则 |
