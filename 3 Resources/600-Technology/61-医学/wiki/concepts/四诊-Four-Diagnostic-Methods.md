# 四诊 Four Diagnostic Methods

## 定义

四诊即**望、闻、问、切**四种诊察方法，是收集病情资料、进行辨证论治的前提。

## 关键要点

| 诊法 | 内容 |
|------|------|
| 望诊 | 神、色、形、态、舌象 |
| 闻诊 | 声音、气味 |
| 问诊 | 主诉、病史、寒热、汗、饮食、二便 |
| 切诊 | 脉诊、按诊 |
