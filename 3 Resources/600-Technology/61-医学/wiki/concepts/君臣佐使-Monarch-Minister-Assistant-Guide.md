# 君臣佐使 Monarch-Minister-Assistant-Guide

## 定义

君臣佐使是方剂的**组方原则**，通过药物在方中的主次分工，使诸药协同增效、制约减毒。

## 关键要点

| 角色 | 作用 |
|------|------|
| 君药 | 针对主病主证，起主要作用 |
| 臣药 | 辅助君药，或治兼证 |
| 佐药 | 佐助、佐制、反佐 |
| 使药 | 引经、调和 |
