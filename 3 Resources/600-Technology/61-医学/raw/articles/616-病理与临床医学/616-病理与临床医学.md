# 616 病理与临床医学

> **UDC 616** — 病理学 · 临床医学（Pathology. Clinical medicine）。
> 隶属 [[61-医学|61 医学]]。

## 类目

**疾病本身** —— 从病理机制到内科各系统的诊断与治疗，是 UDC 61 中体量最大的分类。

## 内容要点

| 方面 | 要点 |
|------|------|
| 病理学 | 病因 · 发病机制 · 细胞损伤 · 炎症 · 肿瘤 · 循环障碍 |
| 诊断学 | 症状与体征 · 检验 · 影像 · 病理活检 |
| 内科各系统 | 循环 · 呼吸 · 消化 · 泌尿 · 血液 · 内分泌 · 神经 |
| 感染性疾病 | 传染 · 免疫与变态反应 · 发热 |
| 皮肤 · 精神 | 皮肤病 · 精神障碍（部分交叉 159.9） |
| 治疗 | 一般治疗 · 内科用药（交叉 615） |
