# 613 卫生学

> **UDC 613** — 卫生学通论 · 个人卫生与健康（Hygiene generally. Personal health and hygiene）。
> 隶属 [[61-医学|61 医学]]。

## 类目

面向**个人与日常生活**的卫生与健康 —— 区别于 614 的群体公共卫生。

## 内容要点

| 方面 | 要点 |
|------|------|
| 个人卫生 | 清洁 · 口腔 · 皮肤 · 睡眠 |
| 饮食卫生 | 营养 · 食品安全 · 饮水 |
| 环境与居住 | 空气 · 光照 · 噪声 · 居室卫生 |
| 生活方式 | 运动 · 戒烟限酒 · 作息 · 心理健康 |
| 职业与运动卫生 | 劳动保护 · 运动卫生（交叉 614） |
| 健康素养 | 自我监测 · 体检 · 急救常识 |
