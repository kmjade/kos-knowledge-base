# 06-推拿与导引

> 以手法作用于体表（推拿）与主动运动（导引）防治疾病、强身健体。

## 推拿手法

| 手法 | 说明 |
|------|------|
| 推法、拿法 | 用指掌推按、拿捏 |
| 按法、揉法、摩法 | 垂直按压、回旋揉动、轻摩 |
| 滚法 | 手背滚动（现代常用） |
| 一指禅 | 拇指端持续着力 |
| 正骨 | 整复关节脱位、错缝 |

## 导引养生

- **八段锦**：八节柔缓功法
- **五禽戏**：[[华佗-Hua-Tuo|华佗]]创编，仿虎鹿熊猿鸟
- **太极拳**：刚柔相济、意气形合一
- **易筋经**：强筋壮骨

## 适应证

颈肩腰腿痛、筋骨损伤、康复、小儿推拿（消化不良、发热等）
