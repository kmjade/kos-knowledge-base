# 614 公共卫生

> **UDC 614** — 公共卫生与卫生防疫 · 事故预防（Public health and hygiene. Accident prevention）。
> 隶属 [[61-医学|61 医学]]。

## 类目

面向**群体与社会**的健康 —— 防疫、卫生管理、伤害预防，即预防医学视角。

## 内容要点

| 方面 | 要点 |
|------|------|
| 流行病学 | 疾病分布 · 三环节两因素 · 暴发调查 |
| 传染病防控 | 传播途径 · 隔离 · 消毒 · 免疫规划（疫苗） |
| 卫生管理 | 卫生法规 · 卫生监督 · 医疗机构与公共卫生体系 |
| 环境卫生 | 水 · 空气 · 土壤 · 食品 · 职业卫生 |
| 伤害预防 | 交通 · 职业 · 家庭意外（Accident prevention） |
| 健康促进 | 健康教育 · 慢病管理 · 健康监测与统计 |
