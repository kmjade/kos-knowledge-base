# 617 外科·骨科·眼科

> **UDC 617** — 外科学 · 骨科学 · 眼科学（Surgery. Orthopaedics. Ophthalmology）。
> 隶属 [[61-医学|61 医学]]。

## 类目

以**手术与操作**为核心的治疗性学科。

## 内容要点

| 方面 | 要点 |
|------|------|
| 外科总论 | 无菌术 · 麻醉 · 输血 · 休克 · 创伤 · 围手术期 |
| 普通外科 | 腹部 · 甲状腺乳腺 · 血管 · 肛肠 |
| 骨科 | 骨折 · 关节 · 脊柱 · 运动损伤 · 关节置换 |
| 眼科 | 屈光 · 白内障 · 青光眼 · 眼底病 |
| 泌尿外科 | 结石 · 前列腺 · 泌尿肿瘤 |
| 神经外科 · 心胸外科 | 颅脑 · 胸腔与心脏 |
| 其他 | 烧伤 · 整形 · 口腔（部分） |
