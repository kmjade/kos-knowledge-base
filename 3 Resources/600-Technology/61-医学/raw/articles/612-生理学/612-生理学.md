# 612 生理学

> **UDC 612** — 生理学（Physiology, human and comparative）。
> 隶属 [[61-医学|61 医学]]。

## 类目

| 系统 | 要点 |
|------|------|
| 血液与循环 | 血液成分 · 心脏泵血 · 血压 · 微循环 |
| 呼吸 | 肺通气 · 气体交换 · 呼吸调节 |
| 消化与营养 | 消化液 · 吸收 · 能量代谢 |
| 泌尿 | 滤过 · 重吸收 · 水盐与酸碱平衡 |
| 神经 | 兴奋传导 · 反射 · 感觉与运动 |
| 内分泌 | 激素调节 · 下丘脑-垂体轴 |
| 生殖 · 体温 · 免疫 | 生殖周期 · 体温调节 · 免疫应答 |
