# 636 畜牧学

> **UDC 636** — 畜牧与繁育总论 · 家畜饲养（Animal husbandry and breeding. Livestock rearing）。
> 隶属 [[63-农学|63 农学]]。

## 类目

**家畜家禽**的繁殖、饲养与管理。

## 内容要点

| 方面 | 要点 |
|------|------|
| 畜种 | 猪 · 牛（乳/肉）· 羊 · 禽 · 马 · 兔 |
| 繁殖 | 发情 · 配种 · 人工授精 · 育种选育 |
| 饲料与营养 | 粗/精饲料 · 配合饲料 · 营养需要（能量/蛋白） |
| 饲养管理 | 分阶段饲养 · 圈舍环境 · 防疫 |
| 动物健康 | 常见疫病 · 兽医防疫（交叉 61 医学） |
| 智慧畜牧 | 电子耳标 · 精准饲喂 |
