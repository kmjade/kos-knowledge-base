# 634 园艺学

> **UDC 634 / 635** — 园艺总论 · 园林植物（Horticulture generally. Garden plants. Gardening）。
> 隶属 [[63-农学|63 农学]]。

## 类目

**果树 · 蔬菜 · 花卉**等园艺作物的栽培与生产。

## 内容要点

| 方面 | 要点 |
|------|------|
| 果树 | 苹果 · 柑橘 · 葡萄 · 桃；整形修剪 · 疏花疏果 |
| 蔬菜（`635.1/.8`） | 叶菜 · 果菜 · 根菜 · 设施栽培 |
| 花卉与观赏植物（`635`） | 鲜切花 · 盆栽 · 园林苗木 |
| 繁殖 | 嫁接 · 扦插 · 压条 · 组织培养（交叉 60） |
| 设施园艺 | 温室 · 大棚 · 无土栽培 |
| 采后 | 分级 · 贮藏 · 保鲜 |
