# 639 渔猎与水产

> **UDC 639** — 渔猎 · 捕鱼 · 鱼类繁育（Hunting. Fishing. Fish breeding）。
> 隶属 [[63-农学|63 农学]]。

## 类目

**水产养殖与捕捞**，以及狩猎与野生动物利用。

## 内容要点

| 方面 | 要点 |
|------|------|
| 水产养殖 | 池塘 · 网箱 · 工厂化 · 稻渔综合种养 |
| 养殖对象 | 鱼（鲤/草/罗非）· 虾蟹 · 贝 · 藻 |
| 苗种与饲料 | 人工繁育 · 配合饲料 · 投饲管理 |
| 捕捞 | 渔具渔法 · 禁渔期 · 渔业资源管理 |
| 环境与健康 | 水质调控 · 鱼病防治 |
| 狩猎与野生动物 | 狩猎管理 · 野生动物利用与保护 |
