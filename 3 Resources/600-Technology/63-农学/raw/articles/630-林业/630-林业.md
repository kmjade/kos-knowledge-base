# 630 林业

> **UDC 630** — 林业（Forestry）。
> 隶属 [[63-农学|63 农学]]。

## 类目

## 内容要点

| 方面 | 要点 |

| 森林资源 | 林种（用材/防护/经济/薪炭）· 林分结构 · 蓄积量 |
| 苗木与造林 | 采种 · 育苗 · 造林 · 混交 |
| 森林经营 | 抚育间伐 · 主伐更新 · 森林经理 |
| 林产品 | 木材 · 竹材 · 松香 · 林下经济 |
| 保护 | 森林防火 · 病虫害 · 自然保护区 |
