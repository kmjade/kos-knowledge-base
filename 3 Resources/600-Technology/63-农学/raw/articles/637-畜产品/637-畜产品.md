# 637 畜产品

> **UDC 637** — 家畜与猎物产品（Produce of domestic (farmyard) animals and game）。
> 隶属 [[63-农学|63 农学]]。

## 类目

畜牧与猎获所得**产品**及其初级处理。

## 内容要点

| 方面 | 要点 |
|------|------|
| 乳 | 牛乳/羊乳成分 · 挤奶 · 巴氏杀菌 · 乳制品（酪/粉） |
| 蛋 | 禽蛋结构 · 分级 · 贮藏 |
| 肉 | 胴体分级 · 冷鲜/冷冻 · 排酸 |
| 毛皮与绒 | 羊毛 · 皮革 · 羽绒 |
| 其他 | 蜂产品（交叉 638）· 骨血副产品 |
| 质量安全 | 兽药残留 · 冷链 · 追溯 |
