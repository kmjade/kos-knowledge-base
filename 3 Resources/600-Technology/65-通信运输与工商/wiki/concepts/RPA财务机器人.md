# RPA 财务机器人

> **概念** — **RPA（Robotic Process Automation，机器人流程自动化）** 在财务 / 会计领域的应用：用软件「机器人」模拟人工操作各业务系统，自动执行**规则明确、重复性高**的财务流程。

## 是什么

RPA 机器人以「**非侵入**」方式工作 —— 不改造现有系统，而是模拟人在界面上的**点击、录入、读取、上传**，把**手工、重复、规则化**的财务操作交给软件自动完成。

## 典型场景

| 域 | 流程 |
| ---- | ---- |
| 应付 / 应收（AP/AR） | 发票录入 · 三单匹配 · 付款处理 |
| 总账 / 对账 | 银行对账 · 往来对账 · 月结 |
| 费用报销 | 单据审核 · **发票查验**（真伪）· 入账 |
| 报表 | 数据采集 · 合并 · 上报 |
| 税务 | 申报数据准备 · 开票 |
| 资金 | 网银查询 · 余额 / 调拨监控 |

## 技术栈

| 组件 | 作用 |
| ---- | ---- |
| RPA 引擎 | 流程编排与执行（UiPath · 实在智能 · 影刀 · 金智维 等） |
| **OCR / IDP** | 发票 · 单据 · 合同识别（智能文档处理） |
| 规则引擎 | 校验 · 匹配 · 例外判定 |
| **AI（LLM / ML）** | 非结构化理解 · 智能决策 · 异常处理 |

## 与相关概念

- **RPA → IPA → 超级自动化（Hyperautomation）**：RPA + AI + 流程挖掘 + 低代码。
- **数字员工 / 财务 AI Agent**：以 LLM 驱动的「自主财务助手」（结合 RPA 做执行）。
- 与 [[财务管理-Finance|财务管理]] · 会计共基座。

## 优势

降本 · 提效 · 减少人为差错 · **合规可追溯**（每步留痕）· 7×24 不间断 · 释放人力做分析决策。

## 挑战 / 风险

| 风险 | 说明 |
| ---- | ---- |
| 脆弱性 | 被操作系统的界面 / 版本变更即失效 |
| 例外处理 | 非标准单据需人工兜底 |
| 数据安全 | 涉及资金 / 敏感数据 → 权限 · 加密 · 审计 |
| 内控与治理 | 需职责分离（SoD）· 变更管理 · 机器人运维 |
| 合规 | 等保 · 财务内控规范 |
