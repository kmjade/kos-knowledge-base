# 654 通信

> **UDC 654** — 通信（Communication）。隶属 [[65-通信运输与工商|65 通信运输与工商]]。

## 类目

通信的**服务 / 行业 / 组织**（工程技术入 `621.39`）—— 电信服务 · 广播 · 网络服务 · 邮政通信。

## 内容要点

| 项 | 说明 |
|------|------|
| 电信 | 固定电话 · 移动通信 · 数据业务 · 卫星通信 |
| 广播 | 广播 · 电视 · 流媒体 |
| 网络 | 互联网服务（ISP）· 数据中心 · CDN |
| 邮政 | 邮政通信 · 快递（与 656 交叉） |
| 治理 | 频谱 · 牌照 · 普遍服务 · 网络中立 |

## UDC 定位

- `654` 相对 `621.39`（电信工程）：**654 管服务与行业，621.39 管设备与技术**。
- `654` 相对 `004.7`（计算机网络）：**004.7 是计算网络，654 是通信行业**。

## 关联

- 上级：[[65-通信运输与工商|65 通信运输与工商]]
- 相邻支线：[[656-运输与邮政|656 运输与邮政]] · [[659-公关|659 公关]]
- 技术侧：`621.39` 电信工程（[[62-工程学|62 工程学]]）
