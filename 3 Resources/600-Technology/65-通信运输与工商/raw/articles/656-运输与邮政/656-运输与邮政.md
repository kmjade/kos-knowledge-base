# 656 运输与邮政

> **UDC 656** — 运输 · 邮政（Transport services, postal services）。隶属 [[65-通信运输与工商|65 通信运输与工商]]。

## 类目

运输与邮政的**服务 / 行业 / 组织**（工程入 `625`/`629`）—— 各运输方式 · 物流与供应链 · 邮政。

## 内容要点

| 项 | 说明 |
|------|------|
| 铁路 | 客运 · 货运 · 铁路运营 |
| 公路 | 道路运输 · 城市交通 · 网约车 |
| 水运 | 航运 · 港口 · 内河 |
| 空运 | 航空运输 · 机场 · 航线 |
| 物流 | 仓储 · 配送 · 供应链 · 多式联运 |
| 邮政 | 邮政服务 · 快递（与 654 交叉） |

## UDC 定位

- `656` 相对 `625`/`629`（工程，62 容器）：**656 管运输服务，`625`/`629` 管交通工程**。
- `656` 相对 `654`：**654 传信息，656 运人与货**。
