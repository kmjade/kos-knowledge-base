# 659 公关

> **UDC 659** — 广告 · 宣传 · 公共关系（Advertising, publicity, public relations）。隶属 [[65-通信运输与工商|65 通信运输与工商]]。

## 类目

广告与公关 —— 广告 · 品牌传播 · 公共关系 · 危机公关 · 媒介。

## 内容要点

| 项 | 说明 |
|------|------|
| 广告 | 创意 · 媒介投放 · 效果衡量 |
| 品牌传播 | 品牌定位 · 整合营销传播（IMC） |
| 公共关系 | 公众沟通 · 媒体关系 · 舆情 |
| 危机公关 | 危机预警 · 应对 · 修复 |
| 媒介 | 传统媒体 · 社交媒介 · 内容平台 |

## UDC 定位

- `659` 相对 `658.8`（营销）：**658.8 是营销整体，659 是广告 / 公关传播**。
- `659` 相对 `316`（社会学）：传播的**社会理论**入 `316`，**实务**入 659。
