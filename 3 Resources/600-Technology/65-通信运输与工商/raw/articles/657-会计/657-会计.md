# 657 会计

> **UDC 657** — 会计（Accountancy）。隶属 [[65-通信运输与工商|65 通信运输与工商]]。

## 类目

会计与审计 —— 财务会计 · 管理会计 · 成本会计 · 审计 · 税务 · 财务报告。

## 内容要点

| 项 | 说明 |
|------|------|
| 财务会计 | 复式记账 · 三大报表 · 会计准则（IFRS / GAAP） |
| 管理会计 | 成本核算 · 预算 · 本量利 · 绩效 |
| 审计 | 内部审计 · 外部审计 · 内控 |
| 税务 | 税种 · 纳税筹划 · 合规 |
| 财务报告 | 合并报表 · 信息披露 · 财务分析 |

## UDC 定位

- `657` 相对 `005.9`（管理领域）：**657 是会计专业，005 是一般管理**。
- `657` 相对 `33`（经济学）：**657 管记账实务，33 管经济理论**。
