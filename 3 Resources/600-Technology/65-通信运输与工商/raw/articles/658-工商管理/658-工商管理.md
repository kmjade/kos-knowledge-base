# 658 工商管理

> **UDC 658** — 工商管理（Business management, administration, marketing）。隶属 [[65-通信运输与工商|65 通信运输与工商]]。

## 类目

企业与工商活动的**组织与管理** —— 企业组织 · 战略 · 营销（`658.8`）· 生产运营 · 人力资源（`658.3`）。

## 内容要点

| 项 | 说明 |
|------|------|
| 企业组织 | 公司治理 · 组织结构 · 商业模式 |
| 战略 | 战略分析 · 竞争战略 · 增长 |
| 营销（`658.8`） | 4Ps · 品牌 · 数字营销（**已收编 `658-Marketing`**） |
| 生产运营 | 生产计划 · 质量 · 供应链 |
| 人力资源（`658.3`） | 招聘 · 绩效 · 薪酬 · 劳动关系 |

## UDC 定位

- `658` 相对 `005`（一般管理理论，0 类）：**005 管一般原理，658 管企业 / 工商**。
- `658` 相对 `331`（劳动经济学）：`658.3` 是**企业人事关系**，`331` 是**劳动经济学**（参照，不迁）。
