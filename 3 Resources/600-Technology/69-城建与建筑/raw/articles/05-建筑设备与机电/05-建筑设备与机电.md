# 05 建筑设备与机电

> 定位：建筑的「血脉与神经」 —— 让建筑**可居、可用、可运行**的设备系统。深库见 [[696-建筑设备与安装|696 建筑设备与安装]] · [[696-建筑设备与安装|696 建筑机电（MEP）]]。

## MEP 三大专业

| 专业 | UDC | 内容 |
| ---- | :--: | ---- |
| 给排水 | 696.1 | 给水 · 排水 · 雨水 · 消防水 |
| 建筑电气 | 696.3 | 供配电 · 照明 · 弱电 / 智能化 · 防雷接地 |
| 暖通（HVAC） | 697 | 供暖 · 通风 · 空调（另见 06） |

## 系统要点

| 系统 | 关键 |
| ---- | ---- |
| 给水 | 水量 · 水压 · 水质 · 防回流污染 |
| 排水 | 坡度 · 存水弯水封 ≥50mm · 通气 |
| 燃气 / 蒸汽 | 防泄漏防爆 · 热补偿 · 特种设备 |
| 供配电 | 负荷分级 · 可靠性 · ≤35kV |
| 消防 | 消火栓 · 喷淋 · 报警联动（强条最密） |

## 安装工艺

```
连接 · 支撑 · 试验
```

- **连接** —— 螺纹 / 焊接 / 沟槽 / 卡压 / 热熔。
- **支撑** —— 支吊架（固定 / 活动 / 抗震）。
- **试验** —— 水压 / 灌水通球 / 绝缘接地 / 漏风量。

## 2026

1. **装配式机电（MiMEP / DfMA）** —— 工厂预制 · 现场拼装。
2. **BIM 管线综合深化** —— 碰撞 → 净高 → 综合支吊架（LOD400）。
3. **免焊连接普及** —— 薄壁不锈钢卡压取代焊接。
