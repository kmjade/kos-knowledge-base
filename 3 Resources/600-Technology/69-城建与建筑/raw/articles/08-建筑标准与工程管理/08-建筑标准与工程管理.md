# 08 建筑标准与工程管理

> 定位：建筑的**规则与组织层** —— 「以标准定质量、以验收定交付」的制度骨架。

## 标准体系

| 层级 | 说明 | 示例 |
| ---- | ---- | ---- |
| 强制性通用规范 | **全文强制** · 2022 年前后落地 | GB 55032 施工质量 · GB 55020 给排水 · GB 55024 电气 · GB 55036 消防 |
| 技术规范 | 设计 / 施工 / 验收 | GB 50300 建筑工程施工质量验收统一标准 |
| 产品标准 | 材料 / 构件指标 | GB 175 水泥 · GB 1499.2 钢筋 |

> 通用规范正逐步取代分散旧强条 —— 与 [[01-城建与建筑总论|01 城建与建筑总论]] 主线一致；参见 [[05-标准化与规范导论|05 标准化与规范导论]]。

## 建设程序

```
立项 → 勘察设计 → 招标投标 → 施工 → 监理 → 竣工验收 → 交付使用
```

| 阶段 | 关键 |
| ---- | ---- |
| 立项 | 可行性研究 · 报建 |
| 设计 | 方案 / 初设 / 施工图 · 审图 |
| 招投标 | 招标 · 合同 |
| 施工 | 进度 / 质量 / 安全 / 成本 |
| 验收 | 分部 / 竣工 · 备案 |

## 三控三管一协调

| 维度 | 内容 |
| ---- | ---- |
| 三控 | 质量 · 进度 · 成本 |
| 三管 | 合同 · 安全 · 信息 |
| 一协调 | 参建各方组织协调 |
