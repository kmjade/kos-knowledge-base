# 09 绿色建筑与智能建造

> 定位：建筑业的**未来方向** —— 低碳化（绿色建筑）与数字化（智能建造）双主线。

## 绿色建筑

| 维度 | 内容 |
| ---- | ---- |
| 节能 | 围护保温 · 高性能门窗 · 高效设备（GB 55015） |
| 低碳 | 低碳水泥 · 再生骨料 · 木结构固碳 |
| 节地 / 节水 / 节材 | 集约用地 · 中水回用 · 装配式减材 |
| 评价 | GB/T 50378 绿色建筑评价标准（基本 / 一 / 二 / 三星）· 近零能耗 |

## 建筑工业化

```
工厂预制 → 现场装配
```

- **装配式混凝土（PC）** —— 预制梁柱板墙 · 套筒灌浆。
- **装配式钢结构** —— 模块化 · 快速建造。
- **装配式机电 / 装修（MiMEP / DfMA）** —— 机房模块 · 干法装修。

## 智能建造

| 技术 | 应用 |
| ---- | ---- |
| BIM | 设计协同 · 碰撞检查 · 施工模拟（LOD400）· 运维数字孪生 |
| 建筑机器人 | 砌筑 · 抹灰 · 喷涂 · 测量 |
| 物联网 / 传感器 | 结构监测 · 智慧工地 |
| 3D 打印 | 混凝土构件 · 异形结构 |

## 2026 三条位移

1. **光储直柔（PEDF）** —— 建筑从耗能末端变为能源节点。
2. **MiMEP / 模块化机房** —— 现场安装时间大幅缩短。
3. **数字孪生交付** —— 竣工即交付可运维的 BIM 模型。
