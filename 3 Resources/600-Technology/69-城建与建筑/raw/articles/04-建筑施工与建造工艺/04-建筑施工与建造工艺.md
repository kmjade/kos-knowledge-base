# 04 建筑施工与建造工艺

> 定位：把图纸变成实体的**执行层** —— 现场作业与工艺。深库见 [[693-砌筑与建筑工艺|693 砌筑与建筑工艺]] · [[694-木结构与木作|694 木结构与木作]]。

## 建设流程

```
土方 → 基础 → 主体结构 → 围护 → 机电安装 → 装饰装修 → 竣工验收
```

| 阶段 | 内容 |
| ---- | ---- |
| 基础工程 | 土方开挖 · 桩基 · 筏板 · 防水 |
| 主体结构 | 钢筋 · 模板 · 混凝土浇筑 · 砌体 |
| 围护 | 外墙 · 屋面 · 门窗幕墙 |
| 机电 | 管线预埋 · 设备安装（见 05） |
| 装饰 | 饰面 · 涂装 · 铺贴（见 07） |

## 主要工艺

| 工艺 | 要点 |
| ---- | ---- |
| 砌筑 | 组砌方式 · 砂浆饱满 · 灰缝 |
| 钢筋混凝土 | 钢筋连接 / 保护层 · 模板支设 · 浇筑振捣 · 养护 |
| 木作 | 大木作（构架）· 小木作（装修）· 榫卯 / 五金 |
| 抹灰 | 底层 / 中层 / 面层 · 平整度 |

## 施工组织

| 手段 | 说明 |
| ---- | ---- |
| 流水施工 | 工序搭接 · 减少窝工 |
| 网络计划 | 关键路径（CPM）· 工期优化 |
| 装配式施工 | 工厂预制 + 现场吊装 · 干法作业 |

## 2026

- **装配式 / 建筑工业化** —— PC 构件 · 装配式装修 · MiMEP。
- **建筑机器人** —— 砌筑 · 抹灰 · 喷涂机器人进场。
- **BIM 深化前置** —— 碰撞 / 净高在模型里解决，现场只装配。
