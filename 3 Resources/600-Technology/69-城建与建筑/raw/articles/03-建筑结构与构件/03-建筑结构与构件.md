# 03 建筑结构与构件

> 定位：**结构骨架**决定建筑「立得住」，**构件**是骨架的组成件。深库见 [[692-建筑构件|692 建筑构件]]。

## 结构体系

| 体系 | 受力特征 | 适用 |
| ---- | ---- | ---- |
| 砖混结构 | 墙体承重 · 横向墙 | 低层住宅 |
| 框架结构 | 梁柱承重 · 空间灵活 | 多层办公 / 商业 |
| 剪力墙结构 | 墙肢抗侧 · 刚度大 | 高层住宅 |
| 框架-剪力墙 | 双重抗侧 | 高层综合楼 |
| 钢结构 | 工厂化 · 大跨 / 超高 | 大跨场馆 · 超高层 |
| 木结构 | 材料可再生 · 装配快 | 低多层 · 装配式 |
| 装配式（PC） | 工厂预制 + 现场装配 | 住宅工业化 |

## 构件（UDC 692.2–692.6）

| 构件 | 类号 | 要点 |
| ---- | :--: | ---- |
| 墙体 | 692.2 | 承重 / 非承重 · 保温 · 隔声 |
| 屋面 | 692.4 | 防水 · 排水坡度 · 保温隔热 |
| 楼地面 | 692.5 | 楼板 · 面层 · 隔声 |
| 楼梯 | 692.6 | 踏步 · 净高 · 防火疏散 |
| 门窗 | 692 | 气密 / 水密 / 抗风压 · 采光 |

## 传力路径

```
荷载 → 楼板 / 屋面 → 梁 → 柱 / 墙 → 基础 → 地基
```
