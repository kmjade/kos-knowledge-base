# 02 建筑材料

> 定位：建筑材料是建筑工业的**物质基础层** —— 一切构件、工艺、饰面的上游。深库见 [[691-建筑材料|691 建筑材料]]。

## 材料谱系

| 门类 | 典型材料 | 关键性能 |
| ---- | ---- | ---- |
| 胶凝材料 | 水泥（水硬性）· 石灰 · 石膏（气硬性） | 强度等级 · 凝结时间 · 安定性 |
| 混凝土 | 普通 / 高强 / 高性能 / 自密实 / UHPC | 强度 C15–C80 · 和易性 · 耐久性 |
| 砂浆 | 水泥砂浆 · 混合砂浆 · 干混砂浆 | 强度 M · 保水性 · 粘结 |
| 建筑钢材 | 热轧钢筋 · 型钢 · 钢丝 | 牌号（HPB300 / HRB400 / Q355）· 屈服强度 |
| 砌体材料 | 烧结砖 · 蒸压砖 · 砌块 · 石材 | 强度 MU · 吸水率 · 导热 |
| 木材 | 原木 · 板材 · 胶合板 · 集成材 | 含水率 · 强度等级 · 防腐 |
| 玻璃 | 平板 · 钢化 · 夹层 · 中空 | 安全 · 节能（Low-E） |
| 功能材料 | 防水卷材 / 涂料 · 保温材料 · 密封胶 | 防水等级 · 导热 λ · 燃烧性能 |

## 以标准定性能

| 层级 | 作用 | 示例 |
| ---- | ---- | ---- |
| 产品标准 | 定义强度 / 耐久 / 环保指标 | GB 175 水泥 · GB 1499.2 钢筋 |
| 应用技术规范 | 规定「怎么用」 | GB 50010 混凝土结构设计 · JGJ 144 外保温 |

> 与 [[01-城建与建筑总论|01 城建与建筑总论]]「以标准定质量」主线同构。

## 2026 三条位移

1. **低碳化** —— 水泥新国标收紧（GB 175-2023）· 低碳水泥 · 再生骨料。
2. **高性能化** —— UHPC · 高强钢筋 HRB600 · 自密实混凝土。
3. **工程木复兴** —— 胶合木 / CLT 正交胶合木进入高层与装配式。
