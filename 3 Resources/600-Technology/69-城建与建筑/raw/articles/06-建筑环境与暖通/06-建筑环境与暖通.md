# 06 建筑环境与暖通

> 定位：让室内**热舒适、空气洁净、声光适宜** —— 建筑与人的界面。深库见 [[697-暖通空调|697 暖通空调]]。

## 建筑物理（四要素）

| 要素 | 关注 |
| ---- | ---- |
| 热 | 保温隔热 · 热桥 · 遮阳 |
| 声 | 隔声 · 吸声 · 噪声控制 |
| 光 | 采光 · 照明 · 眩光 |
| 风 / 气 | 自然通风 · 气密性 · 室内空气质量（IAQ） |

## 暖通空调（HVAC）

| 子系统 | 内容 |
| ---- | ---- |
| 供暖 | 散热器 · 地暖 · 热源（锅炉 / 热泵） |
| 通风 | 自然 / 机械 · 防排烟 · 新风 |
| 空调 | 冷热源 · 风系统 / 水系统 · 末端 |
| 净化 | 过滤 · 温湿度控制（洁净室 / 数据中心） |

## 主线规范

- **GB 55015-2021**《建筑节能与可再生能源利用通用规范》（强制）
- **GB 55016-2021**《建筑环境通用规范》（强制）—— 声 · 光 · 热工

## 2026

1. **热泵化** —— 空气源 / 地源热泵替代燃煤锅炉。
2. **健康建筑** —— 新风 · 空气净化 · 低挥发材料（GB/T 50378 健康建筑）。
3. **光储直柔（PEDF）** —— 建筑从「耗能末端」转向「能源节点」。
