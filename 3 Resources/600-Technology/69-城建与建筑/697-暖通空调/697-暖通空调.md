## 类目

建筑**暖通空调（HVAC）**系统 —— 冬季供暖、室内通风换气、夏季空调与冷热源。
它同时是建筑的**最大用能项**，与「双碳」直接挂钩。

## 内容要点

| 系统 | 要点 |
| ---- | ---- |
| 供暖（Heating） | 散热器 · 地暖（辐射）· 热源（锅炉 → 热泵）· 分户计量 |
| 通风（Ventilation） | 自然通风 · 机械新风 · 排风 · 防排烟 |
| 空调（Air Conditioning） | 中央空调 · 风机盘管 · VRV/多联机 · 冷热源（冷水机组 / 磁悬浮） |
| 输配 | 风管 · 水管 · 保温 · 阀门与附件 |
| 控制 | 温湿度控制 · 新风联动 · 节能运行 |

## 暖通空调研讨（2026-09-28）

> 定位：697 补上「室外气候」与「室内舒适」之间的差距 —— 冬供暖 · 夏供冷 · 全年通风换气。它同时是建筑的**最大用能项**，与「双碳」直接挂钩。

**一、系统四层**

| 层 | 内容 | 关键 |
| -- | ---- | ---- |
| 冷热源 | 锅炉 / 热泵 / 冷水机组 / 多联机 | 能效（COP / IPLV / APF）· 制冷剂 |
| 输配 | 风管 · 水管 · 保温 · 阀门 | 输配能耗 · 水力平衡 |
| 末端 | 散热器 · 地暖 · 风机盘管 · 风口 | 舒适性（温度 / 风速 / 辐射） |
| 控制 | 温湿度 · 新风联动 · 群控 | 按需供给 · 节能运行 |

**二、三条功能线**

- **供暖**：散热器 / 地暖（辐射，JGJ 142）· 热源（锅炉 → **热泵**）· 分户计量。
- **通风**：自然通风 · 机械新风（含热回收）· **防排烟**（GB 51251）。
- **空调**：中央空调（全空气 / 风机盘管）· VRV 多联机 · 冷热源（离心 / 螺杆 / **磁悬浮**）。

**三、一条总纲 + 一条底线**

- 总纲：**GB 55015-2021**《建筑节能与可再生能源利用通用规范》（2022-04-01，强制）· **GB 55016-2021**《建筑环境通用规范》（声 / 光 / 热工 / 室内空气）。
- 底线：**防排烟**（GB 51251-2017 + GB 55036-2022）—— 消防验收硬指标。

> 与 [[696-建筑设备与安装|696]] 的 GB 55020 / 55024、[[698-装饰装修|698]] 的 GB 55032 一脉：**「通用规范」体系**。

**四、2026：三个大位移**

1. **热泵化**：空气源 / 地源热泵替代燃煤锅炉（发改委《推动热泵行业高质量发展行动方案》，2030 能效 +20%）；工业超高温热泵。
2. **AI 接管**：AI 高效机房 · AI 多联机（系统节能 15–30%）· 负荷预测与主动运维。
3. **能效与碳**：**GB 21455-2025**（房间空调器能效，一级 APF≥5.30，电辅热退出）；暖通产品**碳足迹量化**标准起步；磁悬浮下沉数据中心（液冷 · 风液同源）。

**五、与相邻支线**

- 冷热源 / 管网与 [[696-建筑设备与安装|696]] 的供热 · 给排水交叠；风管与 [[吊顶]]、末端与 [[698-装饰装修|698]] 交接。
