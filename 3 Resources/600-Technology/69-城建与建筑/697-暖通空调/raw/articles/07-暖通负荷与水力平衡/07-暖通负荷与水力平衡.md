# 07 暖通负荷与水力平衡

> 定位：负荷计算决定**系统容量**，水力平衡决定**系统是否真能达标** —— 是暖通设计的两个基础问题。

## 负荷计算

| 负荷 | 内容 |
| ---- | ---- |
| 冷负荷 | 围护传热 + 太阳辐射 + 内部得热（人 / 灯 / 设备）+ 新风 |
| 热负荷 | 围护传热 + 冷风渗透 + 新风加热 |
| 湿负荷 | 人体 / 工艺散湿 |

- 逐时负荷 → 确定冷热源与末端容量；围护性能（保温 / 门窗）直接影响负荷（GB 50176 热工）。

## 输配与水力平衡

| 问题 | 手段 |
| ---- | ---- |
| 近热远冷 | 平衡阀 · 静态 / 动态平衡 |
| 水泵能耗 | 变频 · 变流量（VWV） |
| 风平衡 | 风阀调节 · 定 / 变风量（CAV / VAV） |
| 分区 | 按朝向 / 用途分区控制 |

## 关键

- 输配能耗常占暖通总能耗的 20–40% → **变频 + 平衡**是节能重点。
- 供回水温差（大温差小流量）降低输配能耗。
