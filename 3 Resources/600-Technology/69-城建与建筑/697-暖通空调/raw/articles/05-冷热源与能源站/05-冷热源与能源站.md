# 05 冷热源与能源站

> 定位：冷热源是暖通系统的「心脏」—— 制造冷量与热量，决定系统能效与碳排放。

## 冷源（供冷）

| 设备 | 说明 |
| ---- | ---- |
| 离心式冷水机组 | 大冷量 · 高效 |
| 螺杆式冷水机组 | 中等冷量 |
| **磁悬浮冷水机组** | 无油 · 高效 · 部分负荷优（下沉数据中心） |
| 多联机（VRV） | 分散 · 变频 |

## 热源（供热）

| 设备 | 说明 |
| ---- | ---- |
| 锅炉 | 燃气 / 电 · 传统 |
| **空气源热泵** | 从空气取热 · 广泛 |
| **地源 / 水源热泵** | 高效 · 需地埋管 / 水源 |
| 余热回收 / 热电联产 | 区域能源 |

## 能源站

集中设置冷热源 + 蓄能（蓄冷 / 蓄热）+ 输配泵组；**高效机房**（AI 群控）是节能重点。

## 能效指标

| 指标 | 含义 |
| ---- | ---- |
| COP | 制冷 / 制热性能系数 |
| IPLV | 综合部分负荷性能系数 |
| APF | 全年能源消耗效率（多联机 / 空调器） |
| SCOP | 供热季节性能系数 |

| GB 21455-2025 | 房间空气调节器能效限定值及能效等级 |
