# 04 空调系统

> 定位：空调负责**夏季供冷与全年温湿度调节** —— 按输配介质分为全空气、全水、空气-水与制冷剂系统。

## 系统分类（按输配介质）

| 系统 | 介质 | 特点 |
| ---- | ---- | ---- |
| 全空气系统 | 风 | 集中处理 · 大空间 |
| 全水系统 | 水 | 风机盘管 · 灵活 |
| 空气-水系统 | 风 + 水 | 风机盘管 + 新风 · 最常用 |
| 制冷剂系统 | 制冷剂 | **VRV / 多联机** · 分户灵活 |

## 常见形式

| 形式 | 说明 |
| ---- | ---- |
| 中央空调 | 冷热源集中 · 风管 / 水管输配 |
| 风机盘管 + 新风 | 办公 / 酒店主流 |
| **VRV 多联机** | 一拖多 · 变频 · 分户计量 |
| 多联机 + 新风机 | 家用中央空调 |

## 关键

- 冷热源与末端匹配（见 [[05-冷热源与能源站|05]]）。
- 输配能耗大 → 变频、分区、按需供给。
- 与 [[03-通风与防排烟|03 通风]]、[[06-空气处理与净化|06 空气处理]] 协同。
