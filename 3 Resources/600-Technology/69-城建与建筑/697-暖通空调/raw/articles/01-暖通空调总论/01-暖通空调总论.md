# 01 暖通空调总论

> 定位：暖通空调补上「室外气候」与「室内舒适」之间的差距 —— 冬供暖 · 夏供冷 · 全年通风换气。它是建筑的**最大用能项**，与「双碳」直接挂钩。

## 什么是暖通空调

建筑**暖通空调（HVAC = Heating, Ventilation and Air Conditioning）**系统：为建筑提供供暖、通风、空调的综合系统。

> **UDC 697** — 建筑物的供暖、通风与空调。隶属 [[69-城建与建筑|69 城建与建筑]]。

## 系统四层

| 层 | 内容 | 关键 |
| -- | ---- | ---- |
| 冷热源 | 锅炉 / 热泵 / 冷水机组 / 多联机 | 能效（COP / IPLV / APF）· 制冷剂 |
| 输配 | 风管 · 水管 · 保温 · 阀门 | 输配能耗 · 水力平衡 |
| 末端 | 散热器 · 地暖 · 风机盘管 · 风口 | 舒适性（温度 / 风速 / 辐射） |
| 控制 | 温湿度 · 新风联动 · 群控 | 按需供给 · 节能运行 |

## 三条功能线

- **供暖**：散热器 / 地暖（辐射，JGJ 142）· 热源（锅炉 → **热泵**）· 分户计量。
- **通风**：自然通风 · 机械新风（含热回收）· **防排烟**（GB 51251）。
- **空调**：中央空调（全空气 / 风机盘管）· VRV 多联机 · 冷热源（离心 / 螺杆 / **磁悬浮**）。

## 一条总纲 + 一条底线

- 总纲：**GB 55015-2021** 建筑节能与可再生能源利用通用规范 · **GB 55016-2021** 建筑环境通用规范。
- 底线：**防排烟**（GB 51251-2017 + GB 55036-2022）—— 消防验收硬指标。

## 2026 三条位移

1. **热泵化** —— 空气源 / 地源热泵替代燃煤锅炉；工业超高温热泵。
2. **AI 接管** —— AI 高效机房 · AI 多联机（节能 15–30%）· 负荷预测与主动运维。
3. **能效与碳** —— GB 21455-2025（空调器能效）· 产品碳足迹量化 · 磁悬浮下沉数据中心。
