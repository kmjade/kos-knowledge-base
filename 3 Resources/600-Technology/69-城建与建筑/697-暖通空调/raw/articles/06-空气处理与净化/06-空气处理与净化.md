# 06 空气处理与净化

> 定位：空气处理把「混合空气」加工成「送风状态」—— 加热 / 冷却 / 加湿 / 除湿 / 过滤，是室内空气品质（IAQ）的保障。

## 空气处理过程

| 过程 | 说明 |
| ---- | ---- |
| 加热 / 冷却 | 盘管 · 表冷器 |
| 加湿 / 除湿 | 蒸汽 / 电极加湿 · 冷却除湿 |
| 过滤 | 初效 / 中效 / 高效（HEPA） |
| 混合 | 回风 + 新风 |

## 空气处理机组（AHU / PAU）

- **AHU**：组合式空调机组 · 处理回风 / 混风。
- **PAU**：新风机组 · 独立处理新风。
- 段组合：新风段 → 过滤段 → 表冷段 → 加热段 → 加湿段 → 风机段。

## 净化与洁净

| 级别 | 应用 |
| ---- | ---- |
| 一般净化 | 办公 / 住宅（G4 + F7–F9） |
| 洁净室 | 医药 / 电子 / 手术室（HEPA H13/H14） |
| 特殊 | 生物安全（负压）· 排风过滤 |

## 室内空气品质（IAQ）

- 新风量 · 换气次数 · 污染物浓度（CO₂ / VOC / 颗粒物）。
- 标准：GB 55016（建筑环境）· GB/T 18883（室内空气质量）· GB 50325（室内环境污染控制）。

## 规范

| 规范 | 说明 |
| ---- | ---- |

| GB 50325-2020 | 民用建筑工程室内环境污染控制标准 |
