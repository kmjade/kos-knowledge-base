# 02 供暖系统

> 定位：供暖是**冬季室内热舒适的保障** —— 由热源、管网与末端组成，正从「燃煤集中供热」转向「热泵 + 分户计量」。

## 末端形式

| 末端 | 说明 |
| ---- | ---- |
| 散热器（暖气片） | 对流 + 辐射 · 升温快 · 老式集中供暖 |
| **地板辐射采暖（地暖）** | 辐射为主 · 舒适 · 低温热水（JGJ 142） |
| 风机盘管 | 对流 · 冷暖两用（与空调共用） |
| 辐射板 / 毛细管 | 顶棚 / 墙面辐射 |

## 系统形式

| 形式 | 说明 |
| ---- | ---- |
| 集中供暖 | 市政热网 / 区域锅炉房 · 热计量 |
| 分户供暖 | 壁挂炉 · 空气源热泵 · 地源热泵 |
| 辐射供冷 | 地暖 + 供冷（JGJ 142 辐射供暖供冷） |

## 关键

- **供水温度**：地暖低温（35–45℃），散热器较高。
- **分户计量**：热计量表 · 温控阀 · 按需供热。
- **水力平衡**：避免近热远冷（见 [[07-暖通负荷与水力平衡|07]]）。
