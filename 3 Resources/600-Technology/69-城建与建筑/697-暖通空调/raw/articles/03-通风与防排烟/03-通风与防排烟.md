# 03 通风与防排烟

> 定位：通风解决**室内空气质量与热舒适**；防排烟是**消防安全的硬指标** —— 火灾时控制烟气、保障疏散。

## 通风

| 类型 | 说明 |
| ---- | ---- |
| 自然通风 | 热压 / 风压 · 开窗 · 中庭 · 通风器 |
| 机械通风 | 送风 / 排风 · 全空气系统 |
| **新风系统** | 引入室外新鲜空气 · 含**热回收**（全热 / 显热） |
| 局部排风 | 厨房 · 卫生间 · 实验室 |

## 防排烟（消防底线）

| 系统 | 说明 |
| ---- | ---- |
| 防烟 | 加压送风（楼梯间 / 前室）· 保持正压 |
| 排烟 | 机械排烟 / 自然排烟 · 排烟口 · 排烟风机 |
| 联动 | 火灾报警联动 · 补风 |

## 关键

- 新风量按人员密度 / 面积确定；热回收降低新风能耗。
- 防排烟是消防验收的**强制性**要求（GB 51251 + GB 55036）。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 51251-2017 | 建筑防烟排烟系统技术标准 |
| GB 55036-2022 | 消防设施通用规范（强制） |
| GB 55016-2021 | 建筑环境通用规范（强制 · 室内空气） |
| GB 50736-2012 | 供暖通风与空气调节设计规范 |
