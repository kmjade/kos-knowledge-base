# 08 暖通施工与调试

> 定位：暖通「三分设备、七分安装」—— 风管 / 水管施工质量与调试直接决定系统能否达标。

## 施工内容

| 分项 | 要点 |
| ---- | ---- |
| 风管制作安装 | 漏风量 · 严密性 · 支吊架 · 保温 |
| 水管安装 | 管道连接 · 坡度 · 支吊架 · 试压 |
| 设备安装 | 机组 · 水泵 · 风机 · 减振 |
| 风阀 / 水阀 | 调节阀 · 防火阀（联动） |

## 调试与检测

| 项 | 内容 |
| ---- | ---- |
| 水压试验 | 强度 + 严密性 |
| 风管漏风量 | 中压 / 高压系统检测 |
| 风量平衡 | 各风口风量调试 |
| 水系统 | 冲洗 · 平衡阀调试 |
| 系统联合调试 | 冷热源 + 末端 + 控制联动 |
| 消防联动 | 防排烟联动调试（GB 50166） |

## 质量与验收

隐蔽验收（管道 / 防火阀）· 系统调试报告 · 能效验收。

## 规范

| 规范 | 说明 |
| ---- | ---- |

| GB 50738-2011 | 通风与空调工程施工规范 |
| GB 50242 | 建筑给水排水及采暖工程施工质量验收规范 |
| GB 50166-2019 | 火灾自动报警系统施工及验收标准（联动） |
| GB 55032-2022 | 施工质量控制通用规范（强制） |
