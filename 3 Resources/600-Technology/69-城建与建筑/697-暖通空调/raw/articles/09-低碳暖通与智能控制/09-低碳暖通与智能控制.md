# 09 低碳暖通与智能控制

> 定位：暖通是建筑最大用能项 —— 减碳与智能化是行业主赛道。

## 减碳路径

| 路径 | 内容 |
| ---- | ---- |
| 热泵化 | 空气源 / 地源 / 水源热泵替代燃煤锅炉 |
| 电气化 | 供暖电气化 · 与可再生电力耦合（光储直柔） |
| 高效设备 | 磁悬浮机组 · 变频 · 一级能效 |
| 系统优化 | 大温差小流量 · 分区 · 按需供给 |
| 能量回收 | 新风热回收 · 余热回收 |
| 冷媒替代 | 低 GWP 制冷剂 |

## 智能控制

| 技术 | 应用 |
| ---- | ---- |
| AI 高效机房 | 冷源群控优化（系统节能 15–30%） |
| 负荷预测 | 提前调温 · 削峰填谷 |
| 数字孪生 | 系统建模 · 故障诊断 · 主动运维 |
| 传感 / IoT | 温湿度 · CO₂ · 阀门状态 |
| 群控 / 楼控（BA） | 暖通与建筑设备联动 |

## 2026 三线

1. **热泵化** —— 政策驱动（热泵高质量发展行动方案），工业超高温热泵。
2. **AI 接管** —— AI 多联机 · 高效机房 · 主动运维。
3. **碳足迹量化** —— 暖通产品碳足迹标准起步 · 数据中心液冷。
