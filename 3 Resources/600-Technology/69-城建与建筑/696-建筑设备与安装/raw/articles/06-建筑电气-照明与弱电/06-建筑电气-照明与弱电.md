# 06 建筑电气-照明与弱电

> 定位：照明把电能变成「可用的光」（照度 · 眩光 · 能效），弱电 / 智能化把建筑变成「会感知、能联动」的系统。

## 照明

| 要点 | 内容 |
| ---- | ---- |
| 光源 | LED 主流 · 高效节能 |
| 布灯 | 照度 · 均匀度 · 眩光（UGR） |
| 控制 | 分区 · 感应 · 调光（无主灯趋势） |
| 应急 | 应急照明 · 疏散指示 |

## 弱电 / 智能化

| 系统 | 说明 |
| ---- | ---- |
| 综合布线 | 数据 / 语音 / 视频 |
| BAS / BA | 楼宇自动化（暖通 · 电气 · 给排水联动） |
| 安防 | 视频监控 · 门禁 · 入侵报警 |
| 消防报警 | 火灾报警与联动（GB 50166） |
| 智能家居 | 家庭场景 · 互联 |

## 关键

- 照度标准与照明功率密度（LPD）限值（节能）。
- 强弱电分设 · 屏蔽 · 接地。
- 智能化与暖通 / 电梯 / 消防联动（[[697-暖通空调|697]]）。

## 规范

| 规范 | 说明 |
| ---- | ---- |

| GB 50314-2015 | 智能建筑设计标准 |
| GB 50303-2015 | 建筑电气工程施工质量验收规范 |
| GB 50166-2019 | 火灾自动报警系统施工及验收标准 |
| GB/T 50034-2024 | 建筑照明设计标准 |
