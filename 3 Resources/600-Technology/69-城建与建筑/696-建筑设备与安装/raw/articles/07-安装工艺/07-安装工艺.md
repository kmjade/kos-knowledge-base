# 07 安装工艺

> 定位：安装工艺是 MEP 的「手艺」一侧 —— 把图纸上的系统变成现场可运行的实体。质量靠「**连接 · 支撑 · 试验**」三件套兜底。

## 四个工种

| 工种 | 对象 | 核心技能 |
| ---- | ---- | ---- |
| 管道工 Pipe fitter | 管道系统 | 连接（螺纹 / 焊接 / 沟槽 / 卡压 / 热熔）· 支吊架 · 试压 |
| 电工 Electrician | 强电 / 弱电 | 配管配线 · 桥架 · 接地 · 送电调试 |
| 金属工 Metal worker | 风管 / 支吊架 / 金属构件 | 下料 · 焊接 · 制作安装 |
| 排水工 Drainlayer | 排水 / 室外管网 | 坡度 · 检查井 · 闭水 / 闭气 |

## 通用工艺主线：连接 · 支撑 · 试验

- **连接**（按管材分）：螺纹 · 焊接 · 沟槽（卡箍）· **卡压 / 环压**（薄壁不锈钢）· 热熔（PPR / PB）。
- **支撑**：支吊架（固定 / 活动 / **抗震**）。
- **试验**：给水——强度 + 严密性水压试验；排水——灌水 / 通球；电气——绝缘 / 接地电阻；风管——漏风量。

## 2026：从「现场加工」到「工厂预制 + 现场装配」

1. **装配式机电（MiMEP / DfMA）** —— 管道 / 支吊架 / 机房模块工厂预制，现场拼装。
2. **BIM 管线综合深化** —— 碰撞 → 预留预埋 → 净高 → 综合支吊架（LOD400）。
3. **免焊连接普及** —— 薄壁不锈钢卡压 / 沟槽取代焊接。

## 安全与合规

- **特种作业持证**：电工 · 焊工 · 高处 · 有限空间。
- **强制性通用规范**：[[GB 55032-2022|GB 55032-2022]]（施工质量）+ 各专业 550xx。
