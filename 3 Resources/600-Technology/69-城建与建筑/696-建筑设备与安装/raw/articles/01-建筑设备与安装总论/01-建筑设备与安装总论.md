# 01 建筑设备与安装总论

> 定位：建筑设备与安装是建筑的**「血脉与神经」** —— 让建筑可居、可用、可运行。即通常所称 **MEP（Mechanical / Electrical / Plumbing）**。

## 什么是建筑设备与安装

建筑内的**设备系统与安装工程** —— 给排水、燃气、蒸汽、电气（强电 / 弱电）等。

> **UDC 696** — 建筑物内的设备、服务与安装（Equipment, services, installations in buildings：sanitary, gas, steam, electrical）。隶属 [[69-城建与建筑|69 城建与建筑]]。

## 三专业（MEP）

| 专业 | UDC | 内容 |
| ---- | :--: | ---- |
| 给排水 | 696.1 | 给水 · 排水 · 雨水 · 消防水 |
| 建筑电气 | 696.3 | 供配电 · 照明 · 弱电 / 智能化 · 防雷接地 |
| 暖通（HVAC） | 697 | 供暖 · 通风 · 空调（另见 [[697-暖通空调|697 暖通空调]]） |

## 系统四层

| 层 | 内容 |
| ---- | ---- |
| 源 | 市政给水 / 电源 / 燃气 / 热源 |
| 输配 | 管道 · 桥架 · 风管 · 支吊架 |
| 末端 | 用水器具 · 灯具 / 插座 · 风口 |
| 控制 | 计量 · 监控 · 智能化 |

## 主线：连接 · 支撑 · 试验

- **连接**：螺纹 / 焊接 / 沟槽 / 卡压 / 热熔。
- **支撑**：支吊架（固定 / 活动 / 抗震）。
- **试验**：水压 / 灌水通球 / 绝缘接地 / 漏风量。

## 一条总纲：强制性「通用规范」

- **GB 55020-2021** 给水排水与节水 · **GB 55024-2022** 建筑电气与智能化 · **GB 55009-2021** 燃气 · **GB 55010-2021** 供热 · **GB 55036-2022** 消防设施 · **GB 55032-2022** 施工质量。
- 「通用规范」体系全面接管旧强条（与 [[697-暖通空调|697]] / [[698-装饰装修|698]] 一脉）。

## 2026 三条位移

1. **装配式机电（MiMEP / DfMA）** —— 管道 / 支吊架 / 机房模块工厂预制。
2. **BIM 管线综合深化** —— 碰撞 → 净高 → 综合支吊架（LOD400）。
3. **免焊连接普及 + 光储直柔** —— 薄壁不锈钢卡压；建筑电气向「能源节点」转型。
