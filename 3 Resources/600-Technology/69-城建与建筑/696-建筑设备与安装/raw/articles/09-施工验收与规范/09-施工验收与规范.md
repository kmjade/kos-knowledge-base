# 09 施工验收与规范

> 定位：MEP 的**收口与交付** —— 以强制性「通用规范」体系为准绳，完成隐蔽验收、系统调试与竣工验收。

## 验收主线

```
隐蔽验收（管道 / 桥架 / 防火封堵）→ 单机试运转 → 系统联动调试 → 分部 / 竣工验收
```

| 分项 | 验收要点 |
| ---- | ---- |
| 给排水 | 水压 / 灌水 / 通球试验 · 管道坡度 |
| 电气 | 绝缘 / 接地电阻 · 送电试运行 |
| 通风空调 | 漏风量 · 风量 / 冷热调试 |
| 消防 | 报警联动 · 防排烟联动 · 消防水试压 |
| 燃气 | 严密性试验 · 防爆要求 |

## 强制性「通用规范」体系

| 规范 | 专业 |
| ---- | ---- |
| GB 55020-2021 | 给水排水与节水 |
| GB 55024-2022 | 建筑电气与智能化 |
| GB 55009-2021 | 燃气工程 |
| GB 55010-2021 | 供热工程 |
| GB 55036-2022 | 消防设施 |
| GB 55032-2022 | 施工质量控制 |

## 2026 三条位移

1. **数字化验收** —— 数据留存 · 竣工即交付可运维 BIM。
2. **装配式机电验收** —— 模块化预制件的进场与拼装验收。
3. **能效与碳** —— 系统能效验收 · 碳足迹。
