# 02 建筑给水系统

> 定位：给水是 MEP「水」一侧的入口 —— 核心是**水量 · 水压 · 水质**三点，外加**防回流污染**一条安全线。

## 子系统

| 子系统 | 关键 |
| ---- | ---- |
| 生活 / 生产给水 | 水量 · 水压 · 分区供水 |
| **二次供水** | 无负压 / 变频 + 蓄水池；智慧水务（CJJ 140） |
| 热水供应 | 集中 / 分户 · 循环 |

## 管材换挡

镀锌钢管 / PVC → **薄壁不锈钢管**（DN≤80 优先）· PPR · PE · 铜管；直饮水入户。

## 关键控制

- **水质**：防回流污染 · 管道材料 · 消毒。
- **水压**：分区 · 变频恒压 · 防超压。
- **试验**：强度 + 严密性**水压试验**。

| ---- | ---- |

| CJJ 140-2010 | 二次供水工程技术规程 |
| GB 50974-2014 | 消防给水及消火栓系统技术规范 |
