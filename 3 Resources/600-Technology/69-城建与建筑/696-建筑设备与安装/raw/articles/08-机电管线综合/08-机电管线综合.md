# 08 机电管线综合

> 定位：MEP 的「收口」一侧 —— 把水 / 气 / 电三条系统在**有限空间**里排得下、撑得住、测得准。三大命题：**排布（管线综合）· 承重（支吊架）· 验证（试压与调试）**。

## 管线综合：排布原则

| 原则 | 内容 |
| ---- | ---- |
| 优先级 | 重力管（有坡度）先排 · 大管优先 |
| 避让 | **小管让大管 · 有压让无压** |
| 分层 | 电在上 / 风管单独 · 桥架在水管上方 |
| 空间 | 检修 ≥300×300mm · 净高控制 |

工具：**BIM 深化**（GB/T 51235 §5.5 机电深化设计）—— 碰撞检查 → 预留预埋 → 净空控制 → 支吊架选型及荷载验算；模型细度 ≥ LOD400。

## 支吊架：承重 + 抗震

- 三类：**固定 · 活动 · 抗震**；**综合支吊架**（多管共用）省材 · 整齐，须受力计算。
- 规范：GB/T 17116 · **GB 50981-2014**（机电抗震）· **T/CECS 420-2022**（抗震支吊架安装及验收）· CJ/T 476（产品）。
- 抗震要点：斜撑 ≥30° · 后扩底锚栓（非膨胀）· 构件不得现场加工。

## 试压与调试：验证「装对了」

| 系统 | 验证 |
| ---- | ---- |
| 给水 / 消防 / 采暖 | 水压试验：强度 + 严密性 |
| 排水 | 灌水 · 通球 · 闭气 |
| 通风空调 | 漏风量 · 风量 / 冷热调试 |
| 电气 | 绝缘 · 接地电阻 · 送电 |
| 消防 | 火灾自动报警**联动调试**（GB 50166-2019） |

## 2026：综合 → 数字前置

1. **BIM 深化前置** —— 净高 / 碰撞 / 支吊架在模型里解决，现场只装配。
2. **装配式综合支吊架 + 机房模块**（MiMEP）。
3. **调试数字化** —— 系统联动 + 数据留存。
