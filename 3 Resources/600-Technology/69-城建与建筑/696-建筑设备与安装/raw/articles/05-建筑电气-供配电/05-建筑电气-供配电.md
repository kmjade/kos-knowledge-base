# 05 建筑电气-供配电

> 定位：供配电是建筑的**动力来源** —— 从市电引入到末端配电，同时承担防雷接地的安全职责。

## 系统链路

```
城市电网 → 引入 → 变配电所（变压器 / 高低压柜）→ 低压配电 → 末端（照明 / 动力 / 插座）
```

| 环节 | 关键 |
| ---- | ---- |
| 负荷分级 | 一级 / 二级 / 三级 → 供电可靠性 |
| 变配电 | 变压器 · 高低压开关柜 · 母线 |
| 低压配电 | 配电箱 · 回路 · 保护 |
| 应急电源 | 柴油发电机 · EPS / UPS |

## 防雷与接地

| 项 | 内容 |
| ---- | ---- |
| 接闪 | 避雷针 / 带 / 网 |
| 引下 | 引下线 |
| 接地 | 等电位 · 接地网 · 接地电阻 |

## 2026：从「耗能末端」到「能源节点」

1. **光储直柔（PEDF）**：光伏 + 储能 + 直流 + 柔性 —— 建筑新型配电系统。
2. **建筑直流配电**：T/CABEE 030-2026 民用建筑直流配电设计标准。
3. **零碳建筑电气**：微电网 · 储能 · 充电桩 · 智能配电。
