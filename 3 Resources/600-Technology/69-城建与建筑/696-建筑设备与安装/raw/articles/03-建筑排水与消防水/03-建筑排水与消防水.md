# 03 建筑排水与消防水

> 定位：排水讲**排放通畅**（坡度 · 水封 · 通气），消防水讲**可靠**（强条最密的一支）。

## 排水系统

| 子系统 | 关键 |
| ---- | ---- |
| 生活污水 / 废水 | 坡度 · 检查口 · 通气管 |
| 雨水 | 重现期 · 溢流 · 屋面雨水口 |
| **同层排水** | 降板 / 墙排 · 减少穿楼板 · 易检修（CJJ 232） |

> **水封是命门**：存水弯水封 ≥50mm · 通气防虹吸。

## 消防水系统

| 系统 | 规范 |
| ---- | ---- |
| 消火栓 | GB 50974-2014 |
| 自动喷水 | GB 50084-2017（设计）· GB 50261-2017（施工验收） |
| 强条总纲 | **GB 55036-2022** 消防设施通用规范 |

- 组件：消防水泵接合器 · 高位消防水箱 · 水泵房 · 消防水池。

## 关键控制

- 排水：灌水 / 通球 / 闭气试验。
- 消防水：强度 + 严密性水压试验 · 系统联动调试。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 55020-2021 | 建筑给水排水与节水通用规范（强制） |

| GB 50974-2014 | 消防给水及消火栓系统技术规范 |
| GB 50084-2017 | 自动喷水灭火系统设计规范 |
| CJJ 232-2016 | 建筑同层排水工程技术规程 |
