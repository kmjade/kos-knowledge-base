# 04 燃气与供热管网

> 定位：燃气（可燃 · 防爆）与蒸汽（带压 · 热应力）—— 共性：**带压 + 危险介质**，安全第一。

## 燃气

- **三防**：防泄漏 · 防积聚 · 防点火（报警 + 通风 + 防爆电气）。
- 系统链路：门站 → 输配管网 → 引入管 → 室内管 → 用气设备。
- 材料 / 连接：不锈钢波纹软管 · 燃气专用管 · 螺纹 / 焊接。
- 2026：全国城镇**燃气安全专项整治**（管网更新 + 智能监测）。

## 蒸汽 / 供热管网

- 供热管网：设计压力 ≤2.5MPa、热水 ≤200℃ / 蒸汽 ≤350℃（CJJ/T 34-2022）。
- 三大构造难点：**热补偿 · 保温 · 疏水**；支架分固定 / 活动。
- 压力管道属**特种设备**（GB/T 20801 · TSG 监察）。

## 一条总纲：强制性「通用规范」

- **GB 55009-2021**《燃气工程项目规范》+ **GB 55010-2021**《供热工程项目规范》（均全文强制）。
- 与 [[697-暖通空调|697 暖通空调]] 的冷热源 / 供热在本库与 [[697-暖通空调|697]] 交叠。
