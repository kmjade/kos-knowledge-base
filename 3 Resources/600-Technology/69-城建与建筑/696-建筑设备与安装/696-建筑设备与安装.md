## 类目

建筑内的**设备系统与安装工程** —— 给排水、燃气、蒸汽、电气（强电/弱电）等，即通常所称 **MEP（Mechanical / Electrical / Plumbing）**。

## 内容要点

| 专业                   | 内容                                                                    |
| -------------------- | --------------------------------------------------------------------- |
| 给排水（Sanitary）        | 生活给水（二次供水）· 排水（同层排水）· 雨水 · 消防水（消火栓 / 喷淋）· 管材（薄壁不锈钢）                   |
| 燃气 / 蒸汽（Gas & Steam） | 燃气管道（防爆安全）· 蒸汽 / 供热管网（热补偿 · 保温 · 疏水）· 压力管道（特种设备）                      |
| 建筑电气（Electrical）     | 供配电（≤35kV）· 照明 · 弱电 / 智能化 · 防雷接地 · 光储直柔                               |
| 安装工艺                 | 管道工（Pipe fitter）· 电工（Electrician）· 金属工（Metal worker）· 排水工（Drainlayer）＋ 连接工艺（卡压 / 沟槽 / 焊接）· 支吊架 · 试压调试 |
| 综合                   | 管线综合（BIM 深化）· 支吊架（含抗震）· 试压与调试                                                    |

## 给排水研讨（2026-09-28）

> 定位：696 MEP 的「水」一侧 —— 生活给水 · 排水 · 雨水 · 消防水。核心是**水质 · 水压 · 水量**三点，外加**排放通畅**与**消防可靠**两条安全线。

**一、四条子系统**

| 子系统 | 内容 | 关键 |
| ------ | ---- | ---- |
| 给水 | 生活 / 生产给水 · 二次供水 | 水量 · 水压 · 水质 · 防回流污染 |
| 排水 | 生活污水 / 废水 · 通气 | 坡度 · 存水弯水封 ≥50mm · 通气防虹吸 |
| 雨水 | 屋面雨水 | 重现期 · 溢流 |
| 消防水 | 消火栓 · 自动喷水 · 灭火器 | 可靠性（强条最密） |

**二、一条总纲：强制性「通用规范」接管**

- **GB 55020-2021**《建筑给水排水与节水通用规范》（2022-04-01 实施）—— 全文强制，废止 GB 50015-2019 · GB 50242-2002 等一批旧强条。
- **GB 55036-2022**《消防设施通用规范》—— 接管消防水系统强条。

> 与 698 的 [[GB 55032-2022]] 同构：**强制性「通用规范」体系**正取代分散强条。

**三、给水：从「能出水」到「水质安全 + 节水」**

- 管材换挡：镀锌钢管 / PVC → **薄壁不锈钢管**（DN≤80 优先）、PPR、PE、铜管；直饮水入户。
- 二次供水：**无负压 / 变频** + 智慧水务（CJJ 140）。
- 水压分区 · 防回流污染 · 管道压力试验。

**四、排水：水封与通气是命门**

- 存水弯水封 ≥50mm；通气管防虹吸；检查口。
- **同层排水**（CJJ 232-2016）：降板 / 墙排，减少穿楼板、易检修。

**五、消防水：强条最密的一支**

- 消火栓 GB 50974-2014；自动喷水 GB 50084-2017（设计）+ GB 50261-2017（施工验收）；GB 55036-2022（强条）。
- 消防水泵接合器 · 高位消防水箱 · 水泵房。

**六、2026 三个位移**

1. **管材**：薄壁不锈钢成市政供水「黄金标准」（寿命 >70 年 · 抑菌 · 低碳）。
2. **二次供水智能化**：无负压 + 边缘计算 + AI 调度；老旧管网改造刚需。
3. **装配与节水**：装配式机电（T/CAIEC 298-2026）+ 中水 / 雨水回用。

## 燃气 / 蒸汽研讨（2026-09-28）

> 定位：696 的「气 / 热」一侧 —— 燃气（可燃 · 防爆）与蒸汽（带压 · 热应力）。共性：**带压 + 危险介质**，安全第一。

**一、燃气：安全是唯一主线**

- 三防：**防泄漏 · 防积聚 · 防点火**（报警 + 通风 + 防爆电气）。
- 系统链路：门站 → 输配管网 → 引入管 → 室内管 → 用气设备。
- 材料 / 连接：不锈钢波纹软管 · 燃气专用管 · 螺纹 / 焊接。

**二、蒸汽 / 供热：压力 + 热应力**

- 供热管网：设计压力 ≤2.5MPa、热水 ≤200℃ / 蒸汽 ≤350℃（CJJ/T 34-2022）。
- 三大构造难点：**热补偿 · 保温 · 疏水**；支架分固定 / 活动。
- 压力管道属**特种设备**（GB/T 20801 · TSG 监察）。

**三、一条总纲：强制性「通用规范」**

- **GB 55009-2021**《燃气工程项目规范》+ **GB 55010-2021**《供热工程项目规范》（均 2022-01-01 实施）—— 全文强制。

> 与 [[GB 55032-2022]] · GB 55020-2021 · GB 55024-2022 一脉：**「通用规范」体系**全面接管旧强条。

**四、2026 位移**

1. 全国城镇**燃气安全专项整治** → 管网更新 + 智能监测。
2. 燃气输配验收**升为国标**：GB/T 51455-2023 代 CJJ 33-2005。
3. 供热 CJJ/T 34-2022 更新；清洁供热 / 余热利用。

## 建筑电气研讨（2026-09-28）

> 定位：696 的「电」一侧 —— 供配电 · 照明 · 弱电（智能化）· 防雷接地。它既是**动力**，也是今天**能源转型的载体**（光储直柔）。

**一、四条主线**

| 主线 | 内容 | 关键 |
| ---- | ---- | ---- |
| 供配电 | 变配电 · 低压配电 | 负荷分级 · 供电可靠性 · ≤35kV |
| 照明 | 光源 · 布灯 | 照度 · 眩光 · 能效 |
| 弱电 / 智能化 | 综合布线 · BA · 安防 | 智能建筑 |
| 防雷接地 | 接闪 · 引下 · 接地 | 等电位 |

**二、总纲**：**GB 55024-2022**《建筑电气与智能化通用规范》（2022-10-01，强制）—— 废止 GB 50303-2015 等一批强条；适用 ≤35kV。

**三、2026：从「耗能末端」到「能源节点」**

1. **光储直柔（PEDF）**：光伏 + 储能 + 直流 + 柔性 —— 建筑新型配电系统（碳中和方法论）。
2. **建筑直流配电**：T/CABEE 030-2026《民用建筑直流配电设计标准》（2026-06-01）；照明标准增直流配电内容。
3. **零碳建筑电气**：25DX016-1 图集；微电网 · 储能 · 充电桩 · 智能配电。

| GB 50314-2015   | 智能建筑设计标准 |
| GB 50057-2010   | 建筑物防雷设计规范 |

## 安装工艺研讨（2026-09-28）

> 定位：696 的「手艺」一侧 —— 把图纸上的系统变成现场可运行的实体。四个工种 + 通用施工工艺；质量靠「**连接 · 支撑 · 试验**」三件套兜底。

**一、四个工种**

| 工种 | 对象 | 核心技能 |
| ---- | ---- | -------- |
| 管道工 Pipe fitter | 管道系统 | 连接（螺纹 / 焊接 / 沟槽 / 卡压 / 热熔）· 支吊架 · 试压 |
| 电工 Electrician | 强电 / 弱电 | 配管配线 · 桥架 · 接地 · 送电调试 |
| 金属工 Metal worker | 风管 / 支吊架 / 金属构件 | 下料 · 焊接 · 制作安装 |
| 排水工 Drainlayer | 排水 / 室外管网 | 坡度 · 检查井 · 闭水 / 闭气 |

**二、通用工艺主线：连接 · 支撑 · 试验**

- **连接**（按管材分）：螺纹 · 焊接 · 沟槽（卡箍）· **卡压 / 环压**（薄壁不锈钢）· 热熔（PPR / PB）。
- **支撑**：支吊架（固定 / 活动 / **抗震**）—— GB/T 17116 · GB 50981 · T/CECS 420-2022。
- **试验**：给水——强度 + 严密性水压试验；排水——灌水 / 通球；电气——绝缘 / 接地电阻；风管——漏风量。

**三、2026：从「现场加工」到「工厂预制 + 现场装配」**

1. **装配式机电（MiMEP / DfMA）**：管道 / 支吊架 / **机房模块**工厂预制，现场拼装；实测现场安装时间可缩短约 60%。
2. **BIM 管线综合深化**：碰撞检查 → 预留预埋 → 净高优化 → 综合支吊架；模型细度 ≥ **LOD400**（GB/T 51235）。
3. **免焊连接普及**：薄壁不锈钢**卡压 / 沟槽**取代焊接，降火险、提效率。

**四、安全与合规**

- **特种作业持证**：电工 · 焊工 · 高处 · 有限空间。
- **强制性通用规范**：[[GB 55032-2022]]（施工质量）+ 各专业 550xx（给排水 / 燃气 / 供热 / 电气 / 消防）。
- 隐蔽验收 · 系统调试 · 成品保护。

## 综合研讨（2026-09-28）

> 定位：696 的「收口」一侧 —— 把水 / 气 / 电三条系统在**有限空间**里排得下、撑得住、测得准。三大命题：**排布（管线综合）· 承重（支吊架）· 验证（试压与调试）**。

**一、管线综合：排布原则**

| 原则 | 内容 |
| ---- | ---- |
| 优先级 | 重力管（有坡度）先排 · 大管优先 |
| 避让 | **小管让大管 · 有压让无压** |
| 分层 | 电在上 / 风管单独 · 桥架在水管上方 |
| 空间 | 检修 ≥300×300mm · 净高控制（车道 2500 / 货车 2800 / 车位 2300 mm） |

工具：**BIM 深化**（GB/T 51235 §5.5 机电深化设计）—— 碰撞检查 → 预留预埋 → 净空控制 → 支吊架选型及荷载验算；模型细度 ≥ LOD400。

**二、支吊架：承重 + 抗震**

- 三类：**固定 · 活动 · 抗震**；**综合支吊架**（多管共用）省材 · 整齐，须受力计算。
- 规范：GB/T 17116 · **GB 50981-2014**（机电抗震）· **T/CECS 420-2022**（抗震支吊架安装及验收）· CJ/T 476（产品）。
- 抗震要点：斜撑 ≥30°、后扩底锚栓（非膨胀）、构件不得现场加工。

**三、试压与调试：验证「装对了」**

| 系统 | 验证 |
| ---- | ---- |
| 给水 / 消防 / 采暖 | 水压试验：强度 + 严密性 |
| 排水 | 灌水 · 通球 · 闭气 |
| 通风空调 | 漏风量（GB 50243）· 风量 / 冷热调试 |
| 电气 | 绝缘 · 接地电阻 · 送电 |
| 消防 | 火灾自动报警**联动调试**（GB 50166-2019） |

**四、2026：综合 → 数字前置**

1. **BIM 深化前置**：净高 / 碰撞 / 支吊架在模型里解决，现场只装配。
2. **装配式综合支吊架 + 机房模块**（MiMEP）。
3. 调试走向**数字化**（系统联动 + 数据留存）。
