> 定位：69 子库的「物质基础」层 —— 一切构件、工艺的上游。本类只收「作为建材使用」的品种 / 性能 / 选用；制造归 66/67。

**二、主线：以标准定性能**

- 每个品种 = **产品标准**（强度 / 耐久 / 环保指标）+ **应用技术规范**（怎么用）。
- 强条转向：**GB 550xx 通用规范**接管材料相关强制要求（GB 55015 节能 · GB 55016 环境 · GB 55005 木结构）。

**三、2026 位移**

1. **低碳化**：水泥新国标收紧（GB 175-2023 增铬(VI) / 放射性限量）· 低碳水泥 · 再生骨料。
2. **高性能化**：**UHPC**（抗压达普通混凝土 5–8 倍）· 高强钢筋 HRB600 · 自密实混凝土。
3. **工程木复兴**：胶合木 / **CLT** 正交胶合木进入高层与装配式。

**四、标准核实（本轮）**

## 胶凝材料研讨（2026-09-28）

> 定位：胶凝材料 = 能把散粒（骨料 / 纤维）**胶结成整体**的「胶」，是混凝土 / 砂浆 / 抹灰的基质。它分两族：**水硬性**（水泥 · 遇水硬化，水中不散）与**气硬性**（石灰 · 石膏，只在空气中硬化）。

**一、两族对照（关键区分）**

| 族 | 代表 | 硬化条件 | 典型用途 |
| -- | ---- | -------- | -------- |
| 水硬性 | 硅酸盐水泥系列 | 水化 → 潮湿 / 水中持续硬化 | 混凝土 · 结构 |
| 气硬性 | 石灰 · 石膏 · 水玻璃 | 干燥 + 碳化（只在空气） | 抹灰 · 砌筑 · 室内 |

> 一句话记：**水泥「不怕水」；石灰 / 石膏「怕水」**。

**二、水泥：六大通用 + 特性**

- **六大通用硅酸盐水泥**：硅酸盐 · 普通硅酸盐 · 矿渣 · 火山灰质 · 粉煤灰 · 复合。
- 关键指标：强度等级（42.5 / 52.5…）· 凝结时间 · **安定性**（游离 CaO / MgO）。
- **[[GB 175-2023]]** 收紧：删复合 32.5、增**水溶性铬(VI)** 与**放射性核素**限量、改细度。
- **特性水泥**：抗硫酸盐 · 中 / 低热 · 快硬 · 膨胀 · 白色 · 道路 · 铁铝酸盐。

**三、石灰与石膏**

- **石灰**：生石灰 CaO →（熟化）→ 熟石灰 Ca(OH)₂ → 石灰膏；**须充分熟化**（底层 ≥15d / 面层 ≥30d），否则「爆灰」。
- **石膏**：建筑石膏（β 半水）· 高强石膏（α）· 硬石膏；**凝结快、微膨胀** —— 抹灰石膏 · 石膏基自流平 · 装配式。

**四、外加剂：混凝土的「第五组分」**

- GB 8076 混凝土外加剂 · GB 50119 应用规范：减水 / 缓凝 / 早强 / 引气 / 防水。
- 水泥与外加剂的**相容性**决定实际性能。

**五、2026：低碳是唯一主线**

1. **熟料替代**：矿渣 / 粉煤灰 / 石灰石 / 固废基。
2. **碱激发 / 地聚物（AACM）**：无熟料、无高温，碳排约为波特兰水泥的 **1/5–1/10**；团标先行（T/CIECCPA 138-2026 煤基固废地质聚合物）。
3. 其他颠覆路线：**LC3**（石灰石煅烧黏土，熟料替代 >50%）· **铁铝酸盐水泥**（低碳 · 海工）· 碳捕集（CCUS）。
4. 瓶颈：成本 + **缺产品标准 / 耐久性评测体系**。

## 混凝土研讨（2026-09-28）

> 定位：混凝土 = **胶凝材料 + 骨料 + 水 + 外加剂 / 掺合料** 的混合物。它是 69 的「体积主体」—— 建筑绝大多数的重量与碳排都压在它身上。

**一、五组分**

| 组分 | 作用 | 代表 |
| ---- | ---- | ---- |
| 胶凝材料 | 胶结 | 水泥 · 掺合料（粉煤灰 / 矿渣粉 / 硅灰） |
| 骨料 | 骨架 | 砂 · 石 · 再生骨料 |
| 水 | 水化 + 和易 | — |
| 外加剂 | 调性能 | 减水 / 缓凝 / 早强（GB 8076） |

**二、分类维度**

- 按强度：普通（C15–C60）· 高强（≥C60）· 超高强（UHPC）。
- 按性能：高性能（HPC）· 自密实（SCC）· 纤维增强 · 清水 · 透水。
- 按用途：结构 · 道路 · 水工 · 大体积 · 装饰 · 喷射。

**三、三项关键指标**

- **强度等级 C**：标准立方体抗压强度标准值（GB/T 50107 检验评定）。
- **和易性**：坍落度 / 扩展度 —— 决定可施工性。
- **耐久性**：抗渗 · 抗冻 · 抗碳化 · 氯离子渗透 —— 决定寿命。

**四、工艺链路**

`配合比设计 → 搅拌 → 运输 → 浇筑 → 振捣 → 养护`

- 规范：GB 50666（施工）· GB 50204（验收）· GB 50010（设计）。
- **养护**是强度与耐久的关键环节；大体积混凝土控温差防裂。

**五、2026 三位移**

1. **UHPC 落地**：抗压达普通混凝土 5–8 倍 → 减截面 · 增面积；**JC/T 60034-2026**（UHPC 非承重构件，2026-09-01）。
2. **工业化**：预制 / 装配式 · 自密实（SCC）· 高强钢筋配合。
3. **低碳化**：低碳混凝土（熟料替代 · 碳捕集）· **再生骨料**（GB/T 25177）· **3D 打印混凝土**（T/CCPA 34-2022；低碳 UHPC 可减碳约 45%）。

## 砂浆研讨（2026-09-28）

> 砂浆 = 胶凝材料 + 细骨料 + 水。它是「薄层胶结」—— 用在砌缝（砌筑）、墙面（抹灰）、地面、粘结。

- 按用途：砌筑 · 抹灰 · 地面 · 防水 · 粘结（瓷砖胶）· 装饰。
- 按胶凝材料：水泥 · 水泥混合 · 石灰 · 石膏 · 聚合物。
- 关键：强度等级 **M**（Mb / Ms / Ma 分族）· 保水性 · 粘结强度 · 稠度。
- **主线：现场拌制 → 预拌**（干混 / 湿拌）—— 质量稳定、环保（GB/T 25181-2019）。
- 特种砂浆：瓷砖胶（JC/T 547）· 腻子（JG/T 298）· 抹灰石膏（GB/T 28627）· 自流平 · 防水砂浆。

## 钢材研讨（2026-09-28）

> 建筑钢材 = 强度高、可焊、可工业化 → 钢结构 + 钢筋混凝土两大「骨」之一。

- 品种：钢筋（光圆 / 带肋 / 预应力）· 型钢（H 型 / 工字 / 角钢）· 钢板 · 钢管 · 钢丝绳。
- 牌号体系：
  - 钢筋：HPB300（光圆）· HRB400/500/600（带肋）· HRB400E（抗震）。
  - 结构钢：Q235 · **Q355**（代 Q345）· Q390 / Q460（高强）。
- 关键：屈服强度 · 抗拉强度 · 伸长率 · **碳当量**（可焊性）· 冲击韧性。
- 2026：**高强钢筋 HRB600** · 高强钢（Q460+）· 钢结构装配式 · 耐候钢。

## 砌体材料研讨（2026-09-28）

> 砌体 = 块材 + 砂浆砌筑的「离散整体」。材料侧看块材（墙材）。

- 品种：烧结砖 · 蒸压砖（灰砂 / 粉煤灰）· 混凝土砌块 · **蒸压加气 ALC** · 石材。
- 关键：强度 **MU** · 吸水率 · 抗冻 · 干燥收缩 · 传热系数。
- 分类维度（GB/T 11968-2020）：ALC 按尺寸偏差分 I 型（薄灰缝）/ E 型（厚灰缝）；强度 A1.5–A5.0；干密度 B03–B07。
- **三大政策线**：禁实（禁烧结黏土实心砖）· 轻质高强 · 节能（自保温）。
- 2026：**ALC 精准砌块免抹灰** · 装配式墙板替代现场砌筑。

## 玻璃研讨（2026-09-28）

> 玻璃 = 透明 · 脆性 · 可钢化/夹层/中空 —— 建筑「透明围护」的核心，也是最大的热工薄弱点。

- 品种：平板玻璃（浮法）· 钢化（安全）· 夹层（安全）· 中空（节能）· Low-E 镀膜 · 防火玻璃 · 光伏玻璃（BIPV）。
- 两条主线：
  - **安全**：钢化 / 夹层；屋面 / 地板玻璃**强制夹层**（JGJ 113 强条）。
  - **节能**：中空 + Low-E → 传热系数 K 降低（GB 55015 节能）。
- 2026：**三玻两腔** · **真空玻璃** · BIPV 光伏玻璃 · 大板玻璃。

## 功能材料研讨（2026-09-28）

> 功能材料 = 不承重、但决定建筑「好不好用 / 安不安全 / 省不省能」的材料 —— 防水 · 保温 · 密封 · 防火 · 隔声。

- **防水**：卷材 / 涂料；等级 + 设防道数（GB 50108 地下 · GB 50345 屋面）。
- **保温**：岩棉 / 聚苯板（EPS / XPS）/ 聚氨酯 / 气凝胶；核心指标 **导热系数 λ** + **燃烧性能**（GB 8624）。
- **密封**：硅酮 / 改性硅烷 / 聚氨酯胶。
- **一条硬线**：**燃烧性能等级**（GB 8624）—— 保温材料的火灾风险是外保温的命门（JGJ 144 强条）。
- 2026：**一体化**（保温装饰一体板）· 超低能耗 / 被动房（GB 55015）· 气凝胶 · A 级防火保温。
