# 07 木材

> 定位：木材料侧 —— 承接 [[694-木结构与木作|694 木结构与木作]] 的「材料」面：从原木到工程木。

## 形态谱

- 原木 / 锯材。
- **人造板**：胶合板 · 纤维板 · 刨花板 · 细木工板。
- **工程木**：胶合木 GLT · **CLT** 正交胶合木 · LVL。

## 关键指标

- 含水率 · 强度等级（TC / TB）· 防腐 · 防火 · **甲醛释放**（GB/T 39600 E0 / ENF）。

## 工程木的意义

- 把小材胶合成大构件 —— 解决实木「尺寸受限 · 材质不均」，是高层木结构的物质前提。

## 规范

| 木材规范 | 说明 |
| --- | --- |
| GB 50005-2017 | 木结构设计标准 |
| GB/T 26899 | 结构用集成材 |
| GB/T 9846 | 普通胶合板 |
| GB/T 11718 | 中密度纤维板 |
| GB/T 4897 | 刨花板 |
| GB/T 39600-2021 | 人造板及其制品甲醛释放量分级 |
