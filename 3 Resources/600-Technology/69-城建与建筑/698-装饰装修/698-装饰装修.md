## 抹灰饰面研讨（2026-09-28）

> 就本表「抹灰饰面」一行展开。**定位**：698 七项工艺中唯一不以「被观看」为目的的工序 —— 产出的是「下一道工序的作业条件」（平整 · 牢固 · 吸水均一的基面）。饰面质量的七八成在此层定型。

**一、主线：把「异质毛坯」洗成「均质基面」**

| 先天矛盾      | 现象                      | 手段                                      |
| ------------- | ------------------------- | ----------------------------------------- |
| 不平整        | 墙面歪、垂直度差          | 吊直套方 · 灰饼(≤1.5m) · 冲筋 · 靠尺      |
| 不牢固 / 异质 | 混凝土 · 砖 · 加气块 · 基体交接 | 凿毛 · 界面剂 · 挂网（搭接 ≥100mm）       |
| 吸水不一      | 干基层抢水 → 砂浆失水收缩 | 湿润 · 分层间隔 · 湿润养护（≥7d）         |

**二、四类分项（GB 50210 §4）**

| 分项         | 定义                     | 代表工艺                                            |
| ------------ | ------------------------ | --------------------------------------------------- |
| 一般抹灰     | 找平找直，普通 / 高级两级 | 水泥砂浆 · 水泥混合砂浆 · 聚合物水泥砂浆 · 粉刷石膏 |
| 保温层薄抹灰 | 保温层外聚合物砂浆薄抹   | 外墙外保温系统                                      |
| 装饰抹灰     | 直接做出装饰效果         | 水刷石 · 斩假石 · 干粘石 · 假面砖                  |
| 清水砌体勾缝 | 不抹，只勾缝             | 砂浆勾缝 / 原浆勾缝                                 |

> 本表原仅列「一般抹灰 · 装饰抹灰」；研讨后补全四类 —— 否则「保温层薄抹灰」「清水砌体勾缝」两项在 698 无处归位。

**三、工艺链路（十二步）**

`基层处理 → 界面处理 → 湿润 → 找规矩(吊直套方) → 做灰饼(≤1.5m) → 冲筋 → 做护角(M20 · 高≥2m · 每侧≥50mm) → 底层(搓毛) → 中层(刮平) → 面层(压光两遍) → 养护 → 成品保护`

**四、病害机理（为什么必空必裂）**

- **强度梯度**：中层 ≤ 底层 ≤ 基层 —— 高标号压弱层，收缩应力撕开裂口。
- **分层厚度**：单遍 7–9mm；总厚 ≥35mm 必须加强（不同基体交接挂网，搭接 ≥100mm）。
- **三大通病根**：基层未清未润 · 一遍成活过厚 · 门窗边塞缝不实。

**五、2026 现场：三个位移**

1. **手工 → 机械化 / 机器人**：砂浆泵送 + 机械喷涂 + 刮平机器人；机器人关键成果 = 把「垂4平4、粘结 0.2MPa」**参数化**为 **≈30kg 对墙压力**（隐性经验显式化）。标准已至 —— T/SZCIA 001-2025《建筑抹灰机器人施工技术标准》。
2. **厚抹灰 → 薄抹灰 / 免抹灰**：口诀「以精度换厚度」（铝模 + ALC 精度提升 → 粉刷石膏薄抹 5–8mm，或直接免抹灰刮腻子）。本质是把「找平」功能**前移到工厂**，功能不变、地点变。
3. **规范层面**：GB 50210-2018 仍现行，其 5 条强条已由 GB 55032-2022 取代；网传「抹灰单独立规」未获权威库证实（见下节）。

**六、边界裁定（693 ↔ 698）**

693 与 698 均有「抹灰」：**693 = 砌筑施工的一环（工艺视角）**，**698 = 饰面成型的地基层（饰面视角）**。同一工序两视角 → 建议子库内**默认落 698，693 只作引用**，避免重复建页（参见 [[693-砌筑与建筑工艺|693 砌筑与建筑工艺]]）。

## 涂装研讨（2026-09-28）

> 定位：698 中「面饰成型」的主力 —— 与抹灰（造**基面**）相对，涂装造的是**面层**。它同时兑现观感、耐候与**室内空气环保**三项结果。涂料只是"半成品"，**成败一半在基层、在配套**。

**一、主线：把「平整基面」变成「功能面层」**

| 目标     | 手段                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 附着耐久 | 基层处理（清污 · 消碱 · 封闭）· 含水率达标 · 腻子↔底漆↔面漆同体系配套 |
| 观感     | 多遍成活 · 分色线平直 · 涂膜饱满（无流坠 / 透底 / 掉粉 / 起皮）       |
| 环保     | 低 VOC 涂料 + 达标限量（GB 30981.1）· 室内空气验收（GB 50325）         |

**二、两套正交分类（关键辨析）**

| 轴                     | 依据        | 取值                                                       |
| ---------------------- | ----------- | ---------------------------------------------------------- |
| 标准轴（GB 50210 §12） | 分散介质    | 水性涂料涂饰 · 溶剂型涂料涂饰 · 美术涂饰                   |
| 应用轴（本表）         | 产品 / 部位 | 乳胶漆 · 真石漆（仿石）· 艺术涂料 · 木器漆 · 金属漆 · 无机涂料 |

> 误区：把「真石漆 / 木器漆」当作与「水性 / 溶剂型」并列的类别 —— 二者是不同轴。「真石漆 / 多彩」多为**水性**；「木器漆 / 金属漆」按**用途**命名，水性或溶剂型皆有。

**三、工艺链路**

`基层处理(清污 · 消碱 · 找平) → 含水率检测 → 抗碱封闭底漆 → 腻子(耐水/普通)+打磨 → 底漆 → 面漆(≥2 遍) → 养护 → 验收`

关键控制数（GB 50210 §12.1）：**含水率** 溶剂型 ≤8% / 乳液型 ≤10% / 木材 ≤12%；**环境温度** 水性涂料 5–35℃；厨卫找平层用**耐水腻子**；找平层粘结强度按 **JG/T 298**；**涂层养护期满后**方可验收。

**四、2026 现场：三个位移**

1. **溶剂型 → 水性化**：中国水性涂料渗透率 2025 年破 **42%**；建筑墙面涂料占水性涂料应用约 58%，VOC 法规是主推力。
2. **仿石漆替代石材外墙**：多彩 / 水包水 / 水包砂仿石漆成乡村与住宅外墙主流；**艺术涂料品牌集体下探仿石漆**寻第二增长曲线。
3. **无机 / 功能涂料**：硅酸盐 · 磷酸盐 · 钛酸盐基**无机涂料**（防火阻燃 · 高耐候 · 透气）与反射隔热涂料成增长极；机器人喷涂延续抹灰的装备化主线。

**五、规范重大变更（本次核实，重点）**

- **GB 30981.1-2025**《涂料中有害物质限量 第 1 部分：建筑涂料》+ **GB 30981.2-2025**（工业涂料）：2025-05-30 发布，**2026-06-01 实施**，现行。
- 整合替代 **7 项旧标准**（GB 18582-2020 墙面 · GB 38468-2019 地坪 · GB 18581-2020 木器 · GB 24409-2020 车辆 · GB 24613-2009 玩具 · GB 30981-2020 工业防护 · GB 38469-2019 船舶）—— 旧标准已于 2026-06-01 废止。
- 管理升级：从「单一指标控制」→「**系统风险防控**」；新增 SVOC · 辅助材料（腻子/固化剂/稀释剂等 12 类）· 生物杀伤剂 · 总铅等管控。
- 对照前次：GB 50210 的「2025 版」是讹传；**涂料的「2025 版」是真变更**（GB 30981 系列，权威库可查）。

| 涂装规范        | 说明                                                               |
| --------------- | ------------------------------------------------------------------ |
| GB 50210-2018   | §12 涂饰工程（水性 / 溶剂型 / 美术）                               |
| GB 30981.1-2025 | 建筑涂料有害物质限量（代替 GB 18582-2020 等）                      |
| GB 30981.2-2025 | 工业涂料有害物质限量（代替 GB 18581-2020 木器等 5 项）              |
| JGJ/T 29-2015   | 建筑涂饰工程施工及验收规程                                         |
| GB 50325-2020   | 民用建筑工程室内环境污染控制标准（氡 · 甲醛 · 氨 · 苯系物 · TVOC） |
| JG/T 298-2010   | 建筑室内用腻子（找平层粘结强度依据）                               |

## 铺贴研讨（2026-09-28）

> 定位：与抹灰、涂装同属「饰面成型」，但铺贴是**块材饰面** —— 用离散块（砖 / 板 / 石）拼出连续面。核心矛盾是**「块多、缝多、粘结面隐蔽」**：质量看不见，只能靠**空鼓敲击 + 拉拔**事后验证。

**一、主线：把「块材」变成「连续 · 牢固 · 平整的面」**

| 目标               | 手段                                                          |
| ------------------ | ------------------------------------------------------------- |
| 附着（防空鼓脱落） | 粘结材料匹配等级 · 满浆（双面上胶）· 基层强度与平整达标       |
| 平整（无高低差）   | 找平器 / 定位器 · 基面平整度 ≤2mm · 排版弹线                  |
| 观感（缝直色匀）   | 美缝 / 填缝 · 分格缝与留缝 · 整砖套割                         |

**二、两个维度：部位 × 工法**

| 部位        | 规范                    | 要点                          |
| ----------- | ----------------------- | ----------------------------- |
| 内墙砖      | GB 50210 §10.2          | 满粘法 · 大面与阳角无空鼓     |
| 外墙砖      | GB 50210 §10.3 + JGJ 126 | ≤100m · ≤8 度 · 满粘 · 样板件 |
| 墙面石材/板 | GB 50210 §9 饰面板       | 干挂 / 湿贴 / 粘贴            |
| 地面砖石    | GB 50209                | 结合层 · 无空鼓               |

| 工法        | 做法                  | 适用              |
| ----------- | --------------------- | ----------------- |
| 厚贴（传统） | 水泥砂浆 15–20mm      | 小规格 · 普通砖   |
| 薄贴        | 瓷砖胶 3–10mm（齿刀刮胶） | 主流；大板/岩板必用 |
| 干挂 / 点挂 | 金属挂件 / 背栓       | 石材 · 大板 · 高处 |

**三、关键：瓷砖胶等级（JC/T 547）**

| 代号  | 含义                                              |
| ----- | ------------------------------------------------- |
| C1    | 拉伸粘结强度 ≥0.5MPa（常规小砖 · 干燥区）         |
| C2    | ≥1.0MPa（玻化砖 · 大板/岩板 · 厨卫 · 地暖必选）    |
| T     | 抗滑移（上墙不坠）                                |
| S1/S2 | 柔性（抗基层变形 · 地暖 / 外墙 / 新旧交接）        |
| E     | 延长开放时间（大板慢施工）                        |

> 顶配 **C2TES1**。选错等级 = 空鼓脱落的头号根因。

**四、2026 现场：三个位移**

1. **大规格化**：岩板 / 大板（900×1800 起）普及 → 厚贴退场，**薄贴（JC/T 60006）+ 双面上胶 + 找平器 + 振动揉压**成标准动作；空鼓率目标 <5%。
2. **胶粘剂替代水泥砂浆**：瓷砖胶专业化分级（C1/C2 · T/S/E）；**JC/T 547-2026 将于 2026-12-01 实施**，代替 JC/T 547-2017。
3. **大板/岩板专用胶 + 团体标准**：T/CBMCA 039-2023《陶瓷大板岩板装修镶贴应用规范》· T/CECS 10508-2025《陶瓷大板用胶粘剂》补位。

**五、空鼓：贯穿始终的命题**

- **定性**：内墙满粘法 大面 / 阳角无空鼓；外墙 无空鼓·裂缝；地面砖石 无空鼓。
- **检测**：小锤轻击 / 空鼓锤敲中心与四角；外墙拉拔（JGJ/T 110）。
- **根因**：基层强度与平整不足 · 粘结料不饱满（未双面上胶）· 材料等级不匹配 · 养护期扰动。
- 阳角是重灾区（建议阳角条 / 护角）。

| 铺贴规范          | 说明                                                       |
| ----------------- | ---------------------------------------------------------- |
| GB 50210-2018     | §9 饰面板 · §10 饰面砖（内墙 / 外墙）                       |
| GB 50209-2010     | 建筑地面工程施工质量验收规范（地面砖石 · 结合层）           |
| JGJ 126-2015      | 外墙饰面砖工程施工及验收规程                               |
| JGJ/T 110-2017    | 建筑工程饰面砖粘结强度检验标准                             |
| JC/T 547-2017     | 陶瓷砖胶粘剂（**2026-12-01 由 JC/T 547-2026 代替**）        |
| JC/T 60006-2020   | 瓷砖薄贴法施工技术规程                                     |
| T/CBMCA 039-2023  | 陶瓷大板岩板装修镶贴应用规范                               |
| T/CECS 10508-2025 | 陶瓷大板用胶粘剂（2026-03-01 实施）                        |

## 裱糊与软包研讨（2026-09-28）

> 定位：698 中**最「轻」、也最受冲击**的一类 —— 以软质卷材（纸 / 布）或软包面料覆面，**纯面饰 · 不承力**。命运正被「干法装配」改写：现场裱糊 ↓，工厂预制护墙板 / 墙板 ↑。

**一、主线：把「高平整基层」覆上「软质面」**

- 前提极苛：裱糊基层须达**高级抹灰**标准（GB 50210 13.2.2 → 4.2.10）—— 面越软，越藏不住底。
- 两个命门：**接缝**（对花 / 阴角搭接 / 阳角不接缝）+ **粘结**（不脱层 / 空鼓 / 翘边）。

**二、两类分项 + 一条硬指标**

| 分项 | 对象                              | 主控                                    |
| ---- | --------------------------------- | --------------------------------------- |
| 裱糊 | 壁纸（PVC / 复合纸 / 无纺）· 墙布 | 燃烧性能等级 · 拼接对花 · 牢固无空鼓翘边 |
| 软包 | 墙面 / 门 软包                     | 面料·内衬·边框燃烧等级 + 木材含水率      |

> 硬指标：**燃烧性能等级**（GB 8624）—— 裱糊 / 软包是室内火灾蔓延的关键面，主控项目列首位。

**三、工艺链路**

`基层达高级抹灰 → 满刮腻子+打磨 → 基膜/清漆封闭 → 弹线 → 裁布(留缝) → 上胶(糯米胶/专用胶) → 铺贴对花 → 赶压排气 → 阴角顺光搭接 / 阳角包边无接缝 → 清洁养护`

关键：拼缝「距墙 1.5m 观察不显缝」（GB 50210 13.2.3）。

**四、2026 现场：一个位移 + 一个反例**

1. **现场裱糊 → 工厂装配**：护墙板 / 集成墙板 / 木饰面 / SPC 板以**干法快装锁扣**替代湿作业裱糊（免铲墙 · 免批腻子 · 免胶 · 即装即住）；2026 护墙板家装渗透率约 18%，装配式内装规模爆发。
2. **无缝墙布**：裱糊内部的升级 —— 一幅布整墙（消灭竖缝）、功能化（抗菌 / 除醛 / 调湿）；仍走「软质裱糊」路线，以「整体无缝」对抗装配板。
3. 环保换挡：**GB 18585-2023**（壁纸限量，2024-12-01 实施，20 年首次大修）；装配板侧卷向 **ENF 级**（≤0.025mg/m³，GB/T 39600）。

## 吊顶研讨（2026-09-28）

> 定位：698 中唯一**悬挂于结构之下**的工序 —— 结构安全（防坠落）与防火是命门，观感其次。

**一、分类（GB 50210 §7，按面板形状，取代旧「明 / 暗龙骨」）**

| 分项         | 骨架                 | 面层                                                        |
| ------------ | -------------------- | ----------------------------------------------------------- |
| 整体面层吊顶 | 轻钢 / 铝合金 / 木龙骨 | 石膏板 · 水泥纤维板 · 木板                                 |
| 板块面层吊顶 | 同上                 | 石膏板 · 金属板 · 矿棉板 · 木板 · 塑料板 · 玻璃板 · 复合板 |
| 格栅吊顶     | 同上                 | 金属 · 木材 · 塑料 · 复合材料                               |

**二、两条安全红线**

- **重型 / 振动设备严禁吊在龙骨上**（7.1.12 原强条 → 现由 GB 55032-2022 接管）：3kg 以上灯具 · 投影仪 · 风扇 · 音箱等。
- **吊杆构造**：距主龙骨端部 ≤300mm；吊杆 >1500mm 设**反支撑**；>2500mm 或上部为网架 / 钢屋架 → **钢结构转换层**。
- 木龙骨 / 木面板须**防火处理**（GB 50222）；面积 >100㎡ 或长度 >15m 宜设**伸缩缝 / 分格缝**。

**三、工艺链路**

`测量放线 → 吊杆安装 → 承载龙骨 → 覆面龙骨 → 边龙骨 → 隐蔽验收(管道/设备/防火) → 面板安装 → 板缝处理 → 成品保护`

**四、2026：材料换挡**

- **GB/T 11981-2024**《建筑用轻钢龙骨》（2025-05-01 实施）：分 D 类（吊顶）/ Q 类（隔墙）；主龙骨壁厚 ≥0.8mm。
- **GB/T 9775-2025**《纸面石膏板》（2026-01-01 实施）：类型 3→6（新增 T 耐潮 / TH 耐潮耐火）；耐火型遇火稳定性 20→**≥40min**；面密度改实测值。
- 趋势：厨卫**集成吊顶** · 无主灯 + **大板 / 蜂窝大板** · 装配式快装。

| --------------- | ------------------------------------- |
| GB 50210-2018   | §7 吊顶（整体 / 板块 / 格栅）         |
| GB 55032-2022   | 通用规范（重型设备不得吊于龙骨）      |
| GB/T 11981-2024 | 建筑用轻钢龙骨（2025-05-01 实施）     |

## 幕墙研讨（2026-09-28）

> 定位：698 中唯一**与结构工程同权**的外围护工序 —— 它不是「装修」配件，而是**建筑外围护 + 结构安全**系统；验收由专门技术规范主导，GB 50210 §11 只列项目。

**一、四类面板 × 技术规范**

| 幕墙                            | 技术规范                  |
| ------------------------------- | ------------------------- |
| 玻璃幕墙                        | JGJ 102                   |
| 金属与石材幕墙                  | JGJ 133                   |
| 人造板材幕墙（瓷板/陶板/微晶/纤维水泥） | JGJ 336（高度不宜 >100m） |
| 组合面板                        | GB/T 21086                |

**二、结构胶：幕墙的生命线**

- 隐框 / 半隐框玻璃幕墙：玻璃与铝型材粘结**必须用中性硅酮结构密封胶**；镀膜玻璃不用酸性硅酮胶。
- 结构胶使用前须做**相容性 + 剥离粘结性试验**，复验邵氏硬度 / 拉伸粘结；**有效期内**使用；**不应在现场打注**（双组分除外）。
- 人流密集 / 幼儿场所 · 易撞部位 → **安全玻璃** + 警示标志；结构设计使用年限不宜低于 **25 年**（GB/T 21086）。

**三、2026：三条进化线**

- **单元式幕墙**（工厂预制、现场挂装）成主流工法。
- **BIPV 光伏幕墙 / 智能幕墙 / 双层·呼吸式幕墙**：幕墙从「围护」转向「产能 + 调适」。
- 防火：GB 55032-2022 接管 JGJ 102 幕墙强条（预埋件数量 / 规格 / 位置 / 防腐）。

**四、版本核实**

- **JGJ 102-2003 · JGJ 133-2001 · JGJ 336-2016 · GB/T 21086-2007**：权威库均记**现行**。
- ⚠️ 网络流传 **「JGJ 102-2023」**（内容农场式解读，含「条款记不清」字样），权威库**未证实** → 存疑，不采信。

## 门窗与五金研讨（2026-09-28）

> 定位：698 中承担**「洞口系统」**的一行 —— 连接室内外的界面，同时扛**物理性能**（气密 / 水密 / 抗风压 / 隔声 / 保温）与**安全**（防坠落 / 防雷）双责。一半是「装修」，一半是「建筑构件」。

**一、五类分项（GB 50210 §6）**

| 分项                              | 对象                    |
| --------------------------------- | ----------------------- |
| 木门窗 / 金属门窗 / 塑料门窗      | 常规门窗                |
| 特种门                            | 防火 / 防盗 / 自动门等  |
| 门窗玻璃                          | 平板 / 中空 / 夹层 / 安全玻璃 |

**二、安全红线**

- **6.1.11**（原强条）：外门窗安装必须牢固，**砌体上严禁射钉固定** → 现由 GB 55032-2022 接管。
- **6.1.12**（原强条）：推拉门窗扇必须牢固并**装防脱落装置**。
- 金属门窗扇：开关灵活 · 关闭严密 · 无倒翘；推拉扇开关力 **≤50N**；框墙缝隙填嵌饱满 + 密封胶。

**三、2026：从「门窗」到「系统窗」**

- **系统窗**（GB/T 39529）：型材 / 玻璃 / 五金 / 密封**成套设计验证**，替代现场拼凑。
- 性能分级（GB/T 31433）：气密 ≥7 级（公建 10 层+）/ ≥6 级 · 水密 ≥3 级 · 抗风压 ≥4 级（7 层+）。
- 节能：断桥铝 + Low-E 中空 / 三玻两腔；电动 / 智能门窗（GB/T 39188）。
