# 02 抹灰饰面

> 定位：698 七项工艺中唯一不以「被观看」为目的的工序 —— 产出的是「下一道工序的作业条件」（平整 · 牢固 · 吸水均一的基面）。饰面质量的七八成在此层定型。

## 主线：把「异质毛坯」洗成「均质基面」

| 先天矛盾 | 现象 | 手段 |
| ---- | ---- | ---- |
| 不平整 | 墙面歪、垂直度差 | 吊直套方 · 灰饼（≤1.5m）· 冲筋 · 靠尺 |
| 不牢固 / 异质 | 混凝土 · 砖 · 加气块 · 基体交接 | 凿毛 · 界面剂 · 挂网（搭接 ≥100mm） |
| 吸水不一 | 干基层抢水 → 砂浆失水收缩 | 湿润 · 分层间隔 · 湿润养护（≥7d） |

## 四类分项（GB 50210 §4）

| 分项 | 定义 | 代表工艺 |
| ---- | ---- | ---- |
| 一般抹灰 | 找平找直，普通 / 高级两级 | 水泥砂浆 · 混合砂浆 · 聚合物水泥砂浆 · 粉刷石膏 |
| 保温层薄抹灰 | 保温层外聚合物砂浆薄抹 | 外墙外保温系统 |
| 装饰抹灰 | 直接做出装饰效果 | 水刷石 · 斩假石 · 干粘石 · 假面砖 |
| 清水砌体勾缝 | 不抹，只勾缝 | 砂浆勾缝 / 原浆勾缝 |

## 工艺链路（十二步）

`基层处理 → 界面处理 → 湿润 → 找规矩(吊直套方) → 做灰饼(≤1.5m) → 冲筋 → 做护角 → 底层(搓毛) → 中层(刮平) → 面层(压光两遍) → 养护 → 成品保护`

## 病害机理（为什么必空必裂）

- **强度梯度**：中层 ≤ 底层 ≤ 基层 —— 高标号压弱层，收缩应力撕开裂口。
- **分层厚度**：单遍 7–9mm；总厚 ≥35mm 必须加强（不同基体交接挂网，搭接 ≥100mm）。
- **三大通病根**：基层未清未润 · 一遍成活过厚 · 门窗边塞缝不实。

## 2026 三条位移

1. **手工 → 机械化 / 机器人** —— 砂浆泵送 + 机械喷涂 + 刮平机器人（已参数化：≈30kg 对墙压力）。
2. **厚抹灰 → 薄抹灰 / 免抹灰** —— 铝模 + ALC 精度提升 → 粉刷石膏薄抹 5–8mm，或直接免抹灰刮腻子。
3. **规范层面** —— GB 50210-2018 现行，其 5 条强条由 GB 55032-2022 取代；「抹灰单独立规」未证实。
