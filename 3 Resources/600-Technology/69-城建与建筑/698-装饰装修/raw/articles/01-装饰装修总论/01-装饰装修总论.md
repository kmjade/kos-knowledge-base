# 01 装饰装修总论

> 定位：装饰装修是建筑的**「面子与里子」** —— 以「饰面成型」为目的的现场工艺总称。它把毛坯变成可用的空间。

## 什么是装饰装修

建筑**面层与装饰装修**的现场工艺 —— 抹灰饰面、涂装、铺贴、裱糊、吊顶、幕墙、门窗等。

> **UDC 698** — 装饰装修工艺（Finishing and decorating trades）。隶属 [[69-城建与建筑|69 城建与建筑]]。

## 工艺谱系（七项）

| 工艺 | 要点 |
| ---- | ---- |
| 抹灰饰面 | 一般 / 保温层薄抹灰 / 装饰抹灰 / 清水砌体勾缝 · 腻子找平 |
| 涂装 | 水性 / 溶剂型 / 美术 · 乳胶漆 · 真石漆 · 艺术涂料 |
| 铺贴 | 墙地砖 · 石材 · 大板岩板 · 薄贴 · 瓷砖胶 |
| 裱糊与软包 | 壁纸 · 无缝墙布 · 软包 / 硬包 |
| 吊顶 | 轻钢龙骨 · 石膏板 · 矿棉板 · 铝扣板 |
| 幕墙 | 玻璃 / 石材 / 金属 / 人造板 · BIPV · 结构胶 |
| 门窗与五金 | 木 / 金属 / 塑料门窗 · 特种门 · 系统窗 · 玻璃安装 |

## 主线：从「基面」到「面层」

```
基层（毛坯） → 抹灰/找平（造基面） → 涂装/铺贴/裱糊（造面层） → 收口/成品保护
```

- **造基面**：抹灰 —— 产出「下一道工序的作业条件」（平整 · 牢固 · 吸水均一）。
- **造面层**：涂装 / 铺贴 / 裱糊 —— 兑现观感、耐候、环保。

## 2026 三条位移

1. **手工 → 机械化 / 机器人** —— 砂浆泵送 · 机械喷涂 · 抹灰 / 喷涂机器人。
2. **湿作业 → 干法装配** —— 薄抹灰 / 免抹灰 · 护墙板 / 集成墙板快装 · 装配式内装。
3. **环保换挡** —— GB 30981.1-2025（建筑涂料限量）· GB 18585-2023（壁纸）· ENF 级板材。
