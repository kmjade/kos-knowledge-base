# 09 装配式装修与绿色装修

> 定位：装饰装修的**未来方向** —— 干法装配（工厂预制 + 现场拼装）与绿色环保（低 VOC · 可再生 · 可拆改）。

## 装配式装修

| 系统 | 部品 |
| ---- | ---- |
| 隔墙 | 轻质条板 · 集成墙面 |
| 吊顶 | 模块化吊顶 |
| 墙面 | 护墙板 · 集成墙板 · 木饰面 · SPC 板 |
| 地面 | 架空地板 · 干式地暖 · 快装地板 |
| 厨卫 | 整体卫浴 · 集成厨房 |

```
工厂预制部品 → 现场干法拼装（锁扣 / 挂装）
```

**优势**：免湿作业 · 免铲墙批腻子 · 即装即住 · 可拆改。

## 绿色装修

| 维度 | 内容 |
| ---- | ---- |
| 环保材料 | 低 VOC 涂料（GB 30981.1）· 无醛板材（ENF 级 · GB/T 39600）· 低辐射 |
| 室内空气 | GB 50325 验收（氡 · 甲醛 · 氨 · 苯系物 · TVOC） |
| 资源 | 可回收 / 可再生材料 · 工厂化减少损耗 |
| 健康 | 抗菌 · 除醛 · 调湿功能饰面 |

## 2026 三条位移

1. **湿作业 → 干法快装** —— 护墙板 / 集成墙板渗透率上升，装配式内装规模爆发。
2. **环保换挡** —— GB 30981.1-2025（涂料）· GB 18585-2023（壁纸）· ENF 级板材。
3. **机械化** —— 抹灰 / 喷涂机器人 · 工厂化部品。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 30981.1-2025 | 建筑涂料有害物质限量 |
| GB 18585-2023 | 壁纸有害物质限量 |
| GB 50325-2020 | 民用建筑工程室内环境污染控制标准 |
| GB/T 39600-2021 | 人造板甲醛释放量分级（E0 / ENF） |
| GB/T 51129 | 装配式建筑评价标准 |
