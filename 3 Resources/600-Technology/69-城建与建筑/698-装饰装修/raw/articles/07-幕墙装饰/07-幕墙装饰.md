# 07 幕墙装饰

> 定位：698 中唯一**与结构工程同权**的外围护工序 —— 它不是「装修」配件，而是**建筑外围护 + 结构安全**系统；验收由专门技术规范主导，GB 50210 §11 只列项目。

## 四类面板 × 技术规范

| 幕墙 | 技术规范 |
| ---- | ---- |
| 玻璃幕墙 | JGJ 102 |
| 金属与石材幕墙 | JGJ 133 |
| 人造板材幕墙（瓷板 / 陶板 / 微晶 / 纤维水泥） | JGJ 336（高度不宜 >100m） |
| 组合面板 | GB/T 21086 |

## 结构胶：幕墙的生命线

- 隐框 / 半隐框玻璃幕墙：玻璃与铝型材粘结**必须用中性硅酮结构密封胶**；镀膜玻璃不用酸性硅酮胶。
- 结构胶使用前须做**相容性 + 剥离粘结性试验**，复验邵氏硬度 / 拉伸粘结；**有效期内**使用；**不应在现场打注**（双组分除外）。
- 人流密集 / 幼儿场所 · 易撞部位 → **安全玻璃** + 警示标志；结构设计使用年限不宜低于 **25 年**（GB/T 21086）。

## 2026：三条进化线

- **单元式幕墙**（工厂预制、现场挂装）成主流工法。
- **BIPV 光伏幕墙 / 智能幕墙 / 双层·呼吸式幕墙** —— 幕墙从「围护」转向「产能 + 调适」。
- 防火：GB 55032-2022 接管 JGJ 102 幕墙强条。

## 版本核实

- **JGJ 102-2003 · JGJ 133-2001 · JGJ 336-2016 · GB/T 21086-2007**：权威库均记**现行**。
- ⚠️ 网络流传「JGJ 102-2023」权威库**未证实** → 存疑，不采信。
