# 06 裱糊与软包

> 定位：698 中**最「轻」、也最受冲击**的一类 —— 以软质卷材（纸 / 布）或软包面料覆面，**纯面饰 · 不承力**。命运正被「干法装配」改写。

## 主线：把「高平整基层」覆上「软质面」

- 前提极苛：裱糊基层须达**高级抹灰**标准（GB 50210 13.2.2 → 4.2.10）—— 面越软，越藏不住底。
- 两个命门：**接缝**（对花 / 阴角搭接 / 阳角不接缝）+ **粘结**（不脱层 / 空鼓 / 翘边）。

## 两类分项 + 一条硬指标

| 分项 | 对象 | 主控 |
| ---- | ---- | ---- |
| 裱糊 | 壁纸（PVC / 复合纸 / 无纺）· 墙布 | 燃烧性能等级 · 拼接对花 · 牢固无空鼓翘边 |
| 软包 | 墙面 / 门 软包 | 面料 · 内衬 · 边框燃烧等级 + 木材含水率 |

> 硬指标：**燃烧性能等级**（GB 8624）—— 裱糊 / 软包是室内火灾蔓延的关键面，主控项目列首位。

## 工艺链路

`基层达高级抹灰 → 满刮腻子 + 打磨 → 基膜/清漆封闭 → 弹线 → 裁布(留缝) → 上胶 → 铺贴对花 → 赶压排气 → 阴角顺光搭接 / 阳角包边无接缝 → 清洁养护`

## 2026：一个位移 + 一个反例

1. **现场裱糊 → 工厂装配** —— 护墙板 / 集成墙板 / 木饰面 / SPC 板以**干法快装锁扣**替代湿作业裱糊。
2. **无缝墙布** —— 一幅布整墙（消灭竖缝）· 功能化（抗菌 / 除醛 / 调湿）。
3. **环保换挡** —— GB 18585-2023（壁纸限量）· 装配板卷向 ENF 级（GB/T 39600）。
