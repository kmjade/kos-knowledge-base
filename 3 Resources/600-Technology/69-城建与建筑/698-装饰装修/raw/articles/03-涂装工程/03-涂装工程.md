# 03 涂装工程

> 定位：698 中「面饰成型」的主力 —— 与抹灰（造**基面**）相对，涂装造的是**面层**。它同时兑现观感、耐候与**室内空气环保**三项结果。

## 主线：把「平整基面」变成「功能面层」

| 目标 | 手段 |
| ---- | ---- |
| 附着耐久 | 基层处理（清污 · 消碱 · 封闭）· 含水率达标 · 腻子↔底漆↔面漆同体系配套 |
| 观感 | 多遍成活 · 分色线平直 · 涂膜饱满（无流坠 / 透底 / 掉粉 / 起皮） |
| 环保 | 低 VOC 涂料 + 达标限量（GB 30981.1）· 室内空气验收（GB 50325） |

## 两套正交分类

| 轴 | 依据 | 取值 |
| ---- | ---- | ---- |
| 标准轴（GB 50210 §12） | 分散介质 | 水性涂料 · 溶剂型涂料 · 美术涂饰 |
| 应用轴 | 产品 / 部位 | 乳胶漆 · 真石漆 · 艺术涂料 · 木器漆 · 金属漆 · 无机涂料 |

> 误区：把「真石漆 / 木器漆」当作与「水性 / 溶剂型」并列 —— 二者是不同轴。

## 工艺链路

`基层处理 → 含水率检测 → 抗碱封闭底漆 → 腻子 + 打磨 → 底漆 → 面漆(≥2 遍) → 养护 → 验收`

关键控制数（GB 50210 §12.1）：含水率 溶剂型 ≤8% / 乳液型 ≤10% / 木材 ≤12%；环境温度 水性 5–35℃；厨卫用**耐水腻子**。

## 2026 三条位移

1. **溶剂型 → 水性化** —— 水性涂料渗透率上升，VOC 法规主推。
2. **仿石漆替代石材外墙** —— 多彩 / 水包水 / 水包砂。
3. **无机 / 功能涂料** —— 硅酸盐基无机涂料 · 反射隔热 · 机器人喷涂。
