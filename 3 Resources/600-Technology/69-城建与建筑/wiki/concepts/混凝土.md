# 混凝土

> **概念** — **胶凝材料 + 骨料 + 水 + 外加剂 / 掺合料** 的混合物；建筑的「体积主体」，绝大多数重量与碳排压在它身上。

## 五组分

| 组分 | 作用 | 代表 |
| ---- | ---- | ---- |
| 胶凝材料 | 胶结 | 水泥 · 掺合料（粉煤灰 / 矿渣粉 / 硅灰） |
| 骨料 | 骨架 | 砂 · 石 · 再生骨料 |
| 水 | 水化 + 和易 | — |
| 外加剂 | 调性能 | 减水 / 缓凝 / 早强 |

## 分类维度

- 按强度：普通（C15–C60）· 高强（≥C60）· 超高强（**UHPC**）。
- 按性能：高性能（HPC）· 自密实（SCC）· 纤维增强 · 清水 · 透水。
- 按用途：结构 · 道路 · 水工 · 大体积 · 装饰 · 喷射。

## 三项关键指标

- **强度等级 C**（GB/T 50107 检验评定）·
- **和易性**（坍落度 / 扩展度，决定可施工性）·
- **耐久性**（抗渗 · 抗冻 · 抗碳化 · 氯离子渗透，决定寿命）。

## 工艺

`配合比设计 → 搅拌 → 运输 → 浇筑 → 振捣 → 养护`

**养护**是强度与耐久的关键环节；大体积混凝土控温差防裂。

## 2026 三位移

1. **UHPC 落地**（抗压达普通混凝土 5–8 倍）；JC/T 60034-2026。
2. 工业化（预制 / 装配式 · SCC）。
3. 低碳化（熟料替代 · **再生骨料** GB/T 25177 · **3D 打印混凝土**）。
