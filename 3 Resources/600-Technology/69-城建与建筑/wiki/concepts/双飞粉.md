# 双飞粉

> **概念 / 材料** — 双飞粉是**重质碳酸钙**（重钙）按细度分级的俗称，主要成分 **CaCO₃**（含少量碳酸镁），是涂料、腻子等行业最常用的**体质填料**。

## 名称与成分

| 项 | 内容 |
| ---- | ---- |
| 俗名 | 双飞粉 · 钙镁粉 · 大白粉 |
| 主要成分 | **重质碳酸钙 CaCO₃**（少量 MgCO₃） |
| 来源 | 天然方解石 / 大理石 / 石灰石**机械磨碎**（区别于化学沉淀的「轻钙」） |
| 简称 | 重钙（GCC，Ground Calcium Carbonate） |

## 细度分级（粉末细度谱系）

| 名称 | 目数 |
| ---- | ---- |
| 单飞粉 | 200 目 |
| **双飞粉** | **325 目** |
| 四飞粉 | 400 目 |
| 超细重钙 | 1250 目及以上 |

## 性质

白度高 · 化学惰性、不易反应 · 热稳定性好（400 ℃ 以下不分解）· 吸油率低 · 折光率低 · 质软、硬度低、磨耗小 · 无毒无味、分散性好。

## 主要用途

| 领域 | 作用 |
| ---- | ---- |
| 涂料 / 油漆（尤其**水性涂料**） | 体质颜料/填料，用量约 **20–60%**（油性涂料 10–35%），起骨架、填平作用，部分替代钛白粉 |
| **腻子** | 耐水腻子主要填料（占比可达 **70–75%**） |
| 乳胶漆 | 增量、改善流变性、提高耐久与遮盖 |
| 造纸 / 橡胶 / 塑料 / 人造石 / 牙膏 / 饲料 | 填充、增量、降本、补强 |

## 与建筑装饰的关系

- 是 [[乳胶漆]]、腻子等**水性墙面材料**的核心填料；粗级别用于腻子/底漆，中细级别用于建筑涂料与内墙无光/半光漆。
- 目数越高（越细），遮盖力与光泽表现越好，成本随之上升。
