# 砌筑工程

> **概念** — 最「现场」的一类工艺 —— 砌砖 · 砌块 · 石砌 · 混凝土浇筑 · 抹灰；把散料变成结构，靠「手 + 规矩」。

## 工艺谱系

| 工艺 | 要点 |
| ---- | ---- |
| 砌砖 | 湿润 · 灰缝 8–12mm · 组砌 · 皮数杆 |
| 砌块 | 排块 · 灰缝 · 芯柱 / 构造柱 |
| 石砌 | 毛石 / 料石 · 勾缝 |
| 混凝土 | 配料 · 搅拌 · 浇筑 · 振捣 · 养护 · 施工缝 |
| 抹灰 | 底层 / 中层 / 面层（详见 [[抹灰饰面]]） |
| 加固 | 构造柱 · 圈梁 · 拉结筋 |

## 散料 → 结构的「三个规矩」

- **材料**：砖需湿润 · 砂浆饱满度 · 块材折压比（GB 50574）。
- **几何**：皮数杆 · 轴线位移 · 垂直度 · 灰缝厚度。
- **整体**：构造柱 · 圈梁 · 拉结筋 —— 把脆性砌体「箍」成抗震整体。

## 边界（693 ↔ 698）

抹灰在 693 是砌筑工艺的一环，在 [[698-装饰装修|698-装饰装修]] 是饰面成型的地基层 —— 同一工序两视角。

## 2026

免抹灰 / 薄抹灰 · 装配式替代现场砌筑 · 通用规范换挡。

## 核实

**GB 50203-2011 现行**；网传「GB 50203-2024」**未证实 → 不采信**。
