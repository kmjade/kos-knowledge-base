# 吊顶

> **概念** — 悬挂于结构之下的顶面系统；[[698-装饰装修|装饰装修]] 中唯一**结构安全（防坠落）+ 防火**为命门的工序。

## 定义

**吊顶（Suspended Ceiling）** 由吊杆、龙骨骨架与面板组成的顶面构造，用以遮蔽管线设备、调整净高、控制声光。

## 分类（GB 50210 §7，按面板形状，取代旧「明 / 暗龙骨」）

| 分项 | 骨架 | 面层 |
| ---- | ---- | ---- |
| 整体面层吊顶 | 轻钢 / 铝合金 / 木龙骨 | 石膏板 · 水泥纤维板 · 木板 |
| 板块面层吊顶 | 同上 | 石膏板 · 金属板 · 矿棉板 · 木板 · 塑料板 · 玻璃板 · 复合板 |
| 格栅吊顶 | 同上 | 金属 · 木材 · 塑料 · 复合材料 |

## 两条安全红线

- **重型 / 振动设备严禁吊在龙骨上**（7.1.12 原强条 → 现由 [[GB 55032-2022]] 接管）：3kg 以上灯具 · 投影仪 · 风扇 · 音箱等。
- **吊杆构造**：距主龙骨端部 ≤300mm；吊杆 >1500mm 设**反支撑**；>2500mm 或上部为网架 / 钢屋架 → **钢结构转换层**。
- 木龙骨 / 木面板须防火处理；面积 >100㎡ 或长度 >15m 宜设伸缩缝 / 分格缝。

## 工艺链路

`测量放线 → 吊杆安装 → 承载龙骨 → 覆面龙骨 → 边龙骨 → 隐蔽验收 → 面板安装 → 板缝处理 → 成品保护`

## 2026：材料换挡

- **GB/T 11981-2024**《建筑用轻钢龙骨》（2025-05-01 实施）：分 D 类（吊顶）/ Q 类（隔墙）；主龙骨壁厚 ≥0.8mm。
- **GB/T 9775-2025**《纸面石膏板》（2026-01-01 实施）：类型 3→6；耐火型遇火稳定性 20→**≥40min**。
- 趋势：厨卫**集成吊顶** · 无主灯 + 大板 / 蜂窝大板 · 装配式快装。

## 与其他概念的关系

- 与 [[幕墙]] 同为「悬挂 / 外围护」构造，但吊顶在室内、负责顶面。
- 验收：[[GB 50210]] §7；安全强条由 [[GB 55032-2022]] 接管。
