# 胶凝材料

> **概念** — 能把散粒（骨料 / 纤维）**胶结成整体**的「胶」，是混凝土 / 砂浆 / 抹灰的基质。

## 定义

**胶凝材料（Cementitious Material）** 分两族：

| 族 | 代表 | 硬化条件 |
| -- | ---- | -------- |
| **水硬性** | 硅酸盐水泥系列 | 遇水硬化，水中 / 潮湿可持续 |
| **气硬性** | 石灰 · 石膏 · 水玻璃 | 只在空气中硬化（干燥 + 碳化） |

> 一句话记：**水泥「不怕水」；石灰 / 石膏「怕水」**。

## 水泥

- **六大通用硅酸盐水泥**：硅酸盐 · 普通硅酸盐 · 矿渣 · 火山灰质 · 粉煤灰 · 复合。
- 关键指标：强度等级（42.5 / 52.5…）· 凝结时间 · **安定性**（游离 CaO / MgO）。
- **特性水泥**：抗硫酸盐 · 中 / 低热 · 快硬 · 膨胀 · 白色 · 道路 · 铁铝酸盐。
- **GB 175-2023** 收紧：删复合 32.5、增**水溶性铬(VI)** 与**放射性核素**限量。

## 石灰与石膏

- **石灰**：生石灰 CaO →（熟化）→ 熟石灰 Ca(OH)₂；须**充分熟化**，否则「爆灰」。
- **石膏**：建筑石膏（β 半水）· 高强石膏（α）；**凝结快、微膨胀** → 抹灰石膏 / 自流平 / 装配式。

## 2026：低碳主线

熟料替代 · **碱激发 / 地聚物（AACM，碳排约波特兰水泥 1/5–1/10）** · LC3 · 铁铝酸盐 · 碳捕集。

## 与其他概念的关系

- 服务于 [[混凝土]] · [[建筑砂浆]] 的基质。
- 相关规范：GB 175-2023 · GB/T 748-2023 · GB/T 9776-2022 · GB/T 28627-2023 · JC/T 479-2013。
