# 白水泥

> **概念 / 材料** — 白水泥即**白色硅酸盐水泥**（代号 **P·W**），以**氧化铁含量极低**的硅酸盐水泥熟料、适量石膏及规定混合材料磨细制成的水硬性胶凝材料，是饰面与彩色制品的专用水泥。

## 定义与特征

- **定义**：由氧化铁含量少的白色硅酸盐水泥熟料 + 适量石膏（+ 规定混合材料）磨细制成的水硬性胶凝材料。
- **与普通硅酸盐水泥的差别**：普通水泥颜色主要由 **Fe₂O₃** 引起；白水泥通过**降低熟料 Fe₂O₃ 含量**获得高白度 —— 代价是**强度略低、成本更高**，多用于**装饰**而非承重。

## 等级与代号（GB/T 2015-2017）

| 维度 | 分级 |
| ---- | ---- |
| 强度等级 | **32.5 · 42.5 · 52.5**（按 3d / 28d 抗压与抗折强度） |
| 白度 | 按白度分 **1 级 / 2 级**，代号 **P·W-1 · P·W-2** |
| 白度测定 | 按 GB/T 5950-2008 |

## 主要技术要求（GB/T 2015-2017）

| 项目 | 要求 |
| ---- | ---- |
| 三氧化硫 SO₃ | ≤3.5% |
| **水溶性铬(Ⅵ)** | ≤10 mg/kg（GB 31893） |
| 氯离子 Cl⁻ | ≤0.06% |
| 45 μm 筛余 | ≤30.0% |
| 凝结时间 | 初凝 ≥45 min · 终凝 ≤600 min |
| 安定性 | 沸煮法合格 |
| 强度 | 按 GB/T 17671（ISO 法） |
| 黄外 / 放射性 | 符合 GB 6566 |

## 如何「变白」（生产要点）

| 环节 | 措施 |
| ---- | ---- |
| 配料 | 原料纯净 —— 石灰石 / 白垩 · 高岭土 / 白土 · 石英砂；控制 Fe₂O₃ 极低 |
| 煅烧 | **弱还原气氛**；燃料用无灰分的天然气 / 重油或煤气 |
| 冷却 | **急冷（水淬）** 防止 Fe 着色 |
| 粉磨 | 磨机衬板用**花岗岩 / 白色陶瓷 / 耐磨特殊钢**，研磨体用硅质卵石 / 瓷球，防铁污染 |
| 掺料 | 掺白度较高的石膏 / 石灰石；提高细度 |

## 主要用途

| 领域 | 示例 |
