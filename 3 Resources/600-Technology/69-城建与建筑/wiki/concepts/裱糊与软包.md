# 裱糊与软包

> **概念** — 以软质卷材（壁纸 / 墙布）或软包面料覆面的「轻面饰」；[[698-装饰装修|装饰装修]] 中**最受冲击**、正被干法装配替代的一类。

## 定义

**裱糊**以胶粘剂把壁纸 / 墙布粘贴于墙、顶；**软包**以面料 + 内衬 + 边框形成柔性饰面。二者均**纯面饰 · 不承力**，并**要求基层达高级抹灰标准**（面越软，越藏不住底）。

## 两类分项 + 一条硬指标

| 分项 | 对象 | 主控 |
| ---- | ---- | ---- |
| 裱糊 | 壁纸（PVC / 复合纸 / 无纺）· 墙布 | 燃烧性能等级 · 拼接对花 · 牢固无空鼓翘边 |
| 软包 | 墙面 / 门 软包 | 面料·内衬·边框燃烧等级 + 木材含水率 |

> 硬指标是**燃烧性能等级**（GB 8624）—— 裱糊 / 软包是室内火灾蔓延的关键面，主控项目列首位。
> 基层：须符合同标准**高级抹灰**要求（GB 50210 §13.2.2 → §4.2.10）。两个命门是**接缝**与**粘结**。

## 2026：一个位移 + 一个反例

1. **现场裱糊 → 工厂装配**：护墙板 / 集成墙板 / 木饰面 / SPC 板以**干法快装锁扣**替代湿作业裱糊（免铲墙 · 免批腻子 · 免胶 · 即装即住）；2026 护墙板家装渗透率约 18%。
2. **无缝墙布**：裱糊内部的升级 —— 一幅布整墙（消灭竖缝）、功能化（抗菌 / 除醛 / 调湿），以「整体无缝」对抗装配板。

## 与其他概念的关系

- 基层依赖 [[抹灰饰面]]（须达高级抹灰）。
- 环保限量：[[GB 18585]]（壁纸有害物质限量）；验收：[[GB 50210]] §13。
- 与 [[涂装]] · [[铺贴]] 同属「面饰成型」，但最轻、最易被替代。
