# 安装工艺

> **概念** — 把图纸上的系统变成现场可运行的实体；四工种 + 通用工艺；质量靠「**连接 · 支撑 · 试验**」三件套兜底。

## 四个工种

| 工种 | 对象 | 核心技能 |
| ---- | ---- | -------- |
| 管道工 Pipe fitter | 管道系统 | 连接 · 支吊架 · 试压 |
| 电工 Electrician | 强电 / 弱电 | 配管配线 · 桥架 · 接地 |
| 金属工 Metal worker | 风管 / 支吊架 / 金属构件 | 下料 · 焊接 · 制作安装 |
| 排水工 Drainlayer | 排水 / 室外管网 | 坡度 · 检查井 · 闭水 |

## 通用工艺：连接 · 支撑 · 试验

- **连接**：螺纹 · 焊接 · 沟槽 · **卡压 / 环压**（薄壁不锈钢）· 热熔。
- **支撑**：支吊架（固定 / 活动 / **抗震**）。
- **试验**：给水水压 · 排水灌水 / 通球 · 电气绝缘 / 接地电阻 · 风管漏风量。

## 2026：现场加工 → 工厂预制 + 现场装配

**装配式机电（MiMEP / DfMA）**（实测现场安装时间可缩短约 60%）· **BIM 管线综合深化**（≥LOD400）· 免焊连接普及。

## 注意

- 特种作业持证（电工 · 焊工 · 高处 · 有限空间）。
- 规范：GB 50236 / GB 50683（焊接）· GB 50981 / T/CECS 420-2022（抗震支吊架）· GB/T 29038-2024（薄壁不锈钢）。
