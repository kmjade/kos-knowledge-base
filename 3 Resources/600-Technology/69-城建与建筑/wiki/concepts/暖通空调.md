# 暖通空调

> **概念** — 补上「室外气候」与「室内舒适」的差距 —— 冬供暖 · 夏供冷 · 全年通风换气。它同时是建筑的**最大用能项**，与「双碳」直接挂钩。

## 系统四层

| 层 | 内容 |
| -- | ---- |
| 冷热源 | 锅炉 / 热泵 / 冷水机组 / 多联机 |
| 输配 | 风管 · 水管 · 保温 · 阀门 |
| 末端 | 散热器 · 地暖 · 风机盘管 · 风口 |
| 控制 | 温湿度 · 新风联动 · 群控 |

## 三条功能线

- **供暖**：散热器 / 地暖（辐射，JGJ 142）· 热源（锅炉 → **热泵**）。
- **通风**：自然通风 · 机械新风（含热回收）· **防排烟**（GB 51251）。
- **空调**：中央空调 · VRV 多联机 · 冷热源（离心 / 螺杆 / **磁悬浮**）。

## 总纲 + 底线

- 总纲：**GB 55015-2021**（节能与可再生能源）· **GB 55016-2021**（建筑环境）。
- 底线：**防排烟**（GB 51251-2017 + [[GB 55036-2022]]）。

## 2026 三大位移

① **热泵化**（替代燃煤锅炉）；② **AI 接管**（AI 高效机房 / 多联机，节能 15–30%）；③ **能效与碳**（GB 21455-2025，一级 APF≥5.30）。
