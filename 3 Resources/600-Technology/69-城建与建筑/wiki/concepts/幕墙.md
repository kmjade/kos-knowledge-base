# 幕墙

> **概念** — 由面板与支承结构组成、相对主体结构**有一定位移能力**的建筑外围护系统；[[698-装饰装修|装饰装修]] 中唯一**与结构工程同权**的一类。

## 定义

**幕墙（Curtain Wall）** 不承重、包覆于主体结构外侧的外围护墙。它不是「装修」配件，而是**外围护 + 结构安全**系统——验收由专门技术规范主导，[[GB 50210]] §11 只列主控与一般项目。

## 四类面板 × 技术规范

| 幕墙 | 技术规范 |
| ---- | -------- |
| 玻璃幕墙 | JGJ 102 |
| 金属与石材幕墙 | JGJ 133 |
| 人造板材幕墙（瓷板 / 陶板 / 微晶 / 纤维水泥） | JGJ 336（高度不宜 >100m） |
| 组合面板 | GB/T 21086 |

## 结构胶：幕墙的生命线

- 隐框 / 半隐框玻璃幕墙：玻璃与铝型材粘结**必须用中性硅酮结构密封胶**；镀膜玻璃不用酸性硅酮胶。
- 结构胶使用前须做**相容性 + 剥离粘结性试验**，复验邵氏硬度 / 拉伸粘结；**有效期内**使用；**不应在现场打注**（双组分除外）。
- 人流密集 / 幼儿场所 · 易撞部位 → **安全玻璃** + 警示标志；结构设计使用年限不宜低于 **25 年**。

## 2026：三条进化线

1. **单元式幕墙**（工厂预制、现场挂装）成主流工法。
2. **BIPV 光伏幕墙 / 智能幕墙 / 双层·呼吸式幕墙**：幕墙从「围护」转向「产能 + 调适」。
3. 防火：[[GB 55032-2022]] 接管 JGJ 102 幕墙强条。

## 版本核实

- **JGJ 102-2003 · JGJ 133-2001 · JGJ 336-2016 · GB/T 21086-2007**：权威库均记**现行**。
- ⚠️ 网传「**JGJ 102-2023**」（内容农场式解读）权威库**未证实** → 存疑，不采信。

## 与其他概念的关系

- 与 [[门窗工程]] 同属「外围护 / 洞口」系统；与 [[铺贴]] 的干挂同源。
- 验收：[[GB 50210]] §11 + 各专项技术规范。
