# 木结构

> **概念** — 69 中唯一**以生物基材料**为主的结构体系；在「双碳」语境下从「传统」翻红为「低碳前沿」。

## 类别

| 类别 | 要点 |
| ---- | ---- |
| 体系 | 抬梁 / 穿斗（传统）· 轻型木结构 · 胶合木 Glulam · **CLT** |
| 连接 | 榫卯 · 齿连接 · 螺栓 / 钢夹板 |
| 大木作 | 柱 · 梁 · 枋 · 檩 · 椽 · 斗拱 |
| 小木作 | 门 · 窗 · 隔断 · 天花 · 栏杆 |
| 细木工 | 橱柜 · 固定家具 · 木饰面基层 |
| 防护 | 防腐 · 防虫 · 防火 · 防潮 |

## 木材的「两怕一喜」

- **两怕**：怕水怕火（含水率 → 变形 / 腐朽；防火需阻燃或防火板包裹）。
- **一喜**：喜**工厂预制**（天然适配 DfMA）。

## 一条总纲

- **GB 55005-2021**《木结构通用规范》（强制性）。

## 2026 复兴三线

工程木 + 高层（CLT）· **Timber-MiC**（模块化集成建筑）· 生物基固碳 / 混合结构。

- 规范：GB 50005-2017 · GB 50206-2012 · GB/T 50165-2020 · GB/T 51226-2017。
