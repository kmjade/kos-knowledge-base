# 燃气与供热

> **概念** — 696 的「气 / 热」一侧 —— 燃气（可燃 · 防爆）与蒸汽（带压 · 热应力）。共性：**带压 + 危险介质**，安全第一。

## 燃气：安全是唯一主线

- 三防：**防泄漏 · 防积聚 · 防点火**（报警 + 通风 + 防爆电气）。
- 链路：门站 → 输配管网 → 引入管 → 室内管 → 用气设备。

## 蒸汽 / 供热：压力 + 热应力

- 供热管网：压力 ≤2.5MPa、热水 ≤200℃ / 蒸汽 ≤350℃。
- 三大难点：**热补偿 · 保温 · 疏水**。
- 压力管道属**特种设备**。

## 一条总纲

**GB 55009-2021**《燃气工程项目规范》+ **GB 55010-2021**《供热工程项目规范》（均强制）。

## 2026

燃气安全专项整治（管网更新 + 智能监测）· 输配验收升国标（GB/T 51455-2023）· 供热 CJJ/T 34-2022。
