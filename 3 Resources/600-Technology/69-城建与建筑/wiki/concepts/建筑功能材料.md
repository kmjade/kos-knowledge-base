# 建筑功能材料

> **概念** — 不承重、但决定建筑「好不好用 / 安不安全 / 省不省能」的材料 —— 防水 · 保温 · 密封 · 防火 · 隔声。

## 分类

- **防水**：卷材 / 涂料；等级 + 设防道数（GB 50108 地下 · GB 50345 屋面）。
- **保温**：岩棉 / 聚苯板（EPS / XPS）/ 聚氨酯 / 气凝胶；核心指标 **导热系数 λ**。
- **密封**：硅酮 / 改性硅烷 / 聚氨酯胶。

## 一条硬线

**燃烧性能等级**（GB 8624）—— 保温材料的火灾风险是外保温的命门（JGJ 144 强条）。

## 2026

**一体化**（保温装饰一体板）· 超低能耗 / 被动房（GB 55015）· 气凝胶 · A 级防火保温。
