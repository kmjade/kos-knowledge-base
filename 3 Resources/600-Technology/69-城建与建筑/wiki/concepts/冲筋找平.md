# 冲筋找平

> **概念 / 工艺** — 冲筋找平是抹灰 / 地面找平的核心手段：先在基层按间距做出**「筋」（标筋）**作为厚度与平整基准，再用**长靠尺（刮杠）**在筋之间刮平，使面层与筋齐平。

## 什么是「冲筋」

- **冲筋（标筋）**：用砂浆或抹灰石膏，在墙面（竖向）或地面（横向）抹出一条条**条形基准**，其厚度 = 设计抹灰厚度，其平面 = 最终饰面基准面。
- 以筋为**导轨**，两筋之间填砂浆后用 2m 铝合金靠尺刮平 —— 一次刮出平整面。

## 冲筋 ⊂ 归方找平

| 关系 | 说明 |
| ---- | ---- |
| **冲筋找平** | 一种找平**手段**：保证**单面**平整、垂直（墙面↔地面） |
| [[归方找平]] | **全方位校准**：以冲筋工艺为基础，额外把墙↔顶、墙↔墙交角也归到 90° |

> 归方找平 = 冲筋找平 + 全屋方正校准。

## 与「做灰饼」的关系

抹灰「找规矩」的三步递进：

```
吊直套方（找规矩） → 做灰饼（定厚度） → 冲筋（连成基准） → 刮平（找平）
```

| 工序 | 作用 |
| ---- | ---- |
| 做灰饼 | 用砂浆小块（约 50×50mm）贴在墙面，**定抹灰厚度**；间距 ≤1.5m |
| **冲筋** | 在灰饼之间抹出竖向条筋，**连成找平导轨** |

## 施工流程

`基层处理 → 找规矩(吊直套方) → 做灰饼 → 冲筋(间距 1.2–1.5m) → 靠尺刮平 → 搓毛/压实 → 养护`

## 关键控制

| 项 | 要点 |
| ---- | ---- |
| 筋的垂直 / 水平 | 靠尺 + 线锤 / 激光线校准 |
| 筋的间距 | 约 **1.2–1.5m**（不超靠尺有效长度） |
| 厚度一致 | 各筋同厚 · 与灰饼齐平 |
| 靠尺 | 2m 铝合金刮杠 · 力度均匀 |
| 分层 | 单遍不宜过厚 · 总厚 ≥35mm 须加强（挂网） |
| 养护 | 保湿 ≥7d（防早期开裂） |

## 应用

- 墙面**一般抹灰**（水泥砂浆 / 混合砂浆 / 粉刷石膏）。
- **地面找平**（找平层 / 自流平前置）。
- **保温层薄抹灰**（外保温系统）。
