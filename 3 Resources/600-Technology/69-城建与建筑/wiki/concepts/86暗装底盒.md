# 86暗装底盒

> **概念 / 材料** — 86 型暗装底盒（俗称**暗盒 / 接线盒**）是**预埋于墙体**内的电气接线盒，用于安装 **86 mm × 86 mm** 面板的开关、插座、网络 / 电视等面板。

## 基本参数

| 属性 | 值 |
| ---- | -- |
| 规格 | **86 型**（行业标准） |
| 面板尺寸 | 86 × 86 mm |
| 底盒（暗盒）尺寸 | 约 75×75 ~ 80×80 mm |
| 安装孔中心距 | **60.3 mm**（国际标准） |
| 深度 | H38 / H45 / H50 / H60 / H70 mm |
| 线管接口 | Ø20 / Ø25 mm |
| 材质 | **阻燃 PVC**（主流）· 金属（镀锌钢 / 达克罗防腐） |

## 通用性

底盒规格统一，**面板可互换** —— 同一 86 盒可装开关、电源插座、网络、电视、电话等各类 86 型面板，仅面板随品牌 / 型号不同。

## 分类

| 维度 | 类型 |
| ---- | ---- |
| 安装方式 | **暗装**（埋墙）/ 明装（明装盒）—— 两者不混用 |
| 材质 | PVC（阻燃、绝缘）/ 金属（坚固、屏蔽、防火） |
| 深度 | H38 / H45 / H50 / H60 / H70（深盒容线更多、利于散热） |
| 组合 | 单盒 / **多联盒**（连排拼接，多联排安装不错位） |

## 结构

盒体 · 敲落孔（进出线孔）· 螺丝孔（螺母耳 / 铁片，铜芯或达克罗更耐用、抗滑丝）· 连接件（连排）。

## 作用

- **保护 + 连接电线**：线管内的电线在此过渡 / 接头。
- **定位 + 固定**：为面板提供安装孔基准，决定面板是否端正、牢固。
- 与房屋同寿命 → 需选**高强度、阻燃、螺口耐用**的产品。

## 选型要点

| 要点 | 说明 |
| ---- | ---- |
| 材质 | 耐高温**阻燃 PVC** 或金属；避免再生料（发脆、易裂、阻燃不达标） |
| 壁厚 | 加厚，水泥回填不易压瘪 |
| 螺口 | 铜芯 / 达克罗螺栓，多次拆装不滑丝 |
| 尺寸 | 国标尺寸，误差小、安装牢固 |
| 认证 | **3C 认证** |

## 相关规格

- **118 型 / 120 型**（面板更大 / 长方，暗盒与之对应，不可与 86 混用）。
- 穿线管：PVC 阻燃管 Ø16 / Ø20 / Ø25。

## 规范

- 国标尺寸 86×86；安装孔中心距 60.3 mm。
- **GB 50303-2015** 建筑电气工程施工质量验收规范 · **GB 55024-2022** 建筑电气与智能化通用规范（强制）。
- 阻燃 / 3C 认证（电工辅料安全）。
