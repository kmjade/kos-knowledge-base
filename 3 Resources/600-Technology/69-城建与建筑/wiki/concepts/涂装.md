# 涂装

> **概念** — 以涂料在基面上形成装饰 + 保护面层的工艺；[[698-装饰装修|装饰装修]] 中「面饰成型」的主力。

## 定义

**涂装（Painting / Coating）** 是把涂料施于基面形成连续涂膜的工序，同时兑现**观感 · 耐候 · 室内空气环保**三项结果。涂料只是「半成品」，**成败一半在基层、在配套**。

## 两套正交分类

| 轴 | 依据 | 取值 |
| -- | ---- | ---- |
| 标准轴（GB 50210 §12） | 分散介质 | 水性涂料涂饰 · 溶剂型涂料涂饰 · 美术涂饰 |
| 应用轴 | 产品 / 部位 | 乳胶漆 · 真石漆（仿石）· 艺术涂料 · 木器漆 · 金属漆 · 无机涂料 |

> 常见误区：把「真石漆 / 木器漆」当作与「水性 / 溶剂型」并列的类别 —— 二者是不同轴。「真石漆 / 多彩」多为**水性**；「木器漆 / 金属漆」按**用途**命名，水性或溶剂型皆有。

## 工艺与关键数

`基层处理(清污 · 消碱 · 找平) → 含水率检测 → 抗碱封闭底漆 → 腻子+打磨 → 底漆 → 面漆(≥2 遍) → 养护 → 验收`

- **含水率**：溶剂型 ≤8% / 乳液型 ≤10% / 木材 ≤12%
- **环境温度**：水性涂料 5–35℃；厨卫找平层用耐水腻子
- 涂层须**养护期满**后验收（GB 50210 §12.1）

## 2026 三个位移

1. **溶剂型 → 水性化**：中国水性涂料渗透率 2025 年破 42%，VOC 法规驱动。
2. **仿石漆替代石材外墙**：多彩 / 水包水 / 水包砂成乡村与住宅外墙主流。
3. **无机 / 功能涂料**：硅酸盐 · 磷酸盐 · 钛酸盐基无机涂料（防火 · 耐候 · 透气）与反射隔热涂料成增长极。

## 与其他概念的关系

- 依附 [[抹灰饰面]] / [[铺贴]] 提供的基层；面层质量受「腻子↔底漆↔面漆」配套制约。
- 环保限量：[[GB 30981]]（2026-06-01 实施的建筑 / 工业涂料限量）。
- 验收：[[GB 50210]] §12。
