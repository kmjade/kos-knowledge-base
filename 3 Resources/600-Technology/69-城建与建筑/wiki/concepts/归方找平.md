# 归方找平

> **概念 / 工艺** — 归方找平（规方找平）是以**激光水平仪 + 冲筋工艺**，用石膏或水泥砂浆对墙面 / 地面 / 顶面做**全方位校准**，使房间各面夹角精准 **90°**、面层平整的找平做法。

## 是什么

- **归方**：把房间的墙、地、顶规整为**方正** —— 各面交角 90°、墙面垂直、地面水平。
- **找平**：把基层的不平整找平（平整度 / 垂直度达标）。
- 合起来 = **「全方位校准」**：既保证墙面 ↔ 地面垂直，又让墙面 ↔ 顶面、墙面 ↔ 墙面都呈 90°。

## 与「冲筋找平」的区别

| 维度 | 冲筋找平 | **归方找平** |
| ---- | ---- | ---- |
| 校准范围 | 主要保证墙面与地面垂直 | **全方位**（墙↔地 · 墙↔顶 · 墙↔墙交角） |
| 目标 | 单面平整、垂直 | **全屋方正** + 平整 |
| 适用 | 常规墙面找平 | 定制柜 / 无主灯 / 大板铺贴等对「方正」敏感处 |

## 施工四步（参考）

| 步 | 内容 |
| ---- | ---- |
| 1 基层处理 | 清浮灰 → 铲除空鼓松动 → 修补 → **刷界面剂**（防脱落） |
| 2 归方放线 | 激光水平仪定中心点 → 弹**十字基准线 + 归方控制线**；以最长 / 最宽墙为参考，测各墙最高 / 最低点定找平厚度 |
| 3 冲筋 | 竖向做「筋」，间距 **800–1200mm**；铝合金靠尺 + 激光线反复校准，确保筋垂直平整 |
| 4 找平刮涂 | 筋间满批抹灰石膏 → 长靠尺刮动找平 → 稍干压实收光 |

## 关键控制

- **基层**：清理 · 润湿（无明水）· 界面剂 —— 决定是否空鼓 / 开裂。
- **标高**：多点控制（间距 1–2m）→ 找平层厚度均匀，避免「中间高四周低」。
- **冲筋**：间距 · 高度与标高一致 · 垂直度（线锤 / 垂直度仪）。
- **精度**：最终墙面平整度误差 **≤3mm**（GB 50210 验收允差）。
- **养护**：7–14d，保湿防早期失水开裂。

## 价值

1. **避免「大小头」缝隙** —— 定制柜 / 门套 / 踢脚线接缝严丝合缝。
2. **避免射灯「洗墙」波浪纹** —— 无主灯设计的关键（平整如镜）。
3. **提升定制复尺精度** —— 墙面误差小，可直接精准复尺下单。
4. **墙体加固** —— 铲墙皮 + 界面剂 + 厚批石膏，降低后期开裂 / 空鼓。

> **不必盲目全屋归方**：优先做**全屋定制区域墙面**与**射灯洗墙区**两处，性价比最高。

## 与铺贴的关系

大板 / 岩板等块材铺贴对基层**方正与平整**极敏感 —— 铺贴前须完成找平（基层平整度控制在约 10mm 以内），否则「越贴越歪」、收口缝宽不均、空鼓率上升。归方找平为其提供**方正、平整、可控**的基准面（参见 [[04-铺贴工程|04 铺贴工程]]）。
