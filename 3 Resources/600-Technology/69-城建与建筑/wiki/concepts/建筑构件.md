# 建筑构件

> **概念** — 把「材料」组装成「部件」的中间层（墙 / 屋面 / 楼地面 / 楼梯 / 门窗）；设计（72 建筑）与施工的交接面。

## 五类（UDC 692.x）

| 类号 | 构件 | 核心 |
| :--: | ---- | ---- |
| 692.2 | 墙 | 承载 · 分隔 · 保温 |
| 692.4 | 屋面 | 防水 · 排水 · 保温隔热 |
| 692.5 | 楼地面 | 承载 · 找平 · 隔声 |
| 692.6 | 楼梯 | 疏散 · 踏步 · 栏杆 |
| 692.7 | 门窗 | 气密 · 水密 · 节能 |

## 构造层次（「叠」出来的性能）

- 屋面：面层 → 防水层 → 找平层 → 保温层 → 找坡层 → 结构层。
- 地面：面层 → 结合层 → 找平层 → 垫层 → 基层。

性能不靠单一材料，靠**层次组合 + 节点**。

## 2026

装配式（叠合板 / 预制墙 / 预制楼梯）· 一体化（保温装饰一体板）· 性能化设计（PBD）。
