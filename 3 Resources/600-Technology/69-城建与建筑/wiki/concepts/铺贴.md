# 铺贴

> **概念** — 用离散块材（砖 / 板 / 石）拼出连续面的**块材饰面**工艺；核心矛盾是「块多 · 缝多 · 粘结面隐蔽」。

## 定义

**铺贴（Tiling / Paving）** 以粘结材料将墙地砖、石材、大板 / 岩板等块材固定于基层。质量看不见，只能靠**空鼓敲击 + 拉拔**事后验证。

## 两个维度：部位 × 工法

| 部位 | 规范 | 要点 |
| ---- | ---- | ---- |
| 内墙砖 | [[GB 50210]] §10.2 | 满粘法 · 大面与阳角无空鼓 |
| 外墙砖 | [[GB 50210]] §10.3 + JGJ 126 | ≤100m · ≤8 度 · 满粘 · 样板件 |
| 墙面石材 / 板 | [[GB 50210]] §9 饰面板 | 干挂 / 湿贴 / 粘贴 |
| 地面砖石 | GB 50209 | 结合层 · 无空鼓 |

| 工法 | 做法 | 适用 |
| ---- | ---- | ---- |
| 厚贴（传统） | 水泥砂浆 15–20mm | 小规格 · 普通砖 |
| 薄贴 | 瓷砖胶 3–10mm（齿刀刮胶） | 主流；大板 / 岩板必用 |
| 干挂 / 点挂 | 金属挂件 / 背栓 | 石材 · 大板 · 高处 |

## 瓷砖胶等级（[[JC-T 547|JC/T 547]]）

| 代号 | 含义 |
| ---- | ---- |
| C1 / C2 | 拉伸粘结强度 ≥0.5 / ≥1.0 MPa（大板 · 岩板 · 厨卫 · 地暖必选 C2） |
| T / S1·S2 / E | 抗滑移 / 柔性 / 延长开放时间 |

> 顶配 **C2TES1**。选错等级 = 空鼓脱落的头号根因。

## 空鼓：贯穿始终的命题

- **定性**：内墙满粘法 大面 / 阳角无空鼓；外墙 无空鼓 · 裂缝；地面砖石 无空鼓。
- **根因**：基层强度与平整不足 · 粘结料不饱满（未双面上胶）· 材料等级不匹配 · 养护期扰动。
- 阳角是重灾区；大板 / 岩板铺贴空鼓率目标 <5%。

## 与其他概念的关系

- 基层同 [[抹灰饰面]]；干挂工法与 [[幕墙]] 同源。
- 2026 大规格化：薄贴 + 双面上胶 + 找平器成为标准动作（[[JC-T 547|JC/T 547]] 为粘结材料依据）。
