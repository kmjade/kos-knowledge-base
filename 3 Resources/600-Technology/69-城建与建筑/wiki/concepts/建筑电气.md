# 建筑电气

> **概念** — 696 的「电」一侧 —— 供配电 · 照明 · 弱电（智能化）· 防雷接地。既是**动力**，也是今天**能源转型的载体**。

## 四条主线

| 主线 | 关键 |
| ---- | ---- |
| 供配电 | 负荷分级 · 供电可靠性 · ≤35kV |
| 照明 | 照度 · 眩光 · 能效 |
| 弱电 / 智能化 | 综合布线 · BA · 安防 |
| 防雷接地 | 接闪 · 引下 · 接地 · 等电位 |

## 总纲

**GB 55024-2022**《建筑电气与智能化通用规范》（强制，适用 ≤35kV）。

## 2026：从「耗能末端」到「能源节点」

1. **光储直柔（PEDF）**：光伏 + 储能 + 直流 + 柔性 —— 建筑新型配电系统。
2. **建筑直流配电**：T/CABEE 030-2026。
3. **零碳建筑电气**（25DX016-1）· 微电网 · 储能 · 充电桩。
