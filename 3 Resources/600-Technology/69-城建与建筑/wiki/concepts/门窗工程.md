# 门窗工程

> **概念** — 连接室内外的**洞口系统**；[[698-装饰装修|装饰装修]] 中同时承担**物理性能**与**安全**双责的一行，一半是「装修」，一半是「建筑构件」。

## 定义

**门窗工程**指门窗（木 / 金属 / 塑料 / 特种门）与门窗玻璃的安装及收口。它决定气密 · 水密 · 抗风压 · 隔声 · 保温等物理性能，并涉及防坠落、防雷等安全指标。

## 五类分项（GB 50210 §6）

| 分项 | 对象 |
| ---- | ---- |
| 木门窗 / 金属门窗 / 塑料门窗 | 常规门窗 |
| 特种门 | 防火 / 防盗 / 自动门等 |
| 门窗玻璃 | 平板 / 中空 / 夹层 / 安全玻璃 |

## 安全红线

- **6.1.11**（原强条）：外门窗安装必须牢固，**砌体上严禁射钉固定** → 现由 [[GB 55032-2022]] 接管。
- **6.1.12**（原强条）：推拉门窗扇必须牢固并**装防脱落装置**。
- 金属门窗扇：开关灵活 · 关闭严密 · 无倒翘；推拉扇开关力 **≤50N**；框墙缝隙填嵌饱满 + 密封胶。

## 2026：从「门窗」到「系统窗」

- **系统窗**（GB/T 39529）：型材 / 玻璃 / 五金 / 密封**成套设计验证**，替代现场拼凑。
- 性能分级（GB/T 31433）：气密 ≥7 级（公建 10 层+）/ ≥6 级 · 水密 ≥3 级 · 抗风压 ≥4 级（7 层+）。
- 节能：断桥铝 + Low-E 中空 / 三玻两腔；电动 / 智能门窗。
- 主要产品标准：铝合金门窗 GB/T 8478-2020 · 检测 GB/T 7106-2019。

## 与其他概念的关系

- 与 [[幕墙]] 同属「外围护 / 洞口」系统；安装收口与 [[涂装]] · [[铺贴]] 交接。
- 验收：[[GB 50210]] §6；安全强条由 [[GB 55032-2022]] 接管。
