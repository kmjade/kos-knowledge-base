# 管线综合

> **概念** — 把水 / 气 / 电三条系统在**有限空间**里排得下、撑得住、测得准。三大命题：**排布 · 承重 · 验证**。

## 排布原则

| 原则 | 内容 |
| ---- | ---- |
| 优先级 | 重力管（有坡度）先排 · 大管优先 |
| 避让 | **小管让大管 · 有压让无压** |
| 分层 | 电在上 / 风管单独 |
| 空间 | 检修 ≥300×300mm · 净高控制 |

## 支吊架

固定 / 活动 / **抗震**；综合支吊架（多管共用）须受力计算。规范：GB/T 17116 · GB 50981-2014 · T/CECS 420-2022。

## 试压与调试

给水→水压（强度 + 严密性）· 排水→灌水 / 通球 / 闭气 · 通风空调→漏风量 · 电气→绝缘 / 接地电阻 · 消防→**联动调试**。

## 工具：BIM 深化

**GB/T 51235-2017** §5.5 机电深化设计 —— 碰撞检查 → 预留预埋 → 净空控制 → 支吊架荷载验算；模型细度 ≥ LOD400。
