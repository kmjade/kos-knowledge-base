# 钛白粉

> **概念 / 材料** — 钛白粉即**二氧化钛（TiO₂）颜料**，折射率高、光散射强、遮盖力与着色力居白色颜料之首，号称「白色颜料之王」，是 [[乳胶漆]] 等建筑涂料的**核心白色颜料**。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 化学式 | TiO₂ |
| CAS | 13463-67-7 |
| 晶型 | **锐钛型（A, anatase）· 金红石型（R, rutile）** |
| 折射率 | 锐钛 ≈2.55 · 金红石 ≈2.71–2.80 |
| 最佳粒径 | 约 **0.2–0.3 μm**（可见光半波长） |

## 两种晶型

| 晶型 | 折射率 | 耐候 / 抗粉化 | 硬度 | 典型用途 |
| ---- | :--: | :--: | :--: | ---- |
| **金红石型 (R)** | 高 | 优（吸收 UV-A 保护漆膜） | 较硬 | 外墙 / 户外涂料 · 汽车 / 工业漆 · 高端塑料 |
| **锐钛型 (A)** | 较低 | 较差 | 较软、低磨耗 | 内墙 · 造纸 · 化纤消光 · 化妆品 · 陶瓷 |

## 为什么遮盖力最强

- **高折射率** → 与基料（折射率 ~1.5）差异大 → 折射型光散射强 → 遮盖力、着色力最优。
- 金红石型吸收 **UV-A（350–400 nm）** 并转为热，保护漆膜有机成分，故耐候性远胜锐钛型。

## 生产工艺

| 工艺 | 要点 | 特点 |
| ---- | ---- | ---- |
| **硫酸法** | 钛矿溶于硫酸 → 水解 → 煅烧 | 成熟；可制锐钛 / 金红石；废酸与副产物多 |
| **氯化法** | 钛矿 + 氯气 → TiCl₄ → 高温氧化 | 质量高、着色力强、废弃物少、更清洁；**当前主流** |

> 后续均经**表面处理**：Al₂O₃ / SiO₂ 无机包膜 + 有机处理，改善分散性与耐候性。

## 主要用途

| 领域 | 作用 |
| ---- | ---- |
| **涂料**（最大用量） | 白度 · 遮盖力 · 耐候（外墙优先金红石） |
| 塑料 / 母粒 | 白色浓缩 · 遮盖 · 耐候 |
| 造纸 / 油墨 | 遮盖 · 白度 · 印刷 |
| 橡胶 / 化纤 | 填充 · 消光 |
| 化妆品 / 防晒 | 物理防晒 · 遮盖（化妆级重金属限值严） |
| 陶瓷 / 食品 / 医药 | 乳浊 · 着色（食品 / 医药级） |

## 关键指标

TiO₂ 含量 · 白度 / 色相 · **着色力（消色力）** · **遮盖力 / 散射力** · 吸油量 · 105 ℃ 挥发物 · 水溶物 · 45 μm 筛余 · pH · 电阻率 · 分散性 · 耐候性。

## 标准

- **GB/T 1706-2006**《二氧化钛颜料》—— 分类 **A1/A2（锐钛）· R1/R2/R3（金红石）**；适用硫酸法或氯化法生产；主要用于涂料、橡胶、塑料、油墨、造纸等行业。
- 配套：GB/T 30793（XRD 测锐钛/金红石比）· GB/T 5211 系列（颜料通用试验方法）。

## 2026 三条位移

1. **氯化法国产化** —— 高端金红石着色力与耐候替代进口。
2. **硫酸法绿色化** —— 废酸回用 / 副产物资源化。
3. **专用化** —— 化妆级（重金属严限）· 塑料母粒级 · 平光乳胶漆专用级。
