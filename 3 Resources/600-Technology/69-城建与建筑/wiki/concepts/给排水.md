# 给排水

> **概念** — 696 MEP 的「水」一侧 —— 生活给水 · 排水 · 雨水 · 消防水。核心是**水质 · 水压 · 水量**，外加**排放通畅**与**消防可靠**。

## 四条子系统

| 子系统 | 关键 |
| ------ | ---- |
| 给水 | 水量 · 水压 · 水质 · 防回流污染 · 二次供水 |
| 排水 | 坡度 · 存水弯水封 ≥50mm · 通气防虹吸 |
| 雨水 | 重现期 · 溢流 |
| 消防水 | 消火栓 · 自动喷水 · 灭火器（强条最密） |

## 一条总纲

**GB 55020-2021**《建筑给水排水与节水通用规范》（强制）+ [[GB 55036-2022]]《消防设施通用规范》。

## 2026 三个位移

① 管材 → **薄壁不锈钢**；② 二次供水**智能化**（无负压 + AI）；③ 装配与节水（中水 / 雨水回用）。
