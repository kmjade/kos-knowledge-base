# 乳胶漆

> **概念 / 材料** — 乳胶漆即**合成树脂乳液涂料**，以合成树脂**乳液**为成膜基料、以**水**为分散介质的水性墙面涂料，是建筑内 / 外墙装饰的主力材料。

## 组成（四大组分）

| 组分 | 作用 | 代表 |
| ---- | ---- | ---- |
| **乳液**（成膜物） | 决定漆膜性能与附着 | 苯丙 · 纯丙 · 醋丙 · 硅丙 · VAE |
| **颜填料** | 着色 / 遮盖 / 增量 | [[钛白粉]]（TiO₂）· [[双飞粉]]（重钙）· 滑石粉 · 高岭土 |
| **助剂** | 调施工与储存 | 分散 · 润湿 · 成膜助剂 · 增稠 · 消泡 · 防霉 · 防冻 |
| **水** | 分散介质（无有机溶剂） | — |

## 分类

- **部位**：内墙漆 / 外墙漆（外墙需耐候、抗紫外、抗污）。
- **工序**：底漆 / 面漆（中涂）。
- **光泽**：平光 / 哑光 · 丝光 / 半光 / 高光。
- **功能**：净味 · 抗甲醛 · 抗菌 · 耐擦洗等。

## 关键性能指标

| 指标 | 含义 |
| ---- | ---- |
| 对比率 | 遮盖力（≥0.90 合格，≥0.95 优等） |
| 耐洗刷性 | 内墙耐擦洗次数 |
| 耐水 / 耐碱性 | 漆膜抗泛碱、抗起皮 |
| 附着力 · 耐候性 | 外墙关键指标 |
| VOC / 甲醛含量 | 环保限量 |

## 标准与规范

| 标准 | 内容 |
| ---- | ---- |
| GB/T 9755（2024 版「合成树脂乳液墙面涂料」） | 墙面涂料产品要求（原内墙 GB/T 9756 · 外墙 GB/T 9755-2014） |
| **GB 18582-2020** | 《建筑用墙面涂料中有害物质限量》（**强制性**）：VOC 内墙 ≤80 g/L · 外墙 ≤120 g/L · 甲醛 ≤50 mg/kg 等 |
| GB 50210 / GB 55032 | 涂饰工程施工与验收 |

## 2026 三条位移

1. **低 VOC / 净味** —— 环保限值收紧（GB 18582-2020）驱动配方水性化、无添加。
2. **功能化** —— 抗甲醛 · 抗菌 · 抗污 · 保温隔热等复合功能。
3. **无机 / 艺术涂料** —— 无机涂料（硅酸盐/硅溶胶）、艺术涂料分流高端市场。
