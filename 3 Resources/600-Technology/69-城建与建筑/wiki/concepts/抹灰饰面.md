# 抹灰饰面

> **概念** — 用砂浆把毛坯基层找平成「可饰面基面」的现场湿作业；[[698-装饰装修|装饰装修]] 七项工艺中唯一**不以「被观看」为目的**的工序。

## 定义

**抹灰（Plastering / Rendering）** 是以水泥 / 石灰 / 石膏等胶凝材料配制砂浆，**分层涂抹**于基层，形成平整、牢固、吸水均一的**基面**。它产出的是「下一道工序的作业条件」——饰面质量的七八成在此层定型。

> 边界：[[693-砌筑与建筑工艺|693 砌筑]] 与 698 均有「抹灰」——693 是砌筑施工的一环（工艺视角），698 是饰面成型的地基层（饰面视角）。同一工序两个视角。

## 四类分项（GB 50210 §4）

| 分项 | 定义 | 代表工艺 |
| ---- | ---- | -------- |
| 一般抹灰 | 找平找直，普通 / 高级两级 | 水泥砂浆 · 水泥混合砂浆 · 聚合物水泥砂浆 · 粉刷石膏 |
| 保温层薄抹灰 | 保温层外聚合物砂浆薄抹 | 外墙外保温系统 |
| 装饰抹灰 | 直接做出装饰效果 | 水刷石 · 斩假石 · 干粘石 · 假面砖 |
| 清水砌体勾缝 | 不抹，只勾缝 | 砂浆勾缝 / 原浆勾缝 |

## 主线：把「异质毛坯」洗成「均质基面」

| 先天矛盾 | 手段 |
| -------- | ---- |
| 不平整 | 吊直套方 · 灰饼(≤1.5m) · 冲筋 · 靠尺 |
| 不牢固 / 异质 | 凿毛 · 界面剂 · 挂网（搭接 ≥100mm） |
| 吸水不一 | 湿润 · 分层间隔 · 湿润养护（≥7d） |

**病害机理**：强度梯度须满足 **中层 ≤ 底层 ≤ 基层**，否则收缩应力撕开裂口；单遍 7–9mm，总厚 ≥35mm 须加强。空鼓 / 开裂 / 脱落三大通病，根多在基层而非常面层。

## 与其他概念的关系

- 是 [[涂装]] · [[铺贴]] · [[裱糊与软包]] 的**基层前提**（基层平整度、含水率、碱度直接决定饰面成败）。
- 施工与验收：[[GB 50210]] §4；其原强制条文现由 [[GB 55032-2022]] 接管。
- 与砌筑的分工见 [[693-砌筑与建筑工艺|693 砌筑与建筑工艺]]。
