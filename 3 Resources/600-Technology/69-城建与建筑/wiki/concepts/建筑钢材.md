# 建筑钢材

> **概念** — 强度高、可焊、可工业化；钢结构与钢筋混凝土的两大「骨」之一。

## 品种

钢筋（光圆 / 带肋 / 预应力）· 型钢（H 型 / 工字 / 角钢）· 钢板 · 钢管 · 钢丝绳。

## 牌号体系

| 用途 | 牌号 |
| ---- | ---- |
| 钢筋 | HPB300（光圆）· HRB400 / 500 / 600（带肋）· HRB400E（抗震） |
| 结构钢 | Q235 · **Q355**（代 Q345）· Q390 / Q460（高强） |

## 关键指标

屈服强度 · 抗拉强度 · 伸长率 · **碳当量**（可焊性）· 冲击韧性。

## 2026

**高强钢筋 HRB600** · 高强钢（Q460+）· 钢结构装配式 · 耐候钢。

## 与其他概念的关系

- 用于 [[混凝土]]（配筋）与 [[建筑构件]] / [[安装工艺]]（钢结构）。
- 核心规范：GB/T 1499.2-2024 · GB/T 1591-2018 · **GB 50017-2017**（设计）· **GB 50205-2020**（验收）。
