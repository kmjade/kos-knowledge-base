# GB/T 28627-2023

> **实体** — 《抹灰石膏》，推荐性国家标准，2023-10-01 实施，全部代替 GB/T 28627-2012。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB/T 28627-2023 |
| 名称 | 抹灰石膏（又名抹灰石膏砂浆）（Gypsum plaster） |
| 类型 | 推荐性国家标准（产品标准） |
| 发布 / 实施 | 2023-03-17 / 2023-10-01 |
| 代替 | GB/T 28627-2012（2012 版于 2023-10-01 废止） |
| 提出 / 归口 | 中国建筑材料联合会 / SAC/TC 195 |
| CCS / ICS | Q13 / 91.100.10 |
| 采标 | 非等效采用 EN 13279-1:2005（2012 版口径） |
| 状态 | 现行 |

## 适用范围

规定抹灰石膏的**分类和标记、一般要求、技术要求、试验方法、检验规则**以及包装、标志、运输和贮存；适用于**建筑物室内墙面和顶棚基底找平**用的石膏砂浆抹灰材料。

## 2023 版主要变化（对照 2012）

| 维度 | 变化 |
| ---- | ---- |
| 术语 | 更改「抹灰石膏」定义；**删除「面层抹灰石膏」**；**删除「保温层抹灰石膏」** |
| 命名 | 「轻质底层抹灰石膏」→ **轻质抹灰石膏**；「底层抹灰石膏」→ **重质抹灰石膏** |
| 分类 / 一般要求 | 更改分类和标记；更改一般要求 |
| 性能 | **删除细度**技术要求与试验方法；更改**保水率**要求与试验方法 |
| 新增指标 | **增加硫酸钙含量、放射性核素限量**指标 |
| 删除指标 | 删除面层 / 保温层抹灰石膏强度、保温层体积密度、导热系数要求 |
| 装置 | 保水率测定装置 → 保水率**测定仪** |
