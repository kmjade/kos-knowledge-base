# JC/T 547

> **实体** — 《陶瓷砖胶粘剂》（瓷砖胶）的建材行业标准，铺贴选材的核心依据。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | JC/T 547-2017（现行）→ JC/T 547-2026（**2026-12-01 实施**） |
| 名称 | 陶瓷砖胶粘剂 |
| 类型 | 建材行业标准 |
| 归口 | 全国轻质与装饰装修建筑材料标准化技术委员会 |
| 状态 | 2017 版现行，2026-12-01 起由 2026 版代替 |

## 关键内容

- 强度等级：**C1**（拉伸粘结强度 ≥0.5MPa）· **C2**（≥1.0MPa）。
- 性能代号：**T**（抗滑移）· **S1 / S2**（柔性）· **E**（延长开放时间）。
- 顶配组合 **C2TES1**：大板 / 岩板 / 墙砖 / 地暖通用。

## 挑选逻辑

| 场景 | 选型 |
| ---- | ---- |
| 室内干区 · 小规格陶质砖 | C1 |
| 厨卫 · 阳台 · 淋浴区 | C2 |
| 大板 / 岩板（≥600×1200） | C2T / C2TES1 |
| 地暖房间 | C2S1 / C2TES1 |

## 与其他实体的关系

- 服务于 [[铺贴]]；配套 [[GB 50210]] §10 饰面砖工程。
