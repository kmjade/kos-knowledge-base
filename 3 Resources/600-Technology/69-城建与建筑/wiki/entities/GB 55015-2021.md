# GB 55015-2021

> **实体** — 《建筑节能与可再生能源利用通用规范》，建筑节能领域的强制性工程建设规范。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 55015-2021 |
| 名称 | 建筑节能与可再生能源利用通用规范 |
| 类型 | 强制性工程建设规范（全文强制） |
| 实施 | 2022-04-01 |
| 状态 | 现行 |

## 作用

新建 / 扩建 / 改建及既有建筑节能改造的设计、施工、验收及运行管理必须执行；**被动优先 + 可再生能源**，是建筑「双碳」的底线规范。
