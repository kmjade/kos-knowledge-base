# GB 55024-2022

> **实体** — 《建筑电气与智能化通用规范》，电气与智能化的强制性工程建设规范。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 55024-2022 |
| 名称 | 建筑电气与智能化通用规范 |
| 类型 | 强制性工程建设规范（全文强制） |
| 实施 | 2022-10-01 |
| 状态 | 现行 |

## 作用

供电电压 ≤35kV 的工业与民用建筑和市政工程电气与智能化系统必须执行；废止 GB 50303-2015 · GB 50314-2015 · GB 50601-2010 等一批旧强条。
