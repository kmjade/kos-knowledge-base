# GB 55032-2022

> **实体** — 《建筑与市政工程施工质量控制通用规范》，全文强制的工程建设通用规范；接管了多项旧标准的强制性条文。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 55032-2022 |
| 名称 | 建筑与市政工程施工质量控制通用规范 |
| 类型 | 强制性工程建设规范（全文强制） |
| 发布 | 2022-07-15（住建部公告 2022 年第 117 号） |
| 实施 | 2023-03-01 |
| 状态 | 现行 |

## 作用

全文强制；**现行工程建设标准与本规范不一致的，以本规范为准**。它废止了一批旧标准中的强制性条文，其中包括 [[GB 50210]] 的 5 条。

| 场景 | 原依据 → 现依据 |

| 重型设备 / 振动设备不得安装在吊顶龙骨上 | GB 50210 7.1.12 → 本规范 §3.3.7 |
| 外门窗安装牢固、砌体上严禁射钉固定 | GB 50210 6.1.11 → 本规范 §3.3.7 |
| 推拉门窗扇防脱落 | GB 50210 6.1.12 → 本规范 §3.3.7 |
