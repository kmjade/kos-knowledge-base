# GB 55020-2021

> **实体** — 《建筑给水排水与节水通用规范》，给排水与节水的强制性工程建设规范。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 55020-2021 |
| 名称 | 建筑给水排水与节水通用规范 |
| 类型 | 强制性工程建设规范（全文强制） |
| 实施 | 2022-04-01 |
| 状态 | 现行 |

## 作用

建筑给水排水与节水工程的设计、施工、验收必须执行；废止 GB 50015-2019 · GB 50242-2002 等一批旧强条。
