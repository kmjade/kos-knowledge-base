# 抹灰机器人

> **实体** — 自动完成墙面砂浆抹平的建筑机器人，建筑机器人中率先规模化落地的场景。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 类型 | 建筑机器人（内墙抹灰） |
| 效率 | 300–700㎡/天（人工的 5–10 倍） |
| 质量 | 空鼓率约 0.08%（人工 0.7–1.2%） |
| 关键参数 | **≈30kg 对墙压力**（对应「垂4平4、粘结 0.2MPa」） |
| 代表厂商 | 蔚建科技 · 中建八局「智能装备 + 产业工人」 |
| 相关标准 | T/SZCIA 001-2025 建筑抹灰机器人施工技术标准（2025-06-01 实施） |

## 核心特性

- 把大工师傅的**隐性经验参数化**（对墙压力 · 抹压速度 · 抹灰厚度），实现「经验数字化、施工标准化」。
- 与砂浆泵送 + 机械喷涂组成「泵送 + 喷涂 + 刮平」作业链。
- 需配套**机器人专用抹灰砂浆**（解决泵送稳定性差、上墙易流坠）。

## 与其他实体的关系

- 应用于 [[抹灰饰面]]；是智能建造对传统湿作业的替代方向。
