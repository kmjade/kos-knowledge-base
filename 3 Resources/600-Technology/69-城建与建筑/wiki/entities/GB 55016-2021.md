# GB 55016-2021

> **实体** — 《建筑环境通用规范》，保障建筑声 / 光 / 热 / 空气质量的强制性工程建设规范。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 55016-2021 |
| 名称 | 建筑环境通用规范 |
| 类型 | 强制性工程建设规范（全文强制） |
| 实施 | 2022-04-01 |
| 状态 | 现行 |

## 作用

民用建筑及工业建筑中辅助办公类建筑的**声环境 · 光环境 · 建筑热工 · 室内空气质量**的设计、检测及验收必须执行。
