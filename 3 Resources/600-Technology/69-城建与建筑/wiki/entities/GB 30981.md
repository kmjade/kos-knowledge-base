# GB 30981

> **实体** — 《涂料中有害物质限量》系列强制性国家标准，2025 年发布、**2026-06-01 实施**，整合替代 7 项旧涂料限量标准。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 30981.1-2025（建筑涂料）· GB 30981.2-2025（工业涂料） |
| 名称 | 涂料中有害物质限量 · 第 1 / 2 部分 |
| 类型 | 国家标准（强制性） |
| 发布 | 2025-05-30（国标公告 2025 年第 12 号） |
| 实施 | 2026-06-01 |
| 状态 | 现行 |

## 整合替代的旧标准（均于 2026-06-01 废止）

- 第 1 部分：GB 18582-2020（建筑用墙面涂料）· GB 38468-2019（室内地坪涂料）
- 第 2 部分：GB 18581-2020（木器）· GB 24409-2020（车辆）· GB 24613-2009（玩具）· GB 30981-2020（工业防护）· GB 38469-2019（船舶）

## 意义

从「单一指标控制」→「**系统风险防控**」；新增 SVOC、辅助材料（腻子 / 固化剂 / 稀释剂等 12 类）、生物杀伤剂、总铅等管控。

## 与其他实体的关系

- 服务于 [[涂装]]；与 [[GB 50210]] §12 涂饰工程配套。
- 对照：GB 50210 的「2025 版」是讹传，而本标准的「2025 版」是**真实变更**（权威库可查）。
