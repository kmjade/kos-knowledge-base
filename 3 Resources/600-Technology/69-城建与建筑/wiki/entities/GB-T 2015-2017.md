# GB/T 2015-2017

> **实体** — 《白色硅酸盐水泥》，推荐性国家标准，2018-09-01 实施，代替 GB/T 2015-2005。

规定白色硅酸盐水泥的**术语和定义 · 组分与材料 · 分级和代号 · 技术要求 · 试验方法 · 检验规则 · 包装标志运输贮存**；适用于白色硅酸盐水泥的生产与使用。

| 项目 | 要求 |
| ---- | ---- |
| 三氧化硫 SO₃ | ≤3.5% |
| 水溶性铬(Ⅵ) | ≤10 mg/kg |
| 氯离子 | ≤0.06% |
| 45 μm 筛余 | ≤30.0% |
| 凝结时间 | 初凝 ≥45 min · 终凝 ≤600 min |
| 白度 | 按 GB/T 5950-2008（规范性附录） |
| 强度 | 按 GB/T 17671 |
