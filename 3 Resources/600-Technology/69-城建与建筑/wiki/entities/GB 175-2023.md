# GB 175-2023

> **实体** — 《通用硅酸盐水泥》，通用硅酸盐水泥的**强制性国家标准**，2024-06-01 实施，全部代替 GB 175-2007。

## 基本资料

| 属性 | 值 |
| ---- | -- |
| 标准号 | GB 175-2023 |
| 名称 | 通用硅酸盐水泥（Common portland cement） |
| 类型 | 强制性国家标准（产品标准） |
| 发布 | 2023-11-27 |
| 实施 | 2024-06-01 |
| 代替 | GB 175-2007（全部代替） |
| 归口 | 工业和信息化部 |
| CCS / ICS | Q11 / 91.100.10 |
| 状态 | 现行 |

## 适用范围

规定通用硅酸盐水泥的**分类 · 组分与材料 · 强度等级 · 技术要求 · 试验方法 · 检验规则 · 包装/标志/运输/贮存**；适用于通用硅酸盐水泥。

## 六大通用硅酸盐水泥

| 代号 | 名称 |
| ---- | ---- |
| P·I / P·II | 硅酸盐水泥 |
| P·O | 普通硅酸盐水泥 |
| P·S | 矿渣硅酸盐水泥 |
| P·P | 火山灰质硅酸盐水泥 |
| P·F | 粉煤灰硅酸盐水泥 |
| P·C | 复合硅酸盐水泥 |

## 2023 版主要变化（对照 GB 175-2007）

| 维度 | 变化 |
| ---- | ---- |
| 组分 | 更改水泥组分规定；删除「活性混合材料 / 非活性混合材料」规定 |
| 混合材 | 更改矿渣 / 粉煤灰 / 火山灰质 / 石灰石 / 砂岩要求；**删除「窑灰」**；石灰石、砂岩增**亚甲蓝值**检验 |
| 石膏 | 删除天然石膏「二级（含）以上」的规定 |
| 强度等级 | **删除复合硅酸盐水泥（P·C）32.5、32.5R** |
| 健康安全 | **增加水溶性铬(VI) 限量**（GB 31893，≤10.0 mg/kg）与**放射性核素限量**（GB 6566）及测定方法 |
| 安定性 | 增加**压蒸安定性**合格要求，列为**型式检验**项目 |
| 碱含量 | 低碱水泥需求由买卖双方协商确定 |
| 强度 / 细度 | 更改各强度等级 **3d 抗压强度**指标与**细度**要求 |
| 出厂 | 增加**产品质量证明材料**要求（含铬(VI)、放射性、压蒸安定性等型式检验结果） |

## 对本子库的影响

- 是 [[胶凝材料]] 支线的**核心产品标准** —— 定义六大通用水泥的分类、组分与指标。
- 收紧健康与环保限值（铬(VI) · 放射性），与低碳化主线（熟料替代 · 碱激发 / LC3）并行。
