# GB/T 9776-2022

> **实体** — 《建筑石膏》，推荐性国家标准，2023-07-01 实施，代替 GB/T 9776-2008。

## 适用范围

规定建筑石膏的**分类与标记、原材料、技术要求、试验方法、检验规则**以及包装、标志、运输和贮存；适用于**天然石膏、烟气脱硫石膏和磷石膏**制得的建筑石膏，其他工业副产石膏可参照执行。

## 关键定义

- **建筑石膏**（calcined gypsum）—— 天然石膏或工业副产石膏经一定温度煅烧脱水制得，以 **β 半水硫酸钙（β-CaSO₄·½H₂O）** 为主要成分、**不预加任何外加剂或添加物**、用于建筑材料的粉状胶凝材料。
- 分立：**天然建筑石膏** · **脱硫建筑石膏** · **磷建筑石膏**（按原料）。

## 2022 版主要变化（对照 2008）

| 维度 | 变化 |
| ---- | ---- |
| 术语 | 删除「烟气脱硫石膏 / 磷石膏」定义；更改「脱硫建筑石膏 / 磷建筑石膏」定义 |
| 分类 / 原材料 | 更改分类；更改原材料要求 |
| 性能 | 更改组成；更改物理力学性能 —— **取消细度指标，增加干强度指标** |
| 健康环保 | 更改**放射性核素限量**；**增加 pH 要求**；**增加限制成分含量要求**（如水溶性氯离子等） |
| 试验 | 更改组成试验方法；删除细度试验方法；增加干强度试验方法；**增加水溶性氯离子含量测定方法（附录 A）** |
| 检验 | 更改型式检验规定 |

> 版本：1988 首发，2008 第一次修订，2022 第二次修订。
