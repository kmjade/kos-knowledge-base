## 类目

以**砌筑**为代表的现场建筑工艺 —— 砖石砌筑、砌块砌筑、抹灰、混凝土浇筑与养护、防水保温施工等施工作业。
它是**把材料与构件变成实体的执行层**：图纸上的构造层次，在现场一道道做出来。

## 内容要点

| 工艺 | 要点 |
| ---- | ---- |
| 砌砖 | 砖的浇水润湿 · 灰缝厚度（8–12mm）· 组砌方式（一顺一丁 / 三顺一丁）· 皮数杆 |
| 砌块砌筑 | 排块设计 · 灰缝 · 芯柱与构造柱 |
| 石砌 | 毛石 / 料石砌筑 · 勾缝 |
| 抹灰 | 底层 / 中层 / 面层 · 厚度控制 · 阴阳角 |
| 混凝土工程 | 配料 · 搅拌 · 浇筑 · 振捣 · 养护 · 施工缝 |
| 砌体加固 | 构造柱 · 圈梁 · 拉结筋 |
| 防水 / 保温 | 卷材 / 涂膜 · 外保温系统施工 |

## 砌筑研讨（2026-09-28）

> 定位：693 是**最「现场」的一类工艺** —— 砌砖、砌块、石砌、混凝土浇筑、抹灰。它把散料变成结构，靠的是「手 + 规矩」。

**一、工艺谱系**

| 工艺 | 要点 |
| ---- | ---- |
| 砌砖 | 湿润 · 灰缝 8–12mm · 组砌（一顺一丁）· 皮数杆 |
| 砌块 | 排块 · 灰缝 · 芯柱 / 构造柱 |
| 石砌 | 毛石 / 料石 · 勾缝 |
| 混凝土 | 配料 · 搅拌 · 浇筑 · 振捣 · 养护 · 施工缝 |
| 抹灰 | 底层 / 中层 / 面层（详见 698 抹灰研讨） |
| 加固 | 构造柱 · 圈梁 · 拉结筋 |

**二、主线：散料 → 结构的「三个规矩」**

- **材料规矩**：砖需湿润 · 砂浆饱满度 · 块材强度等级与折压比（GB 50574）。
- **几何规矩**：皮数杆 · 轴线位移 · 垂直度 · 灰缝厚度。
- **整体规矩**：构造柱 · 圈梁 · 拉结筋 —— 把脆性砌体「箍」成抗震整体。

**三、边界（693 ↔ 698）**

- 抹灰在 693 是「砌筑工艺的一环」，在 [[698-装饰装修|698 装饰装修]] 是「饰面成型的地基层」—— 同一工序两个视角。

**四、2026 位移**

1. **免抹灰 / 薄抹灰**：砌块精度提升 → 减少湿作业。
2. **装配式**：预制墙板 / 叠合构件替代现场砌筑。
3. **标准换挡**：结构性通用规范（GB 550xx）接管旧强条。

**五、核实**

- **GB 50203-2011** 砌体结构工程施工质量验收规范 —— 权威库记**现行**；网传「GB 50203-2024」**未证实 → 不采信**（与 GB 50210-2025 同类讹传）。

| 砌筑规范 | 说明 |
| --- | --- |
| GB 50203-2011 | 砌体结构工程施工质量验收规范 |
| GB 50574-2010 | 墙体材料应用统一技术规范 |
| GB 50666-2011 | 混凝土结构工程施工规范 |
| GB 50204-2015 | 混凝土结构工程施工质量验收规范 |
