# 03 砌筑工程

> 定位：砌筑是 693 的**代表工艺** —— 用砂浆把砖 / 砌块 / 石「砌」成墙体，靠组砌与拉结构造形成整体。

## 砌砖

| 要点 | 内容 |
| ---- | ---- |
| 材料 | 砖提前浇水润湿 · 砂浆强度与饱满度 |
| 灰缝 | 厚度 **8–12mm** · 水平 / 竖向灰缝饱满 |
| 组砌 | 一顺一丁 · 三顺一丁 · 梅花丁 |
| 控制 | **皮数杆** · 轴线位移 · 垂直度 · 平整度 |

## 砌块砌筑

- **排块设计**：按砌块模数排版，减少砍砖。
- **灰缝**：水平灰缝与竖缝（专用砂浆 / 灌孔）。
- **芯柱 / 构造柱**：配筋灌注，增强整体性。

## 石砌

毛石砌筑（乱毛石 / 平毛石）· 料石砌筑 · 勾缝防渗。

## 砌体加固构造

| 构造 | 作用 |
| ---- | ---- |
| 构造柱 | 约束砌体 · 抗震 |
| 圈梁 | 沿墙顶连续 · 增强整体 |
| 拉结筋 | 墙与柱 / 墙与墙连接 |
| 过梁 | 洞口上方承托 |

## 质控与验收

砂浆试块 · 灰缝饱满度 · 轴线与垂直度 · 构造柱与圈梁（GB 50203）。
