# 06 防水工程

> 定位：防水是建筑的**防护线** —— 靠「设防道数 + 节点处理」防止渗漏，是使用体验与寿命的关键。

## 防水部位

| 部位 | 主要做法 |
| ---- | ---- |
| 地下 | 防水混凝土 · 卷材 / 涂膜外防外贴 |
| 屋面 | 卷材 / 涂膜 · 找坡排水 |
| 卫生间 / 厨房 | 涂膜 · 上翻 · 闭水试验 |
| 外墙 | 防水砂浆 · 节点密封 · 排水空腔 |

## 材料与做法

| 类型 | 说明 |
| ---- | ---- |
| 卷材防水 | 沥青 / 高聚物改性沥青 / 合成高分子卷材 |
| 涂膜防水 | 聚氨酯 · 聚合物水泥（JS）· 水泥基渗透结晶 |
| 防水混凝土 | 抗渗等级 P6 / P8 · 结构自防水 |
| 刚性防水 | 防水砂浆 · 细石混凝土 |

## 核心：节点与设防

- **节点**：阴阳角 · 管根 · 变形缝 · 后浇带 · 落水口（附加层加强）。
- **设防**：按防水等级确定道数（GB 50345 屋面 · GB 50108 地下）。
- **验收**：蓄水 / 淋水试验 · 闭水试验。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 55030-2022 | 建筑与市政工程防水通用规范（强制） |
| GB 50108 / GB 50208 | 地下工程防水（设计 / 验收） |
| GB 50345 / GB 50207 | 屋面工程（设计 / 验收） |
| GB 50208 | 地下防水工程质量验收规范 |
