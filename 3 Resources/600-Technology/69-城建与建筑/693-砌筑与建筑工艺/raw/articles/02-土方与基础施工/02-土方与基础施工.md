# 02 土方与基础施工

> 定位：土方与基础是**施工的第一步** —— 为上部结构提供稳定的支承面与作业面。

## 土方工程

| 工序 | 要点 |
| ---- | ---- |
| 开挖 | 放坡 · 支护 · 机械 / 人工 |
| 降水 | 明排 / 井点降水 · 控制地下水位 |
| 支护 | 土钉墙 · 排桩 · 地下连续墙（深基坑） |
| 回填 | 分层夯实 · 压实度 |

## 基础施工

| 基础 | 施工要点 |
| ---- | ---- |
| 条形 / 独立基础 | 垫层 · 钢筋 · 浇筑 |
| 筏板基础 | 大体积混凝土 · 测温防裂 |
| 桩基础 | 灌注桩 / 预制桩 · 静载试验 |
| 地下室 | 防水 · 抗浮 · 后浇带 |

## 质量控制

轴线与标高 · 基底验槽 · 大体积混凝土温控 · 防水节点 · 沉降观测。
