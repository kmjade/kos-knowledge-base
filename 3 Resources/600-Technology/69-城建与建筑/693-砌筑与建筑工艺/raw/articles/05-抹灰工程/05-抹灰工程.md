# 05 抹灰工程

> 定位：抹灰是**砌筑工艺的一环**（在 693），也是**饰面成型的地基层**（在 698）—— 用砂浆把基层找平，为后续饰面提供基准面。

## 构造层次

```
基层 → 底层（粘结）→ 中层（找平）→ 面层（成型）
```

| 层 | 作用 | 厚度（参考） |
| ---- | ---- | ---- |
| 底层 | 与基层粘结 | 依基层 |
| 中层 | 找平 | — |
| 面层 | 平整 · 光洁 | — |

> 总厚度：普通抹灰 ≤18mm · 高级抹灰 ≤25mm（一次不宜过厚，分层施工）。

## 施工要点

| 要点 | 内容 |
| ---- | ---- |
| 基层处理 | 清理 · 浇水 · 界面剂 · 甩毛 |
| 分层 | 每层不宜过厚 · 待前层凝固后再抹 |
| 控制 | 冲筋 / 标筋 · 阴阳角方正 · 平整度 |
| 护角 | 门窗洞口 / 阳角护角 |
| 特种 | 防水砂浆 · 保温砂浆 · 机械喷涂抹灰 |

## 质量与验收

空鼓 / 开裂 / 脱层检查 · 平整度 / 垂直度 / 阴阳角（GB 50210 §4）。

## 边界（693 ↔ 698）

- 在 693：抹灰是**砌筑找平工艺**；在 [[698-装饰装修|698 装饰装修]]：抹灰是**饰面地基层** —— 同一工序两个视角。
