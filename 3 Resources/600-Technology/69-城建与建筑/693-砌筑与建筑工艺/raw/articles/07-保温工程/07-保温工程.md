# 07 保温工程

> 定位：保温工程是**建筑节能的第一道工序** —— 在围护结构上做保温层，降低传热、防结露、控热桥。

## 保温做法

| 类型 | 说明 |
| ---- | ---- |
| **外墙外保温（ETICS）** | 保温板 + 抹面 + 饰面 · 主流 |
| 外墙内保温 | 室内侧 · 施工简便 · 易热桥 |
| 夹心保温 | 墙体夹层 · 耐久 |
| 自保温 | 自保温砌块 / 加气混凝土 |
| 屋面保温 | 正置 / 倒置式 |
| 地面保温 | 地暖绝热层 |

## 外保温系统构造

```
基层墙体 → 粘结 / 锚固 → 保温板（EPS / XPS / 岩棉 / 聚氨酯）
       → 抹面胶浆 + 玻纤网（增强）→ 饰面层
```

## 关键与质控

| 要点 | 内容 |
| ---- | ---- |
| 粘结 + 锚固 | 双重固定 · 拉拔试验 |
| 防裂 | 抹面层压入玻纤网 · 分格缝 |
| 防火 | 保温材料燃烧性能（GB 8624）· 防火隔离带（JGJ 144 强条） |
| 热桥 | 节点（窗口 / 女儿墙 / 阳台）处理 |
| 验收 | 厚度 · 粘结强度 · 锚栓 |

## 规范

| 规范 | 说明 |
| ---- | ---- |
| JGJ 144-2019 | 外墙外保温工程技术标准 |
| GB 55015-2021 | 建筑节能与可再生能源利用通用规范（强制） |
| GB 50176 | 民用建筑热工设计规范 |
| GB 8624-2012 | 建筑材料及制品燃烧性能分级 |
