# 08 施工组织与安全

> 定位：施工组织是**把工序排成时间与空间** —— 用流水 / 网络计划组织资源，用安全文明措施守住底线。

## 施工组织

| 手段 | 说明 |
| ---- | ---- |
| 流水施工 | 工序搭接 · 作业面轮换 · 减少窝工 |
| 网络计划 | 关键路径（CPM）· 工期与资源优化 |
| 平面布置 | 临时道路 · 材料堆场 · 塔吊 / 施工电梯 |
| 进度控制 | 总控计划 → 月 / 周计划 → 纠偏 |

## 安全与文明施工

| 项 | 要点 |
| ---- | ---- |
| 安全 | 三宝（安全帽 / 安全带 / 安全网）· 四口五临边 · 临电 |
| 危大工程 | 深基坑 · 高支模 · 起重吊装专项方案与验收 |
| 消防 | 动火审批 · 消防通道 · 灭火器材 |
| 文明 | 扬尘 / 噪声控制 · 围挡 · 车辆冲洗 |
| 人员 | 特种作业持证（电工 / 焊工 / 起重） |

技术交底 · 隐蔽工程验收 · 施工日志 · 竣工资料归档。
