# 01 砌筑与建筑工艺总论

> 定位：本总论是 693 深库的**起点** —— 把「材料」（[[691-建筑材料|691]]）与「构件」（[[692-建筑构件|692]]）变成实体的**现场工艺**。给出**工艺谱系 · 三个规矩 · 边界 · 2026 位移**。

## 什么是砌筑与建筑工艺

以**砌筑**为代表的现场建筑工艺 —— 砖石砌筑、砌块砌筑、混凝土浇筑与养护、抹灰、防水保温施工等施工作业。它靠「**手 + 规矩**」把散料变成结构。

> **UDC 693** — 砌筑与相关建筑工艺（Masonry and related building crafts）。隶属 [[69-城建与建筑|69 城建与建筑]]。

## 工艺谱系

| 工艺 | 要点 |
| ---- | ---- |
| 砌砖 | 湿润 · 灰缝 8–12mm · 组砌（一顺一丁）· 皮数杆 |
| 砌块 | 排块 · 灰缝 · 芯柱 / 构造柱 |
| 石砌 | 毛石 / 料石 · 勾缝 |
| 混凝土 | 配料 · 搅拌 · 浇筑 · 振捣 · 养护 · 施工缝 |
| 抹灰 | 底层 / 中层 / 面层 |
| 加固 | 构造柱 · 圈梁 · 拉结筋 |

## 主线：散料 → 结构的「三个规矩」

- **材料规矩**：砖需湿润 · 砂浆饱满度 · 块材强度等级与折压比（GB 50574）。
- **几何规矩**：皮数杆 · 轴线位移 · 垂直度 · 灰缝厚度。
- **整体规矩**：构造柱 · 圈梁 · 拉结筋 —— 把脆性砌体「箍」成抗震整体。

## 2026 三条位移

1. **免抹灰 / 薄抹灰** —— 砌块精度提升 → 减少湿作业。
2. **装配式** —— 预制墙板 / 叠合构件替代现场砌筑。
3. **标准换挡** —— 结构性通用规范（GB 550xx）接管旧强条。
