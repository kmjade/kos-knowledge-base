# 09 装配式施工与建筑工业化

> 定位：把「现场湿作业」搬进工厂 —— 预制构件现场装配，是建筑工艺从「手工」转向「制造」的方向。

## 装配式结构体系

| 体系 | 说明 |
| ---- | ---- |
| 装配式混凝土（PC） | 预制柱 / 梁 / 叠合板 / 墙 / 楼梯 |
| 装配式钢结构 | 钢框架 + 叠合楼板 + 围护 |
| 装配式木结构 | 工程木构件预制装配 |
| 模块化建筑 | 整体模块（MiC）· 集成度最高 |

## 关键工序

| 工序 | 要点 |
| ---- | ---- |
| 深化设计 | BIM 拆分 · 预埋 · 吊点 |
| 预制生产 | 模具 · 钢筋 · 浇筑 · 养护 · 脱模 |
| 运输吊装 | 吊点 / 吊具 · 临时支撑 · 精度控制 |
| **连接** | **套筒灌浆**（半灌浆 / 全灌浆）· 后浇混凝土 · 干式连接 |
| 防水 / 接缝 | 打胶 + 排水空腔 |

## 质量与检测

灌浆饱满度检测 · 构件尺寸偏差 · 连接节点验收。

## 2026 三条位移

1. **MiC 模块化** —— 工厂集成度提升，现场「搭积木」。
2. **装配式装修 / MiMEP** —— 干法作业，与机电预制协同。
3. **智能建造** —— 机器人生产 + BIM 全过程追溯。
