# 04 钢筋混凝土工程

> 定位：钢筋混凝土工程是**主体结构施工的核心** —— 模板、钢筋、混凝土三工种协同，把设计图变成承重实体。

## 三大分项

| 分项 | 要点 |
| ---- | ---- |
| **模板工程** | 支设 / 拆除 · 刚度与稳定 · 周转材料 |
| **钢筋工程** | 下料 · 连接（搭接 / 机械 / 焊接）· 保护层 · 绑扎 |
| **混凝土工程** | 配料 · 搅拌 · 运输 · 浇筑 · 振捣 · 养护 |

## 混凝土施工要点

| 环节 | 关键 |
| ---- | ---- |
| 浇筑 | 分层浇筑 · 自由倾落高度 · 连续供应 |
| 振捣 | 插入式 / 平板式 · 避免漏振与过振 |
| 施工缝 | 位置留置 · 接浆处理 |
| 养护 | 保湿养护 ≥7d（掺缓凝 / 抗渗 ≥14d）· 温控防裂 |
| 大体积 | 测温 · 保温 · 后浇带 |

## 质量与验收

钢筋隐蔽验收 · 混凝土试块（GB/T 50107 强度检验评定）· 外观与尺寸偏差。
