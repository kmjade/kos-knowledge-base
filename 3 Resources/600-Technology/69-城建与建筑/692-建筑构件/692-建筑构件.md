## 类目

构成建筑物的**部件与构件** —— 基础、柱梁、墙体、楼板与楼地面、屋面、楼梯、门窗、幕墙等，以及其构造做法与选型。
构件的**结构设计**入 624–628（土木），**建筑设计**入 72；本类收**构件本体与构造**（把材料「叠」成部件的那一层）。

## 构造层次（示例）

```
屋面（自上而下）：面层 → 防水层 → 找平层 → 保温层 → 找坡层 → 结构层
地面（自上而下）：面层 → 结合层 → 找平层 → 垫层 → 基层
```

## 建筑构件研讨（2026-09-28）

> 定位：把「材料」组装成「部件」的中间层 —— 基础 / 柱梁 / 墙 / 楼地面 / 屋面 / 楼梯 / 门窗 / 幕墙。
> 它是**设计（72 建筑）与施工（693/698）的交接面**：图纸上的构造层次，在现场一道道做出来。

**一、构件谱系**

| 类别 | 构件 | 核心 |
| ---- | ---- | ---- |
| 结构构件 | 基础 · 柱 · 梁 · 楼板 | 承载 · 传力 |
| 围护构件 | 墙体 · 屋面 · 门窗 · 幕墙 | 防水 · 保温 · 采光 |
| 分隔构件 | 隔墙 · 楼地面 | 分隔 · 隔声 |
| 竖向交通 | 楼梯 | 疏散 · 通行 |

**二、主线：构造层次（「叠」出来的性能）**

- 屋面：面层 → 防水层 → 找平层 → 保温层 → 找坡层 → 结构层。
- 地面：面层 → 结合层 → 找平层 → 垫层 → 基层。
- 性能不靠单一材料，靠**层次组合 + 节点**：防水 / 保温 / 隔声都在「层」里解决。

**三、2026 位移**

1. **装配式**：构件 / 部件工厂预制（叠合板 · 预制墙 · 预制楼梯），现场装配；BIM 贯穿设计-生产-施工。
2. **一体化**：保温装饰一体板、结构保温一体化，减少现场工序。
3. **性能化设计（PBD）**：按性能目标选构造，材料用量最省。
