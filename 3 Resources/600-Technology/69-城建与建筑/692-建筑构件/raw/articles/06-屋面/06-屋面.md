# 06 屋面

> 定位：屋面是建筑的**顶部围护构件** —— 解决防水、排水、保温隔热，是「构造层次」最典型的部位。

## 类型

| 类型 | 说明 |
| ---- | ---- |
| 平屋面 | 坡度小（找坡 2% 左右）· 卷材 / 涂膜防水 |
| 坡屋面 | 坡度大 · 瓦材 · 排水好 |
| 种植 / 倒置式 | 生态屋面 / 保温层置于防水层之上 |

## 构造层次（自上而下）

```
面层 → 防水层 → 找平层 → 保温层 → 找坡层 → 结构层
```

| 层 | 作用 |
| ---- | ---- |
| 面层 | 保护 / 装饰 / 上人 |
| **防水层** | 核心 · 卷材 / 涂膜 |
| 找平层 | 为防水提供平整基层 |
| 保温层 | 隔热（EPS / XPS / 岩棉 / 泡沫混凝土） |
| 找坡层 | 形成排水坡度 |
| 结构层 | 楼板 / 屋面板 |

## 关键：防水与排水

- **防水等级 / 设防道数**（GB 50345）· 强制通用规范 **GB 55030-2022**（建筑与市政工程防水通用规范）。
- **排水**：找坡 · 天沟 · 雨水口 / 雨水管 · 溢流口。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 50345 | 屋面工程技术规范 |

| GB 50176 | 民用建筑热工设计规范 |
| GB 50693 | 坡屋面工程技术规范 |
