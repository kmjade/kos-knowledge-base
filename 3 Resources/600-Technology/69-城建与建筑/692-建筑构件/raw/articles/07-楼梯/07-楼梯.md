# 07 楼梯

> 定位：楼梯是建筑的**竖向交通构件** —— 平时通行、灾时疏散，是防火与疏散设计的核心。

## 类型

| 类型 | 说明 |
| ---- | ---- |
| 直跑楼梯 | 单向 · 简单 |
| 双跑楼梯 | 折返 · 最常用 |
| 剪刀楼梯 | 双跑交叠 · 高层疏散 |
| 旋转 / 弧形 | 空间受限 · 装饰性强 |
| 室外楼梯 | 疏散 · 辅助 |

## 组成

梯段（踏步）· 平台（休息平台 / 楼层平台）· 栏杆与扶手 · 踏步防滑。

## 关键尺寸与安全

| 项 | 要点 |
| ---- | ---- |
| 踏步 | 踏步高 h 与宽 b：约 **2h + b ≈ 600–630 mm**（舒适） |
| 净高 | 梯段净高 ≥2.20 m · 平台净高 ≥2.00 m |
| 疏散 | 宽度 / 数量按计算 · 防火隔墙 + 乙级防火门（GB 50016） |
| 栏杆 | 高度 ≥0.90 m（临空 1.05 m）· 防攀爬 / 防坠落 |

## 装配式楼梯

工厂预制（板式 / 梁式）→ 现场吊装 + 灌浆连接，是装配式建筑的标准构件。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 50352 | 民用建筑设计统一标准 |
| GB 50016 | 建筑设计防火规范 |
| GB 50011 | 建筑抗震设计规范 |
