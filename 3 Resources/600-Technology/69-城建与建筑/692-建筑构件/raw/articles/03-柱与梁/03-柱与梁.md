# 03 柱与梁

> 定位：柱与梁构成建筑的**骨架** —— 柱承受竖向荷载与水平（地震 / 风）作用，梁把楼面荷载传给柱与墙。

## 柱

| 类型 | 说明 |
| ---- | ---- |
| 框架柱 | 主要竖向承重构件 |
| 构造柱 | 砌体结构中的约束柱（非承重 · 抗震） |
| 钢柱 / 钢管混凝土柱 | 高层 / 大跨 |

## 梁

| 类型 | 说明 |
| ---- | ---- |
| 框架梁 | 连接柱 · 承受楼面荷载 |
| 次梁 | 支承于主梁 · 细分楼板跨度 |
| 圈梁 | 沿墙顶连续 · 增强整体性 |
| 过梁 | 洞口上方 · 承托上部墙体 |

## 节点（关键）

- 梁柱节点核心区 —— 抗剪与锚固，是**抗震的命门**（强柱弱梁 · 强节点弱构件）。
- 钢筋连接：绑扎搭接 · 机械连接 · 焊接。

## 材料与形式

混凝土框架 · 钢结构 · 木结构（梁柱榫卯 / 金属连接件）· 型钢（H 型钢 · 工字钢）。
