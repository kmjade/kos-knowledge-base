# 01 建筑构件总论

> 定位：建筑构件是**把「材料」组装成「部件」的中间层** —— 上承材料（[[691-建筑材料|691 建筑材料]]），下接工艺与装饰（[[693-砌筑与建筑工艺|693]] · [[698-装饰装修|698]]）。
> 本总论给出**分类 · 构造主线 · 生产链定位 · 2026 位移**，作为 692 深库的起点。

## 什么是建筑构件

建筑构件（building elements）是**构成建筑物的各部件** —— 基础、柱、梁、板、墙、屋面、楼梯、门窗、幕墙等。每一个构件都由**若干材料层 + 节点**「叠」成，其性能（承载 · 防水 · 保温 · 隔声）由**层次组合**决定，而非单一材料。

> **UDC 692** — 建筑结构部件与构件（Structural parts and elements of buildings）。隶属 [[69-城建与建筑|69 城建与建筑]]。

## 分类

| 类别 | 构件 | 核心 |
| ---- | ---- | ---- |
| 结构构件 | 基础 · 柱 · 梁 · 楼板 | 承载 · 传力 |
| 围护构件 | 墙体 · 屋面 · 门窗 · 幕墙 | 防水 · 保温 · 采光 |
| 分隔构件 | 隔墙 · 楼地面 | 分隔 · 隔声 |
| 竖向交通 | 楼梯 | 疏散 · 通行 |

## 构造层次主线

```
屋面（自上而下）：面层 → 防水层 → 找平层 → 保温层 → 找坡层 → 结构层
地面（自上而下）：面层 → 结合层 → 找平层 → 垫层 → 基层
```

> 性能不靠单一材料，靠**层次组合 + 节点**：防水 / 保温 / 隔声都在「层」里解决。

## 生产链定位

```
材料（691） ─► 构件（692，本章） ─► 工艺（693/694） ─► 安装（696/697） ─► 饰面（698）
```

## 2026 三条位移

1. **装配式** —— 构件 / 部件工厂预制（叠合板 · 预制墙 · 预制楼梯），现场装配；BIM 贯穿设计-生产-施工。
2. **一体化** —— 保温装饰一体板、结构保温一体化，减少现场工序。
3. **性能化设计（PBD）** —— 按性能目标选构造，材料用量最省。
