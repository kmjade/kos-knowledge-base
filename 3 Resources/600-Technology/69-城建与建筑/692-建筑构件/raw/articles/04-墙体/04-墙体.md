# 04 墙体

> 定位：墙体是建筑的**竖向围护与分隔构件** —— 承担承重（或填充）、保温、隔声、防火等多重角色。

## 分类

| 维度 | 类型 |
| ---- | ---- |
| 受力 | **承重墙** · 非承重（填充墙 / 隔墙） |
| 材料 | 砌体墙（砖 / 砌块 · UDC 692.2）· 混凝土墙（现浇 / PC）· 轻质隔墙 |
| 位置 | 外墙（围护 + 保温）· 内墙（分隔 + 隔声） |

## 关键性能

| 性能 | 做法 |
| ---- | ---- |
| 承载 | 砌体 / 混凝土 · 圈梁构造柱约束 |
| 保温 | 外墙外保温（EPS / XPS / 岩棉 · JGJ 144）· 自保温砌块 |
| 隔声 | 质量定律 + 双层 / 夹芯构造 |
| 防火 | 燃烧性能等级（GB 8624）· 防火墙 |
| 防水 | 外墙防水 · 节点（窗洞 · 女儿墙） |

## 构造要点

- 砌体墙：组砌方式 · 灰缝饱满 · 拉结筋 · 构造柱与圈梁。
- 填充墙：与主体柔性连接（抗震）· 顶部斜砌或柔性填缝。
- 现浇混凝土墙：模板 · 钢筋 · 养护（防裂）。
