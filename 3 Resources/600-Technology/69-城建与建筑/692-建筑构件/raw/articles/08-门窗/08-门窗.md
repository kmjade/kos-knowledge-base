# 08 门窗

> 定位：门窗是建筑围护的**可开启洞口构件** —— 采光、通风、通行，同时是最薄弱的**热工与气密节点**。

## 材质

| 材质 | 特点 |
| ---- | ---- |
| 木门窗 | 保温好 · 需防腐 |
| 钢门窗 | 强度高 · 易锈 |
| **铝合金门窗** | 主流 · 断桥隔热 |
| 塑料（PVC）门窗 | 保温好 · 强度受限 |
| 铝木复合 | 兼顾观感与性能 |

## 关键性能

| 性能 | 说明 |
| ---- | ---- |
| 气密 / 水密 | 分级（GB/T 7106） |
| 抗风压 | 高层 / 台风区关键 |
| 保温 | 传热系数 K · 断桥铝 + 中空 / Low-E 玻璃 |
| 隔声 | 中空 / 夹层玻璃 |
| 采光 | 窗地比（GB 50352） |
| 防火 | 防火门 / 防火窗（GB 50016） |

## 构造要点

- **断桥铝**：隔热条隔断热桥；**系统窗**：整体设计（型材 + 五金 + 玻璃 + 密封）。
- 安装：附框 / 湿法 vs 干法 · 密封胶 + 防水透气膜 · 抗风压锚固。
- 与建筑节能：外窗是围护保温的**短板**（GB 55015 节能）。
