# 09 幕墙与外围护

> 定位：幕墙是**非承重的外围护构件** —— 悬挂于主体结构，是高层与公共建筑的「外衣」，兼作采光与节能界面。

## 类型（按面板）

| 类型 | 说明 |
| ---- | ---- |
| 玻璃幕墙 | 透明 · 采光 · 美观 |
| 石材幕墙 | 庄重 · 自重较大 |
| 金属幕墙 | 铝板 / 铝塑板 · 轻质 |
| 陶板 / 人造板 | 装饰性 · 耐候 |

## 类型（按构造）

框架式（元件式）· 单元式（工厂装配）· 全玻幕墙 · 点支式。

## 关键性能

| 性能 | 说明 |
| ---- | ---- |
| 抗风压 | 高层 / 大面幕墙首要 |
| 水密 / 气密 | 分级 · 等压腔设计 |
| 平面内变形 | 抗震 / 层间位移适应 |
| 节能 | 中空 + Low-E · 断热型材 · 遮阳 |
| 光污染 | 玻璃反射比限制（GB 55016） |

## 2026 位移

1. **BIPV 光伏幕墙** —— 幕墙发电（双碳）。
2. **智能幕墙** —— 可调遮阳 / 电致变色 / 通风幕墙。
3. **装配化单元式** —— 工厂集成度更高。
