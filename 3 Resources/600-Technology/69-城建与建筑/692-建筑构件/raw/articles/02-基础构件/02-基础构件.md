# 02 基础构件

> 定位：基础是**建筑与地基之间的传力构件** —— 把上部结构的荷载扩散到地基。它决定建筑的**稳定与沉降**控制。

## 基础类型

| 类型 | 受力 / 适用 |
| ---- | ---- |
| 条形基础 | 墙下连续 · 砌体 / 框架浅基础 |
| 独立基础 | 柱下单独 · 框架结构 |
| 筏板基础 | 满堂整板 · 软弱地基 / 高层 |
| 箱形基础 | 筏板 + 地下室墙体 · 刚度大 |
| 桩基础 | 深基础 · 端承 / 摩擦桩 · 软土 |

## 地下室与防水

- **地下室**：挡土 · 防水 · 抗浮；与主体同步开挖与浇筑。
- **防水**：设防道数 + 等级（GB 50108 地下工程防水）；卷材 / 涂料 / 防水混凝土。
- **抗浮**：地下水位高时，用抗拔桩 / 配重 / 泄水减压。

## 关键指标

地基承载力 · 沉降量 · 抗浮安全系数 · 防水等级。
