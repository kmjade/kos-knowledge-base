# 05 楼板与楼地面

> 定位：**楼板**是水平承重构件（传给柱 / 墙）；**楼地面**是楼板的表面构造层，解决找平、面层、隔声与防水。

## 楼板类型

| 类型 | 说明 |
| ---- | ---- |
| 现浇楼板 | 整体性好 · 梁板 / 无梁楼盖 |
| 预制板 | 工厂预制 · 快速 |
| **叠合板** | 预制底板 + 现浇叠合层（装配式的核心） |
| 密肋 / 空心楼盖 | 减轻自重 · 大跨 |

## 地面构造层次

```
面层 → 结合层 → 找平层 → 垫层 → 基层
```

| 层 | 作用 |
| ---- | ---- |
| 面层 | 使用与装饰（见 [[698-装饰装修|698]]） |
| 找平层 | 平整度基准 |
| 垫层 | 传力 · 防潮 |
| 基层 | 素土 / 混凝土 |

## 关键性能

承载 · 隔声（撞击声 / 空气声）· 保温（地面辐射采暖）· 防水（卫生间 / 厨房）· 平整度。
