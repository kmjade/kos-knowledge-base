## 木结构与木作研讨（2026-09-28）

> 定位：694 是 69 中唯一**以生物基材料**为主的结构体系 —— 木结构（承重）+ 大木作（传统构架）+ 小木作（装修部件）+ 细木工。在「双碳」语境下从「传统」翻红为「低碳前沿」。

**一、类别**

| 类别 | 要点 |
| ---- | ---- |
| 木结构体系 | 抬梁 / 穿斗（传统）· 轻型木结构 · 胶合木 Glulam · **CLT** |
| 连接 | 榫卯 · 齿连接 · 螺栓 / 钢夹板 |
| 大木作 | 柱 · 梁 · 枋 · 檩 · 椽 · 斗拱 |
| 小木作 | 门 · 窗 · 隔断 · 天花 · 栏杆 |
| 细木工 | 橱柜 · 固定家具 · 木饰面基层 |
| 防护 | 防腐 · 防虫 · 防火（阻燃）· 防潮 |

**二、主线：木材的「两怕一喜」**

- **两怕**：**怕水怕火**（含水率 → 变形 / 腐朽；防火需阻燃或防火板包裹）。
- **一喜**：喜**工厂预制**（工程木 + 装配式，天然适配 DfMA）。
- 现代工程木（胶合木 · CLT）把小材胶合成大构件，解决实木「尺寸受限、材质不均」的短板。

**三、一条总纲**

- **GB 55005-2021**《木结构通用规范》（强制性）—— 木结构体系的强条总纲（与 696/697/698 的 550xx 同族）。

**四、2026 复兴三线**

1. **工程木 + 高层**：CLT 让木结构突破 6 层（多高层木结构）。
2. **Timber-MiC**：木结构模块化集成建筑（场外预制 · 现场装配 · 低碳）。
3. **低碳叙事**：木材为**生物基固碳材料**；混合结构（钢-木 / 砼-木）拓展场景。
