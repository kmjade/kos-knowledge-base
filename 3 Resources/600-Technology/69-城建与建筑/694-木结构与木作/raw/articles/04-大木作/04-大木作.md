# 04 大木作

> 定位：大木作是**中式传统建筑的承重构架体系** —— 用柱、梁、枋、檩、椽搭起「骨架」，是中国木构建筑的主体工艺。

## 主要构件

| 构件 | 作用 |
| ---- | ---- |
| 柱 | 竖向承重 |
| 梁 | 横向承重（抬梁式） |
| 枋 | 柱间联系 |
| 檩（桁） | 承椽 · 屋面荷载 |
| 椽 | 直接承托屋面基层 |
| **斗拱** | 柱顶 / 额枋上的层层出跳构件 · 传力 + 装饰 + 耗能 |

## 构架类型

- **抬梁式**：柱—梁—瓜柱—梁 层层叠置，室内空间大（官式）。
- **穿斗式**：柱直接承檩、穿枋串联，用料省（南方）。
- **混合式**：抬梁与穿斗并用。

## 关键工艺

弹线放样 · 榫卯制作 · 立架（上梁）· 举折（屋面曲线）· 侧脚与生起。

## 保护与加固

古建筑木结构维护与加固（GB/T 50165）· 柱脚防腐 · 纠偏 · 墩接。

## 规范

| 规范 | 说明 |
| ---- | ---- |
