# 09 工程木与装配式木结构

> 定位：**工程木**把小材胶合为大构，**装配式**把构件送上工地 —— 两者合力使木结构从低层走向中高层，成为低碳建筑的先锋。

## 工程木类型

| 类型 | 全称 | 形态 / 用途 |
| ---- | ---- | ---- |
| **Glulam (GLT)** | 胶合木 | 层板胶合 · 梁柱大跨 |
| **CLT** | 正交胶合木 | 纵横层叠 · 墙板 / 楼板 |
| **LVL** | 单板层积材 | 顺纹层积 · 梁 / 枋 |
| LSL / PSL | 定向 / 平行木片积成材 | 高强构件 |
| 胶合板 / OSB | — | 覆面板 · 剪力墙 |

## 装配式木结构

| 体系 | 说明 |
| ---- | ---- |
| 预制墙板 / 楼板 | CLT / 板式构件 |
| 预制空间单元 | 模块化房间 |
| **Timber-MiC** | 模块化集成建筑 · 场外高集成 · 现场装配 |

## 关键优势与挑战

| 维度 | 内容 |
| ---- | ---- |
| 低碳 | 木材固碳 · 加工能耗低（vs 砼 / 钢） |
| 轻质 | 自重小 → 基础减负 · 抗震 |
| 快装 | 干法 · 预制 · 工期短 |
| 挑战 | 防火 · 防潮 · 声学 · 高层刚度 · 成本 |

## 2026 三线

1. **多高层突破** —— CLT 让木结构进入 6 层以上（GB/T 51226）。
2. **Timber-MiC** —— 场外预制 + 现场装配。
3. **混合结构** —— 木-钢 / 木-砼组合拓展场景。

## 规范

| 规范 | 说明 |
| ---- | ---- |
