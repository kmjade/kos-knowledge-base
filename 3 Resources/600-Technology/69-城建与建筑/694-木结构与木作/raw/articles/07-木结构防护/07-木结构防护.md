# 07 木结构防护

> 定位：木材「两怕」—— **怕水、怕火**。防护工程就是让木构件耐久（防腐防虫）与安全（防火）。

## 防腐与防虫

| 要点 | 内容 |
| ---- | ---- |
| 含水率 | 控制木材含水率 · 保持通风（构造防潮） |
| 药剂处理 | 加压浸注防腐剂（CCA / ACQ / 铜唑）· 涂刷 |
| 防虫 | 防白蚁（土壤屏障 · 药剂）· 防蛀 |
| 构造 | 避免木构件直接接触土壤 / 混凝土 · 设防潮层 |

> 规范：GB 50005 · GB/T 50476（木材防腐）· GB/T 51390（防腐木）。

## 防火

| 措施 | 说明 |
| ---- | ---- |
| 阻燃处理 | 浸渍 / 涂覆阻燃剂 |
| 防火板包裹 | 石膏板 / 防火板包覆提升耐火极限 |
| 加大截面 | 大截面木构件遇火成炭层，保护内部（**炭化速率**法） |
| 构造 | 防火隔墙 · 自动喷淋 · 报警 |

> 规范：**GB 55005-2021**（木结构通用规范 · 强制）· GB 50016（建筑防火）· GB/T 51226（多高层木结构）。

## 耐火原理：炭化层护芯

木材燃烧时表面形成**炭化层**，阻碍内部继续燃烧 —— 大截面木构件可获得可观耐火极限（优于钢的「软化」）。

## 规范

| 规范 | 说明 |
| ---- | ---- |
| GB 55005-2021 | 木结构通用规范（强制） |
| GB 50005-2017 | 木结构设计标准（防护章节） |
| GB 50016 | 建筑设计防火规范 |
| GB/T 50476 | 混凝土 / 木结构耐久性相关（配套） |
