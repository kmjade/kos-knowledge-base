# 05 小木作

> 定位：小木作是**建筑中的木制装修部件** —— 门窗、隔断、天花、栏杆、罩等；不承重，但决定空间与观感。

## 主要部件

| 部件 | 说明 |
| ---- | ---- |
| 门 | 板门 · 隔扇门 · 格门 |
| 窗 | 槛窗 · 支摘窗 · 花窗 |
| 隔断 | 隔扇 · 罩 · 屏风 |
| 天花 | 藻井 · 平棋 · 天花 |
| 栏杆 | 寻杖栏杆 · 坐凳 |
| 外檐装修 | 挂落 · 雀替 |

## 对比：大木作 ↔ 小木作

| 维度 | 大木作 | 小木作 |
| ---- | ---- | ---- |
| 性质 | 承重构架 | 非承重装修 |
| 部位 | 柱梁枋檩椽 | 门窗隔断天花栏杆 |
| 现代对应 | 木结构体系 | 木门窗 / 木装修 |

## 现代延伸

现代木门窗、木隔断、木格栅、木饰面（详见 [[06-细木工与木装修|06 细木工与木装修]] 与 [[08-门窗|08 门窗]]）。
