# 02 木结构体系

> 定位：木结构体系是**以木材承重**的结构形式 —— 从中国传统构架到现代工程木框架，核心是「以小材成大构」。

## 传统体系

| 体系 | 特征 |
| ---- | ---- |
| 抬梁式 | 柱上架梁、梁上叠梁瓜柱 · 官式建筑主流 |
| 穿斗式 | 柱直接承檩、穿枋串联 · 用料省 · 南方民居 |
| 井干式 | 原木层叠咬合 · 林区 |

## 现代体系

| 体系 | 特征 |
| ---- | ---- |
| **轻型木结构** | 规格材龙骨 + 覆面板 · 北美独栋主流 |
| **胶合木结构（Glulam）** | 层板胶合 · 大跨梁柱 |
| **CLT 正交胶合木** | 纵横层叠 · 墙板 / 楼板 · 多高层 |
| 梁柱（重型木）结构 | 大截面集成材 · 公共建筑 |
| 混合结构 | 木-砼 / 木-钢组合 |

## 关键：工程木把小材变大材

- 实木「尺寸受限、材质不均、易开裂」；
- **胶合木 / CLT / LVL** 通过胶合、正交、层积，得到稳定的大构件。
