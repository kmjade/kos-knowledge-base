# 06 细木工与木装修

> 定位：细木工是**精细的木制品加工与安装** —— 橱柜、固定家具、木饰面、木地板等，是室内装修的木作部分。

## 主要品类

| 品类        | 说明                              |     |
| --------- | ------------------------------- | --- |
| 木门窗       | 实木 / 实木复合门窗（见 [[08-门窗\|08 门窗]]） |     |
| 木饰面       | 饰面板 + 基层（龙骨 / 阻燃板）              |     |
| 木地板       | 实木 / 实木复合 / 强化 / 竹木             |     |
| 固定家具      | 橱柜 · 衣柜 · 卫浴柜                   |     |
| 木楼梯       | 踏步 / 栏杆 / 扶手                    |     |
| 木质吊顶 / 格栅 | 装饰性                             |     |

## 施工要点

| 环节 | 要点 |
| ---- | ---- |
| 基层 | 龙骨找平 · 防潮处理 · 阻燃要求 |
| 面层 | 拼缝 · 收口 · 阳角 |
| 含水率 | 与室内平衡含水率适配（防胀缩） |
| 环保 | 板材甲醛释放限量（E1 / ENF）· 胶粘剂 |

## 与木结构的分工

- **承重**：木结构体系（[[02-木结构体系|02]] · [[08-木结构施工与安装|08]]）。
- **装修**：细木工（本章）—— 属 [[698-装饰装修|698 装饰装修]] 的木作分支。
