# 03 木构件与连接

> 定位：**连接决定木结构的安全** —— 传统靠榫卯，现代靠金属连接件；节点是木结构受力的关键部位。

## 传统连接：榫卯

| 类型 | 说明 |
| ---- | ---- |
| 直榫 / 燕尾榫 | 抗拔 · 抗剪 |
| 搭接 / 抱肩 | 柱梁交接 |
| 斗拱 | 层层出跳 · 传力与减震（耗能） |
| 穿枋 | 穿斗式串联柱列 |

> 榫卯「以柔克刚」：允许微量变形，地震时耗能。

## 现代连接件

| 类型 | 说明 |
| ---- | ---- |
| 齿连接 | 传统与现代结合的承压连接 |
| 螺栓 + 钢夹板 | 抗剪 / 抗拉 |
| 钉 / 螺钉 | 轻型木结构板-骨连接 |
| 金属连接件（齿板 · 挂件） | 工厂预制的标准化节点 |
| 钢-木组合节点 | 混合结构 |

## 关键

- 连接设计需考虑**木材顺纹 / 横纹受力差异**与**含水率变化**。
- 节点应**外露可检修**，避免隐蔽腐烂。
