# 08 木结构施工与安装

> 定位：木结构施工是**「在场外预制、在现场装配」**的典型 —— 与 DfMA（面向制造与装配的设计）天然契合。

## 施工流程

```
材料加工（工厂）→ 构件预制 → 运输 → 现场吊装 → 连接 → 围护 → 验收
```

| 阶段 | 要点 |
| ---- | ---- |
| 材料 / 加工 | 木材验收（含水率 · 等级）· 工厂下料 |
| 预制 | 构件制作 · 预拼装 · 金属连接件预装 |
| 吊装 | 吊点 · 临时支撑 · 校正 |
| 连接 | 榫卯 / 螺栓 / 连接件（见 [[03-木构件与连接|03]]） |
| 围护 | 保温 · 防水透气膜 · 覆面板 |

## 关键控制

| 项 | 要点 |
| ---- | ---- |
| 含水率 | 安装时木材含水率适配（防后期变形） |
| 尺寸偏差 | 构件加工精度 · 节点就位 |
| 防护 | 端部防腐 · 防潮 · 防火处理 |
| 进度 | 干法施工 · 受天气影响小 · 工期短 |
