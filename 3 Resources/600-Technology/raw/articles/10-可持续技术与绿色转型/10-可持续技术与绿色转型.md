# 10 可持续技术与绿色转型

> **UDC 6** —— 技术既是问题的一部分（排放 · 耗竭），也是解药的一部分（减排 · 循环）。
> 本章**收束导论**：把「造物 / 用能 / 制造 / 数字化」放进「**地球边界**」里看。

---

## 一、为什么

| 驱动力 | 说明 |
|:--|:--|
| **气候** | 温室气体 → 升温 → 极端天气 |
| **资源** | 化石 · 矿产 · 淡水有限 |
| **外部性** | 环境成本未计入价格 |
| **代际正义** | 当代不能透支后代（见 [[04-应用科学伦理|04 伦理]]） |

---

## 二、可持续是什么

- **三支柱**：环境 · 社会 · 经济（缺一不可）；
- **布伦特兰定义**：满足当代需求，**不损害后代**满足其需求的能力；
- **地球边界（Planetary Boundaries）**：气候 · 生物多样性 · 氮磷 · 土地利用… 的**安全阈值**。

---

## 三、碳：核心度量

```
碳源 → 大气 → 碳汇（森林/海洋/CCUS）
```

- **碳达峰 → 碳中和（净零）**：先封顶，再中和；
- **碳足迹 / 核算（GHG Protocol）**：范围一（直接）· 范围二（外购能）· 范围三（供应链）。

## 五、循环经济

| 线性经济 | 循环经济 |
|:--|:--|
| 取用 → 制造 → 丢弃 | **减量 → 复用 → 回收 → 再设计** |
| 废弃物 = 终点 | 废弃物 = **资源** |

- **工业共生**：一厂的废料 = 另一厂的原料；
- **再制造 / 翻新**：延长产品寿命；
- **从摇篮到摇篮（Cradle to Cradle）**：设计即循环。

## 七、挑战与争议

| 争议 | 说明 |
|:--|:--|
| **绿色洗白** | 宣传 > 实质 |
| **成本与公平** | 转型成本谁承担（公正转型） |
| **技术乐观 vs 足够性** | 「效率」能否替代「少用」 |
| **回弹效应 / Jevons 悖论** | 效率提升反增总消耗 |
| **供应链转移** | 污染外包 ≠ 减排 |

## 核心问题

**如何把技术系统放进地球边界内 —— 既满足当代需求，又不透支后代？**
