# 05 标准化与规范导论

> **UDC 6** —— 标准是「让**不同的人 · 不同的地方 · 不同的时间**，做出彼此可兼容的东西」的**公共语言**。
> 本章是 [[03-应用科学方法论|03 方法论]] 的**规则层**：把「一次性做对」升级为「**可复制地做对**」。

---

## 一、为什么需要标准

| 目的 | 说明 |
|:--|:--|
| **互通 / 互操作** | 螺母与螺栓 · 插座 · 通信协议 |
| **安全底线** | 强制规范护住生命财产 |
| **规模经济** | 通用件 → 低成本 · 可替换 |
| **信任与贸易** | 认证即信任 · 降低交易成本 |
| **知识固化** | 把经验写成**可传承的规则** |

---

## 二、术语辨析

| 术语 | 侧重 | 效力 |
|:--|:--|:--|
| **标准** | 技术要求（怎么算合格） | 可强制 / 可推荐 |
| **规范** | 系统性要求（设计/施工/验收） | 常含强制条文 |
| **规程** | 操作过程（怎么做） | 过程导向 |
| **指南** | 建议性做法 | 非强制 |
| **法规** | 法律约束 | 强制 |

> 一句话：**标准定"合格线"，规范定"系统规则"，规程定"操作步骤"，法规定"底线"。**

---

## 三、标准的类型

### 3.1 按层级

`国际`（ISO · IEC · ITU）→ `区域`（EN）→ `国家`（GB · ANSI · DIN · JIS）→ `行业`（CJJ · JGJ · YD）→ `团体`（T/CECS · T/CABEE）→ `企业`（Q/…）

### 3.2 按内容

基础 / 术语 · 方法 · 产品 · 过程 · 服务 · **接口与数据**（互操作性最强的层）

### 3.3 按效力

| 效力 | 例 |
|:--|:--|
| **强制** | `GB`（强制性国标）· **全文强制「通用规范」**（`GB 55xxx`） |
| **推荐** | `GB/T` · ISO 多数标准 |
| **指导** | `GB/Z` |

---

## 四、中国标准体系

```
国标    GB（强制） / GB/T（推荐） / GB/Z（指导）
行业标准 CJJ · JGJ · JG · YD · NB …
团体标准 T/…（学会 / 联盟，如 T/CECS 420-2022）
企业标准 Q/…
```

> **趋势（重要）：** **强制性「通用规范」体系**（`GB 55xxx`，全文强制）正逐步**取代分散强条** —— 见 [[69-城建与建筑|69 城建]] 的 [[696-建筑设备与安装|696 建筑机电]]（`GB 55020`/`55024`/`55032` 等）。

---

## 五、标准的生命周期

```
提案 → 起草 → 征求意见 → 审查 → 发布 → 实施 → 复审（一般 ≤ 5 年）
```

- **协调性**：与上位法 / 相关标准不打架；
- **一致性**：技术指标自洽、可检测；
- **可追溯**：引用与版本清楚。

---

## 六、合规与认证

| 环节 | 说明 |
|:--|:--|
| **合格评定** | 证明"符合标准"的总体活动 |
| **检测 / 试验** | 按方法标准测指标 |
| **认证** | 第三方背书（产品 / 体系 / 人员） |
| **认可** | 对认证/检测机构的认可（CNAS 等） |
| **采标** | 采用国际标准：**IDT**（等同）· **MOD**（修改）· **NEQ**（非等效） |

---

## 七、标准的价值与局限

| 价值 | 局限 |
|:--|:--|
| 互通 · 安全 · 规模 · 信任 | **滞后**于创新（标准追不上技术） |
| 降低交易成本 | **标准战**（谁的标准 = 谁的话语权） |
| 保护公共安全 | 过度标准化**抑制多样性**与试错 |
| 促贸易 | 标准可作为**技术性贸易壁垒** |

---

## 核心问题

**如何用「公共规则」，让技术可互通、可信任、可规模化？**
