# 04 应用科学伦理

> **UDC 6** —— 技术是**放大器**：功率越大、外溢越广、越不可逆，就越需要伦理。
> 本章是 [[03-应用科学方法论|03 方法论]] 的**价值约束**：不只问「**能不能做**」，更问「**该不该做 · 谁负责**」。

---

## 一、为什么技术需要伦理

| 特征 | 伦理含义 |
|:--|:--|
| **力量** | 能改世界 → 就有**责任** |
| **外溢** | 影响**第三方与后代**（非自愿者） |
| **不可逆** | 有些后果（核 · 基因 · 环境）**无法撤回** |
| **信息不对称** | 专家 vs 公众 · 制造者 vs 使用者 |
| **双重用途** | 同一技术可善用，也可恶用 |

---

## 二、核心原则

| 原则 | 含义 |
|:--|:--|
| **善行 / 不伤害** | 增进福祉 · 避免伤害（首要） |
| **责任** | 可追溯、有人对后果负责 |
| **自主与知情同意** | 尊重当事人的自愿选择 |
| **公正** | 收益与风险**公平分配** |
| **预防原则** | 科学不确定时，先审慎 |
| **可持续 / 代际正义** | 不牺牲后代满足当下 |
| **透明与可解释** | 决策与系统可被审视 |

## 四、三类伦理框架（思考工具）

| 框架 | 判据 | 追问 |
|:--|:--|:--|
| **后果论** | 看结果（最大善） | 谁受益 / 受损？净效果如何？ |
| **义务论** | 看原则 / 责任 | 有无权利被侵犯？是否可普遍化？ |
| **美德论** | 看人（品格） | 正直的人会怎么做？ |

> **快速自检三问**：① 谁会受益、谁会受损？② 有人的权利被侵犯吗？③ 我愿意被这样对待吗？

## 五、工程伦理准则与治理工具

**准则（工程师 / 科学家的职业承诺）：**

1. **公众的安全、健康与福祉优先**。
2. 只在**胜任**范围内执业。
3. **客观、诚实**——不伪造、不隐瞒风险。
4. 拒绝不合伦理的指令；必要时**揭弊（whistle-blowing）**。
5. 尊重自然与环境。

**治理工具：**

| 工具 | 作用 |
|:--|:--|
| 法律 / 标准 | 底线约束（强制规范 · 监管） |
| 伦理审查 | IRB（人体研究）· IACUC（动物）· 机构伦理委员会 |
| 认证 / 许可 | 执业资格 · 产品认证 |
| 影响评估 | 环境（EIA）· 隐私（DPIA）· 安全（HAZOP） |
| 审计 / 追溯 | 事后核验 · 责任可查 |

## 六、经典案例（教训）

| 案例 | 教训 |
|:--|:--|
| **挑战者号 / 哥伦比亚号** | 安全被**进度与层级**压过 —— 组织性失职 |
| **福特 Pinto** | 用**成本-收益**折算生命 → 底线错误 |
| **切尔诺贝利 / 福岛** | 系统设计与**监管失效**叠加 |
| **沙利度胺（反应停）** | 药物审批与**知情同意**的必要 |
| **三鹿奶粉 / 数据造假** | 逐利压倒诚信 → 公共灾难 |
| **基因编辑婴儿** | 越界 · 未经充分伦理审查 · 不可逆 |

> 共同模式：**不是技术不够强，而是「人 / 组织 / 制度」在压力下放弃了对后果的尊重。**

---

## 核心问题

**技术的力量越大，越必须先回答：应该做吗？谁受益？谁受损？谁负责？**
