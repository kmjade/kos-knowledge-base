# 07 材料与能源基础

> **UDC 6** —— **材料**是「造物」的**物质基础**，**能源**是「做功」的**动力基础**；二者是全部应用科学的**共同底座**。
> 本章为导论主线的**资源层**：材料（`62`/`66`/`67`/`68`）与能源（`620`/`66`/`621.3`）。

---

## 一、材料：从原子到部件

### 1.1 材料四要素

```
成分 → 结构 → 工艺 → 性能
（Composition → Structure → Processing → Properties/Performance）
```

> 改**工艺**就能改**结构**，改**结构**就能改**性能** —— 这是材料工程的全部杠杆。

### 1.2 材料家族

| 家族 | 代表 | 特点 |
|:--|:--|:--|
| **金属** | 钢 · 铝 · 铜 · 钛 | 强度 · 导电导热 · 可加工 |
| **无机非金属** | 陶瓷 · 玻璃 · 水泥 · 石材 | 硬 · 耐高温 · 脆 |
| **高分子** | 塑料 · 橡胶 · 纤维 · 涂料 | 轻 · 易成型 · 耐蚀（但耐温差） |
| **复合材料** | 碳纤维 · 玻璃钢 · 混凝土 | 取长补短 |
| **功能材料** | 半导体 · 磁性 · 光电 · 形状记忆 | 功能优先 |

### 1.3 性能维度

| 维度 | 指标 |
|:--|:--|
| **力学** | 强度 · 硬度 · 韧性 · 疲劳 · 蠕变 |
| **物理** | 电 / 磁 / 热 / 声 / 光 |
| **化学** | 耐蚀 · 稳定性 |
| **工艺** | 可铸 · 可焊 · 可加工 · 可回收 |

### 1.4 选材方法

**约束（不达标就淘汰）+ 目标（越大越好）→ 材料性能指标 → Ashby 选材图。**

## 二、能源：从一次到终端

### 2.1 能源链

```
一次能源 → 转换 → 二次能源（电 / 热 / 氢）→ 输配 → 终端用能
```

### 2.2 能源类型

| 类 | 例 |
|:--|:--|
| **化石** | 煤 · 石油 · 天然气（高碳 · 有限） |
| **核** | 裂变 · （聚变·未来） |
| **可再生** | 水 · 风 · 光 · 生物质 · 地热 · 潮汐 |
| **储能** | 电池 · 抽水蓄能 · 储热 · 储氢 |

### 2.3 效率与热力学

- **第一定律**：能量守恒（不能凭空造能）；
- **第二定律**：**方向性** · **熵增** · **卡诺极限**（热机效率 < `1 − Tc/Th`）；
- **能量品质（exergy）**：电能 ≈ 纯功；低温热 ≈ 低品质。

> 一句话：**没有"免费能源"，只有效率与品质的取舍。**

### 2.4 能源系统与转型

发电 → 输配 → 用电；**电网**是最大的人造系统（见 [[06-技术系统与基础设施|06 系统]]）。
**转型方向**：电气化 · 可再生 · 储能 · 氢能 · 智能电网 → **碳中和**。

## 三、材料 × 能源（交叉前沿）

| 方向 | 关键材料 / 技术 |
|:--|:--|
| 光伏 | 硅 · 钙钛矿 · 薄膜 |
| 电池 | 锂离子 · 钠离子 · 固态 |
| 储氢 | 高压 · 液氢 · 金属氢化物 |
| 热电 / 节能 | 热电材料 · 相变材料 · 保温 |
| 核能 | 燃料 · 包壳 · 屏蔽材料 |

> 能源转型，本质是一场**材料战** —— 谁掌握关键材料（锂 · 稀土 · 硅），谁掌握能源。

---

## 四、可持续与循环

| 原则 | 说明 |
|:--|:--|
| **减量（Reduce）** | 少用材料 / 少耗能（第一优先） |
| **复用（Reuse）** | 延长寿命 |
| **回收（Recycle）** | 闭环回炉 |
| **再设计（Redesign）** | 面向循环设计（易拆解 · 单一材料） |
| **全生命周期评估（LCA）** | 从摇篮到坟墓算清账 |

> 呼应 [[04-应用科学伦理|04 伦理]]：**代际正义** 要求把"末端治理"前移到"源头设计"。

---

## 核心问题

**用什么材料、什么能源，才能造得出来、跑得起来、且可持续？**
