# 12 技术与社会

> **UDC 6** —— 技术不是真空里的产物：它**由社会塑造**，又反过来**重塑社会**。
> 本章把 [[3 Resources/600-Technology/600-Technology|600 技术]] 与 [[300-Social|300 社会科学]] 系在一起。

---

## 一、两种视角

| 视角 | 主张 |
|:--|:--|
| **技术决定论** | 技术按自身逻辑演进，**决定**社会 |
| **社会建构论（SCOT）** | 技术是社会**协商建构**的产物 |

> **结论（现代共识）**：技术与社会**共构 / 共演** —— 互为因果，难分先后。

---

## 二、技术如何塑造社会

| 维度     | 影响                                                                                                |
| :----- | :------------------------------------------------------------------------------------------------ |
| **经济** | 生产力 · 增长 · 分配与不平等                                                                                 |
| **劳动** | 自动化 · 替代 / 创造 · 技能升级或极化                                                                           |
| **文化** | 媒体 · 注意力 · 生活方式                                                                                   |
| **政治** | 治理 · 监控 · 信息战 · 动员                                                                                |
| **空间** | 城市化 · 基础设施（见 [[06-技术系统与基础设施\|06 技术系统与基础设施]]） |

---

## 三、社会如何塑造技术

| 机制 | 说明 |
|:--|:--|
| **需求拉动 vs 技术推动** | 市场/社会需求牵引技术方向 |
| **制度 / 文化 / 政策** | 补贴 · 法规 · 价值观塑造技术路径 |
| **路径依赖与锁定** | 早期社会选择决定长期形态（见 [[02-应用科学史与技术演化\|02 史]]） |
| **使用者再发明（domestication）** | 用户按己意改造技术 |

> 案例：QWERTY 键盘 · 铁路轨距 · 电动车政策 · 各国隐私法规塑造互联网形态。

## 四、关键议题

| 议题 | 说明 |
|:--|:--|
| **数字鸿沟** | 接入 / 技能 / 收益不均 |
| **隐私与监控** | 数据权力 · 治理边界 |
| **平台与零工** | 劳动形态与保障 |
| **自动化与就业** | 替代 · 创造 · 技能极化 |
| **技术地缘** | 技术民族主义 · 出口管制 · 供应链安全 |
| **人机关系** | 依赖 · 代理 · 主体性（见 [[09-数字化与智能技术\|09 数字智能]]） |

---

## 五、社会技术系统（Socio-technical Systems）

> **技术 = 硬件 + 人 + 制度 + 文化**。一个技术要真正落地，必须整套**社会安排**到位（培训 · 法规 · 配套 · 惯例）。

只换硬件、不改系统 → **自动化常失败**（组织不匹配）。

## 核心问题

**技术与社会，谁塑造谁？如何让技术「为多数人增益」，而非加剧分化？**
