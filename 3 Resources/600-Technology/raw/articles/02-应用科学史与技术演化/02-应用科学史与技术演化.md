# 02 应用科学史与技术演化

> **UDC 6** —— 应用科学的历史，是「**人如何把自然规律变成可用的东西**」的历史。
> 本章是 [[01-应用科学概述|01 应用科学概述]] 的续章：前者立**概念**，本章给**时间轴与演化逻辑**。

## 一、九段历程

| 时期 | 标志技术 | 关键跃迁 |
|:--|:--|:--|
| **史前**（~1 万年前） | 石器 · 用火 · 种植 · 制陶 | 从采集 → 生产 |
| **古代**（~前 3000–500） | 冶金 · 文字 · 灌溉 · 建筑 · 医学 | 专业化 · 城市 |
| **古典–中世纪**（500–1400） | 造纸 · 印刷 · 火药 · 指南针 · 机械钟 | **知识可复制** |
| **科学革命**（16–17C） | 望远镜 · 显微镜 · 大气压 · 力学 | **科学开始反哺技术** |
| **工业革命 1.0**（18C 末） | 蒸汽机 · 纺织机械 · 铁路 | 动力替代人力 |
| **工业革命 2.0**（19–20C 初） | 电力 · 内燃机 · 化工 · 电报 | 能源与化工体系 |
| **工业革命 3.0**（20C 中后） | 计算机 · 半导体 · 航天 · 核能 | 信息与自动化 |
| **工业革命 4.0**（21C） | 互联网 · 移动 · 生物技术 · AI | 智能与融合 |
| **当代** | 新能源 · 机器人 · 合成生物 · 生成式 AI | 跨域收敛 |

## 二、演化逻辑（五条规律）

| 规律 | 含义 |
|:--|:--|
| **组合进化** | 新技术 ≈ 既有技术的**重新组合**（Brian Arthur《技术的本质》） |
| **S 曲线** | 每项技术经历「诞生 → 加速 → 饱和 → 被替换」的生命周期 |
| **通用目的技术（GPT）** | 蒸汽 · 电力 · 计算机 · AI 等**通用技术**重塑全部行业 |
| **科学 ↔ 技术双向** | 古代技术先行、科学滞后；19C 起科学引领；当代二者交织 |
| **路径依赖与锁定** | 历史选择（QWERTY 键盘 · 铁路轨距）塑造今天的形态 |

## 四、值得记住的转折点

1. **可复制知识**（印刷术）：把「个人经验」变成「社会资产」—— 现代技术加速的总开关。
2. **科学引领技术**（19C 电磁学 → 电动机 · 发电机）：从「工匠试错」转向「原理驱动」。
3. **通用技术扩散**（电力 · 计算机）：真正改变世界的不是发明本身，而是**它渗透进所有行业**。
4. **系统化**（标准化 · 流水线 · 质量工程）：让技术从「能做」走向「**稳定、廉价、大规模**」。
