# 08 制造范式与自动化

> **UDC 6** —— 制造是「把设计变成实物」的环节；**每次"范式"跃迁，都重写了成本、速度与质量的边界。**
> 本章为导论主线的**实现层**：制造（`67` · `68` · `62`）与自动化（`681.5`）。

---

## 一、范式演进

| 阶段 | 标志 | 跃迁 |
|:--|:--|:--|
| **手工** | 匠人 · 单件 | 技艺，不可复制 |
| **工场 / 互换性** | 分工 · 可互换零件（Whitney） | 可批量修配 |
| **流水线** | 福特 T 型（1913） | 节拍 · 大规模 · 降本 |
| **精益** | 丰田 TPS | 消除浪费 · 小批量多样 |
| **自动化 / 机器人** | PLC · 工业机器人 | 去人化 · 一致性 |
| **数字化** | CAD/CAM · MES · 数字孪生 | 信息贯通 |
| **智能 / 柔性** | 工业 4.0 · CPS · AI | 自适应 · 大规模定制 |
| **增材 / 分布式** | 3D 打印 · 按需 | 无模具 · 本地化 |

---

## 二、生产系统的四种形态

| 形态 | 特征 | 适合 |
|:--|:--|:--|
| **Job shop**（车间） | 通用设备 · 多变 | 单件 / 小批 |
| **Flow shop**（流水） | 固定路线 · 高效 | 大批量 |
| **Cellular**（单元） | 成组技术 · 一族产品 | 中小批 |
| **FMS**（柔性制造系统） | 可重构 · 自动换型 | 多品种中批 |

---

## 三、制造的核心指标

节拍（Takt）· 产能 · **OEE**（设备综合效率）· 良率 · 在制品（WIP）· 交付期（Lead time）· 单位成本。

> **利特尔法则**：`WIP = 产出率 × 周期时间` —— 在制品越多，交付越慢。

---

## 四、自动化

**层次**：机械化 → 半自动 → 全自动 → **自适应 / 智能**。

| 技术 | 作用 |
|:--|:--|
| **PLC / 工控** | 逻辑与流程控制 |
| **CNC** | 数控加工（见 [[62-工程学\|62 工程学]]） |
| **工业机器人** | 焊接 · 搬运 · 装配 · 喷涂 |
| **协作机器人（cobot）** | 人机同工位 |
| **AGV / AMR** | 物流自动化 |
| **机器视觉** | 检测 · 引导 · 定位 |
| **SCADA / MES** | 监控 / 制造执行 |

> 机器人学另见 [[68-成品制造|68 成品制造]]（`681.5` 的 UGV · microROS · RoboMaster）与 [[007-控制论|007 控制论]]。

---

## 五、精益与质量

- **TPS / 精益**：准时化（JIT）· 看板 · **七种浪费**（过量生产 · 等待 · 搬运 · 加工 · 库存 · 动作 · 不良）；
- **质量**：QC/QA · SPC · **六西格玛**（见 [[03-应用科学方法论|03 方法论]] · `005.6` 质量管理）。

---

## 六、数字化与智能

| 概念 | 含义 |
|:--|:--|
| **CAD / CAM / CAPP** | 设计 → 制造 → 工艺规划 |
| **PLM** | 产品全生命周期管理 |
| **数字孪生** | 物理系统 ↔ 虚拟镜像 |
| **工业 4.0 / CPS** | 信息物理系统 · 互联 · 自治 |
| **IIoT** | 工业物联网 · 数据采集 |
| **预测性维护** | 用数据预判故障 |
| **AI 制造** | 排产 · 质检 · 工艺优化 |

---

## 七、增材与分布式

- **增材制造（3D 打印）**：从**减材**（切削）到**增材**（逐层堆积）—— 无模具、可定制、拓扑自由；
- **分布式 / 按需制造**：就近生产，压缩供应链（呼应 [[06-技术系统与基础设施|06 基础设施]]）。

---

## 八、单位经济与可持续

| 命题 | 张力 |
|:--|:--|
| **规模 vs 定制** | 大规模定制的"甜蜜点" |
| **效率 vs 柔性** | 换型成本决定多品种经济性 |
| **增长 vs 可持续** | 绿色制造 · 循环（见 [[07-材料与能源基础\|07 材料与能源]]） |

---

## 核心问题

**如何以更低的成本、更高的质量、更快的速度，把设计「批量」变成实物？**
