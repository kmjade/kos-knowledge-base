# 05 通信方式

## JSON 指令支持的通信方式

| 方式 | 说明 |
|------|------|
| 串口/USB | 上位机通过串口与 ESP32 通信 |
| HTTP 请求 | 网络下发 JSON 指令 |
| ESP-NOW | 无线点对点通信 |
| Web 应用 | 浏览器控制页下发指令 |

## 上位机通信

上位机（树莓派/Jetson/旭日 X3）通过**串口**与 ESP32 下位机通信。

## 配置灵活

大部分配置可用 JSON 指令实现（如无需 USB 线即可配置 WiFi）。
