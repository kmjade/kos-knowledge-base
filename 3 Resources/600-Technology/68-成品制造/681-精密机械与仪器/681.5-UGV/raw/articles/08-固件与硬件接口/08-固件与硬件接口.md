# 08 固件与硬件接口

## 固件更新

- 支持固件更新
- 自动下载电路，可边充电边使用
- ESP32 下载工具

## 驱动板板载接口

| 接口 | 说明 |
|------|------|
| TTL 总线舵机接口 | 云台/机械臂 |
| I2C | 传感器 |
| UART | 串口通信 |
| SD 卡 | 存储 |
| PWM | 舵机 |

## 电机参数

- 编码器电机，速度闭环
- PID 可配置（JSON 指令）
