# 02 硬件与架构

## 整体架构

```
上位机（可选）：树莓派 / Jetson Nano / Jetson Orin Nano / 旭日 X3
        ↓ 串口
下位机：ESP32（板载 WiFi + 蓝牙）
        ↓
驱动板：直流电机（编码器）、总线舵机、PWM 舵机、SD 卡
供电：UPS 模块（3S 18650 7800mAh + INA219）
交互：0.96" OLED
```

## 核心部件

| 部件 | 说明 |
|------|------|
| 底盘 | 六轮四驱，橡胶轮胎减震 |
| 下位机 | ESP32（WiFi + 蓝牙） |
| 驱动板 | 直流电机、总线/PWM 舵机、SD 卡 |
| 供电 | UPS 3S 18650（7800mAh），5V/3.3V 输出 |
| 扩展 | 1020 铝型材导轨（203mm 间距） |

## 电机

- 编码器电机，支持**速度闭环控制**
- PID 可配置
