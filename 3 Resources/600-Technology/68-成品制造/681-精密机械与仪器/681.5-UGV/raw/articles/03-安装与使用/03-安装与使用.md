# 03 安装与使用

## 使用前注意（必读）

- 检查电池安装与接线
- 首次上电确认电源

## 电池安装

3 节 18650 串联（3S），UPS 模块提供防过充/过放/过流/短路保护。

## 首次使用

1. 安装电池
2. 上电
3. ESP32 自动建立 WiFi 热点
4. 连接热点，用浏览器打开控制页

## Web 端控制

- 无需 APP，Chromium 内核浏览器即可
- 手机或电脑连接热点后登录控制页
- 可下发 JSON 指令控制机器人

## 固件更新

- 支持固件更新（自动下载电路，可边充电边使用）
