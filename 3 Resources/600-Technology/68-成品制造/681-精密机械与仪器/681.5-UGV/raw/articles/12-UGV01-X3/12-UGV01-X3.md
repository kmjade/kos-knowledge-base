# 12 UGV01-X3

## 什么是 UGV01-X3

UGV01-X3 是 **UGV01（履带底盘）** 的 AI 定位变体，上位机升级为 **地平线旭日 X3**，并搭载 **DTOF LD19 激光雷达**与**夜视红外摄像头**，面向 ROS2 与高阶视觉/导航开发。

![[Pasted image 20260915150457.png]]
![[Pasted image 20260915150514.png]]

#### UGV01 系列产品是一款具备超强的越野通过能力、抗震性能和开源全部代码可二次开发的移动机器人履带底盘。支持扩展多种上位机，该型号产品的上位机为旭日® X3 派，上位机通过串口与 ESP32 下位机进行通信，电机带有编码器可以获得速度反馈来进行速度闭环控制。内置 3S 18650 锂电池 (3 节 18650 锂电池串联) UPS 供电模块，为机器人提供持续能量来源的同时支持边充电边放电。内置多功能机器人驱动板，可扩展总线舵机、PWM 输出、SD 卡等功能，驱动板基于 ESP32，板载 WIFI 和蓝牙、板载 9 轴 IMU。  
  
它采用了多独立悬挂系统，大幅度减少了复杂地形冲击，并配有两条 1020 欧标型材扩展导轨，使其轻松满足重载、避震、越野等要求，为二次开发提供了更多的可行性。

![灵活可扩展型越野履带 UGV](https://www.waveshare.net/photo/accBoard/UGV01-X3/UGV01-X3-details-5.jpg)

## 产品特性

- 采用**多独立悬挂系统**，每侧配有四个独立悬挂，大幅度减少复杂地形冲击。
- 重负载爬坡时，悬挂收缩，后轮会提供格外支撑，拥有优秀的爬坡能力。
- 电机带有**编码器**，可获得速度反馈进行速度闭环控制。
- 搭载交互设备 **0.96inch OLED 屏幕**。
- 带有充电接口和自动下载电路，可**边充电边使用**。
- UPS 供电模块板载 **INA219** 采集芯片，实时监控电池电压、充电电流。
- UPS 供电模块三节串联 18650 电池，**7800mAh** 大容量，输出电流更大，电机动力更强。
- UPS 供电模块提供输出 **5V / 3.3V** 用于扩展其它设备。
- 板载锂电池保护电路：防过充、防过放、防过流、短路保护。
- 例程基于 **Arduino IDE**（免手动配置编译环境）；ESP32 开机自建 WIFI 热点，手机/电脑（Chromium 浏览器）连入 `192.168.4.1` 即可控制，**无需装 App**。
- 下位机 ESP32 可驱动直流电机、总线舵机，板载 OLED 接口、TF 卡槽、九轴 IMU、WiFi/蓝牙；不接上位机也可单独使用。
- 上位机为旭日 X3，经串口与下位机通信，用其算力做高阶开发。
- 搭载 **DTOF LD19 激光雷达**（0.02~12m · 360° 测距）。
- 搭载**可夜视红外摄像头**（光线强时开 IR-CUT，弱时可关闭做主动夜视）。
- 全部代码开源，提供丰富文档与教程。

## 教程

> ⚠️ **购买海外版**需自行安装 **3 个 18650 锂电池**方可使用。首次接电池注意 LED 灯：**亮起 = 电池正负极接反**，请检查；**接反时禁止充电**（有爆炸风险）。

### 1. 安装电池

- [UGV01/UGV01-X3 安装电池](https://www.waveshare.net/wiki/UGV01/UGV01-X3%E5%AE%89%E8%A3%85%E7%94%B5%E6%B1%A0)

### 2. 基本使用

上位机旭日 X3、下位机 ESP32。开机后 ESP32 优先连接已知 WIFI 热点；20 秒内未连上则自建热点：

- 热点名：`UGV01_BASE` · 密码：`12345678`
- 手机连热点后（提示无网络时选「不允许切换」，保持连接），用 Chrome 访问 `192.168.4.1` 打开控制页：查看电压 / 姿态角、控制移动、发 JSON 命令控制总线舵机 / PWM 舵机、切换摄像头 IR-CUT 等。

下位机 ↔ 上位机为**串口通信**，波特率 `1,000,000`；数据结构与 Web 控制的 JSON 相同，例：`{"T":1,"L":0.5,"R":0.5}`（`T=1` 履带动作；`L`/`R` = 左/右履带速度，m/s）。

### 4. 上位机旭日 X3 入门

- [旭日 X3 官方教程 · 快速开始](https://developer.horizon.ai/api/v1/fileData/documents_pi/Quick_Start/Quick_Start.html#id3) —— 可直接跑 MIPI 摄像头例程（需 HDMI）：

```bash
cd /app/ai_inference/03_mipi_camera_sample/
sudo python3 ./mipi_camera.py
```

- [TogetherROS 机器人平台用户手册](https://developer.horizon.ai/api/v1/fileData/TogetherROS/index.html) —— 地平线面向机器人的操作系统
- [Apps 应用实例（SLAM / NAV2）](https://developer.horizon.ai/api/v1/fileData/TogetherROS/app/index.html) —— 需**多机通信**：VMware + Ubuntu **20.04**（TogetherROS 基于 ROS Foxy，仅 20.04 可装）+ 网络适配器**桥接模式**；使 Ubuntu IP 与 X3 前三段一致（如 `192.168.10.X`）。参考 [ROS Foxy 官方文档](https://docs.ros.org/en/foxy/Installation/Ubuntu-Install-Debians.html)。

### 5. 激光雷达 ROS2 包安装 / 使用

```bash
mkdir -p ldlidar_ros2_ws/src && cd ldlidar_ros2_ws/src
git clone https://github.com/ldrobotSensorTeam/ldlidar_stl_ros2.git
cd ~/ldlidar_ros2_ws
sudo chmod 777 /dev/ttyUSB0          # 雷达通常为 /dev/ttyUSB0（ls -l /dev/tty* 查看）
source /opt/tros/local_setup.bash    # 或 /opt/ros/foxy/local_setup.bash
sudo apt install python3-colcon-common-extensions && colcon build
source install/setup.bash
ros2 launch ldlidar_stl_ros2 ld19.launch.py           # 启动 LD19 节点
ros2 launch ldlidar_stl_ros2 viewer_ld19.launch.py    # RViz2 显示
```
