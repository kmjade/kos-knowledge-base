# JSON 指令集 JSON Commands

## 定义

JSON 指令集是 UGV 的**交互协议**：文本 JSON 命令控制机器人（底盘速度 CMD_SPEED_CTRL、PWM、ROS 控制 CMD_ROS_CTRL、PID、OLED、IMU、云台/机械臂），语言无关，支持串口/USB/HTTP/ESP-NOW。
