# ESP32 下位机

## 定义

ESP32 是 UGV 的**下位机主控**，板载 WiFi + 蓝牙，Arduino IDE 开发。负责驱动直流电机、总线舵机等，与上位机通过串口通信，解析 JSON 指令。
