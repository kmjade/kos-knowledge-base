# ROS 控制 ROS Control

## 定义

ROS 控制是 UGV 的上层控制方式：下位机支持 `CMD_ROS_CTRL`，上位机运行 ROS2，将 `/cmd_vel` 转换为 JSON 指令驱动底盘。
