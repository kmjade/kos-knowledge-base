# 开发板 Dev Board

## 定义

开发板是 RoboMaster 的**嵌入式硬件平台**：A 型板（STM32F427，竞赛/进阶）与 C 型板（教育）。支持 CAN 通信驱动 M3508/M2006 电机、FreeRTOS、UWB 定位、IMU、PWM、OLED、SD 卡等。
