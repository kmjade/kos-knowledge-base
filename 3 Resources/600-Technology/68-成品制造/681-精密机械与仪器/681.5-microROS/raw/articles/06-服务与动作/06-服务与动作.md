# 06 服务与动作

## Service 服务

[[Service-服务|服务]] 是请求/响应（req/res）的同步通信，适合一次性配置、参数读取、命令下发。

```c
rcl_service_t srv;
rclc_service_init_default(&srv, &node,
  ROSIDL_GET_SRV_TYPE_SUPPORT(example_interfaces, srv, SetBool), "/set_led");
```

## Action 动作

[[Action-动作|动作]] 面向长时任务（导航、抓取、扫描），带反馈/取消。micro-ROS 对 action 支持有限，复杂 action 建议上位机实现、MCU 只做底层执行。

## executor 与并发

MCU 单线程下，`rclc` 用 executor 统一调度回调；多个实体（定时器/订阅/服务）排队轮询。实时性要求高时注意回调内避免阻塞。

## 选型建议

| 场景 | 选择 |
|:----|:-----|
| 持续数据流（里程计/IMU） | topic |
| 一次性命令（开关/设参） | service |
| 长时任务（导航/抓取） | action（尽量上位机侧） |
