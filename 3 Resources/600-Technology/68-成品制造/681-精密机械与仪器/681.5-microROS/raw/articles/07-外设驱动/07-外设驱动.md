# 07 外设驱动

## 核心思路

把底盘相关的外设「脏活」封装成标准 ROS 2 topic，主控只消费话题：

| 外设 | 硬件接口 | 输出 topic |
|:----|:--------|:----------|
| 编码器电机 | PWM + 编码器 | `/odom`（`nav_msgs/Odometry`） |
| IMU | I2C/SPI | `sensor_msgs/Imu` |
| LiDAR | UART | `sensor_msgs/LaserScan` |
| 舵机/云台 | PWM | 自定义或 `JointState` |
| 蜂鸣器/LED | GPIO | `std_msgs` / 自定义 |

## 底盘速度契约

订阅 `/cmd_vel`（`geometry_msgs/Twist`）→ 解算各轮转速 → 驱动电机；同时由编码器积分发布 `/odom`。这是本项目「接口契约优先」原则在 MCU 侧的落地形式。

## ESP32-S3 外设要点

- 编码器电机驱动：4 通道（Yahboom 板）
- PWM 舵机：2 通道
- IMU：QMI8658B（V2）6 轴
- LiDAR：UART1（TX GPIO17 / RX GPIO18）
- 电平 3.3V，接线先断电
