# Service 服务

## 定义

Service 是 ROS 2 / [[micro-ROS]] 的请求/响应（req/res）同步通信实体，适合一次性命令、参数读取。MCU 侧用 [[rclc]] 的 client/server API 实现。与持续数据流的 [[Topic-话题]] 互补。
