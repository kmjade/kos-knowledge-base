# Action 动作

## 定义

Action 是 ROS 2 / [[micro-ROS]] 面向长时任务（导航、抓取、扫描）的通信实体，带反馈与取消。micro-ROS 对 action 支持有限，复杂长时任务建议在上位机侧实现，MCU 只做底层执行。
