# Raspberry Pi

## 定义

Raspberry Pi（树莓派）是 [[micro-ROS]] 常见的上位机主控，运行 ROS 2 + [[micro-ROS-Agent]]（常 Docker），与 [[ESP32-S3]] 下位机构成大小脑架构。5/4B 用于教育/轻量场景。
