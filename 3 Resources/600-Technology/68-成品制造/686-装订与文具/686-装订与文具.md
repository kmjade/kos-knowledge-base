# 686 装订与文具

> **UDC 686** — 装订 · 金属镀饰 · 制镜 · 文具（Bookbinding. Metallizing. Mirror-making. Stationery）。
> 隶属 [[68-成品制造|68 成品制造]]。

## 类目

**装订、制镜与文具**制造。

## 内容要点

| 方面 | 要点 |
|------|------|
| 装订 | 骑马订 · 无线胶装 · 精装 · 线装 |
| 印后加工 | 覆膜 · 烫金 · 模切 · 裱糊 |
| 制镜与镀饰 | 玻璃镜 · 金属镀饰 |
| 文具 | 笔 · 本册 · 办公文具 · 美术用品 |
| 标准 | 学生用品安全（GB 21027） |

## 边界
