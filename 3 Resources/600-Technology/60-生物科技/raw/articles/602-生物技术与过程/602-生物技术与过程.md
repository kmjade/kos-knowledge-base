# 602 生物技术与过程

> **UDC 602** — 生物技术过程与技术（Processes and techniques in biotechnology）。
> 隶属 [[60-生物科技|60 生物科技]]。

## 类目

把生物体系变成产品的**过程与技术** —— 上游（改造）· 中游（培养/发酵）· 下游（分离纯化）。

## 内容要点

| 环节 | 技术 |
|------|------|
| 上游（Upstream） | 基因操作 · 重组 DNA · 载体构建 · 宿主转化（细菌/酵母/哺乳细胞） |
| 中游（Fermentation） | 培养基 · 灭菌 · 生物反应器 · 分批/流加/连续培养 · 参数控制（pH/溶氧/温度） |
| 下游（Downstream） | 固液分离 · 细胞破碎 · 层析 · 超滤 · 结晶 · 冻干 |
| 分析检测 | PCR/qPCR · 电泳 · 色谱 · 质谱 · 酶活测定 |
| 放大与工程 | 中试 · 放大准则 · 无菌操作 · GMP 车间 |
