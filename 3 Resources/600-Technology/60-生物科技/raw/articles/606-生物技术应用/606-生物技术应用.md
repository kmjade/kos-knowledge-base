# 606 生物技术应用

> **UDC 606** — 生物技术应用（Applications of biotechnology）。
> 隶属 [[60-生物科技|60 生物科技]]。

## 类目

生物技术在各领域的**应用** —— 按应用领域划分（医药 / 工业 / 农业 / 环境 / 能源 / 食品）。

## 内容要点

| 领域 | 应用 |
|------|------|
| 医药健康（Red） | 生物制药 · 疫苗 · 基因与细胞治疗 · 体外诊断 · 组织工程 |
| 工业（White） | 工业酶 · 生物催化 · 生物基化学品 · 生物炼制 |
| 农业（Green） | 转基因作物 · 分子育种 · 生物农药 · 生物固氮 |
| 环境（Grey） | 生物修复 · 废水处理 · 固废生物处理 · 生物监测 |
| 能源 | 生物燃料（乙醇/生物柴油/沼气）· 微生物燃料电池 |
| 食品 | 发酵食品 · 食品添加剂 · 益生菌 |

## 组合类号（UDC 冒号）

- `606:61` — 生物技术应用于医学
- `606:63` — 生物技术应用于农业
- `606:502` — 生物技术应用于环境保护
