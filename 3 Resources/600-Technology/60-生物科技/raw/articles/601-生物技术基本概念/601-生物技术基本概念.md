# 601 生物技术基本概念

> **UDC 601** — 生物技术基本概念（Fundamental concepts）。
> 隶属 [[60-生物科技|60 生物科技]]。

## 类目

生物技术的**定义、范畴与学科定位** —— 与基础生物学、医学、农学、化学工程的边界。

## 内容要点

| 项 | 说明 |
|------|------|
| 定义 | 利用**生物体系（细胞 / 酶 / 基因）**或其组分，为人类生产有用产品或提供服务的技术 |
| 古典 vs 现代 | 古典：酿造 · 制酱 · 育种；现代：**基因工程 · 细胞工程 · 发酵工程 · 酶工程 · 蛋白质工程** |
| 五大工程 | 基因工程 · 细胞工程 · 发酵工程 · 酶工程 · 蛋白质工程 |
| 关键概念 | 重组 DNA · 克隆 · 表达系统 · 生物反应器 · 生物加工 |
| 学科关系 | 基础原理源自 57 生物学；应用落于 61 医学 / 63 农学 / 66 化工 |

## UDC 定位

- 60 相对 **57 生物学**：57 是**基础**（结构与机理），60 是**应用技术**（过程与产品）。
- 60 相对 **61 医学 / 63 农学**：后两者按**应用领域**分，60 按**技术手段**分，交叉处用冒号组合（如 `606:61`）。
