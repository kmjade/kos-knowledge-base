# 671 贵金属与宝石制品

> **UDC 671** — 贵金属与宝石制品（Articles of precious metals, gems, precious stones）。
> 隶属 [[67-各种工业|67 各种工业]]。

## 类目

金 · 银 · 铂等**贵金属**与**宝石**制成的工艺品与首饰。

## 内容要点

| 方面 | 要点 |
|------|------|
| 贵金属 | 金/银/铂 · 纯度（K 金）· 合金 |
| 首饰工艺 | 铸造 · 錾刻 · 镶嵌 · 抛光 |
| 宝石 | 钻石 · 彩宝 · 玉石 · 分级（4C） |
| 鉴定 | 成色 · 印记 · 证书 |
| 标准 | 贵金属纯度、首饰有害元素限量 |
