# 673 有色金属制品

> **UDC 673** — 有色金属制品（Articles of nonferrous metals, except precious metals）。
> 隶属 [[67-各种工业|67 各种工业]]。

## 类目

**非贵金属有色金属**（铝 · 铜 · 锌 · 镁 · 钛等）的制品。

## 内容要点

| 方面 | 要点 |
|------|------|
| 铝制品 | 铝型材 · 铝板 · 压铸件（门窗/箱体） |
| 铜制品 | 铜管 · 铜线 · 黄铜件 · 铜合金 |
| 其他 | 锌合金 · 镁合金 · 钛制品 |
| 表面处理 | 阳极氧化 · 电镀 · 拉丝 |
| 应用 | 建筑 · 电气 · 交通轻量化 |
