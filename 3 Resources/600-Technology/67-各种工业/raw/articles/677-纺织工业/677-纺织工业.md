# 677 纺织工业

> **UDC 677** — 纺织工业（Textile industry）。
> 隶属 [[67-各种工业|67 各种工业]]。

## 类目

**纤维 → 纱线 → 织物 → 染整**的工业链。

## 内容要点

| 方面 | 要点 |
|------|------|
| 纤维 | 天然（棉麻毛丝）· 化学纤维（涤纶/锦纶/粘胶） |
| 纺纱 | 开清 · 梳棉 · 并条 · 粗纱 · 细纱 |
| 织造 | 机织 · 针织 · 无纺 |
| 染整 | 前处理 · 染色 · 印花 · 后整理 |
| 性能 | 克重 · 密度 · 色牢度 · 缩水 |
| 智能纺织 | 功能性纤维 · 智能可穿戴 |
