# 675 皮革工业

> **UDC 675** — 皮革工业（Leather industry，含毛皮与人造革）。
> 隶属 [[67-各种工业|67 各种工业]]。

## 类目

**制革**与毛皮、人造革工业。

## 内容要点

| 方面 | 要点 |
|------|------|
| 原料皮 | 生皮种类 · 防腐保存 |
| 制革工序 | 浸水 · 脱毛 · 鞣制（铬/植鞣）· 整饰 |
| 毛皮 | 鞣制 · 染色 · 皮草 |
| 人造革 | PU/PVC 合成革 · 超纤 |
| 皮革制品 | 鞋面 · 箱包 · 服装（下游入 68/685） |
| 环保 | 铬污染治理 · 清洁生产 |
