# 661 化学品

> **UDC 661** — 化学品（Chemicals）。
> 隶属 [[66-化学技术|66 化学技术]]。

## 类目

化学工业的**产品** —— 基本化学品与精细化学品。

## 内容要点

| 方面 | 要点 |
|------|------|
| 无机化学品 | 酸 · 碱 · 盐 · 化肥 · 氯碱 |
| 有机化学品 | 烃类 · 醇醛酸酯 · 溶剂 |
| 基本 vs 精细 | 大宗（三酸两碱）· 精细（医药/农药/染料中间体） |
| 催化 | 催化剂类型 · 择形 · 失活与再生 |
| 生产单元 | 合成氨 · 硫酸 · 乙烯 |
