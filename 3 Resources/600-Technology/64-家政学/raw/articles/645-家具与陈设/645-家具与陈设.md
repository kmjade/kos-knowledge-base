# 645 家具与陈设

> **UDC 645** — 家具与陈设（Household furnishings）。
> 隶属 [[64-家政学|64 家政学]]。

## 类目

**家用器具与陈设** —— 从使用角度（制造入 67/68）。

| 方面 | 要点 |
|------|------|
| 家具 | 坐卧 · 储物 · 桌几 · 材质（实木/板式/金属） |
| 家用电器 | 厨电 · 清洁电器 · 环境电器 |
| 家用器具 | 炊具 · 餐具 · 五金 |
| 室内陈设 | 布艺 · 灯具 · 装饰品 · 绿植 |
| 选购与保养 | 尺寸/材质 · 保养 · 耐用性 |
