# 649 育儿与居家护理

> **UDC 649** — 育儿 · 居家护理 · 待客（Child rearing. Home nursing. Hospitality）。
> 隶属 [[64-家政学|64 家政学]]。

## 类目

家庭内部的**照护与接待**。

## 内容要点

| 方面 | 要点 |
|------|------|
| 婴幼儿照护 | 喂养 · 睡眠 · 如厕训练 · 安全 |
| 家庭教育 | 习惯培养 · 亲子沟通 · 家庭教养 |
| 老人照护 | 起居 · 用药提醒 · 防跌倒 · 陪伴 |
| 病人居家护理 | 基础护理 · 生命体征 · 饮食 · 康复辅助 |
| 待客礼仪 | 接待 · 拜访 · 馈赠与礼节 |
| 家庭健康 | 应急急救 · 家庭药箱 · 卫生习惯 |

## 边界

- **临床医疗 / 护理专业** → [[61-医学|61 医学]]（本类只收**居家**照护）
- **儿童心理发展理论** → 交叉心理学 / 教育学
