# 647 家政服务与人员

> **UDC 647** — 家政服务与人员（Public households. Household staff）。
> 隶属 [[64-家政学|64 家政学]]。

## 类目

**家政外包服务与从业**，含酒店、餐饮、保洁等**商业化家政**。

## 内容要点

| 方面 | 要点 |
|------|------|
| 家庭服务 | 保洁 · 月嫂/育儿嫂 · 养老照护 · 钟点工 |
| 公共家政 | 酒店客房 · 餐饮服务 · 物业保洁 · 洗衣店 |
| 用工 | 雇佣 · 培训 · 合同 · 纠纷 |
| 服务标准 | 服务流程 · 质量标准 · 评价 |
| 安全与诚信 | 背景核实 · 保险 · 隐私 |
