# 古琴 Guqin

中国传统七弦弹拨乐器，约三千年历史，居「琴棋书画」文人四艺之首。2003 年被联合国教科文组织列入「人类口头和非物质文化遗产代表作」名录。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类别 | 弦乐器 · 民族乐器（拨弦） |
| 弦数 | 七弦 |
| 徽位 | 13 个（泛音定位标记） |
| 音色 | 散音（空弦）、按音（按弦）、泛音（泛音）三种 |
| 记谱 | 减字谱 |
| 代表曲 | 《流水》《广陵散》《平沙落雁》《梅花三弄》 |
| 典故 | 「高山流水」知音（伯牙与钟子期） |

## 与「古琵琶」的分流

古琴与琵琶同属中国弹拨乐器，但谱系迥异：古琴是本土士大夫乐器，音色「清微淡远」，重「韵」与意境；琵琶（曲项）经西域传入，偏世俗与叙事。二者分别代表中国弦乐「文人雅乐」与「民间俗乐」两条线索。
