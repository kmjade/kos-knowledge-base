# 02 安装与快速入门

## 系统要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows / Linux / macOS（Apple Silicon M 系列） |
| Python | 3.13 推荐；3.14 可用（部分自定义节点可能有问题）；3.12 稳妥回退 |
| GPU | NVIDIA（CUDA）最佳；AMD（ROCm）/ Intel / Apple Silicon 支持 |
| 浏览器 | Chrome 143+（更低版本有已知渲染问题） |

### 显存建议

| 场景 | 显存建议 |
|------|----------|
| SD 1.5 文生图 | 4–6GB（低显存 `--lowvram` 可下探到 2GB） |
| SDXL | 8GB+ |
| FLUX FP16 | 24GB 舒适 |
| 视频 / 训练 | 32GB+ |

## 安装方式

| 方式 | 适用 | 说明 |
|------|------|------|
| Comfy Desktop | 全平台 | 桌面应用，可管理多个实例，一键安装（入门首选） |
| Portable 便携包 | 仅 Windows | 内嵌 Python（python_embeded），解压即用 |
| 手动安装 | 全平台 / 全 GPU | `git clone` + venv + PyTorch，最灵活 |

### 方式一：Comfy Desktop

从 [Comfy-Org/Comfy-Desktop](https://github.com/Comfy-Org/Comfy-Desktop) Releases 下载安装包，双击安装。自带独立 Python 环境，无需配置系统 Python。

### 方式二：Portable 便携包（Windows）

按 GPU 类型选包，用 7-Zip 解压后双击启动脚本：

| 包 | CUDA / Python | 适用 GPU |
|----|---------------|----------|
| `ComfyUI_windows_portable_nvidia.7z` | CUDA 13.0 / Py3.13 | 现代 NVIDIA（RTX 系列） |
| `ComfyUI_windows_portable_nvidia_cu126.7z` | CUDA 12.6 / Py3.12 | NVIDIA 10 系及更老 |
| `ComfyUI_windows_portable_amd.7z` | ROCm | AMD |
| `ComfyUI_windows_portable_intel.7z` | — | Intel |

下载地址：`https://github.com/Comfy-Org/ComfyUI/releases/latest/download/<包名>.7z`

解压后目录含 `run_nvidia_gpu.bat`（NVIDIA GPU）/ `run_cpu.bat`（纯 CPU），双击即启动。启动时**命令行窗口不能关闭**，否则服务停止。

### 方式三：手动安装

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI

# 建虚拟环境（Windows）
python -m venv venv
source venv/Scripts/activate      # Git Bash；cmd 用 venv\Scripts\activate

# 装 PyTorch（NVIDIA 现代卡，CUDA 13.0）
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
# 10 系及更老 GPU 改用 cu126：https://download.pytorch.org/whl/cu126

# 装其余依赖
pip install -r requirements.txt

# 启动
python main.py
```

浏览器打开 `http://127.0.0.1:8188`。

## 第一次使用

### 启动与界面

启动后浏览器打开 `http://127.0.0.1:8188`，ComfyUI 默认自动加载一套文生图工作流（节点图）。工作流也可通过以下方式加载：

| 方式 | 操作 |
|------|------|
| 默认工作流 | 启动时自动加载 |
| 从图片载入 | 把 ComfyUI 生成的图片（内含工作流元数据）拖入界面，或 `Workflows → Open` 打开图片 |
| 从 JSON 载入 | `Workflows → Export` 导出 / `Workflows → Open` 打开 `.json` |

### 安装模型

ComfyUI **默认不含基础模型**，加载工作流后会提示「模型缺失」。模型统一放在 `<ComfyUI>/models/` 下，按类型分子目录：

| 子目录 | 内容 |
|--------|------|
| `checkpoints/` | 主模型（Checkpoint） |
| `vae/` | VAE |
| `lora/` | LoRA |
| `embeddings/` | 文本嵌入 |
| `upscale_model/` | 放大模型 |

- Portable 版路径：`ComfyUI_windows_portable/ComfyUI/models/`
- Desktop 版：顶部胶囊菜单 → Storage 标签查看 / 打开模型目录

两种安装方式：

1. **自动下载**：点缺失模型提示里的 Download，自动从 Hugging Face 拉取（需网络可达 HF；长时间无进度则改手动）。
2. **手动安装**：下载 [v1-5-pruned-emaonly-fp16.safetensors](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/resolve/main/v1-5-pruned-emaonly-fp16.safetensors)（约 2GB，SD1.5），存到 `models/checkpoints/`，保存后刷新或重启 ComfyUI。

### 首次文生图

1. 模型就位后，按键盘 `R` 刷新节点列表（让「Load Checkpoint」下拉框出现新模型）
2. 在「Load Checkpoint」节点选中刚装的模型
3. 在「CLIP Text Encode」节点填入正向提示词（可选负向提示词）
4. 点 Queue Prompt 生成，图像出现在「Save Image」节点下方

## 常用命令行参数

| 参数 | 用途 |
|------|------|
| `--lowvram` | 低显存模式（显存不足时开启） |
| `--highvram` | 高显存模式（默认，需大显存） |
| `--cpu` | 纯 CPU 运行（无 GPU 兜底，更慢） |
| `--listen` | 允许局域网访问 |
| `--port 8188` | 指定端口 |
