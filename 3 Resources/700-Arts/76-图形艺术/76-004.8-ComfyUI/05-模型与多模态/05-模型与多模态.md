# 05 模型与多模态

## 支持的模型

## FLUX

FLUX（Black Forest Labs）**原生支持**（经自定义节点），ComfyUI 发布数日内即支持。变体：Flux Schnell / Dev / Kontext，FP8 约 12GB。ComfyUI 可在 **12GB 显存**跑 FLUX（A1111 会崩）。

## Z-Image-Turbo

Z-Image-Turbo（阿里通义实验室）—— **6B 蒸馏文生图模型**，CFG 内嵌蒸馏、步数压到 8–9 步，主打亚秒级出图（RTX 4090 上 1024px 约 2.3s）。用法与 SD1.5 相反：

| 参数 | Z-Image-Turbo | SD1.5 对照 |
|------|---------------|------------|
| 采样步数 | 8–9（官方 9） | 25 |
| CFG | 0.0 或 1.0 | 7 |
| 采样器 | euler（或 res_multistep / res_2s） | euler |
| 调度器 | simple（或 sgm_uniform） | — |
| 负向提示词 | **基本无效**（用正向词排除，如 plastic skin / extra fingers） | 需要 |
| 分辨率 | 需能被 16 整除，常用 1024×1024 | 512×512 |

> ⚠️ **显存门槛**：6B 模型 —— 6–8GB 需 GGUF 量化版，12GB+ 可用 BF16。2GB 显卡（如 P600）无法本地运行，需换卡或走云端。
> ⚠️ 步数勿超过 ~14，否则出现「蜡感皮肤 / 斑块」。
