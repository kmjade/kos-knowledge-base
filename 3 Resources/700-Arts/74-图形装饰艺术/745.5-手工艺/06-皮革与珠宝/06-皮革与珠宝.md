# 06 皮革与珠宝

## 皮革（Leathercraft）

| 要点 | 说明 |
|------|------|
| 选皮 | 植鞣革、铬鞣革 |
| 裁切 | 裁皮刀、版型 |
| 打孔缝合 | 斩、针线（马鞍针法） |
| 处理 | 封边、上油 |
| 作品 | 钱包、卡包、皮带、包袋 |

## 珠宝与串珠

| 子类 | 说明 |
|------|------|
| 串珠 | 珠子穿制（手链/项链/编织珠） |
| 金属珠宝 | 银饰制作（锯/锉/焊） |
| 宝石镶嵌 | 爪镶/包镶 |

## 材料与工具

皮料、线、斩、针、裁皮刀；珠子、线、钳、针。
