# 08 商业与办公空间

> 商业与办公空间设计以「品牌 + 体验 + 效率」为核心，与住宅设计的逻辑不同。

## 办公空间

| 类型 | 特点 |
|------|------|
| 传统格子间 | 私密、专注，沟通弱 |
| 开放式办公 | 协作、灵活，噪音大 |
| 混合式（ABW） | 按任务选工位，灵活 |
| 联合办公 | 共享、社群、弹性 |

### 办公设计要点

- 声学处理（吸音板、地毯、电话间）
- 人体工学工位 + 充足任务光
- 协作区与专注区分离
- 绿植与休闲区提升幸福感

## 餐饮空间

| 类型 | 设计要点 |
|------|---------|
| 快餐 | 高效动线、明亮、易清洁 |
| 正餐 | 氛围、灯光（暖色）、私密卡座 |
| 咖啡 | 休闲、社交、绿植、软装 |
| 主题餐厅 | 沉浸式、品牌叙事 |

## 零售空间

| 手法 | 说明 |
|------|------|
| 橱窗 | 吸引进店的第一界面 |
| 动线 | 引导顾客走完动线（宜家式） |
| 陈列 | 焦点、层次、灯光 |
| 体验区 | 试用、互动 |

## 酒店空间

- 大堂：品牌形象、接待、社交
- 客房：舒适、隔音、睡眠体验
- 公区：餐厅、会议、健身、泳池
