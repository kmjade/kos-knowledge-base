# 软装陈设 Soft Decoration

## 定义

软装（Soft Decoration）是空间中「可移动、可更换」的装饰要素，包括布艺、饰品、绿植、灯具与艺术品，赋予空间个性与温度。

## 要素

| 类别 | 内容 |
|------|------|
| 布艺 | 窗帘、地毯、抱枕、床品 |
| 饰品 | 摆件、挂画、花瓶 |
| 绿植 | 盆栽、花艺 |
| 灯具 | 装饰灯、氛围灯 |

## 搭配原则

色彩呼应、材质对比、高低错落、留白、主题统一。
