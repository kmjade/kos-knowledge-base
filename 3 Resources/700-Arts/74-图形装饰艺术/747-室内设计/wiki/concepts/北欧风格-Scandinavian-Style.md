# 北欧风格 Scandinavian Style

## 定义

北欧风格（Scandinavian Style）源自北欧国家的室内设计传统，强调明亮、功能、自然材料与温暖舒适（hygge），是当代最受欢迎的住宅风格之一。

## 特征

| 特征 | 说明 |
|------|------|
| 明亮 | 大面积白墙 + 充足采光 |
| 木材 | 浅色橡木、松木 |
| 功能 | 实用、简洁家具 |
| 温暖 | 织物、绿植、暖光 |
| 自然 | 自然材质与色彩 |
