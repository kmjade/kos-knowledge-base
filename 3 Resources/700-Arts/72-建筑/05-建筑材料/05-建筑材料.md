# 05 建筑材料

## 主要材料

| 材料 | 特点 | 用途 |
|------|------|------|
| 混凝土 | 抗压、可塑 | 结构主体 |
| 钢材 | 抗拉、轻质 | 结构/大跨 |
| 木材 | 可再生、温暖 | 结构/装修 |
| 玻璃 | 透光 | 幕墙/采光 |
| 砖石 | 耐久、厚重 | 砌体/饰面 |

## 选材考量

| 因素 | 说明 |
|------|------|
| 强度 | 结构安全 |
| 耐久 | 使用寿命 |
| 保温隔热 | 节能 |
| 环保 | 绿色建材 |
| 经济 | 成本 |

## 建筑材料研讨（2026-09-28）

> 定位：从**建筑（设计）视角**看材料 —— 材料是「形式的载体」。

- **五材**：混凝土（抗压 / 可塑）· 钢（抗拉 / 大跨）· 木（可再生 / 温暖）· 玻璃（透光 / 脆弱）· 砖石（耐久 / 厚重）。
- **选材五考量**：强度 · 耐久 · 保温隔热 · 环保 · 经济。
- **分工**：材料性能（[[691-建筑材料|691 建筑材料]]）→ 建筑表达（本库）；材料本身即设计语言。
- **2026**：低碳材料 · 工程木（CLT）· 高性能混凝土 · 节能玻璃。
