# 04 建筑结构

## 结构体系

| 体系 | 说明 | 适用 |
|------|------|------|
| 框架结构 | 梁柱承重 | 多层建筑 |
| 剪力墙结构 | 墙体承重抗侧 | 高层住宅 |
| 框架-剪力墙 | 混合 | 高层 |
| 大跨结构 | 桁架/网架/悬索/膜 | 体育场/航站楼 |
| 砌体结构 | 砖石承重 | 低层 |

## 受力概念

| 概念 | 说明 |
|------|------|
| 受压/受拉/受弯 | 基本受力 |
| 荷载 | 恒载/活载/风载/地震 |
| 抗震 | 抗震设防、耗能 |

## 建筑结构研讨（2026-09-28）

> 定位：结构 = 建筑的「骨」；选体系 = 在「跨度 / 高度 / 造价」间取舍。

- **体系**：框架 · 剪力墙 · 框架-剪力墙 · 大跨（桁架 / 网架 / 悬索 / 膜）· 砌体。
- **受力**：压 / 拉 / 弯 · 荷载（恒 / 活 / 风 / 地震）· 抗震（设防 / 耗能）。
- **结构「通用规范」家族**：GB 55002-2021 抗震 · GB 55006-2021 钢结构 · GB 55008-2021 混凝土结构 · GB 55005-2021 木结构 · GB 55003 地基基础。
- **设计规范**：GB 50010 混凝土 · GB/T 50011 抗震 · GB 50017 钢结构 · GB 50003 砌体 · GB 50009 荷载。
- **2026**：装配式 · 高性能材料（UHPC / 高强钢）· 减隔震。
