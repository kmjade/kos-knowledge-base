## 建筑设计研讨（2026-09-28）

> 定位：建筑设计 = 从「需求」到「可施工图纸」的转化；靠**阶段分解 + 图语言 + 模数**。

- **三阶段**：方案设计 → 初步设计 → 施工图设计（《建筑工程设计文件编制深度规定》2016 年版）。
- **图语言**：平面 / 立面 / 剖面 + 节点详图 + 总平面。
- **模数协调**：GB/T 50002-2013（基本模数 M=100mm）—— 工业化 / 装配式的尺寸基础。
- **工具链**：AutoCAD（二维）→ SketchUp / Rhino（建模 / 参数化）→ Revit（BIM）。
- **2026**：**BIM 正向设计** + AI 辅助 · 参数化生成。
