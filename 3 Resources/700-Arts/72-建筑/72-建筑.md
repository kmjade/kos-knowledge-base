# 72 建筑 Architecture

> 建筑学（Architecture，UDC 72）是研究建筑的设计、结构、材料、历史、理论与技术的学科。本知识库是 700-Arts 下的**建筑大类总览**，覆盖建筑设计、历史风格、结构、材料、技术、理论、类型与规范。数据更新至 2026-09。
