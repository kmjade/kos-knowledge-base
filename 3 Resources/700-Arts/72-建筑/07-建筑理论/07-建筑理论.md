# 07 建筑理论

## 核心概念

| 概念 | 说明 |
|------|------|
| 空间 | 建筑的本质是空间 |
| 形式 | 造型与构成 |
| 功能 | 形式服从功能（现代主义） |
| 文脉 | 与环境的对话 |

## 理论流派

| 流派 | 主张 |
|------|------|
| 功能主义 | 形式服从功能 |
| 有机建筑 | 与环境融合（赖特） |
| 极少主义 | 少即是多（密斯） |
| 后现代 | 反纯粹、装饰 |

## 建筑理论研讨（2026-09-28）

> 定位：理论 = 回答「建筑为什么这样」。

- **四组母题**：空间（本质）· 形式（构成）· 功能（形式服从功能）· 文脉（与环境对话）。
- **两条线索**：形式主义（比例 / 构图 / 类型）vs 功能主义（形式追随功能）；现代 → 后现代 → 解构 → 数字。
- **三要素回响**：坚固 ↔ 构造真实 · 实用 ↔ 功能 · 美观 ↔ 形式。
- **当代问题**：场所精神 · 建筑现象学 · 可持续伦理。
