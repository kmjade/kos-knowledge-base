| 构造 | 说明 |
|------|------|
| 墙体 | 承重/围护 |
| 屋面 | 防水/保温 |
| 门窗 | 采光/通风 |
| 楼地面 | 结构/面层 |

## 绿色建筑

| 策略 | 说明 |
|------|------|
| 被动式设计 | 朝向/遮阳/自然通风 |
| 节能 | 保温/高效设备 |
| 可再生能源 | 光伏/地源热泵 |
| 评价 | LEED / 绿建标准 |

## BIM

BIM（建筑信息模型）是建筑的**数字化信息载体**，Revit 等软件实现设计-施工-运维一体化。

## 建筑技术研讨（2026-09-28）

> 定位：**构造 + 绿色 + BIM** = 建筑「落地」的技术面。

- **构造**：墙 / 屋面 / 门窗 / 楼地面（与 [[692-建筑构件|692 建筑构件]] 交接）。
- **绿色建筑**：被动式 → 节能 → 可再生能源 → 评价（**GB/T 50378-2019（2024 年版）** 绿色建筑评价 · **GB/T 51350-2019** 近零能耗）。
- **BIM**：数字化信息载体，设计-施工-运维一体化。
- **2026**：**近零 / 零碳建筑** · **BIM 正向设计** · **数字孪生 / CIM** · 智慧建造。
