## 建筑历史与风格研讨（2026-09-28）

> 定位：建筑史 = 「结构能力 × 审美观念」的演化史。

- **西方谱系**：古典（柱式）→ 哥特（尖拱 / 飞扶壁）→ 文艺复兴（比例 / 穹顶）→ 巴洛克 → 现代主义（柯布西耶 / 密斯 / 赖特）→ 后现代 → 当代（参数化 / 绿色）。
- **两条暗线**：**材料 / 结构突破**（石拱 → 钢筋混凝土 → 钢 → 工程木）· **观念变迁**（神性 → 人文 → 机器时代 → 生态）。
- **中国线**：木构架（抬梁 / 穿斗）· 屋顶等级（庑殿 / 歇山 / 悬山 / 硬山）· 斗拱 · 院落（四合院）—— 详见 [[694-木结构与木作|694 木结构与木作]]。
