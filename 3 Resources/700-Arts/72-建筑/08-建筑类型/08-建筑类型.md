# 08 建筑类型

## 主要类型

| 类型 | 说明 | 例子 |
|------|------|------|
| 住宅 | 居住 | 公寓、别墅 |
| 公共建筑 | 教育/医疗/文化 | 学校、医院、图书馆 |
| 商业建筑 | 办公/商业 | 写字楼、商场 |
| 文化建筑 | 文化/观演 | 博物馆、剧院 |
| 交通建筑 | 交通枢纽 | 航站楼、车站 |
| 体育建筑 | 运动场馆 | 体育场、体育馆 |

## 设计要点

不同类型有不同的流线、功能、规范要求。

## 建筑类型研讨（2026-09-28）

> 定位：类型 = **用途对空间的组织约束**。

- **分类**：住宅 · 公共（教育 / 医疗 / 文化）· 商业 · 文化（观演）· 交通 · 体育。
- **类型学**：功能决定空间骨架（住宅的「套型」· 剧院的「观众厅—舞台」· 航站楼的「流程线」）。
- **规范**：住宅设计规范 **GB 50096-2011** · 建筑设计防火（GB 50016 + GB 55037）· GB 50352。
- **2026**：民生建筑（医养 / 教育）· **城市更新存量改造** · 平急两用。
