# 08 制片与产业

## 制片流程

| 阶段 | 内容 |
|------|------|
| 开发 | 剧本、融资、项目立项 |
| 前期制作 | 选角、勘景、分镜、搭建团队 |
| 拍摄 | 实拍阶段，最密集的资金与人力投入 |
| 后期制作 | 剪辑、声音、调色、特效 |
| 发行放映 | 院线、流媒体、衍生品 |

## 好莱坞制片厂制度

- **黄金时代**（1930s–40s）：垂直整合（制作—发行—放映），类型片与明星制
- **「五大」**：米高梅、派拉蒙、华纳、福克斯、雷电华
- **1948 派拉蒙判决**：强制剥离放映环节，终结垂直垄断，独立制片兴起

## 独立电影 vs 制片厂

| 维度 | 制片厂 | 独立电影 |
|------|--------|----------|
| 资本 | 高预算、大发行 | 低预算、艺术导向 |
| 创作 | 市场导向 | 作者导向 |
| 代表 | 漫威、迪士尼 | 圣丹斯电影节出品 |

## 全球产业格局

- **好莱坞**：全球票房主导
- **宝莱坞**（印度孟买）：产量巨大
- **华语电影**：第五代/第六代导演，合拍片
- **流媒体**：Netflix、Disney+ 等改变发行与观影方式
