# 蒙太奇 Montage

## 定义

蒙太奇（Montage，法文「装配」）指通过**镜头的并置**产生新意义的剪辑观念：两个镜头相接，其含义大于单个镜头之和。库里肖夫实验证明同一张面无表情的脸与不同画面并置，会让观众读出不同情绪。

## 关键要点

| 要点 | 说明 |
|------|------|
| 吸引力蒙太奇 | 爱森斯坦提出——用镜头「碰撞」冲击观众，产生思想 |
| 主要类型 | 节奏蒙太奇、平行蒙太奇、隐喻蒙太奇、理性蒙太奇 |
| 代表作 | 爱森斯坦《战舰波将金号》「敖德萨阶梯」 |
