# 好莱坞 Hollywood

位于美国洛杉矶的电影产业中心，**全球电影工业的主导力量**——以制片厂制度、类型片与明星制为核心，从 20 世纪初延续至今。

| 地点 | 美国洛杉矶 |
| 黄金时代 | 1930s–40s（五大制片厂） |
| 标志 | 好莱坞标志、奥斯卡 |

## 关键节点

- **制片厂制度**：垂直整合（制作—发行—放映）
- **1948 派拉蒙判决**：剥离放映，终结垄断，独立电影兴起
- **当代**：六大制片厂 + 流媒体平台重塑格局
