# 02 电子游戏史

> **定位** —— `794:004` 计算机游戏子库「媒介线」第 2 章：以**平台世代**为主轴的电子游戏通史。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]] · 知识地图：[[794-004-计算机游戏/00-MOCs/计算机游戏知识地图|计算机游戏知识地图]]

## 一、分期总表

| 期 | 年代 | 载体 | 标志性节点 | 文化意义 |
|:--|:--|:--|:--|:--|
| **史前** | 1950s–1960s | 大型机 / 示波器 | `OXO` · `Tennis for Two` · `Spacewar!` | 实验室里的可玩性实验 |
| **街机期** | 1970s–1980s | 街机机台 | `Pong` · `Space Invaders` · `Pac-Man` · `Donkey Kong` | 街机厅 = 公共娱乐空间；日本厂商崛起 |
| **主机期** | 1980s–1990s | 家用主机 | FC/红白机 · `Super Mario Bros.` · Sega Mega Drive · 平台战争 | 客厅娱乐；「电子游戏」成为家庭日常 |
| **PC 与在线期** | 1990s–2000s | PC / 互联网 | 局域网 FPS · MMO（`魔兽世界`）· Mod · Steam 数字发行 | 玩家成为创作者与社群 |
| **移动期** | 2010s | 智能手机 | App Store / Google Play · F2P 内购 · 全民化 | 玩家基数数量级扩张 |
| **云与服务期** | 2020s– | 云 / 订阅 / 跨平台 | 订阅制 · 赛季运营 · UGC 平台 · 跨端存档 | 游戏成为**持续服务** |

## 二、三条主线

1. **平台主线** —— 街机 → 主机 → PC → 移动 → 云：每次载体迁移都重塑用户、商业模式与文化。
2. **技术主线** —— 位图 → 精灵 → 2D 引擎 → 3D 硬件加速 → 网络化 → 大规模实时服务。
3. **商业主线** —— 按次投币 → 买断 → 数字发行 → F2P/内购 → 订阅/通行证。

## 三、关键课题

| 课题 | 说明 |
|:--|:--|
| **平台战争** | 世代更替中硬件、独占与生态的竞争（任天堂 / 世嘉 / 索尼 / 微软） |
| **数字发行** | Steam 等平台商店重构发行与长尾；独立游戏受益 |
| **在线化** | 从局域网到 MMO 到服务型游戏，「单机」边界模糊 |
| **保存（preservation）** | 载体失效、在线服务关停 → 游戏史保存成为学科议题 |
| **地方史** | 各区域（日 / 美 / 欧 / 中 / 韩）路径不同，勿以单一路径概全 |
