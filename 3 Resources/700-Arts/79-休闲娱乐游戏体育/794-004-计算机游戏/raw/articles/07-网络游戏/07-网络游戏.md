# 07 网络游戏

> **定位** —— `794:004` 计算机游戏子库「生态线」第 7 章：**联网 / 在线运行**的游戏形态与运营。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、形态谱系

| 形态 | 特征 | 代表 |
|:--|:--|:--|
| **局域网 / 联机** | 小规模 · 会话制 | 早期 FPS · 联机对战 |
| **MMO** | 持久世界 · 大规模同屏 | [[794-魔兽世界\|魔兽世界]] 型 |
| **在线竞技** | 短局 · 排位 | MOBA · 战术射击 |
| **手游在线** | 触屏 · 强运营 | 竞技 / 卡牌 / 休闲 |
| **服务型（GaaS）** | 持续更新 · 赛季 | 跨形态通称 |

## 二、技术结构（概念层）

| 维度 | 说明 |
|:--|:--|
| **客户端 / 服务器** | 权威服务器防作弊；客户端预测与回滚改善手感 |
| **同步模型** | 状态同步 vs 帧同步；延迟与抖动补偿 |
| **分线与实例** | 分线 / 副本缓解同屏压力 |
| **持久化** | 账号 · 角色 · 经济数据的一致性 |
| **反作弊与安全** | 客户端完整性 · 行为检测 · 交易风控 |

## 三、运营（LiveOps）

- **节奏**：日常 / 周常任务 · 版本更新 · 赛季重置 · 节日活动。
- **社区**：公告 · 论坛 / 社群 · 客服与举报。
- **经济**：货币分层（可交易 / 绑定）· 通胀控制 · 掉落与概率公示。
- **生命周期**：拉新 → 留存 → 变现 → 守成 / 关停（含**停服与数据保存**议题）。
