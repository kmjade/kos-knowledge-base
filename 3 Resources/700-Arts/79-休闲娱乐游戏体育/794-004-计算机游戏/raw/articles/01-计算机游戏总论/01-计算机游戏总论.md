# 01 计算机游戏总论

> **定位** —— `794:004` 计算机游戏子库的**总论 / 导读**章：界定范围 · 分期 · 门类谱系 · 与邻接类边界。

## 一、定义与范围

**计算机游戏（Computer Games / 电子游戏）** —— 以**计算设备**为运行载体、以**交互**为核心的娱乐产品：玩家通过输入设备与运行时系统（图形 / 物理 / 网络）持续交互，在规则约束下获得目标、挑战与体验。

| 维度 | 覆盖 |
|:--|:--|
| **载体** | 街机 · 主机（console）· 个人电脑 · 掌机 · 手机 · 网页 · 云 |
| **形态** | 单机 · 局域网 · 在线／网游 · 手游 · 云游戏 · 电竞 |
| **视角** | 媒介史 · 平台与硬件 · 类型 · 产业 · 文化 |
| **不覆盖** | **设计方法**（玩法 / 系统 / 关卡 / 叙事 / 数值）→ 深号 **`794.8` 游戏设计**；**引擎与实时渲染** → **`794.8-Unreal-Engine`**；**实体桌游**（象棋 / 棋牌 / 拼图）→ 上位 **`794`** |

> **本库记「媒介 / 平台 / 产业 / 文化」，设计库记「设计方法」** —— 二者互补、不重叠（见 [[794.8-游戏设计|794.8 游戏设计]]）。

## 二、分期（简）

| 期 | 年代 | 标志 |
|:--|:--|:--|
| **史前** | 1950s–1960s | 实验室演示（`Tennis for Two` · `Spacewar!`）· 大学大型机 |
| **街机期** | 1970s–1980s | `Pong` · `Space Invaders` · `Pac-Man`；街机厅成为公共空间 |
| **主机期** | 1980s–1990s | 红白机 / FC · Sega · **平台战争**；家用客厅为战场 |
| **PC 与在线期** | 1990s–2000s | 局域网 → 互联网 · MMO（`魔兽世界`）· Mod 文化 · 数字发行（Steam） |
| **移动期** | 2010s | 智能机普及 · F2P / 内购 · 全民化 |
| **云与服务期** | 2020s– | 云游戏 · 订阅制 · 赛季运营 · 跨平台 · UGC 平台 |

> 分期是**视角**而非硬边界：各期在平台、商业模式与文化上叠加共存。

## 三、门类谱系

| 轴 | 分类 |
|:--|:--|
| **按平台** | 街机 · 主机 · PC · 掌机 · 移动 · 云 |
| **按人数／拓扑** | 单人 · 本地多人 · 联网 · 大规模在线（MMO） |
| **按类型（genre）** | 动作 · 射击（FPS/TPS）· 角色扮演（RPG/ARPG）· 策略（RTS/回合）· 模拟 · 体育竞速 · 沙盒 · Roguelike · 休闲 |
| **按商业模式** | 买断（premium）· 免费＋内购（F2P）· 订阅 · 赛季 / 战斗通行证 · 广告 |
| **按生产方** | 3A 大厂 · 中型 · **独立游戏** · UGC 平台 |

## 四、产业与文化（概览）

- **产业** —— 发行与平台商店（Steam / PlayStation / Xbox / Switch / 移动商店）· 平台抽成 · 主机授权 · 电竞生态 · 直播与创作者经济。
- **文化** —— 玩家社群 · **模组（Mod）** · 速通（speedrun）· 游戏批评与「游戏是否艺术」之辩 · 地方化与审查。
- **平台战争** —— 硬件世代、独占内容与生态锁定，是理解主机史的主线之一。
