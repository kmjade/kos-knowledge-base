# 05 电子竞技

> **定位** —— `794:004` 计算机游戏子库「生态线」第 5 章：**电子竞技**（以电子游戏为载体的组织化竞技）。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、定义与门槛

电子竞技 = **规则明确的对抗性** + **观众规模** + **组织化赛制**（联赛 / 杯赛 / 巡回）。常见门槛：稳定的竞技规则、平衡性维护、反作弊与裁判体系、可观赏性。

## 二、主要项目族

| 类型 | 代表项目族 | 赛制特征 |
|:--|:--|:--|
| **MOBA** | `Dota 2` · `英雄联盟` | 常规赛 + 世界赛 · 战队联赛 |
| **FPS / 战术射击** | `CS` 系列 · 战术竞技 | 地图制 · 回合制赛制 |
| **RTS** | 星际 / 魔兽争霸系（历史） | 1v1 · 天梯 + 杯赛 |
| **格斗** | 街霸 / 铁拳系 | 双败淘汰 · EVO 型赛事 |
| **体育 / 竞速** | FIFA / 赛车系 | 仿真体育联赛化 |
| **卡牌 / 自走棋** | 数字卡牌 | 赛季 + 天梯 |

## 三、生态结构

| 角色 | 职能 |
|:--|:--|
| **项目方 / 发行商** | 定规则、办赛、控生态（赛事授权） |
| **赛事方 / 联赛** | 组织赛程、转播与招商 |
| **俱乐部 / 战队** | 选手签约、训练、青训 |
| **选手 / 教练 / 分析师** | 竞技与战术 |
| **主播 / 内容创作者** | 观赛入口与社区扩散 |
| **观众 / 赞助商 / 平台** | 收入与传播 |

## 四、职业化与商业模式

- **收入**：赞助 · 转播权 · 门票 · 周边 · 游戏内分成 · 联盟席位。
- **职业化要素**：合同与转会 · 青训体系 · 住宿与体能管理 · 退役路径。
- **区域差异**：韩国早期制度化 · 中国联赛化 · 欧美俱乐部化 · 地区政策影响巨大。

## 五、争议与治理

| 议题 | 说明 |
|:--|:--|
| **公平性** | 外挂 · 假赛 · 消极比赛 · 裁判与录像回看 |
| **健康与劳动** | 训练时长 · 职业寿命 · 心理与伤病 |
| **合规** | 未成年人保护 · 赛事博彩边界 · 授权纠纷 |
| **可持续** | 泡沫化风险 · 项目生命周期短 |
