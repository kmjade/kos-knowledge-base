# 06 游戏产业

> **定位** —— `794:004` 计算机游戏子库「生态线」第 6 章：游戏的**生产 / 发行 / 平台 / 变现**结构。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、产业链

| 环节 | 职能 | 关键角色 |
|:--|:--|:--|
| **开发** | 制作游戏 | 第一方工作室 · 第三方开发商 · 独立团队 |
| **发行** | 资金 · 市场 · 渠道 | 发行商 · 自发行 |
| **平台 / 商店** | 分发与抽成 | 主机商店 · PC 商店（Steam / Epic …）· 移动商店 |
| **渠道 / 订阅** | 触达用户 | 主机订阅 · 云服务 · 捆绑包 |
| **运营** | 持续服务 | LiveOps · 社区 · 客服 |
| **周边 / 衍生** | 授权与扩展 | 影视改编 · 玩具 · 电竞赛事 |

## 二、商业模式

| 模式 | 收入结构 | 典型场景 |
|:--|:--|:--|
| **买断（premium）** | 一次性购买 | 单机大作 · 独立游戏 |
| **免费 + 内购（F2P）** | 道具 / 抽卡 / 外观 | 手游 · 服务型网游 |
| **订阅** | 月/年费内容库 | 平台订阅 · 云游戏 |
| **赛季 / 通行证** | 周期付费 + 活跃 | 竞技 / 服务型 |
| **广告** | 展示 / 激励视频 | 休闲手游 |
| **混合** | 买断 + 内购 / DLC | 3A 长线运营 |

## 三、平台商店与抽成

- **主机商店**：认证 + 平台抽成 + 独占谈判。
- **PC 商店竞争**：抽成比例、独占窗口、区域定价成为竞争点。
- **移动商店**：抽成与政策（支付通道）争议长期存在。

## 四、平台战争与独占

- **世代更替**带动硬件销量与内容军备；**独占 / 限时独占**是核心武器。
- **第一方工作室**并购成为内容壁垒策略。
- **跨平台**在服务型游戏时代逐渐成为常态。

## 五、结构性问题

| 议题 | 说明 |
|:--|:--|
| **成本与风险** | 3A 成本上升 → 续作化 / 保守化 |
| **劳工** | crunch · 外包 · 裁员周期 |
| **地区格局** | 研发与发行的区域分工与政策（版号 / 分级） |
| **可持续性** | 抽卡与未成年人保护 · 消费争议 |
