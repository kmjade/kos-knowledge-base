# 09 游戏文化

> **定位** —— `794:004` 计算机游戏子库「生态线」第 9 章：围绕游戏的**社群 · 创作 · 批评与治理**。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、玩家社群

| 形态 | 说明 |
|:--|:--|
| **公会 / 战队** | 组织化协作与竞技（与电竞生态衔接，见 05） |
| **论坛 / 社群平台** | 攻略 · 二创 · 争议与治理 |
| **直播 / 视频** | 观赛与「云玩家」；创作者经济 |
| **线下** | 展会 · 展赛（con）· 街机厅 / 桌游吧 |

## 二、创作与 UGC

- **Mod（模组）** —— 玩家改造与扩展：从早期关卡编辑器到大型转换模组，常成为续作的灵感源。
- **二创** —— 同人图 / 文 / 视频；版权与合理使用边界。
- **UGC 平台** —— 游戏内创作 + 分成，模糊「玩家 / 创作者」边界。
- **速通（speedrun）** —— 以极限效率为目标；社区规则与验证体系是其核心。

## 三、批评与讨论

| 议题 | 说明 |
|:--|:--|
| **「游戏是否艺术」** | 从媒介特性（交互 / 规则 / 玩家能动性）展开的长期论辩 |
| **游戏研究（game studies）** | 叙事学 vs 游戏学（ludology）等路径 |
| **内容批评** | 评测 · 评论 · 创作者伦理与「评分/曝光」争议 |
| **保存与档案** | 载体失效与在线关停 → 游戏史保存（呼应 02） |

## 四、治理与文化边界

- **分级与审查** —— 各区域制度差异；本地化与内容调整。
- **社群治理** —— 反骚扰 · 反作弊 · 平台社区准则。
- **健康议题** —— 沉迷 · 消费 · 未成年人保护（呼应 06/07）。
