# 08 独立游戏

> **定位** —— `794:004` 计算机游戏子库「生态线」第 8 章：**独立（indie）游戏**的生产与生态。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、定义与边界

- **广义**：不依赖（或不完全依赖）大发行资金、由小团队主导创作的游戏。
- **判据不在预算而在**：创作自主权 · 资金来源 · 发行方式 · 团队规模。
- **与「大厂」并非二元**：存在大量中间形态（独立发行标签 · 平台扶持 · 联合开发）。

## 二、生产条件

| 要素 | 说明 |
|:--|:--|
| **引擎与工具** | 通用引擎与低门槛工具链大幅降低制作门槛 |
| **资产来源** | 外包 · 素材商店 · 开源资产 · 程序化生成 |
| **团队** | 1–10 人常见；分工弹性（一人多角） |
| **资金** | 自筹 · 众筹 · 平台预付款 · 补贴 / 基金 · 孵化器 |

## 三、发行与变现

| 渠道 | 特点 |
|:--|:--|
| **PC 商店**（如 Steam） | 长尾与发现机制；竞争激烈 |
| **独立平台**（如 itch.io） | 低门槛 · 可实验 / 原型 |
| **主机 / 移动** | 需认证 · 曝光依赖平台推荐 |
| **捆绑 / 展会** | 曝光与社区积累（游戏节 · Demo） |
| **变现** | 买断为主；亦有 DLC / 抢先体验 / 订阅收录 |

## 四、生存法则（经验性）

- **垂直切口 + 强记忆点**：小团队以机制 / 美术 / 题材差异取胜。
- **可玩原型优先**：Demo 与展会试玩是发现与传播的关键。
- **社区共研**：开发日志 · 抢先体验 · 玩家反馈闭环。
- **风险管理**：范围控制（scope）胜过野心。

## 五、影响

- **玩法创新试验场**：Roguelite、解谜叙事、实验交互多自独立圈扩散至主流。
- **Mod → 独立**：从模组社区走向独立创作的路径常见。
- **文化多样性**：地方题材与个人表达的重要出口。
