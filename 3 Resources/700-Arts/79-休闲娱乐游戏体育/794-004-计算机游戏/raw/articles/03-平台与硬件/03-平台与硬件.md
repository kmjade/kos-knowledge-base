# 03 平台与硬件

> **定位** —— `794:004` 计算机游戏子库「媒介线」第 3 章：**运行载体**（平台形态）与**硬件构成**。
> 隶属 [[794-004-计算机游戏|794:004 计算机游戏]]

## 一、平台形态

| 平台 | 特征 | 典型输入 | 商业模式倾向 |
|:--|:--|:--|:--|
| **街机** | 专用机台 · 公共场所 | 摇杆 + 按键 · 光枪 · 体感 | 按次投币 |
| **主机**（console） | 客厅 · 世代更替 · 独占内容 | 手柄 | 买断 + 平台抽成 |
| **掌机** | 便携 · 续航优先 | 内置按键 / 触摸 | 买断 |
| **个人电脑** | 开放平台 · 可自定硬件 | 键鼠 · 手柄 | 多商店并存 |
| **移动** | 智能机 / 平板 · 触屏 | 触摸 · 陀螺仪 | F2P + 内购 + 广告 |
| **云** | 渲染在服务器 · 终端仅解码 | 手柄 / 触摸 | 订阅 / 时长 |

## 二、硬件构成

| 部件 | 作用 | 演进要点 |
|:--|:--|:--|
| **处理器** | 逻辑 / 物理 / AI | 从单核到多核异构 |
| **图形处理器** | 渲染与并行计算 | 固定管线 → 可编程着色器 → 光追 / 超分 |
| **内存** | 资产与状态驻留 | 容量与带宽决定同屏复杂度 |
| **存储** | 载入与流式 | 卡带 → 光盘 → 硬盘 / 闪存 · 流式加载 |
| **输入** | 交互通道 | 手柄 · 键鼠 · 触屏 · 体感 · 无障碍设备 |
| **输出** | 视听呈现 | 分辨率 / 帧率 / 刷新率 / HDR / 环绕声 |

## 三、平台策略

- **独占与窗口期** —— 独占内容 / 限时独占是平台战争的常规手段。
- **授权与认证** —— 主机平台对发行有认证与抽成（开发者须遵守平台规约）。
- **向下兼容** —— 世代过渡期的用户留存策略。
- **跨平台与跨端存档** —— 服务型游戏的标准期望。
