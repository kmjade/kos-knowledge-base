# 04 类型与形式

> **定位** —— `794:004` 计算机游戏子库「媒介线」第 4 章：**类型（genre）谱系**与描述维度。
> ⚠️ 本章记**媒介/形式**分类；**设计方法**（玩法 · 系统 · 关卡 · 叙事 · 数值）归 [[794.8-游戏设计|794.8 游戏设计]]。

## 一、主要类型

| 类型 | 核心交互 | 亚类 / 代表 |
|:--|:--|:--|
| **动作** | 时机 · 反应 | 平台跳跃 · 格斗 · 砍杀 |
| **射击** | 瞄准 · 定位 | FPS · TPS · 弹幕 · 大逃杀 |
| **角色扮演（RPG）** | 成长 · 叙事 | 日式 JRPG · 欧美 WRPG · **ARPG** |
| **策略** | 决策 · 资源 | RTS · 回合制 · 战棋 · 大战略 |
| **模拟** | 系统建模 | 经营 · 建造 · 飞行 / 驾驶 · 生活模拟 |
| **体育与竞速** | 规则化对抗 | 足球 / 篮球 · 赛车 |
| **沙盒 / 开放世界** | 自由探索 | 生存建造 · 开放世界冒险 |
| **Roguelike** | 随机 + 永久死亡 | 传统 RL · Roguelite |
| **休闲 / 益智** | 低门槛 | 三消 · 解谜 · 音乐节奏 |
| **多人竞技（MOBA）** | 团队对抗 | 分路 · 英雄 · 排位 |

## 二、描述维度（正交于类型）

| 维度 | 取值 |
|:--|:--|
| **视角** | 第一人称 / 第三人称 / 俯视 / 侧视 / 上帝视角 |
| **时间** | 实时 / 回合 / 可暂停实时 |
| **人数与拓扑** | 单人 / 本地多人 / 联机 / 大规模在线 |
| **进程结构** | 线性关卡 / 开放世界 / 无限循环 / 赛季 |
| **胜负结构** | 通关 / 对抗 / 无尽 / 沙盒无终点 |

## 三、混合与演化

- **类型融合**是常态（如 RPG × 射击 = `ARPG`/刷宝射击；模拟 × 生存 = 生存建造）。
- **Roguelite** 以局外成长降低传统 Roguelike 的挫败，成为独立游戏主力形态之一。
- **服务型转型**：同一类型可因运营模式（赛季 / 通行证）改变体验节奏。
