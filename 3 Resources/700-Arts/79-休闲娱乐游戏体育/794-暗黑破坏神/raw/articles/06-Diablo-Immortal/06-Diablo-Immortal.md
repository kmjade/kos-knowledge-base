# Diablo Immortal — 暗黑破坏神：不朽

> 2022 年 6 月 2 日发售，与网易 (NetEase) 联合开发的大型多人手游。继承经典暗黑元素，引入阵营 PvP 与大规模多人内容。

## 一、核心信息

|    项目    | 内容 |
| :------: | ---- |
|  开发商 | Blizzard × NetEase |
|  平台 | iOS · Android · PC (Beta) |
|  时序 | D2 与 D3 之间 |
|  职业数 | 8 |
| 阵营 | 不朽者 (Immortals) vs 暗影会 (Shadows) |
|  PvE  | 地城副本、上古秘境、地狱骨匣 |
|  PvP  | 宝库守卫、斗争循环、战场 |

## 三、阵营 PvP 循环

```
  暗影会 (Shadows)                   不朽者 (Immortals)
       │                                  │
  完成契约任务  ────→  暗影等级提升  ────→  挑战不朽者
       │                                  │
  阵营战 (斗争循环) ←──→ 宝库防御           宝库守卫
```

## 四、货币化争议

| 机制 | 描述 | 争议点 |
|------|------|--------|
| 传奇宝石 | 核心装备强化，需重复抽取升级 | P2W (付费取胜) |
| 战斗通行证 | 赛季付费轨道 | 可接受 |
| 拍卖行 | 玩家间交易系统 | 价格混乱 |
| 上古秘境 | 宝石获取地城 | 付费加速 |

> 传奇宝石的满级成本推估超 10 万美元，引发「Do YoU gUyS nOt HaVe PhOnEs?」事件。
