# Diablo I — 崔斯特瑞姆的黑暗 (The Darkening of Tristram)

> 1996 年 12 月 31 日发售，开创了现代 ARPG 类型的奠基之作。崔斯特瑞姆小镇被魔王迪亚布罗的恐惧吞噬，玩家深入大教堂底下的十六层迷宫。

## 一、核心信息

|    项目    | 内容 |
| :------: | ---- |
|  开发商 | Blizzard North |
|   平台   | PC (Windows 95) |
|  地城层数 | 16 层 (教堂 1-4 → 地下墓穴 5-8 → 洞穴 9-12 → 地狱 13-16) |
|  可选职业 | 战士 (Warrior)、游侠 (Rogue)、魔法师 (Sorcerer) |
|  扩展包 | Hellfire (1997, Synergistic Software) |
|  最大玩家数 | 4 (Battle.net) |

## 二、三大原初职业

| 职业 | 英文 | 主属性 | 特点 |
|:---:|------|:-----:|------|
| 战士 | Warrior | 力量 | 近战耐久、修复装备 |
| 游侠 | Rogue | 敏捷 | 远程弓箭、发现陷阱 |
| 魔法师 | Sorcerer | 魔力 | 法术 (火球/闪电/石化) |

## 三、地城层级

```
教 堂 (1-4)  →  地下墓穴 (5-8)  →  洞 穴 (9-12)  →  地 狱 (13-16)
  ↓               ↓                ↓                  ↓
 骷髅·堕落者    山羊人·蝙蝠      石像鬼·法师         地狱骑士·迪亚布罗
```

## 四、标志性首领

|    首领    | 英文 | 层数 |        特点        |
| :-----: | :---: | :-: | :--------------: |
|  屠夫 | The Butcher |  2  | 「Fresh meat!」 |
|  骷髅王 | King Leoric |  3  | 崔斯特瑞姆的前国王 |
| 大主教拉萨雷斯 | Archbishop Lazarus | 15  | 叛徒，召唤迪亚布罗 |
| 迪亚布罗 | Diablo | 16  | 恐惧之王，终极首领 |

## 五、核心系统

|   系统   |        描述        |
| :---: | :--------------: |
| 随机地城 | 每次新游戏重新生成全部楼层 |
| 神殿 | 临时增益/诅咒（隐藏效果） |
| 法术书 | 任何职业可学，魔法书消耗品 |
| 物品耐久 | 装备有耐久度，需修理 |
| 死亡机制 | 掉装捡尸体 |

> Diablo I 确立了「点击移动 + 刷怪掉宝」的核心循环，为后续所有 Diablo-like 游戏的模板。
