# 赛季 (Season)

## 定义

Diablo III 首创的 **PC ARPG 赛季重置**机制：周期性开启新赛季，玩家从零开始、共享独特**赛季主题**与奖励，赛季结束角色并入非赛季。D4 沿用（每 3 个月一季，含赛季通行证）。

## 关键要点

| 要素 | 说明 |
|------|------|
| 赛季旅程 | 章节式任务，奖励套装 / 宠物 / 头像框 |
| 海德格礼物 | 完成旅程赠送**完整职业套装** |
| 赛季主题 | 每季独特机制（如 S27「圣光呼唤」天使坩埚与圣化；S40 为其重跑） |
| 排行榜 | 大秘境职业 / 团队排名 |

- 当前（2026-10）：**第 40 赛季「圣光呼唤」**，2026-10-02 开启；核心机制**天使坩埚 (Angelic Crucibles)**。
