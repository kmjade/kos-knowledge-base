# 卡奈魔方 (Kanai's Cube)

## 定义

Diablo III 的核心**装备加工工具**：可**萃取**传奇能力（不占用装备位）、重铸装备、转换材料等，是流派配装的关键一环。

## 关键要点

| 功能 | 说明 |
|------|------|
| 萃取能力 | 将传奇特效「装入」魔方（武器 / 护甲 / 首饰各一） |
| 重铸 | 同名装备重掷（含远古 / 太古） |
| 材料转换 | 类型 / 品质转换 |
| 赛季红利 | 部分赛季开第四栏位（如 S39 借此多装一件） |
