# 装备与词缀 (Items & Affixes)

## 定义

暗黑系列**装备驱动**的核心：装备按**品质层级**划分，属性由**词缀（affix）**随机组合决定，传奇 / 套装提供改变玩法的特效。

## 关键要点

| 要素 | 说明 |
|------|------|
| 品质 | 普通 → 魔法（蓝）→ 稀有（黄）→ 传奇（橙）→ 套装（绿）；D3 另有远古 / 太古 |
| 词缀 | 主属性 · 暴击 · 攻速 · 冷却缩减 · 范围伤害 … |
| 传奇特效 | 改变技能机制（流派基石） |
| 加工 | 附魔（重掷一词缀）· 重铸 · D3 [[卡奈魔方-Kanai-Cube\|卡奈魔方]] |
| D4 | 世界阶级决定掉落；无 MF 词缀 |
