# 刷宝核心循环 (Loot Loop)

## 定义

Diablo 系列（及「暗黑类」ARPG）的**核心循环**：**击杀怪物 → 掉落装备 → 变强 → 挑战更高难度 → 更优掉落**。由 Diablo I 确立，是 ARPG 的普适模板。

## 关键要点

| 环节 | 说明 |
|------|------|
| 刷怪 | 随机地城 / 秘境，精英密集 |
| 掉落 | 词缀系统 · 品质层级 · 传奇 / 套装 |
| 变强 | 换装 · 技能符文 · 巅峰等级 |
| 进阶 | 难度阶梯（折磨 → 大秘境层级） |
| 效率 | 每次循环比上次更快 / 更难 / 更多收获 |
