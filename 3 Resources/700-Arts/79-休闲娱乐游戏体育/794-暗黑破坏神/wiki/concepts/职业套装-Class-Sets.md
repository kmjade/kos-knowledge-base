# 职业套装 (Class Sets)

## 定义

暗黑系列的高阶装备集合：**同一套装凑齐 N 件**即激活**阶梯式件效**（(2)/(4)/(6) 件），是 D3 流派的核心骨架。

## 关键要点

| 要素 | 说明 |
|------|------|
| 件效 | (2)/(4)/(6) 件递增，驱动专属玩法 |
| 来源 | 掉落 / **海德格礼物**（赛季旅程赠送整套） |
| 代表 | 恐惧之地机铠 · 九十蛮夷 · 英勇圣御 · 正义楷模 · 蒙杜奴古战装 · 堤丰罩衣 · 燃烧狂欢节舞会装束 |
| 配装 | 常以 [[卡奈魔方-Kanai-Cube\|卡奈魔方]] + 皇家华戒「5 件吃 6 件」 |
