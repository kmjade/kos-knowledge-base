# 赫拉迪姆方块 (Horadric Cube)

## 定义

Diablo II 的核心**合成工具**：将物品放入方块按配方组合，产出升级 / 打孔 / 手工物品等，是 D2 装备体系的中枢。

## 关键要点

| 配方类型 | 示例 |
|------|------|
| 符文升级 | 3× 相同符文 → 1× 更高级符文 |
| 宝石升级 | 3× 相同宝石 → 1× 更高级 |
| 装备打孔 | 符文 + 完美宝石 + 普通装备 |
| 手工物品 | P.Gem + 符文 + 珠宝 + 蓝装 |
