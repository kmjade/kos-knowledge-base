# 暴雪娱乐 (Blizzard Entertainment)

《暗黑破坏神》系列的开发与发行商；Diablo I / II 由 **Blizzard North** 开发，III 起由 Blizzard 本体。另发行《魔兽世界》《星海争霸》《斗阵特攻》等。

## 核心信息

| 参数 | 说明 |
|------|------|
| 类型 | 游戏开发 / 发行商 |
| 相关工作室 | **Blizzard North**（D1/D2）· Blizzard（D3/D4） |
| 母公司 | 动视暴雪 → 微软（2023） |
| 代表系列 | **Diablo** · Warcraft · StarCraft · Overwatch · Hearthstone |
| 国服营运 | 网易（`d3.blizzard.cn`） |

## 主要事迹

- 1996 推出 Diablo，开创现代 ARPG。
- Diablo IV (2023) 系列首度开放世界 + MMO 元素。
- Diablo Immortal (2022) 与网易联合开发。
