# 迪亚波罗 (Diablo)

系列同名反派 —— **恐惧之王**，燃烧地狱七大魔王之首（三大 Prime Evil 之一），是 Diablo I / II / III 的终极威胁。

## 核心信息

| 参数 | 说明 |
|------|------|
| 身份 | 恐惧之王 · Prime Evil |
| 领域 | 燃烧地狱 |
| 出场 | Diablo I（大教堂底层）· II · III |
| 相关 | 墨菲斯托 · 巴尔（三大 Prime Evil） |

## 主要事迹

- D1：被大主教拉萨雷斯召唤至崔斯特瑞姆大教堂底层。
- D2：腐化英雄（「黑暗流浪者」），最终于地狱熔炉被击败。
- D3（RoS）：作为 Prime Evil 再度降临。
