# 05 中盘与战斗

> 中盘是布局之后、官子之前的**主战场**：局部战斗与全局平衡在此分胜负。

## 攻防

| 概念 | 说明 |
|:--|:--|
| **攻击** | 紧逼对方弱棋，迫其做活或受损，借势取利 |
| **治孤 / 做活** | 被攻方求活、反击或弃子外逃 |
| **急所** | 关系到棋块生死的要点 |
| **大场 vs 急所** | 「**急所先于大场**」—— 有危险先处理 |

## 势与地

| 概念 | 说明 |
|:--|:--|
| **地（实地）** | 已确定围住的空 |
| **势（外势）** | 面向中腹的潜在影响力，可转化为地 |
| **转换** | 以地换势 / 以势换地，是中盘的核心权衡 |

## 打入与侵消

| 手段 | 说明 |
|:--|:--|
| **打入** | 深入对方势力范围，谋求就地做活或分割 |
| **侵消** | 浅削对方模样，压缩其成空潜力而不深入 |

## 弃子与厚薄

- **弃子**：主动放弃局部棋子，换取外势、先手或更大事。
- **厚势**：坚固无弱点的棋，是攻击与成空的资本。
- **薄棋**：有断点或薄弱的棋，须谨慎防守、避免受攻。

## 打劫战斗

- 中盘常见**劫争**：以劫材多寡决定得失，往往牵动全局。
