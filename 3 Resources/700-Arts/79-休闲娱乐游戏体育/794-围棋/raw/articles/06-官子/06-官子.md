# 06 官子

> 官子（收官）是**中盘之后、终局之前**的阶段：边界定型、逐点收束，细节常定一目半目之胜负。

## 先后手

| 类型 | 说明 |
|:--|:--|
| **先手官子** | 我方收完，对方必须应；可连续获取 |
| **后手官子** | 收完轮到对方，需比较大小 |
| **逆收官子** | 本属对方先手的官子，我方主动先收 |

## 目数计算

- 官子价值 = 「得了多少目」＋「先后手」（先手官子可按双倍价值估算）。
- 收官原则：**先大后小** · **先手优先** · 算清每一处的目数与手数。

## 常见官子手段

| 手段 | 说明 |
|:--|:--|
| **扳 / 退** | 边界的基本推进 |
| **挡 / 立** | 封口与守地 |
| **飞 / 跳** | 扩张或联络 |
| **夹** | 收紧对方，争夺边界 |

## 终局与胜负

- 双方收完官子后**停手（pass）**，进入计算。
- 数子（中国）/ 数目（日韩）→ 加**贴目** → 地多者胜（常见一目半目之差）。
