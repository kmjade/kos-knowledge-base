# 01 围棋导论

## 什么是围棋

围棋是**起源于中国**的两人**棋盘游戏**：在 19×19 的棋盘上，黑先白后，轮流把棋子落在**交叉点**上，以**围地（围空）**多者为胜。棋子落下后不再移动；棋块被完全包围、失去全部「气」时会被提掉。

它大概是「**规则最简、变化最繁**」的博弈：规则一页纸可写完，复杂度却远超国际象棋，长期是人工智能最难攻克的棋类。

## 起源与传播

| 时期 | 事件 | 意义 |
|:--|:--|:--|
| 传说 | 尧造围棋（《世本》「尧造围棋，丹朱善之」） | 不可考，反映其古老 |
| 先秦 | 《左传》襄公二十五年（前 548）「弈者举棋不定」；《论语》「不有博弈者乎」 | 最早的可靠文字记载 |
| 汉唐 | 传入朝鲜半岛、日本 | 东亚「棋文化圈」形成 |
| 江户 | 日本四大家（本因坊 · 安井 · 井上 · 林）· 御城棋 | 职业制度与棋院雏形 |
| 20 世纪 | 吴清源与「新布局」· 日本主导 → 韩国崛起 → 中国中兴 | 现代围棋格局 |
| 2016 | AlphaGo 战胜李世石 | 围棋进入 AI 时代 |

## 为什么围棋特殊

| 对照 | 围棋 |
|:--|:--|
| **目标** | 围地（不直接擒王 / 吃子） |
| **子力** | **无**固定价值，每颗子的价值随全局而变 |
| **判断** | 偏整体、模糊 —— 「势」与「地」、「厚」与「薄」 |
| **规模** | 19×19 合法局面约 **2.08×10¹⁷⁰**；远超市井常比的国际象棋（~10⁴⁷） |
| **和局** | 罕见（贴目 + 半目制） |

> 难点不在「**算**」，而在「**评**」。这正是 2016 年 AlphaGo 之前，传统搜索型 AI 长期无法突破围棋的原因。

## 核心概念初览

| 概念 | 说明 |
|:--|:--|
| **气** | 棋子（或棋块）上下左右相邻的空点；无气即被提 |
| **提子** | 使对方棋块无气后将其移出棋盘 |
| **劫** | 禁止「立即回提」的循环，须先寻劫 |
| **禁着点** | 落子即自杀（无气）之点为禁着 |
| **眼** | 被己方完全包围的空点；**两个真眼**即为活棋 |
| **地 / 目** | 所围空点；终局以地多者为胜 |
| **贴目** | 为补偿黑棋先手之利，黑须贴还给白若干目 |
| **阶段** | 布局 → 中盘 → 官子（收官） |

## 与其他棋类

- **围棋**：目标围地 · 全局性 · 多为「斗智的和平」（不直接消灭对方）。
- **国际象棋 / 中国象棋**：目标擒王 · 局部子力价值明确（车 5 · 马 3 …）。
- 概言之：围棋更接近「**建立优势结构**」，象棋更接近「**精确战术执行**」。

## 为什么值得了解

- **文化**：琴棋书画之「棋」即围棋；与道家、兵法、禅缠绕。
- **思维**：训练全局判断、权衡与耐心，以及「弃子取势」的取舍。
- **AI**：AlphaGo · AlphaGo Zero · AlphaZero · KataGo —— 深度强化学习 + MCTS 的里程碑，也是理解现代 AI 的绝佳入口。
