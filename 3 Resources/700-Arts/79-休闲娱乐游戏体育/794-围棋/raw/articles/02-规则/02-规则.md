# 02 规则

## 棋盘与棋子

- 标准棋盘 **19×19 = 361 个交叉点**；9 路 / 13 路多用于教学与快棋。
- 棋子分黑白，**黑先行**；棋子落在**交叉点**上，落定后不再移动（除被提）。

## 气与提子

| 概念 | 说明 |
|:--|:--|
| **气** | 一颗（或相连的一块）棋子**上下左右**相邻的空点 |
| **提子** | 一方落子后使对方某棋块的气变为 0 → 该棋块被移出棋盘 |
| **连接** | 同色棋子直线相邻即连成一块，**共享气** |

> 活棋靠「气」；围住对方的气，就能吃掉对方。

## 禁着点与自杀

- 落子后**己方**该棋块无气（且不能同时提掉对方）→ 该点为**禁着点**。
- 例外：落子虽使己方无气，但**同时提掉对方**棋块，则允许（提子优先）。

## 劫（Ko）

- **劫**：一种「提一子 — 回提一子」的循环。
- 规则**禁止立即回提**：被提方须先在别处落一手（**寻劫 / 劫材**），对方应着之后方可回提。
- 劫是围棋「战斗」的核心机制之一。

## 终局与胜负

| 项目 | 说明 |
|:--|:--|
| **终局** | 双方连续**停手（pass）**，或一方认输 |
| **中国规则（数子）** | 以「己方活子数 ＋ 所围空点」计 |
| **日韩规则（数目）** | 以「所围空点 ＋ 提掉对方子数」计 |
| **应氏规则** | 计点制（含时间罚点） |
| **贴目** | 补偿黑先手之利：中国 **7.5 目** · 日韩 **6.5 目** · 应氏 **8 点** |
| **胜负** | 地多者胜；贴目带「半目 / 零点」以避免和棋 |

> 三种规则体系在**绝大多数局面**下结果一致，差异主要在双活、劫与计算口径的细节。

## 礼仪

- **猜先**定黑白；落子即定、**不悔棋**；认输、复盘有礼。
