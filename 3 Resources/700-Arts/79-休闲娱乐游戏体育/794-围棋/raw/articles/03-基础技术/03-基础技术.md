# 03 基础技术

> 从「气」出发，掌握**连接与分断**、**死活**、**基本战术**与**手筋** —— 这是下棋的地基。

## 连接与分断

| 术语 | 说明 |
|:--|:--|
| **连（接）** | 把己方棋子连成一块，共享气、更坚固 |
| **断** | 割开对方棋子，制造弱棋与战机 |
| **粘 / 虎 / 接** | 常见补断手段 |

## 眼与死活

| 概念 | 说明 |
|:--|:--|
| **眼** | 被己方棋子完全包围的空点（对方难以在其中成活） |
| **真眼 / 假眼** | 真眼无法被破；假眼可被填掉 |
| **活棋** | **两只真眼**即活（对方无法同时紧气提掉） |
| **死棋** | 无法做出两眼、且被包围的棋块 |
| **大眼** | 直四、曲四、板六多为活形；刀把五、花六多为死形 |

> 死活是围棋基本功：**做活**与**杀棋**是一体两面。

## 基本战术

| 战术 | 说明 |
|:--|:--|
| **征子（征）** | 连续打吃，把对方赶往边线吃掉；须先算清「征不掉」时的接应 |
| **枷吃** | 不紧气、以形围困，吃掉对方 |
| **扑 / 倒扑** | 先送一子，再提回更多 |
| **接不归** | 打吃使对方不能接回 |
| **滚打包收** | 连续打吃把对方压成一团 |

## 手筋

- **手筋**：局部攻防中的**妙手 / 要点**，往往不合常理却能一举制胜。
- 学手筋 = 积累「形的感觉」，是棋力跃升的关键。

## 强弱与厚薄

| 概念 | 说明 |
|:--|:--|
| **厚势** | 坚固、无后顾之忧的外势 |
| **薄棋** | 有弱点的棋，易被攻击 |
| **弃子** | 主动放弃局部棋子，换取外势或先手 |
