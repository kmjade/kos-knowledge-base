# 04 布局与定式

> 布局是全局的**第一印象**：抢占大场、确立势力，为后续战斗搭台。

## 效率序：金角银边草肚皮

| 区域 | 围空效率 | 说明 |
|:--|:--|:--|
| **角** | 最高 | 两边即封口，少量子即可成空 |
| **边** | 中 | 需一线封口 |
| **中腹（草肚皮）** | 最低 | 四面开阔，需大量子 |

> 一句话：**先占角，再拆边，后向中腹**。

## 常见起手

| 着点 | 位置 | 特点 |
|:--|:--|:--|
| **星** | 4-4 | 取势取速，重视外势与中央 |
| **小目** | 3-4 | 取地实在，注重实地与均衡 |
| **三三** | 3-3 | 直接取角地 |
| **目外 / 高目** | 3-5 / 4-5 | 偏向势力与模样 |
| **天元** | 10-10 | 中央，较少见（全局构思） |

## 定式（Joseki）

- **定式**：角部双方公认的**合理应对序列**，是长期实战与研究的结晶。
- 目的：在局部取得大致两分的利益分配，避免吃亏。
- 常见：星定式、小目定式、三三定式；「挂角」「守角」「夹击」为其核心构件。
- **AI 时代**：定式被大幅改写（如**开局点三三**成为常规），旧定式许多被淘汰或重估。

## 布局的组成部分

| 术语 | 说明 |
|:--|:--|
| **占角** | 优先建立角部根据地 |
| **挂角 / 守角** | 进攻 / 巩固对方角地 |
| **夹击** | 紧逼对方挂角之子 |
| **拆边** | 沿边展开，扩大地盘 |
| **大场** | 全局价值最大的要点 |
| **分投** | 打入对方阵势之间，分而治之 |

## 布局理论与流派

- **新布局**（1933，吴清源 · 木谷实）：打破「小目优先」，重视**速度与中腹**，是围棋观念的里程碑。
- **中国流 / 韩国流** 等：不同年代的主导布局体系。
