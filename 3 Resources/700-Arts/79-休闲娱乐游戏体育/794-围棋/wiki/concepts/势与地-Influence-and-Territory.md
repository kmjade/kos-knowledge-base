# 势与地 Influence and Territory

## 定义

**势（外势）**是面向中腹、尚未成地的**潜在影响力**；**地（实地）**是已确定围住的空。二者的权衡与**转换**是围棋战略的核心。

## 关键要点

| 要点 | 说明 |
|------|------|
| 外势 | 坚固无弱点的棋，是攻击与成空的资本（「厚」） |
| 实地 | 已确定的空，直观的得分 |
| 转换 | 以地换势 / 以势换地 |
| 厚薄 | 厚=坚固强大；薄=有弱点、易被攻击 |
| 平衡 | 全局胜负取决于势与地的总账 |

> 围棋难在「**评**」：势/地、厚/薄是整体而模糊的判断，无固定子力价值。
