# 贴目 Komi

## 定义

**贴目**是为**补偿黑棋先手之利**，规定黑棋在终局结算时贴还给白棋的目数。

## 关键要点

| 规则体系 | 贴目 |
|------|------|
| 中国规则 | **7.5 目** |
| 日韩规则 | **6.5 目** |
| 应氏规则 | **8 点** |

- 贴目带「半目 / 零点」，使和棋几乎不可能。
- 贴目多少直接影响布局取向（先手价值的界定）。
