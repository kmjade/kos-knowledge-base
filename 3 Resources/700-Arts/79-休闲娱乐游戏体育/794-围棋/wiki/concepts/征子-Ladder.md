# 征子 Ladder

## 定义

**征子（征）**是最基本的吃子战术：**连续打吃**，把对方棋子一节节赶往边线，最终吃掉。

## 关键要点

| 要点 | 说明 |
|------|------|
| 直线追赶 | 每次只留一口气，逼迫对方逃 |
| 征子有利 / 不利 | 前方若有对方接应（**引征**），征子失败甚至崩盘 |
| 算清接应 | 下征子前必须看清全盘有无引征之子 |
| 相关手筋 | 与枷吃、接不归等并列 |

> 征子是检验「算路」的入门课，也是**手筋**的基础。
