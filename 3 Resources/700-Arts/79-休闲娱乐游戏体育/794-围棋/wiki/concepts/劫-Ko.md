# 劫 Ko

## 定义

**劫**是「提一子 — 回提一子」的循环局面。规则**禁止立即回提**：被提方须先在别处落一手（**寻劫 / 劫材**），对方应着之后，方可回提。

## 关键要点

| 要点 | 说明 |
|------|------|
| 禁止立即回提 | 防止无限循环 |
| 劫材 | 用来「交换」的别处手段；劫材多者占优 |
| 劫争 | 以全局得失决定劫的归属，常牵动大局 |
| 应劫 / 消劫 | 应对劫、或化解劫争 |

> 劫是围棋**战斗**的核心机制之一，也是规则体系（中国/日韩）差异所在。
