# 定式 Joseki

## 定义

**定式**是角部双方**公认的合理应对序列**，是长期实战与研究的结晶。其目的是在局部取得大致**两分**的利益分配、避免吃亏。

## 关键要点

| 要点 | 说明 |
|------|------|
| 分类 | 星定式 · 小目定式 · 三三定式 |
| 核心构件 | 挂角 · 守角 · 夹击 |
| 可选择性 | 定式分支众多，须配合全局选择 |
| AI 时代 | 定式被大幅改写（如**开局点三三**成为常规），旧定式许多被淘汰或重估 |

> 定式不是死记，而是理解「**为什么这样走合理**」。
