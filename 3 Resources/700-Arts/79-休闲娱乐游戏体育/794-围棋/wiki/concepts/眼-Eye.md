# 眼 Eye

## 定义

**眼**是被己方棋子完全包围的空点：对方无法在其中落子成活（落子即自杀/被提）。眼是棋块存活的根据。

## 关键要点

| 要点 | 说明 |
|------|------|
| 真眼 / 假眼 | **真眼**无法被破；**假眼**可被对方填掉 |
| 两眼活棋 | 一块棋有**两只真眼**即**活棋**（对方无法同时紧气提掉） |
| 大眼 | 直四、曲四、板六等多为**活形**；刀把五、花六等多为**死形** |
| 做眼 | 主动构造眼位以求活 |
| 破眼 | 攻击方抢占眼位以杀棋 |

> 眼是**死活**问题的核心：争的就是能不能做出两眼。
