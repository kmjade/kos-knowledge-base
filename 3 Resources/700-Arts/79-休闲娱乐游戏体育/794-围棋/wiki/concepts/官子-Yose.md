# 官子 Yose

## 定义

**官子（收官）**是**中盘之后、终局之前**的阶段：双方逐点收束边界、定型，细节常定一目半目之胜负。

## 关键要点

| 要点 | 说明 |
|------|------|
| 先手官子 | 我方收完，对方必须应 |
| 后手官子 | 收完轮到对方，需比较大小 |
| 逆收官子 | 本属对方先手的官子，我方主动先收 |
| 目数价值 | 「得了多少目」＋「先后手」（先手可按双倍估算） |
| 收官原则 | **先大后小** · **先手优先** |
