# 手筋 Tesuji

## 定义

**手筋**是局部攻防中的**妙手 / 要点**，往往不合常理却能一举制胜。积累手筋即积累「**形的感觉**」。

## 常见手筋

| 手筋 | 说明 |
|------|------|
| 征子（征） | 连续打吃把对方赶往边线吃掉 |
| 枷吃 | 不紧气、以形围困 |
| 扑 / 倒扑 | 先送一子，再提回更多 |
| 接不归 | 打吃使对方不能接回 |
| 滚打包收 | 连续打吃把对方压成一团 |

> 手筋与「死活」紧密相关：许多死活题的关键正是一手手筋。
