# 气 Qi

## 定义

**气**是围棋中最基本的概念：一颗棋子（或其**直线相连**的同色棋块中的全部棋子）在棋盘上**上下左右相邻的空点**数量。气决定棋块的生死 —— **气尽即被提**。

## 关键要点

| 要点 | 说明 |
|------|------|
| 计数 | 只看上下左右，**不看斜对角** |
| 共享 | 相连的同色棋子连成一块，**共享气** |
| 紧气 | 落子减少对方的气 |
| 提子 | 使对方棋块气为 0 → 移出棋盘 |
| 长气 | 通过连接或延伸增加自身的气 |
