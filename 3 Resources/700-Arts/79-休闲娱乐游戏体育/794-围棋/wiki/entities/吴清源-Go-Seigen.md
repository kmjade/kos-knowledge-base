# 吴清源 Go Seigen

华裔日本棋手（1914–2014），被誉为「**昭和棋圣**」，20 世纪围棋的标杆人物。

## 核心信息

| 参数 | 说明 |
|------|------|
| 类型 | 棋手 |
| 国籍 | 中国出生 · 旅日 |
| 标志 | 十番棋横扫日本高手 · 新布局 |
| 影响 | 现代围棋观念与实践的奠基者 |

## 主要贡献

- **新布局**（1933，与木谷实）：打破「小目优先」，重视**速度与中腹**。
- **十番棋**：以升降十番棋连续击败日本顶尖棋手，将对手降级，堪称传说。
- 晚年提出「**21 世纪围棋**」，强调均衡与全局。
