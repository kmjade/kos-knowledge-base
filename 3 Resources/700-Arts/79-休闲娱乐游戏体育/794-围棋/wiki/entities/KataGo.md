# KataGo

**开源围棋 AI**（2019 起），由 David J. Wu 等开发，以**训练效率高、棋力强**著称，广泛用于棋力分析与自我训练。

## 核心信息

| 参数 | 说明 |
|------|------|
| 类型 | 围棋 AI（开源） |
| 起点 | 2019 |
| 特点 | 高效 · 可分析 · 社区可复现 |
| 生态 | 与 Leela Zero 等构成开源围棋 AI 生态 |

## 意义

- 把「AlphaGo 级」能力带给社区，成为棋手复盘与研究的常用工具。
- 与 AlphaGo 一起，将围棋的**理论定式**推向重构。
