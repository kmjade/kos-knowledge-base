# 当湖十局

**1739 年**（清乾隆四年），国手**范西屏**与**施襄夏**在浙江**当湖**（今平湖）的对局谱，被誉为中国古代围棋的最高峰。

## 价值

- 代表清代「国手」时代的棋艺巅峰，是中国古谱的典范。
- 其布局与战斗思路常被后世研究、与今棋对照。
