# 发阳论

日本江户时期的**死活题名著**（1713 年刊），汇集高难度**死活 / 手筋**题目，是死活训练的经典教材。

## 价值

- 死活与手筋的题库，训练算路与「形的感觉」。
- 与《玄玄棋经》（中国）并列，代表古典围棋死活研究的顶峰。
