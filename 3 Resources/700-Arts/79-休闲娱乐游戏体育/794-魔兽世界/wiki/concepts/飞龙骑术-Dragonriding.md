# 飛龍騎術 (Dragonriding)

## 定義

《巨龍時代》(Dragonflight, 10.x) 引入的**動量飛行系統**：以加速、爬升、俯衝與精力管理取代傳統靜態飛行，最高速度遠超傳統 310% 飛行（可逾 900%）。

## 關鍵要點

| 要素 | 說明 |
|------|------|
| 機制 | 動量飛行：加速 · 爬升 · 俯衝 · 精力管理 |
| 龍族 | 四種可自訂飛龍坐騎 + 外觀雕紋收集 |
| 天賦 | 飛龍騎術天賦樹，解鎖技能與被動 |
| 速度 | 最高逾 900%（遠超傳統 310%） |
| 擴展 | TWW 起全艾澤拉斯可用 |
