# 史詩鑰石地城 (Mythic+)

## 定義

WoW 的**無限層級 5 人地城挑戰**（Legion 7.0 引入，源於 MoP/WoD 挑戰模式）。以**鑰石層級**遞增難度，每週**詞綴**輪換，設時間限制與賽季地城池。

## 關鍵要點

| 要素 | 說明 |
|------|------|
| 起源 | 挑戰模式（MoP/WoD）→ 史詩鑰石地城（Legion 7.0） |
| 層級 | M2 → M+∞，每層疊加約 7–10% 怪物血量與傷害 |
| 詞綴 | 依層級啟動：M2（暴君/強悍）· M4 · M7 · M10（賽季詞綴） |
| 賽季 | 每賽季更換地城池（4 舊 + 4 新） |
| 評分 | Raider.IO（BfA）→ 遊戲內建評分（Shadowlands+） |
| 門檻 | 2,000 分 → 傳送門；2,500 分 → 成就；鑰石大師（KSM）坐騎 |
