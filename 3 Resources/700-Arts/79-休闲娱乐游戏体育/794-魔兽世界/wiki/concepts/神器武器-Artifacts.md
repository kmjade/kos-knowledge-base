# 神器武器 (Artifacts)

## 定義

《軍臨天下》(Legion, 7.x) 引入的**專精專屬武器系統**：每專精一把獨特神器，含外觀解鎖、神器天賦樹（神器之力）與**聖物插槽**。7.3 加入熔爐擴展上限。BfA 由**艾澤萊晶岩**取代。

## 關鍵要點

| 要素 | 說明 |
|------|------|
| 覆蓋 | 每職業每專精一把（如戰士武器系「斯多姆卡·滅戰者」） |
| 成長 | 神器之力（技能樹）· 聖物插槽 · 外觀雕紋 |
| 後續 | 7.3 熔爐系統擴展；8.0 由 [[03-熊猫人→争霸艾泽拉斯|艾澤萊晶岩]] 取代 |
| 評價 | 多數正面；外觀收集（法師塔）成經典 |
