# 探究 (Delves)

## 定義

《地心之戰》(TWW, 11.x) 引入的**1–5 人小型 PvE**，填補單人 / 小團隊與團隊 / M+ 之間的獎勵鴻溝。每賽季輪換場景，可搭配 NPC 同伴（布萊恩·銅鬚）。

## 關鍵要點

| 要素 | 說明 |
|------|------|
| 規模 | 1–5 人（含 NPC 同伴） |
| 層級 | Tier 1–11，越高越難 |
| 賽季 | 每賽季更新探究場景與主題 |
| 獎勵 | 寶庫解鎖 + 終點寶箱，可達**英雄團隊**級別 |
| 類型 | 礦坑 · 挖掘 · 洞穴 · 真菌 |
