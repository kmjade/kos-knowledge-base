# 阿薩斯·米奈希爾 (Arthas Menethil)

《魔獸世界》最具標誌性的角色之一 —— 羅德隆王子，墮落為**巫妖王**，是《巫妖王之怒》(WotLK, 3.x) 的最終首領。

## 核心信息

| 參數 | 說明 |
|------|------|
| 身份 | 羅德隆王子 → 死亡騎士 → **巫妖王** |
| 資料片 | 魔獸爭霸 III · 巫妖王之怒 (3.x) |
| 要塞 / 首領 | 冰冠城塞 (Icecrown Citadel) |
| 關鍵器物 | 霜之哀傷 (Frostmourne) · 影之哀傷 |

## 主要事跡

- 斯坦索姆屠城 → 追擊魔將瑪爾加尼斯 → 拔出霜之哀傷墮落。
- 與伊利丹·怒風於冰冠城塞對決。
- 冰冠城塞首領戰為 WoW 經典最終戰之一。
