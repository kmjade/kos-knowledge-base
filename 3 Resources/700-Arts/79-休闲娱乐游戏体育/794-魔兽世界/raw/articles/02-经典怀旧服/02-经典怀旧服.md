# 魔獸世界 — 經典懷舊服（Classic）

> 《魔獸世界》**三條並行產品線**之一 —— **經典懷舊服**：逐階段復刻舊版本（時間鎖），並含 **探索賽季 (SoD)** · **20 週年紀念版（永久 60）** 等變體。
> 隸屬 [[794-魔兽世界|794 魔獸世界]] 子庫。與 **正式服**（[[01-正式服|01 正式服]]）· **無限**（[[03-无限|03 無限]]）**並行**。

## 一、版本線（逐階段復刻）

| 版本 | 發佈 | 階段 | 特色 |
| :---: | :--: | :--: | :--- |
| Classic (2019) | 2019.08 | 6 階段 | 忠實復刻 1.12 版本 |
| TBC Classic | 2021.06 | 5 階段 | 外域 + 血精靈/德萊尼 |
| WotLK Classic | 2022.09 | 5 階段 | 北裂境 + 死亡騎士 |
| Cataclysm Classic | 2024.05 | 持續更新 | 大災變經典版 |
| 探索賽季 (SoD) | 2023.11 | 7 階段 | 經典 + 實驗：符文系統、新團隊機制 |
| 20 週年紀念版（永久 60） | 2024.11 | 持續 | 永久 60 級，無後續資料片 |

## 二、探索賽季 (Season of Discovery) 核心特性

| 要素 | 說明 |
| :---: | :--- |
| 符文系統 | 裝備符文獲得新技能（如法師治療、盜賊坦克） |
| 等級階段 | 25 → 40 → 50 → 60 每階段提升上限 |
| 職業重塑 | 經典職業打破角色定位（補法、坦賊、坦術、坦薩） |
| 新團隊 | 黑暗深淵 (25) · 諾姆瑞根 (40) · 沉沒的神廟 (50) · 熔火之心 (60) |
| 全新掉落 | 經典團隊副本獲得全新設計裝備 |

## 三、三線關係（待核）

> 經典懷舊服與 **正式服** · **無限** 為**三條並行產品線**（2026-10-08 用戶口徑）；三線之具體關係 / 進入點**待核**。新作「無限」見 [[03-无限|03 無限]]。
