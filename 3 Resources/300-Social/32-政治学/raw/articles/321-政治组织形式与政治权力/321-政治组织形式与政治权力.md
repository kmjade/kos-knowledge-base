# 321 政治组织形式与政治权力

> **UDC 321** — 政治组织形式、国家政治权力（Forms of political organization. State political power）。
> 隶属 [[3 Resources/300-Social/32-政治学/32-政治学|32 政治学]]。

## 类目

**国家如何被组织、政治权力如何构成** —— 国家形式、政体、主权与统治正当性。

## 内容要点

| 层面 | 内容 |
|------|------|
| 国家形式 | 单一制 · 联邦制 · 邦联制 |
| 政体 | 君主制 · 共和制 · 民主制 · 威权 / 极权 |
| 权力结构 | 主权 · 立法 / 行政 / 司法（组织面见 342） |
| 正当性 | 合法性 · 统治类型（传统 / 卡理斯玛 / 法理） |
