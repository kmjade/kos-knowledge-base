# 老子 Laozi

传统上被视为道家创始人，姓李名耳（一说老聃），生活于春秋末期，曾为周守藏室之史。相传著《道德经》（《老子》）五千余言。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 思想家 |
| 时期 | 传统定为春秋末期（⚠️ 有争，见下） |
| 核心主张 | 道法自然、无为而治、柔弱胜刚强、反者道之动 |
| 代表文本 | 《道德经》（约五千言，八十一章） |
| 地位 | 道家创始（传统说法），与儒家并列为中国思想两大主干 |

## 要义

- **他的方案是「退返」**：面对礼崩乐坏，儒法墨都要重建秩序，老子则**质疑秩序本身**——「大道废，有仁义」，把文明化视为问题的来源之一。
- **他的影响穿透整个中国思想史**：黄老之学、法家的「术」、后世的玄学与禅宗皆有其影子。

## ⚠️ 争议：其人其书

| 问题 | 争点 |
|------|------|
| 其人 | 老子是孔子问礼的老聃？还是战国人？是否实有其人？ |
| 其书 | 《老子》成书年代与作者：春秋末？战国？ |
| 新材料 | 郭店楚简（1993）出土《老子》最早抄本之一，**但与通行本差异显著**，提示文本经历了长期增改 |

> 本库按既定纪律**两说并列、不代裁**：把「老子」其人其书视为**传统归属**，而把《老子》文本视为一个**成书过程**。参见 [[08-思想与学术\|08 章]]。
