# 商鞅 Shang Yang

战国中期政治家、法家代表（约前 390—前 338），卫国人，入秦说孝公变法，前 356、前 350 年两次推行改革，使秦国转弱为强。孝公死后被车裂。

| 参数 | 说明 |

| 时期 | [[07-战国：变法与统一\|战国]]中期（秦） |

| 著作 | 《商君书》（⚠️ 多为后学辑录，非全部本人所作） |

## 变法要点

| 领域 | 措施 |
|------|------|
| 土地 | 废井田、开阡陌，承认土地私有与买卖 |
| 军功 | 军功爵制；宗室无军功不得为属籍 |
| 编户 | 什伍连坐、告奸，建立国家直接控制的户籍 |
| 行政 | 普遍推行县制，官吏由国君任免 |
| 经济 | 重农抑商、奖励耕织、统一度量衡 |

## 要义

- **他是「制度胜出」的样本**：商鞅本人被车裂，但变法成果被秦完整继承——说明变法已越过个人成败，成为国家机器的结构。
- **他留下的是帝制的技术包**：[[编户齐民-Registered-Commoners\|编户齐民]]、郡县、军功爵、上计考课，经秦而汉，成为此后两千年的行政底色。
- **他的思想被[[韩非-Han-Fei\|韩非]]综合**：商鞅主「法」，申不害主「术」，慎到主「势」，韩非合而为一。
