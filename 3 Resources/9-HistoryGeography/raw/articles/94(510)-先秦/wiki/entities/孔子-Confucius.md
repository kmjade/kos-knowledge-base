# 孔子 Confucius

春秋末期鲁国人（前 551—前 479），名丘，字仲尼。儒家学派创始人，中国私学之始，其言行由弟子辑为《论语》。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 思想家、教育家 |
| 时期 | [[06-春秋：霸主与华夏认同\|春秋]]末期（鲁） |
| 核心主张 | 「仁」为内在根据，「礼」为外在规范；正名；中庸 |
| 教育主张 | **有教无类**，开私人讲学之风 |
| 文献工作 | 传统认为删《诗》《书》、订礼乐、作《春秋》（⚠️ 具体程度有争） |
| 地位 | 儒家创始，后世尊为「至圣先师」 |

## 要义

- **他面对的问题是礼崩乐坏**：其方案是**复原并重新解释周礼**（「郁郁乎文哉，吾从周」）——不是创新制度，而是为旧制度找到新的内在根据（仁）。
- **他的制度后果极其深远**：「学在官府」变为「**学在四夷**」，士成为流动的知识阶层——这是[[百家争鸣-Hundred-Schools\|百家争鸣]]的社会前提。
- **他的历史语境是华夏认同**：「微管仲，吾其被发左衽矣」一语，体现了[[06-春秋：霸主与华夏认同\|春秋]]「攘夷」事业的文明意义。
