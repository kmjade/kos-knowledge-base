# 宗法制 Zongfa

## 定义

**宗法制**是以**嫡长子继承**为核心的亲属组织与权力继承制度，把血缘关系等级化、政治化。它是西周「封建」得以运转的内在规则。

## 要点

| 要点 | 说明 |
|------|------|
| 嫡庶之别 | 正妻所生为嫡，庶子地位低于嫡子 |
| 嫡长子继承 | 嫡长子继承父位，为**大宗** |
| 大宗 / 小宗 | 余子分封为**小宗**；小宗在其支系内又自成大宗，层层递推 |
| 丧服制度 | 以服制亲疏（斩衰、齐衰等）量化亲属关系，使血缘等级可视 |

## 要义

- **宗法 = 血缘的政治化**：继承规则一旦确定，权力交接就不再依赖个人能力或武力，从而降低内耗——这是西周制度设计的关键优势。
- **宗法与封建一体两面**：[[封建制-Fengjian|封建]]解决「地」的分配，宗法解决「人」的排序；两者共同构成「家国同构」的秩序。
- **后世的延续**：宗法观念深刻影响中国后世的家族制度与政治文化（「家国同构」「嫡庶之别」），是理解帝制中国社会结构的长线线索。

> 王国维《殷周制度论》把「立子立嫡之制」列为殷周之际最剧之变的第一项。
