# 二重证据法 Dual Evidence

## 定义

**二重证据法**是[[王国维-Wang-Guowei\|王国维]]提出的史学方法：「**取地下之实物与纸上之遗文互相释证**」（《古史新证》，1925）。即用出土材料（甲骨、金文、简帛、考古遗存）与传世文献互相比对、互相校验。

## 首功之作

王国维《殷卜辞中所见先公先王考》（1917）以甲骨卜辞校《史记·殷本纪》，证明商王世系基本可靠——**这第一次证明「传世文献可以被出土材料验证」**，从而为「释古」提供了方法论工具。

## 意义与边界

| 面向 | 说明 |
|------|------|
| 反对一概怀疑 | 回应[[顾颉刚-Gu-Jiegang\|古史辨派]]的疑古，证明文献并非全不可信 |
| 反对一概相信 | 同样可用出土材料**证伪**文献（如《竹书纪年》与《史记》的异同） |
| 边界 | 出土材料本身需解读，且沉默的考古遗存不必然对应文献名号——**这正是[[03-夏与二里头\|夏之争]]无法闭合的原因** |

## 疑古 → 释古 → 走出疑古

| 阶段 | 主张 |
|------|------|
| 信古 | 传统古史系统可信 |
| 疑古 | 层累造成的古史（古史辨派） |
| 释古 | 用出土材料重新解释与检验（二重证据法） |
| 走出疑古 | 李学勤倡之（⚠️ 该提法亦有争议，被指可能滑回信古） |

## 与证据强度分层

本库把二重证据法的精神操作化为**证据强度分层**（见 [[09-考古与史料\|09 章]]）：

| 层级 | 含义 |
|:--:|------|
| A | 出土文字自证 |
| B | 同时代实物 + 文献互证 |
| C | 晚出文献记载，考古部分吻合 |
| D | 晚出文献记载，无考古对应 |

> 使用要点：**层级逐条判定，不按朝代整体套用。**
