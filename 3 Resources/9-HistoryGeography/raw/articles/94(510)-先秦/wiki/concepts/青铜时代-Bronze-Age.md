# 青铜时代 Bronze Age

## 定义

**青铜时代**指以青铜（铜锡合金）为主要技术标志的历史阶段。中国青铜时代大体自龙山时代晚期（冶铜术出现）延续至战国，其核心不是生产工具，而是**礼器与兵器**——这一点与欧洲青铜时代以工具为主的形态不同。

## 关键事实

| 器物 | 说明 |
|------|------|
| **后母戊鼎**（旧称司母戊鼎） | 商代，重约 832.84 公斤，现存最大最重青铜器 |
| **毛公鼎** | 西周晚期，铭文约 497 字，现存最长青铜器铭文 |
| 礼器组合 | 爵、觚、鼎、簋等，**组合即等级** |
| 妇好墓器物 | 商王武丁配偶墓，印证甲骨所记 |

## 要义

- **青铜是政治的，不是经济的**：礼器用于祭祀与身份标识，其分配即权力分配。
- **礼器体系是[[礼乐制度-Li-Yue|礼乐制度]]的物质基础**：等级通过器用数量与组合被可视化、可执行化。
- **铭文即史料**：金文（青铜器铭文）记录了册命、征伐、赏赐，是西周史最可靠的文字材料之一（见 [[05-西周：封建宗法礼乐|05 章]]）。
