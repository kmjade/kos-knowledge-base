# 06 春秋：霸主与华夏认同

## 时代的开端：王纲解纽

前 770 年平王东迁洛邑，周王室失去了关中故地，实力与威望同步衰减。由此形成春秋时代的基本格局：

| 现象 | 说明 |
|------|------|
| 王室衰微 | 王畿缩小，天子无力号令诸侯，「礼乐征伐自天子出」变为「自诸侯出」 |
| 强并弱 | 大国兼并小国，诸侯国数量急剧减少 |
| 楚、吴、越崛起 | 南方非姬姓势力进入中原政治舞台，**使「华夏」的边界成为真问题** |
| 卿大夫专权 | 至春秋晚期，鲁三桓、晋六卿等卿族崛起，权力再度下移 |

## 霸主政治

「霸」即「伯」，本义为诸侯之长。霸主以**「尊王攘夷」**为旗帜，代天子维持秩序：

- **尊王**：形式上承认周天子权威，以获得合法性。
- **攘夷**：抵御戎狄、楚等「夷」势力，同时以此号令诸侯。

| 说法 | 五霸构成 |
|------|---------|
| 《史记》系 | 齐桓公、晋文公、秦穆公、宋襄公、楚庄王 |
| 通行另一说 | 齐桓公、晋文公、楚庄王、吴王阖闾、越王勾践 |

> **⚠️ 约定 ≠ 事实**：「春秋五霸」并无当时定的名单，是后世追述的不同版本。本库如实并列两说，不选其一。

**重要节点**：齐桓公「九合诸侯，一匡天下」；晋楚长期争霸；前 546 年**弭兵之会**达成停战协议，是春秋国际政治的一次制度化尝试。

## 华夏认同：一个被这场乱世「造」出来的概念

春秋时代最深远的思想后果之一，是**「华夏」从血缘宗族概念转变为文化—政治共同体概念**：

- 「夷夏之辨」的标准从**族属**（是否为姬姓、是否出于周室）逐渐转向**文化**（是否行周礼、用华夏文字与礼俗）。
- 楚从「荆蛮」逐步被纳入华夏体系；吴、越亦循此路径。
- 结果是：**华夏不是先存在再扩张，而是在与「夷」的互动中不断重新定义自己**。

> 这正是孔子「微管仲，吾其被发左衽矣」一语的历史背景——攘夷事业的意义不仅在于军事，更在于文明边界的确认。

## 礼崩乐坏

孔子以「礼崩乐坏」概括这个时代：等级仪节被僭越（如季氏「八佾舞于庭」），宗法与封建的秩序基础松动。其制度表现包括：

| 表现 | 说明 |
|------|------|
| 僭越 | 诸侯用天子礼、卿大夫用诸侯礼 |
| 赋税变革 | 前 594 年鲁国「初税亩」，按亩征税，事实上承认私有土地 |
| 生产力变化 | 铁器与牛耕逐步推广，土地价值上升，井田制基础被侵蚀 |
| 士阶层崛起 | 宗法秩序松动，大量士人流向社会，为百家争鸣提供了人 |

## 从春秋到战国的分界

| 方案 | 依据 |
|------|------|
| 前 476 或前 475 | 《春秋》绝笔（鲁哀公十四年，前 481 获麟；传统以「春秋」纪年终于前 476/475） |
| 前 453 | 晋国三家灭智伯，晋分事实已成 |
| **前 403** | 周威烈王命韩、赵、魏为诸侯——**《资治通鉴》以此为战国起点** |

> 本库不取单一界标，只在行文中标注所用方案。**任何「春秋结束于 X 年」的表述都必须交代是哪种约定。**
