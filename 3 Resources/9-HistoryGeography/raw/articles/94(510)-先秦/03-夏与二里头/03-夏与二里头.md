# 03 夏与二里头

> **本章是先秦史最大的公开悬案。** 本库按既定纪律：**两说并列，不代为裁决。**

## 文献中的夏

| 文献 | 内容 | 成书年代 |
|------|------|---------|
| 《尚书》 | 夏书诸篇（禹贡、甘誓等） | 部分为后世追述 |
| 《史记·夏本纪》 | 夏世系：禹—启—…—桀，共十四世十七王 | 西汉 |
| 《竹书纪年》 | 编年体夏史 | 战国魏襄王墓出土，西晋出土 |
| 《左传》《国语》 | 引夏事、夏训 | 战国 |

核心叙事：**禹治水有功 → 启继位（禅让→世袭的转折）→ 传十七王 → 桀无道 → 商汤灭夏**。

> ⚠️ 关键难点：**所有记载「夏」的文献，成书都晚于夏千年以上**。它们可能保存了真实记忆，也可能是周人乃至更晚的构造——这正是 [[09-考古与史料|疑古与释古]]之争的核心案例。

## 考古中的二里头

| 项目 | 内容 |
|------|------|
| 发现 | 1959 年徐旭生豫西调查时发现 |
| 位置 | 河南偃师，伊洛平原 |
| 年代 | 约前 1750—前 1530（遗址）；二里头文化约前 1900—前 1500 |
| 规模 | 约 300 万平方米，中国最早的宫城（约 10.8 万平方米） |
| 关键遗存 | 大型宫殿基址（1 号、2 号）、青铜礼器作坊、绿松石龙形器、最早的青铜爵与兵器 |
| 性质 | **东亚最早的「广域王权国家」都邑**——其文化因素辐射至广大区域 |

二里头的意义在于：它第一次呈现出**跨区域的政治统合**面貌（宫城、官营手工业、礼器制度、辐射范围），这在良渚、陶寺之后是质的跃升。

## 争议：二里头 = 夏？

| 立场 | 论据 | 代表倾向 |
|------|------|---------|
| **肯定派** | 年代吻合（约前 1750—前 1530 落在[[01-先秦导论\|断代框架]]的夏晚期）、地望吻合（伊洛流域即文献「夏墟」所在）、社会发展阶段吻合（王权国家） | 可将二里头晚期直接称「夏」 |
| **谨慎派** | **迄今未发现自证性文字**（如「夏」字）；二里头文化的分布与《夏本纪》所述疆域并不严丝合缝；「夏」是后人名号，用遗址套文献名存在循环论证风险 | 主张称「二里头文化」而非「夏文化」；许宏《最早的中国》即持此谨慎态度 |

> **本库处置**：两说并列，页面与索引中一律写作「夏与二里头」，不写「夏都二里头」。**分辨一句关键话**——「二里头是早期国家」是考古共识；「二里头是夏」是**文献与考古对接的推论**，两者证据强度不同。

## 与上下文的接续

- **上游**：[[02-史前与文明起源|史前]]的多元格局中，二里头为何率先完成整合？其直接前身一般指向**新砦期**遗存（河南新密新砦），是新石器末期向二里头过渡的关键环节。
- **下游**：[[04-商与甲骨|商]]的崛起路径（汤灭夏）与二里头晚期衰落、郑州商城与偃师商城的兴起在年代上相接——**「夏商更替」的考古学界线，同样依赖文献推定**。
