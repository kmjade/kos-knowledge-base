# 09 考古与史料

> 本章是**方法论章**。前面各章的所有争论（[[03-夏与二里头|夏]]、[[05-西周：封建宗法礼乐|商周之变]]、[[08-思想与学术|诸子系统]]），最终都要落到「**我们凭什么这么说**」这个问题上。

## 先秦史的根本困难

**越早的时段，记载它的文献越晚出。** 记载夏的《史记》成书于西汉；记载西周的《诗经》成书于西周至春秋。这与「同时代记录同时代」的近代史完全不同，因而先秦史的方法论问题格外尖锐。

## 疑古：古史辨运动

| 项目 | 内容 |
|------|------|
| 提出者 | [[顾颉刚-Gu-Jiegang\|顾颉刚]] |
| 代表 | 《古史辨》（1923 年起） |
| 核心命题 | **「层累地造成的中国古史」**——时代愈后，传说的古史期愈长，中心人物愈放愈大 |
| 实例 | 禹的地位随时代上升；尧舜在孔子时尚未被系统言及 |
| 影响 | 把「三皇五帝」的整齐系统判为战国秦汉的构造 |

## 释古：二重证据法

| 项目 | 内容 |
|------|------|
| 提出者 | [[王国维-Wang-Guowei\|王国维]] |
| 表述 | 「取地下之实物与纸上之遗文互相释证」（《古史新证》，1925） |
| 首功 | 以[[甲骨文-Oracle-Bone-Script\|甲骨]]卜辞校《史记·殷本纪》，证商王世系基本可靠（1917） |
| 意义 | 证明**文献可以被出土材料验证**，从而反对一概怀疑 |

## 疑古 → 释古 → 走出疑古

| 阶段 | 主张 | 代表 |
|------|------|------|
| 信古 | 传统古史系统可信 | 传统经学 |
| 疑古 | 古史系统多为层累构造 | 顾颉刚（古史辨派） |
| 释古 | 用出土材料重新解释、检验古史 | 王国维；李学勤倡「走出疑古时代」 |

> **⚠️ 本库不代裁**：「走出疑古」自提出以来亦受到批评，被指为对疑古的过度反拨、可能滑回「信古」。**正确的态度既不是「一概信」也不是「一概疑」，而是逐条标注证据强度。**

## 证据强度分层法（本库通用）

| 层级 | 含义 | 例 |
|:--:|------|-----|
| A | 出土文字自证 | 甲骨文所记商王世系 |
| B | 同时代实物 + 文献互证 | 利簋铭文与武王克商 |
| C | 晚出文献记载，考古部分吻合 | 《夏本纪》与二里头 |
| D | 晚出文献记载，无考古对应 | 「三皇五帝」系统 |

> 使用本表时请记住：**层级是逐条判定的，不是按朝代整体套用**。同一个西周，金文属 A/B，而「周公制礼作乐」的细节属 C。

## 主要史料

### 传世典籍

| 类型 | 代表 | 使用须知 |
|------|------|---------|
| 经 | 《尚书》《诗经》《周易》 | 成书复杂，须辨伪与分层 |
| 史 | 《春秋》《左传》《国语》《战国策》《竹书纪年》 | 《竹书纪年》出土于战国墓，记事与《史记》多有异同 |
| 子 | 诸子书 | 多成于学派后学之手，须辨「书」与「人」 |
| 集 | 《楚辞》 | 与 82-1 诗歌库交叉，见 [[3 Resources/8-Literature/raw/articles/82-1-诗歌/82-1-诗歌\|82-1 诗歌]] |

### 出土文献

| 材料 | 时段 | 特点 |
|------|------|------|
| [[甲骨文-Oracle-Bone-Script\|甲骨文]] | 商 | 占卜记录，非「史书」，须由卜辞推史事 |
| 金文 | 商—战国 | 铸于礼器，涉册命、征伐、赏赐 |
| 简帛 | 战国—秦汉 | 郭店、上博、清华、马王堆、银雀山等 |
| 考古遗存 | 新石器—战国 | 城址、墓葬、器物组合，无文字自证 |

## 断代工程及其争议

**夏商周断代工程**（1996—2000）汇集历史学、考古学、天文学、测年技术，给出夏商周年代的推定表。它使本库 [[01-先秦导论|断代框架]] 有了可引用的年代，但：

- 其方法与结论**在国内外学界均受到质疑**（尤其测年精度与文献推定的结合方式）。
- 因此本库一律将相关年代标注为「**断代工程推定**」，而非史实。
