# 04 商与甲骨

## 从传说走入实证

商是先秦史中**第一个被出土文字直接证实**的王朝——这一点的分量怎么强调都不过分：它把「夏之疑」与「商之信」切成两半，也让「二重证据法」第一次有了完整的成功案例（见 [[09-考古与史料]]）。

## 基本脉络

| 阶段 | 内容 |
|------|------|
| 先商 | 商族活动于东方（豫东、鲁西南一带），屡迁 |
| 建国 | 汤（成汤）灭夏，都亳 |
| 中期 | 「九世之乱」与频繁迁都（史称「前八后五」） |
| 盘庚迁殷 | 约前 1300 年迁都于殷（今河南安阳），此后至商亡**273 年不再迁都** |
| 末亡 | 纣（帝辛）亡于牧野之战，前 1046 年 |

> 商王世系见《史记·殷本纪》。**王国维以甲骨卜辞校勘，证实《殷本纪》所记先公先王世系基本可靠**（《殷卜辞中所见先公先王考》，1917）——这是「文献可信度可用出土材料验证」的里程碑。

## 甲骨文

| 项目 | 内容 |
|------|------|
| 性质 | 商王室**占卜记录**：卜问祭祀、征伐、田猎、年成、疾病、风雨 |
| 发现 | 1899 年王懿荣辨认出甲骨上的文字；此前被当作「龙骨」入药 |
| 发掘 | 1928 年中央研究院历史语言研究所开始科学发掘殷墟 |
| 数量 | 已发现约 **15 万片**（含流散海外者） |
| 字数 | 单字约 **4500**，已释读者约 **1500** |
| 成熟度 | **已高度成熟**——六书具备，意味着它必有更早的前身，汉字起源应远早于商 |

甲骨文的成熟度反过来说明：**汉字的起源问题在商之前，而目前尚无定论**。

## 神权政治

商的政治形态通常被概括为**神权与王权的合一**：

- **至上神「帝」**：商人的至上神，具有支配自然与人间祸福的能力，但**带强烈的自然神与占卜色彩**，与周人的「天」在性质上有别（见 [[天命观-Mandate-of-Heaven|天命观]]）。
- **祭祀与占卜**：王即最高祭司，日常决策依托卜问，形成了庞大的祭祀体系。
- **人祭与人殉**：殷墟发现大量人祭、人殉遗迹，是商代宗教与权力运作的重要侧面，也是后世「殷道衰」叙事的依据之一。

## 青铜与礼制

商代的物质文明以[[青铜时代-Bronze-Age|青铜]]礼器为核心：

| 器物 | 说明 |
|------|------|
| **后母戊鼎**（旧称司母戊鼎） | 重约 832.84 公斤，现存最大最重青铜器 |
| 妇好墓出土器物 | 商王武丁配偶之墓，随葬青铜器、玉器数千件，印证甲骨中「妇好」其事 |
| 青铜礼器组合 | 爵、觚、鼎、簋等，**礼器组合即等级标识**，是后来[[礼乐制度-Li-Yue\|礼乐]]的物质基础 |

## 走向商周之变

商的灭亡常被叙述为「纣王无道」，但制度史视角更关注**周人如何解释并改造这一更替**——即「以德配天」的[[天命观-Mandate-of-Heaven|天命观]]。这一解释权的转移，是 [[05-西周：封建宗法礼乐|西周]]的核心内容，也是「商周之变」之所以被称为「中国政治与文化之变革，莫剧于殷周之际」（王国维《殷周制度论》）的原因。
