# 05 西周：封建·宗法·礼乐

> 西周是先秦制度的**定型期**。后世儒家所向往的「三代之治」，其制度模板主要来自本章的三件套：**封建、宗法、礼乐**。

## 大事脉络

| 年代（约） | 事件 |
|-----------|------|
| 前 1046 | 武王克商（牧野之战），商亡 |
| 前 1042—前 1039 | 三监之乱；周公东征平定 |
| 前 1039 前后 | **周公制礼作乐**、大规模分封 |
| 前 841 | **国人暴动**，厉王出奔，共和行政——**中国历史确切纪年之始** |

| 前 770 | 平王东迁洛邑，东周（春秋）始 |

## 一、天命观：政治合法性的原型

商人之上帝是自然神色彩浓厚的「帝」；周人则以**「天」**取代之，并注入「德」的概念：

> **天命靡常**（《诗经·大雅·文王》）——天命不固定于一家，唯有**敬德**者能保有之。

这一「**以德配天**」的逻辑，把政权更替解释为道德的裁决，是**中国政治合法性的原型**。它同时是双刃剑：既为周人克商提供正当性，也为后世「革命」（汤武革命）留下理论口子。详见 [[天命观-Mandate-of-Heaven|天命观]]。

> **争议（两说并列）**：王国维等认为「天命—德」是周人**创制**，是殷周之际最剧之变；另一派认为周人的「天」与商人的「帝」在功能上多有连续，周人主要是**继承并改造**了既有的至上神观念，以便解释政权更替。本库不裁决。

## 二、封建：封邦建国

**封建**（封邦建国）是西周的基本政治架构：王将土地与人民授予同姓、异姓贵族及先代之后，建立诸侯国，以屏藩王室。

| 要素 | 说明 |
|------|------|
| 授民授疆土 | 分封的核心是「人」与「地」同时授予，非单纯封土 |
| 对象 | 同姓（姬姓为主）、异姓功臣、先代帝王之后（如宋为殷后） |
| 义务 | 朝觐、纳贡、从征、守土 |
| 层级 | 王—诸侯—卿大夫—士，与[[宗法制-Zongfa\|宗法]]互为表里 |

**⚠️ 学术争论：封建 ≠ feudalism。** 以西语 feudalism 对译「封建」是否成立，长期有争。西周分封与西欧封君封臣制在权力结构、依附关系、契约性上差异显著（西欧的封臣—封君关系具双向契约性与军事采邑特征，西周则以血缘宗法为纽带）。本库在制度讨论中一律用「封建（封邦建国）」并标注此争论。

## 三、宗法：血缘的政治化

**宗法制**是以**嫡长子继承**为核心的亲属组织与权力继承制度：

- **大宗 / 小宗**：嫡长子继承父位为大宗，余子分封为小宗；小宗又在其支系内为大宗。
- **嫡庶之别**：正妻所生为嫡，庶子地位低于嫡子。
- **丧服制度**：以服制亲疏量化亲属关系，使血缘等级可视化。

宗法与封建是一体两面：**封建解决「地」的分配，宗法解决「人」的排序**。详见 [[宗法制-Zongfa|宗法制]]。

## 四、礼乐：制度的仪式化

**礼乐制度**把等级秩序固化为一整套可操作的仪节与乐舞：

| 层面 | 内容 |
|------|------|
| 礼 | 祭祀、朝聘、丧葬、婚冠、燕飨等仪节，按等级规定器用、数量、程序 |
| 乐 | 与礼配合的乐舞，等级不同则乐制不同 |
| 功能 | 使等级「可视、可听、可行」，把强制力转化为**习以为常的秩序感** |

> 王国维《殷周制度论》称「中国政治与文化之变革，莫剧于殷周之际」，其核心即「立子立嫡之制」「宗法」「丧服」「分封」「同姓不婚」诸端——**本章三件套正是这一判断的具体内容**。

## 五、井田与经济

**井田制**是文献所述西周土地制度：土地分「公田」「私田」，形如「井」字，八家共耕公田。详见 [[井田制-Jingtian|井田制]]。

> ⚠️ 井田制的**实际形态与是否普遍实行，学界分歧极大**（有主张为理想化描述者）。本库标注为「文献所述制度」，不作为确证史实。
