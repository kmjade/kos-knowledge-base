## 三条主线

| 主线 | 内容 |
|------|------|
| **制度线** | 多元并立 → 王权 → 封建宗法 → 霸主 → 变法郡县 |
| **思想线** | 天命与德 → 礼乐 → 礼崩乐坏 → 百家争鸣 |
| **证据线** | 传说 → 甲骨金文 → 简帛 → 二重证据法 |
