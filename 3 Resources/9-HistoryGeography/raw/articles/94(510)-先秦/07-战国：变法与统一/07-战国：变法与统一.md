# 07 战国：变法与统一

> 战国是中国历史上**第一次全面制度重组**：封建的贵族政治被郡县官僚制取代，血缘身份被军功与编户取代。秦的统一是这场重组的结果，不是起点。

## 序幕：三家分晋与田氏代齐

- 前 453 年，晋国韩、赵、魏三家灭智伯，晋国实际分裂。
- 前 403 年，周威烈王正式命三家为诸侯——**《资治通鉴》以此开篇，视为战国起点**。
- 齐国的田氏逐步取代姜姓君主（田氏代齐，前 386 年列为诸侯）。

这两件事的象征意义在于：**「封建」的合法性外壳（周天子册命）已被反用来承认篡夺**，礼制秩序名存实亡。

## 战国七雄

| 国 | 位置 | 特点 |
|----|------|------|
| 秦 | 关中 | 变法最彻底，最终统一 |
| 楚 | 江汉 | 疆域最大，地方势力强 |
| 齐 | 东方 | 经济富庶，稷下学宫所在地 |
| 燕 | 北方 | 偏处东北 |
| 韩、赵、魏 | 中原 | 三晋，地处四战之地 |

## 变法运动

| 国 | 主持者 | 主要内容 |
|----|-------|---------|
| 魏 | 李悝 | 《法经》（中国第一部比较系统的成文法典）、「尽地力之教」、平籴法 |
| 楚 | 吴起 | 削贵族、明法审令（后被贵族所杀，变法中断） |
| 秦 | **[[商鞅-Shang-Yang\|商鞅]]** | 前 356、前 350 两次变法，见下 |

### 商鞅变法（最彻底的一例）

| 领域 | 措施 |
|------|------|
| 土地 | 废井田、开阡陌，承认土地私有与买卖 |
| 军功 | 军功爵制——斩敌首者进爵，宗室无军功不得为属籍 |
| 编户 | 什伍连坐、告奸，把人口编入国家直接控制的户籍 |
| 行政 | 普遍推行县制，设令、丞，由国君任免 |
| 经济 | 重农抑商、奖励耕织、统一度量衡 |

> 商鞅本人最终被车裂，但其变法成果被秦完整继承——**这说明变法已越过了个人成败，成为国家机器的结构**。

## 三大制度转型

| 转型 | 从 | 到 |
|------|------|------|
| 行政 | 封建（分封世袭） | **郡县制**（中央任免、考课） |
| 身份 | 血缘贵族 / 国人野人 | **[[编户齐民-Registered-Commoners\|编户齐民]]**（国家直接编户的平等国民） |
| 土地 | [[井田制-Jingtian\|井田]]（公田私田） | 授田制 / 私人土地买卖 |
| 选官 | 世卿世禄 | 军功、荐举、养士 |
| 官僚管理 | — | 俸禄、上计（考绩）、玺符（授权凭证） |

> **「编户齐民」是理解中国帝制的钥匙**：国家绕开贵族，把每一个人直接登记为纳税人、兵源与劳役单位。这套技术在战国成型，秦推向全国，汉加以完善。

## 军事与战争形态

- 铁兵器普及、弩的大规模使用。
- 战争规模从春秋的「车战数百乘」升至战国的**数十万兵力对决**（如长平之战）。
- 征兵制取代贵族车战，与编户齐民互为因果。

## 合纵连横与统一

- **合纵**：六国联合抗秦（苏秦为代表）。
- **连横**：秦分化六国（张仪为代表）。
- 前 221 年，秦王政灭六国，**先秦时代结束**，[[3 Resources/9-HistoryGeography/中国史|中国史]]进入「秦汉」断代。

## 与下一断代的接口

秦的统一不是突变：**郡县制、编户齐民、军功爵、官僚考课全部来自战国**。秦所做的，是把七国的各自试验统一为一套全国制度。因此理解秦汉帝制，必须回到本章。
