# 04-课程与教学论

> 课程回答「教什么」，教学回答「怎么教」，评价回答「学得如何」。

## 课程的类型

| 维度 | 类型 |
|------|------|
| 表现形式 | 显性课程 vs 隐性课程（校园文化、师生关系） |
| 组织方式 | 分科课程 vs 综合课程 |
| 设计主体 | 国家课程 vs 地方课程 vs 校本课程 |
| 属性 | 学科课程 vs 活动课程（经验课程） |

## 课程设计：泰勒原理（Tyler）

| 步骤 | 问题 |
|:----:|------|
| 1 | 学校应达成哪些教育目标？ |
| 2 | 提供哪些经验以实现目标？ |
| 3 | 如何有效组织这些经验？ |
| 4 | 如何确定目标已实现（评价）？ |

## 教学方法

| 方法 | 特点 | 适用 |
|------|------|------|
| 讲授法 | 高效传递系统知识 | 知识传授 |
| 讨论法 | 交流碰撞、培养思维 | 开放性问题 |
| 探究/发现法 | 学生自主探索建构 | 科学、项目 |
| PBL（问题/项目式学习） | 真实问题驱动 | 综合能力 |
| 翻转课堂 | 课前自学、课上练习讨论 | 混合式 |
| 合作学习 | 小组协作、互教互学 | 社会性目标 |

## 教学评价

| 类型 | 时机 | 目的 |
|------|------|------|
| 形成性评价 | 过程中 | 改进教学（反馈） |
| 总结性评价 | 结束后 | 判定成绩/达标 |
| 过程性评价 | 全程 | 关注成长轨迹 |
| 表现性评价 | 真实任务 | 考察应用与迁移能力 |
