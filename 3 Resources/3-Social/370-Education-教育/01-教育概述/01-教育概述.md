# 01-教育概述

> 教育的本质是「有目的地培养人」的社会活动。

## 教育的定义

| 层次 | 定义 |
|------|------|
| 广义 | 一切增进人的知识、技能、身心发展、影响思想品德的活动（社会教育/家庭教育/学校教育） |
| 狭义 | 学校教育——教育者按社会要求，有目的、有计划、有组织地影响受教育者 |
| 词源 | 中国「教」= 上所施下所效，「育」= 养子使作善；西方 educate = 引出（ex-duce，由内而外引导） |

## 教育三要素

| 要素 | 作用 |
|------|------|
| 教育者 | 主导作用——设计、组织、引导 |
| 受教育者 | 主体地位——主动建构、内化 |
| 教育影响（中介） | 内容 + 手段——连接二者 |

## 教育的功能

| 维度 | 功能 |
|------|------|
| 个体发展 | 促进社会化与个性化、发展智力与品格 |
| 社会功能 | 文化传承、劳动力再生产、社会分层与流动、意识形态再生产 |
| 正/负功能 | 既可能促进，也可能固化不平等（冲突论视角） |

## 教育的历史演进

| 时期 | 特征 |
|------|------|
| 原始社会 | 教育与生产生活融合，无专职教师 |
| 古代（奴隶/封建） | 教育与生产劳动分离，产生学校，阶级性明显 |
| 近代 | 义务教育兴起、班级授课制、教育普及化 |
| 现代 | 民主化、终身化、信息化、国际化 |

## 学制系统（以中国为例）

| 学段 | 年限 | 说明 |
|------|:----:|------|
| 学前教育 | 3 年 | 幼儿园 |
| 义务教育 | 9 年 | 小学 6 + 初中 3（法定） |
| 高中阶段 | 3 年 | 普通高中 / 中职 |
| 高等教育 | 3–5+ 年 | 专科/本科/研究生 |
