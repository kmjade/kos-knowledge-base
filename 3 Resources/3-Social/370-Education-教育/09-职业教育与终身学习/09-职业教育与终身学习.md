# 09-职业教育与终身学习

> 面向职业与持续发展的教育——从职前培养到终身成长。

## 职业教育体系

| 层次 | 说明 |
|------|------|
| 中职 | 培养基础技能人才 |
| 高职（专科） | 培养技术技能人才 |
| 职业本科 | 高层次技术技能 |
| 职业培训 | 短期技能提升、转岗 |

## 核心模式

| 模式 | 说明 |
|------|------|
| 学徒制 | 工学结合、师傅带教（德国双元制典范） |
| 产教融合 | 校企合作、订单培养 |
| 现代学徒制 | 招生即招工、入校即入厂 |
| 1+X 证书 | 学历证书 + 多项职业技能等级证书 |

## 成人教育与继续教育

| 形式 | 说明 |
|------|------|
| 开放大学/夜大 | 面向成人的学历教育 |
| 继续教育 | 在职提升、知识更新 |
| 社区教育 | 面向全民的公益学习 |
| 企业内训 | 组织学习与技能培训 |

## 终身学习

| 支柱（UNESCO） | 内涵 |
|------|------|
| 学会求知 | 学习如何学习 |
| 学会做事 | 技能与胜任力 |
| 学会共处 | 协作与理解 |
| 学会生存/发展 | 自我实现与应变 |

> 终身学习是 21 世纪的核心生存能力——知识半衰期缩短，学习不再止于学校。
