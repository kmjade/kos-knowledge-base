# 02-教育哲学

> 追问「教育为了什么」——教育的目的、价值与根本假设。

## 教育目的的三种取向

| 取向 | 主张 | 代表 |
|------|------|------|
| 个人本位 | 教育的目的是促进个人完善与自我实现 | 卢梭、杜威 |
| 社会本位 | 教育服务于国家与社会需要 | 涂尔干、赫尔巴特 |
| 知识本位 | 教育是传递真知与理性的活动 | 永恒主义、古典主义 |

## 主要教育哲学流派

| 流派 | 核心主张 | 关键人物 |
|------|---------|---------|
| 进步主义 | 以儿童为中心、做中学、经验本位 | 杜威（Dewey） |
| 永恒主义 | 研读经典、培养理性、真理不变 | 赫钦斯、阿德勒 |
| 要素主义 | 回归基础知识与学科基本技能 | 巴格莱 |
| 建构主义 | 知识由学习者主动建构 | 皮亚杰、维果茨基 |
| 批判教育学 | 教育应解放被压迫者、反对灌输 | 弗莱雷（Freire） |
| 存在主义 | 教育关乎个人自由选择与责任 | 布伯、萨特 |

## 关键人物

| 人物 | 贡献 |
|------|------|
| 孔子 | 「有教无类」「因材施教」，东方教育思想源头 |
| 苏格拉底 | 产婆术（苏格拉底问答法），启发式教学 |
| 卢梭 | 「自然教育」，尊重儿童天性（《爱弥儿》） |
| 杜威 | 「教育即生活、即生长、即经验改造」 |
| 蒙台梭利 | 感官教育、有准备的环境、儿童自主 |
| 弗莱雷 | 「被压迫者教育学」，对话式教育反对灌输 |

## 关键争论

| 争论 | 两端 |
|------|------|
| 教育目的 | 个人发展 vs 社会需要 |
| 课程中心 | 儿童中心 vs 学科中心 |
| 教学方式 | 传授 vs 发现/建构 |
| 教育公平 | 均等 vs 卓越 |
