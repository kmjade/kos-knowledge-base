# 07-基础教育

> 面向全体适龄儿童少年的奠基性教育，通常指义务教育 + 高中阶段（K-12）。

## 学制与阶段

| 阶段 | 年限 | 说明 |
|------|:----:|------|
| 小学 | 6 年 | 启蒙与习惯养成 |
| 初中 | 3 年 | 义务教育终点 |
| 高中 | 3 年 | 普通高中 / 中职分流 |
| 义务教育 | 9 年 | 法定、免费、强制 |

## 核心素养（中国）

| 维度 | 内涵 |
|------|------|
| 文化基础 | 人文底蕴 + 科学精神 |
| 自主发展 | 学会学习 + 健康生活 |
| 社会参与 | 责任担当 + 实践创新 |

## 课程标准与学科

| 学科领域 | 说明 |
|------|------|
| 语文/外语 | 语言与人文 |
| 数学 | 逻辑与抽象 |
| 科学/理化生 | 科学探究 |
| 史地政 | 人文社会 |
| 体艺 | 身心与审美 |
| 信息科技 | 数字化素养、编程 |

## 评价与选拔

| 评价 | 说明 |
|------|------|
| 过程性评价 | 日常表现、作业、课堂 |
| 学业水平考试 | 达标性 |
| 中考 | 初中升高中选拔 |
| 高考 | 高中升大学选拔（高度竞争） |

## 争议与改革

| 议题 | 方向 |
|------|------|
| 应试 vs 素质 | 从分数导向转向核心素养 |
| 双减 | 减轻作业与校外培训负担 |
| 教育公平 | 城乡、区域资源均衡 |
| STEM/编程 | 早期培养数字与计算思维 |
