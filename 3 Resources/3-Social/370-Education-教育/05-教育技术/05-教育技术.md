# 05-教育技术

> 教育技术（EdTech）是运用技术优化教与学的理论与实践。本库的 RoboMaster（机甲大师）教育机器人即归于此。

## 教育技术的演进

| 阶段 | 技术 | 代表 |
|------|------|------|
| 视听教育 | 幻灯、广播、电视 | 早期电化教育 |
| 计算机辅助教学（CAI） | 课件、教学软件 | 20 世纪 80-90s |
| 网络学习 | LMS、e-learning | Blackboard、Moodle |
| 移动与混合学习 | MOOC、翻转课堂 | Coursera、edX、可汗学院 |
| 智能教育 | AI、大数据、自适应 | 智能辅导、学习分析 |

## 学习形式

| 形式 | 特点 |
|------|------|
| e-learning | 数字化在线学习，灵活自主 |
| MOOC | 大规模开放在线课程 |
| 翻转课堂 | 课前视频自学 + 课上实践讨论 |
| 混合式学习 | 线上 + 线下结合 |
| 微课/短视频 | 碎片化知识点 |

## AI 教育

| 应用 | 说明 |
|------|------|
| 个性化/自适应学习 | 按学习者水平动态调整内容与难度 |
| 智能辅导系统（ITS） | 一对一诊断与反馈 |
| 自动批改 | 作业/作文智能评分 |
| 学习分析 | 从行为数据预测学业风险 |
| 生成式 AI | 备课、出题、答疑、陪练 |

## 教育机器人（STEAM）

| 平台 | 定位 |
|------|------|
| RoboMaster（机甲大师 S1/EP） | DJI 教育机器人，Python SDK，步兵/工程机器人 |
| Tello Edu | DJI 教育无人机 |
| LEGO Mindstorms / SPIKE | 积木式编程机器人 |
| 智能小车 | DIY 移动机器人（嵌入式 + 循迹/避障） |
| Micro:Bit / Arduino | 创客教育基础硬件 |

> 教育机器人把「编程 + 机械 + 电子 + 算法」整合进项目式学习，是 STEAM 教育的典型载体。
