# 03-教育心理学

> 研究学习与教学的心理规律——人如何学习、如何促进学习。

## 学习理论四大流派

| 流派 | 核心 | 代表 |
|------|------|------|
| 行为主义 | 学习是刺激-反应的联结，强化塑造行为 | 巴甫洛夫、斯金纳、桑代克 |
| 认知主义 | 学习是信息加工与认知结构的重组 | 皮亚杰、布鲁纳、奥苏贝尔 |
| 建构主义 | 学习是学习者主动建构意义 | 皮亚杰、维果茨基 |
| 社会学习 | 观察与模仿学习 | 班杜拉 |

## 发展理论

| 理论 | 核心 | 关键概念 |
|------|------|---------|
| 皮亚杰认知发展 | 认知分阶段发展 | 感知运动→前运算→具体运算→形式运算（图式/同化/顺应/平衡） |
| 维果茨基社会文化 | 发展源于社会互动 | 最近发展区（ZPD）、支架（scaffolding） |
| 埃里克森心理社会 | 一生八大阶段 | 每一阶段有发展任务与危机 |

## 动机理论

| 概念 | 说明 |
|------|------|
| 内在 vs 外在动机 | 内在（兴趣/胜任）更持久；外在（奖励）可削弱内在动机（过度理由效应） |
| 自我效能感 | 对「我能做到」的信念，影响坚持与表现（班杜拉） |
| 归因理论 | 成功/失败归因于努力、能力、难度、运气 |
| 成长型思维 | 相信能力可通过努力发展（德韦克） |

## 教学启示

| 原理 | 应用 |
|------|------|
| 最近发展区 | 教学应略高于学生现有水平，提供支架 |
| 间隔与检索练习 | 比重复阅读更有效的记忆策略 |
| 有意义学习 | 新知识联系已有知识（先行组织者） |
| 反馈 | 及时、具体、指向改进 |
