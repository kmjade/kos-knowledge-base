# 06-学前教育

> 面向 0–6 岁儿童的教育，奠定终身发展的基础。

## 幼儿发展特点

| 维度 | 特点 |
|------|------|
| 身体 | 快速生长，大肌肉→精细动作 |
| 认知 | 前运算阶段（皮亚杰）：自我中心、直觉思维、泛灵论 |
| 语言 | 词汇爆发期，从单字到完整句 |
| 社会性 | 从平行游戏到合作游戏，建立同伴关系 |

## 主要教育理念

| 理念 | 核心 | 关键要素 |
|------|------|---------|
| 蒙台梭利 | 有准备的环境、儿童自主 | 感官教具、混龄、教师为观察者 |
| 瑞吉欧 | 儿童的一百种语言 | 项目式探究、环境即第三位教师 |
| 华德福 | 尊重身心发展节奏 | 艺术化教学、无早期识字 |
| 高瞻（HighScope） | 主动学习 | 计划-工作-回顾循环 |

## 游戏本位学习

| 游戏类型 | 说明 |
|------|------|
| 机能性游戏 | 重复动作（跑、跳） |
| 建构性游戏 | 搭积木、拼图 |
| 象征性游戏 | 假装/角色扮演 |
| 规则性游戏 | 有规则的小组游戏 |

> 游戏是幼儿的主导活动——「玩中学」是学前教育的基本方式。

## 幼小衔接

| 关注点 | 做法 |
|------|------|
| 学习准备 | 注意力、任务意识、前书写/前阅读 |
| 社会适应 | 规则意识、同伴交往、情绪管理 |
| 生活自理 | 作息、整理、自我服务 |
| 去小学化 | 避免过早灌输学科知识 |
