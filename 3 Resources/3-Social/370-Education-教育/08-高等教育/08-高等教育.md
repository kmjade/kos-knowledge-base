# 08-高等教育

> 建立在中等教育之上的专业与学术教育，承担教学、科研与社会服务三大职能。

## 大学的三大功能

| 功能 | 说明 |
|------|------|
| 教学（人才培养） | 培养专业人才与公民 |
| 科研（知识生产） | 原创研究与知识创新 |
| 社会服务 | 成果转化、智库、继续教育 |

## 通识教育 vs 专业教育

| 维度 | 通识教育 | 专业教育 |
|------|---------|---------|
| 目标 | 培养完整的人、批判思维 | 培养专业能力 |
| 内容 | 跨学科基础、人文科学 | 学科深度知识 |
| 关系 | 互补——通识提供广度，专业提供深度 | |

## 学位与层次

| 层次 | 学位 | 年限 |
|------|------|:----:|
| 专科 | 大专 | 3 年 |
| 本科 | 学士 | 4–5 年 |
| 硕士 | 硕士 | 2–3 年 |
| 博士 | 博士 | 3–5+ 年 |

## 研究型 vs 应用型高校

| 类型 | 定位 | 侧重 |
|------|------|------|
| 研究型 | 学术研究、基础创新 | 科研、研究生培养 |
| 应用型 | 服务产业、技能应用 | 实践、就业导向 |
| 职业本科 | 高层次技术技能 | 产教融合 |

## 关键议题

| 议题 | 说明 |
|------|------|
| 学术自由 | 大学自治与思想自由 |
| 质量保障 | 认证、评估、排名 |
| 普及化 | 高等教育大众化→普及化 |
| 国际化 | 留学、合作办学、全球排名 |
