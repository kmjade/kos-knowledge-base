# 訂單流 Order Flow

## 定義

訂單流（Order Flow）是**市場微結構**層面的分析方法，通過追蹤每一筆交易或每一個 Tick 的**主動買單與主動賣單**來判斷市場的即時供需失衡。不同於傳統 K 線技術分析（只看價格的起點和終點），訂單流關注交易發生的**過程**：

```
傳統 K 線：  Open ——— High/Low ——— Close  （只看結果）
訂單流：     每一筆交易的買/賣方向、數量、時間  （追蹤過程）
```

### 核心理念

```
價格變動 = 供需失衡的結果
訂單流   = 供需失衡的即時測量

主動買單 > 主動賣單 → 價格上漲
主動賣單 > 主動買單 → 價格下跌
主動買單 = 主動賣單 → 價格橫盤
```

---

## 訂單流的核心工具

### 1. Delta（買賣差額）

```
Delta = 主動買單量 − 主動賣單量

正 Delta = 買方主導
負 Delta = 賣方主導
```

- **累積 Delta (CVD)** → [[CVD-Indicator]]
- 單根 K 線的 Delta → 判斷該 K 線的實際買賣壓力

### 2. Footprint Charts（足跡圖）

Footprint 圖表將每根 K 線的成交量**按價格水平**分解，顯示每個價位的買賣量：

```
標準 K 線：      單一 OHLC
Footprint K 線：  每個 Tick 價位的買量 vs 賣量

示例（橫向足跡）：
價格    買量    賣量    Delta
3800    1,245   892     +353
3799    1,102   1,301   −199
3798    567     2,103   −1,536  ← 大量拋售
3797    234     1,876   −1,642  ← 止損踩踏
```

| 足跡模式 | 含義 |
|:---------|------|
| **POC** (Point of Control) | 成交量最大的價格水平，即市場認可的公允價值 |
| **VA** (Value Area) | 成交量佔 70% 的價格區間（POC 上下） |
| **High Volume Node** | 大量成交的價格位 → 未來的支撐/阻力 |
| **Low Volume Node** | 成交量空洞 → 價格容易快速通過 |
| **Delta Divergence** | 價格突破但 Delta 未跟進 → 假突破 |

### 3. DOM（Depth of Market / 市場深度）

DOM 顯示當前掛單（Limit Orders）的分佈：

```
賣方掛單 (Ask Side)
┌──────────────────────────────┐
│ 3802    500                  │
│ 3801    1,200                │ ← 賣方流動性聚集
│ 3800    3,500 ← ↓↓↓          │ ← 強阻力
├──────────────────────────────┤
│         當前價 3798           │
├──────────────────────────────┤
│ 3797    2,100 ← ↑↑↑          │ ← 強支撐
│ 3796    800                  │
│ 3795    300                  │
└──────────────────────────────┘
買方掛單 (Bid Side)

解讀：
- 厚牆 (Thick Wall) = 大量掛單 → 可能是真正的支撐/阻力
- 薄牆 (Thin Wall) = 少量掛單 → 容易被突破
- 吸單 (Iceberg) = 隱藏掛單 → 大戶隱藏真實意圖
```

### 4. Tape Reading（行情紙帶閱讀）

Tape Reading 是訂單流最原始的形式——逐筆觀察交易：

```
觀察維度：
1. 交易速度：快 → 市場情緒強烈
2. 單筆大小：大單 → 機構參與
3. 買賣方向：主動買 vs 主動賣
4. 連續性：持續單向 → 趨勢；反覆 → 盤整

典型 Tape Reading 信號：
- "吸籌"：價格橫盤，但持續出現大額主動買單 → 蓄力上漲
- "派發"：價格上漲，但持續出現大額主動賣單 → 即將下跌
- "止損獵殺"：價格快速打穿關鍵位後迅速收回 → 假突破
```

## 訂單流的關鍵信號

### 吸收 Absorption

```
現象：價格橫盤 / 窄幅震盪，但 Delta 持續偏離（大量買/賣被吸收）
含義：一方在默默累積倉位，另一方在提供流動性
行動：突破方向 = 吸收方的方向
```

### 高潮 Climax

```
現象：Delta 急劇放大 + 成交量暴增 + 長影線
含義：一方力量衰竭（投降式交易）
行動：準備反轉
```

### 失衡 Imbalance

```
現象：連續多根 K 線的 Delta 都 > 閾值（或 < 負閾值）
含義：單邊力量持續主導
行動：順 Delta 方向交易
```

## 多時間框架訂單流分析

```
趨勢框架（4H / D1）：
  ├── 確定主要的多空方向
  ├── POC 作為關鍵支撐/阻力
  └── VA 區間作為價值區域

入場時機（M15 / M5）：
  ├── 吸收/失衡信號
  ├── Delta 背離確認
  └── 大單突破跟進

出場/風控：
  ├── POC 作為止損參考
  ├── High Volume Node 作為目標位
  └── Delta 反轉作為離場信號
```

## 常見機構訂單流策略

| 策略 | 原理 | 時間框架 |
|:----|------|:--------:|
| **吸收突破** | 識別吸收後跟隨突破方向 | M15+ |
| **POC 回測** | POC 是公允價值，價格偏離後回歸 | 任意 |
| **Delta 背離** | 價格 v.s. Delta 背離 → 反轉 | M5+ |
| **流動性獵殺** | 價格掃止損後反轉（雙底/雙頂） | M5 |
| **大單跟蹤** | 追蹤機構大單的方向 | Tape |

## 訂單流 vs 傳統技術分析

| 維度 | 傳統 TA | 訂單流 |
|:----|:-------|:------|
| 數據 | OHLC + Volume | Tick、Delta、DOM、足跡 |
| 時間粒度 | K 線（M1~MN） | 逐筆交易 |
| 信號類型 | 型態、指標交叉 | 供需失衡、吸收、背離 |
| 核心問題 | "價格在哪裡" | "資金在做什麼" |
| 適用市場 | 所有 | 期貨、股票 (有 Level 2) |
| 外匯適用性 | ✅ 完全適用 | ⚠️ 限於 Tick Volume 近似 |
