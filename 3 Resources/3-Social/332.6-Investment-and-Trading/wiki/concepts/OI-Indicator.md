# OI 指標 OI Indicator (Open Interest / 持倉量)

## 定義

OI（未平倉合約 / Open Interest）是**期貨和期權市場**特有的指標，表示在某特定時間點**尚未平倉的合約總數**。每一張合約都有買方和賣方，OI 計算的是這類合約的總對數。

```
OI = 所有未平倉的買方(或賣方)合約總數

OI 增加 = 新資金流入市場（新買方 + 新賣方）
OI 減少 = 資金退出市場（既有買方平倉 + 既有賣方平倉）
OI 不變 = 倉位轉移（既有賣方→新買方，或新賣方→既有買方）
```

> **與成交量的區別**：
> - **Volume** = 一定時間內的交易活躍度（流量）
> - **OI** = 市場中尚未了結的倉位總量（存量）

---

## 價格 × OI 四象限框架

OI 最有價值的用法是與價格趨勢結合分析，形成**四象限框架**：

```
                OI 增加（資金流入）          OI 減少（資金流出）
                ─────────────────     ─────────────────
價格上漲  │  🟢 強勢上漲              🟡 弱勢反彈
          │  新多頭資金進場           空頭回補 / 多頭獲利了結
          │  趨勢健康，可持有         趨勢可能反轉
          │
價格下跌  │  🔴 強勢下跌              🟢 跌勢尾聲
          │  新空頭資金進場           多頭停損 / 空頭獲利了結
          │  趨勢健康，宜做空         趨勢可能見底
```

### 四象限詳解

| 象限 | 價格 | OI | 市場含義 | 行動 |
|:----:|:----:|:--:|---------|:----:|
| **①** | ↑ | ↑ | **強勢上漲** — 多頭建立新倉，新資金流入 | 🟢 持有多單 / 加倉 |
| **②** | ↑ | ↓ | **弱勢反彈** — 空頭回補或存量多頭獲利離場 | ⚠️ 減倉 / 準備做空 |
| **③** | ↓ | ↑ | **強勢下跌** — 空頭建立新倉，新資金流入 | 🔴 持有空單 / 加倉 |
| **④** | ↓ | ↓ | **跌勢尾聲** — 多頭停損或存量空頭獲利離場 | ⚠️ 減倉 / 準備做多 |

### 極端值信號

| 信號 | 條件 | 含義 |
|------|------|------|
| **OI 創歷史新高** | OI 遠高於過去 N 期均值 | 市場極度活躍，波動可能加劇 |
| **OI 驟降 > 20%** | 單日 OI 大幅減少 | 大規模平倉（黑天鵝事件或交割日臨近） |
| **OI 與價格分歧** | 價格創新高但 OI 停滯/下降 | 上漲無新資金跟進 → 反轉風險 |
| **OI 續增但價格橫盤** | OI ↑, Price 持平 | 多空正在蓄力 → 即將突破 |

---

## OI 的增減含義

### OI 增加 → 新資金流入

| 情境 | 解釋 |
|------|------|
| 新買方開多 + 新賣方開空 | 雙方都建立新倉，市場參與度提升 |
| 趨勢中 OI 增加 | 趨勢獲得確認，動能可能持續 |
| 盤整中 OI 增加 | 市場在累積倉位，醞釀突破 |

### OI 減少 → 資金流出

| 情境 | 解釋 |
|------|------|
| 既有買方平多 + 既有賣方平空 | 雙方都在離場，市場冷卻 |
| 趨勢中 OI 減少 | 趨勢缺乏信心，可能反轉 |
| 大幅上漲後 OI 驟降 | 多頭獲利了結 → 回調風險 |

### OI 不變 → 存量博弈

| 情境 | 解釋 |
|------|------|
| 新買方開多 + 既有賣方平空 | 多方換手，但總量未變 |
| 既有買方平多 + 新賣方開空 | 空方換手，但總量未變 |

## OI 與成交量對比

| 情境 | Volume | OI | 含義 |
|:----:|:------:|:--:|------|
| 突破新高 | 放量 ↑ | 增加 ↑ | ✅ 有效突破，跟進 |
| 突破新高 | 放量 ↑ | 減少 ↓ | ⚠️ 假突破（獲利了結），反轉 |
| 大跌 | 放量 ↑ | 劇減 ↓↓ | 🛑 多頭投降式平倉（賣壓高峯，可能見底） |
| 緩跌 | 縮量 ↓ | 減少 ↓ | 🔄 多頭緩慢離場，跌勢可能持續 |

## OI 的市場差異

| 市場 | OI 可用性 | 數據來源 | 說明 |
|:----|:---------:|---------|------|
| **期貨** | ✅ 核心指標 | 交易所每日公佈 | OI 的原始應用場景 |
| **期權** | ✅ 核心指標 | 交易所每日公佈 | Call/Put OI 可計算 PCR |
| **股票** | ⚠️ 有限 | 交易所 Level 2 | 部分市場提供總持倉 |
| **外匯** | ❌ 無 OI | COT 報告（替代） | 外匯分散式市場無統一 OI |
| **加密貨幣** | ✅ 有 | 各交易所 API | 永續合約 OI（常用） |

### 外匯市場的 OI 替代方案

外匯是分散式場外市場（OTC），無中心交易所，因此**沒有真正的 OI 數據**。替代方案：

| 替代指標 | 說明 | 頻率 |
|---------|------|:----:|
| **COT 報告** | CFTC 每週公佈的期貨持倉數據（芝加哥交易所的外匯期貨） | 每週五 |
| **Tick Volume** | MT4 的 Tick 次數（活躍度代理） | 即時 |
| **CVD** | 累積成交量差值（買賣壓力代理） | 即時 |

## MQL4 實現

### 內置函數

MQL4 無內建 OI 函數。外匯 EA 無法直接獲取 OI，以下方法僅適用於**期貨市場**的 MetaTrader 版本：

```cpp
// 若經紀商提供 OI（部分期貨經紀商支援）
// 可以通過 iCustom 或自定義數據源獲取
// 以下為 OI 四象限分析邏輯框架

enum ENUM_OI_QUADRANT
{
   OI_Q1_BULL_STRONG = 1,   // Price↑ OI↑  強勢上漲
   OI_Q2_BULL_WEAK  = 2,   // Price↑ OI↓  弱勢反彈
   OI_Q3_BEAR_STRONG = 3,   // Price↓ OI↑  強勢下跌
   OI_Q4_BEAR_WEAK  = 4    // Price↓ OI↓  跌勢尾聲
};

// OI 四象限判斷
ENUM_OI_QUADRANT OI_Quadrant(double priceNow, double pricePrev,
                               double oiNow, double oiPrev)
{
   bool priceUp = (priceNow > pricePrev);
   bool oiUp = (oiNow > oiPrev);
   
   if (priceUp && oiUp)    return OI_Q1_BULL_STRONG;
   if (priceUp && !oiUp)   return OI_Q2_BULL_WEAK;
   if (!priceUp && oiUp)   return OI_Q3_BEAR_STRONG;
   if (!priceUp && !oiUp)  return OI_Q4_BEAR_WEAK;
   
   return -1; // 數據相同
}
```

## COT 報告中的 OI 分析

COT（Commitment of Traders）報告由 CFTC 每週五公佈，包含外匯期貨的 OI 和持倉分類：

### 主要持倉分類

| 類別 | 說明 | 信號含義 |
|------|------|---------|
| **商業（商業）** | 避險者（銀行/企業） | 通常逆勢操作 |
| **非商業（投機）** | 投機者（對沖基金） | 趨勢跟隨者 |
| **非報告（零售）** | 小型交易者 | 通常接盤 |

### 極端持倉信號

```
非商業淨多單 創歷史新高 → 散戶過度看多 → 反轉風險 ↑
非商業淨空單 創歷史新高 → 散戶過度看空 → 反轉風險 ↑
```

## 參數建議

| 場景 | 建議設定 | 說明 |
|:----|:--------:|------|
| OI 變化率閾值 | ±10% | 超過此值視為顯著變化 |
| OI 趨勢線週期 | 5-10 日 | 判斷 OI 的趨勢方向 |
| 價格-OI 背離確認 | 連續 2-3 日 | 避免單日噪音信號 |
| COT 報告極端值 | 歷史百分位 > 90% | 反轉信號觸發條件 |

---

## 限制與注意事項

1. **外匯無 OI** — OI 最適合期貨市場。外匯交易者需透過 COT 報告或 CVD/Tick Volume 替代。
2. **延遲性** — COT 報告延遲 3 天公佈（持倉截止日為週二，公佈日為週五）。
3. **資料頻率** — OI 通常為每日數據，無法用於日內交易。
4. **品種差異** — 農產品、金屬、能源、金融期貨的 OI 行為模式不同。
5. **到期日效應** — 合約到期前 OI 會自然下降（移倉換月），非資金流出信號。
