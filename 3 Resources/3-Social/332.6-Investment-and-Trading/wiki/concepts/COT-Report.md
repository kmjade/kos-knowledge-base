# COT 报告

> Commitment of Traders (COT) 是由美國商品期貨交易委員會（CFTC）每週發佈的期貨市場持倉報告，展示不同類型交易者的多空持倉分佈。

---

## 發佈資訊

| 項目 | 說明 |
|------|------|
| 發佈機構 | CFTC（美國商品期貨交易委員會） |
| 頻率 | 每週 |
| 持倉截止日 | 每週二收盤 |
| 公佈日 | **每週五** 15:30 ET |
| 數據跨度 | 1986 年至今 |
| 涵蓋市場 | 農產品、能源、金屬、外匯、股指、國債期貨 |

## 報告類型

| 報告 | 分類 | 適合品種 |
|------|------|---------|
| **Legacy（傳統）** | 商業 / 非商業 / 不可報告 | 商品期貨（基礎分析） |
| **Disaggregated（細分）** | 生產商/貿易商 / 互換交易商 / 管理資金 / 其他 | 商品期貨（**推薦**） |
| **TFF（金融期貨）** | 金融期貨專用分類 | 外匯 / 股指 / 國債 |
| **CIT（商品指數）** | 商品指數交易者補充 | 指數型商品 |

## 核心概念

- **商業持倉** (Commercial)：套期保值者（生產商、用戶），以避險為目的
- **非商業持倉** (Non-Commercial)：投機者（對沖基金、趨勢跟蹤者），**主要分析對象**
- **不可報告持倉** (Non-Reportable)：小型交易者，通常反向指標
- **未平倉量** (Open Interest)：市場總持倉合約數

## 常用特徵

| 特徵 | 計算方式 | 信號含義 |
|------|---------|---------|
| 淨非商業持倉 | 多頭 - 空頭 | 機構看多/看空程度 |
| COT Index | (當前 - 最小值)/(最大值 - 最小值) | 0-1 範圍，>0.9 超買，<0.1 超賣 |
| 偏度 (Bias) | (多-空)/(多+空) | [-1, 1]，方向強度 |
| 管理資金佔比 | 管理資金持倉 / 總 OI | 機構參與度 |
| 持倉變化率 | 週環比變化 | 持倉動能 |
