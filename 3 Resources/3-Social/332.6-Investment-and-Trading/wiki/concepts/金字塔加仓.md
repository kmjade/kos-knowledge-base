# 金字塔加仓 Pyramid Position Adding

> 趋势确认后逐步加码，而非一次性全仓。—— 海龟交易法则核心头寸管理策略

---

## 定义

金字塔加仓是 **趋势跟踪系统** 中的头寸构建方法。初始头寸建立后，当价格朝有利方向移动一定距离（通常以 ATR 为单位），就追加一个单位，最多追加到预设上限（海龟标准为 4 单位）。

核心特征：
- **顺势加仓** —— 只在已有浮盈时加仓，绝不逆势摊平
- **步进触发** —— 每达到一个阈值才加一单，非一次性建仓
- **波动率自适应** —— 步长以 ATR 为单位，波动大时步长自动放大

---

## 数学模型

### 加仓触发公式（海龟标准）

```
第 N 次加仓触发价 = 入场价 ± N × 0.5 × ATR

其中：
  N   = 当前已持仓单位数（第 1 单 N=0，第 2 单 N=1, ...）
  ATR = 当前平均真实波幅（20 周期）
```

### 触发序列示例

假设多头入场价 1.1050，ATR = 0.0020（20 点）：

| 单位 | 触发价 | 距入场 | 累计暴露 |
|:----:|:------|:------|:--------|
| 第 1 单 | 1.1050（突破入场） | 0 | 1 单位 |
| 第 2 单 | 1.1060（+0.5 ATR） | +10 点 | 2 单位 |
| 第 3 单 | 1.1070（+1.0 ATR） | +20 点 | 3 单位 |
| 第 4 单 | 1.1080（+1.5 ATR） | +30 点 | 4 单位 |

间距恒定为 **0.5 ATR**，但触发门槛逐级递增。

### 平均持仓成本

满仓 4 单位后，平均入场价：

```
平均成本 = (1.1050 + 1.1060 + 1.1070 + 1.1080) / 4 = 1.1065
```

即平均成本在入场价上方 **0.75 ATR** 处。止损设在入场价 - 2.0 ATR = 1.1010 时，满仓止损亏损 ≈ 1.25 ATR × 4 单位，而非 4 × 2.0 ATR。

## 仓位结构

```
价格 ↑
          ██      ← 第 4 单（距入场 +1.5 ATR, 浮盈最大）
        ████      ← 第 3 单（距入场 +1.0 ATR）
      ██████      ← 第 3 单（距入场 +0.5 ATR，浮盈最小）
    ████████      ← 第 1 单（入场价，浮盈最深）
    
    ← 越上方的仓位在趋势反转时越安全（浮盈保护层厚）
    ← 所有单位在出场信号触发时同时平仓
```

## 实现方式

### 加仓检测时机

海龟系统的加仓检测与其他信号不同：

| 信号 | 检测频率 |
|:----|:---------|
| 入场信号（突破） | 仅 **新 K 线** 开盘 |
| 出场信号（反向突破） | 仅 **新 K 线** 开盘 |
| **加仓信号** | **每个 Tick**（盘中实时） |

### 典型流程（TurtleTrader 架构）

```
① 新 K 线: Donchian 通道突破 → BuyStop 成交，1 单位入场
② 盘中 Tick: 检测 Bid >= 入场价 + 1 × 0.5 × ATR → 市价加仓第 2 单
③ 盘中 Tick: 检测 Bid >= 入场价 + 2 × 0.5 × ATR → 市价加仓第 3 单
④ 盘中 Tick: 检测 Bid >= 入场价 + 3 × 0.5 × ATR → 市价加仓第 4 单
⑤ 新 K 线: 检测反向突破 → 全部平仓出场
```

### 防重复触发机制

```cpp
// 关键保护：m_lastAddPrice 记录上一次加仓触发价
double stepPrice = m_entryPrice + m_currentUnits * m_addStepATR * atr;
if (triggered && m_lastAddPrice != stepPrice) { /* 允许加仓 */ }
```

## 与其它加仓方法对比

| 维度 | 金字塔（顺势） | 等距网格（逆势） | 马丁格尔（逆势加倍） |
|:----|:-------------|:---------------|:------------------|
| 方向 | 顺趋势 | 逆趋势（反弹交易） | 逆趋势摊平 |
| 间距 | 0.5 ATR（波动率自适应） | 固定点数 | 固定点数 |
| 手数 | 等量或递减 | 等量 | 指数递增（2ⁿ） |
| 浮亏保护 | 有（已有浮盈缓冲） | 无（浮亏累积） | 无（浮亏指数增长） |
| 胜率 | < 40% | 50-60% | > 90%（但输一次即爆仓） |
| 盈亏比 | 极高（3:1 ~ 10:1） | 中（1:1 ~ 2:1） | 低（单次亏损吃掉 N 次盈利） |
| 适用行情 | 强趋势 | 震荡/弱趋势 | 震荡（不可用于趋势） |

## 变体

### 等量金字塔（标准海龟）

每单手数相等（如各 0.1 手），总暴露呈阶梯状，是实际上的"矩形"加仓。你的代码库中 [[TurtleTrader架构文档]] 和自有 EA 框架均采用此方式。

### 减量金字塔（改进型）

从第 3 单位开始递减手数：

| 单位 | 标准等量 | 减量（建议） |
|:----:|:--------:|:-----------:|
| 第 1 单 | 1.0 单位 | 1.0 单位 |
| 第 2 单 | 1.0 单位 | 1.0 单位 |
| 第 3 单 | 1.0 单位 | 0.7 单位 |
| 第 4 单 | 1.0 单位 | 0.5 单位 |

**效果：** 尾部轻仓降低趋势末段反转的冲击，满仓暴露从 4.0 降至 3.2。

### 几何金字塔（激进型）

步长指数递增（0.5N → 1.0N → 2.0N），手数指数递减。适合资金充裕的长期趋势交易。

## 风控协同

### 止损规则（2.0 ATR 硬止损）

```
止损价 = 首单入场价 ± 2.0 × ATR
```

注意：加仓后止损 **不跟随移动**，直到出场信号触发。

### 净风险分析

满仓 4 单位时，止损触发亏损 ≈ 1.25 ATR × (4 单位手数总和)，远小于 4 个独立头寸止损的理论最大值 8.0 ATR。

### 熔断规则

高阶实现（如 TurtleTrader 的 RiskManager）还会加入：
- **日亏损熔断**（5%）：一日亏损超阈值暂停交易
- **连损熔断**（3 次）：连续亏损后暂停
- **ATR 成本熔断**：ATR 过高时暂停（成本占比超标）

## 常见陷阱

| 陷阱 | 说明 |
|:----|:------|
| 加仓价位检查缺失 | buy 侧缺少 `ask > triggerPrice` 检查会导致同一 Tick 重复加仓（参见内部工单记录） |
| 震荡市反复加仓 | 不具备趋势识别过滤器时，假突破 + 加仓会放大亏损 |
| 资金不足 | 4 单位金字塔需较大保证金，部分品种（如 USWTI）波动大时易爆 |
| 心态陷阱 | 浮盈回吐的心理压力 > 浮亏，需严格机械执行 |
