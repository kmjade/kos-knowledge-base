# 三大加仓方法论

> 金字塔、马丁格尔、网格——三种截然不同的加仓哲学，对应三种市场观。

---

## 总览对比

| 维度 | [[金字塔加仓\|金字塔 Pyramid]] | 马丁格尔 Martingale | 网格 Grid |
|:----|:------------------------|:-------------------|:---------|
| **方向** | 顺趋势加仓 | 逆势加仓（亏损翻倍） | 双向挂单 |
| **核心逻辑** | 浮盈加码，让利润奔跑 | 输了加倍，一次翻本 | 价格回归，震荡套利 |
| **间距** | 0.5 ATR（波动率自适应） | 固定点数 | 固定点数 |
| **手数变化** | 等量 / 递减 | 指数递增（2ⁿ） | 等量 |
| **胜率** | < 40% | > 90%（单次） | 50-60% |
| **盈亏比** | 极高（3:1 ~ 10:1） | 极低（1:1） | 中（1:1 ~ 2:1） |
| **爆仓风险** | 中 | **极高** | 中高（单边行情） |
| **适用行情** | 强趋势 | 震荡（理论） | 震荡 |
| **最差行情** | 长期震荡 | 单边趋势 | 单边趋势 |
| **资金需求** | 中高 | 中（需深口袋） | 高 |
| **心理压力** | 浮盈回吐 | 浮亏深渊 | 持续钝痛 |

## 方法论一：金字塔加仓（顺势）

### 核心思想

趋势确认后建立初始头寸，价格朝有利方向移动 **每 0.5 ATR** 追加一单位，最多 4 单位。

### 数学表达

```
第 N 次加仓触发价 = 入场价 ± N × 0.5 × ATR
满仓平均成本 ≈ 入场价 ± 0.75 × ATR
```

### 关键特征

- **有浮盈保护**：加仓时已有利润缓冲
- **低胜率高盈亏比**：单次趋势可覆盖多次小额试错
- **波动率自适应**：ATR 增大时步长自动扩大

### 典型参数

| 参数 | 海龟标准 | 说明 |
|:----|:--------:|:----|
| 最大单位 | 4 | 单方向最多加仓次数 |
| 加仓步长 | 0.5 ATR | 一步一单 |
| 硬止损 | 2.0 ATR | 首单入场价 ± 2 ATR |
| 出场 | 反向 Donchian 突破 | 新 K 线判断 |

### 代表人物

Richard Dennis、Curtis Faith（海龟交易实验）

### 优劣势

| 优势 | 劣势 |
|:----|:----|
| 趋势行情中利润最大化 | 震荡市中反复止损 |
| 回撤可控（有浮盈缓冲） | 回撤期长达 6-12 个月 |
| 适合大资金容量 | 需极大心理纪律 |

> 详见 [[金字塔加仓]]

## 方法论二：马丁格尔（逆势加倍）

### 核心思想

每次亏损后，将下一单的 **手数加倍**，直到盈利一次——单次盈利覆盖所有累积亏损，然后重置。

### 数学表达

```
第 N 次加仓手数 = 初始手数 × 2^(N-1)
总亏损 = 初始手数 × (2^N - 1)
一次盈利覆盖 = 当前手数 × 止盈点数
```

### 示例（EURUSD，初始 0.01 手，间距 10 点）

| 次数 | 手数 | 累计浮亏 | 价格方向 | 备注 |
|:----:|:----:|:--------:|:--------|:----|
| 第 1 次 | 0.01 | -1.0 点值 | 开仓做多 | |
| 第 2 次 | 0.02 | -3.0 点值 | 跌 10 点加倍 | |
| 第 3 次 | 0.04 | -7.0 点值 | 跌 20 点再加倍 | |
| 第 4 次 | 0.08 | -15.0 点值 | 跌 30 点 | |
| 反弹 10 点 | 0.08 盈利 | **+8.0 点值** | 一次翻本 + 盈利 | 净盈利 = 8 - 7 = +1.0 |

### 关键特征

- **极高单次胜率**：理论上只要不止损，价格总会回归一次
- **一次回本**：一次盈利覆盖所有亏损
- **指数风险**：亏损次数增加时，手数指数倍膨胀
- **深口袋需求**：需准备充裕资金应对最坏情况

### 风险模型：连亏 N 次后的资金需求

| 连亏次数 | 手数 | 单次亏损 | 累计亏损 | 所需保证金 |
|:-------:|:----:|:--------:|:--------:|:----------:|
| 1 | 0.01 | -$1.0 | -$1.0 | $10 |
| 2 | 0.02 | -$2.0 | -$3.0 | $20 |
| 3 | 0.04 | -$4.0 | -$7.0 | $40 |
| 4 | 0.08 | -$8.0 | -$15.0 | $80 |
| 5 | 0.16 | -$16.0 | -$31.0 | $160 |
| 6 | 0.32 | -$32.0 | -$63.0 | $320 |
| 7 | 0.64 | -$64.0 | -$127.0 | $640 |
| 8 | 1.28 | -$128.0 | -$255.0 | $1,280 |
| 9 | 2.56 | -$256.0 | -$511.0 | $2,560 |
| 10 | 5.12 | -$512.0 | -$1,023.0 | $5,120 |

> 连续 10 次亏损只需 1,023 点单边行情（EURUSD 约 100 点）。

### 常见变体

| 变体 | 新增规则 | 效果 |
|:----|:---------|:----|
| **反马丁格尔** | 盈利时加倍，亏损时重置 | 趋势中放大利润，但震荡中频繁小额亏损 |
| **软马丁格尔** | 加仓倍率 < 2（如 1.5×） | 降低指数增长斜率，容错次数更多 |
| **分段马丁格尔** | 设最大连亏次数（如 stop after 5 losses） | 截断尾部风险 |
| **带止损马丁格尔** | 连亏达 N 次后硬止损出局 | 防止无限亏损 |

### 优劣势

| 优势 | 劣势 |
|:----|:----|
| 理论胜率极高 | 一次黑天鹅即爆仓 |
| 逻辑简单，易编程 | 资金需求指数增长 |
| 震荡市稳定盈利 | 趋势市必死 |

> **结论：** 马丁格尔不应用于真实趋势市场。仅适合震荡区间可控的品种，且必须设硬止损。

## 方法论三：等距网格（双向挂单）

### 核心思想

在预设价格区间内，以 **固定点数间距** 双向挂 Buy Stop / Sell Stop 订单。价格穿过一层就成交一层，吃固定止盈（或利用对冲机制锁利）。

### 工作原理

```
价格区间: 1.1000 — 1.1100
网格间距: 10 点
层数:     11 层（含上下边界）

        1.1100 ─── Sell Limit 区
        1.1090 ──┬─ Sell Stop
        1.1080 ──┤
        1.1070 ──┤
        1.1060 ──┤
        1.1050 ──┼─ 中线（初始价格）
        1.1040 ──┤
        1.1030 ──┤
        1.1020 ──┤
        1.1010 ──┴─ Buy Stop
        1.1000 ─── Buy Limit 区
```

价格上涨时触发 Sell Stop 开空仓，下跌时触发 Buy Stop 开多仓。每个仓位设固定止盈（如 10 点），网格自动运行。

### 盈亏模型

```
网格盈利 = 成交次数 × 间距点数 × 手数 × 每点价值

处于网格区间的震荡：价格每穿越一层，盈利一层
突破网格区间的趋势：突破方向的所有逆向仓位全部浮亏，形成"浮亏墙"
```

### 三种网格变体

| 变体 | 机制 | 趋势适应性 |
|:----|:----|:----------|
| **经典网格** | 双向挂单，各自止盈 | 弱（突破即崩溃） |
| **顺势网格** | 只在网格一侧挂单向单（如只挂 Buy Stop） | 中（方向选对时） |
| **动态网格** | 网格区间随移动平均线漂移 | 较强 |

### 优劣势

| 优势 | 劣势 |
|:----|:----|
| 震荡市自动化盈利 | 单边行情一突破即爆仓 |
| 免盯盘，机械运行 | 网格参数难优化（间距/区间/手数） |
| 胜率稳定（50-60%） | 浮亏起风暴时心理压力大 |
| 多种 EA 商业产品使用 | 一次大趋势可吃掉数月盈利 |

> 你的代码库中的 **EasyGo** 商业产品即基于网格/套利策略。

## 三者在不同市场环境的表现

### 强趋势市场

```
收益曲线:
金字塔: ─────────────────── ↗  (大幅盈利)
马丁格尔: ─────── ↘↘↘ 爆仓  (死亡)
网格:    ─────── ↘ 浮亏墙    (深度浮亏)
```

### 震荡市场

```
收益曲线:
金字塔: ─↗↘↗↘↗↘─── ─ (反复止损, 小幅亏损)
马丁格尔: ─↗↗↗↗↗───  (连续盈利, 稳定增长)
网格:    ─↗↗↗↗↗───  (每层吃止盈, 稳定增长)
```

### 弱趋势市场

```
收益曲线:
金字塔: ─↗↘↗↘─ ──── (进场就反转, 频繁试错)
马丁格尔: ─↗↘↗↘↘↘爆仓 (趋势延伸时爆仓)
网格:    ─↗↘↗↘↘───  (部分网格被突破)
```

## 综合对比维度

### 资金曲线特征

| 方法论 | 曲线形状 | 最大回撤 | 夏普比率 | 收益来源 |
|:------|:--------|:--------:|:--------:|:--------|
| 金字塔 | 台阶式跃升+长期横盘 | 30-40% | 0.3-0.5 | 少数大趋势 |
| 马丁格尔 | 平滑上升+突然归零 | 100%（爆仓） | 低（尾部风险） | 高胜率小盈利 |
| 网格 | 锯齿状缓升 | 20-50% | 0.5-0.8 | 频率套利 |

### 资金规模适应性

| 方法论 | 小资金 | 中资金 | 大资金 |
|:------|:-----:|:------:|:------|
| 金字塔 | 受限（4 单位需保证金） | ✅ | ✅ |
| 马丁格尔 | ❌（难抗连亏） | ⚠️（需深口袋） | ✅ |
| 网格 | ✅ | ✅ | ⚠️（流动性约束） |

### 编程复杂度

| 方法论 | 代码量 | 难点 |
|:------|:------|:-----|
| 金字塔 | 中（~50 行信号逻辑） | 加仓价位防重复、挂单管理 |
| 马丁格尔 | 低（~20 行） | 连亏熔断、资金管理 |
| 网格 | 中高（挂单管理复杂） | 订单跟踪、网络恢复、层数计算 |

## 组合思路

三种方法论并非互斥，可在不同时间框架或品种上组合使用：

| 组合 | 配置 | 效果 |
|:----|:-----|:-----|
| 金字塔（主）+ 网格（辅） | 趋势时金字塔吃大趋势，震荡时网格吃震荡 | 平滑资金曲线 |
| 网格做波段 + 金字塔做趋势 | 统一品种不同周期 | 多时间维度捕捉 |
| 马丁格尔仅用于极小仓位 | 0.01 手起步，设 5 次熔断 | 娱乐性收入，不对账户构成威胁 |

## 编程实现要点

### 金字塔 — 防重复触发

```cpp
// 关键：m_lastAddPrice 记录上一单触发价
if (Bid >= entryPrice + currentUnits * stepATR) {
    double stepPrice = entryPrice + currentUnits * stepATR;
    if (stepPrice != m_lastAddPrice) {  // ← 价位未触发过
        AddPosition();
        m_lastAddPrice = stepPrice;
    }
}
```

### 马丁格尔 — 连亏熔断

```cpp
int consecutiveLosses = 0;
const int MAX_LOSSES = 5;  // 最多连亏 5 次

void OnCloseOrder() {
    if (orderProfit < 0) {
        consecutiveLosses++;
        if (consecutiveLosses >= MAX_LOSSES) {
            DisableTrading("连亏熔断触发");
            return;
        }
        lots *= 2;  // 加倍
    } else {
        consecutiveLosses = 0;
        lots = initialLots;  // 重置
    }
}
```

### 网格 — 层数跟踪

```cpp
struct GridLevel {
    double price;
    int ticket;
    bool active;
};

GridLevel levels[MAX_LEVELS];
double gridStep = 10 * Point();

void OnTick() {
    for (int i = 0; i < MAX_LEVELS; i++) {
        if (!levels[i].active) continue;
        // 检测止盈
        if (OrderSelect(levels[i].ticket)) {
            if (OrderProfit() > targetProfit) {
                OrderClose(...);
                levels[i].active = false;
            }
        }
    }
}
```
