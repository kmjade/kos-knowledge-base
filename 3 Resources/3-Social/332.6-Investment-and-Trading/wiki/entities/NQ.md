## 特點

### 1. 科技權重極高

```
NQ 前五大權重板塊：
  ① 科技       ~55%（AAPL、MSFT、NVDA）
  ② 通信服務    ~15%（GOOGL、META）
  ③ 非必需消費  ~12%（AMZN、TSLA）
  ④ 醫療保健    ~6%
  ⑤ 必需消費    ~3%

NQ vs ES：
  NQ = 聚焦成長型/科技股
  ES = 更均衡（金融、醫療、工業權重更高）
```

### 2. 高波動性

NQ 的波動率通常是 ES 的 **1.5–2.0 倍**：

| 指標 | NQ | ES | 比率 |
|:----|:--:|:--:|:----:|
| ATR (D1, 14) | ~350 點 | ~100 點 | ~3.5× |
| 平均真實波幅 ($) | ~$7,000 | ~$5,000 | ~1.4× |
| Beta to SPX | ~1.3 | ~1.0 | — |
| 年化波動率 | ~25% | ~15% | ~1.7× |

### 3. NQ / ES 價差交易

NQ 與 ES 高度相關（相關係數 ~0.85–0.90），但波動率不同，因此常用於**配對交易 / 價差交易**：

```
NQ:ES 比率 = NQ 價格 / ES 價格

常態範圍：約 3.5–5.0（取決於科技股表現）
比率上升 = 科技股 outperforming（NQ 跑贏）
比率下降 = 科技股 underperforming（ES 相對強勢）

交易策略：
  比率 > 上軌 → 空 NQ / 多 ES（均值回歸）
  比率 < 下軌 → 多 NQ / 空 ES（均值回歸）
```

### 4. 對宏觀事件敏感

NQ 對以下事件反應最強烈：
- **FOMC 利率決議** — 成長股對利率極敏感
- **CPI / PPI 通膨數據** — 影響貼現率→估值→科技股
- **大型科技股財報** — AAPL、MSFT、NVDA、AMZN 財報前後 NQ 波動加劇
- **AI/半導體產業新聞** — NVDA 佔 NQ 權重 ~7%

## 交易時間（美東時間）

| 時段 | 時間 | 說明 |
|:----|:----:|------|
| **美股指數開盤** | 09:30–16:00 | 流動性最佳，波動最大 |
| **盤前** | 04:00–09:30 | 歐洲盤連動，波動漸增 |
| **盤後** | 16:00–20:00 | 財報後波動 |
| **夜盤** | 20:00–次日 04:00 | 亞洲盤時段，流動性最低 |

> 注意：NQ 電子盤實際上可交易 23 小時/日（17:00–18:00 休市），但流動性集中在美股開盤時段。
