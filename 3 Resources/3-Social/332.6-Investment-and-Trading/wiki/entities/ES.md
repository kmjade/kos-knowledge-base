# ES (S&P 500 E-mini)

## 基本信息

| 屬性 | 值 |
|:----|:---|
| **全稱** | E-mini S&P 500 Futures |
| **交易所** | CME (Chicago Mercantile Exchange) |
| **產品代碼** | ES |
| **合約乘數** | $50 × S&P 500 指數 |
| **最小跳動** | 0.25 指數點 = $12.50 |
| **電子交易時間** | 週日 18:00 – 週五 17:00（美東時間, 每日 17:00–18:00 休市）|
| **實物/現金** | 現金交割 |
| **流動性** | ⭐⭐⭐⭐⭐ 全球最大期貨合約之一 |

## 合約規格

| 參數 | 數值 |
|:----|:----:|
| 名義價值（@ 5,500 點） | $275,000 |
| 維持保證金（約） | $10,000–15,000 |
| 日內保證金（約） | $500–1,500 |
| 平均日範圍 | 40–80 點 |
| 典型點差 | 0.25–1.00 跳動 |

## 特點

### 1. 全球最重要的期貨合約

ES 是全球**交易量最大**的股指期貨之一，被視為：

```
ES 的角色：
  📊 美國股市的基準——標普 500 覆蓋 ~80% 美國市值
  🌐 全球風險情緒的風向標——"市場只有 ES 和非 ES"
  🛡 機構對沖的首選工具——流動性極深
  🔮 現貨市場的先行指標——ES 夜盤反映亞歐時段情緒
```

### 2. 行業分佈均衡

```
ES 的 GICS 行業權重（約略）：
  ① 科技      ~30%
  ② 金融      ~12%
  ③ 醫療保健   ~12%
  ④ 非必需消費 ~11%
  ⑤ 通訊服務  ~9%
  ⑥ 工業      ~8%
  ⑦ 必需消費  ~6%
  ⑧ 能源      ~4%
  ⑨ 公用事業  ~3%
  ⑩ 房地產    ~3%
  ⑪ 材料      ~2%

相比 NQ：ES 更均衡分散，抗波動能力更強
```

### 3. 流動性與交易成本

ES 的流動性是全球最深的，這意味著：

| 優勢 | 說明 |
|:----|------|
| **極低點差** | 主力合約通常 1 跳動內成交 |
| **大單承接** | 數百張合約不影響價格 |
| **24 小時交易** | 除 17:00–18:00 休市外，幾乎全天活躍 |
| **期權鏈完整** | ES 期權是流動性最好的指數期權之一 |

### 4. ES / NQ 比率的參考意義

```
ES:NQ 比率（或 NQ:ES 比率）是市場風格的晴雨表：

NQ/ES 比率上升 = 科技股跑贏（Risk-On）
  → 市場偏好成長型/高 beta 股票
  → 通常發生在利率下降 / 風險偏好上升時

NQ/ES 比率下降 = 價值/防禦股跑贏（Risk-Off）
  → 市場偏好防禦型/低 beta 股票
  → 通常發生在利率上升 / 風險規避時

關鍵參考：
  NQ/ES 比率 = 4.5+ → 科技極端擁擠 → 可能回調
  NQ/ES 比率 = 3.5− → 科技極端低配 → 可能反彈
```

## ES 對宏觀事件的敏感性

| 事件 | 影響 | 反應方向 |
|:----|:----|:--------:|
| **FOMC 升息** | 緊縮→不利估值 | 下跌（尤其成長股） |
| **FOMC 降息** | 寬鬆→有利估值 | 上漲 |
| **CPI 超預期** | 通膨→加速緊縮 | 下跌 |
| **NFP 超預期** | 經濟強→鷹派預期 | 短多長空 |
| **GDP 強勁** | 經濟好→盈利增 | 上漲 |
| **地緣衝突** | 避險情緒 | 下跌（能源板塊除外） |
| **政府停擺** | 不確定性 | 小跌 / 盤整 |

### Micro E-mini (MES)

對於零售交易者，CME 提供 **Micro E-mini S&P 500 (MES)**：

```
MES 合約乘數 = $5（是 ES 的 1/10）
名義價值（@ 5,500）= $27,500
保證金約 = $1,000–1,500

優勢：精確風控、小資金起步
缺點：佣金佔比相對較高
```

## 交易策略場景

| 場景 | 看漲 | 看跌 |
|:----|:----|:----|
| **突破交易** | ES 突破前高 + CVD 正 Delta | ES 跌破前低 + CVD 負 Delta |
| **VWAP 回測** | ES 回測 VWAP + 吸收信號 | ES 反彈 VWAP 遇阻 |
| **POC 回測** | POC 支撐 + 低量測試 | POC 阻力 + 低量測試 |
| **NQ/ES 配對** | 做多強勢/做空弱勢 | 比率極端回歸 |
| **宏觀事件** | 利多不跌→真強 | 利多不漲→真弱 |
