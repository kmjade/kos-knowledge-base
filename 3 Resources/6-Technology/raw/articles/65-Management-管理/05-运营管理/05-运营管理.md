# 05-运营管理

> 把输入转化为输出的过程——效率、质量与供应链。

## 运营系统

```
输入（原料、人力）→ 转化过程 → 输出（产品、服务）
```

## 质量管理

| 方法 | 说明 |
|------|------|
| TQM | 全面质量管理 |
| 六西格玛 | 减少缺陷（3.4 ppm） |
| PDCA | 计划-执行-检查-改进 |
| 精益 | 消除浪费 |

## 精益生产

| 概念 | 说明 |
|------|------|
| 及时制 (JIT) | 零库存 |
| 看板 | 拉动式生产 |
| 持续改进 (Kaizen) | 小步改进 |
| 消除浪费 | 七大浪费 |

## 供应链管理

```
供应商 → 制造商 → 分销商 → 零售商 → 消费者
```

- 库存管理（EOQ 模型）
- 牛鞭效应、需求预测
- 供应链风险与韧性

## 服务运营

- 服务特性：无形、不可存储、异质
- 排队理论、容量管理
- 服务质量管理（SERVQUAL）
