# 07-财务管理

> 组织的「钱袋子」——筹资、投资与利润分配。

## 三大财务报表

| 报表 | 内容 |
|------|------|
| 资产负债表 | 资产 = 负债 + 所有者权益 |
| 利润表 | 收入 − 费用 = 利润 |
| 现金流量表 | 经营·投资·筹资现金流 |

## 财务分析

| 指标 | 公式 |
|------|------|
| 流动比率 | 流动资产 / 流动负债 |
| 资产负债率 | 负债 / 资产 |
| 毛利率 | 毛利 / 收入 |
| 净资产收益率 ROE | 净利润 / 所有者权益 |
| 每股收益 EPS | 净利润 / 股本 |

## 资金时间价值

$$FV = PV(1+r)^n, \quad PV = \frac{FV}{(1+r)^n}$$

## 投资决策

| 方法 | 说明 |
|------|------|
| 净现值 NPV | 收益现值 − 成本 |
| 内部收益率 IRR | 使 NPV=0 的折现率 |
| 回收期 | 收回投资的时间 |

## 筹资与资本结构

- 债务 vs 权益
- 资本成本（WACC）
- 杠杆（财务风险）
