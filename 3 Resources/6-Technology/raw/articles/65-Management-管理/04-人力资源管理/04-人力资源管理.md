# 04-人力资源管理

> 组织最宝贵的资源是「人」——选、育、用、留。

## HR 职能

| 职能 | 内容 |
|------|------|
| 招聘 | 吸引、选拔人才 |
| 培训 | 提升能力 |
| 绩效 | 评估、反馈 |
| 薪酬 | 报酬、福利 |
| 员工关系 | 沟通、劳资 |

## 招聘与选拔

- 内部 vs 外部招聘
- 结构化面试、测评、背景调查
- 人岗匹配

## 绩效管理

| 方法 | 说明 |
|------|------|
| KPI | 关键绩效指标 |
| OKR | 目标与关键结果 |
| 360 度评估 | 多方反馈 |
| 平衡计分卡 | 多维考核 |

## 薪酬与激励

- 固定薪酬 + 浮动薪酬
- 股权激励、奖金
- 内在激励（成长、认可）

## 人才发展

- 职业通道（管理/专家双通道）
- 继任计划、人才梯队
- 学习型组织
