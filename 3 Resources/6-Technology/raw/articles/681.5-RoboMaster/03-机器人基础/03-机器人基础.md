# 03 机器人基础

## Robot 对象

```python
from robomaster import robot
ep_robot = robot.Robot()
ep_robot.initialize(conn_type="ap")
```

Robot 是核心对象，通过它访问各模块：`ep_chassis`、`ep_gimbal`、`ep_blaster`、`ep_camera`、`ep_sensor`、`ep_led`、`ep_arm`、`ep_gripper` 等。

## 底盘（Chassis）

底盘控制**全向移动**：

```python
ep_chassis = ep_robot.chassis
ep_chassis.drive_speed(x=0.5, y=0, z=0, timeout=5)  # 前进
ep_chassis.move(x=0.5, y=0, z=0, xy_speed=0.5)       # 定距移动
```

- 麦克纳姆轮全向移动（x/y/z 平移与旋转）
- `drive_speed`（速度）/ `move`（位移）

## 云台（Gimbal）

云台控制**瞄准**：

```python
ep_gimbal = ep_robot.gimbal
ep_gimbal.recenter()                              # 回中
ep_gimbal.move(pitch=20, yaw=30)                  # 相对移动
ep_gimbal.drive_speed(pitch_speed=10, yaw_speed=10)
```

- pitch（俯仰）+ yaw（偏航）
- 用于瞄准射击、视觉追踪
