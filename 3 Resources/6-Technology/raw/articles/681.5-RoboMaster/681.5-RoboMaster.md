# 681.5 RoboMaster

> RoboMaster 是 **大疆（DJI）** 出品的**教育机器人平台**，产品线涵盖 S1（智能教育机器人）、EP（教育拓展套装）与 TT（教育无人机），以「机器人 + Python/Scratch 编程 + 官方 SDK + 机甲大师赛」为核心，面向 STEM 教育与机器人竞赛。数据更新至 2026-09。

## 核心问题

如何用大疆 RoboMaster 教育机器人 + Python SDK，让学习者通过编程控制机器人完成运动、射击、感知与任务，实现 STEM 教育目标？
