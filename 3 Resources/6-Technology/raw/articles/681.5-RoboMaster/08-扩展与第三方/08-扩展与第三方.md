# 08 扩展与第三方

## RoboMaster EP 扩展模块

EP 在 S1 基础上新增：

| 模块 | 说明 |
|------|------|
| 机械臂（Arm） | 抓取作业 |
| 机械爪（Gripper） | 末端夹取 |
| 高性能舵机 | 精密动作 |
| 红外深度传感器 | 测距/避障 |

可组装为**步兵机器人**或**工程机器人**。

## 第三方硬件兼容

EP 兼容：

| 硬件 | 说明 |
|------|------|
| Micro:Bit | 开源教育板 |
| Arduino | 开源硬件 |
| Raspberry Pi | 树莓派 |
| NVIDIA Jetson Nano | AI 边缘计算 |

## 扩展编程

```python
ep_arm = ep_robot.arm
ep_gripper = ep_robot.gripper
```
