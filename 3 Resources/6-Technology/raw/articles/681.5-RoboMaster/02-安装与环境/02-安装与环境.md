# 02 安装与环境

## 安装 SDK

```bash
pip install robomaster
```

RoboMaster SDK 是官方 Python SDK，用于 **EP 与 Tello Edu（TT）** 系列。

## 连接方式

| 方式 | 说明 |
|------|------|
| USB 直连 | USB 线连接机器人 |
| Wi-Fi 直连 | 机器人 Wi-Fi 热点直连 |
| 路由器组网 | 机器人加入同一局域网 |

## 初始化

```python
from robomaster import robot

if __name__ == '__main__':
    ep_robot = robot.Robot()
    ep_robot.initialize(conn_type="ap")   # ap / sta / rndis
```

- `ap`：直连（机器人热点）
- `sta`：组网（局域网）
- `rndis`：USB 直连
