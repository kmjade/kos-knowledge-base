# 12 开发板与嵌入式

## 大疆开发板

| 开发板 | 说明 |
|------|------|
| A 型板 | 基于 STM32F427，竞赛/进阶（CAN 总线、时钟树、GPIO、DMA） |
| C 型板 | 教育开发板（C-RTOS 简化模板） |

## CAN 与电机

| 主题 | 说明 |
|------|------|
| CAN 通信 | 大疆 3508 电机驱动（CAN 协议） |
| M3508 / M2006 | 大疆无刷电机，速度/位置 PID 闭环控制 |
| PWM 控制 | 电机/舵机 PWM |

## 嵌入式示例

| 示例 | 说明 |
|------|------|
| IMU 陀螺仪 | 姿态读取 |
| UWB 定位 | 室内定位 |
| OLED 显示 | 状态显示 |
| SD 卡读写 | 数据存储 |
| 遥控器接收 | SBUS/DBUS |
| FreeRTOS | 实时操作系统 |
