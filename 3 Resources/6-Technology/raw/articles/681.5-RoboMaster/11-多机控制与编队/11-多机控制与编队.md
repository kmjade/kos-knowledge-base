# 11 多机控制与编队

## 多机控制

RoboMaster SDK 支持**多机**控制与编队：

| 场景 | 说明 |
|------|------|
| 多机 API | 汇总多机控制接口 |
| 编队 TT | 多台 TT 无人机编队 |
| 编队 EP | 多台 EP 机器人编队 |

## 编队（TT）

多台 TT 无人机协同控制，编队飞行（借助 SDK 多机 API + 组网）。

## 编队（EP）

多台 EP 机器人组网编队，协同运动与任务。

## 典型流程

1. 多机加入同一网络（组网）
2. 分别初始化各机器人
3. 多机 API 协同控制
4. 编队队形与协同任务
