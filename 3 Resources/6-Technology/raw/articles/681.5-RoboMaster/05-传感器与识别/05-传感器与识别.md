# 05 传感器与识别

## 传感器（Sensor）

```python
ep_sensor = ep_robot.sensor
ep_sensor.sub_distance(freq=5, callback=distance_cb)   # 红外距离
ep_sensor.sub_adapter(freq=5, callback=adapter_cb)     # 击打检测
```

- 红外深度传感器（测距）
- 击打检测（装甲板）
- 陀螺仪/姿态

## 视觉识别（Vision）

SDK 内置智能识别（视觉标签、线识别、人群识别、手势等）：

```python
ep_vision = ep_robot.vision
ep_vision.sub_detect_info(name="marker", callback=marker_cb)  # 视觉标签
ep_vision.sub_detect_info(name="line", callback=line_cb)      # 线识别
```

## LED 与音频

```python
ep_led = ep_robot.led
ep_led.set_led(comp=comp_all, r=255, g=0, b=0)   # LED 灯效
```
