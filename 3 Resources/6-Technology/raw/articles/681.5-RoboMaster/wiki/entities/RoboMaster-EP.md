# RoboMaster EP

大疆教育拓展套装（2020-03 发布），开放官方 SDK，支持机械臂/机械爪/舵机/红外深度传感器，兼容 Micro:Bit、Arduino、树莓派、Jetson Nano。

## EP / EP Core 形态

| 型号 | 形态 | 摄像头位置 |
|:--|:--|:--|
| EP Core | 机械臂 + 夹爪（工程师形态） | 机械臂 |
| EP | 两者可切换（EP Core + 云台/发射器） | 随形态 |

> EP 在 EP Core 基础上增加云台与发射器，既可搭成 S1「战士」形态，也可搭成「工程师」形态。

## 双控制器

架构与 [[RoboMaster-S1|S1]] 相同（[[智能中控-Intelligent-Controller|智能中控]] Android + 运动控制器，CAN 连接），但**智能中控/运动控制器硬件不同、不可互换**（EP 处理能力更强）。

## 核心规格

| 参数 | 说明 |
|:--|:--|
| 类型 | 教育机器人（拓展套装） |
| 编程 | Scratch 3.0 + Python 3.6 |
| 扩展 | 机械臂/爪、第三方硬件（树莓派/Jetson Nano/Micro:Bit/Arduino） |
| 固件 | SDK 要求 ≥ 01.01.0500 |
