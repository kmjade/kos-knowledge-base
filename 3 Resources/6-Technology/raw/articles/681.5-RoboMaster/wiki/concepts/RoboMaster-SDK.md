# RoboMaster SDK

## 定义

RoboMaster SDK 是大疆官方 **Python SDK**（`robomaster` 包），用于 EP 与 Tello Edu（TT），提供运动控制、飞行控制、智能识别、灯效、数据推送、视频流与音频流 API。采用模块化设计 + 订阅回调模式。

## 关键模块

robot / chassis / gimbal / blaster / camera / sensor / vision / led / arm / gripper / flight。
