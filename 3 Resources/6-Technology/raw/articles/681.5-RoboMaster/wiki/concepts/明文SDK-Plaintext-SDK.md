# 明文 SDK Plaintext SDK

## 定义

明文 SDK 是 RoboMaster 的**纯文本协议通信**开发方式：语言无关、协议简单、连接灵活（串口/WiFi/USB）、底层控制，适合嵌入式/单片机等资源受限环境与第三方平台接入。
