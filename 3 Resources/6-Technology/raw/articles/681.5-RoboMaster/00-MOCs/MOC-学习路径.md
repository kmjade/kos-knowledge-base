# MOC-学习路径

> [!info] 概述
> RoboMaster EP 机器人系统化学习路径，从环境搭建到多机编队控制。

---

## 学习阶段总览

```
第一阶段：环境搭建（1周）
    ↓
第二阶段：SDK 基础（2周）
    ↓
第三阶段：EP 机器人控制（2-3周）
    ↓
第四阶段：拓展模块（2周）
    ↓
第五阶段：多机控制（2-3周）
```

## 学习建议

1. **动手实践**：每个接口都要亲自测试
2. **查阅 API**：遇到问题查阅 API 文档
3. **项目驱动**：设计小项目综合练习
4. **记录笔记**：记录常用代码和问题解决方案
