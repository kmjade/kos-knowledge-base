# 04 射击与图传

## 射击器（Blaster）

```python
ep_blaster = ep_robot.blaster
ep_blaster.fire()          # 单次射击
ep_blaster.fire(times=3)   # 连射
```

- 水弹 / 红外射击
- 配合云台瞄准

## 图传相机（Camera）

```python
ep_camera = ep_robot.camera
ep_camera.start_video_stream(display=True)   # 开始图传
img = ep_camera.read_cv2_image()             # 读取帧（OpenCV）
ep_camera.stop_video_stream()
```

- 第一人称视角（FPV）图传
- 视频流可配合 OpenCV 做视觉处理

## 视频流

SDK 提供视频流 API，可拉取实时画面用于识别与控制。
