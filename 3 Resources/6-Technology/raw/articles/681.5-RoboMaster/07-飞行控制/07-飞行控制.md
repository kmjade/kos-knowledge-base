# 07 飞行控制

## RoboMaster TT / Tello EDU

RoboMaster TT 是**教育无人机**（Tello EDU 升级版），支持开源、多机协同控制与 AI 应用。

## 飞行控制 API

```python
from robomaster import robot

tl_drone = robot.Drone()
tl_drone.initialize()
tl_flight = tl_drone.flight
tl_flight.takeoff().wait_for_completed()   # 起飞
tl_flight.forward(50).wait_for_completed()  # 前飞 50cm
tl_flight.land().wait_for_completed()       # 降落
```

- 起飞/降落、前后左右上下飞行、旋转
- 多机协同（编队）
