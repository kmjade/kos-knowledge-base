# 07 制造与下单

## 输出文件

| 文件 | 用途 |
|:--|:--|
| Gerber | PCB 生产文件（含钻孔） |
| BOM（物料清单） | SMT/焊接元件清单 |
| 坐标文件（Pick & Place） | 贴片机坐标 |
| 装配图 | 手工焊接辅助 |

## 生成方式

- 顶部菜单「制造 → 生成 Gerber」/「制造 → 生成 BOM」
- 或「文件 → 导出 → Gerber」

## 一键下单

- 顶部菜单「制造 → 下单 PCB/SMT」，直接对接 [[嘉立创JLC|嘉立创]] 打样
- BOM 可一键导入 [[立创商城LCSC|立创商城]] 配单，元件带真实库存
- SMT 贴片支持，需 BOM + 坐标文件

## 拼板下单

拼板文件（含工艺边）直接导出 Gerber 下单，V 割/邮票孔需在拼板时标注。

## 注意事项

- 下单前确认板框、钻孔、阻焊开窗是否正确
- 元件与封装须与商城 SKU 绑定，否则 SMT 无法配单
