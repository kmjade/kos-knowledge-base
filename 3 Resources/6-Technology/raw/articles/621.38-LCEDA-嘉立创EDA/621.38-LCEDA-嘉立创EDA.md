# 621.38 嘉立创EDA 知识库

> 顶层入口。嘉立创EDA 是免费网页版原理图/PCB 设计工具，把「画原理图 → 布局布线 → 导出 Gerber → 嘉立创打样」这条链路收敛成一条网页内闭环，是本项目自制 PCB 的工具层参照。

## 一句话

> 嘉立创EDA 让 PCB 设计从「装软件 + 建库」降到「浏览器 + 立创商城器件库直搜直用」——器件 = 符号 + 封装 + 3D 模型，选中即带封装与库存，画完直接下单打样。
