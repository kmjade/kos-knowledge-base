# 05 库与封装

## 库的类型

| 库 | 内容 |
|:--|:--|
| 器件库 | 完整器件（符号 + 封装 + 3D） |
| 符号库 | 电气符号 |
| 封装库 | 焊盘图形 |
| 复用图块库 | 可复用电路片段 |

> 核心关系：**器件 = 符号 + 封装 + 3D 模型**。

## 创建与查找

| 操作 | 方式 |
|:--|:--|
| 创建符号 | 文件 → 新建 → Symbol |
| 创建封装 | 文件 → 新建 → 封装 |
| 查找器件 | `Shift+F` 或左侧 Libraries 图标 |
| 更换封装 | Footprint Manager（封装管理器） |

## 更新与编辑

- 编辑工程内封装：选中封装后右键「编辑封装」，或底部面板
- 更新符号/封装：菜单「设计 → 更新符号」

## 与立创商城联动

器件搜索直接连 [[立创商城LCSC|立创商城]]，带真实库存、价格与封装，选器件即绑定可采购的实体元件。
