# 621.38 嘉立创EDA 知识库

> 嘉立创EDA（LCEDA，海外版 EasyEDA）是免费的网页版原理图/PCB 设计工具，与嘉立创（JLC）PCB 打样和立创商城（LCSC）元器件采购深度绑定。本知识库覆盖标准版 + 专业版两个版本，从环境界面到原理图、PCB、库与封装、制造下单与快捷键。
> 定位为本项目「自制 PCB」的工具层参照。数据更新至 2026-09。
