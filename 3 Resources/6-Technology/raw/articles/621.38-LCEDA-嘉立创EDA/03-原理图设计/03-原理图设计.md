# 03 原理图设计

## 放置器件

- 顶部菜单「放置 → 器件」/ 工具栏图标 / 快捷键 `Shift+F`
- 支持立创商城 + 嘉立创EDA 双引擎搜索
- 按 `Tab` 设置名称与位号，`Esc` 关闭对话框

## 元件属性

| 属性 | 说明 |
|:--|:--|
| 名称 / 位号 | 元件标识（如 `R1`、`U1`） |
| 器件 / 符号 / 封装 | 绑定到库 |
| 加入 BOM | 是否纳入物料清单 |
| 转到 PCB | 是否参与 PCB |
| 多部件属性 | 子部件管理 |

> 名称可用 `={属性名}` 关联其他属性。

## 连线元素

| 元素 | 快捷键 |
|:--|:--|
| 导线 | `W` |
| 总线 | `B` |
| 网络标签 | `N` |
| 文本 | `T` |

## 多部件元件

- 子部件位号格式须为 `U1.1`、`U1.2`（**不能用** `U1.A`、`U1.B`）
- 用于运放等一颗芯片含多个相同单元

## 更新符号/封装

- 顶部菜单「设计 → 更新符号」，或右键元件「更新符号」
- 紫色虚线框表示该符号最近有修改，通过「设计 → 更新工程库」更新
