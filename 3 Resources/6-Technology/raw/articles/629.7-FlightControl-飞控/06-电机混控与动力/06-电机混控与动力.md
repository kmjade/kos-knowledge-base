# 06 电机混控与动力

## 混控（Mixer）

混控把控制环输出的**期望力矩与油门**（roll/pitch/yaw/推力）映射到**每个电机的输出**。不同构型有不同的混控矩阵。

## 多旋翼构型

| 构型 | 电机数 | 特点 | 常见 |
|:--|:--|:--|:--|
| 四轴 X | 4 | 均衡、简单 | 最主流 |
| 四轴 + | 4 | 前后/左右对称 | 早期 |
| 六轴 | 6 | 冗余、载重 | 行业机 |
| 八轴 | 8 | 高冗余、重载 | 植保/物流 |

## X 四轴混控示例

```
motor[0] = thrust + roll - pitch + yaw   # 右前
motor[1] = thrust - roll - pitch - yaw   # 左前
motor[2] = thrust - roll + pitch + yaw   # 左后
motor[3] = thrust + roll + pitch - yaw   # 右后
```

> 符号由电机旋转方向与机架几何决定，PX4 通过 `mixer` 文件定义。

## ESC 协议

| 协议 | 刷新率 | 特点 |
|:--|:--|:--|
| PWM | 50–490 Hz | 兼容最广，老旧 |
| OneShot125/42 | 125/42 kHz 等效 | 模拟，低延迟 |
| Multishot | ~32 kHz | 模拟 |
| [[ESC\|DShot300/600/1200]] | 数字 | 无校准、CRC 校验、双向回传（RPM） |

> DShot 是当前主流：数字信号免校准、抗噪、支持电机转速回传，便于 RPM 滤波与失效检测。

## 动力系统选型

| 参数 | 含义 | 选择依据 |
|:--|:--|:--|
| 电机 KV | 每伏转速 | 小桨高 KV，大桨低 KV |
| 桨尺寸 | 直径×螺距 | 载重 vs 续航 |
| 电调电流 | 持续电流 | 匹配电机峰值电流 |
| 电池 S 数 | 电芯数（电压） | 3S–6S 常见 |
