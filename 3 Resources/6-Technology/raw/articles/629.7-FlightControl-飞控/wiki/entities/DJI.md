# DJI

## 定义

DJI（大疆创新）是消费/行业无人机与飞控（A3/N3）龙头厂商，也是 [[3 Resources/6-Technology/raw/articles/681.5-RoboMaster/RoboMaster|RoboMaster]] 教育机器人（S1/EP/TT）出品方。TT/Tello 用高层 Python API 屏蔽飞控细节，是「飞控的 SDK 抽象」。
