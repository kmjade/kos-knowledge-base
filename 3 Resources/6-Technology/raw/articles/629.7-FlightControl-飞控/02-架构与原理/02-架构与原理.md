# 02 架构与原理

## 控制闭环

飞控核心是一个**高频闭环**（典型 400–1000 Hz），四个环节循环：

```
感知 ──► 估计 ──► 控制 ──► 执行
 ▲                          │
 └──────── 传感器反馈 ◄──────┘
```

| 环节 | 内容 | 频率 | 关键组件 |
|:--|:--|:--|:--|
| 感知 | IMU/气压/GPS/磁力计读取 | 1–8 kHz | 传感器驱动 |
| 估计 | 姿态/位置/速度解算 | 250–1000 Hz | [[04-姿态估计\|EKF/互补滤波]] |
| 控制 | PID 级联输出期望力矩 | 250–1000 Hz | [[05-控制回路\|级联 PID]] |
| 执行 | 混控 → ESC → 电机 | 与电机同步 | [[06-电机混控与动力\|Mixer]] |

## 硬件分层

```
┌ 上位机（大脑）Pi / Jetson / PC ── 规划·感知·决策（ROS 2）
├ 飞控（小脑）MCU + RTOS ── 姿态/位置闭环（PX4/ArduPilot）
├ 传感器层 ── IMU · 气压计 · GPS · 磁力计 · 光流
├ 执行层 ── ESC · 电机 · 舵机
└ 通信层 ── MAVLink / 数传 / 图传 / RC
```

## 软件分层（以 PX4 为例）

| 层 | 职责 | 组件 |
|:--|:--|:--|
| RTOS | 实时调度 | NuttX |
| 消息总线 | 进程间通信 | [[uORB]] |
| 控制模块 | 姿态/位置控制、混控 | mc_att_control / mc_pos_control / mixer |
| 估计模块 | 状态估计 | EKF2 / LPE |
| 驱动层 | 传感器/执行器 | IMU / GPS / ESC 驱动 |
| 通信层 | 对外通信 | MAVLink / uXRCE-DDS |

## 关键设计权衡

1. **实时性**：控制环必须确定性执行，抖动会导致姿态发散 → 专用 RTOS
2. **冗余**：关键传感器（IMU）常做双备份，硬件上 Pixhawk FMU 带冗余 IMU
3. **failsafe**：任何环节失效都要能安全落地/返航 → [[09-安全与故障处理]]
4. **模块化**：PX4 通过 uORB 解耦模块，便于替换估计器/控制器
