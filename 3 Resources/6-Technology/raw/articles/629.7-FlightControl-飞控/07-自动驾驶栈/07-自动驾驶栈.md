# 07 自动驾驶栈

## PX4

[[PX4]] 是模块化开源飞控栈，运行在 **NuttX RTOS** 上，进程间通过 [[uORB]] 消息总线通信。

| 模块 | 职责 |
|:--|:--|
| commander | 状态机（arming/飞行模式） |
| sensors | 传感器驱动与标定 |
| EKF2 / LPE | 状态估计 |
| mc_att_control / mc_pos_control | 姿态/位置控制 |
| mixer | 混控 |
| mavlink | 通信 |

- 优点：模块化、文档全、MAVSDK/ROS 2 支持好、仿真（Gazebo/SITL）成熟
- 飞行模式：Manual / Altitude / Position / Mission / Offboard / RTL

## ArduPilot

[[ArduPilot]] 是另一大开源自驾仪，运行在 **ChibiOS RTOS**，代码库较单体但支持平台极广：

- 载体：多旋翼、固定翼、直升机、车（Rover）、船、潜艇（Sub）、天线跟踪
- 特色：丰富的自动任务、地形跟随、冗余传感器仲裁、非 GPS 导航
- 通信：MAVLink、脚本（Lua）、ROS（ros2 接口）

## Betaflight

[[Betaflight]] 面向 FPV 竞速，追求**最低延迟、最高机动**：

- 无 RTOS（或轻量），控制环极高频（8 kHz 级）
- 特色：RPM 滤波、动态陷波、快速调参、OSD 集成
- 定位：手感优先，不做复杂自主导航

## 对比

| 维度 | PX4 | ArduPilot | Betaflight |
|:--|:--|:--|:--|
| RTOS | NuttX | ChibiOS | 裸机/轻量 |
| 架构 | 模块化(uORB) | 单体(库) | 紧凑 |
| 载体 | 多旋翼/固定翼/VTOL | 多旋翼/固定翼/船/车/ROV | 多旋翼(FPV) |
| 自主导航 | 强 | 最强 | 弱 |
| 手感/延迟 | 中 | 中 | 极致 |
| 学习门槛 | 中 | 中高 | 低 |
