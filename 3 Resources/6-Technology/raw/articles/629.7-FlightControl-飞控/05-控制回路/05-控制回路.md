# 05 控制回路

## PID 基础

PID 控制器输出 = P（比例）+ I（积分）+ D（微分）：

| 项 | 作用 | 调大副作用 |
|:--|:--|:--|
| P | 快速响应误差 | 超调、振荡 |
| I | 消除稳态误差 | 积分饱和、慢 |
| D | 抑制超调、阻尼 | 放大噪声 |

## 级联控制（Cascade PID）

飞控控制是**多环嵌套**，内环频率高于外环：

```
位置环 ──► 速度环 ──► 姿态角环 ──► 角速度环 ──► 混控 ──► 电机
 (低频)                        (高频)
```

| 环 | 输入 | 输出 | 频率（PX4） |
|:--|:--|:--|:--|
| 位置环 | 位置误差 | 期望速度 | 50–100 Hz |
| 速度环 | 速度误差 | 期望姿态角 | 100–250 Hz |
| 姿态角环 | 姿态误差 | 期望角速度 | 250–400 Hz |
| 角速度环 | 角速度误差 | 力矩/油门 | 400–1000 Hz |

> 角速度环是**手感核心**：内环调好，外环只需慢速跟踪。

## 调参方法论

1. **先内后外**：先调角速度环（P→D→I），再姿态环，再速度/位置环
2. **P 到振荡再减半**：逐步加 P 到轻微振荡，取振荡值一半附近
3. **D 抑制超调**：D 加 P 的响应速度，但先滤波再微分
4. **I 慢速消除稳态误差**：I 宜小，配合积分限幅防饱和
5. **仿真优先**：SITL 里调完再上真机

## 特殊控制

- **油门混合**：多旋翼姿态控制叠加在基础油门（悬停油门）上
- **抗饱和**：积分限幅 + 抗积分饱和（anti-windup）
- **前馈**：轨迹跟踪加入加速度前馈，减少跟踪滞后
