# 09 安全与故障处理

## failsafe 体系

飞控的安全设计核心是「**任何链路失效都要能安全处置**」，而非依赖单一保护：

| 失效场景 | 检测 | 处置 |
|:--|:--|:--|
| 遥控信号丢失 | 无 RC 心跳 | RTL / Land / Hold（可配） |
| GPS 丢失 | 卫星数/定位失效 | 切回无 GPS 模式（姿态/光流） |
| 数传丢失 | 无 MAVLink 心跳 | 按预置航线继续 |
| 低电量 | 电压/电流积分 | 强制 RTL / 自动降落 |
| 传感器故障 | 冗余仲裁 | 切备用 IMU/估计器 |
| 地理围栏越界 | 位置超界 | RTL / Land |

## 关键机制

| 机制 | 说明 |
|:--|:--|
| RTL（Return to Launch） | 自动返回起飞点并降落 |
| geofence | 虚拟围栏，越界触发动作 |
| arming 检查 | 起飞前自检（传感器/参数/定位） |
| 冗余传感器 | 双 IMU/气压计投票仲裁 |
| 桨失效保护 | 六/八轴失去单电机仍可控 |

## 冗余设计（Pixhawk）

```
FMU 主 MCU + 双 IMU + 双气压计 + 双电源
   └── 单点失效不坠机
```

## 安全规范（作业）

1. **空域合规**：遵守当地无人机法规（登记、限飞、视距）
2. **SITL 先行**：任何新配置先在仿真里验证
3. **失控预案**：预设 RTL 高度、备用降落点
4. **日志复盘**：飞控日志（ulog/.bin）是事故分析的关键
