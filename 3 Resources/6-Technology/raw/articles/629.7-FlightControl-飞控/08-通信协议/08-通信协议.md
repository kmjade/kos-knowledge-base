# 08 通信协议

## MAVLink

[[MAVLink]] 是飞控生态的**事实标准通信协议**，轻量、面向消息，支持串口/UDP/TCP。

| 特性 | 说明 |
|:--|:--|
| 消息 | HEARTBEAT / ATTITUDE / GPS_RAW_INT / COMMAND_LONG 等 |
| 传输 | 串口 / UDP / TCP / 数传 |
| 版本 | MAVLink 1（8 字节头）→ MAVLink 2（13 字节头，扩展） |
| 签名 | MAVLink 2 支持消息签名 |

## 通信链路

```
飞控 ──MAVLink──► 数传电台 ◄──► 地面站（QGC / Mission Planner）
  │
  └──MAVLink──► 上位机（Pi/Jetson）── ROS 2 ──► 应用
```

## 地面站

| 地面站 | 生态 | 特点 |
|:--|:--|:--|
| [[QGroundControl]] | PX4 | 官方、跨平台、Mission 规划 |
| [[Mission Planner]] | ArduPilot | 功能最全、参数/日志分析 |

## 图传

| 类型 | 特点 | 用途 |
|:--|:--|:--|
| 模拟图传 | 低延迟、无压缩 | FPV 竞速 |
| 数字图传 | 高清、加密 | 行业作业（DJI OcuSync/自组网） |
| WiFi/4G/5G | 远距离、低带宽 | 远程指挥、流媒体 |

## RC 遥控

| 协议 | 特点 |
|:--|:--|
| SBUS / CRSF | 串行接收机协议（低延迟） |
| ELRS | 开源长距离遥控链路 |
