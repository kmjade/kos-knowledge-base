# 07-质量工程

> 质量是制造的生命线——从检验到预防。

## 质量概念

- 符合性质量、适用性质量
- 顾客满意度
- 质量成本（预防、鉴定、内部损失、外部损失）

## 质量控制工具（QC 七大手法）

| 工具 | 用途 |
|------|------|
| 检查表 | 数据收集 |
| 柏拉图 | 抓主要问题 |
| 因果图（鱼骨图） | 找根因 |
| 直方图 | 分布 |
| 散布图 | 相关性 |
| 控制图 | 过程监控 |
| 分层法 | 分类分析 |

## SPC 统计过程控制

- 控制图（X̄-R 图）
- 过程能力指数：$C_p = \frac{USL-LSL}{6\sigma}$
- 异常判定规则

## 六西格玛

- DMAIC：定义 → 测量 → 分析 → 改进 → 控制
- 目标：缺陷率 3.4 ppm
- 黑带、绿带

## 质量管理体系

- ISO 9001（质量）
- IATF 16949（汽车）
- PDCA 循环、持续改进
- 全面质量管理 (TQM)
