# 09-可持续制造

> 在创造价值的同时保护地球——绿色制造与循环经济。

## 绿色制造

| 方面 | 措施 |
|------|------|
| 节能 | 高效设备、能源管理 |
| 减材 | 轻量化设计、减少废料 |
| 清洁生产 | 减少污染物 |
| 绿色材料 | 可回收、可降解 |

## 循环经济

```
线性经济：原料 → 产品 → 废弃
循环经济：原料 → 产品 → 回收 → 再制造
```

- 3R：减量 (Reduce)、再利用 (Reuse)、回收 (Recycle)
- 产品再制造、翻新
- 材料闭环

## 生命周期评估 (LCA)

- 从摇篮到坟墓的环境影响
- 碳足迹计算
- 产品环境声明

## 碳中和制造

- 能源结构转型（可再生能源）
- 碳捕集 (CCUS)
- 碳交易、碳标签

## 可持续供应链

- 绿色采购、供应商评估
- 责任矿产、公平贸易
- 透明追溯

## 未来展望

- 生物制造、绿色化学
- 循环设计（可拆解、模块化）
- 净零工厂
