# 04-精密制造

> 微米级的精度——现代工业的「眼睛」与「手」。

## CNC 数控加工

- 计算机数字控制
- G 代码编程
- 数控车、铣、加工中心
- 多轴联动（3/4/5 轴）

## 公差与配合

| 概念 | 说明 |
|------|------|
| 尺寸公差 | 允许的尺寸偏差 |
| 形位公差 | 形状、位置精度 |
| 配合 | 间隙、过渡、过盈 |
| 表面粗糙度 | Ra 值 |

## 精密测量

| 仪器 | 精度 |
|------|------|
| 游标卡尺 | 0.02 mm |
| 千分尺 | 0.001 mm |
| 三坐标测量机 (CMM) | 微米级 |
| 激光干涉仪 | 纳米级 |

## 特种加工

| 方法 | 原理 |
|------|------|
| 电火花 (EDM) | 电蚀 |
| 激光加工 | 高能光束 |
| 超声波 | 高频振动 |
| 电解加工 | 电化学溶解 |

## 精密制造应用

- 半导体、精密模具
- 航空航天、医疗器械
- 光学元件、手表
