# 02-金属加工

> 金属的成型与改性——制造业最基础的工艺。

## 铸造 (Casting)

| 方法 | 特点 |
|------|------|
| 砂型铸造 | 成本低、灵活 |
| 压铸 | 高精度、大批量 |
| 熔模铸造 | 精密、复杂 |
| 离心铸造 | 管状件 |

## 锻造 (Forging)

- 自由锻、模锻
- 改善金属组织、提高强度
- 热锻 vs 冷锻

## 切削加工 (Machining)

| 工艺 | 特点 |
|------|------|
| 车削 | 旋转工件（车工） |
| 铣削 | 旋转刀具（铣工） |
| 刨削 | 直线切削（刨工） |
| 钻削 | 钻孔 |
| 磨削 | 精加工（磨工） |

> **机加工四大工种**：车工、铣工、刨工、磨工（车铣刨磨）——对应车床、铣床、刨床、磨床。

> **独立建库**：切削加工的完整知识库见 [[3 Resources/6-Technology/raw/articles/671-Machining-机械加工/671-Machining-机械加工|671 机械加工]]（切削原理 · 车铣刨磨钻 · 钳工 · 数控 · 工艺规程）。

## 钳工 (Fitter / Bench Work)

| 工序 | 说明 |
|------|------|
| 划线 | 按图纸标记加工位置 |
| 锯削 | 手锯/机锯下料 |
| 锉削 | 锉刀修整表面 |
| 钻孔 | 台钻/手电钻 |
| 攻丝/套丝 | 内/外螺纹 |
| 装配 | 零件组装、调试 |

> 钳工是手工为主的工种，是机加工（车铣刨磨）的补充与装配环节。

## 焊接 (Welding)

| 方法 | 特点 |
|------|------|
| 电弧焊 | 通用 |
| 气焊 | 薄件 |
| 激光焊 | 精密 |
| 电阻焊 | 点焊、批量 |

## 热处理

- 退火（软化）、正火、淬火（硬化）、回火（去脆）
- 改变金属性能的关键工艺

## 表面处理

- 电镀、喷涂、阳极氧化
- 防腐、美观、耐磨
