# 06-智能制造

> 数据驱动的制造——工业 4.0 与数字孪生。

## 工业 4.0

| 技术 | 作用 |
|------|------|
| 物联网 (IoT) | 设备互联 |
| 大数据 | 分析决策 |
| 人工智能 | 优化预测 |
| 数字孪生 | 虚拟映射 |
| 云计算 | 算力底座 |
| 5G | 高速连接 |

## 数字孪生

- 物理实体 → 虚拟模型 → 实时同步
- 仿真、预测、优化
- 产品全生命周期

## 智能工厂

```
传感器 → 数据采集 → 分析 → 决策 → 执行
```

- 预测性维护（减少停机）
- 质量预测、能耗优化
- 柔性生产、自适应

## 工业互联网

- 设备、产线、供应链互联
- 平台：预测性维护、远程监控
- 数据安全与标准

## 中国制造 2025

- 制造强国战略
- 智能制造、绿色制造、高端装备
- 关键核心技术自主

## 未来趋势

- AI 驱动的自主制造
- 生成式设计
- 人机共融、无人工厂
