# 08-供应链与生产管理

> 协调生产与供应——从计划到交付。

## 生产计划

| 层次 | 内容 |
|------|------|
| 长期 | 产能规划 |
| 中期 | 综合生产计划 |
| 短期 | 主生产计划 (MPS)、物料需求计划 (MRP) |

## 精益生产

| 概念 | 说明 |
|------|------|
| 及时制 (JIT) | 零库存、拉动式 |
| 看板 | 视觉信号 |
| 单件流 | 减少在制品 |
| 消除七大浪费 | 等待、搬运、过度加工等 |

## 供应链管理

```
供应商 → 制造商 → 分销 → 零售 → 客户
```

- 库存管理（EOQ、安全库存）
- 牛鞭效应
- 供应商关系

## 约束理论 (TOC)

- 瓶颈决定系统产出
- 五步法：识别瓶颈 → 利用 → 服从 → 提升 → 循环

## 数字化供应链

- 需求预测（AI）
- 可视化、追溯
- 供应链韧性（应对中断）
