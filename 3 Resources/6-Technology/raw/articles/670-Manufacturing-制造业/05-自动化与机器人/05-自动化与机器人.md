# 05-自动化与机器人

> 让机器替人干活——生产效率的引擎。

## 自动化层次

```
单机自动化 → 产线自动化 → 车间自动化 → 工厂自动化
```

## 工业机器人

| 类型 | 特点 | 应用 |
|------|------|------|
| 关节型 | 灵活 | 焊接、装配 |
| SCARA | 平面 | 搬运、装配 |
| 并联 | 高速 | 分拣 |
| 协作机器人 (Cobot) | 人机协作 | 灵活作业 |

## 自动化产线

- 传送带、机械手、传感器
- PLC（可编程逻辑控制器）控制
- 视觉检测

## 传感器

| 类型 | 用途 |
|------|------|
| 位置/位移 | 定位 |
| 力/扭矩 | 装配 |
| 视觉 | 检测、定位 |
| 温度/压力 | 过程监控 |

## 机器人应用

- 焊接、喷涂（危险环境）
- 搬运、码垛（重体力）
- 装配、检测（精密）
- AGV/AMR 物流机器人

## 人机协作趋势

- 协作机器人（安全、易编程）
- 机器人 + AI 视觉
- 柔性自动化
