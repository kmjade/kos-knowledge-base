# 01-制造业概述

> 从原料到产品——制造业是实体经济的基石。

## 制造业体系

| 分类 | 内容 |
|------|------|
| 重工业 | 钢铁、机械、化工 |
| 轻工业 | 纺织、食品、家电 |
| 高新技术 | 电子、芯片、航空航天 |

## 四次工业革命

| 阶段 | 标志 |
|------|------|
| 第一次 | 蒸汽机、机械化 |
| 第二次 | 电力、流水线 |
| 第三次 | 计算机、自动化 |
| 第四次 | 物联网、AI、数字孪生 |

## 制造模式

| 模式 | 特征 |
|------|------|
| 大批量生产 | 规模经济、标准化 |
| 精益生产 | 消除浪费 |
| 柔性制造 | 快速切换产品 |
| 大规模定制 | 批量 + 个性化 |
| 智能制造 | 数据驱动 |

## 制造流程

```
设计 → 材料准备 → 加工 → 装配 → 检验 → 交付
```

## 制造业地位

- 创造就业、支撑产业链
- 技术创新载体
- 国家安全（工业体系完整）
- 中国是「世界工厂」
