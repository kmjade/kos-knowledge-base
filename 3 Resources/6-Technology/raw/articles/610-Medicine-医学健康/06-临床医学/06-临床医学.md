# 06-临床医学

> 在病床旁诊断与治疗疾病——内科是临床医学的核心。

## 诊断方法

| 方法 | 内容 |
|------|------|
| 问诊 | 病史、症状 |
| 体格检查 | 视触叩听 |
| 实验室检查 | 血、尿、生化 |
| 影像学 | X 线、CT、MRI、超声 |

## 常见内科疾病

| 系统 | 疾病 |
|------|------|
| 心血管 | 高血压、冠心病、心衰 |
| 呼吸 | 肺炎、哮喘、COPD |
| 消化 | 胃炎、溃疡、肝炎 |
| 内分泌 | 糖尿病、甲亢 |
| 泌尿 | 肾炎、肾衰竭 |

## 心血管疾病（全球首位死因）

- **高血压**：≥140/90 mmHg，生活方式 + 药物
- **冠心病**：冠状动脉粥样硬化 → 心绞痛/心梗
- **危险因素**：吸烟、高血脂、糖尿病、肥胖、缺乏运动

## 糖尿病

- 1 型：胰岛素绝对缺乏（自身免疫）
- 2 型：胰岛素抵抗（占 90%）
- 诊断：空腹血糖 ≥7.0 mmol/L 或 HbA1c ≥6.5%

## 感染性疾病

- 病原体：细菌、病毒、真菌、寄生虫
- 抗生素合理使用、疫苗预防
