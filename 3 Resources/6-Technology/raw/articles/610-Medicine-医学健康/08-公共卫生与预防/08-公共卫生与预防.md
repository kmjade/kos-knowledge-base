# 08-公共卫生与预防

> 面向人群健康的科学——预防胜于治疗。

## 三级预防

| 级别 | 目标 | 措施 |
|------|------|------|
| 一级预防 | 防发病 | 疫苗、健康教育、生活方式 |
| 二级预防 | 早发现 | 筛查、体检 |
| 三级预防 | 防恶化 | 康复、并发症管理 |

## 流行病学

| 指标 | 定义 |
|------|------|
| 发病率 | 新病例 / 人群 / 时间 |
| 患病率 | 现有病例 / 人群 |
| 病死率 | 死亡 / 病例 |
| 基本再生数 R₀ | 一个病例传染的平均人数 |

## 免疫与疫苗

| 疫苗类型 | 代表 |
|------|------|
| 灭活疫苗 | 流感、脊髓灰质炎 |
| 减毒活疫苗 | 麻疹、水痘 |
| mRNA 疫苗 | COVID-19 |

## 营养与健康

- 宏量营养素：碳水化合物、蛋白质、脂肪
- 微量营养素：维生素、矿物质
- 膳食指南：均衡、多样、适量

## 慢性病防控

- 心血管病、糖尿病、癌症的四大危险因素：
  吸烟、不健康饮食、缺乏运动、酗酒
