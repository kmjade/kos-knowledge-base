# 07-外科学

> 用手术方法治疗疾病——从无菌术到微创与移植。

## 外科基本原则

| 原则 | 说明 |
|------|------|
| 无菌术 | 防止感染（消毒、灭菌） |
| 无创操作 | 减少组织损伤 |
| 解剖复位 | 恢复结构 |
| 充分引流 | 排出积液 |

## 外科分支

| 分支 | 范围 |
|------|------|
| 普外科 | 腹部、甲状腺、乳腺 |
| 骨科 | 骨折、关节、脊柱 |
| 神经外科 | 脑、脊髓 |
| 心胸外科 | 心、肺、食管 |
| 泌尿外科 | 肾、膀胱、前列腺 |

## 创伤

- **急救原则**：气道 (Airway) → 呼吸 (Breathing) → 循环 (Circulation)（ABC）
- 出血控制、固定、转运

## 麻醉

| 类型 | 方式 |
|------|------|
| 全身麻醉 | 意识消失 |
| 椎管内麻醉 | 下半身阻滞 |
| 局部麻醉 | 局部感觉消失 |

## 微创与移植

- 腹腔镜、机器人手术（创伤小、恢复快）
- 器官移植：肾、肝、心、肺
- 免疫抑制（抗排斥反应）
