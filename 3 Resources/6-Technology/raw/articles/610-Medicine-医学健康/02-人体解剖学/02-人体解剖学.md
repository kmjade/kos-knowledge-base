# 02-人体解剖学

> 研究人体结构的科学——从细胞到器官系统。

## 组织层次

```
细胞 → 组织 → 器官 → 系统 → 人体
```

| 层次 | 说明 |
|------|------|
| 细胞 | 基本生命单位 |
| 组织 | 上皮、结缔、肌肉、神经 |
| 器官 | 由多种组织构成 |
| 系统 | 功能相关的器官组合 |

## 器官系统（11 个）

| 系统 | 主要器官 | 功能 |
|------|------|------|
| 运动系统 | 骨骼、肌肉 | 支撑与运动 |
| 循环系统 | 心、血管 | 运输 |
| 呼吸系统 | 肺、气道 | 气体交换 |
| 消化系统 | 胃肠、肝胰 | 消化吸收 |
| 泌尿系统 | 肾、膀胱 | 排泄 |
| 生殖系统 | 性腺 | 生殖 |
| 神经/内分泌 | 脑、腺体 | 调控 |

## 解剖方位术语

| 术语 | 含义 |
|------|------|
| 上/下 | 头侧/足侧 |
| 前/后 | 腹侧/背侧 |
| 内侧/外侧 | 近/离正中线 |
| 近端/远端 | 近/离躯干 |
