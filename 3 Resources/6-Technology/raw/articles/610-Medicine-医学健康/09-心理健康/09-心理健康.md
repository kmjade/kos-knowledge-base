# 09-心理健康

> 心理的完好状态——情绪、认知与行为，是整体健康不可分割的部分。

## 心理健康标准

- 情绪稳定、自我接纳
- 良好的人际关系
- 适应环境、应对压力
- 现实认知、目标感

## 常见精神障碍

| 障碍 | 特征 |
|------|------|
| 抑郁症 | 持续情绪低落、兴趣丧失 |
| 焦虑症 | 过度担忧、紧张 |
| 双相障碍 | 情绪极端波动 |
| 精神分裂症 | 思维、感知、行为紊乱 |
| 创伤后应激 (PTSD) | 创伤后持续应激 |

## 心理疗法

| 疗法 | 核心 |
|------|------|
| 认知行为疗法 (CBT) | 改变认知与行为模式 |
| 正念疗法 | 觉察当下、接纳 |
| 心理动力学 | 探索潜意识 |
| 人本主义 | 自我实现 |

## 压力管理

- 压力源 → 评估 → 应对（问题导向 vs 情绪导向）
- 健康应对：运动、睡眠、社交、正念
- 警惕「职业倦怠」：情绪耗竭、去人格化、低成就感

## 与交易/知识工作的连接

> 交易心理（贪婪、恐惧、过度交易）本质上是心理健康问题在金融场景的体现——纪律、复盘、情绪管理都是心理疗法的应用。
