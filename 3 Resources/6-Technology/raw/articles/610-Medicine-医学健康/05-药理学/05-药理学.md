# 05-药理学

> 研究药物与机体相互作用的科学——药代动力学 + 药效学。

## 药代动力学（药物在体内）

| 阶段 | 内容 |
|------|------|
| 吸收 | 药物进入血液循环 |
| 分布 | 到达靶组织 |
| 代谢 | 肝脏转化（细胞色素 P450） |
| 排泄 | 肾脏排出 |

- **半衰期** $t_{1/2}$：血药浓度降一半的时间
- **生物利用度**：进入体循环的比例

## 药效学（药物作用）

- **受体**：药物作用的靶点（激动/拮抗）
- **量效关系**：$E = \frac{E_{max}[D]}{EC_{50} + [D]}$
- **治疗窗**：有效且安全的剂量范围

## 常用药物类别

| 类别 | 代表 | 用途 |
|------|------|------|
| 抗生素 | 青霉素、头孢 | 抗感染 |
| 解热镇痛 | 阿司匹林、布洛芬 | 退热止痛 |
| 降压药 | ACEI、CCB | 高血压 |
| 降糖药 | 二甲双胍、胰岛素 | 糖尿病 |
| 抗凝药 | 华法林、肝素 | 血栓 |

## 合理用药原则

- 适应证、剂量、疗程正确
- 注意药物相互作用与不良反应
- 避免抗生素滥用（耐药性）
