# 04-病理学

> 研究疾病的病因、发生机制与形态变化——医学的「桥梁学科」。

## 疾病的基本过程

| 过程 | 说明 |
|------|------|
| 细胞适应 | 肥大、增生、萎缩、化生 |
| 细胞损伤 | 变性、坏死、凋亡 |
| 炎症 | 机体对损伤的防御反应 |
| 修复 | 再生、纤维化、瘢痕 |

## 炎症 (Inflammation)

- **五大表现**：红、肿、热、痛、功能障碍
- 急性 vs 慢性炎症
- 关键介质：组胺、前列腺素、细胞因子

## 肿瘤 (Neoplasm)

| 特征 | 良性 | 恶性 |
|------|------|------|
| 分化 | 成熟 | 不成熟 |
| 生长 | 缓慢、膨胀性 | 快速、浸润性 |
| 转移 | 无 | 有 |
| 复发 | 少 | 常见 |

- **癌 vs 肉瘤**：上皮来源 vs 间叶来源
- 分期：TNM（肿瘤大小、淋巴结、转移）

## 常见病因

- 遗传因素（基因突变）
- 感染（细菌、病毒、真菌）
- 免疫异常（自身免疫）
- 环境（理化因素、营养）
