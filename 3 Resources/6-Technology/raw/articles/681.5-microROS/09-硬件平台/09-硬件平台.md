# 09 硬件平台

## 主流 MCU 平台

| 平台 | 特性 | micro-ROS 集成 |
|:----|:-----|:--------------|
| [[ESP32-S3]] | 双核 240MHz、WiFi/BT、外设丰富 | `micro_ros_espidf_component`（最成熟） |
| ESP32 | 单核/双核、普及度高 | 同上 |
| STM32 | 工业级、生态成熟 | `micro_ros_stm32cubemx_utils` |
| RP2040 (Pico) | 低价双核 | Arduino / `micro_ros_arduino` |

## 支持 RTOS

FreeRTOS、Zephyr、NuttX，以及 ESP-IDF（内置 FreeRTOS）。

## Yahboom micro-ROS 控制板

[[Yahboom|Yahboom]] 板是 micro-ROS 的**现成参考硬件**：ESP32-S3 + 4 通道编码器电机驱动 + 2 通道 PWM 舵机 + 6 轴 IMU + LiDAR 接口，预载 micro-ROS 外设驱动固件，直连树莓派/Jetson。

### 主控芯片

| 项目 | 规格 |
|:----|:-----|
| 处理器 | ESP32-S3 双核 Xtensa LX7 |
| CPU 频率 | 240MHz |
| 内存 | 512KB SRAM |
| 闪存 | 8MB |
| 无线通讯 | 2.4GHz WiFi 4/5、Bluetooth 5.0 |
| 工作电压 | 3.3V |
| 工作温度 | -40°C ~ +85°C |

### 板载资源

| 资源 | 数量/规格 |
|:----|:----------|
| 编码器电机接口 | 4 路（310 编码器电机，PWM + 增量式 AB 相编码器） |
| PWM 舵机接口 | 2 路（S1/S2，500–2500μs 对应 0–180°） |
| IMU 传感器 | 六轴（加速度计 + 陀螺仪） |
| 激光雷达接口 | MS200（串口） |
| 通讯接口 | Type-C 串口（烧录/通讯）、外置天线 |
| 供电 | 7.4V T 型电池口、DC 8.4V 充电口、PD 为树莓派 5 供电 |

### GPIO 分配

| 电机 | PWM | DIR | 编码器 A | 编码器 B |
|:----|:----|:----|:---------|:---------|
| M1 | GPIO6 | GPIO7 | GPIO1 | GPIO2 |
| M2 | GPIO8 | GPIO9 | GPIO3 | GPIO4 |
| M3 | GPIO10 | GPIO11 | GPIO12 | GPIO13 |
| M4 | GPIO14 | GPIO15 | GPIO16 | GPIO17 |

| 接口 | GPIO |
|:----|:-----|
| 舵机 S1 | GPIO18 |
| 舵机 S2 | GPIO19 |
| MCU 指示灯 | GPIO45 |
| KEY1 按键 | GPIO42 |
| BOOT 按键 | GPIO0（启动模式选择，勿长拉低） |

| UART | TX | RX |
|:----|:---|:---|
| UART0 烧录/调试 | GPIO43 | GPIO44 |
| UART1 LiDAR | GPIO17 | GPIO18 |
| UART2 图传（V2） | GPIO36 | GPIO35 |

### 工作模式

| 模式 | 进入方式 | 行为 |
|:----|:--------|:-----|
| 正常运行 | 上电默认 | 加载 ROS2 节点，MCU 灯每 3 秒快闪两下 |
| 配置 | 上电按住 BOOT | 开 AP 热点，SSID `microROS_xxxxxx`、密码 `12345678`，灯每秒闪一次 |
| 测试 | 上电按住 KEY1 | 自测电机/舵机/IMU/蜂鸣器/LED，灯每 3 秒快闪三次 |
| 低电压 | 电池 < 7.0V | 蜂鸣器报警、灯快闪、限制电机功率 |

### 电源规格

- 电池：2S 锂电池 7.4V（T 型接口，推荐 2000–5000mAh）
- 充电：DC 8.4V / 2–3A，约 2–3 小时
- 低压保护：< 7.0V 报警

## 选型要点

- 需 WiFi 遥操作 → ESP32 系列
- 需工业可靠性/多 CAN → STM32
- 需快速原型 → Yahboom 板（外设已集成）
