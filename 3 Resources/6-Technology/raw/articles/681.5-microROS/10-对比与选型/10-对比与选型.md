# 10 对比与选型

## 三条协议线对照

> 本章直接服务本项目设计原则 #4「统一接口契约」。

| 维度 | micro-ROS | UGV JSON | RoboMaster SDK |
|:----|:----------|:---------|:---------------|
| 协议 | Micro XRCE-DDS | 自定义 JSON 文本 | 自定义文本 + 二进制 |
| 模型 | ROS 2 topic/service/action | 指令集 | 模块 API |
| 主控侧 | 标准 ROS 2 接口 | 需自写解析 | Python 库 |
| 跨平台复用 | 高（DDS 收敛） | 中（逐协议适配） | 低（绑定 DJI） |
| 实时性 | 串口/UDP | 串口 | 端口 20020 |
| 代表 | [[Yahboom]] 板 | [[3 Resources/6-Technology/raw/articles/681.5-UGV/681.5-UGV\|UGV01/02]] | [[RoboMaster]] S1/EP |

## micro-ROS vs rosserial

| 维度 | micro-ROS | rosserial |
|:----|:----------|:----------|
| 架构 | client-agent（XRCE-DDS） | 直连串口 |
| 多机 | 支持 | 单主限制 |
| 内存/类型 | 静态内存 + 类型系统 | 简单 |
| 状态 | 官方活跃维护 | 半废弃 |

## 收敛策略

1. **主控侧只认 ROS 2**：`/cmd_vel` + `/odom` + `sensor_msgs`
2. **底层差异下放**：RoboMaster/UGV 私有协议由驱动层/桥接节点翻译成 ROS 2 topic
3. **micro-ROS 作 MCU 层标准**：新底盘默认 ESP32 + micro-ROS 直接出标准 topic
