# 05 话题与通信

## Topic 发布/订阅

[[Topic-话题|话题]] 是 micro-ROS 最基本的通信实体，MCU 侧用 [[rclc|rclc]] 的 publisher/subscriber API，与上位机 ROS 2 完全同构。

```c
// 发布 /odom（伪码）
rcl_publisher_t pub;
rclc_publisher_init_default(&pub, &node,
  ROSIDL_GET_MSG_TYPE_SUPPORT(nav_msgs, msg, Odometry), "/odom");
```

MCU 侧 `rclc` 依赖 **executor** 驱动回调（单线程轮询），常用 `rclc_executor_spin`。

## 消息类型

- 标准类型：`std_msgs`、`sensor_msgs`（IMU/激光）、`nav_msgs/Odometry`、`geometry_msgs/Twist`（`/cmd_vel`）
- 自定义类型：由 `.msg` 定义，micro-ROS 编译时生成 C 类型（静态内存优先）

## 接口契约视角

> 对本项目而言，micro-ROS 的关键价值在于：把 `sensor_msgs/Imu`、`nav_msgs/Odometry`、`geometry_msgs/Twist` 这些**标准消息**当作统一接口契约——`/cmd_vel` + `/odom` 不因底盘更换而改变，只有板载驱动变。

## QoS 与传输

micro-ROS 支持有限 QoS（Best-Effort / Reliable），受串口带宽限制，高频大数据（如点云）需控制频率或降采样。
