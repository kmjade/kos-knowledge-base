# 11 应用与实战

## 典型案例

| 场景 | 链路 |
|:----|:-----|
| 底盘遥操作 | 摇杆 → `/cmd_vel` → micro-ROS → 电机 |
| 里程计 | 编码器 → `/odom` → 上位机 SLAM |
| 传感器采集 | IMU/LiDAR → `sensor_msgs` → 可视化/导航 |
| 多机集群 | 多 MCU 各挂 Agent，统一进 DDS 图 |

## 最小闭环：遥操作

1. 下位机订阅 `/cmd_vel`，驱动电机；发布 `/odom`
2. 上位机跑 rosbridge（9090），浏览器/摇杆发 `/cmd_vel`
3. Rviz2 订阅 `/odom` 显示轨迹

## 调试要点

- Agent 侧 `-v4` 看 Client 上线日志
- `ros2 topic list / echo` 验证链路
- 串口波特率、电平、交叉接线是高频坑

## 扩展方向

- 与 [[3 Resources/6-Technology/raw/articles/681.5-UGV/681.5-UGV|UGV 底盘]] 结合：ESP32 出标准 topic，替代私有 JSON
- 接入 本项目：模块化载荷（探测/喷药/播种）作独立 ROS 2 节点
