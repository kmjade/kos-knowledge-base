# 03 环境搭建

## 上位机侧

| 组件 | 用途 | 版本建议 |
|:----|:-----|:--------|
| ROS 2 | DDS 图 | Humble |
| [[micro-ROS-Agent\|micro-ROS Agent]] | 桥接 | humble 版 |
| Docker | 运行 agent（可选） | — |

Agent 两种装法：
- **Docker**（推荐）：`microros/micro-ros-agent:humble`
- **源码**：`micro_ros_setup` 构建

## 下位机侧（ESP32 为例）

工具链：**ESP-IDF** + **micro_ros_espidf_component**（把 micro-ROS 作为 ESP-IDF 组件引入）。

```c
// idf_component.yml
dependencies:
  micro_ros_espidf_component:
    git: https://github.com/micro-ROS/micro_ros_espidf_component.git
```

其他 MCU 走对应集成：STM32 用 `micro_ros_stm32cubemx_utils`，Pico 用 Arduino/`micro_ros_arduino` 等。

## 构建工具 micro_ros_setup

`micro_ros_setup` 是官方工具，用于：
1. 下载/配置 micro-ROS 与目标平台工具链
2. 生成静态/动态类型支持固件
3. 交叉编译并烧录固件

## 最小验证

烧录后，Agent 侧应看到 Client 上线；发布一个 `std_msgs/msg/String` 话题，上位机 `ros2 topic echo` 能收到，即链路打通。
