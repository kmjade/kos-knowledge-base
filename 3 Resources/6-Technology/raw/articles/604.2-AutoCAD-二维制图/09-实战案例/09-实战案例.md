# 09 实战案例

## 案例总览

| 案例 | 难度 | 覆盖 |
|------|:----:|------|
| 机械零件图 | ⭐⭐ | 绘图、标注、图层 |
| 建筑平面图 | ⭐⭐⭐ | 图层、块、外部参照 |
| 布局出图 | ⭐⭐ | 布局、视口、打印 |

## 案例一：机械零件图

```
1. 建图层：轮廓线/中心线/标注/隐藏线
2. 画中心线 → 画主视图轮廓 → 修剪/圆角
3. 画剖面视图
4. 线性/半径标注 + 公差
5. 填标题栏 → 布局出图
```

**要点**：图层规范、对象捕捉、尺寸标注样式统一。

## 案例二：建筑平面图

```
1. 建图层：轴线/墙体/门窗/标注/家具
2. 画轴线网（外部参照或直接绘制）
3. 多线/双线画墙体 → 修剪
4. 插入门窗块（动态块）
5. 文字标注房间名、尺寸标注
6. 布局设置 1:100 视口出图
```

**要点**：大量使用块（门窗）复用、图层组织、注释性标注。

## 案例三：布局出图

```
模型空间 1:1 画好 → 布局空间：
1. 插入图框块（A3/A2）
2. 创建视口 → 设置比例（如 1:50）
3. 锁定视口
4. 打印样式（CTB）控制线宽
5. 打印/导出 PDF
```

**要点**：模型空间真实尺寸、布局空间排版、注释性保证多比例一致。
