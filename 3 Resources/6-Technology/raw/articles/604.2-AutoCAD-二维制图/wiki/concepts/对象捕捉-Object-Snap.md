# 对象捕捉 Object Snap

## 定义

对象捕捉（Osnap）精确捕捉几何点（端点、中点、圆心、交点等），是 AutoCAD 精确制图的关键机制。

## 常用捕捉

| 捕捉 | 说明 |
|------|------|
| END / MID | 端点 / 中点 |
| CEN / QUA | 圆心 / 象限点 |
| INT / PER | 交点 / 垂足 |
| TAN | 切点 |
