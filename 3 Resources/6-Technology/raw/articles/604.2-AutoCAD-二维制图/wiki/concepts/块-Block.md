# 块 Block

## 定义

块是可复用的命名对象组合，一次定义、多处插入。块定义修改后所有实例同步更新，是 AutoCAD 提效的关键。

## 能力

| 能力 | 说明 |
|------|------|
| 创建/插入 | BLOCK / INSERT |
| 块属性 | 附加文字信息 |
| 动态块 | 参数化、可变形态 |
| 块计数 | 统计数量 |
