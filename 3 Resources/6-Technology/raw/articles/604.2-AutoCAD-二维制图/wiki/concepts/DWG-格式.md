# DWG 格式

## 定义

DWG 是 AutoCAD 的原生文件格式，也是 CAD 行业事实标准，用于存储二维/三维图形数据。

## 相关格式

| 格式 | 说明 |
|------|------|
| DWG | 原生格式 |
| DXF | 开放交换格式 |
| DWT | 模板文件 |
| PDF / DWF | 输出/共享格式 |
