# 图层 Layer

## 定义

图层是 AutoCAD 组织与管理对象的核心机制，把同类对象放在同一图层，统一控制颜色、线型、线宽与可见性。

## 图层属性

| 属性 | 说明 |
|------|------|
| 颜色 / 线型 / 线宽 | 对象显示与打印属性 |
| 开/关、冻结/解冻 | 可见性与计算参与 |
| 锁定 | 可见但不可编辑 |
