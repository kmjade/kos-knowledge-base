# 命令行 Command Line

## 定义

命令行是 AutoCAD 的标志性交互方式，几乎所有操作都能通过输入命令（或缩写）完成，是提升效率的关键。

## 常用缩写

| 缩写 | 命令 |
|------|------|
| L | LINE |
| C | CIRCLE |
| TR | TRIM |
| O | OFFSET |
| M | MOVE |
