# 06 布局与打印

## 模型空间 vs 布局空间

| 空间 | 说明 |
|------|------|
| **模型空间（Model）** | 按真实尺寸 1:1 绘制 |
| **布局空间（Layout/Paper）** | 组织打印，设置图框与视口 |

> 核心原则：**模型空间画真实尺寸，布局空间排图出图**。

## 视口（Viewport）

布局中的视口是「窗口」，透过它查看模型空间的图形：

| 要点 | 说明 |
|------|------|
| 创建视口 | 布局里画矩形视口 |
| 设置比例 | 每个视口可设不同比例 |
| 视口锁定 | 防止误缩放 |
| 多视口 | 一图多视角/多比例 |

## 打印（Plot）

| 要素 | 说明 |
|------|------|
| 打印机/绘图仪 | 输出设备 |
| 图纸尺寸 | A0–A4 |
| 打印比例 | 1:1、1:2、1:100… |
| 打印样式（CTB/STB） | 线宽、颜色输出控制 |
| 输出格式 | PDF、DWF、图片 |

## 图框与标题栏

| 要素 | 说明 |
|------|------|
| 图框 | 标准图幅（带边距） |
| 标题栏 | 项目名、图号、比例、日期 |
| 字段（Field） | 自动更新的文字（日期、文件名） |
