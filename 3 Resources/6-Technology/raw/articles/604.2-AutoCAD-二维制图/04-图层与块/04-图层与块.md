# 04 图层与块

## 图层（Layer）

图层是 AutoCAD 的对象组织与管理核心——把同类对象放在同一图层，统一控制其颜色、线型、线宽与可见性。

| 图层属性 | 说明 |
|----------|------|
| 颜色（Color） | 对象颜色 |
| 线型（Linetype） | 实线/虚线/点划线/中心线 |
| 线宽（Lineweight） | 打印线宽 |
| 开/关、冻结/解冻 | 控制可见性与参与计算 |
| 锁定 | 可见但不可编辑 |

> 专业制图惯例：按功能分图层（轮廓线、中心线、标注、文字、隐藏线…）。

## 块（Block）

块是可复用的命名对象组合，插入一次即创建一个实例：

| 能力 | 说明 |
|------|------|
| 块定义（BLOCK） | 创建块 |
| 插入（INSERT） | 插入块实例 |
| 块属性（ATTRIB） | 附加文字信息（如零件号） |
| 块编辑（BEDIT） | 编辑块定义，所有实例同步更新 |
| 块计数 | 统计块数量 |

## 动态块（Dynamic Block）

动态块在块定义中加入参数与动作，插入后可拉伸、旋转、翻转、阵列，一个块替代多个静态块。

## 设计中心与工具选项板

| 工具 | 用途 |
|------|------|
| 设计中心（ADC） | 跨图纸复用图层、块、样式 |
| 工具选项板 | 拖拽插入常用块与命令 |
