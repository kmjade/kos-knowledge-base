# 05 标注与文字

## 尺寸标注（Dimension）

| 标注类型 | 命令 | 用途 |
|----------|------|------|
| 线性标注 | DIMLINEAR | 水平/垂直尺寸 |
| 对齐标注 | DIMALIGNED | 斜线尺寸 |
| 半径/直径 | DIMRADIUS / DIMDIAMETER | 圆/圆弧 |
| 角度标注 | DIMANGULAR | 角度 |
| 连续/基线标注 | DIMCONTINUE / DIMBASELINE | 链式标注 |
| 引线标注 | LEADER | 指引说明 |

## 文字（Text）

| 类型 | 说明 |
|------|------|
| 单行文字（TEXT） | 简单单行 |
| 多行文字（MTEXT） | 段落、格式、符号 |
| 文字样式 | 字体、高度、宽度因子 |

## 注释性（Annotative）

注释性对象（标注、文字、填充）会自动随视口比例缩放，保证不同比例的视口里打印大小一致——这是多比例出图的关键。

## 标注样式（Dimstyle）

统一管理尺寸的外观（箭头、文字、单位、公差），建议创建企业/项目标准样式。
