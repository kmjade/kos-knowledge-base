# 02 界面与命令

## 界面组成

| 区域 | 功能 |
|------|------|
| 功能区（Ribbon） | 顶部选项卡式工具栏 |
| 命令行 | 底部，输入命令（AutoCAD 标志性特性） |
| 绘图区 | 中央，绘制图形 |
| 状态栏 | 底部，对象捕捉、栅格、坐标开关 |
| 属性面板 | 查看/修改对象属性 |

## 命令行

命令行是 AutoCAD 的核心交互方式——几乎所有操作都能通过输入命令完成：

```
LINE（L）      画直线
CIRCLE（C）    画圆
TRIM（TR）     修剪
EXTEND（EX）   延伸
OFFSET（O）    偏移
MOVE（M）      移动
COPY（CO）     复制
```

> 记住常用命令缩写能大幅提升绘图效率。

## 坐标系

| 坐标类型 | 说明 |
|----------|------|
| 绝对坐标 | `X,Y`（如 `10,20`） |
| 相对坐标 | `@X,Y`（相对上一点） |
| 极坐标 | `@距离<角度`（如 `@50<30`） |

## 对象捕捉（Object Snap）

精确捕捉几何点，是精确制图的关键：

| 捕捉 | 说明 |
|------|------|
| END | 端点 |
| MID | 中点 |
| CEN | 圆心 |
| INT | 交点 |
| PER | 垂足 |
| TAN | 切点 |

> 快捷键 `F3` 开关对象捕捉，`F8` 开关正交（Ortho）。
