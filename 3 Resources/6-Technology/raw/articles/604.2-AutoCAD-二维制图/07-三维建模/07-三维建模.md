# 07 三维建模

## 三维对象类型

| 类型 | 说明 |
|------|------|
| 线框（Wireframe） | 仅边线 |
| 曲面（Surface） | 无厚度的面 |
| 实体（Solid） | 有体积的实体模型（最常用） |
| 网格（Mesh） | 多边形网格 |

## 三维实体创建

| 命令 | 作用 |
|------|------|
| BOX | 长方体 |
| CYLINDER | 圆柱体 |
| SPHERE | 球体 |
| CONE | 圆锥 |
| EXTRUDE | 拉伸（二维轮廓 → 实体） |
| REVOLVE | 旋转成体 |
| LOFT | 放样 |
| SWEEP | 扫掠 |

## 实体编辑

| 命令 | 作用 |
|------|------|
| UNION | 并集（合并实体） |
| SUBTRACT | 差集（挖去） |
| INTERSECT | 交集 |
| FILLETEDGE | 边倒圆 |
| CHAMFEREDGE | 边倒角 |

## 视图与视觉样式

| 视觉样式 | 说明 |
|----------|------|
| 二维线框 | 线框 |
| 隐藏 | 隐藏背面线 |
| 真实（Realistic） | 带材质着色 |
| 概念（Conceptual） | 概念着色 |

> AutoCAD 2026 通过 Graphics System Fabric（GSF）改善概念/隐藏样式的图形性能。

## 渲染

| 要素 | 说明 |
|------|------|
| 材质 | 赋予对象材质 |
| 光源 | 点光、聚光、天光 |
| 渲染 | 输出照片级图像 |
