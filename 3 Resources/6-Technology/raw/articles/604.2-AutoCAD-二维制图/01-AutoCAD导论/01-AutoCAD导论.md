# 01 AutoCAD 导论

## 什么是 AutoCAD

AutoCAD 是 Autodesk 旗下的通用 CAD / 制图平台，以**二维绘图**为核心、兼具三维建模能力，广泛用于建筑、工程、制造等领域的图纸绘制与设计。

## Autodesk（欧特克）

| 要点 | 说明 |
|------|------|
| 母公司 | Autodesk（美国工业软件巨头，旗下还有 Revit、Inventor、Fusion 360、3ds Max） |
| AutoCAD 首发 | 1982 年 12 月（首个 PC 平台 CAD 程序之一） |
| 地位 | 全球最广泛使用的 CAD 制图软件之一 |

## 核心特性

| 特性 | 说明 |
|------|------|
| 精确绘图 | 基于坐标与对象捕捉的精确制图 |
| 图层组织 | 用图层管理对象属性与可见性 |
| 块复用 | 可复用的命名对象，配合动态块 |
| 命令行 | 标志性的命令驱动操作 |
| 可扩展 | AutoLISP / .NET API / 脚本自动化 |

## 版本演进

| 版本 | 年份 | 关键变化 |
|------|------|----------|
| AutoCAD 1.0 | 1982 | 首个 PC CAD 版本 |
| R14 / 2000 | 1990s 末 | 现代化界面 |
| 按年份命名 | 2010s 起 | 每年一个版本（2024/2025/2026…） |
| **AutoCAD 2026** | 2025-04 | 第 40 版：AI 赋能（Smart Blocks）、11x 打开速度 |

## AutoCAD 2026 AI 能力

| 功能 | 说明 |
|------|------|
| Smart Blocks（搜索/转换） | 识别重复几何并建议转换为块 |
| Smart Blocks（检测/转换） | AI 扫描整图识别重复图形 |
| 标记导入/辅助 | 从 PDF/JPG/PNG 导入反馈，AI 识别 MOVE/COPY 等指令 |
| 活动洞察「有何变更」 | 编辑会话详细分解 |
| 连接的支持文件 | 通过 Autodesk Docs 共享项目支持文件 |

## 版本类型

| 版本 | 说明 |
|------|------|
| **AutoCAD** | 完整版（2D + 3D） |
| **AutoCAD LT** | 仅二维，价格更低 |
| Web / Mobile | 云端与移动端 |
