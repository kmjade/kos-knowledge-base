# 03 二维绘图基础

## 绘图命令

| 命令 | 缩写 | 作用 |
|------|:----:|------|
| LINE | L | 画直线 |
| CIRCLE | C | 画圆 |
| ARC | A | 画圆弧 |
| RECTANGLE | REC | 画矩形 |
| POLYGON | POL | 画正多边形 |
| POLYLINE | PL | 画多段线（连续线段/弧） |
| ELLIPSE | EL | 画椭圆 |
| HATCH | H | 填充图案 |

## 修改命令

| 命令 | 缩写 | 作用 |
|------|:----:|------|
| MOVE | M | 移动 |
| COPY | CO | 复制 |
| ROTATE | RO | 旋转 |
| SCALE | SC | 缩放 |
| TRIM | TR | 修剪 |
| EXTEND | EX | 延伸 |
| OFFSET | O | 偏移 |
| MIRROR | MI | 镜像 |
| ARRAY | AR | 阵列（矩形/环形） |
| FILLET | F | 倒圆角 |
| CHAMFER | CHA | 倒角 |

## 多段线（Polyline）

多段线是一条由多段直线/弧组成的**单一对象**，可整体编辑宽度、闭合，是 AutoCAD 最常用的图元之一。

## 图层（Layer）基础

图层用于组织对象并控制其属性（颜色、线型、线宽、打印），是专业制图的基础（详见 [[04-图层与块]]）。

## 典型绘图流程

```
设置图层 → 画中心线 → 画轮廓 → 修剪/圆角 → 标注 → 检查
```
