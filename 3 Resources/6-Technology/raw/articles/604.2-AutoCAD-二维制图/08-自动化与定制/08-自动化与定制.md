# 08 自动化与定制

## AutoLISP

AutoCAD 内建的脚本语言，用于自动化重复操作与定制功能：

```lisp
;; 画一个边长 100 的正方形
(defun c:sq ()
  (command "RECTANG" "0,0" "100,100")
)
```

- 加载：`(load "myscript.lsp")`
- 定义命令：`(defun c:命令名 () ...)`

## 脚本（Script）

`.scr` 脚本文件按顺序执行命令，适合批量操作：

```
LINE 0,0 100,0 100,100 C
ZOOM E
```

运行：`SCRIPT` 命令选择脚本文件。

## 定制界面

| 定制 | 说明 |
|------|------|
| CUI | 自定义用户界面（功能区、工具栏、快捷键） |
| 快捷键别名 | acad.pgp 文件定义命令缩写 |
| 自定义线型/填充 | 线型文件、填充图案 |

## 外部参照（Xref）

外部参照把其他 DWG 文件引用到当前图中，用于协作与多专业协同：

| 能力 | 说明 |
|------|------|
| 附着（Attach） | 引用外部 DWG |
| 参照管理器 | 管理参照 |
| 绑定/拆离 | 合并或断开参照 |
| eTransmit | 打包图纸与依赖 |

> 外部参照常用于：建筑图引用结构/机电底图、团队分工协作。
