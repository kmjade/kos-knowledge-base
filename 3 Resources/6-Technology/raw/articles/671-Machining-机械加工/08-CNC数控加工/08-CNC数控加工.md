# 08 CNC 数控加工

## 数控加工

数控（Numerical Control，NC）通过**数字化指令**控制机床运动，实现自动化、高精度、可重复的加工；计算机数控（CNC）用计算机生成并执行加工程序。

## 控制方式

| 方式 | 特点 |
|------|------|
| 开环 | 步进电机，无反馈 |
| 闭环 | 伺服电机 + 位置反馈，精度高 |

## 数控编程（G/M 代码）

| 代码 | 含义 |
|------|------|
| G00 | 快速定位 |
| G01 | 直线插补 |
| G02 / G03 | 顺/逆圆弧插补 |
| M03 / M05 | 主轴正转 / 停止 |
| M30 | 程序结束并复位 |

- CAM 软件由 CAD 模型自动生成刀路与代码

## 加工中心（MC）

加工中心是**带自动换刀（ATC）刀库**的数控机床，一次装夹完成铣、钻、镗、攻丝等多工序；多轴（3/4/5 轴）实现复杂曲面。
