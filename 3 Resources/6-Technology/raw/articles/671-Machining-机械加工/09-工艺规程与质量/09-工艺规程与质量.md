# 09 工艺规程与质量

## 工艺规程

工艺规程规定零件的**加工路线**：工序 → 工步 → 装夹 → 刀具 → 切削参数，是组织生产的依据。

- **基准**：定位基准、测量基准
- **定位与夹紧**：保证加工精度

## 公差与配合

| 概念 | 说明 |
|------|------|
| 公差 | 允许的尺寸变动量（IT01–IT18 等级） |
| 配合 | 间隙配合 / 过渡配合 / 过盈配合 |
| 基孔制 / 基轴制 | 配合制度 |

## 表面粗糙度

- **Ra**（轮廓算术平均偏差）最常用
- **Rz**（微观不平度十点高度）
- 影响配合、耐磨、疲劳强度与外观

## 测量

| 量具 | 用途 |
|------|------|
| 游标卡尺 | 内外径、深度 |
| 千分尺 | 高精度尺寸（0.01/0.001 mm） |
| 三坐标测量机（CMM） | 复杂几何检测 |
