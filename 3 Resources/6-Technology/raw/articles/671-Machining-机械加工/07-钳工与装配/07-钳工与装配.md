# 07 钳工与装配

## 钳工

钳工是以**手工工具**为主的工种，是机加工（车铣刨磨）的补充与装配环节。

| 工序 | 说明 |
|------|------|
| 划线 | 按图纸在毛坯上标记加工位置 |
| 锯削 | 下料 |
| 锉削 | 锉刀修整表面 |
| 刮削 | 高精度平面/配合面 |
| 攻丝/套丝 | 内外螺纹 |

## 装配

- 把零件按图纸组装成部件/整机
- 配合、间隙、紧固、调试
- 钳工技能：初级工 → 中级工 → 高级工 → 技师 → 高级技师
