# 02 切削原理

## 切削运动

- **主运动**：切除材料的主要运动（车削中工件的旋转）
- **进给运动**：使切削持续进行的辅助运动（车刀的进给）

## 切屑形成

| 切屑类型 | 条件 |
|----------|------|
| 带状切屑 | 塑性材料、高速 |
| 节状切屑 | 中等速度 |
| 粒状切屑 | 低速 |
| 崩碎切屑 | 脆性材料（铸铁） |

## 切削三要素

| 要素 | 符号 | 单位 |
|------|:--:|------|
| 切削速度 | v | m/min |
| 进给量 | f | mm/r |
| 背吃刀量 | ap | mm |

## 切削力与切削热

- 切削力分解为主切削力、进给力、背向力
- 切削热大部分由切屑带走，需**切削液**冷却润滑

## 刀具材料

| 材料 | 特点 |
|------|------|
| 高速钢（HSS） | 韧性好、通用 |
| 硬质合金 | 硬度高、耐热、主流 |
| 陶瓷 | 高速精加工 |
| 立方氮化硼（CBN） | 淬硬钢精加工 |
| 金刚石（PCD） | 有色金属、复合材料 |
