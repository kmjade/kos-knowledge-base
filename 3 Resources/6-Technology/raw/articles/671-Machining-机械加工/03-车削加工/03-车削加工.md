# 03 车削加工

## 车削与车床

车削是**工件旋转、车刀进给**的切削方式，在车床上完成，主要用于加工回转体零件（轴、盘、套）。

## 装夹

| 方式 | 适用 |
|------|------|
| 三爪卡盘 | 圆形工件自定心 |
| 四爪卡盘 | 不规则工件、找正 |
| 顶尖 + 卡盘 | 长轴 |
| 心轴 | 套类精加工 |

## 典型车削操作

| 操作 | 说明 |
|------|------|
| 车外圆 | 轴类外表面 |
| 车端面 | 保证长度与垂直度 |
| 镗孔 | 内孔加工 |
| 车螺纹 | 三角/梯形螺纹 |
| 切断/切槽 | 分割与沟槽 |
