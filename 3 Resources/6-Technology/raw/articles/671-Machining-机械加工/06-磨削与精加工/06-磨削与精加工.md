# 06 磨削与精加工

## 磨削

磨削用**高速旋转的砂轮**作刀具，可获得高精度（IT5–IT6）与低粗糙度，是精加工的主要手段。

## 砂轮

| 参数 | 说明 |
|------|------|
| 磨料 | 氧化铝、碳化硅、CBN、金刚石 |
| 粒度 | 粗细决定表面质量 |
| 结合剂 | 陶瓷、树脂、金属 |
| 硬度 | 磨粒脱落难易 |

## 磨削类型

| 类型 | 用途 |
|------|------|
| 外圆磨 | 轴类外表面 |
| 内圆磨 | 孔 |
| 平面磨 | 平面 |
| 无心磨 | 大批量圆柱件 |

## 超精加工

| 工艺 | 说明 |
|------|------|
| 研磨 | 研具 + 磨料，极高精度 |
| 珩磨 | 孔的精整加工 |
| 抛光 | 表面光亮 |
| 超精加工 | 极低粗糙度 |
