# 数控机床 CNC Machine Tool

## 概述

数控机床由**数控系统（CNC）**控制，按程序指令自动完成切削加工，实现高精度、高一致性与复杂轮廓加工。

## 关键要点

| 要点 | 说明 |
|------|------|
| 控制系统 | 发那科 FANUC、西门子 SINUMERIK、三菱等 |
| 类型 | 数控车床、数控铣床、加工中心、数控磨床 |
| 编程 | G/M 代码，CAM 自动生成 |
