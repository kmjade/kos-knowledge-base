# 钳工 Bench Work

## 定义

钳工是以**手工工具**为主的工种，负责划线、锉削、锯削、刮削、攻丝套丝与装配，是机加工（车铣刨磨）的补充与总装环节。

## 关键工序

| 工序 | 说明 |
|------|------|
| 划线 | 按图纸标记加工位置 |
| 锉削/刮削 | 手工修整表面与配合面 |
| 攻丝/套丝 | 内外螺纹 |
| 装配 | 零件组装、调试 |
