# 数控编程 CNC Programming

## 定义

数控编程是编写 **G/M 代码**指令，控制数控机床按预定轨迹与工艺参数自动加工的过程。CAM 软件可从 CAD 模型自动生成刀路与程序。

## 常用代码

| 代码 | 含义 |
|------|------|
| G00 | 快速定位 |
| G01 | 直线插补 |
| G02 / G03 | 顺/逆圆弧插补 |
| M03 / M05 | 主轴正转 / 停止 |
| M30 | 程序结束并复位 |
