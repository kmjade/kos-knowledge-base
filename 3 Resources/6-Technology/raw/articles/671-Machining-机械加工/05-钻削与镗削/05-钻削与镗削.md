# 05 钻削与镗削

## 钻削

用钻头在工件上加工孔，麻花钻是最常用的刀具。

| 工序 | 说明 |
|------|------|
| 钻孔 | 粗加工孔 |
| 扩孔 | 扩大已有孔 |
| 铰孔 | 精加工孔，IT7–IT9 |
| 锪孔 | 孔口倒角/沉孔 |

## 攻丝（螺纹加工）

- **攻丝**：在孔内加工内螺纹（丝锥）
- **套丝**：在圆杆上加工外螺纹（板牙）
- 机用丝锥 / 手用丝锥

## 镗削

镗削用于**扩大并校正已有孔**，精度高于钻孔，可在镗床或加工中心上进行，适合大孔与同轴孔系。
