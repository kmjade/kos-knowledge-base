# 04 铣削加工

## 铣削与铣床

铣削是**多刃刀具旋转、工件进给**的切削方式，在铣床上完成，用于平面、沟槽、曲面与齿轮。

## 铣刀

| 类型 | 用途 |
|------|------|
| 面铣刀 | 平面 |
| 立铣刀 | 沟槽、侧面、型腔 |
| 三面刃铣刀 | 槽与台阶 |
| 成形铣刀 | 特定轮廓（齿轮、螺纹） |

## 顺铣 vs 逆铣

| 方式 | 特点 |
|------|------|
| 顺铣 | 表面质量好、机床需消隙 |
| 逆铣 | 稳定、常用 |

## 典型操作

- 铣平面、铣沟槽、铣键槽、铣成形面
- 齿轮加工：成形法 / 展成法（滚齿、插齿）
