# 02 电子元件

## 无源元件

| 元件 | 功能 | 单位 |
|------|------|------|
| 电阻 | 限流/分压 | 欧姆（Ω） |
| 电容 | 储能/滤波 | 法拉（F） |
| 电感 | 储能/滤波 | 亨利（H） |

## 有源元件

| 元件 | 功能 |
|------|------|
| 二极管 | 单向导电、整流 |
| 三极管（BJT） | 放大/开关 |
| MOSFET | 开关/功率 |
| LED | 发光二极管 |

## 元件参数

- 阻值/容值/耐压
- 精度、温漂、功率
- 封装（贴片/直插）
