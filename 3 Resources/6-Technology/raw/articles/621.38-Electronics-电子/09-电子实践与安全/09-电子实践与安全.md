# 09 电子实践与安全

## 焊接

| 要点 | 说明 |
|------|------|
| 烙铁温度 | 300–350°C |
| 焊锡 | 无铅/含铅 |
| 助焊剂 | 改善润湿 |

## 调试

| 步骤 | 说明 |
|------|------|
| 目检 | 检查焊接/短路 |
| 通电 | 分步上电 |
| 测量 | 万用表/示波器 |
| 隔离 | 逐模块排查 |

## 安全须知

| 注意 | 说明 |
|------|------|
| 高压 | 电容放电、隔离 |
| 静电 | ESD 防护 |
| 烙铁 | 防烫伤 |
| 锂电池 | 防过充/短路 |

## 实战建议

1. 从 Arduino + 面包板入门
2. 学焊接 + 万用表
3. 做 PCB 打样
4. 进阶 STM32/ESP32
