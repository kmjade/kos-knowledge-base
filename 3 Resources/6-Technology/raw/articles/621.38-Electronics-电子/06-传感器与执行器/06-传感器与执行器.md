# 06 传感器与执行器

## 传感器

| 传感器 | 测量 |
|--------|------|
| 温度（NTC/DS18B20） | 温度 |
| 光敏/光强 | 光 |
| 红外/超声 | 距离 |
| IMU | 姿态 |
| 压力 | 压力 |

## 执行器

| 执行器 | 说明 |
|--------|------|
| 直流电机 | 驱动 |
| 步进电机 | 定位 |
| 舵机 | 角度 |
| 继电器 | 开关 |

## 驱动

电机驱动（H 桥、L298N、DRV8825）与接口（PWM、I2C、SPI、UART）。
