# 05 集成电路

## IC 分类

| 类型 | 说明 |
|------|------|
| 模拟 IC | 运放、电源管理 |
| 数字 IC | 逻辑、存储 |
| 混合信号 IC | ADC/DAC |
| 微控制器（MCU） | 单片机 |
