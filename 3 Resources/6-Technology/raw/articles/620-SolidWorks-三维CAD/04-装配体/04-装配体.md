# 04 装配体

## 装配体概述

装配体把多个零件按约束关系组合成完整产品。SolidWorks 的装配体与零件全关联——修改零件，装配体自动更新。

## 配合（Mate）

配合定义零件间的几何约束关系：

| 配合类型 | 作用 |
|----------|------|
| 重合（Coincident） | 面/点/线对齐 |
| 平行（Parallel） | 保持平行 |
| 垂直（Perpendicular） | 保持垂直 |
| 相切（Tangent） | 面与面相切 |
| 同轴（Concentric） | 圆柱/圆孔对齐 |
| 距离/角度（Distance/Angle） | 定量约束 |

## 两种装配设计方法

| 方法 | 说明 |
|------|------|
| **自下而上** | 先建零件，再逐个装配（传统、直观） |
| **自上而下** | 在装配体中直接建模（适合创新设计、关联驱动） |

## 干涉检查

检测零件间是否发生干涉（重叠），确保可装配：

- 「评估 → 干涉检查」选择零件 → 报告干涉体积
- 用于发现设计错误，避免制造后无法装配

## 大装配性能

| 工具 | 用途 |
|------|------|
| 轻化（Lightweight） | 减少内存占用 |
| 大型装配体模式 | 自动优化显示 |
| SpeedPak | 简化子装配表示 |
| 选择性加载 | 只加载需要的组件 |
