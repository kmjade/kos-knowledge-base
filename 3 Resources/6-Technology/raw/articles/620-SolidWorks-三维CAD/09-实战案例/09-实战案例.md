# 09 实战案例

## 案例总览

| 案例 | 难度 | 覆盖 |
|------|:----:|------|
| 零件设计 | ⭐⭐ | 零件建模 |
| 装配体 | ⭐⭐⭐ | 装配、配合 |
| 工程图出图 | ⭐⭐ | 工程图 |
| 仿真验证 | ⭐⭐⭐ | Simulation |

## 案例一：支架零件设计

```
上视基准面 → 草图（L 形轮廓，完全定义）→ 拉伸 8mm
→ 打孔（φ6 通孔 ×2，阵列）
→ 圆角 R3
→ 保存 .SLDPRT
```

**要点**：草图完全定义、先主体后细节、命名特征。

## 案例二：装配体

```
新建装配体 → 插入底座零件（固定）
→ 插入支架（配合：重合 + 同轴 + 距离）
→ 插入螺栓（配合：同轴 + 重合）
→ 干涉检查 → 无干涉
→ 保存 .SLDASM
```

**要点**：固定第一个零件、合理配合、定期干涉检查。

## 案例三：工程图出图

```
从装配体 → 新建工程图
→ 插入标准三视图 + 剖面视图
→ 智能尺寸标注 + 公差 + 表面粗糙度
→ 填标题栏（属性链接）
→ 保存 .SLDDRW / 导出 PDF
```

**要点**：视图布局、关键尺寸、制造要求标注。

## 案例四：仿真验证

```
打开零件 → Simulation 新建算例（线性静力）
→ 指定材料（如 6061 铝合金）
→ 固定约束（安装面）
→ 施加载荷（压力/力）
→ 生成网格 → 运行
→ 查看应力云图与安全系数
```

**要点**：合理简化、正确约束、校核安全系数 > 1。
