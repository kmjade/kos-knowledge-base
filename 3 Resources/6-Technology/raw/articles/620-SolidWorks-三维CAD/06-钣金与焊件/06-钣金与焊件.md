# 06 钣金与焊件

## 钣金（Sheet Metal）

SolidWorks 钣金模块专为薄板金属件设计，支持展开与折弯。

| 功能 | 说明 |
|------|------|
| 基体法兰（Base Flange） | 从草图创建钣金基体（2026 可从曲面/面/顶点起） |
| 边线法兰（Edge Flange） | 沿边添加折弯 |
| 折弯（Bend） | 生成折弯 |
| 展开（Flat Pattern） | 一键展开为平面下料图 |
| 成型工具 | 压凸、百叶窗等冲压特征 |

## 焊件（Weldments）

焊件模块用于结构件（框架、支架、型材）设计：

| 功能 | 说明 |
|------|------|
| 结构件（Structural Member） | 沿草图线段生成型材（方管、角钢、工字钢） |
| 焊缝（Weld Bead） | 添加焊缝 |
| 角撑板/端盖 | 连接处加强件 |
| 切割清单（Cut List） | 自动生成型材清单与下料长度 |

## 典型应用

| 场景 | 模块 |
|------|------|
| 机箱/外壳/支架 | 钣金 |
| 框架/机架/桁架 | 焊件 |
| 混合结构 | 钣金 + 焊件组合 |
