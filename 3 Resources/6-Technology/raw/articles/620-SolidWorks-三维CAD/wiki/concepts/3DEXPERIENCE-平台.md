# 3DEXPERIENCE 平台

## 定义

3DEXPERIENCE 是达索系统的云端协同平台，把 SolidWorks 连接到云端协作、数据管理与高级应用。

## 能力

| 能力 | 说明 |
|------|------|
| 云存储 | 集中管理设计数据 |
| 协同设计 | 多人实时协作 |
| xDesign / xMotion | 云端建模与运动 |
| PLM | 产品全生命周期管理 |
