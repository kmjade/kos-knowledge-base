# 配合 Mate

## 定义

配合（Mate）定义装配体中零件之间的几何约束关系，决定零件如何定位与运动。

## 类型

| 配合 | 作用 |
|------|------|
| 重合 | 面/点/线对齐 |
| 平行 / 垂直 | 方向约束 |
| 相切 | 面与面相切 |
| 同轴 | 圆柱/孔对齐 |
| 距离 / 角度 | 定量约束 |
