# 仿真 FEA Simulation

## 定义

SolidWorks Simulation 是完全集成的结构分析工具，基于有限元分析（FEA），在制造前验证设计强度。

## 分析类型

| 类型 | 说明 |
|------|------|
| 线性静力 | 应力、位移、安全系数 |
| 频率 / 屈曲 | 模态、失稳 |
| 疲劳 | 交变载荷寿命 |
| 热 | 温度场、热应力 |
| 非线性 / 动力学 | 大变形、碰撞 |
