# SolidWorks Flow Simulation

SolidWorks 的流体与热仿真模块，基于 CFD，用于内流/外流流动分析、传热分析与电子散热优化。

## 能力

| 能力 | 说明 |
|------|------|
| 流体流动 | 内流/外流 |
| 传热 | 传导、对流、辐射 |
| 电子散热 | 机箱风道、散热器优化 |
