# 05 工程图

## 工程图概述

工程图把三维模型投影为二维图纸，用于制造与交流。SolidWorks 的工程图与模型**全关联**——改模型，图纸自动更新。

## 视图类型

| 视图 | 说明 |
|------|------|
| 标准三视图 | 前视、上视、右视 |
| 投影视图 | 从已有视图投影 |
| 剖面视图 | 切开显示内部 |
| 局部放大图 | 放大细节 |
| 断裂视图 | 压缩长零件显示 |
| 辅助视图 | 沿斜面方向投影 |

## 标注

| 标注 | 说明 |
|------|------|
| 智能尺寸 | 快速标注尺寸 |
| 公差 | 尺寸公差（配合/极限） |
| 表面粗糙度 | 表面光洁度符号 |
| 形位公差（GD&T） | 几何公差标注 |
| 焊接符号 | AWS A2 标准（2026 增强） |
| 技术要求 | 文字注释 |

## 图框与标题栏

| 要素 | 说明 |
|------|------|
| 图框 | 图纸格式（A0–A4） |
| 标题栏 | 零件名、图号、材料、比例、日期 |
| 属性链接 | 链接零件自定义属性 |

## MBD（Model-Based Definition）

MBD 直接在三维模型上标注尺寸与公差（3D 标注），减少对 2D 图纸的依赖，是制造数字化趋势。SolidWorks 2026 增强 3D 坐标尺寸支持。
