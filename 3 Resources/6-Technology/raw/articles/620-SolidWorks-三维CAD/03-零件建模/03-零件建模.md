# 03 零件建模

## 参数化建模

SolidWorks 采用**参数化、基于特征**的建模：模型由一系列特征堆叠而成，尺寸作为参数驱动几何，改尺寸即自动重建模型。

## 基础特征

| 特征 | 作用 |
|------|------|
| **拉伸（Extrude）** | 沿直线方向延伸草图 |
| **旋转（Revolve）** | 绕轴旋转草图（回转体） |
| **扫描（Sweep）** | 沿路径扫掠截面 |
| **放样（Loft）** | 在多个截面间过渡生成 |
| **边界（Boundary）** | 双向边界曲面/实体 |

## 修饰特征

| 特征 | 作用 |
|------|------|
| 圆角（Fillet） | 边倒圆 |
| 倒角（Chamfer） | 边倒角 |
| 抽壳（Shell） | 挖空实体、留壁厚 |
| 拔模（Draft） | 加脱模斜度 |
| 筋（Rib） | 加加强筋 |

## 参考特征

| 特征 | 作用 |
|------|------|
| 镜像（Mirror） | 对称复制 |
| 阵列（Pattern） | 线性/圆周/草图阵列 |
| 孔（Hole） | 标准孔（螺纹孔、沉头孔） |

## 建模建议

| 建议 | 说明 |
|------|------|
| 先大后小 | 先建主体，再加细节 |
| 草图完全定义 | 避免特征漂移 |
| 命名特征 | 便于后续维护 |
| 合理基准面 | 避免引用易变几何 |

## 典型流程示例

```
上视基准面 → 草图（矩形 50×30） → 拉伸 20mm → 圆角 R5 → 抽壳 2mm
```
