# 08 数据管理与协作

## SolidWorks PDM

产品数据管理（PDM）系统，管理设计文件的版本、权限与流程：

| 功能 | 说明 |
|------|------|
| 版本控制 | 文件历史与回滚 |
| 检入/检出 | 防止并发编辑冲突 |
| 工作流 | 审批、发布流程 |
| 搜索 | 按属性/名称快速查找 |
| 权限 | 角色与访问控制 |

## 3DEXPERIENCE 平台

达索系统的云端平台，把 SolidWorks 连接到云端协作、数据管理与高级应用：

| 能力 | 说明 |
|------|------|
| 云存储 | 集中管理设计数据 |
| 协同设计 | 多人实时协作 |
| xDesign / xMotion | 云端建模与运动 |
| 生命周期管理 | PLM 全流程 |

> SOLIDWORKS 2026 深化 3DEXPERIENCE 集成：托管切割清单、材料定义、批量上传。

## 文件与格式

| 类型 | 说明 |
|------|------|
| .SLDPRT | 零件文件 |
| .SLDASM | 装配体文件 |
| .SLDDRW | 工程图文件 |
| STEP / IGES | 中性交换格式 |
| STL | 3D 打印 |
