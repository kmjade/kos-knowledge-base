# 07 仿真与分析

## SolidWorks Simulation（FEA）

完全集成的结构分析工具，基于有限元分析（FEA），在制造前验证设计强度。

| 分析类型 | 说明 |
|----------|------|
| 线性静力分析 | 应力、位移、安全系数 |
| 非线性静力分析 | 大变形、材料非线性 |
| 频率分析 | 固有频率、模态 |
| 屈曲分析 | 失稳临界载荷 |
| 疲劳分析 | 交变载荷寿命 |
| 热分析 | 温度场与热应力 |

### 分析流程

```
材料属性 → 约束（固定/铰接）→ 载荷（力/压力/扭矩）→ 网格 → 求解 → 后处理
```

## Flow Simulation（流体/热）

| 能力 | 说明 |
|------|------|
| 流体流动 | 内流/外流 CFD |
| 传热 | 传导、对流、辐射 |
| 电子散热 | 机箱风道、散热器优化 |

## Plastics（注塑成型）

注塑成型分析：充填、保压、冷却、翘曲，验证塑料件可制造性。

## Motion（运动分析）

| 能力 | 说明 |
|------|------|
| 运动仿真 | 机构运动轨迹 |
| 动力学 | 力、加速度、碰撞 |

## 版本层级

| 工具 | 层级 |
|------|------|
| SimulationXpress / FloXpress | 基础（免费） |
| Simulation Standard | 线性静力 |
| Simulation Professional | + 频率/屈曲/热/疲劳 |
| Simulation Premium | + 非线性/动力学 |
