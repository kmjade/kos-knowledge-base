# 01 SolidWorks 导论

## 什么是 SolidWorks

SolidWorks 是达索系统（Dassault Systèmes）旗下的三维 CAD / 产品开发套件，采用**参数化、基于特征**的实体建模方式，覆盖零件、装配体、工程图与仿真，是机械设计与产品开发领域最主流的工具之一。

## 达索系统（Dassault Systèmes）

| 要点 | 说明 |
|------|------|
| 母公司 | 法国达索系统（工业软件巨头，旗下还有 CATIA、SIMULIA、DELMIA） |
| SolidWorks 起源 | 1993 年由 SolidWorks Corporation（Jon Hirschtick 等）创立 |
| 收购 | 1997 年被达索系统收购 |
| 定位 | 中端机械 CAD，与高端 CATIA 形成互补 |

## 核心特性

| 特性 | 说明 |
|------|------|
| 参数化建模 | 尺寸驱动，改尺寸自动更新模型 |
| 基于特征 | 拉伸、旋转、倒角等特征堆叠成模型 |
| 全关联 | 零件→装配→工程图双向关联，一处改处处更新 |
| 集成仿真 | 内置 FEA、流体、运动仿真 |

## 版本演进

| 版本 | 年份 | 关键变化 |
|------|------|----------|
| SolidWorks 95 | 1995 | 首个版本 |
| SolidWorks 1.0 商业化 | 1995 | Windows 原生三维 CAD |
| 按年份命名 | 2010s 起 | 每年一个大版本（2024/2025/2026…） |
| **SOLIDWORKS 2025** | 2024-09 | 零件/装配/工程图增强 |
| **SOLIDWORKS 2026** | 2025-11 | AI 赋能：生成式工程图、AURA 助手、装配结构生成器 |

## SOLIDWORKS 2026 AI 能力

| 功能 | 说明 |
|------|------|
| 生成式工程图 | 提示词引导生成工程图（Beta） |
| AURA 助手 | 从社区/文档提取知识回答问题 |
| 紧固件识别 | 自动识别螺母螺栓并装配 |
| 装配结构生成器 | 文本提示生成装配结构（Beta） |
| BREP 转参数化 | STEP/IGES 导入 → 可编辑特征模型 |

## 版本层级

| 版本 | 内容 |
|------|------|
| **Standard** | 零件、装配、工程图 |
| **Professional** | + 钣金、焊件、PDM、Toolbox |
| **Premium** | + 仿真、布线、运动分析 |
