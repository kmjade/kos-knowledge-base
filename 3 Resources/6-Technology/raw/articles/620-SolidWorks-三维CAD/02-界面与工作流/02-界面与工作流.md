# 02 界面与工作流

## 界面组成

| 区域 | 功能 |
|------|------|
| CommandManager | 顶部选项卡式工具栏，按功能分组 |
| FeatureManager 设计树 | 左侧，列出零件/装配的特征历史 |
| 图形区 | 中央，显示与操作模型 |
| 任务窗格 | 右侧，资源、库、设计库 |
| 状态栏 | 底部，显示单位、光标位置 |

## FeatureManager 设计树

设计树是 SolidWorks 的核心——按**建模顺序**列出所有特征，是「基于特征」建模的体现：

```
零件1
├── 前视基准面
├── 上视基准面
├── 右视基准面
├── 原点
├── 草图1
├── 拉伸1
├── 圆角1
└── 抽壳1
```

> 在设计树中拖动特征可改变建模顺序；双击可编辑。

## 建模工作流

```
选择基准面 → 绘制草图 → 添加几何关系与尺寸 → 生成特征 → 重复
```

## 草图（Sketch）

草图是二维轮廓，是所有特征的基础：

| 要素 | 说明 |
|------|------|
| 几何关系 | 水平/垂直/相切/同心/对称等约束 |
| 尺寸 | 驱动尺寸（参数化核心） |
| 完全定义 | 草图无自由度（推荐，避免漂移） |

## 基准面与参考几何

| 类型 | 用途 |
|------|------|
| 基准面 | 草图的放置平面（前/上/右 + 自定义） |
| 基准轴 | 旋转/阵列的参考轴 |
| 坐标系 | 自定义坐标参考 |

## 鼠标与视图操作

| 操作 | 效果 |
|------|------|
| 中键拖动 | 旋转视图 |
| Shift+中键 | 平移 |
| 滚轮 | 缩放 |
| 方向键 | 视图定向 |
