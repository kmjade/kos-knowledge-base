# 03 工程设计方法

## 设计流程

| 阶段 | 说明 |
|------|------|
| 需求分析 | 明确目标与约束 |
| 概念设计 | 方案构思 |
| 详细设计 | 计算/建模/制图 |
| 验证 | 仿真/测试 |

## 系统工程

| 概念 | 说明 |
|------|------|
| 需求分解 | 顶层需求 → 子系统 |
| 接口管理 | 子系统间接口 |
| V 模型 | 设计-验证对应 |
| 权衡分析 | 性能/成本/风险 |

## 设计优化

| 方法 | 说明 |
|------|------|
| DFM/DFA | 面向制造/装配设计 |
| 可靠性设计 | 失效分析 |
| 参数化/拓扑优化 | 结构优化 |
