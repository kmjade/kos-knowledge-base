# 05 工程材料

## 材料分类

| 类别 | 代表 | 特点 |
|------|------|------|
| 金属 | 钢、铝、铜、钛 | 强度高、可加工 |
| 高分子 | 塑料、橡胶 | 轻、耐腐蚀 |
| 陶瓷 | 氧化铝、碳化硅 | 耐高温、硬脆 |
| 复合材料 | 碳纤维、玻纤 | 轻质高强 |

## 材料性能

| 性能 | 说明 |
|------|------|
| 力学 | 强度、硬度、韧性 |
| 热学 | 导热、膨胀 |
| 电学 | 导电/绝缘 |
| 耐腐蚀 | 化学稳定性 |

## 选材

按强度/成本/重量/环境选择，常用手册与数据库。
