# 01 工程导论

## 什么是工程学

工程学是**应用科学知识解决实际问题**的学科，将数学、物理、材料等知识转化为产品、结构与系统。

## 工程方法

| 步骤 | 说明 |
|------|------|
| 定义问题 | 需求分析 |
| 方案设计 | 多方案比较 |
| 详细设计 | 计算、制图 |
| 实施 | 制造/建造 |
| 验证 | 测试、改进 |

## 历史脉络

| 时期 | 里程碑 |
|------|--------|
| 古代 | 土木（金字塔、水利） |
| 工业革命 | 机械工程兴起 |
| 19 世纪 | 电气/化工工程 |
| 20 世纪 | 电子/计算机/航天 |
| 当代 | 信息、AI、绿色工程 |
