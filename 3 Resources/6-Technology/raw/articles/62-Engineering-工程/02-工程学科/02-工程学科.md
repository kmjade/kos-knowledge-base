# 02 工程学科

## 主要分支

| 学科 | 领域 |
|------|------|
| 机械工程 | 机械设计、制造、热力 |
| 电气工程 | 电力、电机、控制 |
| 电子工程 | 电路、IC、嵌入式 |
| 土木工程 | 结构、桥梁、道路 |
| 化学工程 | 化工、材料 |
| 计算机工程 | 软硬件结合 |

## 交叉学科

| 学科 | 说明 |
|------|------|
| 机电一体化 | 机械 + 电子 + 控制 |
| 机器人工程 | 机械 + 电子 + AI |
| 生物医学工程 | 工程 + 医学 |
| 环境工程 | 工程 + 环保 |
