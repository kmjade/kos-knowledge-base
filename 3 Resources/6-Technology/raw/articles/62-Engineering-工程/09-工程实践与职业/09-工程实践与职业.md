# 09 工程实践与职业

## 工程师职业

| 角色 | 说明 |
|------|------|
| 设计工程师 | 方案与详细设计 |
| 制造工程师 | 工艺与制造 |
| 质量工程师 | 质量保证 |
| 项目经理 | 计划与协调 |

## 项目管理

| 概念 | 说明 |
|------|------|
| 范围/进度/成本 | 三要素 |
| 风险管理 | 识别/评估/应对 |
| 团队协作 | 跨专业协同 |

## 实战建议

1. 学好数学/物理基础
2. 掌握 CAD（AutoCAD/SolidWorks）
3. 熟悉标准规范
4. 参与实际项目
