# 06 工程力学

## 分支

| 分支 | 研究内容 |
|------|----------|
| 静力学 | 力平衡、支座反力 |
| 材料力学 | 应力/应变/强度/刚度 |
| 流体力学 | 流体静力学/动力学 |
| 热力学 | 能量、热力循环 |

## 核心概念

| 概念 | 说明 |
|------|------|
| 应力/应变 | 材料受力与变形 |
| 弯曲/剪切/扭转 | 基本变形 |
| 稳定性 | 屈曲 |
