# 08 工程伦理与安全

## 工程伦理

| 原则 | 说明 |
|------|------|
| 公共安全 | 以公众利益为先 |
| 诚实 | 不隐瞒缺陷 |
| 专业能力 | 只做胜任的事 |
| 责任 | 对后果负责 |

## 安全

| 方面 | 说明 |
|------|------|
| 设计安全 | 安全系数、冗余 |
| 职业安全 | 劳动保护 |
| 可持续 | 环保、全生命周期 |
