# 07 扩展与二次开发

## 扩展能力

| 扩展 | 说明 |
|------|------|
| 总线舵机（TTL） | 云台/机械臂 |
| PWM 舵机 | 常规舵机 |
| SD 卡 | 数据存储 |
| IO4/IO5 | 通用 IO |
| 1020 铝型材导轨 | 灵活扩展外设 |

## 二次开发

- **全代码开源**（例程 + 图纸 + 3D 模型）
- **Arduino IDE 开发**（ESP32，无需手动配置环境）
- 开源扩展平面图与底盘结构图

## 云台与机械臂

JSON 指令支持云台基础控制与机械臂控制（外接模块）。
