# 01 UGV 导论

## 什么是 UGV 系列

UGV 是 **微雪（Waveshare）** 出品的**移动机器人底盘系列**，开源全部代码，支持扩展树莓派、Jetson、地平线旭日 X3 等多种上位机，面向机器人二次开发与 DIY。

## 系列型号

| 型号        | 底盘   | 特点             |
| --------- | ---- | -------------- |
| **UGV01** | 履带式  | 多独立悬挂系统，超强越野通过 |
| **UGV02** | 六轮四驱 | 橡胶轮胎减震，优秀爬坡    |
|           |      |                |

## 共同特性

| 特性 | 说明 |
|------|------|
| ESP32 下位机 | 板载 WiFi/蓝牙，Arduino 开发 |
| JSON 指令集 | 串口/USB/HTTP/ESP-NOW 通信 |
| UPS 供电 | 3S 18650（7800mAh）+ INA219 监控 |
| 上位机扩展 | 树莓派/Jetson/旭日 X3 |
| 扩展导轨 | 1020 铝型材（203mm 间距） |
| OLED 屏 | 0.96 英寸实时显示 |
| 编码器电机 | 速度闭环控制 |

## UGV01 vs UGV02

| 维度 | UGV01 | UGV02 |
|------|-------|-------|
| 底盘 | 履带式 | 六轮四驱 |
| 减震 | 多独立悬挂 | 橡胶轮胎 |
| 越野 | 超强通过 | 超强爬坡 |

## 出品方：Waveshare

微雪（Waveshare）是知名开源硬件厂商，UGV 系列是其机器人底盘产品线。
