# UGV

微雪（Waveshare）出品的移动机器人底盘系列，涵盖 **UGV01（履带式）** 与 **UGV02（六轮四驱）**，全代码开源，支持多种上位机与 ROS2。

| 参数 | 说明 |
|------|------|
| 类型 | 移动机器人底盘系列 |
| 出品方 | Waveshare |
| 型号 | UGV01（履带）/ UGV02（六轮四驱） |
| 下位机 | ESP32 |
| 供电 | 3S 18650（7800mAh） |
| 通信 | JSON（串口/USB/HTTP/ESP-NOW） |
