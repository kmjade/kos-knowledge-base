# 10 对比与选型

## 一句话总结

| 型号 | 定位 |
|------|------|
| **UGV01** | 履带旗舰——多独立悬挂，极限越野 |
| **UGV02** | 六轮猛兽——橡胶轮胎，四驱重载 |

## 核心差异

| 维度 | UGV01 | UGV02 |
|------|-------|-------|
| 底盘结构 | 履带式 | 六轮四驱 |
| 悬挂系统 | 每侧 4 个独立悬挂 | 橡胶轮胎自然减震 |
| 驱动轮数 | 2 驱（后轮驱动） | 4 驱（后四轮驱动） |
| 轮胎 | 橡胶履带 | 柔软橡胶轮胎 |
| 载重能力 | 中等 | 更强（六轮分摊） |
| 爬坡角度 | 极佳（履带抓地） | 优秀（四驱推力） |
| 转弯半径 | 较大（履带摩擦） | 较小（差速转向） |
| 速度 | 中等 | 较快 |
| 噪音 | 较大（履带噪音） | 较小 |
| 适合地形 | 泥地、沙地、碎石 | 平地、草地、轻越野 |
| 底盘尺寸 | 紧凑型 | 更大（六轮） |
| 扩展导轨 | 1020 欧标铝型材 ×2 | 1020 铝型材 ×2（203mm 间距） |

## 共同特性

### 硬件平台

| 组件 | 规格 |
|------|------|
| 下位机 | ESP32 |
| 驱动板 | General Driver for Robots |
| 显示 | 0.96" OLED |
| IMU | 九轴（加速度 + 陀螺仪 + 磁力计） |
| 存储 | TF 卡槽 |
| 电池 | 3S 18650（7800mAh） |
| 充电 | 12.6V 2A，支持边充边放 |
| 电源监控 | INA219 |
| 保护 | 防过充/过放/过流/短路 |
| 扩展输出 | 5V / 3.3V |

### 软件平台

| 特性 | 说明 |
|------|------|
| 开发环境 | Arduino IDE |
| WiFi | AP（默认热点 UGV）+ STA |
| Web 控制 | 192.168.4.1（Chromium 浏览器） |
| 通信协议 | JSON 指令集（统一格式） |
| 通信方式 | 串口(115200)/USB/HTTP/ESP-NOW |
| 心跳机制 | 3 秒无移动指令自动停止 |

### 上位机支持

树莓派（4B/5）、NVIDIA Jetson Nano/Orin Nano、地平线旭日 X3 派，或任何支持 UART 的设备。

## 选型建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| 极限越野（泥地/沙地） | **UGV01** | 履带 + 独立悬挂 = 无敌通过性 |
| 室内/平地巡检 | **UGV02** | 橡胶轮安静、不伤地板 |
| 重载运输 | **UGV02** | 六轮分散负重，四驱推力强 |
| 教学/实验 | **UGV01** | 结构简单直观，两轮差速易理解 |
| ROS 机器人开发 | 两者皆可 | 均支持 ROS 控制指令 |
| 精准定位 | **UGV02** | 橡胶轮 + 四驱 = 更精确里程计 |
| 高速运动 | **UGV02** | 橡胶轮滚动阻力小 |
| 低噪音要求 | **UGV02** | 橡胶轮远安静于履带 |

## 上位机安装（通用）

```bash
cd ugv_rpi/
sudo chmod +x setup.sh autorun.sh
sudo ./setup.sh          # 国际用户
sudo ./setup.sh -i       # 国内用户（镜像源）
./autorun.sh             # 开机自启动
```
