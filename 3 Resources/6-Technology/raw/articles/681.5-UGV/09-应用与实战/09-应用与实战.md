# 09 应用与实战

## 应用场景

| 场景 | 说明 |
|------|------|
| 越野移动 | 橡胶轮胎 + 六轮四驱，复杂地形 |
| 重载搬运 | 1020 导轨扩展 |
| ROS2 开发 | 上位机接 ROS2 自主导航 |
| 二次开发 | 开源代码 + 图纸 |

## 实战案例

### Web 遥控

上电 → 连热点 → 浏览器控制页 → 下发 JSON 指令遥控。

### JSON 指令编程

串口/USB 下发 `CMD_SPEED_CTRL` 等指令，程序化控制底盘。

### ROS2 集成

上位机（树莓派/Jetson）运行 ROS2，`/cmd_vel` → JSON → 底盘运动。

### 机械臂扩展

总线舵机 + JSON 指令控制机械臂，实现抓取作业。

### 越野测试

橡胶轮胎减震 + 六轮四驱爬坡。
