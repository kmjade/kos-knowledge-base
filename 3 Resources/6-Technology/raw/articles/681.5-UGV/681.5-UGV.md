# 681.5 UGV

> UGV 是 **微雪（Waveshare）** 出品的**移动机器人底盘系列**，涵盖 **UGV01（履带式）** 与 **UGV02（六轮四驱）**。以「ESP32 下位机 + JSON 指令集 + 多上位机（树莓派/Jetson/旭日 X3）+ ROS 控制」为核心，全代码开源，面向机器人二次开发与 DIY。数据更新至 2026-09。
