# 05-过程控制与系统工程

> 让化工过程稳定、安全、高效地运行。

## 反馈控制

```
设定值 → 控制器 → 执行器 → 过程 → 传感器 →（反馈）→ 控制器
```

| 控制 | 说明 |
|------|------|
| PID | 比例-积分-微分控制（主流） |
| 串级控制 | 主副回路 |
| 前馈控制 | 补偿扰动 |
| 模型预测控制 MPC | 优化控制 |

## 过程优化

- 目标函数：成本、产量、能耗
- 约束：安全、质量、环保
- 线性规划、非线性规划

## 过程系统工程

- 流程图（PFD）、管道仪表图（P&ID）
- 物料衡算、能量衡算
- 流程模拟（Aspen、HYSYS）

## 过程集成

- 换热网络（夹点分析）
- 质量集成（水网络）
- 能量集成（余热回收）

## 数字化与智能

- DCS（集散控制）、SCADA
- 数字孪生
- AI 优化与故障诊断
