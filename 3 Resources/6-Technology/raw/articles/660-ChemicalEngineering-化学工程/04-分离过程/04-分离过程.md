# 04-分离过程

> 从混合物中提纯目标组分——化工的「提纯」。

## 主要分离方法

| 方法 | 原理 | 应用 |
|------|------|------|
| 蒸馏 | 沸点差 | 石油分馏 |
| 吸收 | 溶解度 | 气体净化 |
| 萃取 | 分配系数 | 提纯、制药 |
| 结晶 | 溶解度变化 | 制盐、制药 |
| 吸附 | 表面作用 | 干燥、净化 |
| 膜分离 | 选择性透过 | 海水淡化、气体分离 |
| 干燥 | 水分蒸发 | 食品、化工 |

## 蒸馏

- 相对挥发度、回流比
- 塔板数、填料塔
- 共沸、萃取精馏

## 膜分离

| 类型 | 分离对象 |
|------|------|
| 微滤 | 颗粒 >0.1 μm |
| 超滤 | 大分子 |
| 纳滤 | 小分子 |
| 反渗透 | 离子（海水淡化） |

## 分离效率

- 纯度、回收率
- 能耗（分离常占化工能耗大部分）
- 过程强化（减少能耗）
