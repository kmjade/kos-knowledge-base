# 01-化学工程概述

> 从实验室到工厂——化学工程的本质是「放大」。

## 过程工业

```
原料 → 预处理 → 反应 → 分离 → 纯化 → 产品
```

## 三大核心

| 核心 | 内容 |
|------|------|
| 传递现象 | 动量、热量、质量 |
| 化学反应工程 | 反应器、催化 |
| 分离工程 | 提纯、分离 |

## 单元操作

- 流体输送、换热、蒸馏、吸收、萃取、结晶、干燥、过滤
- 「单元操作」概念（1923）是化工学科化的里程碑

## 放大 (Scale-up)

- 实验室 → 中试 → 工业规模
- 放大效应：传热传质、混合、安全
- 放大是化工最大的工程挑战

## 化工与相关学科

| 学科 | 关系 |
|------|------|
| 化学 | 提供反应原理 |
| 物理 | 传递现象基础 |
| 工程 | 设备与放大 |
| 生物 | 生物化工 |
