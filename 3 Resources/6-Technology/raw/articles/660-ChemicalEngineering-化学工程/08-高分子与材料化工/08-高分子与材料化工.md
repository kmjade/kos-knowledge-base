# 08-高分子与材料化工

> 高分子材料的合成与加工——塑料时代的化工。

## 三大合成材料

| 材料 | 代表 | 用途 |
|------|------|------|
| 塑料 | PE、PVC、PP、PS | 包装、建材 |
| 合成纤维 | 涤纶、锦纶、腈纶 | 纺织 |
| 合成橡胶 | 丁苯、顺丁 | 轮胎 |

## 聚合反应

| 类型 | 特征 |
|------|------|
| 加成聚合 | 单体直接连接（乙烯 → 聚乙烯） |
| 缩合聚合 | 脱小分子（尼龙、涤纶） |
| 共聚 | 多种单体 |

## 聚合物加工

- 挤出、注塑、吹塑、压延
- 添加剂：增塑剂、稳定剂、填料

## 功能高分子

| 类型 | 应用 |
|------|------|
| 导电聚合物 | 电子 |
| 医用高分子 | 植入、载药 |
| 分离膜 | 水处理、气体分离 |
| 高性能纤维 | 碳纤维、芳纶 |

## 塑料污染与循环

- 微塑料、白色污染
- 回收、降解塑料
- 生物基材料
