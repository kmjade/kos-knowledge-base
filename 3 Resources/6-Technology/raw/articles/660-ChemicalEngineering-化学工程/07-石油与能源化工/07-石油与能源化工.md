# 07-石油与能源化工

> 能源的化学转化——从炼油到新能源。

## 石油炼制

| 过程 | 目的 |
|------|------|
| 常减压蒸馏 | 分馏（汽油、柴油、重油） |
| 催化裂化 | 重油 → 轻油 |
| 催化重整 | 提高辛烷值 |
| 加氢裂化 | 深度加工 |
| 焦化 | 渣油 → 焦炭 |

## 天然气化工

- 甲烷 → 合成气（CO + H₂）
- 合成气 → 甲醇、氨、液体燃料（费托合成）
- LNG、页岩气

## 煤化工

- 煤焦化、煤气化、煤液化
- 煤制油、煤制烯烃
- 中国的「富煤」国情

## 新能源化工

| 方向 | 技术 |
|------|------|
| 氢能 | 电解水制氢、储氢、燃料电池 |
| 生物燃料 | 乙醇、生物柴油 |
| 电池材料 | 锂电、钠电、固态电池 |
| 光伏材料 | 多晶硅、钙钛矿 |

## 能源转型

- 化石能源 → 可再生能源
- 碳捕集利用与封存 (CCUS)
- 电化工（绿氢、电合成）
