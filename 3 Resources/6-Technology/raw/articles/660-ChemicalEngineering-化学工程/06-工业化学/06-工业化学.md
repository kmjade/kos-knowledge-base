# 06-工业化学

> 大宗与精细化工产品的生产——化工的产品端。

## 基础无机化工

| 产品 | 用途 |
|------|------|
| 硫酸 (H₂SO₄) | 化肥、冶金 |
| 合成氨 (NH₃) | 化肥、炸药 |
| 烧碱 (NaOH) | 造纸、纺织 |
| 纯碱 (Na₂CO₃) | 玻璃、化工 |
| 氯气 (Cl₂) | 消毒、PVC |

## 化肥

- 氮肥（尿素、硝酸铵）
- 磷肥（过磷酸钙）
- 钾肥（氯化钾）
- 复合肥

## 有机化工

- 乙烯、丙烯（基础原料）
- 甲醇、乙醇
- 苯、甲苯、二甲苯
- 聚合物单体（乙烯 → 聚乙烯）

## 精细化工

| 类别 | 产品 |
|------|------|
| 医药中间体 | 原料药 |
| 农药 | 杀虫剂、除草剂 |
| 染料、涂料 | 着色、防护 |
| 添加剂 | 催化剂、助剂 |

## 化工产业链

```
石油/煤/天然气 → 基础原料 → 中间体 → 精细化工 → 终端产品
```
