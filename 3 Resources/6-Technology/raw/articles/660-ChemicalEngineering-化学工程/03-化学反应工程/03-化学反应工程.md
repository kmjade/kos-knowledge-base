# 03-化学反应工程

> 反应器设计与反应动力学——化工的「心脏」。

## 反应动力学

- 反应速率：$r = kC_A^n$
- 阿伦尼乌斯：$k = Ae^{-E_a/RT}$
- 转化率、选择性、收率

## 反应器类型

| 类型 | 特征 | 应用 |
|------|------|------|
| 间歇 (Batch) | 分批操作 | 制药、精细化工 |
| CSTR | 连续搅拌、均匀 | 液相反应 |
| PFR | 推流、连续 | 气相反应 |
| 流化床 | 固体流态化 | 催化裂化 |
| 固定床 | 固体催化剂填充 | 合成氨 |

## 催化

| 类型 | 说明 |
|------|------|
| 均相催化 | 催化剂与反应物同相 |
| 多相催化 | 催化剂为固相（工业主流） |
| 酶催化 | 生物催化剂 |
| 光/电催化 | 新能源方向 |

## 催化剂设计

- 活性、选择性、稳定性
- 载体、助剂、活性组分
- 失活与再生（中毒、积碳、烧结）

## 重要催化过程

- 合成氨（Haber-Bosch，铁催化剂）
- 催化裂化（石油炼制）
- 加氢、脱氢、氧化
