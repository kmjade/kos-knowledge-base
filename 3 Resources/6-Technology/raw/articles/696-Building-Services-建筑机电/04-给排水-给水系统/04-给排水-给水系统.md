# 04 给排水 — 给水系统

> 给水系统把合格的水送至各用水点，保证水质、水压与水量。

## 给水方式

| 方式 | 说明 |
|------|------|
| 市政直供 | 直接利用市政水压 |
| 水箱 + 泵 | 水箱储水 + 加压泵 |
| 变频恒压供水 | 变频泵按需供水 |
| 分区供水 | 高层分低/中/高区 |

## 给水系统组成

| 组成 | 作用 |
|------|------|
| 水源/引入管 | 市政接驳 |
| 水箱/水池 | 储水、调蓄 |
| 水泵 | 加压 |
| 管道 | 输送 |
| 用水器具 | 龙头、洁具 |

## 热水系统

| 方式 | 说明 |
|------|------|
| 集中热水 | 锅炉/热泵 + 循环管道 |
| 局部热水 | 电热水器、燃气热水器 |

## 设计要点

- 水压满足最不利点（住宅 ≥ 0.05MPa）
- 管材选择（PPR / 铜 / 不锈钢）
- 水质保障（防倒流、防污染）
- 保温与防结露
