# 06 暖通 — 供暖系统

> 供暖系统在寒冷季节为室内提供热量，维持舒适的室内温度。

## 供暖方式

| 方式 | 说明 |
|------|------|
| 散热器 | 传统、升温快、可调节 |
| 地暖（地板辐射） | 舒适、均匀、占层高 |
| 中央空调制热 | 冷暖两用 |
| 电采暖 | 局部、灵活 |

## 热源

| 热源 | 说明 |
|------|------|
| 市政集中供热 | 城市热网 |
| 燃气锅炉 | 独立供暖 |
| 空气源热泵 | 节能（COP 高） |
| 地源热泵 | 高效、初投资高 |

## 供暖系统组成

```
热源 → 输送（管道/水泵） → 末端（散热器/地暖） → 回水
```

## 设计要点

- 热负荷计算（围护结构传热 + 渗透）
- 供水/回水温度（散热器 75/50℃，地暖 45/35℃）
- 分户计量与温控
- 水力平衡
