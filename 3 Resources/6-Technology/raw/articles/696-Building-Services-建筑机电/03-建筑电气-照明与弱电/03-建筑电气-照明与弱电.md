# 03 建筑电气 — 照明与弱电

## 照明系统

| 类型 | 说明 |
|------|------|
| 一般照明 | 均匀基础照明 |
| 应急照明 | 疏散、备用（消防要求） |
| 景观照明 | 立面、园林 |
| 智能照明 | 调光、场景控制 |

> 照度、色温、显色指数（CRI）是照明设计三大参数。

## 弱电系统（智能化）

| 系统 | 作用 |
|------|------|
| 消防报警 | 烟感、温感、联动 |
| 安防监控 | 门禁、视频监控、入侵报警 |
| 综合布线 | 网络、电话、有线电视 |
| 楼宇自控（BAS） | 机电设备监控 |
| 广播/会议 | 公共广播、会议系统 |

## 防雷与接地

| 项目 | 说明 |
|------|------|
| 外部防雷 | 接闪器、引下线、接地 |
| 内部防雷 | 等电位连接、SPD 电涌保护 |
| 接地 | 保护接地、功能接地 |
