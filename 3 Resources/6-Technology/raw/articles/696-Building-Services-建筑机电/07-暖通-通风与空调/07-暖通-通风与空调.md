# 07 暖通 — 通风与空调

## 通风系统

| 类型 | 说明 |
|------|------|
| 自然通风 | 开窗、烟囱效应 |
| 机械通风 | 风机送/排风 |
| 新风系统 | 引入室外新鲜空气 |
| 防排烟 | 火灾时排烟、加压送风 |

## 空调系统

| 系统 | 说明 |
|------|------|
| 分体空调 | 一拖一，家用 |
| 多联机（VRV） | 一拖多，商用 |
| 中央空调 | 集中冷热源 + 末端 |
| 精密空调 | 机房恒温恒湿 |

## 冷热源

| 冷源 | 说明 |
|------|------|
| 冷水机组 | 离心/螺杆/风冷 |
| 冷却塔 | 散热 |
| 热泵 | 冷暖两用 |

## 设计要点

- 冷/热负荷计算
- 气流组织（送风、回风、排风）
- 风管水力计算
- 保温与防结露
- 室内空气品质（CO₂、PM2.5）
