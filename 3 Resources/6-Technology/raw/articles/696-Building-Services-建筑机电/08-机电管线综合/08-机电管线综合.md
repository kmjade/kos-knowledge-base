# 08 机电管线综合

> 管线综合是机电各专业的「会师」——在有限空间内协调风管、水管、桥架，避免碰撞，保证净高。

## 管线种类

| 管线 | 特点 |
|------|------|
| 风管 | 截面大，优先排布 |
| 水管（冷/热/消防） | 有坡度、保温 |
| 桥架（电缆） | 可弯曲、需检修空间 |
| 母线槽 | 大截面供电 |

## 管线综合原则

| 原则 | 说明 |
|------|------|
| 大管优先 | 风管先定，水管/桥架避让 |
| 有压让无压 | 有压管让重力排水管 |
| 电上水下 | 桥架在上，水管在下 |
| 检修空间 | 阀门、检修口可达 |
| 净高优先 | 保证吊顶下净空 |

## BIM 协同

| 环节 | 说明 |
|------|------|
| 建模 | 各专业 Revit 模型 |
| 碰撞检测 | Navisworks 自动查碰撞 |
| 综合协调 | 调整管线路由 |
| 出图 | 综合图、预留预埋图 |

> BIM 让管线综合从「二维叠图」走向「三维协同」，大幅减少现场返工。
