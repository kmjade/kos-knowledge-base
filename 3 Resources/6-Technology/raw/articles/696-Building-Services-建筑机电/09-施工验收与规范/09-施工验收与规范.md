# 09 施工验收与规范

## 施工流程

```
施工准备 → 预留预埋 → 管道/风管安装 → 设备安装 → 调试 → 验收
```

## 关键施工环节

| 环节 | 要点 |
|------|------|
| 预留预埋 | 套管、洞口、吊架 |
| 管道安装 | 坡度、支架、保温 |
| 风管安装 | 密封、法兰、吊架 |
| 电气安装 | 桥架、穿线、接线 |
| 设备安装 | 水泵、风机、机组 |

## 调试与验收

| 项目 | 说明 |
|------|------|
| 单机试运行 | 设备空载/负载测试 |
| 系统调试 | 水压试验、风量平衡、电气绝缘 |
| 联合调试 | 联动、消防联动 |
| 竣工验收 | 资料、实体、功能 |

## 常用规范（中国）

| 规范 | 内容 |
|------|------|
| GB 50015 | 建筑给水排水设计标准 |
| GB 50016 | 建筑设计防火规范 |
| GB 51348 | 民用建筑电气设计标准 |
| GB 50736 | 民用建筑供暖通风与空气调节设计规范 |
