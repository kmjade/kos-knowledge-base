# 02 建筑电气 — 供配电

> 供配电是建筑电气的「主干」——把市政电力引入建筑，分配至各用电末端。

## 供配电系统

| 环节 | 说明 |
|------|------|
| 变电所 | 高压 10kV → 低压 0.4kV |
| 变压器 | 容量按负荷计算 |
| 配电柜/箱 | 分配、保护、计量 |
| 线路 | 电缆、母线槽 |

## 负荷等级

| 等级 | 说明 | 供电要求 |
|:----:|------|---------|
| 一级 | 中断造成重大损失（医院/消防） | 双电源 + 自备电源 |
| 二级 | 中断造成较大损失 | 双回路 |
| 三级 | 一般负荷 | 单回路 |

## 关键设备

| 设备 | 作用 |
|------|------|
| 变压器 | 电压变换 |
| 高压/低压开关柜 | 通断与保护 |
| 配电箱 | 末端分配 |
| 电缆/母线 | 电能传输 |
| UPS/EPS | 不间断电源、应急电源 |

## 设计要点

- 负荷计算（需要系数法）
- 短路电流计算与保护配合
- 接地与防雷
- 电缆截面与压降校核
