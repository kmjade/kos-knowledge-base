# 05 给排水 — 排水与消防

## 排水系统

| 类型 | 说明 |
|------|------|
| 生活污水 | 粪便污水（需化粪池/处理） |
| 生活废水 | 洗涤废水（可中水回用） |
| 雨水 | 屋面/地面雨水排放 |
| 通气管 | 排水立管排气、防负压 |

## 排水要点

- 坡度保证自流（支管 ≥ 0.02）
- 存水弯水封（≥ 50mm，防臭）
- 高层排水设专用通气管
- 雨水重现期与屋面溢流

## 消防水系统

| 系统 | 说明 |
|------|------|
| 消火栓 | 室内外消火栓、消防泵 |
| 自动喷淋 | 闭式/开式喷头，湿式/干式 |
| 消防水池/水箱 | 储水 + 稳压 |
| 灭火器 | 便携式，按危险等级配置 |

> 消防水是建筑给排水中最严格的系统——水量、水压、可靠性均有强制规范。
