# 五行学说 Five Elements

## 定义

五行（木火土金水）以**取象比类**归纳事物属性，以**相生相克**说明事物间的制化关系，中医以此构建脏腑联系与疾病传变模型。

## 关键要点

| 要点 | 说明 |
|------|------|
| 相生 | 木→火→土→金→水→木 |
| 相克 | 木→土→水→火→金→木 |
| 五脏对应 | 肝木·心火·脾土·肺金·肾水 |
| 乘侮 | 相乘（过克）、相侮（反克）为病态 |
