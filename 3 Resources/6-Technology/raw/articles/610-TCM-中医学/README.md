# 中医学 (Traditional Chinese Medicine / DDC 610.951)

> 以整体观念与辨证论治为核心的传统医学，涵盖基础理论、诊断、中药、方剂、针灸、推拿与养生。
> 中医与 [[3 Resources/6-Technology/raw/articles/610-Medicine-医学健康/610-Medicine-医学健康|610 医学健康]]（现代医学）同属 DDC 610，互补互鉴。

## 学习路径

1. **打基础** → [[01-中医基础理论]]：阴阳五行、藏象、气血津液
2. **学会看病** → [[02-中医诊断学]]：四诊 + 辨证论治
3. **会用方药** → [[03-中药学]] + [[04-方剂学]]
4. **外治疗法** → [[05-针灸与经络]] + [[06-推拿与导引]]
5. **读经典** → [[07-中医经典]]
6. **临床与养生** → [[08-中医临床各科]] + [[09-中医养生与治未病]]
