# 03-中药学

> 研究中药的性能、功效与应用的学科——四气五味、归经、配伍。

## 药性理论

- **四气**：寒、热、温、凉
- **五味**：酸、苦、甘、辛、咸
- **归经**：药物对特定脏腑经络的选择性作用
- **升降浮沉**：作用趋向（升浮向上外，沉降向下内）

## 常用分类与代表药

| 分类 | 代表药 |
|------|--------|
| 解表药 | 麻黄、桂枝、薄荷、菊花 |
| 清热药 | 黄连、黄芩、金银花、连翘 |
| 补虚药 | 人参、黄芪、当归、熟地黄、甘草 |
| 活血化瘀药 | 川芎、丹参、红花、桃仁 |
| 化痰止咳药 | 半夏、贝母、桔梗 |
| 安神药 | 酸枣仁、远志、龙骨 |
| 泻下药 | 大黄、芒硝 |
