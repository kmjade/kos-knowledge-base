# 08-服装与饰品

> 服装工业与饰品制造——从面料到成衣，从珠宝到配饰。

## 服装生产流程

```
设计 → 打版 → 裁剪 → 缝制 → 整烫 → 质检 → 包装
```

## 服装类型

| 类别 | 产品 |
|------|------|
| 男装/女装 | 正装、休闲、运动 |
| 童装 | 婴儿、儿童 |
| 内衣 | 贴身衣物 |
| 鞋帽 | 鞋、帽、袜 |

## 服装工艺

- 裁剪（排料、套裁）
- 缝制（平缝、锁边、包边）
- 整烫（定型）
- 装饰（印花、刺绣、钉珠）

## 饰品

| 类型 | 材料 |
|------|------|
| 珠宝 | 金、银、宝石 |
| 时尚饰品 | 合金、树脂 |
| 箱包 | 皮革、织物 |
| 皮带、围巾 | 皮革、织物 |

## 服装产业

- 快时尚 vs 慢时尚
- 服装供应链、代工
- 服装尺码标准

## 可持续时尚

- 二手、租赁、修补
- 环保面料、再生纤维
- 减少浪费
