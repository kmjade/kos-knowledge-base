# 03-钟表与光学仪器

> 时间与光学的精密制造——机械与光学的极致。

## 钟表

| 类型 | 原理 |
|------|------|
| 机械表 | 发条 + 擒纵 |
| 石英表 | 石英振荡 |
| 电子表 | 集成电路 |
| 原子钟 | 原子跃迁（最高精度） |

- 擒纵机构是机械钟表的核心
- 瑞士、日本是钟表制造强国

## 眼镜

- 镜片材料：玻璃、树脂
- 屈光矫正：近视、远视、散光
- 镜架材质与设计

## 光学镜头

| 类型 | 应用 |
|------|------|
| 相机镜头 | 摄影 |
| 望远镜 | 天文、观察 |
| 显微镜 | 微观观察 |
| 激光光学 | 精密加工、测量 |

## 光学原理

- 折射、反射、色散
- 透镜组合、镀膜
- 光学设计（像差校正）

## 制造工艺

- 精密研磨、抛光
- 镀膜（增透、反射）
- 装配与校准
