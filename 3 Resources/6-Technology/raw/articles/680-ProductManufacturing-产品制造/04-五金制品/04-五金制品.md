# 04-五金制品

> 金属小件的制造——锁具、工具与五金配件。

## 五金分类

| 类别 | 示例 |
|------|------|
| 建筑五金 | 门窗配件、合页、拉手 |
| 紧固件 | 螺丝、螺母、螺栓、铆钉 |
| 锁具 | 门锁、挂锁、智能锁 |
| 工具 | 扳手、钳子、螺丝刀 |
| 卫浴五金 | 水龙头、花洒 |

## 锁具

| 类型 | 原理 |
|------|------|
| 机械锁 | 弹子、叶片 |
| 电子锁 | 密码、刷卡 |
| 智能锁 | 指纹、人脸、APP |
| 密码锁 | 转盘、按钮 |

## 工具制造

- 材质：碳钢、合金钢、铬钒钢
- 热处理：淬火、回火（硬度）
- 表面处理：镀铬、发黑

## 紧固件

- 螺纹标准（公制、英制）
- 强度等级（8.8、10.9、12.9）
- 防松（弹簧垫圈、螺纹胶）

## 制造工艺

- 冷镦、冲压、机加工、电镀
- 标准化、大批量生产
