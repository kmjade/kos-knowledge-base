# 02-精密仪器

> 高精度的测量与检测设备——科学、工业与医疗的「眼睛」。

## 仪器分类

| 类别 | 示例 |
|------|------|
| 测量仪器 | 三坐标、量具、传感器 |
| 分析仪器 | 光谱仪、色谱仪、质谱 |
| 医疗仪器 | 监护仪、内窥镜、影像设备 |
| 科学仪器 | 显微镜、望远镜、粒子探测器 |

## 精密仪器的要求

- 高精度、高稳定性
- 抗干扰、环境适应性
- 标定与溯源（计量）

## 制造要点

- 精密加工、精密装配
- 光学、电子、机械复合
- 洁净环境、质量控制

## 医疗仪器

| 类型 | 原理 |
|------|------|
| 超声 | 声波成像 |
| X 光/CT | 穿透成像 |
| MRI | 核磁共振 |
| 监护仪 | 生命体征监测 |

## 计量与标准

- 计量溯源、校准
- 国际单位制 (SI)
- 实验室认证（ISO 17025）
