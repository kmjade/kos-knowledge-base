# 05-家用电器

> 家庭生活的电气化——从冰箱到智能家居。

## 家电分类

| 类别 | 产品 |
|------|------|
| 白色家电 | 冰箱、洗衣机、空调 |
| 黑色家电 | 电视、音响 |
| 厨房电器 | 微波炉、电饭煲、烤箱 |
| 小家电 | 吸尘器、吹风机、电熨斗 |

## 家电核心部件

- 压缩机（冰箱、空调）
- 电机（洗衣机、吸尘器）
- 加热元件（电饭煲、热水器）
- 控制板（智能控制）

## 能效标准

- 能效等级（1-5 级）
- 节能技术（变频、热泵）
- 能耗标识

## 智能家电

| 功能 | 技术 |
|------|------|
| 远程控制 | WiFi、APP |
| 语音交互 | 语音助手 |
| 自动调节 | 传感器、AI |
| 互联互通 | 智能家居平台 |

## 家电安全

- 电气安全（接地、绝缘）
- 3C 认证、安全标准
- 使用安全（防触电、防火）

## 家电回收

- 电子垃圾、回收拆解
- 环保制冷剂、材料循环
