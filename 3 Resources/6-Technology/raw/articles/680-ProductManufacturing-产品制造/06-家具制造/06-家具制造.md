# 06-家具制造

> 实用与美观的结合——木工与家具设计。

## 家具分类

| 类别 | 产品 |
|------|------|
| 坐具 | 椅、凳、沙发 |
| 卧具 | 床、床垫 |
| 收纳 | 柜、架、抽屉 |
| 桌台 | 桌、茶几、书桌 |

## 家具材料

| 材料 | 特性 |
|------|------|
| 实木 | 天然、耐用、贵 |
| 人造板 | 经济、稳定（刨花板、密度板） |
| 金属 | 现代、坚固 |
| 塑料 | 轻便、多彩 |
| 软包 | 布艺、皮革 |

## 木工工艺

| 工艺 | 说明 |
|------|------|
| 榫卯 | 传统木工连接 |
| 胶合 | 胶水连接 |
| 五金连接 | 螺丝、连接件 |
| 表面处理 | 油漆、贴面 |

## 家具设计

- 人体工学、舒适性
- 风格（北欧、极简、中式）
- 空间适配、模块化
- 环保（低甲醛、FSC 木材）

## 智能家具

- 电动升降桌、智能床
- 充电、照明、传感器
- 适老化家具
