# 01-产品制造概述

> 面向特定用途的成品制造——贴近生活的制造分支。

## 产品分类

| 类别 | 示例 |
|------|------|
| 精密仪器 | 测量、医疗、科学仪器 |
| 消费品 | 家电、家具、服装 |
| 文体用品 | 文具、玩具、体育器材 |
| 日用五金 | 锁具、工具、五金件 |

## 产品制造流程

```
设计 → 材料 → 加工 → 装配 → 质检 → 包装 → 交付
```

## 产品设计

| 维度 | 内容 |
|------|------|
| 功能 | 满足需求 |
| 外观 | 美学、人机 |
| 成本 | 可制造性 |
| 安全 | 标准合规 |
| 可持续 | 可回收、耐久 |

## 产品生命周期

```
引入 → 成长 → 成熟 → 衰退
```

## 制造趋势

- 个性化定制、小批量
- 智能化、互联化产品
- 可持续材料与设计
- 快消 vs 耐用品的平衡
