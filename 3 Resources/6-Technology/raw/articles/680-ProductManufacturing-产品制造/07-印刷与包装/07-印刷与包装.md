# 07-印刷与包装

> 信息的载体与产品的「外衣」——印刷与包装工业。

## 印刷方式

| 方式 | 特点 | 应用 |
|------|------|------|
| 胶印 | 高质量、大批量 | 书籍、杂志 |
| 凹印 | 高产能 | 包装、钞票 |
| 柔印 | 环保、灵活 | 标签、软包装 |
| 丝网印刷 | 厚墨层 | 服装、玻璃 |
| 数码印刷 | 可变数据、小批量 | 按需印刷 |

## 印刷流程

```
设计 → 制版 → 印刷 → 印后（装订、模切、烫金）
```

## 包装

| 类型 | 材料 |
|------|------|
| 纸包装 | 纸箱、纸盒 |
| 塑料包装 | 薄膜、瓶 |
| 金属包装 | 罐、桶 |
| 玻璃包装 | 瓶 |

## 包装功能

- 保护（防潮、防震）
- 便利（易开、便携）
- 信息（标签、说明）
- 营销（品牌、外观）

## 标签

- 不干胶标签、RFID 标签
- 条码、二维码
- 食品标签法规

## 可持续包装

- 减量、可回收、可降解
- 纸基替代塑料
- 循环包装
