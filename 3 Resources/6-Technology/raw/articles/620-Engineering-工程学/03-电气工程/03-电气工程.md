# 03-电气工程

> 电力与电能的工程——从发电机到智能电网。

## 电路基础

| 定律 | 公式 |
|------|------|
| 欧姆定律 | $V = IR$ |
| 功率 | $P = VI = I^2R$ |
| 基尔霍夫定律 | $\sum I = 0$，$\sum V = 0$ |

## 交流电路

- $V(t) = V_0\sin(\omega t)$
- 阻抗、相量、功率因数
- 三相电：工业供电标准

## 电机

| 类型 | 原理 | 应用 |
|------|------|------|
| 直流电机 | 换向器 | 调速 |
| 交流感应电机 | 旋转磁场 | 工业 |
| 同步电机 | 同步转速 | 发电 |
| 变压器 | 电磁感应 | 变压 |

## 电力系统

```
发电 → 升压 → 输电 → 降压 → 配电 → 用户
```

- 高压输电减少损耗（$P_{loss} = I^2R$）
- 智能电网、可再生能源并网

## 安全

- 接地、绝缘、断路器
- 电流对人体的危害

## 电工认证与规范

### 电工认证（中国）

| 证书 | 发证机关 | 说明 |
|------|----------|------|
| 特种作业操作证（电工） | 应急管理部门 | 上岗必备，分低压/高压等作业类别 |
| 职业技能等级证书（电工） | 人社部门备案评价机构 | 初级工 → 中级工 → 高级工 → 技师 → 高级技师 |
| 注册电气工程师 | 住建部门（勘察设计注册） | 供配电 / 发输变电，设计资格 |

### 特种作业电工类别

| 作业类别 | 说明 |
|----------|------|
| 低压电工作业 | 1 kV 以下设备安装与检修 |
| 高压电工作业 | 1 kV 及以上设备运行与检修 |
| 防爆电气作业 | 爆炸危险环境中的电气设备 |
| 继电保护 / 电力电缆 / 电气试验作业 | 专项作业类别 |

### 核心电气规范

| 规范 | 说明 |
|------|------|
| GB 50054 | 低压配电设计规范 |
| GB 50303 | 建筑电气工程施工质量验收规范 |
| GB 50057 | 建筑物防雷设计规范 |
| GB/T 3805 | 特低电压(ELV)限值 |
| GB 50169 | 接地装置施工及验收规范 |

| NFPA 70 / NEC | 美国国家电气规范 |

### 安全规范要点

- 接地与等电位联结、漏电保护（RCD）
- 供配电系统接地形式：TN / TT / IT
- 特低电压（SELV / PELV）与绝缘
- 触电急救：断电 → 施救 → 心肺复苏
