# 06-化学工程

> 把化学反应放大到工业规模——从实验室到工厂。

## 单元操作

| 操作 | 原理 | 应用 |
|------|------|------|
| 蒸馏 | 沸点差 | 石油分馏 |
| 吸收 | 溶解度 | 气体净化 |
| 萃取 | 分配系数 | 提纯 |
| 结晶 | 溶解度变化 | 制药 |
| 干燥 | 水分蒸发 | 食品 |
| 过滤 | 颗粒分离 | 固液分离 |

## 化学反应器

| 类型 | 特征 |
|------|------|
| 间歇反应器 | 分批操作 |
| 连续搅拌反应器 (CSTR) | 稳态、均匀 |
| 管式反应器 (PFR) | 推流、连续 |
| 催化反应器 | 有催化剂 |

## 化工过程

```
原料 → 预处理 → 反应 → 分离 → 纯化 → 产品
```

## 传递现象

- 动量传递（流体力学）
- 热量传递（换热器）
- 质量传递（扩散、对流传质）

## 过程安全

- 危险化学品管理
- 防爆、防泄漏
- 案例：博帕尔事故（1984）
