# 07-材料工程

> 研究材料的结构、性能与加工——材料是文明的基石。

## 材料四大类

| 类别 | 特征 | 代表 |
|------|------|------|
| 金属 | 导电、延展、高强度 | 钢、铝、铜、钛 |
| 陶瓷 | 硬、脆、耐高温 | 氧化铝、玻璃 |
| 聚合物 | 轻、易加工、绝缘 | 塑料、橡胶 |
| 复合材料 | 组合性能 | 碳纤维、玻璃钢 |

## 材料性能

| 性能 | 说明 |
|------|------|
| 力学 | 强度、硬度、韧性 |
| 热学 | 导热、热膨胀 |
| 电学 | 导电、绝缘、半导体 |
| 化学 | 耐腐蚀 |

## 微观结构与性能

- 晶格、晶粒、位错
- 热处理：退火、淬火、回火
- 合金化：改善性能（钢 = 铁 + 碳）

## 先进材料

| 材料 | 应用 |
|------|------|
| 纳米材料 | 医药、电子 |
| 石墨烯 | 电子、储能 |
| 形状记忆合金 | 医疗、航空 |
| 超导材料 | 磁共振、输电 |
| 半导体材料 | 芯片（硅、GaAs） |

## 材料选择

- 性能-成本-可加工性权衡
- 生命周期、可回收性
