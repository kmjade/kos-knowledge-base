# 05-土木工程

> 建造人类基础设施——建筑、桥梁、道路与水利。

## 结构力学

| 概念 | 说明 |
|------|------|
| 应力 | $\sigma = F/A$ |
| 应变 | $\varepsilon = \Delta L/L$ |
| 杨氏模量 | $E = \sigma/\varepsilon$ |
| 屈曲 | 受压失稳 |

## 建筑材料

| 材料 | 特性 | 用途 |
|------|------|------|
| 混凝土 | 抗压 | 基础、柱 |
| 钢筋 | 抗拉 | 配筋 |
| 钢材 | 高强 | 框架、桥 |
| 木材 | 轻质 | 住宅 |

- 钢筋混凝土：钢筋 + 混凝土互补（抗拉 + 抗压）

## 桥梁类型

| 类型 | 跨度 | 示例 |
|------|------|------|
| 梁桥 | 短 | 一般道路 |
| 拱桥 | 中 | 石拱桥 |
| 斜拉桥 | 大 | 苏通大桥 |
| 悬索桥 | 超大 | 金门大桥 |

## 基础设施

- 道路、铁路、隧道、机场、港口
- 给排水、防洪
- 抗震设计、地基处理
