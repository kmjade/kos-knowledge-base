# 02-机械工程

> 最古老的工程分支——力、能量与运动。

## 静力学与动力学

| 分支 | 研究 |
|------|------|
| 静力学 | 平衡状态（$\sum F = 0$） |
| 动力学 | 运动与力（$F = ma$） |
| 材料力学 | 应力、应变、强度 |

## 热力学与热机

| 循环 | 过程 | 效率 |
|------|------|------|
| 卡诺循环 | 理想循环 | 上限 |
| 奥托循环 | 汽油机 | 4 冲程 |
| 狄塞尔循环 | 柴油机 | 压燃 |
| 朗肯循环 | 蒸汽轮机 | 发电 |

- 热机效率上限：$\eta = 1 - T_c/T_h$（卡诺效率）

## 制造工艺

| 工艺 | 说明 |
|------|------|
| 铸造 | 液态金属成型 |
| 锻造 | 压力成型 |
| 机加工 | 车、铣、钻、磨 |
| 焊接 | 连接金属 |
| 3D 打印 | 增材制造 |

## 机械传动

- 齿轮、皮带、链条、凸轮
- 减速比、扭矩、功率 $P = \tau\omega$
