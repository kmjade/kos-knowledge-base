# 04-电子工程

> 电子器件的工程——从半导体到数字系统，信息时代的基石。

## 半导体器件

| 器件 | 功能 |
|------|------|
| 二极管 | 单向导通 |
| 晶体管（BJT/FET） | 放大、开关 |
| 集成电路 (IC) | 集成大量元件 |
| 传感器 | 物理量→电信号 |

## 模拟电路

- 放大器（运放）、滤波器
- 反馈：正反馈（振荡）、负反馈（稳定）

## 数字电路

| 门 | 逻辑 |
|------|------|
| AND | A·B |
| OR | A+B |
| NOT | ¬A |
| XOR | A⊕B |

- 组合逻辑、时序逻辑（触发器、寄存器）
- 二进制、布尔代数

## 信号处理

- 模数转换 (ADC)、数模转换 (DAC)
- 采样定理：$f_s \ge 2f_{max}$（奈奎斯特）
- 滤波、调制、傅里叶变换

## 摩尔定律

- 集成电路晶体管数约每 18–24 个月翻倍
- 驱动半导体产业半个世纪
