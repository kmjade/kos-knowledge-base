# 09-环境工程与可持续

> 用工程手段保护环境与实现可持续发展。

## 水处理

| 处理 | 方法 |
|------|------|
| 给水处理 | 混凝、沉淀、过滤、消毒 |
| 污水处理 | 一级（物理）、二级（生物）、三级（深度） |
| 活性污泥法 | 微生物降解有机物 |

## 大气污染控制

| 污染物 | 控制 |
|------|------|
| 颗粒物 | 除尘（静电、布袋） |
| SO₂ | 脱硫 |
| NOx | 脱硝 |
| 温室气体 | 减排、CCUS（碳捕集） |

## 固体废弃物

- 减量化 → 资源化 → 无害化
- 分类、回收、堆肥、焚烧、填埋
- 塑料污染、电子垃圾

## 可持续发展

> 布伦特兰定义：满足当代需求，不损害后代满足其需求的能力。

- 三支柱：经济、社会、环境
- 联合国 SDGs（17 个可持续发展目标）
- 循环经济：闭合物质循环

## 清洁生产与绿色工程

- 生命周期评估 (LCA)
- 绿色设计、节能降耗
- 可再生能源系统集成
