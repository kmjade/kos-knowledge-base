# 08-航空航天工程

> 飞行与航天的工程——从空气动力学到轨道力学。

## 空气动力学

| 力 | 说明 |
|------|------|
| 升力 | 机翼上下压力差 |
| 阻力 | 摩擦、压差 |
| 推力 | 发动机提供 |

- 伯努利原理：流速快处压强低
- 升力系数、攻角、失速

## 推进系统

| 类型 | 原理 | 应用 |
|------|------|------|
| 活塞发动机 | 螺旋桨 | 小型飞机 |
| 涡轮喷气 | 喷气推进 | 客机 |
| 涡轮风扇 | 高涵道比 | 现代客机 |
| 火箭 | 反作用力 | 航天 |

## 轨道力学

- 第一宇宙速度 ~7.9 km/s（环绕）
- 第二宇宙速度 ~11.2 km/s（逃逸）
- 开普勒定律、霍曼转移轨道

## 航天器

| 类型 | 功能 |
|------|------|
| 卫星 | 通信、遥感、导航 |
| 空间站 | 长期驻留（ISS） |
| 探测器 | 深空探测 |
| 运载火箭 | 送入轨道 |

## 航天历史

- 1957 斯普特尼克（第一颗卫星）
- 1969 阿波罗 11（登月）
- 2020s 可重复使用火箭（SpaceX）、深空探测
