# 01-工程学概述

> 工程是把科学转化为实用的学科——在约束下设计与建造。

## 工程方法

```
识别需求 → 定义问题 → 提出方案 → 分析建模 → 原型测试 → 优化实施 → 维护改进
```

## 工程设计约束

| 约束 | 说明 |
|------|------|
| 技术 | 可行性、性能 |
| 经济 | 成本、预算 |
| 安全 | 风险、可靠性 |
| 环境 | 可持续、污染 |
| 伦理 | 责任、公正 |

## 工程伦理

- 安全优先、诚实透明
- 可持续性、社会责任
- 案例：挑战者号（1986）、切尔诺贝利（1986）

## 系统思维

- 整体大于部分之和
- 反馈、涌现、耦合
- 可靠性与冗余设计

## 工程 vs 科学

| 科学 | 工程 |
|------|------|
| 认识世界（为什么） | 改造世界（怎么做） |
| 发现规律 | 应用规律 |
| 追求真理 | 追求方案 |
