# 05 图像与图形

## 链接图像（Linked Graphics）

InDesign 默认**链接**而非嵌入图像：

| 要点 | 说明 |
|------|------|
| 链接 | 图像引用外部文件，文件小 |
| 嵌入 | 图像嵌入文档，文件大 |
| 链接面板 | 管理链接状态（缺失/修改） |

> 打包（Package）时自动收集链接图像，避免交付缺图。

## 图形框架（Frame）

| 框架 | 说明 |
|------|------|
| 矩形/椭圆/多边形框架 | 承载图像 |
| 适合（Fitting） | 图像适配框架方式 |
| 裁切 | 框架内裁切图像 |

## 色彩管理

| 颜色模式 | 说明 |
|----------|------|
| CMYK | 印刷四色 |
| RGB | 屏幕显示 |
| 专色（Spot） | Pantone 等专色 |
| 色板（Swatches） | 颜色库 |
| 渐变/色调 | 渐变与浅色 |

## 文字环绕（Text Wrap）

| 类型 | 说明 |
|------|------|
| 环绕边框 | 文字绕开框架 |
| 环绕形状 | 绕图像轮廓 |
| 跳至下一栏 | 文字跳过图像 |

## 效果与透明

| 效果 | 说明 |
|------|------|
| 投影/羽化 | 阴影与柔边 |
| 混合模式 | 图层混合 |
| 不透明度 | 透明度控制 |
