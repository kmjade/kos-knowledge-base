# 04 母版页与样式

## 母版页（Master Page / Parent Page）

母版页是应用于多页的模板，实现跨页一致的版式：

| 能力 | 说明 |
|------|------|
| 自动页码 | 插入当前页码标记 |
| 页眉/页脚 | 运行标题 |
| 应用到页面 | 单页或跨页应用 |
| 覆盖（Override） | 局部修改母版元素 |
| 父子母版 | 基于母版再派生 |

## 段落样式（Paragraph Style）

段落样式是专业排版的核心，一处修改全文档更新：

| 能力 | 说明 |
|------|------|
| 创建/应用 | 定义后一键套用 |
| 基于（Based On） | 样式继承 |
| 下一样式 | 自动衔接 |
| 快速应用 | Quick Apply 快速套用 |

## 字符样式（Character Style）

字符样式用于段落内的局部格式（如强调、链接），不改变段落整体。

## 对象样式（Object Style）

对象样式统一框架的外观（描边、填充、文字环绕、文本框架选项）。

## 网格（Grid）

| 网格 | 说明 |
|------|------|
| 基线网格 | 文字基线对齐 |
| 文档网格 | 整体对齐 |
| 版面网格 | 东亚排版专用 |
