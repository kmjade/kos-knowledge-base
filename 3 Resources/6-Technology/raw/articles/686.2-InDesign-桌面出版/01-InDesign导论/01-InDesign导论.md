# 01 InDesign 导论

## 什么是 InDesign

Adobe InDesign 是行业标准的**桌面出版（DTP）与排版软件**，用于杂志、书籍、宣传册、海报、电子书与交互式 PDF 等印刷与数字版面设计。

## 桌面出版（DTP）

桌面出版（Desktop Publishing）用电脑完成版面设计与排版，取代传统的照排工艺。InDesign 是 DTP 时代的核心工具。

## Adobe

| 要点 | 说明 |
|------|------|
| 母公司 | Adobe（美国软件巨头，Creative Cloud 订阅套件） |
| 前身 | PageMaker（Adobe 收购 Aldus） |
| InDesign 首发 | 1999 年 |
| 定位 | 版面排版核心，与 Photoshop（位图）、Illustrator（矢量）配合 |

## 三件套分工

| 软件 | 作用 |
|------|------|
| Photoshop | 位图图像处理 |
| Illustrator | 矢量图形绘制 |
| **InDesign** | 版面排版与出版输出 |

## 版本演进

| 版本 | 年份 | 关键变化 |
|------|------|----------|
| InDesign 1.0 | 1999 | 取代 PageMaker |
| CS 系列 | 2003–2012 | Creative Suite |
| CC 系列 | 2013 起 | Creative Cloud 订阅 |
| **InDesign 2026**（v21） | 2025-10 | Flex Layout、Firefly AI、云文档 |

## InDesign 2026 新功能

| 功能 | 说明 |
|------|------|
| Flex Layout | CSS Flexbox 式弹性布局 |
| Firefly AI | 文生图、生成式扩展 |
| MathML | 数学公式 |
| PDF 转可编辑 | 导入 PDF 转为可编辑文档 |
| 云文档 | 自动保存、实时同步、文本编辑分享 |
