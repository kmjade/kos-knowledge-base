# 06 表格与长文档

## 表格（Table）

| 能力 | 说明 |
|------|------|
| 创建表格 | 表格工具或置入 |
| 单元格/表头 | 行列表头 |
| 表样式/单元格样式 | 表格样式 |
| 表格导出 | PDF/EPUB 表格可访问性（2026 增强） |

## 书籍（Book）

书籍功能管理多文档长出版物（如一本多章的书）：

| 能力 | 说明 |
|------|------|
| 书籍面板 | 管理多个文档 |
| 同步样式 | 章节间样式同步 |
| 连续页码 | 跨文档连续编号 |

## 目录（Table of Contents）

自动生成目录：

| 要点 | 说明 |
|------|------|
| 基于段落样式 | 用标题样式生成 |
| 自动更新 | 更新页码与条目 |
| 导出 | 交互式 PDF 书签 |

## 索引（Index）

| 能力 | 说明 |
|------|------|
| 索引标记 | 标记关键词 |
| 索引生成 | 自动生成索引 |

## 交叉引用（Cross-References）
