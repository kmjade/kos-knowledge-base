# 02 界面与文档

## 界面组成

| 区域 | 功能 |
|------|------|
| 工具箱（Toolbox） | 选择、文字、图形、框架工具 |
| 控制面板 | 上下文相关属性 |
| 面板（Panels） | 页面、图层、链接、样式 |
| 粘贴板 | 页面外的暂存区 |
| 页面 | 实际的版面 |

## 文档设置

新建文档（New Document）关键参数：

| 参数 | 说明 |
|------|------|
| 页面尺寸 | A4/A3/自定义 |
| 页边距（Margins） | 版面留白 |
| 分栏（Columns） | 文字分栏 |
| 出血（Bleed） | 印刷裁切余量（通常 3mm） |
| 辅助信息区（Slug） | 备注区 |

## 页面与跨页

| 概念 | 说明 |
|------|------|
| 页面（Page） | 单页 |
| 跨页（Spread） | 对开的两页 |
| 母版页（Master） | 应用于多页的模板 |

## 出血（Bleed）

出血是延伸到页面裁切边缘之外的颜色/图像，确保裁切后无白边：

- 常见出血：3mm（印刷）、0.125 英寸（美国）
- 元素需延伸至出血线

## 标尺与参考线

| 工具 | 说明 |
|------|------|
| 标尺 | 页面定位 |
| 参考线 | 手动对齐线 |
| 智能参考线 | 自动对齐提示 |
