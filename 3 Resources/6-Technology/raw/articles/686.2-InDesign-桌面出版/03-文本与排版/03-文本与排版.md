# 03 文本与排版

## 文本框架（Text Frame）

文本框架是承载文字的容器：

| 能力 | 说明 |
|------|------|
| 创建 | 文字工具拖拽 |
| 串接（Threading） | 文本在框架间流动 |
| 自动排入 | 长文本自动流入多页 |

## 字符格式

| 属性 | 说明 |
|------|------|
| 字体（Typeface） | 字体系 |
| 字号/行距（Size/Leading） | 大小与行间距 |
| 字偶距/字距（Kerning/Tracking） | 字符间距 |
| OpenType 特性 | 连字、小型大写 |
| 首字下沉（Drop Cap） | 段落首字放大 |

## 段落格式

| 属性 | 说明 |
|------|------|
| 对齐 | 左/中/右/两端 |
| 缩进/间距 | 段前/段后 |
| 连字（Hyphenation） | 自动断词 |
| 孤行/寡行控制 | 避免孤立行 |
| 项目符号/编号 | 列表 |

## 样式（Styles）

| 样式 | 作用 |
|------|------|
| 字符样式 | 字符级格式 |
| 段落样式 | 段落级格式（含字符+段落） |
| 嵌套样式/GREP 样式 | 自动套用 |

> 用样式而非手动格式化，是专业排版的关键（详见 [[04-母版页与样式]]）。

## 排版（Typography）

| 要点 | 说明 |
|------|------|
| 基线网格 | 文字对齐基线 |
| 连字/断词 | 两端对齐质量 |
| 特殊字符 | 破折号、引号、空格 |
