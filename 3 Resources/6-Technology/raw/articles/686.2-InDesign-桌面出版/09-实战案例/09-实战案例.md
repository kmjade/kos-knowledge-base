# 09 实战案例

## 案例总览

| 案例 | 难度 | 覆盖 |
|------|:----:|------|
| 宣传册 | ⭐⭐ | 文档、文本、图像 |
| 杂志 | ⭐⭐⭐ | 母版页、样式、长文档 |
| 书籍 | ⭐⭐⭐⭐ | 书籍、目录、索引 |

## 案例一：宣传册

```
1. 新建文档（A4、3mm 出血、分栏）
2. 设计母版页（页眉、页脚、页码）
3. 排入文本（置入 Word → 自动流）
4. 置入图像（链接、适合框架）
5. 应用段落样式、文字环绕
6. 预检 → 打包 → 导出打印 PDF
```

**要点**：出血、母版页、链接图像、打包输出。

## 案例二：杂志

```
1. 设置网格（分栏 + 基线网格）
2. 建母版页（不同栏目模板）
3. 建段落/字符样式（标题、正文、引文）
4. 逐页排版，链接图像，文字环绕
5. 生成目录
6. 预检 → 导出 PDF/X-4
```

**要点**：网格系统、样式体系、目录、印刷标准。

## 案例三：书籍

```
1. 建书籍文件（Book），分章管理
2. 每章用统一母版页 + 样式
3. 同步书籍样式
4. 连续页码、生成目录与索引
5. 交叉引用
6. 打包 → 导出 EPUB + 打印 PDF
```

**要点**：书籍管理、样式同步、目录索引、双格式输出。
