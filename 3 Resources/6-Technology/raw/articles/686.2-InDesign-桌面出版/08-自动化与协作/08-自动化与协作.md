# 08 自动化与协作

## 数据合并（Data Merge）

用 CSV/TXT 数据源批量生成个性化版面（名片、证书、信函）：

- 数据字段插入文本框
- 多条记录批量生成
- 2026 增强：多行记录、UTF-8 编码支持

## 脚本（Scripting）

| 语言 | 说明 |
|------|------|
| JavaScript（ExtendScript） | 最常用 |
| AppleScript / VBScript | 平台脚本 |
| UXP 脚本 | 现代脚本 API |

## InDesign Server

服务端版本的 InDesign，用于自动化批量排版（出版、金融、制造业报表）。

## 协作（2026 增强）

| 功能 | 说明 |
|------|------|
| 云文档 | 自动保存、实时同步 |
| 文本编辑分享 | 分享链接给协作者编辑文本 |
| InCopy on Web（Beta） | 浏览器文本编辑 |
| 审阅（Review） | 在线批注审阅 |
