# 07 输出与导出

## 预检（Preflight）

导出前检查文档问题（缺失字体、缺失链接、溢流文本）：

- 实时预检面板
- 打包前自动预检

## 打包（Package）

打包收集文档 + 链接图像 + 字体，确保交付完整：

```
文件 → 打包 → 检查摘要 → 生成打包文件夹
```

## 打印 PDF（Print PDF）

| 要点 | 说明 |
|------|------|
| PDF/X 标准 | 印刷标准（PDF/X-1a、X-4） |
| 出血/裁切标记 | 印刷标记 |
| 色彩 | CMYK + 专色保留 |

## 交互式 PDF

| 功能 | 说明 |
|------|------|
| 超链接 | 内部/外部链接 |
| 书签 | 目录书签 |
| 按钮/表单 | 交互元素 |
| 多媒体 | 视频/音频 |

## EPUB / HTML5

| 格式 | 说明 |
|------|------|
| EPUB | 电子书（回流式/固定版式） |
| HTML5 | 网页出版物 |
| Publish Online | 在线发布 |
