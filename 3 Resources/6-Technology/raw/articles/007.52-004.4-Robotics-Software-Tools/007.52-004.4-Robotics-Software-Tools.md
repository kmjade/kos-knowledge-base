# 007.52:004.4 机器人软件开发工具

> 机器人软件开发工具（Robotics Software Tools，UDC 007.52:004.4）是机器人工程的**软件工具链**：以 ROS2 为核心，涵盖建模（URDF/xacro）、可视化（RViz/RQt/Foxglove）、仿真（Gazebo/Isaac Sim）、运动规划（MoveIt 2）、导航与 SLAM（Nav2/SLAM Toolbox）、硬件控制（ros2_control/micro-ROS）。数据更新至 2026-09。
