# 03 建模与描述

## URDF / xacro

| 格式 | 说明 |
|------|------|
| URDF | 机器人模型描述（link/joint） |
| xacro | URDF 的宏扩展（复用/参数化） |
| SDF | Gazebo 仿真格式 |

## tf2（坐标变换）

tf2 管理坐标系变换树（base_link → odom → map 等），是导航/感知的基础。

## 典型用法

- URDF 定义连杆与关节
- xacro 宏生成复杂模型
- robot_state_publisher 发布 tf
- 供 RViz / Gazebo / MoveIt 使用
