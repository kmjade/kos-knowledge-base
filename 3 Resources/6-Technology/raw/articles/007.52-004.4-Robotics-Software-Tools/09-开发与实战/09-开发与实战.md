# 09 开发与实战

## 开发环境

| 环境 | 说明 |
|------|------|
| Ubuntu 24.04 + Jazzy | 主流 |
| Docker | `ros:jazzy-ros-base-noble` 镜像 |
| macOS | Homebrew（ros2-jazzy） |

## CI 与版本控制

- 行为树 XML、规划器 YAML、控制器 YAML 纳入版本控制
- 多发行版 CI matrix（Jazzy + Kilted）
- 避免同 workspace 混用发行版

## 完整示例（rbot）

开源 `rlxai/rbot` 展示完整 AMR 栈：

```
URDF/Xacro → ros2_control（diff_drive + joint_state_broadcaster）
→ 遥操作 → LiDAR/相机感知 → EKF + AMCL
→ SLAM Toolbox（async/lifelong）→ Nav2（MPPI + SMAC Hybrid-A*）
→ Docker 容器化
```

## 实战建议

1. 默认 Jazzy（Ubuntu 24.04）
2. 依赖未移植时才用 Humble
3. 仿真先行（Gazebo Harmonic），再迁移真机
