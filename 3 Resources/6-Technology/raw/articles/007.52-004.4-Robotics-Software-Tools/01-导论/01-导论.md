# 01 导论

## 什么是机器人软件开发工具链

机器人软件开发工具是机器人工程的**软件栈**：以 **ROS2** 为核心中间件，配合建模、可视化、仿真、运动规划、导航 SLAM、硬件控制等工具，构成完整的开发工具链。

## ROS2 发行版（2026）

| 发行版 | 发布 | EOL | 类型 | 说明 |
|--------|------|-----|------|------|
| Humble Hawksbill | 2022-05 | 2027-05 | LTS | 保守选择 |
| **Jazzy Jalisco** | 2024-05 | 2029-05 | LTS | 当前默认（Ubuntu 24.04） |
| Kilted Kaiju | 2025-05 | 2026 底 | 非 LTS | 实验特性 |
| Lyrical Luth | 2026-05 | ~2031 | LTS | 新发布 |

> ROS1 Noetic 已于 2025-05 EOL，ROS2 是唯一受支持的路径。建议默认 Jazzy。

## 工具链全景

| 类别 | 工具 |
|------|------|
| 建模 | URDF / xacro / SDF |
| 可视化 | RViz / RQt / Foxglove / rosbag |
| 仿真 | Gazebo Harmonic/Ionic / Isaac Sim / MuJoCo |
| 运动规划 | MoveIt 2 / OMPL / TRAC-IK |
| 导航 SLAM | Nav2 / SLAM Toolbox / AMCL |
| 硬件控制 | ros2_control / micro-ROS |
