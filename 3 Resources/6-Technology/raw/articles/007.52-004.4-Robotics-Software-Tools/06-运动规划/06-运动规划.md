# 06 运动规划

## MoveIt 2

操作机器人（机械臂）的**事实标准**运动规划框架：

| 组件 | 说明 |
|------|------|
| 规划器 | OMPL（默认）、CHOMP、STOMP、Pilz Industrial |
| IK 求解 | KDL、TRAC-IK、bio_ik、IKFast |
| 配置 | URDF + SRDF（MoveIt Setup Assistant） |

## 关键坑点

- URDF/SRDF 碰撞模型与真实机器人不一致是常见问题
- 规划管线参数在 Jazzy→Kilted 有弃用变更

## MoveIt Pro

PickNik 的商业行为树驱动版本。
