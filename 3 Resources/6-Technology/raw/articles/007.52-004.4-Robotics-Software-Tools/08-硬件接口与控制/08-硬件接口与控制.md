# 08 硬件接口与控制

## ros2_control

控制器与硬件之间的**标准化接口**，确定性控制环（通常 100Hz–1kHz）：

| 组件 | 说明 |
|------|------|
| 硬件接口 | pluginlib 插件（SystemInterface） |
| 控制器 | JointTrajectoryController、DiffDriveController、JointStateBroadcaster 等 |
| 配置 | URDF `<ros2_control>` 标签 + controllers.yaml |

## micro-ROS

把 ROS2 延伸到**微控制器**（ESP32/STM32/Teensy/RP2040），运行 FreeRTOS/Zephyr/NuttX：

- 最小 rcl 栈 + micro XRCE-DDS 客户端
- 通过 micro-ROS agent（主机）经串口/UART/USB/UDP 通信
- 应用：电机控制器、IMU 驱动、接近传感器作为 ROS2 节点
