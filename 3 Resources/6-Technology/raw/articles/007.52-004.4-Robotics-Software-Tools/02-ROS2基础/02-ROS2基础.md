# 02 ROS2 基础

## 核心通信

| 机制 | 说明 |
|------|------|
| 话题（Topic） | 发布/订阅，多对多 |
| 服务（Service） | 请求/响应，一对一 |
| 动作（Action） | 长任务（可取消/反馈） |
| 参数（Parameter） | 运行时配置 |

## DDS 中间件

| DDS | 说明 |
|-----|------|
| Fast DDS | Jazzy 默认，MoveIt/Gazebo 推荐 |
| Cyclone DDS | Nav2 推荐，内存高效 |
| Zenoh | 云边桥接、NAT 穿透、多机 |
| Iceoryx 2 | 单机零拷贝、亚毫秒 |

## 生命周期节点

ROS2 节点支持**生命周期管理**（未配置/未激活/激活等状态），Nav2 等核心节点均为生命周期节点。

## QoS

服务质量策略：可靠/尽力、持久性、深度等，按传感器/命令需求配置。
