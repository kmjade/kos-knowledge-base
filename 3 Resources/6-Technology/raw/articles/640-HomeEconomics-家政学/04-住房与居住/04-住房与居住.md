# 04-住房与居住

> 居住空间的选择、设计与整理——家的物理基础。

## 住房选择

| 因素 | 说明 |
|------|------|
| 位置 | 通勤、配套 |
| 面积 | 户型、功能 |
| 朝向 | 采光、通风 |
| 成本 | 租金/房贷、物业 |

## 室内设计原则

- 功能分区（动区/静区）
- 动线流畅
- 采光通风
- 色彩与材质搭配

## 收纳整理

| 方法 | 核心 |
|------|------|
| 断舍离 | 舍弃无用之物 |
| 怦然心动整理法 | 只留心动之物 |
| 分类收纳 | 同类集中 |
| 垂直收纳 | 利用高度 |

## 家居安全

- 防火（烟感、灭火器）
- 防滑、防摔（老人、儿童）
- 用电安全
- 空气质量（甲醛、通风）

## 智能家居

- 智能照明、温控
- 安防监控、门锁
- 语音助手、自动化
