# 03-烹饪学

> 把食材变成美食的科学与艺术。

## 烹饪原理

| 原理 | 说明 |
|------|------|
| 热传递 | 传导、对流、辐射 |
| 蛋白质变性 | 凝固（熟化） |
| 淀粉糊化 | 吸水膨胀 |
| 美拉德反应 | 褐变、风味 |
| 焦糖化 | 糖受热褐变 |

## 基本刀工

- 切、片、剁、劈、拍、剞
- 丝、片、丁、块、条、末

## 火候

| 火候 | 适用 |
|------|------|
| 旺火 | 爆炒 |
| 中火 | 煎、炒 |
| 小火 | 炖、焖 |
| 微火 | 慢炖、煲汤 |

## 调味

- 基本味：咸、甜、酸、辣、苦、鲜
- 调味时机：烹调前（腌制）、中、后

## 主要烹饪方法

| 方法 | 特点 |
|------|------|
| 炒 | 快速、高温 |
| 蒸 | 保留营养 |
| 煮 | 水煮 |
| 炖 | 慢火入味 |
| 煎/炸 | 外酥里嫩 |
| 烤 | 干热 |

## 中餐 vs 西餐

- 中餐：热锅快炒、复合调味
- 西餐：精确温度、酱汁体系
