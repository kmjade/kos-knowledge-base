# 08-家庭健康与护理

> 守护家人的健康——预防、急救与照护。

## 家庭健康管理

| 方面 | 内容 |
|------|------|
| 健康档案 | 体检、疫苗、病史 |
| 生活方式 | 饮食、运动、睡眠 |
| 慢病管理 | 血压、血糖监测 |
| 心理健康 | 情绪、压力 |

## 家庭急救

| 情况 | 处理 |
|------|------|
| 烧烫伤 | 冲、脱、泡、盖、送 |
| 止血 | 压迫、包扎 |
| 气道异物 | 海姆立克法 |
| 心肺复苏 (CPR) | 胸外按压 + 人工呼吸 |
| 中毒 | 催吐/不催吐、就医 |

## 常见症状照护

- 发热、咳嗽、腹泻
- 体温测量、用药安全
- 何时就医（红旗征象）

## 慢性病家庭照护

| 疾病 | 家庭照护 |
|------|------|
| 高血压 | 限盐、监测 |
| 糖尿病 | 饮食、血糖 |
| 失能老人 | 翻身、防压疮 |

## 家庭药箱

- 常备药、急救用品
- 药品储存、有效期
- 儿童安全（高处、锁）
