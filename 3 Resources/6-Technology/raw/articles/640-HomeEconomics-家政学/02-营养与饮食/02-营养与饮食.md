# 02-营养与饮食

> 吃什么、怎么吃——营养是健康的第一基石。

## 六大营养素

| 营养素 | 功能 | 来源 |
|------|------|------|
| 碳水化合物 | 供能 | 谷物、薯类 |
| 蛋白质 | 组织修复 | 肉蛋奶豆 |
| 脂肪 | 储能、激素 | 油、坚果 |
| 维生素 | 代谢调节 | 蔬果 |
| 矿物质 | 生理功能 | 广泛 |
| 水 | 生命基础 | 饮水、食物 |

## 能量

- 三大产能营养素：碳水 4 kcal/g、蛋白 4 kcal/g、脂肪 9 kcal/g
- 基础代谢、体力活动

## 膳食指南（平衡膳食）

- 食物多样、谷类为主
- 多吃蔬果、奶类、大豆
- 适量鱼禽蛋瘦肉
- 少盐少油、控糖限酒

## 膳食宝塔

```
油盐（少） → 奶豆 → 鱼肉蛋 → 蔬果 → 谷物（多）
```

## 特殊人群营养

| 人群 | 重点 |
|------|------|
| 孕妇 | 叶酸、铁 |
| 婴幼儿 | 母乳、辅食 |
| 老年人 | 蛋白、钙、维 D |
| 慢性病患者 | 控糖、低盐、低脂 |

## 食品安全

- 食品标签、保质期
- 储存、烹饪安全
- 食源性疾病预防
