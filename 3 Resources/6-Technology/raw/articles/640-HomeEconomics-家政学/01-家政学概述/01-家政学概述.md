# 01-家政学概述

> 让家庭生活更美好的科学——系统化生活技能。

## 家政学体系

| 领域 | 内容 |
|------|------|
| 食 | 营养、烹饪 |
| 衣 | 服装、纺织 |
| 住 | 住房、收纳 |
| 育 | 育儿、教育 |
| 财 | 家庭财务 |
| 康 | 家庭健康 |

## 家庭生命周期

```
单身 → 新婚 → 育儿 → 空巢 → 老年
```

## 家庭管理

| 资源 | 管理 |
|------|------|
| 时间 | 家务分工、效率 |
| 金钱 | 预算、储蓄 |
| 人力 | 家庭成员协作 |
| 空间 | 收纳、动线 |

## 家政学的价值

- 提升生活品质
- 促进家庭和谐
- 培养生活技能
- 可持续发展（低碳生活）

## 现代家政趋势

- 智能家居、极简生活
- 外食/预制菜兴起
- 双职工家庭的家务外包
- 终身学习、亲子共育
