# 05-服装与纺织

> 从面料到穿搭——衣着的科学与审美。

## 天然纤维

| 纤维 | 特性 |
|------|------|
| 棉 | 吸湿、透气 |
| 麻 | 凉爽、耐磨 |
| 羊毛 | 保暖、弹性 |
| 丝绸 | 光滑、光泽 |

## 化学纤维

| 纤维 | 特性 |
|------|------|
| 涤纶 | 耐磨、易干 |
| 锦纶 | 强度高 |
| 腈纶 | 保暖、蓬松 |
| 氨纶 | 高弹性 |

## 服装护理

- 洗涤标识（水温、方式）
- 熨烫温度
- 收纳（防潮、防虫）
- 去渍技巧

## 穿搭基础

| 原则 | 说明 |
|------|------|
| 合体 | 尺码、剪裁 |
| 场合 | 正装/休闲/运动 |
| 色彩 | 协调、对比 |
| 比例 | 上下身比例 |

## 可持续时尚

- 快时尚的环境问题
- 二手、租赁、修补
- 环保面料
