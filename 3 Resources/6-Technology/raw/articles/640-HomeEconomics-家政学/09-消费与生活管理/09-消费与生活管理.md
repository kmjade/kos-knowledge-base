# 09-消费与生活管理

> 聪明的消费与有品质的生活。

## 消费决策

- 需要 vs 想要
- 性价比、生命周期成本
- 冲动消费、消费陷阱
- 理性购物清单

## 消费者权益

- 知情权、选择权、安全权
- 退换货、投诉维权
- 合同、保修

## 极简主义

| 理念 | 说明 |
|------|------|
| 断舍离 | 断绝、舍弃、脱离 |
| 少而精 | 质量 > 数量 |
| 一进一出 | 买新先弃旧 |
| 数字极简 | 减少信息噪音 |

## 生活品质

- 时间管理、工作生活平衡
- 睡眠、运动、休闲
- 兴趣爱好、精神生活
- 人际关系、社交

## 可持续生活

- 减少浪费（食物、能源）
- 垃圾分类、回收
- 低碳出行
- 环保消费

## 终身学习

- 生活技能的持续更新
- 数字技能、健康素养
- 财务素养
