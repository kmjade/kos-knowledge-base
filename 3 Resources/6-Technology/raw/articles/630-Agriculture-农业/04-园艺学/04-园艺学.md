# 04-园艺学

> 果树、蔬菜与花卉的栽培——农业中的精细分支。

## 园艺分类

| 类别 | 内容 |
|------|------|
| 果树 | 苹果、柑橘、葡萄、桃 |
| 蔬菜 | 叶菜、果菜、根菜 |
| 花卉 | 观赏植物 |
| 设施园艺 | 温室、大棚 |

## 果树栽培

- 嫁接：接穗 + 砧木
- 整形修剪：通风透光、控制生长
- 疏花疏果：提高品质
- 果园管理：施肥、灌溉、病虫害

## 蔬菜栽培

- 露地栽培 vs 设施栽培
- 育苗、定植、肥水管理
- 反季节蔬菜（温室）

## 花卉栽培

- 切花、盆花、绿化
- 光周期调控开花
- 温室环境控制（温度、光照、湿度）

## 设施园艺

| 设施 | 功能 |
|------|------|
| 地膜覆盖 | 保温保湿 |
| 塑料大棚 | 反季节种植 |
| 玻璃温室 | 精准环境控制 |
| 无土栽培 | 水培、基质培 |

- 现代温室 = 环境可控的「植物工厂」
