# 02-作物学

> 研究作物的种植、育种与生产——粮食生产的核心。

## 主要粮食作物

| 作物 | 学名 | 主要产区 |
|------|------|------|
| 水稻 | *Oryza sativa* | 亚洲 |
| 小麦 | *Triticum aestivum* | 温带 |
| 玉米 | *Zea mays* | 全球 |
| 大豆 | *Glycine max* | 美洲、亚洲 |
| 马铃薯 | *Solanum tuberosum* | 全球 |

## 经济作物

- 棉花、甘蔗、油菜、花生
- 茶叶、咖啡、烟草、橡胶

## 种植制度

| 制度 | 说明 |
|------|------|
| 单作 | 单一作物 |
| 轮作 | 不同作物轮换（养地） |
| 间作/套种 | 同时/错时混种 |
| 复种 | 一年多熟 |

## 作物育种

| 方法 | 说明 |
|------|------|
| 选择育种 | 优选性状 |
| 杂交育种 | 杂种优势 |
| 诱变育种 | 辐射/化学诱变 |
| 基因工程 | 转基因（抗虫、抗除草剂） |
| 分子标记辅助 | 精准选择 |

## 作物生理

- 光合作用、蒸腾作用
- 光周期、温度对生长的影响
- 营养（氮磷钾）与水分需求
