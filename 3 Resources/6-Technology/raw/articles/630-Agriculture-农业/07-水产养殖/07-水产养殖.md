# 07-水产养殖

> 水生生物的生产——捕捞与养殖并重。

## 渔业类型

| 类型 | 说明 |
|------|------|
| 海洋捕捞 | 近海、远洋 |
| 淡水养殖 | 池塘、湖泊 |
| 海水养殖 | 网箱、滩涂 |
| 稻田养殖 | 稻鱼共生 |

## 主要养殖品种

| 类别 | 品种 |
|------|------|
| 鱼类 | 草鱼、鲤鱼、鲈鱼、三文鱼 |
| 甲壳类 | 虾、蟹 |
| 贝类 | 牡蛎、扇贝、蛤 |
| 藻类 | 海带、紫菜 |

## 养殖技术

- 苗种繁育（人工繁殖）
- 饲料投喂、水质管理
- 病害防治
- 增氧、循环水系统

## 过度捕捞

- 全球渔业资源衰退
- 休渔期、捕捞配额
- 可持续渔业（MSC 认证）

## 水产养殖的意义

- 提供优质蛋白
- 减少对野生渔业依赖
- 未来食物安全的重要组成
