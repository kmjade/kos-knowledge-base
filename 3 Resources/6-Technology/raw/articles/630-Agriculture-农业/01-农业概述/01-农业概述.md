# 01-农业概述

> 人类最古老的产业——从刀耕火种到精准农业。

## 农业类型

| 类型 | 特征 |
|------|------|
| 传统农业 | 经验、人力、低投入低产出 |
| 现代农业 | 机械化、化学化、良种化 |
| 精准农业 | 信息技术、变量投入 |
| 生态农业 | 生态循环、减少化肥农药 |
| 有机农业 | 禁止合成化学品 |

## 农业史的三个阶段

| 阶段 | 标志 |
|------|------|
| 原始农业 | 刀耕火种 |
| 传统农业 | 铁犁、畜力、轮作 |
| 现代农业 | 绿色革命、基因技术 |

## 绿色革命

- 20 世纪 60–70 年代
- 高产品种 + 化肥 + 灌溉 + 农药
- 大幅增产，但也带来环境问题

## 农业在国民经济中的地位

- 第一产业（农业、林业、牧业、渔业）
- 粮食安全是国家安全基础
- 农业人口占比随发展下降

## 挑战

- 人口增长 vs 耕地有限
- 气候变化、水资源短缺
- 土壤退化、生物多样性下降
