# 09-农业经济与可持续

> 农业的经济规律与可持续未来。

## 粮食安全

> 定义：所有人在任何时候都能获得足够、安全、有营养的食物。

- 四维度：可获得性、可及性、利用、稳定
- 全球饥饿人口：约 7–8 亿
- 粮食生产 vs 分配不均

## 农业经济

| 概念 | 说明 |
|------|------|
| 供给与需求 | 农产品价格 |
| 蛛网模型 | 生产决策滞后 |
| 农业补贴 | 支持农民收入 |
| 土地制度 | 产权、流转 |

## 可持续农业

| 模式 | 核心 |
|------|------|
| 生态农业 | 生态循环 |
| 有机农业 | 无合成化学品 |
| 保护性农业 | 少耕、覆盖、轮作 |
| 气候智慧农业 | 适应 + 减缓气候变化 |

## 农业与环境

- 农业是温室气体重要来源（甲烷、氧化亚氮）
- 化肥污染（水体富营养化）
- 农药残留、生物多样性

## 未来农业

- 垂直农业、城市农业
- 人造肉、替代蛋白
- 基因编辑作物
- 数字农业与 AI
