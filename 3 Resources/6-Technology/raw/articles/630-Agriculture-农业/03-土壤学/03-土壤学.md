# 03-土壤学

> 研究土壤的组成、性质与肥力——农业的根基。

## 土壤组成

| 组分 | 比例 |
|------|:--:|
| 矿物质 | ~45% |
| 有机质 | ~5% |
| 水 | ~25% |
| 空气 | ~25% |

## 土壤质地

| 类型 | 特征 |
|------|------|
| 砂土 | 粗、透水、保肥差 |
| 壤土 | 适中（最宜耕作） |
| 黏土 | 细、保水、透气差 |

## 土壤肥力

- **物理肥力**：结构、孔隙、通气
- **化学肥力**：养分（N、P、K）、pH
- **生物肥力**：微生物、有机质

## 土壤养分

| 元素 | 作用 | 缺乏症状 |
|------|------|------|
| 氮 N | 叶片生长 | 黄叶 |
| 磷 P | 根、花、果 | 紫叶 |
| 钾 K | 抗逆、品质 | 叶缘焦枯 |

## 土壤退化

| 问题 | 成因 |
|------|------|
| 水土流失 | 植被破坏、坡地耕作 |
| 盐碱化 | 灌溉不当 |
| 酸化 | 化肥滥用、酸雨 |
| 荒漠化 | 过度放牧、干旱 |

## 土壤保护

- 轮作、覆盖、免耕
- 有机肥、绿肥
- 水土保持（梯田、植被）
