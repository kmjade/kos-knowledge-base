# 06-林业

> 森林的培育、经营与保护——生态与经济的双重价值。

## 森林类型

| 类型 | 特征 | 分布 |
|------|------|------|
| 热带雨林 | 物种丰富 | 赤道附近 |
| 温带落叶林 | 四季落叶 | 中纬度 |
| 针叶林（泰加林） | 耐寒 | 高纬度 |
| 亚热带常绿林 | 常绿阔叶 | 亚热带 |

## 森林的功能

| 功能 | 说明 |
|------|------|
| 生态 | 涵养水源、固碳、防风、栖息地 |
| 经济 | 木材、林产品 |
| 社会 | 休憩、文化、就业 |

## 木材生产

- 用材林、经济林、防护林、薪炭林
- 轮伐期、间伐、主伐
- 可持续林业（FSC 认证）

## 森林经营

- 造林、抚育、采伐
- 人工林 vs 天然林
- 病虫害防治

## 森林破坏与保护

| 问题 | 影响 |
|------|------|
| 滥砍滥伐 | 水土流失、生物丧失 |
| 森林火灾 | 生态灾难、碳排放 |
| 病虫害 | 大面积死亡 |

- 退耕还林、天然林保护
- 森林碳汇（应对气候变化）
