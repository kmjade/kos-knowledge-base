# 06 仿真运行

## 启动命令对比

| 操作 | Classic | 新版 |
|:--|:--|:--|
| 带 GUI 启动 | `gazebo world.sdf` | `gz sim world.sdf` |
| 无头（headless） | `gzserver world.sdf` | `gz sim -s world.sdf`（server only） |
| 独立客户端 | `gzclient` | `gz sim -g` |
| 暂停/单步 | 空格 | `Esc` / 空格 |

## 组合启动（新版 gz-launch）

```bash
gz sim -r -v 4 world.sdf    # -r 立即运行, -v 4 日志级别
```

也可用 YAML 编排多个子系统：

```yaml
# gz sim 内部用 gz-launch 组合 server + GUI
```

## 录制与回放

| 功能 | Classic | 新版 |
|:--|:--|:--|
| 录制状态 | `.state` 文件 | `gz sim -r --record` / log |
| 回放 | `gazebo -p` | `gz sim -r --playback` |
| 录制话题 | rosbag | rosbag + gz 的 log |

## 仿真控制

- 重置：`gz world -r`（新版重置世界）
- 服务：`gz sim` 暴露 service（世界控制/实体控制）
- 步进：单步模式用于确定性调试
