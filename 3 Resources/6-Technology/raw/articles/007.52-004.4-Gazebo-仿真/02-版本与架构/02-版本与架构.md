# 02 版本与架构

## 两条版本线

| 维度 | Gazebo Classic | 新版 Gazebo（Ignition 谱系） |
|:--|:--|:--|
| 版本 | ≤ Gazebo 11 | Citadel→Fortress→Garden→Harmonic→Ionic→Jetty |
| 架构 | 单体外壳 | 模块化 `gz-*` 库 |
| 命令 | `gazebo` / `gzserver` / `gzclient` | `gz sim` |
| 通信 | 内部 | `gz-transport`（基于 protobuf） |
| 状态 | 已停止维护 | 活跃开发 |

## 新版 Gazebo 模块化架构

新版把单体拆成一组 `gz-*` 库：

| 模块 | 职责 |
|:--|:--|
| `gz-sim` | 仿真主程序（替代 gazebo） |
| `gz-physics` | 物理引擎抽象（ODE/Bullet/DART/TPE） |
| `gz-rendering` | 渲染（OGRE2/OGRE） |
| `gz-sensors` | 传感器模型 |
| `gz-transport` | 进程间通信（pub/sub，protobuf） |
| `gz-msgs` | 消息定义 |
| `gz-plugin` | 插件加载 |
| `gz-gui` | GUI 框架 |
| `gz-launch` | 组合启动（YAML 编排） |
| `gz-fuel` | 模型/世界在线库 |
| `gz-math` / `gz-common` | 基础库 |

## 命名史（为什么叫 Ignition 又叫 Gazebo）

1. 2018 起 Open Robotics 用「Ignition」做模块化重构的**代号**，各库 `ign-*`
2. 2021 年 `ignition-` 前缀改名 `gz-`（Ignition 是「点火」，Gazebo 的 G）
3. 2021 底起，**产品层面「Ignition」改回「Gazebo」**，用**城市名**做发行名（Citadel/Fortress/Garden/Harmonic/Ionic/Jetty）

> 社区常把新版叫「Ignition」或「gz」，均指同一条模块化线。
