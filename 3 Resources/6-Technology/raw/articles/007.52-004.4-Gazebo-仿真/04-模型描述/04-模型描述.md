# 04 模型描述

## URDF vs SDF

| 维度 | URDF | SDF |
|:--|:--|:--|
| 全称 | Unified Robot Description Format | Simulation Description Format |
| 用途 | 机器人运动学描述（ROS 原生） | 仿真世界/模型（Gazebo 原生） |
| 嵌套 | 不支持嵌套模型 | 支持嵌套、世界级描述 |
| 物理属性 | 弱（需 gazebo 扩展标签） | 原生支持惯性/碰撞/摩擦 |
| 表达力 | 有限（无闭合链、无子模型） | 强（模型组合、状态） |

## 两者关系

- ROS 生态用 **URDF** 描述机器人（`robot_state_publisher` 发布 `/tf`）
- Gazebo 仿真时把 URDF **转换**成 SDF（`gazebo` 标签补物理参数），或用原生 **SDF** 建模

```xml
<!-- URDF 里的 gazebo 扩展，补惯性/碰撞 -->
<gazebo reference="base_link">
  <material>Gazebo/Grey</material>
  <mu1>0.5</mu1>
</gazebo>
```

## 新版 Gazebo 的 SDF 优势

新版 Gazebo 原生支持 SDF 1.x，支持：
- 模型嵌套、子模型
- 世界级传感器、物理参数
- `gz-fuel` 在线模型直接 `<include>`

## 转换工具

- `rosrun xacro xacro model.urdf.xacro` → URDF
- `gz sdf -p model.sdf` 打印 SDF
- `sdformat` 库处理 SDF 文件
