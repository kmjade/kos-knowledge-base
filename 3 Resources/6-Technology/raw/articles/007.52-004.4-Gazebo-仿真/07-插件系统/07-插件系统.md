# 07 插件系统

## 插件类型

| 类型 | 作用 |
|:--|:--|
| World 插件 | 世界级逻辑（如物理更新钩子） |
| Model 插件 | 控制模型（如差速驱动） |
| Sensor 插件 | 自定义传感器 |
| System 插件 | 新版通用系统（仿真生命周期钩子） |
| Visual 插件 | 渲染自定义 |

## Gazebo Classic 插件

- 用 `libgazebo_ros_*` 桥接 ROS
- C++ 继承 `ModelPlugin` / `WorldPlugin` 等基类

```cpp
class MyModelPlugin : public gazebo::ModelPlugin {
  void Load(physics::ModelPtr model, sdf::ElementPtr sdf) override { ... }
};
GZ_REGISTER_MODEL_PLUGIN(MyModelPlugin)
```

## 新版 Gazebo 插件

- 基于 `gz-plugin`，`gz sim` 用 **System** 接口
- 插件类型通过 SDF `<plugin filename="..." name="...">` 声明

```xml
<plugin filename="libgz-sim-diff-drive-system.so" name="gz::sim::systems::DiffDrive">
  <left_joint>left_wheel_joint</left_joint>
</plugin>
```

## 内置插件（新版）

- `DiffDrive`（差速）、`AckermannSteering`、`JointController`
- `TouchPlugin`、`Altimeter`、`IMU`
- `ApplyJointForce` 等
