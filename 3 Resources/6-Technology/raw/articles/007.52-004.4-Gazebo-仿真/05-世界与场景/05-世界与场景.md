# 05 世界与场景

## 世界文件（.sdf / .world）

世界是仿真的容器，包含物理参数、灯光、地面、以及一组模型。

```xml
<sdf version="1.6">
  <world name="default">
    <physics type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_update_rate>1000</real_time_update_rate>
    </physics>
    <include>
      <uri>model://sun</uri>
    </include>
    <model name="ground_plane">
      <static>true</static>
      <link name="link">
        <collision name="collision">
          <geometry><plane><normal>0 0 1</normal></plane></geometry>
        </collision>
      </link>
    </model>
  </world>
</sdf>
```

## 物理引擎

| 引擎 | 说明 |
|:--|:--|
| ODE | 默认，通用刚体 |
| Bullet | 支持软体 |
| DART | 精确、适合抓取/接触 |
| TPE | 轻量（新版，适合大量实体） |

## 灯光与天空

- `<light>`：点光/方向光/聚光
- `sun`、`sky` 模型（模型库内置）
- 阴影参数影响性能

## 场景编辑

- Classic：GUI 里拖模型、改属性
- 新版：`gz sim -g` GUI 编辑，或手写 SDF + `gz fuel` 拉模型
