# 语言文学和语系文学 · Literatures by Language / Language Family (UDC 821)

> [!info] UDC 821 — 语言文学和语系文学
> 按语系 / 语种划分的文学（`821.1/.2` 印欧 · `821.11` 日耳曼语系 · `821.16` 斯拉夫 · `821.9` 其余语系）。

## 📖 概述

UDC `821` 收**按语言或语系划分的文学**，与 `82`（文学本体：体裁、理论）互补：`82` 论「文学是什么、有哪些形式」，`821` 论「哪种语言的文学」。
