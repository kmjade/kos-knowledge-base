# 滕王阁序 Teng Wang Ge Xu

> **体裁说明**：本文是**骈文（四六文）**，不是诗——全篇骈偶，属散文史范畴。本库收录它以两条理由：① 文末附有《**滕王阁诗**》，是诗体；② 骈文是把诗法（对偶、声律、用典）移植到散文的极端形态，与 [[骚体-Sao-Style|骚体]]、[[将进酒-Jiang-Jin-Jiu|将进酒]] 同属「体裁越界」一类。详见 [[骈文-Pianwen|骈文]]。

## 原文

全名《秋日登洪府滕王阁饯别序》，一题《滕王阁诗序》。唐·[[王勃-Wang-Bo|王勃]] 作。**全文约七百余字，异文较多**（见下文「文本校勘」），此据通行本。

> 豫章故郡，洪都新府。星分翼轸，地接衡庐。襟三江而带五湖，控蛮荆而引瓯越。物华天宝，龙光射牛斗之墟；人杰地灵，徐孺下陈蕃之榻。雄州雾列，俊采星驰。台隍枕夷夏之交，宾主尽东南之美。都督阎公之雅望，棨戟遥临；宇文新州之懿范，襜帷暂驻。十旬休假，胜友如云；千里逢迎，高朋满座。腾蛟起凤，孟学士之词宗；紫电青霜，王将军之武库。家君作宰，路出名区；童子何知，躬逢胜饯。
>
> 时维九月，序属三秋。潦水尽而寒潭清，烟光凝而暮山紫。俨骖騑于上路，访风景于崇阿；临帝子之长洲，得天人之旧馆。层峦耸翠，上出重霄；飞阁流丹，下临无地。鹤汀凫渚，穷岛屿之萦回；桂殿兰宫，即冈峦之体势。
>
> 披绣闼，俯雕甍，山原旷其盈视，川泽纡其骇瞩。闾阎扑地，钟鸣鼎食之家；舸舰弥津，青雀黄龙之舳。云销雨霁，彩彻区明。**落霞与孤鹜齐飞，秋水共长天一色。** 渔舟唱晚，响穷彭蠡之滨；雁阵惊寒，声断衡阳之浦。
>
> 遥襟甫畅，逸兴遄飞。爽籁发而清风生，纤歌凝而白云遏。睢园绿竹，气凌彭泽之樽；邺水朱华，光照临川之笔。四美具，二难并。穷睇眄于中天，极娱游于暇日。天高地迥，觉宇宙之无穷；兴尽悲来，识盈虚之有数。望长安于日下，目吴会于云间。地势极而南溟深，天柱高而北辰远。关山难越，谁悲失路之人？萍水相逢，尽是他乡之客。怀帝阍而不见，奉宣室以何年？
>
> 嗟乎！时运不齐，命途多舛。冯唐易老，李广难封。屈贾谊于长沙，非无圣主；窜梁鸿于海曲，岂乏明时？所赖君子见机，达人知命。**老当益壮，宁移白首之心？穷且益坚，不坠青云之志。** 酌贪泉而觉爽，处涸辙以犹欢。北海虽赊，扶摇可接；东隅已逝，桑榆非晚。孟尝高洁，空余报国之情；阮籍猖狂，岂效穷途之哭！
>
> 勃，三尺微命，一介书生。无路请缨，等终军之弱冠；有怀投笔，慕宗悫之长风。舍簪笏于百龄，奉晨昏于万里。非谢家之宝树，接孟氏之芳邻。他日趋庭，叨陪鲤对；今兹捧袂，喜托龙门。杨意不逢，抚凌云而自惜；钟期既遇，奏流水以何惭？
>
> 呜呼！胜地不常，盛筵难再；兰亭已矣，梓泽丘墟。临别赠言，幸承恩于伟饯；登高作赋，是所望于群公。敢竭鄙怀，恭疏短引；一言均赋，四韵俱成。请洒潘江，各倾陆海云尔。

### 附录：《滕王阁诗》

> 滕王高阁临江渚，佩玉鸣鸾罢歌舞。
> 画栋朝飞南浦云，珠帘暮卷西山雨。
> 闲云潭影日悠悠，物换星移几度秋。
> 阁中帝子今何在？槛外长江空自流。

七言八句四联。**形式上已是律诗的轮廓，但平仄对仗尚未完全合律**——初唐七律未定型，故一般视作七言律化过程中的中间样本，而非严格七律。

## 赏析四维

| 维度 | 赏析 |
|------|------|
| 语言 | 通篇**四六相间的对偶句**，「骈四俪六」。「落霞与孤鹜齐飞，秋水共长天一色」以两句十字纳天地两景，是本篇的语言极点——**句式全对而意象全变于前人**（详下）。骈文的难处在于对偶易使文气停滞，本篇以对句推进叙事（地理 → 宴会 → 登览 → 悲慨 → 言志），句偶而气不偶 |
| 意象 | 上段多**天象与地理**：翼轸、衡庐、三江五湖、蛮荆瓯越——以星野与山川定位一座楼阁。中段转入**色彩与器物**：潦水寒潭、烟光暮山、层峦耸翠、飞阁流丹、青雀黄龙。色彩字密度极高，是骈文「藻饰」的典型 |
| 意境 | 由**盛**入**悲**再入**壮**：高朋满座之盛 → 「兴尽悲来，识盈虚之有数」之悲 → 「老当益壮」「穷且益坚」之壮。全篇的空间感是不断拉远的——由一阁之宴，拉到宇宙无穷、北辰南溟 |
| 情感 | 前半为酬应之盛，后半为**失路之慨**。「关山难越，谁悲失路之人？萍水相逢，尽是他乡之客」写漂泊；「冯唐易老，李广难封」写不遇；至「老当益壮，宁移白首之心？穷且益坚，不坠青云之志」转为自振。**年二十余而语极苍老**，是阅读此篇最耐咀嚼之处 |

## 结构与手法

```
一 地理   豫章故郡 → 星分翼轸 → 物华天宝，人杰地灵
二 宴会   都督阎公 → 高朋满座 → 家君作宰，躬逢胜饯
三 登览   时维九月 → 层峦耸翠，飞阁流丹
四 极景   披绣闼，俯雕甍 → 落霞与孤鹜齐飞，秋水共长天一色   ← 全文之眼
五 悲慨   遥襟甫畅 → 天高地迥 → 兴尽悲来，识盈虚之有数
六 伤怀   望长安于日下 → 关山难越 → 怀帝阍而不见
七 自振   嗟乎！时运不齐 → 冯唐易老，李广难封 → 老当益壮，穷且益坚
八 陈情   勃，三尺微命 → 有怀投笔，慕宗悫之长风
九 辞谢   胜地不常，盛筵难再 → 请洒潘江，各倾陆海   → 附《滕王阁诗》
```

| 手法 | 例证 | 效果 |
|------|------|------|
| 骈偶 | 通篇四六对句，几无散句 | 形式约束加到底——与本篇气象之阔形成张力 |
| 用典 | 「徐孺下陈蕃之榻」「冯唐易老，李广难封」「睢园绿竹」「邺水朱华」「终军之弱冠」「宗悫之长风」「钟期既遇」 | 密度远高于诗；以典代人、以典代事，省字而增厚（参见 [[用典-Allusion\|用典]]） |
| 点化 | 「落霞与孤鹜齐飞，秋水共长天一色」化北周·庾信《马射赋》「落花与芝盖同飞，杨柳共春旗一色」 | **句式全袭而意象全换**：由「落花/芝盖」的宫廷仪仗，换成「落霞/孤鹜」的天地景色——是「点化」的标准案例 |
| 由盛入悲 | 「四美具，二难并」之后紧接「兴尽悲来」 | 在最热闹处忽然转折，是全文的气脉开关 |
| 以对句推进叙事 | 地理用对、宴会用对、言志亦用对 | 骈文常见的毛病是对偶使文气板滞，此处以内容递进维持动力 |
| 卒章见诗 | 文末附《滕王阁诗》七言八句 | 序文说尽，以诗收束；「阁中帝子今何在？槛外长江空自流」把前文的盛筵一笔荡开 |

## 知人论世

[[王勃-Wang-Bo|王勃]]（650—676），字子安，绛州龙门人，**初唐四杰**之首。通行系年为上元二年（675）九月九日——王勃赴交趾（今越南北部）探望任交趾令的父亲王福畤，途经洪州，适逢都督阎伯屿重修滕王阁落成，大宴宾客，王勃即席作此序。次年（676）渡海溺水，惊悸而卒，年二十七。

**滕王阁的来历**：滕王即唐高祖李渊第二十二子李元婴，贞观十三年（639）封滕王，后都督洪州，建阁于州城，故名。

**一则须标注来源的传闻**：阎伯屿本意让其婿孟学士作序以扬名，先请众宾皆辞，王勃年少不辞，阎公不悦，遣人逐句来报，至「落霞与孤鹜齐飞，秋水共长天一色」乃叹服——此说出自**五代王定保《唐摭言》**，属笔记传闻而非史实记载，引用时应作「相传」。（同类的来源标注，本库 `离骚` 页「孔子删诗说」、《九辩》民歌说亦已如此处理。）

## 文本校勘

本篇异文甚多，且多为**避讳改字**与**传抄替换**两类，与本库既有的校勘线索（[[静夜思-Jing-Ye-Si|静夜思]]「看月光→明月光」、[[将进酒-Jiang-Jin-Jiu|将进酒]] 敦煌《惜罇空》、[[沁园春-雪-Qin-Yuan-Chun-Xue|沁园春·雪]]「原驱→原驰」）同属一类。

| 通行本 | 异文 | 说明 |
|--------|------|------|
| 豫章故郡 | 南昌故郡 | **避唐 代宗李豫讳**（代宗在位 762–779，已在王勃身后）。故「豫章」为原文，「南昌」是后世传本改字 |
| 层峦耸翠 | 层台耸翠 | 传抄替换，两说并存 |
| 舸舰弥津 | 舸舰迷津 | 「弥」「迷」音近而讹 |
| 遥襟甫畅 | 遥吟俯畅 | 传抄异文 |

另有「十旬休假／十旬休暇」等零散异文。**引用时应标注所据版本**，不宜径称「原文如此」。

## 影响

- **骈文史上的巅峰之作**，也是骈文最广为人知的篇目——多数读者经由本篇而非经由六朝骈文认识「骈文」这一文体。
- 「落霞与孤鹜齐飞，秋水共长天一色」成为汉语中最著名的对句之一，也是讨论「**点化 vs 袭用**」的必引案例（参见 [[骈文-Pianwen|骈文]]、[[用典-Allusion|用典]]）。
- 文中「老当益壮，宁移白首之心」「穷且益坚，不坠青云之志」「关山难越，谁悲失路之人」等句，其接受史已远超文学范围。
- **与 [[格律诗-Regulated-Verse|格律诗]] 对读**：所附《滕王阁诗》是七律定型前的样本，与 [[春望-Chun-Wang|春望]]、[[七律-长征-Qi-Lu-Chang-Zheng|七律·长征]] 并列，可见七言八句「从不定型到定型」的跨度。
- **与 [[念奴娇-赤壁怀古-Nian-Nu-Jiao|念奴娇·赤壁怀古]] 对读**：末联「阁中帝子今何在？槛外长江空自流」与「大江东去，浪淘尽，千古风流人物」是同一时空结构的两种写法——**以永恒的自然对消逝的人事**。
- [[杜甫-Du-Fu|杜甫]]《戏为六绝句》「王杨卢骆当时体……不废江河万古流」为四杰正名，是初唐新体接受史的关键文献。
