# 忆秦娥·娄山关 Yi Qin E · Lou Shan Guan

## 原文

> 西风烈，长空雁叫霜晨月。
> 霜晨月，马蹄声碎，喇叭声咽。
>
> 雄关漫道真如铁，而今迈步从头越。
> 从头越，苍山如海，残阳如血。

词，双调四十六字，上下片各五句、三仄韵一叠韵，忆秦娥调。现代·[[毛泽东-Mao-Zedong|毛泽东]] 作。

> **⚠️ 版权提示**：作者 1976-09-09 逝世，保护期至 **2026-12-31** 止，2027-01-01 起进入公有领域。全文暂录于此供内部研读，**保护期届满前不得纳入公开发布集**（见 [[毛泽东-Mao-Zedong|毛泽东]]）。

## 赏析四维

| 维度 | 赏析 |
|------|------|
| 语言 | 全篇以**短促硬冷的入声／仄韵**为底：「烈」「月」「咽」「铁」「越」「血」，无一柔字。两处叠句（「霜晨月」「从头越」）是词牌规定的**叠韵**，此处正好用作情绪的顿住与回旋。全词四十六字而三处用「声」——雁叫、蹄声、喇叭声，声音本身参与造境（参见 [[韵律-Prosody\|韵律]]） |
| 意象 | 西风、长空雁、霜、晨月、马蹄、喇叭、雄关、苍山、残阳——全为**冷色、硬质、听觉性**的军旅意象。上片无一物温暖，下片以「残阳如血」给出一片唯一的红，且红得惨烈 |
| 意境 | 上片是**行军**：寒寂、急促、断续（「声碎」「声咽」）。下片是**过关**：苍茫、壮阔。八字结句「苍山如海，残阳如血」以最阔的视觉，收束最紧的节奏——**以静写动之后，以阔收窄** |
| 情感 | 上片沉郁。下片由「雄关漫道真如铁，而今迈步从头越」翻起，是决绝的自我加压；结句却回落为悲壮的静观。**不是胜利的欢呼，而是重压下的决绝**——这是它与一般「凯歌」式作品的分野 |

## 结构与手法

```
上片  西风烈 → 雁叫霜晨月 → （叠）霜晨月 → 马蹄声碎，喇叭声咽
       （写景：霜晨急行军，三句一「声」，冷而促）
下片  雄关漫道真如铁 → 而今迈步从头越 → （叠）从头越 → 苍山如海，残阳如血
       （议论起，叠句顿住，以景收）
```

| 手法 | 例证 | 效果 |
|------|------|------|
| 叠句（词牌格） | 「霜晨月」叠、「从头越」叠 | 词牌硬性要求，此处恰成情绪的顿住与回旋——与 [[声声慢-Sheng-Sheng-Man\|声声慢]] 的「叠字造境」同一原理，一在字内，一在句间 |
| 通感与听觉 | 雁叫、声碎、声咽 | 不写行军之状而写行军之声，「碎」「咽」以**声音的质地**写人的心境 |
| 由景入议再入景 | 上片纯景 → 下片起于议论 → 结于景 | 议论只一句即止，让结尾的景自己承担分量，不加解释 |
| 色彩对照 | 上片霜月之白／下片残阳之红 | 一片冷白与一片血红的对撞，全词的视觉高潮在最后五字 |
| 一字领起 | 「烈」「碎」「咽」「铁」「海」「血」 | 每句末字皆重且硬，韵脚即力量点 |

## 知人论世

作于 1935 年 2 月，红军二渡赤水、再占娄山关之后。此役是遵义会议后的第一个大胜，故词中的「雄关」「从头越」有具体所指——「从头越」既是过关，也是遵义会议后路线重整的自况。

**题名与词牌**：「忆秦娥」调相传始于唐·[[李白-Li-Bai|李白]]《忆秦娥·箫声咽》（「箫声咽，秦娥梦断秦楼月」），调名即取自该词中的「秦娥」。故本词在形式上是一次**跨千年的接续**——同调、同为仄韵短章，而所写一为闺中相思（李白词的传统读法），一为霜晨行军。

**系年的一点不确定**：有研究者据手迹与回忆，认为此词或为后来追记而非当时即作，系年仍有讨论。同类的系年之疑，本库 [[将进酒-Jiang-Jin-Jiu|将进酒]]（752 或 744）、[[声声慢-Sheng-Sheng-Man|声声慢]]（早年或南渡后）亦有，属诗词考订的常态。

## 影响

- 结句「苍山如海，残阳如血」被推为现代旧体词中最雄阔的收束之一，也是「以景结情」的教科书式样本。
- 本库 [[词-Ci|词]] 一页中「现代词」与宋词并置的示例——与 [[念奴娇-赤壁怀古-Nian-Nu-Jiao|念奴娇·赤壁怀古]] 的「壮阔」、[[声声慢-Sheng-Sheng-Man|声声慢]] 的「绵密」构成三种抒情范式。
- 与 [[七律-长征-Qi-Lu-Chang-Zheng|七律·长征]] 同写长征，一为律诗（叙事总结），一为词（一役一景），可见同一题材在两体中的不同处理方式。
- 补 [[06-诗歌史]] 近现代行「新诗」之外的另一条线：旧体格律在 20 世纪的延续。
