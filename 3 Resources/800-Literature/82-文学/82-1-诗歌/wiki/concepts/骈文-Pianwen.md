# 骈文 Pianwen

## 定义

骈文是以**对偶句式**为主体的文体。「骈」为两马并驾，喻句句成对；因多以四字、六字相间成句，又称**四六文**。它与散体文（古文）相对，是中国古代最讲究形式的文体之一——**通篇对偶、句句用典、限以声律、辞采藻饰**。

## 要义

| 项 | 说明 |
|----|------|
| 骈偶 | 通篇对仗，字数自二至八皆可，通行以四六相间。所谓「骈四俪六」 |
| 用典 | **密度远高于诗**，几乎句句有典，事典与语典并用（参见 [[用典-Allusion\|用典]]） |
| 声律 | 讲究平仄相对，与近体诗同步律化（参见 [[平仄-Pingze\|平仄]]、[[韵律-Prosody\|韵律]]） |
| 藻饰 | 辞采华美，色彩字、金玉字、天象字密集，是「以丽为工」的极致 |
| 体裁 | 多用于序、书、启、表、檄、赋、碑志，六朝与唐代前期尤盛 |
| 源流 | 汉赋为源（[[骚体-Sao-Style\|骚体]] → 汉赋 → 骈赋 → 骈文）；六朝有徐陵、庾信，唐代有王勃、骆宾王 |
| 骈散之争 | 中唐韩愈、柳宗元起**古文运动**，以散体相抗，遂成长达千年的骈散之争；骈文此后再未独占文坛 |

## 骈文与诗的关系

骈文是**把诗法移植到散文**的极端形态：对偶、声律、用典、藻饰——四者本是诗的手段，骈文把它们用到了散文上。因此它是「诗」与「文」之间的**边界地带**，也正是本库收录《[[滕王阁序-Teng-Wang-Ge-Xu|滕王阁序]]》的理由——它与 [[骚体-Sao-Style|骚体]]、[[将进酒-Jiang-Jin-Jiu|将进酒]] 同属「体裁越界」这一类现象：**形式约束加到底，内容反而被逼出气象**。

同时，骈文也是讨论 「**点化**」的最佳场地：名句常出自化用前人现成句式（如王勃「落霞与孤鹜齐飞，秋水共长天一色」之于庾信《马射赋》），是袭用还是青出于蓝，历来聚讼。
