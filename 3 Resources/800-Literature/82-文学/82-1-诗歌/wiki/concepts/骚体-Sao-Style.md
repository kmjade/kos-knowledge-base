# 骚体 Sao Style

## 定义

骚体（楚辞体）是以《离骚》得名的诗歌体式，特征是**打破《诗经》的四言定格，以六言／七言为主的长短句**，并大量使用「兮」字作为节奏标记。汉以后凡仿此体者称「拟骚」，亦为汉赋（骚体赋）之源，其下游再衍为骈赋与 [[骈文-Pianwen|骈文]]。

## 要义

| 项 | 说明 |
|----|------|
| 兮字两式 | 句腰（《离骚》「帝高阳之苗裔**兮**，朕皇考曰伯庸」）与句尾（《九歌》「袅袅**兮**秋风，洞庭波**兮**木叶下」），承担不同的停顿切分功能 |
| 篇幅 | 由短章转向长篇，单篇可逾两千字，得以容纳叙事与抒情的复合结构 |
| 乐与诵 | 《汉书·艺文志》「不歌而诵谓之赋」；楚辞是否入乐，学界有争 |
| 与格律的关系 | 骚体是汉语诗歌**第一次形式解放**；后世近体诗的格律化（[[格律诗-Regulated-Verse|格律诗]]）是另一方向的收紧，二者构成钟摆 |
