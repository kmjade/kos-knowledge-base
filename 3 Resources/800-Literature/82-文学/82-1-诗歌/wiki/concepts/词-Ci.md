# 词 Ci

## 定义

词是**依乐调填制的诗歌体裁**，唐五代兴起、宋代极盛。每首词须按某一**词牌**的规定填写：词牌给出字数、句数、句式长短、平仄与韵位，填词即「倚声」。因此词又称「曲子词」「长短句」「诗余」。早期词可入乐歌唱，南宋以后渐与音乐脱钩，成为纯书面文学体裁。

## 要义

| 项 | 说明 |
|----|------|
| 词牌 | **不是题目，而是乐调谱式**。同调作品字数、句式、平仄、韵位一致；作者另加题目或小序以明本意（如「念奴娇·赤壁怀古」，词牌「念奴娇」+ 题「赤壁怀古」） |
| 分片 | 多数分上下两片（又称上下阕）；单片者为小令，多片者罕见 |
| 字数分层 | 通行分法：小令 58 字以内／中调 59–90 字／长调 91 字以上。此系后人约成，非宋人本意 |
| 韵位 | 韵随乐句而设，**较诗为密**，且可中途换韵——与 [[格律诗-Regulated-Verse\|格律诗]]「一韵到底」正相反 |
| 平仄 | 依词谱而定，总体较律诗为宽；但亦有严守者，故词有「格律谨严程度」之争 |
| 句式 | 长短句错落，一字至十一字句皆有，形成与五七言诗完全不同的节奏单位 |
| 风格两派 | **豪放**（苏轼、辛弃疾）与**婉约**（柳永、李清照）。李清照《词论》主张词「别是一家」，反对以诗法为词；苏轼则「以诗为词」破此界，辛弃疾更「以文为词」 |

| 忆秦娥 | 双调四十六字 | [[忆秦娥-娄山关-Yi-Qin-E-Lou-Shan-Guan\|忆秦娥·娄山关]]（毛泽东） |
| 满江红 | 双调九十三字 | [[满江红-怒发冲冠-Man-Jiang-Hong\|满江红·怒发冲冠]]（岳飞） |

**词牌与声情**：同一词牌的惯用韵部会影响声情。《满江红》正体押**入声仄韵**——入声短促硬冷，天然宜抒豪壮悲愤，与「怒发冲冠」互为表里；姜夔则改作**平韵**以求谐律，其〈满江红·仙姥来时〉序称旧调仄韵「多不协律」，歌者须把字「融入去声方谐音律」，是词史上少见的「为合乐而换韵部」的记录。故**选词牌即是选声情**，填词非仅按字填格。

## 词与诗的关系

词出于诗而自成一格。宋代是「诗庄词媚」的分工期，词长期被视为「艳科」「小道」；苏轼以诗为词、辛弃疾以文为词，词的题材与气象被拉宽，遂有豪放一派与言志传统在词体中的接续。这一「破界」过程，与本库 [[骚体-Sao-Style|骚体]] 之于四言诗、[[将进酒-Jiang-Jin-Jiu|将进酒]] 之于近体格律，是同一类型的**体裁越界**现象。
