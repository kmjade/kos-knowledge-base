# 82-3 小说 Fiction

> 小说（Fiction/Novel，UDC 82-3）是以叙事为核心、通过人物、情节与环境塑造虚构世界的散文体文学体裁，涵盖叙事学、技巧、人物视角、流派、小说史、创作、赏析与类型。本知识库是 800-Literature 下的**小说大类总览**。数据更新至 2026-09。
