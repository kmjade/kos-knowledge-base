# 04 人物与视角

## 人物类型（福斯特）

| 类型 | 说明 |
|------|------|
| 扁平人物 | 性格单一、标签化 |
| 圆形人物 | 性格复杂、立体多面 |

## 人物塑造手法

| 手法 | 说明 |
|------|------|
| 直接塑造 | 直接交代性格 |
| 间接塑造 | 通过言行、心理、他人评价展现 |
| 人物弧光 | 性格在情节中的成长转变 |

## 叙事视角

| 视角 | 代表 | 特点 |
|------|------|------|
| 第一人称 | 《麦田里的守望者》 | 主观、亲切 |
| 第三人称全知 | 《战争与和平》 | 全景、史诗 |
| 意识流 | 《尤利西斯》 | 内心独白、自由联想 |
