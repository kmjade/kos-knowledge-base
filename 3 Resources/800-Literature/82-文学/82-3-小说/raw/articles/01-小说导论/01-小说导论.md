# 01 小说导论

## 什么是小说

小说是以**叙事为核心**的散文体文学体裁，通过虚构的人物、情节与环境塑造一个完整的想象世界，是最具包容性与自由度的文学样式。

## 小说三要素

| 要素 | 说明 |
|------|------|
| 人物（Character） | 行动的主体 |
| 情节（Plot） | 事件的因果编排 |
| 环境（Setting） | 时间、地点与社会背景 |

## 主要分类

| 维度 | 类型 |
|------|------|
| 按篇幅 | 长篇、中篇、短篇、微型小说 |
| 按内容 | 现实、历史、科幻、推理、言情、奇幻 |
| 按叙事 | 第一/第三人称、意识流、书信体 |

## 历史脉络

| 时期 | 特点 |
|------|------|
| 古代 | 神话、史诗、传奇（故事雏形） |
| 文艺复兴 | 《堂吉诃德》现代小说萌芽 |
| 18–19 世纪 | 现实主义成熟 |
| 20 世纪 | 现代主义、意识流、后现代 |
| 当代 | 类型小说、网络文学、跨媒介 |
