# 09 小说类型

## 主要类型

| 类型 | 特征 | 代表 |
|------|------|------|
| 科幻小说 | 科技想象、未来 | 凡尔纳、阿西莫夫、克拉克、赫伯特、刘慈欣、田中芳树、卡德 |
| 推理小说 | 谜题、解谜、侦探 | 柯南·道尔、阿加莎·克里斯蒂 |
| 言情小说 | 爱情、情感关系 | 简·奥斯汀、亦舒 |
| 奇幻小说 | 魔法、异世界 | 托尔金、《哈利·波特》 |
| 历史小说 | 历史背景、虚实结合 | 罗贯中、司各特、二月河 |
| 悬疑/惊悚 | 悬念、紧张、恐惧 | 斯蒂芬·金 |
| 都市/商战 | 现实题材、商业与人性的思辨 | 豆豆 |

## 类型 vs 文学

| 维度 | 类型小说 | 纯文学 |
|------|----------|--------|
| 侧重 | 情节、可读性 | 语言、思想、人物 |
| 结构 | 程式化 | 实验性 |
| 读者 | 大众 | 精英/小众 |

## 科幻子类型

| 子类型 | 说明 |
|--------|------|
| 硬科幻 | 强调科学严格性 |
| 软科幻 | 重科技的社会后果 |
| 赛博朋克 | 高科技低生活 |
| 太空歌剧 | 星际文明、宏大战争与英雄史诗 |
