# 奥森·斯科特·卡德作品集

> [!info] 定位

## 概览

奥森·斯科特·卡德（Orson Scott Card，1951-08-24 生于华盛顿州里奇兰，在犹他州长大），美国科幻作家、评论家，毕业于杨百翰大学与犹他大学，现居北卡罗来纳州。卡德坚信小说具有教化意义，认为应当向读者传递积极上进的信息，「安德」系列即其观念的集中体现。

其成名作《安德的游戏》（1985）几乎同时包揽 **1986 年雨果奖与星云奖**最佳长篇；翌年续作《死者代言人》再获 **1987 年雨果奖与星云奖**——卡德由此成为首位连续两年同获双奖的作家。

- **安德主线（Ender's Saga）**：安德的游戏 → 死者代言人 → 外星屠异 → 精神之子

## 评价与影响

- 首位连续两年（1986、1987）同获雨果奖与星云奖最佳长篇的作家。
- 《安德的游戏》长期位列英文科幻经典与青少年必读书目，多次改编为漫画、有声剧与 2013 年同名电影。
- 争议：卡德在同性婚姻等社会议题上的公开立场，长期引发读者与业界对其人身与其作品的分离讨论。
