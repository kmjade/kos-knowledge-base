# 燕垒生作品集

> [!info] 定位
> 本页是 800-Literature 下「82-3 小说 · 武侠玄幻」专题页，收录燕垒生《天行健》的谱系与思想脉络。数据更新至 2026-10。

## 概览

燕垒生，中国网络作家，以**《天行健》**知名。该书是早期网络文学中「**新派武侠／军事玄幻**」的重要作品，以**战争**为核心，写帝国军、共和军与**蛇人**入侵的乱世，兼有权谋、宫斗与个人抉择。

书名取自《周易·乾卦》——**「天行健，君子以自强不息」**。

## 评价与影响

- 被视为**早期网络文学中「军事＋玄幻」融合**的代表作之一，以战争场面与权谋铺陈见长。
- 书名与主题承《周易》「自强不息」的古典理想主义，与网文「主角成长史」的爽感并置。
- 影响后世军事玄幻／权谋流派；「天地人」系列续作在读者中长受关注。
