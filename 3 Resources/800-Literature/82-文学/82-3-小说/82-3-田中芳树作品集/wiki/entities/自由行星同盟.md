# 自由行星同盟

> **实体（组织）** — 《银河英雄传说》三大势力之一，共和民主制国家，宇宙历 527 年建国，宇宙历 800 年灭亡。

## 基本资料

| 属性 | 值 |
|------|-----|
| 性质 | 共和民主制（议会 + 国防委员会） |
| 首都 | 海尼森 |
| 建国 | 帝国历 218 年（= 宇宙历 527），由亚雷·海尼森领导 |
| 灭亡 | 新帝国历 2 年（800）2 月 20 日「冬蔷薇园敕令」 |
| 象征 | 伊谢尔伦要塞 · 杨舰队 |
| 代表 | 杨威利、比克古、特留尼西特 |

## 概述

由「长征一万光年」的流亡者建立，以自由平等为立国理想。然而后期政治腐败、政客操弄军部与媒体，先后爆发「救国军事委员会」政变、国家广场大屠杀等内耗。宇宙历 799 年被迫与帝国签订巴拉特和约，800 年正式灭亡。其民主理念由伊谢尔伦共和政府延续。

## 制度与机构

- **统合作战本部 · 国防委员会**；伊谢尔伦要塞司令部。
- **特务机构**：审查会（曾非法传讯杨威利）。
- **流亡政权**：银河帝国正统政府（瑞姆夏德为首，拥幼帝艾尔威·由谢夫二世）。
