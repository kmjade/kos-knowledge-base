# 费沙自治领

> **实体（组织）** — 帝国与同盟之间的商业都市国家，「第三势力」，控扼费沙回廊的战略要冲。

## 基本资料

| 属性 | 值 |
|------|-----|
| 性质 | 商业自治领（名义自治，实受地球教支配） |
| 位置 | 费沙行星 · 费沙回廊 |
| 建立 | 帝国历 373 年（= 宇宙历 682），雷欧波特·拉普 |
| 结局 | 宇宙历 798 年被莱因哈特占领，800 年成为帝国新都 |
| 代表 | 鲁宾斯基（「黑狐」）、博尔德克、盖塞林格 |

## 概述

凭借唯一可通行的费沙回廊与两大国通商，费沙以中立商业国自居，暗中却由地球教操纵，靠情报与操纵维持三国均势。宇宙历 798 年 12 月，米达麦亚奇袭占领费沙，鲁宾斯基失踪，盖塞林格被射杀；次年莱因哈特迁都于此，费沙由「第三极」变为帝国中枢。
