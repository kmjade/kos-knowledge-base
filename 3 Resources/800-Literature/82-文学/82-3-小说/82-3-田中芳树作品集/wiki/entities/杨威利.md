# 杨威利

> **实体（人物）** — 《银河英雄传说》双主角之一，自由行星同盟提督，无心从军却百战不败的「魔术师杨」。

## 角色定位

黑发、懒散，本欲成为历史学者却因家境所迫从军。厌恶战争与军队，却在战术上近乎无敌——以少数兵力屡破帝国大军。其思想核心是对民主制度的捍卫与对「国家至上」的警惕：国家是工具，个人的自由与权利高于国家的兴亡。
