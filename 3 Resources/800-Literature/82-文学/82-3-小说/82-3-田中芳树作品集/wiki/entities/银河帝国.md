# 银河帝国

> **实体（组织）** — 《银河英雄传说》三大势力之一，专制君主制国家，历经高登巴姆王朝与罗严克拉姆王朝。

## 基本资料

| 属性 | 值 |
|------|-----|
| 性质 | 专制君主制 · 军事贵族制 |
| 首都 | 奥丁（旧都）→ 费沙（新都，宇宙历 800 迁都） |
| 前身 | 银河联邦（宇宙历 310 被鲁道夫篡夺） |
| 王朝 | 高登巴姆王朝 → 罗严克拉姆王朝 |
| 代表 | 鲁道夫一世、佛瑞德李希四世、莱因哈特 |

## 概述

宇宙历 310 年，鲁道夫·冯·高登巴姆推翻银河联邦自立为帝，建立银河帝国，历五世纪。其后期腐朽僵化，靠「恶劣遗传因子排除法」「社会秩序维护局」等高压统治维系。宇宙历 797 年，莱因哈特推翻旧贵族与旧王朝，推行改革、解放农奴，宇宙历 799 年登基建立罗严克拉姆王朝，完成统一。

## 制度与机构

- **军部**：帝国统帅本部 · 宇宙舰队 · 军务省（尚书）。
- **特务**：社会秩序维护局 → 国内安全保障局。
- **贵族制**：旧门阀贵族（利普休达特贵族联合军）。
- **勋章与称谓**：「帝国双璧」「狮子之泉七元帅」「黄金狮子旗」。
