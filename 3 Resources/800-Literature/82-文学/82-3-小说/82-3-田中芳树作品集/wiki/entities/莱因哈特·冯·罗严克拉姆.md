# 莱因哈特·冯·罗严克拉姆

> **实体（人物）** — 《银河英雄传说》双主角之一，罗严克拉姆王朝始祖，以「我的征途是星之大海」自况的黄金狮子。

## 角色定位

金发碧眼的美少年，军事与政治双料天才。为夺回被高登巴姆王朝夺走的姐姐安妮罗杰而从军，凭借连战连捷的军功一路崛起，推翻旧帝国、统一宇宙。他冷酷果决又带有少年的纯粹，视战场为自我实现的舞台，被杨威利形容为「燃烧别人，也燃烧自己」的火焰般的美感。
