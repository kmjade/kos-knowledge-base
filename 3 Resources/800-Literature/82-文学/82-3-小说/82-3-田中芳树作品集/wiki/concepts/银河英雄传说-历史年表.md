# 《银河英雄传说》历史年表

> **概念（年表）** — 全书以四重纪年（西历／宇宙历／帝国历／新帝国历）构建的历史骨架，来源为附录《银河英雄传说》历史年表。

## 纪年体系

| 纪年 | 说明 |
|------|------|
| 西历 | 公元纪元（前史） |
| 宇宙历 | 银河联邦成立（西历 2801）改元宇宙历元年 |
| 帝国历 | 鲁道夫篡权（宇宙历 310）改元帝国历元年 |
| 新帝国历 | 莱因哈特登基（宇宙历 799）改元新帝国历元年 |

## 前史（西历）

- 2129 地球统一政府成立（首都布里斯本）
- 2360 超光速航行实现
- 2690 拉古朗市屠城事件；2704 黑旗军（BFF）灭地球统一政府
- 2801 银河联邦成立（= 宇宙历元年，首都德奥里亚）

## 银河帝国期（帝国历）

- 宇宙历 268 鲁道夫·冯·高登巴姆诞生
- 宇宙历 310 = **帝国历元年** 鲁道夫篡权，银河帝国成立
- 帝国历 9（318）恶劣遗传因子排除法、社会秩序维护局成立；帝国历 42（351）鲁道夫去世
- 帝国历 164（473）亚雷·海尼森「长征一万光年」
- 帝国历 218（527）自由行星同盟成立（首都海尼森）
- 帝国历 331（640）达贡歼灭战（林帕欧、尤斯夫·托波洛）
- 帝国历 373（682）费沙自治领成立（雷欧波特·拉普）
- 帝国历 436（745）第二次迪亚马特会战（布鲁斯·阿修比战死）
- 帝国历 454–458（763–767）伊谢尔伦要塞建成；杨威利诞生
- 帝国历 467（776）吉尔菲艾斯、莱因哈特诞生
- 帝国历 477（786）吉尔菲艾斯初会莱因哈特；安妮罗杰成为皇帝宠妃
- 帝国历 486（795）第三次迪亚马特会战
- 帝国历 487（796）亚斯提会战、卡斯特普动乱
- 帝国历 488（797）利普休达特战役（贵族联合军覆灭，吉尔菲艾斯护主而死）
- 帝国历 489（798）第八次伊谢尔伦攻略战（坎普阵亡）
- 帝国历 490（799）兰提马里欧、巴米利恩会战

## 新帝国历（宇宙历 799 起）

- **新帝国历元年（799）** 莱因哈特登基，罗严克拉姆王朝成立；巴拉特和约；杨威利、比克古退役
- **新帝国历 2 年（800）** 杨威利遭地球教徒暗杀；罗严塔尔叛乱（第二次兰提马里欧会战）并身亡；伊谢尔伦共和政府成立
- **新帝国历 3 年（801）** 莱因哈特迎娶希尔德；皇子诞生；冬馆大火；希瓦星域会战；莱因哈特与尤里安讲和；六名一级上将晋升元帅；莱因哈特病逝，希尔德摄政；德·维利被击杀；伊谢尔伦撤离要塞
