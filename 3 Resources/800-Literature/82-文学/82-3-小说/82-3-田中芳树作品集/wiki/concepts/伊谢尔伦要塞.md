# 伊谢尔伦要塞

> **概念（战略要冲）** — 扼守伊谢尔伦回廊的巨型要塞，全书最重要的军事舞台，帝国与同盟反复争夺。

## 概述

伊谢尔伦要塞位于连接帝国与同盟的唯一航道「伊谢尔伦回廊」上，配备主炮「雷神之锤」（输出约 924 兆瓦），易守难攻。谁控制伊谢尔伦，谁就掌握了两国攻守的咽喉。

## 关键特征

| 特征 | 说明 |
|------|------|
| 主炮 | 「雷神之锤」，一击可歼灭舰队 |
| 防御 | 「女神的项链」等外围攻击卫星 |
| 代表战例 | 杨威利多次攻略与死守；秃鹰之城要塞对要塞 |

## 在作品中的角色

- 杨威利以伊谢尔伦为据点，多次以少胜多。
- 帝国以移动要塞「秃鹰之城」（主炮「秃鹰之喙」）发起要塞对要塞战，失败。
- 杨死后，伊谢尔伦成为「伊谢尔伦共和政府」的根据地，最终撤离。
