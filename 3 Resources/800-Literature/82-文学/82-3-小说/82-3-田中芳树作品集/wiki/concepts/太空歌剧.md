# 太空歌剧 Space Opera

> **概念** — 以星际为舞台、聚焦宏大战争与英雄传奇的科幻类型，《银河英雄传说》是其在日本最具代表性的作品。

## 定义

太空歌剧指以宇宙航行、星际帝国、大规模舰队会战为核心，情节偏向浪漫化史诗与英雄叙事的科幻子类型。相较「硬科幻」对科学设定的严格推演，太空歌剧更看重戏剧性、政治博弈与人物命运的宏大铺陈。

## 关键特征

| 特征 | 说明 |
|------|------|
| 舞台 | 银河尺度，多星系、多势力 |
| 冲突 | 帝国 vs 共和、会战与谋略 |
| 人物 | 天才统帅、英雄群像 |
| 基调 | 史诗化、浪漫化，兼具悲剧性 |
| 科学 | 设定服务于叙事（亚空间跳跃、要塞炮等） |

## 在《银河英雄传说》中的体现

- 银河帝国与自由行星同盟的百年战争，构成史诗骨架。
- 双主角莱因哈特与杨威利的对峙，是「天才对决」的典范。
- 以「历史叙事」的口吻（史料、年表、后记）营造真实感。

## 与其他概念的关系

- 与 [[架空历史小说]] 交叉：以虚构历史映射现实政治。
- 与硬科幻相对：重人物与政治，轻技术推演。
