# 架空历史小说 Alternate History

> **概念** — 在虚构的历史框架中展开政治与战争叙事的小说类型，田中芳树被视为其代表人物之一。

## 定义

架空历史小说以不存在的国家、王朝与年表为背景，模仿真实历史的叙事方式（纪年、战役、人物传记、史料引述），借此探讨权力、制度与人性的普遍命题。它与「历史小说」的区别在于：世界是虚构的，但历史的逻辑与质感被刻意写实。

## 关键特征

| 特征 | 说明 |
|------|------|
| 虚构世界 | 西川大陆式的架空大陆 / 银河帝国式的星际政治 |
| 拟真史料 | 年表、传记、后记、史书口吻 |
| 政治内核 | 制度之争、权谋、兴亡周期律 |
| 史诗结构 | 多卷、多势力、长时段 |

## 代表与延伸

- 田中芳树《银河英雄传说》：以四重纪年体系（西历／宇宙历／帝国历／新帝国历）营造历史纵深。
- 中国网络文学《紫川》（老猪）被广泛认为「最具《银河英雄传说》气质」，曾获「银河英雄传说纪念奖」。参见 [[0 Inbox/1-input/clippings/紫川|紫川（剪藏）]]。
