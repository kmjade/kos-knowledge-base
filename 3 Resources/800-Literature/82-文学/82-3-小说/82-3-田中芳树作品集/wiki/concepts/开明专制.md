# 开明专制 Enlightened Despotism

> **概念** — 《银河英雄传说》的核心政治命题之一：贤明的独裁者能否替代低效的民主？莱因哈特的罗严克拉姆王朝是其文学化样本。

## 定义

开明专制指由具备才能与德性的君主独揽大权、推行改革与善政的统治形态。它承认专制的高效，但寄希望于统治者的贤明，因而内含「人存政举、人亡政息」的根本脆弱性——莱因哈特年仅 25 岁病逝，正是这一命题的注脚。

## 关键张力

| 面向 | 表现 |
|------|------|
| 效率 | 改革迅速、政令直达、根除腐败 |
| 正当性 | 权力源自实力而非民意 |
| 脆弱性 | 依存于君主个人，继承即成难题 |
| 道德风险 | 无人约束，可善亦可暴 |

## 在作品中的呈现

- 莱因哈特推翻腐朽旧王朝、解放农奴、肃清腐败，展现专制的「效率之美」。
- 与之对照的是同盟民主的腐败与低效（特留尼西特政权）。
- 杨威利一面敬佩莱因哈特，一面坚持民主制度的长期价值，指出「民主是枪口下产生的」。
