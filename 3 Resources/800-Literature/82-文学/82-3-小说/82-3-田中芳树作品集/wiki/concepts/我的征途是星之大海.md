# 我的征途是星之大海

> **概念（名句／主题）** — 莱因哈特的宣言，日本科幻流行文化的标志性句子，凝缩了《银河英雄传说》的野心与浪漫。

## 出处

出自由莱因哈特为主角的外传《击碎星辰的人》末章标题（「我的征途是星之大海」）。少年莱因哈特以此表达对星辰大海的征服欲与自我期许，成为其一生志向的写照。

## 意涵

| 层面 | 解读 |
|------|------|
| 个人 | 少年野心与自我超越的浪漫 |
| 主题 | 「征途」即无尽的欲望与代价 |
| 文化 | 成为日本 SF／动画流行文化名句 |
