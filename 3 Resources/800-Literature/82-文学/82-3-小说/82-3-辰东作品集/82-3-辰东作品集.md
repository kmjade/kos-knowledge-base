# 辰东作品集

> [!info] 定位
> 本页是 800-Literature 下「82-3 小说 · 玄幻」专题页，收录辰东《神墓》的谱系与思想脉络。数据更新至 2026-10。

## 概览

辰东，中国网络**玄幻**小说代表作家之一，起点中文网签约作家，以《神墓》成名，后著《遮天》《完美世界》《圣墟》等，被视为「网文黄金一代」的代表。其作以**宏大的世界体系、远古神话设定与热血成长**见长。

## 评价与影响

- 辰东《神墓》被视为**2000 年代中后期玄幻网文的里程碑作品**之一，奠定其在网文圈的地位。
- 「**神墓**」式的**远古神话＋悬念**设定，影响了后续大批玄幻作品。
