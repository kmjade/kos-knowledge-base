# 罗贯中作品集

> [!info] 定位
> 本页是 800-Literature 下「82-3 小说 · 中国古典」专题页，收录罗贯中作品的整体谱系与思想脉络。数据更新至 2026-10。

## 概览

罗贯中（约 1330 – 约 1400），元末明初小说家、戏曲家，名本，字贯中，号湖海散人，太原（一说东原/杭州）人。相传曾师从施耐庵，是中国**章回体小说**的开创者之一。

其代表作**《三国演义》**（全称《三国志通俗演义》）是中国**第一部长篇章回体历史演义小说**，以东汉末年群雄割据到西晋统一的历史为骨，融民间传说、话本与史实于一体，塑造了曹操、刘备、诸葛亮、关羽等深入民族记忆的人物群像。它与《水浒传》《西游记》《红楼梦》并称**四大名著**。

## 文本结构

- **120 回**，每回两句话目（如「第一回 宴桃园豪杰三结义 斩黄巾英雄首立功」）。
- 开篇《临江仙》——「滚滚长江东逝水，浪花淘尽英雄」——即全书史观的定调：**「天下大势，分久必合，合久必分」**。
- 叙事主线：汉末乱世 → 群雄逐鹿（官渡/赤壁）→ 三足鼎立 → 蜀汉衰亡 → 魏晋代兴 → 三分归一。

## 评价与影响

- 被誉「中国章回小说开山之作」，明末清初毛宗岗父子的评改本成为通行本。
- 对东亚（日本、朝鲜）历史演义小说与后世戏曲、说书、影视、游戏（如《真·三国无双》系列）影响极深。
- 「少不读水浒，老不读三国」等俗谚，折射其谋略与世故的阅读文化；「桃园结义」「三顾茅庐」「草船借箭」等已成汉语成语与典故。

> [!question] 待探索
> 「尊刘抑曹」的正统观与《三国志》史实记载的差异；演义体「历史真实 vs 文学真实」的边界；三国故事在东亚的跨文化接受与再创作。
