# 弗兰克·赫伯特作品集

## 概览

弗兰克·赫伯特（Frank Herbert，1920–1986），美国科幻小说家，生于华盛顿州塔科马（Tacoma），毕业于华盛顿大学。其最重要作品为**《沙丘》系列**。1965 年出版的《沙丘》（*Dune*）几乎同时获得 **1966 年雨果奖与星云奖**最佳长篇，被视为科幻史上最伟大的长篇之一，也是「生态科幻」与「软科幻史诗」的巅峰。

赫伯特以**沙漠生态学**为骨、**宗教与政治权力**为魂，在《沙丘》中构建了厄拉科斯（Arrakis）这颗干旱行星的完整生态—经济—宗教系统，并由此追问救世主神话、预言与自由意志的悖论。

## 世界观与设定

| 设定 | 说明 |
|------|------|
| 厄拉科斯（沙丘） | 唯一出产「香料」的荒漠行星，生态与经济的枢纽 |
| 香料（melange / spice） | 延寿、预知与星际航行所必需，权力争夺的核心 |
| 沙虫（Shai-Hulud） | 沙漠巨兽，香料循环的关键环节，被弗雷曼人神化 |
| 弗雷曼人（Fremen） | 适应沙漠的原住民，围绕其形成宗教与政治运动 |
| 各大家族与公会 | 亚崔迪、哈肯尼、宇航公会、贝尼·杰瑟里特——权力博弈的棋盘 |

## 评价与影响

- 《沙丘》为**首部同时获雨果奖与星云奖**的最佳长篇之一，长期位居「史上最佳科幻」榜单前列。
- 深刻影响后世生态科幻、太空歌剧与「世界建构」（world-building）范式；对《星球大战》《权力的游戏》等均有可辨识影响。
- 多次影视化：大卫·林奇 1984 版、2021／2024 年丹尼斯·维伦纽瓦新版（获多项奥斯卡奖），使原著的生态与政治母题再度进入公众视野。

> [!question] 待探索
> 赫伯特的「生态—宗教—权力」三角与阿西莫夫「心理史学」的历史观对照；《沙丘》影视改编对原著预知与神话复杂性的取舍；「香料／石油」的资源政治隐喻。
