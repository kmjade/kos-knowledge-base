# 07 表演与导演

## 世界三大表演体系

| 体系 | 代表人物 | 核心 |
|------|----------|------|
| 体验派 | 斯坦尼斯拉夫斯基 | 演员真实体验角色、当众孤独 |
| 表现派/间离 | 布莱希特 | 与角色保持距离、理性批判 |
| 戏曲程式 | 梅兰芳 | 唱念做打、程式化虚拟表演 |

## 斯坦尼体系要点

| 概念 | 说明 |
|------|------|
| 规定情境 | 角色所处的具体情境 |
| 情绪记忆 | 调动演员自身经验 |
| 当众孤独 | 沉浸角色、无视观众 |
| 最高任务 | 贯穿角色的核心目标 |

## 导演艺术

| 要素 | 说明 |
|------|------|
| 场面调度（Mise-en-scène） | 演员走位与舞台构图 |
| 节奏 | 演出速度与张弛 |
| 阐释 | 对剧本的主题诠释 |

## 演员训练

| 方向 | 内容 |
|------|------|
| 台词 | 发声、吐字、情感表达 |
| 形体 | 身段、动作、舞蹈 |
| 即兴 | 快速反应与创造 |
