# 09 欣赏与实践

## 读剧与观剧

| 方法 | 说明 |
|------|------|
| 读剧本 | 关注结构、冲突、潜台词 |
| 观剧 | 关注表演、调度、舞美与现场感 |
| 写剧评 | 从主题、人物、舞台、技术四维分析 |

## 入门剧目推荐

| 门槛 | 推荐 |
|------|------|
| 最易读 | 老舍《茶馆》、易卜生《玩偶之家》 |
| 经典 | 莎士比亚《哈姆雷特》、索福克勒斯《俄狄浦斯王》 |
| 现代 | 贝克特《等待戈多》、布莱希特《大胆妈妈》 |
| 华语 | 曹禺《雷雨》、汤显祖《牡丹亭》 |

## 创作练习

| 练习 | 目标 |
|------|------|
| 独幕剧写作 | 掌握冲突与结构 |
| 潜台词改写 | 训练对话层次 |
| 即兴表演 | 训练行动与反应 |
| 读剧会 | 文本到台词的转化 |

## 戏剧评论四维

| 维度 | 关注点 |
|------|--------|
| 文本 | 主题、结构、人物、语言 |
| 表演 | 演员塑造、台词、形体 |
| 舞台 | 舞美、灯光、服装 |
| 导演 | 阐释、节奏、场面调度 |
