# 02 戏剧理论

## 亚里士多德《诗学》

| 概念 | 说明 |
|------|------|
| 模仿论（Mimesis） | 戏剧是对行动与生活的模仿 |
| 悲剧六要素 | 情节、人物、思想、语言、音乐、景象 |
| 卡塔西斯（Catharsis） | 通过怜悯与恐惧获得情感净化 |
| 情节优先 | 情节高于人物，悲剧模仿完整的行动 |

## 三一律

| 律 | 要求 |
|----|------|
| 行动一致 | 一条主要情节线 |
| 时间一致 | 故事发生于一天之内 |
| 地点一致 | 单一地点 |

> 三一律由 16–17 世纪新古典主义者（卡斯泰尔韦特罗等）归纳，强加于古希腊理论，法国古典主义奉为金科玉律。

## 悲剧与喜剧

| 类型 | 特点 |
|------|------|
| 悲剧 | 严肃、高贵者因缺陷/命运毁灭，引发怜悯与恐惧 |
| 喜剧 | 表现可笑之人与事，结局多圆满 |
| 正剧（Drama） | 18 世纪后兴起，介于二者之间 |

## 现代戏剧理论

| 理论 | 倡导者 | 核心 |
|------|--------|------|
| 史诗剧 | 布莱希特 | 间离效果、理性批判 |
| 体验派 | 斯坦尼斯拉夫斯基 | 真实体验、当众孤独 |
| 残酷戏剧 | 阿尔托 | 冲击感官、仪式化 |
| 质朴戏剧 | 格洛托夫斯基 | 摒弃舞美、以演员为本质 |
| 戏剧解构 | 后现代 | 反叙事、反意义中心 |
