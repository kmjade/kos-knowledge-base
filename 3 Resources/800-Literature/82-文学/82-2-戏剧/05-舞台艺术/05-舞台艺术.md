# 05 舞台艺术

## 舞台美术构成

| 部门 | 说明 |
|------|------|
| 布景（Set） | 空间环境与场景 |
| 灯光（Lighting） | 氛围、时间、情绪、焦点 |
| 服装（Costume） | 时代、身份、性格 |
| 化妆（Makeup） | 角色形象塑造 |
| 道具（Props） | 角色可持用/可移动物品 |
| 音响（Sound） | 音效与配乐 |

## 舞台类型

| 类型 | 特点 |
|------|------|
| 镜框式（Proscenium） | 观众单面观看，有台口 |
| 伸出式（Thrust） | 舞台伸入观众席三面 |
| 圆形/环形（Arena） | 观众四面环绕 |
| 黑箱（Black Box） | 可灵活配置的现代剧场 |

## 灯光设计要点

| 要素 | 说明 |
|------|------|
| 照明角度 | 正面/侧面/顶光/逆光 |
| 色彩 | 色片营造氛围与情绪 |
| 亮度/节奏 | 明暗对比与变化节奏 |
