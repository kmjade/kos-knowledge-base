# 01 戏剧导论

## 什么是戏剧

戏剧是以**演员表演**为核心的综合艺术——演员在舞台上扮演角色，通过**行动与对话**呈现故事与冲突，供观众在当下、同一时空内观看。戏剧的希腊词源 *drama* 意为「行动」，亚里士多德称之为「行动的模仿」（mimesis）。

## 戏剧六要素（亚里士多德）

| 要素 | 说明 |
|------|------|
| 情节（Plot） | 行动的编排，**最重要的要素** |
| 人物（Character） | 承载行动的角色 |
| 思想（Thought） | 主题与观念 |
| 语言（Diction） | 台词与措辞 |
| 音乐（Music） | 节奏与旋律成分 |
| 景象（Spectacle） | 视觉呈现（布景、服装） |

## 戏剧的构成三要素

| 要素 | 说明 |
|------|------|
| 剧本 | 文本基础（台词、舞台指示） |
| 演员 | 表演主体（角色的肉身呈现） |
| 观众 | 接受者，与演员共处同一时空 |

## 主要类型

| 类型 | 说明 |
|------|------|
| 话剧（Drama） | 以对白与行动为主 |
| 歌剧（Opera） | 以歌唱为主，音乐主导 |
| 舞剧（Ballet/Dance） | 以舞蹈为主 |
| 戏曲（Xiqu） | 中国唱念做打程式化传统戏剧 |
| 音乐剧（Musical） | 歌、舞、对白融合 |

## 历史脉络

| 时期 | 特点 |
|------|------|
| 古希腊 | 酒神祭祀 → 悲剧/喜剧定型 |
| 中世纪 | 宗教剧、道德剧 |
| 文艺复兴 | 莎士比亚、洛佩·德·维加 |
| 法国古典 | 三一律、莫里哀 |
| 19 世纪 | 现实主义、自然主义 |
| 20 世纪 | 象征/表现/荒诞/史诗/残酷戏剧 |
| 当代 | 后现代、沉浸式、数字剧场 |
