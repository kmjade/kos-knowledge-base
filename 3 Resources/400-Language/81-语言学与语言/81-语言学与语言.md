# 语言学与语言 · Linguistics & Language (UDC 81)

> [!info] UDC 81 — 语言学与语言
> （特别是历史的）语言学意义上的语文学作品入此；特定语言/语族的历史描述附加 `-112`（`81-112`）。

## 📖 概述

UDC `81` 是**语言学**主轴：研究语言本身（结构、历史、方法论），并与 `811`（具体语言）配合使用——`811.111:81` 表示「英语的语言学方面」。
