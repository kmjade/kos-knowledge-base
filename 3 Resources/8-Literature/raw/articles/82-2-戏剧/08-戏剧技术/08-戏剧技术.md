# 08 戏剧技术

## 舞台机械

| 设备 | 说明 |
|------|------|
| 吊杆（Fly System） | 悬挂布景、灯具 |
| 转台（Turntable） | 场景快速切换 |
| 升降台（Elevator） | 多层面舞台变化 |

## 灯光与音响

| 系统 | 说明 |
|------|------|
| 灯光控制台 | 编程控制灯具、色片、追光 |
| 音响系统 | 拾音、扩声、音效播放 |
| 投影/视频 | 多媒体背景、数字舞美 |

## 数字与沉浸式

| 方向 | 说明 |
|------|------|
| 沉浸式戏剧 | 打破舞台/观众界限（如《不眠之夜》） |
| VR/AR 剧场 | 虚拟场景与增强现实 |
| 全息投影 | 数字演员与虚拟舞美 |

## 剧院管理

| 环节 | 说明 |
|------|------|
| 制作 | 剧目立项、预算、排期 |
| 演出运营 | 票务、场务、宣传 |
| 舞台监督 | 演出统筹与提示（cues） |
