# 03 剧本创作

## 剧本结构

| 结构 | 说明 |
|------|------|
| 三幕结构 | 建置（setup）→ 冲突发展（confrontation）→ 解决（resolution） |
| 起承转合 | 中国古典叙事结构 |
| 冲突中心 | 所有情节围绕核心冲突展开 |

## 戏剧冲突

| 类型 | 说明 |
|------|------|
| 人与人 | 角色之间的意志对立（最常见） |
| 人与环境 | 角色与社会、自然的对抗 |
| 人与自我 | 角色内心的矛盾 |

## 人物塑造

| 手法 | 说明 |
|------|------|
| 欲望（Want）与需求（Need） | 表层目标 vs 深层动机 |
| 人物弧光 | 角色在剧情中的成长与转变 |
| 行动定义人物 | 「行动中的人」而非静态标签 |

## 对话与潜台词

| 概念 | 说明 |
|------|------|
| 潜台词 | 台词表层之下的真实意图 |
| 独白/旁白 | 揭示内心、向观众倾诉 |
| 停顿 | 沉默的戏剧张力 |

## 舞台指示

| 要素 | 说明 |
|------|------|
| 场景说明 | 时间、地点、环境 |
| 动作指示 | 角色的行为、走位 |
| 情绪提示 | 语气、表情 |
