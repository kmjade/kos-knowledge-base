# 05 意象与修辞

## 意象与意境

| 概念 | 说明 |
|------|------|
| 意象 | 情与景结合的最小单位（如「月」「柳」） |
| 意境 | 由意象群构成的整体艺术境界 |
| 典型意象 | 月＝思乡、柳＝惜别、雁＝传书、菊＝高洁 |

## 核心修辞

| 修辞 | 说明 | 例 |
|------|------|-----|
| 比喻 | 明喻/暗喻/借喻 | 「二月春风似剪刀」 |
| 象征 | 以具体暗示抽象 | 屈原「香草美人」 |
| 通感 | 感官互通 | 「红杏枝头春意闹」 |
| 用典 | 化用典故 | 辛弃疾「廉颇老矣」 |
| 拟人 | 赋予物以人性 | 「我寄愁心与明月」 |
| 夸张 | 夸大事物的特征 | 「白发三千丈」 |

## 赋比兴

| 手法 | 说明 |
|------|------|
| 赋 | 直陈其事 |
| 比 | 以此物比彼物（比喻） |
| 兴 | 先言他物以引起所咏之词 |
