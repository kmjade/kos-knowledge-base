# 06 诗歌史

## 中国诗歌史

| 时期 | 体裁 | 代表 | 要点 |
|------|------|------|------|
| 先秦 | 四言诗/楚辞（骚体） | [[诗经-Shi-Jing\|诗经]]、[[屈原-Qu-Yuan\|屈原]] | 诗歌源头；比兴传统（风）与象征体系（骚）两条源流 |
| 汉魏 | 乐府、五言 | 曹操、曹植、陶渊明 | 建安风骨、田园诗 |
| 初唐 | 七言渐律、骈文 | [[王勃-Wang-Bo\|王勃]]、杨炯、卢照邻、骆宾王 | 初唐四杰；律诗定型前夜 |
| 唐 | 近体诗 | 李白、杜甫、白居易 | 诗歌巅峰、律绝成熟 |
| 宋 | 词 | 苏轼、辛弃疾、李清照、[[岳飞-Yue-Fei\|岳飞]] | 豪放与婉约；南宋爱国词 |
| 元明清 | 散曲、诗 | 马致远、纳兰性德 | 延续与总结 |
| 近现代（新诗） | 新诗 | 徐志摩、北岛、海子 | 白话自由诗 |
| 近现代（旧体） | 词、律诗 | [[毛泽东-Mao-Zedong\|毛泽东]] | 旧体格律的现代延续 |

> **两条并行线**：20 世纪中国并非只有白话新诗一路。旧体诗词（词、律诗）始终有人在写，其中影响最大者为 [[毛泽东-Mao-Zedong\|毛泽东]]——用最严格的词谱与律句写现代题材（参见 [[词-Ci\|词]]）。本库名篇页中「近现代」一格即由此补齐。

## 先秦两源对照

| 维度 | 风（《诗经》） | 骚（《楚辞》） |
|------|---------------|---------------|
| 文化 | 中原礼乐 | 南方巫楚、神话系统 |
| 句式 | 四言、重章叠句 | 长短句、「兮」字（[[骚体-Sao-Style\|骚体]]） |
| 手法 | 赋比兴（[[比兴-Bixing\|比兴]]） | 香草美人象征（[[香草美人-Xiang-Cao-Mei-Ren\|香草美人]]） |
| 主体 | 集体、类型化抒情 | 个人、自传性、主体高扬 |
| 下游 | 乐府 → 建安 → 杜甫 | 汉赋 → 李白 → 李贺 |
