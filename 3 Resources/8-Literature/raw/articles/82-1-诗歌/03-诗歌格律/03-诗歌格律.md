# 03 诗歌格律

## 汉语格律（近体诗）

| 概念 | 说明 |
|------|------|
| 平仄 | 平声 vs 仄声（上/去/入）的交替 |
| 押韵 | 韵脚在偶句，依平水韵 |
| 对仗 | 颔联、颈联须对仗 |
| 律诗 | 八句，五言/七言 |
| 绝句 | 四句，五言/七言 |

## 词与曲格律

| 概念 | 说明 |
|------|------|
| 词牌 | 定格式、定平仄、定韵脚 |
| 阙 | 上阙/下阙（上下片） |
| 散曲 | 元曲，可加衬字 |

## 西方格律

| 概念 | 说明 |
|------|------|
| 音步（Foot） | 抑扬格、扬抑格、抑抑扬格等 |
| 五音步抑扬格 | 莎士比亚十四行的基础 |
| 押韵格式 | 交叉韵、抱韵、对偶韵 |
| 十四行诗 | 意大利式/英国式（莎士比亚体） |
| 自由诗 | 无固定格律，靠节奏与分行 |
