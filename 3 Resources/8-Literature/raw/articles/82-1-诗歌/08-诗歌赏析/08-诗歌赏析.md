# 08 诗歌赏析

## 赏析四维

| 维度 | 关注点 |
|------|--------|
| 语言 | 炼字、炼句、音韵 |
| 意象 | 意象选择与组合 |
| 意境 | 整体艺术境界 |
| 情感 | 情志与寄托 |

## 读诗方法

| 方法 | 说明 |
|------|------|
| 细读 | 逐字逐句品味 |
| 知人论世 | 结合作者生平与时代 |
| 比较 | 同题诗、同派诗对读 |
| 吟诵 | 以声韵体味节奏 |
