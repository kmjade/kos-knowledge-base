# 01 诗歌导论

## 什么是诗歌

诗歌是以**精炼语言、鲜明意象与音乐性的韵律**表达情感与思想的文学体裁。中国诗学传统强调「诗言志」「诗缘情」，西方则重「模仿」（mimesis）与「想象」（imagination）。

## 诗歌四要素

| 要素 | 说明 |
|------|------|
| 意象（Imagery） | 情意与物象的结合 |
| 韵律（Rhythm/Rhyme） | 声音的节奏与押韵 |
| 语言（Diction） | 精炼、凝练、多义 |
| 情感（Emotion） | 抒发的核心内核 |

## 主要分类

| 维度 | 类型 |
|------|------|
| 按内容 | 抒情诗、叙事诗、戏剧诗 |
| 按形式 | 格律诗、自由诗、散文诗 |
| 按地域 | 中国诗、西方诗 |
| 按篇幅 | 短诗、长诗、史诗 |

## 历史脉络

| 时期 | 特点 |
|------|------|
| 先秦 | [[诗经-Shi-Jing\|诗经]]四言、[[离骚-Li-Sao\|楚辞]]骚体 |
| 汉魏 | 乐府、五言诗、建安风骨 |
| 唐 | 近体诗（律诗/绝句）巅峰 |
| 宋 | 词、豪放与婉约 |
| 元明清 | 散曲、诗歌延续 |
| 近现代 | 白话新诗（新月、朦胧等） |
| 西方 | 史诗 → 抒情诗 → 十四行 → 自由诗 → 现代主义 |
