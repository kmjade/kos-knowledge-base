# 07 诗歌创作

## 创作过程

| 阶段 | 说明 |
|------|------|
| 灵感（感兴） | 触景生情、因事起兴（例：[[滕王阁序-Teng-Wang-Ge-Xu\|滕王阁序]] 即席而作，相传至「落霞与孤鹜齐飞」句而阎公叹服——出《唐摭言》，属笔记传闻） |
| 立意 | 确定主题与情感基调 |
| 取象 | 选取意象、营造意境 |
| 炼字炼句 | 推敲字词、精炼表达 |
| 修改 | 反复打磨、格律校验（例：[[七律-长征-Qi-Lu-Chang-Zheng\|七律·长征]]「浪拍 → 水拍」，1952 年采纳读者建议） |

## 炼字炼句

| 概念 | 说明 |
|------|------|
| 炼字 | 推敲关键词（如「僧敲月下门」） |
| 炼句 | 打磨佳句、警句 |
| 炼意 | 深化主题与意境 |

## 格律创作要点

| 要点 | 说明 |
|------|------|
| 押韵 | 依韵书（平水韵/中华新韵） |
| 平仄 | 遵循律句的平仄格式 |
| 对仗 | 律诗中间两联求工稳 |

## 现代诗创作

| 要点 | 说明 |
|------|------|
| 意象经营 | 用具体意象承载抽象情感 |
| 分行与节奏 | 以断句营造节奏与留白 |
| 克制表达 | 少直白、多暗示 |
