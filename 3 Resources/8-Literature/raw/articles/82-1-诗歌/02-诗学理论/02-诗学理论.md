# 02 诗学理论

## 中国诗学传统

| 命题 | 出处/内涵 |
|------|-----------|
| 诗言志 | 《尚书·尧典》，诗表达情志 |
| 诗缘情 | 陆机《文赋》，诗因情而生 |
| 兴观群怨 | 孔子论《诗》的社会功能 |
| 意境说 | 王国维《人间词话》，情景交融 |
| 神韵说 | 王士祯，含蓄冲淡 |
| 性灵说 | 袁枚，独抒性灵 |

## 西方诗学传统

| 理论 | 代表 | 核心 |
|------|------|------|
| 模仿论 | 亚里士多德 | 诗是对行动的模仿 |
| 表现论 | 华兹华斯 | 诗是强烈情感的自然流露 |
| 形式主义 | 什克洛夫斯基 | 陌生化、文学性 |
| 新批评 | 艾略特、兰色姆 | 细读、非个人化 |
| 结构主义 | 雅各布森 | 诗歌语言的诗性功能 |

## 王国维境界说

| 范畴 | 说明 |
|------|------|
| 有我之境 | 以我观物，物皆著我色彩 |
| 无我之境 | 以物观物，不知何者为我 |
| 造境/写境 | 理想派与写实派 |
