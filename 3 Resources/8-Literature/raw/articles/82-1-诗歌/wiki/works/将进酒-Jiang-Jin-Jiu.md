# 将进酒 Qiang Jin Jiu

## 原文

> 君不见，黄河之水天上来，奔流到海不复回。
> 君不见，高堂明镜悲白发，朝如青丝暮成雪。
> 人生得意须尽欢，莫使金樽空对月。
> 天生我材必有用，千金散尽还复来。
> 烹羊宰牛且为乐，会须一饮三百杯。
> 岑夫子，丹丘生，将进酒，杯莫停。
> 与君歌一曲，请君为我倾耳听。
> 钟鼓馔玉不足贵，但愿长醉不复醒。
> 古来圣贤皆寂寞，惟有饮者留其名。
> 陈王昔时宴平乐，斗酒十千恣欢谑。
> 主人何为言少钱，径须沽取对君酌。
> 五花马，千金裘，呼儿将出换美酒，与尔同销万古愁。

乐府《鼓吹曲辞·汉铙歌》旧题，古辞首句「将进酒，乘大白」；**「将」读 qiāng（请）**，题意为「请饮酒」。唐·[[李白-Li-Bai|李白]] 作。

## 赏析四维

| 维度 | 赏析 |
|------|------|
| 语言 | 以七言为骨，间插三言（「岑夫子，丹丘生」）与五言，长短参差成顿挫；两度以「君不见」呼告开场，把独白变为对席间的宣讲。 |
| 意象 | 两组宏阔意象叠起——黄河自天而降（空间之奔逝）与镜中白发（时间之骤逝），一巨一微逼出「人生须尽欢」；其后转入金樽、三百杯、五花马、千金裘，全是可挥霍之物。 |
| 意境 | 由天地的浩荡转入酒席的热，再由热转入历史的冷（「古来圣贤皆寂寞」）；全诗是一个不断加速又不断下坠的空间。 |
| 情感 | 悲 → 欢 → 狂 → 愤 → 愁。表面纵酒行乐，骨子里是「才不见用」的愤懑；末句「万古愁」把个人酒兴接到历史愁绪，以狂放写悲慨。 |

## 结构与手法

**情感曲线**：

```
悲（黄河／白发）→ 欢（尽欢／天生我材）→ 狂（三百杯／杯莫停）
                                        ↓
愁（万古愁）← 愤（圣贤寂寞／陈王自比）← 蔑（钟鼓馔玉不足贵）
```

| 手法 | 例证 | 效果 |
|------|------|------|
| 呼告 | 「君不见」×2、「岑夫子，丹丘生」、「请君为我倾耳听」 | 把读者与酒友拉入现场，歌行体的现场感 |
| 夸张与数字 | 三百杯、斗酒十千、千金裘、万古愁 | 以量的极端写情的极端 |
| 价值倒置 | 「钟鼓馔玉不足贵」「古来圣贤皆寂寞，惟有饮者留其名」 | 翻转世俗价值表——愤懑的修辞形态 |
| 用典 | 「陈王昔时宴平乐」— 用曹植《名都篇》「宴平乐，美酒斗十千」事，以曹植自比：才高而被弃，全诗最要紧的自况（见 [[用典-Allusion\|用典]]） | 以古人之酒自况今日之才 |
| 换韵 | 韵脚随段落转换（回／雪／月／来／杯／停／听／醒／名／谑／酌／愁） | 韵随情转，不守一韵到底 |

## 知人论世

李白（701—762），字太白，号青莲居士。天宝元年（742）奉诏入京，供奉翰林；天宝三载（744）赐金放还，此后长期漫游。诗中的「岑夫子」即岑勋，「丹丘生」即元丹丘（道士，李白挚友）。系年主流定于**天宝十一载（752）前后**，与岑勋、元丹丘饮于嵩山；一说作于赐金放还之后。「天生我材必有用」置于此履历下，不是骄傲，而是自我宽解的强撑——是 [[李白-Li-Bai|李白]]「飘逸豪放」之下的第二层。

## 版本问题

敦煌写本（P.2567、P.2552 等）保存有题作**《惜罇空》**的同源作品，学界多视为《将进酒》的早期或不同传本，异文显著：

| 通行本（宋以后） | 敦煌写本《惜罇空》 |
|------------------|-------------------|
| 高堂明镜悲白发 | 床头明镜悲白发 |
| 朝如青丝暮成雪 | 朝如青云暮成雪 |
| 天生我材必有用 | 天生吾徒有俊才 |
| 钟鼓馔玉不足贵 | 钟鼓玉帛岂足贵 |
| 古来圣贤皆寂寞 | 古来圣贤皆死尽 |
| 题《将进酒》 | 题《惜罇空》 |

其中「皆寂寞／皆死尽」最要紧：若敦煌本更近原作，今本的「寂寞」即是后人的**雅化**——把激愤到近于破口的语气磨成了苍凉。此现象与 [[静夜思-Jing-Ye-Si|静夜思]]「看月光 → 明月光」同属唐诗接受的常态，两页可互证。**注意**：敦煌本是否即原作仍有争议，引用时应标注为「一作」而非定论。

## 影响

- 与《蜀道难》《行路难》并称李白**古乐府歌行**的代表，是近体诗定型之后「格律之外」一路的巅峰；与 [[格律诗-Regulated-Verse|格律诗]] 构成体裁上的两极。
- 「天生我材必有用」「千金散尽还复来」成为汉语中最著名的自我肯定句，其接受史已远超文学范围。
- 与 [[离骚-Li-Sao|离骚]] 构成「抒愤」传统的两端：屈原的忠怨与李白的狂放。
