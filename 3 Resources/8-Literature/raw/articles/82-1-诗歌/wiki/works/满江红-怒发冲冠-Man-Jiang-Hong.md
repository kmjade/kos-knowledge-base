# 满江红·怒发冲冠 Man Jiang Hong

## 原文

> 怒发冲冠，凭栏处、潇潇雨歇。抬望眼，仰天长啸，壮怀激烈。三十功名尘与土，八千里路云和月。莫等闲、白了少年头，空悲切。
>
> 靖康耻，犹未雪。臣子恨，何时灭。驾长车踏破，贺兰山缺。壮志饥餐胡虏肉，笑谈渴饮匈奴血。待从头、收拾旧山河，朝天阙。

词，双调九十三字，上片八句四仄韵、下片十句五仄韵（正体），满江红调。南宋·[[岳飞-Yue-Fei|岳飞]] 作——**作者归属有争议，见下文**。

「凭栏处」一作「凭阑处」。全文无异文之要者，但**作者问题远重于文本问题**（对比 [[将进酒-Jiang-Jin-Jiu|将进酒]] 的敦煌异文、[[滕王阁序-Teng-Wang-Ge-Xu|滕王阁序]] 的避讳改字：那些是「字对不对」，此为「人是不是」）。

## 赏析四维

| 维度 | 赏析 |
|------|------|
| 语言 | 全篇以**入声仄韵**为底（歇、烈、月、切、雪、灭、缺、血、阙），韵脚短促硬冷，与内容互为表里。动词尽力：「怒」「冲」「抬」「啸」「驾」「踏破」「收拾」——几乎每一句都有一个发力点，极少静态描写 |
| 意象 | 上片是**个人的身体与天气**：怒发、栏、雨、眼、啸。下片转为**国家的耻与山河**：靖康、长车、贺兰山、胡虏、匈奴、旧山河、天阙。全词的意象运动是**由一身推及一国** |
| 意境 | 上片激愤而收于自警（「空悲切」），下片悲壮而收于复国（「朝天阙」）。整体是**一「愤」一「誓」的两段式**，中间以换头为枢轴；不用景物铺陈，全以情绪推进——这在宋词中很少见 |
| 情感 | 悲愤与决绝。上片对己，下片对天下：**「莫等闲」是自警，「待从头」是立誓**。这一由内转外的转折，是全词的气脉开关 |

## 结构与手法

```
上片  怒发冲冠 → 凭栏·雨歇 → 抬望眼·仰天长啸 → 三十功名/八千里路 → 莫等闲·白了少年头
      （由外而内的激愤，收在自警——写给自己的）
下片  靖康耻未雪 → 臣子恨何时灭 → 驾长车·踏破贺兰山缺 → 饥餐胡虏肉/渴饮匈奴血 → 待从头·收拾旧山河
      （由耻而誓，收在复国的终点——写给天下的）
```

| 手法 | 例证 | 效果 |
|------|------|------|
| 时空对举 | 「三十功名尘与土，八千里路云和月」 | 时间（三十年／三十岁）与空间（八千里征程）相对，而俱以「尘与土」「云和月」化轻——**自轻功名而自重征程**，全词最凝练处 |
| 由内转外 | 上片收于「空悲切」（对己），下片起于「靖康耻」（对国） | 换头即枢轴，个人悲慨接入国族叙事 |
| 极端化修辞 | 「壮志饥餐胡虏肉，笑谈渴饮匈奴血」 | 复仇的想象推到极致，力量最强，也最招讨论（见「争议」） |
| 排比短句 | 「靖康耻，犹未雪。臣子恨，何时灭。」三字一顿 | 节奏急促如鼓点，与入声韵共构「誓师」语气 |
| 卒章定调 | 「待从头、收拾旧山河，朝天阙」 | 以未来的完成态收束当下的悲愤，不留回旋 |

## 知人论世

[[岳飞-Yue-Fei|岳飞]]（1103—1142），字鹏举，相州汤阴（今河南汤阴）人，南宋抗金名将。绍兴十一年十二月廿九（公历 1142 年 1 月 27 日）被以「**莫须有**」罪名杀害于临安大理寺狱，年三十九。宋孝宗时追谥武穆，宁宗时追封鄂王。

词中「**靖康耻**」指靖康二年（1127）金军攻破汴京、掳徽钦二帝北去之事——这是南宋一切主战话语的起点。「三十功名」可解作三十年之功名，亦可解作三十岁（岳飞 1130 年代正当三十余）；「八千里路」泛言转战之远。

## 争议：作者归属（本页最须审慎处理的一节）

**此词是真是伪，学界至今无定论。** 通行教材仍署岳飞，但质疑声从 20 世纪 30 年代延续至今。两类证据并列如下：

### 质疑方

| 疑点 | 内容 |
|------|------|
| 文献断层 | 此词**最早见于明中叶**：杭州岳庙赵宽书碑（约 1502）、徐阶编《岳集》（1536）收录。**宋、元文献一概不见** |
| 岳珂失收 | 岳飞之孙岳珂编《金佗稡编》，收岳飞诗文最全，**未收此词**；《宋史·岳飞传》亦未引 |
| 地理不合 | 「驾长车踏破，**贺兰山**缺」——贺兰山在今宁夏，属西夏方向，与岳飞抗金的实际战场（江淮、中原）不合；而明代恰有王越等人在贺兰山一带与鞑靼作战 |
| 语境时机 | 「靖康耻」「胡虏」「匈奴」之语，在明代抗鞑靼、明末抗清的语境中才获得最大共鸣 |

代表论者：**余嘉锡**《四库提要辨证》（20 世纪 30 年代首先系统质疑）、**夏承焘**《岳飞〈满江红〉词考辨》（1961，以「贺兰山」为突破口）。

### 辩方

- 岳飞被抄家，文稿散失，岳珂编纂时**漏收是可能的**——「未见」不等于「必无」；
- 「贺兰山」在古典诗词中常作**泛指敌人巢穴**的借代，非实指地理；
- 明人事迹与词句相似，只能说明**此词在明代被需要**，不能证明明代才有。

代表论者：**邓广铭**《再论岳飞的〈满江红〉词不是伪作》。

### 本页的处置

**两说并列，不代为裁决**（处理方式同 [[诗经-Shi-Jing|诗经]] 页「孔子删诗说」、[[离骚-Li-Sao|离骚]] 页题名三说、[[滕王阁序-Teng-Wang-Ge-Xu|滕王阁序]] 页《唐摭言》传闻）。但须区分两件事：

> **文献学上的作者归属** ≠ **文学史上的接受事实**。
> 即便作者存疑，「怒发冲冠」一词自明中叶以来、尤其抗战时期所起的精神史作用，已是既成事实——**一首词被需要到什么程度，与它是否出自某人之手，是两个独立的问题**。

## 影响

- 明中叶后随岳飞地位抬升（追谥、立庙、岳传流行）而广泛传抄；**抗战时期**成为最强的动员文本之一，「满江红」几成救亡话语的代名词。
- 由此产生一个别的宋词没有的处境：**它的作者问题与它的传播强度成正比**——越被需要，越被追问来源。
- **当代教材处理**：因「胡虏」「匈奴」等**古代民族称谓**涉及今日民族关系，教材与选本多有节录、注释或改换处理。此属接受史的一部分，如实标注即可（性质同 [[将进酒-Jiang-Jin-Jiu|将进酒]] 页标注敦煌本「一作」）。
- **与 [[沁园春-雪-Qin-Yuan-Chun-Xue|沁园春·雪]] 对读**：两者同属「以词论史／言志」一路，且同样承受「文学评价与政治评价缠绕」的处境——但一为作者无争、评价有争，一为评价无争、作者有争，恰成镜像。
- **词牌**：《满江红》正体押入声仄韵，声情激越，宜抒豪壮悲愤，与「怒发冲冠」互相选中；姜夔则改作平韵以求谐律（〈满江红·仙姥来时〉序）。详见 [[词-Ci|词]]。
