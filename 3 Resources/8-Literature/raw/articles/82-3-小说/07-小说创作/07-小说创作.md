# 07 小说创作

## 创作过程

| 阶段 | 说明 |
|------|------|
| 立意 | 确定主题与核心冲突 |
| 构思 | 人物、情节、结构大纲 |
| 起稿 | 连续写作、完成初稿 |
| 修改 | 打磨语言、情节、人物 |

## 情节设计

| 要点 | 说明 |
|------|------|
| 核心冲突 | 驱动情节的引擎 |
| 开端-发展-高潮-结局 | 经典情节曲线 |
| 悬念与伏笔 | 保持读者兴趣 |
| 节奏 | 张弛有度 |

## 人物塑造

| 要点 | 说明 |
|------|------|
| 欲望与动机 | 人物行动的内在动力 |
| 缺陷与成长 | 人物弧光 |
| 对话个性化 | 语言符合身份性格 |

## 开头与结尾

| 要点 | 说明 |
|------|------|
| 开头 | 快速建立悬念、代入 |
| 结尾 | 收束主题、余韵或反转 |
