## 研究簡報：硬科幻小说

### 概覽

硬科幻（Hard SF）是科幻小說的一種子類型，強調**「硬科學」**（物理、數學、化學、生物學）的嚴格性與可推演性——作者承諾不違背當前已知科學，讀者則付出相應的認知努力作為交換。與著重科技後果與人文哲思的**軟科幻**相對。硬科幻讓物理定律本身成為敘事引擎：重力、燃料（Δv）、熱力學等限制製造障礙與張力，而非單純的背景板。

### 關鍵發現

1. 硬科幻的「硬」指**硬科學**（物理、數學、化學、生物），而非社會科學；核心是「科學合理且內在自洽」。
2. 硬科幻是作者與讀者的**契約**：作者不違背已知科學，讀者付出認知努力作為交換。
3. **科學本身是敘事引擎**：重力、Δv（燃料）、熱力學等限制製造障礙與張力，而非背景板。
4. 與軟科幻的分界：軟科幻重科技帶來的社會／哲學後果，硬科幻重科技本身與技術細節。
5. 常見陷阱：資訊傾倒（infodump）、扁平人物、前後不一致、過度晦澀的術語。
6. 西方代表作者：Arthur C. Clarke、Isaac Asimov、Greg Egan、Alastair Reynolds、Peter Watts、Kim Stanley Robinson、Andy Weir。
7. 華語硬科幻「三巨頭」：劉慈欣（宏大宇宙建構）、王晉康（沉鬱科技反思）、何夕（詩意情感與個體關懷）；王晉康另提出「核心科幻」以調和軟硬對立。
8. 劉慈欣《三體》以基礎物理為引擎（黑暗森林、二向箔、降維打擊），獲雨果獎，將華語硬科幻推向世界。

### 提取的概念

| 概念 | 說明 |
|------|------|
| 硬科幻 (Hard SF) | 以硬科學嚴格性為核心的科幻子類型 |
| 軟科幻 (Soft SF) | 重科技後果與人文哲思的科幻 |
| 黑暗森林 (Dark Forest) | 劉慈欣提出的宇宙社會學推論 |
| 核心科幻 (Core SF) | 王晉康提出、調和軟硬對立的概念 |
| Δv | 太空推進的速度增量，硬科幻常用物理約束 |
| 平凡科幻 (Mundane SF) | 摒棄超光速等不可能技術的變體 |
| 資訊傾倒 (Infodump) | 硬科幻常見的技術解說過度陷阱 |

### 矛盾／爭議

- **軟硬界限模糊**：王晉康「核心科幻」與部分評論者主張打破二元對立——硬科幻亦需人文深度，軟科幻亦需邏輯自洽。
- **華語科幻定位**：有論者稱劉慈欣「單槍匹馬把中國科幻提升到世界級」，亦有聲音指其宇宙觀過於冷酷／具社會達爾文色彩，評價分歧。
- **可讀性光譜**：數學／理論物理向（如 Greg Egan）對一般讀者門檻高，與 Andy Weir 的「可及硬科幻」形成兩端。
