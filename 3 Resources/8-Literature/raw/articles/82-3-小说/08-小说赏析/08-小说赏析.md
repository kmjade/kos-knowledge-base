# 08 小说赏析

## 赏析四维

| 维度 | 关注点 |
|------|--------|
| 主题 | 思想与意义 |
| 人物 | 塑造与弧光 |
| 叙事 | 视角、结构、时间 |
| 语言 | 风格、节奏、细节 |

## 分析方法

| 方法 | 说明 |
|------|------|
| 细读 | 逐段精读、发现潜文本 |
| 叙事分析 | 分解视角、时序、叙述者 |
| 主题批评 | 提炼母题与思想 |
| 比较 | 同题/同派作品对读 |

## 名篇示例

| 作品 | 作者 | 赏析要点 |
|------|------|----------|
| 《孔乙己》 | 鲁迅 | 不可靠叙述、反讽 |
| 《变形记》 | 卡夫卡 | 荒诞、异化 |
| 《老人与海》 | 海明威 | 冰山理论、硬汉 |
| 《百年孤独》 | 马尔克斯 | 魔幻现实、循环 |
