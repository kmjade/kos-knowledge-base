# 03 小说技巧

## 情节技巧

| 技巧 | 说明 |
|------|------|
| 悬念（Suspense） | 引发读者期待与好奇 |
| 伏笔（Foreshadowing） | 为后文埋下线索 |
| 突转（Peripeteia） | 情节的意外转折 |
| 巧合 | 偶然事件推动情节 |

## 描写技巧

| 描写 | 说明 |
|------|------|
| 环境描写 | 渲染氛围、衬托人物 |
| 肖像描写 | 外貌刻画性格 |
| 心理描写 | 内心活动揭示 |
| 细节描写 | 以小见大、真实感 |

## 结构技巧

| 结构 | 说明 |
|------|------|
| 线性结构 | 按时间顺序 |
| 环形结构 | 首尾呼应 |
| 多线并置 | 多条线索交织 |
| 碎片化 | 现代/后现代常用 |
