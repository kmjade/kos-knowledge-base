# 02 叙事学

## 叙述者与视角

| 视角 | 说明 | 特点 |
|------|------|------|
| 第一人称 | 「我」叙述 | 亲切、有限 |
| 第二人称 | 「你」叙述 | 罕见、代入 |
| 第三人称限知 | 跟随某一人物 | 悬念、主观 |
| 第三人称全知 | 上帝视角 | 无所不知 |
| 不可靠叙述者 | 叙述者不可信 | 反讽、多义 |

## 叙事时间（热奈特）

| 概念 | 说明 |
|------|------|
| 时序 | 顺叙、倒叙、插叙、预叙 |
| 时距 | 概略、场景、停顿、省略 |
| 频率 | 单一/重复/反复叙述 |

## 叙述层次

| 层次 | 说明 |
|------|------|
| 故事（Story） | 被叙述的事件本身 |
| 话语（Discourse） | 事件的叙述方式 |
| 元叙述 | 关于叙述的叙述 |
