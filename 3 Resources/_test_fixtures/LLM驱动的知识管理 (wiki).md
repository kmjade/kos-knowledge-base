# LLM 驱动的知识管理系统设计

> **概念** — 将大语言模型应用于个人知识管理系统的设计方案。

## 定义

利用 LLM 的内容理解能力实现智能化的知识捕获、分类、检索和生成，涵盖分拣（Triage）、编译（Wiki Compile）和语义检索三大模块。

## 关键特征

- 智能分拣：LLM 驱动的 Inbox 自动分类与路由
- 知识编译：从原始资料自动生成结构化知识页面
- 语义检索：基于 Embedding 的向量化内容检索

- [[KOS-Wiki-Compile]] — 知识编译引擎，本方案的核心处理层
