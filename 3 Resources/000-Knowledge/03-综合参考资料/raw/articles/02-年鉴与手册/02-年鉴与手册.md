# 02 年鉴与手册

> **UDC 03 / DDC 030** — 本支线收两类**非释义型**工具书：**年鉴**（按年的事实与数据切片）与**手册 / 指南**（把操作与选择压成可速查的形态）。
> 归属判据一句话：**查「某一年发生了什么」，还是查「这件事该怎么做」。**
> 所属：[[03-综合参考资料|03 综合参考资料]]（综合参考资料）· 落位：`03-综合参考资料/raw/articles/02-年鉴与手册/`。
> ⚠️ **序号不是类号**：支线序号 `02` 是**容器内序号**，与 UDC `02`（信息学）无关（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 一、定位与边界

**收什么**

| 族 | 范围 | 典型 |
|:--|:--|:--|
| 年鉴 | 综合性 · 统计 · 地方 · 行业 / 学科 · 机构年报 | 《中国统计年鉴》· 《中国百科年鉴》· 省市年鉴 |
| 手册 | 操作手册 · 数据 / 参数手册 · 标准手册 · 速查便览 | 《机械设计手册》· 设备操作手册 |
| 指南 | 导览型工具书 | 就医指南 · 使用指南 |

**不收什么**

| 主题 | 去向 | 理由 |
|:--|:--|:--|
| 百科全书 · 辞书 · 类书 | [[3 Resources/000-Knowledge/03-综合参考资料/raw/articles/01-百科与辞书/01-百科与辞书\|01 百科与辞书]] | 查**概念与词义**，无年度切片 |
| 名录 · 参考咨询 | [[3 Resources/000-Knowledge/03-综合参考资料/raw/articles/03-名录与参考咨询/03-名录与参考咨询\|03 名录与参考咨询]] | 查**机构 / 人物信息**、查「怎么查」 |
| 期刊等连续出版物 | [[05-连续出版物、期刊\|05 连续出版物、期刊]] | 按**出版形态**归 05，见下方 ⚠️ |
| 标准文本 | [[006-标准化\|006 标准化]] | 标准是**规范**，手册是**摘要与选用** |
| 教科书 · 专著 | 随学科归类 | 线性通读，非查考 |
| 统计方法 · 指标理论 | [[31-统计学\|31 统计学]] | 年鉴**给数**，统计学**给方法** |

## 二、三种「非释义型」工具书

| 维度 | 年鉴 | 手册 | 指南 |
|:--|:--|:--|:--|
| 时间性 | **强**：一年一册 | 弱：随版更新 | 弱：不定期 |
| 内容 | 事实 · 数据 · 大事记 | 方法 · 参数 · 流程 | 路径 · 联系 · 评价 |
| 编排 | 栏目 + 条目 + 统计表 | 主题 / 流程步骤 | 地理 / 主题 |
| 回答的问题 | 某年怎么样 | 怎么做 / 取什么值 | 去哪里 / 找谁 |
| 典型 | 《中国统计年鉴》 | 《机械设计手册》 | 就医指南 |

> 📌 三者与百科、辞书的分野在**知识形态**：百科与辞书给**解释**，年鉴给**快照**，手册给**操作**，指南给**路径**。

## 三、年鉴

> 定义：**按年出版**、系统记录**上一年度**事实、数据与进展的工具书。

**类型**

| 类型 | 说明 | 例 |
|:--|:--|:--|
| 综合性年鉴 | 全域年度记录 | 《中国百科年鉴》· 《世界年鉴》 |
| 统计年鉴 | 以数据表为主体 | 《中国统计年鉴》 |
| 地方年鉴 | 一省 / 市 / 县 | 省年鉴 · 市年鉴 · 区县志式年鉴 |
| 行业 / 学科年鉴 | 一行业或学科的年度进展 | 学科年鉴 · 行业年鉴 |
| 机构年鉴 / 年报 | 单一机构的年度报告 | 企业年报 · 大学年报 |

> ⚠️ **年报 ≠ 年鉴**：年报是**机构自述**（面向股东 / 上级），年鉴多为**第三方或官方汇编**（面向查检）。文献类型相邻，责任结构不同。

**六个要素**

| 要素 | 要点 | 陷阱 |
|:--|:--|:--|
| 收录年度 | 记录的是**哪一年** | 与出版年混淆（2024 年鉴多记 2023 年数据） |
| 统计口径 | 指标定义 · 范围 · 计价 | 口径变更 ⇒ 时间序列断裂 |
| 栏目体例 | 特载 · 概况 · 统计资料 · 大事记 · 附录 | 栏目年际调整，跨年不可直接对接 |
| 索引 | 主题 / 分类 / 表格索引 | 只会按栏目翻检 |
| 编纂机构 | 统计局 · 方志办 · 行业协会 | 权威性与覆盖范围差异大 |
| 载体 | 纸本 / 数据库 / 光盘 | 数据库版**回溯修订**，与纸本不一致 |

## 四、手册与指南

**手册五型**

| 类型 | 内容 | 例 |
|:--|:--|:--|
| 操作手册 | 步骤 · 流程 · 注意事项 | 设备操作手册 |
| 数据 / 参数手册 | 表格式参数与选型 | 材料手册 · 电气手册 |
| 标准手册 | 标准摘要与选用指引 | 设计手册 |
| 速查便览 | 公式 · 图表 · 判据 | 数学手册 · 临床手册 |
| 指南（guide） | 路径 · 选择 · 评价 | 就医指南 · 写作指南 |

**手册 vs 教科书**

| 维度 | 手册 | 教科书 |
|:--|:--|:--|
| 阅读方式 | **查**（非线性） | **读**（线性） |
| 知识形态 | 结论 · 参数 · 步骤 | 推导 · 练习 · 讨论 |
| 更新动力 | 技术迭代 | 教学大纲 |
| 缺失 | 不解释「为什么」 | 不便速查 |

> 📌 手册的价值在**省略**：把推理过程拿掉，只留可执行结论——代价是**不提供判据**，误用风险由使用者承担。

## 五、年鉴的判读

| 判据 | 做法 |
|:--|:--|
| 出版年 → 数据年 | 引用一律写明「数据年度」而非「年鉴年份」 |
| 口径一致性 | 跨年比较前先查指标定义是否变更 |
| 栏目变动 | 遇栏目调整，改用连续序列拼补 |
| 修订与回溯 | 数据库版可能修正旧数，注明取数时间 |
| 权威层级 | 国家统计局 > 部门 > 行业协会 > 商业机构 |
| 引用格式 | 编者 · 年鉴名 · 年份卷 · 页码 · 表号 |

## 六、中国年鉴谱系

| 阶段 | 代表 | 特点 |
|:--|:--|:--|
| 近代 | 《申报年鉴》（1933）· 《中国经济年鉴》（1930 年代） | 商业与行业驱动，统计初建 |
| 新中国 | 《中国统计年鉴》（1982–）· 《中国百科年鉴》（1980–1994） | 国家统计体系成型 |
| 当代 | 地方志年鉴化 · 行业年鉴激增 · 数据库版 | 纸本 + 在线并行，口径趋标准化 |

> 📌 地方年鉴与地方志（旧志）是两种文献：**年鉴按年续修**，**方志按代重修**；二者常由同一机构（方志办）编纂，但体例与周期不同。

## 七、使用场景

| 场景 | 用什么 |
|:--|:--|
| 查某年数据 | 统计年鉴（先定数据年） |
| 查政策与大事 | 综合性年鉴「大事记 / 特载」 |
| 查参数与选型 | 手册 + 对应标准号 |
| 查机构与联系人 | 名录（03 支线） |
| 查概念与词义 | [[3 Resources/000-Knowledge/03-综合参考资料/raw/articles/01-百科与辞书/01-百科与辞书\|01 百科与辞书]] |

## 八、核心问题

> 年鉴的可比性依赖**口径不变**，而口径恰由编纂机构按年调整；手册的权威依赖**版次**，而版次又被技术迭代追着走。二者都在「稳定」与「更新」之间交易：**所谓时间序列，是编纂者维持出来的连续**。
