# 03 名录与参考咨询

> **UDC 03 / DDC 030** — 本支线收两类**指向性**工具：**名录**（谁 / 在哪 / 怎么联系）与**参考咨询**（该用哪种工具、按什么路径查）。
> 归属判据一句话：**查「这个人 / 这家机构在哪」，还是查「这个问题该到哪里去查」。**
> 所属：[[03-综合参考资料|03 综合参考资料]]（综合参考资料）· 落位：`03-综合参考资料/raw/articles/03-名录与参考咨询/`。

## 一、定位与边界

**收什么**

| 族 | 范围 | 典型 |
|:--|:--|:--|
| 名录 | 机构 · 人名 · 行业 / 企业 · 会员 · 地名 · 会议 | 政府机构名录 · 名人录 · 厂商名录 |
| 参考咨询（方法层） | 参考源指南 · 查检策略 · 工具书使用法 · 接题与核验 | 参考源导引（pathfinder）· 工具书指南 |

**不收什么**

| 主题 | 去向 | 理由 |
|:--|:--|:--|
| 传记 · 人物生平 | `929` 人物传记 | 人名录是**事实卡片**，传记是**叙述** |
| 地方志 · 地名学 | `9` 史地类 | 地名录只做**名称—位置**对照 |
| 图书馆参考咨询**服务**（读者服务 · 馆际互借 · 咨询台管理） | [[02-信息学\|02 信息学]] | 服务与制度属图书馆学 |
| 检索系统 · 数据库 · 元数据 | [[02-信息学\|02 信息学]] | 系统与标准，不是工具书 |
| 年鉴 · 手册 · 指南 | [[02-年鉴与手册\|02 年鉴与手册]] | 查年度事实 / 操作步骤 |
| 百科 · 辞书 · 类书 | [[01-百科与辞书\|01 百科与辞书]] | 查概念与词义 |
| 书目 · 目录 | [[01-目录学\|01 目录学]] | 记「有哪些文献」 |

> 📌 **切分要点**：**「参考咨询服务」归 02**（属图书馆学），**「参考咨询方法 / 工具指南」归本支线**（属工具书使用）。同一业务，服务制度与方法手册两投。

## 二、名录的类型

| 类型 | 内容 | 例 |
|:--|:--|:--|
| 机构名录 | 名称 · 职能 · 地址 · 联系方式 | 政府机构名录 · 学会名录 |
| 人名录 | 在世人物简况（who's who 体） | 《WHO'S WHO》· 各行业名人录 |
| 行业 / 企业名录 | 行业内的企业清单 | 厂商名录 · 黄页 |
| 会员名录 | 组织成员名单 | 学会会员录 · 协会名录 |
| 地名录 | 地名与位置对照 | 地名辞典 · gazetteer |
| 会议 / 活动名录 | 会议 · 展览 · 赛事 | 会议指南 · 展会名录 |

> ⚠️ **名录 ≠ 名册**：名册是**内部管理**文件（花名册），名录是**对外查检**工具书——判据看**是否面向不特定读者发行**。

## 三、人名录与传记的分界

| 维度 | 人名录 | 传记 |
|:--|:--|:--|
| 单元 | 条目化简况（生卒 · 职务 · 著作） | 叙述性生平 |
| 选录 | 特定范围（在世 / 行业 / 会员） | 不限 |
| 用途 | 查「他是谁、在哪」 | 理解其生平与评价 |
| 归类 | 本支线（工具书） | `929` 传记 |

> ⚠️ **已故人物的详传归 929**；名录中的条目只是**事实卡片**，不承担评价功能。二者可互相参见，不可互替。

## 四、参考咨询：从问题到工具

> 定义：帮助读者**定位与获取**信息的服务与方法。本支线只收**方法层**。

| 步骤 | 动作 | 要点 |
|:--|:--|:--|
| 1 接题 | 澄清范围 · 时限 · 已有线索 | 先问「你真正要解决的是什么」 |
| 2 选源 | 按问题类型选工具（见矩阵） | 不按「手边有什么」选 |
| 3 检索 | 字顺 · 分类 · 索引 · 交叉参见 | 记录检索路径 |
| 4 核验 | 多源比对 · 版本核对 · 时效检查 | 单一工具不足以下结论 |
| 5 交付 | 注明来源 · 版本 · 检索日期 | 让结果可复核 |

**问题类型 → 工具矩阵**

| 要查 | 首选 | 备选 |
|:--|:--|:--|
| 是什么 / 概念 | [[01-百科与辞书\|01 百科与辞书]] | 专科辞书 |
| 某年数据 / 事实 | [[02-年鉴与手册\|02 年鉴与手册]] | 统计数据库 |
| 谁 / 在哪 / 怎么联系 | 本支线（名录） | 机构官网 |
| 有哪些文献 | [[01-目录学\|01 目录学]] | 文献数据库 |
| 怎么做 / 取什么值 | [[02-年鉴与手册\|02 年鉴与手册]] | [[006-标准化\|006 标准化]] |
| 术语是否规范 | [[01-百科与辞书\|01 百科与辞书]] | [[006-标准化\|006 标准化]] |

## 五、名录的编纂与判读

| 要点 | 陷阱 |
|:--|:--|
| 收录标准 | 付费入录 · 自我申报 ⇒ 商业名录可信度低 |
| 时效 | 名录半年即旧，须注明**截止日期** |
| 排序 | 字顺 / 分类 / 地区，影响查得率 |
| 索引 | 名称 · 别名 · 曾用名 · 简称 |
| 改名与沿革 | 机构撤并更名 ⇒ 设参见，不留空指向 |
| 隐私 | 个人信息最小化（对齐 People CRM 的 `privacy: restricted` 约束） |

> 📌 评价一份名录，先看**谁编、收录谁、截止到哪天**——三者不明，条目再多也不可引用。

## 六、中国脉络

| 形态 | 例 | 说明 |
|:--|:--|:--|
| 搢绅录 · 题名录 | 明清《缙绅录》· 科举题名录 | 官职与人名的年度名录 |
| 同业公会名录 | 商会会员录 | 行业名录前身 |
| 现代机构名录 | 政府机构名录 · 学会会员录 | 官方 / 协会编纂 |
| 数字名录 | 企业信用信息公示系统 · 网络黄页 | 实时更新，可检索 |

> 📌 传统「题名录」兼有**名录**与**史料**两重性质：当年是查检工具，今日是一手史料——**工具书会随时间变成史料**。

## 七、参考咨询的数字化

| 变化 | 影响 |
|:--|:--|
| 工具书架 → 检索系统 | 「选源」从翻书架变成选库 |
| 参考咨询 → 信息素养教育 | 从代查转向教人查 |
| 指南页 → 在线路径 | 链接失效成为新问题 |
| AI 问答 | 即时但**无版本、无收录边界**，须回原始工具核验 |

> ⚠️ 数字化改变的是**检索路径**，不改变**核验责任**：答案越快，越需要说明「依据哪一版、哪一条目」。

## 八、核心问题

> 名录回答「谁在哪里」，价值取决于**收录标准与截止日**；参考咨询回答「该查什么」，价值取决于**是否愿意先澄清问题**。数字化把两者都压进一个搜索框——**检索的便利，是否以放弃「知道自己查的是什么」为代价？**
