# PARA 与知识管理

> **资源：** PARA 在个人知识管理（PKM）中的深入应用与实践。

---

## 核心内容

### 信息流模型

PARA 本质是一个**信息过滤器**，从粗糙的搜集到精炼的知识：

```
采集 → 项目化 → 完成 → 领域化 → 固化认知 → 归档
```

1. **采集阶段** — 闪念笔记、书签、截图 → 放入 `06-Daily` 或 `0 Inbox`
2. **项目化** — 判断是否有明确的产出目标 → 创建项目
3. **执行阶段** — 在项目文件夹中推进，产生具体成果
4. **领域化** — 项目完成后，将可复用的知识沉淀到领域
5. **归档** — 不再活跃的项目/领域移至 `4 Archives/`

### PARA 与 Zettelkasten

| 维度 | PARA | Zettelkasten |
|------|------|-------------|
| 焦点 | 行动与完成 | 连接与发现 |
| 结构 | 树形文件夹 | 网状链接 |
| 生命周期 | 从活跃到归档 | 永久积累 |
| 适用场景 | 项目管理 | 知识发现 |

两者互补：PARA 管理"做什么"，Zettelkasten 管理"知道什么"。
