## 范围纪律

- **不做鉴定**：不判断印与跋的真伪，不给估价
- **不凭一印定递藏**：一方印只给一个时点
- **不把「旧藏」当「真迹」**：来源不证明内容
- **不把馆藏号当流传史**：那是入藏后的管理痕迹
- **不越隐私边界**：最小必要信息，禁区见上
- **不复述法律条文**：物权 · 返还 · 出境归 [[34-法律|34 法律]]
