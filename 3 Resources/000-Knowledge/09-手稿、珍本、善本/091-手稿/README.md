## 范围纪律

- **不做鉴定**：真伪、年代、价值结论须由具备资质者据实物作出
- **不把编号当价值**：编在 `091` 不表示珍贵，也不表示已鉴定
- **不把印本当手稿**：批校本的主体仍是印本
- **不把「公开影像」当「可自由使用」**：访问状态与权利状态是两件事
- **不复述法律条文**：文物法 · 档案法 · 出境管制条文归 [[34-法律|34 法律]]
