## 范围纪律

- **不径改而无记**：改一个字必留一条校记，否则读者无法复核
- **不以理校独断**：无本可据时只写「疑当作」，不写「本作」
- **不引二手转录当原书**：转引须标层级，能回图就回图
- **不把辑本当复原**：拼合界面是推定，不是发现
