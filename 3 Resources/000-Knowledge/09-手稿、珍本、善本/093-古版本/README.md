## 范围纪律

- **不做鉴定**：不给确定年份、真伪、估价结论
- **不单证断代**：一条证据只支持一个假设
- **不把大致年代写成确定年**：`约` / `待考` / `存疑` 必须保留
- **不把市场著录当学术结论**：拍卖话术不是断代依据
- **不复述法律条文**：定级与出境条文归 [[34-法律|34 法律]]
