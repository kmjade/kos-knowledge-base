# 03 连续出版物著录

> **UDC 05 / DDC 050** — 本支线处理连续出版物的**记录问题**：一条书目记录该记哪几样（**著录要素**）· 刊改名后是开新记录还是续旧记录（**变更管理**）· 馆藏怎么记（**到馆卷期**）· 电子版怎么处理（**载体表现**）。
> 归属判据一句话：**问「这条记录怎么写、改名后怎么连、馆藏怎么挂」，而不是「这是什么形态、这本刊好不好」。**
> 所属：[[05-连续出版物、期刊|05 连续出版物、期刊]]（连续出版物、期刊）· 落位：`05-连续出版物、期刊/raw/articles/03-连续出版物著录/`。
> ⚠️ **序号不是类号**：支线序号 `03` 是**容器内序号**，与 UDC `03`（综合参考资料）不是同一层级概念（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 一、定位与边界

**收什么**

| 面 | 范围 | 典型 |
|:--|:--|:--|
| 著录规则 | ISBD(CR) · RDA · AACR2 的连续出版物条款 · 中国编目规则 | 选哪套规则、各要素怎么记 |
| 著录要素 | 题名 · 版本 · 卷期年月 · 出版发行 · 载体 · 丛编 · 附注 · ISSN | 一条记录长什么样 |
| 变更管理 | 主要 / 次要变更 · 分段著录 · 连接款目 | 改名后开新记录 |
| 馆藏与电子版 | 到馆卷期（holdings）· 载体变化 · 电子位置 | 缺期怎么记、纸电如何分记 |

**不收什么**

| 主题 | 去向 | 理由 |
|:--|:--|:--|
| 连续出版物的形态认定 · 刊期 · ISSN 分配 | [[01-类型与刊期\|01 类型与刊期]] | 认定「是什么」，不是「怎么写」 |
| 同行评审 · 计量 · 出版模式 | [[02-学术期刊与同行评审\|02 学术期刊与同行评审]] | 制度与评价，不是记录 |
| 分类法 · 主题标引 · 元数据方案（DC / BIBFRAME） | [[025-Classification-Metadata\|025 分类法与元数据]] | 内容揭示与数据模型 |
| 书目理论 · 目录学史 · 规范控制的原理 | [[01-目录学\|01 目录学]] | 理论与编制，不是逐条著录 |
| 纸本文献的版本鉴定 | [[002-文档、书籍、著作、著作人\|002 文档与书籍]] | 版本学，不是连续著录 |

> 📌 **切分要点**：**「这是什么」归 01**（形态）· **「它好不好」归 02**（制度）· **「怎么记录」归本支线**（著录）。三问三投，同一本刊可同时出现在三处。

## 二、著录标准的谱系

| 标准 | 年代 | 定位 |
|:--|:--|:--|
| **ISBD(S)** | 1977 起 | 连续出版物国际标准书目著录（早期专册） |
| **ISBD(CR)** | 2002 | 由 ISBD(S) 与 ISBD(ER) 合并而成，覆盖**连续与其他连续性资源** |
| **ISBD 统一版** | 2011 · 2021 修订 | 各类型合并为一册，连续出版物条款并入 |
| **AACR2** | 1978（1988 / 2002 修订） | 英美编目规则；**1978 起采用分段著录**（见第四节） |
| **RDA** | 2010 起 | 基于 FRBR / LRM 的新规则；2020 前后经 3R 项目重写为「official RDA」 |
| **中国文献编目规则** | 第二版 2005 | 中文编目实践的主干规则 |
| **GB/T 3792.3** | 1985 → 2009 | 文献著录·连续性资源部分；2009 版与 ISBD 框架对齐 |
| **CNMARC** | 依 UNIMARC | 中文书目数据的机读格式 |
| **MARC 21** | 英美体系 | 英文书目数据的机读格式 |

> ⚠️ **别把规则当格式**：ISBD / RDA 是**著录内容规则**（记什么、怎么措辞），CNMARC / MARC 21 是**数据承载格式**（放在哪个字段）。同一套 ISBD 内容可以装进两种 MARC。
> 📌 **本支线只做框架级对照**；逐条规则以官方文本为准，版本频繁，遇细节须回原文核对（列待补）。

## 三、著录要素

| 项 | 记什么 | 连续出版物的特殊处 |
|:--|:--|:--|
| 题名与责任说明 | 正题名 · 并列题名 · 其他题名 · 责任者 | **题名可能变**（见第四节） |
| 版本项 | 版次 · 版本类型 | 连续出版物少用版次，多用「地区版 / 语种版」 |
| **卷期年月项** | 起始卷期与年份、终止卷期与年份 | 连续出版物的**核心识别项**；未停刊则记起而无止 |
| 出版发行项 | 出版地 · 出版者 · 出版年 | 出版者可随年更替 |
| 载体形态 | 册数 · 尺寸 · 附件 | 连续出版物的载体是**累积体**，常用馆藏而非册数 |
| 丛编项 | 所属丛编 | 与「丛刊」形态须分辨（见 [[01-类型与刊期\|01 类型与刊期]]） |
| 附注项 | 刊期 · 题名沿革 · 索引 · 缺期 | **变更与关联主要在此说明** |
| ISSN 与获得方式 | ISSN · 价格 | ISSN 变化即「另一种刊」（见 01 支线） |
| 标准号 | CN 号等 | 与 ISSN 并列，不可互替 |

**信息源与「首末比对」**

| 原则 | 内容 |
|:--|:--|
| 规定信息源 | 题名页 / 首页 / 首期封面，优先于装订题名与书脊 |
| 依据**首期**著录 | 题名、责任者、卷期起点以首期为据 |
| 核对**最新期** | 记「最新所见期」（latest issue consulted），据此发现变更 |
| 缺期如实记 | 到馆不完整须在附注与馆藏中记明，不得以「完整」推定 |

> ⚠️ **连续出版物的著录是「时点快照 + 时间跨度」**：一条记录同时承载「某一次编目时所见的最新期」与「自首期起的连续区间」。二者混淆，记录就失真。

## 四、变更管理与分段著录

**两种历史路线**

| 路线 | 做法 | 后果 | 现状 |
|:--|:--|:--|:--|
| **最新题名著录**（latest entry） | 一条记录永远用**当前题名**，旧题名进附注 | 记录唯一，但历史被压成一行字 | 早期做法，1978 年前常见 |
| **分段著录**（successive entry） | 每次**主要变更**开一条新记录，用新题名；新旧记录以连接款目相连 | 记录数增加，但每一时段可独立检索与引用 | **1978 年（AACR2）起为通行做法** |

**主要变更 → 新记录**

| 变更 | 处理 |
|:--|:--|
| 正题名变更 | 新记录 · 新 ISSN · 连接款目 |
| 责任团体变更（影响识别） | 视规则判为主要变更 |
| 出版者变更 | 一般**次要变更**，同记录内更替并注记 |
| 载体变化（印刷 → 在线） | 通常**另立记录**（另一载体表现），二者互连 |
| 合并 / 分辑 / 并入 | 各自开记录，双向连接 |

**连接款目（MARC 21 ↔ CNMARC）**

| 关系 | MARC 21 | CNMARC | 用法 |
|:--|:--|:--|:--|
| 先前款目（旧题名） | 780 | 430 | 新记录指回旧刊 |
| 后续款目（新题名） | 785 | 440 | 旧记录指向新刊 |
| 连接说明附注 | 580 | 3XX 附注类 | 用文字说明沿革 |
| 电子位置 | 856 | 856 | 在线版 URL |

> ⚠️ **连接必须双向**：只在新记录里写「继承自某刊」而旧记录不写「由某刊续出」，读者与系统都会断链。改名、合并、并入都按此办理。

## 五、馆藏、完整性与电子版

| 概念 | 记什么 | 与书目记录之别 |
|:--|:--|:--|
| **书目记录**（bibliographic record） | 刊本身的描述 | 一刊一条（分段著录下为一时段一条） |
| **馆藏记录**（holdings） | 本馆实际到馆的卷期区间与缺期 | 一馆一条，可多份 |
| 馆藏格式 | MFHD（MARC Format for Holdings Data）· Z39.71 馆藏声明 | 与书目分库或分字段 |
| 完整性 | 缺期 · 断年 · 补配记录 | 不得用书目记录掩盖缺藏 |

**电子连续出版物三问**

| 问 | 处理分歧 |
|:--|:--|
| 纸电是否分记录 | 通行做法**分开**（不同载体表现），以连接款目互指 |
| 记录的是「拥有」还是「可访问」 | 拥有（本地镜像）与访问（订阅在线）性质不同，馆藏语义不同 |
| 链接失效怎么办 | 856 需维护；持久标识（DOI / PURL）优于裸 URL |

> 📌 **一书目记录，一馆藏记录，各自为政**：把「本馆有哪几期」塞进书目记录的附注，是最常见的连续著录坏味道——馆藏会变，书目不应随之重编。

## 六、核心问题

> 连续出版物的著录难题只有一个：**一条记录该代表「这本刊」，还是「这本刊在某一段时间的状态」？** 最新题名著录选了前者，代价是把改名折叠成附注；分段著录选了后者，代价是记录增殖与连接维护。**没有无损的选项**——连续性本身就是对「唯一标识」这个概念的反驳。编目的选择不是技术细节，而是**对「什么算同一个东西」的立场**。
