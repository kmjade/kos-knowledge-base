# 01 类型与刊期

> **UDC 05 / DDC 050** — 本支线处理连续出版物的**身份问题**：它**是什么形态**（类型）· **多久出一期**（刊期）· **凭什么被唯一指认**（编号）。
> 归属判据一句话：**问「这是不是连续出版物、是哪一种、怎么编号」，而不是「这本刊好不好、论文怎么评审」。**
> 所属：[[05-连续出版物、期刊|05 连续出版物、期刊]]（连续出版物、期刊）· 落位：`05-连续出版物、期刊/raw/articles/01-类型与刊期/`。
> ⚠️ **序号不是类号**：支线序号 `01` 是**容器内序号**，与 UDC `01`（目录学）不是同一层级概念（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 二、连续出版物的定义与判据

> 定义（ISBD(CR) / ISSN 体系口径的简化）：**连续发行、无预定终止、通常带期次或卷号标识、通常分期陆续出版**的出版物。

| 判据 | 是 | 否 |
|:--|:--|:--|
| 发行是否连续 | 有计划地一期接一期 | 一次性出完 |
| 有无预定终止 | 无（理论上是开放的） | 有（确定共 N 卷） |
| 是否分期标识 | 卷 / 期 / 年 / 月日 | 册 / 卷次（多卷本） |
| 有无所属编号 | ISSN 一类连续标识 | ISBN 一类单册标识 |

**近邻三辨**

| 对象 | 关键差别 | 例 |
|:--|:--|:--|
| 单册（monograph） | 一次性、有预定终止、用 ISBN | 专著 · 论文集（非系列） |
| 丛书（series，多卷本） | 各卷独立完整、无预定刊期、各有 ISBN | 某某丛书 · 某某文集 |
| 集成性资源（integrating resource） | 以「更新页 / 整页替换」累积更新，不按期 | 活页法规汇编 · 持续更新的数据库 |

> ⚠️ **边界灰区**：**丛刊**（有编号、定期或不定期连续出版，但各辑有独立题名）在中文语境常与「丛书」混称。判据看**有无预定刊期与连续编号意图**：有则按连续出版物处理，无则归 `08`。此灰区列为待补。

## 三、类型谱

| 类型 | 特征 | 典型 |
|:--|:--|:--|
| 学术期刊 | 同行评审 · 论文体 · 有卷期 | 学报 · 专业期刊 |
| 通俗杂志 | 大众阅读 · 商业运营 | 综合类 / 垂类杂志 |
| 评论型期刊 | 长文评论 · 书评 · 思想评论 | 评论 / 学刊 |
| 通报 · 快报 | 短讯 · 快报 · 优先发表 | 学会通报 · letters |
| 文摘 · 索引刊 | 二次文献 · 摘录与标引 | 文摘杂志 · 索引刊 |
| 报纸 | 高频 · 新闻时效 · 大开张或小报 | 日报 · 周报 |
| 年刊 · 年报类 | 一年一册 | 年刊 · annual review |
| 丛刊 · 连续丛编 | 有编号 · 各辑独立题名 | 丛刊 · 集刊 |
| 官方公报 | 权威发布 · 编号连续 | 政府公报 · 学会公报 |
| 电子连续出版物 | 在线发行 · 一媒介一号 | 电子刊 · 在线-only 刊 |

> 📌 **类型不是等级**：学术期刊与通俗杂志的差别在**评审与读者**，不在**连续性**；文摘刊是**二次文献**，形态仍是连续出版物。

## 四、刊期与卷期结构

**刊期（frequency）** 是出版方承诺的**出刊节奏**，与**内容时效**是两件事。

| 中文 | 英文 | 每年期数（约） |
|:--|:--|:--|
| 日刊 | daily | 250–365 |
| 周刊 | weekly | 52 |
| 半月刊 | semimonthly / biweekly | 24 |
| 月刊 | monthly | 12 |
| 双月刊 | bimonthly | 6 |
| 季刊 | quarterly | 4 |
| 半年刊 | semiannual | 2 |
| 年刊 | annual | 1 |
| 不定期 | irregular | 不定 |

**卷期结构**

| 要素 | 规则 | 注意 |
|:--|:--|:--|
| 卷（volume） | 通常一年一卷 | 跨年卷 · 一年两卷均存在，须看本刊说明 |
| 期（issue / number） | 卷内按刊期递增 | 期号可跨卷连续，也可每年重编 |
| 合刊（combined issue） | 两期并作一期出版 | 编号常写作 `3/4`，易造成「缺期」误判 |
| 增刊（supplement） | 正刊之外的附册 | 可能独立编号，也可能续正刊期号 |
| 特刊（special issue） | 主题专辑 | 常由客座编辑主持，评审规则可能与正刊不同 |
| 出版时滞 | 收稿到见刊的间隔 | 与刊期无关；快刊 ≠ 快审 |

> ⚠️ **引用必须到卷期页**：只写「某刊 2024 年」无法定位；只写刊期（「月刊」）更不能定位。刊期描述**节奏**，卷期页描述**位置**。

## 五、编号体系

| 标识 | 层级 | 作用 | 特点 |
|:--|:--|:--|:--|
| **ISSN** | 刊 | 指认**一种连续出版物**（题名级） | 8 位：前 7 位 + 1 位校验位，常写作 `1234-5679` |
| **e-ISSN** | 刊（媒介） | 电子版专用 | 一种刊的纸 / 电版本**各有一号** |
| **ISSN-L** | 刊（跨媒介） | 把同一刊的不同媒介版本**连成一个刊** | 取该刊首个分配的 ISSN 作为连接号 |
| **CN 号** | 刊（中国） | 国内统一连续出版物号 | 形如 `CN XX-XXXX/YY`，后段为分类标识 |
| **邮发代号** | 发行 | 邮政发行渠道标识 | 只说明「哪条发行渠道」，不具识别唯一性 |
| **CODEN** | 刊 | 老式刊名代码 | 多用于科技文献，逐步被 ISSN 取代 |
| **ISBN** | **单册** | 指认一本书 / 一卷 | 丛书各卷各有 ISBN；刊**不用** ISBN |
| **DOI** | **文章** | 指认一篇具体文章 | 文章级，不替代刊级标识 |

> 📌 **三级不可互替**：**ISSN 指刊 · DOI 指文 · ISBN 指册**。用 ISSN 引单篇论文、用 ISBN 指整刊，都是常见的引用错误。
> ⚠️ **一媒介一号**：同一种刊的印刷版与在线版通常各有 ISSN，靠 **ISSN-L** 关联；因此「找 ISSN」时必须先用 ISSN Portal 一类登记库**反查刊名**，不可由记忆推定。

## 六、生命周期与题名变更

| 事件 | 是否需新 ISSN | 说明 |
|:--|:--|:--|
| 创刊 | 是 | 首次分配 |
| 主要变更（正题名、出版者等） | **是** | 视为**新刊**，旧刊记录保留 |
| 次要变更（拼写、副题名微调） | 否 | 仍为同一刊 |
| 休刊 · 复刊 | 否 | 卷期可能续编或重启，须核对 |
| 停刊 | 否 | 记录关闭，不回改 |
| 合并（merger） | 新刊新号 | 两刊并入一刊，须双向参见 |
| 分辑（split） | 各新号 | 一刊分为数刊 |
| 并入（absorption） | 承接刊续号，被并入刊关闭 | 易造成「同一刊换了名字」的错觉 |

> ⚠️ **改刊名 ≠ 改标题**：判据是变更的**程度**（题名、责任者、出版者），不是「看起来像不像同一本」。主要变更产生**新 ISSN + 新记录**，两者以「先前款目 / 后续款目」相连——这是 `03 连续出版物著录` 的事，本支线只记判定节点。

## 七、判读：一份出版物是不是期刊

| 步骤 | 问 | 若否 |
|:--|:--|:--|
| 1 | 是否分期连续出版、无预定终止？ | 单册 / 多卷本 → 非本支线 |
| 2 | 是否有卷 / 期 / 年月一类期次标识？ | 无期次 → 集成性资源或丛书 |
| 3 | 是否有 ISSN（或办刊中已申请）？ | 无号但有刊期 → 仍可能是刊，编号待补 |
| 4 | 刊期是否稳定（含「不定期」声明）？ | 完全无序 → 按单册或丛编处理 |
| 5 | 题名是否发生过主要变更？ | 是 → 视为**另一种刊**，分别识别 |

> 📌 **识别顺序**：先看**形态**（连续 / 期次 / 无终止），再看**编号**（ISSN），最后才看**内容**（学术 / 通俗）。若从内容倒推形态，容易把「连续出版的主题读物」误判为期刊。

## 八、核心问题

> 刊期承诺的是**节奏**，ISSN 承诺的是**身份**——两者都不承诺质量。一年十二期可以是水刊，四年一期可以是名刊。**当评价体系把「刊期与编号」当成质量的代理指标时，被测量的其实是出版频率，而不是知识增量。**
