# 02 出版社与出版业

> **UDC 07 / DDC 070** — 本支线处理**出版社这一机构**与**图书出版这门生意**：书是怎么被做成商品的（**出版链**）· 谁有资格出（**出版资质与书号**）· 版权怎么分（**授权与版税**）· 钱在哪一环被拿走（**折扣与账期**）· 卖不掉怎么办（**库存与退货**）。
> 归属判据一句话：**问「这本书是谁出的、凭什么能出、卖出去的钱怎么分」，而不是「印刷怎么装订、书怎么编目」。**
> 所属：[[07-报纸、出版社|07 报纸、出版社]]（容器直属支线，落 `raw/articles/02-出版社与出版业/`）。
> ⚠️ **序号不是类号**：支线序号 `02` 是**容器内序号**，与 UDC `02`（信息学）无关；本支线**不新增类号**，承容器 `07`（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 一、定位与边界

**收什么**

| 面 | 范围 | 典型问题 |
|:--|:--|:--|
| 机构 | 出版社的类型 · 资质 · 内部分工 | 这家社是什么性质 |
| 产品 | 图书作为商品：版本 · 印次 · 定价 | 这版是第几印 |
| 流程 | 选题 → 组稿 → 编校 → 印制 → 发行 → 回款 | 这本书卡在哪一环 |
| 权利 | 著作权归属 · 授权范围 · 版税与预付 | 版权在谁手上 |
| 经济 | 折扣 · 账期 · 退货 · 库存 | 卖一本能挣多少 |
| 制度 | 书号 · 在版编目 · 备案 · 审核 | 能不能合法出 |

| 著作权法条文 · 侵权诉讼 | [[34-法律\|34 法律]] | 本支线只给结构，不给法律意见 |
| 报纸 · 新闻生产 · 采编流程 | `01-报纸与新闻业`（已建壳） | 同为容器支线，对象不同 |

## 三、三层对象

| 层 | 对象 | 观察点 | 常见混淆 |
|:--|:--|:--|:--|
| 产品 | 一本有 ISBN 的书（及其版本、印次） | 版次 · 印次 · 定价 · 装帧 | 把「重印」当「新版」 |
| 机构 | 一家出版社 | 资质 · 主办主管 · 编辑规模 · 出书结构 | 把「策划公司」当「出版社」 |
| 制度 | 书号申领、在版编目、内容审核 | 书号来源 · CIP · 备案 | 把「有书号」当「内容已审」 |

**近邻四辨**

| 对比 | 判据 |
|:--|:--|
| 出版社 vs 印刷厂 | 前者**选题与内容责任**，后者**受托印制**，不承担内容责任 |
| 出版社 vs 民营策划机构 | 是否有**出版资质与书号申领权**；策划机构通常只做选题与编辑，挂靠出版 |
| 图书 vs 期刊 | 图书有 ISBN 与版次，期刊有 ISSN 与卷期 |
| 正式出版 vs 内部资料 | 是否有 ISBN / 公开发行；内部资料不得公开销售 |

> ⚠️ **有书号不等于有编辑**：书号是行政许可结果，编辑质量是另一回事，两者须分别判断。

## 四、机构类型谱十类

| 类型 | 特征 | 判读要点 |
|:--|:--|:--|
| 大众出版社 | 面向一般读者，品种多 | 畅销依赖度 · 退货率 |
| 教育 / 教材出版社 | 教材教辅，发行靠系统征订 | 是否依赖行政渠道 |
| 学术出版社 | 专著与论文集，读者窄 | 印量小 · 是否有出版资助 |
| 专业 / 科技出版社 | 面向行业，工具书与标准 | 作者与审稿专家资质 |
| 大学出版社 | 隶属高校，兼学术与教材 | 学术委员会是否真审 |
| 少儿出版社 | 童书与绘本 | 年龄段划分 · 插画版权 |
| 工具书 / 辞书出版社 | 字典、年鉴、手册 | 修订周期 · 编纂委员会 |
| 独立出版 / 小出版社 | 品种少，选题偏 | 资金链 · 发行渠道 |
| 自助出版 / 自出版平台 | 作者付费，平台提供书号与印制 | **谁在审、审不审** |
| 版权代理 / 出版服务商 | 代理版权或承接编印 | 责任主体是谁 |

> ⚠️ **「出版服务」常是模糊地带**：须问清谁申报选题、谁署出版单位、谁承担内容责任。

## 五、出版链：九个环节与各自的卡点

| 环节 | 做什么 | 卡点 / 风险 |
|:--|:--|:--|
| 1 选题 | 市场判断、选题论证会 | 选题会是否真论证，还是背书 |
| 2 签约 | 授权范围、版税、交稿期 | 授权范围写窄写宽，后续纠纷源头 |
| 3 组稿 / 写作 | 作者交稿、翻译、插图 | 交稿延期与质量不符 |
| 4 审稿 | 三审（初审 · 复审 · 终审） | 三审是否由不同人实质完成 |
| 5 编辑加工 | 文字编辑 · 校对（三校） | 编校差错率是硬指标 |
| 6 设计排版 | 封面 · 版式 · 字体授权 | 字体与图片版权 |
| 7 印制 | 印厂招标 · 印数决策 | **印数决定库存风险** |
| 8 发行 | 主渠道 · 电商 · 馆配 · 直销 | 折扣与账期 |
| 9 回款与重印 | 结算 · 退货 · 加印或报废 | 退货率与资金周转 |

> ⚠️ **印数是出版业最关键的赌注**：印多了压库存，印少了断货，且**决策常在信息最少时做出**。
> ⚠️ **三审三校是制度，不是口号**：判断时看是否留下可核的记录，而不是看封面上的声明。

## 六、书号与元数据

| 项 | 作用 | 判读要点 |
|:--|:--|:--|
| ISBN | 图书的唯一标识（含国别 / 出版者 / 书名 / 校验位） | 同一书的不同装帧可有不同 ISBN |
| 在版编目（CIP） | 出版前的分类与著录数据 | CIP 数据错，会影响检索与馆藏 |
| 条码 | 销售结算用 | 与 ISBN 一致，重印不改 |
| 版本 / 印次 | 区分内容修订与单纯加印 | **重印 ≠ 修订** |
| 定价与印张 | 定价常按印张与装帧档次定 | 同一书不同版本定价不可比 |
| ONIX 等元数据 | 向渠道传递书目信息 | 元数据缺失直接降低上架率 |

> ⚠️ **书号是行政许可，不是内容质量证明**：它只说明「可公开出版」，不说明「内容经得起检验」。

## 七、版权与授权

| 权利项 | 内容 | 常见争议 |
|:--|:--|:--|
| 复制发行权 | 纸质出版的专有 / 非专有 | 是否**专有**、期限多长 |
| 翻译权 | 译本出版 | 原文授权与译本授权是两层 |
| 数字权利 | 电子书、数据库、有声 | 旧合同常未约定，形成空白 |
| 衍生权 | 影视、文创、课程 | 是否一并授予 |
| 汇编 / 摘编 | 选集、教材选用 | 合理使用的边界 |
| 版税 | 按定价 × 版税率 × 销量 | 按**定价**还是**实洋**结算差别极大 |

**三种结算结构**

- **版税制**：按销量结算，作者承担部分市场风险
- **买断制**：一次性付酬，作者不参与后续
- **预付 + 版税**：预付可回收（royalty advance），未销完不予结算

> ⚠️ **「按定价还是按实洋」是版税合同的第一道分水岭**：折扣越深，两种算法差距越大。
> ⚠️ **本支线不给合同建议**：条款效力与纠纷处理归 [[34-法律|34 法律]]。

## 八、定价与折扣结构

| 环节 | 典型结构 | 谁承担 |
|:--|:--|:--|
| 定价 | 按印张 / 同类书 / 心理价位 | 出版社 |
| 发货折扣 | 定价的若干折给渠道 | 出版社让利 |
| 渠道返点 / 促销 | 满减、榜单费、坑位费 | 通常由出版社承担 |
| 账期 | 发货后数月结算 | 出版社垫资 |
| 退货 | 未售部分可退 | 出版社承担库存与物流 |
| 实洋 | 定价 × 实际折扣 × 实际销量 | **这才是收入** |

> ⚠️ **码洋是虚的，实洋才是钱**：用码洋谈规模，等于用标价谈营收。
> ⚠️ **高定价 + 高折扣**是常见组合：账面好看，回款难看。

## 九、渠道与发行

| 渠道 | 特点 | 风险 |
|:--|:--|:--|
| 主渠道（新华等） | 覆盖广、账期长 | 铺货容易、动销缓慢 |
| 电商平台 | 流量集中、折扣战 | 价格体系被击穿 |
| 实体书店 | 陈列与体验 | 上架费与退货 |
| 馆配 | 面向图书馆招标 | 折扣极低、账期长 |
| 直销 / 团购 | 毛利高 | 依赖特定关系 |
| 自营网店 / 私域 | 数据自有 | 流量成本 |
| 电子书平台 | 边际成本近零 | 分成比例与定价权 |

> ⚠️ **「上架」不等于「动销」**：铺货量、动销率、退货率三个数要一起看。

## 十、编辑角色与出版伦理

| 角色 | 职责 | 常见越界 |
|:--|:--|:--|
| 策划编辑 | 选题与作者资源 | 为畅销牺牲审稿 |
| 文字编辑 | 结构、文字、事实核对 | 代写、代改到失真 |
| 校对 | 校异同、校是非 | 只校错字不校事实 |
| 复审 / 终审 | 内容与导向把关 | 形式签字 |
| 美术 / 技术编辑 | 封面与版式 | 图片与字体授权不清 |

**伦理四问**

1. **署名是否真实** —— 挂名主编、代写、AI 生成内容是否披露
2. **引用是否可回溯** —— 参考文献是否真被读过
3. **重复出版是否披露** —— 旧稿改头换面是否说明
4. **资助关系是否公开** —— 资助方是否影响结论

> ⚠️ **学术不端的查处主体是作者单位与期刊，不是出版社**；但出版社的审稿是最后一道可拦阻的关口。

## 十一、数字出版与开放获取

| 形态 | 机制 | 关键问题 |
|:--|:--|:--|
| 电子书 | 授权平台销售 | 分成比例 · 定价权 |
| 有声书 | 改编与演播 | 改编权与演播者权利 |
| 数据库 / 知识服务 | 机构订阅 | 与纸书是否重复授权 |
| 开放获取（OA） | 作者或机构付费，读者免费 | **谁付、付多少、审稿是否独立** |
| 按需印刷（POD） | 一册起印 | 单册成本高，但零库存 |
| 自出版平台 | 作者自费全流程 | 无第三方审稿 |

> ⚠️ **OA 不等于无成本**：成本从读者端移到作者端或机构端，**付费方改变议程**。

## 十二、指标误用

| 指标 | 看似说明 | 实际扭曲 |
|:--|:--|:--|
| 码洋 | 经营规模 | 折扣与退货未扣除 |
| 品种数 | 出版能力 | 鼓励铺品种、稀释编辑力 |
| 印数 | 市场需求 | 铺货与压货难区分 |
| 榜单排名 | 畅销程度 | 榜单可购买、口径不一 |
| 退货率 | 渠道效率 | 也可反映铺货过度 |
| 编校差错率 | 质量 | 抽查样本与口径决定结果 |
| 获奖数 | 学术水平 | 评奖取向与申报能力 |

> ⚠️ **出版业最常见的自欺是用码洋谈业绩、用品种谈实力**。

## 十三、中国语境

| 项 | 要点 |
|:--|:--|
| 出版资质 | 设立出版单位须审批，实行主管主办制度 |
| 书号申领 | 书号实名申领，与选题绑定；**买卖书号属违规** |
| 三审三校 | 制度性要求，须留痕 |
| 重大选题备案 | 特定题材须履行备案程序 |
| 民营策划 | 可做选题与编辑，但须与有资质出版社合作 |
| 教材教辅 | 目录与征订受行政体系约束 |
| 图书零售 | 电商折扣长期低于实体店，价格体系承压 |
| 馆配招标 | 折扣低、账期长，是学术书的重要出口 |
| 出版基金 | 学术著作常依赖各类资助，须披露 |
| 走出去 / 引进版 | 版权贸易逆差与引进结构长期受关注 |

> ⚠️ **「合作出版」是最需要问清的说法**：谁署名、谁申报、谁承担内容与法律责任的答案可能不一致。

## 十四、判读六步与三条纪律

**六步**

1. **看版权页** —— 出版社 · 书号 · 版次印次 · 印数 · 定价
2. **看 CIP 数据** —— 分类与著录是否与内容相符
3. **看编辑记录** —— 有无责任编辑、复审终审署名
4. **看授权链条** —— 译本、图片、字体是否有授权说明
5. **看资助披露** —— 资助方与致谢是否明确
6. **看渠道与折扣** —— 定价与常见售价的差距，推测折扣结构

**三条纪律**

- **不用码洋判断影响力**：先换算实洋与销量
- **不把书号当质量证明**：书号只证明可公开出版
- **不评价个案是非**：只判读流程、资质与利益结构

## 十五、病理八项

| 病理 | 表现 | 后果 |
|:--|:--|:--|
| 书号寻租 | 买卖书号、变相挂靠 | 内容责任虚置 |
| 三审空转 | 签字齐全、无人真读 | 差错与风险外溢 |
| 品种膨胀 | 为凑规模大量低质品种 | 编辑力被稀释 |
| 折扣击穿 | 长期低价促销 | 实体渠道萎缩、定价失真 |
| 库存堆积 | 印数决策失准 | 资金沉淀、报废 |
| 版税不清 | 按定价 / 实洋混用 | 作者信任崩塌 |
| 挂名与代写 | 名人署名、代笔 | 学术与公信受损 |
| 元数据缺失 | 书目信息不全 | 上架率与可发现性下降 |

> ⚠️ **出版业的失信往往不是某一本书出错，而是流程签字齐全却无人负责**。

## 十六、核心问题

任何一本正式出版物，先问三句：

1. **谁出的** —— 出版单位是谁、有无资质、责任编辑是谁
2. **凭什么** —— 书号与 CIP 是否真实、选题是否备案、授权是否完整
3. **钱怎么分** —— 定价与折扣结构、版税按什么基数、谁承担退货
