# 03 新闻学与传播

> **UDC 07 / DDC 070** — 本支线处理**理论层**问题：新闻为什么有力量（**效果**）· 报道如何被组织成意义（**框架与话语**）· 媒介自身如何改变社会（**媒介化**）· 评价新闻该用什么标准（**规范理论**）· 这些主张凭什么成立（**证据与方法的边界**）。
> 归属判据一句话：**问「这条报道为什么这样呈现、为什么有人信、凭什么说它有影响」，而不是「这一版谁定的稿、卖了多少份」。**
> 所属：[[07-报纸、出版社|07 报纸、出版社]]（容器直属支线，落 `raw/articles/03-新闻学与传播/`）。
> ⚠️ **序号不是类号**：支线序号 `03` 是**容器内序号**，与 UDC `03`（综合参考资料）无关；本支线**不新增类号**，承容器 `07`（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 三、四个研究取向

| 取向 | 问什么 | 代表传统 | 局限 |
|:--|:--|:--|:--|
| 效果 | 媒介对认知与态度做了什么 | 宣传研究 · 有限效果 · 议程设置 | 易把相关当因果 |
| 文本 | 报道如何构造意义 | 符号学 · 框架 · 话语分析 | 易滑向批评者的立场 |
| 生产 | 组织与常规如何塑造内容 | 把关 · 新闻社会学 | 易忽略受众与技术 |
| 接受 | 读者如何解码与使用 | 使用与满足 · 编码 / 解码 | 易高估受众自主性 |

> ⚠️ **四个取向不能互相替代**：用文本分析证明「读者被影响」，或用效果数据证明「报道有偏向」，都是**跨层越界**。

## 四、核心概念谱

| 概念 | 说的是 | 常见误用 |
|:--|:--|:--|
| 议程设置 | 媒介影响**议题重要性排序**，不必然改变态度 | 被说成「媒介告诉你怎么想」 |
| 框架 | 选择与凸显某些面向，形成解释路径 | 与「立场」混为一谈；框架可中性分析 |
| 把关 | 内容在多环节被筛选 | 被简化为「审查」 |
| 沉默的螺旋 | 感知意见气候影响表达意愿 | 跨语境直接套用，忽略测量条件 |
| 涵化 | 长期接触塑造世界观 | 用单次接触推断长期效果 |
| 使用与满足 | 受众主动选择媒介满足需求 | 被当作「效果不存在」的挡箭牌 |
| 编码 / 解码 | 编码意图与解读可错位 | 把「误读」当读者失误 |
| 媒介化 | 媒介逻辑渗透其他社会领域 | 概念通胀，什么都能叫媒介化 |
| 公共领域 | 理性批判性讨论的空间 | 忽略准入不平等 |
| 第四权力 | 媒介对权力的监督角色 | 当作事实描述，而非规范主张 |

> ⚠️ **概念不等于论证**：贴上「框架」标签，不构成对框架的分析。

## 五、传播模型与范式

| 模型 | 结构 | 被批评之处 |
|:--|:--|:--|
| 线性（传输） | 发送者 → 讯息 → 渠道 → 接收者 → 效果 | 忽略反馈与意义协商 |
| 互动 | 加入反馈回路 | 仍以「传递信息」为核心 |
| 仪式观 | 传播是**共同体的维系**，非仅信息传递 | 难做因果检验 |
| 网络 / 平台 | 多向、算法中介、可测量 | 测量的是行为痕迹，不是意义 |

> ⚠️ **范式选择决定结论形态**：仪式观问「共享了什么」，效果研究问「改变了多少」——问题不同，不能互相否定。

## 六、客观性之争

**客观性作为职业规范**：产生于通讯社需向不同立场客户供稿的处境，核心是**可验证性**，不是「无立场」。

| 主张 | 内容 | 反驳 |
|:--|:--|:--|
| 事实与意见分离 | 报道事实，评论另置 | 选择与排序本身即判断 |
| 平衡报道 | 呈现多方 | 可能造成「虚假对等」 |
| 中立语言 | 避免评价性词汇 | 词汇的中立性本身受文化制约 |
| 可验证性 | 结论可被他人复核 | 这是**方法规范**，非立场保证 |

> ⚠️ **更站得住的替代标准**：不是「有没有立场」，而是**立场是否公开 · 证据是否可复核 · 结论是否与证据相称**。

## 七、怎么读一篇报道（框架分析六问）

1. **命名** —— 用了哪个词指称当事人（「抗议者」还是「暴徒」）
2. **归因** —— 把原因归于个人、制度还是偶发
3. **引语** —— 谁被引、引了哪一句、谁没有声音
4. **排序** —— 什么放在前面，什么放在末尾
5. **视觉** —— 配图、图说、版面位置带来的暗示
6. **缺席** —— 谁完全不在报道里

> ⚠️ **缺席是最难被发现的偏向**：不是写错了什么，而是**根本没有人被问到**。

## 八、受众与效果研究

| 阶段 | 核心主张 | 方法 | 问题 |
|:--|:--|:--|:--|
| 强效果（早期） | 媒介可直接塑造态度 | 宣传效果观察 | 样本与情境受限 |
| 有限效果 | 中介因素削弱效果 | 调查 · 面板 | 低估长期与累积 |
| 回归（议程 / 涵化） | 长期与认知层面有效果 | 内容 + 调查结合 | 因果识别困难 |
| 使用与满足 | 受众按需求选择 | 问卷 | 自陈偏差 |
| 平台时代 | 效果与分发逻辑耦合 | 日志 · 实验 | 平台数据不可得 |

> ⚠️ **「有影响」与「有多大影响」是两个问题**：多数争议错在把前者当后者。

## 九、传播伦理与规范理论

**四类规范传统**（报刊四种理论及其后续修订）

| 传统 | 媒介位置 | 主要约束 |
|:--|:--|:--|
| 权威主义 | 服务于既有秩序 | 事前许可 |
| 自由至上 | 自由市场中的观点竞争 | 事后追责 |
| 社会责任 | 自由伴随义务 | 职业规范与自律 |
| 苏联式 | 服务于特定目标 | 组织化引导 |

**伦理五原则**（可作判读标尺）

- **真实**：可核，不虚构
- **公正**：给被指控者回应机会
- **最小伤害**：只披露必要信息
- **独立**：不受利益方干预
- **问责**：有更正与申诉机制

> ⚠️ **规范理论是「应该怎样」，不是「实际怎样」**：用它评价现实时，须说明评价标准，而不是把它当事实描述。

## 十、平台与算法传播

| 现象 | 常见断言 | 证据状况 |
|:--|:--|:--|
| 过滤气泡 | 人只看得到同温层 | 实证结果混杂，多数用户仍接触多元信息 |
| 回音室 | 观点在同质群体中强化 | 与「气泡」常被混用，机制不同 |
| 注意力经济 | 注意力成为稀缺资源 | 解释力强，但易滑向万能解释 |
| 算法把关 | 分发即新的把关 | 与「编辑把关」的问责结构不同 |
| 情绪传播 | 愤怒更易扩散 | 平台与样本差异大 |

> ⚠️ **不要把流行断言当结论**：「过滤气泡」在研究中远未定论；引用时须给出证据条件。

## 十一、指标与方法的误用

| 做法 | 问题 |
|:--|:--|
| 用内容分析推断效果 | 跨层越界：文本 ≠ 接受 |
| 用调查自陈测量曝光 | 记忆偏差 |
| 用平台数据代表公众 | 平台用户非总体 |
| 把相关性叙述为影响 | 需排除反向因果与共同原因 |
| 单案例外推为结构 | 个案说明可能性，不说明普遍性 |
| 用「传播力指数」排名 | 指标构造不透明，权重任意 |

> ⚠️ **方法决定可说的范围**：没有对照组，就不该谈因果。

## 十二、中国语境

| 项 | 要点 |
|:--|:--|
| 马克思主义新闻观 | 党性与人民性统一，作为规范框架 |
| 宣传体制 | 分级管理、口径与通稿机制 |
| 舆论监督 | 有制度空间，边界随议题与时期变化 |
| 媒体融合 | 传统媒体与平台化分发结合，县级融媒体为典型 |
| 网络治理 | 平台责任、内容审核、实名制等制度安排 |
| 国际传播 | 「讲好中国故事」框架下的对外传播能力建设 |
| 学术传统 | 新闻学与传播学分立，近年交叉增多 |
| 数据可得性 | 平台数据、行业数据获取受限，影响实证研究 |

> ⚠️ **规范框架与经验研究不是一回事**：前者规定「应当如何报道」，后者回答「实际如何传播」，混用会使结论失去检验条件。

## 十三、判读六步与三条纪律

**六步**

1. **看主张类型** —— 描述性（发生了什么）/ 规范性（应当如何）/ 因果性（导致什么）
2. **看层级** —— 文本 · 生产 · 接受 · 技术，是否在同一层内论证
3. **看证据** —— 样本、时间、对照、来源可得性
4. **看概念** —— 用的是哪个定义，是否前后一致
5. **看反例** —— 作者是否处理了不利证据
6. **看立场** —— 规范性主张是否明示

**三条纪律**

- **不跨层论证**：文本分析不证明效果，效果数据不证明偏向
- **不把个案当结构**：一个案例说明可能性，不说明普遍规律
- **不用术语替代论证**：贴上「框架」「媒介化」不构成分析

## 十四、病理八项

| 病理 | 表现 | 后果 |
|:--|:--|:--|
| 概念通胀 | 什么现象都叫「媒介化」「景观」 | 概念失去分辨力 |
| 跨层越界 | 用文本推断效果 | 结论不可检验 |
| 因果倒置 | 把相关当影响 | 政策与判断失误 |
| 抽样偏差 | 只研究可得样本 | 结论不可外推 |
| 单案例外推 | 以个案定性整体 | 过度概括 |
| 规范混淆 | 把「应当」说成「就是」 | 论证偷换 |
| 万能解释 | 一切归于「资本」「算法」 | 停止追问具体机制 |
| 数据崇拜 | 有数字就当地证据 | 忽略构造与口径 |

> ⚠️ **理论最有用的地方是提出可被反驳的问题**；一旦什么都能解释，它就不再解释任何事。

## 十五、核心问题

任何一条关于新闻与传播的主张，先问三句：

1. **在说哪一层** —— 文本、生产、接受，还是技术
2. **凭什么** —— 样本、对照、定义、反例是否处理
3. **是描述还是规范** —— 「实际如何」与「应当如何」是否被混用
