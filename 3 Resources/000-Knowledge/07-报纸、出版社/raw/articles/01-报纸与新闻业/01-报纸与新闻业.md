# 01 报纸与新闻业

> **UDC 07 / DDC 070** — 本支线处理**报纸这一客体**与**新闻生产这一行当**：报纸是什么、分哪些种（**形态谱**）· 一条新闻如何从事件变成版面（**生产链**）· 谁有权决定上不上、怎么上（**编辑权与所有权**）· 靠什么活（**报业经济**）· 出错怎么办（**更正与伦理操作**）。
> 归属判据一句话：**问「这张报纸怎么做出这一版、谁决定的、凭什么」，而不是「新闻为什么能影响人、媒介权力是什么」。**
> 所属：[[07-报纸、出版社|07 报纸、出版社]]（容器直属支线，落 `raw/articles/01-报纸与新闻业/`）。
> ⚠️ **序号不是类号**：支线序号 `01` 是**容器内序号**，与 UDC `01`（目录学）无关；本支线**不新增类号**，承容器 `07`（见 [[_meta/architecture/adr/ADR-010-两级编号契约与DDC-UDC缝隙裁决规则|ADR-010]]）。

## 一、定位与边界

**收什么**

| 面 | 范围 | 典型问题 |
|:--|:--|:--|
| 形态 | 报纸的类型 · 刊期 · 开张 · 受众定位 | 这是党报、都市报还是行业报 |
| 生产 | 选题 → 采访 → 写作 → 编辑 → 审稿 → 排版 → 付印 | 这一版是谁定的稿 |
| 编辑权 | 发行人 / 总编 / 编辑 / 记者的权限边界 | 撤稿是谁拍的板 |
| 经济 | 发行 · 广告 · 订阅 · 付费墙 · 成本结构 | 它靠什么活着 |
| 伦理操作 | 核实 · 更正 · 匿名源 · 隐私 · 图像处理 | 这条消息源够不够 |
| 法域位置 | 名誉 · 隐私 · 消息源保护 · 报道限制 | 能不能写、写到什么程度 |

**不收什么**

| 主题 | 去向 | 理由 |
|:--|:--|:--|
| 新闻理论 · 传播学 · 媒介批评 · 框架分析 | `03-新闻学与传播`（待建） | 那是**理论层**，本支线是**实务层** |
| 出版社 · 图书出版 · 版权贸易 | `02-出版社与出版业`（待建） | 同为容器支线，对象不同 |
| 印刷工艺 · 排版技术 · 装订 | 容器 `600-Technology`（`655-印刷出版`） | 工艺归技术 |
| 期刊 · 连续出版物著录 | `05-连续出版物、期刊` | 著录与刊期体系另库 |
| 书目 · 编目 · 检索 | [[01-目录学\|01 目录学]] · [[02-信息学\|02 信息学]] | 文献组织 |
| 平台算法 · 推荐系统 | [[02-信息学\|02 信息学]] · [[004.8-人工智能\|004.8 人工智能]] | 技术机制 |
| 具体诉讼的胜负 · 合规结论 | [[34-法律\|34 法律]] | 本支线只给结构，不给法律意见 |

> 📌 **切分要点**：**「这一版是怎么做出来的」归本支线**；**「新闻为什么有力量、媒介如何塑造认知」归 `03`**。同一条新闻，两边各记一面。实务问题先问流程与权限，理论问题才问效果与意义。

## 三、报纸是什么：三层对象

| 层 | 对象 | 观察点 | 常见混淆 |
|:--|:--|:--|:--|
| 产品 | 一份按期出版的印刷品 | 开张 · 版数 · 栏目 · 刊期 | 把「版面」当「内容」 |
| 机构 | 一家报社（编辑部 + 经营部 + 印厂） | 所有权 · 编制 · 收支 | 把「报社」当「记者」 |
| 制度 | 一套登记、刊号、采访资格的安排 | 刊号 · 主管主办 · 记者证 | 把「能办报」当「能采访」 |

**近邻四辨**

| 对比 | 判据 |
|:--|:--|
| 报纸 vs 期刊 | 刊期与装订：报纸多为大开张、不装订、周期短；期刊有封面与卷期 |
| 报纸 vs 通讯社 | 通讯社**供应**稿件，通常不直接面向大众发行 |
| 报纸 vs 门户 / 客户端 | 是否有**自采权与编辑责任**：聚合平台转载，责任在源头 |
| 报纸 vs 内部资料 | 是否公开发行、是否领刊号：内部资料不作公开报道依据 |

> ⚠️ **有版面不等于有采编**：整版转载、通稿汇编、企业软文，都不构成本报的新闻生产。

## 四、形态谱十类

| 类型 | 特征 | 判读要点 |
|:--|:--|:--|
| 党报 | 机关报，传达立场与政策 | 社论与通稿比例 · 版面序列 |
| 都市报 | 面向市民，重社会新闻与服务 | 广告依赖度 · 本地覆盖 |
| 晚报 / 早报 | 以出版时段切分读者场景 | 截稿时间决定新闻新鲜度 |
| 行业报 / 专业报 | 面向特定行业，重数据与政策 | 是否依赖被报道行业的广告 |
| 地方报 | 行政区域覆盖，重地方政务 | 与地方财政、宣传部门的关系 |
| 免费报 | 免费派发，全靠广告 | 发行量是否可核（赠阅≠购买） |
| 侨报 / 外文报 | 面向特定语言社群 | 双重议程：母国与居住国 |
| 地下报 / 另类报 | 非主流渠道，常无刊号 | 消息不可核，只能作史料 |
| 号外 / 特刊 | 非定期，事件驱动 | 与常规编辑流程的偏离 |
| 电子报 / 报纸客户端 | 纸版形态的数字化 | 「纸版停刊 + 转网」不等于停办 |

> ⚠️ **「转型为新媒体」是模糊说法**：须分开问——纸版是否停印 · 采编队伍是否保留 · 是否仍有原创采访。

## 五、新闻生产链：九个环节与各自的权力点

| 环节 | 做什么 | 权力点（谁能否决） |
|:--|:--|:--|
| 1 线索 | 通稿 · 热线 · 记者网络 · 监测 | 谁能上选题会 |
| 2 选题 | 定题、定角度、定篇幅 | 部门主任 / 编前会 |
| 3 采访 | 约访 · 取证 · 记录 | 采访对象的配合与拒绝 |
| 4 写作 | 结构 · 引语 · 事实排列 | 记者的框架选择 |
| 5 编辑 | 改稿 · 定标题 · 裁长度 | 责任编辑的删改权 |
| 6 审稿 | 事实复核 · 敏感点把关 | 审读 / 法务 / 宣传口径 |
| 7 排版 | 版面位置 · 字号 · 配图 | 版面编辑（**位置即权重**） |
| 8 付印 | 校对 · 印刷 · 分发 | 最后一道拦阻点 |
| 9 反馈 | 读者来信 · 更正要求 · 投诉 | 是否刊登更正 |

> ⚠️ **标题与位置常比正文更能定调**：同一条稿，头版头条与内页简讯是两种新闻。
> ⚠️ **撤稿往往发生在第 6 与第 8 环节之间**：了解流程，才知道「为什么这版空了」。

## 六、新闻价值的判定

| 要素 | 含义 | 滥用形态 |
|:--|:--|:--|
| 时新性 | 刚发生、正在发生 | 旧闻翻新、无由头重发 |
| 接近性 | 地理 / 心理上离读者近 | 本地小事放大为要闻 |
| 显著性 | 涉及名人、权力、大额 | 名人琐事挤占公共议题 |
| 重要性 | 影响人数与程度 | 被流量逻辑挤到次要位置 |
| 人情味 | 有具体的人与处境 | 煽情替代结构解释 |

**「什么不上报」同样有规律**

- 无具名消息源且无法交叉核实的指控
- 涉及未成年人身份的可识别信息
- 自杀的方法与细节（除非公共安全必需）
- 正在侦查中的案件细节（易妨碍程序）
- 纯粹私人领域且无公共利益的隐私

> ⚠️ **新闻价值不是「读者爱看」**：前四项是公共性判断，第五项才是可读性；次序颠倒即娱乐化。

## 七、消息源结构

| 层级 | 类型 | 核实要求 |
|:--|:--|:--|
| 一手 | 亲历者 · 原始文件 · 现场 | 记录可复现（时间、地点、在场人） |
| 二手 | 通稿 · 转载 · 研究报告 | 回溯到原始出处，注明转引 |
| 匿名 | 不愿具名者 | 编辑部内部须知道其身份；对外说明为何匿名 |
| 官方 | 通报 · 发布会 · 公文 | 注意「通报 ≠ 定论」，程序阶段要写清 |
| 数据 | 统计 · 年报 · 数据库 | 口径、年份、是否可比 |

**核实的三条操作底线**

1. **两个独立来源** —— 独立指互不引用、无共同上游。
2. **关键事实单点核** —— 人名、职务、数字、时间，逐项回源。
3. **预设立场自查** —— 若证据只支持一半结论，标题须相应收窄。

> ⚠️ **匿名源是最后手段，不是常规手段**：匿名保护的是**人身安全**，不是**不便具名**。

## 八、编辑权与所有权

| 角色 | 权力 | 边界 |
|:--|:--|:--|
| 发行人 / 社长 | 经营与人事 | 不应直接改稿 |
| 总编辑 | 终审、定调 | 对版面负最终责任 |
| 部门主任 | 选题与人力 | 不得越过编辑改事实 |
| 责任编辑 | 改稿、定标题 | 改动须让记者知情 |
| 记者 | 采访与写作 | 不得虚构、不得收受利益 |
| 经营 / 广告 | 销售版面 | **不得干预编辑内容** |

**编辑独立的三道防火墙**

- **组织**：编辑部与经营部分设，考核不交叉
- **流程**：广告与新闻的分界规则书面化（软文须显著标注）
- **财务**：广告主不得以撤单威胁影响报道（须有可追溯的处理记录）

> ⚠️ **「广告部说不能发」是本支线最该记录的一类事实**：它不是伦理瑕疵，而是**结构性干预**。

## 九、报业经济

| 收入 | 机制 | 结构性风险 |
|:--|:--|:--|
| 发行 | 订阅与零售 | 单价长期低于成本，靠量摊薄 |
| 广告 | 版面售卖 · 分类广告 | 广告主集中度高时，编辑独立性受挤压 |
| 付费墙 | 订阅制 · 计量制 | 强化「取悦订户」的选题偏移 |
| 活动与增值 | 论坛 · 榜单 · 培训 | **榜单与评奖易与广告混同** |
| 政府支持 | 补贴 · 采购 · 专项资金 | 依赖度决定批评空间 |

**成本结构为什么决定新闻形态**

- 固定成本高（采编人力）、边际成本低 → 规模是生死线
- 深度调查周期长、不确定 → 最先被砍
- 通稿与转载成本近零 → 同质化是经济学结果，不是懒惰

> ⚠️ **免费不等于无成本**：读者不付钱时，付费方就是广告主或财政，**议程权随之转移**。

## 十、伦理操作层

| 情形 | 常规做法 | 易错点 |
|:--|:--|:--|
| 事实错误 | 显著位置刊登更正，注明原文与更正内容 | 悄悄改网页不留痕迹 |
| 严重失实 | 撤稿并说明原因 | 只删不说明 |
| 隐私 | 只写与公共利益相关的部分 | 披露住址、就医细节 |
| 未成年人 | 隐去身份可识别信息 | 化名仍可反推 |
| 自杀 | 不写方法、不渲染细节 | 引语复述方法 |
| 图像 | 不摆拍、不拼接改变事实；示意图须标注 | 「示意」字样被裁掉 |
| 利益冲突 | 申报并回避相关选题 | 收受礼品、车马费不申报 |

> ⚠️ **更正的价值在于位置**：内页角落的一行更正，等于没有更正。

## 十一、法域位置（只给结构，不给结论）

| 议题 | 关键点 | 本支线不做什么 |
|:--|:--|:--|
| 名誉 / 诽谤 | 真实性与主观过错是核心争点 | 不判断个案胜负 |
| 隐私与个人信息 | 公共利益与最小必要 | 不给合规方案 |
| 消息源保护 | 采访材料与身份的留存风险 | 不承诺「绝对安全」 |
| 报道限制 | 程序阶段、涉案人员、特殊时期 | 不复述具体禁令 |
| 著作权 | 转载授权、图片使用 | 不代为取得授权 |

> ⚠️ **法规版本变动频繁**：条文以现行有效文本为准，本库只记结构，不提供法律意见。

## 十二、技术与形态变迁

| 阶段 | 技术条件 | 对新闻形态的影响 |
|:--|:--|:--|
| 铅排 / 活字 | 排版成本极高 | 版面固化，改版周期长 |
| 电传 / 传真 | 异地传版 | 全国版与地方版分叠 |
| 计算机排版 | 改版成本骤降 | 版数扩张、彩版普及 |
| 互联网 | 发布即时、无版面约束 | 「截稿时间」概念松动 |
| 移动端 | 阅读碎片化 | 标题与首图决定打开率 |
| 算法分发 | 平台决定可见性 | 采编让位于运营指标 |

> ⚠️ **形态变了，核实义务没变**：发布更快不等于标准更低。

## 十三、指标误用

| 指标 | 看似说明 | 实际扭曲 |
|:--|:--|:--|
| 发行量 | 影响力 | 赠阅、摊派可注水 |
| 点击 / 阅读量 | 传播力 | 标题党与情绪题收益更高 |
| 转发量 | 认同度 | 愤怒比认同更易转发 |
| 停留时长 | 内容质量 | 长文天然占优 |
| 稿件数量 | 生产率 | 鼓励碎片、抑制调查 |
| 获奖数 | 专业水平 | 评奖周期与选题取向绑定 |

> ⚠️ **单一指标必被优化**：考核什么，编辑部就生产什么。

## 十四、中国语境

| 项 | 要点 |
|:--|:--|
| 主管主办 | 报纸须有主管、主办单位，刊号与主体绑定 |
| 刊号 | 公开刊号与内部资料准印证不同，后者不作公开报道依据 |
| 党报体制 | 机关报的社论与通稿具有特定权威层级 |
| 都市报 | 1990 年代兴起，市场化程度较高，受属地管理 |
| 记者证 | 新闻记者证须核验；无证采访与「假记者」是两件事 |
| 新闻敲诈 | 以报道相要挟索取利益，属违法行为的常见形态 |
| 版权转载 | 网络转载须授权，聚合平台的责任划分仍在演化 |
| 自媒体 | 无采编资质，多为评论与整合，事实核验标准差异大 |
| 县级融媒体 | 整合县域媒体资源，兼有政务发布与本地新闻职能 |
| 报纸休刊 / 停刊 | 须区分休刊、停刊、转网，与「编辑部撤销」不是一回事 |

> ⚠️ **「有刊号」与「有采访权」不是同一件事**：前者是出版许可，后者与记者证、派遣关系相关。

## 十五、判读六步与三条纪律

**六步**

1. **看报头** —— 出版单位、主管主办、刊号、日期、版数
2. **看版面序列** —— 头版头条与内页分布，读出权重
3. **看消息源** —— 具名 / 匿名 / 通稿，能否回溯
4. **看标题与正文差** —— 标题是否超出正文证据
5. **看更正与追踪** —— 有无更正栏，有无后续报道
6. **看经营界面** —— 广告占比、软文标注、榜单来源

**三条纪律**

- **不把转载当原创**：先找源头，再谈可信度
- **不把单篇当编辑方针**：要看同一报纸一段时间内的选题分布
- **不评价个案是非**：只判读流程与证据，不裁决事实争议

## 十六、病理八项

| 病理 | 表现 | 后果 |
|:--|:--|:--|
| 通稿化 | 整版依赖统发稿 | 版面失去本地性 |
| 标题党 | 标题超出正文 | 信任一次性透支 |
| 匿名源滥用 | 关键指控无具名 | 无法追责、无法纠错 |
| 软文混同 | 广告未标注 | 读者无法分辨立场 |
| 更正缺失 | 只改网页不登更正 | 错误沉淀为「常识」 |
| 单一指标 | 以点击定生死 | 调查报道消失 |
| 采编经营混岗 | 记者拉广告 | 报道被交易 |
| 档案断裂 | 旧报未数字化 | 无法回溯，历史不可核 |

> ⚠️ **最严重的不是出错，是无法追溯**：没有档案与更正的报纸，等于没有可核查的记录。

## 十七、核心问题

任何一张报纸、一条新闻，先问三句：

1. **谁做的** —— 编辑部是谁、记者是否在编、有无采访权
2. **凭什么** —— 消息源能否回溯、关键事实是否交叉核实
3. **谁在付钱** —— 收入结构决定议程空间，免费往往意味着别处付费
