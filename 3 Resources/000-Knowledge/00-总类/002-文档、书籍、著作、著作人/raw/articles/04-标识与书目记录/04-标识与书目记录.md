# 04 标识与书目记录

> 本库第 04 章。第 03 章拆开一本书；本章回答：**如何用一个稳定的号码指认一份文档、一部著作、一个责任者**，以及这些号码如何进入书目记录。

## 一、标识要解决什么

| 需求 | 问题 | 失败后果 |
|:------|:------|:------|
| **指认**（identify） | 这是哪一份文档 | 同名混淆 · 张冠李戴 |
| **消歧**（disambiguate） | 两个相似名称是否指同一对象 | 重复记录 · 错误合并 |
| **定位**（locate） | 到哪里找到它 | 链接失效 · 馆藏错位 |
| **引用**（cite） | 如何让别人准确指向它 | 引文不可复核 |
| **关联**（link） | 它与其他对象是什么关系 | 版本谱系断裂 |

- 一个标识符很少同时满足五项；不同类型各有所长（ISBN 擅长指认出版单元，DOI 擅长解析与引用）。
- **标识 ≠ 地址**：地址会变，标识应当稳定；两者由「解析」机制连接。

## 二、标识符的六个属性

| 属性 | 含义 | 关键问题 |
|:------|:------|:------|
| **作用域**（scope） | 标识哪一类对象 | 著作？版本？副本？责任者？ |
| **唯一性** | 在作用域内不重复 | 由谁保证？注册机构还是本地 |
| **持久性**（persistence） | 对象存续期内保持有效 | 机构退出后是否仍可解析 |
| **粒度**（granularity） | 标识到多细 | 整本书 / 某一章 / 某一页 / 某一数据集 |
| **语法与校验** | 有无固定结构、校验位 | 能否离线识别录入错误 |
| **治理**（governance） | 谁分配、谁维护、谁付费 | 封闭注册 vs 开放解析 |

- **校验位**（check digit）是低成本的质量装置：ISBN-10 用模 11，ISBN-13 用模 10，ISSN 用模 11，ORCID 用模 11-2。
- **持久性不是永久性**：任何标识都依赖一个仍在运行的解析或登记机构。

## 三、标识对象的层级

把第 01 章的四层模型换成标识视角：

| 层级 | 标识对象 | 典型标识 |
|:------|:------|:------|
| **责任者** | 人 / 机构 | ORCID · ISNI · VIAF |
| **著作（work）** | 抽象内容单元 | ISTC（文本作品）· ISWC（音乐作品） |
| **版本 / 出版单元** | 一次编辑制作 | ISBN（图书）· ISMN（乐谱） |
| **载体 / 副本** | 某一册、某一文件 | 馆藏条码 · 本地登录号 · 文件哈希 |
| **内容位置** | 章节、图表、段落 | DOI 后缀 · 片段标识（fragment） |

- **越往下的标识越不稳定**：副本会丢失、重排、重新扫描；越往上的标识越抽象，越难与实际手里的东西一一对应。
- 同一对象可以有多套标识：一本书同时有 ISBN、馆藏号、DOI（电子版）、内部资产编号。

## 四、ISBN：出版单元的标识

ISBN（ISO 2108）标识**出版单元**——某出版社的某一版、某一装帧形态，而不是「这部著作」。

13 位结构（2007 年起）：

| 段 | 位数 | 含义 |
|:------|:------|:------|
| **GS1 前缀** | 3 | `978`（图书）或 `979` |
| **注册组** | 1–5 | 语言 / 国家 / 地区组（如 `7` 中国） |
| **出版者** | 1–7 | 出版者代码 |
| **出版物** | 1–6 | 该出版者内的序号 |
| **校验位** | 1 | 模 10 加权（1,3 交替） |

- **一个 ISBN 对应一种可独立销售的形态**：精装、平装、电子书通常各有 ISBN。
- **同一部著作可以有很多 ISBN**：不同出版社、不同版次、不同装帧、不同语种。
- **ISBN 不标识著作**：若要指认「作品本身」，需要 ISTC 一类作品级标识（实践中很少用）。
- ISBN-10 仍会出现在旧书与旧数据库里，转换时补 `978` 前缀并重算校验位。
- 边界：ISBN 的分配与元数据登记由出版者与 national ISBN agency 负责，编目规则归 [[3 Resources/000-Knowledge/01-目录学/01-目录学|01 目录学]]。

## 五、ISSN 与连续出版物

| 属性 | 说明 |
|:------|:------|
| **结构** | 8 位：7 位序号 + 1 位校验（模 11，可为 `X`） |
| **作用域** | **连续出版物**（期刊 · 报纸 · 年刊 · 丛书） |
| **分配对象** | 题名层级，不是单期 |
| **ISSN-L** | 把同一刊物的不同媒介版本（印刷 / 在线）关联到一个「连接 ISSN」 |

- **ISBN 管「一种书」，ISSN 管「一种刊」**：期刊的单期通常不单独编 ISBN。
- 电子刊与印刷刊各有 ISSN，通过 ISSN-L 关联。
- 丛书既有 ISSN（丛编），其中各册又各有 ISBN —— 两个层级并存。

## 六、其他内容标识

| 标识 | 标准 | 作用域 | 说明 |
|:------|:------|:------|:------|
| **ISMN** | ISO 10957 | 乐谱 | 13 位，以 `979-0` 开头 |
| **ISRC** | ISO 3901 | 录音制品 | 标识某一次录音，不是作品 |
| **ISWC** | ISO 15707 | 音乐作品 | 标识词曲作品本身 |
| **ISAN** | ISO 15706 | 视听作品 | 电影、电视、游戏 |
| **ISTC** | ISO 21047 | 文本作品 | 跨版本标识「同一部作品」，实践使用有限 |

- 这一层标识的共同难题：**作品边界的判定**（改编、译本、续作算不算同一作品）没有技术解，只有制度约定。
- 使用频率与制度支持高度相关：ISBN / ISSN / DOI 广泛使用，ISTC 等则较为边缘。

## 七、DOI：内容对象的持久标识

DOI（ISO 26324）是**Handle System** 之上的一层命名机制，用来标识内容对象并提供解析。

| 组成 | 说明 | 例子形态 |
|:------|:------|:------|
| **前缀**（prefix） | `10.` + 注册机构编号 | `10.1000` |
| **后缀**（suffix） | 由注册者自行分配 | `xyz123` |
| **解析** | 通过 `doi.org` 查询当前 URL | `https://doi.org/10.1000/xyz123` |

- **DOI 标识内容，不标识载体**：同一论文的 HTML 版与 PDF 版通常共用一个 DOI。
- **DOI 的承诺是「解析」，不是「内容正确」**：它保证你被带到登记方指定的位置，不保证内容未被篡改。
- **版本问题**：数据集、软件、预印本常用「版本化 DOI」或「概念 DOI + 版本 DOI」两套并存。
- **DOI ≠ URL**：URL 是地址，会失效；DOI 是名字，由解析服务转成当前地址。
- 边界：DOI 的注册、元数据与解析政策属出版与信息机构，本库只讨论它作为「文档标识」的性质。

## 八、持久标识与链接失效

| 机制 | 维护方 | 特点 |
|:------|:------|:------|
| **Handle** | CNRI | DOI 的底层；前缀 + 后缀，全球解析 |
| **ARK** | Internet Archive | 开放、可自建，带校验与「不哭」策略 |
| **PURL** | OCLC | 重定向型持久 URL |
| **URN / NBN** | 各国国家图书馆 | 国家书目号，如 `urn:nbn:...` |
| **内容哈希**（CID / checksum） | 去中心化网络 | 按内容寻址，内容变则标识变 |

- **链接失效（link rot）**是文档世界的慢性病；持久标识是制度性缓解，不是技术保证。
- **内容寻址**与**名称寻址**是两条路线：前者把「标识 = 内容指纹」，后者把「标识 = 稳定名字 + 解析」。
- 引用实践中，DOI / Handle 优于裸 URL；网页引用应附访问日期与存档副本。

## 九、责任者标识

| 标识 | 维护方 | 作用域 | 特点 |
|:------|:------|:------|:------|
| **ISNI** | ISNI International Agency | 公共身份（作者 · 表演者 · 机构） | 16 位；跨领域 |
| **ORCID** | ORCID 组织 | 研究者 | 16 位；与出版流程深度集成 |
| **VIAF** | OCLC | 名称规范档 | 聚合各国图书馆的规范记录，不是分配制 |
| **ResearcherID / Scopus ID** | 商业数据库 | 学者 | 平台内唯一，跨平台不通用 |

- 责任者标识的核心问题是**消歧**：同名、改名、机构变更、姓名转写差异。
- 标识解决的是「机器可区分」，不解决「学术责任如何分配」（后者见第 06–07 章）。
- 作者页面的稳定标识（ORCID）正在成为论文投稿与基金申请的必填项。

## 十、标识与书目记录

标识是书目记录的**主键**，记录是标识的**上下文**：

| 记录类型 | 标准 / 生态 | 用途 |
|:------|:------|:------|
| **MARC 21 / UNIMARC** | 图书馆编目 | 馆藏目录、联合目录 |
| **BIBFRAME** | 美国国会图书馆 | 用关联数据模型替代 MARC |
| **LRM / RDA** | IFLA / RDA 指导委员会 | 概念模型与著录规则，FRBR 的后继 |
| **Dublin Core** | DCMI | 15 个核心元素的通用元数据 |
| **schema.org / BibFrame Lite** | 搜索引擎生态 | 网页结构化数据 |
| **ONIX** | EDItEUR | 出版流通环节的元数据交换 |

- **标识回答「是哪一个」，记录回答「它是什么样」**：没有标识，记录无法去重；没有记录，标识无法解释。
- **模型演进**：FRBR（1998）→ LRM（2017），把「作品—表达—载体—副本」重新表述为「作品—表达—载体—个体」并加入「代理」。
- 本库只讨论标识在记录中的**角色与层级**；MARC 字段、著录细则、编目规则归 [[3 Resources/000-Knowledge/01-目录学/01-目录学|01 目录学]]。

## 十一、五个常见误读

1. **「ISBN 是书的身份证」** —— 它标识的是某一版、某一装帧的出版单元，不是著作，也不唯一对应一本书。
2. **「一本书只有一个 ISBN」** —— 精装、平装、电子版、不同版次通常各有 ISBN。
3. **「有 DOI 就一定打得开」** —— DOI 保证解析到登记方指定位置，不保证该位置长期可用。
4. **「链接就是标识」** —— URL 是地址，会变；标识需要独立的解析层。
5. **「标识唯一 = 对象唯一」** —— 标识只保证作用域内不重复，跨体系仍然可能指向同一对象。

## 本章要点

- 标识服务于**指认 · 消歧 · 定位 · 引用 · 关联**，一个标识很少同时满足全部。
- 评估标识看六属性：**作用域 · 唯一性 · 持久性 · 粒度 · 语法校验 · 治理**。
- 标识有层级：责任者 / 著作 / 版本 / 副本 / 内容位置；越往下越不稳定。
- **ISBN 标识出版单元**（一版一装帧），**ISSN 标识连续出版物**，各有校验位与分配机构。
- **DOI 是名称 + 解析**，保证解析不保证内容；URL 是地址，不能替代标识。
- 责任者标识（ORCID · ISNI · VIAF）解决机器消歧，不解决责任分配。
- 标识是书目记录的主键；MARC → BIBFRAME / LRM 的演进是模型演进，著录规则归 01 目录学。
