## 一、类型不是一个维度

「文档分几类」没有唯一答案，因为分类依赖**分类目的**。同一条文档可以同时在五个轴上被命名：

| 轴 | 取值示例 | 回答的问题 |
|:------|:------|:------|
| **载体形态** | 纸质 · 电子 · 实物 · 混合 | 它依附在什么介质上 |
| **生成方式** | 手写 · 印刷 · 原生数字 · 数字化 | 内容如何被写上去 |
| **职能地位** | 公文 · 私文书 · 出版物 · 记录 · 档案 | 它在业务或法律中扮演什么角色 |
| **使用场景** | 阅读 · 凭证 · 存档 · 交易 · 展示 | 谁、为何使用它 |
| **生命周期阶段** | 草稿 · 定稿 · 发布 · 归档 · 处置 | 它处在流转的哪一段 |

- 五个轴**相互独立**：一份扫描的合同同时是「电子」「数字化」「私文书」「凭证」「已归档」。
- 因此「文档类型」应说成**类型标签的组合**，而不是一棵互斥的分类树。
- 本章按「载体 → 生成 → 职能 → 生命周期」展开，最后回到真实性这一横切问题。

## 二、按载体形态

| 形态 | 典型例子 | 优势 | 脆弱点 |
|:------|:------|:------|:------|
| **纸质** | 信函 · 合同 · 书刊 · 手稿 | 无需设备即可读；物理痕迹可作证据 | 占空间 · 单点易毁 · 难检索 |
| **电子** | PDF · 网页 · 数据库 · 邮件 | 可复制 · 可检索 · 可远距离传输 | 依赖格式、软件、介质与电力 |
| **实物** | 标本 · 铭文 · 样品 · 模型 | 证据性强；不可替代 | 不可复制 · 难借阅 · 解释成本高 |
| **混合** | 带附件的合同 · 书 + 光盘 · 纸质 + 扫描件 | 各取所长；兼顾凭证与流通 | 版本配对困难；易出现「两份不一致」 |

- **Briet（1951）**的经典例子：一只被制成标本、编入目录、可供研究的羚羊，就是一份**文档**——载体是实物，文档性来自它被纳入的信息实践。
- 载体形态影响**使用成本**：纸质适合沉浸阅读与签署，电子适合检索与分发，实物适合证据与展陈。
- 「混合文档」的关键风险不是技术，而是**主副本判定**：哪一份是权威版本。

## 三、原生数字与数字化

| 类别 | 定义 | 典型例子 | 管理重点 |
|:------|:------|:------|:------|
| **原生数字**（born-digital） | 从未以实体形态存在 | 网页 · 电子邮件 · 电子表格 · 数字音视频 | 格式 · 日志 · 哈希 · 签名 |
| **数字化**（digitized） | 由实体原件转写而来 | 扫描件 · 翻拍照片 · 转录文本 | 转换链 · 分辨率 · 色彩 · OCR 误差 |

- **数字化不是复制，而是转写（transcription）**：每一次扫描或转录都包含取舍（分辨率、裁切、色彩管理、字符识别），都会丢失信息。
- 因此数字化产物必须与**原件**和**转换记录**一起理解：谁扫的、用什么设备、什么参数、是否 OCR、是否校勘。
- **扫描件 ≠ 原件**：在证据场景中，扫描件的证明力取决于能否回溯原件与转换过程（法律效力问题归 UDC 34 法律）。
- 原生数字文档没有「原件」这一物理锚点，其真实性只能靠**过程证据**维持（元数据、审计日志、数字签名、保管链）。

## 四、按职能与法律地位

| 类型 | 定义 | 与相邻概念的区别 |
|:------|:------|:------|
| **公文** | 机关、组织在公务活动中形成并使用的文档 | 强调**形成主体**与公务程序 |
| **私文书** | 个人或非公务主体形成的文档 | 与公文相对，不等于「私人秘密」 |
| **出版物** | 经编辑、复制并向公众发行的文档 | 强调**公开流通**与版本标识（详见第 08 章） |
| **记录**（record） | 作为业务活动**证据**而被保存的文档 | 关键词是「证据」与「业务过程」 |
| **档案**（archive） | 经鉴定、整理、长期保存的记录 | 关键词是「鉴定」与「长期保存」 |

- **同一文档在不同阶段身份不同**：一份合同在签约时是「凭证」，在履约期是「业务记录」，移交档案馆后成为「档案」。
- **record ≠ document**：不是所有文档都是记录，只有被纳入业务过程并作为证据留存的那部分才是。
- **档案 ≠ 旧文件**：档案的核心是**受控的原始记录性**（来源、次序、完整性），而不是「年头久」。
- **灰色文献**（报告 · 学位论文 · 会议资料 · 标准 · 预印本）处在出版与未出版之间，类型归属见第 05 章。

## 五、电子文档的载体条件

电子文档的可读性由三层共同保证，缺一层即失效：

| 层 | 内容 | 失效表现 |
|:------|:------|:------|
| **编码 / 格式** | 字节如何表示字符、版面、音视频 | 乱码 · 无法解析 · 版面错位 |
| **读取器** | 解释格式的软件（阅读器、播放器、数据库引擎） | 软件停产 · 许可失效 · 版本不兼容 |
| **运行环境** | 操作系统、硬件、字体、外部资源、DRM | 系统升级后打不开 · 字体缺失 · 授权服务器下线 |

常见风险与缓解：

| 风险 | 说明 | 缓解手段 |
|:------|:------|:------|
| **格式过时** | 专有格式随厂商退出而失传 | 采用开放、有公开规范、被广泛实现的格式 |
| **渲染漂移** | 同一文件在不同环境呈现不同 | 固定版式格式（如 PDF/A，ISO 19005）；保留渲染快照 |
| **外部依赖** | 字体、图片、链接、脚本存放在别处 | 自包含封装；记录依赖清单 |
| **比特腐坏** | 存储介质随时间产生静默错误 | 定期校验哈希；多副本异地保存 |

- 电子文档的「文档性」包含**呈现层**：同一份 HTML 在两种浏览器里可能是两份不同的文档体验。
- 长期可读的三条基本要求：**开放格式 · 自描述（含元数据）· 可校验（哈希与签名）**。
- 边界：具体格式规范与技术实现归 [[3 Resources/000-Knowledge/00-总类/00-总类|00 总类]]（数据格式）与 004 计算机科学；本库只讨论「作为文档载体时的性质」。

## 六、生命周期模型

一条常见的线性模型：

```
创建 → 使用 / 流转 → 归档 → 长期保存 → 处置
```

| 阶段 | 关键动作 | 典型失败 |
|:------|:------|:------|
| **创建** | 起草、命名、版本标识、元数据登记 | 命名随意、版本混乱、无元数据 |
| **使用 / 流转** | 传阅、签署、发布、引用 | 副本泛滥、修改不留痕 |
| **归档** | 鉴定、整理、著录、移交 | 「全部留着」或「到期即删」 |
| **长期保存** | 校验、迁移、仿真、封装 | 只做备份，不做迁移 |
| **处置** | 到期销毁或永久保存 | 无授权销毁；或该销毁的永久堆积 |

- **生命周期模型**（records life cycle）把文档看作有出生与死亡的过程；**连续体模型**（records continuum, Upward 1996）则强调「创建、捕获、组织、pluralize」四维**同时发生**，不按阶段排队。
- 两种模型不冲突：前者便于制度设计，后者便于理解「归档动作其实在创建时就已开始」。
- 生命周期中身份会变：草稿 → 定稿 → 发布件 → 记录 → 档案 → 历史文献；每一跳都可能改变**权威副本**与**访问权限**。

## 七、真实性与完整性

文档管理的四个经典质量（参照 ISO 15489 的记录管理原则）：

| 质量 | 含义 | 保障手段 |
|:------|:------|:------|
| **真实性**（authenticity） | 确系所称主体所形成 | 签名 · 保管链 · 来源元数据 |
| **可靠性**（reliability） | 内容可信地代表所涉事务 | 形成过程受控 · 审核痕迹 |
| **完整性**（integrity） | 内容与结构未被未授权改动 | 哈希校验 · 版本控制 · 访问审计 |
| **可用性**（useability） | 可被定位、检索、呈现 | 著录 · 格式迁移 · 索引 |

- **固定性（fixity）**：用哈希值证明「字节未变」；它是完整性的技术底线，但不证明内容为真。
- **迁移会改变字节，但不改变文档同一性**：只要迁移过程被记录（provenance），迁移后的副本仍是「同一文档」的可信副本。
- **备份 ≠ 保存**：备份防的是事故，保存防的是**格式与介质的长期失效**；两者目标不同。
- 数字签名的技术机制归 004，其法律效力归 34 法律；本库只讨论它作为「真实性证据」的角色。

## 八、五个常见误读

1. **「文档就是纸」** —— 电子文件、实物标本、数据集同样是文档；载体不是判据。
2. **「数字化就是复制」** —— 数字化是带取舍的转写，必然有损，且依赖转换参数。
3. **「扫描件等于原件」** —— 证明力取决于能否回溯原件与转换链。
4. **「有备份就等于保存好了」** —— 备份防事故，不防格式过时与介质老化。
5. **「档案就是旧文件」** —— 档案是受控的原始记录，核心是来源与完整性，不是年龄。

## 本章要点

- 文档类型是**多轴标签的组合**，不存在唯一的互斥分类树。
- 载体分纸质 / 电子 / 实物 / 混合；混合文档的核心问题是**权威副本判定**。
- 数字化是**有损转写**，必须与原件和转换记录一起理解；原生数字文档靠过程证据维持真实性。
- 记录是「作为证据保存的文档」，档案是「经鉴定并长期保存的记录」；二者都不是材质或年龄概念。
- 电子文档的可读性 = 格式 + 读取器 + 运行环境；长期保存要求开放格式、自描述、可校验。
- 生命周期模型（线性）与连续体模型（多维）互补；真实性、可靠性、完整性、可用性构成四类质量。
