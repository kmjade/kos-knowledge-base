## 一、为什么类型重要

「著作类型」不是图书馆员的癖好，它决定了四件事：

| 决定项 | 说明 | 例子 |
|:------|:------|:------|
| **评价标准** | 不同类型按不同尺子衡量 | 论文看创新与可复现；标准看共识与可执行 |
| **发表路径** | 类型决定投到哪里、经过什么审查 | 期刊同行评议 vs 机构内部审阅 |
| **引用格式** | 引用条目需要类型标识 | `[J]` 期刊 · `[R]` 报告 · `[S]` 标准 · `[D]` 学位论文 |
| **生命周期** | 类型决定更新与撤稿方式 | 期刊论文有撤稿；标准有版本替代；数据集有版本号 |

- 类型是**制度约定**，不是本体论分类：同一份文本换一个发表渠道，类型就可能改变。
- 类型判断的核心是**创作方式 + 审查机制 + 流通渠道**三者的组合。

## 二、分类的四个轴

| 轴 | 取值 | 影响 |
|:------|:------|:------|
| **创作方式** | 原创 · 编纂 · 翻译 · 改编 · 汇编 | 责任归属与著作权形态 |
| **审查机制** | 同行评议 · 编辑审稿 · 机构审阅 · 无审查 | 可信度预期与证据等级 |
| **流通渠道** | 期刊 · 会议 · 图书 · 报告系列 · 预印本平台 · 数据仓库 | 获取方式与可引用性 |
| **发表状态** | 未发表 · 预印本 · 已接收 · 正式发表 · 撤稿 | 版本关系与引用选择 |

- 四个轴**相互独立**：一份会议论文可以是同行评议、正式发表、汇编成册。
- 因此「类型」应理解为**标签组合 + 制度约定**，而不是单棵分类树（与第 02 章的多轴类型观一致）。

## 三、学术类著作

| 类型 | 典型审查 | 典型载体 | 说明 |
|:------|:------|:------|:------|
| **期刊论文**（journal article） | 同行评议 | 学术期刊 | 原创研究 · 综述 · 短讯 · 病例报告等子类型 |
| **会议论文**（conference paper） | 程序委员会评议 | 会议录（proceedings） | 全文 · 短文 · 海报；学科差异极大 |
| **专著**（monograph） | 出版社审稿 | 图书 | 单一作者或团队，系统论述一个主题 |
| **编著**（edited volume） | 出版社审稿 | 图书 | 编者组织多作者章节，章节各有作者 |
| **图书章节**（book chapter） | 编者 + 出版社 | 编著中的一章 | 常被单独引用 |
| **学位论文**（thesis / dissertation） | 答辩委员会 | 机构库 | 未正式出版，属灰色文献 |
| **预印本**（preprint） | 平台筛查（非同行评议） | 预印本服务器 | 发表前的公开版本 |
| **工作论文**（working paper） | 机构内部 | 系列出版物 | 经济学等领域的常见形态 |

- **子类型差异不可忽略**：综述（review）与原创研究（original article）的贡献性质不同；短讯（letter）与全文的证据量不同。
- **学科惯例不同**：计算机科学的顶级会议在评价上常等同于甚至高于期刊；人文社科则以专著与期刊论文为主。
- **专著 ≠ 编著**：前者是单一整体论述，后者是编者组织的论文集，责任结构不同。

## 四、机构与规范类著作

| 类型 | 形成主体 | 审查 | 特点 |
|:------|:------|:------|:------|
| **技术报告**（technical report） | 研究机构 · 实验室 | 机构内部 | 编号成系列；常作为预印本替代 |
| **白皮书**（white paper） | 企业 · 行业组织 | 内部 / 外部顾问 | 立场性强，常带营销目的 |
| **标准**（standard） | 标准化组织 | 委员会共识 | 编号 + 版本 + 实施日期；具规范性 |
| **政策报告 / 咨询报告** | 政府 · 智库 | 委托方审阅 | 面向决策，不追求学术创新 |
| **规范 / 指南**（guideline） | 专业共同体 | 专家共识 | 介于标准与论文之间 |

- **标准是「著作」吗**：是。它有责任主体（技术委员会）、版本、编号与著作权，只是作者形态是**机构作者**（见第 06 章）。
- **白皮书 ≠ 技术报告**：前者以主张与说服为目的，后者以记录方法与结果为目的。
- 机构类著作的引用价值取决于**可获取性 + 可核查性**，而不是审查强度。

## 五、灰色文献

灰色文献（grey literature）指**不由商业出版者控制、难以通过常规书目渠道获取**的文献。

| 维度 | 内容 |
|:------|:------|
| **典型类型** | 学位论文 · 技术报告 · 会议录 · 工作论文 · 政府文件 · 标准草案 · 预印本 · 机构年报 |
| **共同特征** | 非商业出版 · 发行范围有限 · 书目控制薄弱 · 格式不统一 |
| **价值** | 包含阴性结果、地方数据、政策细节，常是正式文献的系统性缺口 |
| **难点** | 获取困难 · 版本不清 · 引用信息不全 · 长期保存无保障 |

- **灰色 ≠ 低质量**：许多灰色文献经过严格内审，只是没有进入商业出版链条。
- 系统综述与方法学指南通常要求**检索灰色文献**，以减少发表偏倚（见 [[3 Resources/000-Knowledge/00-总类/001-科学与知识总论、智力工作组织/001-科学与知识总论、智力工作组织|001 科学总论]] 的 001.8 支线）。
- 灰色文献的**书目控制**归 [[3 Resources/000-Knowledge/01-目录学/01-目录学|01 目录学]]；本库只讨论其类型特征与边界。

## 六、数据集与软件作为著作

| 类型 | 标识 | 引用形态 | 关键问题 |
|:------|:------|:------|:------|
| **数据集**（dataset） | DOI（DataCite）· 版本号 | 数据引用条目 | 版本 · 许可 · 可复现性 |
| **软件 / 代码** | DOI（如 Zenodo）· 仓库 URL | 软件引用条目 | 版本 · 依赖 · 可运行性 |
| **补充材料**（supplementary material） | 随论文 DOI | 通常不单独引用 | 与主文的绑定关系 |
| **数据库 / 知识库** | 自有标识 + DOI | 视同数据集 | 持续更新 vs 快照 |

- **数据集是可引用著作**：现代出版规范要求数据有独立标识、许可与作者贡献说明。
- **FAIR 原则**（可发现 · 可访问 · 可互操作 · 可复用）是数据集作为著作的质量框架。
- **补充材料 ≠ 数据集**：前者附属于论文，后者是可独立复用的研究对象。
- 数据集与软件的作者贡献可用 CRediT 类角色描述（见第 07 章）。

## 七、类型与证据等级

类型本身不决定质量，但**审查机制**影响证据预期：

| 状态 | 审查 | 证据定位 |
|:------|:------|:------|
| **正式发表**（version of record） | 同行评议 + 编辑 | 引用首选 |
| **已接收稿**（accepted manuscript） | 已通过评议，未排版 | 内容等同，排版不同 |
| **预印本** | 平台筛查 | 时效优先，结论待核 |
| **工作论文 / 报告** | 机构内部 | 过程性证据 |
| **博客 / 网页** | 无 | 线索，不作证据 |

- **预印本 ≠ 未完成**：它可能是已完成但尚未通过评议的稿子；引用时应标注版本与日期。
- **撤稿**（retraction）是类型的特殊状态：文献仍存在，但不再支持原结论，引用必须注明。
- 证据等级的判断应看**研究设计 + 审查 + 复现**，而不是仅看类型标签。

## 八、版本关系：从预印本到正式发表

一条常见的版本链：

```
预印本（preprint）
    │ 投稿 / 同行评议
    ▼
已接收稿（accepted manuscript / AAM）
    │ 排版 / 校对
    ▼
正式发表版（version of record / VoR）
    │ 修订 / 更正 / 撤稿
    ▼
更正（correction）· 撤稿（retraction）· 新版本
```

- **引用应指向 VoR**，除非讨论版本差异或 VoR 不可获取。
- ** embargo（禁限出版期）**：部分期刊限制 AAM 的公开时间，影响机构库存档。
- 版本链是「同一著作、不同文档」的典型例子（第 01 章的作品同一性、第 03 章的版次）。

## 九、五个常见误读

1. **「论文就是期刊论文」** —— 会议论文、预印本、学位论文同样是论文形态，审查与流通不同。
2. **「预印本等于没做完」** —— 它可能已完成，只是尚未通过评议；应看版本与日期。
3. **「会议论文低期刊一等」** —— 学科差异巨大，计算机科学顶级会议是首要发表渠道。
4. **「数据集不算著作」** —— 有标识、有作者、有许可的数据集是可引用著作。
5. **「译著就是原著」** —— 译著是衍生著作，译者承担独立责任，引用须区分。

## 本章要点

- 著作类型由**创作方式 · 审查机制 · 流通渠道 · 发表状态**四轴组合而成，不是单棵分类树。
- 学术类型包括期刊论文 · 会议论文 · 专著 · 编著 · 章节 · 学位论文 · 预印本 · 工作论文；子类型差异不可忽略。
- 机构类型包括技术报告 · 白皮书 · 标准 · 政策报告；标准是机构作者的规范性著作。
- **灰色文献**非商业出版、书目控制薄弱，但常含正式文献的系统性缺口；灰色 ≠ 低质量。
- 数据集与软件是可引用著作，需独立标识、版本与许可。
- 类型不直接决定证据等级；**审查机制 + 研究设计**才是判断依据。
- 版本链（预印本 → AAM → VoR → 更正 / 撤稿）是「同一著作、不同文档」的典型。
