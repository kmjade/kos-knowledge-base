## 一、一本书的三个层次

「书」至少在三层上被谈论，混淆这三层是版本问题的常见来源：

| 层 | 指什么 | 判断单位 | 例子 |
|:------|:------|:------|:------|
| **物理层** | 手里这一册（册 / codex） | 装订单位 | 某社 2020 年精装第 3 次印刷本 |
| **出版层** | 一次编辑、制作、发行的出版单元 | 版次 + 出版者 | 某社「修订版」 |
| **内容层** | 其中的著作与文本 | 作品 / 版本 | 《红楼梦》程乙本 |

- 一层可以对应多个另一层：一册书可含多部著作（文集）；一部著作可装成多册（套书）。
- 版次问题发生在**出版层**，版本校勘问题发生在**内容层**，装帧与开本问题发生在**物理层**。

## 二、物理结构解剖

一本现代平装 / 精装书的典型构件：

| 部位 | 内容 | 功能 |
|:------|:------|:------|
| **护封 / 封面** | 书名 · 作者 · 出版社 · 宣传语 | 识别与营销；精装另有书壳 |
| **书脊** | 书名 · 作者 · 社标 | 上架时的唯一可见面 |
| **书芯** | 折帖、订口、切口、天头、地脚 | 承载正文的物理载体 |
| **前置页**（prelims） | 书名页 · 版权页 · 献词 · 目录 · 序 | 身份与法律信息 |
| **正文** | 章节 · 图表 · 注释 | 内容主体 |
| **后置页** | 附录 · 参考文献 · 索引 · 跋 · 广告页 | 检索与补充 |

中国传统线装书的对应构件不同，术语不可直译：

| 构件 | 说明 |
|:------|:------|
| **书衣 / 封面** | 最外层保护与题签 |
| **书脑 / 书脊** | 装订侧 |
| **书口 / 版心** | 折页边缘；版心有鱼尾、象鼻、黑口白口 |
| **天头 / 地脚** | 上下留白，批注常在此 |
| **卷** | **内容单位**（如「第一至五卷」），不等于现代「册」 |
| **册 / 函** | 物理单位；多册可装一函 |

- **卷 ≠ 册**：古籍的「卷」按内容分，一册可含数卷，一卷也可分装数册。
- 物理结构决定使用方式：开本影响携带，装帧影响耐久，版心布局影响批注空间。

## 三、副文本：正文之外的装置

Genette（1997）把围绕正文、参与塑造阅读的装置称为 **paratext（副文本）**，分两类：

| 类 | 位置 | 内容 | 作用 |
|:------|:------|:------|:------|
| **peritext（书内副文本）** | 同一册内 | 书名页 · 版权页 · 献词 · 序跋 · 目录 · 注释 · 页码 · 版式 · 插图说明 | 引导阅读、确立身份、标示权利 |
| **epitext（书外副文本）** | 书外 | 作者访谈 · 书信 · 日记 · 书评 · 广告 · 发布会 · 社交媒体宣传 | 塑造书的公共形象与期待 |

- **副文本不是装饰**：它决定「这本书是什么书」—— 丛书归属、目标读者、权威性声明都在这里。
- **版权页**（colophon / copyright page）是法律与书目信息的交汇点：出版者、版次、印次、ISBN、著作权声明、印刷厂。
- 副文本会随版本变化：修订版常改写序言、更新参考文献、重做封面 —— 这些变化本身是版本判定的线索。

## 四、书目要素：一本书如何被描述

书目描述（著录）把上述结构转成结构化记录。本库只列**要素**，著录规则与格式归 [[3 Resources/000-Knowledge/01-目录学/01-目录学|01 目录学]]：

| 要素组 | 内容 | 常见来源 |
|:------|:------|:------|
| **题名** | 正题名 · 副题名 · 并列题名 · 交替题名 | 书名页（不是封面） |
| **责任者** | 著者 · 编者 · 译者 · 绘者 | 书名页 |
| **版本项** | 版次说明（第 2 版 · 修订版 · 增订版） | 书名页 / 版权页 |
| **出版项** | 出版地 · 出版者 · 出版年 | 版权页 |
| **载体形态** | 页数 · 开本 · 装帧 · 附件 | 书本身 |
| **丛编项** | 丛书名 · 编号 | 书名页 / 封面 |
| **标准号** | ISBN · ISSN（连续出版物）· DOI（电子版） | 版权页 / 封底条码 |

- **书名页优先**：题名与责任者以书名页为准，封面与书脊只作参考（两者常为营销而简化）。
- **ISBN 标识的是出版单元**，不是著作，也不是某一册的每一次印刷（详见第 04 章）。
- 著录的取舍（哪些要素必填、如何转录）属于编目规则，本库不展开。

## 五、版次与印次

| 概念 | 英文 | 定义 | 判定依据 |
|:------|:------|:------|:------|
| **版次** | edition | 内容或版式的**实质变更**后形成的新出版单元 | 修订 · 增补 · 重排 · 改版 · 换出版社重制 |
| **印次** | impression / printing | 同一版次的**重复印刷** | 仅印量增加，内容与版式不变 |
| **刷次** | — | 同一印次内的细微调整（如勘误后重刷） | 出版惯例不一，界限模糊 |

常见版本类型：

| 类型 | 含义 | 是否构成新版次 |
|:------|:------|:------|
| **修订版**（revised edition） | 内容有实质修改 | 是 |
| **增订版**（enlarged edition） | 增加章节或材料 | 是 |
| **新版**（new edition） | 重新排版或重新编辑 | 是 |
| **影印本 / 重印本** | 按原版复制 | 通常否（可能算新印次） |
| **平装 / 精装** | 装帧不同 | 视惯例；内容未变时多按同一版次的不同装帧 |

- **「新版 = 重印」是错的**：新版次意味着读者需要重新核对内容；重印只需核对是否同一版。
- 引用时的规范写法要能区分两者：`第 3 版，第 2 次印刷`。
- 数字出版削弱了「印次」：持续更新的电子书更像「版本号」，而非一次性印刷批次。

## 六、古籍版本与校勘

传统文献的「版本」比现代出版复杂，因为它同时是**物质对象**与**文本传承**：

| 维度 | 类型 | 说明 |
|:------|:------|:------|
| **制作方式** | 稿本 · 抄本 · 刻本 · 活字本 · 石印本 · 影印本 | 决定字形、行款与批注形态 |
| **刻印时序** | 初印本 · 后印本 · 递修本 | 同一副版片在不同时期的印本 |
| **文本状态** | 白文本 · 注本 · 批校本 · 过录本 | 是否含他人校注 |
| **稀缺程度** | 孤本 · 稀见本 · 通行本 | 影响校勘与定价 |

- **版本谱系**：把各版本按传承关系排列，判断孰先孰后、谁承谁。
- **校勘四法**（陈垣）：对校（异本互校）· 本校（本书前后互证）· 他校（引文与旁证）· 理校（以文理推断）。
- **版本鉴定**（牌记 · 避讳 · 纸张 · 字体 · 藏书印）属文献学技术，规范与著录归 01 目录学与 09 手稿、珍本、善本；本库只讨论「版本作为书的属性」。

## 七、装帧与开本

| 维度 | 取值 | 影响 |
|:------|:------|:------|
| **开本** | 16 开 · 32 开 · A5 · B5 · 特装 | 携带性 · 阅读距离 · 版面容量 |
| **装帧** | 平装 · 精装 · 线装 · 活页 · 裸脊 | 耐久性 · 摊平度 · 成本 |
| **纸张** | 胶版纸 · 轻型纸 · 铜版纸 | 重量 · 透印 · 图片还原 |
| **附件** | 光盘 · 地图 · 索引册 · 数字资源码 | 书与「混合文档」的边界 |

- 装帧是**物理层**属性，通常不改变内容层，但会影响「这一册是否算同一版」的判定。
- 大开本画册与便携平装书可以是同一部著作、同一版次，只是装帧不同。

## 八、电子书：书还是文件？

| 形态 | 代表格式 | 与纸书的关系 |
|:------|:------|:------|
| **固定版式** | PDF · 固定版 EPUB | 保留页码与版面，接近「扫描 / 排版成品」 |
| **可重排** | EPUB（reflowable）· MOBI / AZW3 | 无固定页，版面由阅读器生成 |
| **网页 / 应用** | HTML · 阅读 App | 无「册」，持续更新，边界最模糊 |

- 电子书保留了大部分**副文本**：封面、书名页、版权页、ISBN、目录仍在，只是以元数据或首页呈现。
- **「页」不再稳定**：引用电子书通常用章节号或位置号，而不是页码。
- 可重排格式让「版式」不再是书的固定属性，但**出版单元**（版次、出版者、ISBN）依然成立。
- 电子书与「数据库 / 数据集」的边界，取决于它是否仍以「一部可被完整阅读的作品」为单位发行。

## 九、五个常见误读

1. **「书就是里面的文本」** —— 副文本、装帧、开本共同构成「书」这一对象。
2. **「新版就是重印」** —— 版次涉及实质变更，印次只是同版加印。
3. **「卷就是册」** —— 卷是内容单位，册是物理单位，古籍中两者常不一致。
4. **「页数代表内容多少」** —— 开本、字号、行距都会改变页数，页数不是内容长度的稳定度量。
5. **「电子书没有版本」** —— 出版单元与版次依然存在，只是以版本号、更新日期或 DOI 版本表示。

## 本章要点

- 书分三层：**物理层（册）· 出版层（版次）· 内容层（作品 / 文本）**，版本问题必须说明在哪一层。
- 物理结构（书壳 · 书脊 · 书芯 · 前置页 · 后置页）与线装书构件（书衣 · 版心 · 卷 · 函）不能直译互换。
- 副文本（peritext / epitext）不是装饰，它确立书的身份、读者与权利。
- 书目要素以**书名页**为准；ISBN 标识出版单元，不标识著作或单次印刷。
- **版次 ≠ 印次**：前者是实质变更，后者是重复印刷；古籍另叠加制作方式与文本状态两个维度。
- 装帧与开本属物理层；电子书弱化「页」，但**出版单元**仍成立。
