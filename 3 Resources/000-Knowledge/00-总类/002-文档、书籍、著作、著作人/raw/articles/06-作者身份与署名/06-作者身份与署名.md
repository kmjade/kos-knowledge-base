# 06 作者身份与署名

## 一、署名承担五种功能

| 功能 | 说明 | 失效后果 |
|:------|:------|:------|
| **归属**（attribution） | 标明谁创作了这份内容 | 无法追溯来源 |
| **责任**（accountability） | 谁对内容与错误负责 | 撤稿时无人可问 |
| **荣誉**（credit） | 谁获得学术与社会承认 | 激励扭曲 · 贡献被抹去 |
| **权利**（copyright） | 谁享有著作财产权 | 授权与收益纠纷 |
| **可发现**（discoverability） | 检索与评价系统的入口 | 成果无法被归集 |

- 五种功能**可能分离**：著作权可以转让，但学术责任不能；荣誉可以共享，但责任必须有人承担。
- 署名争议的本质，通常是**多种功能被当成同一件事**来处理。

## 二、作者的类型

| 类型 | 形态 | 责任结构 |
|:------|:------|:------|
| **个人作者** | 单一自然人 | 全部责任集中于一人 |
| **合作作者** | 多人共同署名 | 共同但有区别的责任（按贡献声明划分） |
| **机构作者**（corporate author） | 组织、委员会、协作组署名 | 由机构承担，个人以成员身份列于附录 |
| **匿名作者** | 不披露身份 | 仍有登记主体，只是不对公众披露 |
| **化名 / 笔名** | 使用替代名称 | 真实身份可查或不可查；法律责任仍归属真实主体 |
| **代笔**（ghostwriting） | 实际写作者不署名 | 伦理问题；职业写作中须合同约定 |

- **机构作者不是「无人负责」**：标准由技术委员会署名，责任落在委员会与所属组织。
- **大型协作组**（如高能物理、基因组联盟）采用「协作组 + 成员列表」双层署名，成员贡献由内部政策规定。
- **匿名 ≠ 免责**：匿名保护的是公众身份，不取消法律与伦理责任。

## 三、署名资格：谁算作者

医学与出版界最常用的判据是 **ICMJE 四条**，四条须同时满足：

| 条件 | 内容 |
|:------|:------|
| **1 实质贡献** | 对构思、设计、数据获取或分析有实质贡献 |
| **2 起草或修订** | 参与起草或对重要内容作批判性修订 |
| **3 最终认可** | 同意最终发表版本 |
| **4 承担责任** | 同意对整体工作负责，能回应质疑 |

- **只满足部分条件者应列入致谢**：提供资金、数据、设备、语言润色、常规技术支持的，通常不构成作者身份。
- 三类问题署名：

| 类型 | 含义 | 问题 |
|:------|:------|:------|
| **挂名作者**（gift / guest authorship） | 未达标准却署名 | 稀释责任 · 学术不端 |
| **代笔作者**（ghost authorship） | 达到标准却未署名 | 隐瞒贡献 · 利益冲突 |
| **荣誉作者**（honorary authorship） | 因职位或声望被列入 | 责任虚置 |

- 不同学科标准不同：人文社科更强调独立写作，团队科学更依赖贡献声明；但「能承担责任」是共同底线。

## 四、署名顺序意味着什么

| 位置 | 常见含义 | 备注 |
|:------|:------|:------|
| **第一作者** | 主要执行者 / 主要执笔者 | 学生与早期研究者最看重 |
| **共同第一作者** | 贡献相当，标注 equal contribution | 需所有共同一作同意 |
| **通讯作者**（corresponding author） | 对外联络、对投稿与质询负责 | 不等于「老板」，但常由课题负责人担任 |
| **末位作者** | 资深作者 / 指导者（实验室传统） | 学科惯例差异大 |
| **字母序** | 全体作者按姓氏排序 | 数学、经济学期刊常见 |

- **贡献序 vs 字母序**是两套制度：前者传递贡献信息，后者刻意淡化排序。
- **通讯作者**是**责任角色**，不是荣誉头衔：负责投稿、通信、数据与代码的可获取性。
- 署名顺序争议应在投稿前以书面共识解决，而非事后协商。

## 五、机构作者与集体署名

| 形态 | 例子 | 署名写法 |
|:------|:------|:------|
| **标准化组织** | ISO · IEC · 国家标准化机构 | 机构名 + 标准编号 |
| **政府机构** | 部门、统计局、监管机构 | 机构名 + 报告编号 |
| **企业** | 白皮书、技术文档 | 公司名（可加作者列表） |
| **协作组** | 大型科研联盟 | 协作组名 + 成员附录 |
| **编辑委员会** | 辞书、年鉴、指南 | 编委会署名 |

- 机构署名的**责任主体是组织**：个人成员变动不影响著作归属。
- 引用机构著作时，**机构名即作者名**；缩写须与全文一致并在参考文献中展开。
- 集体署名的风险：责任分散、个人贡献不可见；缓解办法是贡献声明与成员列表。

## 六、匿名、化名与身份披露

| 情形 | 动机 | 处理原则 |
|:------|:------|:------|
| **笔名 / 化名** | 创作自由 · 隐私 · 市场定位 | 书目记录可注明「著者题名」或真实姓名 |
| **佚名** | 历史流传 · 作者不可考 | 按「佚名」著录，不作推测 |
| **匿名评审** | 公正评价 | 与「作者署名」是两件事，不可混淆 |
| **匿名举报 / 匿名来源** | 保护信息提供者 | 新闻与调查伦理，非著作署名问题 |
| **网络化名** | 社区身份 | 平台账号可作责任锚点 |

- **匿名作者仍是责任主体**：出版合同、版权登记、投稿系统都留有真实身份。
- 图书馆的**名称规范**（authority control）负责处理同一作者的不同名称形式；规则归 [[3 Resources/000-Knowledge/01-目录学/01-目录学|01 目录学]]。

## 七、作者身份与标识

第 04 章的责任者标识在这里落地：

| 问题 | 表现 | 解决机制 |
|:------|:------|:------|
| **同名** | 张三 / 张叁 / Zhang San | ORCID · ISNI · VIAF 消歧 |
| **改名** | 婚姓、译名、笔名 | 标识不变，名称作别名 |
| **转写差异** | 汉字 / 拼音 / 韦氏 | 规范档记录多种形式 |
| **机构变更** | 作者换单位 | 标识跟随个人，不跟随机构 |
| **贡献不可见** | 只看到名字 | 贡献声明（CRediT） |

- **标识解决机器消歧，不解决责任分配**；两者需要不同的制度。
- 作者页面（研究者主页、机构库）应同时维护**标识**与**署名变体**，避免成果分裂到多个身份下。

## 八、署名争议与变更

| 情形 | 处理 |
|:------|:------|
| **投稿前** | 书面确认作者列表、顺序、通讯作者 |
| **审稿中增删作者** | 须全体作者同意，并向编辑说明理由 |
| **发表后更正** | 通过正式更正（corrigendum）变更署名 |
| **撤稿** | 全体作者知情；不可单方面撤下名字 |
| **贡献争议** | 依贡献声明与通信记录裁定 |

- 署名变更是**有记录的正式操作**，不是悄悄改稿。
- 撤稿通知中的作者态度（同意 / 不同意）本身是重要信息。

## 九、AI 能当作者吗

现行主流规范（ICMJE · COPE · 多数出版社政策）一致：**AI 不能署名为作者**。

| 理由 | 说明 |
|:------|:------|
| **无法承担责任** | 作者须对内容负责并回应质疑，AI 不能 |
| **无法同意发表** | 无法签署版权与伦理声明 |
| **责任必须落到人** | 使用 AI 的作者对输出负全责 |

- **AI 使用应披露**：在方法、致谢或专门声明中说明工具、用途与人工核查方式。
- AI 可以辅助写作、翻译、绘图、编码，但**不能成为归属对象**。
- 这与第 01 章的「作者功能」一致：作者是制度中的责任位置，不是文本的生产者本身。

## 十、五个常见误读

1. **「作者就是执笔者」** —— 作者是承担责任者，执笔只是贡献之一。
2. **「署名顺序等于贡献大小」** —— 贡献序、字母序、通讯作者制度并存，不能一概而论。
3. **「通讯作者是行政角色」** —— 通讯作者承担对外责任与数据可获取性，是实质责任角色。
4. **「机构作者等于没人负责」** —— 责任落在组织与委员会，个人贡献另有记录。
5. **「AI 可以当共同作者」** —— 现行规范明确排除，责任必须由人承担。

## 本章要点

- 署名承担**归属 · 责任 · 荣誉 · 权利 · 可发现**五种功能，这些功能可能分离。
- 作者类型包括个人 · 合作 · 机构 · 匿名 · 化名 · 代笔；机构作者的责任落在组织。
- **ICMJE 四条**是常用的署名资格判据；不满足者列入致谢。
- 署名顺序有两套制度（贡献序 / 字母序）；通讯作者是责任角色。
- 匿名不等于免责；名称规范负责处理同一作者的不同名称形式。
- 责任者标识（ORCID / ISNI / VIAF）解决消歧，不解决责任分配。
- **AI 不能署名**：无法承担责任、无法同意发表；使用须披露。
