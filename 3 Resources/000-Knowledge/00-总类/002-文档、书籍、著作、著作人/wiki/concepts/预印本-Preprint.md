# 预印本 Preprint

## 定义

**预印本**是正式发表前公开的稿本，通常发布在学科预印本服务器上，经平台筛查但未经同行评议。它不是「未完成」的同义词：许多预印本已是完成稿，只是尚未通过评议。预印本是**版本链**中的一环，而非孤立类型。

## 要点

版本链：

```
预印本 → 已接收稿（AAM）→ 正式发表版（VoR）→ 更正 / 撤稿
```

| 版本 | 审查状态 | 引用地位 |
|:------|:------|:------|
| **预印本** | 平台筛查 | 时效优先，结论待核 |
| **AAM** | 已通过评议，未排版 | 内容等同 VoR，排版不同 |
| **VoR** | 同行评议 + 编辑 | 引用首选 |
| **更正 / 撤稿** | 发表后处理 | 必须注明 |

- **embargo**：出版商允许 AAM 公开前的禁限期，常见 6–24 个月。
- 预印本平台：arXiv · bioRxiv · medRxiv · SSRN · Zenodo · OSF。
- 版本必须标清：混用预印本与 VoR 会造成引用混乱（见 [[版次与印次-Edition-and-Impression|版次与印次]]）。

## 要义

- **预印本 ≠ 正式发表**：评议状态与责任归属不同，引用时应注明版本与日期。
- **预印本 ≠ 低质量**：它是传播机制的选择，不是质量标签。
- 绿色开放获取常以 AAM 形式自存档（见 [[开放获取-Open-Access|开放获取]]）。
- 数据集与软件的「版本化 DOI」遵循同样的版本逻辑（见 [[DOI]]）。
- 参见 [[灰色文献-Grey-Literature|灰色文献]]。
