# 数字保存 Digital Preservation

## 定义

**数字保存**是让数字对象跨越技术变化仍然**可读、可理解、可验证**的持续过程。它不是一次性的备份动作，而是一组从创建时就开始的约束：格式选择、元数据、标识、校验与迁移计划。保存的目标不止「能打开」，还包括「能解释」与「能证明未被篡改」。

## 要点

| 威胁 | 机制 |
|:------|:------|
| **比特腐坏** | 介质产生静默错误 |
| **格式过时** | 读取器消失 |
| **软件依赖** | 特定应用 / 插件失效 |
| **链接失效** | 外部资源下线 |
| **机构消亡** | 托管方停止服务 |
| **人为 / 恶意** | 误删、覆盖、勒索软件 |

| 策略 | 做法 | 风险 |
|:------|:------|:------|
| **迁移** | 定期转为新格式 | 每次转换可能引入变化 |
| **仿真** | 模拟旧运行环境 | 仿真器也会过时 |
| **封装** | 打包文件 + 元数据 + 工具 | 包内工具仍需可运行 |

**OAIS**（ISO 14721）提供通用框架：SIP / AIP / DIP + 六个功能实体；TDR（ISO 16363）提供认证。

## 要义

- **备份 ≠ 保存**：备份防丢失，保存防失效。
- **3-2-1**（3 份副本 · 2 种介质 · 1 份异地）+ 定期校验 + 版本快照，是基础实践。
- **迁移必须记录**（谁迁、何时、从什么到什么、校验值），否则真实性无法证明。
- **可理解性**依赖保存元数据：格式说明、来源、权利、迁移历史。
- 分布式保存（LOCKSS · CLOCKSS · Portico）应对机构消亡。
