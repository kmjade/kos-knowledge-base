# 版次与印次 Edition and Impression

## 定义

**版次**（edition）是内容或版式发生**实质变更**后形成的出版单元；**印次**（impression / printing）是同一版次的**重复印刷**。二者混淆会导致引用与版本核对出错。版次问题发生在**出版层**，不是物理层或内容层。

## 要点

| 概念 | 定义 | 判定依据 |
|:------|:------|:------|
| **版次** | 实质变更后的出版单元 | 修订 · 增补 · 重排 · 改版 · 换社重制 |
| **印次** | 同版重复印刷 | 仅印量增加，内容与版式不变 |
| **刷次** | 同一印次内的细微调整 | 出版惯例不一，界限模糊 |

| 版本类型 | 含义 | 是否新版次 |
|:------|:------|:------|
| **修订版** | 内容实质修改 | 是 |
| **增订版** | 增加章节或材料 | 是 |
| **新版** | 重新排版或编辑 | 是 |
| **影印 / 重印** | 按原版复制 | 通常否 |

## 要义

- **新版 ≠ 重印**：新版需要重新核对内容，重印只需确认同一版。
- 引用应写成「第 3 版，第 2 次印刷」，把两个维度都固定下来。
- **装帧不同**（平装 / 精装）通常不构成新版次，但会影响「这一册是否算同一出版单元」的判定。
- 电子出版弱化印次，转向**版本号 / 更新日期 / DOI 版本**（见 [[标识符-Identifier|标识符]]）。
- 古籍的「版」另叠加制作方式与文本状态（见 [[版本谱系-Textual-Criticism|版本谱系]]）。
