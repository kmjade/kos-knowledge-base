# 02 系统论与信息论

> **支线 02 / UDC 007** — 系统论与信息论（Systems Theory and Information Theory）：把对象看作**相互作用的整体**，并用**不确定性削减**来度量其中的通信。
> 所属：[[007-控制论|007 控制论]]（支线 02）。
> 落位：`007-控制论/raw/articles/02-系统论与信息论/`。
> 关注「整体怎么组成、复杂性从何而来、信息如何度量与传输」，不涉及回路如何稳（→ 支线 01），也不涉及人机分工（→ 支线 03）。

---

## 一、两条汇流

控制论诞生时并行着两条思想线，二者共同构成本支线：

| 线索 | 代表 | 核心提问 |
|:--|:--|:--|
| **一般系统论** | Ludwig von Bertalanffy | 不同领域的「系统」是否有共同的结构规律？ |
| **信息论** | Claude Shannon（1948） | 信息能否被**定量**？通信的极限在哪？ |

> 共同点：都反对「拆到最小零件就能解释整体」的还原论，转而研究**关系、组织与约束**。

## 二、系统的基本特征

| 特征 | 含义 | 反例 / 对照 |
|:--|:--|:--|
| **整体性** | 整体行为不能由部分简单相加得出 | 一堆零件 ≠ 一台发动机 |
| **层次性** | 系统由子系统构成，又是更大系统的部分 | 细胞 → 器官 → 个体 → 种群 |
| **开放性** | 与环境交换物质、能量、信息 | 封闭系统终将趋于熵最大 |
| **动态性** | 状态随时间演化，存在稳态与瞬态 | 静态结构图不足以描述 |
| **目的性** | 行为指向某个目标或吸引子 | 恒温、寻食、趋利 |
| **涌现** | 全局模式由局部规则交互产生 | 鸟群、市场、意识 |

> **关键判据**：系统之所以是系统，在于**部件之间的耦合**。切断耦合，整体性即消失。

## 三、层级与一般系统论

Bertalanffy 主张存在跨学科的**同构规律**：增长、竞争、稳态、分化在物理、生物、社会系统中反复出现。

| 层级视角 | 关注点 | 典型工具 |
|:--|:--|:--|
| 子系统 | 部件功能与接口 | 分解、模块化 |
| 系统 | 内部结构与反馈 | 回路图、状态空间 |
| 超系统 | 环境约束与资源 | 边界分析、利益相关方 |
| 层级间 | 跨层涌现与下向因果 | 多尺度建模 |

> **边界是选择而非事实**：划在哪里，决定了什么算「内部变量」、什么算「扰动」。

## 四、复杂性

| 维度 | 线性系统 | 非线性 / 复杂系统 |
|:--|:--|:--|
| 叠加性 | 部分之和 = 整体 | 不成立（涌现） |
| 预测 | 可解析、可外推 | 长期不可精确预测 |
| 分布 | 正态、集中 | 幂律、长尾、重尾 |
| 行为 | 收敛或发散 | 多稳态、分岔、混沌、临界 |

复杂性不等于「零件多」，而在于**相互作用密度与反馈强度**。三个常用判据：

1. **非线性**——小扰动可放大为大后果（阈值、相变）；
2. **涌现**——规则简单，全局行为复杂；
3. **自组织**——秩序无需外部设计者（与支线 01 的自组织一节互见）。

> **「混沌边缘」**：完全有序则僵化，完全随机则无序；最有适应力的系统常处于二者之间。

## 五、信息论：度量不确定性

Shannon 把「信息」定义为**不确定性的削减**，与意义无关：

```
信源 → 编码器 → 信道（噪声）→ 译码器 → 信宿
```

| 概念 | 含义 | 要点 |
|:--|:--|:--|
| **信息量** | `I = −log₂ p`（比特） | 越不可能的事件，信息量越大 |
| **熵 H** | 随机变量的平均信息量 | 熵最大 = 最不可预测 |
| **冗余** | `1 − H/H_max` | 抗噪的代价；自然语言冗余高 |
| **信道容量 C** | 可靠传输的上限 | 由带宽与信噪比决定 |
| **噪声** | 信道对信号的随机扰动 | 决定误码率与所需冗余 |

**两个编码定理**（Shannon 1948）：

- **信源编码**：无损压缩的下限是信源熵；
- **信道编码**：只要速率 < 容量 C，就存在使误码率任意小的编码。

> **重要区分**：信息论量的是**语法层**（符号序列的可预测性），不涉及**语义**（是否真实）与**语用**（是否有用）。意义的组织属于 [[3 Resources/000-Knowledge/02-信息学/02-信息学|02 信息学]]。

## 六、从信息到知识

| 层 | 问题 | 学科归属 |
|:--|:--|:--|
| 语法 | 符号如何排列、可压缩到多少 | 信息论（本支线） |
| 语义 | 符号指称什么、是否一致 | 逻辑 / 语义学 · 知识组织 |
| 语用 | 对谁有用、如何影响行动 | 传播学 / 决策 · [[005-管理\|005 管理]] |

> 控制论关心的是**信息如何驱动行动**；信息论只保证「传得准」，不保证「传得有意义」。

## 七、系统方法

| 方法 | 用途 | 注意 |
|:--|:--|:--|
| 黑箱方法 | 只由输入—输出关系推断行为 | 内部机制不可辨识 |
| 建模与仿真 | 在受控条件下试探系统 | 模型是简化，不是复制 |
| 边界与利益相关方分析 | 确定系统范围与目标冲突 | 边界选择即价值判断 |
| 软系统方法论（SSM） | 处理目标本身有争议的「软问题」 | 强调学习而非最优解 |
| 生存系统模型（VSM） | 诊断组织的必要功能 | 与支线 01 的必要多样性呼应 |

## 九、核心问题

> 一个由大量相互作用部件构成的整体，其**全局行为**如何从局部规则中涌现——而我们又能用多少信息去描述和控制它？
