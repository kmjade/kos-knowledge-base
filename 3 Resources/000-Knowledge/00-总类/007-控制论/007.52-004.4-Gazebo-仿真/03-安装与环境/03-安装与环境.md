# 03 安装与环境

## Gazebo Classic（历史）

```bash
sudo apt install gazebo11          # Ubuntu
sudo apt install ros-<distro>-gazebo-ros-pkgs   # ROS1 集成
```

## 新版 Gazebo

### 独立安装

```bash
sudo apt install gz-harmonic        # LTS，推荐
# 或 gz-ionic / gz-fortress
```

### 与 ROS2 绑定安装（推荐）

```bash
# Jazzy + Harmonic（推荐组合）
sudo apt install ros-jazzy-ros-gz
sudo apt install ros-jazzy-ros-gz-sim
```

`ros_gz` metapackage 包含 `ros_gz_bridge`、`ros_gz_sim`、`ros_gz_image`、`ros_gz_point_cloud` 及示例。

## 环境变量（新版）

| 变量 | 作用 |
|:--|:--|
| `GZ_SIM_RESOURCE_PATH` | 模型/世界搜索路径（新版） |
| `GAZEBO_MODEL_PATH` | 模型路径（Classic） |

## 版本配对速查

| ROS2 Distro | Gazebo | ros_gz 分支 |
|:--|:--|:--|
| Humble | Fortress（或 Harmonic） | humble |
| Jazzy | Harmonic | jazzy |
| Kilted | Ionic | kilted |
| Rolling/Lyrical | Jetty | ros2 |

> 若你的项目用 Humble，配 Fortress/Harmonic；升级 Jazzy 则用 Harmonic。
