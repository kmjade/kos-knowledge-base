# 007.5 自动系统

> **UDC 007.5** — 自动系统（Automatic / Automated Systems）：无需人持续干预，即可按预定逻辑完成感知、判断与执行的系统。
> 所属：[[007-控制论|007 控制论]]。落位：`007-控制论/007.5-自动系统/`。
> 关注「系统怎么自动运转、分成几层、怎么保证不出事」；回路的稳定性原理见 [[01-控制与反馈|支线 01]]，人的角色见 [[03-人力工程|支线 03]]。

---

## 一、三个易混词

| 词 | 含义 | 落点 |
|:--|:--|:--|
| **自动化**（automation） | 用装置替代人的部分作业 | 过程与趋势 |
| **自动控制**（automatic control） | 使被控量按目标变化的技术 | 算法与回路 |
| **自动系统**（automatic system） | 承载上述功能的**整体**（含对象、装置、能源、接口） | 本页 |

> 判据不在「有没有机器」，而在**是否形成闭环**：能自行测量偏差并修正，才算自动系统；仅按定时动作执行的属开环自动化设备。

## 二、系统的组成

| 部件 | 作用 | 常见形态 |
|:--|:--|:--|
| 被控对象 / 过程 | 被调节的物理量或流程 | 温度、压力、流量、位移、产线 |
| 传感与变送 | 把状态转为可处理信号 | 热电偶、编码器、流量计 |
| 控制器 | 按偏差或程序决定动作 | 继电器、PLC、DCS、工控机 |
| 执行机构 | 把控制量转为物理作用 | 阀门、电机、变频器、气缸 |
| 能源与动力 | 提供动作所需能量 | 电、气、液压 |
| 通信与接口 | 连接各层与人机界面 | 现场总线、工业以太网、HMI |

> **两种基本结构**：开环（按程序/时间动作，不核对结果）与闭环（测量结果并修正）。实际系统常为混合：主回路闭环，辅以顺序与联锁逻辑。

## 三、控制方式的演进

| 阶段 | 代表技术 | 特征 |
|:--|:--|:--|
| 机械式 | 离心调速器、凸轮机构 | 靠物理结构实现反馈，无电子元件 |
| 继电逻辑 | 继电器柜、梯形图 | 顺序与联锁，逻辑固定、改动困难 |
| 电子模拟 | 运算放大器调节器 | 连续 PID，参数可调 |
| 可编程 | PLC · DCS · SCADA | 逻辑可编程，集中监控 |
| 计算机化 | 工控机 · 嵌入式 | 复杂算法、数据记录、优化 |
| 网络化 | 工业以太网 · IIoT · CPS | 分布式协同，信息物理融合 |

## 四、自动化的层级

工业界常用「自动化金字塔」：

| 层 | 功能 | 典型系统 |
|:--|:--|:--|
| 现场层 | 传感与执行 | 仪表、变送器、执行器 |
| 控制层 | 实时调节与联锁 | PLC · DCS 控制器 |
| 监控层 | 监视、报警、操作 | SCADA · HMI |
| 管理层 | 排产、质量、设备 | MES · EMS |
| 决策层 | 计划与经营 | ERP · APS |

> 层与层之间的**时间尺度**逐级放大：毫秒级回路 → 秒级监控 → 天级计划。跨层设计失败，往往源于把不同时间尺度混在一个回路里。

## 五、关键技术

| 技术 | 用途 | 要点 |
|:--|:--|:--|
| PID 调节 | 连续量的稳定控制 | 与 [[01-控制与反馈\|支线 01]] 的 P/I/D 取舍同源 |
| 顺序控制 | 按步骤推进流程 | 状态机、步进逻辑 |
| 前馈 / 比值控制 | 扰动未显形前补偿 | 依赖可测扰动 |
| 联锁与互锁 | 禁止危险动作组合 | 条件不满足即封锁 |
| 报警管理 | 异常提示与分级 | 防止报警泛滥 |
| 冗余与容错 | 单点故障不致停机 | 双机热备、表决 |

## 六、自动化等级与人的角色

| 等级 | 人做什么 | 风险 |
|:--|:--|:--|
| L0 手动 | 全程操作 | 负荷高 |
| L1 辅助 | 人操作、系统提示 | 提示被忽略 |
| L2 部分自动 | 人监督、异常接管 | 注意力漂移 |
| L3 条件自动 | 系统执行、人待命 | 接管请求的提前量不足 |
| L4 高度自动 | 人仅在限定外干预 | 技能退化 |
| L5 完全自动 | 无人 | 责任归属与异常兜底 |

> 与 [[03-人力工程|支线 03]] 的自动化悖论一致：**自动化程度越高，人越需要被专门设计为「有效的监督者」**，而不是被默认成随时能接手的备份。

## 七、可靠性与安全

| 概念 | 含义 |
|:--|:--|
| **失效安全**（fail-safe） | 故障时进入安全状态（如断气关阀） |
| **冗余** | 多重通道，单点失效不影响功能 |
| **安全仪表系统**（SIS） | 与过程控制分离的独立保护层 |
| **安全完整性等级**（SIL） | 按 IEC 61508 量化保护层可靠性 |
| **纵深防御** | 多层防护，避免单点突破 |

> **基本原则**：安全功能必须**独立于**常规控制功能。用同一个控制器既做调节又做保护，等于把两道防线合并为一道。

## 九、核心问题

> 一个系统要「无人值守仍可靠」，需要在哪些层设冗余、在哪些点留给人、又怎样保证故障时一定落到安全侧？
