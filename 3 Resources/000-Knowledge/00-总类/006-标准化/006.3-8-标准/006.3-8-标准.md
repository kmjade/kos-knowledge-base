## 一、标准是什么

| 视角 | 含义 |
|:--|:--|
| 制度视角 | 经协商一致制定、由公认机构批准、供共同使用和重复使用的**规则性文件** |
| 文献视角 | 有唯一编号、固定版式、明确适用范围与规范性条款的**技术文献** |
| 法律视角 | 原则上自愿；被**技术法规**或合同引用后产生约束力 |

> 一句话：标准是「**把共识固化成可复用的条款**」。

## 二、标准号的构成

```
GB/T  1.1  - 2020
 │     │      └─ 年代号（发布年）
 │     └─ 顺序号
 └─ 标准代号（发布机构 + 标准性质）
```

| 代号 | 性质 |
|:--|:--|
| GB | 强制性国家标准 |
| GB/T | 推荐性国家标准 |
| GB/Z | 国家标准化指导性技术文件 |
| ISO · IEC · ITU | 国际标准 |
| EN | 欧洲区域标准 |
| DB + 行政区划代码 | 地方标准 |
| T/ + 团体代号 | 团体标准 |
| Q/ + 企业代号 | 企业标准 |

| 示例 | 解读 |
|:--|:--|
| `GB/T 1.1-2020` | 推荐性国标，顺序号 1.1，2020 年版 |
| `GB 50016-2014` | 强制性国标（工程建设） |
| `ISO 9001:2015` | 国际标准，年份用冒号 |
| `IEC 60068-1:2013` | 国际标准，分部用连字符 |

> 识别要点：**代号定性质，年代号定版本**。同一顺序号的不同年代号是**不同版本**，不可混用。

## 三、按性质与效力（006.3 的核心）

| 类型 | 约束力 | 典型场景 |
|:--|:--|:--|
| 强制性标准 | 必须执行；不符合不得生产、销售、进口 | 人身健康 · 财产安全 · 国家安全 · 生态环境安全 |
| 推荐性标准 | 自愿采用；被引用后产生约束 | 通用技术、方法、管理 |
| 指导性技术文件 | 参考性，供尚在探索的领域使用 | 新技术、新方法 |

> 中国 2018 年《标准化法》后：**强制性标准仅限国家标准**（GB）；行业标准、地方标准均为推荐性。

## 四、标准文献的四个特征

| 特征 | 含义 | 实务影响 |
|:--|:--|:--|
| 编号唯一 | 一号一标准，顺序号+年代号定位 | 引用必须写全，避免张冠李戴 |
| 时效性强 | 复审（一般 ≤5 年）、修订、废止 | 引用前须核验**现行有效** |
| 版本敏感 | 修订换年代号；修改单单独发布 | 注日期/不注日期引用后果不同 |
| 被引用即约束 | 法规、合同、认证依据常引用标准 | 自愿标准可能变成事实强制 |

## 五、引用方式：注日期 vs 不注日期

| 方式 | 写法 | 效果 |
|:--|:--|:--|
| **注日期引用** | `GB/T 1.1-2020` | 只适用该版本；后续修订不自动适用 |
| **不注日期引用** | `GB/T 1.1` | 适用**最新版本**（含修改单） |

> 选择原则（GB/T 1.1）：需要锁定技术状态（如安全、试验方法）用注日期；希望随标准更新自动跟进用不注日期。合同与法规引用尤其要写明。
