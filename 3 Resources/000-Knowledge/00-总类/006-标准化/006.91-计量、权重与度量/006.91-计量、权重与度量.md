# 006.91 计量、权重与度量

> **UDC 006.91** — 计量学 / 度量衡总论（Metrology · Weights and measures）：**测量**及其应用的科学，研究量值如何定义、复现、传递与比较。
> 所属：[[006-标准化|006 标准化]]，落位 `006-标准化/006.91-计量、权重与度量/`（folder-note）。
> 与支线 03 的分工：**03 讲「计量 + 合格评定」的制度全景；本笔记聚焦计量本体（度量衡、量值、溯源）**。

---

## 一、从度量衡到计量

| 阶段 | 基准 | 局限 |
|:--|:--|:--|
| 度量衡 | 实物原器（尺、斗、秤、千克原器） | 会磨损、不可异地复现、依赖保管 |
| 经典计量 | 物理现象定义（如铯原子跃迁定义秒） | 精度提升，仍分基本/导出 |
| 现代计量 | **基本单位全部由物理常数定义**（2019 SI 修订） | 任何时间、地点可复现，摆脱实物 |

> 关键转折：计量的可信度不再来自「保存得好的实物」，而来自「**可复现的自然常数 + 不间断的溯源链**」。

## 二、核心术语

| 术语 | 含义 |
|:--|:--|
| 量（quantity） | 可定性区分、可定量表达的现象属性 |
| 量值（value of a quantity） | 数值 × 单位 |
| 测量（measurement） | 通过实验获得量值的过程 |
| 测量结果 | 测量所得量值 + **测量不确定度** |
| 误差（error） | 测量结果 − 真值（真值不可知，故用不确定度表达可信区间） |
| 测量不确定度（uncertainty） | 对测量结果分散性的定量表征 |
| 溯源（traceability） | 通过不间断的校准链，把测量结果联系到国家/国际基准 |
| 校准（calibration） | 建立示值与参考标准对应关系的技术操作 |
| 检定（verification） | 依法制规程判定计量器具是否合格的法制行为 |

> 易混点：**误差是「差多少」，不确定度是「有多不确定」**；校准不判合格，检定判合格。

## 三、测量体系的三层结构

```
SI 定义（自然常数）
   ↓  复现
国家计量基准（primary standard）
   ↓  传递
副基准 / 工作基准 / 标准器
   ↓  校准
工作计量器具（现场仪表、衡器、量具）
```

| 层级 | 作用 | 责任主体 |
|:--|:--|:--|
| 定义层 | 规定单位与常数 | CGPM · BIPM |
| 基准层 | 复现单位、参与国际比对 | 国家计量院（如 NIM） |
| 传递层 | 校准标准器、出具证书 | 校准实验室 |
| 应用层 | 生产、贸易、医疗、环境中的测量 | 使用单位 |

> 溯源链**任何一环断裂**，末端测量结果就失去可比性。

## 四、计量的三个领域

| 领域 | 关注 | 例 |
|:--|:--|:--|
| 科学计量 | 单位定义、基准、极限测量 | 时间频率、量子计量 |
| 工业计量 | 生产与检测中的准确测量 | 尺寸、温度、压力、电学 |
| 法制计量 | 涉及公平交易、健康安全、环境的强制管理 | 衡器、加油机、水表、电表、医用计量器具 |

## 五、度量衡的法制面

| 机制 | 内容 |
|:--|:--|
| 计量单位制 | 法定计量单位（中国以 SI 为基础） |
| 计量器具管理 | 型式批准 · 强制检定 · 周期检定 |
| 市场监督 | 集贸市场衡器、定量包装商品净含量抽查 |
| 国际互认 | BIPM 互认安排（CIPM MRA）· OIML 国际建议 |

> 度量衡是**最古老的标准化**：先有「一斤一两」的共识，才有可交易的市场。
