# 标准文献 Standards Literature

## 定义

标准文献指作为**文献与判定依据**的标准文本。与「标准体系」讲结构不同，标准文献关注**如何识别、引用与核验**一份具体标准。

## 标准号构成

```
GB/T  1.1  - 2020
 │     │      └─ 年代号（发布年）
 │     └─ 顺序号
 └─ 标准代号（发布机构 + 标准性质）
```

| 代号 | 性质 |
|:--|:--|
| GB | 强制性国家标准 |
| GB/T | 推荐性国家标准 |
| GB/Z | 指导性技术文件 |
| ISO · IEC · ITU | 国际标准 |
| EN | 欧洲区域标准 |
| DB + 行政区划代码 | 地方标准 |
| T/ + 团体代号 | 团体标准 |
| Q/ + 企业代号 | 企业标准 |

## 四个特征

| 特征 | 含义 | 实务影响 |
|:--|:--|:--|
| 编号唯一 | 一号一标准 | 引用必须写全 |
| 时效性强 | 复审、修订、废止 | 引用前核验现行有效 |
| 版本敏感 | 修订换年代号；修改单单列 | 注日期/不注日期后果不同 |
| 被引用即约束 | 法规、合同、认证引用 | 自愿标准可能事实强制 |

## 引用方式

| 方式 | 写法 | 效果 |
|:--|:--|:--|
| 注日期引用 | `GB/T 1.1-2020` | 只适用该版本 |
| 不注日期引用 | `GB/T 1.1` | 适用最新版本（含修改单） |

## 现行性核验

| 渠道 | 用途 |
|:--|:--|
| 全国标准信息公共服务平台 | 查现行状态与替代关系 |
| ISO Online Browsing Platform | 查 ISO/IEC 标准状态 |
| 标准封面「代替」栏 | 看替代关系、实施日期、过渡期 |

> 核验三问：**是否现行？被谁替代？何时实施？**
