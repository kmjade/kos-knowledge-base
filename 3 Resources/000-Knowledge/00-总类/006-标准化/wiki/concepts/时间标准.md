# 时间标准 Time Standards

## 定义

时间标准规定「一秒有多长」与「现在几点」，并通过守时、比对与授时把时间传递给用户。时间是 SI 七个基本量之一，也是精度最高的量。

## 时间尺度

| 尺度 | 性质 | 与 UTC 的关系 |
|:--|:--|:--|
| TAI（国际原子时） | 连续、均匀，无闰秒 | UTC = TAI − 37 s（截至 2026） |
| UT1（世界时） | 基于地球自转 | 与 UTC 偏差控制在 0.9 s 内 |
| UTC（协调世界时） | 法定时间基准 | 通过闰秒贴近 UT1 |
| GPS 时 | 卫星导航系统内部时 | 无闰秒；与 TAI 固定差 19 s |
| 本地时（北京时间） | UTC + 时区偏移 | UTC+8 |

## 秒的定义

1967 年起：铯-133 原子基态两个超精细能级间跃迁辐射的 **9 192 631 770 个周期**。

## 闰秒

| 项 | 说明 |
|:--|:--|
| 触发 | UTC 与 UT1 偏差接近 0.9 s |
| 方式 | 6/30 或 12/31 最后一秒插入或删除 1 s |
| 代价 | 依赖时间连续的系统面临跳变风险 |
| 走向 | CGPM 2022 决议：最迟 2035 年取消闰秒 |

## 建立与传递

```
秒定义 → 国家时间频率基准 → BIPM 国际比对 → TAI/UTC → 授时
```

| 环节 | 手段 |
|:--|:--|
| 守时 | 多台原子钟组 + 算法合成 |
| 比对 | GPS 共视、卫星双向时间频率传递 |
| 授时 | 短波/长波、卫星导航、NTP / PTP |
| 中国 | 国家授时中心（NTSC）发播北京时间 |

## 测时技术三代

| 代际 | 代表 | 精度 |
|:--|:--|:--|
| 天文测时 | 日晷、中星仪 | 秒 – 毫秒 |
| 原子钟 | 铯钟、铷钟、氢脉泽 | 纳秒 / 天 |
| 光钟 | 锶、镱、铝离子 | 10⁻¹⁸ 量级 |
