# 计量学 Metrology

## 定义

计量学是**测量及其应用的科学**，研究量值如何定义、复现、传递与比较。它保证不同时间、地点、主体做出的测量**可比较、可复现**。

## 从度量衡到计量

| 阶段 | 基准 | 局限 |
|:--|:--|:--|
| 度量衡 | 实物原器 | 磨损、不可异地复现 |
| 经典计量 | 物理现象定义 | 精度提升，仍分基本/导出 |
| 现代计量 | 物理常数定义（2019 SI） | 任何时间地点可复现 |

## 核心术语

| 术语 | 含义 |
|:--|:--|
| 量 / 量值 | 可定量表达的现象属性 / 数值 × 单位 |
| 测量结果 | 量值 + 测量不确定度 |
| 误差 | 测量结果 − 真值（真值不可知） |
| 测量不确定度 | 对结果分散性的定量表征 |
| 溯源 | 通过校准链联系到国家/国际基准 |
| 校准 | 建立示值与参考标准的对应 |
| 检定 | 依法制规程判定器具是否合格 |

> **误差是「差多少」，不确定度是「有多不确定」**。

## 三个领域

| 领域 | 关注 |
|:--|:--|
| 科学计量 | 单位定义、基准、极限测量 |
| 工业计量 | 生产与检测中的准确测量 |
| 法制计量 | 公平交易、健康安全、环境的强制管理 |
