# 03 计量与合规

> **支线 03 / UDC 006** — 计量与合规（Metrology & Conformity）：保证**量值准确一致**，并证明事物**符合标准或法规要求**。
> 所属：[[006-标准化|006 标准化]]（支线 03）。
> 落位：`006-标准化/raw/articles/03-计量与合规/`。
> 关注「测量是否可信、合格由谁证明」，不涉及标准体系结构（→ 支线 01）与制定流程（→ 支线 02）。

---

## 一、三个概念的分工

| 概念 | 回答 | 性质 |
|:--|:--|:--|
| 计量（metrology） | 量值是否准确、可溯源、可比较 | 测量科学 + 法制管理 |
| 标准（standard） | 依据是什么 | 技术文件 |
| 合格评定（conformity assessment） | 是否满足要求、由谁证明 | 证明活动与程序 |

> 链条：**标准给要求 → 计量保证测量可信 → 合格评定据此作出判定**。

## 二、单位制（SI）

### 七个基本单位

| 量 | 单位 | 符号 |
|:--|:--|:--:|
| 时间 | 秒 | s |
| 长度 | 米 | m |
| 质量 | 千克 | kg |
| 电流 | 安培 | A |
| 热力学温度 | 开尔文 | K |
| 物质的量 | 摩尔 | mol |
| 发光强度 | 坎德拉 | cd |

> **2019 年 SI 修订**：七个基本单位全部改由**物理常数**定义（ΔνCs · c · h · e · k · N_A · K_cd），不再依赖实物基准（如国际千克原器）。意义：定义在任何时间、地点可复现。

### 导出单位与前缀

- 导出单位 = 基本单位的幂次组合；部分有专名：Hz · N · Pa · J · W · C · V · F · Ω · S · Wb · T · H · °C · lm · lx · Bq · Gy · Sv · kat。
- 十进前缀：Y/Z/E/P/T/G/M/k · m/µ/n/p/f/a/z/y，跨 10²⁴ 至 10⁻²⁴。

## 三、计量的三个分支

| 分支 | 关注 | 典型活动 |
|:--|:--|:--|
| 科学计量 | 定义、基准、前沿测量 | 国家计量院建立基准、参与国际比对 |
| 工业 / 应用计量 | 生产与检测中的准确测量 | 校准、测量不确定度评定、在线测量 |
| 法制计量 | 涉及公平交易、健康安全、环境的强制管理 | 强制检定、计量器具型式批准、市场监督 |

### 校准 vs 检定 vs 检测

| 活动 | 性质 | 输出 | 是否判定合格 |
|:--|:--|:--|:--:|
| 校准（calibration） | 技术操作，建立示值与参考标准的对应 | 校准证书 + 测量不确定度 | 否（只给量值关系） |
| 检定（verification） | 法制行为，按规程全面评定 | 检定证书 / 不合格通知书 | 是 |
| 检测（testing） | 按方法测特性 | 检测报告 | 通常按限值判定 |

> **量值溯源链**：SI 定义 → 国家基准 → 副基准 / 工作基准 → 标准器 → 工作计量器具。每一环都需**不间断的校准链条**与**不确定度**支撑。

## 四、合格评定

ISO/IEC 17000 将合格评定定义为：**证明产品、过程、体系、人员或机构满足规定要求的活动**。

| 工具 | 做法 | 主体 |
|:--|:--|:--|
| 抽样 | 从总体中取代表性样本 | 检测 / 检验机构 |
| 测试（testing） | 按标准方法测特性 | 实验室 |
| 检验（inspection） | 对产品/装置/过程作符合性检查 | 检验机构 |
| 认证（certification） | 第三方书面保证 | 认证机构 |
| 认可（accreditation） | 对机构**能力**的承认 | 认可机构（如 CNAS） |
| 供方符合性声明（SDoC） | 第一方自我声明 | 供方 |

### 认证的常见对象

| 对象 | 例 |
|:--|:--|
| 产品 | CCC 强制性产品认证 · CE 标志（欧盟法规框架） |
| 管理体系 | ISO 9001 · ISO 14001 · ISO/IEC 27001 |
| 人员 | 审核员、检验员资格 |
| 服务 | 服务认证 |

> 认可 ≠ 认证：**认可是对「机构有没有能力做」的承认**，认证是对「产品/体系符不符合」的证明。

## 五、合规与市场监督

| 机制 | 说明 |
|:--|:--|
| 技术法规 | 强制执行的法律文件；标准常被**引用**而获得约束力 |
| 强制性认证 | 未获认证不得出厂 / 销售 / 进口（如 CCC） |
| 监督抽查 | 事后监管，公布不合格名单 |
| 召回 / 下架 | 发现缺陷后的纠正措施 |
| WTO/TBT 协定 | 技术法规、标准、合格评定程序不得构成不必要的贸易障碍；须通报与协商 |

> **标准 vs 技术法规**：标准原则上是**自愿性**技术依据；一旦被法规引用，相关条款即产生**强制力**。这是「合规」的入口。
