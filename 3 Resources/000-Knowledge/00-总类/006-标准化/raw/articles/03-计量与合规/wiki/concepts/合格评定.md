# 合格评定 Conformity Assessment

## 定义

合格评定是**证明产品、过程、体系、人员或机构满足规定要求的活动**（ISO/IEC 17000）。它把「标准的要求」转化为「可被信任的结论」。

## 工具箱

| 工具 | 做法 | 主体 |
|:--|:--|:--|
| 抽样 | 取代表性样本 | 检测 / 检验机构 |
| 测试 | 按标准方法测特性 | 实验室 |
| 检验 | 对产品/装置/过程作符合性检查 | 检验机构 |
| 认证 | 第三方书面保证 | 认证机构 |
| 认可 | 对机构**能力**的承认 | 认可机构（如 CNAS） |
| 供方声明（SDoC） | 第一方自我声明 | 供方 |

## 认证的常见对象

| 对象 | 例 |
|:--|:--|
| 产品 | CCC 强制性产品认证 · CE 标志 |
| 管理体系 | ISO 9001 · ISO 14001 · ISO/IEC 27001 |
| 人员 | 审核员、检验员资格 |
| 服务 | 服务认证 |

## 认证 ≠ 认可

| 维度 | 认证 | 认可 |
|:--|:--|:--|
| 对象 | 产品 / 体系 / 人员 / 服务 | 从事评定活动的**机构** |
| 回答 | 「符不符合要求」 | 「有没有能力做评定」 |
| 主体 | 认证机构 | 认可机构 |

## 与标准、计量的关系

```
标准给要求 → 计量保证测量可信 → 合格评定作出判定
```

## 合规与贸易

- 技术法规可引用标准，使标准产生强制力；
- 强制性认证（CCC）是市场准入条件；
- WTO/TBT 协定要求合格评定程序不构成不必要的贸易障碍。
