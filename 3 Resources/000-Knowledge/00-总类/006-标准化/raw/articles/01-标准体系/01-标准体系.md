# 01 标准体系

> **支线 01 / UDC 006** — 标准体系（Standards System）：由标准组成的、按内在联系形成的**科学有机整体**。
> 所属：[[006-标准化|006 标准化]]（支线 01）。
> 落位：`006-标准化/raw/articles/01-标准体系/`。
> 关注「有哪些标准、怎样分层、彼此怎样配套」，不涉及标准如何制定（→ 支线 02）与如何合格评定（→ 支线 03）。

---

## 一、标准体系的三层含义

| 层 | 含义 | 回答的问题 |
|:--|:--|:--|
| 集合 | 一定范围内的标准总和 | 有哪些标准？ |
| 结构 | 按层级、对象、专业形成的层次与配套关系 | 谁管谁？谁引用谁？ |
| 功能 | 整体覆盖某领域，避免遗漏与冲突 | 够不够用？有没有打架？ |

> 判定要点：**单个标准不成体系**。体系的价值在于「覆盖完整 + 层次清晰 + 边界不重叠」。

## 二、层级：适用范围递减，要求递增

| 层级 | 适用范围 | 典型代号 | 说明 |
|:--|:--|:--|:--|
| 国际 | 全球 | ISO · IEC · ITU | 自愿采用；进入贸易/法规后具事实约束力 |
| 区域 | 区域经济组织 | EN（CEN · CENELEC · ETSI） | 如欧盟协调标准，支撑法规推定符合 |
| 国家 | 一国 | 中国 GB / GB/T / GB/Z · 美国 ANSI · 德国 DIN · 英国 BS · 日本 JIS | 中国分强制性（GB）与推荐性（GB/T） |
| 行业 | 行业 | 中国 YY（医药）· JB（机械）· HG（化工） | 2018 年《标准化法》后不再设强制性行业标准 |
| 地方 | 省级行政区 | DB + 行政区划代码 | 仅限地方自然条件、风俗习惯等特殊要求 |
| 团体 | 学会 / 协会 / 产业联盟 | T/ 前缀（如 T/CESA） | 团体标准，市场自主制定，可高于国标 |
| 企业 | 单一组织 | Q/ 前缀 | 企业标准，**不得低于**强制性标准 |

> **层级不变量**：上级标准定「底线与通用语言」，下级标准定「更严或更具体」。下位标准严于上位标准是常态，宽松则须有依据。
>
> 中国标准层级（2018 年《标准化法》修订后）：**国家 · 行业 · 地方 · 团体 · 企业** 五级；国际/区域标准不属于国内法定层级，通过「采用」进入。

## 三、类型：按标准化对象划分

| 类型 | 内容 | 例 |
|:--|:--|:--|
| 基础 / 术语 | 概念、术语、符号、分类、编码 | GB/T 20000.1 标准化工作指南 |
| 产品 | 品种、规格、性能、技术要求 | 产品标准 |
| 方法 / 试验 | 试验、测量、检验、分析方法 | 试验方法标准 |
| 过程 / 服务 | 流程、操作规程、服务规范 | 服务标准 |
| 安全 / 卫生 / 环保 | 限值、防护、排放 | 多为强制性 |
| 管理 | 管理体系、评价、审核 | ISO 9001 · ISO 14001 |

> 按**约束力**另分：强制性标准（必须执行，中国仅限保障人身健康、生命财产安全、国家安全、生态环境安全及经济社会管理基本需要的技术要求）与推荐性标准（自愿采用，被合同/法规引用后产生约束）。

## 四、标准体系表

标准体系的落地形式是**体系表**（GB/T 13016《标准体系构建原则和要求》）：

| 组成 | 内容 |
|:--|:--|
| 层次结构图 | 按专业/对象分层，标明上下位与并列关系 |
| 标准明细表 | 逐项列出标准号、名称、状态（已发布 / 在研 / 待制定） |
| 统计表 | 按层级、类型、标龄统计覆盖与缺口 |
| 编制说明 | 范围、依据、边界、与相邻体系的接口 |

**构建原则**：目标明确 · 全面成套 · 层次恰当 · 划分清楚 · 避免重复交叉。

> 体系表不是一次画完的静态图：它随技术演进与标准复审（一般 5 年）持续修订。
