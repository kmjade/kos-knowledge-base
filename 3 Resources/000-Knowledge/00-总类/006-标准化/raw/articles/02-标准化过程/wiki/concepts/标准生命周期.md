# 标准生命周期 Standards Lifecycle

## 定义

标准生命周期指一项标准从**需求识别到废止**的全过程。每个阶段都有明确输入、输出与放行条件，构成阶段门（stage-gate）。

## 九个阶段

| 阶段 | 主要动作 | 产出 |
|:--|:--|:--|
| 预研 / 提案 | 需求识别 · 必要性论证 · 查新 | 提案 |
| 立项 | 评估 · 公示 · 计划下达 | 立项批复 |
| 起草 | 起草组 · 试验验证 | 工作组草案（WD）+ 编制说明 |
| 征求意见 | 公开征求意见（国标一般 ≥60 天） | 征求意见稿（CD） |
| 审查 | 技术委员会审查 · 协商一致 | 送审稿（DS） |
| 批准发布 | 行政批准 · 编号 · 公告 | 标准文本 |
| 出版 / 实施 | 出版 · 宣贯 · 过渡期 | 现行标准 |
| 复审 | 周期性评估（一般 ≤5 年） | 继续 / 修订 / 废止 |
| 废止 | 公告 · 过渡安排 | 作废标准 |

## 两条路径

| 路径 | 适用 | 特点 |
|:--|:--|:--|
| 常规程序 | 新制定、重大变化 | 全阶段 · 周期长 · 共识充分 |
| 快速程序 | 采用成熟国际标准 / 有限修订 | 复用既有共识，缩短周期 |

## 核心不是「写完文本」

而是**协商一致**与**可验证**：程序正义（公开、透明、可追溯）决定标准的合法性。
