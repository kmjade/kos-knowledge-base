# 阿萨比亚（ʿaṣabiyya）

## 定义

Ibn Khaldun（14 世纪《穆卡迪玛》）提出的**社会凝聚力／团结纽带**概念：边缘群体的强纽带带来战斗力与纪律，据此建立王朝。

## 机制

**循环而非线性**：

```
边缘群体（强 ʿaṣabiyya）
  → 征服 · 建朝
  → 城市生活 · 奢靡
  → 三代之后纽带削弱
  → 被新的边缘群体取代
```

## 为什么至今有用

它预测的是**组织活力的代际衰减**，可类比于创业公司制度化后的动力丧失 —— 是**最早的系统性兴衰理论**，比近代社会科学的同类模型早了四百年。

## 限度

- 「三代」是**观察归纳**，不是定律；
- 无法解释为何某些王朝能维持更久（制度、财政、外部环境未进入模型）。
