# 03 进步与变迁

> **支线 03 / UDC 008** — 进步与变迁（Progress and Change）：**「进步」这个观念从哪来、凭什么成立、代价由谁承担**。
> 所属：[[008-文明与文化|008 文明与文化]]（支线 03）。
> 落位：`008-文明与文化/raw/articles/03-进步与变迁/`。
> 本支线处理**进步观的谱系与现代化的理论争论**，不收具体经济史、技术史与发展政策——那些归 `300-Social/33-经济学` 与 `600-Technology`。

## 一、进步观的谱系：循环 → 线性 → 进步

**「进步」不是常识，而是一个有生日的历史产物。**

| 阶段 | 时间观 | 代表 |
|:--|:--|:--|
| **循环论** | 治乱兴衰往复，无终极方向 | 希腊（柏拉图的政治循环）· 印度（劫波）· 中国（五德终始 · 治乱循环） |
| **线性救赎史** | 时间有起点、有终点，意义在终点 | 基督教历史神学（奥古斯丁） |
| **世俗化进步论** | 终点被去掉，方向保留：**未来必然更好** | 启蒙（Turgot 1750 · Condorcet 1795 · Kant） |
| **进步作为信念** | 从描述变成**规范要求** | 19 世纪（Bury《进步的观念》1920 系统梳理） |

关键转化在**第三步**：基督教的「终点」被移除，但**方向感被保留下来**，装进了世俗历史。于是「未来优于过去」从一个**信仰**变成了许多人以为的**事实**。

> 📌 **Bury 的判据**（1920）：进步观 = 「文明已经、正在、并将继续朝某个方向前进」的**综合假说**。它需要**跨代比较**与**方向判断**，而这两者都难以证成。

## 二、19 世纪：社会进化论及其政治用途

| 理论 | 主张 |
|:--|:--|
| Comte 三阶段 | 神学 → 形而上学 → 实证（知识形态的进步） |
| Spencer | 社会如有机体，从同质到异质（**社会达尔文主义的思想源头**） |
| Morgan / Engels | 蒙昧 → 野蛮 → 文明（阶段论，见支线 01） |

> ⚠️ **这套理论的用途必须明写**：它把**欧洲的当下**设为标尺，把其他社会定位在「尚未到达」，从而为殖民、同化与「文明使命」提供了**看似科学的正当性**。这不是理论的边缘瑕疵，而是它的**主要社会功能**。

## 三、20 世纪：进步信念的碎裂

四重打击，逐层剥掉了「必然更好」的假设：

1. **两次大战与极权**：技术最先进的国家做出最系统化的屠杀 —— 工具理性与道德进步**不相关**；
2. **核武器与生态危机**：进步的技术成果同时是**灭绝与不可逆损害的手段**；
3. **去殖民与全球不平等**：贫困被重新解释为**结构性产物**，而不是「发展阶段落后」；
4. **后现代对元叙事的怀疑**（Lyotard 1979）：不再相信有一个统摄一切、必然向善的历史脚本。

> 📌 **结果不是「进步不存在」，而是「进步不能再免论证」**。任何进步主张现在都必须回答：**在什么指标上、对谁、在多长时间里、以什么为代价**。

## 四、现代化理论：主张与反击

### 主张（1950s–60s）

| 代表 | 核心 |
|:--|:--|
| Rostow《经济成长的阶段》1960 | 传统 → 起飞前提 → 起飞 → 成熟 → 大众高消费（**五阶段**） |
| Parsons 模式变量 | 特殊主义 → 普遍主义、归属 → 成就、弥散 → 专一（现代化 = 结构分化） |

**隐含假设**：现代化 = **西方化**；它是**终点收敛**的过程；先发国家的路径可被后发国家复制。

### 反击（1970s– ）

| 批评 | 要点 |
|:--|:--|
| **依赖理论**（Prebisch · Frank） | 边缘的「欠发达」不是落后，而是**被核心的剥削关系生产出来的** |
| **世界体系**（Wallerstein） | 核心 / 半边缘 / 边缘是**同一体系内的位置**，不是先后顺序 |
| **后殖民研究** | 「现代」与「传统」的二分本身是殖民知识的产物 |
| **多重现代性**（Eisenstadt） | 现代性有多个文化纲领，不是单一模板的复制 |
| **历史制度主义** | 制度由**关键节点与路径依赖**塑形，不存在「自然趋同」 |

> 📌 **当前较稳的立场**：**结构分化（专业化、城市化、官僚化）确有跨社会共性，但它的文化形式与结果高度分叉。** 「现代化」作为描述有限成立，作为**处方**不成立。

## 五、技术与文明：谁塑造谁

| 立场 | 主张 | 主要弱点 |
|:--|:--|:--|
| **技术决定论** | 技术按其内在逻辑推进，社会随之改变 | 解释不了**同样的技术在不同社会结果不同** |
| **社会建构论**（SCOT, Bijker / Pinch） | 技术形态由相关社会群体的协商决定，「闭合」后才显得必然 | 容易低估物质约束与权力不对称 |
| **技术政治**（Winner 式） | 技术安排本身**分配权力**（谁必须适应谁） | 需要具体的历史—制度分析，难一般化 |

> 📌 **实用结论**：问「这项技术会带来什么」时，先问 **它把成本转移给了谁、它降低了谁的协调成本**。技术很少决定结果，但它**重排了胜负条件**。

### 大加速与人类世

20 世纪中叶后，人口、能耗、材料、氮循环、物种灭绝速率**同时陡升**（「大加速」）。Crutzen 提出「人类世」，其学术价值在于：**人类活动已成为地质尺度的力量**，因此「进步」必须计入**不可逆性与代际外部性**。

### 风险社会（Beck）

现代化在解决旧风险（饥荒、疫病）的同时**生产新风险**（核、化学、气候），而新风险的特点是：**不可感知、跨代、无补偿对象**。这直接瓦解了「以损失可计算」为前提的保险与问责逻辑。

## 六、怎样算「更好」：指标的战争

| 指标 | 长处 | 硬伤 |
|:--|:--|:--|
| GDP | 可加总、可比、高频 | 不计分配、不计环境、不计无偿劳动；**灾难与诉讼也计入增长** |
| HDI | 含健康与教育 | 仍是均值，掩盖内部差距 |
| 主观幸福感 | 直接测「人怎么觉得」 | **Easterlin 悖论**：收入上升到某点后，幸福不再随之上升（长期、跨国层面） |
| 预期寿命 / 婴幼儿死亡 | 对分配与公共卫生敏感，较难造假 | 不反映生活质量与自主性 |
| 不平等指标（如顶层收入占比） | 揭示**增长归谁** | 数据可得性差（避税、财富口径） |

> 📌 **四条必问**：**在什么指标上进步？对谁？多久？代价记在谁的账上？** 少任何一条，结论就是宣传。

## 七、代价转移：进步的成本账

**「进步」的账面上常有看不见的支出项：**

| 代价类型 | 例 |
|:--|:--|
| **空间转移** | 污染与高耗能产业迁往环境规制较弱的地区 |
| **时间转移** | 资源耗竭与气候损害推给后代（**代际外部性**） |
| **劳动转移** | 效率收益建立在无酬照护与不均衡工时的重新分配上 |
| **意义转移** | 可计算的产出被高估，不可计算的关系被系统性低估 |

> ⚠️ **这不是「所以进步是假的」**。这是要求**任何进步叙事附带成本栏**。把成本栏留白的进步论，通常是**收益方的视角**。

## 八、变迁 ≠ 进步：去掉目的论

| 概念 | 是否需要方向判断 |
|:--|:--|
| **变迁**（change） | 否 —— 只描述差异 |
| **发展**（development） | 弱 —— 通常指规模 / 复杂度上升，**不蕴含更好** |
| **进步**（progress） | 是 —— 必须给出评价标准与受益者 |

> 📌 **这一支线的核心纪律**：**默认用「变迁」，只有在明确给出指标、对象与代价后，才允许使用「进步」。**

## 十、核心问题

> 当「未来会更好」不再是默认前提，**我们还能凭什么说某件事是进步**——以及，这个说法必须附上哪些条件才算数？
