## 一、载体谱系

| 载体 | 时期 / 地域 | 特点 |
|:------|:------|:------|
| 泥板 | 古代两河 | 楔形文字压印；烧制后可长期保存 |
| 甲骨 | 商代中国 | 契刻；龟甲、兽骨 |
| 金石 | 古代多地 | 青铜铭文 · 石碑；耐久、公开 |
| 竹简 · 木牍 | 先秦至魏晋 | 编连成册；「册」「编」等字形来源 |
| 帛书 | 先秦至汉 | 轻便、昂贵；易朽 |
| 纸 | 东汉以后 | 纤维制成；传播最广的书写载体 |
| 羊皮纸 / 犊皮纸 | 欧洲 · 近东 | 动物皮；可刮改重用 |
| 棕榈叶 · 贝叶 | 南亚 · 东南亚 | 刻写后涂墨；热带环境 |
| 桦树皮 | 印度 · 东欧 | 轻便；易脆 |
| 电子屏幕 | 当代 | 像素显示；无固定物质痕迹 |

> 载体不是中性的：材料成本决定谁能写、写多少；载体形态决定装帧、检索与保存方式。

## 二、书写工具

| 工具 | 书写效果 |
|:------|:------|
| 刻刀 · 凿 | 线条硬直；甲骨、金石 |
| 芦苇笔 | 早期近东；线条有弹性 |
| 毛笔 | 提按变化丰富；汉字书写的核心工具 |
| 羽毛笔 | 欧洲中世纪；线条随削制而异 |
| 硬笔（钢笔 / 铅笔 / 圆珠笔） | 线条稳定；现代日常书写 |
| 触控笔 · 手写笔 | 数字输入；压感与倾斜可记录 |

- 工具与字形互相塑造：毛笔的提按促成汉字的笔锋与章法；硬笔普及后字形趋于简化、匀称。
- 工具的**磨损与更换**会在手迹中留下可观察的差异（笔尖粗细、墨流变化）。

## 三、墨与着色材料

| 材料 | 说明 |
|:------|:------|
| 墨块 · 墨锭 | 松烟 / 油烟 + 胶；研磨后使用 |
| 墨汁 | 现代液体墨；成分配比影响保存 |
| 墨水 | 铁胆墨 · 蓝黑墨；酸性可能导致纸张脆化 |
| 颜料 | 朱砂 · 石青 · 金泥等；用于批注、题跋、装饰 |
| 隐显墨 | 特殊用途；需加热或试剂显现 |

> 墨色、光泽、渗透深度是鉴定与年代判断的重要线索，但受保存环境影响，不能单独作为结论。

## 四、制作工艺

| 工艺 | 要点 |
|:------|:------|
| 造纸 | 原料（麻 / 树皮 / 竹 / 棉）→ 蒸煮 → 打浆 → 抄纸 → 压榨 → 干燥 |
| 简牍制作 | 削制 → 杀青（去汁防蠹）→ 编连 |
| 帛书制作 | 织造 → 书写；帛面处理影响吸墨 |
| 装帧 | 卷轴 · 经折 · 蝴蝶装 · 线装 · 平装 |
| 印刷 | 雕版 · 活字；与手写形成不同的物质痕迹 |

- 造纸术的传播改变了书写的社会成本，是书写史的关键转折。
- 工艺细节（帘纹、纤维、胶料）可用于断代与产地判断。

## 五、材料分析

| 方法 | 用途 |
|:------|:------|
| 纤维分析 | 判断纸 / 帛原料与产地 |
| 墨迹成分分析 | 区分墨种、年代与书写顺序 |
| 光谱 / 多光谱 | 显现褪色、覆盖、修改痕迹 |
| X 射线 / 红外成像 | 无损观察内部结构、隐藏文字 |
| 碳十四测年 | 有机载体的年代范围（有误差） |
| 显微观察 | 笔痕、刻痕、纤维损伤 |

> 材料分析必须与文献考证、笔迹比对**联合使用**；单一检测不足以定真伪。

## 六、保存与修复

| 风险 | 对策 |
|:------|:------|
| 湿度波动 | 恒温恒湿；避免频繁取出 |
| 光照 | 控制照度与紫外；展陈限时 |
| 酸化 | 脱酸处理；中性材料封装 |
| 虫害 / 霉变 | 低温干燥 · 防虫材料 · 隔离 |
| 机械损伤 | 无酸文件夹 · 平放 / 专用支架 |
| 修复 | 最小干预 · 可逆性 · 材料相容性 |

- 修复伦理：**可识别性**与**可逆性**优先，避免过度修复掩盖历史信息。
