## 一、起源的判据

### 1.1 前文字与文字

| 类型 | 符号对应 | 例子 |
|:------|:------|:------|
| 记号 / 图画 | 直接表示事物或概念 | 岩画 · 陶器刻符 · 结绳 |
| 半文字（semasiographic） | 表示意义，不绑定语言 | 交通标志 · 数学符号 · 乐谱 |
| 完整文字（glottographic） | 记录语言单位（词 / 音节 / 音素） | 楔形文字 · 汉字 · 字母 |

- 判据的核心不是「能否表意」，而是**能否按语言读出**。
- 记账符号（token / bulla）是先于文字的重要前身，但它记录的是**数量与物**，不是语句。

> 争议：新石器时代的刻划符号（半坡 · 贾湖 · 欧洲温查符号）算不算「文字」？主流看法是**前文字**，证据不足以证明其记录语言。

### 1.2 独立发明的标准

| 标准 | 说明 |
|:------|:------|
| 系统性 | 有一批固定符号与组合规则 |
| 语言绑定 | 符号对应词 / 音节 / 音素 |
| 连续使用 | 不是孤立的一次性记号 |
| 自主发生 | 无外部文字体系的直接输入 |

## 二、独立起源中心

| 中心 | 时间 | 代表 | 备注 |
|:------|:------|:------|:------|
| 美索不达米亚 | 约公元前 3200 年 | 楔形文字 | 从记账泥筹演变而来 |
| 埃及 | 约公元前 3200 年 | 圣书体 | 是否受两河启发仍有争论 |
| 中国 | 约公元前 1200 年（商） | 甲骨文 | 更早的刻符与文字之间的连续性待证 |
| 中美洲 | 约公元前 900–300 年 | 萨波特克文 · 玛雅文字 | 独立发展 |

- **印度河流域文字**（约公元前 2600 年）：成熟但**未破译**，是否独立起源无法定论。
- **克里特线形文字 A**：未破译；线形文字 B 已证为希腊语。
- 单源论（所有文字源自一处）已基本被放弃；多源独立发明是主流框架。

## 三、起源的动因

| 动因 | 说明 |
|:------|:------|
| 记账与仓储 | 剩余产品、贡赋、贸易需要可核查的记录 |
| 行政与国家 | 人口、土地、赋税、法令的规模化管理 |
| 宗教与礼仪 | 祭祀名录、卜辞、铭文 |
| 纪念与权力 | 王名、战功、法典的公开宣示 |

> 文字并非「文明自然而然会发明」的东西：多数社会在没有文字的情况下运行了数千年。文字是**特定制度需求**的产物。

## 四、传播路径

### 4.1 近东—地中海线

```
楔形文字 ──→ 埃兰 · 赫梯 · 乌加里特
埃及圣书体 ──→ 西奈原始字母 ──→ 腓尼基字母
                                  ├──→ 希腊字母 ──→ 拉丁字母
                                  │                 └──→ 西里尔字母
                                  └──→ 阿拉米字母 ──→ 阿拉伯字母
                                                     └──→ 希伯来字母
```

- **腓尼基字母**是字母传播的关键节点：辅音音素文字，随贸易扩散至地中海。
- 希腊字母加入元音字母，形成完整的**音素字母**体系。

### 4.2 南亚—东南亚线

- 婆罗米系文字（Brahmi）→ 天城文 · 泰文 · 藏文 · 东南亚诸文字。
- 婆罗米文字的来源有「阿拉米影响说」与「本土起源说」之争，尚无定论。

### 4.3 东亚线

| 方向 | 结果 |
|:------|:------|
| 汉字 → 日本 | 万叶假名 → 平假名 / 片假名 |
| 汉字 → 朝鲜半岛 | 吏读 · 乡札 → 谚文（1443） |
| 汉字 → 越南 | 喃字；现代转用拉丁化国语字 |

> 汉字文化圈的传播不是「照搬」，而是**借形造字**：借用字形，按本语言重新分配读音与用法。

### 4.4 美洲线

- 中美洲文字在区域内部传播（萨波特克 → 玛雅等），与旧大陆体系无直接联系。

## 五、分化与借用

| 机制 | 说明 | 例子 |
|:------|:------|:------|
| 借形借音 | 连字形与读音一起借 | 日文音读汉字 |
| 借形改音 | 借字形，按本语言读 | 日文训读 · 越南喃字 |
| 借意造字 | 借构字法自造新字 | 日制汉字（国字）· 韩制汉字 |
| 字母改造 | 增删字母、加附加符号 | 拉丁字母的变体 · 西里尔字母 |
| 书写方向改变 | 从左到右 / 右到左 / 竖排 | 希腊早期行款 · 阿拉伯右行 |

- 文字传播常伴随**正字法定型**：一旦与教育、宗教、行政绑定，改动成本急剧上升。
- 文字也可以**被替换**：土耳其语 1928 年由阿拉伯字母改用拉丁字母；越南由喃字改用国语字。

## 六、争论与未决

| 争论 | 现状 |
|:------|:------|
| 埃及文字是否受两河启发 | 时间接近，接触证据不足；「独立发明 + 刺激扩散」均有可能 |
| 中国文字的独立起源 | 多数学者主张独立；新石器刻符与甲骨文之间的缺环仍是问题 |
| 印度河流域文字 | 未破译，语系归属与是否独立均无定论 |
| 单源 vs 多源 | 多源为主流；「所有字母同源」仅适用于部分体系 |
| 文字与文明 | 文字不是文明的必要条件，而是特定治理结构的产物 |
