# 003.6 思维图形化表示

> **UDC 003.6** — 其他图形表示（Other types of graphic representation of ideas）：**图表 · 图解 · 地图 · 记谱 · 符号 · 信息图**。
> 所属：[[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003-书写体系与文字|003 书写体系与文字]]。
> 本库回答：**当文字不够用时，人如何用图形组织与传达思想？**
> 文字类型见 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.2-文字类型/003.2-文字类型|003.2 文字类型]]；符号编码见 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.08-字符与编码/003.08-字符与编码|003.08 字符与编码]]。

> ⚠️ **类号说明**：UDC `003.6` 的权威标目未能在线核实；本库按其常见语义「其他图形表示」作**局部子库编号**，主题名取用户裁定「思维图形化表示」。

## 核心问题

| 问题 | 本库回答 |
|:------|:------|
| 图形表示与文字有何不同 | 图形直接呈现关系与结构，不必先编码为语言 |
| 有哪些主要图形类型 | 统计图 · 图解 · 地图 · 网络图 · 记谱 · 符号 · 信息图 |
| 图形为什么有效 | 外部认知 · 双编码 · 空间推理 · 降低工作记忆负担 |
| 图形如何误导 | 视觉变量滥用 · 比例失真 · 选择性呈现 |

---

## 一、界定：文字之外

| 类型 | 是否记录语言 | 说明 |
|:------|:------|:------|
| 文字（glottographic） | 是 | 可按语言读出；见 003 主干 |
| 半文字 / 图形表示（semasiographic） | 否 | 直接表示意义与关系；本库 |
| 图像 / 绘画 | 否 | 以形象再现为主；艺术与图像研究另属 |

- 图形表示的核心不是「画得像」，而是**把关系显式化**：层级、流程、比例、位置、连接。
- 同一内容可以用文字、表格、图形三种方式表达；选择取决于**要突出什么关系**。

## 二、类型谱系

| 类型 | 主要用途 | 例子 |
|:------|:------|:------|
| 统计图 | 展示数量与分布 | 柱状图 · 折线图 · 散点图 · 箱线图 |
| 示意图 / 图解 | 解释结构与机制 | 流程图 · 电路图 · 解剖图 · 爆炸图 |
| 网络图 | 展示连接与路径 | 节点—连线图 · 树状图 · 桑基图 |
| 地图 | 展示空间分布 | 地形图 · 专题地图 · GIS 图层 |
| 思维导图 / 概念图 | 组织概念与联想 | 放射状导图 · 概念关系图 · 论证图 |
| 记谱法 | 记录时间性行为 | 五线谱 · 简谱 · 六线谱 · 拉班舞谱 |
| 符号系统 | 快速传达指令或状态 | 图标 · 象形符号 · 交通标志 · emoji |
| 科学记号 | 形式化表达 | 数学公式 · 化学结构式 · 费曼图 |
| 信息图 | 综合叙事 | 数据故事 · 解释性长图 |

> 类型之间常混合：一张信息图可以同时包含统计图、地图、图标与文字。

## 三、视觉变量

图形语言有一套可组合的「词法」：

| 变量 | 可编码的差异 |
|:------|:------|
| 位置 | 空间坐标；最精确的视觉变量 |
| 大小 | 数量 · 重要性 |
| 形状 | 类别 · 身份 |
| 明度 / 颜色 | 类别 · 顺序 · 强调 |
| 方向 | 趋势 · 朝向 |
| 纹理 | 类别 · 材质 |
| 连接 | 关系 · 路径 · 隶属 |

- **位置**通常承载最精确的定量信息；面积与角度次之；颜色最不精确。
- 一张图能有效编码的变量数量有限，堆叠过多会牺牲可读性。

## 四、认知功能

| 机制 | 说明 |
|:------|:------|
| 外部认知 | 把信息卸载到外部表征，减少记忆负担 |
| 双编码 | 语言 + 图像双通道并行，提升回忆 |
| 空间推理 | 利用位置与距离进行推断 |
| 图解推理 | 通过结构关系发现文字中不明显的关系 |
| 共同注意 | 图形作为协作时的共享参照物 |

> 图形不是「装饰」，而是**思维工具**：画图的过程本身会改变人理解问题的方式。

## 五、设计与误用

| 问题 | 表现 |
|:------|:------|
| 比例失真 | 截断坐标轴 · 面积与数值不成比例 |
| 视觉噪音 | 过度装饰 · 无关元素挤占信息 |
| 编码冲突 | 同一颜色表示不同类别 |
| 选择偏倚 | 只展示有利区间 / 样本 |
| 可及性不足 | 低对比度 · 仅靠颜色区分 · 缺替代文本 |
| 误导性地图 | 投影变形 · 分级统计口径不一致 |

> 判断一张图，先问：**它想让读者比较什么？** 再看视觉编码是否服务于这个比较。
