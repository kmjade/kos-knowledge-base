# 形声字 Phonosemantic Characters

## 定义

**形声字**由**形符**（表意构件）与**声符**（提示读音的构件）组合而成，是六书之一，也是汉字系统中最具能产性的造字方式。例：江（氵表水 + 工示音）· 河（氵 + 可）· 铜（钅表金属 + 同示音）· 妈（女 + 马）。

## 要点

| 维度 | 说明 |
|:------|:------|
| 结构 | 形符 + 声符（多为左右 / 上下结构） |
| 形符作用 | 提示意义类别，不精确限定词义 |
| 声符作用 | 提示读音，不保证完全同音 |
| 能产性 | 新字、方言字、科技用字多沿用此模式 |
| 占比 | 现代汉字中占绝大多数 |

- **声符表音的可靠性随时代下降**：语音演变使许多形声字今读与声符不再一致（如「江」不读「工」）。
- **形符的语义范围较宽**：氵只表示与水相关，不区分江 / 河 / 湖 / 海的具体差别。
- 形声化意味着汉字系统**同时使用语义与语音两条线索**，这是它区别于纯表意或纯表音系统的关键。

## 要义

- 「汉字是表意文字」的说法，在形声字占多数的事实面前必须修正为**意音文字**。
- 形声结构使汉字**无需无限造新符号**：复用有限构件即可生成新字，是系统可持续的核心机制。
- 声符的提示性也解释了**见字猜音**的可能与限度：同声符字往往音近，但不保证同音。
