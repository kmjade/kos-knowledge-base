# 汉字 Hanzi

## 定义

**汉字**是记录汉语的书写符号系统，以**单个方块字符**为单位，同时承载**意义**与**语音**信息。按文字类型学分，汉字不是字母文字，而是**语标 / 意音文字**：一个字符通常对应一个语素（音节），形声字中一部分构件表意、一部分构件提示读音。汉字的最小书写单位是**笔画**，结构单位是**部件**，检索单位常取**部首**。

## 要点

| 层面 | 内容 |
|:------|:------|
| 字符单位 | 字 · 部件 · 笔画 · 部首 |
| 类型定位 | 语标 / 意音文字；非字母、非纯表意 |
| 构形原则 | 六书（象形 · 指事 · 会意 · 形声 · 转注 · 假借） |
| 字体形态 | 篆 · 隶 · 楷 · 行 · 草（书写形态，不是编码单位） |
| 历时主线 | 甲骨 → 金文 → 战国文字 → 小篆 → 隶书 → 楷书 |
| 共时变体 | 繁简 · 正异 · 新旧字形 · 地区字形标准 |

- **形声字占现代汉字绝大多数**，因此把汉字称为「表意文字」并不准确；它是**意音文字**。
- **字符与字形必须分开**：Unicode 码位标识抽象字符，具体字形由字体与地区标准决定。
- 汉字同时是**语言单位**（语素 / 音节）与**视觉单位**（方块构形），这一双重性决定了它在正字法、检索与编码上的特殊问题。

## 要义

- 「汉字是表意文字」是常见简化；更准确的表述是**意音文字**，且形声化是汉字系统维持生命力的关键机制。
- 理解汉字要分三层：**字符层**（哪个字）· **字形层**（写成什么样）· **编码层**（在计算机里怎么表示）。
- 汉字史的关键转折是**隶变**：从描绘物象的线条转为书写笔画，奠定此后两千年的字形基础。
- 一字多形是常态（繁简 / 正异 / 新旧 / 地区），任何字符处理都必须先声明采用哪套字形标准。
