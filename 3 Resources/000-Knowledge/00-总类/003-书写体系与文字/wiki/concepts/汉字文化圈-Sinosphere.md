# 汉字文化圈 Sinosphere

## 定义

**汉字文化圈**指历史上借用汉字或据汉字创制本民族文字的东亚地区，主要包括中国、日本、朝鲜半岛、越南，以及部分周边民族政权。其纽带不是「同一种语言」，而是**共享字形与文言书写传统**：汉字长期作为书面通用语（文言）的载体，各地以不同方式用汉字记录本语言。

## 要点

| 地区 / 语言 | 关系 |
|:------|:------|
| 日本 | 汉字 + 假名混写；常用汉字表 · 音读 / 训读 |
| 韩国 | 谚文为主，汉字用于人名、古典与部分正式场合 |
| 越南 | 历史上使用喃字；现代以国语字（拉丁化）为主 |
| 其他 | 方块壮字 · 契丹大字 · 西夏文等借形或仿制文字 |

- 借用方式大致三类：**直接使用汉字**（文言）· **借形造字**（喃字、方块壮字）· **借形制符**（假名、谚文的部分构件来源）。
- **音读 / 训读**是日本借用汉字的典型双层：音读接近借入时的汉语读音，训读对应日语固有词义。
- 越南与韩国先后转向表音或拉丁化文字，说明汉字圈是**历史传播范围**，不是稳定的现行文字共同体。

## 要义

- 汉字文化圈的核心是**共享字形与书写传统**，而非语言同源或政治统一。
- 借形不等于照搬：各地都对汉字做过**本地化改造**，形成不同的字符系统与正字法。
- 研究汉字圈需区分**文字传播**（字形与书写技术）与**语言接触**（词汇、语法影响）两条线。
