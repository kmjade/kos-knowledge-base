# 汉字注音与检索 Hanzi Phonetic Notation and Lookup

## 定义

**注音**是用符号系统标注汉字读音的方法；**检索**是按某种可排序特征查找汉字的方法。两者共同解决汉字的一个结构性问题：**字符本身不直接、完整地表音**，因此需要外部标音与排序规则。

## 要点

| 方式 | 说明 | 适用 |
|:------|:------|:------|
| 反切 | 用两字（上字取声母、下字取韵调）拼读 | 传统音韵 |
| 注音符号 | 1918 年公布，声母 / 韵母 / 声调符号 | 台湾地区 |
| 汉语拼音 | 1958 年公布，拉丁字母转写 | 国际通用 · 教学 · 输入 |
| 部首检字 | 按部首 + 剩余笔画检索 | 字典 · 辞书 |
| 四角号码 | 按四角笔形编码 | 旧式工具书 |
| 笔画 / 笔顺 | 按笔画数与书写顺序排序 | 名录 · 索引 |

- **反切**是传统音韵学的核心工具，其价值在于用当时可用的字汇描述读音，而非使用字母。
- **注音符号与汉语拼音**功能重叠，分属不同地区的标准；转写时需声明方案。
- **部首检字**依赖字形，**拼音检字**依赖读音：两种排序逻辑对应汉字的两个面向。

## 要义

- 汉字系统的「不充分表音」不是缺陷，而是其类型选择的结果；注音方案是对这一特征的外部补偿。
- 检索方式决定了工具书的组织逻辑，也影响了数字化输入法的设计（拼音 / 形码 / 手写）。
- 拼音是**转写**而非文字替代：它记录读音，不承担汉字的语素区分功能（同音词问题仍在）。
