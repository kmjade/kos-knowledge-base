# 汉字编码 Hanzi Encoding

## 定义

**汉字编码**是把汉字映射为计算机可处理的数字序列的规则体系。它需要同时解决三个问题：**字符集**（收录哪些字）· **码位分配**（每个字对应哪个编号）· **编码形式**（编号如何存为字节）。汉字的字符量庞大、字形变体多，使这三点都比拉丁字母编码复杂。

## 要点

| 层面 | 内容 |
|:------|:------|
| 早期编码 | GB2312（6763 字）→ GBK → GB18030（强制国标，覆盖全部 Unicode 码位） |
| 国际编码 | Unicode CJK 统一表意文字（U+4E00 起）· 扩展区 A–H · 兼容表意文字 |
| 编码难点 | 一字多码（兼容 / 异体）· 字形差异（同一码位不同地区字形）· 增补字 |
| 输入 | 拼音 · 形码（五笔 / 仓颉）· 手写 · 语音 |
| 排版 | 横排 / 竖排 · 标点避头尾 · 中西文混排 · 全角 / 半角 |

- **GB2312 → GBK → GB18030** 是兼容式扩展：后者向前兼容前者，同时扩大字符覆盖。
- **Unicode CJK 统一表意文字**试图让同一抽象字符共享码位，但各地区字形差异导致「一码多形」。
- **兼容表意文字**区收录为兼容旧编码而保留的重复字符，是「一字多码」的主要来源。
- 编码只管**字符身份**，不管**字形外观**：字体负责渲染，地区标准负责字形选择。

## 要义

- 汉字编码的核心矛盾是**统一与差异**：统一码位便于交换，地区字形差异又要求区分呈现。
- 「字符」与「字形」必须分开：Unicode 码位标识抽象字符，具体字形由字体与地区标准决定（见 [[字形与字符-Glyph-and-Character|字形与字符]]）。
- 编码选择会直接影响**检索、排序、简繁转换与排版**，不是纯技术细节。
- 通用编码机制（UTF-8 / UTF-16 / 规范化）见 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.08-字符与编码/003.08-字符与编码|003.08 字符与编码]]；本页只收汉字特有部分。
