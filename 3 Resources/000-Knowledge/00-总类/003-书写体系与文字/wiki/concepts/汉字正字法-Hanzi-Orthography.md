# 汉字正字法 Hanzi Orthography

## 定义

**汉字正字法**是关于「哪个字形是正确 / 标准写法」的制度与规范。它处理四层叠加的变体：**繁简**（简化字 / 繁体字）· **正异**（正体 / 异体）· **新旧字形**（同一字的笔画微差）· **地区标准**（大陆 / 台湾 / 香港 / 日本等）。

## 要点

| 议题 | 要点 |
|:------|:------|
| 规范汉字 | 国家通用语言文字法框架下的字形标准 |
| 简化字 | 1956 年后推行；来源含草书楷化 · 古字 · 俗字 · 符号替代 |
| 繁体字 | 港台及海外沿用；与简化字**并非一一对应** |
| 异体字 | 同音同义异形；整理后保留正体、淘汰异体 |
| 新旧字形 | 同一字形的笔画微差（如「户」「骨」），影响检索与排版 |
| 俗字 / 讹字 | 民间书写变体；研究字形演变的重要材料 |

- **多对一**是繁简关系的常态：一个简化字可能对应多个繁体字（如「发」← 發 / 髮），反向转换必须依赖语境。
- **新旧字形差异**不改变字符身份，却会改变字形外观与部分检索结果，是数字化的隐蔽难点。
- 正字法是**制度问题，不是文字本质问题**：它规定标准，不改变汉字作为意音文字的类型属性。

## 要义

- 「一字多形」是常态：繁简、正异、新旧、地区差异四层叠加，任何字符处理都必须先声明采用哪套字形标准。
- 简化字的来源多样，因此**不能用单一规则反推繁体**；繁简转换是有损操作。
- 正字法与编码相互牵制：不同地区标准可能为同一抽象字符指定不同字形（见 [[字形与字符-Glyph-and-Character|字形与字符]]）。
