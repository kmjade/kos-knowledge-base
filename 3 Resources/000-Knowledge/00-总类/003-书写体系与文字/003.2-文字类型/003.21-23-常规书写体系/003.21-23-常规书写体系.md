# 003.21/.23 常规书写体系

> **UDC 003.21/.23** — 识字共同体用于一般目的的**常规书写体系**及其**正字法**（Conventional writing systems used for general purposes by literate communities; orthographies）。
> 所属：[[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.2-文字类型/003.2-文字类型|003.2 文字类型]]（下位范围子库）。
> 本库回答：**一个成熟文字共同体实际使用的那套书写约定，包含哪些层面？**

> ⚠️ **类号说明**：`003.21/.23` 为 UDC 的**缩写范围**（`.21` 至 `.23`，沿用主类号 003.2）。标目取自 UDC 分类表：「Conventional writing systems used for general purposes by literate communities; orthographies」。来源为二手整理，**权威标目仍待核定**。

## 核心问题

| 问题 | 本库回答 |
|:------|:------|
| 「常规书写体系」指什么 | 一个识字社会日常通用、已约定成俗的文字系统 |
| 它包含哪些层面 | 字符集 · 字形标准 · 正字法 · 标点与排版惯例 |
| 为什么单列这一层 | 文字类型学讲「符号记录什么」，这里讲「社会实际怎么用」 |
| 与 003.2 什么关系 | 003.2 是类型学总轴；003.21/.23 是其下按**成熟通用体系**切出的范围 |

---

## 一、范围与定位

| 层 | 回答的问题 | 对应类号 |
|:------|:------|:------|
| 文字类型学 | 符号记录词、音节还是音素 | 003.2 |
| **常规书写体系** | **某个识字共同体实际通用的书写约定** | **003.21/.23（本库）** |
| 正字法 | 哪个写法算标准 | 本库（orthographies 在标目内） |
| 字符编码 | 如何进入计算机 | 003.08 |

- 「常规」强调**社会约定与通用性**：不是个人手迹，也不是实验性记号系统。
- 「书写体系」在此是**成套制度**：字符、字形、拼写 / 用字规则、标点、排版惯例共同构成。
- 本库是**范围容器**，具体文字体系（如汉字、拉丁字母、假名）按类号落到下位或专题页。

## 二、共同特征

| 特征 | 说明 |
|:------|:------|
| 约定性 | 写法由共同体规范，不取决于个人偏好 |
| 通用性 | 覆盖该语言的日常书写，而非专门记号 |
| 可教学 | 可通过学校 / 辞书 / 正字法手册传递 |
| 有标准 | 存在正体、异体、新旧字形等规范区分 |
| 可扩展 | 能通过造字、借词、技术符号扩充 |

> 一个体系「成熟」的标志不是符号数量，而是**有稳定的正字法与教育传承机制**。

## 四、与 003.2 类型学的关系

| 轴 | 内容 | 是否价值排序 |
|:------|:------|:------|
| 003.2 类型学 | 语标 · 音节 · 字母 · 辅音音素 · abugida · featural | 否，描述工具 |
| 003.21/.23 常规体系 | 成熟通用体系 + 正字法 | 否，按社会使用切分 |

- 两轴**交叉而非替代**：同一个体系可以既是「字母文字」（类型），又是某语言的「常规书写体系」（制度）。
- 辅音音素文字（abjad）与元音附标文字（abugida）在 UDC 此范围中没有独立下位号，讨论时归入 003.2 类型学层面。

## 五、正字法层面

| 层面 | 内容 | 例 |
|:------|:------|:------|
| 字符集 | 哪些符号算作该系统成员 | 拉丁字母 26 字母 + 附加符号 |
| 字形标准 | 同一字符的标准写法 | 汉字新旧字形 · 拉丁字母手写体 |
| 拼写 / 用字 | 词如何写 | 英语拼写 · 汉字繁简 |
| 标点 | 断句与语气标记 | 中西标点差异 |
| 排版惯例 | 大小写 · 空格 · 行款 | 竖排 / 横排 · 全角 / 半角 |

> 正字法问题常被误当作「编码问题」；实际是**社会规范问题**，编码只是其后的一层实现。
