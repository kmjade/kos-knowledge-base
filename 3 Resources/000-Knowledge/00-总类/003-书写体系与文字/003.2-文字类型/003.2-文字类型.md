## 一、分类的基准

文字分类看的是**符号与语言单位的对应关系**，而不是字体、书写工具或地域。

| 记录单位 | 类型 | 一个符号对应 |
|:------|:------|:------|
| 词 / 语素 | 语标文字（logographic） | 一个词或语素 |
| 音节 | 音节文字（syllabary） | 一个音节 |
| 音素（辅音） | 辅音音素文字（abjad） | 一个辅音 |
| 音素（辅音 + 元音） | 字母文字（alphabet） | 一个音素 |
| 辅音 + 元音附标 | 元音附标文字（abugida） | 一个辅音 + 固有元音 |
| 区别性特征 | 特征文字（featural） | 发音特征（如谚文） |

> 现实中的文字系统几乎都是**混合体系**：日文 = 汉字（语标）+ 假名（音节）；中文 = 语标为主 + 少量记号；英文拼写保留大量历史层积。

## 二、语标文字

**符号记录词或语素**，与语音没有稳定的一一对应。

| 文字 | 说明 |
|:------|:------|
| 汉字 | 现行唯一的成熟语标体系；形声字占多数，兼表音意 |
| 古埃及圣书体 | 兼有表意、表音与限定符 |
| 楔形文字 | 从图画符号演变为音节 / 语标混合 |
| 玛雅文字 | 语标与音节符号并用 |

- 优点：跨方言、跨时代可读（文言文即例证）。
- 代价：符号量大，学习成本高；需借助注音或教育体系普及。

## 三、音节文字

**一个符号记录一个音节**，通常与辅音 + 元音的组合绑定。

| 文字 | 说明 |
|:------|:------|
| 日文假名 | 平假名 / 片假名，音节拍（mora）为单位 |
| 线形文字 B | 迈锡尼希腊语，音节表 |
| 切罗基文 |  Sequoyah 创制，音节表 |
| 彝文 | 音节文字（规范彝文） |

> 音节文字与语标文字的界线并非绝对：日文汉字可读作多个音节，假名也可作语标使用。

> 详见下位子库 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.2-文字类型/003.21-23-常规书写体系/003.22-音节文字/003.22-音节文字|003.22 音节文字]]（音节表结构 · 代表体系 · 形成路径 · 正字法）。

## 四、字母文字与辅音音素文字

### 4.1 字母文字（alphabet）

符号记录**辅音与元音音素**，理论上可用少量字母拼写全部词。

| 文字 | 特点 |
|:------|:------|
| 拉丁字母 | 全球使用最广；大小写、附加符号因语言而异 |
| 希腊字母 | 首个完整记录元音的字母体系 |
| 西里尔字母 | 斯拉夫语族为主 |
| 谚文（韩文） | 字母按音节组块，兼具特征文字性质 |

### 4.2 辅音音素文字（abjad）

**只记录辅音**，元音由读者补足或用附加符号标注。

| 文字 | 说明 |
|:------|:------|
| 腓尼基字母 | 早期辅音字母体系，字母文字的共同源头之一 |
| 阿拉伯字母 | 元音以附加符号表示，正文常省略 |
| 希伯来字母 | 辅音为主，元音符号用于教学 / 经典文本 |

### 4.3 元音附标文字（abugida）

介于辅音音素文字与音节文字之间：**辅音字母自带固有元音**，改元音用附加符号。

| 文字 | 说明 |
|:------|:------|
| 天城文 | 印地语、梵语等 |
| 泰文 | 元音符号可置于辅音上下左右 |
| 藏文 | 辅音基字 + 元音符号 |

> 详见下位子库 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.2-文字类型/003.21-23-常规书写体系/003.23-字母文字/003.23-字母文字|003.23 字母文字]]（音素原则 · 字母表结构 · 代表体系 · 形成路径 · 正字法）。

## 五、类型学的争论

| 争论 | 要点 |
|:------|:------|
| 线性进化论 | 「图画 → 语标 → 音节 → 字母」并非普遍规律；多数文字是混合演化 |
| 分类粒度 | Daniels & Bright 增列 abjad / abugida / featural，四类说被细化为六类 |
| 语标 vs 意音 | 汉字常被称为「意音文字」，强调形声字的表音成分，而非纯表意 |
| 文字与语言 | 同一语言可换用不同文字（土耳其语：阿拉伯 → 拉丁）；文字类型不决定语言类型 |

> 结论：类型学是**描述工具**，不是价值排序。「字母文字更先进」是 19 世纪的进化论偏见，不是分类学结论。
