## 一、基本概念

| 概念 | 定义 | 例子 |
|:------|:------|:------|
| 抽象字符（character） | 语言中可区分的书写单位 | 拉丁字母 A · 汉字「永」 |
| 码位（code point） | 字符在字符集中的编号 | U+0041 · U+6C38 |
| 字形（glyph） | 字体中实际绘制的形状 | A 的衬线 / 无衬线形态 |
| 编码形式（encoding form） | 码位到码元的映射规则 | UTF-8 · UTF-16 |
| 字节序列（byte sequence） | 最终存储 / 传输的二进制 | `41` · `E6 B0 B8` |

> 关键区分：**字符 ≠ 字形**。同一个码位在不同字体、不同地区标准下可以有不同字形（如「直」「骨」的日韩中写法）。

## 二、字符集

### 2.1 单字节与地区字符集

| 字符集 | 范围 | 说明 |
|:------|:------|:------|
| ASCII | 0–127 | 7 位；英文与控制字符 |
| ISO-8859-1 | 0–255 | 西欧语言；Latin-1 |
| Windows-1252 | 0–255 | 微软扩展，常见于旧网页 |
| GB2312 | 6763 汉字 | 1980；简体中文基础集 |
| GBK | 2 万余字符 | 1995；GB2312 扩展 |
| GB18030 | 全 Unicode 覆盖 | 2000 / 2005 / 2022；中国强制标准 |
| Big5 | 繁体中文 | 1984；台湾地区 |
| Shift-JIS | 日文 | 多字节，兼容 ASCII |
| EUC-KR | 韩文 | 多字节 |

- 地区字符集的核心问题是**互不兼容**：同一字节序列在不同字符集下含义不同。
- 中文环境长期存在 GB 系与 Big5 的分裂；跨地区交换必须先声明编码。

### 2.2 Unicode

| 层面 | 说明 |
|:------|:------|
| 码位空间 | U+0000–U+10FFFF，共 17 个平面 |
| BMP | U+0000–U+FFFF，基本多文种平面 |
| 辅助平面 | U+10000 以上；含扩展汉字、emoji、历史文字 |
| CJK 统一表意文字 | U+4E00 起；扩展 A–H 等区块 |
| 兼容字符 | 为与旧字符集互操作保留的码位 |

**统一（unification）的代价**：同一码位承载不同地区字形，显示哪个字形由字体与地区标准决定——这正是「一码多形」问题。

## 三、编码形式

| 编码 | 码元 | 特点 |
|:------|:------|:------|
| UTF-8 | 8 位 | 1–4 字节；ASCII 兼容；Web 事实标准 |
| UTF-16 | 16 位 | BMP 2 字节；辅助平面用代理对；Windows / Java 内部常用 |
| UTF-32 | 32 位 | 定长 4 字节；实现简单、空间浪费 |
| UCS-2 | 16 位 | 早期定长方案，不能表示辅助平面（已过时） |

- **UTF-8 的优势**：与 ASCII 兼容、无字节序问题、对英文文本空间效率高。
- **UTF-16 的陷阱**：代理对（surrogate pair）使「字符数」与「码元数」不再相等。
- **BOM**：字节序标记；UTF-8 的 BOM（`EF BB BF`）常导致解析问题，通常不建议添加。

## 四、规范化与比较

| 概念 | 说明 |
|:------|:------|
| NFC | 规范合成：组合字符尽量合成单码位 |
| NFD | 规范分解：拆成基字符 + 组合记号 |
| NFKC / NFKD | 兼容分解 / 合成：同时折叠兼容字符 |
| 组合字符 | 基字符 + 附加记号（如 é = e + ◌́） |
| 字素簇（grapheme cluster） | 用户感知的「一个字符」，可能由多个码位组成 |
| 大小写折叠 | case folding；与简单大小写转换不同 |

> 字符串比较前必须先做**规范化**，否则视觉相同的文本可能不相等。

## 五、乱码与常见故障

| 现象 | 成因 |
|:------|:------|
| 乱码（mojibake） | 用 A 编码解码 B 编码的字节 |
| 问号 / 方块 | 字符集不支持该字符，或字体缺字形 |
| 半个汉字 | 多字节字符被按字节截断 |
| emoji 显示异常 | 代理对 / ZWJ 序列 / 字体缺字 |
| 排序不符预期 | 未按语言规则做 collation |

> 排查顺序：确认**字节来源编码** → 确认**解码声明** → 检查**规范化与字体覆盖**。

## 六、输入、检索与排版

| 环节 | 要点 |
|:------|:------|
| 输入法 | 拼音 / 形码 / 手写 / 语音；输入法产出的是码位序列 |
| 检索 | 需要规范化 · 大小写折叠 · 变音符号处理 |
| 排序（collation） | 按语言习惯排序，不是按码位大小 |
| 分词 | 中文等无空格语言需分词后才能检索 |
| 排版 | 字体回退（fallback）· 复杂文字整形（shaping）· 竖排 · 中西文混排 |
| 宽度 | 全角 / 半角；东亚宽度（East Asian Width）影响对齐 |
