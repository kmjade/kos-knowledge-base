# 003.3 手迹

> **UDC 003.3** — 手迹（Handwriting / autograph）：**亲笔痕迹 · 笔迹特征 · 鉴定辨伪 · 数字化**。
> 所属：[[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003-书写体系与文字|003 书写体系与文字]]。
> 本库回答：**一个人亲手写下的痕迹，能告诉我们什么？又如何被保存、辨认与验证？**
> 文字类型见 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.2-文字类型/003.2-文字类型|003.2 文字类型]]；字符编码见 [[3 Resources/000-Knowledge/00-总类/003-书写体系与文字/003.08-字符与编码/003.08-字符与编码|003.08 字符与编码]]。

## 核心问题

| 问题 | 本库回答 |
|:------|:------|
| 什么是「手迹」 | 某人亲笔书写留下的可见痕迹 |
| 手迹与手稿、书法有何不同 | 手迹看「谁写的」，手稿看「文本状态」，书法看「审美创作」 |
| 笔迹能否识别人 | 司法笔迹鉴定可作证据；笔迹相面（graphology）不具科学效力 |
| 手迹如何长期保存 | 载体保护 · 扫描 / 多光谱 · 编目 · 数字化检索 |

## 一、界定：三种「手写的痕迹」

| 概念 | 关注点 | 典型对象 | 归属 |
|:------|:------|:------|:------|
| **手迹**（autograph） | 书写者身份与亲笔性 | 信札 · 签名 · 批注 · 题跋 | 本库 |
| **手稿**（manuscript） | 文本状态与版本 | 草稿 · 誊清稿 · 抄本 | [[002-文档、书籍、著作、著作人\|002 文档与书籍]] |
| **书法**（calligraphy） | 审美与艺术表达 | 碑帖 · 条幅 · 扇面 | `3 Resources/700-Arts` |

- 同一件纸本可以同时是手迹、手稿与书法作品；分类取决于**研究问题**。
- 本库只处理「亲笔痕迹」这一层：**谁写的、何时写的、是否真迹、如何数字化**。

## 二、形态与载体

| 载体 / 形态 | 说明 |
|:------|:------|
| 甲骨刻辞 | 契刻痕迹；刻手与书写者的关系需分辨 |
| 简牍 · 帛书 | 墨书原迹；笔锋、墨色保留较好 |
| 写本 · 抄本 | 抄写者的笔迹；年代与地域风格 |
| 尺牍 · 信札 | 最直接的个人手迹；含署名、日期、寒暄格式 |
| 签名 · 花押 | 身份标识；重复书写形成稳定特征 |
| 批注 · 题跋 | 阅读痕迹与流传证据 |
| 日记 · 草稿 | 修改过程、涂乙、旁注 |
| 数字手写 | 触控笔迹、电子签名；新型「手迹」 |

## 三、笔迹特征

| 层面 | 可观察特征 |
|:------|:------|
| 运笔 | 起收笔 · 力度 · 速度 · 连断 |
| 结体 | 字形比例 · 部件位置 · 简化 / 繁化习惯 |
| 章法 | 行距 · 字距 · 倾斜 · 页面布局 |
| 用字 | 异体字 · 简化写法 · 个人惯用字 |
| 工具 | 毛笔 / 硬笔 / 刻刀造成的线条差异 |

> 笔迹是**习惯与情境的叠加**：工具、姿势、年龄、疾病、书写速度都会改变外观。鉴定不能只看单个字。

## 四、鉴定与辨伪

### 4.1 可靠方法

| 方法 | 作用 |
|:------|:------|
| 笔迹比对 | 与已知真迹比对运笔、结体、章法 |
| 载体检测 | 纸张 · 绢帛 · 墨色 · 颜料的年代与成分 |
| 书写工具分析 | 笔痕 · 刻痕 · 印刷与手写的区分 |
| 印章 · 题跋 | 流传链条与同时代佐证 |
| 文献考证 | 内容、称谓、纪年、事件是否吻合 |
| 多光谱 / 成像 | 显现褪色、覆盖、刮改痕迹 |

### 4.2 需要区分的两种「笔迹学」

| 名称 | 性质 |
|:------|:------|
| 司法笔迹鉴定（forensic document examination） | 以可比对的书写习惯特征作同一性判断；有证据规则约束 |
| 笔迹相面（graphology） | 以笔迹推断性格 / 品格；**缺乏可靠效度，属伪科学** |

> 本库只收前者及文献学、文物鉴定方法；后者仅作为「伪科学案例」记录，不作为方法使用。

## 五、数字化

| 环节 | 内容 |
|:------|:------|
| 采集 | 高分辨率扫描 · 多光谱 · 3D 表面形貌 |
| 识别 | HTR（手写文本识别）· 版面分析 · 印章 / 签名检测 |
| 建模 | 笔迹特征提取 · 书写者识别 · 生成模型 |
| 呈现 | 手稿数据库 · 图像对照 · 释文与索引 |
| 复刻 | 字体复刻 · 仿真复制；需标注「非原件」 |

> HTR 与 OCR 不同：手写体的连笔、异体、涂改使识别难度显著高于印刷体。

## 六、著录、收藏与伦理

| 议题 | 要点 |
|:------|:------|
| 编目 | 书写者 · 受书者 · 时间 · 地点 · 载体 · 尺寸 · 递藏 |
| 释文 | 逐字录文；保留涂乙、旁注、残缺信息 |
| 流传 | 题跋 · 藏印 · 目录著录 · 拍卖记录 |
| 版权 | 手迹原件物权 ≠ 文字著作权 |
| 隐私 | 信札、日记涉及第三方隐私；公开需谨慎 |
