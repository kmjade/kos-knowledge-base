# 08 自动化与AI接入

> 通过 URI 协议、本地 API、CLI 与 MCP，把 Obsidian 接入外部工具与 AI 代理，实现自动化读写。

## URI 协议

用 `obsidian://` 从外部打开/创建笔记：

| URI | 作用 |
|-----|------|
| `obsidian://open?vault=X&file=笔记` | 打开笔记 |
| `obsidian://new?vault=X&file=新笔记` | 新建笔记 |
| `obsidian://search?vault=X&query=关键词` | 搜索 |

## 本地 API 与 CLI

| 工具 | 说明 |
|------|------|
| Local REST API 插件 | 通过 HTTP 接口读写笔记（AI 代理常用） |
| obsidian-cli | 命令行操作 Obsidian |
| MCP（Model Context Protocol） | 让 AI 工具连接 Vault |

> 本库的 AI 代理（KOS 引擎）通过 Local REST API / 文件系统与 Obsidian 交互。
