# Obsidian

本地优先的 Markdown 个人知识管理（PKM）应用，由 Dynalist 团队开发，2020 年发布，2022 年 1.0 正式版。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 本地优先 PKM / 笔记应用 |
| 格式 | Markdown（纯文本） |
| 存储 | 本地文件夹（Vault） |
| 平台 | Windows / macOS / Linux / iOS / Android |
| 版本 | 1.14（2026-09） |
| 许可 | 个人免费；Sync/Publish/商用付费 |

## 关键特性

- 双向链接、反向链接、关系图谱
- 属性（Properties）、Bases 数据库
- 核心 + 社区插件、主题、Canvas
- 端到端加密同步（Sync）、网站发布（Publish）
