# 03-组织行为学

> 研究人在组织中的行为——个体、群体与组织。

## 动机理论

| 理论 | 核心 |
|------|------|
| 马斯洛需求层次 | 生理→安全→社交→尊重→自我实现 |
| 赫茨伯格双因素 | 保健因素 vs 激励因素 |
| 期望理论 | 努力→绩效→奖励→价值 |
| 公平理论 | 投入产出比较 |

## 领导力

| 风格 | 特征 |
|------|------|
| 独裁 | 集中决策 |
| 民主 | 参与决策 |
| 放任 | 授权自主 |
| 变革型 | 愿景激励 |
| 交易型 | 奖惩交换 |

## 团队

- 团队 vs 群体
- 团队发展阶段：形成→震荡→规范→执行→解散
- 高绩效团队特征：信任、互补、共同目标

## 组织文化

- 价值观、信念、行为规范
- 沙因文化三层次：器物→价值观→基本假设
- 强文化 vs 弱文化

## 组织变革

- 变革阻力（习惯、恐惧、利益）
- 科特八步变革法
- 组织学习与适应
