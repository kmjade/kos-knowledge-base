# 08-项目管理

> 在约束（时间、成本、范围）下交付独特成果。

## 项目三角

```
        范围
        /  \
       /    \
    成本 —— 时间
```

- 三者相互制约，只能平衡不能兼得

## 项目生命周期

```
启动 → 规划 → 执行 → 监控 → 收尾
```

## 计划工具

| 工具 | 用途 |
|------|------|
| WBS | 工作分解结构 |
| 甘特图 | 时间进度 |
| 关键路径法 (CPM) | 最长路径 |
| PERT | 不确定性估算 |

## 敏捷 (Agile)

| 框架 | 特征 |
|------|------|
| Scrum | 冲刺、每日站会、回顾 |
| 看板 | 可视化工作流 |
| 极限编程 (XP) | 结对、TDD |

- 敏捷宣言：个体交互 > 流程工具；可工作软件 > 详尽文档

## 风险管理

- 识别 → 评估 → 应对 → 监控
- 风险应对：规避、转移、减轻、接受
- 储备金、应急计划

## 项目成功因素

- 清晰目标、高层支持
- 合适团队、有效沟通
- 变更管理、持续改进
