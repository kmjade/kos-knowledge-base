# 09-创新与创业管理

> 创造与商业化新价值——创新是增长的引擎，创业是创新的载体。

## 创新类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 颠覆式创新 | 从低端/新市场切入 | 数码相机 |
| 渐进式创新 | 持续改进 | 手机迭代 |
| 商业模式创新 | 新的盈利方式 | 订阅制 |
| 开放式创新 | 内外协同 | 众包 |

## 创新扩散

- 创新者 → 早期采用者 → 早期大众 → 后期大众 → 落后者
- 跨越鸿沟（早期采用者 → 早期大众）

## 创业过程

```
机会识别 → 团队组建 → 资源获取 → 产品开发 → 增长 → 退出
```

## 精益创业

| 概念 | 说明 |
|------|------|
| MVP | 最小可行产品 |
| 构建-测量-学习 | 快速迭代循环 |
| 验证性学习 | 用数据验证假设 |
| 转型 (Pivot) | 调整方向 |

## 商业模式画布

- 九要素：价值主张、客户细分、渠道、关系、收入流、关键资源、关键活动、关键伙伴、成本结构

## 创新管理

- 组织创新文化、容错机制
- R&D 投入、知识产权
- 变革管理、数字化转型
