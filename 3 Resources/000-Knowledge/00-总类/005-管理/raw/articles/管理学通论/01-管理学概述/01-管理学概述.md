# 01-管理学概述

> 管理是通过他人完成目标的科学与艺术。

## 管理四职能

| 职能 | 内容 |
|------|------|
| 计划 (Plan) | 设定目标、制定方案 |
| 组织 (Organize) | 分配资源、建立结构 |
| 领导 (Lead) | 激励、沟通、指导 |
| 控制 (Control) | 监督、纠偏、评估 |

## 管理理论演变

| 学派 | 核心 | 代表 |
|------|------|------|
| 科学管理 | 效率、标准化 | 泰勒 |
| 行政管理 | 组织原则 | 法约尔、韦伯 |
| 行为学派 | 人际关系 | 梅奥（霍桑实验） |
| 系统学派 | 组织是开放系统 | 巴纳德 |
| 权变理论 | 视情境而定 | 菲德勒 |

## 管理的层次

```
高层（战略）→ 中层（战术）→ 基层（执行）
```

## 管理者角色（明茨伯格）

| 类型 | 角色 |
|------|------|
| 人际 | 领导者、联络者、代表人 |
| 信息 | 监督者、传播者、发言人 |
| 决策 | 企业家、危机处理者、资源分配者、谈判者 |

## 效率 vs 效能

- **效率**：正确地做事（投入产出比）
- **效能**：做正确的事（目标达成）
