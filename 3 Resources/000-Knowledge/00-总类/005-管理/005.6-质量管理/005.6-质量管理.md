## 一、质量观的三次跃迁

| 阶段 | 做法 | 责任 |
|:------|:------|:------|
| 检验 | 事后挑不合格 | 质检部门 |
| 统计控制（SPC） | 过程内控（控制图） | 生产 |
| **TQM** | 全员 · 全过程 · 持续改进 · 以顾客为中心 | **全员** |

> 质量 = **符合要求的程度**，最终由**顾客**定义。

## 二、核心工具

| 工具 | 用途 |
|:------|:------|
| PDCA | 计划-执行-检查-处置（改进循环） |
| 因果图 / 5Why | 找根因 |
| 帕累托图 | 抓主要矛盾（80/20） |
| 控制图 | 区分正常波动与异常 |
| FMEA | 事前失效风险分析 |
| 六西格玛 / DMAIC | 定义-测量-分析-改进-控制 |

## 三、标准与体系

- **ISO 9000 族**：质量体系要求与术语；**认证**是外部证明。
- 质量成本：预防 < 鉴定 < 内部失效 < 外部失效（越晚越贵）。
- 与 **006 标准化**的分工：`006` 管「标准怎么定」（含质量标准的制修订），`005.6` 管「组织内怎么管质量」。

## 四、落地要点

- 领导层承诺 + 数据驱动 + 员工参与（TQM 三支柱）。
- 度量先行：无数据则改进不可验证。
- 反对"运动式质量"：需嵌入日常流程。
