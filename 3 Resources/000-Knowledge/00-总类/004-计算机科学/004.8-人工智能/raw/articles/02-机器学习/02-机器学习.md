## 一、定义

机器学习研究**如何让系统从数据中自动改进性能**，而不靠逐条手写规则。

> Mitchell（1997）式定义：若程序在任务 **T** 上以度量 **P** 衡量的性能随经验 **E** 提升，则该程序从 **E** 中学习。

三个要素缺一不可：**任务（T）· 经验（E）· 度量（P）**。

## 二、学习范式

| 范式 | 数据形态 | 目标 | 代表 |
|:--|:--|:--|:--|
| 监督学习 | 带标签 `(x, y)` | 学映射 `f: x → y` | 分类 · 回归 |
| 无监督学习 | 无标签 `x` | 发现结构 | 聚类 · 降维 · 密度估计 |
| 强化学习 | 交互轨迹 `(s, a, r, s')` | 最大化累积奖励 | 策略梯度 · Q-learning |
| 自监督学习 | 无人工标签 | 从数据自身构造监督 | 掩码语言模型 · 对比学习 |

## 三、标准流程

```
问题定义 → 数据采集 → 特征/表示 → 模型选择 → 训练 → 验证 → 部署 → 监控
```

| 阶段 | 关键问题 |
|:--|:--|
| 问题定义 | 任务与度量是否匹配业务目标 |
| 数据 | 代表性 · 标签质量 · 泄漏 |
| 特征 / 表示 | 手工特征 vs 端到端学习 |
| 模型 | 容量 · 归纳偏置 · 可解释性 |
| 训练 | 损失函数 · 优化器 · 正则化 |
| 验证 | 划分策略 · 交叉验证 · 分布偏移 |
| 部署 | 延迟 · 成本 · 监控 · 回滚 |

## 四、核心权衡

| 议题 | 说明 |
|:--|:--|
| 欠拟合 / 过拟合 | 容量不足 vs 记忆训练集 |
| 偏差–方差 | 误差分解：偏差² + 方差 + 噪声 |
| 经验风险 / 结构风险 | 训练误差 vs 加正则项的泛化目标 |
| 探索 / 利用 | 强化学习特有：试新 vs 用已知 |
| 样本效率 | 数据量、先验与迁移的平衡 |

## 五、评估

- **分类**：准确率 · 精确率 / 召回率 · F1 · ROC-AUC · PR-AUC
- **回归**：MSE · MAE · R²
- **排序 / 生成**：NDCG · BLEU / ROUGE · 人工评估
- **可靠性**：校准 · 置信区间 · 分布外检测

> 度量必须与**任务代价**一致：类别不平衡时准确率会误导。
