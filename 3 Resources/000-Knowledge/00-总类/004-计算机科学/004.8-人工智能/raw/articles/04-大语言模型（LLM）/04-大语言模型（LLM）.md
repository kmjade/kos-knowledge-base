## 一、定义

大语言模型是**在海量文本上预训练、以预测下一 token 为目标**的神经网络，通常为数十亿至数千亿参数的 Transformer 解码器。

```
文本 ──分词──▶ token 序列 ──Transformer──▶ 下一个 token 的概率分布
                     ▲                              │
                     └──────── 自回归生成 ◀─────────┘
```

> 核心事实：**一个目标（下一 token 预测）+ 足够规模 → 广泛的语言与任务能力**。

## 二、架构要点

| 组件 | 作用 |
|:--|:--|
| Tokenizer | 文本 → 子词单元（BPE / SentencePiece） |
| Embedding | token → 向量；位置编码注入顺序信息 |
| Transformer 解码器 | 因果自注意力 + 前馈网络，逐层堆叠 |
| 输出头 | 隐状态 → 词表分布 |
| 上下文窗口 | 单次可处理的最大 token 数 |

**关键机制**：自注意力（全局依赖）· 残差与归一化（深网络可训练）· KV Cache（推理加速）。

## 三、训练阶段

| 阶段 | 数据 | 目标 | 产出 |
|:--|:--|:--|:--|
| 预训练（pre-training） | 大规模无标注语料 | 下一 token 预测 | 基座模型（base） |
| 监督微调（SFT） | 指令–回答对 | 学会遵循指令 | 指令模型 |
| 偏好对齐（RLHF / DPO） | 人类偏好比较 | 有用 · 无害 · 诚实 | 对齐模型 |
| 推理增强（可选） | 推理轨迹 | 提升多步推理 | 推理模型 |

> 规模、数据质量与数据配比，往往比架构微调更决定最终能力。

## 五、能力与局限

| 能力 | 局限 |
|:--|:--|
| 语言理解与生成 | 幻觉（事实性错误） |
| 跨任务泛化 | 上下文长度与注意力衰减 |
| 少样本学习 | 推理链脆弱 · 计算不稳 |
| 工具使用 | 时效性 · 私有知识缺失 |
| 多语言 | 低资源语言表现不均 |

**幻觉的根源**：目标是**似然**而非**真值**；缓解靠检索 · 工具 · 校验 · 对齐。

## 六、评估

- **基准**：知识问答 · 推理 · 代码 · 数学 · 长上下文。
- **方法**：自动评测 · 人工偏好 · 对抗测试 · 在线 A/B。
- **陷阱**：数据污染 · 基准饱和 · 指标与真实用途脱节。
