# 大语言模型（LLM）

> **概念** — 大语言模型是在海量文本上以**预测下一 token** 为目标预训练的神经网络，通常为数十亿至数千亿参数的 Transformer 解码器。

## 核心机制

```
文本 ──分词──▶ token 序列 ──Transformer（因果自注意力）──▶ 下一 token 分布
                    ▲                                        │
                    └──────────── 自回归生成 ◀───────────────┘
```

| 组件 | 作用 |
|:--|:--|
| Tokenizer | BPE / SentencePiece，文本 → 子词 |
| Embedding + 位置编码 | 语义向量 + 顺序信息 |
| Transformer 解码器 | 因果自注意力 + FFN，逐层堆叠 |
| 输出头 | 隐状态 → 词表概率 |
| KV Cache | 推理时复用历史键值，降低延迟 |

**关键结论**：单一目标（下一 token 预测）+ 足够规模与数据质量 → 广泛的语言与任务能力。

## 训练阶段

| 阶段 | 数据 | 目标 | 产出 |
|:--|:--|:--|:--|
| 预训练 | 大规模无标注语料 | 下一 token 预测 | 基座模型 |
| 监督微调（SFT） | 指令–回答对 | 遵循指令 | 指令模型 |
| 偏好对齐（RLHF / DPO） | 人类偏好比较 | 有用 · 无害 · 诚实 | 对齐模型 |
| 推理增强 | 推理轨迹 | 多步推理 | 推理模型 |

## 能力与局限

| 能力 | 局限 |
|:--|:--|
| 语言理解与生成 | 幻觉（事实性错误） |
| 跨任务泛化 · 少样本 | 上下文长度与注意力衰减 |
| 工具使用 · 多语言 | 时效性 · 私有知识缺失 · 低资源语言偏弱 |

**幻觉根源**：优化目标是**似然而非真值**；缓解依赖检索 · 工具 · 校验 · 对齐。
