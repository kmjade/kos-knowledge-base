# 表示与推理

> **概念** — 表示与推理研究**如何把世界编码成机器可用的结构**，以及**如何在该结构上推导出新结论**。它是符号主义路线的核心，与学习路线并列。

## 定义

| 环节 | 问题 | 产物 |
|:--|:--|:--|
| 表示 | 用什么结构刻画对象、关系与约束 | 逻辑式 · 图 · 向量 · 规则 |
| 推理 | 已知前提如何推出结论 | 演绎 · 归纳 · 溯因 · 概率 |
| 规划 | 如何从初始状态到达目标状态 | 动作序列 · 策略 |

## 表示形式

| 形式 | 特点 | 擅长 | 局限 |
|:--|:--|:--|:--|
| 一阶 / 描述逻辑 | 形式语义严格 | 可验证推理 | 知识获取瓶颈 |
| 产生式规则 | 条件–动作 | 专家系统 | 规则冲突 · 难维护 |
| 语义网络 / 知识图谱 | 实体–关系三元组 | 检索 · 关联 · 可解释 | 覆盖不全 · 噪声 |
| 框架 / 本体 | 概念层次与约束 | 领域建模 · 互操作 | 建模成本高 |
| 分布式向量表示 | 稠密嵌入 | 相似度 · 泛化 | 不可直接推理 |

## 推理类型

| 类型 | 方向 | 例 |
|:--|:--|:--|
| 演绎 | 一般 → 特殊，结论必真 | 三段论 · 定理证明 |
| 归纳 | 特殊 → 一般，结论或然 | 从样本得规律 |
| 溯因 | 观察 → 最佳解释 | 诊断 · 根因分析 |
| 概率推理 | 不确定性下的信念更新 | 贝叶斯网络 |
| 神经推理 | 隐式、分布式 | 大模型的多步推断 |

## 规划

- **状态空间搜索**：BFS / DFS / A\*（启发式可采纳性决定最优性）。
- **分层规划（HTN）**：任务分解为子任务。
- **约束满足**：以约束剪枝搜索空间。
- **学习式规划**：用模型或强化学习生成动作序列。

## 知识图谱

```
(实体) ──关系──▶ (实体)      例：(Transformer) ──属于──▶ (深度学习)
```

构建环节：本体设计 → 实体识别 → 关系抽取 → 对齐消歧 → 存储查询（SPARQL / 图数据库）。质量瓶颈在**覆盖度与一致性**。

## 神经符号

| 结合方式 | 做法 |
|:--|:--|
| 神经 → 符号 | 从文本抽取结构化知识，供符号系统推理 |
| 符号 → 神经 | 规则 / 知识约束注入训练或解码 |
| 交替 | 模型生成候选，求解器校验（如程序合成） |

> 分工原则：**感知与泛化交给神经，精确约束与验证交给符号**。
