# 检索增强生成（RAG）

> **概念** — RAG 在生成前**先从外部知识源检索相关内容**并拼入上下文，使模型基于证据作答。它解决知识时效、私有知识与可溯源三个问题。

## 流程

```
离线：文档 ─▶ 解析 ─▶ 分块 ─▶ 向量化 ─▶ 索引（+ 元数据）
在线：问题 ─▶ 改写 ─▶ 检索（稠密 / 稀疏 / 混合）─▶ 重排 ─▶ 拼装 ─▶ 生成 ─▶ 带引用答案
```

## 关键组件与失效点

| 组件 | 设计要点 | 常见问题 |
|:--|:--|:--|
| 解析 | PDF / HTML / 表格 / 扫描件 | 版式丢失 · 表格错位 |
| 分块 | 固定长度 · 语义 · 层级 | 切断语义 · 块过大稀释 |
| 嵌入 | 领域适配 · 多语言 · 维度 | 语义漂移 · 领域不匹配 |
| 索引 | HNSW · IVF · PQ | 召回 / 延迟权衡 |
| 检索 | 稠密 · BM25 · 混合（RRF） | 单路召回偏差 |
| 重排 | Cross-encoder · LLM 重排 | 成本 · 延迟 |
| 拼装 | 顺序 · 去重 · 压缩 · 引用 | 超窗 · 噪声干扰 |
| 生成 | 引用约束 · 拒答 | 幻觉 · 忽略证据 |

## 进阶形态

| 形态 | 做法 |
|:--|:--|
| Hybrid RAG | 向量 + BM25 融合 |
| Multi-query | 多路改写并行检索 |
| HyDE | 先写假设答案再检索 |
| GraphRAG | 实体关系图 + 社区摘要 |
| Agentic RAG | 模型自主决定检索与迭代 |
| Self-RAG | 自评估检索必要性与证据充分性 |
| 多模态 RAG | 图像 / 表格 / 音频检索 |

## 评估

| 维度 | 指标 |
|:--|:--|
| 检索 | Recall@k · MRR · NDCG |
| 上下文 | 相关性 · 覆盖率 · 噪声率 |
| 生成 | 忠实度（faithfulness）· 答案相关性 |
| 端到端 | 正确率 · 引用准确率 · 拒答率 |
| 工程 | 延迟 · 成本 · 可扩展性 |

> **忠实度是核心指标**：答案是否只依据检索到的证据。

## 典型失效与对策

| 失效 | 原因 | 对策 |
|:--|:--|:--|
| 检索不到 | 分块 / 嵌入 / 查询不匹配 | 混合检索 · 改写 · 调块 |
| 检索噪声 | 召回过宽 | 重排 · 阈值 · 元数据过滤 |
| 忽略证据 | 上下文过长 · 指令弱 | 压缩 · 强化引用约束 |
| 拼接矛盾 | 多源冲突 | 冲突标注 · 来源优先级 |
| 引用错配 | 块句未对齐 | 细粒度引用 · 后验校验 |
