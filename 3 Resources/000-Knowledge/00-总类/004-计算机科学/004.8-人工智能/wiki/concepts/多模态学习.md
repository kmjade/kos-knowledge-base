# 多模态学习

> **概念** — 多模态学习研究**同时处理两种及以上模态**（文本 / 图像 / 音频 / 视频 / 动作）的模型：跨模态表示、对齐、融合与生成。

## 核心问题

1. **表示对齐**：不同模态如何映射到同一语义空间。
2. **信息互补**：如何利用模态间的冗余与互补。
3. **粒度差异**：一句文本可对应一图多区域。

## 任务谱

| 模态 | 典型任务 |
|:--|:--|
| 视觉 | 分类 · 检测 · 分割 · 生成 |
| 文本 | 理解 · 生成 · 翻译 |
| 音频 / 语音 | ASR · TTS · 音频理解 |
| 视频 | 动作识别 · 时序理解 · 生成 |
| 跨模态 | 图文检索 · 图像描述 · VQA · 文生图 |

## 架构路线

| 路线 | 机制 | 代表 |
|:--|:--|:--|
| 对比对齐 | 双塔编码，拉近配对样本 | CLIP 式 |
| 早期融合 | 输入层拼接 / 加和 | 简单多模态分类 |
| 晚期融合 | 独立编码后决策融合 | 集成方案 |
| 交叉注意力 | 模态间注意力交互 | 视觉–语言模型 |
| 统一 token | 各模态离散化 | 统一序列建模 |
| 生成式桥接 | 用生成模型连接模态 | 文生图 / 文生视频 |

## 训练范式

| 范式 | 目标 | 数据 |
|:--|:--|:--|
| 对比学习 | 配对样本相似度最大化 | 图文对 |
| 掩码重建 | 还原被遮蔽片段 | 单 / 跨模态 |
| 生成建模 | 最大化条件似然 | 图文 · 视频文本 |
| 指令微调 | 遵循多模态指令 | 多模态问答 |
| 对齐微调 | 多模态偏好对齐 | 人类偏好 |

## 关键挑战

| 挑战 | 说明 |
|:--|:--|
| 表示对齐 | 语义粒度不一致 |
| 模态缺失 | 推理时某模态不可用 |
| 组合泛化 | 未见过的概念组合 |
| 幻觉 | 生成内容与输入不符 |
| 评估 | 开放式生成难自动度量 |
| 成本 | 视频 / 高分辨率开销大 |

## 评估

- **检索**：Recall@k · 图文匹配准确率。
- **生成**：FID · CLIPScore · 人工评分 · 一致性。
- **理解**：VQA 准确率 · BLEU / CIDEr / SPICE。
- **可靠性**：幻觉率 · 鲁棒性 · 偏见。

> 自动指标与人类感知常不一致，**人工评估不可省**。
