# 机器感知

> **概念** — 感知是从原始信号（像素 · 波形 · 点云）中提取**关于世界的有意义结构**：把信号转成可供推理与决策使用的表示。

## 与生成的分工

| 方向 | 问题 | 典型任务 |
|:--|:--|:--|
| 感知 | 世界**是什么** | 分类 · 检测 · 分割 · 识别 |
| 生成 | 如何**产生**符合描述的信号 | 文生图 · TTS · 视频生成 |

> 二者共用表示与主干网络，但目标函数不同（判别 vs 似然）。

## 任务谱

| 模态 | 任务 |
|:--|:--|
| 视觉 | 分类 · 检测 · 分割 · 姿态 · 深度 · 跟踪 |
| 语音 | ASR · 说话人识别 · 语音事件 |
| 文本 | 分词 · 实体识别 · 依存 / 语义分析 |
| 三维 | 点云分割 · 检测 · SLAM · 重建 |
| 时序信号 | 传感器融合 · 异常检测 · 行为识别 |

## 技术路线

| 路线 | 思路 | 代表 |
|:--|:--|:--|
| 手工特征 + 分类器 | 人工描述子 + 浅层判别 | SIFT · HOG · MFCC |
| 端到端深度学习 | 特征与判别联合学习 | CNN 检测 / 分割 |
| 自监督预训练 | 从无标注信号学表示 | 对比 · 掩码建模 |
| 视觉 Transformer | 分块 + 自注意力 | ViT 系列 |
| 开放词汇感知 | 语言引导的零样本识别 | CLIP 式 · 开放词表检测 |
| 大模型感知 | 通用模型识别 / 描述 / 推理 | 视觉语言模型 |

## 关键问题

| 问题 | 说明 |
|:--|:--|
| 数据偏置 | 采集分布 ≠ 部署分布 |
| 分布偏移 | 光照 · 天气 · 传感器更换导致骤降 |
| 长尾 / 开放世界 | 类别无限，闭集假设失效 |
| 标注成本 | 像素级标注昂贵 |
| 鲁棒与对抗 | 微小扰动可致误判 |
| 置信度校准 | 需要"知道不确定" |

## 评估

- **闭集**：Top-1 / Top-5 · mAP · IoU / mIoU · WER。
- **开放集**：开放词表召回 · OOD 检测 · ECE 校准误差。
- **效率**：延迟 · 吞吐 · 能耗 · 体积（端侧）。

> 单基准分数不足以说明可用性，**须同时报告分布偏移与校准**。
