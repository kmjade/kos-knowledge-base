## 一、数据 — 信息 — 知识

```
数据（事实 / 符号） → 信息（有语境的数据） → 知识（可用的判断）
```

- **数据**是原始记录；价值来自**可被组织、检索与复用**。
- 三个基本问题：**怎么存**（结构）· **怎么处理**（管道）· **怎么取**（查询）。

## 三、按结构化程度

| 程度 | 形态 | 载体 |
|:------|:------|:------|
| 结构化 | 表 / 记录 / 类型 | 数据库（`004.65`） |
| 半结构化 | JSON / XML / YAML | 文件 + 解析（`004.63`） |
| 非结构化 | 文本 / 图像 / 音视频 | 对象存储 + 索引 |
| 向量化 | 嵌入向量 | 向量库（`004.65`） |

## 四、常用数据格式

| 格式 | 特征 | 适用 |
|:------|:------|:------|
| CSV | 简单 · 无类型 | 表格交换 |
| JSON | 嵌套 · 通用 | 接口 · 配置 |
| Parquet / ORC | **列式** · 压缩 | 分析 · 大数据 |
| 二进制序列化 | 紧凑 · 快 | 高性能传输 |
