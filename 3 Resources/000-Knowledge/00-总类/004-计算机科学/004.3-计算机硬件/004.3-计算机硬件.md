# 004.3 计算机硬件

> **UDC 004.3** — 计算机硬件（**总览**）：器件 · 部件 · 互连。
> 所属：[[004-计算机科学|004 计算机科学]]。

## 一、器件

| 器件 | 说明 |
|:------|:------|
| 晶体管 | 现代计算的开关单元（MOSFET） |
| 集成电路 | 把电路集成到芯片（SSI → VLSI） |
| 逻辑门 | AND / OR / NOT → 组合与时序电路 |
| 存储单元 | SRAM · DRAM · Flash · 磁介质 |

> 工艺节点（nm）是密度与功耗的粗略标尺；先进节点 → 制造与成本挑战。

## 三、复分（适用于 004.3）

### 1｜外部类复分：`62-1/-9`（适用整个 004.3）

> **`62-1/-9`** —— 机器、设备、厂房、**工艺和产品特征**的专用复分（源自 UDC 62），**整类适用**。
> 用于表达硬件的**制造工艺 / 产品特征**层面，例：`004.31-181` 之类的"工艺面"表达。

### 2｜本类专用复分：`004.3'1/'2`（撇号系列）

| 复分 | 类目 |
|:--|:------|
| `004.3'1` | 计算机**生产** |
| `004.3'2` | 计算机**安装** |

> 撇号复分（`'…`）与点零复分（`.0…`）同属**专用复分**，**不占主题位**。
> 详见 [[004.3-硬件专用复分|004.3'1/'2 硬件专用复分]]。

### 3｜应用注释（`.01/.08` 与 004.3x 的配合）

> **`004.01/.08` 专用复分号适用于计算技术**：
> `004.07` = **内存特性**；`004.08` = **内存存储介质**。
> 故在 `004.33` 上可叠加：`004.33.07`（存储单元的**特性**面）· `004.33.08`（存储单元的**介质**面）。

## 四、可靠性与功耗

| 议题 | 对策 |
|:------|:------|
| 纠错 | ECC 内存 · RAID |
| 散热 | 风冷 · 液冷 · 功耗墙 |
| 能效 | 动态调频 · 大小核 · 专用加速器 |

## 五、趋势

- 异构集成（CPU + GPU + NPU + 内存一体封装）。
- 存算一体 · 近存计算（缓解"内存墙"）。
- 开源指令集（RISC-V）与 chiplet 先进封装。
