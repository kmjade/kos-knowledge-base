## 一、概述

- **计算的本质**：图灵机为理论计算模型；**丘奇-图灵论题**把"可计算"刻划为"图灵可计算"；其边界由**不可判定性**（如停机问题）划定 —— 计算的极限是**逻辑事实**。
- **学科四象限**：理论（算法 / 复杂度 / 可计算性）· 系统（架构 / 系统软件 / 网络）· 软件（语言 / 工程 / 数据）· 应用（AI / 图形 / 交互）。
- **简史**：1930s 图灵机 → 1940s ENIAC 与冯·诺依曼架构 → 1950s 高级语言/晶体管 → 1970s 集成电路/Unix/C → 1980s PC → 1990s 万维网 → 2000s 移动/云 → 2010s– 深度学习。
- **冯·诺依曼架构**：`输入 → CPU（控制器/运算器）↔ 存储器 ↔ 输出`，程序存储 + 顺序执行。

> 分清 **计算机科学**（理论 · 为什么）与 **编程**（实践 · 怎么做）：前者归本库，后者的工具链归 `004.4-软件`。
