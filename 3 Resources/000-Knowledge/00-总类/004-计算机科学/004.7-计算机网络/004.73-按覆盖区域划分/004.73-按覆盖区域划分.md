# 004.73 按网络覆盖区域划分

> **UDC 004.73** — 按网络覆盖区域划分：PAN / LAN / MAN / WAN。
> 所属：[[004.7-计算机网络|004.7 计算机通讯、计算机网络]]（UDC 004.7 的下位）。
> 位置：`004.7-计算机网络/` 下的**文件夹笔记**（2026-10-20 升格，可挂下位笔记）。

---

## 一、按范围分类

| 类型 | 全称 | 范围 | 例 |
|:------|:------|:------|:------|
| **PAN** | Personal Area Network | 数米 | 蓝牙 · NFC · USB |
| **LAN** | Local Area Network | 楼宇 / 园区 | 以太网 · Wi-Fi |
| **MAN** | Metropolitan Area Network | 城市 | 城域以太 · 有线电视网 |
| **WAN** | Wide Area Network | 国家 / 全球 | 运营商骨干 · **互联网** |

> 分类是**尺度**维度，不是技术维度 —— 同一技术可用于不同尺度。

## 二、接入网 vs 骨干网

| 侧 | 关注 |
|:------|:------|
| 接入网 | 最后一公里 · 成本 · 覆盖（光纤到户 / 5G / 同轴） |
| 汇聚 | 城域汇聚 · 带宽收敛比 |
| 骨干网 | 大容量 · 冗余 · 长距（DWDM） |

## 三、组网要素

- 交换机 / 路由器 / 防火墙的层级布置。
- VLAN · 子网划分 · DMZ。
- 无线：信道 · 漫游 · 频段（2.4/5/6 GHz）。
- 出口：多线接入 · 负载均衡 · NAT。

## 四、企业 / 家庭 / 运营商

| 场景 | 典型形态 |
|:------|:------|
| 家庭 | 光猫 + 无线路由 · 单网段 |
| 企业 | 核心-汇聚-接入三层 · VLAN · 实名 |
| 数据中心 | Spine-Leaf · 扁平高带宽 |
| 运营商 | AS 互联 · IXP · 骨干环网 |

## 五、相关指标

- 上行 / 下行带宽 · 时延 · 抖动 · 可用性（SLA）。
- 覆盖与穿透（无线）· 移动性管理（蜂窝）。
