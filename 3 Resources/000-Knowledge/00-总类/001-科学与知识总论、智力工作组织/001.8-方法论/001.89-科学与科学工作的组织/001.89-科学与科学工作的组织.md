## 一、为什么科学工作要组织

- **从小科学到大科学**：个人手艺式研究 → 团队 → 大科学（加速器 · 基因组计划 · 多中心试验 · 航天 · 气候模拟）。规模越大，**协调成本**越成为决定性变量。
- **组织的五项功能**：

| 功能 | 内容 | 缺失后果 |
|:------|:------|:------|
| 分工 | 把问题拆成可并行的角色与任务 | 重复劳动、能力浪费 |
| 协调 | 让分工结果能拼合成一个结论 | 数据不可比、结论对不上 |
| 资源汇聚 | 集中仪器、经费、数据、算力 | 只能做小问题 |
| 连续性 | 跨越人员更替保存能力与数据 | 人一走，线索断 |
| 问责 | 明确谁对数据、结论、经费负责 | 失误无人承担 |

- **组织不是中性容器**：它决定**谁的问题被立项、什么证据算合格、哪些人进得来**。同一种方法在不同的组织里，产出可以完全不同。
- 三类基础成本：**协调成本**（沟通与对齐）· **激励成本**（让人做该做的事）· **守门成本**（筛选与评价）。

## 二、组织单元与层级

| 层级 | 典型形态 | 主要产出 | 关键约束 |
|:------|:------|:------|:------|
| 个人 | 研究者 · 学生 | 技能 · 局部发现 | 时间 · 专长有限 |
| 团队 / 实验室 | PI 组 · 实验室 · 研究组 | 论文 · 数据 · 方法 | 经费 · 带头人 · 规模 |
| 机构 | 研究所 · 院系 · 中心 · 医院 | 平台 · 训练 · 长期能力 | 编制 · 治理 · 使命 |
| 项目 / 计划 | 基金项目 · 大科学计划 · 多中心试验 | 定向交付物 | 期限 · 预算 · 协调 |
| 系统 | 国家体系 · 国际协作 | 政策 · 标准 · 基础设施 | 制度 · 政治 · 资源总量 |

- **项目是跨层级的组织单元**：有目标、期限、预算、交付物与验收——组织行为围绕它聚合，也容易被它切割。
- **矩阵结构**：学科条线（系 / 所）与任务条线（项目 / 中心）交叉；双重汇报是常态，冲突也来自这里。
- **组织边界 ≠ 学科边界**：跨学科问题常落在两个组织单元的缝隙里，无人负责。

## 三、分工与协作

| 模式 | 结构 | 优势 | 风险 |
|:------|:------|:------|:------|
| 师徒制 / PI 制 | 一位负责人 + 若干成员 | 方向集中、训练完整 | 权力集中、路径依赖 |
| 团队科学 | 多角色并行（实验 / 理论 / 数据 / 工程） | 规模产出、技能互补 | 贡献难归因、沟通成本 |
| 分布式协作 | 多机构 · 多中心 · 共享协议 | 样本与外部效度 | 标准不一、责任分散 |
| 跨学科中心 | 围绕问题重组学科 | 视角互补、方法迁移 | 评价标准错配 |
| 众包 / 公民科学 | 开放任务给大量参与者 | 规模与多样性 | 质量控制、激励设计 |

- **署名与贡献**：作者顺序、通讯作者、CRediT 贡献分类——署名是组织内**分配承认**的主要机制，也是冲突高发点。
- **规模收益与协调成本**：团队变大，产出并非线性增长；沟通路径按人数平方增长，超过一定规模需要**分层与标准化**（共同数据格式、SOP、预注册、定期同步）。
- **跨学科的评价错配**：用单学科期刊标准评价跨学科工作，常导致「两边都不认」。需要专门评审结构或转换评价口径。

## 四、资源配置

| 模式 | 机制 | 优点 | 缺点 |
|:------|:------|:------|:------|
| 项目制竞争资助 | 申报 → 同行评议 → 限期拨款 | 择优、议题引导 | 申请成本高、偏好渐进 |
| 机构稳定资助 | 按机构 / 人员下拨 | 长期能力、自由探索 | 可能保护低效 |
| 混合模式 | 基础经费 + 竞争项目 | 兼顾稳定与择优 | 设计复杂、口径不一 |
| 慈善 / 产业资助 | 基金会 · 企业 · 合同研究 | 补位冷门、转化导向 | 议程偏移、利益冲突 |

- **同行评议分配**：可靠性有限（评审者一致性不高）· 偏好已知路径（保守）· 声誉累积（马太效应）。
- **风险组合**：探索性研究失败率高但上限高；渐进研究确定性高但天花板低。健康的资助体系需要**按组合配置**，而非逐项要求「保证产出」。
- **时间尺度错配**：资助周期（3–5 年）常短于问题周期（10 年以上）；连续性依赖机构而非项目。
- **间接成本**：设备维护、平台人员、行政管理常被低估；挤占间接成本等于透支基础设施。

## 五、科研基础设施

| 类型 | 内容 | 组织问题 |
|:------|:------|:------|
| 物理设施 | 大型仪器 · 实验平台 · 观测网 | 共享规则、机时分配、维护经费 |
| 数据设施 | 数据库 · 标准 · 标识符 · 长期保存 | 互操作、治理权、隐私 |
| 计算设施 | 集群 · 云 · 模型与算力 | 访问公平、成本、可复现 |
| 知识设施 | 图书馆 · 预印本 · 开放获取 | 订阅成本、版本与归档 |
| 制度设施 | 使用协议 · 优先权 · 伦理审查 | 规则统一、跨境协作 |

- 基础设施具有**公共品属性**：非竞争性、难排他，市场供给不足，通常需要公共投入与治理。
- **共享平台**把「谁能做某类研究」从个人能力问题变成**准入问题**；机时与访问规则因此是实质性的科学政策。
- 基础设施的**标准化程度**决定协作半径：数据格式、元数据、样本协议不统一，跨机构合作就退化为一次性项目。

## 六、人才与职业

- **训练链**：本科 → 博士 → 博士后 → 独立职位；每级都是筛选，也都是**流失点**。
- **聘用形态**：终身轨（tenure）· 项目聘 · 固定期限合同 · 兼职与访问；稳定性与流动性之间的取舍。
- **职业结构**：多数领域呈金字塔形，博士产出大于稳定职位供给，形成「博士后困境」与离开学术的隐性成本。
- **评价工具**：

| 工具 | 测什么 | 偏差 |
|:------|:------|:------|
| 同行评议 | 专业判断 | 一致性低、人情与声誉 |
| 文献计量 | 引用与发表 | 领域差异、综述偏好、操纵 |
| altmetrics | 传播与影响 | 热度不等于质量 |
| 贡献分类（CRediT） | 角色分工 | 依赖如实填报 |

- **激励错配**：评价论文数量 → 拆分发表；评价短期产出 → 回避长期问题；评价引用 → 追逐热点。**评价什么，就得到什么**。

## 七、组织失灵与治理

| 失灵 | 机制 | 治理方向 |
|:------|:------|:------|
| 指标替代目标 | 可测指标取代真实目标（Goodhart 定律） | 多指标组合 · 同行判断 · 定期审查指标本身 |
| 短期化 | 聘期与考核周期压缩研究视野 | 长周期资助 · 滚动评估 |
| 行政负担 | 申报、报表、合规挤占研究时间 | 流程简化 · 一次采集多方复用 |
| 马太效应 | 声誉与资源自我强化 | 盲审 · 新人配额 · 随机分配试点 |
| 不端与利益冲突 | 压力 + 机会 + 弱监督 | 数据留存 · 披露制度 · 独立调查 |
| 重复与碎片化 | 缺乏协调的并行投入 | 注册与综述 · 跨机构协调机构 |

- **评价改革**：DORA（不唯期刊影响因子）· CoARA（改革科研评价）· 注册报告 · 开放数据与代码 · 贡献分类。
- **组织设计原则**：目标一致（激励与使命对齐）· 信息对称（决策者拿得到真实数据）· 冗余与独立验证（关键结论多路复核）· 可问责（责任能落到具体角色）。
- **自组织与外部干预的边界**：共同体能自净的部分交给共同体；涉及公共资源分配、安全与伦理的部分需要外部监督。二者不可互相替代。
