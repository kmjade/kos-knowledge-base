# 04 证据与推断

> 本库第 04 章。区分**数据 / 证据 / 结论**，给出证据强度的一般排序，并处理三类推断：因果、统计、不确定性表达。
> 入口：[[001.8-方法论|001.8 方法论]]。上一章：[[03-研究设计四维|03 研究设计四维]]；下一章：[[05-失效模式|05 常见失效模式]]。

---

## 一、数据、证据、结论

| 层 | 含义 | 例子 |
|:------|:------|:------|
| 数据 | 未经解释的记录 | 血压读数 · 访谈转录 · 日志 |
| 证据 | 与某主张相关的数据（经选择与解释） | 「干预组血压平均下降 8 mmHg」 |
| 结论 | 由证据支持的判断 | 「该干预可降低血压」 |

- 数据不自动成为证据：**相关性**由研究问题与设计赋予。
- 同一批数据可以支持不同结论，取决于**比较对象与假设**。
- 结论的强度不能超过证据与设计所能支撑的范围——这是推断的第一原则。

## 二、证据强度阶梯

**一般排序（弱 → 强）**：

```
个案 / 轶事 < 横断面观察 < 队列 / 病例对照 < 随机对照试验 < 系统综述 / 元分析
```

| 层级 | 强在哪 | 弱在哪 |
|:------|:------|:------|
| 个案 / 轶事 | 生动 · 发现线索 | 无法排除偶然与混杂 |
| 横断面 | 可描述分布与关联 | 时序不明 |
| 队列 / 病例对照 | 可看时序 · 适合罕见结果 | 混杂 · 回忆偏差 |
| RCT | 随机化控制混杂 | 外推受限 · 成本高 |
| 系统综述 / 元分析 | 汇总 · 检验异质性 | 受原始研究偏倚污染 |

**三条必要修正**：

1. 阶梯是**统计倾向**，不是绝对等级：设计良好的观察研究可强于执行糟糕的 RCT。
2. 元分析的强度取决于**纳入研究质量**；「垃圾进，垃圾出」。
3. 不同问题适用不同阶梯：机制问题看质性证据，预测问题看外部验证。

## 三、因果推断

**三个前提**：

| 前提 | 含义 | 失败后果 |
|:------|:------|:------|
| 关联 | 原因与结果统计相关 | 无关联则无从谈起 |
| 时序 | 原因先于结果 | 反向因果 |
| 排除替代解释 | 混杂、选择、测量等被控制 | 虚假因果 |

- **反事实框架**：因果效应 = 同一对象在接受与不接受处理两种情形下的结果之差；现实中只能观察其一，故需设计（随机化、自然实验）来近似。
- **混杂**：同时影响处理与结果的第三变量。随机化能均衡已知与未知混杂；观察研究只能控制**已测量**的混杂。
- **Collider（对撞变量）**：同时受处理与结果影响的变量；对它控制反而制造偏倚。控制变量不是越多越好。
- **常见识别策略**：随机化 · 自然实验（政策断点、时间冲击）· 工具变量 · 断点回归 · 双重差分 · 匹配。每种都有可论证的假设，不能只看方法名称。

## 四、统计推断

| 概念 | 含义 | 常见误用 |
|:------|:------|:------|
| p 值 | 原假设为真时，观察到当前或更极端结果的概率 | 当成「原假设为真的概率」 |
| 显著性水平 α | 事先设定的判定阈值（常 0.05） | 当成效应重要性的门槛 |
| 置信区间 | 估计的不确定性范围 | 说成「真有 95% 概率落在区间内」 |
| 效应量 | 效应的大小（标准化或原单位） | 只报 p 值不报效应量 |
| 统计功效 | 检出真实效应的概率 | 功效不足时把「不显著」当「无效应」 |

- **显著 ≠ 重要**：大样本下微小差异也会显著；要看效应量与实际意义。
- **不显著 ≠ 无效应**：可能是样本太小、测量太粗；应报告区间，区分「无证据」与「证据表明无」。
- **多重比较**：比较次数越多，假阳性越多；需校正、预注册或明确标为探索性。
- **p 值不是证据强度本身**：它依赖样本量、模型与停止规则。

## 五、贝叶斯视角

| 要素 | 含义 |
|:------|:------|
| 先验 | 数据前对参数的信念分布 |
| 似然 | 数据在不同参数下的概率 |
| 后验 | 更新后的信念分布 |

- 贝叶斯推断直接回答「给定数据，参数落在某范围的概率」，与频率派的「长期重复性质」不同。
- 先验的争议：客观先验 vs 主观先验；敏感性分析可检验结论对先验的依赖。
- 实用价值：小样本 · 累积证据 · 决策场景；但计算与先验选择需要透明。

## 六、不确定性表达

- **区间优于点估计**：报告估计值与置信 / 可信区间。
- **预测区间宽于置信区间**：预测新个体比估计均值更不确定。
- **情景优于单一预言**：复杂系统给条件句与情景，比给点预测更诚实。
- **语言等级**（示例，需与研究领域惯例对齐）：

| 表述 | 大致含义 |
|:------|:------|
| 有强证据表明 | 多项高质量研究一致 |
| 证据提示 | 方向一致但强度有限 |
| 尚无一致证据 | 研究不足或结果冲突 |
| 证据表明无 | 有足够功效的研究支持「无实质效应」 |

> 避免把「尚无证据」写成「证明不存在」，也避免把「一项研究」写成「科学已证明」。

## 七、六个常见误读

| 误读 | 纠正 |
|:------|:------|
| 统计显著 = 效应重要 | 看效应量与区间 |
| 不显著 = 没有效应 | 看功效与区间 |
| 相关 = 因果 | 检查时序、混杂与替代解释 |
| 元分析 = 定论 | 受原始研究偏倚与异质性影响 |
| 大数据不需要推断 | 大样本仍有选择偏差与测量问题 |
| 置信区间 = 参数概率 | 频率派区间不是后验概率 |
