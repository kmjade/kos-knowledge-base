# 02 研究链条

> 本库第 02 章。把研究拆成可检查的环节：**问题 → 文献 → 假说 → 设计 → 数据 → 分析 → 推断 → 检验 → 修正**，并指出每一环最常断在哪里。
> 入口：[[001.8-方法论|001.8 方法论]]。上一章：[[01-方法与方法论|01 方法、方法论、技法]]；下一章：[[03-研究设计四维|03 研究设计四维]]。

---

## 一、链条总览

```
问题 → 文献 → 假说 / 研究问题 → 设计 → 数据 → 分析 → 推断 → 检验 / 复现 → 修正 → 传播
```

| 环节 | 主要产出 | 合格判据 |
|:------|:------|:------|
| 问题 | 可回答的研究问题 | 范围清楚 · 概念可操作 |
| 文献 | 空白与既有解释图谱 | 覆盖反方 · 检索可复现 |
| 假说 | 可检验的预期 | 方向明确 · 能被推翻 |
| 设计 | 抽样、对照、测量方案 | 能区分竞争解释 |
| 数据 | 记录与元数据 | 完整 · 可追溯 · 合规 |
| 分析 | 描述与推断结果 | 与预注册一致 · 敏感性分析 |
| 推断 | 结论与适用范围 | 效应量 · 不确定性 · 边界 |
| 检验 | 复现与独立验证 | 独立数据 · 同法可重复 |
| 修正 | 理论或方法的更新 | 公开修订理由 |

> 链条是**检查表**，不是实际路径。真实研究常在环节间回跳（见第七节）。

## 二、问题与文献

- **可回答性**：问题要能对应到可观察的后果。不可回答的典型：概念未定义（「意识是否自由」）、范围无限（「教育的本质」）、同义反复。
- 好问题的四个维度：**重要**（回答后改变什么）· **新颖**（空白或矛盾）· **可行**（资源与伦理）· **具体**（边界与对象清楚）。
- **空白类型**：

| 空白 | 含义 | 检索线索 |
|:------|:------|:------|
| 证据空白 | 无人做过该对象 / 人群 | 系统综述的「未来研究」 |
| 方法空白 | 现有方法测不准 | 测量批评、效度研究 |
| 理论空白 | 现有解释矛盾或不足 | 竞争理论的对峙点 |
| 实践空白 | 已知有效但未落地 | 实施科学、转化研究 |

- 文献检索要**可复现**：数据库、检索式、时间范围、纳入排除标准。只读支持自己观点的文献，是后续一切偏差的起点。

## 三、假说与操作化

- **可检验假说**：说得出「什么结果会让我放弃它」。方向性（正/负/差异）与比较对象要明确。
- **操作化**：把概念转成可测量的变量。例：「压力」→ 皮质醇 / 自评量表 / 行为指标；不同操作化可能给出不同结论。
- **预注册**：在收数据前写下假说、主要结局、分析计划。它把「事后解释」与「事前检验」分开。
- 探索性研究**不必**有预注册假说，但必须标明自己是探索性的，不能事后包装成验证性。

## 四、设计与抽样

- 设计回答：**和谁比、比什么、怎么控制替代解释**（详见 [[03-研究设计四维|03 研究设计四维]]）。
- 抽样要说明：抽样框（总体清单）· 抽样方法 · 样本量依据（功效分析）· 流失与无应答。
- 常见暗礁：样本量不足导致「无显著结果」被误读为「无效应」；方便样本被当成代表性样本。

## 五、数据与分析

- **测量**：信度（稳定性）与效度（测到了想测的）是两件事；仪器校准、问卷预试、编码者一致性都要报告。
- **数据管理**：原始数据只读、清洗脚本可复跑、缺失机制说明（随机缺失 / 非随机缺失）。
- **分析**：
  - 先描述再推断；先看图再看检验。
  - 主要分析与次要分析分开；多重比较要校正或明示。
  - 敏感性分析：换模型、换子样本、换缺失处理，看结论是否稳。
- **盲法**：受试者、实施者、评估者、分析者，能盲则盲；盲不了要说明偏差方向。

## 六、推断与检验

- 报告**效应量 + 不确定性**，不只报 p 值（详见 [[04-证据与推断|04 证据与推断]]）。
- 区分三种「检验」：

| 检验 | 问什么 | 手段 |
|:------|:------|:------|
| 统计检验 | 结果能否由偶然产生 | 显著性、区间 |
| 稳健性检验 | 换假设后结论是否仍成立 | 敏感性分析、替代模型 |
| 独立复现 | 他人在新数据上能否得到同结论 | 重复实验、多中心 |

- **发现语境 vs 辩护语境**：发现的路径可以是偶然、直觉、试错；辩护时必须给出可公开检查的证据链。两者不能混写。

## 七、真实研究是非线性的

- 常见回跳：分析中发现测量问题 → 回设计；文献读到矛盾 → 改问题；预实验失败 → 换操作化。
- **诚实的报告**应标明回跳：哪些是事前计划，哪些是事后调整。隐瞒回跳会产生 **HARKing**（事后假设当作事前假设）。
- 迭代不是缺陷；**不披露迭代**才是。
- 意外发现（serendipity）在科学史中常见，但它的**确认**仍要走完整链条。

## 八、五个常见误读

| 误读 | 纠正 |
|:------|:------|
| 研究必须按链条顺序走 | 链条是检查表；回跳是常态，关键是披露 |
| 有了数据就能推断 | 推断依赖设计与假设，数据本身不自动给出因果 |
| 预注册限制探索 | 预注册区分验证与探索，不禁止探索 |
| 复现失败 = 原研究造假 | 可能是执行差异、样本差异或效应本身不稳 |
| 统计不显著 = 没有效果 | 可能功效不足；需看区间与效应量 |
