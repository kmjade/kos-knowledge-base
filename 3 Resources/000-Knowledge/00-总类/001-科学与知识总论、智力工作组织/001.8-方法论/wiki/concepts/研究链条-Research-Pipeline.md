# 研究链条 Research Pipeline

## 定义

**研究链条**是把研究拆成可检查环节的检查表：**问题 → 文献 → 假说 → 设计 → 数据 → 分析 → 推断 → 检验 / 复现 → 修正 → 传播**。它是检查工具，不是实际路径——真实研究常在环节间回跳。

## 要点

| 环节 | 主要产出 | 合格判据 |
|:------|:------|:------|
| 问题 | 可回答的研究问题 | 范围清楚 · 概念可操作 |
| 文献 | 空白与既有解释图谱 | 覆盖反方 · 检索可复现 |
| 假说 | 可检验的预期 | 方向明确 · 能被推翻 |
| 设计 | 抽样、对照、测量方案 | 能区分竞争解释 |
| 数据 | 记录与元数据 | 完整 · 可追溯 · 合规 |
| 分析 | 描述与推断结果 | 与预注册一致 · 敏感性分析 |
| 推断 | 结论与适用范围 | 效应量 · 不确定性 · 边界 |
| 检验 | 复现与独立验证 | 独立数据 · 同法可重复 |
| 修正 | 理论或方法的更新 | 公开修订理由 |

**四类研究空白**：证据空白（无人做过）· 方法空白（测不准）· 理论空白（解释矛盾）· 实践空白（未落地）。

**三种检验**：统计检验（能否由偶然产生）· 稳健性检验（换假设后是否成立）· 独立复现（新数据能否得到同结论）。

## 要义

- 好问题四维：**重要 · 新颖 · 可行 · 具体**；不可回答的典型是概念未定义、范围无限、同义反复。
- 文献检索要**可复现**（数据库、检索式、时间范围、纳入排除标准）；只读支持自己观点的文献，是后续一切偏差的起点。
- 假说必须说得出「什么结果会让我放弃它」；[[操作化-Operationalization|操作化]]决定概念能否被测量。
- 迭代不是缺陷，**不披露迭代**才是：哪些事前计划、哪些事后调整必须标明，否则产生 [[p-hacking|p-hacking]] 与 HARKing。
- 区分**发现语境**与**辩护语境**：发现可以靠直觉与试错，辩护必须给出可公开检查的证据链。
- 五个常见误读：必须顺序执行；有数据就能推断；预注册限制探索；复现失败 = 造假；不显著 = 无效应。
