# 效应量 Effect Size

## 定义

**效应量**是效应的大小，可用原始单位（如血压下降 8 mmHg）或标准化单位（如 Cohen's d）表示。它回答「差异有多大」，与回答「差异是否可能由偶然产生」的 [[p值-p-Value|p 值]] 互补。

## 要点

| 表达 | 优点 | 注意 |
|:------|:------|:------|
| 原始单位 | 可直接解释实践意义 | 跨研究不可直接比较 |
| 标准化单位 | 可跨研究汇总 | 受样本异质性影响 |
| 区间估计 | 显示不确定性 | 比点估计更诚实 |
| 最小重要差异 | 连接统计与决策 | 需领域判断，非统计产物 |

## 要义

- 报告效应量 + 不确定性，不只报 p 值；这是[[证据强度-Evidence-Hierarchy|证据推断]]的基本要求。
- 显著但效应微小，可能没有实践意义；反之，不显著但区间宽，不能断言无效应。
- 元分析汇总的是效应量，因此受原始研究的[[发表偏倚-Publication-Bias|发表偏倚]]与[[选择偏差-Selection-Bias|选择偏差]]影响。
- 效应量的解释依赖情境与领域惯例；「大 / 中 / 小」的通用阈值只能作粗略参照。
- 预测问题看外部验证与误差，机制问题看效应路径；不要用同一尺度强行比较。
