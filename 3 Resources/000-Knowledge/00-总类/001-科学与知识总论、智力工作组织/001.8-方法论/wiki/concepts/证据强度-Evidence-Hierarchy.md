# 证据强度 Evidence Hierarchy

## 定义

**证据强度阶梯**是按研究设计对因果主张的支持力给出的一般排序。它是**统计倾向**，不是绝对等级，也不适用于所有类型的问题。

## 要点

**一般排序（弱 → 强）**：

```
个案 / 轶事 < 横断面观察 < 队列 / 病例对照 < 随机对照试验 < 系统综述 / 元分析
```

| 层级 | 强在哪 | 弱在哪 |
|:------|:------|:------|
| 个案 / 轶事 | 生动 · 发现线索 | 无法排除偶然与混杂 |
| 横断面 | 可描述分布与关联 | 时序不明 |
| 队列 / 病例对照 | 可看时序 · 适合罕见结果 | 混杂 · 回忆偏差 |
| RCT | 随机化控制混杂 | 外推受限 · 成本高 |
| 系统综述 / 元分析 | 汇总 · 检验异质性 | 受原始研究偏倚污染 |

**区分三层**：数据（未经解释的记录）→ 证据（与某主张相关的数据）→ 结论（由证据支持的判断）。

## 要义

- **三条必要修正**：设计良好的观察研究可强于执行糟糕的 RCT；元分析强度取决于纳入研究质量（垃圾进，垃圾出）；不同问题适用不同阶梯。
- 结论的强度不能超过证据与设计所能支撑的范围——这是推断的第一原则。
- 表达不确定性时，区分「尚无一致证据」与「证据表明无」；前者是空白，后者需要足够功效。
- 区间优于点估计，预测区间宽于置信区间，情景优于单一预言。
- 与 [[发表偏倚-Publication-Bias|发表偏倚]]、[[可重复性危机-Replication-Crisis|可重复性危机]] 联动：阶梯上游的设计也会被下游的发表与复现问题污染。
