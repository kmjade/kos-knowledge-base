## 一、方法、方法论、技法

| 概念 | 含义 | 回答的问题 |
|:------|:------|:------|
| **方法**（method） | 具体的研究程序 | 「这一步怎么做」 |
| **方法论**（methodology） | 关于方法的选择、依据与评价 | 「为什么用这个方法、它凭什么可信」 |
| **技法**（technique） | 操作层面的技巧 | 「怎么做得更稳、更准」 |

- 方法论有**描述性**（研究者实际怎么做）与**规范性**（应该怎么做）两面。
- 方法论不提供「唯一正确流程」：方法选择取决于问题、对象、资源与伦理约束。
- **方法与范式相关**：范式决定什么算问题、什么算证据（参见 [[范式-Paradigm|范式]]）。

## 二、研究链条

**通用链条**：问题 → 文献 → 假说 / 研究问题 → 研究设计 → 数据 → 分析 → 推断 → 检验 / 复现 → 修正 → 传播。

| 环节 | 关键动作 | 常见失败 |
|:------|:------|:------|
| 问题 | 界定范围、可回答性 | 问题过大、概念未定义 |
| 文献 | 确认空白与既有解释 | 只读支持性文献 |
| 假说 | 给出可检验的预期 | 不可证伪、事后假设 |
| 设计 | 选择对照、样本、测量 | 无对照、样本不足 |
| 数据 | 采集、清洗、记录 | 测量误差、缺失非随机 |
| 分析 | 描述、推断、敏感性分析 | 多重比较、过拟合 |
| 推断 | 效应量、不确定性、因果 | 把相关当因果 |
| 检验 | 独立复现、预注册对照 | 只做一次、不可复现 |

## 三、研究设计四维

| 维度 | 取值 | 说明 |
|:------|:------|:------|
| **目的** | 探索 · 描述 · 解释 · 预测 | 决定设计与推断强度 |
| **数据** | 定性 · 定量 · 混合 | 与问题匹配，而非与偏好匹配 |
| **时间** | 横断 · 纵向 · 回顾 · 前瞻 | 纵向更强，但成本更高 |
| **控制** | 实验 · 准实验 · 观察 | 控制越强，内部效度越高 |

**设计类型与适用**：

| 设计 | 适用 | 主要威胁 |
|:------|:------|:------|
| 随机对照试验 | 因果效应 | 外部效度、伦理限制 |
| 准实验（自然实验、断点回归） | 不可随机化时 | 未观测混杂 |
| 队列 / 病例对照 | 罕见结果、长期暴露 | 混杂、回忆偏差 |
| 横断面调查 | 描述与关联 | 无法确定时序 |
| 个案 / 质性研究 | 机制、意义、过程 | 外推受限 |
| 计算 / 模拟 | 复杂系统、大规模数据 | 模型假设、过拟合 |

> **内部效度**（因果推断是否成立）与**外部效度**（能否外推）常相互权衡；设计阶段就要说明取舍。

## 四、证据与推断

**证据强度（弱 → 强，适用于医学/社会科学的一般排序）**：

个案 / 轶事 < 横断面观察 < 队列 / 病例对照 < 随机对照试验 < 系统综述 · 元分析。

> 排序是一般倾向，不是绝对等级：设计良好的观察研究可强于执行糟糕的试验。

**因果推断的三个前提**：关联存在 · 时序正确 · 排除主要混杂（或通过设计/模型控制）。

**推断的三个常见混淆**：

| 混淆 | 纠正 |
|:------|:------|
| 统计显著 = 效应重要 | 报告**效应量**与置信区间，不只看 p 值 |
| 不显著 = 无效应 | 可能是功效不足；区分「无证据」与「证据表明无」 |
| 相关 = 因果 | 检查时序、混杂与替代解释 |

## 五、常见失效模式与对策

| 失效 | 机制 | 对策 |
|:------|:------|:------|
| 选择偏差 | 样本非随机、自愿参与 | 明确抽样框、报告流失 |
| 混杂 | 第三变量同时影响自变量与因变量 | 随机化、匹配、分层、敏感性分析 |
| 幸存者偏差 | 只观察到「留下来」的案例 | 追踪完整队列 |
| 测量偏差 | 仪器、问卷、访谈者效应 | 校准、盲法、多源测量 |
| p-hacking | 反复分析直到显著 | 预注册分析计划 |
| 过拟合 | 模型记住噪声 | 交叉验证、独立测试集 |
| 发表偏倚 | 阴性结果不发表 | 注册报告、结果无关评审 |
| 不可复现 | 细节缺失、数据不共享 | 数据与代码开放、复现研究 |

> 对策内核：**预注册 + 可复现**（数据与代码公开）比「结果漂亮」更重要（参见 [[发表偏倚-Publication-Bias|发表偏倚]] · [[可重复性危机-Replication-Crisis|可重复性危机]]）。

## 六、智力工作组织

| 层 | 内容 |
|:------|:------|
| **个人** | 笔记法（卡片盒 · 原子化）· 文献管理 · 项目 / 领域分层 |
| **流程** | 捕获 → 处理 → 组织 → 表达（输入 → 输出 → 成果） |
| **协作** | 预注册 · 数据共享 · 同行评议 · 可复现性规范 · 贡献署名 |
| **工具** | 参考管理 · 版本控制 · 个人知识库 · 自动化脚本 |

- **流程设计的原则**：可追溯（来源与版本）· 可复用（模板与规范）· 可中断（原子化笔记）。
- 智力工作的产出不只是文本，还包括**可复用的判断标准**；默会部分难以文档化（参见 [[默会知识-Tacit-Knowledge|默会知识]]）。

## 七、方法论之争

| 争论 | 一方 | 另一方 | 现状 |
|:------|:------|:------|:------|
| 定量 vs 定性 | 可测量、可统计、可重复 | 意义、情境、机制 | 混合方法渐成常态 |
| 实验 vs 观察 | 控制强、因果清晰 | 贴近真实、外推好 | 按问题取舍 |
| 理论驱动 vs 数据驱动 | 先有假说再检验 | 从数据中发现模式 | 计算科学推动二者结合 |
| 单一方法 vs 方法多元 | 标准化便于比较 | 多方法交叉验证 | 三角验证（triangulation） |

- 方法论多元不是「怎么都行」：每种方法都有其适用条件与失效模式。
- 判断方法好坏的标准是**与问题的匹配度**，而非方法的「先进程度」。
