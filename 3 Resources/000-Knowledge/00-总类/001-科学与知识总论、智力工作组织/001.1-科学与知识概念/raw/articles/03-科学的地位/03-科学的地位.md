# 03 科学的地位

> 本库第 03 章。回答「科学**凭什么有权威**、这份权威到**哪里为止**」：权威的来源、与其他知识形式的效力边界、科学主义的越界、专家与公众的关系。
> 入口：[[001.1-科学与知识概念|001.1 科学与知识概念]]。性质见 [[01-科学的性质|01 科学的性质]]；划界见同库入口页「四、科学的边界」。

---

## 一、「地位」是两层问题

| 层 | 问题 | 回答依据 |
|:------|:------|:------|
| **认识论地位** | 科学主张为何比其他主张更可信 | 方法 · 证据 · 纠错机制 |
| **社会地位** | 科学为何在公共决策中被优先援引 | 建制 · 制度授权 · 历史绩效 |

两者常被混为一谈：**社会地位高，不自动等于认识论上更可靠**；反之，认识论上可靠的主张也可能因不被理解而缺乏社会影响。

## 二、权威从哪来

科学的权威**不是**来自「科学家更聪明」或「结论永远正确」，而来自四件可检验的事：

| 来源 | 机制 | 失灵时 |
|:------|:------|:------|
| **可检验性** | 主张能被独立核查 | 不可测的主张只能靠信任 |
| **纠错机制** | 错误会被后续研究暴露 | 发表偏倚、护短文化 |
| **公共性** | 方法、数据、推理对同行开放 | 数据壁垒、商业保密 |
| **可追责** | 结论有署名、有同行评议、可撤稿 | 权威压制质疑 |

> 一句话：科学的权威是**程序权威**，不是**人格权威**。「专家说的」只有在该专家遵循程序时才构成理由。

### 2.1 权威是有范围的

- **领域限定**：物理学家的权威不及于流行病学问题；跨领域背书不自动成立。
- **证据限定**：权威支持的是「当前证据下的判断」，不是对未来或个案的保证。
- **程度限定**：共识有强弱之分（教科书级 / 主流但有争议 / 前沿未定），公共讨论常把三者混为一谈。

## 三、与其他知识形式的效力边界

| 知识形式 | 有效性来源 | 科学能否取代 | 说明 |
|:------|:------|:--:|:------|
| **常识** | 日常经验、社会传承 | 部分 | 科学常修正常识（地球运动），但日常实践仍依赖常识 |
| **数学 / 逻辑** | 证明 | 否 | 科学使用数学，但不裁决数学真理 |
| **历史学** | 史料、解释、因果重构 | 部分 | 可借科学方法（年代测定），但核心是解释而非预测 |
| **技艺 / 默会知识** | 实践检验、师徒传递 | 否 | 可被部分形式化，不可完全替代 |
| **法律** | 规范、程序、先例 | 否 | 科学提供事实，法律作规范判断 |
| **伦理 / 宗教 / 审美** | 价值、意义、信仰 | 否 | 不主张经验命题，科学无裁决权 |

> 边界不是「高低」，而是**分工**：每种知识形式在其效力域内不可替代，越域使用才是问题。

## 四、事实与价值：休谟断头台

- **是—应当问题**：从「事实如何」推不出「应当如何」（休谟）。
- 科学能回答：某措施**会**产生什么后果、概率多大、代价由谁承担。
- 科学不能单独回答：某后果**是否可接受**、如何权衡公平与效率、哪些价值优先。
- 常见错误：把「技术上可行」当作「应当做」；或把「有科学依据」当作「价值中立」。

> 政策判断 = **科学证据 + 价值权衡 + 程序合法性**，三者缺一不可，且不可互相替代。

## 五、科学主义：三种越界

**科学主义**（scientism）指把科学的方法或权威扩张到其效力域之外。三种典型形态：

| 越界 | 表现 | 问题 |
|:------|:------|:------|
| **范围越界** | 用经验方法裁决价值、意义、审美问题 | 范畴错误：方法不适用其对象 |
| **权威越界** | 以「科学」名义压制尚未检验的异见 | 违背科学自身的可批评原则 |
| **语言越界** | 把「不科学」等同于「错误/无价值」 | 混淆描述与评价；非科学 ≠ 假 |

> 反向的「反科学」同样越界：以价值或立场为由否认可检验的经验结论。两者都是**把某一类权威绝对化**。

## 六、合理怀疑 vs 否认

| 维度 | 合理怀疑（科学内部） | 否认（反科学） |
|:------|:------|:------|
| 对象 | 具体主张、证据强度、方法缺陷 | 整个领域或共识 |
| 举证 | 提出替代解释或指出缺陷 | 要求「绝对证明」，否则不接受 |
| 对反例 | 视为修正契机 | 视为体系阴谋的证据 |
| 结论倾向 | 暂缓判断 / 修正 | 预设结论不变 |

> 判据不在「是否质疑」，而在**是否愿意被证据改变**。

## 七、专家与公众

- **专长不对称是结构性的**：没有人能亲自验证所有知识，现代社会靠**信任分工**运转（见 [[02-知识概念|02 知识概念]]「证言」）。
- **信任需要可问责的接口**：利益披露 · 数据可得 · 结论分级（强/中/弱）· 不确定性明示。
- **民主决策中的科学**：科学提供选项与后果，公众与代议机构作价值选择；把科学当「最终裁决者」或当「可随意否决的意见之一」，都不成立。
- **后常规科学**：在事实不确定、价值争议大、决策紧迫的领域（环境、公共卫生），科学、价值与程序必须同时在场。

## 八、科学的限度

| 限度 | 说明 |
|:------|:------|
| **复杂性** | 多因素耦合系统难做受控实验，因果识别依赖观测设计与模型 |
| **不可重复** | 历史事件、宇宙学、部分医学个案无法重做 |
| **观测扰动** | 测量本身改变对象（量子、社会调查的访谈效应） |
| **伦理约束** | 某些实验不可做（人体、生态），只能靠自然实验与推断 |
| **模型依赖** | 预测依赖模型假设，假设失效则结论失效 |
| **时间尺度** | 长期后果（气候、技术风险）超出常规验证周期 |

> 承认限度不是削弱科学，而是**准确使用**科学：给结论配上限条件，比给结论加绝对保证更可靠。
