# 05 科学如何变迁

> 本库第 05 章。回答「科学**怎么变**」：知识以什么方式被修正、替换与重组；累积论、革命论、纲领论、多元论各自的图景与代价；范式转移的机制；变迁的内部与外部动力。

## 一、为什么「变迁」本身是个问题

如果科学只是「不断积累正确结论」，变迁就不需要解释——新事实补进去即可。但科学史上反复出现的是**结构性替换**：

| 现象 | 例子 |
|:------|:------|
| 核心概念被重新定义 | 从「燃素」到「氧化」；从「以太」到「场」 |
| 基本实体被替换 | 地心 → 日心；热质 → 分子运动 |
| 问题与标准被改写 | 什么算「好解释」、什么算「证据」 |
| 旧理论的合理成分被保留 | 牛顿力学作为相对论的低速极限 |

> 因此问「科学如何变迁」，实际在问三件事：**什么在变**（命题 / 概念 / 标准）· **怎么变**（连续 / 断裂）· **凭什么算进步**（预测力 / 解释力 / 问题解决能力）。

## 二、四种模型

| 模型 | 变迁图景 | 代表 | 主要代价 |
|:------|:------|:------|:------|
| **累积论** | 知识逐层叠加，旧结论被更精确的结论覆盖 | 惠威尔（Whewell）· 逻辑实证主义 | 无法解释概念框架的整体替换 |
| **革命论** | 常规科学 → 异常 → 危机 → 范式转移 → 新常规科学 | 库恩（Kuhn, 1962） | 「不可通约」易被读成相对主义；断裂被夸大 |
| **纲领论** | 硬核受保护，保护带被修补或替换；以「进步 / 退化」评价 | 拉卡托斯（Lakatos） | 进步性需长时段才判得出；评价仍依赖事后视角 |
| **多元论** | 无统一方法，理论与方法竞争共存 | 费耶阿本德（Feyerabend）· 劳丹（Laudan）的问题解决模型 | 难以说明为何某些理论最终胜出 |

> 四者不是互斥的：**大多数日常科学是累积的，少数时刻是革命的，纲领论描述中间尺度，多元论提醒不要事后美化胜者。**

## 三、库恩的机制

| 概念 | 含义 | 常见误读 |
|:------|:------|:------|
| **范式**（paradigm） | 共同体共享的范例、问题与解法标准 | 被当成「一个理论」；实际是**范例 + 标准 + 共同体** |
| **常规科学** | 在范式内解谜，不质疑基本框架 | 被当成「平庸」；实为科学产出最集中的阶段 |
| **异常** | 范式预期与实际观测的持续不符 | 被当成「反例」；单个反例通常不足以动摇范式 |
| **危机** | 异常积累到常规手段无法吸收 | 危机不等于范式已死 |
| **革命 / 范式转移** | 新范式取代旧范式，教科书被重写 | 被当成「一夜替换」；实际常跨代际完成 |

### 3.1 范式转移的实际路径

1. **异常积累**：不是一次失败，而是同类失败反复出现，且补丁越打越多。
2. **危机公开化**：共同体内部出现方法之争、标准之争，年轻研究者开始转向。
3. **新框架出现**：能同时解释旧成功与新异常，且给出新的可检验预测。
4. **代际更替**：旧范式的捍卫者退出，教科书与课程重写。
5. **回溯重写**：科学史被重新叙述为「通向新范式的准备」。

> 关键在于第 3 步：新范式必须**保留旧范式的成功**，否则不构成替代，只是另起炉灶。

### 3.2 「不可通约」的准确含义

- **弱读法**（多数科学哲学家的用法）：概念在范式间**不能逐字对译**（「质量」在牛顿与相对论中含义不同），沟通需要重新学习，但不是无法比较。
- **强读法**（相对主义读法）：范式间无共同标准，因而无所谓进步——这是**推论过度**。
- 可比较的落点：预测精度、覆盖现象范围、问题解决能力、仪器可操作性、与其他领域的整合度。

## 四、波普尔 vs 库恩

| 维度 | 波普尔 | 库恩 |
|:------|:------|:------|
| 科学的关键 | **永远的批判**：猜想 → 反驳 | **常规时期的共识**：范式内解谜 |
| 变迁形态 | 持续的革命（不断淘汰） | 长期的常规 + 间断的革命 |
| 评价标准 | 可证伪性、逼真度 | 共同体接受、问题解决能力 |
| 风险 | 把科学描述得比实际更批判 | 把科学描述得比实际更保守 |

> 两者描述的是科学的**不同时段**，不是对同一事实的竞争解释。常态下库恩更贴近实际，危机时波普尔的图景更贴切。

## 五、变迁的几种现实形态

| 形态 | 说明 | 例子 |
|:------|:------|:------|
| **渐进修正** | 参数、边界条件、辅助假设的持续调整 | 常数精化、模型改进 |
| **工具驱动** | 新仪器打开新现象域 | 望远镜 · 显微镜 · 测序 · 引力波探测 |
| **理论统一** | 两个领域被一个更一般的框架覆盖 | 电与磁 → 电磁学；弱与电磁 → 电弱统一 |
| **理论分化** | 原领域分裂为方法不同的子领域 | 自然哲学 → 各门科学 |
| **跨域迁移** | 方法与概念被搬到新领域并改造 | 统计力学 → 计量经济学；进化论 → 算法设计 |
| **范式回退** | 旧框架在特定范围内被重新采用 | 几何光学在工程中的持续使用 |

> 教科书只记录「胜出」的路径，实际变迁大量是**并存、分层与局部保留**。

## 六、内部动力与外部动力

| 视角 | 主张 | 局限 |
|:------|:------|:------|
| **内部主义** | 科学按自身逻辑演进：问题、证据、理论竞争 | 忽略经费、政策、战争、产业对议题的塑造 |
| **外部主义** | 社会因素决定什么被研究、什么被接受 | 难以解释为何某些理论在多种社会条件下都被接受 |
| **互动视角** | 外部决定**议程与资源**，内部决定**结论的可接受性** | 两者的边界本身随案例变化 |

外部因素的典型作用：

- **经费与优先级**：资助方向改变研究版图（大科学装置、AI 算力）。
- **战争与产业**：雷达、密码学、材料、医药的加速。
- **政策与伦理**：某些研究被禁止或限制，方法转向替代设计。
- **传播与教育**：教科书与课程决定下一代的问题意识。

> 外部因素能解释「为什么研究这个」，很少能单独解释「为什么这个结论被接受」——后者仍需证据与批评。

## 七、个人层面的知识更新

科学变迁不只是共同体的历史，也是每个学习者的经验：

- **信念更新**：遇到反例时，先改辅助假设，最后才动核心信念（与迪昂—奎因一致）。
- **专长迁移**：旧技能在新范式下部分失效，部分转化为新方法的基础。
- **认知惯性**：投入越大，越难放弃旧框架（沉没成本）。
- **可操作建议**：把信念分层（核心 / 工作假设 / 具体判断），对每层设不同的更新门槛。

## 八、六个常见误读

| 误读 | 纠正 |
|:------|:------|
| 科学史 = 正确结论的累积 | 包含概念框架的整体替换与回溯重写 |
| 范式转移 = 新理论更真所以胜出 | 胜出依赖解释力、预测、简洁、共同体接受等多重因素 |
| 不可通约 = 无法比较 | 弱读法只否认逐字对译，不否认可比较 |
| 革命 = 一夜之间 | 通常跨代际完成，旧范式长期并存 |
| 常规科学 = 无创造性 | 解谜阶段的产出最集中，是革命的准备期 |
| 外部因素 = 决定结论 | 外部多决定议程，结论仍需内部证据支持 |
