## 一、为什么科学必须是建制

| 个人认知的局限 | 建制如何回应 |
|:------|:------|
| 无法亲自验证所有主张 | **分工与信任**：专家 + 同行评议 + 证言链 |
| 易受确认偏误与利益影响 | **公开与可批评**：数据、方法、结论对同行开放 |
| 记忆与生命周期有限 | **累积**：期刊、数据库、教科书、引用网络 |
| 单点错误无法自察 | **纠错**：重复实验、撤稿、复现研究、事后批评 |
| 资源与仪器门槛高 | **组织**：实验室、大学、学会、资助机构 |

> 结论：科学知识是**公共物品**，其生产与校验依赖制度，而不仅依赖个人德性。制度设计得好，普通人的工作也能累积成可靠知识；制度失灵，优秀个体也会产出不可靠结论。

## 二、默顿的四条规范（CUDOS）

| 规范 | 内容 | 现实张力 |
|:------|:------|:------|
| **C**ommunism（公有性） | 知识归共同体所有，发现者只获承认 | 专利、商业保密、数据壁垒 |
| **U**niversalism（普遍性） | 评价只看贡献，不问出身 | 机构声望、国籍、性别与语言偏见 |
| **D**isinterestedness（无私利性） | 不以私人利益替代证据 | 经费竞争、晋升压力、产业资助 |
| **O**rganized Skepticism（有组织的怀疑） | 对一切主张同等怀疑，包括自己的 | 权威压制、学派护短、审稿人情 |

> 规范是**应然**而非描述：它的价值在于提供批评制度的标准，而非证明科学界已做到。

## 三、建制的基本装置

| 装置 | 功能 | 典型问题 |
|:------|:------|:------|
| **期刊与同行评议** | 筛选、改进、登记优先权 | 审稿延迟、保守偏见、人情与利益冲突 |
| **优先权与署名** | 分配承认，激励公开 | 争夺优先权、挂名、贡献不透明 |
| **学会与会议** | 形成共同体、传播与批评 | 圈子化、议题固化 |
| **大学与实验室** | 提供资源与稳定岗位 | 教学与科研冲突、临时合同 |
| **资助机构** | 分配资源、设定议程 | 短期化、热门偏向、评审保守 |
| **数据库与标准** | 使知识可检索、可复用 | 格式割裂、访问收费 |
| **评价指标** | 简化质量判断 | 指标替代目标（古德哈特定律） |

## 四、奖励系统与马太效应

- **优先权竞赛**：承认归首个公开发表者，激励快速公开，也激励拆分发表与抢发。
- **引用与声誉**：引用既是承认也是社会资本，形成累积优势。
- **马太效应**（默顿）：已有声誉者获得更多承认与资源，同名工作被归于更知名者。
- **荣誉的层级**：奖项、院士、教职、经费共同构成分层；分层提高效率，也放大不公。

> 奖励系统是科学的**发动机**，也是**失灵的源头**：它奖励的是「被共同体看见的贡献」，不完全等于「真实的贡献」。

## 五、三种典型失灵

| 失灵 | 机制 | 后果 |
|:------|:------|:------|
| **发表偏倚** | 阳性结果更易发表，阴性结果被搁置 | 效应量被高估，文献整体失真 |
| **可重复性危机** | 样本小、发表偏倚、分析自由度（p-hacking）、不共享数据 | 部分领域经典结论无法复现 |
| **掠夺性出版** | 收取版面费、不做实质评审 | 低质内容获得「已发表」外观 |

附加失灵：**指标化评价**（以期刊影响因子代替论文质量、以数量代替贡献）、**利益冲突**（产业资助影响设计与报告）、**撤稿滞后**（错误结论在被撤前已被大量引用）。

## 六、治理与改革

| 工具 | 针对 | 作用 |
|:------|:------|:------|
| **预注册 / 注册报告** | 分析自由度、发表偏倚 | 先定假设与分析方案，减少事后挑结果 |
| **数据与代码共享** | 可重复性 | 允许独立复算与再分析 |
| **开放获取** | 访问不平等 | 降低阅读门槛（需防「作者付费」变掠夺性） |
| **复现研究与多中心合作** | 单点不可靠 | 用独立样本检验效应 |
| **撤稿与关注声明** | 错误传播 | 及时标记不可靠文献 |
| **贡献者角色标准（CRediT）** | 署名不透明 | 明确谁做了什么 |
| **评价改革（DORA 等）** | 指标替代目标 | 以内容而非期刊名评价 |

> 改革的方向不是取消建制，而是**让纠错机制跑得比错误传播更快**。

## 七、共同体的自净能力与边界

- **自净的证据**：撤稿机制、复现项目、方法学批评、开放数据运动——都是共同体对自身失灵的回应。
- **自净的限度**：涉及权威、经费与声誉时，纠错会被延迟或压制；跨领域问题（如医学与产业）更明显。
- **建制的边界**：科学共同体只对**经验主张**负责；价值判断、政策选择属公共领域（见 [[03-科学的地位|03 科学的地位]]）。
- **外部监督的角色**：媒体、监管、司法、公众可以监督科学，但不能替代证据判断。

## 八、对知识工作者的含义

| 场景 | 做法 |
|:------|:------|
| 阅读文献 | 看样本量、预注册、数据可得性、利益披露，而非只看期刊名 |
| 引用结论 | 区分「已复现的效应」与「单篇报告的结果」 |
| 参与评审 | 对阳性与阴性结果采用同一标准；要求可重复的细节 |
| 自己产出 | 先写分析计划，保留原始数据，报告效应量与不确定性 |
| 判断争议 | 看共同体内部是否在按规范争论，而非只看结论是否合意 |

> 建制不是科学的装饰，而是科学**可被信任的结构性理由**。理解建制，才能恰当地信任与恰当地怀疑。

## 九、五个常见误读

| 误读 | 纠正 |
|:------|:------|
| 同行评议 = 质量保证 | 是筛选机制，有偏见与漏网；质量仍需事后检验 |
| 发表 = 结论可靠 | 发表只表示通过当期评审，不表示已复现 |
| 建制失灵 = 科学方法失效 | 失灵多为激励与治理问题，方法本身仍提供纠错路径 |
| 影响因子 = 论文质量 | 期刊层面指标，不能替代单篇评价 |
| 科学自治 = 不受监督 | 自治以公开与可问责为前提 |
