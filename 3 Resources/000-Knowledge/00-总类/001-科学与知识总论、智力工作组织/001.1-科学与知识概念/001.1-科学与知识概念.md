## 一、科学的性质

科学不是「一堆正确的结论」，而是三层叠加：

| 层 | 内容 | 判据 |
|:------|:------|:------|
| 知识层 | 系统化、可累积的命题体系 | 内部一致 · 可检验 |
| 方法层 | 观察 → 假说 → 检验 → 修正 的循环 | 可重复 · 可反驳 |
| 建制层 | 同行评议 · 期刊 · 共同体规范 | 公开 · 可批评 |

### 1.1 三个常被点名的特征

- **可检验**：命题能对应到可观察的后果。
- **可反驳**：说得出「什么结果会推翻它」。
- **公共性**：方法与数据对同行开放，结论可被独立复现。

> 反面：不可反驳的陈述（「任何反例都能被解释过去」）在科学上不作数。

### 1.2 三个容易混淆的区分

| 区分 | 要点 |
|:------|:------|
| **科学 ≠ 技术** | 科学求「为什么成立」，技术求「能否稳定奏效」；技术可以先于理论（蒸汽机早于热力学） |
| **科学 ≠ 数学** | 数学靠证明，科学靠经验检验；数学结论不因新观测而推翻 |
| **科学 ≠ 常识** | 常识以日常经验为界，科学主动构造反直觉的检验情境（受控实验、仪器延伸） |

### 1.3 科学知识的结构

- **观察负载理论**（theory-ladenness）：没有「纯粹中性」的观察，看什么、怎么看已由理论预设。
- **归纳问题**（休谟）：有限次观察推不出全称必然命题；科学因此不追求「证明」，而追求**未被推翻的强支持**。
- **假说—演绎**：从假说推出可检验蕴含，再用实验/观测裁决。
- **迪昂—奎因论题**：检验的从来不是单个假说，而是「假说 + 辅助假设 + 仪器理论」的整体；反例可迫使修正辅助假设而非核心。

## 二、知识概念

> 本篇标题含「知识概念」：科学知识是**知识**的一个制度化子集，先厘清知识本身。

### 2.1 知识的经典定义与争议

- **JTB 定义**：知识 = **被证成的真信念**（Justified True Belief）—— 信念 + 为真 + 有理由。
- **葛梯尔问题**（Gettier, 1963）：可构造「碰巧为真且看似有证成」的反例 ⇒ JTB 是**必要而非充分**条件。
- 后续路线：加第四条件（不可 defeat）· 改以**可靠过程**定义（可靠主义）· 放弃定义、改看**知识归赋的语境**（语境主义）。

### 2.2 知识的类型

| 类型 | 问法 | 例子 |
|:------|:------|:------|
| 命题性知识（know-that） | 知道「某事为真」 | 水的沸点在标准气压下为 100 ℃ |
| 技能性知识（know-how） | 知道「怎么做」 | 会焊接 · 会调参 |
| 熟悉性知识（acquaintance） | 认得「某人/某物」 | 认识这座城市 |
| 默会知识（tacit knowledge） | 难以言传、靠示范传递 | 手感 · 临床直觉 · 师傅带徒 |

### 2.3 与相邻概念的界线

| 概念 | 区别 |
|:------|:------|
| 数据 / 信息 | 数据是记录，信息是消解不确定性的差异，知识是**可据以行动与辩护**的结构化理解（DIKW 层级常被批评为过简） |
| 信念 / 意见 | 知识要求**真**与**证成**；意见可以无理由，信念可以为假 |
| 科学知识 | 命题性知识中经**公共检验**与**共同体批评**的那部分；技能/默会知识常先于它（见 1.2 科学 ≠ 技术） |

> 边界：知识**组织**理论（分类法 / 本体 / 元数据）归 [[3 Resources/000-Knowledge/02-信息学/02-信息学|02 信息学]]；知识**管理**（005.94）归 [[005-管理|005 管理]]。

## 三、科学的地位

- **认识论上**：科学是当代最有说服力的知识形式——不是因为「永远正确」，而是因为它**内置纠错机制**。
- **相对性**：科学 ≠ 唯一的知识形式。常识、数学、历史学、技艺性知识各有其有效性来源；科学的权威主要限于**经验命题**。
- **限度**：价值判断、审美与意义问题不在科学裁决范围（「是」与「应当」的分离）。
- **权威的来源**：可重复的公共程序 + 可追责的共同体，而非「科学家说了算」。

> 与哲学的关系：科学自自然哲学分化而来；哲学至今仍在替科学清理概念前提（因果、概率、定律、解释）。

### 3.1 科学主义的界线

「科学能回答一切问题」是**科学主义**，不是科学本身的立场。可区分的三种越界：

| 越界 | 表现 |
|:------|:------|
| 范围越界 | 用经验方法裁决规范/价值问题 |
| 权威越界 | 以「科学」名义压制尚未检验的异见 |
| 语言越界 | 把「不科学」当作「错误」的同义词 |

## 四、科学的边界

划界问题（demarcation）——「什么算科学」：

| 立场 | 判据 | 代表 | 主要困难 |
|:------|:------|:------|:------|
| 可证伪性 | 能给出被推翻的条件 | 波普尔（Popper） | 好科学也常靠辅助假设「护核」；达尔文式历史科学难做判决性实验 |
| 范式 | 是否共享常规科学的问题与解法 | 库恩（Kuhn） | 判据偏社会性，易滑向相对主义 |
| 研究纲领 | 是否「进步性」地预测新事实 | 拉卡托斯（Lakatos） | 「进步/退化」需长时间尺度才判得出 |

三种典型边界情形：

1. **尚未成熟**的领域——有事实基础、缺统一理论（不必然是非科学）。
2. **伪科学**——借用科学话术，却拒绝对其核心主张作检验（其**传播现象**另见 [[001.9-知识的传播|001.9 知识的传播]]）。
3. **非科学**——本身不主张经验命题（数学 · 逻辑 · 形而上学 · 伦理）。

> 判据是**家族相似**而非单一开关：越靠近「可检验 · 可反驳 · 公共可批评」，越靠近科学。

### 4.1 划界的现实用法

- 划界是**程度判断**，不是身份标签；「某领域是伪科学」通常指**某些主张的辩护方式**，而非该领域所有人。
- 争议常发生在**证据标准**（要多少证据、谁举证），而非「有没有证据」。
- 行政/司法场景中的划界（如教材、诊疗、鉴定）需要**可操作的清单**，而非哲学定义。

## 五、科学如何变迁

| 模型 | 变迁图景 | 代表 |
|:------|:------|:------|
| 累积论 | 知识逐层叠加，旧理论被新理论覆盖 | 逻辑实证主义 |
| 革命论 | 常规科学 → 危机 → 范式转移 → 新常规科学 | [[3 Resources/People/wiki/entities/Thomas-Kuhn-库恩\|库恩]] |
| 纲领论 | 硬核受保护，围绕它的保护带被修补或替换 | 拉卡托斯（Lakatos，承 Popper 的问题意识） |
| 无政府主义 | 方法多元，「怎么都行」 | 费耶阿本德（Feyerabend） |

- **范式转移**不是「更真的理论胜出」的简单叙事：包含解释力、预测力、简洁性、共同体接受度等多重因素。概念详见 [[范式转移-Paradigm-Shift|范式转移]]（史学视角）。
- **波普尔 vs 库恩** 的分歧核心：科学的关键是**永远的批判**（Popper），还是**常规时期的共识**（Kuhn）？两者描述的是科学的不同时段。

## 六、科学的社会建制

| 规范（默顿 CUDOS） | 含义 |
|:------|:------|
| **C**ommunism | 知识归共同体所有，发现者只获承认 |
| **U**niversalism | 评价只依贡献，不问出身 |
| **D**isinterestedness | 不以私利替代证据 |
| **O**rganized Skepticism | 对一切主张同等怀疑 |

现实偏差：发表偏倚 · 可重复性危机 · 经费与议题的相互塑造 · 权威对异见的抑制。这些是**建制问题**，不构成对科学方法的否定——方法的价值恰在于能暴露自身错误。

## 七、四个常见误读

| 误读 | 纠正 |
|:------|:------|
| 科学 = 真理 | 科学 = 当前证据下最可靠、且随时可修正的主张 |
| 有共识 = 已证实 | 共识是**证据与批评的暂态结果**，不是终局 |
| 不可证伪 = 无意义 | 不可证伪的命题可能属**非科学**（形而上学/伦理），不等于无价值 |
| 科学方法 = 唯一理性 | 科学是理性的一种制度化形态，不是理性的全部 |
