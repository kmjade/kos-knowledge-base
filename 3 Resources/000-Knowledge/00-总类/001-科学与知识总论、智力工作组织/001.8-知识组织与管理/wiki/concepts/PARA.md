# PARA

## 定义

PARA 是 Tiago Forte 提出的**行动导向**知识组织方法，按四个分类存放一切资料：**P**rojects（项目）/ **A**reas（领域）/ **R**esources（资源）/ **A**rchives（归档）。

## 要点

| 分类 | 判断标准 | 特点 |
|------|---------|------|
| Projects | 有明确目标与截止时间 | 短期、行动导向 |
| Areas | 需长期维持的责任 | 无截止时间 |
| Resources | 可能用到的主题/兴趣 | 被动参考 |
| Archives | 以上三者中不再活跃的 | 冷存储 |

- 核心问题：「这件事跟哪个项目有关？」
- 适合**项目驱动的多线程工作**，笔记「随项目走」
