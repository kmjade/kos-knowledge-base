# 01 ComfyUI 导论

## 什么是 ComfyUI

ComfyUI 是**最强大的开源节点式生成式 AI 应用**，由 Comfy Org 出品。它以**节点图（Nodes + Links）**组织生成流程，让用户像搭积木一样构建、复用、分享复杂的生成管线，支持图像、视频、音频与 3D 生成。

## 核心理念

| 特性 | 说明 |
|------|------|
| **节点图工作流** | 可视化编程，节点 + 链接 |
| **可复用/可分享** | 工作流导出为 JSON/PNG/WebP |
| **可编程** | WebSocket/REST API + SDK + MCP + CLI |
| **多模态** | 图像 / 视频 / 音频 / 3D |
| **生态** | 1000+ 自定义节点 |

## 出品方：Comfy Org

Comfy Org 是 ComfyUI 的出品方（原作者 comfyanonymous），现提供 ComfyUI Desktop、Comfy Cloud、Comfy MCP、Comfy CLI 与合作伙伴模型。

## 与同类工具对比

| 工具 | 定位 | 与 ComfyUI 的差异 |
|------|------|------------------|
| Stable Diffusion Web UI (A1111) | 表单式界面 | A1111 自 2025-02 基本停更，ComfyUI 活跃 |
| Stable Diffusion Forge | A1111 继任 | Forge 兼容 A1111 扩展，ComfyUI 是不同范式 |
| Fooocus | 极简界面 | ComfyUI 面向高级/生产，学习曲线陡 |

## 状态（2026）
