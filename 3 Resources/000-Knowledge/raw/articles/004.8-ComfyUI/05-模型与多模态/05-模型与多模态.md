# 05 模型与多模态

## 支持的模型

| 类型 | 模型 |
|------|------|
| 图像 | SD 1.5 / 2.x / SDXL / SD3 / FLUX / Pixart / AuraFlow / HunyuanDiT |
| 视频 | SVD / Mochi / LTX-Video / Hunyuan Video / Wan 2.1/2.2 / AnimateDiff |
| 音频 | Stable Audio 等 |
| 3D | Hunyuan3D 2.0 等 |

## FLUX

FLUX（Black Forest Labs）**原生支持**（经自定义节点），ComfyUI 发布数日内即支持。变体：Flux Schnell / Dev / Kontext，FP8 约 12GB。ComfyUI 可在 **12GB 显存**跑 FLUX（A1111 会崩）。

## ControlNet / IPAdapter

| 扩展 | 用途 |
|------|------|
| controlnet-aux | ControlNet 预处理器 |
| ipadapter_plus | 图像提示（风格/角色一致） |

## 视频生成

AnimateDiff、AnimateAnyone-Evolved（姿态转视频）、Wan（T2V/I2V）、SVD、LTX-Video 等。
