# ComfyUI

Comfy Org 出品的节点式生成式 AI 应用（GPL-3.0），支持图像/视频/音频/3D 生成，是高级用户与生产的黄金标准。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 节点式生成式 AI 应用 |
| 出品方 | Comfy Org |
| 范式 | 节点图工作流 |
| 模型 | SD/SDXL/SD3/FLUX/video/audio/3D |
| 许可 | GPL-3.0 |
| 规模 | ~130K stars |

## 关键特性

- 节点图工作流（导出 JSON/PNG/WebP）
- 1000+ 自定义节点 + ComfyUI Manager
- WebSocket/REST API + Comfy SDK + MCP + CLI
- FLUX 原生支持、视频/音频/3D 生成
