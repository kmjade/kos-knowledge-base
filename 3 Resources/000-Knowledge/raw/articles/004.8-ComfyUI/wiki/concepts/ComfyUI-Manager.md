# ComfyUI Manager

## 定义

ComfyUI Manager 是**近乎必装**的自定义节点管理器：一键安装/更新/卸载自定义节点、检测缺失依赖、模型下载、工作流修复、版本管理。

## 关键特性

| 特性 | 说明 |
|------|------|
| 安装 | 克隆到 custom_nodes/ |
| 依赖 | 缺失 Python 依赖检测 |
| 修复 | 工作流自动修复 |
