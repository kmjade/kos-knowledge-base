# API 接口

## 定义

API 是 ComfyUI 的**自动化接口**：内置 WebSocket + REST API + 队列系统，端点如 `/system_stats`、`/api/object_info`、`/api/queue`、`/history`。Comfy Cloud 有差异（API Key、`/history_v2` 等）。
