# 工作流 Workflow

## 定义

工作流（Workflow）是 ComfyUI 的核心：**节点图**表达生成管线，可导出为 **JSON/PNG/WebP** 并嵌入到输出图片中（便于复现与分享）。每个工作流本质是一个 JSON 图（File → Export Workflow (API)）。

## 关键特性

| 特性 | 说明 |
|------|------|
| 节点图 | 可视化编程 |
| 导出 | JSON / PNG / WebP |
| 嵌入 | 工作流嵌在输出图里 |
