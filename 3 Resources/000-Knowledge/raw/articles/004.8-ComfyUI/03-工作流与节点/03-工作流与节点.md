# 03 工作流与节点

## 工作流（Workflow）

工作流是 ComfyUI 的核心：**节点图**表达生成管线，可导出为 **JSON/PNG/WebP**，并嵌入到输出图片中（便于复现与分享）。

## 节点（Nodes）

节点是工作流的**功能单元**，每个节点有输入/输出端口与参数：

| 类别 | 示例 |
|------|------|
| 加载 | Load Checkpoint、Load LoRA、Load Image |
| 提示词 | CLIP Text Encode（正/反） |
| 采样 | KSampler（采样器/步数/CFG/种子） |
| 解码 | VAE Decode |
| 保存 | Save Image |

## 链接（Links）

链接连接节点的输出端口到输入端口，定义数据流（模型/LATENT/IMAGE/MASK 等 datatype）。

## 子图（Subgraph）

把多个节点封装成一个可复用子图。

## Partial Execution（部分执行）

只执行图中选中的部分节点，便于调试。
