# 08 高级与优化

## 显存与性能

| 要点 | 说明 |
|------|------|
| 简单生成 | 比 A1111 更省显存 |
| 复杂节点栈 | 多 ControlNet/IPAdapter/AnimateDiff 更吃显存（全载入内存） |
| FLUX | 12GB 可跑（A1111 会崩） |

## 硬件建议（2026）

| 场景 | 显存 |
|------|------|
| 专业工作流 | 16GB 起步 |
| FLUX FP16 | 24GB 舒适 |
| 视频/训练 | 32GB+（RTX 5090） |

## 生产部署

- **用 release tags**，不用 master（不稳定，可能破坏自定义节点）
- 备份后再大改动
- 谨慎升级 Torch/CUDA
- AMD/Mac 支持，但部分自定义节点 NVIDIA-only
