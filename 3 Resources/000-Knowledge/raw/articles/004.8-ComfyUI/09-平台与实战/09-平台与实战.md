# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| Desktop | Windows/macOS 桌面应用 |
| 本地 Web | 自托管，`http://127.0.0.1:8188` |
| Comfy Cloud | 云端托管，含免费额度 |
| Comfy MCP | 供 AI agent 调用 |
| Comfy CLI | 终端调用 |

## 实战案例

### 文生图

默认工作流：Checkpoint → 提示词 → KSampler → VAE Decode → Save。

### 图生图

Load Image → VAE Encode → KSampler(denoise) → 生成变体。

### FLUX 出图

加载 Flux Dev FP8（~12GB）→ 在 12GB 显存跑 FLUX。

### 视频生成（AnimateDiff）

SD1.5 + animatediff-evolved + ipadapter_plus + VHS_VideoCombine，生成循环动画。

### 工作流分享

导出 PNG（含工作流）→ 分享给他人，拖入即复现。

### Agent 集成（Comfy MCP）

配置 Comfy MCP，让 Claude Code 等 agent 调用 ComfyUI 生成图像。
