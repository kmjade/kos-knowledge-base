# 04 文生图与图生图

## txt2img 工作流

```
Load Checkpoint → CLIP Text Encode（正向+反向）→ Empty Latent Image → KSampler → VAE Decode → Save Image
```

## img2img 工作流

```
Load Image → VAE Encode → KSampler（denoise）→ VAE Decode → Save Image
```

## 核心节点

| 节点 | 用途 |
|------|------|
| Checkpoint Loader | 加载主模型 |
| CLIP Text Encode | 正/反向提示词 |
| KSampler | 采样器/步数/CFG/denoise/种子 |
| VAE Decode/Encode | 潜空间↔图像 |

## 提示词语法

- 正向/反向两个 CLIP Text Encode
- 权重语法与 SD WebUI 类似（`(term:1.2)` 等取决于具体模型）
