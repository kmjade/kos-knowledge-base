# 004.8 Windsurf

> **Windsurf 是「AI 编码 IDE」这一品类的早期代表，2026-06-02 起已正式更名为 Cognition 的 Devin Desktop。** 其独特性不在编辑器本身，而在「**以 agent 管理为中心**」的产品架构：本地代理（Devin Local）与云端代理（Devin Cloud）在同一个看板式界面（Agent Command Center）中统一调度，并通过 ACP 协议接纳第三方代理。
>
> 本页以**历史名建库、现名写正文**：外部资料仍大量以 "Windsurf" 命名，故保留该检索入口，同时记录其向 Devin Desktop 的语义迁移。

## 一句话定位

| 问题 | 回答 |
|------|------|
| 它是什么？ | 基于 VS Code 代码库的 AI IDE，现为 Cognition 的 **Devin Desktop** |
| 与 Cursor 的差异？ | Cursor 以「编辑器 + 补全」为中心；Devin Desktop 以「**代理编排**」为中心 |
| 与 Claude Code / Codex 的关系？ | 不是纯替代——通过 ACP 可将它们作为第三方代理纳入同一界面编排 |
| 商业模式？ | 编辑器作为入口，Devin Cloud 按任务/席位计费 |

## 产品架构

### 三个层次

```
┌─────────────────────────────────────────────┐
│  Agent Command Center（默认界面）             │
│  看板式管理本地/云端代理 · Spaces 共享上下文    │
├──────────────────┬──────────────────────────┤
│  Devin Local     │  Devin Cloud             │
│  编辑器内代理      │  自主执行 · 开 PR         │
│  子代理 · 沙箱     │  IDE 内审 diff / 测试     │
├──────────────────┴──────────────────────────┤
│  IDE 基座（VS Code 血统 · 扩展 / LSP / 终端）  │
└─────────────────────────────────────────────┘
         ↕ ACP（Agent Client Protocol）
   Codex CLI · Claude Agent · OpenCode 等第三方代理
```

### 关键概念

| 概念 | 说明 | 前身 |
|------|------|------|
| **Agent Command Center** | 默认主界面；看板视图追踪运行中/排队中的代理 | Windsurf 2.0 引入 |
| **Spaces** | 将同一任务/项目的会话、PR、文件与上下文归组，供相关代理共享 | 新增 |
| **Devin Local** | 编辑器内代理运行框架；支持子代理与沙箱；官方称 token 效率提升至多 30% | Cascade（2026-07 起下线） |
| **Devin Cloud** | 云端自主代理，可领取任务、开 PR，回到 IDE 内审阅 | Devin |
| **ACP** | 开放协议，允许第三方代理在同一界面并行运行、统一管理 | 新增 |

## 待核实与开放问题

1. **模型层**：二手评测提到 SWE-2 与「Devin Fusion」编排层，未在官方文档核实，暂不写入结论。
2. **定价**：Pro 约 $20/月并打包 Desktop + Cloud 的说法来自第三方评测；官方定价页未能访问，需人工核对。
3. **数据政策**：有评测称默认数据可用于训练、仅付费档可退出；涉及合规，需以官方 DPA 为准。
4. **Cascade 下线时间**：一处来源称 2026-07-01，官方 FAQ 仅称"保留至 7 月"，精确日期待核。
5. **品牌迁移成本**：外部文档、教程、社区仍在用 Windsurf 旧名，检索需同时覆盖两个词。
