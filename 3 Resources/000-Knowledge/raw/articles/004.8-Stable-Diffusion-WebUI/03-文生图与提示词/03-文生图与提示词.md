# 03 文生图与提示词

## txt2img

从文本提示生成图像，核心参数：

| 参数 | 说明 |
|------|------|
| 采样器（Sampler） | 去噪算法（Euler a / DPM++ 2M Karras 等） |
| 采样步数（Steps） | 迭代次数（通常 20–50） |
| CFG Scale | 提示词引导强度（通常 5–8） |
| 分辨率 | 输出尺寸 |
| 种子（Seed） | 固定随机性，可复现 |

## 提示词语法

### 注意力加权

```
((term))         # 加强 term
(term:1.21)      # 精确权重
[term]           # 减弱 term
```

### 反向提示词（Negative Prompt）

排除不想要的内容（如 `low quality, blurry, extra fingers`）。

### 高级语法

| 语法 | 说明 |
|------|------|
| Prompt editing | `[a:b:step]` 在指定步数切换 |
| 调度 | `[a:0.3]` 步数比例切换 |
| 风格 | 保存/加载 Style |

## 常用提示词技巧

- 正向：主体 + 风格 + 质量词 + 光照/构图
- 反向：常见瑕疵词（变形、模糊、多指等）
- 用 LoRA 触发词配合 `<lora:name:0.8>`
