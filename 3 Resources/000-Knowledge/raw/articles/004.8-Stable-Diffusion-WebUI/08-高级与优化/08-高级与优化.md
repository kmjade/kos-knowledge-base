# 08 高级与优化

## Highres Fix（高清修复）

先生成低分辨率，再放大重绘，避免高分辨率下的构图崩坏。

## 放大与超分

| 模型 | 说明 |
|------|------|
| RealESRGAN | 通用放大 |
| ESRGAN | 经典超分 |
| SwinIR | 高质量超分 |

## Tiled Diffusion

分块扩散，支持更高分辨率输出。

## X/Y/Z Plot

批量对比不同参数（采样器/步数/CFG/种子/模型）的效果，生成网格图。

## 显存与性能优化

| 参数 | 说明 |
|------|------|
| `--xformers` | 加速 + 省显存 |
| `--lowvram` | 低显存模式 |
| `--medvram` | 中显存优化 |
| `--opt-sdp-attention` | 更快的注意力实现 |
