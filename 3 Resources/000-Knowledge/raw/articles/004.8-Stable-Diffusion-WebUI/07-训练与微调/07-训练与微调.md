# 07 训练与微调

## 训练方式

| 方式 | 说明 | 资源需求 |
|------|------|----------|
| LoRA 训练 | 轻量微调风格/角色 | 较低（几 GB 显存） |
| Dreambooth | 学习新概念/主体 | 较高（8GB+） |
| Textual Inversion | 学习 embedding 触发词 | 较低 |

## 内置训练标签

SD WebUI 提供 Train 标签，支持 embedding / hypernetwork 训练。

## LoRA 训练要点

- 准备数据集（图像 + 标注/触发词）
- 选择底模（SD 1.5 / SDXL）
- 训练参数：学习率、步数、batch size
- 输出到 `models/Lora/`，提示词 `<lora:name:0.8>` 调用

## 第三方训练工具

| 工具 | 说明 |
|------|------|
| kohya_ss | 主流 LoRA/Dreambooth 训练 |
| sd-scripts | 底层训练脚本 |
