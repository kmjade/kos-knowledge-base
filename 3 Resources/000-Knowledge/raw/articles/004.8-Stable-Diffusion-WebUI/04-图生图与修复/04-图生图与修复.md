# 04 图生图与修复

## img2img

用提示词 + **denoising strength（去噪强度）** 改造现有图像：

| 参数 | 说明 |
|------|------|
| Denoising strength | 越接近 1 变化越大，越接近 0 越保留原图 |
| Loopback | 迭代精炼 |
| Resize | 调整尺寸后重绘 |

## Inpainting（局部重绘）

在 img2img → Inpaint 子标签，用蒙版涂抹需修改区域，只重绘该区域：

| 模式 | 说明 |
|------|------|
| Inpaint masked | 只重绘蒙版区 |
| Inpaint not masked | 只保留蒙版区，重绘其余 |
| Mask blur / padding | 蒙版边缘过渡控制 |

## Outpainting（外扩）

扩展图像边界，生成画布外内容。

## 面部修复（Face Restoration）

集成 **GFPGAN / CodeFormer** 等模型，修复面部细节。

## 放大（Upscale）

内置 **RealESRGAN / ESRGAN / SwinIR** 等放大模型。
