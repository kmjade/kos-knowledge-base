# 004.8 Stable Diffusion Web UI

> Stable Diffusion Web UI（AUTOMATIC1111，简称 A1111）是**最流行的开源本地 Stable Diffusion 图形界面**（Gradio），被誉为「AI 绘画的瑞士军刀」。以 txt2img/img2img/inpainting 三大核心 + 模型管理 + 扩展生态，把 Stable Diffusion 扩散模型变成本地可用的 AI 图像生成与编辑工具。数据更新至 2026-09。
