# 06 扩展与控制

## 扩展（Extensions）

100–300+ 社区扩展，经 Extensions 标签安装（列表或 GitHub URL）：

| 扩展 | 用途 |
|------|------|
| ADetailer | 自动修复面部/手部细节 |
| Regional Prompter | 分区提示词 |
| 放大类 | 更多 upscaler |
| 批处理/自动化 | 批量脚本 |

## ControlNet

社区扩展（`Mikubill/sd-webui-controlnet`），用**结构输入**（深度图/姿态骨架/边缘图）控制生成，最多 **3 个 ControlNet 单元**同时使用。

| 模式 | 输入 |
|------|------|
| Canny | 边缘图 |
| Depth | 深度图 |
| OpenPose | 姿态骨架 |
| Scribble / Segmentation | 涂鸦/分割 |

## REST API

```bash
--api   # 启动参数开启
```

提供 `/sdapi/v1/` REST API，用于批处理与自动化。
