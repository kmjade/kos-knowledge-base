# ControlNet

Stable Diffusion 的**结构控制技术**，在 SD WebUI 中以扩展形式提供（`Mikubill/sd-webui-controlnet`），用深度图/姿态/边缘等条件化生成。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 结构控制技术/扩展 |
| 扩展 | Mikubill/sd-webui-controlnet |
| 模式 | Canny / Depth / OpenPose / Scribble 等 |
