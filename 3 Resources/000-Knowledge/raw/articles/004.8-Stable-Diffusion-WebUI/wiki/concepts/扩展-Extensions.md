# 扩展 Extensions

## 定义

扩展（Extensions）是 SD WebUI 的**插件机制**：100–300+ 社区扩展，经 Extensions 标签安装（列表或 GitHub URL）。常见：ADetailer（自动修脸/手）、Regional Prompter（分区提示词）、放大类、批处理。
