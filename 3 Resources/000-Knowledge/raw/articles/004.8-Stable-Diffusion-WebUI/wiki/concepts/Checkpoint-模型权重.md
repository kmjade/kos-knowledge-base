# Checkpoint 模型权重

## 定义

Checkpoint 是 SD WebUI 的**主模型权重**（SD 1.5 / 2.x / SDXL / SD 3.x），存放于 `models/Stable-diffusion/`。支持热切换（无需重启）、Checkpoint Merger 混合（最多 3 个）、生成参数嵌入图片元数据。
