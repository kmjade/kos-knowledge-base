# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| 本地 Windows/Linux/macOS | 默认方式，NVIDIA GPU 最佳 |
| Stable Diffusion Forge | A1111 活跃继任，更省显存/更快 |
| ComfyUI | 节点式，更灵活/底层 |
| 云端（RunPod 等） | 租 GPU 跑 A1111 |

## 实战案例

### 文生图出图

```
正向：a cute cat, masterpiece, best quality
反向：low quality, blurry, deformed
采样：DPM++ 2M Karras, 30 steps, CFG 7
```

### 图生图改造

上传草图 + 提示词 + denoising 0.6，把草图变成成品图。

### 局部修复

Inpaint 蒙版涂抹面部 → 重绘 + Face Restoration（GFPGAN）修复。

### 角色一致性（LoRA）

训练角色 LoRA → `<lora:my_char:0.8>` 生成同角色不同场景。

### 结构控制（ControlNet）

用 OpenPose 骨架控制人物姿态，Canny 边缘控制构图。

### 批量参数对比

X/Y/Z Plot 一键对比不同采样器/步数/CFG 效果。

### 云端出图

RunPod 租 GPU 跑 A1111，`--listen` 远程访问。
