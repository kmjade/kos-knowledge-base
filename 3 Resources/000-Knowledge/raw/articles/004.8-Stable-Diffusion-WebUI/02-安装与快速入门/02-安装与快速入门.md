# 02 安装与快速入门

## 前提

| 依赖 | 说明 |
|------|------|
| Python | 3.10.x（推荐） |
| GPU | NVIDIA（CUDA）推荐；AMD/Intel 也可 |
| 显存 | SD 1.5 需 4–6GB；SDXL 建议 8GB+ |
| 磁盘 | 模型较大，预留充足空间 |

## 安装

```bash
# 克隆仓库
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui

# Windows
webui-user.bat

# Linux / macOS
./webui.sh
```

首次运行自动下载依赖与默认模型。

## 首次出图

1. 浏览器打开 `http://127.0.0.1:7860`
2. 选择 Checkpoint（模型）
3. 输入正向提示词 + 反向提示词
4. 点「Generate」生成

### 常用命令行参数（webui-user.bat 中 `COMMANDLINE_ARGS`）

| 参数 | 用途 |
|------|------|
| `--xformers` | 加速 + 省显存 |
| `--lowvram` | 低显存模式 |
| `--medvram` | 中显存优化 |
| `--api` | 开启 REST API |
| `--listen` | 允许局域网访问 |
| `--port 7860` | 指定端口 |
