# 05 模型管理

## 模型目录

| 类型 | 目录 | 说明 |
|------|------|------|
| Checkpoint | `models/Stable-diffusion/` | 主模型（SD 1.5 / 2.x / SDXL / SD 3.x） |
| LoRA | `models/Lora/` | 低秩适配微调 |
| VAE | `models/VAE/` | 变分自编码器 |
| Embedding | `models/embeddings/` | Textual Inversion |
| ControlNet | `models/ControlNet/` | 结构控制模型 |

## Checkpoint

- 支持 **热切换**（无需重启）
- 生成参数嵌入 PNG/JPEG 元数据，便于复现
- **Checkpoint Merger**：混合最多 3 个 checkpoint

## LoRA

```
<lora:model_name:0.8>    # 提示词中引用
<lora:a:0.6><lora:b:0.4>  # 可堆叠多个
```

## Textual Inversion / Hypernetwork

用于风格/概念微调，embedding 在提示词中以触发词引用。

## VAE

改善色彩与细节，避免「灰暗发白」问题。
