# 02 安装与快速入门

## 前置条件

OpenChamber 不自带推理能力，它运行在 **OpenCode SDK** 之上。因此：

1. 先安装 **OpenCode**；
2. 再安装 OpenChamber；
3. 在 OpenCode 中配置好模型 provider 与 API 密钥。

```bash
curl -fsSL https://opencode.ai/install | bash
```

> ⚠️ 文档差异：README 称 Desktop 安装包已捆绑匹配版本的 OpenCode CLI；官方文档与中文站 FAQ 仍将 OpenCode 列为前置条件。以实际安装包行为为准。

## 三条安装路径

| 路径 | 适用场景 | 命令 / 入口 | 额外要求 |
|------|---------|------------|---------|
| **Desktop** | 日常主力工作 | GitHub Releases / 官网下载 | 无（可能已捆绑 CLI） |
| **Web + PWA** | 远程访问、手机审阅 | `install.sh` + `openchamber` | Node.js 24.14+、已装 OpenCode CLI |
| **VS Code 扩展** | 会话紧贴代码 | Marketplace（`fedaykindev.openchamber`） | 已装 OpenCode CLI |

### Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

打开 CLI 打印的地址（通常是 `http://localhost:3000`），看到会话列表即成功。浏览器地址栏选「安装」可将其作为 PWA 应用。

### Desktop

从 Releases 或官网下载安装。README 列出 **macOS / Windows / Linux**；官方 Install 文档目前只写 macOS，属文档滞后，实际以 Releases 页为准。

Linux 提供 `.deb`、`.rpm` 与 AppImage：

```bash
sudo apt install ./OpenChamber-*-linux-amd64.deb
sudo dnf install ./OpenChamber-*-linux-x86_64.rpm
chmod +x OpenChamber-*.AppImage && ./OpenChamber-*.AppImage
```

AppImage 需要 FUSE；无 FUSE 时使用 `APPIMAGE_EXTRACT_AND_RUN=1`。

### IDE 扩展

官方为 **VS Code、Cursor、Windsurf、Trae** 提供扩展。VS Code 系可在 Marketplace 搜索 "OpenChamber"；其余宿主按同一扩展机制安装（以后续官方说明为准）。

## 首次运行检查清单

| 步骤 | 预期结果 |
|------|---------|
| 1. 启动 | CLI 打印 URL，或桌面应用打开 |
| 2. 打开 URL | 看到会话列表（session list） |
| 3. 设置 UI 密码 | `--ui-password` 或 `OPENCHAMBER_UI_PASSWORD` |
| 4. 验证 OpenCode | 能选择 provider / 模型并发起一次对话 |
| 5. 可选：配对手机 | Settings → Remote Instances → Add a device → 扫码 |

> 只要实例可能被他人访问——尤其是经隧道或公网——**必须先设密码**。

## 该用哪个端

官方 Quickstart 的建议：

| 场景 | 推荐端 |
|------|--------|
| macOS 上日常工作 | Desktop |
| 远程访问、手机上审阅 | Web / PWA |
| 会话紧贴代码 | VS Code 扩展 |

## 常见启动参数

| 参数 | 作用 |
|------|------|
| `--ui-password <pwd>` | 设置浏览器 UI 密码 |
| `--lan` | 允许局域网访问（默认仅 localhost，慎用） |
| `--port <n>` | 指定端口（默认 3000） |

常用运维命令：

```bash
openchamber status
openchamber logs
openchamber stop
openchamber update
openchamber startup enable
```

## 排障入口

- 页面打不开 → 检查端口占用、Node 版本、OpenCode 是否可用；
- 无法连接远程设备 → 检查 `--lan`、防火墙、配对方式（局域网 vs Relay）；
- 官方 Troubleshooting：https://docs.openchamber.dev/troubleshooting/
