## 核实方法

| 事项 | 建议核实途径 |
|------|-------------|
| 1、2 | 在 Windows 安装包中检查是否自带 `opencode`；查看 Releases 资产清单 |
| 3、4 | 安装后实际打开 Multi-run / Fusion 界面，记录上限与合并行为 |
| 5、6 | 官方 Roadmap / GitHub releases / changelog |
| 7 | GitHub Releases 页与 `package.json` 版本 |
| 8 | 在企业环境中以最小权限部署，验证策略文件权限与密钥处理 |
