# 004.8 Claude Code

> Claude Code 是 **Anthropic** 出品的**智能编码 Agent**：能读取代码库、编辑文件、运行命令并集成开发工具，运行于终端、IDE、桌面应用与浏览器。它以「推理模型 + 内置工具 + 分层扩展系统」为核心，通过 CLAUDE.md 记忆、Skills 技能、子代理、Hooks 钩子、MCP 与插件实现深度定制。数据更新至 2026-09。
