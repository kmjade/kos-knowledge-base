# 03 核心架构

## Agentic 循环

Claude Code 的核心是 **agentic loop（代理循环）**：模型对代码库进行推理，调用内置工具执行操作，观察结果，再决定下一步，循环直到完成任务。

```
用户请求 → 读取代码库 → 推理 → 调用工具（读/搜/改/执行）→ 观察结果 → 继续/完成
```

## 内置工具

| 工具类别 | 能力 |
|----------|------|
| 文件操作 | 读文件、编辑文件（Edit）、写文件（Write）、批量改（MultiEdit） |
| 搜索 | Grep（正则搜索）、Glob（文件匹配） |
| 执行 | Bash（终端命令）、后台进程 |
| 网络 | WebSearch、WebFetch |
| 扩展 | MCP 工具、Skills 技能、子代理委派 |

> 大多数编码任务由内置工具覆盖；扩展层（CLAUDE.md / Skills / Hooks / MCP）负责定制「它知道什么、连什么、自动化什么」。

## 上下文窗口

Claude Code 的上下文窗口在会话中逐渐填满：

| 内容 | 加载时机 |
|------|----------|
| 系统提示 + 工具定义 | 会话开始（可缓存） |
| CLAUDE.md / 记忆 | 自动加载 |
| 文件读取、搜索结果、命令输出 | 按需加载，占用 token |
| 会话历史 | 持续累积，超阈值需 `/compact` 压缩 |

上下文压力可通过 `/context` 查看，`/compact` 手动压缩。

## 提示缓存

Claude Code 自动管理 prompt caching（前缀缓存）。注意：
- 切换模型会触发一次慢的未缓存回合
- `/compact` 有额外成本
- CLAUDE.md 编辑不会在会话中途生效（缓存前缀不变）
- 可用 `/cost` 查看缓存命中率

## 目录结构（`.claude/`）

| 路径 | 用途 |
|------|------|
| `.claude/settings.json` | 项目级配置 |
| `.claude/settings.local.json` | 个人本地配置（gitignore） |
| `.claude/CLAUDE.md`（或根 CLAUDE.md） | 项目记忆 |
| `.claude/skills/` | 技能 |
| `.claude/agents/` | 子代理定义 |
| `.claude/commands/` | 旧式斜杠命令 |
| `.claude/hooks/` | 钩子 |
| `~/.claude/` | 全局配置与个人记忆 |
