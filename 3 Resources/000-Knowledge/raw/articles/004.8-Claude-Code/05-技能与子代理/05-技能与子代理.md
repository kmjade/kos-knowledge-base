# 05 技能与子代理

## 技能（Skills）

技能是包含 `SKILL.md` 的文件夹，提供**可复用的知识、指令与多步工作流**。既可作为斜杠命令手动调用，也可在任务匹配技能描述时由 Claude 自动加载。

### 存放位置

| 路径 | 作用域 |
|------|--------|
| `.claude/skills/<name>/SKILL.md` | 项目级 |
| `~/.claude/skills/<name>/SKILL.md` | 个人级 |

### SKILL.md 格式

```markdown
---
name: my-skill
description: 何时使用此技能的说明
---
技能正文：指令、知识、工作流步骤
```

### 斜杠命令

自定义斜杠命令（如 `/deploy`）触发预设行为，属于技能系统的一部分。新格式推荐 `.claude/skills/<name>/SKILL.md`，兼容旧式 `.claude/commands/`。

## 子代理（Subagents）

子代理是**隔离上下文**中运行的专用 AI 助手，在 `.claude/agents/` 下以 Markdown + YAML frontmatter 定义，运行自己的循环并只回传摘要。

### Frontmatter 字段

| 字段 | 说明 |
|------|------|
| `name` / `description` | 标识与触发说明 |
| `tools` / `disallowedTools` | 可用/禁用工具 |
| `model` | sonnet / opus / haiku / inherit |
| `permissionMode` | 权限模式 |
| `maxTurns` | 最大轮数 |
| `skills` / `mcpServers` / `hooks` | 附加能力 |
| `memory` | 持久记忆作用域（user/project/local） |

### 内置子代理

Explore（只读代码库搜索）、Plan（架构规划）、general-purpose（通用）、Bash、Claude Code Guide。

## 技能 vs 子代理

| 维度 | 技能 | 子代理 |
|------|------|--------|
| 定义 | 如何执行任务（知识+步骤） | 谁来做（角色+权限+边界） |
| 上下文 | 共享主会话 | 隔离上下文，回传摘要 |
| 适用 | 可复用工作流、领域知识 | 上下文隔离、并行任务 |
