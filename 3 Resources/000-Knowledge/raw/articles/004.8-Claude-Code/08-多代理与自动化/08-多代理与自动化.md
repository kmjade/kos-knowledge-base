# 08 多代理与自动化

## 并行与多代理

| 能力 | 说明 |
|------|------|
| 子代理 | 隔离上下文并行处理子任务 |
| Agent View | 一屏管理多个会话，查看各自进度 |
| Agent Teams | 编排多个 Claude Code 实例协同工作 |
| 动态工作流 | 由脚本驱动多个子代理，返回单一结果 |
| 跨会话消息 | 让 Claude 给其他会话发消息 |
| Worktrees | `--worktree` 在独立 git worktree 隔离并行会话 |

## 无头模式与 Agent SDK

### CLI 无头模式

```bash
claude -p "修复这个 bug"                 # print 模式，一次性
cat task.md | claude -p                   # 管道输入
```

### Claude Agent SDK

把 Claude Code 作为库程序化调用（Python / TypeScript）：

```python
from claude_agent_sdk import query
result = await query(prompt="...", options={...})
```

| 语言 | 包名 |
|------|------|
| Python | `claude-agent-sdk` |
| TypeScript | `@anthropic-ai/claude-agent-sdk` |

提供内置工具、完整 agent 循环、上下文管理、hooks、子代理、权限与会话。

## 定时与目标

| 命令 | 功能 |
|------|------|
| `/loop` | 按间隔重复运行提示 |
| `/goal` | 设置完成条件，持续工作直到满足 |
| 定时任务 | 桌面端支持 recurring 定时任务 |

## CI/CD 与代码审查

| 集成 | 说明 |
|------|------|
| GitHub Actions | `@claude` 提及、issue→PR、自动评审 |
