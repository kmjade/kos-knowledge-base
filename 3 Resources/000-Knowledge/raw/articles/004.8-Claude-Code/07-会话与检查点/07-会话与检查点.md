# 07 会话与检查点

## 会话管理

| 操作 | 命令 |
|------|------|
| 继续最近会话 | `claude --continue`（`-c`） |
| 恢复指定会话 | `claude --resume` / `/resume` 选择器 |
| 从 PR 开始 | `claude --from-pr <n>` |
| 会话命名 | `/title` |
| 导出记录 | 导出 transcript |

会话记录默认存于本地（`~/.claude/projects/`）。

## 检查点（Checkpoints）

Claude Code 在修改文件前自动快照，可安全回滚：

| 命令 | 功能 |
|------|------|
| `/undo` | 撤销最近改动 |
| `/rewind` | 回退到更早的检查点 |
| `/diff` | 查看未提交改动 |

## Plan Mode（规划模式）

Plan Mode 让 Claude **只读分析、先出计划不执行**：

```bash
claude --plan        # 以规划模式启动
```

- Claude 读取代码库并生成实施计划，不修改文件
- 适合先评审方案再动手
- VS Code 集成支持 plan review

## 上下文管理

| 命令 | 功能 |
|------|------|
| `/context` | 查看上下文占用 |
| `/compact` | 压缩历史（生成摘要释放空间） |
| `/clear` | 清空会话 |
| `/cost` | 查看 token 与成本、缓存命中率 |

> 模型切换会触发一次未缓存慢回合；CLAUDE.md 编辑不会在会话中途生效（前缀缓存）。
