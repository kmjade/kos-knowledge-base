# Claude Code on the Web

Claude Code 的**云端运行方式**：在浏览器/手机上连接 GitHub 仓库，提交任务并审查 PR，无需本地环境。支持 `--cloud` / `--teleport` 在 Web 与终端间迁移会话。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 云端服务 |
| 能力 | 连接 GitHub、云端沙箱、PR 审查 |
| 迁移 | `--cloud` / `--teleport` |
