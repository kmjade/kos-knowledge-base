# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| 终端 CLI | 全功能，本地优先 |
| VS Code | 内联 diff、@-提及、plan review、快捷键 |
| JetBrains | IntelliJ / PyCharm / WebStorm 等 |
| Desktop 桌面 | 并行会话 + Git 隔离、拖拽布局、集成终端/文件编辑器、App 预览 |
| Web（云端） | 浏览器沙箱，连接 GitHub 仓库，`--cloud` / `--teleport` 迁移会话 |
| 移动 | iOS/Android 启动、监控、steer 任务 |
| Chrome | 连接浏览器测试 Web 应用、自动化填表 |
| Slack / Claude Tag | 团队协作编码 |
| Computer use | CLI 操控桌面 GUI（预览） |

## 实战案例

### 探索陌生代码库

```
❯ 这个项目的架构是什么？核心模块怎么组织？
```

Claude 用 Grep/Glob 搜索 + Read 读文件，产出结构化架构说明。

### 修复 Bug

```
❯ 测试失败在 test_foo.py line 42，帮我定位根因并修复
```

Claude 读相关文件 → 定位 → Edit 修改 → 运行测试验证，全程可见。

### 重构

```
❯ 把 src/ 下所有 print() 替换为 logging
```

跨多文件改造，配合检查点 `/undo` 安全回滚。

### PR 审查

```
/review          # 请求审查当前改动
/code-review ultra   # 云端深度多代理评审
```

### 先规划再动手

```bash
claude --plan     # Plan Mode：只读分析，先出计划
```

### CI/CD 自动评审

GitHub Actions 中配置 `@claude` 提及自动评审、issue 转 PR。

### 定时任务（桌面端）

配置 recurring 任务：每日代码审查、依赖审计、晨报。
