# 02 安装与快速入门

## 前提

- 一个终端 + 一个代码项目
- 认证方式：Claude 订阅（Pro/Max/Team/Enterprise）、Claude Console 账户，或受支持的云平台

## 安装

### 原生安装（推荐）

| 平台 | 命令 |
|------|------|
| macOS / Linux / WSL | `curl -fsSL https://claude.ai/install.sh \| bash` |
| Windows PowerShell | `irm https://claude.ai/install.ps1 \| iex` |
| Windows CMD | `curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd` |

### 包管理器

| 方式 | 命令 |
|------|------|
| Homebrew | `brew install --cask claude-code` |
| WinGet | `winget install Anthropic.ClaudeCode` |
| npm | `npm install -g @anthropic-ai/claude-code` |

## 登录认证

```bash
claude          # 首次运行会引导登录
claude /login   # 切换账号/登录
```

认证来源（优先级从高到低）：Claude 订阅 → API Key（Console）→ 云平台凭证。企业环境可用 `ANT`/SSO/托管设置统一管理。

## 首次对话

```bash
cd your-project
claude
```

输入需求即可。Claude Code 会自动读取项目上下文（CLAUDE.md 等）、搜索代码、编辑文件、运行命令。

### 常用斜杠命令（入门）

| 命令 | 功能 |
|------|------|
| `/help` | 显示帮助 |
| `/model` | 切换模型 |
| `/clear` | 清空会话 |
| `/compact` | 压缩上下文 |
| `/init` | 初始化 CLAUDE.md |
| `/review` | 请求代码审查 |
| `/diff` | 查看未提交改动 |
| `/undo` | 撤销最近改动 |

## 无头模式（Headless）

```bash
claude -p "修复这个 bug"          # 一次性 print 模式
cat prompt.txt | claude -p        # 管道输入
claude --continue / --resume      # 继续/恢复会话
```
