# 01 IoT 导论

## 什么是物联网

物联网（Internet of Things, IoT）是将物理设备通过网络互联、实现数据采集、远程控制与智能协同的系统工程。2026 年的共识是：IoT 已从「连接设备」的工程命题，演进为「连接智能」的系统工程。

## 核心理念

| 特性 | 说明 |
|------|------|
| 协议栈收敛 | MQTT / CoAP / LwM2M 为主，DDS / OPC UA 补关键任务 |
| 架构混合 | 边缘处理时延敏感、云处理分析与 AI |
| 终端 Agent 化 | 从「协议解析」走向「意图解析」 |
| 权衡本质 | 延迟 / 能耗 / 可靠性 / 安全四维权衡，无单一方案全面胜出 |

## 历史脉络

| 时期 | 里程碑 |
|------|--------|
| 1999 | Kevin Ashton 提出「Internet of Things」 |
| 2000s | RFID / WSN 传感网萌芽 |
| 2010s | MQTT 兴起、LPWAN（LoRa/NB-IoT）落地 |
| 2020s | 边缘计算、5G、数字孪生、终端 Agent 化 |

## 分层模型

| 层 | 内容 |
|----|------|
| 感知层 | 传感器、执行器、MCU |
| 网络层 | 无线组网、网关 |
| 平台层 | Broker、设备管理、数据平台 |
| 应用层 | 分析与智能 |

## 2026 趋势

从「动作演示」转向「连接智能」工程化：协议收敛、混合边缘-云、终端 Agent 化、6G 演进、国产平台国标适配。
