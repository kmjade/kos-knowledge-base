# 08 安全与互操作

## 安全基线（2026）

| 层 | 措施 |
|----|------|
| 传输 | TLS/DTLS 加密 |
| 认证 | OAuth 2.0 / JWT 动态认证 |
| 回传 | IPSec VPN |
| 隐私 | 联邦学习 + 差分隐私 |
| 设备 | 零信任持续验证 |

## 国标协议矩阵（选型硬约束）

| 行业 | 协议 |
|------|------|
| 环保 | HJ212 |
| 水利 | SL651 |
| 电力 | DL/T645 + IEC104 |
| 车载 | JT808 + GB32960 |
| 视频 | GB28181 |

## 互操作权衡

标准化（LwM2M 400+ OMA 对象）vs 灵活性（MQTT 私有主题）——本质是「约束 vs 灵活」权衡。
