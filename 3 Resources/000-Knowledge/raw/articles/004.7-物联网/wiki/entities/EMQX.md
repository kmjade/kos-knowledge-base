# EMQX

开源 MQTT broker，6.2 版本引入 A2A 智能体注册中心 + MCP over MQTT 支持，是终端 Agent 化的代表产品。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 开源 MQTT broker |
| 协议 | MQTT / CoAP / LwM2M 等 |
| 关键特性 | A2A 注册中心 + MCP over MQTT |
| 定位 | 云边一体的消息基础设施 |
