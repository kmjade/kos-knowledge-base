# MCP over MQTT

## 定义

MCP over MQTT 是在消息管道上承载 Model Context Protocol，连接智能体与工具/数据，是终端 Agent 化的关键技术之一。

## 关键特性

- MQTT 做数据管道，MCP 做垂直连接工具/数据
- 技术三角：MQTT + MCP + A2A
- 从「协议解析」走向「意图解析」
