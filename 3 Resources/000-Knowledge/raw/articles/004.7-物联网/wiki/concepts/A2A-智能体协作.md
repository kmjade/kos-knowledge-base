# A2A 智能体协作

## 定义

A2A（Agent-to-Agent）是智能体间水平协作的注册/发现机制，EMQX 6.2 在消息管道内置 A2A 注册中心，使终端从「协议解析」走向「意图解析」。

## 关键特性

- 智能体注册中心 + 水平协作
- 与 MCP over MQTT 配合（垂直 + 水平）
- 百亿终端 Agent 化的关键技术
