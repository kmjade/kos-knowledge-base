# 05 架构与计算连续体

## 三种部署模型

| 模型 | 说明 |
|------|------|
| Edge-first | 边缘处理时延/带宽敏感 |
| Cloud-first | 云处理分析与 AI |
| Hybrid（主导） | 边缘+云组合，成熟主流 |

## 计算连续体

IoT – Fog – Cloud 构成「计算连续体」：数据在端、边、云间按需流动处理。

## UNS + EDA（工业数据架构标配）

| 概念 | 说明 |
|------|------|
| 统一命名空间 UNS | 以 ISA-95 层级组织 topic，hub-and-spoke 替代点对点 |
| 事件驱动 EDA | 事件流替代轮询，支撑亚秒级异常检测 |

## OT/IT 融合

Broker 隔离 + 边缘协议归一化（Modbus / PROFINET / OPC-UA → MQTT）。
