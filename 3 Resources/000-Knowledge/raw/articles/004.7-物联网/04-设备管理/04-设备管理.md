# 04 设备管理

## LwM2M v2.0（2026 最大演进）

| 特性 | 说明 |
|------|------|
| 分层架构 | edge → regional → central |
| 边缘代理 | 缓存状态异步上报，本地执行管理逻辑 |
| 响应 | 配合 5G MEC 达亚 5ms |
| 安全 | 强制 DTLS 1.3 + OSCORE |
| 标准化 | 400+ OMA 对象（对比 MQTT broker 私有主题） |
