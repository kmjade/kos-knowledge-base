# 03 网络与无线组网

## 底层无线并存

| 技术 | 特点 | 典型场景 |
|------|------|---------|
| LoRaWAN | 15km 低功耗 | 农业/表计远程 |
| NB-IoT / LTE-M | 蜂窝 LPWAN | 广域低速 |
| BLE 5.4–6.0 | 短距低功耗 | 可穿戴/室内 |
| ZigBee | 网状短距 | 智能家居 |
| UWB | 10cm 测距 | 室内定位 |
| Wi-Fi HaLow | sub-GHz IP 组网 | LoRa 级 IP |
| 5G RedCap | 中档连接 | 工业中速 |
| Thread / Matter | 家居应用层 | 智能家居 |

## 选型维度

| 维度 | 权衡 |
|------|------|
| 距离 | 短距(BLE/ZigBee) vs 长距(LoRa/NB-IoT) |
| 功耗 | 电池供电选 LPWAN |
| 带宽 | 视频/大数据需 5G/Wi-Fi |
| 成本 | 模组与运营成本 |
