# 09 实战案例

## 每日简报机器人

用自然语言创建一个定时任务，每天早上聚合 AI 新闻推送：

```text
Every morning at 9am, check Hacker News for AI news and send me a summary on Telegram.
```

Hermes 自动调用 `cronjob` 工具，通过网关每 60 秒调度器触发。配合 `--skill blogwatcher` 附加技能，可复用可维护的监控工作流。

## GitHub PR 审查代理

配置 Webhook 让 Hermes 自动评论 PR，或直接委派审查任务：

```python
delegate_task(
    goal="Review the authentication module for security issues and fix any found",
    context="Project at /home/user/webapp. Auth files: src/auth/*.py...",
    toolsets=["terminal", "file"]
)
```

参考 `webhook-github-pr-review`、`github-pr-review-agent` 指南搭建端到端流程。

## 团队 Telegram 助手

1. `hermes gateway setup` 选择 Telegram，配置 bot token
2. 设置 `TELEGRAM_ALLOWED_USERS` 白名单或使用私信配对
3. 可选 `/background` 跑长任务、`/voice tts` 语音回复

参考 `team-telegram-assistant` 教程。

## 并行研究

最多 3 个子代理并行调研不同主题，仅回传摘要：

```python
delegate_task(tasks=[
    {"goal": "Research WebAssembly in 2025", "context": "browser support, runtimes", "toolsets": ["web"]},
    {"goal": "Research RISC-V adoption in 2025", "context": "server chips, embedded", "toolsets": ["web"]},
    {"goal": "Research quantum computing progress in 2025", "context": "error correction", "toolsets": ["web"]}
])
```

## 多文件重构

把大重构任务委派给子代理，避免父 Agent 上下文被淹没：

```python
delegate_task(
    goal="Refactor all Python files in src/ to replace print() with logging",
    context="Use logging module with logger = logging.getLogger(__name__)...",
    toolsets=["terminal", "file"]
)
```

## 本地 LLM（零 API 成本）

在 Mac/本地用 Ollama 跑 Hermes，`hermes model` 选择自定义端点（base URL + 本地 key）。适合隐私敏感或离线场景。参考 `local-ollama-setup`、`local-llm-on-mac`。

## 中文社区场景

- **桌面版开箱即用**：下载 Hermes-CN-Desktop，填 API Key 即开始
- **国内模型直连**：配 Kimi / 智谱 / 通义 / MiniMax，无需特殊网络
- **中文文档 MCP**：把 `https://mcp.hermesagent.org.cn/v1` 加进其他 Agent 配置，检索中文文档
- **社区求助**：微信群/飞书/QQ 群 + 社区日报（55+ 期）沉淀实践
