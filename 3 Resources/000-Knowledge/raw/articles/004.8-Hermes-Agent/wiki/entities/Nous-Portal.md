# Nous Portal

Nous Research 的**订阅制模型服务**，在 Hermes Agent 中通过 OAuth 零配置接入，并直连网页搜索、图像生成、TTS 与浏览器自动化等工具网关（v0.10.0 起）。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 订阅制服务 |
| 接入 | `hermes model` OAuth 登录 |
| 工具网关 | 搜索 / 图像 / TTS / 浏览器，免额外 API Key |
| 定位 | 零配置、开箱即用 |
