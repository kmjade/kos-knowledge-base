# 02 安装与快速入门

## 三种上手方式

| 方式 | 适合人群 | 说明 |
|------|----------|------|
| 中文社区桌面版 | 新手/不熟命令行 | 原生客户端，内置中文内核，开箱即用 |
| 一键安装脚本（镜像） | 大陆 CLI 用户 | `install.sh` / `install.ps1`，走国内直连链路 |
| 官方上游 | 高级用户 | `NousResearch/hermes-agent` 源码 / 官方桌面版 |

## 一键安装

### Linux / macOS / WSL2

```bash
curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash
```

### Windows 原生 PowerShell

```powershell
irm https://res1.hermesagent.org.cn/install.ps1 | iex
```

> 中文社区镜像安装器默认精简了浏览器自动化、Chromium、WhatsApp 桥接等体积大且易受外网影响的可选组件，先保证核心可用，之后可让 Agent 自行补全。

### Android / Termux

```bash
curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash
```

安装器自动检测 Termux 并切换 Android 流程（复用系统 Python、补齐 clang/rust/make 等工具链、`.[termux]` 依赖）。

## 安装后

| 平台 | 操作 |
|------|------|
| 类 Unix / WSL2 | `source ~/.bashrc`（或 `~/.zshrc`）后运行 `hermes` |
| Windows PowerShell | 关闭并重新打开 PowerShell，再运行 `hermes` |

后续重配置命令：

```bash
hermes model       # 选择模型提供商和模型
hermes tools       # 配置启用哪些工具
hermes gateway setup  # 设置消息平台
hermes config set  # 单独设置某个配置项
hermes setup       # 或再次运行完整设置向导
```

## 配置大模型提供商

`hermes model` 引导选择推理提供者：

| 提供者 | 说明 | 配置方式 |
|--------|------|----------|
| Nous Portal | 订阅制、零配置 | OAuth 登录 |
| OpenAI Codex | ChatGPT OAuth + Codex 模型 | 设备码认证 |
| Anthropic | Claude 模型（Pro/Max 或 API Key） | Claude Code 认证或 API Key |
| OpenRouter | 跨模型多提供者路由 | API Key |
| DeepSeek | DeepSeek API | `DEEPSEEK_API_KEY` |
| Kimi / Moonshot | Moonshot 模型 | `KIMI_API_KEY` |
| 智谱 Z.AI | GLM 系列 | `GLM_API_KEY` / `ZAI_API_KEY` |
| MiniMax / 国内区 | MiniMax 接口 | `MINIMAX_API_KEY` / `MINIMAX_CN_API_KEY` |
| 阿里云 | DashScope（Qwen） | `DASHSCOPE_API_KEY` |
| Hugging Face | 20+ 开源模型统一路由 | `HF_TOKEN` |
| 自定义端点 | vLLM / SGLang / Ollama 等 | base URL + API Key |

> 随时可用 `hermes model` 切换提供者，无锁定。国内教程常推荐 Kimi、智谱、通义等，无需特殊网络。

## 首次对话

```bash
hermes
```

输入消息即可。开箱即用网络搜索、文件操作、终端命令等工具。

### 常用斜杠命令

| 命令 | 功能 |
|------|------|
| `/help` | 显示所有命令 |
| `/tools` | 列出可用工具 |
| `/model` | 交互式切换模型 |
| `/personality pirate` | 切换个性模式 |
| `/save` | 保存对话 |
| `/voice on` | 开启语音模式 |

### 多行输入与中断

- 多行：`Alt+Enter` 或 `Ctrl+J`
- 中断：直接输入新消息或 `Ctrl+C`
- 恢复会话：`hermes --continue`（简写 `hermes -c`）

## 进阶配置

```bash
hermes config set terminal.backend docker   # Docker 隔离终端
hermes config set terminal.backend ssh      # 远程服务器终端
hermes gateway setup                        # 接入消息平台
pip install "hermes-agent[voice]"           # 语音模式
hermes skills search kubernetes             # 搜索/安装技能
hermes acp                                  # 作为 ACP 服务器供编辑器调用
```
