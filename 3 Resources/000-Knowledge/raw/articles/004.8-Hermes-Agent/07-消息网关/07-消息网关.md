# 07 消息网关

## 概述

消息网关是 Hermes 的**长驻后台进程**，统一连接多个消息平台、管理会话、运行定时任务、发送语音消息。通过 Telegram、Discord、Slack、WhatsApp、Signal、短信、邮件、Home Assistant、Mattermost、Matrix、钉钉、飞书、企业微信、微信、BlueBubbles（iMessage）等 30+ 平台对话。

## 架构

每个平台适配器接收消息 → 按聊天划分的 Session 存储路由 → 分发给 `AIAgent` 处理 → 回传。网关还运行**每 60 秒触发一次**的定时调度器。

## 快速设置与命令

```bash
hermes gateway setup       # 交互式配置（所有平台）
hermes gateway             # 前台运行
hermes gateway install     # 安装为用户服务（Linux/macOS）
sudo hermes gateway install --system  # Linux 系统服务
hermes gateway start / stop / status
```

## 聊天命令（消息中使用）

| 命令 | 功能 |
|------|------|
| `/new` `/reset` `/retry` `/undo` | 会话管理 |
| `/model` `/provider` `/personality` | 模型与个性 |
| `/approve` `/deny` | 审批待处理危险命令 |
| `/background <prompt>` | 后台会话独立运行 |
| `/rollback [n]` | 回滚文件系统检查点 |
| `/voice [on\|off\|tts]` | 语音控制 |
| `/<skill-name>` | 调用任意技能 |

## 安全模型

**默认拒绝所有未授权用户**（有终端访问权限的机器人最安全默认）。

| 机制 | 说明 |
|------|------|
| 白名单 | `TELEGRAM_ALLOWED_USERS=123,...` 或 `GATEWAY_ALLOWED_USERS` |
| 私信配对 | 未知用户收到一次性配对码，`hermes pairing approve telegram XKGH5N7P` 批准 |
| 群聊隔离 | `group_sessions_per_user` 默认按用户隔离会话 |
| 危险命令审批 | 消息中 `/approve` / `/deny` 处理待审批队列 |

## 后台会话

`/background <prompt>` 启动**独立 Agent 实例**异步运行：隔离会话、继承配置、非阻塞，完成后结果回传同一聊天。适合服务器监控、长构建、研究任务、文件整理。
