# 05 技能系统

## 技能是什么

技能（Skills）是**按需加载的知识文档**，Agent 在需要时载入。它们遵循**渐进式披露**模式以最小化 token 使用，并兼容 [agentskills.io](https://agentskills.io/specification) 开放标准。所有技能位于 `~/.hermes/skills/`，Agent 可自行创建、修改或删除。

## 渐进式披露

```
Level 0: skills_list()          → [{name, description, category}]  (~3k tokens)
Level 1: skill_view(name)       → 完整内容 + 元数据
Level 2: skill_view(name, path) → 特定参考文件
```

Agent 仅在真正需要时才加载完整技能内容。

## 使用技能

每个已安装技能自动成为斜杠命令：

```bash
/plan design a rollout for migrating our auth provider
/github-pr-workflow create a PR for the auth refactor
/excalidraw
```

也可自然语言交互：

```bash
hermes chat --toolsets skills -q "What skills do you have?"
```

## SKILL.md 格式

技能由 `SKILL.md` 定义，含 YAML 前置元数据（名称、描述、可选依赖、危险标记、配置设置声明等）与正文指令。技能可按平台启用/禁用，支持条件激活。

## 技能目录与技能中心

```bash
hermes skills search kubernetes
hermes skills search react --source skills-sh
hermes skills search https://mintlify.com/docs --source well-known
hermes skills install openai/skills/k8s
hermes skills install official/security/1password
```

| 来源 | 说明 |
|------|------|
| 捆绑技能（bundled） | 随安装复制，始终可用（如 `plan`） |
| 官方可选技能（optional） | 显式安装 |
| skills.sh | 公开技能目录（约 19,932 条） |
| well-known | 从网站 `/.well-known/skills/index.json` 发现 |
| Skills Hub | 内置技能中心，含预览与安全扫描 |

> 安装第三方技能用 `--force` 前先审查；`--force` 可覆盖非危险策略块，但无法覆盖 `dangerous` 扫描结论。

## 技能 vs 工具

| 维度 | 技能 | 工具 |
|------|------|------|
| 本质 | 知识文档（指令 + 上下文） | 可执行函数 |
| 加载 | 按需渐进披露 | 随工具集启用 |
| 适用 | 工作流、方法论、领域知识 | 单一能力动作 |
