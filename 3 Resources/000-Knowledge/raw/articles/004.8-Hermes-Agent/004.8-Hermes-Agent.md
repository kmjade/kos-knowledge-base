# 004.8 Hermes Agent

> Hermes Agent 是 **Nous Research** 出品的开源**个人 AI Agent 框架**。它以 `AIAgent` 核心编排引擎驱动，通过 CLI / TUI / 桌面版 / Web Dashboard / 消息网关 / ACP 多入口运行，内置技能系统、持久记忆、MCP 工具、定时任务与子代理委派，把通用大模型变成可长期自主工作的个人助手。数据更新至 2026-09（v0.20.0）。
