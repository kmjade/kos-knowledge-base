# 08 自动化与委派

## 定时任务（Cron）

用自然语言或 Cron 表达式自动调度任务，通过单一 `cronjob` 工具管理。

```bash
/cron add 30m "Remind me to check the build"
/cron add "every 2h" "Check server status"
/cron add "every 1h" "Summarize new feed items" --skill blogwatcher
```

也可自然对话：

```text
Every morning at 9am, check Hacker News for AI news and send me a summary on Telegram.
```

### 调度格式

| 格式 | 示例 | 含义 |
|------|------|------|
| 相对延迟 | `30m` / `2h` / `1d` | 一次性，N 时间后运行 |
| 间隔 | `every 2h` / `every 1d` | 重复执行 |
| Cron 表达式 | `0 9 * * *` | 每天 9 点 |
| ISO 时间戳 | `2026-03-15T09:00:00` | 一次性指定时刻 |

### 生命周期

`/cron list / pause / resume / run / remove`（或 `hermes cron ...` 独立 CLI）。任务存于 `~/.hermes/cron/jobs.json`，输出到 `~/.hermes/cron/output/`。

### 执行机制

- 由**网关守护进程**每 60 秒触发，到期任务在全新 `AIAgent` 会话运行
- 可附加零/一/多个技能，可指定投递目标（origin / local / telegram / feishu 等）
- 响应以 `[SILENT]` 开头则成功时静默；失败始终投递
- 文件锁 `~/.hermes/cron/.tick.lock` 防重叠；Cron 会话内禁用递归创建任务

## 子代理委派

`delegate_task` 工具启动**隔离上下文、受限工具集、独立终端**的子 AIAgent 实例，仅最终摘要回传父 Agent。

```python
delegate_task(tasks=[
    {"goal": "Research topic A", "toolsets": ["web"]},
    {"goal": "Research topic B", "toolsets": ["web"]},
    {"goal": "Fix the build", "toolsets": ["terminal", "file"]}
])
```

关键约束：

| 属性 | 值 |
|------|-----|
| 最大并发 | 3 个子代理 |
| 深度限制 | 2（子代理不能再委派） |
| 默认迭代 | 50 轮（可配） |
| 禁止工具 | delegate_task / clarify / memory / send_message / execute_code |
| 模型覆盖 | 可配 `delegation.model` 用更便宜模型 |

**委派 vs execute_code**：需要推理判断用 `delegate_task`；机械式数据处理用 `execute_code`（沙箱 RPC，仅返回 stdout，成本更低）。

## 其他自动化能力

- **代码执行** `execute_code`：沙箱化 Python，把多步工作流压成单次 LLM 调用
- **事件钩子（hooks）**：在生命周期节点运行自定义代码（日志、告警、Webhook、指标、安全）
- **批量处理（batch）**：数百/数千提示并行运行，生成 ShareGPT 轨迹（训练/评估）
- **Git Worktrees**：`worktree: true` 为每个会话建隔离工作树，多 Agent 并行同仓库互不干扰
