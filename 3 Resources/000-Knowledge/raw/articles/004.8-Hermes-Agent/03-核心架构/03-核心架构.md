# 03 核心架构

## 系统概览

Hermes Agent 采用**单一核心 + 多入口**架构：同一个 `AIAgent` 编排引擎同时服务 CLI、网关、ACP、批处理、API Server 与 Python 库。平台差异只存在于入口点，不在 Agent 本体。

```
        Entry Points（入口）
 CLI · Gateway · ACP · Batch · API Server · Python Library
                 │
                 ▼
   AIAgent (run_agent.py，约 9,200 行)  ← 核心编排引擎
   ├─ Prompt Builder（提示词组装）
   ├─ Provider Resolution（提供者解析，3 种 API 模式）
   ├─ Tool Dispatch（工具分发，约 48 工具 / 20 工具集）
   ├─ Context Compression & Caching（压缩与缓存）
   └─ Session Storage（SQLite + FTS5）
```

## 目录结构（关键文件）

| 文件/目录 | 职责 |
|-----------|------|
| `run_agent.py` | `AIAgent` 核心对话循环 |
| `cli.py` | `HermesCLI` 交互式终端 |
| `model_tools.py` | 工具发现、Schema 收集与分发 |
| `toolsets.py` | 工具分组与平台预设 |
| `hermes_state.py` | SQLite 会话/状态库 + FTS5 |
| `hermes_constants.py` | `HERMES_HOME` 与 profile 感知路径 |
| `batch_runner.py` | 批量轨迹生成 |
| `agent/` | prompt_builder、context_engine、memory_manager、prompt_caching 等 |
| `hermes_cli/` | CLI 子命令、配置、认证、模型切换、设置向导、插件管理 |
| `tools/` | 每个工具一个文件 + 中央 registry + 6 终端后端 + MCP 客户端 |
| `gateway/` | 消息平台网关（15 个平台适配器 + session + delivery + hooks） |
| `acp_adapter/` | ACP 服务器（VS Code / Zed / JetBrains） |
| `cron/` | 调度程序 |
| `plugins/` | memory / context_engine 插件 |
| `skills/` + `optional-skills/` | 捆绑技能 + 官方可选技能 |

## 数据流

### CLI 会话

```text
User input → HermesCLI.process_input()
  → AIAgent.run_conversation()
    → prompt_builder.build_system_prompt()
    → runtime_provider.resolve_runtime_provider()
    → API call (chat_completions / codex_responses / anthropic_messages)
    → tool_calls? → handle_function_call() → loop
    → final response → display → save to SessionDB
```

### 网关消息

```text
Platform event → Adapter.on_message() → MessageEvent
  → GatewayRunner._handle_message()
    → 授权用户 → 解析 session key
    → 创建带历史会话的 AIAgent → run_conversation()
    → 通过适配器回传响应
```

### 定时任务

```text
Scheduler tick（每 60s）→ 从 jobs.json 加载到期任务
  → 新建无历史 AIAgent → 注入附加技能
  → 运行任务提示 → 投递结果 → 更新 next_run
```

## 主要子系统

| 子系统 | 说明 |
|--------|------|
| **Agent 循环** | 同步编排引擎，负责提供者选择、提示构建、工具执行、重试、降级、回调、压缩与持久化 |
| **提示词系统** | 组装 SOUL.md、记忆、技能、上下文文件（AGENTS.md/.hermes.md）、工具使用指导 |
| **提供者解析** | 把 `(provider, model)` 映射为 `(api_mode, api_key, base_url)`，支持 18+ 提供者 |
| **工具系统** | 中央注册表 + 导入时自动注册；终端支持 6 后端、浏览器 5 后端、Web 4 后端 |
| **会话持久化** | SQLite + FTS5 全文搜索，压缩过程记录父子传承关系 |
| **消息网关** | 长驻进程，统一会话路由、用户授权、斜杠命令、钩子、定时触发 |
| **插件系统** | 用户级/项目级/pip 入口点三种发现来源，注册工具、钩子、CLI 命令 |
| **定时任务** | 原生 Agent 任务（非 shell 任务），JSON 存储，可附加技能 |
| **ACP 集成** | 通过 stdio/JSON-RPC 暴露为编辑器原生 Agent |
| **RL/轨迹** | 环境框架 + Atropos 集成，生成 ShareGPT 格式轨迹 |

## 设计原则

| 原则 | 实际含义 |
|------|----------|
| **提示稳定性** | 系统提示在对话中不变，保护前缀缓存 |
| **可观察执行** | 每个工具调用通过回调对用户可见 |
| **可中断性** | 任何输入/信号可随时取消进行中的调用 |
| **平台无关核心** | 一个 AIAgent 类服务所有入口 |
| **松耦合** | MCP/插件/记忆等可选子系统用注册表 + check_fn 门控 |
| **配置文件隔离** | 每个 profile 有独立 HERMES_HOME、配置、记忆、会话、网关 PID |
