# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| 终端 CLI | 全功能，内核级沙箱，本地优先 |
| IDE 扩展 | 在 VS Code 等编辑器内使用 |
| ChatGPT 云端 | Codex 集成于 ChatGPT，浏览器运行 |
| CI/CD | `codex exec` 脚本化、GitHub Actions 等 |
| SDK | 程序化嵌入 |

## 实战案例

### 探索陌生代码库

```
❯ 这个项目的架构是什么？核心模块怎么组织？
```

Codex 搜索 + 读文件，产出结构化架构说明。

### 修复 Bug（安全审批下）

```
❯ 测试失败在 test_foo.py line 42，帮我定位根因并修复
```

Codex 读文件 → 定位 → 编辑 → 运行测试，写入工作目录需在 `workspace-write` 沙箱下。

### 只读代码审查

```bash
codex --sandbox read-only "审查这个 PR 的安全问题"
```

只读沙箱下最安全，无写入。

### 先规划再动手

```
/plan      # 先出计划
```

### CI 自动修复

```bash
codex exec --ask-for-approval never "修复失败的测试" --profile ci
```

### 团队约定（AGENTS.md）

```bash
/init      # 生成 AGENTS.md 骨架
```

团队在仓库根维护 AGENTS.md（构建命令、代码规范、禁止项），跨工具共享。
