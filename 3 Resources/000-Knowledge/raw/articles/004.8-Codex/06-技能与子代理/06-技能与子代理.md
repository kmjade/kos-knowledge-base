# 06 技能与子代理

## 技能（Skills）

技能是**可复用的知识、指令与工作流**，由 `SKILL.md` 定义（含 name、description 与可选 `agents/openai.yaml` 元数据）。

### 调用方式

| 方式 | 说明 |
|------|------|
| 显式 | `/skills` 命令或 `$skill-name` 提及 |
| 隐式 | Codex 按描述自动匹配（除非 `allow_implicit_invocation: false`） |

### 元数据（agents/openai.yaml）

`display_name` / `short_description` / `icons` / `default_prompt` / `allow_implicit_invocation` / MCP 依赖声明。

### 技能配置

```toml
[[skills.config]]
path = "..."
enabled = false          # 禁用某技能
```

## 子代理（Subagents）

子代理是**隔离上下文**中运行的专用 agent：

| 命令 | 功能 |
|------|------|
| `/agent` | 切换活跃子代理线程 |
| `/multi-agents` | 别名 |
| `multi_agent` | config 中启用多代理特性 |

Hooks 支持 `SubagentStop` 事件，`decision: "block"` 可继续子代理。

## 技能 vs 子代理

| 维度 | 技能 | 子代理 |
|------|------|--------|
| 定义 | 如何执行任务 | 谁来做（角色+边界） |
| 上下文 | 共享主会话 | 隔离上下文 |
| 适用 | 可复用工作流 | 并行任务、上下文隔离 |
