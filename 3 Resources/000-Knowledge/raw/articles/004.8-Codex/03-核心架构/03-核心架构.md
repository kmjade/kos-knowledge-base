# 03 核心架构

## Agentic 循环

Codex 的核心是 **agentic loop（代理循环）**：模型对代码库推理，调用内置工具执行操作，观察结果，再决定下一步，循环直到完成任务。

```
用户请求 → 读取代码库 → 推理 → 调用工具（读/搜/改/执行）→ 观察结果 → 继续/完成
```

## 内置工具

| 工具类别 | 能力 |
|----------|------|
| 文件操作 | 读文件、编辑、写文件 |
| 搜索 | 代码搜索、文件匹配 |
| 执行 | Shell 命令（受沙箱约束） |
| 网络 | 受控网络访问（取决于沙箱/审批） |
| 扩展 | MCP 工具、Skills、子代理 |

## 沙箱与执行边界

Codex 的独特之处在于**内核级沙箱**（详见 [[04-沙箱与审批]]），内置工具的执行边界由沙箱模式决定：

- `read-only`：只读探索
- `workspace-write`（默认）：读全部，写工作目录 + 白名单 + /tmp
- `danger-full-access`：无沙箱，完全访问

## AGENTS.md 与上下文

Codex 每会话读取仓库根的 `AGENTS.md`，作为**持久系统级指令**注入上下文。全局 `~/.codex/AGENTS.md` 提供跨项目规则，项目级覆盖全局。

## 配置目录（`~/.codex/`）

| 路径 | 用途 |
|------|------|
| `config.toml` | 用户配置 |
| `.codex/config.toml`（项目） | 项目配置 |
| `AGENTS.md` | 全局项目记忆 |
| `skills/` | 技能 |
| `agents/` | 子代理 |
| `hooks/` | 钩子 |
