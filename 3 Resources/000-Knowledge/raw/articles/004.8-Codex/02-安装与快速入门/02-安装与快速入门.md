# 02 安装与快速入门

## 前提

- 一个终端 + 一个代码项目
- 认证方式：ChatGPT 订阅（Plus/Pro/Business/Edu/Enterprise），或 API Key

## 安装

| 方式 | 命令 |
|------|------|
| npm（跨平台） | `npm install -g @openai/codex` |
| Homebrew（macOS） | `brew install --cask codex` |
| 安装脚本 | `curl -fsSL https://chatgpt.com/codex/install.sh \| sh` |
| 二进制 | GitHub Releases 下载对应平台压缩包 |

```bash
codex --version    # 验证安装
```

## 登录认证

```bash
codex                    # 首次运行引导登录
codex login              # 登录（ChatGPT OAuth 或 API Key）
codex login --device-auth   # 无头机器设备码登录
```

| 方式 | 说明 |
|------|------|
| ChatGPT OAuth | 个人推荐，无需 API Key |
| API Key | `export OPENAI_API_KEY="sk-..."`，适合 CI/CD |

## 首次对话

```bash
cd your-project
codex
```

输入需求即可。Codex 会自动读取 AGENTS.md、搜索代码、编辑文件、运行命令。

### 常用斜杠命令（入门）

| 命令 | 功能 |
|------|------|
| `/init` | 初始化 AGENTS.md |
| `/model` | 切换模型 |
| `/plan` | 先规划再执行 |
| `/review` | 代码审查 |
| `/compact` | 压缩上下文 |
| `/diff` | 查看改动 |
| `/permissions` | 审批设置 |

## 无头模式（Headless）

```bash
codex exec "修复这个 bug"              # 一次性执行
codex exec --ask-for-approval never ...  # CI 中不交互
```
