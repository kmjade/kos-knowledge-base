# 04 沙箱与审批

## 沙箱模式（Sandbox Modes）

| 模式 | 说明 |
|------|------|
| `read-only` | 只读探索，无写入，最安全 |
| `workspace-write`（默认） | 读所有文件；写 CWD + `writable_roots` + `/tmp`；网络受控 |
| `danger-full-access` | 无沙箱，完全读写/网络访问（仅限加固 VM/容器） |

```bash
codex --sandbox workspace-write
codex --sandbox read-only
codex --sandbox danger-full-access
```

## 平台级沙箱实现

| 平台 | 实现 |
|------|------|
| macOS | Seatbelt（`sandbox-exec`） |
| Linux | Landlock + seccomp（默认），或 bwrap（v0.100+ 内置） |
| WSL | 经 WSL2 的 Linux 沙箱（WSL1 不支持） |
| Windows | 原生实验性沙箱 |

```bash
codex sandbox seatbelt|landlock|windows -- <cmd>   # 测试沙箱
```

## 审批模式（Approval Modes）

| 模式 | 行为 |
|------|------|
| `untrusted` | 仅已知安全读操作自动运行，其余全部询问（最安全/最慢） |
| `on-request`（默认） | 沙箱内自动运行，逃逸沙箱时才询问 |
| `never` | 从不询问，需配合严格沙箱（CI/脚本） |

```bash
codex --ask-for-approval on-request   # 或 -a on-request
codex exec --ask-for-approval never   # CI 标准形态
```

## CI 注意事项

- 默认交互式审批会在 CI 中挂起 → 必须 `codex exec --ask-for-approval never`
- `--yolo` 等价于 `--dangerously-bypass-approvals-and-sandbox`
- `--full-auto` 已弃用/移除
