# 06 模型映射

## 为什么需要模型映射

Claude Code 内部用 `sonnet` / `opus` / `haiku` 三个「能力档位」调用模型。切换供应商后，这些档位需要映射到该供应商实际的模型名。

| 档位 | 官方模型 | 第三方示例 |
|------|---------|-----------|
| Sonnet（默认） | claude-sonnet | deepseek-v3 / glm-4 / kimi-k2 |
| Opus（强推理） | claude-opus | deepseek-reasoner / glm-4-plus |
| Haiku（快/便宜） | claude-haiku | 供应商轻量模型 |

## 映射环境变量

| 环境变量 | 作用 |
|------|------|
| `ANTHROPIC_MODEL` | 通用默认模型 |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | Sonnet 档映射 |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | Opus 档映射 |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | Haiku 档映射 |

## 配置示例（DeepSeek）

```bash
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN=sk-xxxx
ANTHROPIC_MODEL=deepseek-chat
ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-reasoner
ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-chat
ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-chat
```

## 映射建议

- **代码/通用**：Sonnet → 供应商最强通用模型
- **复杂推理**：Opus → 供应商 reasoning 模型
- **快速补全**：Haiku → 供应商轻量/便宜模型
- 部分供应商仅单一模型，三档映射到同一模型即可
