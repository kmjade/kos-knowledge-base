# 02 安装与快速入门

## 安装方式

| 平台 | 方式 | 命令 |
|------|------|------|
| macOS | Homebrew Cask | `brew install --cask cc-switch` |
| Windows | 安装包 | 从 Releases 下载 `.exe` |
| Linux | AppImage / 包 | 从 Releases 下载 |
| Web | 浏览器 | 直接使用 Web 版 |

> 也可从 GitHub Releases（farion1231/cc-switch）下载对应平台安装包。

## 首次切换流程

1. **启动**：打开 CC Switch 桌面应用
2. **添加供应商**：新建 profile，选择供应商模板（如 GLM、DeepSeek、Kimi）
3. **填入密钥**：粘贴对应供应商的 API Key
4. **切换**：点击目标 profile 使其生效
5. **验证**：在终端运行 `claude`，确认走的是新供应商

## 验证切换结果

```bash
# 切换后启动 Claude Code
claude
# 查看当前生效的端点/模型（环境变量）
echo $ANTHROPIC_BASE_URL
echo $ANTHROPIC_MODEL
```
