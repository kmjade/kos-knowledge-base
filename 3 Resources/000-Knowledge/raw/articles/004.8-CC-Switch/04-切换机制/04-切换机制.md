# 04 切换机制

## 切换原理

CC Switch 的核心动作是：**把所选 profile 的环境变量写入 Claude Code 的配置文件** `~/.claude/settings.json`（或等价环境），使 Claude Code 读取后使用新的供应商。

```
[用户选择 profile] → [CC Switch 读取 profile 配置]
        ↓
[写入 ANTHROPIC_BASE_URL / AUTH_TOKEN / MODEL 等]
        ↓
[Claude Code 启动时读取] → 走新供应商
```

## 与 Claude Code 配置的关系

| 层 | 位置 | 说明 |
|------|------|------|
| CC Switch profile | 应用本地存储 | 多套配置模板 |
| Claude Code settings | `~/.claude/settings.json` | 实际生效的配置 |
| 环境变量 | shell / 会话 | 覆盖 settings |

CC Switch 管理「多套 profile」，切换时把目标 profile 同步到 Claude Code 的生效位置。

## 切换流程（底层）

1. 用户选择 profile
2. CC Switch 组装环境变量集合
3. 写入 Claude Code 生效配置
4. 新会话（`claude` 启动）读取新配置

## 注意事项

- 切换通常在**下次启动** Claude Code 时完全生效
- 已运行的会话一般保持原供应商
- CLI 版（如 huangdijia/ccswitch）用 `ccswitch use <profile>` 切换
