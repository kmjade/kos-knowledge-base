# 09 生态与实战

## 与编码 Agent 配合

| Agent | 支持情况 |
|------|---------|
| Claude Code | 核心支持（Anthropic 配置） |
| Codex | 官方版支持 |
| Gemini CLI | 官方版支持 |
| OpenCode / OpenClaw | 通过自定义端点间接支持 |

## 实战场景

| 场景 | 方案 |
|------|------|
| 降低成本 | 切换到 DeepSeek/Kimi 等中转 |
| 国内访问 | 切换到国内可用供应商端点 |
| 多账号 | 工作/个人 profile 分离 |
| 本地私有 | 中转接 Ollama 本地模型 |
| 团队统一 | deep link 分发统一配置 |

## 端到端实战：切换至 DeepSeek

1. **安装**：`brew install --cask cc-switch`
2. **新建 profile**：选 DeepSeek 预设模板
3. **填密钥**：粘贴 DeepSeek API Key
4. **切换**：激活该 profile
5. **验证**：`claude` 启动，确认 `ANTHROPIC_BASE_URL` 指向 DeepSeek

## 成本与质量权衡

| 供应商 | 成本 | 质量/特点 |
|------|:--:|------|
| Anthropic 官方 | 高 | 最强，功能完整 |
| DeepSeek | 低 | 推理强，性价比高 |
| GLM / Kimi | 中低 | 中文友好 |
