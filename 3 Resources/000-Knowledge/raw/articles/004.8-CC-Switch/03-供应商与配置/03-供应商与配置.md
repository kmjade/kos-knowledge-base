# 03 供应商与配置

## 供应商类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 官方 | Anthropic 官方 API | anthropic（默认） |
| 国内大模型 | 国产模型厂商提供 Claude 兼容端点 | GLM（智谱）、Kimi（月之暗面）、DeepSeek、MiniMax |
| 中转聚合 | 第三方聚合/中转服务 | anyrouter、new-api 等 |
| 自定义 | 自建兼容端点 | 任意 OpenAI/Anthropic 兼容 URL |

## 配置结构

一个 profile 本质是 Claude Code 所需的**环境变量集合**：

| 环境变量 | 作用 |
|------|------|
| `ANTHROPIC_BASE_URL` | API 端点地址 |
| `ANTHROPIC_AUTH_TOKEN` | 认证令牌（Bearer） |
| `ANTHROPIC_API_KEY` | API 密钥（部分供应商用） |
| `ANTHROPIC_MODEL` | 默认模型 |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | Sonnet 映射 |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | Opus 映射 |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | Haiku 映射 |

## 内置供应商模板

官方版内置多家供应商模板，开箱即用：

| 供应商 | 模型家族 |
|------|------|
| Anthropic | Claude 系列（官方） |
| GLM（智谱） | GLM-4 系列 |
| DeepSeek | deepseek-chat / deepseek-reasoner |
| Kimi（月之暗面） | kimi-k2 / moonshot |
| MiniMax | minimax-m 系列 |

## 自定义供应商

用户可新增自定义供应商，填写：

- 名称与图标
- API 端点（`ANTHROPIC_BASE_URL`）
- 认证方式（API Key / Token）
- 模型映射（sonnet/opus/haiku 对应模型名）
