# 供应商 Provider

## 定义

供应商（Provider）是提供 Claude 兼容 API 的服务方，包括 Anthropic 官方、国产大模型厂商（GLM/Kimi/DeepSeek）与第三方中转。CC Switch 以「供应商 profile」为单位组织端点、密钥与模型映射。
