# API 密钥 API Key

## 定义

API 密钥（API Key / Auth Token）是访问供应商 API 的凭据，对应 `ANTHROPIC_AUTH_TOKEN` 或 `ANTHROPIC_API_KEY`。是 CC Switch 配置中需重点保护的安全要素。
