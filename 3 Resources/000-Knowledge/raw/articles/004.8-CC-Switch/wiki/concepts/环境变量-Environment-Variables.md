# 环境变量 Environment Variables

## 定义

环境变量是 Claude Code 读取供应商配置的载体，核心为 `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`/`ANTHROPIC_API_KEY`、`ANTHROPIC_MODEL` 及模型映射变量。CC Switch 切换的本质就是改写这组变量。
