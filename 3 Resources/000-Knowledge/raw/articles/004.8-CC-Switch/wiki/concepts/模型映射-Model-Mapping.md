# 模型映射 Model Mapping

## 定义

模型映射（Model Mapping）是把 Claude Code 的 `sonnet`/`opus`/`haiku` 三档映射到供应商实际模型名的机制，由 `ANTHROPIC_DEFAULT_*_MODEL` 系列环境变量控制。
