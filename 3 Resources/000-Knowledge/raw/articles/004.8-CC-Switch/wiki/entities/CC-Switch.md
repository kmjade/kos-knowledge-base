# CC Switch

## 定位

CC Switch 是最流行的 Claude Code / Codex / Gemini CLI 供应商切换工具，官方桌面版（farion1231/cc-switch，Tauri + React），支持多供应商 profile 一键切换与 MCP/提示词管理。

## 关键特征

- 跨平台桌面 GUI + Web 版
- 管理 Claude Code / Codex / Gemini CLI
- 内置供应商预设 + `ccswitch://` deep link
- 附 MCP 服务器 / Prompts / Skills 管理
