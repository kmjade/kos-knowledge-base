# Anthropic

## 定位

Anthropic 是 Claude 与 Claude Code 的出品方，提供官方 API（api.anthropic.com），是 CC Switch 的默认供应商。

## 关键特征

- 出品 Claude 系列模型
- 官方 API 端点 api.anthropic.com
- Claude Code 默认绑定供应商
