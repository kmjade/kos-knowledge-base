# Claude Code

## 定位

Claude Code 是 Anthropic 出品的终端编码 Agent，是 CC Switch 的核心切换对象。CC Switch 通过改写其供应商配置，使其可接入第三方/中转模型。

## 关键特征

- 出品：Anthropic
- 终端交互式编码 Agent
- 配置位于 `~/.claude/settings.json`
