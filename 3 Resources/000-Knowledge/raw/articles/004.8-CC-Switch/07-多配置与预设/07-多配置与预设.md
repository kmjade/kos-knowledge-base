# 07 多配置与预设

## 多配置（Profile）管理

CC Switch 的核心价值是**多套 profile 并存**，典型用法：

| 场景 | profile 组合 |
|------|-------------|
| 工作/个人 | 工作账号 + 个人账号 |
| 官方/中转 | Anthropic 官方 + DeepSeek 中转 |
| 内外网 | 官方端点 + 国内可用端点 |
| 成本/质量 | 便宜模型 + 强模型 |

## 预设（Preset）

官方版内置供应商预设模板，新建 profile 时一键套用：

- 预设含默认端点、认证方式、模型映射
- 用户只需填密钥即可使用
- CLI 版（ccswitch-tui）内置 55+ Claude Code、47+ Codex 预设

## 导入导出

| 方式 | 说明 |
|------|------|
| 配置文件 | 导出/导入 JSON 配置 |
| deep link | `ccswitch://` 协议一键导入（如 New API） |
| 手动 | 复制粘贴端点/密钥/模型 |

## deep link 协议

`ccswitch://` 是官方版提供的深链协议，第三方平台（如 New API）可生成一条链接，点击即在 CC Switch 中自动创建对应供应商 profile，省去手动填写。
