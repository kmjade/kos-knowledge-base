# 05 密钥与安全

## API 密钥类型

| 类型 | 说明 |
|------|------|
| API Key | 简单密钥（如 `sk-...`），第三方中转常用 |
| Auth Token | Bearer 令牌，Claude Code 官方推荐 |
| OAuth | 官方账号 OAuth 授权（登录态） |

## 密钥存储

| 方案 | 位置 | 安全级别 |
|------|------|:--:|
| CC Switch 应用内 | 应用本地存储 | 中（桌面本地） |
| Claude Code settings | `~/.claude/settings.json` | 中（明文 JSON） |
| 系统钥匙串 | macOS Keychain | 高 |
| 环境变量 | shell 配置 | 中 |

## 安全最佳实践

- **官方账号**优先用 OAuth 登录态，避免存明文密钥
- **中转供应商**密钥注意保管，不提交到版本库
- 检查 `~/.claude/settings.json` 是否含密钥，避免外泄
- 多账号场景用 profile 隔离工作/个人密钥
- 定期轮换密钥，废弃泄漏密钥

## 风险提示

| 风险 | 说明 |
|------|------|
| 中转密钥泄漏 | 第三方中转密钥被窃即被盗刷额度 |
| 配置外泄 | settings.json 含密钥时避免共享/上传 |
| 供应链风险 | 中转供应商可能记录请求内容 |
