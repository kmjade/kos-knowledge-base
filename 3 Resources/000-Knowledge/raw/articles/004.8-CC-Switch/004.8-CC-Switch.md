# 004.8 CC Switch

> CC Switch 是**最流行的 Claude Code / Codex / Gemini CLI 供应商切换工具**，官方桌面版（farion1231/cc-switch，Tauri + React）。以「一键切换 API 供应商 + MCP/提示词管理」为核心，让用户在官方 Anthropic 与第三方中转（GLM / DeepSeek / Kimi / MiniMax 等）之间自由切换。数据更新至 2026-09。
