# 08 高级与扩展

## MCP 服务器管理

官方版 CC Switch 除了切换供应商，还内置 **MCP 服务器管理**：

| 功能 | 说明 |
|------|------|
| 添加 MCP | 图形化配置 MCP server |
| 启停 | 一键启用/禁用 |
| 分组 | 按场景组织 MCP 集合 |

> MCP（Model Context Protocol）让 Claude Code 连接外部工具与数据源，详见 Claude Code 知识库的 MCP 概念页。

## 提示词管理（Prompts）

| 功能 | 说明 |
|------|------|
| 系统提示 | 管理/切换系统提示词 |
| 预设提示 | 保存常用提示模板 |

## Skills 扩展

部分版本支持 Skills 扩展管理，与 Claude Code 的技能系统衔接。

## 自定义端点与代理

| 场景 | 配置 |
|------|------|
| 自建中转 | 填写自建兼容端点 URL |
| 本地模型 | 接 Ollama 兼容端点（`http://localhost:11434/v1`） |
| 网络代理 | 配合系统/工具代理访问 |

## 故障排查

| 问题 | 排查 |
|------|------|
| 切换不生效 | 确认 settings.json 已更新、重启 claude |
| 401 认证失败 | 检查密钥/令牌是否正确 |
| 模型不识别 | 检查模型映射是否为供应商支持名 |
| 端点不通 | 测试端点连通性、检查代理 |
