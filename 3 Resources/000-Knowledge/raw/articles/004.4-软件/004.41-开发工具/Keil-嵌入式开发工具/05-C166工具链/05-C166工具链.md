# 05 C166 工具链（Infineon C166）

> C166（产品包名 PK166）面向 Infineon 的 C166 / XC16x 16 位微控制器家族，曾是汽车电子与工业控制的主流平台。现为 **Legacy** 工具链，作为 MDK-Professional 的一部分提供。

## 目标内核

- Infineon C166 / C167（经典 16 位）
- XC16x（XE166 / XC2000 系列增强内核）
- 一度广泛用于发动机管理、车身电子、工业驱动控制

## 工具链组件

| 组件 | 作用 |
|------|------|
| C166 | C 编译器（支持 C166/XC16x 指令集） |
| A166 | 宏汇编器 |
| L166 | 连接/定位器 |
| OH166 | 目标文件 → HEX 转换器 |

## C166 内核特点

| 特性 | 说明 |
|------|------|
| 位宽 | 16 位 CISC |
| 寄存器 | 16 个通用寄存器（R0–R15），可重组为寄存器窗口 |
| 寻址 | 分段寻址（Near/Far/Shuge 模型） |
| 中断 | 多优先级、快速上下文切换 |
| 典型主频 | 20–80 MHz |

## 现状与建议

- C166 已被 Arm 标记为 **Legacy**，仅用于维护存量项目。
- 新项目建议迁移至 Cortex-M（MDK）或 Infineon AURIX/Tricore（另有 Tasking/AURIX 工具链）。
- 获取方式：MDK-Professional 的 Legacy 工具链，经 `armlm genLIC` 激活。
