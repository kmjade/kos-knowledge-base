# C251 工具链（DK251）

面向 80251 / C251 微控制器（8051 增强内核）的工具链（产品包名 DK251），支持最高 16MB 地址空间。现已并入 MDK-Professional 的 Legacy 工具链。

## 核心规格

| 参数 | 说明 |
|------|------|
| 目标内核 | 80251 / C251（8/16 位增强） |
| 编译器 | C251 |
| 汇编器 | A251 |
| 链接/定位 | L251 |
| 转换 | OH251 |
| 获取方式 | MDK-Professional（`armlm genLIC`） |

## 与 C51 差异

80251 为 24 位地址总线（最高 16MB）、可重定位寄存器文件、可配置中断向量，寄存器映射与经典 8051 不同。
