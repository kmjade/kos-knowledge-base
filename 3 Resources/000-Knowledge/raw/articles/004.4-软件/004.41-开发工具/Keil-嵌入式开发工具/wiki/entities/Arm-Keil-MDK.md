# Arm Keil MDK

Arm 面向 Cortex-M（及 Arm7/Arm9/Cortex-R4）的完整软件开发工具套件，前身 MDK-ARM，MDK v6 以 CMSIS-Toolbox 与 `csolution.yml` 为工程范式，提供 Community / Essential / Professional 三版本。

## 核心规格

| 参数 | 说明 |
|------|------|
| 目标内核 | Cortex-M 全系、Arm7、Arm9、Cortex-R4 |
| IDE | µVision（Windows）+ Keil Studio（VS Code） |
| 编译器 | Arm Compiler for Embedded（AC6 默认） |
| RTOS | RTX5、CMSIS-FreeRTOS |
| 调试 | ULINK、CMSIS-DAP、第三方探针 |
| 版本 | MDK v6（Community / Essential / Professional） |
| 许可 | User-Based Licensing（UBL） |

## 版本差异

| 能力 | Community | Essential | Professional |
|------|:---:|:---:|:---:|
| 商业用途 | ❌ | ✅ | ✅ |
| 功能安全编译器 | ❌ | ❌ | ✅ |
| Legacy 工具链（PK51/DK251/PK166/AC5） | ❌ | ❌ | ✅ |
