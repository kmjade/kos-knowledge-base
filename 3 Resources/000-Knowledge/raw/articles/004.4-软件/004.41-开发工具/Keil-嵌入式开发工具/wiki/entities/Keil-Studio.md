# Keil Studio

Keil Studio 是 Arm 面向 VS Code 的扩展套件，提供跨平台（Windows/Linux/macOS）的嵌入式开发体验，是 MDK v6 的新一代 IDE，逐步承接 µVision 的职责。

## 核心规格

| 参数 | 说明 |
|------|------|
| 形态 | VS Code 扩展 |
| 平台 | Windows / Linux / macOS |
| 工程格式 | `csolution.yml`（CMSIS-Toolbox） |
| 编译 | Arm Compiler 6（armclang） |
| 调试 | CMSIS-DAP / ULINK |
| 与 µVision 关系 | 新范式，跨平台替代 |
