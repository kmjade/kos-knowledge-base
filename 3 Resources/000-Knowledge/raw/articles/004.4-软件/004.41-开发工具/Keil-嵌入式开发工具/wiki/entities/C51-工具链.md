# C51 工具链（PK51）

面向 8051 兼容单片机的行业标准 C 开发工具链（产品包名 PK51），是 8051 事实标准的编译环境，当前用户指南版本 v9.61。

## 核心规格

| 参数 | 说明 |
|------|------|
| 目标内核 | 8051 兼容（8 位） |
| 编译器 | C51（C 编译器） |
| 汇编器 | A51（宏汇编器） |
| 链接/定位 | BL51 / LX51 |
| 库管理 | LIB51 |
| 转换 | OH51（HEX） |
| 内存模型 | SMALL / COMPACT / LARGE |

## C51 语言扩展

`code` / `data` / `idata` / `xdata` / `bdata`、`sfr` / `sbit`、`bit`、`interrupt`、`using`、`reentrant`。
