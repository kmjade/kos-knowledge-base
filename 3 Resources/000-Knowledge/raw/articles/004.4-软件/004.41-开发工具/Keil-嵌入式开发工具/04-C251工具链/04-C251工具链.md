# 04 C251 工具链（80251）

> C251（产品包名 DK251）面向 80251 / C251 微控制器——8051 的增强内核，支持更大的地址空间（最高 16MB）与更高的代码/数据吞吐。注意：**CA251 编译器与 A251 汇编器已不再单独销售**，DK251 专业开发套件现作为 **MDK-Professional** 的一部分提供。

## 工具链组件

| 组件 | 作用 |
|------|------|
| C251 | C 编译器（C → .OBJ） |
| A251 | 宏汇编器 |
| L251 | 连接/定位器（.OBJ → 绝对地址映像） |
| OH251 | 目标文件 → HEX 转换器 |

## 80251 与 8051 的关键差异

| 维度 | 8051（C51） | 80251（C251） |
|------|------------|--------------|
| 地址总线 | 16 位（64KB） | 24 位（最高 16MB） |
| 数据区 | 256B 片内 + 64KB 外存 | 扩展寻址、更大线性空间 |
| 寄存器 | 8 个 R0–R7 | 可重定位寄存器文件（Register File） |
| 指令集 | 255 条 | 兼容 8051 + 扩展指令 |
| 中断向量 | 固定地址 | 可配置（更多中断源） |

## 选型注意

- 经典 8051（AT89C51、STC89C52）→ **C51**，不要用 C251。
- 明确标注 80251 / C251 内核的芯片（部分新型 STC、以及 Atmel 早期 80251 系列）→ **C251**。
- 80251 的寄存器映射与中断向量表与标准 8051 有差异，移植代码时需核对启动文件与 SFR 定义。

## 当前状态

- DK251 已并入 MDK-Professional 的 Legacy 工具链（通过 `armlm genLIC` 激活）。
- 适用于维护存量 80251 项目，新设计通常直接迁移到 Cortex-M（MDK）。
