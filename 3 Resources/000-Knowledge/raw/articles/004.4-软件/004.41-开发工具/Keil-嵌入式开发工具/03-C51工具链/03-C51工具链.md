# 03 C51 工具链（8051）

> C51（产品包名 PK51）是 8051 兼容单片机的行业标准 C 开发工具链，由 C51 编译器、A51 宏汇编器、BL51/LX51 连接定位器、LIB51 库管理器与 OH51 目标文件转换器组成。当前用户指南版本 **v9.61**。

## 工具链组件

| 组件 | 全称 | 作用 |
|------|------|------|
| C51 | C Compiler | C → 目标文件（.OBJ） |
| A51 | Macro Assembler | 汇编 → 目标文件 |
| BL51 / LX51 | Linker/Locator | 连接目标文件并定位到绝对地址 |
| LIB51 | Library Manager | 创建/管理 .LIB 库 |
| OH51 | Object-HEX Converter | 目标文件 → Intel HEX 烧录文件 |

## 支持的 8051 变体

- 经典 8051：AT89C51、AT89S52、STC89C52、NXP P89V51
- 扩展 8051：Dallas DS80C390、NXP MX、Analog Devices ADuC8xx
- Silicon Labs C8051F、TI CC2430/CC2530（8051 内核的无线 MCU）

> 关键区分：**STC89C52、AT89C51 等经典 8051 必须用 C51**；若芯片是 80251 增强内核（如部分 STC 新型号标注 251 架构），则用 C251。

## C51 对 ANSI C 的扩展

| 扩展 | 用途 |
|------|------|
| `code` / `data` / `idata` / `xdata` / `bdata` | 指定变量存放的存储区 |
| `sfr` / `sbit` | 直接访问特殊功能寄存器与位 |
| `bit` | 位变量（存于 20H–2FH 位寻址区） |
| `interrupt n` | 声明中断服务函数（n = 中断号） |
| `using` | 指定寄存器组（0–3） |
| `reentrant` | 声明可重入函数 |

## 内存模型（Memory Model）

| 模型 | 默认变量存放 | 适用 |
|------|-------------|------|
| SMALL | `data`（片内低 128B） | 变量少、速度快 |
| COMPACT | `pdata`（页寻址外存） | 中等数据量 |
| LARGE | `xdata`（外部数据区） | 大数据量，速度较慢 |

## 中断向量与寄存器组

- 8051 中断向量固定：外部 0=0003H、定时器 0=000BH、外部 1=0013H、定时器 1=001BH、串口=0023H。
- 中断函数默认使用寄存器组 0，可用 `using 1/2/3` 切换以减少压栈。

## 8051 内存布局（哈佛结构）

```
8051 Memory Map
├── CODE  (64KB) — 程序 Flash
├── DATA  (128B) — 内部直接寻址 RAM（data）
├── IDATA (256B) — 内部间接寻址 RAM（idata）
├── XDATA (64KB) — 外部 RAM（xdata）
├── SFR   (128B) — 特殊功能寄存器（P0/P1/TMOD/...）
└── BIT   (16B)  — 位寻址区（20H–2FH）
```

## 中断向量表

| 中断 | 向量 | 来源 |
|------|:----:|------|
| RESET | 0x0000 | 系统重置 |
| INT0 | 0x0003 | 外部中断 0 |
| Timer 0 | 0x000B | 定时器 0 |
| INT1 | 0x0013 | 外部中断 1 |
| Timer 1 | 0x001B | 定时器 1 |
| Serial | 0x0023 | UART |
| Timer 2 | 0x002B | 定时器 2（8052） |

## 常用外设代码

```c
// UART 初始化（9600 baud, 11.0592 MHz）
void UART_Init(void) {
    TMOD = 0x20;    // Timer 1, Mode 2 (8-bit auto-reload)
    TH1 = 0xFD;     // 9600 baud @ 11.0592MHz
    SCON = 0x50;    // Mode 1, REN=1
    TR1 = 1;        // Start Timer 1
}
// GPIO 位操作
sbit LED = P1^0;
LED = 0;    // 低电平点亮（8051 一般低电平驱动）
```
