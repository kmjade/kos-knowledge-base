# 07 编译器与链接器

## Arm Compiler：AC5 vs AC6

| 维度 | AC5 | AC6 |
|------|-----|-----|
| 编译器 | `armcc` | `armclang` |
| 后端 | ARM 自研（CCS） | LLVM/Clang |
| 语言标准 | C90/C99、C++03 | C11/C17、C++14/17 |
| 诊断信息 | 基本 | 丰富（Clang 风格 warning） |
| LTO（链接期优化） | ❌ | ✅ |
| 默认语言 | `--gnu`（GNU 扩展） | `-std=gnu11` |
| 状态 | Legacy（冻结） | 现行默认 |

> **新项目一律用 AC6（armclang）**：`Options → Target → ARM Compiler: V6.xx`。CMSIS-DSP v6 及更新组件已放弃 AC5。

## 优化等级

| 等级 | 旗标 | 说明 | 适用 |
|:----:|:-----|------|------|
| `-O0` | No optimization | 完全不优化，最佳调试体验 | Debug 开发 |
| `-O1` | Restricted | 基本优化，不增 code size | 轻度优化 |
| `-O2` | High（默认） | 平衡速度/大小 | 日常使用 |
| `-O3` | Highest | 激进速度优化，code 变大 | 性能热点 |
| `-Ofast` | -O3 + fast-math | 忽略 IEEE 精度 | DSP 运算 |
| `-Os` | Balanced | 面向 code size | Flash 受限 |
| `-Oz` | Smallest | 最小 code size（Clang 6+） | 极小 Flash |

## Scatter-Loading 分散加载脚本（.sct）

Scatter-loading 取代传统 linker script，定义内存布局：

```c
// example.sct — STM32F407VG (1024KB Flash, 128KB RAM)
LR_IROM1 0x08000000 0x00100000  {    // Load Region (Flash 起始, 1MB)
  ER_IROM1 0x08000000 0x00100000  {  // Execution Region — Code
    *.o (RESET, +First)
    *(InRoot$$Sections)
    .ANY (+RO)
  }
  RW_IRAM1 0x20000000 0x00020000  {  // R/W Region — SRAM
    .ANY (+RW +ZI)
  }
}
```

| 关键词 | 含义 |
|--------|------|
| `LR_xxx` | Load Region：可执行文件载入地址 |
| `ER_xxx` | Execution Region：执行时地址 |
| `+RO` | Read-Only：code + constants |
| `+RW` | Read-Write：已初始化数据 |
| `+ZI` | Zero-Initialized：bss 段 |
| `+First` | 确保向量表在最前面 |

## 常用编译选项（armclang）

| 选项 | 功能 |
|------|------|
| `-c` | 只编译不链接 |
| `-g` | 生成调试信息 |
| `-D<macro>` | 定义宏（`-DSTM32F407xx`） |
| `-I<dir>` | 添加 include 路径 |
| `-W<warning>` | 控制 warning 等级 |
| `-target arm-arm-none-eabi` | 目标架构 triplet |
| `-mcpu=cortex-m4` | 目标 CPU |
| `-mthumb` | Thumb 指令集 |
| `-ffunction-sections` | 按函数分节（配合 `--gc-sections`） |

## C51 内存模型与定位

| 关键字 | 存储区 | 地址 |
|--------|--------|------|
| `data` | 片内 RAM 低 128B | 00H–7FH |
| `idata` | 片内 RAM（间接寻址） | 00H–FFH |
| `bdata` | 位寻址区 | 20H–2FH |
| `xdata` | 外部 RAM | 0000H–FFFFH |
| `pdata` | 页寻址外部 RAM | 256B 页 |
| `code` | 程序存储器 | 0000H–FFFFH |

## 链接器（BL51/LX51）职责

1. 合并多个目标文件（.OBJ）与库（.LIB）
2. 解析符号引用，处理段（segment）
3. 定位到绝对地址（按 `code`/`data`/`xdata` 分类）
4. 生成烧录映像（.HEX）与映射文件（.M51/.map）

> LX51 是 BL51 的增强版，支持多文件划分、更细的段控制与 `REMOVEUNUSED` 删除未用代码。

## 常见编译/链接错误

| 错误 | 含义 | 处理 |
|------|------|------|
| `L105` | 段重叠/地址冲突 | 检查内存模型与地址分配 |
| `L107` | 地址空间溢出（如 data 超 128B） | 变量改放 `xdata` / 换 LARGE 模型 |
| `C141` | 语法错误附近 | 检查括号、分号、关键字 |
| `error: #20` | 标识符未定义 | 补头文件/声明 |
