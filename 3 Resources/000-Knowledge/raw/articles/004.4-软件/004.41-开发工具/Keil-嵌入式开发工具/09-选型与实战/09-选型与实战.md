# 09 选型与实战

## 选型决策树

```
目标 MCU 内核？
├─ 8051（AT89C51/STC89C52/NXP 8051）   → C51（PK51）
├─ 80251（增强 8051）                    → C251（DK251，随 MDK-Pro）
├─ C166 / XC16x（Infineon，存量）        → C166（PK166，legacy）
└─ ARM Cortex-M（STM32/GD32/nRF 等）    → MDK-ARM（MDK v6）
```

## MDK 版本选择

| 场景 | 推荐版本 |
|------|---------|
| 学生/学习/开源（非商业） | Community（免费） |
| 中小企业商业项目 | Essential |
| 功能安全（IEC 61508 / ISO 26262） | Professional |
| 需维护 8051/80251/C166 存量 | Professional（Legacy 工具链） |

## 工程搭建流程（µVision）

1. 新建工程 → 选择目标芯片（Device Pack）
2. 勾选 Run-Time Environment（CMSIS Core / Startup / RTOS）
3. 添加源文件，配置 Target Options（编译器、优化、链接）
4. 配置调试器（ULINK/CMSIS-DAP）与 Flash Download
5. 编译 → 下载 → 调试

## 工程搭建流程（MDK v6 / CMSIS-Toolbox）

```bash
cpackget update-index          # 更新软件包索引
cpackget add <vendor>.<pack>   # 安装芯片包
csolution convert -s *.yml     # 解析 csolution 工程
cbuild project.csolution.yml   # 编译（cmake 生成 + 构建）
```

### GPIO LED 闪烁

```c
void GPIO_Init_LED(void) {
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIODEN;   // GPIOD 时钟
    GPIOD->MODER   &= ~(3 << (12*2));       // 清除 PD12 mode
    GPIOD->MODER   |=  (1 << (12*2));       // PD12: Output
    GPIOD->OTYPER  &= ~(1 << 12);           // Push-pull
    GPIOD->OSPEEDR |=  (3 << (12*2));       // High speed
    GPIOD->PUPDR   &= ~(3 << (12*2));       // No pull
}
void LED_Toggle(void) { GPIOD->ODR ^= (1 << 12); }  // Toggle PD12
```

### UART printf 重定向（USART2）

```c
int fputc(int ch, FILE *f) {
    while (!(USART2->SR & USART_SR_TXE));
    USART2->DR = (uint8_t)ch;
    return ch;
}
// 使用: printf("SystemCoreClock: %lu Hz\r\n", SystemCoreClock);
```

### RTX5 任务建立

```c
#include "cmsis_os2.h"
void BlinkTask(void *arg) {
    for(;;) { LED_Toggle(); osDelay(500); }
}
const osThreadAttr_t BlinkAttr = {
    .name = "Blink", .priority = osPriorityNormal, .stack_size = 200
};
// main: osKernelInitialize() → osThreadNew(BlinkTask, NULL, &BlinkAttr) → osKernelStart()
```

### ULINK 调试步骤

```
1. F7 → Build
2. Options → Debug → Select ULINKpro / ST-Link
3. Options → Debug → Settings → SWD, 4 MHz
4. Ctrl+F5 → Start Debug
5. F9 → 在 LED_Toggle() 设断点
6. F5 → Run → 停在断点
7. View → Watch 1 → 添加 GPIOD->ODR
8. View → Serial Windows → USART #2 → printf 输出
9. F10 → Step Over 观察变量
```

## 实战要点

| 要点 | 说明 |
|------|------|
| 启动文件 | 每芯片提供 startup 文件，初始化堆栈/向量表 |
| 分散加载 | `.sct` 脚本控制 ROM/RAM 布局 |
| printf 重定向 | 重写 `fputc`，经 ITM/SWO 或 UART 输出 |
| 烧录算法 | Flash Download 使用芯片对应 Flash 算法 |
| 版本兼容 | CMSIS-DSP v6 需 AC6；升级 MDK 后核对 Pack 版本 |
