# 08 调试与仿真

## 调试探针家族

| 特性 | ULINK2 | ULINKpro | ULINKplus |
|------|:------:|:--------:|:---------:|
| 调试接口 | JTAG / SWD | JTAG / SWD | JTAG / SWD |
| Trace | ❌ | ✅ ETMv3（4-bit） | ✅ SWO/ITM |
| 功耗测量 | ❌ | ❌ | ✅ 电流/电压 |
| SWO 支持 | 基本 | ✅ | ✅ 高频 |
| 最大 SWD 时钟 | 10 MHz | 50 MHz | 50 MHz |
| Code Coverage | ❌ | ✅ | ❌ |
| 适用场景 | 入门/学生 | 专业分析 | 功耗优化 |
| Event Recorder | ✅ | ✅ | ✅ |

## 调试接口

| 接口 | 线数 | 说明 |
|------|:----:|------|
| JTAG | 5（TMS/TCK/TDI/TDO/nTRST） | IEEE 1149.1，传统调试 |
| SWD | 2（SWDIO/SWCLK） | ARM 专用，Cortex-M 主流，接线简单 |
| cJTAG | 2 | 兼容 JTAG + SWD |
| SWO/ITM | 1 | 高速 printf / 事件追踪输出 |

## 软件仿真 vs 硬件调试

| 维度 | 软件仿真器 | 硬件调试 |
|------|-----------|---------|
| 硬件 | 无需开发板 | 需探针 + 目标板 |
| 时序 | 非真实 | 真实 |
| 外设 | 部分模拟 | 全部真实 |
| 功耗测量 | 不支持 | ULINKplus 支持 |
| 适用 | 算法验证、教学 | 量产调试 |

## ITM / SWO Trace 追踪

ITM（Instrumentation Trace Macrocell）通过 SWO（Single Wire Output）输出运行时数据：

```
Cortex-M Core
    │
    ├── ITM (32 channels)
    │   ├── Channel 0: OS events
    │   ├── Channel 1: User printf
    │   └── Channel 31: Timestamps
    │
    └── SWO ──► ULINKpro/plus ──► µVision Trace Window
```

### ITM printf 重定向

```c
// SWO printf — 无需 UART，不占用 CPU
#include "stm32f4xx.h"
#define ITM_Port8(n)   (*((volatile unsigned char *)(0xE0000000+4*n)))

int fputc(int ch, FILE *f) {
    ITM_Port8(0) = (unsigned char)ch;  // ITM Channel 0
    return ch;
}
```

> **优势**：SWO printf 不阻塞 CPU（经 ITM FIFO），真实时序不受影响。

## 断点与监视点

| 类型 | 数量（Cortex-M4） | 说明 |
|------|:----------------:|------|
| 硬件断点 | 6（FPB） | 代码断点，不写 Flash |
| 软件断点 | 不限 | 改 Flash 放 `BKPT`，影响寿命 |
| 数据监视点 | 4（DWT） | 变量读写触发中断 |
| 访问断点 | — | 指定地址读/写触发 |

### 条件断点

```
µVision → Debug → Breakpoints (Ctrl+B)
  Expression:  counter == 100
  Count:       5              // 第 5 次命中才停
  Command:     "printf(...)"  // 触发时执行脚本
```

## Event Recorder 事件记录器

不占 SWO/ITM 通道，经 DWT 记录事件到 RAM buffer：

```c
#include "EventRecorder.h"
EventRecord2(EventID1, val1, val2);   // 记录带 2 参数事件
EventRecorder::Update();              // 刷新到调试器
```

| 特性 | SWO ITM | Event Recorder |
|------|:-------:|:--------------:|
| 硬件需求 | SWO 引脚 | DWT（所有 Cortex-M） |
| 实时性 | ✅ 串流输出 | RAM buffer（暂停后读取） |
| 占用 CPU | 极低 | 极低 |

## 调试工作流

```
1. 编译:  F7 → Build（确保 -g 调试信息）
2. 连接:  Ctrl+F5 → Start Debug Session
3. 断点:  F9 → 设置断点
4. 执行:  F5 Run / F10 Step Over / F11 Step Into
5. 监视:  Watch Window + Memory Window
6. Trace: View → Trace → 分析执行路径/时序
7. 功耗:  ULINKplus → Debug → Power Measurement
8. 结束:  Ctrl+F5 → Stop Debug
```
