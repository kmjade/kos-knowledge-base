# 05 调试与测试

## 调试器（Debugger）

内置 JVM 调试器：

| 操作 | 快捷键 | 说明 |
|------|:------:|------|
| 步入（Step Into） | F7 | 进入方法 |
| 智能步入 | Shift+F7 | 选择进入哪个方法 |
| 步过（Step Over） | F8 | 执行当前行 |
| 步出（Step Out） | Shift+F8 | 跳出方法 |
| 继续 | F9 | 运行到下一断点 |

## 断点（Breakpoint）

| 类型 | 说明 |
|------|------|
| 行断点 | 执行到该行暂停 |
| 条件断点 | 满足条件才暂停 |
| 日志断点（Logpoint） | 不暂停，仅打印日志（2026.2 新增，AI 可放置） |
| 异常断点 | 抛出异常时暂停 |

## 调试面板

| 功能 | 说明 |
|------|------|
| 变量（Variables） | 查看/修改变量值 |
| 调用栈（Frames） | 查看调用链 |
| 线程（Threads） | 多线程状态 |
| 表达式求值 | `Alt+F8` 求值表达式 |
| 监视（Watches） | 持续监视变量 |

## 单元测试

| 框架 | 说明 |
|------|------|
| JUnit | Java 标准测试框架 |
| TestNG | 替代框架 |
| Mockito | Mock 框架 |

- 运行测试：`Ctrl+Shift+F10`
- 生成测试：`Alt+Enter` → Create Test
- 测试覆盖率：Run with Coverage

## 远程调试

支持连接远程 JVM 调试（Debug 配置 → Remote JVM Debug）。
