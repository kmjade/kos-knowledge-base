# 调试器 Debugger

## 定义

IntelliJ IDEA 的内置 JVM 调试器，支持断点、步进、表达式求值与远程调试。

## 能力

| 能力 | 说明 |
|------|------|
| 断点 | 行/条件/异常断点 |
| 步进 | 步入/步过/步出 |
| 求值 | 表达式求值、变量修改 |
| 远程 | 连接远程 JVM |
