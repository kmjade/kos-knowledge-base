# 代码补全 Code Completion

## 定义

代码补全是 IntelliJ IDEA 的核心能力，分析当前文件与项目上下文，智能建议类、方法、字段与关键字。

## 类型

| 类型 | 快捷键 |
|------|--------|
| 基础补全 | `Ctrl+Space` |
| 智能补全 | `Ctrl+Shift+Space` |
| 整行补全 | 机器学习模型 |
| AI 补全 | JetBrains AI |
