# 重构 Refactoring

## 定义

重构是在不改变代码外部行为的前提下改善内部结构。IntelliJ IDEA 提供自动化重构，全项目同步更新。

## 常用重构

| 重构 | 说明 |
|------|------|
| 重命名 | 全项目改名 |
| 提取方法/变量/常量 | 抽取代码 |
| 内联 | 反向合并 |
| 安全删除 | 检查引用后删除 |

> 入口：`Ctrl+Alt+Shift+T`
