# AI Assistant

JetBrains 的 AI 助手，集成于 IntelliJ IDEA，提供代码补全、对话问答、测试生成等能力。

## 能力

| 能力 | 说明 |
|------|------|
| AI 补全 | 整行/整块生成 |
| AI Chat | 对话问答 |
| 测试生成 | 生成单元测试 |
| 提交信息 | 自动写 commit message |
