# 版本控制 VCS

## 定义

版本控制系统管理代码的历史变更。IntelliJ IDEA 内置完整 Git 集成。

## 能力

| 能力 | 说明 |
|------|------|
| 提交/推送 | Ctrl+K / Ctrl+Shift+K |
| 历史 | 提交历史、分支图 |
| 冲突解决 | 合并工具、批量解决 |
