# 快捷键 Shortcuts

## 定义

快捷键是提升 IntelliJ IDEA 效率的核心。可切换 Keymap 方案（IntelliJ / VS Code / Eclipse）。

## 常用快捷键

| 快捷键 | 作用 |
|--------|------|
| Double Shift | Search Everywhere |
| Ctrl+B | 跳转声明 |
| Ctrl+Alt+L | 格式化代码 |
| Alt+Enter | 快速修复 |
| Alt+Insert | 代码生成 |
