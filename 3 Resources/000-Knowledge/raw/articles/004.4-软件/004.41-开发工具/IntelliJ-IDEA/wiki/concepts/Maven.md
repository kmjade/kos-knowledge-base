# Maven

## 定义

Maven 是 Java 主流的构建与依赖管理工具，基于 `pom.xml`，约定优于配置。

## 关键点

| 要点 | 说明 |
|------|------|
| 坐标 | groupId/artifactId/version |
| 生命周期 | clean/compile/test/package |
| 本地仓库 | `~/.m2` |
