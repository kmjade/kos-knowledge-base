# 项目结构 Project Structure

## 定义

项目结构定义项目的 SDK、模块、库与框架配置，是 IntelliJ IDEA 项目的基础。

## 组成

| 模块 | 说明 |
|------|------|
| Project SDK | 项目级 JDK |
| Modules | 模块与依赖 |
| Libraries | 外部库 |
| Facets | 框架识别 |
