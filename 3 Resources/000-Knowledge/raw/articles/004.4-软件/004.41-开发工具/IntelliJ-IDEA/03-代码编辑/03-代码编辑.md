# 03 代码编辑

## 代码补全（Code Completion）

| 类型 | 说明 |
|------|------|
| 基础补全 | `Ctrl+Space`，类/方法/字段 |
| 智能补全 | `Ctrl+Shift+Space`，按类型匹配 |
| 整行补全 | 机器学习模型预测整行 |
| AI 补全 | JetBrains AI 辅助生成 |

## 导航

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+B` / `Ctrl+点击` | 跳转到声明 |
| `Ctrl+Alt+B` | 跳转到实现 |
| `Ctrl+Shift+F` | 全局搜索 |
| `Double Shift` | Search Everywhere |
| `Ctrl+E` | 最近文件 |

## 重构（Refactoring）

`Ctrl+Alt+Shift+T` 打开重构菜单：

| 重构 | 说明 |
|------|------|
| 重命名（Rename） | 全项目同步改名 |
| 提取方法/变量/常量 | 抽取代码片段 |
| 内联（Inline） | 反向合并 |
| 安全删除 | 检查引用后删除 |
| 移动/复制 | 移动类到其他包 |

## 检查（Inspections）

实时静态分析，标出潜在问题：

| 类型 | 示例 |
|------|------|
| 错误 | 编译错误 |
| 警告 | 未使用变量、空指针 |
| 建议 | 可简化的写法 |

> `Alt+Enter`（灯泡）快速应用修复建议。

## 代码生成

| 快捷键 | 生成 |
|--------|------|
| `Alt+Insert` | 构造器、getter/setter、equals/hashCode |
| `psvm` | main 方法 |
| `sout` | System.out.println |
| `Ctrl+Alt+L` | 格式化代码 |
