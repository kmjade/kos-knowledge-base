# 06 版本控制

## Git 集成

IntelliJ IDEA 内置完整的 Git 支持：

| 操作 | 快捷键 | 说明 |
|------|:------:|------|
| 提交 | Ctrl+K | Commit 对话框 |
| 推送 | Ctrl+Shift+K | Push |
| 更新 | Ctrl+T | Pull/Update |
| 历史 | — | 查看提交历史 |

## 版本控制面板

| 功能 | 说明 |
|------|------|
| Local Changes | 查看/暂存改动 |
| Log | 提交历史、分支图 |
| Console | Git 命令输出 |

## 冲突解决

| 方式 | 说明 |
|------|------|
| 合并工具 | 三方合并视图 |
| 简单冲突批量解决 | 2026.2 新增「Resolve All Simple Conflicts」 |
| 手动编辑 | 直接修改冲突标记 |

## 分支与工作树

| 功能 | 说明 |
|------|------|
| 分支管理 | 创建/切换/合并分支 |
| Git Worktrees | 并行工作分支（2026.1 新增，可交给 AI 代理处理） |
| 标签 | 打 tag |

## 其他 VCS

| 系统 | 支持 |
|------|------|
| Git | 完整 |
| GitHub/GitLab | 集成 PR/MR |
| SVN / Mercurial | 支持 |
