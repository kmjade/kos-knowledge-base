# 02 安装与配置

## 安装方式

| 方式 | 说明 |
|------|------|
| JetBrains Toolbox | 推荐，统一管理 JetBrains 产品与版本 |
| 官网安装包 | 直接下载安装 |
| 包管理器 | `scoop` / `brew` / `choco` / `snap` |

## JDK 配置

IntelliJ IDEA 需要 JDK 才能编译 Java：

| 要点 | 说明 |
|------|------|
| 项目 JDK | 每个项目可指定不同 JDK |
| 自动下载 | IDE 可自动下载所需 JDK |
| 多 JDK 共存 | 支持切换 |

## 项目结构（Project Structure）

| 模块 | 说明 |
|------|------|
| Project SDK | 项目级 JDK |
| Modules | 模块划分与依赖 |
| Libraries | 外部库 |
| Facets | 框架识别（Spring 等） |

## 常用设置

| 设置 | 说明 |
|------|------|
| 外观主题 | 深色/浅色主题 |
| 快捷键方案 | Keymap（可切换 VS Code/Eclipse 风格） |
| 代码风格 | 格式化规则 |
| 插件 | 安装/管理插件 |

## 快捷键方案（Keymap）

| 方案 | 适用 |
|------|------|
| IntelliJ | 默认 |
| macOS / Windows | 平台默认 |
| VS Code / Eclipse | 迁移用户 |
