# 09 实战案例

## 案例总览

| 案例 | 难度 | 覆盖 |
|------|:----:|------|
| Java 控制台项目 | ⭐ | 项目结构、运行 |
| Spring Boot 应用 | ⭐⭐⭐ | 依赖、框架、运行 |
| 调试实战 | ⭐⭐ | 断点、调试器 |
| 重构与测试 | ⭐⭐ | 重构、单元测试 |

## 案例一：Java 控制台项目

```
1. 新建项目 → Java + 选择 JDK
2. 创建 main 类（psvm + sout）
3. 运行（Run 'Main'）
4. 打 jar 包（Maven package）
```

**要点**：项目结构、运行配置、快捷键。

## 案例二：Spring Boot 应用

```
1. 新建项目 → Spring Initializr → 选依赖（Web、JPA、Lombok）
2. 自动生成 pom.xml 与启动类
3. 编写 Controller（@RestController）
4. 运行 Spring Boot 配置
5. 用 HTTP Client 测试接口
```

**要点**：Maven 依赖、Spring 框架、运行配置、HTTP Client。

## 案例三：调试实战

```
1. 在可疑代码行打断点（点击行号左侧）
2. Debug 运行（Shift+F9）
3. F8 步过 / F7 步入查看流程
4. 变量面板查看/修改变量值
5. Alt+F8 求值表达式
6. 定位 bug → 修复
```

**要点**：断点、步进、变量监视、表达式求值。

## 案例四：重构与测试

```
1. 选中重复代码 → Ctrl+Alt+M 提取方法
2. Alt+Insert 生成构造器/getter/setter
3. Alt+Enter → Create Test 生成 JUnit 测试
4. 运行测试（Ctrl+Shift+F10）
5. Run with Coverage 查看覆盖率
```

**要点**：重构、代码生成、单元测试。
