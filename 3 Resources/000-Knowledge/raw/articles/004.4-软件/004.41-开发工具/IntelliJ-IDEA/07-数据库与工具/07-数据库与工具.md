# 07 数据库与工具

## 数据库工具（Ultimate）

内置数据库浏览器（基于 DataGrip）：

| 功能 | 说明 |
|------|------|
| 数据源 | 连接 MySQL/PostgreSQL/Oracle/SQLite 等 |
| 查询控制台 | 编写执行 SQL |
| 表浏览/编辑 | 可视化查看修改数据 |
| 迁移 | Flyway/Liquibase（2026.2 增强） |
| Hibernate 调试器 | 查看 SQL/HQL（2026.2 新增） |

## HTTP Client

内置 `.http` 文件执行 HTTP 请求：

```http
GET https://api.example.com/users
Authorization: Bearer {{token}}

###
POST https://api.example.com/users
Content-Type: application/json

{"name": "Alice"}
```

| 要点 | 说明 |
|------|------|
| 请求文件 | `.http` 文件 |
| 变量 | `{{变量}}` 环境变量 |
| 响应查看 | 内联查看响应 |
