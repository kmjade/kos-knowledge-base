# 01 IntelliJ IDEA 导论

## 什么是 IntelliJ IDEA

IntelliJ IDEA 是 JetBrains 旗下的 Java / Kotlin 集成开发环境（IDE），以智能代码补全、自动化重构与内置调试器著称，是 Java 开发者的旗舰 IDE。

## JetBrains

| 要点 | 说明 |
|------|------|
| 公司 | JetBrains（捷克布拉格，软件开发工具公司） |
| 首款产品 | IntelliJ IDEA（2001 年） |
| 产品家族 | PyCharm、WebStorm、CLion、GoLand、DataGrip 等 |
| 定位 | 开发者生产力工具 |

## 核心特性

| 特性 | 说明 |
|------|------|
| 智能代码补全 | 上下文感知的补全（基础/智能/整行/AI） |
| 自动化重构 | 重命名、提取方法等，全项目同步更新 |
| 内置调试器 | 断点、条件断点、表达式求值、远程调试 |
| 静态分析 | 检查（Inspection）实时发现代码问题 |
| 插件生态 | 海量插件 + JetBrains AI |

## 版本演进

| 版本 | 年份 | 关键变化 |
|------|------|----------|
| IntelliJ IDEA 1.0 | 2001 | JetBrains 首款产品 |
| 版本号命名 | 早期 | 按大版本（9/10/11…） |
| 年份命名 | 2018 起 | 按年份（2018.1、2019.1…） |
| **2026.1** | 2026-03 | Java 26、Kotlin 2.3.20、AI 代理（Codex/Cursor/ACP） |
| **2026.2** | 2026-05+ | GitHub Copilot 集成、Java 27 早期、TypeScript 7.0、Logpoints |

## Community vs Ultimate

| 版本 | 说明 |
|------|------|
| **Community（社区版）** | 免费、开源，支持 Java/Kotlin/Groovy/Scala/Android |
| **Ultimate（旗舰版）** | 付费，额外支持 Spring、数据库工具、前端框架、性能分析 |

> 自 2025.3 起，JetBrains 逐步合并两版本：核心功能免费，Ultimate 订阅提供高级工具。
