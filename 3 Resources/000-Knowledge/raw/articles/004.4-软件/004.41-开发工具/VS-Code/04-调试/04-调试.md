# 04 调试

## 调试器

VS Code 内置调试器，通过调试扩展支持各语言（Node.js 内置，Python/Java/C++ 等靠扩展）。

| 操作 | 快捷键 | 说明 |
|------|:------:|------|
| 开始/继续 | F5 | 启动调试 |
| 单步跳过 | F10 | Step Over |
| 单步进入 | F11 | Step Into |
| 单步跳出 | Shift+F11 | Step Out |
| 断点开关 | F9 | Toggle Breakpoint |

## 断点

| 类型 | 说明 |
|------|------|
| 行断点 | 执行到该行暂停 |
| 条件断点 | 满足条件才暂停 |
| 日志点（Logpoint） | 不暂停，仅打印日志 |
| 异常断点 | 抛出异常时暂停 |

## launch.json

调试配置保存在 `.vscode/launch.json`：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Launch Program",
      "program": "${file}"
    }
  ]
}
```

## 调试面板

| 功能 | 说明 |
|------|------|
| 变量（Variables） | 查看/修改变量 |
| 监视（Watch） | 持续监视表达式 |
| 调用堆栈（Call Stack） | 查看调用链 |
| 断点面板 | 管理所有断点 |
| 调试控制台 | 交互式求值 |
