# 01 VS Code 导论

## 什么是 VS Code

Visual Studio Code（VS Code）是微软出品的免费、开源、跨平台代码编辑器，基于 Electron 构建，凭借 IntelliSense、扩展生态、远程开发与 GitHub Copilot 成为全球最常用的开发环境（市场份额约 65–75%）。

## 核心特性

| 特性 | 说明 |
|------|------|
| 轻量快速 | Electron 编辑器，启动快、跨平台 |
| IntelliSense | 智能补全、类型提示、参数提示 |
| 扩展生态 | 数万扩展（30k–60k） |
| 远程开发 | SSH/WSL/容器/Codespaces |
| AI 原生 | GitHub Copilot、Agent Mode、MCP |
| 内置工具 | Git、集成终端、调试器、Jupyter |

## 历史（2015 → 2026）

| 时间 | 事件 |
|------|------|
| 2015-04 | VS Code 首发（微软 Build 大会） |
| 2016 | 发布 1.0，扩展市场开放 |
| 2019 | Remote Development 发布（SSH/容器/WSL） |
| 2021 | GitHub Copilot 首发（VS Code 为主阵地） |
| 2023+ | Copilot Chat、Agent Mode、MCP 持续增强 |
| 2026-07 | **VS Code 1.129**（Agent Host、Agents 窗口、Modern UI） |

## 与 Visual Studio 的区别

| 工具 | 定位 |
|------|------|
| **VS Code** | 轻量代码编辑器，跨平台，扩展驱动 |
| **Visual Studio** | 重量级 IDE，Windows 为主，企业级 |

## 开源与替代

| 版本 | 说明 |
|------|------|
| VS Code | 官方版（含遥测） |
| VSCodium | 无遥测的开源构建版 |
| Cursor / Windsurf | 基于 VS Code 的 AI 编辑器分支 |
