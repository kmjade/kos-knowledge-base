# 08 AI 与 Copilot

## GitHub Copilot

深度集成的 AI 编程助手：

| 能力 | 说明 |
|------|------|
| 行内补全 | 实时代码建议 |
| Copilot Chat | 对话问答、解释代码 |
| 多文件编辑 | Edit Mode 跨文件修改 |
| Agent Mode | 自主执行任务 |
| Copilot Vision | 图像/PDF 附件（1.128 起 GA） |

## Agent 模式（2026 强化）

| 功能 | 说明 |
|------|------|
| Agent Host | 独立进程运行 Copilot/Claude/Codex 代理（1.129） |
| Agents 窗口 | 编辑器 + 详情合并面板 |
| 会话同步 | 跨窗口共享会话（1.123） |
| 1M 上下文 | 超大上下文窗口（1.123） |
| BYOK 模型 | 自带密钥接入自定义模型 |

## MCP 集成

支持 Model Context Protocol，让 AI 代理访问外部工具与数据源。
