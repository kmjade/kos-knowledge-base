# 004.4 VS Code

> Visual Studio Code（VS Code）是微软出品的免费开源代码编辑器，基于 Electron，跨平台，凭借 IntelliSense、扩展生态、远程开发与 GitHub Copilot 成为全球最常用的开发环境。
