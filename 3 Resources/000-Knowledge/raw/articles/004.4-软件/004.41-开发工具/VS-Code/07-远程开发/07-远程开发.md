# 07 远程开发

## Remote Development

VS Code 的远程开发让开发者像操作本地文件一样，在远程服务器、Linux 环境或容器中工作。

| 方案 | 说明 |
|------|------|
| **Remote - SSH** | 通过 SSH 连接远程服务器 |
| **Remote - WSL** | 在 Windows Subsystem for Linux 中开发 |
| **Dev Containers** | 在 Docker 容器中开发 |
| **GitHub Codespaces** | 云端开发环境 |

## 优势

| 优势 | 说明 |
|------|------|
| 一致环境 | 消除「在我机器上能跑」问题 |
| GPU/算力 | 使用远程高性能机器 |
| 团队标准化 | 统一开发环境 |

## 使用

```
1. 安装 Remote - SSH 扩展
2. 命令面板 → Remote-SSH: Connect to Host
3. 输入 ssh user@host
4. 打开远程文件夹 → 像本地一样开发
```

## Dev Containers

- `.devcontainer/` 目录定义容器环境（Dockerfile + devcontainer.json）
- 团队成员打开项目即获得一致环境
