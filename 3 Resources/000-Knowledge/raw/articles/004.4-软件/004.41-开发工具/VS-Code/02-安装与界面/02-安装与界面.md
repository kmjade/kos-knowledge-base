# 02 安装与界面

## 安装方式

| 方式 | 说明 |
|------|------|
| 官网安装包 | Windows/macOS/Linux |
| 包管理器 | `scoop` / `brew` / `choco` / `snap` |
| 浏览器版 | vscode.dev（无需安装） |
| VSCodium | 无遥测开源版 |

## 界面组成

| 区域 | 功能 |
|------|------|
| 活动栏（Activity Bar） | 左侧图标切换视图 |
| 侧边栏（Side Bar） | 资源管理器、搜索、Git、扩展 |
| 编辑器区 | 中央，编辑文件 |
| 面板（Panel） | 底部：终端、问题、输出 |
| 状态栏 | 底部：语言、分支、行列 |

## 命令面板

`Ctrl/Cmd+Shift+P` 打开命令面板，是 VS Code 的「万能入口」——所有操作都能从这里触发。

## 设置（Settings）

| 层级 | 说明 |
|------|------|
| 用户设置 | 全局（`settings.json`） |
| 工作区设置 | 项目级 |
| 文件夹设置 | 多根工作区 |

```json
{
  "editor.fontSize": 14,
  "editor.formatOnSave": true,
  "files.autoSave": "afterDelay"
}
```

## 工作区（Workspace）

| 类型 | 说明 |
|------|------|
| 单文件夹 | 打开一个文件夹 |
| 多根工作区 | `.code-workspace` 文件管理多个根 |
| 无工作区 | 打开单文件 |

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+` `（反引号）` | 切换终端 |
| `Ctrl+B` | 切换侧边栏 |
