# 设置 Settings

## 定义

VS Code 通过 `settings.json` 配置编辑器行为，支持用户级、工作区级与文件夹级三层设置。

## 层级

| 层级 | 说明 |
|------|------|
| 用户 | 全局 |
| 工作区 | 项目级 |
| 文件夹 | 多根工作区 |
