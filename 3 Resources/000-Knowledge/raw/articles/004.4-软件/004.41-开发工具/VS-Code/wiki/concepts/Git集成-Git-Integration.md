# Git 集成 Git Integration

## 定义

VS Code 内置 Git 支持，提供暂存、提交、分支、差异对比与冲突解决。

## 能力

| 能力 | 说明 |
|------|------|
| 暂存/提交 | 源代码管理面板 |
| 分支 | 创建/切换/合并 |
| 冲突 | 三方合并编辑器 |
