# Copilot

## 定义

GitHub Copilot 是深度集成于 VS Code 的 AI 编程助手，提供行内补全、对话、多文件编辑与 Agent 模式。

## 能力

| 能力 | 说明 |
|------|------|
| 行内补全 | 实时建议 |
| Copilot Chat | 对话问答 |
| Agent Mode | 自主执行任务 |
| 多模型 | GPT/Claude/Gemini |
