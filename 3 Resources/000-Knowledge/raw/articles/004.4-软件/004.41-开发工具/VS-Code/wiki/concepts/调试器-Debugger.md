# 调试器 Debugger

## 定义

VS Code 内置调试器，通过调试扩展支持各语言，提供断点、步进、变量监视与调试控制台。

## 能力

| 能力 | 说明 |
|------|------|
| 断点 | 行/条件/日志/异常断点 |
| 步进 | 跳过/进入/跳出 |
| 配置 | launch.json |
