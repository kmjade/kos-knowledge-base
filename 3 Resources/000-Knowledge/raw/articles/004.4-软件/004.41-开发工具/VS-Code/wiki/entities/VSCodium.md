# VSCodium

VS Code 的无遥测开源构建版，功能相同但移除微软遥测与品牌标记。

## 关键信息

| 参数 | 说明 |
|------|------|
| 类型 | 开源构建版 |
| 差异 | 无遥测、无品牌标记 |
| 适用 | 注重隐私的用户 |
