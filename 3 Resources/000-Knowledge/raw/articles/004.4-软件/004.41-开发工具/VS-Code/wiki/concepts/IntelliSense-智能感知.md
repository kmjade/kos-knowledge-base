# IntelliSense 智能感知

## 定义

IntelliSense 是 VS Code 的智能补全引擎，提供代码补全、参数提示、快速信息与转到定义。

## 能力

| 能力 | 说明 |
|------|------|
| 代码补全 | Ctrl+Space |
| 参数提示 | 函数签名 |
| 快速信息 | 悬停文档 |
| 转到定义 | F12 |
