# 工作区 Workspace

## 定义

工作区是 VS Code 的项目容器，分单文件夹与多根工作区（`.code-workspace`）。

## 类型

| 类型 | 说明 |
|------|------|
| 单文件夹 | 打开一个文件夹 |
| 多根工作区 | 管理多个根目录 |
| 无工作区 | 打开单文件 |
