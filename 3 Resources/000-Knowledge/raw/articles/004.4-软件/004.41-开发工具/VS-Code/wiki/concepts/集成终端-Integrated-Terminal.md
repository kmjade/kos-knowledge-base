# 集成终端 Integrated Terminal

## 定义

VS Code 内置终端，在编辑器内直接运行 shell，支持多终端、分屏与命令执行。

## 特点

| 特点 | 说明 |
|------|------|
| 多终端 | 并排多个 shell |
| 内嵌 | 不用切换窗口 |
| 快捷键 | Ctrl+` 切换 |
