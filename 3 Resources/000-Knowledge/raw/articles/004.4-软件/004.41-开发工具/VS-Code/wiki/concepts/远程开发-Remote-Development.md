# 远程开发 Remote Development

## 定义

VS Code 的远程开发让开发者像操作本地文件一样，在远程服务器、WSL 或容器中工作。

## 方案

| 方案 | 说明 |
|------|------|
| Remote - SSH | 连接远程服务器 |
| Remote - WSL | Windows Linux 子系统 |
| Dev Containers | Docker 容器 |
| Codespaces | 云端环境 |
