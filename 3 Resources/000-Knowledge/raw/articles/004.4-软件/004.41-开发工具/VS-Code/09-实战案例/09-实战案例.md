# 09 实战案例

## 案例总览

| 案例 | 难度 | 覆盖 |
|------|:----:|------|
| 项目配置 | ⭐ | 工作区、设置、扩展 |
| 调试实战 | ⭐⭐ | 断点、调试器 |
| 远程开发 | ⭐⭐ | Remote SSH、容器 |
| AI 协作 | ⭐⭐ | Copilot、Agent |

## 案例一：项目配置

```
1. 打开项目文件夹（File → Open Folder）
2. 安装语言扩展（Python/C++ 等）
3. 配置 settings.json（格式化、自动保存）
4. 配置 .vscode/extensions.json（团队推荐扩展）
5. 配置 launch.json（调试配置）
```

**要点**：工作区设置、扩展推荐、调试配置。

## 案例二：调试实战

```
1. 打开源代码 → F9 在可疑行打断点
2. F5 启动调试
3. F10/F11 单步执行，观察变量面板
4. 条件断点：右键断点 → Edit Breakpoint → 输入条件
5. 日志点：不暂停只打印变量
6. 定位 bug → 修复 → 重启调试验证
```

**要点**：断点、条件断点、日志点、变量监视。

## 案例三：远程开发

```
1. 安装 Remote - SSH 扩展
2. 命令面板 → Connect to Host
3. ssh user@remote-server
4. 打开远程项目文件夹
5. 像本地一样编辑/调试
```

**要点**：远程环境、GPU 访问、团队一致环境。

## 案例四：AI 协作

```
1. 安装 GitHub Copilot + Copilot Chat
2. 写注释描述需求 → Tab 接受补全
3. 选中代码 → Copilot Chat 解释/重构
4. Agent Mode 让代理自动完成任务
5. 用 "!" 前缀让聊天直接执行终端命令（1.129）
```

**要点**：补全、对话、Agent 模式、终端命令。
