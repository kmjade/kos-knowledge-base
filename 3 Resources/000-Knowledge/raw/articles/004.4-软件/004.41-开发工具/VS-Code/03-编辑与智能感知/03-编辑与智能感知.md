# 03 编辑与智能感知

## IntelliSense

智能感知是 VS Code 的智能补全，提供类型信息、函数定义、参数提示与内联文档。

| 能力 | 说明 |
|------|------|
| 代码补全 | `Ctrl+Space` 触发 |
| 参数提示 | 函数签名 |
| 快速信息 | 悬停查看定义/文档 |
| 转到定义 | `F12` |

> 对 TypeScript/JavaScript 支持最强，Python/Java/Go/C++ 等通过扩展获得。

## 导航

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+P` | 快速打开文件 |
| `F12` | 转到定义 |
| `Shift+F12` | 查找所有引用 |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+Shift+O` | 跳转到符号 |

## 重构

| 操作 | 说明 |
|------|------|
| 重命名符号 | `F2` |
| 提取函数/变量 | `Ctrl+.`（快速修复） |
| 代码折叠 | `Ctrl+Shift+[` / `]` |

## 多光标与编辑

| 操作 | 快捷键 |
|------|--------|
| 多光标 | `Alt+点击` |
| 选中所有相同 | `Ctrl+Shift+L` |
| 列选择 | `Shift+Alt+拖拽` |

## 格式化

| 操作 | 快捷键 |
|------|--------|
| 格式化文档 | `Shift+Alt+F` |
| 保存时格式化 | `editor.formatOnSave` |
