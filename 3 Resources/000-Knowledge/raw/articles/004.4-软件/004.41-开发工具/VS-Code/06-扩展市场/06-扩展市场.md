# 06 扩展市场

## 扩展（Extensions）

扩展是 VS Code 的核心竞争力——数万扩展覆盖语言、框架、主题、Linter、调试器与工作流。

- 打开：活动栏扩展图标，或 `Ctrl+Shift+X`
- 搜索、安装、禁用、卸载扩展

## 常用扩展

| 扩展 | 用途 |
|------|------|
| Python / Pylance | Python 语言支持 |
| C/C++ / CMake Tools | C/C++ 开发 |
| Java Extension Pack | Java 开发 |
| ESLint / Prettier | 代码检查/格式化 |
| Live Share | 实时协作 |
| Remote - SSH / WSL / Containers | 远程开发 |
| GitHub Copilot / Chat | AI 编程 |
| Docker | 容器管理 |
| Jupyter | 笔记本支持 |

## 扩展管理建议

| 建议 | 说明 |
|------|------|
| 按需安装 | 避免堆太多拖慢启动 |
| 工作区推荐 | `.vscode/extensions.json` 推荐团队扩展 |
| 配置同步 | 设置同步（Settings Sync）跨设备 |

## 主题（Themes）

| 类型 | 说明 |
|------|------|
| 颜色主题 | 编辑器配色 |
| 图标主题 | 文件图标 |
| 产品主题 | 整体界面 |
