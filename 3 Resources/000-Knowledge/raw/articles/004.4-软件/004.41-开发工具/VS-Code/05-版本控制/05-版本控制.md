# 05 版本控制

## Git 集成

VS Code 内置完整的 Git 支持，无需安装额外扩展即可进行日常操作。

| 操作 | 说明 |
|------|------|
| 暂存/提交 | 源代码管理面板 |
| 提交历史 | 查看 log |
| 分支管理 | 创建/切换/合并 |
| 差异对比 | 内联 diff 视图 |
| 冲突解决 | 三方合并编辑器 |

## 源代码管理面板

| 元素 | 说明 |
|------|------|
| 更改（Changes） | 已修改未暂存 |
| 暂存（Staged） | 已暂存 |
| 提交信息 | 输入 commit message |
| 分支状态 | 当前分支、同步状态 |

## 常用操作

| 操作 | 说明 |
|------|------|
| 克隆仓库 | 欢迎页 Clone Repository |
| 提交 | 面板输入信息 → 勾选提交 |
| 推送/拉取 | 状态栏同步按钮 |
| 解决冲突 | 点击冲突文件 → 选择版本 |
