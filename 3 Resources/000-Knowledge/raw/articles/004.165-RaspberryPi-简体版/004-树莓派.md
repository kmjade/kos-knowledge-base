# 004.165 树莓派 Raspberry Pi

> 树莓派（Raspberry Pi）是全球最畅销的单板计算机（Single Board Computer, SBC），由英国树莓派基金会推出，累计出货量超过 6,000 万台，横跨教育、创客、边缘计算与工业嵌入式等场景。
