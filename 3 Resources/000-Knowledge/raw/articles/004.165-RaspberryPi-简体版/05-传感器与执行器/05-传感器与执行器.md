# 05 传感器与执行器

## 温度与湿度传感器

### DHT22（AM2302）— 数字温湿度

| 参数 | 范围 | 精度 |
|------|------|:---:|
| 温度 | -40°C ~ 80°C | ±0.5°C |
| 湿度 | 0% ~ 100% RH | ±2% RH |
| 通信 | 单线（One-wire 协议风格） | — |
| 采样率 | 0.5 Hz（每 2 秒） | — |

```python
# 使用 adafruit-circuitpython-dht 库
import adafruit_dht
import board
dht = adafruit_dht.DHT22(board.D4)  # GPIO 4
temp = dht.temperature  # °C
hum = dht.humidity      # %
```

> DHT22 需要在 DATA 线接 3.3V 之间加 4.7kΩ–10kΩ pull-up 电阻。

### BME280 — 精密温湿压

| 参数 | 范围 | 精度 |
|------|------|:---:|
| 温度 | -40°C ~ 85°C | ±0.5°C |
| 湿度 | 0% ~ 100% RH | ±3% |
| 气压 | 300 ~ 1100 hPa | ±1 hPa |
| 通信 | I²C（0x76/0x77）或 SPI | — |

```python
import board
import adafruit_bme280
i2c = board.I2C()
bme = adafruit_bme280.Adafruit_BME280_I2C(i2c, address=0x76)
print(f"{bme.temperature:.1f}°C, {bme.humidity:.1f}%, {bme.pressure:.1f}hPa")
```

### 温湿度传感器选型

| 传感器 | 价格 | 精度 | 通信 | 适用 |
|--------|:---:|:---:|------|------|
| DHT11 | $1 | ±2°C | One-wire | 入门 |
| DHT22 | $3 | ±0.5°C | One-wire | 一般 |
| BME280 | $5 | ±0.5°C/±1hPa | I²C/SPI | 气象站 |
| DS18B20 | $2 | ±0.5°C | 1-Wire | 多点测温 |

## 超声波测距 — HC-SR04

| 参数 | 规格 |
|------|------|
| 范围 | 2cm ~ 400cm |
| 精度 | ±3mm |
| 工作电压 | **5V**（需分压 Echo 脚） |
| 引脚 | VCC / Trig / Echo / GND |

```python
from gpiozero import DistanceSensor
# echo=24, trigger=23
sensor = DistanceSensor(echo=24, trigger=23, max_distance=4)
print(f"{sensor.distance * 100:.1f} cm")
```

> ⚠️ Echo 输出 5V，必须用分压电阻（1kΩ + 2kΩ）降至 3.3V 才能接到 Pi GPIO！

## 惯性测量单元 — MPU6050

| 参数 | 规格 |
|------|------|
| 陀螺仪 | ±250/500/1000/2000 °/s |
| 加速度计 | ±2/4/8/16g |
| 通信 | I²C（0x68） |
| 工作电压 | 3.3V–5V |

```python
from mpu6050 import mpu6050
sensor = mpu6050(0x68)  # I²C 地址
accel = sensor.get_accel_data()  # {'x':..., 'y':..., 'z':...}
gyro = sensor.get_gyro_data()
```

> MPU6050 原生 3.3V I²C，可直接连 Pi GPIO。适合姿态检测、平衡机器人。

## 继电器模块 Relay Module

| 类型 | 控制 | 负载 | 用途 |
|------|------|------|------|
| **5V 单路继电器** | GPIO LOW 触发 | AC 250V/10A | 家电控制 |
| **固态继电器 SSR** | 3-32V DC | AC 24-380V | 静音、频繁切换 |

```python
from gpiozero import OutputDevice
relay = OutputDevice(17, active_high=False)  # LOW 触发常见
relay.on()   # 继电器吸合
relay.off()  # 释放
```

> 继电器模块通常自带光耦隔离与续流二极管保护。驱动电流约 5-10mA，Pi GPIO 可直接驱动。

## 伺服电机 Servo Motor

| 型号 | 扭矩 | 角度 | 电压 | 用途 |
|------|:----:|:----:|:----:|------|
| **SG90** | 1.2 kg·cm | 0–180° | 4.8–6V | 小型机构 |
| **MG996R** | 10 kg·cm | 0–180° | 4.8–7.2V | 机器人关节 |

```python
from gpiozero import AngularServo
servo = AngularServo(18, min_pulse_width=0.5/1000, max_pulse_width=2.5/1000)
servo.angle = 0    # 0 度
servo.angle = 90   # 90 度
servo.angle = 180  # 180 度
```

> ⚠️ SG90 直接从 Pi 5V 脚取电可能造成压降。建议外接 5V/2A 独立电源，共地即可。

## LED 与 NeoPixel/WS2812

### 普通 LED

```python
from gpiozero import LED
led = LED(17)
led.on()
led.off()
# 需串联 220Ω–470Ω 限流电阻
```

### WS2812B（NeoPixel）可寻址 RGB LED

| 参数 | 规格 |
|------|------|
| 电压 | 5V（信号 3.3V 可接受） |
| 协议 | 单线归零码 |
| 串接 | 理论无限（每 LED ~60mA 全亮） |

```python
import board
import neopixel
pixels = neopixel.NeoPixel(board.D18, 8, brightness=0.5)  # 8 颗，GPIO 18
pixels[0] = (255, 0, 0)   # 红
pixels[1] = (0, 255, 0)   # 绿
pixels.fill((0, 0, 255))  # 全蓝
pixels.show()
```

> WS2812B 需要 5V 供电（独立电源），DAT 脚接 GPIO 18（PWM0），3.3V 逻辑通常可接受。若不可靠，加 74AHCT125 做电平转换。

## 传感器选型速查

| 场景 | 推荐传感器 | 通信 | 价格 |
|------|-----------|------|:---:|
| 室内温湿度 | BME280 | I²C | $5 |
| 室外/恶劣环境 | DHT22 | One-wire | $3 |
| 多点测温 | DS18B20 × N | 1-Wire 总线 | $2/pcs |
| 距离检测 | HC-SR04 / VL53L0X | GPIO / I²C | $2–$10 |
| 运动姿态 | MPU6050 / ICM-20948 | I²C | $3–$15 |
| 光线/颜色 | BH1750 / TCS34725 | I²C | $2–$8 |
| 人体感应 | HC-SR501（PIR） | GPIO（数字） | $2 |

## 接线要点

- **共地**：Pi 的 GND 必须与外部电路共地。
- **电平**：5V 传感器/执行器的数据线需电平转换。
- **供电**：大功率负载（舵机/电机/灯带）不要从 GPIO 取电，应外接独立电源。
