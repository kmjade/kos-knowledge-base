## SoC 规格

### BCM2712（Pi 5 / Pi 500 / CM5）

| 区块 | 规格 |
|------|------|
| **CPU** | 4× ARM Cortex-A76 @ 2.4 GHz（64-bit） |
| **GPU** | VideoCore VII @ 800 MHz，OpenGL ES 3.1，Vulkan 1.2 |
| **制程** | 16nm |
| **内存** | LPDDR4X-4267（2/4/8/16GB） |
| **PCIe** | PCIe 2.0 ×1（用于 NVMe / M.2 HAT） |
| **多媒体** | 4Kp60 HEVC 解码、双 HDMI 4Kp60 |
| **I/O 芯片** | RP1（自研南桥，负责 GPIO/USB/MIPI 等） |

### BCM2711（Pi 4B / Pi 400 / CM4）

| 区块 | 规格 |
|------|------|
| **CPU** | 4× ARM Cortex-A72 @ 1.8 GHz |
| **GPU** | VideoCore VI @ 500 MHz |
| **RAM** | LPDDR4-3200（2/4/8GB） |
| **多媒体** | 4Kp60 HEVC、双 micro HDMI 4Kp30 |

## 存储方案对比

| 方案 | 速度 | 容量 | 可靠性 | 适用场景 |
|------|:----:|:----:|:------:|----------|
| **microSD** | ~100 MB/s | 32–512GB | 中等 | 一般使用、原型开发 |
| **USB 3.0 SSD** | ~350 MB/s | 120GB–2TB | 高 | 桌面、NAS |
| **NVMe（Pi 5 HAT）** | ~500+ MB/s | 128GB–2TB | 最高 | 数据库、高频读写 |

> Pi 5 支持通过 M.2 HAT 连接 NVMe SSD（PCIe 2.0 ×1）。长期运行的服务器场景强烈建议使用。

## Compute Module 5（CM5）要点

- 与 CM4 相同机械尺寸（55 × 40 × 4.7mm），两个 100-pin 高密度连接器。
- RAM：2/4/8/16GB **LPDDR4-4267 ECC**；存储：0（Lite）/16/32/64GB eMMC。
- 可选认证无线模组（2.4/5GHz WiFi + BT5.0）、千兆以太网（IEEE 1588）。
- 1× PCIe Gen2 ×1、2× USB 3.0 + 1× USB 2.0、最多 30 GPIO、2× HDMI 4Kp60、2× 4-lane MIPI。
- 共 **32 种变体**；工作温度 -20～+85°C；生产保障至至少 **2036 年**。

## 电源需求

| 型号 | 推荐电源 | 最大电流 |
|------|----------|:-------:|
| Pi 5 | 5V 5A（25W）USB-PD | 5A |
| Pi 4B | 5V 3A（15W）USB-C | 3A |
| Pi Zero 2 W | 5V 2.5A Micro USB | 2.5A |

> Pi 5 需要 **5V/5A** 电源方能发挥完整性能（尤其 USB 与 GPIO 高负载时）。使用低于 3A 的电源会自动限流降频。

## 选型建议

| 需求 | 推荐 | 理由 |
|------|------|------|
| 入门学习 | Pi 5（4GB） | 性能充足、文档丰富 |
| 桌面替代 / 开发 | Pi 5（8/16GB）+ NVMe SSD | 流畅桌面体验 |
| 键盘一体机 | Pi 500（性价比）/ 500+（性能） | 即插即用 |
| IoT 轻量 | Pi Zero 2 W | 低功耗、小体积 |
| 服务器 / NAS | Pi 5（4GB+） | 稳定、省电 |
| 裸机控制 / 传感器 | Pico 2 / Pico 2 W | 实时、低功耗 |
| 工业量产 | CM5 / CM4 | 工业级、可定制底板 |
