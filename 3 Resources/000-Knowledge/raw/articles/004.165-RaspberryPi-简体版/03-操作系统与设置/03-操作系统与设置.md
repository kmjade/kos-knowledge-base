# 03 操作系统与设置

## Raspberry Pi OS

官方操作系统（原名 Raspbian），基于 **Debian** 定制，32-bit 与 64-bit 双版本。

### 版本演进（Debian 代号）

| 代号 | Debian 版本 | 时期 | 关键变化 |
|------|-------------|------|----------|
| Bullseye | Debian 11 | 2021–2023 | — |
| **Bookworm** | Debian 12 | 2023–2025 | Wayland 优先、Piwiz 引导 |
| **Trixie** | Debian 13 | 2025– | 更新的核心包、更长安全维护 |

- **Bookworm**（Debian 12）：2023 年发布，引入 Wayland-first 桌面。最终 Bookworm 版本发布于 2025-05-13（内核 6.12.25）。
- **Trixie**（Debian 13）：2025-08-09 发布，Raspberry Pi OS 对应版本 2025-10-01 上线。
- **最新稳定版**：Raspberry Pi OS **6.3**（2026-06-18），Linux **6.18 LTS** 内核、**LabWC** 合成器。

### 三种映像版本

| 版本 | 桌面环境 | 预装软件 | 映像大小 | 适用场景 |
|------|:-------:|----------|:-------:|----------|
| **Desktop（Full）** | PIXEL（Wayland） | 办公/教育/编程全套 | ~3GB | 桌面替代、教学 |
| **Desktop** | PIXEL（Wayland） | 基本工具 | ~2GB | 一般开发 |
| **Lite** | 无（纯 CLI） | 最小系统 | ~0.5GB | 服务器、嵌入式、headless |

## 可选操作系统

| OS | 特点 | 适合 |
|----|------|------|
| **Ubuntu Server/Desktop** | 完整 Ubuntu 生态、Snap | 熟悉 Ubuntu 的开发者 |
| **DietPi** | 极轻量（Debian-based） | 资源极度受限场景 |

## 安装：Raspberry Pi Imager

官方刷写工具（桌面版 / CLI `rpi-imager`）三步完成：

```
1. 选择设备（Raspberry Pi 5 / 4 / Zero 2W ...）
2. 选择系统（Raspberry Pi OS / Ubuntu / ...）
3. 选择存储介质（microSD / USB / NVMe）
```

**进阶设定（Ctrl+Shift+X）**：
- 设定 hostname（默认 `raspberrypi`）
- 启用 SSH（密码或 SSH key）
- 设定 WiFi SSID/密码（headless 必备）
- 设定用户名与密码
- 时区与键盘布局

> 使用 Imager 进阶设定可在刷写时一次性完成所有初始配置，无需开机后手动配置。

## 初始设置流程

### 方法一：有屏幕 + 键盘

```bash
# 开机后自动进入桌面/CLI
sudo raspi-config
```

### 方法二：Headless 无头设置（无屏幕）

```bash
# 1. 用 Imager 进阶设定写入 WiFi + SSH + user/password
# 2. 插入 microSD 开机，等待 2 分钟
# 3. 寻找 Pi 的 IP：
ping raspberrypi.local           # macOS/Linux
# 或用路由器 DHCP 列表查找
# 4. SSH 连接：
ssh pi@raspberrypi.local
# 5. 首次登录后立即更新：
sudo apt update && sudo apt full-upgrade -y
```

## raspi-config 常用设定

| 选项 | 功能 |
|------|------|
| System Options → Wireless LAN | 设定 WiFi |
| System Options → Boot/Auto Login | 开机模式（Desktop/CLI） |
| Interface Options → SSH | 启用/关闭 SSH |
| Interface Options → I2C / SPI | 启用通信协议 |
| Interface Options → Camera | 启用旧版 camera stack |
| Performance Options → Fan | 风扇 GPIO 与温度阈值 |
| Localisation Options | 时区、键盘、Locale |

## rpi-eeprom 固件管理

```bash
# 查看当前 bootloader 版本
sudo rpi-eeprom-update

# 更新至最新 stable 固件
sudo rpi-eeprom-update -a

# 设定 boot order（Pi 5 支持 NVMe 开机）
sudo rpi-eeprom-config --edit
# BOOT_ORDER=0xf416  → NVMe 优先，然后 SD，然后 USB

# 查看 config
vcgencmd bootloader_config
```

## 建议的首次设定

```bash
# 1. 更新系统
sudo apt update && sudo apt full-upgrade -y

# 2. 安装常用工具
sudo apt install -y git curl wget vim htop neofetch

# 3. 设定防火墙（可选）
sudo apt install -y ufw
sudo ufw allow ssh
sudo ufw enable

# 4. 启用必要的 interfaces
sudo raspi-config nonint do_i2c 0
sudo raspi-config nonint do_spi 0

# 5. 重启
sudo reboot
```

## 远程访问

| 方式 | 说明 |
|------|------|
| SSH | `ssh user@raspberrypi.local`，命令行远程 |
| VNC | 图形桌面远程（raspi-config 启用） |
| Raspberry Pi Connect | 官方基于 WebRTC 的远程访问，无需公网 IP |
