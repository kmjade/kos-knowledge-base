## 气象站 Weather Station

### 架构

```
BME280（I²C） → Python daemon → MQTT → InfluxDB → Grafana
```

### 步骤

```bash
# 1. 硬件接线
Pi 3.3V → BME280 VCC
Pi GND  → BME280 GND
Pi SDA  → BME280 SDA
Pi SCL  → BME280 SCL

# 2. 安装依赖
sudo apt install -y python3-pip influxdb grafana
pip3 install adafruit-circuitpython-bme280 paho-mqtt
```

```python
import time, json, board, adafruit_bme280
import paho.mqtt.client as mqtt

i2c = board.I2C()
bme = adafruit_bme280.Adafruit_BME280_I2C(i2c, address=0x77)
client = mqtt.Client()
client.connect("localhost", 1883)

while True:
    data = {
        "temperature": round(bme.temperature, 1),
        "humidity": round(bme.humidity, 1),
        "pressure": round(bme.pressure, 1)
    }
    client.publish("weather/station1", json.dumps(data))
    time.sleep(60)
```

```bash
# 3. Node-RED：MQTT in → InfluxDB out
# 4. Grafana：Data source → InfluxDB → Dashboard panels
```

## 智能家居中枢 Smart Home Hub

### 架构

```
Pi 5 + Home Assistant OS
├── Zigbee Coordinator（USB dongle: Sonoff ZBDongle-P）
├── MQTT Broker（内置）
├── Node-RED（add-on）
└── 设备整合
    ├── Zigbee: 门窗传感器、智能灯泡、插座
    ├── WiFi: ESPHome 自制传感器
    └── 蓝牙: BLE Tracker / 体温计
```

### 推荐硬件

| 组件 | 型号 | 价格 |
|------|------|:----:|
| 主机 | Pi 5（8GB）+ NVMe 128GB | $130 |
| Zigbee dongle | Sonoff ZBDongle-P（CC2652P） | $18 |
| UPS HAT | PiJuice / Geekworm X708 | $30 |

> 使用 Home Assistant OS 直接刷入，免去 Docker 配置复杂度。搭配 Tailscale 可在外网安全访问。

## 机器人大脑 Robot Brain

### 架构（以 UGV 小车为例）

```
上位机（树莓派）
├── ROS2 Humble
├── Nav2（路径规划）
├── SLAM（Cartographer / SLAM Toolbox）
├── 视觉：Camera Module 3 → YOLO 目标检测
└── 通信：UART/USB → STM32（下位机）

下位机（STM32）— 参见 004.16 嵌入式系统
├── 电机控制（PID）
├── 编码器读取（里程计）
├── IMU（MPU6050）
└── 电池监控
```

### 关键点

- Pi 5 通过 **UART** 与 STM32 通信（115200–921600 bps）
- Pi 处理**高层逻辑**：路径规划、视觉、地图
- STM32 处理**实时控制**：电机 PWM、编码器中断
- Camera Module 3 提供视觉输入，AI Kit（Hailo-8L）可加速 YOLO 推理

## NAS 网络附加存储

```bash
# OpenMediaVault（OMV）安装
# 基于 Debian，专为 NAS 设计的 Web GUI

# 方法一：OMV 官方映像（推荐）
# 从 omv-extras.org 下载 Raspberry Pi 映像 → 刷入

# 方法二：在 Raspberry Pi OS 上安装
curl -sSL https://github.com/OpenMediaVault-Plugin-Developers/installScript/raw/master/install | sudo bash

# 访问 http://<pi-ip>
# 默认账号：admin / openmediavault
```

### 存储配置建议

| 方案 | 硬盘 | RAID | 容量 | 适合 |
|------|------|:----:|:----:|------|
| 基本 | USB 3.0 外接 HDD | 无 | 1–4TB | 家庭备份 |
| 双盘镜像 | 2×USB HDD | RAID 1 | 镜像 50% | 数据安全 |
| NVMe | M.2 HAT + NVMe SSD | 无 | 128GB–2TB | 高速访问 |

> Pi 5 + NVMe SSD + USB HDD = 低成本、低功耗的家庭 NAS。功耗仅 5–10W。

## Pi-hole 广告拦截

```bash
# 一键安装
curl -sSL https://install.pi-hole.net | bash

# 管理后台 http://<pi-ip>/admin
# 设定路由器 DNS 指向 Pi 的 IP 即可全屋去广告
```

### Pi-hole 核心功能

| 功能 | 说明 |
|------|------|
| DNS 过滤 | 阻挡广告/跟踪域名（~150K 默认清单） |
| DHCP 服务器 | 可取代路由器 DHCP |
| 统计面板 | 查询次数、阻挡率、域名排行 |

> 搭建简单、资源消耗极低（Pi Zero 2W 即可），效果显著。

## RetroPie 复古游戏机

```bash
# 在 Raspberry Pi OS 上安装
sudo apt install -y git dialog
git clone --depth=1 https://github.com/RetroPie/RetroPie-Setup.git
cd RetroPie-Setup
sudo ./retropie_setup.sh

# 或直接刷入 RetroPie 映像
# 下载 https://retropie.org.uk/download/
```

### 支持平台

| 平台 | 模拟器 | 性能（Pi 5） |
|------|--------|:-----------:|
| NES / SNES | lr-nestopia / lr-snes9x | ✅ 完美 |
| PS1 | lr-pcsx-rearmed | ✅ 完美 60fps |
| PSP | PPSSPP | ✅ 大部分流畅 |
| Dreamcast | lr-flycast | ✅ 完美 |
| N64 | lr-mupen64plus | ✅ 流畅（Pi 5） |
| PS2 | AetherSX2 | ⚠️ 部分可玩（Pi 5） |

> Pi 5 CPU 性能（~2.4GHz Cortex-A76）已可流畅模拟大部分 Dreamcast/PSP 游戏。
