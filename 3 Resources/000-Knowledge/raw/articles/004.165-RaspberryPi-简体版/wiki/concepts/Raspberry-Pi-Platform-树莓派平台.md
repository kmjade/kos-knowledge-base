# Raspberry Pi Platform 树莓派平台

## 定义

树莓派平台是由英国树莓派基金会（Raspberry Pi Foundation）推出的开源硬件与软件生态，涵盖单板计算机（SBC）、微控制器（MCU）、嵌入式模组（Compute Module）与官方配件。累计出货量超过 6,000 万台，是全球最畅销的单板计算机。

## 产品线

| 产品线 | 代表型号 | 定位 |
|--------|----------|------|
| SBC 旗舰 | Pi 5 | 桌面、开发、AI |
| SBC 键盘一体 | Pi 500 / 500+ / 400 | 即开即用 |
| SBC 迷你 | Zero 2 W | 低功耗嵌入式 |
| MCU | Pico 2 / Pico 2 W | 实时控制、传感器 |
| 嵌入式 SoM | CM5 / CM4 | 工业量产 |
| 配件 | Camera / Touch Display / AI HAT+ | 视觉、显示、AI |

## 组织

- **Raspberry Pi Foundation**：慈善组织，专注教育。
- **Raspberry Pi Ltd**：商业子公司，负责硬件设计、生产与销售。
