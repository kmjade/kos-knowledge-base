# Raspberry Pi Zero 2 W

2021 年推出的迷你无线单板计算机，主打低功耗、小体积与低成本，适合嵌入式、便携与 IoT 节点。

## 核心规格

| 参数 | 规格 |
|------|------|
| SoC | RP3A0（封装集成） |
| CPU | 4× Cortex-A53 @ 1GHz |
| RAM | 512MB LPDDR2 |
| 存储 | microSD |
| 网络 | WiFi 4（802.11n）、BT 4.2 / BLE |
| 显示 | mini HDMI |
| USB | 1× micro USB OTG |
| GPIO | 40-pin（未焊接排针） |
| 尺寸 | 65 × 30 mm |
| 价格 | $15 |

## 定位

比 Pi 5 / Pi 4 显著更省电、更小，性能约为初代 Pi 的 5 倍。适合传感器采集节点、便携设备与低功耗服务器。
