# Raspberry Pi 400

2020 年推出的键盘一体机，把 Raspberry Pi 4 的硬件集成进紧凑键盘，开箱即用，是桌面一体化的先行者。

## 核心规格

| 参数 | 规格 |
|------|------|
| SoC | BCM2711 |
| CPU | 4× Cortex-A72 @ 1.8GHz |
| GPU | VideoCore VI |
| RAM | 4GB LPDDR4 |
| 存储 | microSD |
| 接口 | 2× micro HDMI、2× USB 3.0、1× USB 2.0、GbE、WiFi 5、BT 5.0、40-pin GPIO |
| 价格 | $70 |

## 定位

定位教育与学生入门，已被 Pi 500 系列接替。
