# Compute Module 5

以模块（SoM）形态提供 Raspberry Pi 5 级算力的嵌入式产品，面向工业与量产定制，2024-11 发布。

## 核心规格

| 参数 | 规格 |
|------|------|
| SoC | BCM2712 |
| CPU | 4× Cortex-A76 @ 2.4GHz |
| RAM | 2 / 4 / 8 / 16GB LPDDR4-4267 **ECC** |
| 存储 | 0（Lite）/ 16 / 32 / 64GB eMMC |
| 无线 | 可选认证模组（2.4/5GHz WiFi + BT 5.0 / BLE） |
| 网络 | 千兆以太网 PHY（IEEE 1588） |
| PCIe | 1× PCIe Gen2 ×1（5Gbps） |
| USB | 2× USB 3.0 + 1× USB 2.0 |
| GPIO | 最多 30 个（1.8V / 3.3V） |
| 视频 | 2× HDMI 2.0 4Kp60、2× 4-lane MIPI（DSI/CSI-2） |
| 解码 | 4Kp60 HEVC |
| 尺寸 | 55 × 40 × 4.7mm（与 CM4 机械兼容） |
| 工作温度 | -20～+85°C |
| 生产保障 | 至至少 2036 年 |

## 变体

共 **32 种**组合（无线/非无线 × RAM × eMMC）。CM5 Lite 不带 eMMC，由用户外接存储。

## 定位

用于需要 Pi 生态与 Linux 环境、但要求紧凑形态、ECC 内存、工业级温度与长期供应的量产产品。
