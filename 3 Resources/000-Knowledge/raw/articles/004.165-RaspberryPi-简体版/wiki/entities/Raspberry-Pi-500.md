# Raspberry Pi 500

把 Raspberry Pi 5 塞进键盘的一体式电脑，即插即用，延续 Pi 400 的形态但升级为 Pi 5 硬件。

## 型号对比

| 参数 | Pi 500 | Pi 500+ |
|------|--------|---------|
| 发布 | 2024-12 | 2025-09 |
| SoC | BCM2712 | BCM2712 |
| CPU | 4× Cortex-A76 @2.4GHz | 同左 |
| RAM | 8GB LPDDR4X | **16GB** LPDDR4X |
| 存储 | microSD | microSD + **256GB NVMe SSD** |
| 键盘 | 薄膜键盘 | **机械键盘**（Gateron KS-33 Blue、75%、可编程 RGB） |
| 接口 | 2× micro HDMI、2× USB 3.0、1× USB 2.0、GbE、WiFi 5、BT 5.0、40-pin GPIO | 同左 |
| 价格 | $90 | $200 |

## 定位

面向教育、办公、家庭桌面的一体化低成本电脑。Pi 500+ 进一步满足需要更大内存、本地高速存储与机械键盘手感的重度用户。
