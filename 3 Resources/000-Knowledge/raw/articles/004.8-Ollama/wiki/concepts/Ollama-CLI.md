# Ollama CLI

## 定义

Ollama CLI 是用户与本地模型交互的命令行入口，提供 `pull`、`run`、`list`、`show`、`rm`、`cp`、`create`、`serve`、`ps` 等命令，覆盖模型下载、运行、管理、定制全流程。
