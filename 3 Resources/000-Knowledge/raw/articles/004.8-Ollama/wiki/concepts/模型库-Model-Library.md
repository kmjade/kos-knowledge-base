# 模型库 Model Library

## 定义

模型库（Ollama Library）是官方维护的开源模型仓库（`ollama.com/library`），统一打包了 Llama、Qwen、DeepSeek、Mistral 等模型的多种量化版本，用户通过 `ollama pull` 一键下载。
