# Ollama API

## 定义

Ollama API 是运行在 `localhost:11434` 的 REST 服务，提供 `/api/generate`、`/api/chat`、`/api/embed` 等端点，并兼容 OpenAI 接口（`/v1`），是程序化调用本地模型的标准入口。
