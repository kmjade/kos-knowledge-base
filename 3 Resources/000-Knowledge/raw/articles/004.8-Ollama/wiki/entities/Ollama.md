# Ollama

## 定位

Ollama 是最流行的本地大语言模型运行工具（MIT 许可），提供 CLI + REST API + Modelfile，让开源 LLM 在本地 CPU/GPU 上私有化运行。

## 关键特征

- 一键 `ollama run` 运行 Llama/Qwen/DeepSeek 等模型
- 底层封装 llama.cpp，支持 GGUF 量化模型
- REST API（:11434）+ OpenAI 兼容接口
- 官方模型库 ollama.com/library
