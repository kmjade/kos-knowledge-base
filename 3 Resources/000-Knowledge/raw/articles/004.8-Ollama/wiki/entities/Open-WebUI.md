# Open WebUI

## 定位

Open WebUI 是 Ollama 生态最流行的自托管 Web 前端（Docker 部署），提供图形化对话、模型切换、角色管理、RAG 文档问答与多用户权限。

## 关键特征

- Docker 一键部署（ghcr.io/open-webui/open-webui）
- 接 Ollama 及 OpenAI 兼容后端
- 内置 RAG（文档上传 + 检索问答）
