# Ollama Inc.

## 定位

Ollama Inc. 是 2023 年成立于旧金山的公司，出品 Ollama 本地 LLM 运行时，愿景是「让大模型在本地运行变得简单」。

## 关键特征

- 出品 Ollama CLI / Server / Library
- 主打本地、私有、开源（MIT）
- 生态核心：Open WebUI（社区）
