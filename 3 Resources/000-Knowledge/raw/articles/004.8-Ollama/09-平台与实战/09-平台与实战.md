# 09 平台与实战

## Open WebUI

Open WebUI 是 Ollama 最流行的自托管 Web 前端（Docker 一键部署），提供：

- 图形化对话界面（多模型切换）
- 角色/系统提示管理
- RAG（文档上传 + 检索问答）
- 多用户与权限

```bash
docker run -d -p 3000:8080 \
  -v open-webui:/app/backend/data \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  ghcr.io/open-webui/open-webui:main
```

## 实战场景

| 场景 | 方案 |
|------|------|
| 私有知识问答 | Ollama + Open WebUI RAG |
| 编码助手 | Ollama + Continue（IDE 插件） |
| 本地 Agent | Ollama + LangChain/LangGraph |
| 批量文本处理 | Ollama API + 脚本 |
| 隐私敏感业务 | 完全离线私有化部署 |

## 端到端实战：私有 RAG 问答系统

1. **部署**：`docker` 起 Ollama + Open WebUI
2. **选模型**：`ollama pull qwen2.5:14b`（对话）+ `nomic-embed-text`（嵌入）
3. **灌文档**：Open WebUI 上传文档自动建索引
4. **问答**：界面提问，自动检索 + 生成

## 与编码 Agent 协同

Ollama 可作为本地模型后端，为 Continue、Cline 等 IDE Agent 提供私有推理，与 Claude Code / Codex 等云端 Agent 互补（云端负责强模型，本地负责敏感数据）。
