# 02 安装与快速入门

## 安装方式

| 平台 | 方式 | 命令 |
|------|------|------|
| macOS | 官方安装包 / Homebrew | `brew install ollama` |
| Linux | 官方脚本 | `curl -fsSL https://ollama.com/install.sh \| sh` |
| Windows | 官方安装包 / WSL2 | 下载 `.exe` 或 WSL 内安装 |
| Docker | 官方镜像 | `docker run -d -v ollama:/root/.ollama -p 11434:11434 ollama/ollama` |

## 首次运行

```bash
ollama run llama3.2          # 拉取并运行 Llama 3.2（3B）
ollama run qwen2.5:7b        # 运行通义千问 7B
ollama run deepseek-r1:7b    # 运行 DeepSeek-R1 7B
```

首次运行会自动下载模型（`.gguf` 文件）到 `~/.ollama/models/`。

## 基础命令

| 命令 | 作用 |
|------|------|
| `ollama pull <model>` | 下载模型 |
| `ollama run <model>` | 交互式对话 |
| `ollama list` | 列出已安装模型 |
| `ollama show <model>` | 查看模型信息/Modelfile |
| `ollama rm <model>` | 删除模型 |
| `ollama ps` | 查看已加载模型 |

## 对话提示

- 输入 `/bye` 退出对话
- 输入 `/?` 查看命令帮助
- 用 `/set` 调整会话参数（如 `temperature`）

## 验证安装

```bash
ollama --version          # 查看版本
ollama serve              # 手动启动服务（默认已后台运行）
curl http://localhost:11434/api/tags   # 验证 API 服务
```
