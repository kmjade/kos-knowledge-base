# 004.8 Ollama

> Ollama 是**最流行的本地大语言模型运行工具**（MIT 许可），由 Ollama Inc. 出品。以「一键拉取/运行开源模型 + REST API + Modelfile 定制」为核心，让 Llama / Qwen / DeepSeek / Mistral 等模型在本地 CPU/GPU 上私有化运行。数据更新至 2026-09。

## 核心问题

如何用「本地模型运行时 + Modelfile + API」这一套轻量范式，把开源大模型变成可在个人电脑上私有化、可编程、可嵌入应用的大模型底座？
