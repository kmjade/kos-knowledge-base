# 03 核心架构

## 架构总览

```
┌─────────────┐   CLI (ollama run/pull/...)
│  Ollama CLI │────────┐
└─────────────┘        │
┌─────────────┐        ▼
│  REST API   │──► ┌────────────┐   ┌──────────────┐
│ :11434      │    │  Ollama    │──►│  llama.cpp   │──► GPU/CPU
└─────────────┘    │   Server   │   │  (GGUF 推理) │
                   └────────────┘   └──────────────┘
                         │
                         ▼
              ┌──────────────────────┐
              │  ~/.ollama/models/   │  (模型存储 + 元数据)
              └──────────────────────┘
```

## 关键组件

| 组件 | 作用 |
|------|------|
| **Ollama CLI** | 用户命令行入口，交互式对话 |
| **Ollama Server** | 常驻后台服务，管理模型生命周期 |
| **llama.cpp** | 底层推理引擎，加载 GGUF 并执行 |
| **Model Registry** | 模型元数据 + 本地 manifest |

## GGUF 格式

GGUF（GPT-Generated Unified Format）是 llama.cpp 生态的模型文件格式，把模型权重、分词器、元数据打包成单一文件，支持多种量化精度。

| 量化 | 位宽 | 体积/质量权衡 |
|------|:--:|------|
| f16 | 16 bit | 无损，体积大 |
| q8_0 | 8 bit | 接近无损 |
| q4_K_M | 4 bit | 主流推荐，质量/体积平衡 |
| q4_0 | 4 bit | 更小，略降质量 |
| q2_K | 2 bit | 极小，质量明显下降 |

## 模型加载与驻留

- 模型按需加载，空闲一段时间后自动卸载释放显存（`OLLAMA_KEEP_ALIVE` 控制）
- `ollama ps` 可查看当前驻留模型及其占用

## 硬件后端

| 后端 | 平台 |
|------|------|
| CUDA | NVIDIA GPU |
| Metal | Apple Silicon / Intel Mac |
| ROCm | AMD GPU |
| CPU (AVX) | 无 GPU 回退 |
