# 04 模型管理

## 模型命名与标签

模型名遵循 `<namespace>/<model>:<tag>` 格式，`tag` 默认为 `latest`：

| 示例 | 说明 |
|------|------|
| `llama3.2` | 最新 Llama 3.2（默认 3B） |
| `llama3.2:1b` | 指定 1B 版本 |
| `qwen2.5:7b` | 通义千问 7B |
| `deepseek-r1:32b` | DeepSeek-R1 32B |

## 模型库（Ollama Library）

官方模型库在 `ollama.com/library`，涵盖：

| 模型 | 出品 | 代表规模 |
|------|------|----------|
| Llama | Meta | 1B–405B |
| Qwen | 阿里 | 0.5B–72B |
| DeepSeek | 深度求索 | 1.5B–671B |
| Mistral | Mistral AI | 7B–123B |
| Gemma | Google | 2B–27B |
| Phi | 微软 | 3.8B–14B |

## 管理命令

```bash
ollama pull qwen2.5:7b       # 下载
ollama cp qwen2.5:7b myqwen  # 复制/重命名
ollama push myqwen           # 推送到 ollama.com（需账号）
ollama rm qwen2.5:7b         # 删除
```

## 多模型对比选择

| 需求 | 推荐模型 |
|------|----------|
| 通用对话（小内存） | llama3.2 / qwen2.5:3b |
| 通用对话（均衡） | qwen2.5:7b / llama3.1:8b |
| 中文能力强 | qwen2.5 / deepseek-r1 |
| 推理/数学 | deepseek-r1 / qwq |
| 代码 | qwen2.5-coder / deepseek-coder |
| 多模态（视觉） | llava / qwen2.5-vl |

## 显存估算

7B 模型 q4 量化约需 4–5 GB 显存/内存；70B 约需 40 GB。可用 `ollama show <model>` 查看模型参数量与量化信息。
