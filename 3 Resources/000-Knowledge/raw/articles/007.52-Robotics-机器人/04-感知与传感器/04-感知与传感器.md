# 04 感知与传感器

## 感知模态

| 模态 | 传感器 | 用途 |
|------|--------|------|
| 视觉 | 相机（RGB/RGB-D/立体） | 目标识别、抓取 |
| 距离 | LiDAR / 超声 | 建图、避障 |
| 姿态 | IMU | 惯性导航 |
| 力觉 | 力/扭矩传感器 | 精密装配 |
| 触觉 | 指尖压力、电子皮肤 | 抓握反馈 |

## SLAM（同步定位与建图）

- 激光 SLAM（LiDAR）与视觉 SLAM（V-SLAM）
- 厘米级定位 + 毫米级操作（3D 视觉 + 激光 SLAM + 6 维力控）
- 多模态融合：RGB-D + LiDAR + 触觉统一到同一 3D 场景表示（3D 高斯泼溅/NeRF）

## 挑战

感知可靠性是瓶颈：99.9% 准确率仍意味着千分之一的误判，在安全关键场景不可接受。
