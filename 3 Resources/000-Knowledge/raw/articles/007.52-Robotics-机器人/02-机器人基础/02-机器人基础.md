# 02 机器人基础

## 系统组成

机器人 = **机构（本体）+ 驱动器 + 传感器 + 控制器**：

| 组成 | 说明 |
|------|------|
| 本体/机构 | 连杆、关节、结构 |
| 驱动器（Actuator） | 产生运动的执行元件 |
| 传感器 | 感知内部状态与外部环境 |
| 控制器 | 计算与控制核心 |

## 驱动器（Actuators）

| 类型 | 说明 |
|------|------|
| 电机（含减速器） | 谐波/RV 减速器 + 无刷电机，主流 |
| 直驱电机 | 无减速器，高扭矩密度 |
| 液压伺服 | 大负载（Atlas） |
| 腱驱动 | 仿生柔顺（1X NEO 的 Myofiber） |

> 驱动器是人形机器人成本核心（约 45%），目标扭矩密度 >200 Nm/kg、效率 >80%、单关节 <$2000。

## 传感器

| 类型 | 说明 |
|------|------|
| 编码器 | 关节角度/位置 |
| IMU | 姿态/加速度/角速度 |
| 力/扭矩传感器 | 6 轴力觉 |
| 触觉传感器 | 指尖压力（Figure 03 达 3g 精度） |
| 视觉/LiDAR | 环境感知 |

## 控制器

实时控制（MCU/DSP 固件，亚毫秒关节扭矩环）+ 上层计算（Linux + ROS2）。
