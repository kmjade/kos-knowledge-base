# 09 应用与实战

## 应用领域

| 领域 | 场景 |
|------|------|
| 制造业 | 焊接、装配、电池搬运 |
| 仓储物流 | AMR 分拣、搬运 |
| 医疗 | 手术机器人、康复 |
| 家庭服务 | 清洁、陪伴 |
| 能源/巡检 | 危险环境巡检 |
| 特种 | 救援、空间、军事 |

## 安全标准

| 标准 | 说明 |
|------|------|
| ISO 10218 | 工业机器人安全 |
| ISO/TS 15066 | 协作机器人力/压力限制 |
| EU AI Act | 人形专用规则预计 2027 |

安全架构：硬件急停 + 360° 感知 + 力/扭矩限制 + 碰撞预测 + <10ms 关节扭矩反馈。

## 实战案例

### 工业机械臂

KUKA/ABB 焊接 → 逆运动学 + 轨迹规划 → 力控精密装配。

### 移动机器人（AMR）

LiDAR SLAM 建图 → 路径规划 → 自主导航分拣。

### 人形机器人开发

仿真（Isaac Sim）训练 VLA → sim-to-real 迁移 → 真机部署（如 Atlas 进现代汽车工厂）。

### 学习路径建议

1. ROS2 + Gazebo 仿真入门
2. 运动学/动力学基础
3. 感知（SLAM/视觉）+ 控制
4. 具身智能/VLA 前沿
