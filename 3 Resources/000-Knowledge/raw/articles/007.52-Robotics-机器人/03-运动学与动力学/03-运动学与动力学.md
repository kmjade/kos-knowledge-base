# 03 运动学与动力学

## 运动学（Kinematics）

| 概念 | 说明 |
|------|------|
| 正向运动学（FK） | 关节角度 → 末端位姿 |
| 逆向运动学（IK） | 末端位姿 → 关节角度（多解） |
| 工作空间 | 末端可达范围 |
| DH 参数 | Denavit–Hartenberg 建模约定 |

## 动力学（Dynamics）

| 概念 | 说明 |
|------|------|
| 正向动力学 | 力/力矩 → 运动 |
| 逆向动力学 | 期望运动 → 所需力/力矩（用于控制） |
| 拉格朗日/牛顿-欧拉 | 动力学建模方法 |

## 应用

- 轨迹规划、力控、平衡控制
- 人形/足式机器人全身动力学（MPC 实时求解）
