# 05 控制与规划

## 控制算法

| 算法 | 说明 |
|------|------|
| PID | 经典反馈控制 |
| 力控/阻抗控制 | 接触作业 |
| MPC（模型预测控制） | 实时全身动力学、足式平衡 |
| 强化学习（RL） | 斜坡/楼梯/外力扰动下的步态 |

## 路径与运动规划

| 规划 | 说明 |
|------|------|
| 路径规划 | A*、RRT、Dijkstra（全局） |
| 运动规划 | 关节空间/笛卡尔空间轨迹 |
| 避障 | 势场法、采样法 |

## 实时性

| 层级 | 延迟 |
|------|------|
| 关节扭矩环 | 亚毫秒（MCU/DSP 固件） |
| 足式姿态控制 | ~1ms 确定性 |
| 上层决策 | Linux PREEMPT_RT（数百微秒最坏延迟） |
