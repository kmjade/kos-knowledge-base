# 03-编程语言

> 人与计算机沟通的桥梁——范式、编译与类型系统。

## 编程范式

| 范式 | 核心 | 语言 |
|------|------|------|
| 命令式 | 指令序列 | C |
| 面向对象 | 对象、类、继承 | Java、C++ |
| 函数式 | 纯函数、不可变 | Haskell、Lisp |
| 逻辑式 | 规则推导 | Prolog |
| 声明式 | 描述目标 | SQL |

## 编译 vs 解释

| 方式 | 说明 | 代表 |
|------|------|------|
| 编译 | 源码 → 机器码 | C、Go、Rust |
| 解释 | 逐行执行 | Python、JS |
| JIT | 运行时编译 | Java、C# |

## 编译过程

```
词法分析 → 语法分析 → 语义分析 → 优化 → 代码生成
```

## 类型系统

| 类型 | 特征 | 语言 |
|------|------|------|
| 静态 | 编译期检查 | Java、Rust |
| 动态 | 运行期检查 | Python、JS |
| 强类型 | 严格转换 | Python、Rust |
| 弱类型 | 隐式转换 | JS、C |

## 重要语言

- **系统**：C、C++、Rust、Go
- **应用**：Java、C#、Python
- **脚本**：Python、JS、Bash
- **AI/数据**：Python（事实标准）
