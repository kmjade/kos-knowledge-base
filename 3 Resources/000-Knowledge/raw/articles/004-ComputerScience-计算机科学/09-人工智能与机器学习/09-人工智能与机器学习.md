# 09-人工智能与机器学习

> 让机器学会智能——AI 是计算机科学的最高成就之一。

> 详细内容见姊妹库 [[3 Resources/000-Knowledge/raw/articles/004-人工智能/README|004-人工智能]]。

## 机器学习类型

| 类型 | 特征 | 应用 |
|------|------|------|
| 监督学习 | 有标签 | 分类、回归 |
| 无监督学习 | 无标签 | 聚类、降维 |
| 强化学习 | 奖惩信号 | 游戏、机器人 |
| 自监督学习 | 自身信号 | 预训练（LLM） |

## 核心算法

| 算法 | 用途 |
|------|------|
| 线性/逻辑回归 | 基础预测 |
| 决策树/随机森林 | 分类、特征 |
| SVM | 分类 |
| 神经网络 | 复杂模式 |
| 梯度提升 | 表格数据 |

## 深度学习

- 神经网络多层堆叠
- CNN（图像）、RNN/Transformer（序列）
- 反向传播 + 梯度下降
- GPU 大规模训练

## 大语言模型 (LLM)

| 概念 | 说明 |
|------|------|
| Transformer | 注意力机制架构 |
| 预训练 | 海量文本自监督 |
| 微调 | 任务适配 |
| 提示工程 | 引导输出 |
| RAG | 检索增强生成 |
| Agent | 工具调用、自主行动 |

## AI 伦理

- 偏见、公平、透明
- 安全对齐、可控性
- 隐私、版权
- 就业与社会影响
