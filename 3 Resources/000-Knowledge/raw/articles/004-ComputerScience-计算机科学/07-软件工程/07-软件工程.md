# 07-软件工程

> 系统地构建可靠软件——工程化方法与最佳实践。

## 开发流程

| 模型 | 特征 |
|------|------|
| 瀑布模型 | 线性阶段 |
| 敏捷 (Agile) | 迭代、响应变化 |
| Scrum | 冲刺、站会 |
| DevOps | 开发运维一体化 |
| CI/CD | 持续集成/交付 |

## 软件测试

| 层次 | 说明 |
|------|------|
| 单元测试 | 函数/类 |
| 集成测试 | 模块组合 |
| 系统测试 | 整体 |
| 验收测试 | 用户确认 |

- 测试驱动开发 (TDD)
- 自动化测试、覆盖率

## 软件架构

| 模式 | 特征 |
|------|------|
| 单体 | 单一应用 |
| 微服务 | 独立服务 |
| 分层 | 表现-业务-数据 |
| 事件驱动 | 消息解耦 |

## 设计模式

- 创建型：单例、工厂
- 结构型：适配器、代理
- 行为型：观察者、策略

## 工程实践

- 版本控制（Git）、代码审查
- 重构、技术债管理
- 文档、可维护性
- 安全（OWASP Top 10）
