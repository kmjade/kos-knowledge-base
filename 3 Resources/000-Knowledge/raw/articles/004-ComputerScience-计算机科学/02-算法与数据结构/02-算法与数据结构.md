# 02-算法与数据结构

> 程序 = 数据结构 + 算法——计算机科学的核心。

## 复杂度分析

| 符号 | 含义 |
|------|------|
| O(1) | 常数 |
| O(log n) | 对数（二分查找） |
| O(n) | 线性 |
| O(n log n) | 线性对数（归并排序） |
| O(n²) | 平方（冒泡排序） |
| O(2ⁿ) | 指数 |

## 核心数据结构

| 结构 | 操作复杂度 | 应用 |
|------|------|------|
| 数组 | O(1) 访问 | 连续存储 |
| 链表 | O(1) 插入 | 动态结构 |
| 栈/队列 | O(1) | 递归、调度 |
| 哈希表 | O(1) 平均 | 查找、缓存 |
| 树 | O(log n) | 层级、搜索 |
| 图 | — | 网络、关系 |

## 排序算法

| 算法 | 平均复杂度 | 稳定性 |
|------|:--:|:--:|
| 冒泡 | O(n²) | 稳定 |
| 快速排序 | O(n log n) | 不稳定 |
| 归并排序 | O(n log n) | 稳定 |
| 堆排序 | O(n log n) | 不稳定 |

## 搜索与遍历

- 二分查找（有序数组）
- 深度优先 DFS（栈）
- 广度优先 BFS（队列）
- 图：最短路径（Dijkstra）、最小生成树

## 算法设计范式

- 分治、贪心、动态规划、回溯
- 动态规划：最优子结构 + 重叠子问题
