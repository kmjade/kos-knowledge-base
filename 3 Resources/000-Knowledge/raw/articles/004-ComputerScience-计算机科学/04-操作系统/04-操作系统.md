# 04-操作系统

> 计算机的「管家」——管理硬件与软件资源。

## 核心功能

| 功能 | 说明 |
|------|------|
| 进程管理 | 创建、调度、通信 |
| 内存管理 | 分配、虚拟内存 |
| 文件系统 | 存储组织 |
| 设备管理 | I/O 控制 |
| 用户接口 | 命令、图形界面 |

## 进程与线程

| 概念 | 说明 |
|------|------|
| 进程 | 运行中的程序（独立资源） |
| 线程 | 进程内的执行单元（共享内存） |
| 调度 | CPU 分配（先来先服务、时间片、优先级） |
| 死锁 | 循环等待资源 |

## 内存管理

- **虚拟内存**：逻辑地址 → 物理地址
- 分页、分段
- 页面置换（LRU、FIFO）

## 文件系统

| 系统 | 平台 |
|------|------|
| NTFS | Windows |
| ext4 | Linux |
| APFS | macOS |

- 目录、索引、权限

## 主流操作系统

| OS | 特点 |
|------|------|
| Linux | 开源、服务器、开发者 |
| Windows | 桌面主流 |
| macOS | Unix 内核、开发者友好 |
| Android/iOS | 移动端 |
