# 01-计算机科学概述

> 关于计算的科学——从图灵机到大语言模型。

## 计算的本质

- **图灵机**：理论计算模型，能模拟任何算法
- **丘奇-图灵论题**：可计算 = 图灵可计算
- **可计算性**：停机问题不可判定

## 学科体系

| 领域 | 核心 |
|------|------|
| 理论计算机科学 | 算法、复杂度、可计算性 |
| 计算机系统 | 体系结构、操作系统、网络 |
| 软件 | 编程语言、软件工程、数据库 |
| 应用 | AI、图形学、人机交互 |

## 计算机简史

| 年代 | 里程碑 |
|------|------|
| 1940s | ENIAC、冯·诺依曼架构 |
| 1950s | 高级语言（FORTRAN）、晶体管 |
| 1970s | 集成电路、Unix、C 语言 |
| 1980s | 个人电脑、互联网雏形 |
| 1990s | 万维网、开源运动 |
| 2000s | 移动、云计算 |
| 2010s- | 深度学习、AI 爆发 |

## 冯·诺依曼架构

```
输入 → 控制器/运算器 (CPU) ↔ 存储器 ↔ 输出
```

- 程序存储、顺序执行
- 现代计算机仍遵循此架构

## 计算机科学 vs 编程

| 计算机科学 | 编程 |
|------|------|
| 理论、原理 | 实践、实现 |
| 算法、复杂度 | 语言、工具 |
| 为什么 | 怎么做 |
