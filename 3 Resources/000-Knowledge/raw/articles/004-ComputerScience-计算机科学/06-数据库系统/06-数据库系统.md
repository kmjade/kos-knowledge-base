# 06-数据库系统

> 数据的组织、存储与检索——信息系统的核心。

## 数据库类型

| 类型 | 特征 | 代表 |
|------|------|------|
| 关系型 (SQL) | 表、关系、事务 | MySQL、PostgreSQL |
| 文档型 | JSON、灵活 | MongoDB |
| 键值型 | 简单快速 | Redis |
| 图型 | 节点关系 | Neo4j |
| 时序 | 时间序列 | InfluxDB |
| 向量 | 高维向量 | 向量数据库（AI 检索） |

## 关系模型

- 表（关系）、行（元组）、列（属性）
- 主键、外键、索引
- 规范化（1NF→3NF）

## SQL

```sql
SELECT columns FROM table
WHERE condition
GROUP BY column
ORDER BY column;
```

- CRUD：INSERT、SELECT、UPDATE、DELETE
- JOIN、聚合、子查询

## ACID 事务

| 属性 | 含义 |
|------|------|
| 原子性 | 全做或全不做 |
| 一致性 | 状态一致 |
| 隔离性 | 并发互不干扰 |
| 持久性 | 提交后不丢失 |

## 索引与性能

- B+ 树索引、哈希索引
- 查询优化、缓存
- 分库分表、读写分离

## 向量数据库（AI 时代）

- 高维向量相似度检索
- RAG 检索增强生成的基础设施
