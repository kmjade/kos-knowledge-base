# 05-计算机网络

> 连接世界的技术——分层协议与数据传输。

## OSI 七层 / TCP-IP 四层

| 层 | 功能 | 协议 |
|------|------|------|
| 应用层 | 应用服务 | HTTP、DNS、SMTP |
| 传输层 | 端到端通信 | TCP、UDP |
| 网络层 | 路由寻址 | IP |
| 链路层 | 相邻节点 | Ethernet、WiFi |

## TCP vs UDP

| 特性 | TCP | UDP |
|------|------|------|
| 连接 | 面向连接 | 无连接 |
| 可靠 | 可靠（重传） | 不可靠 |
| 速度 | 慢 | 快 |
| 应用 | 网页、文件 | 视频、游戏 |

## HTTP/HTTPS

- HTTP：无状态请求-响应协议
- HTTPS：TLS 加密
- 方法：GET、POST、PUT、DELETE
- 状态码：200、301、404、500

## IP 与 DNS

- IPv4 → IPv6
- DNS：域名 → IP 解析
- 子网、路由

## 网络安全

| 概念 | 说明 |
|------|------|
| 加密 | 对称（AES）、非对称（RSA） |
| 认证 | 密码、证书、OAuth |
| 防火墙 | 过滤流量 |
| 攻击 | DDoS、MITM、注入 |
