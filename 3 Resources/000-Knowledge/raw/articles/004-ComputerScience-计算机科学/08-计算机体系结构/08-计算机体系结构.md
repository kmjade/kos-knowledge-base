# 08-计算机体系结构

> 计算机硬件的设计与组织——从 CPU 到并行计算。

## 计算机组成

| 部件 | 功能 |
|------|------|
| CPU | 运算与控制 |
| 内存 | 主存（RAM） |
| 存储 | 硬盘、SSD |
| I/O | 输入输出 |
| 总线 | 数据通路 |

## CPU

- 运算器（ALU）、控制器、寄存器
- 流水线、超标量、乱序执行
- 指令集：CISC（x86）vs RISC（ARM）

## 存储层次

```
寄存器 → 缓存(L1/L2/L3) → 内存 → 存储(SSD/HDD)
  快小贵                →      慢大便宜
```

## 并行计算

| 类型 | 说明 |
|------|------|
| 多核 | 多 CPU 核心 |
| SIMD | 单指令多数据 |
| GPU | 大规模并行（AI 训练） |
| 分布式 | 多机集群 |

## 摩尔定律

- 晶体管数约每 2 年翻倍（1965 戈登·摩尔）
- 近年趋缓 → 转向专用芯片（GPU、NPU、TPU）

## 现代趋势

- 异构计算（CPU + GPU + NPU）
- 存算一体、量子计算
- RISC-V 开源指令集
- AI 芯片（推理、训练加速）
