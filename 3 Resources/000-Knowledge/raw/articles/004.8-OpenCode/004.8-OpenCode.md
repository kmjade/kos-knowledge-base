# 004.8 OpenCode

> OpenCode 是 **SST** 出品的**开源终端 AI 编码 Agent**（MIT 协议、Go 单二进制），定位「厂商中立的 Claude Code 替代」。以「多提供者模型路由 + TUI/CLI/Server 三模式 + 分层扩展系统」为核心，通过规则（AGENTS.md）、代理、技能、命令、MCP 与插件深度定制。数据更新至 2026-09。

## 核心问题

如何用一个**开源、厂商中立、多提供者**的终端编码 Agent，把任意模型（Claude/GPT/Gemini/本地）编排成能理解代码库、跨多文件多工具完成编码任务的工具？
