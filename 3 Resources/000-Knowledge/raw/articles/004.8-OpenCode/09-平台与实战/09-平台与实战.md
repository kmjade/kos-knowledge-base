# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| TUI（终端） | 全功能，默认界面 |
| Desktop 桌面 | macOS/Windows/Linux，tabs 多会话 |
| IDE 扩展 | VS Code 等 |
| Web | 浏览器运行 |
| Zen | 托管/云端运行 |
| Go | 订阅服务 |

## 实战案例

### 探索陌生代码库

```
❯ 这个项目的架构是什么？核心模块怎么组织？
```

OpenCode 用 LSP + 搜索 + 读文件，产出结构化架构说明。

### 修复 Bug（复用 Copilot 订阅）

```bash
opencode auth login    # 登录 GitHub 用 Copilot
```

```
❯ 测试失败在 test_foo.py line 42，帮我定位根因并修复
```

### 并行多会话

同一项目启动多个 agent 会话，并行处理不同任务。

### 无头 CI

```bash
opencode run --agent plan "审查这个 PR 的架构风险"
```

### 分享会话

```
/share     # 生成分享链接，用于参考或调试
```

### 自定义代理

```bash
opencode agent create   # 创建专用代理（如代码审查代理）
```

在 `.opencode/agents/` 定义角色、模型、权限，`@name` 调用。
