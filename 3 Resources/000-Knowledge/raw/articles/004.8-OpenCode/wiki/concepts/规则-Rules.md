# 规则 Rules

## 定义

规则（Rules）是 OpenCode 的**持久上下文**：读取项目规则文件（如 **AGENTS.md**）作为每会话注入的指令，与 Claude Code 的 CLAUDE.md、Codex 的 AGENTS.md 约定互通。

## 关键特性

| 特性 | 说明 |
|------|------|
| 文件 | AGENTS.md 等规则文件 |
| 加载 | 每会话自动注入 |
| 互通 | 跨工具通用约定 |
