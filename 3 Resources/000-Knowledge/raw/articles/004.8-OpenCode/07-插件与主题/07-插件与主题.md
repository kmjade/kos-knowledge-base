# 07 插件与主题

## 插件系统（Plugins）

OpenCode 的插件系统用 **TypeScript/JavaScript** 编写，提供 **~25+ 生命周期钩子/事件**，可注册工具、命令、拦截会话事件。

| 特性 | 说明 |
|------|------|
| 语言 | TypeScript / JavaScript |
| 钩子 | 25+ 生命周期事件 |
| 配置 | `opencode.json` 的 `plugin` 数组 + `~/.config/opencode/tui.json` |
| 生态 | npm 插件（`opencode-*`） |

> 插件定位「AI 会话的 husky」——在会话生命周期节点自动化（lint、格式化、通知、安全拦截）。注意：插件以用户权限运行任意代码，安装第三方插件需谨慎。

## 主题（Themes）

TUI 支持自定义主题，配置于 `opencode.json`。

## 键位（Keybinds）

TUI 键位可自定义。

## 格式化（Formatters）

支持代码格式化器集成，编辑后自动格式化。
