# 02 安装与快速入门

## 前提

- 现代终端（WezTerm / Alacritty / Ghostty / Kitty 等）
- 想用的 LLM 提供者的 API Key，或 GitHub Copilot / ChatGPT 订阅

## 安装

| 方式 | 命令 |
|------|------|
| 安装脚本（推荐） | `curl -fsSL https://opencode.ai/install \| bash` |
| npm | `npm install -g opencode-ai` |
| bun | `bun install -g opencode-ai` |
| pnpm | `pnpm install -g opencode-ai` |
| Homebrew | `brew install opencode` |

## 认证与多提供者

```bash
opencode auth login      # 交互式登录
opencode models          # 列出/筛选可用模型
```

| 方式 | 说明 |
|------|------|
| GitHub Copilot | 登录 GitHub 复用 Copilot 账户 |
| ChatGPT Plus/Pro | 登录 OpenAI 复用订阅 |
| API Key | 各提供者 Key（Anthropic/OpenAI/Google 等） |
| 本地模型 | 自托管 / Ollama 等 |

```bash
opencode -m provider/model    # 指定模型启动
opencode -m claude/sonnet-5   # 示例：切换模型
```

## 首次对话

```bash
cd your-project
opencode
```

TUI 内输入需求即可，自动加载 LSP、读取规则（AGENTS.md）、搜索代码、编辑文件。

### 常用命令（入门）

| 命令 | 功能 |
|------|------|
| `/model` | 切换模型 |
| `/new` | 新建会话 |
| `/undo` | 撤销改动 |
| `/share` | 分享会话链接 |

## 无头模式

```bash
opencode run "修复这个 bug"       # 一次性执行（CI）
```
