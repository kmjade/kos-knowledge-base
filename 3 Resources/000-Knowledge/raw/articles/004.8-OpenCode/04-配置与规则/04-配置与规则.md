# 04 配置与规则

## 配置文件

| 文件 | 作用域 |
|------|--------|
| `opencode.json` / `opencode.jsonc` | 项目级（优先于全局） |
| `~/.config/opencode/opencode.json` | 全局级 |

Schema 锚点：`https://opencode.ai/schema/opencode.json`。

### opencode.json 覆盖内容

`provider`（模型提供者）、`agent`（代理）、`mcp`（MCP 服务器与权限）、`permissions`（权限）、`lsp`（LSP）、`plugin`（插件）。

## 权限系统（Permissions）

权限建模为 allow/deny 列表，**deny 优先于 allow**：

```json
{
  "permissions": {
    "allow": ["mcp__codeindex__*"],
    "deny": ["Bash(rm:*)", "Bash(git push:*)"]
  }
}
```

代理的 Bash 权限支持 glob 模式映射：`{"*": "ask", "git status*": "allow", "rm -rf*": "deny"}`（按顺序匹配，最后一个匹配生效）。

## 规则（Rules / AGENTS.md）

OpenCode 读取项目规则文件（如 **AGENTS.md**）作为持久上下文，与 Claude Code 的 CLAUDE.md、Codex 的 AGENTS.md 约定互通。
