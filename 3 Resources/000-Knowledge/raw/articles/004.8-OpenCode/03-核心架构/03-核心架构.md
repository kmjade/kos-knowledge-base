# 03 核心架构

## 三种模式

| 模式 | 说明 | 用途 |
|------|------|------|
| TUI（默认） | Bubble Tea 构建的终端界面 | 交互式日常编码 |
| CLI | `opencode run` 单发命令/无头 | CI、脚本 |
| Server | headless API | 桌面/IDE/自定义客户端接入 |

## Agentic 循环

```
用户请求 → 读取代码库（含 LSP 类型/诊断/符号上下文）→ 推理 → 调用工具 → 观察 → 继续/完成
```

## LSP 集成

OpenCode **自动加载对应 LSP**（Language Server Protocol），为模型提供类型、诊断、符号级上下文——这是其区别于「纯文本搜索」的关键能力。

## 多会话

同一项目可并行启动多个 agent 会话，互不干扰。

## 上下文与规则

OpenCode 读取项目规则（AGENTS.md 等）、配置、技能，注入上下文。

## 目录结构

| 路径 | 用途 |
|------|------|
| `opencode.json` / `opencode.jsonc` | 项目配置 |
| `~/.config/opencode/opencode.json` | 全局配置 |
| `.opencode/agents/` | 自定义代理 |
| `.opencode/skills/` | 技能 |
| `~/.config/opencode/tui.json` | TUI 插件配置 |
