# 05 代理与技能

## 代理（Agents）

### 内置代理

| 代理 | 类型 | 能力 |
|------|------|------|
| `build` | 主代理（默认） | 全工具 |
| `plan` | 主代理 | 只读分析/规划 |
| `general` | 子代理 | 通用 |
| `explore` | 子代理 | 读/grep/glob/list |
| `scout` | 子代理 | webfetch/websearch |

- Tab 键循环切换主代理
- `@<name>` 调用子代理

### 自定义代理

在 `.opencode/agents/` 放 Markdown 文件，YAML frontmatter 定义：

| 字段 | 说明 |
|------|------|
| `description` | 触发说明 |
| `mode` | primary（Tab 循环）/ subagent（`@name`）/ all |
| `model` | 使用的模型 |
| `permission` | Bash 权限 glob 映射 |

```bash
opencode agent create   # 创建代理
opencode agent list     # 列出代理
```

## 技能（Skills）

技能存于 `.opencode/skills/<name>/SKILL.md`（项目）或 `~/.config/opencode/skills/<name>/SKILL.md`（全局），YAML frontmatter：`name`（小写 kebab，≤64 字符）、`description`（1–1024 字符）。

- 技能由**描述匹配**触发模型自动加载
- 命令（`/<name>`）由用户显式调用

## 命令（Commands）

自定义斜杠命令（`/<name>`）触发预设行为。

## 代理 vs 技能 vs 命令

| 维度 | 代理 | 技能 | 命令 |
|------|------|------|------|
| 定义 | 谁来做（角色+边界） | 如何做（知识+步骤） | 一键触发 |
| 触发 | Tab / `@name` | 描述匹配 | `/<name>` |
