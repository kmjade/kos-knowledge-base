# LCC-UDC 映射表

> LCC（美国国会图书馆分类法）与 UDC（国际十进分类法）的主类对照。
> 完整四体系对照（DDC·UDC·CLC·LCC）参见 [[DDC-分类码总表]]。

## 主类对照

## 关键差异

| 维度 | LCC | UDC |
|------|-----|-----|
| 编码格式 | 字母 + 数字（如 QA76.76） | 纯数字（如 004.4） |
| 主类数 | 21（A-Z） | 10 |
| 设计目的 | 排架——单一物理位置 | 索引——多维度表达 |
| 灵活性 | 低——枚举式，交叉学科只能选一位 | 高——`:` 组合任意类号 |
| 更新方式 | 定期印刷补充页 | 维护中心持续更新 |
| 计算机科学 | QA76 | 004 |
| 人工智能 | Q335 | 004.8 |
| 图书馆学 | Z | 02 |
| 传记 | CT | 929 |
