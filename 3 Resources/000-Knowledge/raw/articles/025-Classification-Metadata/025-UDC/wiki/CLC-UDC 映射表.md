# CLC-UDC 映射表

> CLC（中国图书馆分类法）与 UDC（国际十进分类法）的主类对照。
> 完整四体系对照（DDC·UDC·CLC·LCC）参见 [[DDC-分类码总表]]。

## 二十二大类对照

CLC 使用字母+数字编码（如 TP317），UDC 使用纯数字（如 004.4）。

| 类目 | CLC | UDC | 差异说明 |
|------|:---:|:---:|----------|
| 马克思主义·列宁主义·毛泽东思想 | A | — | CLC 独有的意识形态大类，UDC 无直接对应（归入 1 哲学） |
| 哲学·宗教 | B | 1/2 | UDC 将哲学(1)与宗教(2)分列主类 |
| 社会科学总论 | C | 3 | UDC 3 为社会科学大类 |
| 政治·法律 | D | 32/34 | UDC 32 政治、34 法律独立分列 |
| 军事 | E | 355/623 | UDC 355 军事科学 |
| 经济 | F | 33 | 基本一致 |
| 文化·科学·教育·体育 | G | 37/7 | UDC 37 教育、79 体育、7 文化 |
| 语言·文字 | H | 81 | UDC 语言在 81 |
| 文学 | I | 82 | UDC 文学在 82、821 |
| 艺术 | J | 7 | UDC 艺术在 7（含 72-79） |
| 历史·地理 | K | 9 | UDC 9 含历史(93/94)、地理(91)、传记(929) |
| 自然科学总论 | N | 5 | UDC 5 为自然科学 |
| 数理科学和化学 | O | 51/54 | UDC 51 数学、53 物理、54 化学 |
| 天文学·地球科学 | P | 52/55 | UDC 52 天文、55 地学 |
| 生物科学 | Q | 57/59 | UDC 57 生物、58 植物、59 动物 |
| 医药·卫生 | R | 61 | UDC 61 医学，含 R2 中医（UDC 615.8） |
| 农业科学 | S | 63 | UDC 63 农业 |
| 工业技术 | T | 62/66/67/68 | UDC 62 工程、66 化工、67 制造、68 机械 |
| 交通运输 | U | 625/656 | UDC 625 铁路、656 运输 |
| 航空·航天 | V | 629.7 | UDC 629.7 航空航天 |
| 环境科学·安全科学 | X | 502/614 | UDC 502 环境、614 安全 |
| 综合性图书 | Z | 0 | UDC 0 总类 |

## 关键差异

| 维度 | CLC | UDC |
|------|-----|-----|
| 编码格式 | 字母 + 数字（如 TP317.4） | 纯数字（如 004.4） |
| 大类数 | 22 | 10（第 4 类空缺） |
| 意识形态 | A 类独立马克思主义 | 无对应大类 |
| 中医定位 | R2 独立子类 | 归入 61 医学 |
| 中国知识 | K2 中国史、K825 人物传记系统 | 无明显偏向 |
| 计算机科学 | TP3 | 004 |
| 人工智能 | TP18 | 004.8 |
