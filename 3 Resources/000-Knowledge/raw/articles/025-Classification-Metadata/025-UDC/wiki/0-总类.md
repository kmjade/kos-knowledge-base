### 为什么总类重要

UDC 0 是知识管理系统的**元层**——它不直接研究某个具体学科，而是研究知识本身如何被组织、分类和检索。因此 KOS_LLM-Wiki 的整个架构（PARA + UDC + 三语言）本身就是一个 UDC 0 的实践案例。
