# 元数据标准

> 源：07-Metadata-Standards.md — 编译整理。

## 核心内容


> 元数据 = 关于数据的数据——书有作者·标题·日期——这些就是元数据
| Dublin Core: 15个元素——最简单——跨领域 |
|------|
| MODS/MARC: 图书馆专用——复杂但精密 |
| Schema.org: Google·Bing·Yahoo推动——网页结构化数据 |
| 标准 | 领域 | 核心元素 | 维护机构 |
|------|------|----------|----------|
| Dublin Core | 通用 | 15个元素（标题/创建者/主题/描述等） | DCMI |
| MARC 21 | 图书馆 | 数千个字段，机读目录格式 | LC |
| MODS | 图书馆 | XML版MARC，精简但兼容 | LC |
| PREMIS | 数字保存 | 保存元数据 | PREMIS Editorial Committee |
| EAD | 档案 | 编码档案描述 | SAA/LC |
| VRA Core | 视觉资源 | 艺术作品、建筑 | VRA |
| LOM | 教育 | 学习对象元数据 | IEEE |

**元数据三类型：**
1. **描述型** — 资源发现与识别（标题、作者、主题）
2. **结构型** — 复合资源的组织方式（章节、页面）
3. **管理型** — 技术、保存与权利管理

**分类号与元数据的关系：**
分类号（DDC/UDC/LCC）常作为元数据字段出现，桥接传统排架与数字描述。
