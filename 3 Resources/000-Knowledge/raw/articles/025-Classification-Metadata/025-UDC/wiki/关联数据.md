关联数据（Linked Data）是一组在Web上发布结构化数据的准则，使数据可互连和查询。

**四大原则（Tim Berners-Lee）：**
1. 使用URI作为事物名称
2. 使用HTTP URI以便查询
3. 查询时提供有用信息（RDF, SPARQL）
4. 包含指向其他URI的链接

**语义网技术栈：**
URI/IRI → RDF → RDFS → OWL → SKOS → SPARQL

**五星数据：**
★ 在Web上可用（任意格式）
★★ 机器可读的结构化数据
★★★ 非专有格式
★★★★ W3C标准（RDF, SPARQL）
★★★★★ 链接到其他数据

关联数据实现了从孤立分类到全球互联知识图谱的转变。
