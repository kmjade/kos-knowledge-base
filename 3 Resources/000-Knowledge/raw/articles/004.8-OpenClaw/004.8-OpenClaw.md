# 004.8 OpenClaw

> OpenClaw 是**自托管的开源个人 AI Agent 平台**（前身 Clawd / Moltbot），定位「真正会做事的 AI」——发送邮件、管理日历、运行命令、控制浏览器，24/7 自主工作。核心是「Gateway（网关）+ Agent Runtime（代理运行时）」双进程架构，通过 30+ 消息渠道与你对话，配合分层记忆、自动化调度、技能市场与安全治理。数据更新至 2026-09。
