# 03 核心架构

## 双进程模型

| 组件 | 角色 | 说明 |
|------|------|------|
| **Gateway**（控制面） | 长驻 Node.js 进程 | WebSocket（默认端口 18789 loopback）、渠道消息接入、会话管理、访问控制、路由、命令队列 |
| **Agent Runtime**（执行面） | 执行引擎 | LLM 调用、工具执行、推理循环、记忆读写、子代理生成 |

## Agent Loop

```
观察（observe）→ 思考（think）→ 行动（act）→ 循环
```

- 串行化**命令队列**（per-session + global 通道）防止并发破坏共享状态
- 支持流式、块回复、进度草稿（一条可见的 WIP 消息实时更新）

## 关键子系统

| 子系统 | 说明 |
|--------|------|
| 会话管理 | 会话、主会话（跨渠道滚动）、会话同步/附加、会话修剪 |
| 上下文引擎 | 可插拔上下文组装、压缩（compaction）、子代理生命周期 |
| 模型提供者 | provider/model 解析、failover（轮换 auth profile + 跨模型回退） |
| 多代理路由 | agent 边界、渠道账号、bindings |
| 命令队列 | 自动回复队列模式、后台容量、per-session 覆盖 |

## 工作区

Agent workspace 定义位置、布局与备份策略；支持 **managed worktrees**（隔离 git checkout 跑任务）。
