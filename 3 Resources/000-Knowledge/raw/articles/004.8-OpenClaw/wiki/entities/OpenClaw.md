# OpenClaw

自托管的开源个人 AI Agent 平台（前身 Clawd / Moltbot），「真正会做事的 AI」——发邮件、管日历、跑命令、控浏览器，24/7 自主工作，经 30+ 消息渠道交互。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 自托管开源个人 AI Agent |
| 前身 | Clawd → Moltbot |
| 核心 | Gateway + Agent Runtime 双进程 |
| 渠道 | 30+ 消息平台 |
| 模型 | 无关（Claude/GPT/Gemini/本地） |
| 许可 | 核心 MIT |
| 规模 | ~145–180K stars |

## 关键特性

- 消息网关（30+ 渠道）+ 双进程架构
- 分层记忆 + Dreaming 巩固
- 自动化（cron/hooks/standing orders/heartbeat）
- 技能（ClawHub 7000+）+ MCP + ACP
- 安全治理（审批/沙箱/secrets）
