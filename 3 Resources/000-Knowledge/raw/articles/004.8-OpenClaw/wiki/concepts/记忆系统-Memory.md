# 记忆系统 Memory

## 定义

记忆系统是 OpenClaw 的**跨会话记忆**：内置 SQLite 引擎（关键词 + 向量 + 混合检索）、主动记忆（深度历史召回）、Honcho 插件（AI 原生记忆）、工作区 Markdown 文件。可溯源、可预览、可删除。

## 关键特性

| 特性 | 说明 |
|------|------|
| 内置引擎 | SQLite 关键词+向量+混合检索 |
| 主动记忆 | 深度历史召回 |
| 工作区文件 | MEMORY.md 等跨会话 |
