# 自动化 Automation

## 定义

自动化是 OpenClaw 的**自主工作机制**：Automations（Cron 定时任务、webhook、Gmail PubSub）、Hooks（命令与生命周期事件）、Standing Orders（永久操作权限）、Task Flow（后台任务编排）与 Heartbeat（定时唤醒）。让 agent 在无人交互时自主工作。

## 关键特性

| 特性 | 说明 |
|------|------|
| Cron | 定时任务、webhook、PubSub |
| Hooks | 命令/生命周期事件自动化 |
| Standing Orders | 永久操作权限 |
| Heartbeat | 定时唤醒 + 安静时段 |
