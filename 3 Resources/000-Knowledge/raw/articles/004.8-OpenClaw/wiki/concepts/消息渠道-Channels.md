# 消息渠道 Channels

## 定义

消息渠道是 OpenClaw 连接的**消息平台**（WhatsApp、Telegram、Discord、Slack、Signal、iMessage、微信、飞书、QQ、Teams、Google Chat、Matrix、Zalo 等 30+），配合 pairing、access groups、channel routing 与 bot-loop 保护。

## 关键特性

| 特性 | 说明 |
|------|------|
| 渠道数 | 30+ |
| 访问控制 | pairing / access groups / allowlist |
| 主会话 | 跨渠道滚动对话 |
| 多用户 | 会话归属、presence、@提及 |
