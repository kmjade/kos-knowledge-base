# SOUL 人格

## 定义

SOUL.md 是 OpenClaw 的**人格文件**，用于给 agent 一个真实的「声音」而非通用助手腔调。系统提示由 SOUL.md 等组装。

## 关键特性

| 特性 | 说明 |
|------|------|
| 文件 | SOUL.md |
| 作用 | 定义 agent 人格与语气 |
| 系统提示 | 由 SOUL.md 等组装 |
