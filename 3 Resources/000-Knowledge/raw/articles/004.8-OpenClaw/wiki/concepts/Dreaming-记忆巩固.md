# Dreaming 记忆巩固

## 定义

Dreaming 是 OpenClaw 的**后台记忆巩固**机制，分**轻/深/REM** 三阶段，附 Dream Diary。无人交互时自动整理记忆，把会话经验沉淀为长期记忆。

## 关键特性

| 特性 | 说明 |
|------|------|
| 三阶段 | 轻 / 深 / REM |
| Dream Diary | 记录巩固过程 |
| 后台运行 | 无需用户交互 |
