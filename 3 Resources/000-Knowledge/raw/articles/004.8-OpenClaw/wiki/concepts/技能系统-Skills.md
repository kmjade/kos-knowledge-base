# 技能系统 Skills

## 定义

技能（Skills）是 OpenClaw 的**可复用能力**：内置 100+ AgentSkills + 社区 7000+ Skills，通过 `openclaw skills` 搜索/安装/更新，经 ClawHub 市场发现与发布（含安全审计）。

## 关键特性

| 特性 | 说明 |
|------|------|
| 内置 | 100+ AgentSkills |
| 社区 | 7000+ Skills |
| 市场 | ClawHub（含安全审计） |
