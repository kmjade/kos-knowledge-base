# 06 自动化与调度

## 自动化机制

| 机制 | 说明 |
|------|------|
| Automations（Cron） | 定时任务、webhook、Gmail PubSub 触发 |
| Hooks | 命令与生命周期事件的自动化 |
| Standing Orders | 为自主 agent 程序定义永久操作权限 |
| Task Flow | 后台任务之上的编排层 |
| Background Tasks | ACP 运行、子代理、自动化运行的任务追踪 |
| Heartbeat | 定时唤醒（如 ~30 分钟）自主工作，支持安静时段 |

## 定时任务（Cron）

```bash
openclaw automations          # 调度/运行后台任务
```

## Hooks

内部钩子：安装、编写、验证命令与生命周期事件的自动化。

## Standing Orders

定义**永久操作权限**，让 agent 在无人交互时仍按既定规则自主执行。

## IMAP 邮件触发

监听 IMAP 邮箱，把认证过的来信路由到隔离的受限 reader agent。
