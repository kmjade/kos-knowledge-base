# 04 消息网关

## 渠道一览（30+）

| 类别 | 渠道 |
|------|------|
| 主流 IM | WhatsApp、Telegram、Discord、Slack、Signal、iMessage（imsg） |
| 国内 | 微信（WeChat）、企业微信（WeCom）、QQ、飞书（Feishu）、钉钉类 |
| 协作 | Microsoft Teams、Google Chat、Mattermost、Matrix、Nextcloud Talk、Synology Chat |
| 其他 | LINE、IRC、Twitch、Nostr、SMS、Zalo、元宝、Tlon/Urbit |

## 渠道管理

```bash
openclaw channels login      # 账号登录
openclaw channels status     # 状态
openclaw channels logs       # 日志
openclaw pairing             # 批准私信/节点
```

## 访问控制

| 机制 | 说明 |
|------|------|
| Pairing | 批准谁可以私信你 + 哪些节点可加入 |
| Access groups | 可复用的发送者白名单 |
| Group messages | 群聊处理、allowlist、会话、上下文注入 |
| Bot loop protection | 防 bot-to-bot 循环 |

## 路由

- **Channel routing**：按渠道路由规则 + 共享上下文
- **Main session**：跨渠道一个滚动对话（个人 agent 默认）
- **Multi-user mode**：多人操作一个 agent 的会话归属、presence、@提及

## 特殊协议

| 协议 | 说明 |
|------|------|
| A2A | 通过 A2A 1.0 JSON-RPC 连接外部 agent |
| Raft / Reef | 外部 agent / 加密 peer 消息 |
