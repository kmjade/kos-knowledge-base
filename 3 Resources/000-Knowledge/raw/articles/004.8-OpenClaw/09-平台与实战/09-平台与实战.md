# 09 平台与实战

## 平台一览

| 平台 | 特点 |
|------|------|
| TUI | 终端 UI，Gateway-backed 或本地嵌入式 |
| Dashboard（Control UI） | `openclaw dashboard` 安全打开控制面板 |
| 节点（Nodes） | headless 节点主机、配对、相机/屏幕/位置/通知 |
| 桌面/移动 | macOS app、移动客户端、QR 配对 |
| 托管 | DigitalOcean 1-Click 安全部署 |

## 实战案例

### 个人助理

```
❯ 帮我整理收件箱，把重要邮件归档并回复
```

OpenClaw 通过 IMAP/邮件渠道读取邮箱、归类、草拟回复。

### 值机登机

```
❯ 帮我值机明天的航班
```

通过浏览器控制完成表单填写、截图确认。

### 日历管理

```
❯ 安排下周与客户的会议
```

读日历、找空闲、发邀请。

### 自主心跳任务

配置 heartbeat（如每 30 分钟），agent 自主醒来检查待办、推进任务，安静时段不打扰。

### 多设备接入

```bash
openclaw connect   # 一条命令把机器接入 Gateway
openclaw qr        # 生成移动配对二维码
```

### 迁移

```bash
openclaw migrate   # 从其他 agent 系统导入状态
```
