# 08 安全与治理

## 风险警示

| 风险 | 说明 |
|------|------|
| Prompt injection | 恶意指令注入 |
| 记忆中毒 | 恶意指令持久化进长期记忆 |
| 明文密钥 | 早期版本明文存 API key/密码 |
| 「致命三连」 | 私有数据访问 + 不可信内容暴露 + 持久记忆的外部通信 |

> 项目方原话：「如果你不懂命令行，这对你太危险了。」

## 安全机制

| 机制 | 说明 |
|------|------|
| 审批（Approvals） | `openclaw approvals` + exec-policy，HITL 人工审批 |
| 沙箱（Sandbox） | `openclaw sandbox` 管理沙箱运行时与策略 |
| Secrets | `openclaw secrets` 存储/审计，`${VAR_NAME}` 引用避免硬编码 |
| Security 审计 | `openclaw security` 审计并修复常见安全隐患 |
| 访问控制 | allowlist、pairing、access groups |

## 多用户与治理

- 多用户模式：会话归属、presence、@提及
- 配对（pairing）：批准私信/节点
- 策略（policy）一致性检查

## 建议防护

HITL 审批、沙箱、allowlist、审计日志、凭证隔离。
