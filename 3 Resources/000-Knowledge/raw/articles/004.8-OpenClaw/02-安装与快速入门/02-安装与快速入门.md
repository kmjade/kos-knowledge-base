# 02 安装与快速入门

## 安装

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

支持 macOS / Windows / Linux。也可用 DigitalOcean 的安全加固 1-Click 部署。

## 引导（Onboard）

```bash
openclaw onboard          # 交互式引导
openclaw setup            # 系统 agent 聊天式配置
openclaw configure        # 交互式配置提示
openclaw doctor           # 健康检查 + 引导修复
```

## 配置

```bash
openclaw config get/set/patch <key>   # 配置读写
openclaw config validate              # 校验
```

配置存于本地（`~/.openclaw/` 等），敏感信息用 `${VAR_NAME}` 引用而非硬编码。

## 认证与模型

```bash
openclaw models           # 模型状态/列表/设置
openclaw models set <provider/model>
openclaw auth login       # 提供者认证
```

模型无关：Claude、GPT、Gemini 或本地模型，自带 Key。

## 连接消息渠道

```bash
openclaw channels login    # 渠道账号登录
openclaw pairing           # 批准谁可以私信你
```

支持 WhatsApp、Telegram、Discord、Slack、Signal、微信、飞书等 30+ 渠道。

## 启动网关

```bash
openclaw gateway           # 启动/查询/发现网关
openclaw gateway status
```

网关默认监听 loopback 端口 18789（WebSocket）。

## 首次对话

从任意已连接渠道（如 WhatsApp）发消息给 agent 即可；或本地：

```bash
openclaw tui               # 终端 UI
openclaw message "你好"     # 发送消息
```
