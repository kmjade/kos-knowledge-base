# 05 记忆系统

## 记忆分层（Memory Tiers）

| 层 | 说明 |
|----|------|
| 内置引擎 | 默认 SQLite 后端，关键词 + 向量 + 混合检索 |
| 主动记忆 | 深度对话历史召回，仅在确定性召回不足时升级 |
| Honcho | AI 原生跨会话记忆插件 |
| 工作区文件 | Markdown（MEMORY.md、日志）跨会话跨平台 |

## 记忆巩固（Dreaming）

后台记忆巩固，分**轻/深/REM** 三阶段，附 Dream Diary——无人交互时整理记忆。

## 记忆搜索

- 用 embeddings + 混合检索找相关笔记
- 来源可追溯（provenance）、可预览/删除

## 相关命令

```bash
openclaw memory status          # 状态
openclaw memory search "..."    # 搜索
openclaw memory forget "..."    # 遗忘
openclaw wiki                   # memory-wiki vault（含 Obsidian 助手）
openclaw sessions search        # 搜索过往会话
```

## 用户模型

管理持久用户偏好与 Gateway profile 身份。
