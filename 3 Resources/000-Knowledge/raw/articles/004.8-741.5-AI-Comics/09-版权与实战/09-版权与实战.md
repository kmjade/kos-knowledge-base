# 09 版权与实战

## 版权要点

| 要点 | 说明 |
|------|------|
| 商用授权 | 各平台差异大（检查许可） |
| AI 生成版权 | 纯 AI 生成若无显著人类创作投入，可能无法获得版权 |
| IP 风险 | 使用受版权角色名称（如 Naruto）有侵权风险 |

## 实战建议

1. 短篇先用 Midjourney/NovelAI 快速原型
2. 长篇用 SD + LoRA 保证角色一致性
3. 排版用 Canva/Comicai
4. 商用前确认授权

## 实战案例

### 四格漫画

ChatGPT 写段子 → SD 生成 4 格 → Canva 排版 + 气泡。

### 条漫（Webtoon）

Dashtoon 脚本转漫画 → 分镜 → 发布。

### 角色长篇

训练角色 LoRA → SD + ControlNet 批量生成 → 排版成稿。
