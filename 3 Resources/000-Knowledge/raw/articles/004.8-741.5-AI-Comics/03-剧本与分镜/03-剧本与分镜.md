# 03 剧本与分镜

## 剧本

用 ChatGPT / Claude 生成剧情大纲、对白、场景描述。

## 分镜（Storyboard）

把剧本拆成**分镜脚本**：每个分镜包含动作、视角、景别、对白。

```
分镜 1：主角推门而入（全景，正面）
对白：我回来了！
```

## AI 生成分镜

- ChatGPT/Claude 生成 5-10 个关键分镜的文本描述
- 分镜描述 = 角色 + 动作 + 场景 + 构图 + 画风
