# 07 排版与输出

## 排版要素

| 要素 | 说明 |
|------|------|
| 分镜网格 | 漫画页面布局 |
| 对话气泡 | 对白放置 |
| 特效字 | 拟声词（boom、啪） |

## 输出规格

- 单页约 1200×1800 像素、300 DPI
- 条漫（Webtoon）竖屏滚动
- 页漫分页多分镜

## 排版工具

| 工具 | 说明 |
|------|------|
| Canva | 成稿排版/气泡 |
| Comicai / Dashtoon | 内置排版 |
| PS / Clip Studio | 专业漫画排版 |
