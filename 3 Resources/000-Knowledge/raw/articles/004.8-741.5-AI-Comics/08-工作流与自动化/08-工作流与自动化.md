# 08 工作流与自动化

## 标准工作流

```
文本 → ChatGPT 生成分镜 → SD 生成草图 → LoRA+ControlNet 细化 → img2img 上色 → 批量输出
```

## ComfyUI 节点化

把整个流程用 ComfyUI 节点串联，实现批量自动化。

## 漫剧动画

AnimateDiff 做关键帧插值，把漫画升级为动态漫剧。
