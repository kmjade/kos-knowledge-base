# 04 角色设计与一致性

## 角色一致性方法（按可靠性）

| 方法 | 可靠性 | 说明 |
|------|:--:|------|
| LoRA 训练 | 80–90% | 15–50 张参考图，Kohya SS/ComfyUI 训练 |
| 参考图/风格系统 | 60–75% | Midjourney `--cref`、NovelAI Vibe Transfer |
| IP-Adapter 角色 ID 卡 | 中 | ComfyUI 生成标准参考图锁定身份特征 |
| 提示词重复 | 40–60% | `(long blue hair:1.4)` 等，变异大 |
| Brandkit / Character Bible | 中 | 固定角色属性资产 |

## LoRA 训练要点

- 收集 15–50 张不同角度/表情/姿势
- 学习率 0.0001，约 1000 步
- 适合角色出现 20 张以上的项目

## IP-Adapter 角色 ID 卡

生成标准参考图 → 提取特征 → 批量生成三视图，锁定脸型/发际线/鼻梁。
