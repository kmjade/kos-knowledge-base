# 06 线稿与上色

## 线稿（Lineart）

- ControlNet Lineart/Canny 模式从线稿引导生成
- 草图 → 线稿 → 细化

## 上色（Coloring）

- SD img2img 模式上色
- 去噪强度 0.5–0.7
- 提示词加入 `flat coloring, anime style`

## 工作流

```
线稿 → ControlNet 引导 → img2img 上色 → 细化
```
