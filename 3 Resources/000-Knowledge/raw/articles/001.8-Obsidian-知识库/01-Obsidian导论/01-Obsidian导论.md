# 01 Obsidian 导论

## 什么是 Obsidian

Obsidian 是一款**本地优先（local-first）**的 Markdown 个人知识管理（PKM）工具。你的笔记以纯文本 `.md` 文件保存在本地文件夹（Vault）里，通过 Wikilink、反向链接与关系图谱，把零散笔记织成一张可长期复利的知识网络。

## 核心理念：本地优先

| 特性 | 说明 |
|------|------|
| **文件即数据** | 笔记是纯文本 Markdown，永远归你所有，可被任何编辑器打开 |
| **离线可用** | 全部功能在本地运行，无网络依赖 |
| **可迁移** | 换工具/换电脑，文件夹一拷即走，无锁定 |
| **可扩展** | 核心插件 + 社区插件 + CSS 主题，高度可定制 |

## 历史（2020 → 2026）

| 时间 | 事件 |
|------|------|
| 2020-03 | Obsidian 公开测试版发布（Dynalist 团队） |
| 2022-10 | **Obsidian 1.0** 正式发布 |
| 2023 | kepano（Stephan Ango）出任 CEO，推出 Sync 加密同步 |
| 2024 | 属性（Properties）重塑、Canvas 完善 |
| 2025-08 | **Bases** 数据库功能随 v1.9.10 公开（核心插件） |
| 2026-01 | **1.11** 移动端大更新（iOS 小组件、Siri、Android 小组件） |
| 2026-08 | **1.13.7** 稳定版 |
| 2026-09 | **1.14**（Bases Kanban、彩色高亮、Temml 数学渲染） |

> 截至 2026 年，Obsidian 是同类工具中社区与插件生态最活跃的本地优先 PKM 应用之一。

## 定位

| 定位 | 说明 |
|------|------|
| 第二大脑 | 承接 Tiago Forte「Building a Second Brain」理念 |
| PKM 工具箱 | 支持 PARA、Zettelkasten、LYT 等多种方法论 |
| 知识图谱 | 通过双向链接建立笔记间的语义网络 |
| 长期资产 | 本地纯文本，跨越工具与时间周期 |
