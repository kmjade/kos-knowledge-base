# 06 同步与发布

## Obsidian Sync

官方同步服务，**端到端加密**，多设备实时同步 Vault（笔记、附件、设置）。

| 特性 | 说明 |
|------|------|
| 加密 | 端到端加密（E2EE），官方也无法读取 |
| 版本历史 | 笔记的版本回溯 |
| 选择性同步 | 可排除部分文件夹 |
| 多设备 | 桌面 + 移动端 |

## Obsidian Publish

把 Vault 中的笔记发布为公开网站，适合知识库分享、文档站、数字花园。

- 发布单篇笔记或整个 Vault
- 自定义域名、主题
- 支持 Wikilink 与关系图谱（网页版）

## 移动端

| 平台 | 说明 |
|------|------|
| iOS | 2026-01（1.11）起支持锁屏/控制中心小组件、Siri、Spotlight、快速捕获 |
| Android | 小组件、快捷设置磁贴、应用快捷方式 |

> 1.14 新增 iOS 26 原生快速捕获：锁屏/控制中心直接记笔记，不等待 Vault 加载。

## 第三方同步方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| **Obsidian Git** | 版本控制 + 备份 | 需 Git，冲突需处理 |
| iCloud / OneDrive | 免费、自动 | 偶有冲突/损坏风险 |
| Syncthing | 开源、P2P、无中心 | 需自己配置 |
| Dropbox | 稳定 | 免费额度有限 |

## 建议

- 个人多设备 → 官方 Sync（最省心、加密）
- 分享 → Publish
- 备份/版本 → Obsidian Git（或 Sync 自带的版本历史）
