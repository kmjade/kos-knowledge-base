# 03 核心功能

## 反向链接（Backlinks）

反向链接面板显示「有哪些笔记链接到了当前笔记」。这是 Obsidian 区别于普通笔记应用的核心能力——它让知识节点之间的关联自动浮现。

- 打开方式：右侧边栏「反向链接」
- 场景：发现一篇笔记被哪些笔记引用，挖掘隐藏关联

## 关系图谱（Graph View）

把整个 Vault 可视化为一张知识网络图：

- 节点 = 笔记，连线 = 链接
- 支持按标签/路径着色、过滤、局部图谱
- 场景：鸟瞰知识结构、发现孤立笔记、寻找枢纽节点

## 标签（Tags）

```markdown
#标签          → 平铺标签
#父标签/子标签  → 层级标签
```

- 标签面板：浏览所有标签
- 建议：标签用于「主题分类」，链接用于「笔记关联」

## 属性（Properties）

笔记的 YAML frontmatter 元数据，是 Obsidian 的「数据库列」：

```yaml
---
tags: [obsidian]
status: 进行中
priority: 高
---
```

- 可在笔记顶部以表格形式可视化编辑
- Bases 与 Dataview 通过属性查询、分组、计算

## 搜索

| 方式 | 快捷键 | 说明 |
|------|:------:|------|
| 快速切换 | `Ctrl/Cmd+O` | 按文件名跳转 |
| 全局搜索 | `Ctrl/Cmd+Shift+F` | 全文搜索 |
| 命令面板 | `Ctrl/Cmd+P` | 执行任意命令 |

搜索支持运算符：`file:`、`path:`、`tag:`、`line:` 等。

## 标签页与工作区

| 功能 | 说明 |
|------|------|
| 标签页 | 多笔记并排打开 |
| 分屏 | 拖拽标签页到不同方向 |
| 工作区 | 保存/加载窗口布局 |
| 书签 | 快速访问常用笔记 |

## 命令面板

`Ctrl/Cmd+P` 打开命令面板，是 Obsidian 的「万能入口」——所有操作、插件命令都能从这里触发。
