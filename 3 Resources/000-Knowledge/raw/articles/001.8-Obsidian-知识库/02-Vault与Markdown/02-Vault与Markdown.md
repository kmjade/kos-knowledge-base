# 02 Vault 与 Markdown

## Vault（仓库）

Vault 就是一个本地文件夹，里面装着你的所有 Markdown 笔记与附件。Obsidian 打开这个文件夹，把它变成一个知识库。

```
我的知识库/            ← Vault 根目录
├── 笔记.md
├── 项目/
│   └── 项目A.md
├── 附件/              ← 图片、PDF 等
│   └── image.png
└── .obsidian/         ← 配置（主题、插件、设置）
```

> `.obsidian/` 目录存放 Vault 配置（插件、主题、设置），通常不手动修改。

## Markdown 基础语法

| 语法 | 写法 | 效果 |
|------|------|------|
| 标题 | `# H1`、`## H2` | 层级标题 |
| 加粗 | `**粗体**` | **粗体** |
| 斜体 | `*斜体*` | *斜体* |
| 列表 | `- 项目` | 无序列表 |
| 代码 | `` `行内` ``、``` ```块``` ``` | 代码 |
| 表格 | `\| a \| b \|` | 表格 |
| 引用 | `> 引用` | 引用块 |
| 高亮 | `==高亮==` | 高亮（1.14 起支持彩色） |

## Wikilink（维基链接）

Obsidian 的核心语法，用 `[[...]]` 关联笔记：

| 语法 | 作用 |
|------|------|
| `[[笔记名]]` | 链接到一篇笔记 |
| `[[笔记名\|显示文字]]` | 自定义显示文字 |
| `[[笔记名#标题]]` | 链接到笔记内某个标题 |
| `[[笔记名^块ID]]` | 链接到笔记内某个块 |

## 嵌入（Embed）

在链接前加 `!` 即可把目标内容嵌入当前笔记：

| 语法 | 作用 |
|------|------|
| `![[笔记名]]` | 嵌入整篇笔记 |
| `![[image.png]]` | 嵌入图片 |
| `![[笔记名#标题]]` | 嵌入某个标题下的内容 |

## Callout（提示块）

Obsidian 特有的高亮提示块：

```markdown
> [!note] 标题
> 这是内容
```

| 类型 | 用途 |
|------|------|
| `note` / `info` | 信息 |
| `tip` / `hint` | 提示 |
| `warning` / `caution` | 警告 |
| `danger` / `error` | 危险 |
| `example` | 示例 |
| `quote` | 引用 |
| `todo` | 待办 |

> [!tip] 折叠 Callout
> 在类型后加 `-` 或 `+` 可折叠：`> [!note]- 折叠标题`。

## 标签与别名

| 特性 | 语法 | 说明 |
|------|------|------|
| 标签 | `#标签`、`#父/子` | 层级分类 |
| 别名 | frontmatter `aliases: [别名1, 别名2]` | 让笔记可被多个名字找到 |

## 属性（Properties / Frontmatter）

笔记顶部 YAML 区，为笔记添加结构化元数据：

```yaml
---
title: "笔记标题"
tags: [obsidian, pkm]
created: 2026-09-05
aliases: [别名]
---
```

> 属性是 Obsidian 的「数据库字段」，Bases 与 Dataview 都依赖属性来查询与组织笔记。
