# 04 插件与主题

## 核心插件 vs 社区插件

| 类型 | 说明 |
|------|------|
| **核心插件** | Obsidian 官方内置，在「设置 → 核心插件」启用（如反向链接、图谱、Bases、同步） |
| **社区插件** | 第三方开发，在「设置 → 社区插件」浏览安装（如 Dataview、Templater） |

## 必装社区插件（2026 共识）

| 插件 | 下载量级 | 用途 |
|------|:-------:|------|
| **Excalidraw** | ~178 万 | 手绘白板、思维导图、架构图 |
| **Templater** | ~140 万 | 高级模板引擎（JS 自动化） |
| **Dataview** | ~111 万 | DQL 查询，把 Vault 变数据库 |

### Dataview

用类 SQL 的 DQL 把属性/标签变成动态视图：

````markdown
```dataview
TABLE file.link AS "笔记", status
FROM "项目"
WHERE status = "进行中"
SORT file.mtime DESC
```
````

### Templater

比内置模板更强，支持 JS、日期运算、提示输入，配合日记/周期笔记自动填充。

### Excalidraw

手绘风格白板，图表内可含 `[[链接]]`，让视觉与笔记互通。

## 主题（Themes）

主题在「设置 → 外观」切换，常见社区主题：Minimal、Things、AnuPpuccin、Blue Topaz。

## 插件管理建议

- **克制**：保持在 **15–30 个**以内，避免启动变慢
- **起步组合**：Dataview + Templater + Git（或 + Excalidraw）
- **判断维护度**：看最近提交、star 数、下载量
- **按需添加**：有具体需求再装，不要跟风堆插件
