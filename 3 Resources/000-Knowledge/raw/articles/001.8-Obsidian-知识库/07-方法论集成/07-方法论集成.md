# 07 方法论集成

> Obsidian 是「工具」，方法论是「用法」。同一工具可承载多种知识管理流派。

## PARA

由 Tiago Forte 提出，按「可执行性」组织：

| 文件夹 | 含义 |
|--------|------|
| Projects | 有目标、有期限 |
| Areas | 长期负责的领域 |
| Resources | 参考资料 |
| Archives | 归档 |

> 本知识库（KOS_LLM-Wiki）即以 PARA 为骨架。

## Zettelkasten（卡片盒笔记法）

卢曼的学术写作方法：

| 要素 | 说明 |
|------|------|
| 原子笔记 | 一张卡一件事，自成一体 |
| Folgezettel | 卡片间的顺序链接 |
| Hub / 索引 | 主题入口页 |
| 永久笔记 | 用自己的话重写，而非摘抄 |

Obsidian 的 Wikilink 天然契合 Zettelkasten 的「卡片互联」。

## LYT（Linking Your Thinking）

Nick Milo 提出的方法，核心是 **MOC（Map of Content）**：

- MOC 是某个主题的「内容地图」，手动编排相关笔记入口
- 强调「链接 + 地图」而非严格层级文件夹

## 第二大脑（Building a Second Brain）

用 CODE 流程把信息变成可复用的知识资产：

| 步骤 | 含义 |
|------|------|
| Capture | 捕获（剪藏、闪念） |
| Organize | 组织（PARA） |
| Distill | 提炼（渐进式总结） |
| Express | 表达（产出） |

## 如何选择

| 目标 | 推荐方法 |
|------|----------|
| 项目管理 / 生活管理 | PARA |
| 学术写作 / 研究 | Zettelkasten |
| 探索性学习 | LYT（MOC） |
| 综合 | 混合（PARA 骨架 + MOC 导航 + 原子笔记） |

> 本库的「方法论模式」frontmatter 字段（para / lyt / zettel / generic）正是这套混合的落地。
