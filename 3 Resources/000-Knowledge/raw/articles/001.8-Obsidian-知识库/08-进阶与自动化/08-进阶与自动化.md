# 08 进阶与自动化

## 模板（Templates）

### 内置模板

- 核心插件「模板」，插入预设内容 + `{{date}}` 等变量。

### Templater（高级）

```markdown
<% tp.date.now("YYYY-MM-DD") %>
<% tp.file.title %>
<% tp.frontmatter.tags %>
```

- 支持 JavaScript 逻辑、提示输入、动态生成
- 配合日记/周期笔记自动填充

## Canvas（画布）

Obsidian 的可视化画布：把笔记、图片、卡片拖到无限画布上连线。

- 用途：思维导图、项目看板、架构设计、头脑风暴
- 卡片可嵌入笔记，连线可加标签

## URI 协议

用 `obsidian://` 从外部打开/创建笔记：

| URI | 作用 |
|-----|------|
| `obsidian://open?vault=X&file=笔记` | 打开笔记 |
| `obsidian://new?vault=X&file=新笔记` | 新建笔记 |
| `obsidian://search?vault=X&query=关键词` | 搜索 |

## 本地 API 与 CLI

| 工具 | 说明 |
|------|------|
| Local REST API 插件 | 通过 HTTP 接口读写笔记（AI 代理常用） |
| obsidian-cli | 命令行操作 Obsidian |
| MCP（Model Context Protocol） | 让 AI 工具连接 Vault |

> 本库的 AI 代理（KOS 引擎）正是通过 Local REST API / 文件系统与 Obsidian 交互。

## 快捷键

| 操作 | 快捷键 |
|------|:------:|
| 命令面板 | `Ctrl/Cmd+P` |
| 快速切换 | `Ctrl/Cmd+O` |
| 全局搜索 | `Ctrl/Cmd+Shift+F` |
| 切换编辑/预览 | `Ctrl/Cmd+E` |
