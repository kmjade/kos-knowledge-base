# Vault 仓库

## 定义

Vault 是 Obsidian 对一个本地文件夹的称呼——你的所有笔记、附件与配置都以纯文本文件形式存在其中。Obsidian 打开这个文件夹，把它变成可链接、可查询的知识库。

## 结构

```
Vault/
├── 笔记.md
├── 附件/image.png
├── 子文件夹/
└── .obsidian/          ← 插件、主题、设置
```

## 关键特性

| 特性 | 说明 |
|------|------|
| 本地优先 | 数据永远归你所有 |
| 纯文本 | Markdown 可被任何编辑器打开 |
| 可迁移 | 文件夹一拷即走 |
| `.obsidian/` | 配置目录，通常不手动改 |
