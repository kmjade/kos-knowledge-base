# Canvas 画布

## 定义

Canvas 是 Obsidian 的可视化画布功能：把笔记、图片、卡片拖到无限画布上，用连线表达关系。

## 用途

| 用途 | 说明 |
|------|------|
| 思维导图 | 发散整理思路 |
| 项目看板 | 拖拽卡片管理任务 |
| 架构设计 | 绘制系统结构 |
| 头脑风暴 | 自由摆放想法 |

## 特点

- 卡片可嵌入笔记，连线可加标签
- 与 Excalidraw 互补（Canvas 偏结构，Excalidraw 偏手绘）
