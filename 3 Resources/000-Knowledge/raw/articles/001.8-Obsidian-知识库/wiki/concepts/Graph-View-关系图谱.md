# Graph View 关系图谱

## 定义

关系图谱把整个 Vault 可视化为一幅知识网络图：节点是笔记，连线是 Wikilink。它让你鸟瞰知识的整体结构。

## 能力

| 能力 | 说明 |
|------|------|
| 着色 | 按标签/路径给节点上色 |
| 过滤 | 按关键词/标签缩小范围 |
| 局部图谱 | 只看某篇笔记的邻域 |
| 枢纽识别 | 找出被链接最多的核心笔记 |
