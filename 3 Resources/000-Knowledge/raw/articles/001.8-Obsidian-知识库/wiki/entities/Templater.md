# Templater

社区插件，比 Obsidian 内置模板更强的模板引擎，支持 JavaScript 逻辑、日期运算与提示输入。

## 关键信息

| 参数 | 说明 |
|------|------|
| 类型 | 社区插件（模板引擎） |
| 下载量 | ~140 万 |

## 用法

```markdown
<% tp.date.now("YYYY-MM-DD") %>
<% tp.file.title %>
```

配合日记/周期笔记自动填充日期、标题与 frontmatter。
