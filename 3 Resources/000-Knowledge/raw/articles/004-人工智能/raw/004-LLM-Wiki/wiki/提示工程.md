# 提示工程

> 源：提示工程.md — 编译整理。

## 核心内容

### 什么是提示工程？

提示工程（Prompt Engineering）是通过精心设计输入文本（prompt）来引导 LLM 产生期望输出的实践。它是目前与 LLM 交互的主要技术手段。

### 核心框架

**CO-STAR 框架：**
- **C（Context）** — 提供背景上下文
- **O（Objective）** — 明确任务目标
- **S（Style）** — 指定输出风格
- **T（Tone）** — 设定语气语调
- **A（Audience）** — 定义目标受众
- **R（Response）** — 规定输出格式

### 提示要素

- **指令（Instruction）** — 明确告诉模型要做什么
- **示例（Few-shot）** — 提供输入输出样例
- **角色（Role）** — 为模型设定专业身份
- **格式约束（Format）** — 指定输出结构（JSON/表格/列表）


### 进阶技巧

- **思维链（Chain-of-Thought）** — 引导模型逐步推理，提升复杂问题的回答质量
- **少样本（Few-shot）** — 在 prompt 中提供输入输出示例，指导模型理解任务格式
- **角色扮演（Role Prompting）** — 为模型设定领域专家身份，提升回答的专业性

提示工程是 LLM 应用中最具杠杆效应的技能——好的 prompt 可以显著提升输出质量，而无需修改模型本身。
