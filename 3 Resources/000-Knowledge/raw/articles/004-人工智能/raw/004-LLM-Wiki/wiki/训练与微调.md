# 训练与微调

> 源：训练与微调.md — 编译整理。

## 核心内容

### 训练三阶段

**1. 预训练（Pre-training）**
- 目标：下一 token 预测（自回归）
- 数据：TB 级互联网文本、书籍、代码
- 计算：数千 GPU 并行训练数周至数月
- 产出：Base 模型（具备语言能力，但未对齐）

**2. 有监督微调（SFT）**
- 使用人工标注的高质量问答对微调
- 使模型学会遵循指令、回答问题
- 数据量通常为数万至数十万条

**3. 强化学习对齐（RLHF）**
- 训练奖励模型评估回答质量
- 使用 PPO 算法优化策略模型
- 产出：对齐后的助手模型


### 关键概念

- **Base 模型 vs Instruct 模型** — Base 模型仅具备语言建模能力，Instruct 模型经过对齐训练后能遵循指令
- **LoRA（低秩适配）** — 通过少量可训练参数实现高效微调，极大降低显存需求
- **上下文长度** — 从 GPT-3 的 4K 到 GPT-4 的 128K，上下文窗口持续扩展

### 数据流程

`
互联网文本 → 预训练 → Base 模型 → SFT → Instruct 模型 → RLHF → Aligned 模型
`
