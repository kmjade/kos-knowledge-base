# 训练与微调

> **资源：** LLM 的训练流程与微调方法。
> UDC: 004.8:681.3（AI + 计算机系统/训练基础设施）

---

## 训练三阶段

```
预训练（Pre-training）
    ↓
有监督微调（SFT / Instruction Tuning）
    ↓
强化学习对齐（RLHF / DPO）
```

### 1. 预训练（Pre-training）
- **目标**：下一 token 预测（自回归）
- **数据**：TB 级互联网文本、书籍、代码
- **计算**：数千 GPU 并行训练数周至数月
- **产出**：Base 模型（具备语言能力，但未对齐）

### 2. 有监督微调（SFT）
- **目标**：指令跟随与对话能力
- **数据**：人工标注的指令-回答对
- **方法**：全参数微调或 Lora/QLora

### 3. 对齐（Alignment）
- **RLHF**：基于人类反馈的强化学习
  - 训练 reward model → PPO 优化
- **DPO**：直接偏好优化（更简单，无需 reward model）

## 微调方法对比

| 方法 | 参数量 | 显存需求 | 效果 | 适用场景 |
|------|--------|---------|------|---------|
| Full Fine-tune | 全部 | 极高 | 最佳 | 有充足资源 |
| LoRA | 0.1-1% | 低 | 良好 | 任务适配 |
| QLoRA | 0.1-1% | 极低 | 良好 | 单卡微调 |
| Adapter | 少量 | 低 | 中等 | 轻量适配 |

## 关键概念

| 概念 | 说明 |
|------|------|
| Epoch | 完整遍历数据集一次 |
| Batch Size | 每次更新的样本数 |
| Learning Rate | 更新步长 |
| Gradient Accumulation | 累积多个 batch 再更新 |
| Warmup | 逐步增加学习率 |
| Cosine Schedule | 余弦衰减学习率策略 |
