# 文件格式 (File Format)

> 数据的结构化存储方式，决定信息的编码、读写与交换。

## 定义

文件格式（File Format）规定了数据如何在文件中组织和编码。不同格式适用于不同用途——文本、图像、音频、结构化数据等。在本知识库中，核心文件格式为 Markdown (`.md`)，辅以 YAML frontmatter 进行元数据声明。

## 常见格式分类

| 类别 | 示例 |
|:----|:------|
| 文本文档 | Markdown (.md), TXT, HTML, XML |
| 结构化数据 | YAML, JSON, CSV |
| 图像 | PNG, JPEG, SVG |
| 笔记/元数据 | Obsidian 格式, Frontmatter |
