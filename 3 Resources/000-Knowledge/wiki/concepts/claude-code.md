# Claude Code

> Anthropic 推出的命令行 AI 编码助手，基于 Claude 大语言模型。

## 定义

Claude Code 是 Anthropic 开发的命令行（CLI）编码代理工具，允许开发者在终端中直接通过自然语言与 AI 交互来编写、调试和重构代码。它是 Codex（GitHub Copilot 的竞品）生态中的关键产品之一。

## 核心能力

- 自然语言代码生成与修改
- 终端内上下文感知的代码分析
- 多文件编辑与重构
- Git 工作流集成
- 持续会话记忆

## 相关概念

- [[Agent-prompt]] — AI 代理的提示策略
- [[GPT-5]] — 同期的大语言模型对比
- [[提示工程]] — 与 AI 编码代理交互的提示技术

## 定位

Claude Code 属于 LLM 应用层工具，与大模型本身不同，其价值在于将语言模型能力封装为开发者可用的终端工作流。
