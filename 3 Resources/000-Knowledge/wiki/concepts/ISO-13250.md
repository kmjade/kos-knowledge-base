# ISO 13250 主題圖標準

> 主题(Topic Map) 国际标准 · 知识导航与关联结

---

## 定义

ISO 13250 定义了主题图 (Topic Map) 的数据模型，用于表示知识结构、主题间的关联以及主题与外部资源的联系核心概念：Topic (主题) · Association (关联) · Occurrence (资源关联)

## 核心模型

```
Topic Map = { Topics } + { Associations } + { Occurrences }

Topic (主题)           Wiki/Concepts + Wiki/Entities
  ├─┢ Topic Name        aliases
  ├─┢ Occurrence        Sources (外部资源链接)
  └─┢ Association       [[wikilink]] (关联)
      ├─┢ Type          关系类型 (is-a/part-of/related)
      └─┢ Role          角色 (parent/child/sibling)
```
