# 实践论

> 关于实践与认识关系的理论框架 — "实践是检验真理的唯一标准"。

---

## 定义

实践论是认识论的一个分支，探讨人类认识如何起源于实践、如何通过实践验证和发展。其核心命题是：**认识来源于实践，又反过来指导实践，在实践中得到检验和发展。**

在马克思主义哲学传统中，实践论由毛泽东在 1937 年的《实践论》中系统阐述，但其思想根源可追溯到马克思主义认识论的基本原理——认识的过程是"实践、认识、再实践、再认识"的循环往复。

---

## 核心思想

```
实践 → 感性认识 → 理性认识 → 再实践 → 更高层次的认识
  ↑                                          |
  └──────────────────────────────────────────┘
```

这个循环有以下特征：

1. **实践优先** — 认识不是凭空产生的，而是从改造世界的活动中获得的
2. **认识的飞跃** — 从感性认识（经验、感知）到理性认识（概念、规律）是质变
3. **检验标准** — 理性认识是否正确，必须回到实践中验证
4. **螺旋上升** — 每次循环都使认识达到更高层次

---

## 与验入法的关系

实践论是**理论层**，验入法是**操作层**。

| 实践论 | 验入法 |
|--------|--------|
| 认识来源于实践 | 新想法从实践中捕获 |
| 需要验证 | 放入隔离区，先论证 |
| 检验后才纳入体系 | 裁决通过后引入 |
| 循环上升 | 每次论证提升决策质量 |

验入法是实践论在个人知识管理系统中的操作实现——它把"实践—认识—再实践"的循环，变成了"捕获—论证—裁决—执行"的日常流程。

## 应用场景

| 场景 | 实践论的角度 | 验入法的操作 |
|------|------------|------------|
| 新交易策略 | 需要在实盘中验证 | 先回测，再模拟，再实盘 |
| 新的记账方法 | 是否比现有方法更好？ | 隔离区并行试用一个月 |
| 新的学习路径 | 是否符合认知规律？ | 先小规模试点，再铺开 |
| 工具/软件 | 能否提升生产力？ | 试用期 + 对比评估 |

## 关键文献

- 《实践论》（毛泽东，1937）— 核心文本
- 《关于费尔巴哈的提纲》（马克思，1845）— 思想根源："哲学家们只是用不同的方式解释世界，问题在于改变世界"
- 《唯物主义和经验批判主义》（列宁，1909）— 认识论的进一步展开
- 《科学与革命》（波普尔）— 否证论视角：理论也是假说，等待被证伪
