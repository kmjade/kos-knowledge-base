# 知识组织与大模型

> **资源：** LLM 如何改变知识组织（KOS）的方式，以及如何用 LLM 辅助知识管理。
> UDC: 001.8:004.8（知识组织 + AI）

## LLM 对知识组织的冲击

传统知识组织依赖**人工设计的分类体系**（UDC、DDC 等），而 LLM 提供了一种**语义驱动的组织方式**：

| 维度 | 传统 KOS | LLM 增强 KOS |
|------|---------|-------------|
| 分类 | 人工指定类号 | 语义聚类 + 自动分类 |
| 检索 | 关键词匹配 | 语义搜索 + 问答 |
| 关联 | 手动链接 | 自动发现关系 |
| 摘要 | 人工撰写 | 自动生成 |
| 维护 | 人力驱动 | AI 辅助持续更新 |

## LLM 在知识管理中的应用

### 1. 自动标签与分类
- 输入笔记内容 → LLM 推荐 UDC 类号和标签
- 实现笔记的自动归类

### 2. 语义搜索
- 自然语言查询，而非关键词精确匹配
- 跨语言检索（中文问，英文答案）

### 3. 知识提取与摘要
- 从长文档中提取关键概念
- 自动生成笔记摘要

### 4. 关系发现
- 识别不同笔记之间的潜在关联
- 推荐双向链接

### 5. 知识问答
- 基于 Wiki 内容的问答
- RAG（检索增强生成）实现

## 本系统的 AI 辅助设想

```
┌─────────────────┐
│   Obsidian 笔记  │
├─────────────────┤
│  1. 记录原始笔记  │
│  2. LLM 提取元数据 │
│      → UDC 分类   │
│      → 标签推荐    │
│      → 链接建议    │
│  3. 人工审核与调整  │
│  4. 纳入知识体系    │
└─────────────────┘
```

## 未来方向

- **个人知识图谱** — 将笔记转化为 RDF 三元组
- **Agent 辅助研究** — LLM Agent 自动搜集、整理、关联知识
- **动态分类** — LLM 根据知识演化自动调整分类结构
