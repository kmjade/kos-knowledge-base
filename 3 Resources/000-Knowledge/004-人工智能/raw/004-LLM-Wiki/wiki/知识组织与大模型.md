# 知识组织与大模型

> 源：知识组织与大模型.md — 编译整理。

## 核心内容

### LLM 对知识组织的冲击

传统知识组织依赖人工设计的分类体系（UDC、DDC 等），而 LLM 提供了一种语义驱动的组织方式：

### LLM 在知识管理中的应用

### 1. 自动标签与分类
- 输入笔记内容 → LLM 推荐 UDC 类号和标签
- 实现笔记的自动归类
### 2. 语义搜索
- 自然语言查询，而非关键词精确匹配
- 跨语言检索（中文问，英文答案）

### 未来方向

- 个人知识图谱 — 将笔记转化为 RDF 三元组
- Agent 辅助研究 — LLM Agent 自动搜集、整理、关联知识
- 动态分类 — LLM 根据知识演化自动调整分类结构


### LLM 与传统知识组织的融合路径

本系统采用混合策略：

| 层面 | 方式 | 负责方 |
|------|------|--------|
| 宏观分类 | UDC 类号 | 人工指定 |
| 标签 | 扁平标签 | AI 推荐 + 人工确认 |
| 关联 | wiki 链接 | AI 自动 + 人工补充 |

这种分层策略既保持了分类体系的严谨性，又利用了 LLM 的语义理解能力。
