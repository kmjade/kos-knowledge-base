## 编号要点

- **`086` 是 `08` 的主表下位**（三位整体，非 `08.6`）；**`(086)` 带括号是复分号**。
- **`udc` 写本类号 `086`**（不承容器 —— 与支线相反）。
- ⚠️ **`086` 与容器 `06`（一般性质的组织）层级不同，极易混淆**。
- ⚠️ **类名与范围注待核**（以分类表为准）。
