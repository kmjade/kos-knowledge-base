# 082 多图作品汇编

> **类号子库 `082`（容器 `08` · UDC `08`）** —— 本子库处理**汇编作为二次文献**这件事：它的最小单位不是「一篇文章」，而是「**这段材料从哪儿来**」。
> 核心判据一句话：**问「这一段是从哪儿搬来的」，而不是「这本汇编讲了什么」。**
> 所属：[[08-多图作品、集体作品|08 多图作品、集体作品]]（容器 · UDC `08`）· 落**容器根**（`082` 是 `08` 的**主表下位**）。
> ⚠️ **编号性质**：`082` 是 UDC `08` 的主表下位，**不是**支线序号 `02`、不是复分 `(082)`、不是 `08.2`。
> ⚠️ **范围注待核**：`082` 的正式类名与范围以分类表为准；本库名称依用户给定，**未核**。

## 一、定位与边界

**收什么**

| 面 | 范围 | 典型问题 |
|:--|:--|:--|
| 汇编本体 | 资料汇编 · 文章汇编 · 图文汇编 | 它把什么拼在了一起 |
| 层级 | 全录 · 节录 · 摘编 · 辑录 · 拼合 | 原文完整吗 |
| 汇编者 | 编选 · 辑录 · 校点 · 注释 | 汇编者做了什么 |
| 来源链 | 原出处 · 原题 · 节删位置 | 能追回原文吗 |
| 著录 | 来源 · 节录 · 原名 · 汇编者 | 记在哪一层 |
| 引用 | 引汇编还是引原文 | 二次文献的引用滑坡 |

**不收什么**

| 主题 | 去向 |

## 三、「汇编」的三种所指

| 所指 | 材料来源 | 判据 |
|:--|:--|:--|
| **资料汇编** | 文件 · 档案 · 记录 · 统计 | 以原始材料为主，几乎不加论述 |
| **文章汇编** | 已发表的文章 / 论文 | 二次收录，常附导言 |
| **图文汇编** | 图版 + 说明文字 | 图与文各自有来源 |

> ⚠️ **三者混装极常见**：一本「资料汇编」可能夹入编者长文 —— 须分清哪部分是材料、哪部分是论述。
> ⚠️ **「汇编」不保证原创**，但也**不保证不原创**：编者的按语与注释可以是实质贡献。

## 四、汇编与邻近类型

| 类型 | 单位 | 与汇编的差别 |
|:--|:--|:--|
| **汇编** | 材料 | 以**来源**为组织原则 |
| 选集 | 文章 | 以**选择**为组织原则（见 `01`） |
| 合著 | 章节 | 为本书**新写**，非收录 |
| 丛书 | 卷 | 各卷**独立成立**（见 `03`） |
| 文集（全集 / 别集） | 一人之作 | 以**作者**为组织原则 |
| 类书 / 资料长编 | 摘录 | 以**检索或时序**为组织原则 |

> ⚠️ **辨别第一问：这一篇是为本书写的，还是从别处搬来的？**
> ⚠️ **「主编」不等于「汇编者」**：前者组织，后者搬运与校订。

## 五、汇编的层级

| 层级 | 做法 | 完整性 |
|:--|:--|:--|
| **全录** | 原文照录 | 高（仍可能有排印差异） |
| **节录** | 截取片段 | 须标删节位置 |
| **摘编** | 摘句 / 摘段重组 | **已构成新文本** |
| **辑录** | 从多处辑出同一主题 | 来源须逐条标 |
| **拼合** | 多来源拼接成一篇 | **最易制造伪文本** |

> ⚠️ **摘编与拼合不是「汇编」，是「重新写作」**：若不标注，等于制造新文献。
> ⚠️ **节录的删节位置必须可定位**（章节 · 页码 · 段落），否则无法复核。

## 六、完整性纪律

| 情形 | 须记 | 理由 |
|:--|:--|:--|
| 删节 | 删在何处 · 删了什么 | 否则读者以为原文如此 |
| 拼合 | 每一段的来源 | 否则形成伪连续文本 |
| 改题 | **原题 + 新题** | 检索断裂 |
| 改字 / 规范化 | 改了什么 · 依何标准 | 否则被当作原文 |
| 补注 | 编者注须与原文区分 | 注文窜入是经典事故 |
| 译文 | 底本 · 译者 · 是否转译 | 否则不可复核 |
| 图版 | 来源 · 拍摄 / 绘制时点 | 图文错配常见 |

> ⚠️ **最高纪律：不制造新文本**。凡改变原文者，**必须留下可回溯的痕迹**。
> ⚠️ **「编者注」与「原文」在同一版面上混排，是汇编最常见的失真源**。

## 七、汇编者的位置

| 角色 | 做了什么 | 是否构成独立贡献 |
|:--|:--|:--|
| 编选者 | 决定收什么 | 判断，但常不计分 |
| 辑录者 | 从多处辑出 | **常是实质工作** |
| 校点者 | 标点 · 校勘 | **实质性文本工作** |
| 注释者 | 加注 | 可独立引用 |
| 作序者 | 导言 / 按语 | 可独立引用 |

**权利结构（只给结构）**

| 项 | 说明 |
|:--|:--|
| 原作权利 | 汇编不消灭原作权利 |
| 汇编者权利 | 选择与编排可构成独立权利 |
| 注释 / 校点 | 可能构成独立作品 |
| 授权链 | 汇编常缺完整授权，影响数字化 |

> ⚠️ **本节不复述条文、不给法律意见** —— 条文归 [[34-法律|34 法律]]。
> ⚠️ **校点即解释**：标点位置改变句读，等于改变文本（与 `03-文本传承` 呼应）。

## 八、来源链

| 环节 | 可追回什么 | 常见断点 |
|:--|:--|:--|
| 原出处 | 首发载体 · 时间 | 只写「转引自」 |
| 原题 | 检索入口 | 改题后不记原名 |
| 原页码 | 定位 | 重排后页码全变 |
| 节删位置 | 完整性 | 完全不标 |
| 版本 | 用的是哪一版 | 版本不明 |

> ⚠️ **「转引自」是来源链的断裂点**：转引的引文与原文可能已不同。
> ⚠️ **汇编的检索价值取决于来源链的密度**：来源越细，越可替代原文；越粗，越只是「方便」。

## 九、著录要点

| 项 | 记什么 | 归谁 |
|:--|:--|:--|
| 汇编类型 | 资料 / 文章 / 图文 | 本子库 |
| 汇编者 | 姓名 · 角色（编 / 辑 / 校 / 注） | 署名规则归 `02` |
| 来源 | 每条或整体 | 本子库（核心） |
| 完整性 | 全录 / 节录 / 摘编 | 本子库（核心） |
| 收录范围 | 时段 · 主题 · 文献类型 | 本子库 |
| 原题 | 有改题时必记 | 本子库 |
| 书目格式 | 字段与顺序 | [[01-目录学\|01 目录学]] |

> ⚠️ **缺「完整性」与「来源」两项的汇编著录，等于不可用**。
> ⚠️ **「汇编」二字本身不含信息**：须落到类型与范围。

## 十、引用与计量

| 情形 | 后果 |
|:--|:--|
| 引汇编而不引原文 | 原文的引用被记到汇编上 |
| 汇编被高引 | 可能只是「方便引用」 |
| 原文绝版 | 汇编成为唯一可得，但**不等于原文** |
| 转引层层叠加 | 引文逐层失真 |
| 汇编者被计零 | 辑录与校点的劳动消失 |

> ⚠️ **二次文献的引用滑坡**：越方便的本子，越容易被当作原始出处。
> ⚠️ **纪律：能回原文就回原文**；回不到时，须注明「据某某汇编」。

## 十一、数字化

- **拆散即失链**：全文库把汇编拆成篇，来源项常随之丢失。
- **页码重排**：扫描与识别后，原页码体系可能被抹平。
- **图文错配**：图版与说明文字的对应关系在扫描中最易错乱。
- **重复文本识别**：可发现同一材料在多部汇编中的重复收录。
- **授权分层**：汇编整体授权 ≠ 逐篇授权。

## 十二、中国语境

1. **政策文件汇编**：收录范围与截止时点是最关键的两项。
2. **史料汇编**（档案 · 方志 · 碑刻）的**选录标准**常在凡例中说明，须与正文对读。
3. **案例汇编**的**删改与匿名化**程度差异大，影响可复核性。
4. **论争汇编**（讨论集）具有明确的**立场编排**，导言往往是关键。
5. **「资料长编」**体例（以时序排比材料）在史学传统中成熟，**与西方汇编概念不完全对应**。
6. **类书**的摘录性质使其**不能当原文引用**（与 `03-文本传承` 的辑佚问题呼应）。
7. **内部资料汇编**流通受限，编目缺失严重（与 `094` 灰文献问题呼应）。
8. **「编」与「辑」**在中文出版用语中区分不严，**须逐书判断**。

## 十三、判读六步与三条纪律

**六步**

1. **定类型**：资料汇编 / 文章汇编 / 图文汇编。
2. **定完整性**：全录 / 节录 / 摘编 / 辑录 / 拼合。
3. **查来源链**：原出处 · 原题 · 原页码 · 版本。
4. **区分材料与论述**：哪部分是原文，哪部分是编者按语。
5. **判汇编者角色**：编 / 辑 / 校 / 注 / 序。
6. **落结论**：`类型 + 完整性 + 来源密度（细 / 粗 / 缺）`。

**三条纪律**

- **不把汇编当原文** —— 汇编是二次文献，除非全录且已校。
- **不把摘编当节录** —— 重组就是新文本，须明示。
- **不把「转引自」当出处** —— 断链处必须标断。

## 十四、病理八项

1. **删节不标** —— 读者以为原文完整。
2. **拼合无源** —— 制造伪连续文本。
3. **改题不记原名** —— 检索断裂。
4. **编者注混入原文** —— 文本失真。
5. **来源只写「转引自」** —— 链条断在第一环。
6. **完整性不著录** —— 无法判断可用性。
7. **汇编被当原始出处引用** —— 引用滑坡。
8. **逐篇授权缺失** —— 数字化受阻或越界。

## 十五、核心问题

- **这是汇编还是新写**
- **完整性到哪一层**（全录 / 节录 / 摘编）
- **来源链是否可追**
- **汇编者做了什么**（编 / 辑 / 校 / 注）
