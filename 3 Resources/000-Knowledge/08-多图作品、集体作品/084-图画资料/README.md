## 编号要点

- **`084` 是 `08` 的主表下位**（三位整体，非 `08.4`）；**`(084)` 带括号是复分号**。
- **`udc` 写本类号 `084`**（不承容器 —— 与支线相反）。
- **与支线 `04` 毫无关系**：一个是类号，一个是排架序号。
- ⚠️ **类名与范围注待核**（以分类表为准）。
