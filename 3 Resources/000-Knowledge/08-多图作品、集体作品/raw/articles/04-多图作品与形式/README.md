## 编号要点

- **支线序号 `04` 是排架序号**，不是类号；本支线 `udc` 承容器 `08`。
- **本支线以 `(08)` 复分义为主题**：多图作品 · 形式 · 列表 · 插图 · 商业出版物。
- **`(08)` 带括号是复分号**，与主类号 `08` **同形不同用**；复分号不能单独作主类号。
