## 编号要点

- **支线序号 `01` ≠ UDC `01`**：`01` 是容器内排架序号；UDC `01` 是目录学。
- **本支线 `udc` 承容器 `08`**：元数据不写 `01`。
- **`(08)` 是复分号**（合集 · 形式 · 列表 · 插图 · 商业出版物），与主类号 `08` 同形不同用。
