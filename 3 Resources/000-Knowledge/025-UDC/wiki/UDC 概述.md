# UDC 概述

> **资源：** 国际十进分类法（Universal Decimal Classification）的基础介绍。
> UDC: 025.4（分类法与索引）

---

## 核心内容

### 什么是 UDC？

国际十进分类法（Universal Decimal Classification）由 Paul Otlet 和 Henri La Fontaine 于 1895-1905 年间创立，是最早的通用分类法之一。UDC 使用阿拉伯数字和辅助符号来表示人类知识的全领域。

### UDC 结构

#### 主类表

```
0 — 总类（科学知识、信息、组织）
1 — 哲学、心理学
2 — 宗教、神学
3 — 社会科学
4 — 闲置（原为语言学，后并入 8）
5 — 自然科学
6 — 应用科学、医学、技术
7 — 艺术、娱乐、体育
8 — 语言、语言学、文学
9 — 地理、历史
```

#### 辅助符号

| 符号 | 含义 | 范例 |
|------|------|------|
| `:` | 关系符号（组合多个类）| 001.8:004.8 → 知识组织与 AI |
| `+` | 并列符号 | 004+005 → 电脑+管理 |
| `/` | 范围符号 | 004/006 → 电脑到标准化 |
| `-` | 连字号（子类）| 004.8-02 → LLM 的属性 |
| `(0)` | 文献类型 | (03) → 百科全书 |
| `(=)` | 语言 | =111 → 英语 |

#### 通用复分号

- `.0` — 一般性复分
- `.1` — 理论、原理
- `.2` — 分析、方法
- `.3` — 设备、工具
- `.5` — 管理、组织
- `.8` — 应用


### UDC vs DDC 核心差异

| 维度 | DDC | UDC |
|------|-----|-----|
| 分类策略 | **枚举**——每个主题一个数字 | **分面**——通过符号组合多个维度 |
| 连接符 | 无（纯层级） | 有——`+ / : = (…) "…"` |
| 灵活性 | 低 | **高**——可表达复杂关系 |
| 学习曲线 | 低——直观 | 高——需学习符号系统 |
| 适用场景 | 公共/学校图书馆 | 专业/研究图书馆 |
| 核心思维 | 一本书 → 一个号码 | 一本书 → 一个表达式 |

### 辅助符号实例

| 文献主题 | DDC | UDC |
|----------|:---:|:---:|
| 中国医学史（英文） | 610.951 | `61(510)(091)=111` |
| 人工智能教育 | 006.3071 | `004.8:37` |
| 德国哲学词典 | 103.43 | `1(038)=112.2` |
| 日本采矿与冶金 | 669.0952 | `622+669(520)` |
| 21 世纪中国高等教育 | 378.510905 | `378(510)"20"` |

### UDC 十大类概览

| 类 | 内容 | 备注 |
|:--:|------|------|
| **0** | 总论、计算机、信息 | 含 004 计算机科学 |
| **1** | 哲学、心理学 | — |
| **2** | 宗教、神学 | — |
| **3** | 社会科学 | — |
| **4** | ⚠️ **空** — 原语言类已并入 8 | **UDC 独有特征** |
| **5** | 数学、自然科学 | — |
| **6** | 应用科学、医学、科技 | 本库重点领域 |
| **7** | 艺术、娱乐、体育 | — |
| **8** | 语言、语言学、文学 | 1980 年代吸收原第 4 类 |
| **9** | 地理、传记、历史 | — |

> 注意：UDC 没有第 4 类——这是 UDC 不同于 DDC 的明显特征。
### UDC 在本系统的使用

每个笔记的 frontmatter 包含 `udc` 字段：

```yaml
---

---
```

这允许在 Obsidian 中通过 DataView 或搜索查询按 UDC 类号筛选笔记。

### 为什么选用 UDC？

1. **通用性** — 覆盖所有知识领域
2. **灵活性** — 使用组合符号表达复合主题
3. **层次性** — 从粗到精的粒度控制
4. **国际性** — 语言中立，数字标识
