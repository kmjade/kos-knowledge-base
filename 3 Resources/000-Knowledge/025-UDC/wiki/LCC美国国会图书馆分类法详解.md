# LCC 美国国会图书馆分类法详解

> 源：06-LCC-in-Depth.md — 编译整理。

## 核心内容

### 一、概况

| 属性 | 值 |
|------|------|
| 全称 | Library of Congress Classification |
| 首次出版 | 1901年 |
| 维护方 | 美国国会图书馆 (LC) |
| 使用范围 | 美国研究型/大学图书馆为主 |
| 类型 | 枚举式·分卷独立修订 |
| 特色 | Cutter号——字母+数字精确到每本书 |

### 二、二十一大类

| 字母 | 大类 | 说明 |
|:---:|------|------|
| A | 总类 | 百科·索引 |
| B | 哲学·心理学·宗教 | |
| C | 历史辅助科学 | 传记·考古 |
| D | 世界史 | 欧洲·亚洲·非美 |
| E-F | 美国史 | 独享两个大类 |
| G | 地理·人类学·休闲 | 地图·体育·游戏 |

### 三、Cutter 号——LCC的灵魂

| 部分 | 含义 |
|------|------|
| 字母前缀 | 大类+学科 (QA=数学·CS, TK=电气) |
| 数字 | 子类细化 |
| .Cutter | 字母+数字——精确到具体个体 |
> Cutter号让LCC无需复分表即可精确到每本著作——这是与DDC复分机制的根本差异。
---

### 四、LCC vs DDC

| | DDC | LCC |
|------|------|------|
| 大类 | 10 | 21 |
| 编码 | 纯数字 | 字母+数字+Cutter |
| 设计 | 知识树——排架号即位置 | 学科分卷——各科独立 |
| 更新 | 统一版本 (DDC 23) | 分卷独立修订 |
| 精度 | 复分表组合 | Cutter号直达个体 |
| 美国史 | 973-979 | 独占E+F两个大类 |
