# 013 集体书目

> **UDC 013 / DDC 013** — 集体书目（Bibliographies of Groups of Authors）：把**某一类作者**的作品汇成书目——不是一个人（012），也不是一个主题（016）。
> 范围注释（UDCS 中文版）：**「某一类作者的作品书目。」**
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/013-集体书目/`。

---

## 一、类号与边界

| 体系 | 类号 | 类目 |
|:----|:---:|:----|
| UDC | **013** | 集体书目 |
| UDC 上位 | 01 | 书目、目录 |
| DDC | **013** | Bibliographies of specific kinds of persons（特定群体书目） |
| DDC 上位 | 010 | Bibliography（书目总类） |
| CLC | G257 · Z8 | 目录学 · 图书目录 |
| LCC | Z8001–Z8999 | Personal bibliography（按群体 / 人物编号，与 012 共用区段） |

**与兄弟类号的分工**

| 类号 | 类目 | 轴的落点 |
|:----:|:-----|:---------|
| 011 | 通用与一般书目 | 不限作者 / 国家 / 主题 / 格式 |
| 012 | 作者书目、个人书目 | **一个人**（或特定组织出版物） |
| **013** | **集体书目** | **一类作者**（本页） |
| 014 | 具体特征作品书目 | 作品特征，不以作者群为轴 |
| 015 | 地方书目 | 出版 / 收藏的**地方**，不论作者是谁 |
| 016 | 专题目录 | **主题**；作者群只是选材结果 |

> ⚠️ **最容易混的两组**：
> ① **013 vs 015** —— 「杭州籍作家书目」是 `013`（作者群，用国籍/地区复分）；「杭州出版物书目」是 `015`（地方）。
> ② **013 vs 016** —— 「女性科学家著作目录」若以**作者群**选材是 `013`；若以「女性与科学」**主题**选材是 `016`。**看选材标准，不看标题。**

## 二、复分：怎么限定「一类作者」

UDCS 应用注释给出四个面，可组合：

| 面 | 复分符 | 示例 | 读法 |
|:---|:---:|:-----|:-----|
| **职业 / 社会 / 学科领域** | `:` | `013:32(430)` | 德国政治家书目 |
| **语种** | `=` | `013=411.16` | 希伯来语作者书目（示例仅示意） |
| **时期** | `"…"` | `013"18"` | 19 世纪作者书目（示例仅示意） |
| **国籍 / 地区** | `(1/9)` | `013(510)` | 中国作者书目（示例仅示意） |

> 📌 组合顺序：**先 013，再按需叠加复分**。UDCS 只给了 `013:32(430)` 一个官方合并示例；其余示例为结构示意，实际编号须以 UDC 正式表核。

## 三、收什么

| 类型 | 说明 | 示例 |
|:-----|:-----|:-----|
| **职业 / 界别作者群** | 政治家 · 医生 · 律师 · 军人 | `013:32(430)` 德国政治家 |
| **学科 / 专业作者群** | 科学家 · 哲学家 · 史学家 | 某一学科的作者总目 |
| **语种 / 民族作者群** | 某语种、某民族作者 | 少数民族作家书目 |
| **时期作者群** | 某一时代 / 朝代的作者 | 明代作者书目 |
| **国籍 / 地区作者群** | 某国、某地籍贯的作者 | 中国现代作家书目 |
| **性别 / 身份群体** | 女性作者 · 特定身份群体 | 女性作家书目 |
| **机构成员** | 某院 / 某校成员著作 | 科学院院士著作目录 |

> ⚠️ 「机构成员著作」与 `012` 的「特定组织出版的作品书目」不同：前者是**作者身份**（谁写的），后者是**出版主体**（谁出的）。

## 四、怎么做：群体书目的特有难点

| 难点 | 问题 | 处理 |
|:-----|:-----|:-----|
| **成员资格** | 谁算「政治家」？自认、他认、还是按职位？ | 先写**入选判据**，再列人 |
| **边界漂移** | 同一人可属多个群体 | 允许交叉，但每条注明归属依据 |
| **时代 / 语种切分** | 跨期、多语作者怎么放 | 以**主要活动期 / 主要语种**为主，余者互见 |
| **收录层级** | 只收专著，还是收论文、译作、手稿？ | 明示载体与文种范围 |
| **去重** | 同一作品在不同作者条目下重复 | 建**作品—作者**双向索引 |
| **在世 / 敏感信息** | 隐私与政治敏感性 | 只收公开出版物信息，不评价个人 |

> 📌 群体书目的价值不在「人多」，而在**判据清楚**。判据模糊的群体书目，读者无法判断「没查到」是没收还是不存在。

## 五、编排方式

| 方式 | 适用 | 说明 |
|:-----|:-----|:-----|
| **按作者字顺** | 群体成员明确 | 最常用；每人下系作品 |
| **按作者生卒 / 活动期** | 时代跨度大 | 便于看代际分布 |
| **按作品主题** | 群体跨学科 | 需配作者索引 |
| **按机构 / 地区** | 成员按组织归属 | 适合院士、地方作家群 |

> 常见结构：**前言（判据与范围）→ 总表 → 作者条目（小传 + 著作系年）→ 佚名 / 存疑 → 索引**。

## 六、中国传统中的「集体书目」

| 形态 | 说明 | 与 UDC 013 的关系 |
|:-----|:-----|:------------------|
| **地方艺文志** | 一方人士著作的登记 | 作者群 + 地方复分，最接近 `013` |
| **断代总集 / 类编** | 一朝或一类作者的作品总集 | 本身是总集，书目功能附随 |
| **学派 / 师承著述考** | 一派学者的著作 | `013` 的学科 / 学派形态 |
| **书院 / 官学课艺目录** | 某机构成员的课艺 | `013` 的机构成员形态 |

> 中国传统多用「艺文志」「著述考」承载群体书目功能；「集体书目」是 UDC 的分析概念，不是传统类目名。

## 七、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 研究某一群体 | 先确认判据 → 查 013 → 再按人转 012 |
| 编地方文献丛书 | 地方艺文志 + 013（地区复分） |
| 学科史研究 | 学科作者群书目 + 016 专题目录互补 |
| 馆藏建设 | 按群体集中采买，注意判据与载体 |
| 查某人是否属某群体 | 查群体书目收录，同时回查 012 个人书目 |

## 八、核心问题

> 当「群体」由分类者划定——政治家、科学家、女性作家——集体书目究竟是在**描述一个既存群体**，还是在**通过书目生产这个群体**？
