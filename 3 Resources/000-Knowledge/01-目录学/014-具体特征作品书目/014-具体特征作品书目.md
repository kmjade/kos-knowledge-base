# 014 具体特征作品书目

> **UDC 014 / DDC 014** — 具体特征作品书目：按**作品自身的某一特征**（载体、版本、文献类型）汇成的书目——不按谁写（012/013）、不按哪里（015）、不按什么主题（016）。
> ⚠️ **本条与 DDC 014 不等价**：DDC 014 只收**匿名与伪名著作书目**，是 UDC 014 的一个窄子集，且该子集在 UDC 里归 [[012-作者书目、个人书目|012]]（范围注明列「佚名作品」）。
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/014-具体特征作品书目/`。

## 二、判据：什么叫「具体特征」

一句话：**问「这是些什么样的一份东西」，而不是「这是谁写的 / 哪里出的 / 讲什么的」。**

| 判据落点 | 归 014 | 不归 014 |
|:--|:--|:--|
| 物质形态（写本 / 刊本 / 拓本 / 缩微 / 电子） | ✅ | — |
| 版本与文本状态（初版 / 善本 / 稿本 / 批校本 / 删节本） | ✅ | — |
| 文献类型（政府出版物 / 学位论文 / 专利 / 标准 / 会议录 / 连续出版物） | ✅ | — |
| 出版主体是一家**特定机构** | — | ❌ → `012`（范围注明列「特定组织出版的作品书目」） |
| 佚名 / 伪托 | — | ❌ → `012` |
| 某地**出版** | — | ❌ → `015` |
| 某主题 | — | ❌ → `016` |
| 某馆**收藏**的善本清单 | — | ❌ → `017`/`019`（是「目录」不是「书目」） |

> ⚠️ 014 的边界最容易被「看起来像特征」的三件事拉走：**作者归属**（→012）· **出版机构**（→012）· **收藏地点**（→017/019）。

## 三、特征谱：四组

| 组 | 特征 | 书目形态 |
|:---|:-----|:---------|
| **A 载体 / 物质形态** | 甲骨 · 金石 · 简帛 · 写本 · 抄本 · 拓本 · 缩微 · 音像 · 电子 / 数字 | 敦煌遗书目录 · 石刻拓本目录 · 缩微资料目录 |
| **B 版本 / 文本状态** | 初版 · 增订版 · 善本（宋元本 / 活字本 / 和刻本）· 稿本 · 批校本 · 钞本 · 禁毁本 · 删节本 | 善本书目 · 稿本目录 · 禁书目录 |
| **C 文献类型 / 出版方式** | 政府出版物 · 学位论文 · 专利 · 标准 · 技术报告 · 会议录 · 连续出版物 · 内部资料 · 灰色文献 · 自印本 | 学位论文目录 · 专利文献目录 · 标准目录 |
| **D 版式 / 装帧 / 开本** | 大开本 · 袖珍本 · 盲文 · 大字本 · 特殊装帧 · 限量印本 | 盲文读物目录 · 大字本图书目录 |

> 📌 **语种与文字形态不归 014**：语种用 UDC **语言复分号** =（后接语言号，如 `=581` 汉语）表示，不构成「作品自身的特征」；文字 / 书写系统另有专类，归 `003`（[[003-书写体系与文字|003 书写体系与文字]]）。二者均不入特征谱。
>
> 📌 特征可叠加，但**主轴只取一个**：如「民国时期上海出版的线装书」= 地方（015）＋ 装帧（014）＋ 时期复分，须择主轴并互相参见，不可四投。

## 四、与兄弟类的六个易错点

| # | 情形 | 正解 | 理由 |
|:-:|:-----|:-----|:-----|
| 1 | 「善本书目」 | **014** | 特征＝版本状态；不是主题，也不是某馆收藏 |
| 2 | 「国家图书馆善本目录」 | **017/019** | 落在**某一收藏**的清单 |
| 3 | 「宋代刻本目录」 | **014** | 版本特征为主轴；「宋代」是时期限定，不构成 015 |
| 4 | 「福建刻本目录」 | **015 或 014** | 若「福建」指**刻书地**→015；若强调**建本版式特征**→014；须看标题的意图 |
| 5 | 「商务印书馆出版物目录」 | **012** | 特定组织出版的作品书目 |
| 6 | 「儿童图画书目录」 | **016** 或 **011** | 「儿童出版物」在 UDCS 是 `016:087.5` 的官方示例 ⇒ 主题 / 读者对象轴，非载体 |

> ⚠️ 第 6 条尤其反直觉：**读者对象不是「作品特征」而是「选材主题」**，UDCS 用 `016:087.5` 明示。同理「少儿」「青少年」「大字本给老人」要分开看——载体特征归 014，读者群体归 016。

## 五、怎么做：特征书目的著录要点

| 要点 | 说明 |
|:-----|:-----|
| **特征定义前置** | 「善本」按年代还是按稀有度？「政府出版物」含不含地方文件？定义写在前言 |
| **判定的可复核性** | 每条目注明该特征的**依据**（版本项 / 载体项 / 文件类型号） |
| **著录深度** | 特征书目常需超出基本著录：行款 · 版框 · 牌记 · 避讳 · 纸张 · 装帧 |
| **鉴别与存疑** | 特征判定本身是研究结论 ⇒ 设「存疑 / 待考」类，不可强行归类 |
| **载体转换** | 缩微 / 数字化后，原件的特征是否随复制品丢失，须写明依据的是原件还是复制件 |
| **与馆藏目录的分工** | 014 记「世界上存在哪些这样的东西」，017/019 记「本馆有哪些」 |

## 六、中国传统中的「具体特征书目」

| 形态 | 说明 | 与 UDC 014 的关系 |
|:-----|:-----|:------------------|
| **善本书目** | 宋元旧椠、名家批校的登记 | 最典型的 014（版本特征） |
| **稿本 / 抄本目录** | 未刊文本的清查 | 014（文本状态） |
| **禁书目录** | 禁毁、抽毁书目 | 014（流传状态）＋ 政治史语境 |
| **金石 / 碑帖目录** | 拓本、石经的著录 | 014（载体形态），近 [[002-文档、书籍、著作、著作人|002]] |
| **敦煌遗书目录** | 写本群的编目 | 014（写本）＋ 015（藏地）交叉 |
| **丛书子目** | 丛书所含子目的揭示 | ⚠️ 近 UDC `08`（集体作品），不必然是 014 |

> 中国传统目录学以「版本目录」「金石目录」承载 014 的功能；「具体特征」是 UDC 的分析概念，不是传统类目名。

## 七、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 古籍整理 | 先用 014 摸清版本谱系，再回 012 查个人著述 |
| 特藏建设 | 014 定「收什么特征」，017/019 核「本馆已有」 |
| 文献类型研究（学位论文 / 专利 / 标准） | 014 是这类文献的**唯一入口层** |
| 数字化选目 | 按载体特征筛选（稿本、拓本优先） |
| 版本鉴定 | 特征书目是鉴定参照系，非鉴定结论 |

## 八、核心问题

> 「特征」看似客观（是写本还是刊本），实则随技术与制度重划：缩微、影印、数字化之后，**原件特征与复制品特征分离**——014 究竟登记「物」，还是登记「文本」？
