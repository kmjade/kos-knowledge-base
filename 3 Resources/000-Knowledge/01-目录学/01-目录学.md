# 010 目录学（书目学）

> **UDC 01 / DDC 010** — 目录学、书目学（Bibliography）。
> 研究文献目录的编制、著录、组织与检索。
> 「目录学」为学科中文总名，「书目学」为其对译别名；本子库统合**中国目录学传统**（叙录 / 四部 / 目录类型）与**西方书目编目**（ISBD / MARC / FRBR / BIBFRAME）。
> 四体系类号：DDC `010` · UDC `01` · CLC `G25` · LCC `Z`。

> 分工：本页（01 目录学）讲**学科**——书目如何著录、编目与控制；`011`–`016` 收**书目成果**（bibliography）——某一范围、某一人、某一类作者、某一特征或某一主题有哪些书、怎么查；`017`–`019` 收**目录**（catalogue）——**某一实际收藏**里有哪些书。
> ⚠️ **014 的 DDC/UDC 类号不等价**：DDC 014 仅匿名与伪名著作书目（窄），该子集在 UDC 归 `012`。
> ⚠️ **书目 vs 目录**：问「换个图书馆，这份清单还成立吗？」——成立是书目（011–016），不成立是目录（017–019）。

## 核心问题

如何系统化地记录、描述、组织与检索文献，使「文献资源的全貌」可被揭示与利用？

## 学习路径

1. **入门** → 目录学导论（定义、历史、四体系类号）
2. **核心** → 书目著录与编目（ISBD / MARC / 著录单元）
3. **深化** → 书目控制与标准（FRBR / 规范控制 / 联合目录）
4. **中国古典** → 中国目录学源流与四部（刘向刘歆 → 经史子集）→ 类型与方法（叙录 / 辨章学术考镜源流）
5. **前沿** → 数字时代的目录学（BIBFRAME / 关联数据 / 语义网）
