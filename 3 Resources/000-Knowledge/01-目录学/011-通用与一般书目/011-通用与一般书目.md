# 011 通用与一般书目

> **UDC 011 / DDC 011** — 通用与一般书目（General Bibliographies）：**不局限于某一作者、国家、主题或格式**，把跨领域出版物汇成可查检的清单。
> 范围注释（UDCS 中文版）：**「不局限于某一作者、国家、主题或格式」**。
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/011-通用与一般书目/`。
> 与 [[010-书目学|010 目录学（主类总览）]] 的分工：**010 讲书目是什么、怎么著录；011 收书目成果本身**。

## 一、先分清：学科 vs 书目

同一件事在库里有两个落位，别混：

| 层 | 回答的问题 | 落位 |
|:--|:--|:--|
| **目录学（学科）** | 书目如何著录、编目、控制与检索？ | [[01-目录学|01 目录学]]（导论 / ISBD / MARC / FRBR / BIBFRAME） |
| **书目（成果）** | 某一范围内**有哪些书**？怎么查？ | 本页（011 通用与一般书目） |

> 📌 本页不重复讲著录规则；它只登记**书目类型、代表书目与查检入口**。遇到「这本书怎么著录」→ 回 `01-目录学`；遇到「还有哪些书没找到」→ 留在本页。

## 三、书目类型与类号归属

> ⚠️ **只有第一行属于本支线（011）**。其余类型是 UDC `01` 的**兄弟类号**——常被笼统叫作「书目」，但落位不同。

| 类型 | UDC | 收什么 | 典型代表 |
|:-----|:---:|:-------|:---------|
| **通用与一般书目** | **011** | 不限作者 · 国家 · 主题 · 格式 | 格斯纳《万有书目》（*Bibliotheca Universalis*）· 跨领域综合书单 |
| 作者 / 个人书目 | 012 | 某作者的作品、版本、佚名作品；特定组织出版的作品 | 个人著作目录 · 出版社书目 |
| 集体书目 | 013 | 某一**类**作者（职业 / 语种 / 时期 / 国籍） | `013:32(430)` 德国政治家书目 |
| 具体特征作品书目 | 014 | 按作品的具体特征汇总 | —（UDCS 无进一步注释） |
| 地方书目 | 015 | **国家书目** · 地方与区域书目 | British National Bibliography（BNB）· 《中国国家书目》· 《全国总书目》 |
| 专题目录 | 016 | 某一学科 / 主题 | `016:011` 一般书目的书目 · `016:929` 传记目录 |
| 馆藏目录 | 017/019 | 实际收藏清单 · 图书馆目录 | Library of Congress Catalog · 国家图书馆 OPAC |
| 营业 / 在版书目 | 017 | 出版商与书商的商业贸易目录 | *Books in Print*（BIP）· 出版社年度目录 |
| 主题目录 | 017 | 分类或系统目录 · 字母主题目录 | 分类目录 · 字顺主题目录 |
| 人名目录 | 018 | 作者目录 · 人名与地点字顺目录 · 标字目录 | 著者目录 |
| 联合目录 · 字典目录 | 019 | 多馆合并 · 单一次序混合条目 | [[联合目录\|WorldCat]] · CALIS 联合目录 |

## 四、一部书目由什么构成

| 部件 | 说明 | 查检时的用处 |
|:-----|:-----|:-------------|
| **收录范围声明** | 时间 · 语种 · 载体 · 地区 · 选题标准 | 判断「没查到」是没收还是不存在 |
| **编排方式** | 分类 · 字顺（著者 / 书名）· 年代 · 地区 · 字典式 | 决定从哪个入口查 |
| **著录项** | 责任者 · 题名 · 版本 · 出版项 · 页数 · 价格 | 复制准确的引文信息 |
| **提要 / 叙录** | 内容摘要与评价 | 判断是否值得取阅（[[叙录\|叙录]]传统） |
| **辅助索引** | 著者 · 书名 · 主题 · 丛书 | 弥补单一编排的盲区 |
| **馆藏 / 可得性** | 收藏馆 · 索书号 · 在售状态 | 从「知道」到「拿到」 |

> 📌 **先读前言**。书目的前言通常写明收录范围与编排规则；跳过它，后续所有「查不到」都无法解释。

## 五、怎么用

| 场景 | 首选入口 | 注意 |
|:-----|:---------|:-----|
| 确认某书是否存在 / 版本 | 国家书目 · 馆藏目录 | 国家书目登记「出版过」，馆藏目录证明「现在在哪」 |
| 系统找某一主题的书 | 016 专题目录（待建） | 通用书目只给线索，不替代专题目录 |
| 采购 / 馆藏建设 | 在版书目 · 营业书目 | 在版状态随时变动，需标注查询日期 |
| 追溯一人一书的全部版本 | [[012-作者书目、个人书目|012 作者书目、个人书目]] · [[版本目录]] | 版本目录与个人书目互补 |
| 跨馆借阅 | [[联合目录\|联合目录]] | 先查联合目录，再查单馆 OPAC |
| 了解某学科的研究脉络 | 综述 + 专题书目 | 通用书目不含评价，不能替代学术综述 |

## 六、数字时代的「总书目」

传统总书目是**印本清单**；今天同一功能分散在若干系统里：

| 形态 | 例子 | 变化 |
|:-----|:-----|:-----|
| 联机公共目录（OPAC） | 各国国家图书馆 OPAC | 实时、可检索，但只覆盖本馆 |
| 联合目录 | WorldCat · CALIS | 跨馆聚合，覆盖广但元数据质量不一 |
| 元搜索 / 发现系统 | 图书馆发现层 | 聚合纸本与电子资源，结果排序不透明 |
| 关联数据书目 | BIBFRAME · Wikidata | 从「记录」转向「实体关系」 |
| 商业书目数据库 | BIP · 各出版社平台 | 在版信息最全，但受商业授权限制 |

> ⚠️ **数字书目不是「更全的印本」**：它带来**实时性**，也带来**覆盖碎片化**与**排序黑箱**。查证时要记录**查的是哪个系统、哪一天**。
