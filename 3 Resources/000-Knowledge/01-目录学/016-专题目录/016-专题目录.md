# 016 专题目录

> **UDC 016 / DDC 016** — 专题目录（Subject Bibliographies）：按**主题**汇成的书目——不管作者是谁（012/013）、不管版本形态（014）、不管出版地（015）。
> 归属判据一句话：**看选材标准落在「讲什么」还是「谁写的 / 什么样的 / 哪里出的」。**
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/016-专题目录/`。

## 一、类号与边界

| 体系 | 类号 | 类目 |
|:----|:---:|:----|
| UDC | **016** | 专题目录 |
| UDC 上位 | 01 | 书目、目录 |
| DDC | **016** | Bibliographies and catalogs of works on specific subjects（专题文献书目与目录） |
| DDC 上位 | 010 | Bibliography（书目总类） |
| CLC | G257 · Z88 | 目录学 · 专科目录 |
| LCC | **随主题归入各学科类** | LCC 不把专题书目集中在 Z，而是分入被研究学科（如法律书目入 K） |

> 📌 **UDCS 记录 `13358` 未给 016 范围注**，只给四个**合并示例**（见第二节）。本页范围由示例 + 兄弟类分工反推；实编以 UDC 完整版 016 注为准。

**与兄弟类号的分工**

| 类号 | 类目 | 轴的落点 | 关键判据 |
|:----:|:-----|:---------|:---------|
| 011 | 通用与一般书目 | 四轴皆不限 | 若以「书目」为专题 ⇒ `016:011` |
| 012 | 作者书目、个人书目 | 一个人 | 选材是**人** |
| 013 | 集体书目 | 一类作者 | 选材是**作者身份** |
| 014 | 具体特征作品书目 | 作品自身特征 | 选材是**形态 / 类型** |
| 015 | 地方书目 | 出版 / 收藏地 | 选材是**地方** |
| **016** | **专题目录** | **主题** | 选材是**讲什么**（本页） |
| 017 / 019 | 目录 | 某一实际收藏 | 记「本馆有哪些」而非「世上有什么」 |

> ⚠️ **016 与 017 是最实质的一组对立**：`016` 是 **bibliography**（跨馆、跨地的文献清单），`017` 是 **catalogue**（某一收藏的清单）。UDCS 给 `017` 的类名正是「通用目录、**主题目录**」，两个中文名都含「主题」，极易误合。

## 二、怎么造号：016 + 主类号

UDCS 给出的四个官方合并示例，正好示范了四种典型构造：

| 示例 | 读法 | 示范的是 |
|:-----|:-----|:---------|
| `016:011` | 一般书目的书目 | **元层**：以「书目」为专题（书目之书目） |
| `016:087.5` | 儿童出版物目录 | **读者对象 / 主题**：儿童读物 |
| `016:34(05)` | 法律期刊目录 | **主题 + 类型限定**（`(05)` 连续出版物） |
| `016:929` | 传记目录 | **体裁 / 学科**：传记 |

> 📌 结构：**先 016，再以 `:` 接主类号**。主题词从主表取号，不是自造词表——这与图书馆「主题标目」不同，016 是**分类号组合**，不是主题词。

> ⚠️ **`016:34(05)` 的启示**：文献类型（期刊）在这里是**附带限定**，主轴仍是「法律」。所以「法律期刊目录」→ 016，而「学位论文目录」（类型本身即主题）→ 014。**看标题里的主轴词落在哪。**

## 三、收什么

| 专题类型 | 说明 | 例 |
|:-----|:-----|:-----|
| **学科专题** | 一个学科 / 分支的文献总目 | 法律文献目录 · 数学文献目录 |
| **人物专题** | 关于某人的研究文献（非其著作） | 鲁迅研究书目（≠ 鲁迅著作目录，后者归 012） |
| **事件 / 问题专题** | 某一事件、争论、政策领域 | 某议题文献目录 |
| **体裁 / 文献类型专题** | 类型本身即主题 | 传记目录 `016:929` · 儿童读物 `016:087.5` |
| **元书目** | 以书目为对象 | 书目之书目 `016:011` |
| **交叉专题** | 两学科交界 | 需择一主号 + 参见 |
| **推荐 / 举要书目** | 精选而非全备 | 读书记 · 导读书目（⚠️ 与 `011` 的推荐书目易混） |

> ⚠️ **「关于某人的研究文献」≠「某人的著作」**：前者是**主题**（016，研究对象是人），后者是**作者**（012）。这一对最常错。

## 四、专题书目的五个难点

| 难点 | 问题 | 处理 |
|:-----|:-----|:-----|
| **主题粒度** | 「医学」还是「中医内科」？ | 明示收与不收的边界，宁窄勿含糊 |
| **跨学科** | 同一文献属多个专题 | 定主号 + 在余处互见，不重复全录 |
| **半衰期** | 科技 / 法律专题书目几年即废 | 标**收录截止日**与更新计划 |
| **全备 vs 精选** | 求全则臃肿，精选则失据 | 前言写明「穷举式」还是「选择式」 |
| **与学科综述之别** | 书目只列，综述要评 | 可加提要，但**不作研究结论** |
| **语言 / 地域覆盖** | 只收中文？只收本国出版？ | 明示语种与出版地范围 |

> 📌 专题书目的价值不在「多」，而在**边界可判**：读者要能判断「没查到」是**没有**，还是**没收**。

## 五、编排方式

| 方式 | 适用 | 说明 |
|:-----|:-----|:-----|
| **按分类** | 学科内部结构清晰 | 与分类法对齐，便于系统检索 |
| **按主题词字顺** | 主题分散、跨类 | 需配分类索引 |
| **按年代** | 史学研究、事件专题 | 看研究脉络演进 |
| **按文献类型** | 类型专题（期刊 / 学位论文） | 类型内再按主题 |
| **混合** | 大型专题书目 | 分类为主 + 著者 / 主题 / 年代三索引 |

> 常见结构：**前言（范围 · 截止日 · 选材标准）→ 分类总表 → 条目（可带提要）→ 著者索引 → 主题索引 → 未收文献说明**。

## 六、中国传统中的「专题目录」

| 形态 | 例 | 与 UDC 016 的关系 |
|:-----|:---|:------------------|
| **专科目录** | 《经义考》（朱彝尊）· 《小学考》（谢启昆）· 《医籍考》（丹波元胤） | 最典型的 016（学科专题） |
| **佛经目录** | 《出三藏记集》（僧祐）· 《开元释教录》（智昇） | 016（宗教文献专题）＋ 014（译经体例）交叉 |
| **书目之书目** | 历代「目录之目录」 | `016:011` |
| **举要 / 导读目录** | 《书目答问》（张之洞） | ⚠️ 精选 + 治学门径，介于 016 与 `011` 推荐书目 |
| **史志中的「目录类」** | 正史艺文志内的目录门 | 书目**被著录**的位置，不是书目本身 |

> 中国传统「专科目录」与 UDC 016 高度对应；差别在传统目录多以**四部框架内的学科**切分，而 UDC 用主类号组合。

## 七、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 进入一个新领域 | 先找该领域 016 专题书目 → 再顺条目查原文 |
| 文献综述起步 | 016 定范围，综述做评价；二者不互替 |
| 学科史研究 | 按年代排布的专题书目可作研究热度指标 |
| 馆藏补缺 | 016 作理想清单，017/019 核实际馆藏 |
| 交叉学科定位 | 看同一文献在不同专题书目中的归属差异 |

## 八、核心问题

> 专题书目按「主题」划界，而主题的切分本身来自学科建制——**先有学科，才有专题书目；还是专题书目在反复划界中把学科做出来？**
