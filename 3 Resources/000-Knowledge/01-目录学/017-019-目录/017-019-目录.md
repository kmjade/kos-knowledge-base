# 017/019 目录

> **UDC 017/019 / DDC 017–019** — 目录（Catalogues）：**某一实际收藏**的清单。
> 包括注（UDCS）：**「实际收藏清单、图书馆目录、出版商和书商清单等。」**
> 这是 01 支线里唯一**不是书目（bibliography）**的一族 —— 前六条（011–016）回答「世上有什么」，这一族回答「**这里有什么**」。
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/017-019-目录/`。

---

## 一、这一类是什么：目录 ≠ 书目

| | 书目（011–016） | **目录（017/019）** |
|:--|:--|:--|
| 英文 | Bibliography | **Catalogue** |
| 回答 | 世上存在哪些文献 | **某一收藏里有哪些文献** |
| 边界 | 由主题 / 作者 / 特征 / 地方划定 | 由**藏品的物理范围**划定 |
| 完备性 | 力求穷举（可跨馆、跨国） | 只对本收藏完备 |
| 失效 | 随新书出现而过时 | 随**藏品变动**（入藏 / 注销 / 移库）而过时 |
| 典例 | 《全国总书目》 | 某馆 OPAC |

> 📌 **一句话判据**：问「换个图书馆，这份清单还成立吗？」——成立是书目，不成立是目录。

## 二、类号与三个子类

UDC 用**跨度号 `017/019`** 统摄三个并列类，各有独立范围：

| 类号 | 类目 | 包括注（UDCS） | DDC 对应 |
|:----:|:-----|:---------------|:--------|
| **017** | 通用目录、主题目录 | 分类或系统目录 · 字母主题目录 · **出版商与书商的商业贸易目录** | 017 General subject catalogs |
| **018** | 人名目录 | 作者目录 · 人名和地点字母目录 · **标字目录** | 018 Catalogs arranged by author, date, etc. |
| **019** | 字典目录 | **联合目录** · **仓储** | 019 Dictionary catalogs |
| — | 范围注释（019） | 「包含作者、题名、标字、字母主题条目等**单一次序**的目录」 | — |

> ⚠️ **017 的类名是个陷阱**：它把「通用目录」与「主题目录」并列 —— 指的是**主题检索入口**（分类号顺序 / 主题词字顺），不是「专题书目」（那是 [[016-专题目录|016]]）。看的是**清单属于某个收藏**还是**跨馆的文献清单**。

## 三、为什么用 `017/019` 跨度：同一批藏品的三种排法

三个子类不是三种东西，而是**同一批藏品的三种排列方式**：

| 排法 | 类号 | 检索问题 | 缺点 |
|:-----|:----:|:---------|:-----|
| 按**分类 / 主题**分立 | 017 | 「这类书有哪些？」 | 需先懂分类法 |
| 按**人名**分立 | 018 | 「这个人写过 / 被写过什么？」 | 不知人则无从查 |
| **单一顺序混排**（字典式） | 019 | 作者名、题名、主题词混排一处，**一查即中** | 条目臃肿、顺序规则复杂 |

> 📌 `019` 字典目录是**西方图书馆的关键发明**：把作者、题名、主题、丛书各条目按**唯一字顺**混排，读者无需先判断「我该查哪个目录」。UDC 把「联合目录」也放在 019，因为联合目录同样以**单一顺序**跨馆混排。

## 四、收什么 / 不收什么

| 内容 | 归 017/019 | 去向 |
|:-----|:----------:|:-----|
| 某馆馆藏目录（含 OPAC） | ✅ | — |
| 联合目录（跨馆合并） | ✅ | `019` |
| 出版社目录 · 书商营业目录 · 在版书目 | ✅ | `017`（商业目录） |
| 私人藏书目录 / 藏书志 | ✅ | `017` 或 `018`，视排法 |
| 仓储 / 保存库清单 | ✅ | `019` |
| 国家书目（跨馆、力求全备） | — | ❌ → `015`（包括注明列国家书目） |
| 专题书目（跨馆） | — | ❌ → [[016-专题目录\|016]] |
| 善本书目（跨馆的版本清单） | — | ❌ → [[014-具体特征作品书目\|014]] |
| 一个人的著作目录 | — | ❌ → [[012-作者书目、个人书目\|012]] |
| 图书的分类**规则**、编目**标准** | — | ❌ → [[01-目录学\|01 目录学]]（010） |

## 五、书目 vs 目录：四组易错配对

| 配对 | 书目侧 | 目录侧 | 判据 |
|:-----|:-------|:-------|:-----|
| 国家书目 vs 馆藏目录 | `015` | `017` | 是否跨馆、是否求全备 |
| 专题书目 vs 主题目录 | `016` | `017` | 跨馆文献清单 vs 本馆主题入口 |
| 善本书目 vs 善本馆藏目录 | `014` | `017/018` | 「世上有哪些善本」vs「本馆有哪些善本」 |
| 个人著作目录 vs 著者目录 | `012` | `018` | 一个人 vs 一馆藏品的著者入口 |

> ⚠️ 四组里最常错的是第二组，因为 UDCS 给 `017` 的类名就叫「**主题目录**」，与 `016`「专题目录」只差一字。

## 六、中国传统中的「藏书目录」

| 形态 | 说明 | 与 017/019 的关系 |
|:-----|:-----|:------------------|
| **私家藏书志 / 藏书目录** | 如《百宋一廛书录》《皕宋楼藏书志》 | `017` 或 `018`，视其排法 |
| **官修藏书目** | 内阁、翰林院、国子监藏书清单 | `017` |
| **书院 / 寺观藏书目** | 机构藏书登记 | `017` |
| **书业目录** | 坊刻书目、书局营业目录 | `017`（UDCS 明列商业贸易目录） |
| **联合目录**（现代） | 跨馆合并的书目数据库 | `019` |
| **四库全书总目** | ⚠️ **不是目录** | 评述性**书目**，近 [[011-通用与一般书目\|011]] / [[016-专题目录\|016]] |

> 中国传统「目录」一词兼含书目与目录二义，英文 bibliography / catalogue 的分野是**引入概念**；本支线用「典藏范围」作判据，比用中文词面可靠。

## 七、数字时代的「目录」

| 形态 | 变化 | 未变 |
|:-----|:-----|:-----|
| OPAC → 发现系统 | 单一顺序被**相关性排序**取代 | 仍只覆盖本馆（或本联盟）藏品 |
| 联合目录 → 联盟目录 / 元数据云 | 覆盖范围扩大 | 仍是「实际收藏」的集合 |
| 出版社目录 → 电商数据库 | 载体全变 | 仍是商业供给清单 |

> 📌 `019` 的「单一顺序」在数字环境里被**检索取代**——但「目录 = 某收藏的清单」这个**语义内核没有变**。

## 八、核心问题

> 当检索可以任意组合、排序随时重算，「**单一顺序**」还剩下什么？`019` 字典目录的立身之本（读者不必先知道该查哪个入口），是否已被全文检索彻底吸收？
