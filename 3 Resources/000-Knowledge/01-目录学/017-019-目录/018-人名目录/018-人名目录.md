# 018 人名目录

> **UDC 018 / DDC 018** — 人名目录：按**责任者 / 人名**组织的**收藏清单**。
> 包括注（UDCS）：**「作者目录、人名和地点字母目录、标字目录。」**
> 上位：[[017-019-目录|017/019 目录]]。
> 落位：`01-目录学/017-019-目录/018-人名目录/`。

---

## 一、类号与边界

| 体系 | 类号 | 类目 |
|:----|:---:|:----|
| UDC | **018** | 人名目录 |
| UDC 上位 | 017/019 | 目录 |
| DDC | **018** | Catalogs arranged by author, date, etc. |
| CLC | G254.3 | 目录组织（著者目录） |
| LCC | Z695.5 | Author cataloging |

**与最近三类的分工**

| 类号 | 类目 | 判据 |
|:----:|:-----|:-----|
| [[017-通用目录、主题目录\|017]] | 通用目录、主题目录 | 同一收藏，按**内容**排 |
| **018** | 人名目录 | 同一收藏，按**人**排（本页） |
| [[019-字典目录\|019]] | 字典目录 | 同一收藏，**多入口混排** |
| [[012-作者书目、个人书目\|012]] | 作者书目、个人书目 | **跨馆**的某一作者著作清单 |

> ⚠️ **最硬的一对**：`012` 是「这个人写过什么」（跨馆著作目录）；`018` 是「本馆藏书中，这个人参与的有哪些」（馆藏著者入口）。同一作者，两种东西。

## 二、三件为什么同放一类

| 项 | 是什么 | 为何属 018 |
|:---|:-------|:-----------|
| **作者目录** | 按个人 / 团体责任者名称字顺排列 | 人名作唯一入口 |
| **人名和地点字母目录** | 著者名**与地名**同一字顺排列 | 地名在此充当**责任者 / 机构名**（如某地政府），不是主题 |
| **标字目录** | 取题名中**关键词（标字）**作标目，字顺排列 | 标目仍是「词」，但取词位置不同 —— **待核**（UDCS 仅给类名，无定义） |

> 📌 「地点」出现在 018 而非 017，正好说明：**同一个地名词，作责任者入 018，作主题入 017**。这是人名目录最能暴露「词面相同、角色不同」的地方。

## 三、著者目录的核心问题：名称是什么

| 问题 | 表现 | 处理 |
|:-----|:-----|:-----|
| **同名异人** | 两个「张伟」 | 加生卒年 / 学科 / 机构限定 |
| **异名同人** | 本名 · 笔名 · 字号 · 译名 | **规范控制**建参照（见 / 参见） |
| **团体名称变迁** | 机构改名、合并 | 以现行名为准 + 历史名参见 |
| **译名不一** | 同一外籍作者多种译法 | 统一译名表 + 原文名参见 |
| **无责任者** | 佚名、集体编纂 | 题名或编纂机构入口 |
| **会混排** | 个人与机构是否插入同一字顺 | 须在前言写明 |

> 📌 这一支线是**规范控制（Authority Control）**在目录层面最集中的体现 —— 与 [[01-目录学|010]] 的 [[规范控制]]、[[书目控制]] 直接对接。

## 四、编排与著录要点

| 要点 | 说明 |
|:-----|:-----|
| **标目形式** | 姓前名后 / 名前姓后，须全馆一致 |
| **字顺规则** | 汉字按笔画 / 拼音 / 四角号码；西文按逐词或逐字母 —— **规则须写明** |
| **团体标目层级** | 国—省—市—机构，或倒置式 |
| **数目（entry）类型** | 主要数目 / 附加数目 / 统一题名 |
| **参照与见卡** | 异名指向规范名，不可双向循环 |
| **与主题目录的互补** | 同一藏品两个入口，须共享规范档 |

## 五、中国传统中的对应形态

| 形态 | 说明 | 与 018 的关系 |
|:-----|:-----|:--------------|
| **著者索引** | 书目后附的人名索引 | 018 的索引形态（不独立成目） |
| **人名 / 传记目录** | 按人编的文献清单 | ⚠️ 若以「研究某人」为主题 ⇒ 近 [[016-专题目录\|016]] |
| **丛书子目著者索引** | 按人查丛书所收 | 018 |
| **族谱 / 传记书目** | 世家、学案体 | ⚠️ 学案体是**学术史**，非目录 |

> 中国传统目录主流是**分类目录**，独立的人名目录（著者目录）是近代图书馆制度化的产物。

## 六、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 已知作者找其全部馆藏作品 | 查作者目录 |
| 查某机构的出版物 | 机构名入作者目录 |
| 译名不确知 | 先查规范档再回作者目录 |
| 作者研究 | 018 找馆藏，[[012-作者书目、个人书目\|012]] 找全貌 |
| 名称规范维护 | 018 是新旧名参照的落地处 |

## 七、核心问题

> 作者目录默认「人」是作品的稳定锚点。但当作品有多个责任者、机构频繁重组、作者用笔名与 AI 合著并行时，**以人名作唯一入口是否仍是合理的组织原则**？
