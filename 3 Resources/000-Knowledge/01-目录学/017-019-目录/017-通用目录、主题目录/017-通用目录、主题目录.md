# 017 通用目录、主题目录

> **UDC 017 / DDC 017** — 通用目录、主题目录：按**知识内容**（分类号或主题词）组织的**收藏清单**。
> 包括注（UDCS）：**「分类或系统目录、字母主题目录、出版商与书商的商业贸易目录。」**
> 上位：[[017-019-目录|017/019 目录]]（这是「目录」不是「书目」）。
> 落位：`01-目录学/017-019-目录/017-通用目录、主题目录/`。

---

## 一、类号与边界

| 体系 | 类号 | 类目 |
|:----|:---:|:----|
| UDC | **017** | 通用目录、主题目录 |
| UDC 上位 | 017/019 | 目录 |
| DDC | **017** | General subject catalogs |
| CLC | G254.3 | 目录组织（分类目录 / 主题目录） |
| LCC | Z695–Z695.9 | Subject cataloging（主题编目规则） |

**与最近三类的分工**

| 类号 | 类目 | 判据 |
|:----:|:-----|:-----|
| **017** | 通用目录、主题目录 | **某一收藏** ＋ **按知识内容排** |
| [[016-专题目录\|016]] | 专题目录 | **跨馆**的文献清单（主题只是选材标准） |
| [[018-人名目录\|018]] | 人名目录 | 同一收藏，按**责任者**排 |
| [[019-字典目录\|019]] | 字典目录 | 同一收藏，**多入口混排** |

> ⚠️ **017 vs 016 只差一字**：UDCS 给 017 的类名正是「**主题目录**」，与 016「专题目录」形近。分野只有一条 —— **清单是否属于某个实际收藏**。

## 二、三件为什么同放一类

包括注列了三样看似不同的东西，共同点是**按「内容 / 供给」而非按人名组织**：

| 项 | 是什么 | 为何属 017 |
|:---|:-------|:-----------|
| **分类目录 / 系统目录** | 按分类法（DDC / UDC / 中图法）号序排列的馆藏清单 | 内容入口，号码即主题 |
| **字母主题目录** | 按主题词字顺排列的馆藏清单 | 内容入口，词即主题 |
| **出版商 / 书商商业贸易目录** | 出版社、书商的**可供书目**（stock list） | 是「某供给方库存」这一实际收藏的内容清单 |

> 📌 商业目录归 017 而非 [[011-通用与一般书目|011]]，关键在于它是**某一书商当下有什么**，不是**世上出版过什么**。

## 三、分类目录 vs 主题目录

| | 分类目录（Classified） | 主题目录（Alphabetical Subject） |
|:--|:--|:--|
| 排列 | 分类号顺序（系统性） | 主题词字顺（离散性） |
| 优点 | 同族文献**集中**，可见学科结构 | 一词直达，**不必懂分类法** |
| 缺点 | 读者须先知道「归哪类」 | 同族文献被词表切散 |
| 依赖 | 分类法 + 分类号 | 主题词表 / 叙词表 + 参见 |
| 补救 | 配**分类号—主题词对照索引** | 配**词表参照（见 / 参见）** |

> 📌 两者是**同一批藏品的两个内容入口**，互为补充；UDC 把它们并入一类，正因为功能等价。

## 四、编排与著录要点

| 要点 | 说明 |
|:-----|:-----|
| **分类号来源** | 标明所用分类法及版本（不同版本号可能不同） |
| **号码层级的可见性** | 上级类目下是否设「见下位类」指引 |
| **交叉学科** | 多处分组的取舍规则（主类 + 互见） |
| **主题词控制** | 是否用受控词表；自由词与规范词的区别 |
| **参见系统** | 「见」（use）与「参见」（see also）不可混 |
| **时效标注** | 分类法改版后旧号如何换算 |

## 五、中国传统中的对应形态

| 形态 | 说明 | 与 017 的关系 |
|:-----|:-----|:--------------|
| **四部分类的藏书目录** | 私家 / 官修藏书目按经史子集排 | 017（分类目录）＋ 传统分类法 |
| **坊刻书目 / 书局营业目录** | 书坊、书局的在售书目 | 017（UDCS 明列商业贸易目录） |
| **专科书目中的分类编排** | 如《经义考》按类排 | ⚠️ 跨馆 ⇒ [[016-专题目录\|016]]，不是 017 |
| **《四库全书总目》** | 四部分类 + 提要 | ⚠️ 评述性书目，非馆藏目录 ⇒ 011 / 016 |

> 中国传统目录学以「四部分类」为绝对主流，**主题字顺目录是近代随西方编目法引入**的形态。

## 六、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 找「这一类还有哪些」 | 查分类目录，沿号序扩展 |
| 只知概念不知归类的读者 | 查主题目录，词表直达 |
| 馆藏结构分析 | 统计各类号藏书量，看采购偏向 |
| 采购比对 | 商业目录作可采清单，分类目录作已有清单 |
| 分类法评估 | 看某类号下条目是否过密 / 过空 |

## 七、核心问题

> 分类目录把**分类法的世界观**强加给读者：读者必须接受「某主题归某类」才能找到书。当主题词表与分类法都可由机器重算，**目录还要替读者承担这个结构吗**？
