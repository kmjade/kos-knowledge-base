# 十三经

## 定义

十三经是南宋合刻的十三部儒家经典，是「经」这一文献谱系自先秦「六经」历次增并而定型的最终结果。

## 十三经一览

| 经 | 内容 |
|:----|:----|
| 周易 | 卜筮之书，后成为群经之首 |
| 尚书 | 上古政典、誓诰 |
| 诗经 | 风、雅、颂 |
| 周礼 | 官制 |
| 仪礼 | 礼仪程式 |
| 礼记 | 礼意与礼论 |
| 春秋左传 | 编年史传 |
| 春秋公羊传 | 今文义例 |
| 春秋谷梁传 | 今文义例 |
| 论语 | 孔子言行 |
| 孝经 | 孝道 |
| 尔雅 | 训诂辞典 |
| 孟子 | 战国儒学 |

## 形成过程

| 阶段 | 内容 |
|:----|:----|
| 先秦 | 「六经」（诗、书、礼、乐、易、春秋），《乐》亡佚 |
| 汉 | 「五经」博士（易、书、诗、礼、春秋） |
| 唐 | 「九经」（加三礼、三传）；开成石经合刻「十二经」（增《论语》《孝经》《尔雅》） |
| 南宋 | 增《孟子》，合刻「十三经」 |

## 注疏

- 唐宋形成「十三经注疏」体系，合经、注、疏为一体
- 注疏本既是经学成果，也是**经部**分类的主要著录对象
