# 经部

## 定义

经部是「经史子集」四部分类法之首，专收儒家经典及其注疏、训诂、文字音韵之书，是中国传统目录学中「以学统书」分类观最集中的体现。

## 经的成立与谱系

- 先秦已有「六经」之说（诗、书、礼、乐、易、春秋），《乐》经亡佚，汉立「五经」博士
- 唐孔颖达等撰《五经正义》，经义定于一尊；又以三礼（周礼、仪礼、礼记）、三传（左传、公羊、谷梁）扩为「九经」
- 唐文宗开成石经合刻「十二经」（增《论语》《孝经》《尔雅》）
- 南宋增入《孟子》，合刻为「十三经」，儒家「经」的谱系至此定型

## 目录学源流：从六艺略到经部

| 阶段 | 目录 | 形态 |
|:----|:----|:----|
| 西汉 | 刘歆《七略》 | 「六艺略」收易、书、诗、礼、乐、春秋——经部前身 |
| 西晋 | 荀勖《中经新簿》 | 四部之「甲部」纪经 |
| 唐 | 《隋书·经籍志》 | 正式以「经部」名之，列四部之首 |
| 清 | 《四库全书总目》 | 经部十类，四分格局集大成 |

## 四库经部十类

| 类 | 内容 |
|:----|:----|
| 易类 | 《周易》及历代易说 |
| 书类 | 《尚书》及注疏 |
| 诗类 | 《诗经》及诗说 |
| 礼类 | 周礼、仪礼、礼记、三礼总义、通礼、杂礼书 |
| 春秋类 | 《春秋》及三传 |
| 孝经类 | 《孝经》及解说 |
| 五经总义类 | 兼释群经之书 |
| 四书类 | 《大学》《中庸》《论语》《孟子》及合解 |
| 乐类 | 乐书、乐律 |
| 小学类 | 训诂、字书、韵书 |

## 目录学意义

- **位居四部之首**：分类即价值判断。「经」居首而史、子、集次之，直接映射「尊经」的传统学术秩序
- **以学统书**：经部不收经典正文，更收历代注疏、训诂、音韵，「学」随「书」入类
- **学术辨章**：小学（训诂、字书、韵书）本属语言文字，入经部而隶为经学附庸，正是「辨章学术，考镜源流」在分类上的投影
