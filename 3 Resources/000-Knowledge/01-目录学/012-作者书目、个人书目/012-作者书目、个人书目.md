# 012 作者书目、个人书目

> **UDC 012 / DDC 012** — 作者书目、个人书目（Personal Bibliography）：围绕**一个人**（或一个特定组织）汇总其作品、版本、译本与研究文献的书目。
> 范围注释（UDCS 中文版）：**「版本、内容、作者或佚名作品的书目。特定组织出版的作品书目。」**
> 所属：[[01-目录学|01 目录学]]（书目学支线）· 落位：`01-目录学/012-作者书目、个人书目/`。

## 二、收什么

| 部件 | 说明 |
|:-----|:-----|
| **原著目录** | 本人撰写 / 创作的作品，按体裁或年代排列 |
| **版本谱系** | 同一作品的不同版本、修订本、增订本、影印本 |
| **译本** | 外文译本、编译本、节译本 |
| **编纂 / 辑录作品** | 本人编校、辑佚、注释他人的作品（与「著作」分开） |
| **佚名 / 伪托作品** | 归属存疑、托名之作；须标证据与争议 |
| **序跋 / 题记** | 本人所写序跋，常另列 |
| **研究文献** | 他人研究该作者的专著、论文、年谱（secondary bibliography） |
| **特定组织出版物** | 某机构 / 出版社的全部出版物目录（UDCS 明列） |

> 📌 **个人书目不是「作品清单」的同义词**。它至少回答四个问题：他写过什么 · 有哪些版本 · 被译成什么 · 别人怎么研究他。

## 三、编排方式

| 方式 | 适用 | 优点 | 缺点 |
|:-----|:-----|:-----|:-----|
| **编年** | 创作时间可考 | 显示思想 / 风格演变 | 年代争议会传导到全书 |
| **体裁分类** | 作品类型清晰（诗 / 文 / 专著） | 便于按类查 | 跨类作品难安置 |
| **版本谱系** | 单一经典的深入研究 | 直接呈现文本流传 | 不适合全集 |
| **混合** | 多数个人书目 | 兼顾总览与细节 | 需靠索引弥补 |

> 常见结构：**总述 → 原著（编年或分类）→ 译本 → 编纂作品 → 伪托 / 存疑 → 研究文献 → 索引**。

## 四、方法：个人书目怎么做

| 步骤 | 要做的事 | 工具 / 传统 |
|:-----|:---------|:-----------|
| 1. 系年 | 确定每件作品的写作 / 发表时间 | 年谱 · 书信 · 日记 |
| 2. 辨伪 | 区分真作、伪托、误题 | 目录学 · 校雠学 |
| 3. 版本比对 | 记录版式、序跋、刻工、避讳 | [[版本目录]] |
| 4. 辑佚 | 从类书、总集、方志中钩沉佚文 | [[辑佚学]] |
| 5. 著录 | 统一题名、责任者、出版项 | [[著录]] · [[编目]] |
| 6. 作提要 | 说明内容、价值、真伪 | [[叙录]] 传统 |
| 7. 编索引 | 篇名 · 人名 · 主题 | — |

> ⚠️ **个人书目最难的不是「列全」，而是「归属」**：一篇文章是不是他的、一个版本是不是原刻、一条材料是不是误收。归属判断必须留证据链，不能只留结论。

## 五、中国传统中的「个人书目」

| 形态 | 说明 | 与 UDC 012 的关系 |
|:-----|:-----|:------------------|
| **别集 / 全集** | 一人作品的结果，本身不是书目 | 个人书目的**对象** |
| **著述考 / 著述目录** | 专门考订一人著作 | 最接近 `012` |
| **年谱中的著作系年** | 年谱附著作目录 | `012` 的编年形态 |
| **版本目录** | 专记一人一书的版本 | `012` 的版本谱系部分 |
| **研究文献目录** | 后人研究一人的成果 | `012` 的 secondary 部分 |

> 中国传统没有与 UDC `012` 完全对应的独立类目；「著述考」「版本考」「年谱」三者在功能上共同承担个人书目。

## 六、典型代表

| 类型 | 代表（示例） |
|:-----|:-------------|
| 西方作家个人书目 | 莎士比亚、狄更斯、乔伊斯等作家的 **primary + secondary bibliography** |
| 中国学者著述考 | 王国维、鲁迅、胡适等学者的著述目录与年谱 |
| 机构出版物目录 | 某大学出版社 / 学术机构的出版物总目（UDCS 明列） |
| 译本目录 | 某作家作品的外译总目 |

> ⚠️ 上表只给**类型示例**，不充当权威书目清单；具体书名与版本须以馆藏或正式书目核。

## 七、使用场景

| 场景 | 怎么用 |
|:-----|:-------|
| 研究某作者 | 先查个人书目 → 再查研究文献目录 → 最后查专题目录（016） |
| 编全集 / 文集 | 以个人书目为底本，补辑佚与版本校勘 |
| 查某书是否有中译 | 查译本部分，注意转译与节译 |
| 判断作品真伪 | 看个人书目是否收录、依据什么 |
| 馆藏建设 | 按作者集中采买，注意版本而非仅书名 |

## 八、核心问题

> 当「作者」本身就是一个历史建构——笔名、代笔、集体创作、后人追认——个人书目的边界应该划在**身份证上的那个人**，还是**文本背后的那个作者功能**？
