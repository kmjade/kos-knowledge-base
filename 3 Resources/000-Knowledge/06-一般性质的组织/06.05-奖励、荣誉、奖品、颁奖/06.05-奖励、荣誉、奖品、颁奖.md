# 06.05 奖励、荣誉、奖品、颁奖

> **UDC `06.05`** —— 奖励、荣誉、奖品、颁奖。本页记的是**「评选 → 授予 → 记录」这一整套机制**：谁有权颁、按什么标准评、奖意味着什么、又怎样被误用。
> 归属判据一句话：**看的是「一次被组织化的认可行为」，而不是「某项成果本身有多好」。**
> **上级**：[[06-一般性质的组织|06 一般性质的组织]]（容器直属子库，与 `raw/articles/` 下的主题支线平级）· 落位：`06-一般性质的组织/06.05-奖励、荣誉、奖品、颁奖/`。
> ⚠️ **编号性质**：`06.05` 是 UDC `06` 的**专用复分号**（复分机制见 [[06-组织和协会的专用复分|06 组织和协会的专用复分]]），**不是容器内流水号**；语义经用户提供，**待 UDCS 原文核验**（见待补）。

## 一、定位与边界

**这一页做什么**

| 面 | 范围 | 典型问题 |
|:--|:--|:--|
| 概念切分 | 奖励 / 荣誉 / 奖品 / 颁奖 四者的所指 | 「这个算荣誉还是奖品」 |
| 类型谱 | 授予主体 · 对象 · 依据 · 层级 | 「这奖是谁颁的，算什么级别」 |
| 机制 | 提名 → 评审 → 公示 → 授予 → 存档 | 「评选程序站不站得住」 |
| 效力 | 荣誉能兑换什么、会怎样被误读 | 「获奖等于能力强吗」 |
| 撤销 | 瑕疵与失德后的处理 | 「奖能收回吗」 |

**不做什么**

| 主题 | 去向 | 理由 |
|:--|:--|:--|
| 组织的会员资格与会士身份 | [[06.01-会员的权利与义务\|06.01 会员的权利与义务]] | 会员权；会士通常是荣誉，交叉在彼页 |
| 学会的会士制度与学术自治 | [[03-学会与学术团体\|03 学会与学术团体]] | 学术共同体的组织形态 |
| 期刊指标 · 同行评审 · 分区 | [[02-学术期刊与同行评审\|02 学术期刊与同行评审]] | 学术评价的计量面 |
| 学位 · 称号 · 职称评审 | [[37-教育\|37 教育]] · [[35-公共管理军事\|35 公共管理军事]] | 教育制度与国家功勋制度 |
| 体育竞赛与奖牌 | [[79-休闲娱乐游戏体育\|79 休闲娱乐游戏体育]] | 竞赛规则本体 |
| 具体奖项条目（诺奖 · 图灵奖 …） | 本支线 `wiki/entities/`；已成库者见 [[06.05NOBEL：172.4-诺贝尔和平奖\|06.05NOBEL:172.4 诺贝尔和平奖]] | 实例，不是机制 |

> ⚠️ **奖 ≠ 能力**：奖项是**一次组织的判断**，不是被测对象的属性。把「获奖」写进人物页当永久头衔，等于把一个事件固化成身份（记录方法见第八节）。

## 二、四组概念切分

| 概念 | 指向 | 载体 | 可否撤销 | 可否转让 / 继承 |
|:--|:--|:--|:--|:--|
| **奖励**（award / incentive） | 对某种**行为或成果**的回馈 | 决定 + 可能附奖金 | 可（造假 · 资格不符） | 否 |
| **荣誉**（honour / distinction） | 对**身份或贡献**的社会承认 | 称号 · 名衔 · 会士 | 可（程序重审） | 否 |
| **奖品**（prize / trophy） | 荣誉的**物质化** | 奖章 · 奖杯 · 证书 · 奖金 | 物可追回，荣誉须另议 | 物可转让，荣誉不可 |
| **颁奖**（ceremony / awarding） | 授予的**仪式与程序** | 典礼 · 公布 · 存档 | — | — |

**近邻六辨**

| 易混项 | 与「奖」的分界 |
|:--|:--|
| **奖金** | 钱是载体，不是荣誉本身；有奖无金、有金无奖都常见 |
| **称号**（如「某某学者」） | 称号偏身份，通常由制度授予并有任期 |
| **会士（Fellow）** | 学术团体的荣誉等级，不是会员类型的升级（见 [[06.01-会员的权利与义务\|06.01]]） |
| **学位 / 学历** | 由教育制度授予，含资格含义，不能与荣誉互换 |
| **认证 / 资质** | 认证是**门槛**（能不能做），奖项是**承认**（做得好不好） |
| **排名 / 榜单** | 排名是排序，奖项是判断；两者常被媒体并置而成误读 |

> ⚠️ **「国际大奖」不等于「国际组织颁发」**：判断级别看**授予主体与评审范围**，不看名称里有没有「国际」「全球」。

## 三、类型谱

| 轴 | 取值 | 说明 |
|:--|:--|:--|
| **授予主体** | 国家 / 政府间组织 · 学会与学术团体 · 行业与协会 · 企业 · 媒体 · 基金会 · 个人捐赠设立 | 决定正当性来源 |
| **对象** | 个人 · 团队 · 作品 · 机构 · 项目 | 团队奖的**署名与分摊**是常见争议 |
| **依据** | 成果竞赛 · 终身成就 · 会员等级 · 服务贡献 · 公众投票 · 提名委员会判断 | 依据决定可否复核 |
| **层级** | 国际 · 国家 · 省部 · 机构内 · 单位内 | 层级 ≠ 含金量，须看同层竞争范围 |
| **构成** | 仅荣誉 · 荣誉 + 奖金 · 荣誉 + 奖章 · 仅奖金 | 「有金无名」与「有名无金」动机不同 |
| **周期** | 年度 · 双年 · 一次性 · 追授 | 追授的资格与伦理另论 |

> 📌 **读奖项先问三句**：谁颁的（主体）· 评的是谁（对象与范围）· 凭什么（依据与程序）。三句答不全，这个奖的含金量无从判断。

## 四、评选机制

**标准流程六段**

| 段 | 内容 | 常见失误 |
|:--|:--|:--|
| ① 提名 | 自荐 / 推荐 / 机构提名，明确提名权归属 | 提名权集中在少数人 → 网络效应 |
| ② 资格审查 | 硬门槛（年限 · 身份 · 作品范围） | 门槛写着「原则上年满」→ 无法核 |
| ③ 评审 | 同行评议 · 委员会投票 · 公众投票 | 评委与被评人关系未申报 |
| ④ 决策与回避 | 定档 · 表决 · 利害关系人回避 | 回避只写在纸上 |
| ⑤ 公示与异议 | 公示期 · 异议受理 · 答复 | 公示期过短或名单先行外泄 |
| ⑥ 授予与存档 | 典礼 · 证书编号 · 记录归档 | 无存档 → 事后无法核验 |

**三层证据**（判断一个奖是否可信）

| 层 | 要看到的东西 |
|:--|:--|
| 标准公开 | 评选办法、资格条件、评审维度可查 |
| 过程留痕 | 提名与评审记录保存，可应对异议 |
| 结果可诉 | 有申诉或复核通道，且有人受理 |

> ⚠️ **公众投票不是评审**：投票衡量的是动员能力，不是成果质量；把它包装成「评审」会同时损害两者。

## 五、奖项的效力与误读

| 现象 | 机制 | 后果 |
|:--|:--|:--|
| **可兑换性** | 荣誉被制度接入资源分配（经费 · 晋升 · 招聘 · 项目） | 奖项从「承认」变成「筹码」 |
| **累积优势（马太效应）** | 已有荣誉降低再获奖成本 | 强者愈强，新人与边缘领域被挤出 |
| **选择效应** | 只看到获奖者，看不到同水平未获奖者 | 把相关性读成因果 |
| **评审偏差** | 熟人网络 · 机构声望 · 语言与地域 | 系统性偏向名机构与大团队 |
| **荣誉通胀** | 奖项数量增长快于可评对象 | 「人人有奖」→ 识别力下降 |
| **唯奖项评价** | 把奖项当唯一质量信号 | 挤压长期、难量化的贡献 |

> ⚠️ **「获奖 ≠ 水平高」的准确表述**：在控制其他条件后，获奖与水平**相关**，但奖项同时反映**申报意愿、机构支持与人际网络**。把奖项当充分证据，是把三个变量当成一个。

## 六、撤销、追授与瑕疵

| 情形 | 处理 | 要点 |
|:--|:--|:--|
| **成果造假 / 数据不实** | 撤销，公告说明 | 与学术撤稿同理：**撤的是结论的可靠性，不是人的全部** |
| **资格不符** | 撤销并追回奖金 / 奖章 | 须有资格审查的原始记录支撑 |
| **获奖后失德** | 依章程或奖项办法处理 | 「事后行为能否溯及既往」须事先写明 |
| **评审程序瑕疵** | 复核或重评 | 瑕疵 ≠ 结果必然错误 |
| **追授** | 生前贡献、身后授予 | 须明确是否计入「获奖者」统计 |

> ⚠️ **撤销要有程序**：只凭舆论撤奖，会让奖项从此不再可信——**程序的可预期性本身就是奖项的价值的一部分**。
> ⚠️ **「撤销」与「声明无效」不同**：前者是事后剥夺，后者是自始不成立（如资格造假）。

## 七、仪式与物质层

| 要素 | 功能 | 风险 |
|:--|:--|:--|
| 典礼 | 公开承认 · 社群再生产 | 排场与成本的正当性 |
| 奖章 · 奖杯 · 证书 | 可携带的记忆与凭证 | 复制品泛滥削弱象征力 |
| 奖金 | 直接激励 | 金额成为唯一焦点，遮蔽评审质量 |
| 赞助与冠名 | 资金来源 | **赞助方参与评审** → 奖项变成营销 |
| 获奖名单发布 | 传播与背书 | 名单先行外泄、排序被当作等级 |

> ⚠️ **商业奖项的识别**：看**谁出钱、谁评审、谁受益**。可由设奖方主导评审、并把获奖作为营销素材的奖，本质是推广活动。

## 八、记录与元数据

奖项是**事件**，不是属性。在知识库中建议按事件记录：

| 字段 | 说明 | 例 |
|:--|:--|:--|
| `award` | 奖项名称（原文 + 通行译名） | 具体奖项名 |
| `awarded_by` | 授予机构 | 学会 / 国家 / 基金会 |
| `award_date` | 授予年月（不写「某年获奖」） | `YYYY-MM` |
| `award_scope` | 对象类型：个人 / 团队 / 作品 | 团队奖须记分摊 |
| `award_status` | `awarded` / `withdrawn` / `declined` | 撤销须留时间 |
| `award_basis` | 依据成果（链到作品或项目页） | 指向具体作品 / 项目 |

**三条记录纪律**

1. **写事件，不写身份**：人物页写「YYYY-MM 获 X 奖」，不写「著名 X 奖得主」这类永久定语。
2. **写来源，不写传说**：「国际大奖」须落实授予主体与年份。
3. **写状态，不抹痕迹**：撤销的奖项保留记录并标 `withdrawn`，不删条目（**删除会让历史不可核**）。

> ⚠️ **同一奖项的译名不一致**：中文库内应固定一种译名，其余作 `aliases`（如 `aliases: [Award 中文名, Award 英文名]`）。

## 九、中国语境

| 议题 | 要点 |
|:--|:--|
| 国家科学技术奖 | 五类：国家最高科学技术奖 · 国家自然科学奖 · 国家技术发明奖 · 国家科学技术进步奖 · 国际科学技术合作奖 |
| 社会力量设奖 | 由学会 · 协会 · 基金会等设立，按管理办法登记或备案 —— **不是颁了就算数** |
| 学会奖 | 由学术团体颁，评审通常依托理事会 / 专门委员会 |
| 国家荣誉称号与表彰 | 如「人民科学家」等称号 · 劳动模范 · 五一劳动奖章（工会系统） |
| 院士称号 | **荣誉性、终身**，不是职务也不是学位；与「会士」不是一回事（见 [[03-学会与学术团体\|03 学会与学术团体]]） |
| 「破五唯」 | 唯论文 · 唯帽子 · 唯学历 · 唯职称 · 唯奖项 —— 政策取向下，奖项不应作为单一评价依据 |

> ⚠️ **具体奖项设置、设奖备案要求与评选周期须回主管部门文件核对**；本页只给机制与判读框架。

## 十、病理清单

| 病理 | 表现 | 识别信号 |
|:--|:--|:--|
| 奖项通胀 | 名目激增、同义重复 | 一年内同一群体反复获奖 |
| 赞助方主导 | 出资人进评审席 | 评审名单与赞助名单高度重合 |
| 公示走形式 | 公示期极短、无异议渠道 | 名单先于公示发布 |
| 头衔挂靠 | 机构把聘来的获奖者当招牌 | 简介只列奖项不列工作 |
| 追授政治化 | 授予时机与舆论事件同步 | 评审周期被压缩 |
| 名单造假 | 虚构获奖 | 授予机构官网查无此奖 |
| 永久定语 | 「著名 XX 奖得主」写进人物页 | 无法追溯年份与作品 |

## 十一、核心问题

> 奖项的本意是**把稀缺的承认集中到少数人身上**，以此降低外界判断的成本。它一旦被接入资源分配，就会同时生产两种东西：**可信的信号**，和**可经营的资本**。两者的区别不在奖金多少，而在**标准是否公开、过程是否留痕、结果是否可诉**——没有这三样，奖项只是一次仪式；有了这三样，它才配被称为一种「制度」。
