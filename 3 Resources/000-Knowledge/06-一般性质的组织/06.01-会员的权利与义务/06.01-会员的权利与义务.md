# 06.01 会员的权利与义务

> **UDC `06.01`** —— 会员的权利与义务。本页记的是**成员与组织之间那一层约定**：谁算会员、会员能主张什么、必须做什么、被中止或除名时有什么救济。
> 归属判据一句话：**不看组织做什么，只看「成员」这一身份产生的权利义务关系。**
> **上级**：[[06-一般性质的组织|06 一般性质的组织]]（本子库为容器直属子库，与 `raw/articles/` 下的主题支线平级）。
> 落位：`06-一般性质的组织/06.01-会员的权利与义务/`。
> ⚠️ **编号性质**：本支线序号 `06.01` 是 UDC `06` 的**专用复分号**（复分机制见 [[06-组织和协会的专用复分|06 组织和协会的专用复分]]），**不是容器内流水号**，也不是 DDC 号；`06.01` 的语义由用户提供，**仍待 UDCS 原文核验**（见待补）。

## 一、定位与边界

**这一页做什么**

| 面 | 范围 | 典型问题 |

| 资格 | 入会、会员类型、退会与除名 | 「他算不算会员」 |
| 权利 | 表决 · 选举 · 知情 · 参会 · 服务 · 救济 | 「他能不能查账、能不能投票」 |

| 程序 | 章程怎么写才可执行；除名的正当程序 | 「开除他走没走对程序」 |

> ⚠️ **会员 ≠ 股东 ≠ 顾客** —— 三者最容易被混为一谈：

| 关系 | 剩余索取权 | 表决权基础 | 退出方式 | 权利可否转让 |
|:--|:--|:--|:--|:--|
| **股东** | 有（分红 · 剩余财产） | **按出资比例** | 转让股权 | 可转让 |
| **会员** | 无（不分配剩余） | **一人一票** | 退会（通常不退费） | 不可转让、不可继承 |
| **顾客** | 无 | 无 | 不再购买 | — |

> 📌 **判据**：能分红的不是会员权，是股权；能按交钱多少加权的不是会员表决，是股东表决。**「会员」的核心是身份，不是份额。**

## 二、会员资格的取得

**入会五步（章程通常必备）**

| 步 | 内容 | 易出错处 |
|:--|:--|:--|
| ① 申请 | 提交申请表 / 推荐人 / 资格材料 | 无格式要求 → 材料缺失无法核 |
| ② 审核 | 理事会或秘书处按条件核 | 「条件」写成「热心本会事业」= 无法核 |
| ③ 决定 | 表决通过或备案登记 | 谁有权批、几票通过未写明 |
| ④ 缴费 | 会费到账 | 未定「缴费后第几日生效」 |
| ⑤ 生效 | 编入会员名册 · 发证 | 名册与生效日不一致 |

**会员类型谱**

| 类型 | 特征 | 常见权能差异 |
|:--|:--|:--|
| 正式会员（普通） | 全额会费 · 完整权利 | 表决 · 选举 · 被选举 |
| 学生会员 / 青年会员 | 低会费 · 需证明 | 常有表决权，被选举权或受限 |
| 准会员 / 预备会员 | 观察期 | 常无表决权 |
| 团体会员 | 以单位入会，**派代表人** | 代表人行使权利 |
| 荣誉会员 | 授予，通常免会费 | 常**无表决权**（非缴费成员） |
| 终身会员 | 一次性缴费 | 权利同正式会员 |
| 通讯 / 海外会员 | 远程参与 | 表决方式须另定（书面 / 电子） |
| 观察员 | 非成员身份参与 | 无表决权 |

> ⚠️ **团体会员的「代表人」是高频争议点**：一家单位入会、派谁出席、单位换人后代表权是否随之转移、代表人能否被单位单方撤回——章程不写清，表决结果就可能被质疑。
> ⚠️ **会士（Fellow）通常不是会员类型**，而是评出来的**荣誉**；把它做成「交钱升级」的会员等级，会同时损害荣誉与治理（见 [[03-学会与学术团体|03 学会与学术团体]]「会士通胀」）。

## 三、资格的丧失

| 路径 | 性质 | 是否退费 | 可否申诉 |
|:--|:--|:--|:--|
| **自愿退会** | 单方意思表示 | 通常不退（章程另定除外） | — |
| **自动丧失** | 欠费超宽限期 · 失联 · 不再符合资格条件 | 通常不退 | 可（先补正） |
| **中止（停权）** | 保留资格，暂停部分权利 | — | 应有 |
| **除名 / 开除** | 最高档纪律处分，消灭成员关系 | 通常不退 | **必须有** |

> ⚠️ **「中止」与「终止」不可混写**：中止是留资格、停权利（如欠费停表决）；终止是关系消灭。章程混用会让处分失去梯度。
> ⚠️ **欠费自动除名**须写明**宽限期起止、通知方式、补正机会**；只写「逾期视为自动退会」而从不通知，实践中易被认定程序不当。

## 四、权利谱

**按效力层级**（上强下弱）：

| 层级 | 来源 | 可否被章程削减 |
|:--|:--|:--|
| 法定权利 | 法律 · 行政法规（如登记管理条例中的会员大会职权） | **不可** |
| 章程权利 | 本会章程明文 | 须依修改程序 |
| 惯例与承诺 | 多年做法 · 公开承诺 | 可通过正式决议变更，但受诚信原则约束 |

**按功能分**

| 类 | 内容 | 说明 |
|:--|:--|:--|
| **共益权**（参与治理） | 表决 · 选举与被选举 · 提案 · 召集请求权 · 参加会员大会 | 一人一票，不按出资加权 |
| **自益权**（获取服务与信息） | 知情（章程 · 决议 · 会议记录 · 财务报告 · 会员名册）· 使用设施与服务 · 会费优惠 · 获得证书 / 称号 | 知情权是其他权利的前提 |
| **救济权** | 要求说明理由 · 内部申诉 · 向登记管理机关投诉 · 诉请法院 | 章程不能排除诉权 |

> ⚠️ **知情权的边界**：会员名册含个人信息，查阅范围应限定（如「仅限与自身权益相关」），并对接 People CRM 的 `privacy: restricted` —— 不能因为「是会员」就把全体名册与联系方式公开。
> ⚠️ **会员权不可转让、不可继承**：与股权、债权不同，会员身份随人（或随团体会员的代表人）存在。

## 五、义务谱

| 义务 | 内容 | 可执行性要点 |
|:--|:--|:--|
| 遵守章程与决议 | 章程 · 会员大会 / 理事会决议 | 决议须程序合法 |
| 缴纳会费 | 标准 · 周期 · 逾期后果 | 标准须经权力机关表决 |
| 维护组织声誉 | 不得损害本会名誉与利益 | 边界须具体，否则易成压制批评 |
| 出席会议 | 部分章程设为义务 | 与「自愿参会」的权利存在张力 |
| 保密 | 商业秘密 · 评议信息 · 个人信息 | 范围与期限须写明 |
| 竞业 / 利益回避 | 仅特定职务者 | 不宜泛化到全体会员 |
| 接受纪律处分 | 违反章程时 | 须配套处分程序 |

> ⚠️ **兜底条款通常无效**：「其他应尽的义务」这类开放式条款在争议中难以支撑具体处分，义务必须**可识别、可举证**。

## 六、对等结构与不对称

| 张力 | 表现 | 处置原则 |
|:--|:--|:--|
| 缴费 vs 权利 | 会费高的会员要求更大表决权 | **一人一票不动摇**；差异只能体现在服务与参会便利，不能进表决 |
| 会员权 vs 财产权 | 退会要求退会费 | 会费不是股本，除章程另定不退 |
| 个人会员 vs 团体会员 | 团体会员一票，覆盖数十人 | 章程须明示代表人规则与人数上限 |
| 荣誉会员 vs 正式会员 | 荣誉会员不缴费却参与决策 | 通常**不授表决权**，只授荣誉与出席 |
| 老会员 vs 新会员 | 「资历」换取特权 | 可设当选资格年限，但不宜设表决权重 |
| 权利 vs 义务的对等 | 只写权利 → 组织被「许愿」绑架；只写义务 → 成员沦为资源 | 两侧同时具体化，才有可执行性 |

> ⚠️ **「多交钱多权利」是营利逻辑**：一旦表决权与出资挂钩，组织就从会员制退化为出资人控制，非营利的正当性随之瓦解。

## 七、章程条款最小清单

**权利要落地，须配四件基础设施**：

| 设施 | 缺了会怎样 |
|:--|:--|
| **通知** | 未写期限与方式 → 会议与表决可被质疑无效 |
| **表决** | 未写方式 / 计票 / 回避 → 结果无法复核 |
| **记录** | 未写纪要与保存年限 → 事后无法证明「当时通过了什么」 |
| **救济** | 未写申诉受理与答复时限 → 权利只剩纸面 |

**「写了等于没写」的反例**

| 条款写法 | 问题 | 改法 |
|:--|:--|:--|
| 「会员享有选举权」 | 无候选人产生办法 | 补提名主体 · 资格 · 公示期 |
| 「会员有权查阅本会资料」 | 范围与时限不明 | 限定文件类别 · 申请方式 · 答复期限 |
| 「会员有权申诉」 | 无受理主体与时限 | 设申诉委员会 · 答复期限 · 可否再诉 |
| 「理事由会员大会选举产生」 | 未写任期与连任限制 | 补任期 · 连任上限 · 补选规则 |
| 「本章程解释权归理事会」 | 可架空章程权利 | 解释权与修改权分离，重大事项归会员大会 |

> 📌 **章程是宪法，但程序条款才是可执行的那部分。**

## 八、纪律与开除：正当程序

| 要素 | 要求 |
|:--|:--|
| **告知** | 书面告知具体事由、依据条款、拟处分档次 |
| **听证** | 给予陈述与申辩机会（可提交书面材料） |
| **回避** | 利害关系人不得参与该案表决 |
| **表决** | 按章程规定的机关与票数作出 |
| **送达与留档** | 处分决定书面送达，全流程留档 |

**处分阶梯**：提醒 → 警告 → 暂停权利（限期）→ 除名。

**救济路径**：内部申诉 → 登记管理机关（民政）投诉 → 法院。**章程可以约定纪律，不能约定排除法定救济。**

> ⚠️ **除名 ≠ 退会**：除名带名誉后果，程序瑕疵的代价远高于纪律本身。
> ⚠️ **批评与纪律的界线**：会员对组织提出批评属共益权行使，不能直接等同于「损害声誉」义务的违反。

## 九、中国语境

| 议题 | 要点 |
|:--|:--|
| 社会团体 | 会员大会（或会员代表大会）为最高权力机关；章程示范文本含会员权利义务条款 |
| 会费标准 | 须经会员大会（或代表大会）表决，并按规定报备案 —— **不是理事会即可自定** |
| 学会体系 | **会员 ≠ 会士 ≠ 院士**（院士是国家学术称号；见 [[03-学会与学术团体\|03 学会与学术团体]]） |
| 行业协会商会 | 2015 年起与行政机关脱钩，会员基础与治理结构随之调整 |
| 高校学生社团 | 校团委指导下的学生组织，「会员」多为在校学生，权利以活动参与为主 |
| 社区社会组织 | 备案制下多为成员互助，权利义务更依赖内部约定 |
| 民办非企业（社会服务机构） | 通常**无会员**，只有理事会 —— 不要把「服务对象」写成会员 |

> ⚠️ **具体条文、比例与备案要求须回法规核对**；本页只给结构与判读框架，不给条文号。

## 十、病理清单

| 病理 | 表现 | 识别信号 |
|:--|:--|:--|
| **沉默会员** | 会员只缴费不参与 | 大会到会率长期极低，全靠通讯表决 |
| **章程权利虚置** | 权利只写不落程序 | 从无候选人公示 · 从无会议纪要 |
| **会费买头衔** | 缴费即得「高级会员 / 会士」 | 等级与评审脱钩 |
| **开除权滥用** | 以纪律压制批评 | 处分事由为「不当言论」 |
| **申诉无门** | 无内部复核机关 | 处分即终局 |
| **代表人争议** | 团体会员代表权归属不清 | 同一单位出现两名代表 |
| **名册泄露** | 会员信息外流 | 「会员名录」对外售卖或公开 |

## 十一、核心问题

> 会员制的正当性，来自**权利与义务同时可执行**。只写权利，是许愿；只写义务，是征用。而章程里真正决定这套关系能不能运转的，往往不是那几句「会员享有……权利」，而是**通知期限、表决办法、记录保存、申诉通道**这四件看起来最不像「权利」的东西。
