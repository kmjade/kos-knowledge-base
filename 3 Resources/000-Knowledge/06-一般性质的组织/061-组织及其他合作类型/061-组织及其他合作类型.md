# 061 组织及其他合作类型

> **UDC `061`** —— 组织**及其他类型的合作**。本页记的是 `06` 之下的**类型层**：不是「组织一般是什么」（那是 `01` 组织总论），而是**组织的类型与合作被制度化的各种形态**。
> 归属判据一句话：**问「这类合作有没有常设的决策与执行结构」，而不是「它叫什么名字」。**
> **上级**：[[06-一般性质的组织|06 一般性质的组织]]（本子库为容器直属子库，与 `raw/articles/` 下的主题支线平级）。
> 落位：`06-一般性质的组织/061-组织及其他合作类型/`。
> ⚠️ **编号性质**：`061` 是 UDC **主表下位**（不是 `06` 的专用复分号，也与 `06.01` 完全不同）—— 机制辨析见 [[06-组织和协会的专用复分|06 组织和协会的专用复分]]；`.1` / `.2` 是**再下位**，不是复分。**中文译名依用户提供**（`061` 的组织及其他合作类型），英文名依 UDC Summary **"Organizations and other types of co-operation"**；其余下位细分**未核**（见待补）。

## 三、类名里的那个「其他」

UDC 把 `061` 命名为「组织**及其他类型的合作**」，这一句是判读全页的钥匙：**它收的不只是组织，还收合作的制度化形态。**

| 现象 | 有独立法人 | 有常设秘书处 | 决定对成员有约束力 |
|:--|:--|:--|:--|
| 一次性会议 | 否 | 否 | 否 |
| 宣言 / 备忘录 | 否 | 否 | 否（政治承诺） |
| 协定 / 条约 | 否（本身不是组织） | 否 | **是**（对缔约方） |
| 联盟（alliance） | 通常否 | 有时 | 视章程 |
| 联合会（federation） | 通常是 | 是 | 视章程（成员保留主权） |
| 联合体（consortium） | 通常否 | 有时 | 项目层面 |
| 网络（network） | 通常否 | 轻量协调 | 否 |
| 常设组织 | **是** | **是** | **是** |

> 📌 **判据不是「有没有名字」，而是有没有独立的决策与经费**。三者（法人 · 秘书处 · 约束力）齐了，就是组织；都不齐，就是合作；中间地带才是 `061` 真正难判的部分。
> ⚠️ **「组织」这个词常被滥用**：自称「国际××组织」的团体，可能只是一个网站加一个理事会名单。核验看成立文件、章程、财务与决策记录。

## 四、类型谱

| 轴 | 取值 | 判读要点 |
|:--|:--|:--|
| **成员性质** | 政府 · 非政府 · 混合（政府与非政府同席）· 个人 · 机构 | 决定 `061.1` / `061.2` 归属，混合型最易误判 |
| **地域范围** | 国家 · 区域 · 全球 | 范围 ≠ 影响力；区域组织的约束力常强于全球论坛 |
| **职能** | 倡导（advocacy）· 服务（会员服务）· 标准制定 · 协调 · 运营（办事） | 职能决定它需要什么权力 |
| **法律形态** | 社团 · 基金会 · 公司型 · 无独立法人（依条约或章程存在） | 形态 ≠ 治理实质 |
| **成立基础** | 条约 · 章程 · 契约 · 惯例 | 决定成员能否退出、决定如何生效 |
| **成员开放度** | 开放加入 · 邀请制 · 资格审核 · 封闭 | 封闭型多为俱乐部式治理 |

> 📌 **读一个组织先问四句**：谁成立的（成立文件）· 谁出钱（经费来源）· 谁决策（机关与表决）· 决定对成员有没有约束力。四句答不全，「这是什么组织」就无从判断。

## 五、政府组织 vs 非政府组织

| 维度 | `061.1` 政府组织 | `061.2` 非政府组织 |
|:--|:--|:--|
| 成立依据 | 法律 · 法令 · 政府决定 · 政府间条约 | 民间发起 · 章程 · 民事登记 |
| 成员 | 国家 · 政府部门 · 政府指定人员 | 个人 · 机构 · 团体 |
| 经费 | 财政拨款 · 摊款 | 会费 · 捐赠 · 服务收入 · 项目资助 |
| 决策 | 政府代表表决 · 加权（按出资或份额） | 一人一票或按章程 |
| 决定效力 | 可具法律约束力（对成员国） | 一般无强制力（倡导 · 标准 · 认证） |
| 问责对象 | 纳税人 / 议会 / 上级机关 | 会员 / 捐赠人 / 公众 |
| 典型形态 | 政府间组织 · 政府部门 · 监管机构 | 协会 · 学会 · 基金会 · 倡议网络 |

> ⚠️ **「官方 / 民间」不是可靠的判据**：有政府拨款不等于政府组织，有政府官员列席不等于政府控制。判据回到**成立依据与决策权归属**。
> ⚠️ **混合型须单独记**：政府与非政府同席的组织（三方机制、公私伙伴关系），写 `061.1:061.2` 式的复合比强行二选一更诚实；若体系不支持复合，须在附注写明。

## 七、成立文件与治理基线

**成立文件四件**

| 文件 | 作用 | 缺失后果 |
|:--|:--|:--|
| 成立依据（条约 / 法律 / 登记） | 说明它凭什么存在 | 无法确定法律人格与管辖 |
| 章程 / 议事规则 | 定机关、职权、表决 | 决议可被质疑无效 |
| 成员与代表规则 | 谁有席位、代表怎么产生 | 表决结果的代表性无法核 |
| 财务与预算规则 | 钱从哪来、谁批 | 秘书处可脱离成员控制 |

**六项治理基线**

| 项 | 要看到的东西 |
|:--|:--|
| 权力机关 | 大会 / 理事会 / 董事会，谁是最高 |
| 执行机关 | 秘书处 · 总干事 / 秘书长，任命与任期 |
| 监督 | 审计 · 监事会 · 外部评估 |
| 表决 | 一票制 / 加权 / 协商一致（consensus） |
| 退出 | 通知期 · 欠费后果 · 已承诺义务的处理 |
| 解散 | 剩余财产归属 · 档案移交 |

> ⚠️ **「协商一致」不等于「全体同意」**：它常指无人正式反对，个别成员的保留意见仍可存在；把它读成 unanimity 会高估共识。
> ⚠️ **加权表决要看出资还是看人口**：同为政府组织，按摊款加权与按成员国平等表决，是两种不同的组织哲学。

## 八、判读方法与证据

| 步 | 动作 |
|:--|:--|
| ① 定名 | 官方全称 + 原文名（缩写常重名，`WHO` 与各类同名机构） |
| ② 定性 | 政府 / 非政府 / 混合；法人有无 |
| ③ 定时 | 成立年份 · 成立文件 · 关键改组（改名常伴随职能变更） |
| ④ 定权 | 决策机关 · 表决方式 · 决定对成员的效力 |
| ⑤ 定钱 | 经费结构（会费 / 摊款 / 捐赠 / 项目） |
| ⑥ 定范围 | 成员名单与地域覆盖（自称「全球」须看成员构成） |

**三条证据纪律**

1. **看成立文件，不看宣传页**：介绍「致力于……」是意图，章程才是权力。
2. **看成员名单，不看总部地址**：总部在日内瓦不等于成员是全球的。
3. **看预算来源，不看冠名**：冠名方常是出资方，但出资不必然等于控制——须看任命权。

## 九、中国语境

| 议题 | 要点 |
|:--|:--|
| 社会团体 / 基金会 / 社会服务机构 | 属社会组织，登记管理见 [[04-社团与非营利\|04 社团与非营利]]；本页只管**类型判断** |
| 群团组织 | 工会 · 共青团 · 妇联 · 科协 · 侨联等，由党领导、有专门章程与层级体系 —— 归 `061.1` 侧，**不是**「非政府组织」 |
| 事业单位 | 国家设立的公共服务机构，有法人、无会员 —— 不属社会组织，**不要登记为社会团体** |
| 行业协会商会 | 2015 年起与行政机关脱钩；脱钩后仍可能保留政府背景，判读回到**成立依据与决策权** |
| 境外非政府组织 | 依《境外非政府组织境内活动管理法》（2017 年施行）设代表机构或开展临时活动 —— 登记路径与境内社会组织不同 |
| 「非政府组织」一词 | 中文语境常被读作「反政府」或「纯民间」，两种读法都不准确；本页按 UDC `061.2` 的**结构定义**使用 |
| 国际组织在华 | 政府间组织驻华机构与境外 NGO 代表机构，法律地位不同，不可混写 |

> ⚠️ **具体登记条件、业务主管单位要求与活动范围须回法规核对**；本页只给类型框架与判读方法，不给条文号。

## 十、病理清单

| 病理 | 表现 | 识别信号 |
|:--|:--|:--|
| **空壳组织** | 有章程无活动 | 官网只有简介，无年度报告与会议记录 |
| **秘书处俘获** | 执行层实际控制决策 | 大会多年不开，或议题由秘书处设定 |
| **名单注水** | 成员数虚高 | 成员名单不公开，或含大量「挂名会员」 |
| **身份含混** | 政府背景却自称 NGO（或反之） | 成立依据与自我描述矛盾 |
| **纸面联盟** | 签了备忘录即宣布「联盟成立」 | 无常设协调机构、无预算 |
| **名实不符** | 自称「国际」「全球」 | 成员集中于单一国家或单一资助方 |
| **解散无程序** | 停止活动但不注销、不交代财产 | 无解散决议与档案移交记录 |

## 十一、核心问题

> `061` 把「组织」和「其他类型的合作」放进同一个类，是因为两者之间**没有清晰的分界，只有制度化程度的差别**：一份备忘录、一个联盟、一个联合会、一个常设组织，是同一条连续谱上的不同位置。类号在「组织」处切了一刀，但现实里的合作不断在中间地带生长。所以判读的关键不在名字，而在三件事——**有没有独立的法人、有没有常设的秘书处、决定对成员有没有约束力**。三者齐备，才是组织；缺一项，就要问它究竟靠什么维持。
