# 061.1 政府组织与合作

> **UDC `061.1`** —— 政府组织及其合作。本页记的是**以政府为构成单位或设立主体的组织，以及政府之间的合作形态**：谁授权、谁任命、谁出钱、决定对谁有约束力。
> 归属判据一句话：**看授权链能不能一路回溯到法源与预算，而不是看它挂谁的牌子。**
> **上级**：[[061-组织及其他合作类型|061 组织及其他合作类型]]（本子库在其目录之内）· **上位容器**：[[06-一般性质的组织|06 一般性质的组织]]。
> 落位：`06-一般性质的组织/061-组织及其他合作类型/061.1-政府组织与合作/`（**`061` 子库之内** —— `061.1` 是 `061` 的再下位，子库随类号嵌套）。
> ⚠️ **编号性质**：`061.1` 是 `061` 的**再下位**（主表细分），**不是复分号** —— 与 `06.01` 的 `.01` 完全不同（辨析见 [[06-组织和协会的专用复分|06 组织和协会的专用复分]]）。中文名依用户提供，英文名依 UDC Summary（**Governmental organizations**）为底，范围与下位细分**待核**。

## 三、四种所指：最易混的一步

**「政府组织」在中文里至少指四种东西**，混用会让整页判读失焦：

| 所指 | 构成单位 | 独立法人 | 例子形态 |
|:--|:--|:--|:--|
| **A 政府机关** | 部门 · 内设机构 | 通常否（机关法人） | 部 · 委 · 局 · 厅 |
| **B 政府间组织（IGO）** | **国家** | 通常是（依条约） | 多边机构 · 区域组织 |
| **C 政府设立的公共机构** | 依专门法设立 | 通常是（公法人 / 法定机构） | 监管机构 · 公共服务机构 |
| **D 混合机构** | 政府 + 非政府 / 企业 | 视形态 | 公私合作 · 三方机制 |

> ⚠️ **B 最容易被错放**：政府间组织的**成员是国家**，不是个人，也不是政府部门；把它当成「政府的一个部门」会误判其权力来源。
> ⚠️ **C 是判读难点**：有政府背景、有法定职能，但不一定是行政机关 —— 是否受行政程序约束、能否被诉，取决于它的**法律形态**，不取决于名称。
> ⚠️ **灰区要单独记**：政府出资或主导、但登记为非政府形态的组织（俗称 GONGO），二选一都不诚实 —— 在附注写清出资与控制关系。

## 四、类型谱

| 轴 | 取值 | 判读要点 |
|:--|:--|:--|
| **层级** | 中央 / 地方 / 跨部门 / 超国家 | 层级决定授权链长短 |
| **职能** | 监管 · 服务 · 协调 · 研究咨询 · 执法 | 监管型最需要独立性，协调型最易虚化 |
| **法律形态** | 行政机关 · 法定机构 / 公法人 · 国有公司 · 依条约设立 | 形态决定问责路径 |
| **成立依据** | 宪法 · 法律 · 法令 / 政令 · 政府间条约 | 依据决定能否被单方撤销 |
| **成员** | 国家 · 政府部门 · 指定人员 | 「成员」是机构还是国家，决定表决逻辑 |
| **开放度** | 普遍开放 · 邀请制 · 资格审核 · 封闭 | 封闭型多为俱乐部式安排 |

> 📌 **一条硬判据**：**成立依据能否被设立者单方改变** —— 依法律设立的机构，政府不能一纸通知撤掉；依政令设立的，可以。这一条比「级别」更能说明它有多独立。

## 五、政府间组织（IGO）的骨架

| 要素 | 常见形态 | 要问的问题 |
|:--|:--|:--|
| 成员 | 主权国家（少数为准成员 / 观察员） | 谁有表决权，谁只有发言权 |
| 最高机关 | 大会 / 缔约方会议 | 多久开一次，议程谁定 |
| 执行机关 | 理事会 / 执行局 | 席位怎么分配（地域 / 出资 / 轮值） |
| 日常机关 | 秘书处 · 总干事 / 秘书长 | 谁任命，任期，可否连任 |
| 表决 | 一国一票 · 加权 · 协商一致 | 加权按什么（摊款 / 人口 / 份额） |
| 预算 | 法定摊款 · 自愿捐 · 项目资金 | 谁批准，欠费有什么后果 |
| 决定效力 | 建议 · 决定 · 有约束力（须国内转化） | 是否需要成员国立法落地 |
| 退出 | 通知期 · 已承诺义务 | 退出后财产与档案怎么处理 |

> ⚠️ **「有约束力」常被夸大**：多数 IGO 的决议是**建议性**；真正有约束力的，多需成员国**国内法转化**或另有条约机制。
> ⚠️ **秘书处不是「执行大会决定的手」**：议程设置、预算编制、人事任命都把大量实权放在秘书处，这是 IGO 研究的经典议题。
> 📌 **具体某家 IGO 的议题与博弈 → [[327-国际关系|327 国际关系]]**；本页只给结构。

## 六、授权链：政府组织的正当性来源

| 环节 | 内容 | 断裂的后果 |
|:--|:--|:--|
| ① 法源 | 宪法 · 法律 · 条约 · 政令 | 无依据 → 机构存在本身可疑 |
| ② 设立 | 设立文件写明职权、编制、经费 | 职权模糊 → 越权或推诿 |
| ③ 授权 | 法定授权 / 委任 / 委托 | 授权不清 → 「他说的话算不算数」 |
| ④ 任命 | 谁提名、谁批准、任期与免职 | 任命权在哪，实权就在哪 |
| ⑤ 预算 | 谁编制、谁批准、谁审计 | 预算独立 → 实际独立 |
| ⑥ 问责 | 上级 · 议会 · 审计 · 司法 · 公众 | 多重问责 = 无人负责 |

**三种授权形态的差别**

| 形态 | 含义 | 责任归属 |
|:--|:--|:--|
| **法定授权** | 法律直接把权力给该机构 | 机构自负其责 |
| **委任（delegation）** | 上级把部分职权下放 | 通常仍由委任者承担最终责任 |
| **委托（entrustment）** | 把事务交给外部主体办理 | 责任随事务转移，但监督责任不转移 |

> ⚠️ **代表权（谁替谁说话）必须可核**：同一机构在不同场合可能由不同层级代表，表态的效力范围不同 —— 记录时写清「谁 · 以何身份 · 在何场合」。
> ⚠️ **「多重问责」是政府组织的特有病理**：上级、议会、审计、出资方、公众各有要求时，机构会优先满足**最容易让它出事的那一个**，而非最重要的那一个。

## 七、合作形态：政府之间的「合作」长什么样

| 形态 | 有无常设机构 | 有无独立预算 | 决定有无约束力 |
|:--|:--|:--|:--|
| 联合声明 / 公报 | 否 | 否 | 否（政治承诺） |
| 谅解备忘录（MOU） | 通常否 | 否 | 通常否（除非写明） |
| 协定 / 条约 | 否（本身是文件） | 否 | **是**（对缔约方） |
| 联合委员会 / 工作组 | 是（轻量） | 有时 | 视授权 |
| 定期政府间会议 | 是（轮值） | 有时 | 否（多为例行磋商） |
| 共管机构 / 跨境管理局 | **是** | **是** | **是**（在授权范围内） |
| 区域一体化组织 | **是** | **是** | 部分可**直接适用**于成员国内部 |

> 📌 **判断合作「长没长出机构」就三问**：有没有常设秘书处 · 有没有自己的预算 · 决定对成员有没有约束力。三问全否，它仍是**合作**而非**组织**（对应 [[061-组织及其他合作类型|061]] 的连续谱）。
> ⚠️ **备忘录不是条约**：多数 MOU 明确声明「不产生国际法上的权利义务」；把它当条约引用，是常见误读。

## 九、治理基线与透明度

| 项 | 要看到的东西 |
|:--|:--|
| 设立文件 | 职权清单、编制、经费来源 |
| 预算 | 年度预算表 · 摊款比例 · 审计报告 |
| 人事 | 任命主体、任期、回避与利益申报 |
| 决策记录 | 会议纪要、表决结果（含保留意见） |
| 信息公开 | 公开范围、豁免范围、申请渠道 |
| 终止 | 撤销 / 合并 / 解散的程序与财产归属 |

> ⚠️ **信息公开的「豁免范围」是重点**：政府组织普遍有保密条款，关键不是有没有豁免，而是**豁免是否可复议、由谁裁定**。
> ⚠️ **临时机构常设化**：领导小组、联席会议、专项办公室本是临时协调机制，一旦常态化，往往既无编制依据也无退出机制。

## 十、判读方法

| 步 | 动作 |
|:--|:--|
| ① 定位 | 属 A 机关 / B IGO / C 公共机构 / D 混合 |
| ② 溯源 | 成立依据（法条 · 条约 · 政令）能否查到 |
| ③ 定权 | 职权范围、授权形态（法定 / 委任 / 委托） |
| ④ 定人 | 任命主体与任期 —— 任命权在谁手里 |
| ⑤ 定钱 | 预算来源与批准机关 |
| ⑥ 定责 | 对谁负责、可否被诉、有无审计 |

**三条证据纪律**

1. **看设立文件，不看机构简介**：简介写「负责××工作」，设立文件才写「职权限于××」。
2. **看预算来源，不看级别**：级别高但靠项目经费生存的机构，实际受制于出资方。
3. **看任命记录，不看头衔**：头衔可以兼挂，任命权才是控制权。

## 十一、中国语境

| 议题 | 要点 |
|:--|:--|
| 行政机关 | 国务院及其部门、地方政府及其部门 —— 归 **A 类**；行为受行政法约束 |
| 事业单位 | 国家设立、提供公共服务、有法人资格 —— 归 **C 类**；**不是**社会团体，不能按社会组织登记 |
| 法定机构 / 监管机构 | 依专门法或条例设立，行使监管职能；独立性取决于**任命与预算**，不取决于名称 |
| 群团组织 | 工会 · 共青团 · 妇联 · 科协 · 侨联等 —— 归 **A / C 之间**，有专门章程与层级体系，**不属非政府组织** |
| 派出机关 / 管委会 | 开发区、新区管委会多为**派出机构**，法律地位与职权须回设立文件核对 |
| 部际联席会议 | 跨部门协调机制，**非常设法人**；有召集人、无独立预算 |
| 垂直管理 vs 属地管理 | 同一职能两种体制，授权链与问责路径完全不同 |
| 参公管理 | 「参照公务员法管理」是**人事管理制度**，不改变机构的法律形态 |
| 政府购买服务 | 政府作为**委托方**，社会组织作为承接方 —— 责任划分见 [[04-社团与非营利\|04 社团与非营利]] |

> ⚠️ **具体设立依据、编制与职权须回法规与「三定」文件核对**；本页只给结构框架与判读方法，不给条文号。
> ⚠️ **「事业单位」与「社会组织」不可混写**：前者国家设立，后者民间设立 —— 归错侧会连带把经费与问责判断全部做错。

## 十二、病理清单

| 病理 | 表现 | 识别信号 |
|:--|:--|:--|
| **授权不清** | 有机构、无明确职权清单 | 设立文件只写「承担××相关工作」 |
| **叠床架屋** | 同一职能多个机构并行 | 职责交叉、互相推诿 |
| **影子授权** | 以协会 / 中心 / 公司名义行使行政权 | 文件署名与实际权力主体不一致 |
| **多重问责失效** | 谁都管、谁都不负责 | 事故后无明确责任主体 |
| **预算外运行** | 主要依靠收费或项目资金 | 预算表看不到主要收入 |
| **临时机构常设化** | 领导小组 / 联席会议长期存在 | 无编制依据、无退出机制 |
| **派出机构越权** | 无独立法律地位却对外作出决定 | 决定书署名主体与职权不符 |
| **解散无程序** | 撤销后人员与档案无安置 | 无撤销文件与移交记录 |

## 十三、核心问题

> 政府组织的正当性，不在于它自称代表公共利益，而在于**授权链的完整**：每一层权力都能回溯到一条法源、一笔预算、一次任命。链条完整，机构即使级别不高也有实权；链条断裂，机构即使牌子很大也只能靠惯例运行。而合作形态越复杂——从备忘录到共管机构再到一体化组织——授权链越容易被拉长、被稀释、被移交给一个谁也说不清归属的秘书处。**这正是 `061.1` 值得单独成页的原因：它收的不是「政府办的机构」，而是「被授权代表公共权力的组织及其合作」。**
