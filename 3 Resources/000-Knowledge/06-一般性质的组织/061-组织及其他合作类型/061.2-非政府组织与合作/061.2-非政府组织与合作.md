# 061.2 非政府组织与合作

> **UDC `061.2`** —— 非政府组织及其合作。本页记的是**不由政府设立、其决策者不由政府任命，却仍进入公共事务的组织，以及它们彼此之间、它们与政府之间的合作形态**：谁设立、谁出钱、代表谁、对谁负责。
> 归属判据一句话：**「非政府」是关系描述，不是性质判断 —— 真正要问的是「相对于哪个政府、在哪一件事上不政府」。**
> **上级**：[[061-组织及其他合作类型|061 组织及其他合作类型]]（本子库在其目录之内）· **上位容器**：[[06-一般性质的组织|06 一般性质的组织]]。
> 落位：`06-一般性质的组织/061-组织及其他合作类型/061.2-非政府组织与合作/`（**`061` 子库之内** —— `061.2` 是 `061` 的再下位，子库随类号嵌套）。
> ⚠️ **编号性质**：`061.2` 是 `061` 的**再下位**（主表细分），**不是复分号** —— 与 `06.02` 的 `.02` 完全不同（辨析见 [[06-组织和协会的专用复分|06 组织和协会的专用复分]]）。中文名依用户提供，英文名依 UDC Summary（**Non-governmental organizations**）为底，**范围注与再下位细分待核**。

## 三、「非政府」否的是什么

这个词最容易读成两种极端：**「反政府」**（对抗立场）或**「纯民间」**（零接触）。两种都不准确。它实际只否掉三件事，其余一概不断言。

**否掉的三件**

| 否掉的 | 判据 | 为什么是它 |
|:--|:--|:--|
| 政府**设立** | 设立文件由谁签署、初始财产由谁出资 | 设立者决定了组织的「目的基因」 |
| 政府**任命**决策者 | 理事会 / 董事会成员的任命权归谁 | **这一条最关键**：任命权 = 最终控制权 |
| 以行使**公权力**为目的 | 章程目的是公益/互助/倡导，而非执法或行政 | 有公权力即落入 `061.1` 侧 |

**不断言的四件（常被误当判据）**

| 现象 | 为什么不是判据 |
|:--|:--|
| 拿政府经费 / 购买服务合同 | 经费结构影响议程，不改变设立与任命 |
| 办公场所在政府楼里 / 免费使用 | 资源依赖 ≠ 组织归属 |
| 理事会里有政府官员（个人身份） | 关键看**任命权**与表决规则，不看名单 |
| 承担政府委托的公共服务 | 受托执行 ≠ 变成机关；但**长期全额受托**会逼近收编（见 §六） |

**「非政府」也不等于**

- **非营利**：非营利说的是「不分配盈余」，非政府说的是「不由政府设立/任命」。一个组织可以非政府而营利（社会企业），也可以非营利而由政府设立（官办基金会）。
- **非正式**：登记与否是法律状态，与「非政府」是两件事；大量草根组织未登记。
- **反政府**：倡导与监督是公共参与的常态形态，不等于对抗。

> ⚠️ **一句话校正**：不要说「它是民间的」，说「它的设立与任命不在政府手里，但它的钱和它的项目可能与政府高度相关」。

## 四、类型谱

**七轴**

| 轴 | 取值 |
|:--|:--|
| 成员结构 | 会员制 · 非会员制（运营型） |
| 主要活动 | 倡导 · 服务 · 研究 · 互助 · 网络枢纽 |
| 覆盖范围 | 社区 · 地方 · 全国 · 区域 · 国际（INGO） |
| 法律形态 | 社团 · 基金会 · 社会服务机构 · 公司型 · 未登记 |
| 资金来源 | 会员费 · 公众捐赠 · 机构资助 · 政府采购 · 服务收费 |
| 治理结构 | 会员大会 · 理事会 · 信托 · 一人决策 |
| 与政府关系 | 对抗 · 监督 · 补充 · 伙伴 · 执行 · 内嵌 |

**八类常见形态**

| 形态 | 典型结构 | 判读要点 |
|:--|:--|:--|
| 会员制协会 | 会员大会 → 理事会 → 秘书处 | 「代表会员」有程序依据；非会员不入会即无发言权 |
| 资助型基金会 | 理事会 + 资产池，不直接运营项目 | 权力体现在**资助方向**，不在项目现场 |
| 运营型基金会 | 理事会 + 项目团队 | 常兼有资助与执行，须看两本账 |
| 服务型机构 | 理事会 + 专业团队 + 政府/机构合同 | 服务量易核，**独立性最难核** |
| 倡导型组织 | 小团队 + 联盟 + 传播 | 成效靠议题与证据，不靠规模；代表性最弱 |
| 网络 / 平台 | 成员是组织，秘书处极轻 | 「成员」是组织还是个人，决定合作形态 |
| 伞形组织 | 成员是组织，有表决与分摊 | 介于组织与合作之间，看有无约束力 |
| 社会企业 | 公司或合作社形态，收入为主 | 利润不分配 ≠ 非政府；看章程锁定 |

> 📌 **一个组织往往同时占多格**：例如「会员制的行业协会 + 承接政府购买服务 + 加入国际网络」。类型谱用于**描述**，不用于归档。

## 五、法律形态与登记

**没有统一的「NGO」法律形式。** 各国用社团、协会、基金会、非营利公司、信托等不同外壳；「NGO」在国际法上也不是法律范畴（见 §九）。

**中国语境的三类社会组织**

| 类型 | 典型形态 | 备注 |
|:--|:--|:--|
| 社会团体 | 协会 · 学会 · 联合会 · 促进会 | 会员制为主 |
| 基金会 | 公募 / 非公募（现按是否取得公开募捐资格区分） | 财产集合，非会员制 |
| 社会服务机构 | 原「民办非企业单位」 | 直接提供服务 |

- **慈善组织是「认定」而非独立登记类型**：在已有三类中认定，公开募捐资格须**另行取得**。
- **管理体制**：由「双重管理」（业务主管单位 + 登记管理机关）向**直接登记**改革；行业协会商会自 2015 年起推进**与行政机关脱钩**。
- **境外非政府组织**：《境外非政府组织境内活动管理法》（2016 年通过，2017-01-01 施行）—— 登记管理机关为**公安机关**，境内活动须有**业务主管单位**，未登记不得开展或委托开展活动。
- **未登记 ≠ 不存在**：社区社会组织**备案**、挂靠、非法人团体都是现实形态，只是不能独立签约、开票、募捐、雇人。

> ⚠️ **登记形态比「是不是 NGO」实用得多**：它直接决定能不能签合同、能不能开票、能不能公开募捐、能不能雇人。判读先看这一层。

## 六、与政府的关系谱（六档）

| 档 | 特征 | 主要风险 |
|:--|:--|:--|
| 压制 / 取缔 | 法律上不允许存在或活动 | 转入地下，无法问责 |
| 对抗 / 倡导 | 公开批评、诉讼、运动 | 被贴标签，议题失焦 |
| 监督 / 问责 | 研究、报告、评级、听证 | 证据不足即失去公信 |
| 补充 / 服务 | 政府不做或做不好的领域自办 | 边缘化，规模受限 |
| 伙伴 / 合同 | 政府购买服务、共办项目 | 议程被合同条款带走 |
| 执行 / 内嵌 | 长期全额受托，人事与预算受控 | **准政府化**（「收编」） |

**定档三问**

1. **谁定议程** —— 年度计划由谁批准？
2. **谁定预算** —— 单一来源占比多少？
3. **谁任命负责人** —— 任命权在理事会还是在外部？

> **三问全在组织手里 → 关系谱靠左；三问全在外面 → 靠右。** 答案常常是「两左一右」，那就如实写。

**灰区（须附注，不得硬归档）**

| 灰区 | 说明 |
|:--|:--|
| GONGO | 政府背景 NGO：政府设立或主导人事，但以民间名义运作 |
| QUANGO | 准自治非政府组织（英国语境）：执行公共职能、由财政供养、有一定独立性 |
| 群团组织 | 工会 · 共青团 · 妇联 · 科协 · 侨联等：有专门章程与层级体系，**归 `061.1` 侧**，不作 `061.2` 例 |
| 官办基金会 | 政府或国企发起设立，理事会有官方色彩 |
| 枢纽型 / 联合性组织 | 受委托管理、服务其他社会组织，兼具监管传导功能 |

> ⚠️ **关系是逐事的**：同一个组织可以在救灾上是伙伴、在环保监督上是对手。写「它是政府的合作方」而不写「它在哪件事上合作」，等于什么也没说。

## 七、资金结构

| 来源 | 稳定性 | 独立性代价 | 主要问责对象 |
|:--|:--|:--|:--|
| 会员费 | 中（看会员规模） | 低，但易被少数大户主导 | 会员 |
| 公众小额捐赠 | 低（事件驱动） | 最低 | 捐赠人 · 公众 |
| 基金会 / 机构资助 | 中（周期 1–3 年） | 中（议题被资助方框定） | 资助方 |
| 政府购买服务 / 补助 | 高（合同期内） | 高（指标、审计、续约） | 采购方 · 监管 |
| 服务收费 / 社会企业收入 | 中高 | 中（易偏向付费者） | 客户 |
| 境外资金 | 视法规 | 视法规与舆论 | 资助方 · 监管 |

> ⚠️ **资金来源不决定性质，但决定议程。** 单一来源长期超过六成时，「谁的项目」往往就是「谁的议程」——这是**经验判据**，不是定律，须结合合同条款与决策记录看。

## 八、代表性与问责

**四向问责**

| 方向 | 对象 | 机制 |
|:--|:--|:--|
| 对上 | 登记管理机关 · 业务主管单位 · 资助方 | 年报 · 审计 · 项目验收 |
| 对下 | 受益人 · 会员 | 参与式评估 · 申诉渠道 · 会员大会 |
| 对内 | 理事会 · 员工 | 章程 · 议事规则 · 人事制度 |
| 对外 | 公众 · 媒体 · 同行 | 信息公开 · 第三方评估 · 联合声明 |

**「代表谁」的三种主张**

| 主张 | 依据 | 代价 |
|:--|:--|:--|
| 会员授权 | 会员大会选举与表决 | 只代表入会者，非会员被排除 |
| 代表受影响群体 | 「我们与他们同在」的叙事 | 无程序授权，最易被质疑 |
| 专业权威 | 研究、数据、技术能力 | 权威来自方法，不来自人数 |

> ⚠️ **合法性来源与组织形态相关**：会员制靠**程序**，服务型靠**效果**，倡导型靠**证据与联盟**（最弱）。判读时先问「它自称的合法性是哪一种」，再用对应的证据去核。

**两个常见误归**

- **国家人权机构**（依「巴黎原则」设立）：政府设立、依法独立运作 —— 是**灰区**，不是 `061.2` 的典型。
- **红十字国际委员会**：瑞士民法下的社团，但日内瓦公约赋予其国际法上的特殊地位 —— **特殊主体**，不宜当 NGO 范例；各国红十字会 / 红新月会亦多为依专门法设立。

## 九、国际层面

- **「NGO」在国际法上不是法律范畴**，是描述性称谓。联合国语境大致指「非经政府间协议设立」的组织 —— 划的是**设立方式**，不是意识形态。
- **ECOSOC 咨商地位**（《联合国宪章》第 71 条；ECOSOC 第 1996/31 号决议）：**一般 · 特别 · 名册**三类，权利各不同（列席、书面陈述、口头陈述的权限与范围有别）。
- **参与 ≠ 表决**：观察员、条约机构参与、多利益相关方进程（MSI）都不产生表决权；「被邀请发言」与「参与决策」是两件事。
- **多重身份互不推导**：一个组织可以同时是「某国登记的社会服务机构」+「某国际网络的成员」+「ECOSOC 名册组织」—— 三种身份各自独立成立，任何一种都不能推出另外两种。

> ⚠️ 引用「某组织有联合国咨商地位」时，须写明**类别**与**年份**；只说「联合国认可」，等于没说。

## 十、合作形态（六档）

| 档 | 形态 | 有无机构 | 约束力 |
|:--|:--|:--|:--|
| 1 | 联合声明 / 共同倡议 | 无 | 无（署名 ≠ 承诺） |
| 2 | 联盟（coalition） | 无或极轻 | 议题绑定，可退出 |
| 3 | 网络（network） | 轻秘书处 | 信息与标准，多无强制 |
| 4 | 伞形组织（umbrella） | 有 | 成员是**组织**，常有表决与分摊 |
| 5 | 服务合同 / 共管 | 有（项目办公室） | 合同义务，违约可诉 |
| 6 | 平台型倡议（MSI） | 有（秘书处 + 成员承诺） | 自愿标准为主，认证可带市场后果 |

**判据三件**（沿用 [[061-组织及其他合作类型|061]]）：**独立法人 · 常设秘书处 · 决定对成员有约束力**。

> ⚠️ **联盟声明不产生义务**：多数倡议明确「自愿、不具法律约束力」。写合作时须标出**义务层级**：声明 / 承诺 / 合同 / 条约。

## 十二、判读六步

1. **查法律形态与登记状态** —— 是三类中的哪一类？登记 / 备案 / 未登记？境外组织是否依专门法登记？
2. **查章程** —— 目的条款、决策机关、负责人任命方式、解散时财产归属。
3. **查资金构成** —— 至少看三年：单一来源占比、政府合同占比、境外资金占比。
4. **查决策记录** —— 年度计划、预算、重大项目由谁批准；理事会会议记录是否可查。
5. **查活动与宣称的落差** —— 年报里的数量与现场、受益人口径是否对得上。
6. **查披露与审计** —— 年报、审计报告、项目评估是否公开；关联交易是否披露。

**三条证据纪律**

- **看年报与审计，不看宣传页。**
- **看资金构成，不看名号。**
- **看决策记录，不看理事名单。**

## 十三、中国语境（九项）

| 项 | 读法 |
|:--|:--|
| 三类社会组织 | 社会团体 · 基金会 · 社会服务机构 —— 登记类型决定行为能力 |
| 双重管理 → 直接登记 | 部分领域仍须业务主管单位；政策随领域而异 |
| 脱钩改革 | 行业协会商会与行政机关脱钩（2015 年起），去行政化而非去监管 |
| 慈善组织认定 | 认定 + 公开募捐资格，两步分开；有资格才可公开募捐 |
| 境外 NGO 法 | 2017 年起施行；公安机关登记、业务主管单位、活动清单制 |
| 群团组织 | 工会 · 共青团 · 妇联等 —— 归 `061.1` 侧，不作本页例 |
| 枢纽型 / 联合性组织 | 受委托联系、服务同类组织，兼具传导功能 |
| 社区社会组织 | 备案制为主，规模小、贴近基层，不能独立募捐 |
| 政府购买服务 | 合同关系，须与服务对象、绩效指标一并看 |

> ⚠️ **「社会组织」是中国政策语汇，不等于 UDC `061.2` 的全集**：后者是分类法上的「非政府组织」；前者是登记管理口径。二者大量重叠但边界不同，不得互替。
> ⚠️ **不写未核的条文细节**：具体登记条件、领域清单、年度报告要求，一律回法规原文核对。

## 十四、病理（八项）

| 病理 | 机制 |
|:--|:--|
| 使命漂移 | 收入结构悄悄改写目标，章程没改、行为已改 |
| 服务外包收编 | 长期全额受托，人事与预算受制，决策权事实上外移 |
| 壳组织 / 挂靠 | 无独立治理，借用他人登记资质运作 |
| 善款挪用与关联交易 | 通过供应商、关联机构转移资金，披露缺位 |
| 治理失灵 | 名人董事会、家族化、理事会从不表决 |
| 捐赠依赖与项目碎片 | 追着资助周期跑，无长期能力建设 |
| 代表性通胀 | 自称代表某群体，却无任何授权程序 |
| 数据与影响力夸大 | 受益人口径重复计算、效果归因不成立 |

> **共同结构**：都是**问责链的某一环断了**——断了向下的（代表性）、断了合法的（登记与披露）、或断了内部的（治理）。

## 十五、核心问题

> 「非政府」不是一种性质，而是一段关系。
>
> 一个组织之所以「非政府」，只在**设立**与**任命**这两件事上成立；至于它的钱从哪来、它替谁办事、它跟谁签合同，全都不在这两个字的射程之内。于是它最容易被两种叙事绑架：一种把它读成「纯民间」，忽略它对预算与合同的依赖；另一种把它读成「另有所图」，忽略它承担的大量公共服务。
>
> **判断一个非政府组织，真正要问的不是「它是不是民间的」，而是三个可核的问题：决策权在谁手里、钱从哪来、出了问题谁负责。** 前两个决定它今天做什么，第三个决定它明天还在不在。
