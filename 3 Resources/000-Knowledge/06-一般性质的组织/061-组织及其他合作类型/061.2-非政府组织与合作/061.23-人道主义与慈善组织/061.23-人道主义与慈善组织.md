# 061.23 人道主义与慈善组织

> **UDC `061.23`** —— 人道主义与慈善组织。本页记的是**以受难者的紧急需求或公益目的为对象、以自愿资源（捐赠 · 志愿服务 · 人道拨款）为基础的组织**，以及它们行动时的规范、准入、资金与问责结构。
> 归属判据一句话：**先问「义务从哪来」—— 来自受难者的权利（人道），还是来自捐赠者的意愿（慈善）。**

## 三、两词的分野

「人道」与「慈善」在日常语言里常互换，但判据不同。混用会导致两种误判：把捐赠当义务、把义务当恩惠。

| 维度 | 人道主义（humanitarian） | 慈善（charity / philanthropy） |
|:--|:--|:--|
| 核心问题 | 受难者的**紧迫需求**与**权利** | 公益目的的**资源分配** |
| 义务来源 | 人道法 · 人道原则 · 「不使人受苦」的普遍义务 | 捐赠者的**自愿**给予 |
| 时间尺度 | 紧急 → 恢复（可跨年，但以「危机」为界） | 长期（教育 · 医疗 · 济困可持续数十年） |
| 资源结构 | 募捐呼吁 · 机构人道拨款 · 实物 | 个人捐赠 · 基金会资助 · 遗赠 · 信托 |
| 关键约束 | **中立 · 公正 · 独立**（准入与安全的前提） | **目的合规 · 披露 · 反挪用** |
| 失败形态 | 进不去、被政治化、援助军事化 | 募捐营销化、善款碎片化、治理失灵 |

**四原则（人道）**

| 原则 | 约束什么 | 常见违反形态 |
|:--|:--|:--|
| 人道 | 减轻苦难，不因身份区别对待 | 只救「有镜头」的地方 |
| 公正 | 按需求分配，不按阵营 | 优先服务友方控制区 |
| 中立 | 不采取有利于冲突一方的行动 | 使用武装护送、嵌入军事单位 |
| 独立 | 决策不受政治 / 军事 / 经济目的支配 | 资金方直接指定行动地点与对象 |

> ⚠️ **「中立」不等于「沉默」**：见证（bearing witness）与公开报告是许多人道组织的核心方法；争议在于**何时说、说到什么程度**，而不是「说不说」。
> 📌 **慈善不必中立**：倡导型慈善组织完全可以有立场；把四原则套到所有慈善组织身上，会误判它们的合法角色。

## 四、人道行动的类型谱（八类）

| 类型 | 内容 | 判读要点 |
|:--|:--|:--|
| 搜救与紧急救济 | 灾害 / 冲突后的即时生存物资 | 响应时窗与覆盖面，不看物资总量 |
| 医疗 | 战伤救治 · 初级卫生 · 疫病应对 | 是否遵循中立准入；医疗中立是否被尊重 |
| 水 · 卫生 · 营养 | WASH · 营养干预 | 长期维持能力，不只看首轮发放 |
| 庇护与安置 | 临时住所 · 营地 · 非营地支持 | 营地治理与人身安全 |
| 保护 | 法律保护 · 人身安全 · 儿童与性别暴力 | 与「服务」区分：保护常有风险 |
| 恢复与生计 | 现金援助 · 生计重建 | 现金 vs 实物的选择依据 |
| 减灾与备灾 | 预警 · 韧性建设 | 与长期发展项目的边界 |
| 见证与倡导 | 记录 · 报告 · 公开呼吁 | 与中立原则的张力 |

> 📌 **「远程管理」（remote management）**：安全受限时由本地伙伴执行、国际方远程监督 —— 监督强度与问责链随之改变，须写明。

## 五、慈善的类型谱（十类）

| 类型 | 说明 |
|:--|:--|
| 直接救济 / 济贫 | 物资、现金、临时救助 |
| 救急与灾害慈善 | 灾害募捐、应急基金 |
| 教育文化 | 奖学金、图书馆、文化遗产 |
| 医疗健康 | 医院、疾病救助、医学研究 |
| 宗教慈善 | 以信仰团体为载体的救助与服务 |
| 社区基金 | 本地资金池，小额、就近 |
| 资助型基金会 | 不做项目，做资助决策 —— **权力在资助方向** |
| 慈善信托 | 依信托法设立，受托人管理 |
| 志愿服务组织 | 以志愿者为主要执行力量 |
| 互联网募捐平台 | 聚合小额捐赠，须依规指定 / 备案 |

> ⚠️ **不要按「规模」分类**：一间社区小屋与一家国际基金会都可以是慈善组织；差别在**目的、治理与披露**，不在体量。

## 七、组织形态（六类）

| 形态 | 结构要点 |
|:--|:--|
| 红十字 / 红新月运动 | 三部分：**红十字国际委员会**（瑞士社团 + 日内瓦公约赋予的保护性任务，具国际法上的特殊地位）· **红十字会与红新月会国际联合会**（各国红会的联合）· **各国红会**（依国内法设立，在其国内人道领域作为公共当局的**辅助者**） |
| 国际人道 NGO | 医疗、搜救、水卫等专业机构；多依赖募捐呼吁与机构拨款 |
| 宗教背景救济机构 | 动员能力强、基层网络深；须辨明「服务对象是否受信仰条件限制」 |
| 慈善会 / 基金会体系 | 资助型与运营型并存；看两本账（资助决策 + 项目执行） |
| 社区基金与志愿组织 | 就近、小额、依赖本地信任；治理常不正式 |
| 慈善信托 / 捐赠人建议基金 | 受托结构；权力在受托人与分配规则 |

> ⚠️ **红十字不是「普通 NGO」**：其特殊地位来自公约与国内法，不是因为「做得大」。把它当行业范例会误判其他组织的能力边界。

## 八、资金与问责

| 来源 | 特征 | 主要代价 |
|:--|:--|:--|
| 募捐呼吁（appeal） | 危机驱动的集体动员 | 事件后资金骤降，「被遗忘的危机」缺钱 |
| 机构 / 政府人道拨款 | 稳定、可预测 | 定向（earmarking）压缩自主判断 |
| 私营部门 / 企业捐赠 | 快、灵活 | 品牌绑定、议题被营销节奏牵引 |
| 个人小额捐赠 | 独立性最高 | 波动大，行政成本占比敏感 |
| 实物与志愿服务 | 降低成本 | 不匹配、估值与计量争议 |

**问责三线**

1. **对捐赠人** —— 资金用途、比例、报告。
2. **对受益人** —— 投诉与反馈渠道（CHS 的核心），是否真的可用。
3. **对同行标准** —— Sphere / CHS 的自评与外部审计。

**两条硬约束**

- **反恐与制裁合规**：多数司法辖区要求筛查受赠方、防止资源流向受制裁主体；合规不足会直接断掉资金链。
- **防转移（diversion）与防剥削（PSEA）**：援助被武装方截留、工作人员对受益人的性剥削与虐待，是行业公认的系统性风险，须有独立报告机制。

## 九、准入与中立的难题

| 难题 | 表现 | 判读线索 |
|:--|:--|:--|
| 准入（access） | 冲突方拒绝、路障、行政拖延 | 是否有谈判记录与替代方案（远程管理） |
| 跨界（cross-border） | 从邻国越境送援，主权争议 | 是否说明授权来源与风险 |
| 去冲突化（deconfliction） | 通报坐标以免被误击 | 是否与军事方共享信息、共享到什么程度 |
| 援助军事化 | 援助随军事行动推进 | 援助是否被用作战术工具 |
| 双重效忠指责 | 「你收了谁的钱」 | 资金结构 + 决策记录 |
| 中立 vs 见证 | 沉默换准入，还是发声失准入 | 政策是否公开、是否一致适用 |

> ⚠️ **没有零成本的选项**：进入要妥协，不进入要失职。判读的重点不是「它有没有妥协」，而是**它有没有把妥协说出来**。

## 十、本地化与权力

- **「大交易」（2016）** 承诺把更多资源直接交给本地 / 国别组织，减少分包层级。
- 现实结构常是：**国际组织拿大额合同 → 分包给本地伙伴 → 本地伙伴承担一线风险**。
- 三种失衡：**资金比例失衡**（本地伙伴份额低）· **决策权失衡**（议程由上游定）· **风险失衡**（安全与合规责任下沉）。
- 判据：**谁签合同、谁定预算、谁承担被袭击的风险** —— 三者不在一处，就是「本地化」只落在执行层。

## 十一、中国语境（九项）

| 项 | 读法 |
|:--|:--|
| 红十字会 | 依专门法设立；总会机关工作人员参照公务员法管理 —— **参公是人事制度，不改变其法定地位** |
| 慈善会系统 | 地方普遍设立，多具公募资格，与民政部门关系紧密 |
| 基金会 | 公募 / 非公募的历史分类已并入「是否取得公开募捐资格」的判断 |
| 慈善组织认定 | 在已有社会组织中认定；认定与募捐资格是**两步** |
| 慈善信托 | 2016 年起有专门制度，须备案；受托人多为信托公司或慈善组织 |
| 互联网公开募捐 | 须在国务院民政部门指定的平台发布；平台名单以官方公布为准 |
| 网络募捐活动 | 平台集中动员能力强，配捐与流量规则影响资源分布 |
| 应急慈善 | 重大灾害时由应急管理体系协调，社会力量须服从现场统一调度 |
| 境外资金与境外组织 | 境外 NGO 法 + 外汇管理；合作前须核登记与备案状态 |

> ⚠️ **不要把「慈善」写成「政府的补充」或「政府的替代」**：它是有独立法源与治理结构的一类组织，与政府的关系逐事而定（见 [[061.2-非政府组织与合作|061.2]] 的关系谱六档）。

## 十三、判读六步

1. **查法律形态与登记** —— 红十字会 / 慈善组织 / 基金会 / 信托 / 未登记志愿团体。
2. **查章程目的** —— 是「紧急救助」还是「长期公益」；两项都做时，看预算如何切分。
3. **查资金结构** —— 定向比例、单一来源占比、机构与个人捐赠之比。
4. **查规范采纳** —— 是否公开承诺 Sphere / CHS；有无独立审计。
5. **查准入与安全记录** —— 谈判记录、远程管理安排、被袭击与撤离事件。
6. **查问责与投诉机制** —— 受益人能否实际投诉；有无独立调查与 PSEA 政策。

**三条证据纪律**

- **看行动报告与财务，不看募捐文案。**
- **看受益人反馈，不看媒体曝光。**
- **看它如何区分援助与宣传，不看它说了什么。**

## 十四、病理（八项）

| 病理 | 机制 |
|:--|:--|
| 募捐营销化 | 用苦难图像换取点击，受益人成为素材 |
| 定向碎片化 | 资金被指定到项目，紧急优先序无法调整 |
| 援助转移 | 物资被武装方或地方权力截留，无独立核查 |
| 双重效忠 | 资金方指定行动区域，中立名存实亡 |
| 保护失败 | 承诺保护却无能力，受害者二次受伤 |
| 性剥削与虐待 | 权力不对等下的行业性风险，报告机制缺位 |
| 本地伙伴风险转嫁 | 上游拿合同、下游担风险与合规 |
| 数据剥削 | 受益者数据被采集，却不回流任何权利或服务 |

> **共同结构**：都是**受难者在这个结构里没有说话的位置**——募捐叙事、资金条款、分包合同、数据采集，四道环节都可以把他们变成对象而非主体。

---

## 十五、核心问题

> 人道与慈善的差别，不在规模，也不在是否「非政府」，而在**义务的来源**。
>
> 慈善的起点是**给予**：我愿意拿出一部分，交给一个可信的机构去分配。人道的起点是**主张**：有人正在受难，而他们的处境构成对所有人的要求——不因国籍、阵营、信仰而增减。
>
> 这个差别一旦丢掉，两种坏结果都会出现。把慈善当人道，就会把援助写成恩惠，一旦捐赠停止，受难者就从「有权被救」变成「无人负责」。把人道当慈善，就会要求受难者感恩，要求救援者沉默，最后把准入谈判当成公关。
>
> **判断一个人道或慈善组织，要问的不是「它善不善良」，而是三件事：它的行动依据是权利还是意愿、它的钱被绑得多紧、当受难者投诉时它有没有一条能真正走通的路。**
