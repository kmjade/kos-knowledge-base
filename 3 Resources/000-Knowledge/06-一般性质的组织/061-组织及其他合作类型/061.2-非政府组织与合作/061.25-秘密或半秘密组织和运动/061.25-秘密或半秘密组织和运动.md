# 061.25 秘密或半秘密组织和运动

> **UDC `061.25`** —— 秘密或半秘密组织和运动。本页把「秘密」当作**组织的一种属性**来处理：它对谁保密、保什么密、靠什么维持、代价是什么、外部如何核证。
> 归属判据一句话：**秘密不是道德判断，而是可见性梯度 —— 先问「对谁隐藏什么」，再问「为什么能维持」。**
> **上级**：[[061.2-非政府组织与合作|061.2 非政府组织与合作]]（本子库在其目录之内）· **上位类**：[[061-组织及其他合作类型|061 组织及其他合作类型]] · **上位容器**：[[06-一般性质的组织|06 一般性质的组织]]。
> 落位：`06-一般性质的组织/061-组织及其他合作类型/061.2-非政府组织与合作/061.25-秘密或半秘密组织和运动/`（**`061.2` 子库之内** —— `061.25` 是 `061.2` 的再下位，子库随类号嵌套）。
> ⚠️ **编号性质**：`061.25` 是 `061.2` 之下**再一级的主表细分**（小数点后两位紧接），**不是** `061.2.5`、**不是** `061.2-5`、**也不是** `061:25`。中文名依用户提供；**UDCS 中的确切英文名与范围注待核**（疑为 "Secret and semi-secret organizations and movements" 一类表述，须以原文为准，不得推定）。

## 三、「秘密」的五个维度

把「秘密组织」当成一个类别会立刻出错：绝大多数组织都在某个维度上保密。正确的做法是**分维度定位**。

| 维度 | 表现 | 可核证线索 |
|:--|:--|:--|
| 成员身份 | 不公布名单 · 用化名 · 只在小范围互认 | 是否有公开会员册、章程签署记录 |
| 目的与纲领 | 只对内部说明真实目标 | 公开宣言与内部文件是否一致 |
| 行动 | 不预告、不认领 | 行动与公开表态的时间差 |
| 资源 | 资金来源不披露 | 财务报告、审计、登记信息 |
| 存在本身 | 对外否认其存在 | 是否有可核实的对外代表 |

**「对谁保密」同样重要**

| 保密对象 | 常见情形 |
|:--|:--|
| 对政府 / 执法 | 规避登记、取缔或监控 |
| 对公众 / 媒体 | 避免舆论压力或猎奇 |
| 对一般成员 | 核心圈掌握全貌（双层结构） |
| 对竞争者 / 同行 | 保持组织优势 |
| 对家庭成员 | 保护本人与亲属 |

> ⚠️ **保密方向不同，性质就不同**：一个只对公众隐藏财务的社团，与一个对成员都隐藏目标的核心圈，不是同一类对象。判读时先定位「对谁」。
> ⚠️ **合法但保密 ≠ 秘密组织**：企业董事会、修道会、考试命题组都在保密，但不在本页的类型谱内 —— 差别在**保密是否构成其组织形态的核心**。

## 四、类型谱（八类）

| 类型 | 形态要点 | 判据 | 常见误判 |
|:--|:--|:--|:--|
| 秘密社团（兄弟会 / 秘仪型） | 入会仪式 · 内部等级 · 知识分层 | 仪式与秘密知识是凝聚核心 | 被当作「幕后操纵者」 |
| 地下政治组织 | 目标明确 · 层级或细胞制 | 存在即须隐蔽，公开即被取缔 | 被高估规模与能力 |
| 抵抗运动 | 外来占领或高压下的网络 | 目标对外公开，成员对内保密 | 战后被神话化 |
| 秘传 / 宗教团体 | 教义分层 · 师徒传承 | 秘密是教义结构的一部分 | 与「邪教」标签混用 |
| 准军事 / 民兵型 | 纪律 · 指挥链 · 制服或代号 | 有武力准备与指挥结构 | 与合法自卫组织混淆 |
| 网络化运动 | 无中心 · 松散串联 · 共享口号 | 没有可罢免的领导 | 被误认作统一指挥 |
| 双层外壳型（半秘密） | 公开前台 + 内部核心 | 前台可登记、可对外，核心不公开 | 只看前台或只看传闻 |
| 犯罪型组织 | 以非法收益为目的 | **本页只作组织形态描述**，定性归 [[34-法律\|34 法律]] | 把「秘密」等同于「犯罪」 |

> ⚠️ **八类是描述工具，不是罪名表**。同一组织可跨多类；分类的目的是**说明它为什么保密、保密带来什么后果**，不是给它贴标签。

## 五、秘密的四种功能与代价

| 功能 | 换来的 | 代价 |
|:--|:--|:--|
| 生存 | 避免被取缔、被捕、被监控 | 无法公开筹款、无法公开招募、无法公开辩护 |
| 凝聚 | 仪式、秘密知识、共同风险增强归属 | 内部等级固化，新人难以进入决策 |
| 信息控制 | 减少外泄，保持行动突然性 | 内部信息失真，谣言比事实跑得快 |
| 行动安全 | 降低被侦测的概率 | 协调成本高，规模有硬上限 |

> 📌 **四组代价互相叠加**：越保密 → 越依赖内部信任 → 越需要忠诚机制 → 退出成本越高 → 内部分裂越剧烈。

## 六、组织结构谱

| 结构 | 规模上限 | 信任机制 | 典型断裂方式 |
|:--|:--|:--|:--|
| 细胞制 | 小（每单元数人） | 只知本单元，纵向单线 | 单点被捕后的连锁暴露 |
| 层级制 | 中 | 命令链 + 纪律 | 中层叛离、上层失联 |
| 网络化 | 大但松散 | 共享叙事，不共享计划 | 无法协调，行动碎片化 |
| 双层外壳 | 中到大 | 前台负责合法事务，核心负责决策 | 前台被追责而核心隐身 |
| 伞形联合 | 大 | 成员组织各自保留自主 | 路线分歧导致分裂 |

**三条结构性后果**

1. **规模与保密成反比**：单元越多，暴露面越大；这是秘密组织难以做大的结构性原因，而非能力问题。
2. **信任成本随规模上升**：无法用公开制度替代信任时，只能靠人身关系，效率随人数下降。
3. **信息越集中，误判越致命**：核心圈掌握全貌，一旦判断失误，全组织同向出错。

## 七、入会、忠诚与退出

| 环节 | 机制类型 | 分析要点 |
|:--|:--|:--|
| 入会 | 推荐 · 宣誓 · 考验 · 亲缘 / 地缘 · 职业门槛 | 门槛越高，凝聚力越强，补充越慢 |
| 忠诚 | 仪式 · 秘密共享 · 互惠 · 共同风险 · 声誉绑定 | 秘密共享使退出即构成「知情风险」 |
| 退出 | 自愿退出 · 除名 · 沉默义务 | 退出成本决定成员是否敢提异议 |

> ⚠️ **本页只分析机制与后果，不讨论如何施压、如何识别或如何规避。**
> ⚠️ **退出成本是本页最重要的伦理指标**：当一个组织的成员无法安全退出时，它的「自愿性」就已经不成立 —— 这一点与 [[06.01-会员的权利与义务|06.01 会员的权利与义务]] 直接相接。

## 九、半秘密：双层结构

半秘密是最常见、也最容易被误读的形态：**公开的部分与不公开的部分同时存在**。

| 层 | 功能 | 可见性 |
|:--|:--|:--|
| 前台 | 登记、对外联络、募款、发布立场 | 公开可查 |
| 核心 | 决策、人事、资源分配 | 不公开 |

**四条判读线索**

1. **章程公开到什么程度** —— 决策机关与任命程序是否写明。
2. **财务披露的颗粒度** —— 总额公开但来源不公开，还是两者皆无。
3. **对外代表的授权** —— 发言人能否代表组织承诺。
4. **成员结构** —— 公开成员与匿名成员的比例与角色差异。

> ⚠️ **只看前台会低估，只看传闻会高估**。半秘密组织的判读必须**两层同时看**，并明确哪一层有可核证材料。

## 十、研究伦理与证据纪律

研究对象本身的隐蔽性，会系统性地放大三类风险：**信息污染**（宣传、谣言、伪造文件）、**去匿名化伤害**（成员与家属被曝光）、**研究者自身的法律与安全风险**。

| 纪律 | 具体要求 |
|:--|:--|
| 区分来源类型 | 司法文书 · 学术研究 · 调查报道 · 组织自称 · 匿名传闻 —— **五类不可等量齐观** |
| 不做成员点名 | 只描述结构与机制，不指认在世个人 |
| 交叉验证 | 至少两类独立来源；单一来源只作「待核」 |
| 标注不确定性 | 「据称」「据报道」必须保留，不得改写成事实句 |
| 引用时间点 | 组织会变化，结论须附观察时点 |

> ⚠️ **写作伦理先于结论**：本库宁可留空，也不补一段听上去完整但没有来源的叙述。

## 十一、信息生态与误认

秘密性天然制造信息缺口，而缺口会被叙事填补。常见的四种填充物：

| 填充物 | 机制 | 辨别方式 |
|:--|:--|:--|
| 全能化叙事 | 把有限证据推成「幕后操纵一切」 | 追问：它有没有可核证的行动记录 |
| 标签化攻击 | 用「秘密组织」指控对手 | 看指控方是否给出文件与司法结果 |
| 猎奇化传播 | 仪式与符号被放大成核心内容 | 看是否只谈符号、不谈资源与决策 |
| 伪造文件 | 以「泄露材料」形式出现 | 核纸张、格式、时间线、交叉来源 |

> ⚠️ **本页不复述具体阴谋论清单**：复述即传播。只保留**辨别方法**。

## 十二、中国语境（八项）

| 项 | 读法 |
|:--|:--|
| 结社管理 | 社会组织实行登记管理；未登记而以组织名义活动会被依法处理（**认定程序归法律**） |
| 历史研究 | 会党、帮会、秘密教门是史学与社会学研究对象，有成熟文献与档案方法 |
| 宗教团体 | 依法登记与活动规范；宗教团体不等于秘密组织，须分开判断 |
| 境外组织 | 境外非政府组织境内活动依专门法管理 |
| 国家安全 | 反间谍、反渗透有专门法律框架；具体条文与程序回法源核对 |
| 「非法组织」认定 | 属行政 / 司法判断，不属分类法判断 |
| 研究口径 | **以司法文书与官方公告为准**，不以网络传闻为据 |
| 历史叙述的分寸 | 对历史事件只作类型与结构分析，不作当代指认 |

> ⚠️ **本页不评价任何现行组织的合法性**：这是法律与行政机关的判断，不是知识组织系统的功能。
> ⚠️ **历史案例与当代指认必须分开**：史学研究的方法不能直接套到在世组织上。

## 十四、判读六步

1. **查公开法律形态与登记状态** —— 登记 / 备案 / 未登记；未登记不等于非法，但决定其行为能力。
2. **查章程与对外代表** —— 目的是否公开，谁有权代表组织承诺。
3. **查财务披露** —— 总额、来源、审计是否可查。
4. **查成员结构** —— 公开成员与匿名成员的比例与角色差异。
5. **查信息来源与可核证性** —— 用的是哪一类来源，能否交叉验证。
6. **查指控的司法结果** —— 有指控不等于有认定；看结案文书。

**三条证据纪律**

- **看司法文书，不看传闻。**
- **看它公开承诺了什么，再看它做不到什么。**
- **不做成员点名，只留结构判断。**

## 十五、病理（八项）

| 病理 | 机制 |
|:--|:--|
| 分裂（schism） | 保密使分歧无法公开辩论，最终只能分裂 |
| 宗派化 | 领导层不可罢免，异议被视为背叛 |
| 退出惩罚 | 退出成本过高，成员被迫留下 |
| 财务不透明 | 资源分配由核心圈独占，缺乏核对 |
| 渗透恐慌 | 一旦怀疑内鬼，清洗本身成为最大破坏 |
| 目标漂移 | 为自保而行动，原目标逐渐消失 |
| 暴力化 | 封闭 + 高压 + 无外部反馈的常见终局 |
| 神话化 | 内部与外部叙事互相强化，判断能力下降 |

> **共同结构**：都是**反馈回路的缺失** —— 没有公开批评、没有可退出机制、没有外部核对，错误无法被纠正，只能被放大。

## 十六、核心问题

> 「秘密」不是一种组织类型，而是一种**稀缺资源的使用方式**。
>
> 组织用可见性换取安全、凝聚与突然性，代价是把问责、纠错与退出一起抵押出去。规模越大，抵押越重；时间越长，抵押越难赎回。于是秘密组织几乎共享同一条生命曲线：**小规模高效 → 扩张受阻 → 内部猜疑 → 分裂或暴力化**。
>
> **判断一个秘密或半秘密组织，不要先问「它到底在密谋什么」，而要先问三件事：它对谁保密、它靠什么维持忠诚、成员能不能安全退出。** 前两个说明它现在为什么存在，第三个说明它将来会变成什么。
