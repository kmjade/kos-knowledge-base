# 061.27 基金、资助、机构

> **UDC `061.27`** —— 基金、资助、机构。本页把「钱」当作**组织问题**来处理：一笔钱以什么法律关系被持有、由谁决定给谁、给完之后谁负责。
> 归属判据一句话：**基金是财产，基金会是法人，资助是行为，机构是形态 —— 四个词分属四层，混用即失准。**
> **上级**：[[061.2-非政府组织与合作|061.2 非政府组织与合作]]（本子库在其目录之内）· **上位类**：[[061-组织及其他合作类型|061 组织及其他合作类型]] · **上位容器**：[[06-一般性质的组织|06 一般性质的组织]]。
> 落位：`06-一般性质的组织/061-组织及其他合作类型/061.2-非政府组织与合作/061.27-基金、资助、机构/`（**`061.2` 子库之内** —— `061.27` 是 `061.2` 的再下位，子库随类号嵌套）。
> ⚠️ **编号性质**：`061.27` 是 `061.2` 之下**再一级的主表细分**（小数点后两位紧接），**不是** `061.2.7`、**不是** `061.2-7`、**也不是** `061:27`。中文名依用户提供；**UDCS 中的确切英文名与范围注待核**（疑与 foundations / grant-making bodies 一类表述相关，须以原文为准，不得推定）。

## 三、四个词不是同义词

这是本类最常出错的地方。「基金、资助、机构」在日常语里几乎同义，在分析上分属四层。

| 词 | 所指 | 常见误用 |
|:--|:--|:--|
| **基金**（fund / endowment） | 一**笔财产**及其使用目的 | 被当成组织；「这只基金有理事会吗」问错了层 |
| **基金会**（foundation） | 一个**法人**，持有并管理基金 | 被默认一定做资助（运营型基金会不做外部资助） |
| **资助**（grant-making） | 一种**行为**：把钱与资源转移给他人使用 | 被当成组织类型；「机构资助」说的是**方式**，不是机构 |
| **机构**（institution / body） | 一种**组织形式**的泛称 | 被当作实体判据；有牌子不等于有决策权 |

> ⚠️ **一笔基金可以没有法人**：专项基金依附于既有组织，慈善信托由受托人持有 —— 两者都可能没有独立理事会。
> ⚠️ **一个基金会可以不做资助**：运营型基金会自己执行项目，钱不出去。
> ⚠️ **「机构资助」是给法**：指资助受资助方的**整体运转**，与「机构类型」无关。

## 四、基金的三层结构

看一笔基金，要分三层看；三层错位是多数治理问题的来源。

| 层 | 内容 | 谁负责 |
|:--|:--|:--|
| **财产层** | 本金、收益、支出规则 | 受托人 / 理事会（依载体） |
| **法律关系层** | 捐赠人与受益人之间的**受托关系** | 章程 · 信托文件 · 法规 |
| **决策层** | 谁决定给谁、给多少、给多久 | 理事会 · 专业委员会 · 捐赠人（视条款） |

**三种载体**

| 载体 | 是否有独立法人 | 问责路径 |
|:--|:--|:--|
| 基金会 | 有 | 理事会 + 登记管理机关 + 年报 |
| 慈善信托 | 通常无独立法人，由受托人持有 | 受托人 + 信托监察人 + 备案 |
| 专项基金 | 无（依附母体组织） | 母体组织的治理与披露 |

> ⚠️ **载体不同，问责路径就不同**：问「谁负责」之前先问「它以什么形式存在」。把专项基金当独立机构追责，会找错对象。
> ⚠️ **法律关系层最容易被跳过**：钱「是谁的」在民法上并不模糊，模糊的是**谁知道、谁能查、谁能改**。

## 五、类型谱（十类）

| 类型 | 形态要点 | 判据 | 常见误读 |
|:--|:--|:--|:--|
| 资助型基金会 | 不做项目，对外给钱 | 支出以 grants 为主 | 被当成「只开会不发钱」 |
| 运营型基金会 | 自己执行项目 | 支出以自有项目为主 | 被误认作资助方 |
| 社区基金会 | 地域性 · 多元捐赠 · 本地决策 | 资金来自本地、决策在本地 | 被当成小型资助基金会 |
| 企业基金会 | 由企业发起或出资 | 治理与品牌关联度 | 与企业捐赠、CSR 部门混同 |
| 家族基金会 | 家族出资 · 家族治理 | 理事会席位与继承安排 | 被当成私人钱包 |
| 公共 / 官办基金会 | 由政府推动设立或注资 | 人事与预算的政府关联 | 与政府机构混同（承 `061.1`） |
| 慈善信托 | 以信托关系持有 | 受托人 + 信托文件 + 监察人 | 被当成基金会 |
| 捐赠人建议基金（DAF） | 在母体机构下开立子账户 | 捐赠人**建议**、机构**决定** | 「建议」被读成「决定」 |
| 专项基金 / 基金池 | 依附既有组织的定向资金 | 母体治理 + 用途限定 | 被当成独立法人 |
| 公益创投 / 影响力投资 | 以投资形式投入，期待财务或社会回报 | 回报结构 · 退出方式 | 与无偿资助混同 |

> ⚠️ **十类是形态工具，不是等级表**：没有哪一类「更高级」。规模、专业性、治理复杂度是三件不同的事。
> ⚠️ **企业基金会 ≠ 企业捐赠**：前者是独立法人（通常），后者是企业的一笔支出；混同会算错问责对象。
> ⚠️ **DAF 的「建议」是关键词**：法律上决定权在母体机构，不在捐赠人 —— 这是它与家族基金会的实质差别。

## 六、两种资助形态

| 形态 | 资助方控制 | 对受资助方的后果 | 主要风险 |
|:--|:--|:--|:--|
| **项目资助**（project / restricted） | 高：用途、周期、指标均限定 | 项目可做，行政与人力长期赤字 | 项目化陷阱 |
| **机构资助**（core / unrestricted） | 低：用途由受资助方定 | 可建团队、可做长期能力建设 | 被质疑「钱花到哪了」 |
| 一次性 | 中 | 无法规划 | 年年重新申请 |
| 多年期 | 低到中 | 可做长周期工作 | 资助方战略一变即断 |

> 📌 **项目化陷阱的机制**：只给项目 → 管理成本无处报销 → 组织不敢扩编、不敢做研发与政策参与 → 项目越接越多以摊薄成本 → 组织越来越脆。**受资助方不是被饿死的，是被「只给项目」累死的。**
> ⚠️ **机构资助不是「无条件的钱」**：多数仍附治理评估、年度对话与阶段目标，差别在**用途决定权归谁**。
> ⚠️ **多年期承诺的真实性看违约条款**：口头多年期与合同多年期，在组织规划上是两件事。

## 七、资助关系的权力不对称

资助不是平等交换：一方有钱与定义权，一方有执行能力与本地知识。

| 不对称处 | 表现 | 后果 |
|:--|:--|:--|
| 信息 | 资助方依赖受资助方了解现场，却常自认更懂 | 方案由远端设计 |
| 期限 | 一年一签、按年度预算 | 无法做跨越周期的议题 |
| 定义 | 指标、逻辑框架、成功标准由资助方定 | 指标替代目标 |
| 退出 | 资助方可单方中止，受资助方不可 | 风险单向转移 |
| 声誉 | 资助方品牌被看见，执行方常隐名 | 功劳与责任错配 |

**衍生的五种压力**

- **申请成本**：写标书的人力不进项目预算。
- **报告负担**：不同资助方各要一套格式。
- **指标替代**：可计量的被做，重要的被略。
- **使命漂移**：跟着钱的定义走。
- **同质化**：大家做同一批「可资助」的事。

> ⚠️ **判读信号**：受资助方致谢的语气、资助方是否公布**完整**受资助方名单、项目周期是否总是十二个月。
> ⚠️ **不对称本身不是病**：资源方必然有话语权。病在**不对称被当作正常且不必说明**。

## 八、基金会的四种功能

若只是「把钱给出去」，任何支付通道都能替代基金会。基金会的存在理由在四种判断与承担。

| 功能 | 内容 | 可替代物 | 失效形态 |
|:--|:--|:--|:--|
| 筛选与尽调 | 在信息不足处判断谁值得支持 | 同行推荐、公开评选 | 只看关系与名气 |
| 风险承担 | 做政府与市场都不愿先做的事 | 政府试点、天使投资 | 只做安全项目 |
| 长期性 | 用本金支撑跨越政治与市场周期的工作 | 长期政府项目 | 年年换方向 |
| 陪伴与能力建设 | 提供非货币支持（网络、技术、治理） | 咨询机构 | 只开支票 |

> 📌 **四种功能的共同前提是「判断力」**：没有判断力的基金会，等价于一个效率更低的转账通道。
> ⚠️ **「风险承担」不等于「不计后果」**：它指承担**早期不确定性**，不是豁免基本尽调。

## 九、钱的性质：本金、支出与规则

| 维度 | 两种取向 | 分析要点 |
|:--|:--|:--|
| 存续 | 本金型（endowment，只花收益） | 追求永久，决策偏保守，议题易滞后 |
| | 支出型（spend-down，限期花完） | 追求当期影响，可承担高风险，但不可逆 |
| 支出下限 | 年度公益支出比例 | **是下限不是目标**；「刚好达标」本身是信号 |
| 管理成本 | 行政管理费用比例上限 | 上限过低会挤压人力，反而降低效果 |
| 收入来源 | 单一本金 / 持续募捐 / 混合 | 单一来源稳定但议程被单一意志锁定 |

**常见口径（须核）**

- 中国：公募与非公募基金会的年度公益支出比例、行政管理费用比例各有下限 / 上限要求，计算基数与最新口径**须回法规原文核对**（常见引用为 70% / 8% / 10%，但**不得据本页引用**）。
- 美国：私人基金会年度最低分配额通常按资产价值一定比例计（常引 5%），亦**须回法源核对**。

> ⚠️ **比例是治理工具，不是绩效指标**：达标只说明合法，不说明有效。
> ⚠️ **永久性 vs 支出型不是道德选择**，是**时间偏好**选择：前者押注「长期存在」，后者押注「当下改变」。

## 十、治理与问责

| 问责方向 | 问的问题 | 常见缺口 |
|:--|:--|:--|
| 对捐赠人 | 钱是否按意愿使用 | 意愿过于模糊或过于具体 |
| 对受资助方 | 承诺是否兑现、周期是否稳定 | 无申诉渠道 |
| 对公众 | 资助取向与支出结构是否可查 | 只披露总额不披露名单 |
| 对监管 | 年报、审计、比例是否合规 | 形式合规、实质空心 |

**三处结构性风险**

1. **关联交易** —— 发起企业、理事关联方承接项目或采购。
2. **理事会构成** —— 家族 / 企业席位过多时，独立判断被稀释。
3. **捐赠人越位** —— 章程未写清时，大额捐赠人可能实际行使决策权。

> ⚠️ **资金来源不决定性质，但决定议程**（承 [[061.2-非政府组织与合作|061.2]]）：单一来源长期偏高时，须核合同条款与决策记录。
> ⚠️ **关联交易不必然违法**：关键在**是否披露、是否回避、价格是否公允** —— 判断归 [[34-法律|34 法律]] 与会计准则。

## 十一、中国语境（九项）

| 项 | 读法 |
|:--|:--|
| 基金会管理条例（2004） | 确立公募 / 非公募分类与治理要求；**修订情况须核** |
| 慈善法（2016 制定 · 2023 修正） | 慈善组织认定 · 公开募捐资格 · 信息公开 · 信托专章衔接 |
| 慈善信托 | 《信托法》（2001）公益信托专章 + 慈善法；受托人、监察人、备案 |
| 支出与费用比例 | 年度公益支出比例、行政管理费用比例有法定要求；**具体数值与口径回法源核** |
| 境外基金会代表机构 | 依《境外非政府组织境内活动管理法》（2016 通过 · 2017 施行）设立与活动 |
| 企业基金会 | 由企业发起设立，须区分**基金会法人**与**企业内设公益部门** |
| 社区基金 / 社区基金会 | 多依托既有慈善组织设立专项基金，治理与本地性须分别核 |
| 高校基金会 | 校友捐赠与基金运作，涉及资产管理规则 |
| 信息公开 | 年度工作报告、审计报告、募捐与项目信息；**披露颗粒度**是判读要点 |

> ⚠️ **税前扣除资格属财税法规**，不是分类法问题；本页不给税务结论。
> ⚠️ **法规修订频繁**：引用条文前须核现行有效版本，本页只给结构框架。

## 十二、判读六步

1. **查载体与法律形态** —— 基金会法人 / 慈善信托 / 专项基金；无独立法人者，问责指向母体。
2. **查章程与决策权** —— 谁提名理事、谁任免负责人、捐赠人有无否决权。
3. **查资金来源结构** —— 本金、募捐、企业拨款各占多少；是否单一来源。
4. **查支出结构** —— 项目资助 / 机构资助 / 行政成本的比例；**是否公布完整资助名单**。
5. **查资助周期与报告要求** —— 是否多年期；报告频率与颗粒度是否与实际能力匹配。
6. **查关联交易与治理独立性** —— 理事关联方、发起企业承接、回避机制。

**三条纪律**

- **看年报与审计，不看宣传页。**
- **看完整名单，不看精选案例。**
- **看多年趋势，不看单年数字。**

---

## 十三、病理（八项）

| 病理 | 机制 |
|:--|:--|
| 通道化 / 挂名 | 只做出账通道，不做出资判断，实质由他人决定 |
| 资金池化 | 资金集中但不形成资助策略，钱在账上不动 |
| 资助方殖民 | 用指标与模板把受资助方变成执行外包 |
| 报告表演 | 报告为满足格式而写，与实际工作脱节 |
| 指标替代目标 | 可测的被做，重要的被略 |
| 关联交易 | 资源在发起方与基金会之间循环 |
| 休眠基金会 | 依法存在、按比例支出，但无实质判断 |
| 支出率套利 | 为达标而年底突击支出，项目质量让位于比例 |

> **共同结构**：都是**判断环节被跳过** —— 钱进来了、钱出去了，中间「为什么给它」这一步没有留下任何痕迹。

---

## 十四、核心问题

> 基金会不是「有钱的组织」，而是**替不在场的人做判断的组织**：捐赠人不在场，受益人不发言，公众只能事后查账。
>
> 因此它的全部合法性建立在三件事上：**钱是谁的（受托关系）、谁决定给谁（判断权）、给完之后谁负责（问责路径）**。三者任一缺失，它就退化为一个转账通道 —— 合法、合规、无害，也没有理由存在。
>
> **判断一家基金会，不要先看它捐了多少，而要先看它拒绝过什么、公布过什么、以及它的受资助方敢不敢说「不」。**
