# 06.05NOBEL:172.4 诺贝尔和平奖

> **UDC `06.05NOBEL:172.4`** —— 具体奖项的**落位页**：一个由遗嘱创设、由五人委员会评定、以年度授予运行的**制度性荣誉**。

## 三、基本资料

| 属性 | 值 |
|:--|:--|
| 授予机构 | **挪威诺贝尔委员会**（Norwegian Nobel Committee），五人，由挪威议会任命 |
| 授予地 | **奥斯陆**（和平奖是唯一在挪威颁的诺贝尔奖；其余四项在斯德哥尔摩） |
| 首届 | 1901 年 |
| 周期 | 年度（每年 12 月 10 日，诺贝尔逝世纪念日） |
| 依据 | 阿尔弗雷德·诺贝尔 1895 年遗嘱 |
| 奖金 | 瑞典克朗，金额随基金收益浮动；可多人分摊 |
| 获奖人数 | 可为个人 · 多人 · 组织；无硬性上限 |
| 空缺 | 允许当年不颁（历史上确有数年未授予） |
| 追授 | 1974 年后的章程只允许在获奖者去世后不久授予 |
| 保密 | 提名与评审记录保密，**50 年后**开放 |

> ⚠️ **「五个奖项」不是全部**：经济学奖由瑞典中央银行 1968 年设立，**不在诺贝尔遗嘱之内**，正式名称亦不同。本页只涉及和平奖。

## 四、遗嘱与三项标准

诺贝尔遗嘱把和平奖授予「**为促进民族间友爱、为废除或裁减常备军、为召开与推动和平大会作出最多或最好工作的人**」。这一表述产生三个解释空间：

| 表述 | 解释空间 | 实践上的后果 |
|:--|:--|:--|
| 「民族间友爱」 | 可涵盖人权 · 人道救援 · 民主化 | 奖项范围向公民社会扩张 |
| 「废除或裁减常备军」 | 可涵盖军控 · 反核 · 裁军谈判 | 冷战期与军控议题高度绑定 |
| 「和平大会」 | 可涵盖国际组织 · 多边机制 | 国际组织与外交家成为常客 |

> ⚠️ **标准的模糊不是缺陷，而是授权**：遗嘱没有定义「和平」，委员会因此拥有**很大的裁量权**；批评其「政治化」与赞扬其「道义性」，往往指向同一个事实。

## 五、评选流程

| 阶段 | 时点 / 主体 | 要点 |
|:--|:--|:--|
| ① 提名 | 前一年秋季起，**2 月 1 日截止** | 有资格的提名人：各国议员与政府成员 · 国际法院与国家法学家 · 大学相关教授 · 前获奖者 · 诺贝尔研究所相关人员等；**不接受自荐** |
| ② 筛选 | 春季 | 委员会从数百项提名中形成短名单 |
| ③ 评议 | 春至秋 | 委员会会议 · 外部专家与顾问意见 |
| ④ 决定 | 10 月公布 | 委员会内部表决；**决定不可上诉** |
| ⑤ 授予 | 12 月 10 日 | 奥斯陆颁奖典礼 · 获奖演讲 · 奖章与证书 |

**四个容易误解的点**

| 常见误解 | 实际 |
|:--|:--|
| 「提名即入围」 | 提名数量以百计，短名单极少 |
| 「获奖理由=官方评价全文」 | 公布的是**简短颁奖词**，长文本由委员会另行发布 |
| 「可以复议或申诉」 | 决定终局，无上诉机制 |
| 「提名记录随时可查」 | **50 年保密期**，事后研究须等档案开放 |

## 六、获奖者类型谱

| 类型 | 特征 | 说明 |
|:--|:--|:--|
| 国家领导人 / 外交家 | 谈判 · 停战 · 和解 | 争议常来自「在任获奖」的时机 |
| 国际组织 | 多边机制 · 维和 · 人道体系 | 与「和平大会」条款直接呼应 |
| 人权与民主活动家 | 公民权利 · 政治犯 | 20 世纪后期显著增多 |
| 人道救援组织 | 医疗 · 难民 · 饥荒救助 | 常与「友爱」条款挂钩 |
| 记者与言论自由 | 信息自由 · 反审查 | 和平概念的扩展 |
| 科学家 | 军控 · 禁化武 · 气候 | 从「裁军」传统延伸 |
| 宗教领袖 | 跨宗教和解 | 道义象征意义强 |
| 反核与草根运动 | 社会动员 | 与官方外交路径形成对照 |

> 📌 **百年趋势**：从**国家精英与外交成果**，转向**公民社会与人权**；从「结束战争」转向「结构性暴力 · 发展 · 环境」——这正是「和平」定义扩张的证据（见第八节）。

## 七、争议与批评

| 争议 | 内容 | 判断要点 |
|:--|:--|:--|
| **政治化** | 被指服务于某种外交立场 | 看当年的提名结构与委员会构成 |
| **时机问题** | 在任领导人 · 冲突未结束时授予 | 事后成效与授予时点的错位 |
| **效果不可证** | 奖项是否真的促进了和平 | 难以建立因果：获奖 ≠ 因果 |
| **遗漏** | 公认的重要人物从未获奖 | 遗漏与授予同样反映裁量 |
| **欧洲中心** | 委员会构成与议题偏好 | 与「民族间友爱」的普适表述形成张力 |
| **定义扩张** | 环境 · 粮食 · 发展 是否属「和平」 | 属于标准的解释之争，不是程序失误 |
| **获奖者后续失德** | 个别获奖者后来受质疑 | 与撤销机制的关系见 [[06.05-奖励、荣誉、奖品、颁奖\|06.05]] 第六节 |

> ⚠️ **批评不构成撤销理由**：争议针对的是**判断**；撤销针对的是**事实瑕疵**（造假 · 资格不符）。把两者混同，会把奖项变成舆论投票。

## 八、「和平」的定义之争

| 取向 | 含义 | 对应获奖谱系 |
|:--|:--|:--|
| **消极和平** | 没有战争 · 停火 · 裁军 | 停战谈判 · 军控 · 维和 |
| **积极和平** | 无直接暴力，且无结构性压迫 | 人权 · 发展 · 粮食 · 环境 |
| **正负之间** | 以制度与法治替代暴力 | 国际法 · 国际组织 · 民主化 |

> 📌 这一区分（常与 Johan Galtung 的和平研究框架关联）解释了为什么同一个奖既能授予停战谈判者，也能授予气候活动者——**不是标准漂移，而是「和平」被理解为两种不同的东西**。

## 九、与其他诺贝尔奖项的关系

| 项 | 关系 |
|:--|:--|
| 物理 · 化学 · 生理学或医学 · 文学 | 同为遗嘱所设四项，在斯德哥尔摩颁 |
| 经济学奖 | **1968 年由瑞典中央银行设立**，非遗嘱原设，正式名称带设立者 |
| 共同点 | 同一基金会 · 同一授奖周期 · 同类奖章与证书 |
| 差异 | 和平奖由**挪威**的委员会评定，其余由瑞典各机构评定 |

> ⚠️ **不要写成「诺贝尔六奖」而不作说明**：和平奖之外四奖与经济学奖的法律来源不同，混写会掩盖制度差异。

## 十、记录方法

奖项是**事件**，不是属性。本库建议字段：

| 字段 | 值示例形式 |
|:--|:--|
| `award` | 诺贝尔和平奖 / Nobel Peace Prize |
| `awarded_by` | 挪威诺贝尔委员会 |
| `award_date` | `YYYY-10`（公布）/ `YYYY-12-10`（授予） |
| `award_scope` | 个人 / 组织（组织须记全称） |
| `award_joint` | 共同获奖者（并列时必记） |
| `award_citation` | 颁奖词要旨（原文 + 译） |
| `award_status` | `awarded` / `withdrawn` / `declined`（历史上确有拒领） |
| `award_basis` | 依据事件 / 作品 / 行动的链接 |

**三条纪律**

1. **写事件不写身份**：不写「著名和平奖得主」，写「YYYY 年获诺贝尔和平奖」。
2. **写共同获奖**：并列获奖漏记共同获奖者，是把个人史写成英雄史。
3. **写争议要标来源**：争议属于**评价**，须与事实记录分开。

## 十一、病理清单（本奖特有）

| 病理 | 表现 |
|:--|:--|
| 时机政治 | 授予与外交时点高度耦合 |
| 象征通胀 | 「和平」被用于各类议题背书 |
| 颁奖词替代事实 | 只引颁奖词，不查提名与档案 |
| 遗漏成谜 | 以「没获奖」反推「不重要」 |
| 荣誉外溢 | 获奖后被用于与和平无关的商业或政治背书 |
| 记录失真 | 把「提名」写成「入围」，把「公布」写成「颁奖」 |

## 十二、核心问题

> 一个由**私人遗嘱**创设、由**议会任命的五人委员会**评定、程序**保密五十年**、结果**不可上诉**的奖，为什么能成为全球最受注意的道义信号？答案不在它的标准有多精确——恰恰相反，遗嘱只给了三句宽泛的话——而在它把**稀缺的承认**制度化了：每年只有一个（或一组）名字被抬到聚光灯下，而**标准越模糊，叙事空间越大**。这既是它影响力的来源，也是它一切争议的来源。
