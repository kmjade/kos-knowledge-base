# 01 组织总论

> **UDC 06 / DDC 060** — 本支线处理组织的**客体问题**：什么算一个组织（**定义**）· 有哪些种类（**类型学**）· 内部怎么分（**结构**）· 谁有权决定与问责（**治理**）。
> 归属判据一句话：**问「这个组织是什么、怎么构成、谁说了算」，而不是「怎么把它管好、怎么提升绩效」。**

## 二、什么算一个组织

| 要素 | 说明 | 缺失时 |
|:--|:--|:--|
| 目标 | 有被共同承认的意图（不必然书面） | 只是人群，不是组织 |
| 成员与边界 | 谁在内、谁在外可辨 | 无边界的「圈子」 |
| 规则与结构 | 角色、职权、程序 | 一次性协作 |
| 持续性与可替代性 | 人员更替后仍存续 | 随发起人解散 |
| 对外身份 | 有名称、可被识别与追责 | 无名行动 |

**近邻四辨**

| 对象 | 关键差别 |
|:--|:--|
| 群体（group） | 无稳定结构，随情境聚散 |
| 网络（network） | 以关系连接为主，无统一目标与职权链 |
| 市场（market） | 以价格协调，不需组织内部命令 |
| 制度（institution） | 是**规则与惯例**（如婚姻、产权），组织是其载体 |

> ⚠️ **「组织」与「机构」常被混用**：中文「机构」既可指组织实体（a body），也可指制度安排（an institution）。讨论治理时须先说清指哪一个。
> 📌 **正式 ≠ 有章程**：正式化指**角色与规则被明确化**；大量组织有章程却不按章程运转（形式化），也有无章程但高度稳定的组织。

## 三、类型学：五条常用轴

| 轴 | 取值 | 判读意义 |
|:--|:--|:--|
| **目的** | 营利 · 非营利 · 互助 · 公共 | 决定剩余归属与监督方式 |
| **成员资格** | 会员制 · 非会员制 | **协会是会员制，基金会通常无会员** |
| **法律形态** | 公司 · 社会团体 · 基金会 · 社会服务机构 · 事业单位 · 合作社 | 决定登记机关与责任形式 |
| **治理结构** | 会员大会制 · 理事会自我延续制 | 决定权力来源：成员授权 vs 理事自选 |
| **层级** | 国际 · 国家 · 地区 · 基层 | 决定管辖与代表性 |

**关键区分：会员制 vs 非会员制**

| 维度 | 会员制（协会 · 学会 · 合作社） | 非会员制（基金会 · 服务机构） |
|:--|:--|:--|
| 权力来源 | 会员大会选举 | 理事会自我补选（self-perpetuating） |
| 谁的利益 | 会员的共同利益 | 章程指定的公益目的 |
| 治理风险 | 会员冷漠 · 派系 · 代表性不足 | 理事会封闭 · 使命漂移 · 创办人控制 |
| 退出机制 | 退会即失去权利 | 无「退出」，只有监督 |

> ⚠️ **无剩余索取权**：非营利组织不能把盈余分配给控制者，这既是其公信力来源，也是其**治理难题**——没有股东盯着，靠什么约束理事会？
> 📌 **同一目的可有多种法律形态**：做公益可以是基金会、社会服务机构或慈善信托；形态选择影响登记、税收与治理成本，而非「善意程度」。

## 四、结构

| 结构维度 | 光谱 | 后果 |
|:--|:--|:--|
| 分工 | 粗 → 细 | 专业化提升，协调成本上升 |
| 层级 | 扁平 → 多层 | 控制力提升，信息失真上升 |
| 部门化 | 职能 → 产品 → 地域 → 客户 | 决定「谁的KPI优先」 |
| 正式化 | 低 → 高 | 可预期性提升，适应性下降 |
| 集权 | 分权 → 集权 | 决策速度与责任归属的取舍 |

**常见结构类型**

| 类型 | 特征 | 适用与代价 |
|:--|:--|:--|
| 简单结构 | 创办人直管，无中层 | 灵活；规模化即失效 |
| 科层（bureaucracy） | 层级 · 书面规则 · 非人格化 | 可预期、可追责；僵化与目标置换 |
| 专业科层 | 核心是专业人员自治（医院 · 大学） | 专业判断优先；管理层权威弱 |
| 事业部（M 型） | 按产品或地区分权，总部管资源 | 贴近市场；重复建设与内部竞争 |
| 矩阵 | 职能与项目双线汇报 | 资源复用；**双头指挥**冲突 |
| 项目制 / 网络型 | 以任务临时组队 | 响应快；沉淀与归属弱 |

> ⚠️ **结构不是越新越好**：「扁平化」「平台化」在稳定重复的业务上常退化为无明确责任；**科层的非人格化恰恰是公平与可追责的来源**（Weber 的原意）。
> 📌 **结构跟随问题，不跟随潮流**：选结构时先问「哪类决策需要快、哪类必须稳、谁必须被约束」，再谈形态。

## 五、治理

**治理 ≠ 管理**

| | 治理（governance） | 管理（management） |
|:--|:--|:--|
| 回答 | 谁有权决定 · 如何问责 · 边界在哪 | 怎么达成目标 · 资源怎么配 |
| 主体 | 会员大会 · 理事会 · 监事 | 秘书长 / 总经理与执行团队 |
| 文件 | 章程 · 议事规则 · 披露制度 | 预算 · 计划 · 绩效方案 |
| 失效表现 | 越权 · 内部人控制 · 无人问责 | 效率低 · 执行弱 |

**治理的四件基础设施**

| 件 | 作用 | 常见缺口 |
|:--|:--|:--|
| 章程 | 权力来源与程序的总规则 | 抄模板 · 与实际运作脱节 |
| 权力机关 | 会员大会或理事会 | 长期不开会，决议靠追认 |
| 监督 | 监事会 / 独立理事 / 审计 | 监督者由被监督者任命 |
| 披露 | 年报 · 财务 · 关联交易 | 只报总额，不报关联 |

**受托责任（fiduciary duty）两条底线**：**忠实**（不为私利，回避利益冲突）· **勤勉**（知情决策，不挂名）。

> ⚠️ **章程是宪法，不是仪式**：凡「实际怎么运作」与章程不符者，出事时以章程为准，且**违规决议可能无效**。把章程当注册材料而非治理工具，是最普遍的结构性缺陷。

## 六、生命周期与失灵

| 阶段 | 特征 | 典型病理 |
|:--|:--|:--|
| 创立 | 使命驱动 · 结构简单 | 创办人依赖 |
| 成长 | 分工细化 · 引入中层 | 使命稀释 |
| 制度化 | 规则完备 · 预算稳定 | **目标置换**（手段变目的） |
| 成熟 / 僵化 | 惯性大 · 变革阻力强 | 组织惯性 · 只对内部负责 |
| 转型 / 消亡 | 合并 · 拆分 · 关闭 | 拖延导致资产与信任同时耗散 |

**两个高频病**

| 病 | 机制 | 观察指标 |
|:--|:--|:--|
| **使命漂移**（mission drift） | 为生存追逐更易获资助的业务，逐步偏离初衷 | 收入结构与使命的相关度下降 |
| **目标置换**（goal displacement） | 以规则遵守替代目标达成 | 考核只查流程，不看效果 |

> 📌 **组织存续与使命达成是两件事**：存续是手段，使命是目的。当「活下去」成为唯一目标，组织就已完成了它的漂移。

## 七、中国语境

| 形态 | 说明 |
|:--|:--|
| 社会团体 | 会员制，按宗旨开展活动 |
| 基金会 | 以捐赠财产为基础，分公募与非公募 |
| 社会服务机构 | 提供服务的非营利机构（原称「民办非企业单位」，2016 年后改称） |
| 事业单位 | 国家举办的公共服务机构，非一般意义的非营利法人 |
| 群众团体 | 工会 · 共青团 · 妇联等，有特定政治地位 |
| 行业协会商会 | 与行政机关**脱钩**改革（2015 年起分批推进） |

**登记管理体制的变迁**：长期实行「**双重管理**」（登记管理机关 + 业务主管单位），门槛高、依附强；2013 年后对行业协会商会类、科技类、公益慈善类、城乡社区服务类**四类组织**推行直接登记，其余仍多需业务主管单位。

> ⚠️ **登记形态 ≠ 治理实质**：直接登记降低的是**准入门槛**，不改变理事会是否真正开会、章程是否真正约束。观察一个组织，先看它**开不开会、改不改章程、公开不公开账**。

## 八、核心问题

> 组织之所以存在，是因为它能以**命令替代交易**、把重复协作沉淀为结构（Coase 1937 的起点）；但它同时制造新的成本：协调、控制、信息失真、目标置换。**规模每扩大一步，省下的市场成本与新增的管理成本在赛跑**——组织理论真正的问题从来不是「怎么变大」，而是「**在什么问题上，命令比契约更便宜**」。
