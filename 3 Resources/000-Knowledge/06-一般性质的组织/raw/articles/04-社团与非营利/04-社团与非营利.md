# 04 社团与非营利

> **UDC 06 / DDC 060** — 本支线处理社团与非营利的**运营与合规**：怎么合法成立（**注册**）· 谁有权决定（**治理**）· 钱从哪来怎么花（**财务与筹款**）· 凭什么让人相信（**透明度与问责**）。
> 归属判据一句话：**问「这个非营利组织怎么登记、理事会怎么运作、钱怎么筹怎么报」，而不是「组织一般是什么」或「这本会刊好不好」。**

## 二、非营利是什么

| 条件 | 含义 | 易错处 |
|:--|:--|:--|
| **不分配剩余** | 盈余须再投入宗旨，不得分给控制者 | **非营利 ≠ 不赚钱**，而是赚了不能分 |
| 有宗旨与治理 | 章程载明目的 · 有决策机关 | 无宗旨的「朋友圈」不构成组织 |
| 有受益对象 | 公益（不特定多数）或互益（会员） | **互益不等于私益**，私益不具非营利资格 |

**四组常见混淆**

| 说法 | 实际 |
|:--|:--|
| 「非营利 = 慈善」 | 非营利范围更大；慈善是其中**公益**的一支，须另行认定 |
| 「非营利 = 免费」 | 可收费提供服务，只要不分配剩余 |
| 「非营利 = 不能有工资」 | 可支付合理薪酬，超标或自定高薪则触红线 |
| 「公益 = 谁都能受益」 | 公益须**不特定多数**且非会员专享；会员专享属**互益** |

> ⚠️ **互益 vs 公益**：商会、校友会、行业协会服务的是**会员**（互益）；基金会、社会服务机构多面向**不特定公众**（公益）。募捐资格、税收优惠、披露要求都按这条线分岔。

## 三、法律形态谱

| 形态 | 要点 | 常见用途 |
|:--|:--|:--|
| **社会团体** | 会员制 · 章程 · 会员大会 | 协会 · 学会 · 联谊会 |
| **基金会** | 以捐赠财产为基础；分**公募** / **非公募** | 资助型（grant-making）或运作型 |
| **社会服务机构** | 提供服务的非营利机构（原称「民办非企业单位」，2016 年后改称） | 社工机构 · 民办学校 · 养老院 |
| **慈善组织** | 一种**认定**，不是登记形态；可登记为社会团体 / 基金会 / 社会服务机构后申请 | 取得公开募捐与税收优惠的前提之一 |
| **慈善信托** | 以信托方式管理慈善财产，受托人可为信托公司或慈善组织 | 大额捐赠 · 家族慈善 |
| **社会企业** | 混合形态，以商业收入支撑社会目标 | 边界在于分红限制与目标锁定 |
| 境外参照 | nonprofit corporation · charity · foundation（资助型 / 运作型）· association · cooperative | 比较制度 |

> 📌 **登记形态 ≠ 慈善组织**：先选一个登记形态，再（如需）申请慈善组织认定；**认定是加分项，不是独立形态**。
> ⚠️ **公募权是稀缺资源**：只有具备公开募捐资格的慈善组织才能面向公众募捐；无资格者做公开募捐属违法。与有资格机构合作募捐时，**主体责任仍在有资格方**。

## 四、注册与合规

| 步 | 环节 | 要点 |
|:--|:--|:--|
| 1 | 名称核准 | 名称须体现业务范围与组织形式，不得与既有重复 |
| 2 | 业务主管单位（如适用） | 双重管理下须先取得同意；部分类别已可直接登记 |
| 3 | 登记 | 向民政部门提交章程草案 · 发起人 · 资金 · 场所 |
| 4 | 章程核准 | 宗旨 · 业务范围 · 治理结构 · 财产规则须齐备 |
| 5 | 开户与税务 | 银行账户 · 税务登记 · 收费项目与票据 |
| 6 | 年报 / 年检 | 每年报送工作报告与财务，公开可查 |
| 7 | 资格申请 | 公益性捐赠税前扣除资格 · 公开募捐资格 · 慈善组织认定 |
| 8 | 变更与注销 | 法定代表人 · 住所 · 业务范围变更须办手续；注销须清算并处理剩余财产 |

> ⚠️ **剩余财产不能私分**：注销时的剩余财产须按章程或主管机关决定，用于相同或相近宗旨——这是「不分配剩余」在终局时的体现。

## 五、治理

| 机关 | 构成 | 职责 | 常见缺陷 |
|:--|:--|:--|:--|
| 会员大会 / 理事会 | 社会团体为会员大会；基金会设理事会（一般 5–25 人） | 通过章程 · 选任负责人 · 审定预算与重大事项 | 长期不开会，决议事后追认 |
| 监事 / 监事会 | 监事不得由理事、财务人员及其近亲属兼任 | 财务与合规监督 | 监事由被监督者指定 |
| 负责人 | 理事长 / 秘书长 | 对外代表 · 日常执行 | 理事长与秘书长权责不清 |
| 法定代表人 | 通常由理事长或秘书长担任 | 承担法律责任 | 挂名 · 实际决策者不在其位 |

**三条治理红线**

| 红线 | 表现 |
|:--|:--|
| **关联交易** | 理事及其关联方与组织交易须披露、回避、公允定价 |
| **薪酬自定** | 负责人薪酬由自己主导的理事会决定，且显著偏离同类水平 |
| **章程虚置** | 实际运作与章程不符，换届、议事、表决无记录 |

> 📌 **治理是否真实，看三样材料**：**会议纪要 · 表决记录 · 财务报告**。三样都拿得出的组织，治理才不是纸上文章。

## 六、财务与筹款

**收入结构**

| 来源 | 特点 | 风险 |
|:--|:--|:--|
| 捐赠 | 不稳定，受议题热度与信任影响 | 单一资助方依赖 |
| 会费 | 稳定，但受会员规模限制 | 会员流失即断流 |
| 服务收费 | 可预期，接近市场化 | 过度商业化 → 使命漂移 |
| 政府购买服务 | 规模大、周期明确 | 政策变动 · 行政依附 |
| 投资收益 | 适合有本金的基金会 | 市场风险 · 支出与本金平衡 |

**支出比例（中国规则要点）**

| 规则 | 量级 | 注意 |
|:--|:--|:--|
| 公募基金会年度公益事业支出 | 不低于上年总收入的 **70%** | 遇特殊情况的减免须报备 |
| 非公募基金会年度公益事业支出 | 不低于上年末净资产的 **8%** | 以净资产为基数，非收入 |
| 管理费用上限 | 公募基金会一般不超过当年总支出的 **10%**；其他慈善组织另有分档 | 具体分档见民政部等部门规定 |

**筹款方式**

| 方式 | 前提 | 要点 |
|:--|:--|:--|
| 公开募捐 | 须有公开募捐资格 | 可线上 / 线下，须备案方案 |
| 定向募捐 | 面向特定对象 | **不得变相公开** |
| 网络募捐 | 通过民政部门指定的互联网募捐平台 | 平台名单动态调整 |
| 慈善信托 | 委托人与受托人 | 不是募捐，是财产管理安排 |
| 企业 / 月捐 / 遗产捐赠 | 协议与票据 | 税前扣除须有资格与票据 |

**税前扣除**：企业公益性捐赠在年度利润总额 **12%** 以内、个人在申报应纳税所得额 **30%** 以内可扣除（超额部分按现行规定结转），前提是**受赠机构具备税前扣除资格**且开具合规票据。

> ⚠️ **「零管理费」是迷思**（overhead myth）：审计、法务、筹款、专业人才都要花钱。把管理费压到极低，通常意味着**用志愿劳动替代专业能力**、或用隐形成本转移开支——最后受损的是项目效果与可持续性。

## 七、透明度与问责

| 手段 | 内容 | 谁在看 |
|:--|:--|:--|
| 年度工作报告 | 项目 · 财务 · 理事变动 | 登记机关 · 公众 |
| 信息公开平台 | 慈善中国等统一披露 | 捐赠人 · 媒体 |
| 审计 | 年度财务审计 · 专项审计 | 理事会 · 资助方 |
| 项目评估 | 产出 · 结果 · 影响（output / outcome / impact） | 资助方 · 受益方 |
| 效果指标 | 复捐率 · 单位成本 · 目标达成率 | 长期判断依据 |

> 📌 **看披露的顺序**：先看**钱从哪来**（集中度）→ 再看**钱怎么花**（项目 / 管理 / 筹款三分）→ 最后看**效果证据**。只看第三项容易被故事打动，只看第一项容易误判。

## 八、中国语境

| 议题 | 现状要点 |
|:--|:--|
| 双重管理 → 直接登记 | 2013 年后对行业协会商会类、科技类、公益慈善类、城乡社区服务类推行直接登记；其余多仍需业务主管单位 |
| 行业协会商会脱钩 | 2015 年起分批与行政机关脱钩，机构 · 职能 · 资产 · 人员分离 |
| 社区社会组织 | 对达不到登记条件的社区组织实行**备案**管理 |
| 公开募捐资格 | 稀缺，集中于大型基金会与慈善会系统 |
| 网络募捐 | 平台指定制，个案争议推动规则细化 |
| 慈善信托 | 备案制，规模增长但配套税收规则仍在完善 |
| 草根组织 | 资源与人才约束明显，常以项目制依附于基金会资助 |

> ⚠️ **官办与草根的差异不只在资源**：登记路径、募捐资格、政府购买渠道、人才吸引力层层叠加，形成结构性落差。讨论「公益生态」时须先分清这两类主体的约束条件。

## 九、病理与批判

| 病理 | 机制 | 观察 |
|:--|:--|:--|
| **使命漂移** | 为获资助转向易筹资议题 | 项目与宗旨的相关度 |
| **捐赠者主导**（donor dominance） | 资助方指定用途、指定执行方式 | 限定性捐赠占比 |
| 行政化 | 以文件与考核替代服务 | 一线人员与管理人员比例 |
| 关联交易 | 采购、场地、服务流向关联方 | 关联方披露 |
| 数据美化 | 只报受益人次，不报结果 | 指标口径与第三方核验 |
| 信任赤字 | 个案丑闻拉低整体捐赠意愿 | 行业捐赠总额波动 |

> 📌 **非营利的公信力是「借来的」**：它用「不分配剩余」向公众借信任，再靠披露与评估偿还。**当披露变成公关、评估变成自评，借来的信任就在透支。**

## 十、核心问题

> 非营利以「**不能分配剩余**」换取公信力，又以「**必须花钱**」维持能力——审计、法务、筹款、专业人才都是成本。于是公众用「管理费比例」当道德标尺，组织为迎合而压低能力投入，最终**用更少的专业性去解决更难的社会问题**。真正该被追问的不是「管理费多少」，而是「**这一元钱造成了多少改变，谁来核验**」。
