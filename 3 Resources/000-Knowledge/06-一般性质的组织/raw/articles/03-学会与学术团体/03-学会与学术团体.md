# 03 学会与学术团体

> **UDC 06 / DDC 060** — 本支线处理**以学科或专业为纽带**的组织：它怎么被组织起来（**类型与会员制**）· 靠什么运转（**会费 · 会刊 · 年会**）· 握有哪些权力（**标准 · 认证 · 奖励 · 院士**）· 又在哪些地方变味（**门阀化 · 会士通胀 · 会议产业化**）。
> 归属判据一句话：**问「这个学术组织是什么、怎么运转、凭什么有权威」，而不是「它办的刊好不好、这个学科怎么评价」。**

## 二、类型谱

| 类型 | 特征 | 例 |
|:--|:--|:--|
| **科学院 / 学部**（academy） | 常为国家建制，兼有研究实体与荣誉职能 | 法兰西学院（1635）· 英国皇家学会（1660）· 中国科学院（1949，学部 1955） |
| **学会**（learned society） | 以学科为界，学术交流与出版为核心 | 物理学会 · 化学会 · 中华医学会（1915） |
| **专业协会**（professional association） | 以职业为界，含执业标准与认证 | IEEE（1963）· ACM（1947） |
| **研究会 / 专业委员会** | 学会内分支或独立小型团体 | 某学会某专委会 |
| **学术联盟 / 联合体** | 机构会员制，代表集体发声 | 大学联盟 · 学科联合体 |
| **学生学术社团** | 培养性 · 非正式 | 高校学生学会 |
| 非学术但同名者 | 科普团体 · 行业商会 | 注意与专业协会区分 |

> ⚠️ **「学会」与「协会」在中文里常混称**：判据看**纽带**——以**学科 / 学术**为纽带者是学会，以**职业 / 行业**为纽带者是协会。二者可并存（同一群体既有学会也有协会），也可合一。
> 📌 **科学院 ≠ 学会**：科学院多为**国家建制**（有研究实体、有编制、有荣誉院士选聘程序）；学会多为**会员自治**（自缴会费、自选理事）。把两者都叫「学会」会掩盖权力来源的差别。

## 三、会员制

| 维度 | 常见做法 | 后果 |
|:--|:--|:--|
| 入会 | 申请 + 推荐 · 审核 | 开放度高，边界弱 |
| 会员层级 | 普通 / 学生 / 团体会员 / 会士（Fellow） | 层级制造荣誉，也制造不平等 |
| **会士 / 院士** | **选举**（同侪提名 + 评审） | 稀缺性带来权威，也带来门阀与「帽子」效应 |
| 会费 | 年费 · 团体会费 · 终身会员 | 会费=收入基础，但挤压青年与低收入地区成员 |
| 权利 | 参会 · 投稿 · 选举权 · 使用称号 | 权利的实质决定会员是否有黏性 |
| 义务 | 缴会费 · 遵守伦理守则 · 服务学会 | 义务虚化即「缴费换头衔」 |

> ⚠️ **会士制度的两种逻辑**：**荣誉逻辑**（稀缺、选举、终身）与**增长逻辑**（扩员、收费、营销）。同一称号若两种逻辑并用，其信号价值必然被稀释——**会士通胀**往往不是标准降低，而是组织把称号当成收入工具。

## 四、组织与治理

| 层级 | 机构 | 职能 |
|:--|:--|:--|
| 权力机关 | 会员大会 / 代表大会 | 通过章程 · 选举理事 · 决定重大事项 |
| 决策机关 | 理事会 / 常务理事会 | 年度计划 · 预算 · 设立分支机构 |
| 执行机关 | 秘书处（专职） | 日常运营 · 会务 · 出版事务 |
| 学术分支 | 专业委员会 / 分会 | 学科内交流与标准 |
| 地方分支 | 省级 / 市级学会 | 属地会员与活动 |
| 监督 | 监事会 | 财务与合规 |

**三条易断的线**

| 线 | 断裂表现 |
|:--|:--|
| 章程 → 运作 | 章程抄模板，换届靠惯例 |
| 选举 → 代表性 | 候选人由现理事会提名，实质自我延续 |
| 秘书处 → 学术共同体 | 专职化后以运营指标替代学术目标 |

> 📌 **学术自治的关键不在「有没有理事会」，而在「理事是不是被会员选出来的」**。自我提名的理事会 + 形式化的会员大会，是最常见的「有治理之名，无治理之实」。

## 五、核心职能

| 职能 | 内容 | 收入 / 权力来源 |
|:--|:--|:--|
| 学术交流 | 年会 · 专题会 · workshop · 暑期学校 | 注册费 · 赞助 |
| 出版 | 会刊（journal）· 会议录（proceedings）· 通讯（newsletter） | 订阅 / APC / 版税 |
| 标准与伦理 | 术语标准 · 技术规范 · 职业伦理守则 | 权威性（非直接收入） |
| 职业认证 | 执业资格 · 继续教育学分（CPD） | 认证费 · 培训费 |
| 政策倡导 | 立场声明 · 咨询意见 | 代表性 |
| 奖励与荣誉 | 奖章 · 会士 · 最佳论文奖 | 声望 |

**会议与出版的交界**

| 问题 | 处理分歧 |
|:--|:--|
| 会议论文算不算正式发表 | 有正式论文集（proceedings）且经评审者，多数视同发表；**这会与期刊投稿的「未发表」要求冲突** |
| 会议评审强度 | 从摘要录用到全文双盲不等，须看征稿说明 |
| 会议录的连续性 | 系列会议录可按连续出版物处理（见 [[01-类型与刊期\|01 类型与刊期]]） |
| 会议产业化 | 以收费为目的、无实质评审的会议，与掠夺性期刊同构 |

> ⚠️ **学会办刊 ≠ 学会控制刊**：学会常把刊**委托**给商业出版社运营（订阅、平台、APC 由其收取），学会保留名义所有权与编辑权。判断一本学会刊的实际归属，要看**版权页与合同关系**，而非封面上的学会徽标。

## 六、中国的学会体系

| 形态 | 说明 |
|:--|:--|
| 中国科协 | 1958 年由全国科联与全国科普合并而成，是所属全国学会的业务主管与联合体 |
| 全国学会 | 全国性学术团体，多在民政部登记、由科协业务主管 |
| 地方学会 | 省市级，与全国学会为**业务指导**关系而非隶属 |
| 分会 / 专委会 | 学会内设分支，受总会章程约束 |
| 院士制度 | 中国科学院学部（1955 起设学部委员）· 中国工程院（1994 成立）——**属国家荣誉与咨询建制，不是学会会员** |

**体制变迁**：长期为「登记管理机关 + 业务主管单位」的**双重管理**；2013 年后对部分类别推行**直接登记**，行业协会商会类与行政机关**脱钩**（2015 年起分批）。学会的行政化程度、经费来源与人事依附，是判断其实质自治度的三个观察点。

> ⚠️ **院士 ≠ 会士 ≠ 会员**：三者权力来源不同（国家选聘 / 学会选举 / 缴费申请）。混用会导致对权威来源的误判——**能推荐院士的机构，不代表它能代表学科共同体**。

## 七、病理与评价

| 病理 | 机制 | 观察指标 |
|:--|:--|:--|
| 门阀化 | 核心职位在少数机构 / 师承间循环 | 理事单位集中度 · 连任年限 |
| 会士通胀 | 称号扩员以增收 | 年增会士数 / 会员总数 |
| 会议产业化 | 会议收入成为主业务，评审虚化 | 录用率 · 评审周期 · 注册费结构 |
| 收入依赖偏移 | 出版收入占比过高，学会立场随出版社 | 收入结构表 |
| 会员老龄化 | 青年不续费，激励机制断层 | 年龄结构 · 学生会员留存率 |
| 形式化治理 | 章程与运作脱节 | 会议纪要 · 换届程序 |

> 📌 **评价一个学会，看四件事**：**谁在选理事 · 钱从哪来 · 会士怎么产生 · 会议论文怎么评审**。四项都能公开说明者，多半是真自治。

## 八、核心问题

> 学会的本意是**学术共同体的自治形式**：由同行自己组织交流、评判标准、维护伦理。但一旦学术评价、出版收入与职业认证都系于学会一身，它便同时是**裁判、庄家与收费方**——**自治的正当性来自「被同行约束」，而不是来自「握有资格」**。当一个学会的主要权力是发证与办会，它的学术功能就已经让位于经营功能。
