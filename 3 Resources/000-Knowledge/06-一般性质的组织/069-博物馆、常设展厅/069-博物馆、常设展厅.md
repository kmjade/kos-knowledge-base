# 069 博物馆、常设展厅

> **UDC `069`** —— 博物馆；本页把**博物馆**当作一种「以收藏为底、以陈列说话」的机构，把**常设展厅**当作它最稳定、也最难改的产出形式。
> 归属判据一句话：**博物馆是机构，常设展厅是它的固定叙事装置 —— 看一家馆，先看它常年不换的那部分在讲什么。**
> **所属**：[[06-一般性质的组织|06 一般性质的组织]]（容器直属子库）· 邻接：[[061-组织及其他合作类型|061 组织及其他合作类型]] · [[061.2-非政府组织与合作|061.2 非政府组织与合作]]（举办主体侧）。
> 落位：`06-一般性质的组织/069-博物馆、常设展厅/`（容器根 —— `069` 是 `06` 的**主表下位**，与 `061` 平级）。
> ⚠️ **编号性质**：`069` 是 `06` 之下的**主表下位**（三位数里的博物馆专类），不是复分、不是复合。中文名依用户提供；**UDCS 中 `069` 的确切英文名与范围注待核**（通行作 "Museums" 一类表述，须以原文为准）。

**三件本页明确不做的事**

## 三、两个对象：机构与陈列

「博物馆」和「常设展厅」经常被当成一件事，其实分属两层：**一个是法人 / 机构，一个是它固定的陈列装置**。二者可以分离。

| | 有固定常设陈列 | 无常设陈列（只办临展） |
|:--|:--|:--|
| **有馆（机构）** | 典型博物馆 | 当代艺术空间 · 部分专题馆 |
| **无馆（非博物馆机构）** | 企业展厅 · 规划馆 · 纪念馆 · 校史馆 · 博览会常设馆 | 巡回展 · 快闪展 |

> 📌 **四象限的用处**：判断「这是不是博物馆」，看的不是有没有展品，而是**有没有以收藏与研究为基础的长期公共陈列**。
> ⚠️ **「常设」不等于「永久」**：常设展通常以 5–10 年为更新周期，改一次动全身，这正是它的分析价值所在。
> ⚠️ **企业展厅与规划馆不在博物馆序列**：它们没有藏品体系与研究职能，属**宣传 / 展示设施**（本页只作对照，不并入博物馆类型）。

## 四、博物馆的四项基本功能与冲突

| 功能 | 内容 | 与其他功能的冲突 |
|:--|:--|:--|
| 收藏 | 征集 · 编目 · 保管 · 修复 | 与展示冲突：光照、温湿度、触摸都伤藏品 |
| 研究 | 断代 · 释读 · 出版 | 与教育冲突：研究的复杂性与通识表达有张力 |
| 展示 | 常设与临展 · 阐释 | 与收藏冲突：能展的只是藏品极小部分 |
| 教育 | 讲解 · 课程 · 公共项目 | 与研究冲突：时间与人力此消彼长 |

> 📌 **四项功能的资源是同一份**：任何一项被指标化考核，其余三项就会被挤压。常见失衡是**展示挤压收藏与研究**。
> ⚠️ **「展品只占藏品很小比例」是结构事实**，不是管理失败：多数馆的常设展品比例在个位数百分比，库房才是主体。

## 五、类型谱（十类）

| 类型 | 形态要点 | 判据 | 常见误读 |
|:--|:--|:--|:--|
| 综合博物馆 | 多门类 · 大馆 | 藏品跨多个学科 | 被当成「国家级」同义 |
| 历史博物馆 | 时段或事件叙事 | 以历史序列组织常设展 | 与纪念馆混同 |
| 艺术博物馆 / 美术馆 | 以审美与艺术史为轴 | 藏品以艺术品为主 | 忽略其研究职能 |
| 自然史博物馆 | 标本 · 分类 · 演化 | 标本体系与分类学 | 被当成科普场馆 |
| 科技馆 | 互动装置为主 | 以原理演示而非藏品为核心 | 与博物馆混同（**无藏品体系**） |
| 专题博物馆 | 单一行业 / 技艺 / 人物 | 主题集中、规模中小 | 被当作企业展厅 |
| 纪念馆 | 人物或事件 · 纪念性 | 纪念功能优先于收藏 | 与研究型历史馆混同 |
| 生态 / 遗址博物馆 | 原地保护 · 场域即展品 | 遗址本体是核心藏品 | 被当成景区配套 |
| 数字博物馆 | 无实体或虚实结合 | 以数字藏品与虚拟陈列为主 | 被当成官网 |
| 常设展厅（非博物馆） | 企业 · 规划 · 校史 · 主题馆 | 有固定陈列、无藏品研究 | 被统计进「博物馆数量」 |

> ⚠️ **十类是形态工具，不是等级表**：规模、藏品量、研究能力是三件不同的事。
> ⚠️ **科技馆与数字馆的归类争议最大**：若以「收藏—研究—陈列」三件为判据，二者常只有陈列。

## 六、常设展厅的结构

常设展是博物馆的**固定叙事装置**：它把某一套判断写成空间，让观众按既定顺序走完。

| 结构层 | 内容 | 分析要点 |
|:--|:--|:--|
| 叙事脚本 | 主题 · 分期 · 因果链 | 谁被放在开端、谁被放在结尾 |
| 空间序列 | 单向 / 环线 / 自由 | 单向动线＝强叙事，自由动线＝弱叙事 |
| 展品等级 | 原件 · 复制 · 复原 · 数字 | 原件比例决定「物质性」的强度 |
| 展签三层 | 名称 · 说明 · 阐释 | 只有名称＝陈列；有阐释＝解释 |
| 互动装置 | 演示 · 游戏 · 沉浸 | 装置常替代实物成为主角 |
| 更新机制 | 十年一改 / 长期不动 | 不更新的常设展＝凝固的判断 |

> ⚠️ **「展签写多少」是阐释权的直接体现**：只写年代与材质，是把解释让给观众；写满因果判断，是把结论交给机构。
> ⚠️ **沉浸式与数字化不是中性手段**：它们把注意力从物转向效果，常伴随原件比例下降。
> ⚠️ **常设与临展的配比是资源信号**：临展多、常设十年不动，说明机构把资源放在「可宣传」的部分。

## 七、藏品治理

| 环节 | 核心问题 | 判据 / 风险 |
|:--|:--|:--|
| 征集政策 | 收什么、不收什么 | 有无成文 policy；是否只收「好看好展」的 |
| 入藏 | 权属是否清晰 | 来源链（provenance）是否完整 |
| 编目 | 记录到什么颗粒度 | 有无统一著录标准与公开目录 |
| 保管与修复 | 条件与优先级 | 库房条件、修复记录 |
| 注销（deaccession） | 能否出售或转让藏品 | **多数职业道德准则严格限制**，收益通常须用于藏品本身 |
| 归还（repatriation） | 来源国 / 原属群体的追索 | 依法律与伦理双轨，程序复杂 |

**来源与非法流转**

- 1970 年 UNESCO 公约与 1995 年 UNIDROIT 公约构成跨境文物返还的主要国际框架（**具体适用须回法源核**）。
- 收购「无来源记录」的藏品，是机构声誉风险的最高发点。

> ⚠️ **注销不是财务工具**：把藏品当资产变现，在职业伦理上高度受限；判断归 [[34-法律|34 法律]] 与行业准则。
> ⚠️ **「来源不明」不等于「非法」**，但**举证责任在收藏方**：这是本领域最基本的伦理立场。

## 八、公共性、资金与治理

| 维度 | 形态 | 分析要点 |
|:--|:--|:--|
| 举办主体 | 国有 · 非国有 · 混合 | 决定人事、预算与考核口径 |
| 开放政策 | 免费 · 收费 · 分时 | 免费提升可及性，也改变收入结构 |
| 收入结构 | 财政拨款 · 门票 · 文创 · 赞助 · 基金 | 单一来源决定议程（接 [[061.27-基金、资助、机构\|061.27]]） |
| 赞助与命名 | 展厅冠名 · 特展赞助 | 需披露；商业内容与阐释的边界 |
| 治理 | 理事会 · 馆长负责制 · 上级主管 | 学术自治与行政考核的张力 |

> ⚠️ **文创不是研究**：文创收入可以养馆，但不能替代藏品研究与陈列更新。
> ⚠️ **免费开放不是中性政策**：它把成本转给财政，也把「客流」变成主要考核指标 —— 指标一变，陈列取向就变。

## 九、阐释与争议

| 议题 | 表现 | 分析要点 |
|:--|:--|:--|
| 谁的叙事 | 单一民族 / 单一立场叙述 | 看缺席者是谁 |
| 去殖民与去中心 | 藏品来源国的声音 | 展签是否标注获取情境 |
| 敏感内容 | 战争 · 族群 · 宗教 | 处理方式：回避 / 并列 / 争议呈现 |
| 复原与重建 | 场景复原、遗址重建 | 复原＝当代解释，不是原状 |
| 数字孪生 | 虚拟重建、线上展 | 可及性提升，物质性下降 |
| 争议展品 | 归属存疑、伦理敏感 | 是否有说明牌与替代叙事 |

> ⚠️ **「客观陈列」不存在**：选择哪些物、按什么顺序、写多少字，都是判断。
> ⚠️ **复原展项必须标注为复原**：把解释当原状，是最常见的失实。

## 十、评估与指标误用

| 常用指标 | 能说明 | 不能说明 |
|:--|:--|:--|
| 参观人次 | 触达规模 | 是否学到、是否被打动 |
| 停留时间 | 注意力投入 | 是否理解（可能只是迷路） |
| 展览数量 | 产出频率 | 质量与更新深度 |
| 藏品数量 | 积累规模 | 是否编目、是否可研究 |
| 教育活动场次 | 公共投入 | 覆盖人群与效果 |
| 满意度 | 当下感受 | 长期影响 |

> ⚠️ **人次是最容易被当作唯一指标的**：一旦成为考核核心，机构会倾向于做「好拍照」的展。
> ⚠️ **观众研究的方法须说明**：抽样方式、问卷设计、是否区分首次与重复观众 —— 否则数字不可比。

## 十一、中国语境（十项）

| 项 | 读法 |
|:--|:--|
| 《博物馆条例》（2015 施行） | 博物馆的设立、备案、管理与扶持的基本规范；**修订情况须核** |
| 设立与备案 | 需符合条件并向省级文物行政部门备案；未备案者不属法定博物馆 |
| 国有 / 非国有 | 举办主体不同，扶持政策、藏品管理与考核口径不同 |
| 免费开放 | 国有博物馆逐步实行免费开放（2008 年起推行）；具体范围与补助口径须核 |
| 藏品管理 | 登记、建档、定级（一级 / 二级 / 三级 / 一般文物）与出入库制度 |
| 纪念馆与党史馆 | 纪念性陈列与研究型历史陈列须分别判断 |
| 规划馆 / 企业展厅 | **不在博物馆序列**，无藏品与研究职能，不宜计入博物馆统计 |
| 文物法律框架 | 《文物保护法》及配套法规；具体条文与程序回法源核对 |
| 非国有博物馆扶持 | 用地、税收、对口帮扶等政策因地区而异，须核现行文件 |
| 运行评估 | 年报、绩效评估与质量等级评定；指标口径会影响陈列取向 |

> ⚠️ **「博物馆」在中国是有法定门槛的名称**：不是有展厅就能自称；备案状态是可核的第一项。
> ⚠️ **本页不评价具体馆的等级与合规**：属行政认定，须查官方名录。

## 十三、判读六步

1. **查法定身份与备案状态** —— 是否依法设立 / 备案；未备案者按「展馆」而非博物馆对待。
2. **查藏品体系** —— 有无成文征集政策、编目标准与可查目录。
3. **查常设展的年龄与结构** —— 上次改陈年份、展签层级、原件比例。
4. **查研究与出版** —— 有无持续的研究产出，而非只有图录。
5. **查资金来源与治理** —— 财政 / 门票 / 文创 / 赞助的占比；理事会与馆长权责。
6. **查阐释立场** —— 谁在叙事中心，谁缺席，争议如何呈现。

**三条纪律**

- **看库房与目录，不看门厅与海报。**
- **看常设展，不看特展**：特展是表态，常设展是立场。
- **看十年变化，不看单年数据。**

---

## 十四、病理（八项）

| 病理 | 机制 |
|:--|:--|
| 仓库化 | 收藏只进不出、不编目、不研究，库房成为终点 |
| 展陈外包化 | 叙事整体交给外部公司，机构失去解释权 |
| 叙事单一化 | 只有一种讲法，缺席者不被提及 |
| 文创替代研究 | 收入指标压过学术产出 |
| 数字替代实物 | 沉浸装置取代原件，物质性流失 |
| 流量指标化 | 以人次为唯一考核，趋向「好拍照」 |
| 藏品流失 | 来源不清、注销随意、保管失序 |
| 名义博物馆 | 有牌照无藏品、有展厅无研究 |

> **共同结构**：都是**「收藏—研究—陈列」这条链断了其中一环** —— 断了收藏，馆变成展厅；断了研究，陈列变成布景；断了陈列，馆变成仓库。

---

## 十五、核心问题

> 博物馆是一个**用物说话的机构**：它替不在场的人保管物，替看不懂的人解释物，替未来的研究者保存证据。
>
> 这三件事彼此拉扯：保管要求不动，解释要求常改，保存要求不卖。任何一项被单独指标化，另外两项就会被牺牲 —— 于是「仓库化」「布景化」「变现化」成为三种典型退化。
>
> **判断一家博物馆，不要先看它的建筑与流量，而要先问三件事：藏品有没有目录、常设展上次改陈是哪一年、展签里有没有一句可以被反驳的话。**
