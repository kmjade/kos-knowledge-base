# UDC 国际十进制分类法 — In-Depth

> UDC（Universal Decimal Classification）是 Paul Otlet 与 Henri La Fontaine 于 1905 年基于 DDC 创建的文献分类系统。其核心创新是**辅助符号体系**——通过 `+ / : = ( ) " "` 等符号组合主题，表达力远超 DDC。

---

## 核心定位

| 维度 | 说明 |
|------|------|
| **创建者** | Paul Otlet & Henri La Fontaine（比利时） |
| **首版** | 1905（基于 DDC 第 5 版） |
| **维护方** | UDC Consortium（荷兰海牙） |
| **类型** | 分面 + 层级分类法 |
| **适用范围** | 专业 / 研究图书馆、文献数据库 |
| **使用国家** | 30+ 国（欧洲、拉美、非洲为主） |

---

## UDC vs DDC 核心差异

| 维度 | DDC | UDC |
|------|-----|-----|
| 分类策略 | **枚举**——每个主题一个数字 | **分面**——通过符号组合多个维度 |
| 连接符 | 无（纯层级） | 有——`+ / : = (…) "…"` |
| 灵活性 | 低 | **高**——可表达复杂关系 |
| 学习曲线 | 低——直观 | 高——需学习符号系统 |
| 适用场景 | 公共 / 学校图书馆 | 专业 / 研究图书馆 |
| 核心思维 | 一本书 → 一个号码 | 一本书 → 一个表达式 |

---

## 辅助符号体系（UDC 的精髓）

UDC 最伟大的创新：用符号让类号可以**组合**。

| 符号 | 功能 | 范例 |
|------|------|------|
| **+** | 并列（两主题并存） | `622+669` = 采矿与冶金 |
| **/** | 范围（连续类号） | `621.3/.4` = 电气工程到热机 |
| **:** | 关系（主题交叉） | `37:004` = 教育与计算机 |
| **=** | 语言 | `61=111` = 医学（英文） |
| **(0…)** | 形式 | `(035)` = 手册、`(043)` = 论文 |
| **(…)** | 地点 | `(510)` = 中国、`(73)` = 美国 |
| **"…"** | 时间 | `"20"` = 21 世纪 |
| **(=…)** | 种族 / 民族 | `(=581)` = 中国人 |

### 实例对比

| 文献主题 | DDC 23 | UDC |
|----------|:------:|:---:|
| 中国医学史（英文） | 610.951 | `61(510)(091)=111` |
| 人工智能教育 | 006.3071 | `004.8:37` |
| 德国哲学词典 | 103.43 | `1(038)=112.2` |
| 日本采矿与冶金 | 669.0952 | `622+669(520)` |
| 21 世纪中国高等教育 | 378.510905 | `378(510)"20"` |

## 十大类概览

| 类 | 内容 | 备注 |
|:--:|------|------|
| **0** | 总论、计算机、信息 | 含 004 计算机科学 |
| **1** | 哲学、心理学 | — |
| **2** | 宗教、神学 | — |
| **3** | 社会科学、统计、政治、经济 | — |
| **4** | ⚠️ **空**——原语言类已并入 8 | **UDC 独有特征** |
| **5** | 数学、自然科学 | — |
| **6** | 应用科学、医学、科技 | 本 vault 重点对应领域 |
| **7** | 艺术、娱乐、体育 | — |
| **8** | 语言、语言学、文学 | 1980 年代吸收原第 4 类 |
| **9** | 地理、传记、历史 | — |

> 注意：UDC 没有第 4 类——这是 UDC 不同于 DDC 的明显特征。

## 设计哲学

| DDC | UDC |
|-----|-----|
| 简单——任何图书馆员都能用 | **精确**——能描述文献的所有维度 |
| 为 **排架** 设计 | 为 **文献检索** 设计 |
| 公共图书馆首选 | 专业图书馆首选 |
