# UDC In-Depth 详解

> 源：04-UDC-in-Depth.md — 编译整理。

## 核心内容

### 核心定位

| 维度 | 说明 |
|------|------|
| 創建者 | Paul Otlet & Henri La Fontaine（比利時） |
| 首版 | 1905（基于 DDC 第 5 版） |
| 维护方 | UDC Consortium（荷蘭海牙） |
| 类型 | 分面 + 层级分类法 |
| 適用範圍 | 专业 / 研究图书馆、文獻数据庫 |
| 使用国家 | 30+ 国（歐洲、拉美、非洲为主） |

### UDC vs DDC 核心差異

| 维度 | DDC | UDC |
|------|-----|-----|
| 分类策略 | 枚举——每个主题一个数字 | 分面——通过符号组合多个维度 |
| 连接符 | 无（纯层级） | 有——+ / : = (…) "…" |
| 灵活性 | 低 | 高——可表达复杂关系 |
| 学习曲线 | 低——直观 | 高——需学习符号系统 |
| 適用場景 | 公共 / 学校图书馆 | 专业 / 研究图书馆 |
| 核心思维 | 一本书 → 一个号码 | 一本书 → 一个表达式 |

### 辅助符号体系（UDC 的精髓）

UDC 最偉大的創新：用符号让类号可以组合。
| 符号 | 功能 | 範例 |
|------|------|------|
| + | 並列（兩主题並存） | 622+669 = 採礦与冶金 |
| / | 範圍（连续类号） | 621.3/.4 = 电气工程到热机 |
| : | 关系（主题交叉） | 37:004 = 教育与计算机 |
| = | 语言 | 61=111 = 医学（英文） |
| (0…) | 形式 | (035) = 手冊、(043) = 论文 |
