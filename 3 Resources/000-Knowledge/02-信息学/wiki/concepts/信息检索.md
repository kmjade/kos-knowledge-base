# 信息检索

## 定义

**信息检索（Information Retrieval, IR）** 是从大规模信息集合中，按用户需求找出相关信息的理论与技术。DDC 类号 **025.04**。它是 [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/信息科学导论|信息科学]] 的核心分支，也是搜索引擎与 RAG 的理论源头。

## 检索模型

| 模型 | 思想 | 代表 |
|------|------|------|
| 布尔模型 | 集合运算（AND / OR / NOT），精确匹配 | 早期书目检索 |
| 向量空间模型 | 文档与查询表示为词向量，按余弦相似度排序 | TF-IDF · LSI |
| 概率模型 | 估计文档与查询相关的概率 | BM25 |
| 语言 / 神经模型 | 用统计或神经网络建模相关性 | 神经排序 · Dense Retrieval |

## 检索语言

- **受控语言**：分类法（[[3 Resources/000-Knowledge/02-信息学/raw/articles/025-分类法与元数据/025-Classification-Metadata|025 分类法与元数据]]）· 叙词表（[[3 Resources/000-Knowledge/02-信息学/raw/articles/025-知识组织/025-Knowledge-Organization|025 知识组织]]）——规范化、高查准
- **自然语言**：关键词 / 全文——灵活、易用、高查全
- 趋势：**混合**——受控词表做语义约束，自然语言做入口

## 检索评价

| 指标 | 含义 |
|------|------|
| 查全率（Recall） | 检出的相关文档 / 全部相关文档 |
| 查准率（Precision） | 检出的相关文档 / 全部检出文档 |
| F1 | 查全与查准的调和平均 |
| nDCG | 考虑排序位置的折损累计增益 |

## 检索系统

- 索引结构：**倒排索引**（词 → 文档列表）
- 检索流程：查询解析 → 索引匹配 → 相关性排序 → 结果呈现
- 现代演进：向量检索 · 语义检索 · [[004.8-人工智能|004.8 人工智能]] 的 RAG（检索增强生成）
