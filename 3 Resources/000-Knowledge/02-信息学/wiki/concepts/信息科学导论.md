# 信息科学导论

## 定义

**信息科学（Information Science）** 研究信息的**产生、组织、存储、检索、传播与利用**的一般规律。它脱胎于图书馆学与文献学，20 世纪中叶随信息论、控制论、计算机科学兴起而独立，是 [[3 Resources/000-Knowledge/02-信息学/02-信息学|02 信息学]] 的立论基础。

> 学科谱系：图书馆学（机构 / 文献）→ 情报学（信息检索）→ 信息科学（信息的一般规律）。

## 核心概念

| 概念 | 含义 |
|------|------|
| 信息（Information） | 减少不确定性的差异；有别于数据（原始符号）与知识（被理解、内化的信息） |
| 数据—信息—知识（DIKW） | 从事实 → 意义 → 判断的递进，详见 [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/知识管理\|知识管理]] |
| 信息生命周期 | 产生 → 采集 → 组织 → 存储 → 检索 → 传播 → 利用 → 归档 |
| 信息熵 | Shannon 信息论：不确定性之度量，信息即熵的减少 |
