# 信息生命周期

## 定义

**信息生命周期（Information Lifecycle）** 描述信息从产生到消亡的全过程。它与 [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/知识管理|DIKW]] 的「价值递进」互补：DIKW 讲**层次**，生命周期讲**流转**。

## 阶段模型

```
产生 → 采集 → 组织 → 存储 → 检索 → 传播 → 利用 → 归档/销毁
```

| 阶段 | 关键问题 | 本库对应 |
|------|---------|---------|
| 产生 | 谁、为何产生 | — |
| 采集 | 如何捕获 | PKM 捕获（→ 001） |
| 组织 | 如何整序 | [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/信息组织|信息组织]] |
| 存储 | 存于何处 | 载体 / 格式 |
| 检索 | 如何找回 | [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/信息检索|信息检索]] |
| 传播 | 如何送达 | 出版 / 网络 |
| 利用 | 如何增值 | [[3 Resources/000-Knowledge/02-信息学/wiki/concepts/知识管理|知识管理]] |
| 归档 | 保留还是销毁 | 档案 / 记录管理 |

## 记录连续体

- 档案学以**记录连续体（Records Continuum）** 替代线性生命周期：产生、捕获、组织、多元利用**同时**发生，而非先后。
- 数字时代的信息常被反复重组、跨库引用，线性模型逐渐让位于网络模型。
