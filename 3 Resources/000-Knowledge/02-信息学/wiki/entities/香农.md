# 克劳德·香农（Claude E. Shannon）

## 定位

美国数学工程师，**信息论之父**（1948 年《通信的数学理论》）。

## 贡献

- 提出**信息熵**：把信息量化为不确定性的减少，单位 **比特（bit）**——信息科学的「信息」由此可度量
- 建立**信源编码 / 信道编码 / 信道容量**定理，奠定数字通信与压缩的理论基础
- 区分了**技术层面的信息**（可度量）与语义、效用层面的信息（后者的处理留给信息科学其他支线）
