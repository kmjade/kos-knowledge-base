# source-Geography-Documents

## 概述

本库的**原始材料层**：地图图集、游记与航海日志、地方志、地理学著作，构成证据强度的判定依据。

## 材料类型

| 类型 | 代表 |
|------|------|
| 古典地理 | 托勒密《地理学指南》|
| 游记与航海 | 《马可·波罗行纪》· 库克航海日志 |
| 地图图集 | 墨卡托地图集 |
| 中国地理 | 《徐霞客游记》· 地方志 |
| 近代著作 | 洪堡《宇宙》· 李特尔《地学通论》|

## 证据强度

- **级别 A–B**：地图 · 实地考察记录为**一手**；纪行类含叙述成分须辨析。
- **级别 C–D**：晚出转述与近人研究，须回溯原始材料。
