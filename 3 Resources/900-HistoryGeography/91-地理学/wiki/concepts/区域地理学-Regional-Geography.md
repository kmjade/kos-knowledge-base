# 区域地理学 Regional-Geography

## 定义

**区域地理学**（UDC `913`）以**特定区域**为对象，综合其自然与人文地理；地方主题用**表 1e（地理复分表）**表示。

## 要点

| 尺度 | 合并示例 |
|------|----------|
| 世界 | `913(100)` |
| 物理区域 | `913(2)` |
| 古代世界 | `913(3)` |
| 现代国家 | `913(4/9)` |

## 要义

- 地理学的**区域传统**，重**独特性与综合**。
- 复分号记于**行内代码**，不作标题。
- 与 [[空间划分-Spatial-Division|空间划分]]、[[比较地理学-Comparative-Geography|比较地理学]] 相对（区域 vs 系统）。
