# 地图学 Cartography

## 定义

**地图学**指关于**地图的编制、表示与阅读**的学问；在 UDC 中，地理的**非文本表示**归 `912`（制图技术 `528` 归 `500`）。

## 要点

| 面向 | 内容 |
|------|------|
| 对象 | 地图 · 图表 · 剖面 · 地球仪 |
| 内容 | 投影 · 符号 · 比例 |
| 身份 | 既是**工具**又是**史料** |

## 要义

- 地图是地理学**最独有的语言**与史料。
- 投影即**取舍**，皆含立场（约定 ≠ 事实）。
- 与 [[地理探险-Geographical-Exploration|地理探险]] 互促：探索生成地图，地图引导探索。
