# 比较地理学 Comparative-Geography

## 定义

**比较地理学**（UDC `911.7`）以**比较**方法研究区域异同（UDC 包括原文：比较区域研究）。

## 要点

| 面向 | 内容 |
|------|------|
| 方法 | 区域比较 |
| 目标 | 揭示异同与规律 |
| 关联 | 区域地理 · 类型地理 |

## 要义

- 比较以**尺度**与**标准**为前提，须明示方能立论。
- 与 [[区域地理学-Regional-Geography|区域地理学]]、[[类型地理学-Typological-Geography|类型地理学]] 互通。
- 承接 [[地理学方法论-Geographical-Methodology|地理学方法论]] 的分析传统。
