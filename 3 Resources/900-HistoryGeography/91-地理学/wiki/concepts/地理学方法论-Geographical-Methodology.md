# 地理学方法论 Geographical-Methodology

## 定义

**地理学方法论**（UDC `910.1`）指地理学的**理论、系统与方法**总体。

## 要点

| 面向 | 内容 |
|------|------|
| 传统 | 描述 · 制图 · 地方志 |
| 分析 | 计量 · 空间分析 · 模型 |
| 人文 | 感知 · 文化 · 批判 |
| 综合 | 区域 · 系统 |

## 要义

- 方法随**思潮**演进（环境决定论 → 可能论 → 区域学派 → 计量革命 → 人文转向）。
- **多元并存**而非线性替代，是地理学方法论的特色。
- 与 [[空间划分-Spatial-Division|空间划分]]、[[比较地理学-Comparative-Geography|比较地理学]] 同属理论地理学面。
