# 自然地理 Physical-Geography

## 定义

**自然地理**（UDC `911.2`）研究**自然环境**（气候 · 地貌 · 水文 · 土壤 · 生物）的空间分布与相互作用。

## 要点

| 分科 | 内容 |
|------|------|
| 气候 | 气候带 · 类型 |
| 地貌 | 地形 · 成因 |
| 水文 | 河湖 · 洋流 |
| 土壤植被 | 地带性 · 分布 |

## 要义

- 核心规律为**地带性**与**地域分异**。
- 水文地理学以**冒号组合** `911.2:556` 表示（UDC 合并示例）。
- 与 `500` 地学**分界**（R3 = A）：地质学侧归 `500`，本库只收空间-区域视角。
