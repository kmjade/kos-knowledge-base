# 文化景观 Cultural-Landscape

## 定义

**文化景观**指人类活动在**地表留下的印记**——经人类改造的自然景观，是文化地理学的核心概念（关联 UDC `911.5` 类型地理学之「自然和文化景观」）。

## 要点

| 面向 | 内容 |
|------|------|
| 内涵 | 人化自然 · 文化印记 |
| 要素 | 聚落 · 农田 · 道路 · 建筑 |
| 尺度 | 局部 → 区域 |
| 关联 | 与自然景观相对 |

## 要义

- 是**人地关系**在景观层面的具现。
- 属 [[类型地理学-Typological-Geography|类型地理学]] 的划分对象之一。
- 定义含**主观性**（形态 vs 感知），须明示（约定 ≠ 事实）。
