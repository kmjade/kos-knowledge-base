# 旅游地理 Tourism-Geography

## 定义

**旅游地理**研究**旅游活动的空间现象**：目的地、客源、线路与其地理条件（UDC 侧属 `910` 一般问题之「旅游」）。

## 要点

| 面向 | 内容 |
|------|------|
| 对象 | 目的地 · 客源 · 线路 |
| 视角 | 空间 · 资源 · 影响 |
| 关联 | 区域地理 · 人文地理 |

## 要义

- 旅游是**人地关系**的当代活跃形态。
- 与 [[地理探险-Geographical-Exploration|地理探险]] 有历史连续性（旅行 → 探险 → 旅游）。
- 资源的**评价**含主观性，须明示（约定 ≠ 事实）。
