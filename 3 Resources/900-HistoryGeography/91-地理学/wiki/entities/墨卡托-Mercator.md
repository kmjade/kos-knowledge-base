# 墨卡托 Mercator

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1512—1594 |
| 身份 | 佛兰德斯地图学家 |
| 关键 | 墨卡托投影 · 《地图集》|
| 遗产 | 近代制图学奠基 |

## 要义

- **墨卡托投影**（1569）保持航向为直线，极利航海，沿用至今。
- 首用「**Atlas**」称地图集，奠定近代地图集传统。
- 投影的**面积变形**是其后世批评焦点（任何投影皆有取舍）。
- 是 [[地图学-Cartography|地图学]] 承前启后的关键人物。
