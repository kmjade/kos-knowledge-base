# 徐霞客 Xu-Xiake

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1587—1641 |
| 身份 | 明代地理学家 · 旅行家 |
| 关键 | 《徐霞客游记》· 喀斯特地貌考察 |
| 遗产 | 中国地理考察传统之典范 |

## 要义

- 三十年实地考察，足迹遍及大半个中国。
- 《**徐霞客游记**》对**喀斯特地貌**（石灰岩溶洞）的记述精确，具科学价值。
- 以**实地考察**精神，为中国地理学传统树一典范。
- 是 [[地理探险-Geographical-Exploration|地理探险]] 与 [[自然地理-Physical-Geography|自然地理]] 的重要人物。
