# 库克 Captain-Cook

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1728—1779 |
| 身份 | 英国航海家 · 探险家 |
| 关键 | 三次太平洋远航 · 测绘 |
| 结局 | 1779 于夏威夷遇难 |

## 要义

- 三次远航太平洋，精确**测绘**大洋洲与太平洋海岸。
- 以科学考察（经度测定 · 动植物记录）结合航海，提升探险的科学性。
- 其航行深远影响**太平洋**的接触史与殖民史。
- 评价须并列：科学探险 vs 殖民开端（**两说并列**）。
