# 托勒密 Ptolemy

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约 100—170 |
| 身份 | 古希腊-罗马地理学家 · 天文学家 |
| 关键 | 《地理学指南》· 经纬网 · 地心说 |
| 遗产 | 古典地理学与制图学之源 |

## 要义

- 《地理学指南》系统整理古典地理知识，奠定**经纬度定位**与**制图**传统。
- 其地心说主导欧洲千余年，至哥白尼方被取代。
- 著作经阿拉伯世界保存，**文艺复兴**时重被发现。
- 是 [[地图学-Cartography|地图学]] 与 [[区域地理学-Regional-Geography|区域地理学]] 的古典源头。
