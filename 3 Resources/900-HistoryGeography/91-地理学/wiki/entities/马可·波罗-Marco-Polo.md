# 马可·波罗 Marco-Polo

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约 1254—1324 |
| 身份 | 威尼斯旅行家 |
| 关键 | 东游元朝 · 《马可·波罗行纪》|
| 遗产 | 欧洲认识东方之窗 |

## 要义

- 经丝路东行，据称仕于元朝，归后成《**行纪**》。
- 其记述激发欧洲对东方的想象，间接催生**大航海**的东方之谋。
- 内容真实性长期争议（**疑信两说**，不代裁）。
- 是 [[地理探险-Geographical-Exploration|地理探险]] 与欧亚交流的关键人物。
