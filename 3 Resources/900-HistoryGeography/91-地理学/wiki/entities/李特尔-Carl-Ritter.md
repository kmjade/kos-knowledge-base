# 李特尔 Carl-Ritter

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1779—1859 |
| 身份 | 德国地理学家 |
| 关键 | 区域地理 · 首任地理学教授 |
| 遗产 | 近代地理学奠基人 |

## 要义

- 以**区域**为单位系统研究地理，强调区域综合。
- 曾任柏林大学首任**地理学教授**，确立地理学的学院地位。
- 与 [[洪堡-Alexander-von-Humboldt|洪堡]] 并称近代地理学奠基人。
- 推动 [[区域地理学-Regional-Geography|区域地理学]] 传统。
