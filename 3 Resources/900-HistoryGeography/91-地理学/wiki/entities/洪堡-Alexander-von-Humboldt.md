# 洪堡 Alexander-von-Humboldt

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1769—1859 |
| 身份 | 德国自然地理学家 · 博物学家 |
| 关键 | 《宇宙》· 南美考察 |
| 遗产 | 近代地理学奠基人 |

## 要义

- 以**实地考察**与**综合**方法研究自然，倡导自然与人文的统一。
- 《宇宙》力图总括自然知识，影响深远。
- 与 [[李特尔-Carl-Ritter|李特尔]] 并称**近代地理学**两大奠基人。
- 推动 [[自然地理-Physical-Geography|自然地理]] 的科学化。
