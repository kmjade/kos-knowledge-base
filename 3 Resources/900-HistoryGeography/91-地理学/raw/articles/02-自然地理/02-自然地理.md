# 02 自然地理

> 主题章（UDC `911.2` 自然地理）：地球自然环境的构成与空间分异。

## 定义

**自然地理**（UDC `911.2`）研究**自然环境**（气候 · 地貌 · 水文 · 土壤 · 生物）的空间分布与相互作用。

> ⚠️ 与 `500` 自然科学**分界**（本库 R3 裁定 = A）：地球科学的**地质学**侧归 `500`；本库只收地理学的**空间与区域**视角。

## 要点

| 分科 | 内容 |
|------|------|
| 气候 | 气候带 · 气候类型 |
| 地貌 | 地形 · 成因 |
| 水文 | 河湖 · 洋流（合并示例 `911.2:556`）|
| 土壤植被 | 地带性 · 分布 |
| 综合 | 自然带 · 地域分异 |

## 要义

- **[[自然地理-Physical-Geography|自然地理]]**：以**地带性**与**地域分异**为核心规律。
- 水文地理学以**冒号组合** `911.2:556` 表示（UDC 合并示例，原文照录）。
- 与人文地理共同构成**人地关系**研究的自然侧。

## 争议 ⚠️

- 自然与人文的**边界**（如环境决定论）争议延续。
- 地球科学（`55`）与自然地理（`911.2`）的**归属**为分类学争论，本库按 R3 = A 分置。
