# 01 地理学思想与方法论

> 主题章（UDC `910.1` 地理学、方法论）：地理学思想史与主要方法流派。

## 定义

**地理学方法论**指地理学**理论、系统、方法**的总体（UDC `910.1`）。它回答「地理学怎么研究」这一根本问题。

## 要点

| 流派 | 要旨 |
|------|------|
| 古典 | 描述 · 制图 · 地方志 |
| 环境决定论 | 环境决定人文 |
| 可能论 | 人地互动 · 选择 |
| 区域学派 | 区域差异 · 独特性 |
| 计量革命 | 空间分析 · 模型 · 统计 |
| 批判与人文 | 社会 · 文化 · 感知转向 |

## 要义

- **[[地理学方法论-Geographical-Methodology|地理学方法论]]**：从描述到解释、从区域到系统，方法随思潮演进。
- 与 [[比较地理学-Comparative-Geography|比较地理学]]、[[空间划分-Spatial-Division|空间划分]] 同属理论地理学面。
- 方法论的**多元并存**是地理学特色，非「进化替代」。

## 争议 ⚠️

- 环境**决定论 vs 可能论**：长期对立，两说并存，不代裁。
- **计量革命**是否使地理学更「科学」，评价不一。
