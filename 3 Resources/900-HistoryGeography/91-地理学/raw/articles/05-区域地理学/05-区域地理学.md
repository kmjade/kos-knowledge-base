# 05 区域地理学

> 主题章（UDC `913` 区域地理学）：以**区域**为单位的综合地理研究，用**表 1e（地理复分表）**定位。

## 定义

**区域地理学**（UDC `913`）以**特定区域**为对象，综合其自然与人文地理（UDC 应用注释：区域地理使用**表 1e** 表示）。

## 要点

| 尺度 | 合并示例 |
|------|----------|
| 世界 | `913(100)` 世界区域地理 |
| 物理区域 | `913(2)` 物理区域、陆地地理 |
| 古代世界 | `913(3)` 古代世界地理 |
| 现代国家 | `913(4/9)` 现代国家与地区描述 |
| 洲际 | `913(4)` 欧洲 · `913(41)` 不列颠群岛 · `913(9)` 大洋洲极地 |

## 要义

- **[[区域地理学-Regional-Geography|区域地理学]]**：地理学的**区域传统**，强调区域的**独特性与综合**。
- 地方主题以**表 1e** 复分，号记于**行内代码**（如 `913(41)`），不作标题。
- 与 [[空间划分-Spatial-Division|空间划分]]、[[比较地理学-Comparative-Geography|比较地理学]] 相对：区域 vs 系统取向。

## 争议 ⚠️

- **区域 vs 系统**：区域描述抑或空间规律？计量革命后区域传统一度式微，晚近复兴，两说并存。
