# 05 安史之乱与藩镇

> 755 年安禄山、史思明起兵，八年战乱使唐朝由盛转衰；乱后藩镇割据成为中晚唐顽疾。

## 定义

**安史之乱**（755—763）是节度使安禄山、史思明发动的叛乱，是唐由盛转衰的**分水岭**。乱后地方节度使拥兵自重，形成**藩镇割据**。

## 要点

| 面向 | 内容 |
|------|------|
| 起因 | 节度使坐大 · 中央虚弱 · 财政失衡 |
| 进程 | 755 起兵 · 破两京 · 763 平 |
| 后果 | 人口锐减 · 财政崩溃 · 藩镇割据 |
| 制度转折 | 均田府兵 → 两税募兵 |

## 要义

- **成因多因**：边镇军权膨胀 + 中央武备空虚 + 玄宗晚年怠政，缺一不成（见 [[安史之乱-An-Lushan-Rebellion|安史之乱]]）。
- **藩镇割据**：河朔三镇等形同半独立，中央与藩镇长期博弈（见 [[藩镇-Fanzhen|藩镇]]）。
- **制度转折**：均田制崩坏，遂行[[两税法-Two-Tax-System|两税法]]，兵制由府兵转[[募兵制-Mubing|募兵]]。
- **文化余响**：杜甫「三吏三别」等，为乱世之诗史。

## 争议 ⚠️

- 安史之乱的**根本成因**：制度（节度使）抑或人事？**两说并列**。
- 藩镇**是否**全然负面（部分藩镇维持地方秩序），学界有修正。
