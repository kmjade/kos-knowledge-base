# 08 开放与交流：丝绸之路·遣唐使·宗教

> 主题章：丝路贸易、遣唐使与留学生、三教并立——唐代开放的世界格局。

## 定义

隋唐是**开放型帝国**：陆海丝路畅通，长安、洛阳、扬州为国际都会；日本[[遣唐使-Envoys-to-Tang|遣唐使]]、新罗、粟特、大食人等纷至沓来；儒、释、道三教并立，景教、祆教、摩尼教亦传入。

## 要点

| 面向 | 内容 |
|------|------|
| 陆路 | 丝绸之路 · 西域都护 |
| 海路 | 广州 · 扬州 · 明州 |
| 遣唐使 | 日本派遣，成批留学生 |
| 宗教 | 儒 · 佛 · 道 + 景 · 祆 · 摩尼 |
| 制度外播 | 汉文化圈形成 |

## 要义

- **丝绸之路**：贸易、宗教、技术、艺术多线流动，长安汇聚中外。
- **[[遣唐使-Envoys-to-Tang|遣唐使]]**：日本大规模学习唐制，律令、文字、佛教皆受影响，唐文化外播东亚。
- **[[佛教中国化-Buddhism-Sinicization|佛教中国化]]**：禅宗、天台、华严等宗派成立；玄奘西行求法。
- **[[羁縻府州-Jimi-System|羁縻府州]]**：以间接统治管理边疆，体现「华夷一家」的帝国秩序。

## 争议 ⚠️

- 「开放」的**程度与底色**（是否平等交往、抑或华夷秩序下的怀柔），学界多解。
- 佛教与政权、经济的张力，评价分歧。
