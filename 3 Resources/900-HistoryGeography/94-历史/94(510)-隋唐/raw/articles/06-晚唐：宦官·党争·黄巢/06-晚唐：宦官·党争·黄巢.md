# 06 晚唐：宦官·党争·黄巢

> 宦官专权、牛李党争、藩镇跋扈与黄巢之乱交困，唐朝终于 907 年为朱温所代。

## 定义

**晚唐**（约 805—907）指安史之乱后唐王朝的衰亡期：中央有宦官专权与「牛李党争」，地方有藩镇割据，民间有赋役重压下的民变，终至黄巢之乱与唐亡。

## 要点

| 痼疾 | 内容 |
|------|------|
| 宦官 | 掌禁军 · 废立皇帝 |
| 党争 | 牛僧孺 vs 李德裕之「牛李党争」 |
| 藩镇 | 河朔半独立 · 中央失控 |
| 民变 | 黄巢之乱 875—884 |
| 亡国 | 907 朱温代唐建梁 |

## 要义

- **宦官专权**：自肃代以降宦官掌神策军，可废立君主，为唐后期政治痼疾。
- **牛李党争**：科举与门第之争的延续，消耗朝政数十年。
- **黄巢之乱**：席卷南北，摧毁唐廷根基，藩镇与流民武装自此失控。
- **唐亡**：907 年朱温（黄巢旧部）篡唐，中国进入**五代十国**。

## 争议 ⚠️

- 唐亡**根本原因**：藩镇 · 宦官 · 党争 · 民变——诸说并列，本库不代裁。
