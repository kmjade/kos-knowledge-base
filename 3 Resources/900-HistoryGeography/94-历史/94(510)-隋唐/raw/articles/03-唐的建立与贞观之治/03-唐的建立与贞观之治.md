# 03 唐的建立与贞观之治

> 李渊父子开国，太宗李世民经玄武门之变登位，开创「贞观之治」——唐代盛世与制度典范的奠基期。

## 定义

**唐**（618—907）由李渊建立。626 年李世民发动**玄武门之变**夺位，是为唐太宗，在位期间政治清明、纳谏用贤，史称**贞观之治**（627—649）。

## 要点

| 面向 | 内容 |
|------|------|
| 开国 | 618 李渊称帝 |
| 玄武门 | 626 太宗夺位 |
| 贞观之治 | 纳谏 · 重农 · 轻刑 · 用人 |
| 名臣 | 魏徵 · 房玄龄 · 杜如晦 |
| 对外 | 破东突厥 · 天可汗 |

## 要义

- **贞观之治**：以「纳谏」「任贤」「轻徭薄赋」为标志，被后世奉为治世典范（见 [[贞观之治-Zhenguan|贞观之治]]）。
- **制度奠基**：完善[[三省六部-Three-Departments-Six-Ministries|三省六部]]与[[科举制-Keju|科举]]，定《贞观律》。
- **天可汗**：破东突厥、抚四夷，被尊为「天可汗」，奠定唐代开放的天下秩序。
- **史鉴之书**：史官修前代史、太宗与魏徵君臣问答，成「以史为鉴」的典范文本。

## 争议 ⚠️

- **玄武门之变**：迫不得已 vs 蓄谋夺位——两说并列。
- 贞观之治的**实际成色**（史书是否溢美）屡有讨论。
