# 玄奘 Xuanzang

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 602—664 |
| 身份 | 唐代高僧 · 佛典翻译家 · 旅行家 |
| 关键 | 西行求法（629—645） · 大慈恩寺译经 |
| 著作 | 《大唐西域记》 |

## 要义

- 西行印度十七年，归国译经七十五部，为汉传佛教义理奠基。
- 《大唐西域记》记中亚南亚地理风物，是**中外交流史**的关键文献。
- 是[[佛教中国化-Buddhism-Sinicization|佛教中国化]]的推动者与见证者。
