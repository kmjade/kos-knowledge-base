# 武则天 Wu Zetian

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 624—705 |
| 身份 | 唐高宗皇后 · 太后 · 武周皇帝 |
| 关键 | 690 称帝改周 · 中国唯一女皇 |
| 用人 | 破关陇门阀 · 广科举 · 拔寒门 |

## 要义

- 打击门阀、扩大[[科举制-Keju|科举]]取士，重塑唐代政治格局。
- 治下国力延续，为[[开元盛世-Kaiyuan|开元盛世]]积蓄条件。
- 705 年「神龙政变」后复唐，其身后评价两极。
