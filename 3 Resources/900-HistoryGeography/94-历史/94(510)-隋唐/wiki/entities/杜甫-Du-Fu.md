# 杜甫 Du Fu

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 712—770 |
| 身份 | 唐代诗人 · 「诗圣」 |
| 风格 | 沉郁顿挫 · 现实关怀 |
| 代表作 | 「三吏」「三别」《春望》《茅屋为秋风所破歌》 |

## 要义

- 以诗**纪实**，反映[[安史之乱-An-Lushan-Rebellion|安史之乱]]前后的社会疮痍，号称「诗史」。
- 其儒家情怀与忧患意识，为后世士人人格典范。
- 与[[李白-Li-Bai|李白]]并称「李杜」。
