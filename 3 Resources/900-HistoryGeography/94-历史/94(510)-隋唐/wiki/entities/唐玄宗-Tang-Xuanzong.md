# 唐玄宗 Tang Xuanzong

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 685—762 |
| 身份 | 唐皇帝（李隆基） |
| 前期 | 开元盛世 · 贤相姚崇宋璟 |
| 后期 | 天宝怠政 · [[安史之乱-An-Lushan-Rebellion\|安史之乱]] |

## 要义

- 前期励精图治，成就[[开元盛世-Kaiyuan|开元盛世]]，唐国力文化达顶峰。
- 后期任人不明、宠幸边将，酿成[[安史之乱-An-Lushan-Rebellion|安史之乱]]，奔蜀退位。
- 一身而系唐之**盛衰转折**，是典型的「半世明君」形象。

## 争议 ⚠️

- 由盛转衰的**转折点**（开元末 vs 天宝）学界多解。
