# 李白 Li Bai

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 701—762 |
| 身份 | 盛唐诗人 · 「诗仙」 |
| 风格 | 豪放飘逸 · 想象奇绝 |
| 代表作 | 《将进酒》《蜀道难》《静夜思》 |

## 要义

- 盛唐气象的**典型化身**，浪漫主义诗歌的巅峰。
- 漫游入仕、赐金放还，其生平与盛唐兴衰交织。
- 与[[杜甫-Du-Fu|杜甫]]并称「李杜」，为唐诗双峰。
