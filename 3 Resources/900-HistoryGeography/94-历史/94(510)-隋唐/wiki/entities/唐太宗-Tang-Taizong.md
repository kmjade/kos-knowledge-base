# 唐太宗 Tang Taizong

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 598—649 |
| 身份 | 唐第二代皇帝（李世民） |
| 关键 | 玄武门之变 · 贞观之治 · 天可汗 |
| 名臣 | 魏徵 · 房玄龄 · 杜如晦 |

## 要义

- 626 年经**玄武门之变**夺位，在位开创[[贞观之治-Zhenguan|贞观之治]]。
- 纳谏任贤、轻徭慎刑，完善[[三省六部-Three-Departments-Six-Ministries|三省六部]]与[[科举制-Keju|科举]]。
- 破东突厥，被尊「天可汗」，奠定唐代天下秩序。
