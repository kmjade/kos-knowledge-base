# 开元盛世 Kaiyuan

## 定义

**开元盛世**是唐玄宗李隆基前期（713—741，开元）出现的国力、经济、文化俱达顶峰之局。

## 要点

| 面向 | 内容 |
|------|------|
| 君主 | 唐玄宗（前期） |
| 贤相 | 姚崇 · 宋璟 · 张九龄 |
| 经济 | 户口增殖 · 国库充盈 |
| 文化 | 唐诗极盛 · 乐舞书画 |
| 都会 | 长安 · 洛阳 |

## 要义

- 政治相对清明、疆域辽阔，为唐代**国力顶点**。
- 文化上李白、杜甫、王维、吴道子等并世，佛道兴隆。
- 其后「天宝」年间由盛转衰，终致[[安史之乱-An-Lushan-Rebellion|安史之乱]]。
