# 安史之乱 An-Lushan-Rebellion

## 定义

**安史之乱**（755—763）是节度使安禄山、史思明发动的叛乱，是唐由盛转衰的**分水岭**。

## 要点

| 面向 | 内容 |
|------|------|
| 时间 | 755—763 |
| 主谋 | 安禄山 · 史思明 |
| 进程 | 破两京 · 玄宗奔蜀 · 平乱 |
| 后果 | 人口锐减 · 财政崩坏 · [[藩镇-Fanzhen\|藩镇割据]] |

## 要义

- 成因**多因**：边镇军权膨胀 + 中央武备空虚 + 玄宗晚年怠政。
- 战后唐廷由盛转衰，中央权威、财政、兵制俱受重创。
- 促成[[租庸调-Zu-Yong-Diao|租庸调]]→[[两税法-Two-Tax-System|两税法]]、府兵→[[募兵制-Mubing|募兵]]的制度转折。

## 争议 ⚠️

- **根本成因**：制度（节度使）抑或人事（玄宗）？两说并列。
