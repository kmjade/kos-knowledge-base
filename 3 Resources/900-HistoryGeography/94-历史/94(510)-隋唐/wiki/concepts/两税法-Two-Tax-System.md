# 两税法 Two-Tax-System

## 定义

**两税法**是唐德宗建中元年（780）由杨炎推行、以**资产**为课税基础、一年**夏秋两征**的税制，取代[[租庸调-Zu-Yong-Diao|租庸调]]。

## 要点

| 面向 | 内容 |
|------|------|
| 创设 | 780 年，杨炎 |
| 依据 | 资产（贫富）而非人丁 |
| 征收 | 夏 · 秋两征 |
| 形态 | 以钱计征（折纳实物） |

## 要义

- 是中国税制由**人丁为本**转向**资产为本**的关键转折。
- 简化税制、扩大税基，缓解安史之乱后的财政危机。
- 亦开此后「以钱为税」与折纳盘剥之端，遭后世批评。

## 争议 ⚠️

- 两税法**利弊**（简税之利 vs 加重盘剥之弊）争议不衰，本库不代裁。
