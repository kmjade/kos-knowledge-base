# 佛教中国化 Buddhism-Sinicization

## 定义

**佛教中国化**指佛教在隋唐由传入、译介走向**本土宗派化**的过程：禅宗、天台宗、华严宗、净土宗等相继成立。

## 要点

| 宗派 | 特征 |
|------|------|
| 禅宗 | 直指人心 · 见性成佛 |
| 天台宗 | 一念三千 · 止观 |
| 华严宗 | 法界缘起 |
| 净土宗 | 念佛往生 |

## 要义

- [[玄奘-Xuanzang|玄奘]]西行求法、译经，义理达于精严。
- 禅宗以中国式智慧简化修行，成为此后**最盛**的宗派。
- 佛教与儒、道并立，深度渗入哲学、文学、艺术与民间生活。

## 争议 ⚠️

- 佛教与政权、土地经济的**张力**（僧侣免役 · 寺院经济）评价分歧。
