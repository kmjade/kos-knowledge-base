# 募兵制 Mubing

## 定义

**募兵制**是唐中后期取代[[府兵制-Fubing|府兵制]]的军制：国家招募职业兵，发放粮饷，兵农分离。

## 要点

| 面向 | 内容 |
|------|------|
| 取代 | 府兵制 |
| 时点 | 中唐（开元后） |
| 特征 | 职业兵 · 兵农分离 · 募资养兵 |
| 后果 | 边镇节度使拥兵 |

## 要义

- [[均田制-Juntian|均田制]]崩坏后，府兵兵源枯竭，遂行募兵。
- 募兵与**节度使**结合，为[[藩镇-Fanzhen|藩镇割据]]埋下伏笔。
- 兵制由「兵农合一」转向「**职业化**」，是唐后期军事格局的关键变化。
