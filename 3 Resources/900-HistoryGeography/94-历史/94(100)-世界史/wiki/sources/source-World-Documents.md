# source-World-Documents

## 概述

本库的**原始材料层**：跨区域的传世文献、出土文字与实物考古，构成证据强度的判定依据。

## 材料类型

| 类型 | 代表 |
|------|------|
| 传世史著 | 希罗多德 · 修昔底德 · 塔西佗 |
| 宗教与经典 | 圣经 · 古兰经 |
| 出土文字 | 罗塞塔石碑 · 楔形泥板 · 敦煌文书 |
| 实物考古 | 城市遗址 · 庞贝 · 器物 |
| 研究著作 | 麦克尼尔 · 斯塔夫里阿诺斯 · 沃勒斯坦 |

## 证据强度

- **级别 A**：出土文字自证 / 同时代实物+文献互证（如铭文 · 同时代档案）。
- **级别 B**：晚出文献 + 考古部分吻合（多数早期史）。
- **级别 C–D**：晚出文献无考古对应 / 孤证（传说与存疑）。
