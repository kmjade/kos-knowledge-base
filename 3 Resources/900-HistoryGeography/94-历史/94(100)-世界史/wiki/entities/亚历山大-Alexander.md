# 亚历山大 Alexander

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 前 356—前 323 |
| 身份 | 马其顿国王 · 军事家 |
| 关键 | 东征波斯 · 建空前帝国 |
| 遗产 | [[希腊化-Hellenism\|希腊化]]时代 |

## 要义

- 十余年东征，灭波斯，兵抵印度，建立横跨欧亚非的帝国。
- 死后帝国分裂为**托勒密 · 塞琉古 · 安提柯**诸希腊化王朝。
- 促成希腊文化与东方的**首次大规模融合**。
- 评价两极：文化传播者 vs 征服者 —— **两说并列**。
