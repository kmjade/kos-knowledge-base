# 凯撒 Caesar

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 前 100—前 44 |
| 身份 | 罗马政治家 · 军事统帅 |

| 结局 | 前 44 被刺 |

## 要义

- 征服高卢，跨卢比孔河引发内战，击败庞培，任终身独裁官。
- 其死标志**罗马共和的终结**，经后三头政治走向帝制（奥古斯都）。
- 「凯撒」成为后世帝王称号之源（Kaiser / Tsar）。
- 评价两极：破坏共和的僭主 vs 改革家 —— **两说并列**。
