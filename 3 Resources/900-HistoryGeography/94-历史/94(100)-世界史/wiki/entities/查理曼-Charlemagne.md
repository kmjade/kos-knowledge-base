# 查理曼 Charlemagne

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 742—814 |
| 身份 | 法兰克国王 · 加洛林皇帝 |
| 关键 | 800 年加冕「罗马人的皇帝」|
| 遗产 | 西欧政治与教育奠基 |

## 要义

- 统一西欧大部，800 年由教皇加冕为**皇帝**，奠「神圣罗马」观念之基。
- 推行**加洛林文艺复兴**，兴办学校、整理典籍。
- 其帝国三分，为**法 · 德**等国雏形。
- 与 [[西欧封建制-Western-Feudalism|封建制]] 的奠基相关。
