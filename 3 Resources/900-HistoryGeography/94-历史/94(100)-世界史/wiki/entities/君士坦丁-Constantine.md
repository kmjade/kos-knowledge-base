# 君士坦丁 Constantine

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约 272—337 |
| 身份 | 罗马皇帝（306—337）|
| 关键 | 米兰敕令 · 迁都君士坦丁堡 |
| 遗产 | 基督教国教化 · 拜占庭之始 |

## 要义

- 313 年**米兰敕令**，给予基督教合法地位。
- 迁都**君士坦丁堡**，奠定东罗马（拜占庭）千年基业。
- 召开尼西亚会议，塑造基督教正统。
- 是古典向中世纪**转折**的关键人物。
