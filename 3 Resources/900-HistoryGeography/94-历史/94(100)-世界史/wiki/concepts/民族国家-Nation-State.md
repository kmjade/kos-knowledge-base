# 民族国家 Nation-State

## 定义

**民族国家**指以**民族认同**为基础、拥有主权与明确疆界的现代国家形态；随法国大革命与 19 世纪民族主义而普及。

## 要点

| 面向 | 内容 |
|------|------|
| 兴起 | 法国大革命 · 19 世纪 |
| 要素 | 主权 · 疆界 · 民族认同 · 公民 |
| 类型 | 单一民族 / 多民族国家 |
| 后果 | 独立 · 统一 · 亦引发冲突 |

## 要义

- 取代 [[帝国-Empire|帝国]] 成为现代政治的基本单位。
- 既是**解放**力量（民族独立），又可能催生排他与战争 —— 两说并存。
- 与 [[殖民主义-Colonialism|去殖民化]]、[[全球化-Globalization|全球化]] 张力并存。
