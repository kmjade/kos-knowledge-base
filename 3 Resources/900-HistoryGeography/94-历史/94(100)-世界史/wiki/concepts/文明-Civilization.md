# 文明 Civilization

## 定义

**文明**（civilization）通常指以**城市、文字、国家、社会分层**为标志的复杂社会形态，与「史前文化」相对。其界定标准与内涵随学术演变而变。

## 要点

| 面向 | 内容 |
|------|------|
| 标志 | 城市 · 文字 · 国家 · 分层 |
| 起源 | 两河 · 尼罗河 · 印度河 · 黄河 |
| 形态 | 原生 / 次生文明 |
| 研究 | 汤因比 · 亨廷顿等（各有框架）|

## 要义

- 四大**原生文明**各自独立或半独立起源，反驳单线传播论。
- 「文明」一词本身**含价值判断**（文明 vs 野蛮），须批判使用（约定 ≠ 事实）。
- 与 [[帝国-Empire|帝国]]、[[轴心时代-Axial-Age|轴心时代]] 共同构成古典时代分析框架。
