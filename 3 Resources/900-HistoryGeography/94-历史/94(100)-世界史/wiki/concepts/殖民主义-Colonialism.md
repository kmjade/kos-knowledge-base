# 殖民主义 Colonialism

## 定义

**殖民主义**指近代欧洲国家在海外建立**殖民地、攫取资源与统治权**的制度与实践；19 世纪后期达于顶峰（「帝国主义」）。

## 要点

| 阶段 | 内容 |
|------|------|
| 早期（16—18 世纪）| 据点 · 贸易垄断 |
| 高峰（19 世纪后期）| **瓜分非洲** · 全球殖民 |
| 形态 | 定居 / 剥削 / 间接统治 |
| 终结 | 二战后去殖民化 |

## 要义

- 与 [[大航海时代-Age-of-Discovery|大航海]]、[[工业革命-Industrial-Revolution|工业革命]] 互促，构成世界经济体系。
- 既传播技术与制度，又造成**掠夺与不平等** —— 评价两极，两说并列。
- 遗产深远：民族解放运动与现代 [[民族国家-Nation-State|民族国家]] 的催生。
