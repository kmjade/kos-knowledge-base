# 西欧封建制 Western-Feudalism

## 定义

**西欧封建制**指中世纪西欧以**封君封臣关系**（采邑 / 封土）与**庄园经济**为核心的政治-社会制度。

## 要点

| 面向 | 内容 |
|------|------|
| 核心 | 封君封臣 · 采邑 · 效忠 |
| 经济 | 庄园 · 农奴 · 领主 |
| 政治 | 权力分散 · 层层分封 |
| 奠基 | [[查理曼-Charlemagne\|查理曼]] 加洛林帝国 |

## 要义

- 权力**分散**、无强中央，与帝国形态迥异。
- 「封建」一词的**适用性**（能否用于非西欧）为重大争论（约定 ≠ 事实）。
- 与城市复兴、教会共同塑造中世纪西欧社会。
