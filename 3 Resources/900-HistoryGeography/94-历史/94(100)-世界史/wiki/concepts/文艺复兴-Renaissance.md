# 文艺复兴 Renaissance

## 定义

**文艺复兴**指约 **14—17 世纪**发端于意大利、以**人文主义**与**古典复兴**为旗帜的思想文化运动。

## 要点

| 面向 | 内容 |
|------|------|
| 时间 | 14—17 世纪 |
| 中心 | 意大利 → 全欧 |
| 核心 | 人文主义 · 古典复兴 |
| 代表 | 但丁 · 达·芬奇 · 伊拉斯谟 |

## 要义

- 重新发现希腊罗马**古典**，以人为本，挑战中世纪神学权威。
- 为**科学革命**与近代思想奠基（与宗教改革并称近代先声）。
- 争议：它是否**截然区别于**中世纪（断裂抑或延续）—— 两说并存。
