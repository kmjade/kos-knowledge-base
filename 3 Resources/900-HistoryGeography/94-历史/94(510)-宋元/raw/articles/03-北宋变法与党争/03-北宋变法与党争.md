# 03 北宋变法与党争

> 面对冗官冗兵冗费之弊，王安石推行新法，引发新旧党争，贯穿北宋后期。

## 定义

**熙宁变法**（1069 起）是宋神宗支持、王安石主持的全面改革，涉及财政、军事、科举诸端；反对者以司马光为首，形成**新旧党争**。

## 要点

| 新法 | 内容 |
|------|------|
| 青苗法 | 官府贷谷于农 |
| 募役法 | 纳钱代役 |
| 方田均税 | 清丈田亩 |
| 保甲法 | 民兵编制 |
| 市易 · 均输 | 官营平准 |

## 要义

- **变法动机**：解「三冗」之弊、富国强兵。
- **新旧党争**：变法派与守旧派反复倾轧，政争延续至南宋，影响政治生态（见 [[王安石变法-Wang-Anshi-Reforms|王安石变法]]）。
- **评价两极**：变革先驱 vs 扰民致乱——**两说并列**，本库不代裁。
- 其对手[[司马光-Sima-Guang|司马光]]主编《资治通鉴》，思想与史学影响深远。

## 争议 ⚠️

- 变法**成败**与**动机之纯驳**，学界与政治文化中长期争讼。
