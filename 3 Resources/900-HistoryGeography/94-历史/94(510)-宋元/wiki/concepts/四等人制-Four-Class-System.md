# 四等人制 Four-Class-System

## 定义

**四等人制**指元朝按征服先后与族属划分的社会等级：**蒙古人 · 色目人 · 汉人 · 南人**，权利与地位有别。

## 要点

| 等级 | 构成 |
|------|------|
| 蒙古人 | 统治民族 |
| 色目人 | 西域各族 |
| 汉人 | 北方汉族及契丹 · 女真等 |
| 南人 | 原南宋治下汉人 |

## 要义

- 是元代**民族等级**色彩的制度安排，引发社会紧张。
- 与[[行省制-Provincial-System|行省制]]、科举的时段性更张相配套。
- 其**实际执行**程度与被夸大之嫌，学界有讨论——**两说并列**。

## 争议 ⚠️

- 四等人制是否成文、实际效力如何，学界有分歧。
