# 交子 Jiaozi

## 定义

**交子**是北宋在四川出现的**纸币**，被公认为世界最早的纸币，由民间信用票据演变为官办。

## 要点

| 面向 | 内容 |
|------|------|
| 起源 | 北宋四川 |
| 形态 | 纸质代币凭证 |
| 演变 | 民办 → 官办（交子务） |
| 意义 | 商品经济的标志 |

## 要义

- 反映宋代**商品经济与货币需求**的空前高涨。
- 与坊市瓦解、城市繁荣、海外贸易相表里。
- 其通胀与超发问题，亦为后世纸币史的先声。
