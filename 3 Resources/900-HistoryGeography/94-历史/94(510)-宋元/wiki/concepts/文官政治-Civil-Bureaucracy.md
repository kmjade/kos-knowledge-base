# 文官政治 Civil-Bureaucracy

## 定义

**文官政治**指宋代以文臣主导朝政与地方治理的制度形态：重文轻武、分割事权、以科举取士。

## 要点

| 面向 | 内容 |
|------|------|
| 国策 | 强干弱枝 · 重文轻武 |
| 地方 | 文臣知州 + 通判 |
| 中央 | 二府三司分割相权 |
| 选官 | [[科举完善-Expanded-Keju\|科举]] |

## 要义

- 防武将专权、强中央集权，是宋代立国之本。
- 士大夫**共治天下**，「与士大夫治天下」成为政治理念。
- 利在稳定与文治繁荣，弊在冗官、军事积弱——**两说并存**。
