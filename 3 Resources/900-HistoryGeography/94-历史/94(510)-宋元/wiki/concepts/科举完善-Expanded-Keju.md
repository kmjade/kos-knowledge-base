# 科举完善 Expanded-Keju

## 定义

**科举完善**指宋代科举在规模、程序与公平性上的大发展：取士人数剧增，创殿试、糊名、誊录等制度。

## 要点

| 面向 | 内容 |
|------|------|
| 程序 | 解试 · 省试 · 殿试 |
| 公平 | 糊名 · 誊录 · 锁院 |
| 规模 | 取士远超前代 |
| 内容 | 经义 · 策论 · 诗赋 |

## 要义

- **程序公平化**使科举成为更开放的社会流动通道。
- 士人政治与[[文官政治-Civil-Bureaucracy|文官政治]]互为表里。
- 奠定明清科举「三级考试 + 八股」的基本框架。
