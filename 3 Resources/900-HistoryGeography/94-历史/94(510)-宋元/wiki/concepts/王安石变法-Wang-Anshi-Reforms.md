# 王安石变法 Wang-Anshi-Reforms

## 定义

**王安石变法**（熙宁新法，1069 起）是宋神宗时王安石主持的全面改革，旨在富国强兵、解决「三冗」。

## 要点

| 新法 | 目标 |
|------|------|
| 青苗 · 募役 | 财政 |
| 方田均税 | 税基 |
| 保甲 · 将兵 | 军事 |
| 市易 · 均输 | 商业平准 |
| 三舍法 | 教育取士 |

## 要义

- 以「**理财**」「**整军**」为核心，试图以国家力量重构社会经济。
- 引发**新旧党争**，与[[司马光-Sima-Guang|司马光]]等守旧派长期冲突。
- 评价两极：变革先驱 vs 扰民致乱——**两说并列**，本库不代裁。
