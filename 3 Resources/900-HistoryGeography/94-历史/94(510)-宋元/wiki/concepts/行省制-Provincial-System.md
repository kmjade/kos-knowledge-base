# 行省制 Provincial-System

## 定义

**行省制**是元朝的地方最高行政区制度：中书省派出机构「行中书省」治理辽阔疆域，为后世省级行政之始。

## 要点

| 面向 | 内容 |
|------|------|
| 创设 | 元朝 |
| 单位 | 行省（约十行省） |
| 职能 | 军民财赋统辖 |
| 遗制 | 明清布政使司 · 现代省制 |

## 要义

- 适应**空前疆域**的治理需求，兼具集权与效率。
- 与[[四等人制-Four-Class-System|四等人制]]配套，构成元代统治架构。
- 奠定中国**省级行政区划**的历史基础。
