# 朱熹 Zhu Xi

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1130—1200 |
| 身份 | 南宋理学家 · 教育家 |
| 关键 | 理学集大成 · 《四书章句集注》 |
| 影响 | 元明清官方思想 |

## 要义

- 集周敦颐、二程之大成，构建[[理学-Neo-Confucianism|理学]]体系。
- 编《四书章句集注》，确立**四书**为科举圭臬，影响数百年。
- 其学由南宋而元明清，成为官方意识形态。
