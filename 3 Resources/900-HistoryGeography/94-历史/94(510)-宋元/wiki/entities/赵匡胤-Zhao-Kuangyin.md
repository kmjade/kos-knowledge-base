# 赵匡胤 Zhao Kuangyin

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 927—976 |
| 身份 | 北宋开国皇帝（宋太祖） |
| 关键 | 陈桥兵变 · 杯酒释兵权 · 强干弱枝 |
| 国策 | 重文轻武 · 中央集权 |

## 要义

- 960 年陈桥兵变建宋，结束五代十国分裂。
- 「杯酒释兵权」收武将兵权，确立[[文官政治-Civil-Bureaucracy|文官政治]]格局。
- 其制度设计利在稳定繁荣，弊在军事积弱——**两说并存**。
