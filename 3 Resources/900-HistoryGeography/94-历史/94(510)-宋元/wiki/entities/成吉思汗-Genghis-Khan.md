# 成吉思汗 Genghis Khan

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约 1162—1227 |
| 身份 | 蒙古帝国缔造者（铁木真） |
| 关键 | 统一蒙古（1206） · 西征南伐 |
| 遗产 | 欧亚空前帝国 |

## 要义

- 1206 年统一草原诸部，建蒙古国，号成吉思汗。
- 发动大规模**西征**，重塑欧亚政治格局与交通。
- 其帝国经后代扩张，最终由[[忽必烈-Kublai-Khan|忽必烈]]建元统一中国。

## 争议 ⚠️

- 其历史**评价**（征服者 vs 破坏者 · 交流推动者）分歧巨大，本库不代裁。
