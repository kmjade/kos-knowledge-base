# 忽必烈 Kublai Khan

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1215—1294 |
| 身份 | 元朝开国皇帝（元世祖） |
| 关键 | 建元（1271） · 灭南宋（1279） |
| 制度 | [[行省制-Provincial-System\|行省制]] |

## 要义

- 1271 年建国号「大元」，1279 年灭南宋，完成空前**大一统**。
- 行[[行省制-Provincial-System|行省制]]、通中西交流（马可·波罗来华）。
- 其治下多元族群并存，奠定后世疆域与行政框架。
