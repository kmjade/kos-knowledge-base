# 司马光 Sima Guang

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1019—1086 |
| 身份 | 北宋政治家 · 史学家 |
| 关键 | 反对新法 · 主编《资治通鉴》 |
| 著作 | 《资治通鉴》《涑水记闻》 |

## 要义

- 为新法的主要**反对者**，代表守旧派立场。
- 主编《资治通鉴》，为中国**编年体通史**之巨著。
- 其人其学与[[王安石-Wang-Anshi|王安石]]构成北宋政治的**两极**。
