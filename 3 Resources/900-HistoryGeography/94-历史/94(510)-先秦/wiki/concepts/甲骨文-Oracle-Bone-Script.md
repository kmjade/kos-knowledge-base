# 甲骨文 Oracle Bone Script

## 定义

**甲骨文**是刻（或写）于龟甲、兽骨上的商代文字，内容主要是**王室占卜记录（卜辞）**。它是中国现存最早的成体系文字，也是商史研究的第一手材料。

## 关键事实

| 项目 | 内容 |
|------|------|
| 载体 | 龟腹甲、牛肩胛骨为主 |
| 性质 | 占卜记录：祭祀、征伐、田猎、年成、疾病、风雨、生育 |
| 发现 | 1899 年王懿荣辨认（此前被作「龙骨」入药） |
| 科学发掘 | 1928 年起，中央研究院历史语言研究所发掘殷墟 |
| 数量 | 已发现约 15 万片（含流散海外） |
| 字数 | 单字约 4500，已释读约 1500 |

## 要义

- **成熟度反证起源更早**：甲骨文已具备六书结构，说明汉字起源远在商之前——**商以前的文字形态迄今尚无定论**。
- **它不是「史书」**：卜辞是仪式性记录，史事须间接推求，这决定了商史研究的推论性质。
- **它是[[二重证据法-Dual-Evidence|二重证据法]]的首功**：[[王国维-Wang-Guowei|王国维]]以卜辞校《史记·殷本纪》，证实商王世系基本可靠。
