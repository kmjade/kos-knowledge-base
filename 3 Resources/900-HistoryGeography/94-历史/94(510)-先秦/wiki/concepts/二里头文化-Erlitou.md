# 二里头文化 Erlitou

## 定义

**二里头文化**是分布于河南中西部、以偃师二里头遗址命名的一支青铜时代早期考古学文化（约前 1900—前 1500）。其都邑遗址（约前 1750—前 1530）被视为**东亚最早的广域王权国家都邑**。

## 关键事实

| 项目 | 内容 |
|------|------|
| 发现 | 1959 年徐旭生豫西调查时发现 |
| 位置 | 河南偃师，伊洛平原 |
| 面积 | 约 300 万平方米 |
| 宫城 | 约 10.8 万平方米，中国最早的宫城 |
| 遗存 | 大型宫殿基址、青铜礼器作坊、绿松石龙形器、最早的青铜爵 |
| 辐射 | 文化因素远播，是「广域王权」的核心证据 |

## 要义

- **它证明的**：中国早期国家形态在商之前已经出现（宫城、官营手工业、礼器制度、跨区域影响）。
- **它未证明的**：它是否就是文献中的「夏」。**迄今未发现自证性文字**（如「夏」字）。

## 争议：二里头 = 夏？

| 立场 | 要害 |
|------|------|
| 肯定派 | 年代、地望、社会发展阶段三者吻合 |
| 谨慎派 | 无自证文字；名号是后人追认，套用有循环论证风险（许宏《最早的中国》） |

> 本库一律写「夏与二里头」，**不写「夏都二里头」**。分辨：**「二里头是早期国家」是考古共识；「二里头是夏」是对接文献的推论。**
