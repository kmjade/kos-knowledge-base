# 顾颉刚 Gu Jiegang

中国现代史学家（1893—1980），「古史辨」派创始人，以「**层累地造成的中国古史**」说震动学界，是先秦史料学的关键人物。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 史学家 |
| 时期 | 现代（1893—1980） |
| 代表 | 《古史辨》（1923 年起）、《汉代学术史略》 |
| 核心命题 | 层累地造成的中国古史 |

## 层累说

**时代愈后，传说的古史期愈长；时代愈后，传说中的中心人物愈放愈大。**

| 推论 | 说明 |
|------|------|
| 古史系统是构造物 | 「三皇五帝」的整齐谱系成于战国秦汉，非上古实录 |
| 禹的地位随时代上升 | 从《诗经》中的神性人物到「夏后氏」 |
| 方法论意义 | 把「文献成书年代」置于「文献所述内容」之先考察 |

## 要义与限定

- **他不是简单的「全盘怀疑」**：层累说是**方法论**，要求逐条考订文献的年代与性质，而非一概否定。
- **⚠️ 他受后来批评**：其部分推论（如对禹的性质的判定）被认为过强；「走出疑古」一派正是对此的反拨。
- **本库的用法**：古史辨与[[二重证据法-Dual-Evidence\|二重证据法]]**并非一方压倒另一方**，而是互补——前者管「文献的层次」，后者管「出土的校验」。
