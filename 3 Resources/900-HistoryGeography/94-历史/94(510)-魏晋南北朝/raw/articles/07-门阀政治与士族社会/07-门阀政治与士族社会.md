# 07 门阀政治与士族社会

> 主题章：门阀士族如何成为魏晋南北朝的支配性社会结构，及其盛衰逻辑。

## 定义

**门阀政治**指士族高门与皇权共治、甚至凌驾皇权的政治形态；**士族**（世族 · 门阀）是以累世官宦、经学传家、婚姻圈层维系的特权阶层。其制度基础是**九品中正制**，其社会表征是**士庶之别**。

## 要点

| 概念 | 内容 |
|------|------|
| 九品中正制 | 中正官品评人才，遂「上品无寒门」 |
| 士庶之别 | 士族与庶族在仕宦、婚姻、法律上判然有别 |
| 门阀共治 | 「王与马，共天下」 |
| 庄园经济 | 部曲 · 佃客 · 荫户 |

## 要义

- **制度根源**：[[九品中正制-Nine-Rank-System|九品中正制]]本为选才，却沦为门第世袭的工具。
- **社会结构**：[[士族-Shizu|士族]]垄断清要之职，与皇权、寒门、庶族形成张力。
- **门阀政治**：田余庆《东晋门阀政治》指出其为皇权政治的**变态**而非常态，仅存于东晋一朝（见 [[门阀政治-Menfa-Politics|门阀政治]]）。
- **衰落**：南朝皇权回涨 + 侯景之乱 + 自身腐朽，门阀终为[[科举制-Keju|科举]]时代所取代。

## 争议

- 门阀政治是「士族共和」还是「皇权变态」？**两说并列**。
- 士族**衰落**的时点与主因，学界分歧。
