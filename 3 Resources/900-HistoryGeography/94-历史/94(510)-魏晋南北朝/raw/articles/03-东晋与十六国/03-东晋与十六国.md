# 03 东晋与十六国

> 晋室南渡、偏安江左；北方「五胡」诸族先后建立十六国——中国史上民族大冲突与大融合的关键期。

## 定义

永嘉之乱后，司马睿在**王导**等士族拥戴下于建康称帝（317），是为**东晋**（317—420）。同时北方匈奴、鲜卑、羯、氐、羌等族建立多个政权，史称**十六国**（304—439），至北魏统一北方而终。

## 要点

| 面向 | 内容 |
|------|------|
| 政治 | 「王与马，共天下」——士族与皇权共治 |
| 军事 | 淝水之战（383）东晋以少胜多 |
| 北方 | 十六国迭兴——前秦一度统一（苻坚） |
| 经济 | 侨州郡县 · 土断 · 南方开发 |

## 要义

- **门阀共治**：东晋皇权孱弱，琅琊王氏、颍川庾氏、谯国桓氏、陈郡谢氏轮流执政——门阀政治的典型形态（见 [[07-门阀政治与士族社会]]）。
- **淝水之战**（383）：前秦苻坚南下，东晋谢安、谢玄以八万破八十万，保全江左，前秦随之崩解。
- **民族冲突与融合**：北方诸族政权在冲突中逐步吸纳汉制，为[[05-北朝：北魏与孝文帝改革|北魏汉化]]与[[民族融合-Ethnic-Fusion|民族融合]]铺路。
- **南方开发**：北人南迁带来人口、技术与资本，江南经济开始上升。

## 争议

- 「五胡」「十六国」为后世概括提法——其数目与归属均有史源问题（见 [[09-考古与史料：碑刻·墓志·石窟]]）。
- 东晋是「偏安」还是「南方开发的关键期」？两说并存。
