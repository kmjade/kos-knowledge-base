# 清谈 Qingtan

## 定义

**清谈**是魏晋士人以[[玄学-Xuanxue|玄学]]命题为内容、以辩难为形式的思想性言谈风尚。

## 要点

| 面向 | 内容 |
|------|------|
| 形式 | 主客辩难 · 手挥麈尾 |
| 命题 | 有无 · 言意 · 才性 · 圣人有情无情 |
| 载体 | 《世说新语》记其言行 |
| 主体 | [[士族-Shizu\|士族]]名士 |

## 要义

- 清谈既是**思想活动**，也是[[士族-Shizu|士族]]**身份与品味**的表现。
- 常被后世评为「清谈误国」，然其思辨成果实为玄学所寄——评价**两说并列**。
