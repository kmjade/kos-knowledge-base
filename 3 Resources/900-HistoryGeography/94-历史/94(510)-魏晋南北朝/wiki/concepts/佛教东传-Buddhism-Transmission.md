# 佛教东传 Buddhism-Transmission

## 定义

**佛教东传**指佛教自汉代传入中国，至魏晋南北朝因玄学氛围与乱世需求而广泛传播、并逐步本土化的过程。

## 要点

| 阶段 | 内容 |
|------|------|
| 传入 | 汉（约公元 1 世纪） |
| 格义 | 借[[玄学-Xuanxue\|玄学]]话语理解佛理 |
| 译经 | 鸠摩罗什译《般若》《法华》《维摩》 |
| 兴盛 | 南朝「四百八十寺」· 北朝石窟 |

## 要义

- **格义佛教**：以老庄概念比附佛理，是必要的诠释桥梁，亦被认为有误解之弊——**两说并存**。
- 鸠摩罗什、道安、僧肇推动译经与义理独立化。
- 佛教与儒、道并立，奠定此后中国**三教关系**的基本格局。
