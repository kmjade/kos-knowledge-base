# 士族 Shizu

## 定义

**士族**（世族 · 门阀）是以累世官宦、经学传家、门第婚姻维系的特权阶层，是魏晋南北朝社会的支配力量。

## 要点

| 特征 | 内容 |
|------|------|
| 仕宦 | 垄断清要之职 |
| 婚姻 | 门当户对，不与庶族通婚 |
| 经济 | 庄园 · 部曲 · 佃客 · 荫户 |
| 文化 | 经学 · 玄学 · 书法 · 家训 |

## 要义

- 士族与**庶族 / 寒门**在仕宦、婚姻、法律上判然有别——「士庶之别，国之根本」。
- 典型如琅琊王氏、陈郡谢氏、颍川庾氏、谯国桓氏。
- 南朝皇权回涨 + 侯景之乱 + 自身腐朽，士族渐衰，终让位于科举时代的新士人。
