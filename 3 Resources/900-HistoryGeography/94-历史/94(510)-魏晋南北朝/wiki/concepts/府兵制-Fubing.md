# 府兵制 Fubing

## 定义

**府兵制**是西魏—北周形成的兵农合一军制：以军府统兵，兵士另立军籍、轮番宿卫与征戍。

## 要点

| 面向 | 内容 |
|------|------|
| 形成 | 西魏宇文泰 |
| 特征 | 兵农合一 · 军府统辖 |
| 集团 | 「关陇集团」军事贵族 |
| 沿革 | 北周 → 隋 → 唐前期 |

## 要义

- 府兵制巩固了**关陇集团**，为隋唐皇室与将相的人才库。
- 与[[均田制-Juntian|均田制]]配套：兵士受田、自备军资。
- 唐代因均田瓦解、边防扩大而改为募兵，府兵遂废。
