# 九品中正制 Nine-Rank-System

## 定义

**九品中正制**是曹魏（220）起行的选官制度：由各州郡的**中正官**品评士人，定为九等（上上至下下），作为吏部授官依据。

## 要点

| 面向 | 内容 |
|------|------|
| 创设 | 220 年，陈群建议 |
| 中正 | 州 · 郡设大中正、中正 |
| 品级 | 九品（上上…下下） |
| 后果 | 「上品无寒门，下品无势族」 |

## 要义

- 本以「唯才」矫汉末乡议之弊，却因中正多由士族把持，**沦为门第世袭的工具**。
- 成为[[门阀政治-Menfa-Politics|门阀政治]]与[[士族-Shizu|士族]]社会的制度骨架。
- 隋唐以[[科举制-Keju|科举]]取代之，选官由「品评」转向「考试」。
