# 孝文帝改革 Xiaowen-Reforms

## 定义

**孝文帝改革**指北魏孝文帝（元宏）在冯太后改革基础上推行的**汉化与制度化**措施，以迁都洛阳（494）为标志。

## 要点

| 措施 | 内容 |
|------|------|
| 迁都 | 平城 → 洛阳 |
| 姓氏 | 拓跋改「元」，诸胡姓改汉姓 |
| 服语言 | 禁胡服 · 禁鲜卑语于朝 |
| 婚姻 | 倡导胡汉通婚 |
| 官制 | 依魏晋门阀化官制 |

## 要义

- 改革加速**胡汉融合**，使北魏由部落政权转向华夏式帝国。
- 亦激化矛盾：六镇武人地位下降，成为此后**六镇之乱**与北魏分裂的远因。
- 与[[均田制-Juntian|均田]] · [[民族融合-Ethnic-Fusion|民族融合]]互为一体。

## 争议 ⚠️

- 汉化**成功**抑或**埋下衰亡之因**？两说并列，本库不代裁。
