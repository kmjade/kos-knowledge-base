# 诸葛亮 Zhuge Liang

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 181—234 |
| 身份 | 蜀汉丞相 · 政治家 · 军事家 |
| 关键 | 隆中对 · 联吴抗曹 · 南征北伐 · 鞠躬尽瘁 |
| 著作 | 《出师表》《诫子书》 |

## 要义

- 「隆中对」为刘备定三分之策，奠定蜀汉立国路线。
- 治国以法度严明、吏治清明著称；六出祁山、卒于五丈原。
- 后世形象经《三国演义》**文学化层累**，史实与传说须分层对待。
