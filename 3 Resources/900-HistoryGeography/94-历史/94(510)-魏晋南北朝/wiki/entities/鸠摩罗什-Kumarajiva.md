# 鸠摩罗什 Kumarajiva

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 344—413 |
| 身份 | 后秦高僧 · 佛典翻译家 |
| 出身 | 龟兹（Kucha） |
| 关键 | 长安译经 · 门下弟子三千 |

## 要义

- 主持大规模译经，译出《般若经》《法华经》《维摩诘经》《中论》等。
- 译笔**信达雅兼备**，其译本长期流通，奠定汉传佛教义理基础。
- 是[[佛教东传-Buddhism-Transmission|佛教东传]]由「格义附会」走向**独立理解**的关键人物。
