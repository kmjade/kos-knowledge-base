# 曹操 Cao Cao

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 155—220 |
| 身份 | 东汉末政治家 · 军事家 · 文学家 |
| 关键 | 挟天子以令诸侯 · 官渡之战 · 屯田 · 唯才是举 |
| 追尊 | 魏武帝（子曹丕称帝后） |

## 要义

- 统一北方，奠定曹魏基业；行**屯田制**以充军资，行**唯才是举**以破门第。
- 文学上为「建安风骨」领袖，与子曹丕、曹植并称「三曹」。
- 其历史评价历来分歧：**能臣**与**奸雄**两说并列，本库不代裁。
