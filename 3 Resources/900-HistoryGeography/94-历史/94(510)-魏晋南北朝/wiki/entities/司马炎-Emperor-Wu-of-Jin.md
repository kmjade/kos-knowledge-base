# 司马炎 Emperor Wu of Jin

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 236—290 |
| 身份 | 西晋开国皇帝（晋武帝） |
| 关键 | 代魏建晋 · 灭吴统一（280） · 大封宗室 |
| 后果 | 八王之乱 · 西晋速亡 |

## 要义

- 265 年代魏建晋，280 年灭吴，结束三国分裂、完成**短暂统一**。
- 施行**占田制**、优容门阀，然大封宗室为「八王之乱」埋患。
- 其一统之局仅数十年即崩解，成为[[01-魏晋南北朝导论|分裂时代]]的转折点。
