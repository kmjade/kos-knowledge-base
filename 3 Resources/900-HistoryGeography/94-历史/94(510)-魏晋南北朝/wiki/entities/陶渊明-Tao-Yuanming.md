# 陶渊明 Tao Yuanming

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约 365—427 |
| 身份 | 东晋南朝诗人 · 隐逸高士 |
| 关键 | 田园诗开创 · 「不为五斗米折腰」 |
| 代表作 | 《归园田居》《桃花源记》《饮酒》 |

## 要义

- 开创**田园诗**，以自然淡泊之笔书写隐逸生活，影响深远。
- 「桃花源」理想象征乱世中对安宁的向往。
- 其**辞官归隐**被后世视为士人风骨的典范。
