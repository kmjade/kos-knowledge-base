# 北魏孝文帝 Emperor Xiaowen

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 467—499 |
| 身份 | 北魏皇帝（471—499 在位） |
| 姓 | 拓跋 → 元 |
| 关键 | 迁都洛阳 · 汉化改革 |

## 要义

- 在冯太后改革基础上推行**全面汉化**：迁都洛阳、改汉姓、禁胡服胡语、倡胡汉通婚。
- 改革加速[[民族融合-Ethnic-Fusion|民族融合]]，也使北朝转向华夏式帝国。
- 汉化**功过**历来两说：融合之功 vs 六镇之乱远因——本库**不代裁**。
