## 三条主线

| 主线 | 内容 |
|------|------|
| **政治线** | 三国鼎立 → 西晋统一 → 永嘉南渡 → 南北对峙 → 隋的再统一 |
| **社会线** | 九品中正 → 门阀士族 → 士庶之别 → 门阀衰落 |
| **文化线** | 玄学清谈 → 佛教东传 → 道教兴起 → 三教激荡 |
