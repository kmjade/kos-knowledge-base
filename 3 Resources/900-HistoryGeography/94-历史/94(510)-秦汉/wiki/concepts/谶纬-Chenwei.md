# 谶纬 Chenwei

## 定义

**谶纬**是汉代兴起的**神学化附会之学**：「**谶**」为预示吉凶的隐语预言（图谶），「**纬**」为对儒家经典的方术化附会（纬书，与「经」相对）。合称谶纬。

## 要点

| 类别 | 说明 |
|------|------|
| 谶 | 预言、隐语、图谶，多附会符命 |
| 纬 | 托名孔子，以阴阳五行附会经义 |
| 政治用途 | 论证受命、禅代、改元的**符命** |
| 高峰 | 西汉末至东汉 |

## 要义

- **与政治合法性深度绑定**：[[05-西汉中后期与新莽|王莽]]借图谶受禅，[[06-东汉：豪族政治与帝国衰变|光武]]因《赤伏符》受命，并「宣布图谶于天下」——谶纬成为**改朝换代的话语工具**。
- **儒学的神学化**：谶纬是[[天人感应-Heaven-Man-Correspondence|天人感应]]思想的极端发展；它使儒学带上浓厚神学色彩，也埋下被批判的伏笔。
- **后世的清算**：东汉王充《论衡》「疾虚妄」，以及后世对纬书的排斥（多散佚，仅存辑本），皆针对谶纬的虚妄。
