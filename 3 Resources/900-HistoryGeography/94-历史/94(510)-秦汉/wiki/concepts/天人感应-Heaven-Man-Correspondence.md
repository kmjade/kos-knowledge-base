# 天人感应 Heaven-Man Correspondence

## 定义

**天人感应**是[[董仲舒-Dong-Zhongshu|董仲舒]]新儒学的核心命题：**天与人相互感应**，人君之政得失会引致天降祥瑞或灾异。它为皇权提供了神圣依据，也为**限制君权**提供了理论工具。

## 要点

| 要点 | 说明 |
|------|------|
| 理论来源 | 阴阳五行说 + 儒家伦理 + 天人相类 |
| 祥瑞 | 君德则天降祥瑞（凤凰、甘露等） |
| 灾异 | 君失德则天降灾异（日食、地震、水旱） |
| 政治功能 | 「**屈君而伸天**」——借天意谏诫君主 |

## 要义

- **双刃的合法性理论**：一方面论证「君权天授」，强化皇权；另一方面以「天谴」责君，为士大夫**谏议与批评**提供话语（汉代诏书常见因灾异而下「罪己诏」）。
- **与[[大一统-Great-Unity|大一统]]配套**：天人感应为「大一统」的君权提供宇宙论根据。
- **流变**：其神学化倾向在西汉中后期发展为[[谶纬-Chenwei|谶纬]]，也招致东汉王充《论衡》的批判。
