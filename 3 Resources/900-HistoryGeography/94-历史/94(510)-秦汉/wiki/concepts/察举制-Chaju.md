# 察举制 Chaju

## 定义

**察举制**是汉代由**地方长官考察并推荐**人才入仕的制度，汉武帝时正式确立。科目以「孝廉」（孝悌廉正）与「贤良方正」为主，后加考试对策。

## 要点

| 环节 | 说明 |
|------|------|
| 察举 | 郡国按额岁举，长官负推荐之责 |
| 科目 | 孝廉 · 贤良方正 · 茂才 · 明经 等 |
| 考核 | 对策（策问）定高下，非纯凭推荐 |
| 地位 | 与征辟、任子并行，渐成主流仕途 |

## 要义

- **从「军功」到「德行」**：秦以军功爵、吏道选人；察举以儒家伦理标准取士——**选官标准的儒学化**。
- **制度的两面**：初期打破世卿、广开仕路；后期被[[豪族-Gentry-Clans|豪族]]垄断，推荐沦为请托，「举秀才，不知书；举孝廉，父别居」是其讥（见 [[06-东汉：豪族政治与帝国衰变|06 章]]）。
- **承前启后**：察举是世卿与科举之间的过渡形态；其败坏直接催生了后世**考试取士**的探索。
