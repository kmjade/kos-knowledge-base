# 豪族 Gentry Clans

## 定义

**豪族**指汉代兼有**土地、经学、宗族与武装**的地方大族。他们以庄园经济为基础，以[[察举制-Chaju|察举]]为仕进通道，以门生故吏结成网络，是东汉政治的**实际支配力量**。

## 要点

| 面向 | 表现 |
|------|------|
| 经济 | 大庄园（田庄），农林牧副渔工商兼营，自给自足 |
| 政治 | 垄断察举，累世公卿（袁氏「四世三公」等） |
| 文化 | 家学传承，经学与礼法结合 |
| 军事 | 部曲、私兵，乱世转为割据武装 |
| 社会 | 宗族聚居，宾客、佃客依附 |

## 要义

- **从「兼并之家」到「政治集团」**：西汉的豪强以土地兼并为特征，东汉的豪族进一步**经学化、官僚化**，成为准贵族。
- **帝制的内在张力**：皇权依赖官僚制，豪族却垄断了官僚制的入口——**中央集权与地方大族的结构性矛盾**是东汉政治的主线。
- **历史的延长线**：豪族在魏晋演化为**门阀士族**，构成中古社会的基本单元。本库仅在秦汉语境内论述，门户演化留待后续断代。
