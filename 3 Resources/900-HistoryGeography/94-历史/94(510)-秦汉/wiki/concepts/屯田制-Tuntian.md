# 屯田制 Tuntian

## 定义

**屯田制**是政府组织军队或移民**垦殖荒地**、以所获供养边防与军政的制度。汉代屯田以**边地军屯**为主（河西、西域），是国家经营农业的典型形态。

## 要点

| 类型 | 说明 |
|------|------|
| 军屯 | 戍卒且耕且守，解决边粮转运之难 |
| 民屯 | 移民实边，官给田与耕具，租税分成 |
| 分布 | 河西走廊 · 西域 · 朔方等边郡 |
| 管理 | 属农都尉、田官等系统 |

## 要义

- **后勤即战略**：屯田解决「千里馈粮」的难题，是汉帝国**长期据守河西、经略西域**的物质基础（[[丝绸之路-Silk-Road|丝路]]保障）。
- **国家土地经营**：与盐铁官营同属于**国家对经济的直接介入**，是帝制中国「有为」财政的一环。
- **证据**：**居延汉简**中大量屯戍簿籍是屯田制运行的直接记录（见 [[09-考古与史料：简牍·画像石·封泥|09 章]]）。
