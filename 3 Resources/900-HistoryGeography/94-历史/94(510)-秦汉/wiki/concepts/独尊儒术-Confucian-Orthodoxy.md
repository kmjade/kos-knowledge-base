# 独尊儒术 Confucian Orthodoxy

## 定义

**独尊儒术**指汉武帝采纳[[董仲舒-Dong-Zhongshu|董仲舒]]建议，**罢黜百家、以儒学为官方意识形态**，设五经博士、立太学，使儒学成为仕进与教化的正统学说。

## 要点

| 要点 | 说明 |
|------|------|
| 时间 | 前 134 年（「天人三策」） |
| 措施 | 罢黜百家 · 立五经博士 · 兴太学 |
| 与仕途 | 明经入仕，经学与[[察举制-Chaju\|察举]]挂钩 |
| 实际形态 | **儒表法里**——儒术主合法性，律令吏术主行政 |

## 要义

- **不是「禁绝百家」**：史实是**抬升儒学为官学**，法家、道家仍在实际政治与学术中存在。故「独尊」应理解为**意识形态的官方化**，而非思想的彻底消灭（⚠️ 与「焚书坑儒」的强度有本质不同）。
- **儒表法里**：秦制的律令骨架被保留，儒学提供其**正当性外观**——这是帝制中国「外儒内法」传统的起点。
- **制度后果**：经学成为学问中心，士人读经入仕，塑造了此后两千年的**士大夫文化**。
