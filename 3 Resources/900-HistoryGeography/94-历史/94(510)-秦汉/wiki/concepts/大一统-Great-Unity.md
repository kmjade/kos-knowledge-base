# 大一统 Great Unity

## 定义

**大一统**指政治与文化上**「天下」应统一于一个中央权威**的观念与事实。它既是对秦汉统一帝国的描述，也是此后中国政治文化的核心价值。

## 要点

| 维度 | 表现 |
|------|------|
| 政治 | 中央集权 · [[郡县制-Junxian\|郡县]]·废封建 |
| 文化 | [[独尊儒术-Confucian-Orthodoxy\|独尊儒术]]·书同文 |
| 经济 | 统一货币（半两 · 五铢）· 度量衡 |
| 观念 | 「《春秋》大一统者，天地之常经，古今之通谊」（[[董仲舒-Dong-Zhongshu\|董仲舒]]） |

## 要义

- **「大一统」从事实升为价值**：秦以武力实现统一（事实），汉以儒学为其提供**正当性话语**（价值）——「大一统」遂成为中国政治的正统原则。
- **一言以蔽之**：统一不再只是权宜，而成为「常经」「通谊」——此后任何分裂都被视为**失序**，任何政权都以「统一」自命。
- **张力**：大一统与地方多样性、与「封建」传统（分权）之间存在长期张力，汉初[[03-西汉前期：郡国并行与文景之治|郡国并行]]即其体现。
