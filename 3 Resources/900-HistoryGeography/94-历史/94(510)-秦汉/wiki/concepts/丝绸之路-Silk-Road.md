# 丝绸之路 Silk Road

## 定义

**丝绸之路**指经河西走廊、西域连接中国与中亚、西亚乃至欧洲的**交通与贸易网络**。其开辟以[[张骞-Zhang-Qian|张骞]]「凿空」西域为标志（前 138、前 119 两度出使）。

## 要点

| 要素 | 说明 |
|------|------|
| 起点 | 汉长安 → 河西走廊（武威 · 张掖 · 酒泉 · 敦煌） |
| 通道 | 西域（今新疆）→ 中亚 → 西亚 / 欧洲 |
| 核心商品 | 丝绸西运；良马 · 葡萄 · 苜蓿 · 胡麻东来 |
| 制度保障 | 河西四郡 · 都护府 · [[屯田制-Tuntian\|屯田]]戍边 |

## 要义

- **军事—外交—贸易一体**：丝路的开辟是汉武帝北击匈奴、断「匈奴右臂」战略的产物，**贸易依附于帝国安全**。
- **文化交流的动脉**：佛教、乐舞、物种、技术沿此东传，中原文明与中亚、南亚文明首次大规模直接接触。
- **「丝绸之路」是后世命名**：此名由 19 世纪德国地理学家李希霍芬提出（⚠️），并非当时称谓——本库标明其为**后世概括**。
