# 郡县制 Junxian

## 定义

**郡县制**是以**中央任免、考核、迁转**的地方长官治理国土的行政制度，取代世袭封土。「郡—县」为层级单位，长官非世袭、非本地任职，直接对中央负责。

## 要点

| 要点 | 说明 |
|------|------|
| 层级 | 郡 → 县 → 乡 → 里（汉武帝后于郡上置州部监察） |
| 任免 | 郡守、县令由中央任免，可迁转、可罢黜 |
| 文书行政 | 以簿籍、上计、考课构成控制链 |
| 编户 | 里下什伍相连坐，与户籍赋役一体 |

## 要义

- **郡县是「帝制」的骨架**：秦废封建、行郡县，是[[02-秦的统一与速亡|秦创制]]的核心，也是此后两千年地方行政的基本形态。
- **与封建的根本差别**：封建下土地与人民是「封」的（世袭）；郡县下一切「授」的（可撤）——**主权贯彻到基层**。
- **韧性**：秦亡而郡县不亡；汉初一度[[03-西汉前期：郡国并行与文景之治|郡国并行]]，终以郡县为主、封国被削。
