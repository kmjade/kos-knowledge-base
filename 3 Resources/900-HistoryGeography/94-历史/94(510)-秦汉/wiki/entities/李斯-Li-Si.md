# 李斯 Li Si

楚国上蔡人（约前 280—前 208），法家代表人物，秦统一后的丞相、秦制的**主要设计与执行者**。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 政治家、法家 |
| 时期 | [[02-秦的统一与速亡\|秦]] |
| 师承 | 荀子门人；与韩非同门 |
| 核心主张 | 废封建、行[[郡县制-Junxian\|郡县]]；「以吏为师」；书同文 |
| 代表文献 | 《谏逐客书》、奏请统一文字 |
| 结局 | 与赵高合谋立胡亥，后被赵高诬杀 |

## 要义

- **他是「秦制」的工程师**：郡县、文字、法律的统一，李斯多为直接主导者——**制度层面的秦始皇意志执行者**。
- **法家路线的实操范式**：把法家理论（承先秦 [[94(510)-先秦|先秦]] 库的商鞅、韩非）转化为帝国的行政现实。
- **个人悲剧与制度悲剧**：其本人死于自己所参与构陷的政治阴谋，折射秦政的峻烈（⚠️ 与「焚书」的关系史料有分歧）。
