# 司马迁 Sima Qian

左冯翊夏阳人（约前 145—约前 86），西汉史学家，任**太史令**，著《**史记**》——中国第一部纪传体通史。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 史学家、文学家 |
| 时期 | [[04-汉武帝与帝国定型\|汉武帝期]] |
| 代表著作 | 《史记》130 篇（本纪 · 表 · 书 · 世家 · 列传） |
| 编纂宗旨 | 「究天人之际，通古今之变，成一家之言」 |
| 经历 | 继父司马谈之志；因李陵事受宫刑，发愤著书 |

## 要义

- **他确立了「通史」的体例**：《史记》上起黄帝、下至汉武，为**纪传体**与**正史**的范式，后世二十四史皆仿之。
- **史料与史识的双重价值**：秦汉史的第一手框架多赖《史记》，但须警惕其**汉人立场**（⚠️ 对秦、对项羽的叙述倾向，见 [[02-秦的统一与速亡|02 章]]、[[01-秦汉导论|01 章]]）。
- **史学的人文精神**：以「实录」与「发愤」并重，为中国史学确立了**求真与寄怀**兼具的传统。
