# 董仲舒 Dong Zhongshu

广川人（前 179—前 104），西汉大儒，新儒学的奠基者。以「**天人三策**」应答武帝，推动[[独尊儒术-Confucian-Orthodoxy|独尊儒术]]。

| 参数 | 说明 |
|------|------|

| 理论融合 | 以儒家为主体，吸纳阴阳五行与法家 |
| 代表著述 | 《春秋繁露》；「天人三策」（见《汉书·董仲舒传》） |

## 要义

- **他给「大一统」提供了宇宙论根据**：「《春秋》大一统者，天地之常经」——使统一由政治事实升为**天道原则**（[[大一统-Great-Unity|大一统]]）。
- **以「天」限君**：「屈君而伸天」——为士大夫批评君主与灾异谏议提供理论工具。
- **儒学神学化的推手**：其学既巩固了儒学的官方地位，也开启了此后向[[谶纬-Chenwei|谶纬]]演化的可能。
