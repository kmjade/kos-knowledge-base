# 张骞 Zhang Qian

汉中成固人（约前 164—前 114），西汉外交家、探险家，封博望侯。两次出使西域，史称「**凿空**」。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 外交家、探险家 |
| 时期 | [[04-汉武帝与帝国定型\|汉武帝期]] |
| 出使 | 前 138 首次（历十三年方归）·前 119 再度 |
| 使命 | 联络大月氏夹击匈奴（未成）→ 广通西域诸国 |
| 成果 | 开[[丝绸之路-Silk-Road\|丝绸之路]]；汉置河西四郡、设都护 |

## 要义

- **军事目标，意外开出文明通道**：原为「断匈奴右臂」的军事外交，却成就了欧亚大陆的**交通与贸易网络**（[[丝绸之路-Silk-Road|丝路]]）。
- **帝国视野的拓展**：其行记（《史记·大宛列传》所载）使汉朝首次系统认知中亚，**「西域」由此进入中国的地理与政治视野**。
- **长期经营**：丝路的稳固依赖 [[屯田制-Tuntian|屯田]] 戍边与河西郡县的设置——外交成果由制度巩固。
