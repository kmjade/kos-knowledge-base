# 秦始皇 Qin Shi Huang

秦王政（前 259—前 210），前 246 年即位，前 221 年灭六国、创「皇帝」之号，自称**始皇帝**。中国帝制的开创者。

## 核心规格

| 参数 | 说明 |
|------|------|
| 类型 | 君主、政治家 |
| 时期 | [[02-秦的统一与速亡\|秦]]（前 221—前 210 在位为帝） |
| 核心举措 | 废封建行[[郡县制-Junxian\|郡县]]·书同文车同轨·统一度量衡货币·修驰道长城 |
| 制度 | [[三公九卿-Three-Excellencies\|三公九卿]]·[[汉承秦制-Han-Inherits-Qin\|汉承其制]] |
| 政策 | 严刑峻法·「焚书坑儒」（⚠️ 范围有争） |
| 归宿 | 前 210 崩于沙丘；葬骊山（秦始皇帝陵） |

## 要义

- **他定义了中国政治的「单元」**：此后两千年，「统一」是常态、「分裂」是例外，都与始皇帝确立的帝制框架相关。
- **功与过的双重性**：创制之功（郡县、文字、交通的统一）与苛暴之过（峻法、大役）并存——本库两说并列，不代裁（见 [[02-秦的统一与速亡|02 章]]）。
- **考古见证**：秦始皇陵与兵马俑是其权力与厚葬的物质见证（见 [[09-考古与史料：简牍·画像石·封泥|09 章]]）。
