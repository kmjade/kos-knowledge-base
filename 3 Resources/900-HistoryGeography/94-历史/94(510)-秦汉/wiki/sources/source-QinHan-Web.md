# 秦汉 综合资料

本库的**框架性叙述**（分期、制度脉络、事件时序）主要依据综合网络/百科资料与通行教科书，代表秦汉史的通说框架。

## 性质与强度

- **性质**：二手综合材料，便于迅速建立框架，但**不含一手证据**。
- **证据强度**：C–D（相较于出土简牍与同时代实物）。
- **使用纪律**：凡涉争议，须回落到传世史书与出土材料核对，**不以综合资料为终裁**。

## 适用与限度

| 适用 | 限度 |
|------|------|
| 阶段分期与时序 | 争议问题的结论不可采信 |
| 制度与人物概览 | 细节须以《史记》《汉书》与简牍校验 |
