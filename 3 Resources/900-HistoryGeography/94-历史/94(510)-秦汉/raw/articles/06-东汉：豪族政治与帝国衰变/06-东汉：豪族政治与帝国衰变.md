# 06 东汉：豪族政治与帝国衰变

## 光武中兴（25—57）

**刘秀**（光武帝）在群雄中再建汉室，定都洛阳，史称**东汉**。其治承西汉而有所调整：

- **退功臣、进文吏**：功臣封侯而不预政，行政倚重文吏与儒生。
- **柔道治国**：省刑减赋、释放奴婢、裁并郡县、精兵简政。
- **度田**：清查垦田与户口，遭豪族抵制而难彻底。

## 豪族政治

东汉政权的社会基础是**豪族**（[[豪族-Gentry-Clans|豪族]]）——兼具土地、经学、宗族与武装的地方大族。特征是：

| 面向 | 表现 |
|------|------|
| 经济 | 大庄园（「田庄」），自给自足，兼营工商 |
| 政治 | 垄断[[察举制-Chaju\|察举]]通道，门生故吏结成网络 |
| 文化 | 累世经学，「四世三公」之家（如汝南袁氏、弘农杨氏） |
| 军事 | 私兵、部曲，中央衰弱时转化为割据力量 |

## 外戚与宦官的循环

和帝以后，**皇帝多幼年即位**，形成**外戚—宦官**交替专权的政局：

| 阶段 | 掌权者 |
|------|--------|
| 外戚 | 窦宪、邓骘、梁冀（梁冀尤专横，质帝被鸩） |
| 宦官 | 单超等「五侯」，桓灵之际宦官势盛 |
| 士人反弹 | **党锢之祸**：士大夫清议遭禁锢，前后两次 |

> **党锢之祸**是「士大夫集团」与「宦官集团」的正面冲突，使东汉的士人政治元气大伤。

## 衰亡（184—220）

- **黄巾之乱**（184）：以「太平道」为组织的全国性民变，虽被镇压，但**州郡武装化**不可逆。
- **州牧割据**：为平乱改刺史为州牧，地方军政合一，形成割据（袁绍、曹操、刘表等）。
- **220 年**：曹丕代汉，东汉亡，三国开局。
