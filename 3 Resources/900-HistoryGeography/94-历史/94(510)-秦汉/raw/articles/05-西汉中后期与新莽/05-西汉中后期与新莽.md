# 05 西汉中后期与新莽

## 昭宣中兴

武帝之后，昭帝、宣帝（前 87—前 49）**轻徭薄赋、整顿吏治**，恢复民生，史称「昭宣中兴」。宣帝「霸王道杂之」，被视为汉家治术最成熟的时代。

## 衰象：外戚、豪族与土地兼并

| 问题 | 说明 |
|------|------|
| **外戚专权** | 霍光（昭宣间）开其端，王氏（王政君一族）至成、哀、平三朝把持朝政 |
| **豪族坐大** | [[豪族-Gentry-Clans\|豪族]]兼并土地、垄断经学入仕通道，编户流失 |
| **土地兼并** | 失地农民沦为佃客、奴婢，社会矛盾累积 |
| **儒学经学化** | 经学与仕途绑定，谶纬涌入政治话语（[[谶纬-Chenwei\|谶纬]]，见 08 章） |

> 与武帝朝的「中央强势」相比，中后期是**皇权被外戚与豪族架空**的过程——这成为东汉政治的基本底色（[[06-东汉：豪族政治与帝国衰变|06 章]]）。

## 王莽篡汉与新朝（9—23）

外戚**王莽**以「安汉公」身份受禅代汉，建**新**朝。其**改制**托古：

- **王田制**：仿「井田」将土地收归国有、禁买卖。
- **私属**：奴婢改称「私属」，禁买卖。
- **五均六筦**：国家管制市场与工商。
- **改币、改官名、改地名**：屡变而扰民。

改革脱离实际、执行混乱，加之大兴对匈奴战争，终致绿林、赤眉起义。**昆阳之战**（23）新军大败，新朝覆亡。

## 评价的两说

- **复古倒退说**：王莽改制是违背历史趋势的托古倒车，注定失败。
- **理想主义改制说**：其方案针对的是真实的社会危机（兼并、奴婢），失败在于**手段与执行**，而非方向（现代学界多有此论）。

本库两说并列，不代裁。
