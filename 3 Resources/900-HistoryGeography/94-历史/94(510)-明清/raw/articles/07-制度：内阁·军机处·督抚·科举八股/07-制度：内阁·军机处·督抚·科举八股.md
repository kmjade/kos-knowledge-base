# 07 制度：内阁·军机处·督抚·科举八股

> 主题章：由废丞相到内阁、军机处，皇权空前集中；督抚之设与八股科举。

## 定义

明清制度以**皇权集中**为主线：明废丞相设**内阁**，清设**军机处**；地方行**督抚**制；选官以**科举八股**为准。

## 要点

| 制度 | 内容 |
|------|------|
| 内阁 | 明设，票拟拟旨 |
| 军机处 | 清设，跪受笔录 · 皇权附庸 |
| 督抚 | 总督 · 巡抚统辖省区 |
| 科举 | 八股取士 · 三级考试 |

## 要义

- **[[内阁制-Cabinet|内阁制]]**：票拟 — 批红，相权进一步削弱。
- **[[军机处-Grand-Council|军机处]]**：雍正设，军机大臣「跪受笔录」，皇权集中达到顶峰。
- **[[督抚制-Governor-General|督抚制]]**：承宋元行省，为清代地方最高长官。
- **[[八股文-Eight-Legged-Essay|八股文]]**：科举格式固化，牢笼士人，亦维系社会流动——**功过并存**。

## 争议 ⚠️

- 八股取士的**功过**、军机处的**集权效应**，评价分歧。
