# 03 明中后期：内阁·宦官·一条鞭法

> 内阁与司礼监共理政务、宦官干政，张居正推行一条鞭法——明代中后期的政治与经济改革。

## 定义

**明中后期**（约 1435—1644）指仁宣之后至明亡。政治上有**内阁**与**宦官**（司礼监 · 东厂 · 西厂）之消长；经济上有**一条鞭法**等赋役改革；社会上市镇与白银经济繁荣。

## 要点

| 面向 | 内容 |
|------|------|
| 内阁 | 大学士票拟，渐成宰辅 |
| 宦官 | 司礼监批红 · 厂卫 |
| 改革 | [[一条鞭法-Single-Whip\|一条鞭法]]（张居正） |
| 经济 | 白银货币化 · 市镇 |
| 党争 | 东林党与阉党 |

## 要义

- **内阁制**：废丞相后设内阁，票拟 — 批红的双轨运作（见 [[内阁制-Cabinet|内阁制]]）。
- **宦官干政**：司礼监掌批红、厂卫侦缉，为明代政治痼疾。
- **一条鞭法**：[[张居正-Zhang-Juzheng|张居正]]推行，赋役合并、折银征收（见 [[一条鞭法-Single-Whip|一条鞭法]]）。
- **东林党争**：士人结社议政与阉党倾轧，政局糜烂。

## 争议 ⚠️

- 「资本主义萌芽」等提法为**后世框架**（约定 ≠ 事实），其适用性有争议。
