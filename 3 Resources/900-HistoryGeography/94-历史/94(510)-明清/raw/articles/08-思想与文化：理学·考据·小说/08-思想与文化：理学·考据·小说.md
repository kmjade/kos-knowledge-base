# 08 思想与文化：理学·考据·小说

> 主题章：心学的兴起与批判、清代考据学的兴盛、小说戏曲的繁荣与西学东渐。

## 定义

明清思想文化由**理学官方化**、**心学**兴起、**考据学**（朴学）兴盛、**小说戏曲**繁荣与**西学东渐**构成。

## 要点

| 面向 | 内容 |
|------|------|
| 心学 | 王阳明「致良知」「知行合一」 |
| 批判 | 李贽 · 黄宗羲 · 顾炎武 |
| 考据 | 乾嘉朴学 · 训诂考据 |
| 文学 | 《三国》《水浒》《西游》《红楼》 |
| 西学 | 利玛窦 · 徐光启 · 历算 |

## 要义

- **[[王阳明-Wang-Yangming|心学]]**：由程朱理学转向内在「心即理」，强调主体与践行。
- **[[考据学-Evidential-Scholarship|考据学]]**：[[顾炎武-Gu-Yanwu|顾炎武]]开山，乾嘉学者以训诂考据整理典籍。
- **小说戏曲**：四大名著与《牡丹亭》等，标志市民文学的成熟。
- **西学东渐**：利玛窦、徐光启译《几何原本》，中西知识初会。

## 争议 ⚠️

- 心学与考据学的**流弊**（空疏 / 琐碎）评价分歧。
