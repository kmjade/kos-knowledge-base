# 摊丁入亩 Tan-Ding-Ru-Mu

## 定义

**摊丁入亩**是清雍正年间推行的赋役改革：将历代相沿的**丁银**（人头税）摊入田赋，按亩征收，取消独立人头税。

## 要点

| 面向 | 内容 |
|------|------|
| 推行 | 雍正 |
| 内容 | 丁银并入田赋 |
| 依据 | 田亩 |
| 意义 | 废人头税 · 人口统计松绑 |

## 要义

- 承明[[一条鞭法-Single-Whip|一条鞭法]]而来，**彻底取消人头税**。
- 减轻无地少地者负担，户口隐匿减少，人口统计激增。
- 是中国赋税史由**人丁**转向**土地**的完成。
