# 一条鞭法 Single-Whip

## 定义

**一条鞭法**是明代中后期推行的赋役改革：将田赋、徭役及杂税合并，折银征收，按亩分摊。

## 要点

| 面向 | 内容 |
|------|------|
| 推行 | 嘉靖试行，万历张居正推广 |
| 内容 | 赋役合并 · 折银 |
| 依据 | 田亩 |
| 意义 | 简化税制 · 促进白银货币化 |

## 要义

- 是明代赋役由**实物 · 力役**向**货币**转变的关键（见 [[张居正-Zhang-Juzheng|张居正]]）。
- 促进白银货币化与商品经济发展。
- 后续为清代[[摊丁入亩-Tan-Ding-Ru-Mu|摊丁入亩]]之先声。

## 争议 ⚠️

- 其**实际执行**程度与对农民的负担影响，学界有讨论。
