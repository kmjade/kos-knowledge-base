# 闭关锁国 Seclusion

## 定义

**闭关锁国**指明清两代限制乃至禁止对外贸易与交往的政策，如明海禁、清限口通商（广州一口）。

## 要点

| 面向 | 内容 |
|------|------|
| 明 | 海禁（时弛时禁） |
| 清 | 限口通商 · 广州十三行 |
| 目的 | 防倭 · 防内 · 控夷 |
| 后果 | 与世界潮流隔绝 |

## 要义

- 起于海防与秩序考量，**非**全然拒绝一切贸易。
- 在西方工业化与全球扩张之际，使中国错过交流与转型机遇。
- 其**功过**（防御之利 vs 封闭之弊）**两说并列**，本库不代裁。

## 争议 ⚠️

- 是否应称「闭关锁国」、其历史作用的评价，学界有修正意见。
