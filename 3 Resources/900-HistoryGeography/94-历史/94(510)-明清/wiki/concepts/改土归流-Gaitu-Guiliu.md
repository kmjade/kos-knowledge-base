# 改土归流 Gaitu-Guiliu

## 定义

**改土归流**指明清在西南等地区将世袭的**土司**制改为中央委派的**流官**制，以强化中央管理。

## 要点

| 面向 | 内容 |
|------|------|
| 时间 | 明 · 清（雍正规模最大） |
| 内容 | 废土司 · 设流官 |
| 区域 | 西南 · 湘黔 · 云南 |
| 目的 | 中央集权 |

## 要义

- 将此前「以夷治夷」的间接统治转为**直接治理**。
- 强化边疆整合，亦伴随冲突与镇压。
- 与[[督抚制-Governor-General|督抚制]]、[[行省制-Provincial-System|行省]]共同构成清代疆域治理体系。
