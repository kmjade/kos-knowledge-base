# 张居正 Zhang Juzheng

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1525—1582 |
| 身份 | 明代内阁首辅 · 改革家 |
| 关键 | 万历新政 · 一条鞭法 · 考成法 |
| 地位 | 明代最有权的首辅 |

## 要义

- 推行[[一条鞭法-Single-Whip|一条鞭法]]、考成法，整顿财政与吏治。
- 以**强有力**的首辅执政，短期成效显著。
- 身后被清算，改革多废——其**功过**学界多解。
