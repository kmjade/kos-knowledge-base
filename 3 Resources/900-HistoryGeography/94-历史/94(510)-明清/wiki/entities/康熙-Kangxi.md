# 康熙 Kangxi

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1654—1722 |
| 身份 | 清皇帝（清圣祖 · 玄烨） |
| 关键 | 平三藩 · 收台湾 · 御俄（尼布楚）· 平准噶尔 |
| 治世 | [[康乾盛世-High-Qing\|盛世]]之首 |

## 要义

- 平定内乱、统一台湾、遏制沙俄，奠定**疆域**基础。
- 崇尚文教、编修典籍，亦行**文字狱**。
- 是康熙盛世的缔造者，清代鼎盛的开端。
