# 朱元璋 Zhu Yuanzhang

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1328—1398 |
| 身份 | 明开国皇帝（明太祖 · 洪武） |
| 关键 | 建明（1368） · 废丞相 · 重典治吏 |
| 制度 | 废中书省 · 设锦衣卫 |

## 要义

- 起于布衣，逐元建明，重建汉族王朝。
- **废丞相**、六部直属皇帝，奠定皇权集中与[[内阁制-Cabinet|内阁制]]之前提。
- 严刑惩贪、屡兴大狱，**功过**两说并存。
