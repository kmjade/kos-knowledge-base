# 郑和 Zheng He

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1371—1433 |
| 身份 | 明代航海家 · 太监 |
| 关键 | 七下西洋（1405—1433） |
| 到达 | 东南亚 · 印度洋 · 东非 |

## 要义

- 率世界当时最庞大的船队七下西洋，远达东非。
- 其航海为**朝贡 · 宣威**性质，规模与技术领先欧洲大航海。
- 见[[郑和下西洋-Zheng-He-Voyages|郑和下西洋]]。
