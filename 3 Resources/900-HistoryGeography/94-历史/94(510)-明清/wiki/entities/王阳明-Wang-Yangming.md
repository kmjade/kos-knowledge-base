# 王阳明 Wang Yangming

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1472—1529 |
| 身份 | 明代哲学家 · 军事家 |
| 关键 | 心学集大成 · 致良知 · 知行合一 |
| 著作 | 《传习录》 |

## 要义

- 提出「**心即理**」「**致良知**」「**知行合一**」，由理学转向内在心性。
- 兼为名将（平宁王之乱），**事功与学问**兼擅。
- 其学（阳明学）影响东亚，为中国思想史一高峰。

## 争议 ⚠️

- 其后学**流弊**（空谈心性）评价分歧。
