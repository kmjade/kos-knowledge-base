# 乾隆 Qianlong

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1711—1799 |
| 身份 | 清皇帝（清高宗 · 弘历） |
| 关键 | 定新疆 · 修《四库全书》 |
| 治世 | [[康乾盛世-High-Qing\|盛世]]顶点 |

## 要义

- 平定准部回部、奠定新疆，疆域达于极盛。
- 主持修《四库全书》，亦大量**禁毁**「违碍」书籍。
- 晚年吏治腐败、闭关自守，**盛世之下已伏衰象**。
