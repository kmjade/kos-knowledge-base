## 三条主线

| 主线 | 内容 |
|------|------|
| **政治线** | 鸦片战争 → 自强 → 维新 → 革命 → 民国 → 抗战 → 建国 → 改革 |
| **制度线** | 帝制 → 共和 → 党治 → 现代国家建设 |
| **思想线** | 中体西用 → 启蒙 → 三民主义 → 马克思主义 → 现代化 |
