# 梁启超 Liang Qichao

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1873—1929 |
| 身份 | 维新派 · 启蒙思想家 · 学者 |
| 关键 | 变法 · 《新民说》· 报刊舆论 |

## 要义

- 以**报刊文章**启蒙一代，文风「笔锋常带感情」。
- 倡「新民」，主张国民精神的更新。
- 其思想随时代演变，是近代**启蒙**的代表人物。
