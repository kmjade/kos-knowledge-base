# 孙中山 Sun Yat-sen

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1866—1925 |
| 身份 | 民主革命先行者 · 中华民国缔造者 |
| 关键 | [[辛亥革命-Xinhai-Revolution\|辛亥革命]] · [[三民主义-Three-Principles\|三民主义]] |
| 著作 | 《建国方略》《三民主义》 |

## 要义

- 领导推翻帝制的革命，被尊为「**国父**」。
- 提出[[三民主义-Three-Principles|三民主义]]，晚年发展为新三民主义。
- 是近代中国**共和**道路的象征性人物。
