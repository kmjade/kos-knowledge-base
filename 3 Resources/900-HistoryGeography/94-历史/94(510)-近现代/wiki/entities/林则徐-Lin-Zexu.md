# 林则徐 Lin Zexu

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1785—1850 |
| 身份 | 清代政治家 · 禁烟大臣 |
| 关键 | 虎门销烟（1839） |
| 影响 | 鸦片战争导火索 |

## 要义

- 主张严禁鸦片，虎门销烟为[[鸦片战争-Opium-War|鸦片战争]]的直接导火索。
- 主张了解西方、「师敌之长技」，被视为**开眼看世界**之先驱。
- 其禁烟之**功过**在当时与后世均有不同评价。
