# 毛泽东 Mao Zedong

| 项 | 内容 |
|------|------|
| 生卒 | 1893—1976 |
| 身份 | 革命家 · 政治家 · 中华人民共和国主要缔造者 |

- 领导中国革命并缔造中华人民共和国。
- 其理论与实践对中国近当代影响深远。
- 其**历史评价**涉及并存史观，本库**多说并列**，不代采一说。
