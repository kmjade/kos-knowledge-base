# 鲁迅 Lu Xun

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1881—1936 |
| 身份 | 作家 · 思想家 · 新文化旗手 |
| 关键 | 《狂人日记》《阿Q正传》 |
| 意义 | 白话小说的奠基 |

## 要义

- 以《狂人日记》等奠定中国**现代白话小说**的基础。
- 以杂文**批判国民性**与旧礼教，是[[新文化运动-New-Culture-Movement|新文化运动]]的代表。
- 其文学与思想的**影响**深远而多面。
