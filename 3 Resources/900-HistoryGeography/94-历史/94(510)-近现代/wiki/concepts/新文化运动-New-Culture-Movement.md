# 新文化运动 New-Culture-Movement

## 定义

**新文化运动**（1915 起）是五四前后以《新青年》为阵地、倡民主与科学、反对旧礼教与文言文的思想解放运动。

## 要点

| 面向 | 内容 |
|------|------|
| 阵地 | 《新青年》 |
| 旗手 | 陈独秀 · 胡适 · [[鲁迅-Lu-Xun\|鲁迅]] |
| 口号 | 民主 · 科学 |
| 主张 | 白话文 · 反礼教 · 个性解放 |

## 要义

- 标志中国思想的**近代启蒙**高潮。
- 倡**白话文**，深刻改变文学与文化。
- 为[[五四运动-May-Fourth|五四运动]]与[[新民主主义-New-Democracy|马克思主义传播]]提供思想土壤。

## 争议 ⚠️

- 其**激进反传统**倾向的功过，学界与史观有讨论，本库不代裁。
