# 洋务运动 Self-Strengthening

## 定义

**洋务运动**（约 1860s—1890s）是清廷以「自强」「求富」为号、由洋务派主导的技术与军事近代化运动。

## 要点

| 面向 | 内容 |
|------|------|
| 口号 | 自强 · 求富 |
| 军工 | 江南制造局 · 福州船政 · 天津机器局 |
| 民用 | 轮船招商局 · 开平矿务 · 电报 |
| 教育 | 同文馆 · 派遣留美幼童 |
| 军事 | 北洋水师 |

## 要义

- 主张[[中体西用-Ti-Yong|中体西用]]，学器物而不变制度。
- 开启中国**工业化**与近代教育、外交的初步实践。
- 甲午战败标志其**破产**，催化[[维新变法-Hundred-Days-Reform|维新]]与革命。

## 争议 ⚠️

- 洋务运动的**成败**（彻底失败 vs 有限近代化之功）两说并列，本库不代裁。
