# 修昔底德 Thucydides

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约前 460 — 约前 400 |
| 身份 | 古希腊史学家 |
| 著作 | 《伯罗奔尼撒战争史》|
| 特征 | 批判史料 · 求真 |

## 要义

- 西方**批判史学**的先驱，以**严谨考订**与**政治分析**著称。
- 其「**修昔底德陷阱**」为后世**引申概念**（非其本人术语，约定 ≠ 事实）。
- 与 [[希罗多德-Herodotus|希罗多德]] 并称古典史学双璧。
