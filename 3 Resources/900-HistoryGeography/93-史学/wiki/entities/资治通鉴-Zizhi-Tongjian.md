# 资治通鉴 Zizhi Tongjian

## 核心规格

| 项 | 内容 |
|------|------|
| 成书 | 北宋（1084）|
| 主编 | 司马光 |
| 体例 | **编年体**通史 |
| 范围 | 战国至五代（前 403—959）|

## 要义

- 中国**编年体通史**的集大成之作，以「**资治**」为编纂宗旨。
- 与 [[史记-Shiji|《史记》]] 并为**编年**与**纪传**两大史体典范。
- 考异方法（《通鉴考异》）体现**史料批判**意识（→ [[03-史料学与考据|03]]）。
