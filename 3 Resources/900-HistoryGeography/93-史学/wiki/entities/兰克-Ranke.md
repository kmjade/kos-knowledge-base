# 兰克 Leopold von Ranke

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1795—1886 |
| 身份 | 德国史学家 |
| 主张 | 「如实直书」（wie es eigentlich gewesen）|
| 地位 | 近代**科学史学**奠基者 |

## 要义

- 倡导以**档案与原始史料**为基础的**史料批判**方法。
- 其「**如实直书**」与**客观主义**理想影响深远，亦受后世（相对主义）批评。
- 「近代史学之父」为**后世评价**（约定 ≠ 事实）。
