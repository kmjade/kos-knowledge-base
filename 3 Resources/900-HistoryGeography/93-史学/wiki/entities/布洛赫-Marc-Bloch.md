# 布洛赫 Marc Bloch

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 1886—1944 |
| 身份 | 法国史学家 |
| 贡献 | 年鉴学派**联合奠基者** |
| 著作 | 《历史学家的技艺》·《封建社会》|

## 要义

- 与费弗尔共创**年鉴学派**，主张**总体史**与**跨学科**方法。
- 强调**史料批判**与**比较方法**（→ [[02-历史方法论|02]]）。
- 二战中投身抵抗运动殉难，其**史学实践**与**人生**互为注脚。
