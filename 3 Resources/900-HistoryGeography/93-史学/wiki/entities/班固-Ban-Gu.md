# 班固 Ban Gu

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 32—92 |
| 身份 | 东汉史学家 · 文学家 |
| 著作 | 《汉书》（首部**纪传体断代史**）|
| 家族 | 班彪（父）· 班昭（妹）|

## 要义

- 首创**纪传体断代史**体例，为后世正史所沿（→ [[06-史书编纂与叙事|06]]）。
- 《汉书》十志（如《艺文志》《地理志》）为**专门史**之源。
- 与 [[史记-Shiji|《史记》]] 并称「**史汉**」。
