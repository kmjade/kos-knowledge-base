# 希罗多德 Herodotus

## 核心规格

| 项 | 内容 |
|------|------|
| 生卒 | 约前 484 — 约前 425 |
| 身份 | 古希腊史学家 |
| 著作 | 《历史》（希波战争史）|
| 称号 | 「历史之父」 |

## 要义

- 西方**叙事史**传统的奠基者，开创**调查 · 纪事 · 因果追溯**的写法。
- 博采传闻，其**史料可靠性**后世褒贬不一（两说并存）。
- 「历史之父」为**后世称号**（约定 ≠ 事实）。
