# 年鉴学派 Annales School

**年鉴学派**是 20 世纪法国**史学流派**，以**长时段**与**总体史**革新史学研究。

## 要点

| 面向 | 内容 |
|------|------|
| 主张 | 长时段（longue durée）· 总体史 |
| 方法 | 跨学科 · 结构分析 |
| 关注 | 地理 · 经济 · 心态史 |
| 代表 | 布洛赫 · 费弗尔 · 布罗代尔 |

## 争议

- **结构 vs 事件**的权重之争，两说并存。
- 长时段方法对**个体能动**的忽视，不代裁。
