# 历史分期 Historical Periodization

**历史分期**指按**时间框架**对历史进行的**人为划分**（如古代 / 中世纪 / 近代 / 现代）。

## 要点

| 面向 | 内容 |
|------|------|
| 性质 | 概念工具（人为约定）|
| 常见框架 | 三分 / 四分 · 断代 |
| 依据 | 政治 · 经济 · 文化 |
| 应用 | 断代史 · 通史 |

## 争议

- 分期是**概念工具**抑或**历史实体**？两说并存。
- 「中世纪」「近代早期」等**命名的立场性**（约定 ≠ 事实），不代裁。
