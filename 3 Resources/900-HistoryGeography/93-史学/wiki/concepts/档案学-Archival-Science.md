# 档案学 Archival Science

**档案学**（UDC `930.25`）研究档案的**收集、整理、保管与利用**。参照 `005.92` 档案管理（他类）。

## 要点

| 环节 | 内容 |
|------|------|
| 收集 | 接收 · 征集 |
| 鉴定 | 价值 · 期限 |
| 整理 | 分类 · 编目 |
| 保管 | 存藏 · 修复 |
| 利用 | 检索 · 开放 |

## 争议

- 档案的**完整性**（存毁 · 避讳 · 造伪）影响史料价值，须辨析。
- 档案**开放与隐私**的边界，两说并存。
