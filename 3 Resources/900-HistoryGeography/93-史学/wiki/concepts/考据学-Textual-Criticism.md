# 考据学 Textual Criticism

**考据学**研究**文本的校勘、辨伪、辑佚与训诂**，是史料学（[[史料学-Source-Criticism|史料学]]）的核心方法。

## 要点

| 工序 | 内容 |
|------|------|
| 校勘 | 版本对校 · 定本 |
| 辨伪 | 真伪 · 年代 · 作者 |
| 辑佚 | 佚文钩沉 |
| 训诂 | 字词释义 |

## 争议

- 辨伪的**尺度**（疑古 vs 信古）之争，不代裁。
- 出土文献对**传世定本**的冲击，两说并存。
