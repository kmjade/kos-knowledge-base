# 史料学 Source Criticism

**史料学**研究**史料的类型、价值与鉴别**（UDC `930.2` 书写资料 · 纪录和碑文的研究）。

## 要点

| 类型 | 内容 |
|------|------|
| 传世文献 | 正史 · 编年 · 政书 · 文集 |
| 出土文献 | 甲骨 · 金文 · 简帛 · 墓志 |
| 档案 | 公文 · 契约 · 簿册 |
| 非文字 | 器物 · 图像 · 遗址 |

## 争议

- 史料的**可靠性分层**（一手未必真、晚出未必伪），逐条判定。
- **孤证**能否立说，两说并存。
