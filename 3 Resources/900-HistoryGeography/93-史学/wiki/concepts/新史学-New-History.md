# 新史学 New History

**新史学**指 20 世纪以来**问题导向 · 跨学科**的史学取向，从「事件史」转向「结构史 / 总体史」。

## 要点

| 面向 | 内容 |
|------|------|
| 转向 | 事件史 → 结构史 / 总体史 |
| 方法 | 跨学科 · 问题导向 |
| 领域 | 社会史 · 经济史 · 心态史 |
| 关联 | 年鉴学派 |

## 争议

- 新史学的**碎片化**与整体史追求的张力，两说并存。
- **叙事复兴**（叙事史回归）之得失，不代裁。
