# 全球史 Global History

**全球史**指**超越国别框架**、以互动与整合为视角的史学取向。

## 要点

| 面向 | 内容 |
|------|------|
| 视角 | 跨区域互动 · 整合 |
| 对象 | 贸易 · 移民 · 观念传播 |
| 相关 | 文明史 · 世界史 |
| 立场 | 反欧洲中心 |

## 争议

- 全球史与**区域脉络**的张力，两说并存。
- **「中心」的转移**（多中心 vs 单一中心），不代裁。
