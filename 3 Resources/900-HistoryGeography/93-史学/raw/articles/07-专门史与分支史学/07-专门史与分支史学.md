# 07 专门史与分支史学

> 主题章（UDC `930.2` 历史从属学科）：按专题或方法分化出的史学分支。

## 定义

**历史从属学科**（`930.2`）指由史学与**他学科交叉**形成的专门史分支。

## 要点

| 分支 | 交叉学科 |
|------|----------|
| 经济史 | 经济学 |
| 社会史 | 社会学 |
| 文化史 | 文化研究 |
| 人口史 | 人口学 · 谱牒 |
| 环境史 | 生态学 |
| 计量史学 | 统计学 |

## 要义

- **专门史**以**问题导向**与**跨学科方法**为特征（→ [[06-史书编纂与叙事|06]]）。
- **[[新史学-New-History|新史学]]**：从「事件史」转向「结构史 / 总体史」。
- **[[全球史-Global-History|全球史]]**：超越国别框架的整合视角。
- 与 [[92-传记|92 传记]]（人口 / 谱牒）、[[91-地理学|91 地理]]（环境 / 区域）交叉。

## 争议 ⚠️

- 分支史学的**碎片化**与整体史追求的张力，两说并存。
- 跨学科**方法借用**的适用边界，不代裁。
