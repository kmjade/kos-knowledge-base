# 02 历史方法论

> 主题章（UDC `930.2` 历史方法论、历史从属学科）：研究方法与操作程序。

## 定义

**930.2 历史方法论、历史从属学科**，UDC「包括」：**书写资料 · 纪录和碑文的研究**。参照 `003.07` 书写用途与风格（他类）。

## 要点

| 步骤 | 内容 |
|------|------|
| 选题 | 问题意识 · 设问 |
| 搜集 | 史料检索 · 目录学 |
| 批判 | 外证（真伪）· 内证（内容）|
| 解释 | 因果 · 语境 · 比较 |
| 表述 | 叙事 · 论证 · 注释 |

## 要义

- **[[历史方法论-Historical-Method|历史方法论]]**：以**史料批判**（外证 + 内证）为核心。
- **[[考据学-Textual-Criticism|考据学]]**：文本校勘与辨伪的具体方法。
- **[[史料学-Source-Criticism|史料学]]**：方法论的史料基础（→ [[03-史料学与考据|03]]）。
- 量化方法（计量史学）与质性方法并行不悖（约定 ≠ 事实）。

## 争议 ⚠️

- **定量 vs 定性**方法的适用边界，两说并存。
- 史学方法的**他学科借用**（社会学 · 人类学）之得失，不代裁。
