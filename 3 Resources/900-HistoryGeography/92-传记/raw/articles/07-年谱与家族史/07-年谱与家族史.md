# 07 年谱与家族史

> 主题章：**年谱**（编年传记）与**家族史**（世系与家史）。

## 定义

**年谱**为**编年体传记**，逐年系事、考订生平的骨架；**家族史**则综合世系、婚配、迁徙与事迹，是谱牒学（[[03-谱牒学与家谱|03]]）的展开。

## 要点

| 体裁 | 特征 |
|------|------|
| 年谱 | 编年 · 逐年系事 · 考订 |
| 年表 | 简表 · 大事系年 |
| 家族史 | 世系 + 事迹 + 迁徙 |
| 家传 | 家族成员传记汇编 |

## 要义

- **[[年谱-Chronological-Biography|年谱]]**：为**考证生平**提供时间骨架。
- **[[口述史-Oral-History|口述史]]**：补文献之阙，但须防**记忆偏误**。
- 年谱须**逐年标注史料来源**（约定 ≠ 事实）。
- 家族史须与 [[族谱-Family-Register|族谱]] · [[谱牒学-Genealogy|谱牒学]] 互证。

## 争议 ⚠️

- **年谱考订**的异说并存（生卒与事迹系年），不代裁。
- 口述史与文献史料的**互证边界**，两说并存。
