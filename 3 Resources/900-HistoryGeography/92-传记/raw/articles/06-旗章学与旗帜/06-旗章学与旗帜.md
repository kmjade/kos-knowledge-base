# 06 旗章学与旗帜

> 主题章（UDC `929.9` 旗帜、标杆、横幅）：旗帜的研究与象征。

## 定义

**旗章学**（UDC `929.9` 旗帜、标杆、横幅）研究**旗帜**及其形制、沿革与象征。

## 要点

| 面向 | 内容 |
|------|------|
| 要素 | 底 · 图案 · 比例 · 配色 |
| 类型 | 国旗 · 军旗 · 族旗 · 信号旗 |
| 制度 | 颁定 · 修改 · 礼仪 |
| 相关 | 纹章 · 徽记 |

## 要义

- **[[旗章学-Vexillology|旗章学]]**：以**形制比较与沿革考订**为核心方法。
- 旗帜与纹章同属**非文本表示**，是身份与政权的**视觉标识**。
- 与 [[04-纹章学|04 纹章]] 伴生、互补。
- 代表物：[[黄龙旗-Yellow-Dragon-Flag|黄龙旗]] · [[五色旗-Five-Color-Flag|五色旗]]。

## 争议 ⚠️

- 旗帜**象征意义**的解读常含**后世附加**（约定 ≠ 事实）。
- 旗帜**首用/沿革**的考订常有异说，不代裁。
