# 02 传记类型与体裁

> 主题章：传记的**类型与体裁**——从史传、年谱到自传、评传。

## 定义

传记的**体裁**多样（UDC `929` 之下，形式侧参照 `(092)` / `82-9`）：其类型差异反映**叙事立场**与**史料基础**的不同。

## 要点

| 体裁 | 特征 |
|------|------|
| 史传 / 列传 | 正史体例 · 纪传 |
| 年谱 | 编年 · 逐年系事 |
| 行状 / 事略 | 丧葬背景 · 褒扬 |
| 自传 / 回忆录 | 第一人称 · 主观 |
| 评传 | 传 + 评 · 学术性 |

## 要义

- **[[年谱-Chronological-Biography|年谱]]**：编年体传记，考订生平的**骨架**。
- **[[传记辞典-Biographical-Dictionary|传记辞典]]**：群体性传记工具书。
- 形式复分（`(092)` · `82-9`）为他类**参照**，本库不建壳，仅在正文注明。
- 体裁的选择即**立场**的选择（约定 ≠ 事实）。

## 争议 ⚠️

- **自传 / 回忆录**的史料价值：亲历之利 vs 记忆之偏，两说并存。
- 正史列传的**褒贬体例**对史实的塑形，须辨析。
