# 传记方法论 Biographical Method

**传记方法论**指编写与研究传记所依循的**史料考订**与**语境重建**方法。

## 要点

| 步骤 | 内容 |
|------|------|
| 史料搜集 | 列传承记 · 年谱 · 行状 · 书信 |
| 考订 | 系年 · 辨伪 · 互证 |
| 语境重建 | 时代 · 制度 · 关系网 |
| 叙事 | 立场 · 体裁选择 |

## 争议

- **真实性**：史料还原抑或文学建构？两说并存。
- **个体能动 vs 时代结构**的权重之争，不代裁。
