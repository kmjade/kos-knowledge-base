# 旗章学 Vexillology

**旗章学**（UDC `929.9` 旗帜、标杆、横幅）研究**旗帜**及其形制、沿革与象征。

## 要点

| 面向 | 内容 |
|------|------|
| 要素 | 底 · 图案 · 比例 · 配色 |
| 类型 | 国旗 · 军旗 · 族旗 · 信号旗 |
| 方法 | 形制比较 · 沿革考订 |

## 争议

- **象征意义**解读常含后世附加（约定 ≠ 事实）。
- 旗帜**首用/沿革**的考订常有异说，不代裁。
