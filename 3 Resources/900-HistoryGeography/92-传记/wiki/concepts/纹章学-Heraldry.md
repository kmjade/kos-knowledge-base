# 纹章学 Heraldry

**纹章学**（UDC `929.6` 纹章）研究**盾徽与图记**及其制度。UDC「包括」：炫示 · 徽章 · 盾徽 · 奖牌和奖章 · 宪章 · 公文 · 证书。

## 要点

| 面向 | 内容 |
|------|------|
| 要素 | 盾面 · 图记 · 色彩 · 饰章 |
| 制度 | 授予 · 继承 · 登记 |
| 相关 | 印记学 · 钱币学（参照）|

## 争议

- 图记**传承与借用**的辨伪，个案裁量。
- **象征意义**解读含后世建构成分（约定 ≠ 事实）。
