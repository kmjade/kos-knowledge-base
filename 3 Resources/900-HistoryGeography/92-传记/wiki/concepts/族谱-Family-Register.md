# 族谱 Family Register

**族谱**（又称家谱）是中国谱牒传统的**主体文献**，记录家族世系、婚配与事迹。

## 要点

| 体例 | 内容 |
|------|------|
| 世系图 | 支派 · 代际 |
| 世系表 | 生卒 · 婚配 · 子女 |
| 家传 | 事迹 · 行状 |
| 附录 | 祠堂 · 族规 · 坟图 |

## 争议

- **攀附**与**层累**辨伪，个案裁量。
- 始迁祖与远祖记载的**可靠性**，两说并存。
