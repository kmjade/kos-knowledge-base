# 传记辞典 Biographical Dictionary

**传记辞典**是**群体性传记工具书**，按一定收录范围汇辑人物小传。

## 要点

| 面向 | 内容 |
|------|------|
| 体例 | 词条式短传 |
| 范围 | 国别 · 时代 · 行业 |
| 功能 | 检索入口 · 快速定位 |

## 争议

- **收录取舍**反映编纂立场，须辨析。
- 短传的**简要与失真**之权衡，两说并存。
