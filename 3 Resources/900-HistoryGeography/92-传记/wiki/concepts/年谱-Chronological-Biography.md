# 年谱 Chronological Biography

**年谱**是**编年体传记**，逐年系事，为考证生平提供**时间骨架**。

## 要点

| 体例 | 内容 |
|------|------|
| 编年 | 逐年系事 |
| 系事 | 事迹 · 交游 · 著述 |
| 考订 | 异说并列 · 标注来源 |

## 争议

- **生卒与事迹系年**的异说并存，不代裁。
- 年谱的**取舍标准**反映编者立场，须辨析。
