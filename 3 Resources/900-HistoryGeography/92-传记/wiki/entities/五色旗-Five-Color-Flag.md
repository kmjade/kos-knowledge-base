# 五色旗 Five-Color Flag

## 核心规格

| 项 | 内容 |
|------|------|
| 类别 | 旗帜（`929.9`）|
| 形制 | 红黄蓝白黑 · 横条 |
| 关联 | 中华民国北洋时期国旗 |

## 要义

- 五色**对应五族共和**之说（红汉 · 黄满 · 蓝蒙 · 白回 · 黑藏），为**象征约定**，非史实本体（约定 ≠ 事实）。
- 其**配色寓意**解读含后世附加，两说并存。
- 与 [[旗章学-Vexillology|旗章学]] · [[黄龙旗-Yellow-Dragon-Flag|黄龙旗]] 关联。
