# 知识组织与大模型

> **概念** — 知识组织与大模型

## 定义

传统知识组织依赖**人工设计的分类体系**（UDC、DDC 等），而 LLM 提供了一种**语义驱动的组织方式**：

## 关键特征

- 输入笔记内容 → LLM 推荐 UDC 类号和标签
- 实现笔记的自动归类
- 自然语言查询，而非关键词精确匹配
- 跨语言检索（中文问，英文答案）
- 从长文档中提取关键概念
- 自动生成笔记摘要
- 识别不同笔记之间的潜在关联
- 推荐双向链接
- 基于 Wiki 内容的问答
- RAG（检索增强生成）实现
- **个人知识图谱** — 将笔记转化为 RDF 三元组
- **Agent 辅助研究** — LLM Agent 自动搜集、整理、关联知识
- **动态分类** — LLM 根据知识演化自动调整分类结构
