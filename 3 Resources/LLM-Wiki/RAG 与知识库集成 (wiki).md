# RAG 与知识库集成

> **概念** — RAG 与知识库集成

## 定义

RAG（Retrieval-Augmented Generation）是将信息检索与 LLM 生成相结合的技术范式：

## 关键特征

- **知识截断** — 不受 LLM 训练数据截止日期的限制
- **可溯源** — 回答可引用具体笔记
- **成本低** — 不需要重新训练/微调模型
- **易更新** — 新增笔记即刻可用
