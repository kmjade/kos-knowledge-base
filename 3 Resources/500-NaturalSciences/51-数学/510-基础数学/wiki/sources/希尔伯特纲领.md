# 希尔伯特纲领 Hilbert's Program

## 概述

希尔伯特在 **1920 年代**提出的数学基础方案（**计划**/纲领）：把全部数学**形式化**为形式系统，再用**有穷方法**（finitary，构造性、不加无穷假设）证明其**一致性**，从而为数学提供「绝对可靠」的担保。

## 关键节点

| 年份 | 事件 |
|:--|:--|
| 1899 | 《几何基础》—— 公理化与模型化的样板 |
| 1900 | 巴黎演讲 **23 问题**（第 2 问：算术一致性） |
| 1920s | 提出**证明论**（Beweistheorie）作为实现工具 |
| 1928 | 波隆那演讲（与阿克曼）提出**判定问题** Entscheidungsproblem |
| 1930 | 柯尼斯堡演讲：「我们必须知道，我们必将知道」 |
| 1934/1939 | Hilbert & Bernays《数学基础》*Grundlagen der Mathematik* |

## 结局

- **1931** [[哥德尔不完备定理-Gödel-Incompleteness|哥德尔不完备定理]]：**第二定理**指出足够强的一致系统不能在自身内证明其一致性 → **纲领的原初形式受挫**。
- **1936** 根岑以**超限归纳**（至 $\varepsilon_0$）证明算术一致 —— 需**超出**纯有穷手段，故属纲领的**修正版**。
- 判定问题亦被**丘奇-图灵**（1936）证明**不可判定**。
