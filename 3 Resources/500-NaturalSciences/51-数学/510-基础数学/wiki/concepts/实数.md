# 实数 Real Numbers

> **UDC 510**（基础数学）— 实数 ℝ：**有理数 ∪ 无理数** —— [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 之塔的**第四层**，也是**第一个完备**的数系（**完备有序域**）。
> 归属：[[510-基础数学|510 基础数学]]。下层：[[51-数学/510-基础数学/wiki/concepts/有理数|有理数]]；补「洞」来源：[[51-数学/510-基础数学/wiki/concepts/无理数|无理数]]。

---

## 一、定义与构造

- **定义**：$\mathbb R=\mathbb Q\cup(\text{无理数})$；等价地，ℝ = ℚ 的**完备化**。
- **构造**：**戴德金分割**（ℚ 的分割）/ **柯西列**（等价类）。

## 二、公理化刻画

> ℝ 是**唯一**的 **完备有序域**（同构意义）。

即：有序域 ＋ **完备性**（柯西列收敛 / 上确界存在）。

## 三、完备性（多种**等价**表述）

| 表述 | 内容 |
|:--|:--|
| **确界原理** | 有上界的非空子集有**上确界** |
| **柯西准则** | 柯西列**收敛** |
| 单调有界 | 单调有界数列收敛 |
| 区间套 | 闭区间套有唯一公共点 |
| 有限覆盖（Heine–Borel） | 闭区间**紧** |
| 致密性（Bolzano–Weierstrass） | 有界列有收敛子列 |

> 在「有序域」上这六条**互相等价**，皆刻画「完备」—— 是分析定理的公共根。

## 四、结构

| 性质 | 内容 |
|:--|:--|
| **完备有序域** | **唯一**（同构）· **阿基米德** |
| **不可数** ⭐ | 基数 $\mathfrak c=2^{\aleph_0}>\aleph_0$（康托尔） |
| 序完备 · 连通 | 有界集有确界；数轴**连续无空隙** |
| **非代数闭** | $x^2+1=0$ 无解 → 须 ℂ |
| $\mathbb R^n$ | 点集拓扑与分析（多元微积分）的舞台 |

## 五、案例

| 例 | 内容 |
|:--|:--|
| **$\sqrt2$ 的存在** | 集 $\{x\in\mathbb Q:x^2<2\}$ 的**上确界** $=\sqrt2$（确界原理补「洞」） |
| **阿基米德性** | $\forall x>0,\ \exists n\in\mathbb N:\ n>x$ |
| **不可数** | 对角线法：$[0,1]$ 与 ℝ 等势，皆 $\mathfrak c$ |
| **实数 = 数轴** | 实数与数轴上的点**一一对应**（连续统） |

## 六、意义

- **完备性 ⇒ 极限存在** ⇒ 微积分/分析的**地基**（[[517-数学分析|517 数学分析]]）。
- 「**算术 → 分析**」的转折：完备化 ℚ → ℝ（见 [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 三转折点）。
