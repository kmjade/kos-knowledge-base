# 有理数 Rational Numbers

> **UDC 510**（基础数学）— 有理数 ℚ：两个整数之比 $\frac ab$ —— [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 之塔的**第三层**，补上**除法封闭**。
> 归属：[[510-基础数学|510 基础数学]]。下层：[[51-数学/510-基础数学/wiki/concepts/整数|整数]]。

---

## 一、定义与集合论构造

- **定义**：$\mathbb Q=\left\{\dfrac ab : a\in\mathbb Z,\ b\in\mathbb Z\setminus\{0\}\right\}$。
- **构造**：$\mathbb Q=\big(\mathbb Z\times(\mathbb Z\setminus\{0\})\big)/\sim$，$(a,b)\sim(c,d)\iff ad=bc$。

## 二、引入动机

- ℤ 中**除法不封闭**（$a\div b$ 不总在 ℤ）→ 扩张得 ℚ，使**除法封闭**（$b\neq0$）。

## 三、代数结构

| 性质 | 内容 |
|:--|:--|
| **域** | 加 · 减 · 乘 · 除（非零）**皆封闭**；特征 **0** |
| **有序域** | 可比较大小，且序与运算**相容** |
| **稠密** | 任意两有理数之间**仍有有理数** |
| **可数** | ℚ 与 ℕ **等势**（$\aleph_0$） |
| **不完备** ⚠️ | 数轴上有「**洞**」（如 $\sqrt2$）→ 须 ℝ |

## 四、表示与判据

- **分数** $\frac ab$（最简）· **小数** · **百分数**。
- **判据**：有理数 ⟺ **有限小数** 或 **无限循环小数**。

## 五、案例

| 例 | 内容 |
|:--|:--|
| **$\sqrt2\notin\mathbb Q$** | 反证 $p^2=2q^2$ → $p,q$ 同为偶，矛盾 |
| **稠密性** | $a<b$ 皆有理 ⇒ 中项 $\dfrac{a+b}{2}$ 亦有理 |
| **可数枚举** | ℕ ↔ ℚ 对角线枚举 → 基数 $\aleph_0$ |
| **$\frac13=0.333\dots$** | 无限**循环**小数（有理特征） |

## 六、完备化

- ℚ **不完备** → 补「洞」得 ℝ（**戴德金分割** / **柯西列**）→ [[51-数学/510-基础数学/wiki/concepts/数系|数系]]。
