# 整数 Integers

> **UDC 510**（基础数学）— 整数 ℤ：自然数 ＋ 其相反数 ＋ 0 $=\dots,-2,-1,0,1,2,\dots$ —— [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 之塔的**第二层**，补上**减法封闭**。
> 归属：[[510-基础数学|510 基础数学]]。下层：[[51-数学/510-基础数学/wiki/concepts/自然数|自然数]]。

---

## 一、定义与集合论构造

- **定义**：$\mathbb Z=\mathbb N\cup(-\mathbb N)=\{\dots,-2,-1,0,1,2,\dots\}$。
- **集合论构造**：$\mathbb Z=(\mathbb N\times\mathbb N)/\sim$，其中 $(a,b)\sim(c,d)\iff a+d=b+c$；$[(a,b)]$ 记作 $a-b$。

## 二、引入动机

- ℕ 中**减法不封闭**（$a-b$ 可能得负）→ 扩张得 ℤ，使**减法封闭**。

## 三、代数结构

| 性质 | 内容 |
|:--|:--|
| **整环** | 交换环 + 单位元 + **无零因子**（$ab=0\Rightarrow a=0$ 或 $b=0$）；加法有逆元 $-a$ |
| **欧几里得整环 / UFD** | 带余除法 → **唯一分解**（素数分解） |
| **全序** | 可比较大小；但**非良序**（无最小元，与 ℕ 不同） |
| **可数** | ℤ 与 ℕ **等势**（$\aleph_0$） |
| **离散** | 相邻整数间无别的整数 |

## 四、与相邻数系

- 加 · 减 · 乘**封闭**；**除不封闭**（$a\div b$ 不总在 ℤ）→ 引出 $\mathbb Q$（[[51-数学/510-基础数学/wiki/concepts/数系|数系]]）。
- ℤ 是 ℚ 的「**整数环**」；**素数 · 整除 · 同余**的研究即 [[511-数论|511 数论]]。

## 五、案例

| 例 | 内容 |
|:--|:--|
| **带余除法** | $\forall a\in\mathbb Z,\ b>0$：$a=bq+r$，$0\le r<b$（$q,r$ 唯一） |
| **裴蜀定理（Bézout）** | $\gcd(a,b)=ax+by$ 有**整数解** $x,y$ |
| **奇偶** | $\mathbb Z=2\mathbb Z\ \sqcup\ (2\mathbb Z+1)$（偶 ∪ 奇） |
| **无最小元** | $\{0,-1,-2,\dots\}$ 在 ℤ 中无最小元 → 须竖「良序」于 ℕ |
