# 自然数 Natural Numbers

> **UDC 510**（基础数学）— 自然数 ℕ：**计数的数** $0,1,2,\dots$ —— [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 之塔的**基座**，一切算术与数学的起点。
> 归属：[[510-基础数学|510 基础数学]]。

---

## 一、两种口径

| 记法 | 含 0 ？ | 用途 |
|:--|:--:|:--|
| $\mathbb N=\{0,1,2,\dots\}$ | **含** | 现代通行（本文从之） |
| $\mathbb N^*=\mathbb N^+=\{1,2,3,\dots\}$ | 不含 | 部分教材 |

## 二、公理化（皮亚诺公理）

五条公理 —— 0 · 后继 · 0 非后继 · 后继单射 · **归纳** → 详见 [[51-数学/510-基础数学/wiki/concepts/皮亚诺公理|皮亚诺公理]]。

- 加法 / 乘法**递归定义** → 推出全部算术律（交换 · 结合 · 分配）。

## 三、结构与性质

| 性质 | 内容 |
|:--|:--|
| **良序** | 任何非空子集有**最小元** |
| **归纳原理** | ↔ [[51-数学/510-基础数学/wiki/concepts/数学归纳法\|数学归纳法]] ↔ 良序 |
| **半环** | 加 · 乘**封闭**；**无加法逆**（$a-b$ 不总在 ℕ → 需 ℤ） |
| **无穷** | **无最大元**；每数有后继；**可数** |

## 四、基数

- ℕ **可数**：基数 $\aleph_0$（**最小的无穷基数**）。
- ℤ · ℚ · 代数数均与 ℕ **等势**（皆 $\aleph_0$）→ 见 [[康托尔对角线法|康托尔对角线法]]。

## 五、集合论构造

- **冯·诺依曼序数**：$0=\varnothing$，$S(n)=n\cup\{n\}$ → ℕ 在 [[策梅洛-弗兰克尔集合论-ZFC|ZFC]] 中被构造。

## 六、扩张动机

- ℕ 的两处「不封闭」—— **减法 → ℤ**、「除法 → ℚ」—— 正是 [[51-数学/510-基础数学/wiki/concepts/数系|数系]] 扩张链的起点。

## 七、案例

| 例 | 内容 |
|:--|:--|
| **良序 vs ℤ** | ℕ 的非空子集 $\{n^2:n\ge2\}=\{4,9,16,\dots\}$ 有**最小元 4**；而 ℤ 的 $\{0,-1,-2,\dots\}$ **无最小元** |
| **等势（可数）** | ℕ ↔ ℤ 一一对应：$0,1,-1,2,-2,\dots$；ℕ 与 ℚ 亦可枚举 → 皆 $\aleph_0$ |
| **冯·诺依曼序数** | $0=\varnothing$，$1=\{\varnothing\}$，$2=\{0,1\}$，$3=\{0,1,2\}$，即 $n=\{0,\dots,n-1\}$ |
| **后继封闭** | $S(0)=1,\ S(1)=2,\dots$；**无最大元**（对比有限集） |
