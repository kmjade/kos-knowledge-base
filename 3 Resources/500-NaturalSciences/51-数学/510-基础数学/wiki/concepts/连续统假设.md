# 连续统假设 Continuum Hypothesis (CH)

## 陈述

实数集（连续统）的基数 $\mathfrak{c}=2^{\aleph_0}$，是否等于**最小的不可数基数** $\aleph_1$？

$$\text{CH}:\quad 2^{\aleph_0}=\aleph_1$$

即在 $\aleph_0$ 与 $2^{\aleph_0}$ 之间**不存在**其他基数。

## 史实

| 时间 | 事件 |
|:--|:--|
| 1878 | 康托尔首次陈述连续统问题 |
| 1900 | 希尔伯特列为 **23 问题的第一问** |
| 1938/1940 | 哥德尔证 CH 与 ZFC **相容**（在可构成宇宙 $L$ 中成立）→ 不能**证伪** |
| 1963 | [[51-数学/510-基础数学/wiki/entities/科恩\|科恩]] 以 **forcing** 证 CH 与 ZFC **独立** → 也不能**证明** |

## 结论：独立，而非「对错」

- ZFC 存在满足 **CH** 的模型（哥德尔 $L$），也存在**否定 CH** 的模型（科恩强迫扩张）。
- 故 CH 是**公理的补充选择题**，而非可判定的真命题 —— 这正是[[00-数学基础危机|基础危机]]「工程式解决」的典型样本。

## 广义连续统假设（GCH）

$$\text{GCH}:\quad 2^{\aleph_\alpha}=\aleph_{\alpha+1}\ \ (\forall \alpha)$$

同样与 ZFC 独立（Gödel / Cohen）。
