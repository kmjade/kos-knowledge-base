# 康托尔对角线法 Cantor's Diagonal Argument

## 定义

对角线法是一种**反证式构造**：假设某集合可枚举，沿枚举表**对角线**构造一个「每处都与对应行相反」的对象，证明它不在表中，从而导出矛盾。

## 原始出处

康托尔 1891 年论文 *Über eine elementare Frage der Mannigfaltigkeitslehre* 用它证明**实数不可数**（1874 年他先用**区间套**证过一次，对角线法是更「初等」的重证）。

## 一处方法，四处复用

| 用途 | 结果 | 年份 |
|:--|:--|:--|
| 实数不可数 | $|\mathbb{R}| > |\mathbb{N}|$ | 1891 |
| 康托尔定理 | $|2^{S}| > |S|$（幂集严格大） | 1891 |
| 罗素悖论 | $R=\{x\mid x\notin x\}$ 的自指结构 | 1901 |
| 哥德尔不完备 | 「本命题不可证」的自指构造 | 1931 |
| 图灵停机问题 | 不可判定性 | 1936 |

> 四者共享同一技术内核：**自我指涉 + 反证**。

## 直观

```
        x1  x2  x3  …
第1行   1   0   1   …
第2行   0   0   1   …
第3行   1   1   0   …
对角反向: 0   1   1   …  ← 不在任何一行中
```
