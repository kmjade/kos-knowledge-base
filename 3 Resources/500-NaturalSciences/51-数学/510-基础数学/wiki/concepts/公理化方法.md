# 公理化方法 Axiomatic Method

## 定义

公理化方法指：选定一组**原始概念**（不加定义）与一组**公理**（不加证明），仅借助**演绎推理**推出全部定理，从而把一门数学**重建为演绎系统**。

## 历史

| 阶段 | 代表 | 年份 |
|:--|:--|:--|
| 原型 | 欧几里得《几何原本》 | 约前 300 |
| 算术公理化 | 皮亚诺算术 | 1889 |
| 几何再公理化 | 希尔伯特《几何基础》 | 1899 |
| 集合论公理化 | Zermelo 公理集 → ZFC | 1908 / 1922 |
| 元数学转向 | 希尔伯特纲领 | 1920s |

## 四要素与四元问题

| 要素 | 内容 |
|:--|:--|
| 原始概念 | 如「点 · 线」，或集合论的 $\in$ |
| 公理 | 如 ZFC 九条 |
| 推理规则 | 演绎（一阶逻辑） |
| 元问题 | 一致性 · 独立性 · 完备性 · 范畴性 |

| 元性质 | 含义 |
|:--|:--|
| **一致性** consistency | 系统不能推出矛盾 |
| **独立性** independence | 某公理不能由其余推出 |
| **完备性** completeness | 真命题皆可证 |
| **范畴性** categoricity | 同构意义下模型唯一 |

## 意义与边界

- 公理化把「数学是否牢固」**转化为可检验的元数学问题**（希尔伯特纲领）。
- 1931 [[51-数学/510-基础数学/wiki/concepts/哥德尔不完备定理|哥德尔不完备定理]]：足够强的一致系统**不完备**，且不能在系统内自证**一致性**。
- 1936 根岑以**超限归纳**（至 $\varepsilon_0$）证明皮亚诺算术一致 —— 一致性目标部分挽回，但越出了系统自身手段。
