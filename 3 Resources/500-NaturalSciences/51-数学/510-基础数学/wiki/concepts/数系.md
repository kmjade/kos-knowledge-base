# 数系 Number Systems

> **UDC 510**（基础数学）— **数系**：数的**层级体系**及其**扩张**。自 ℕ 起，每一步都由「**某运算不封闭 / 某方程无解**」逼出。
> 归属：[[510-基础数学|510 基础数学]]。跨库：[[2 Areas/学习/数据/课程/数学/初等数学/初等数学|初等数学（算术）]] · [[512-代数|512 代数]] · [[517-数学分析|517 数学分析]] · [[51-数学/51(091)-数学史/51(091)-数学史|51(091) 数学史]]（记数）。
> **本页为数系主题页（扩张主线）**；各子库的「数系链」表述**指回本页**。

## 一、扩张链

| 数系 | 符号 | 加入 | 补的**缺口**（动机） | 得到 / 代价 |
|:--|:--:|:--|:--|:--|
| 自然数 | ℕ | 1, 2, 3 … | **计数** | — |
| 整数 | ℤ | 0 与负数 | **减法**封闭（$a-b$ 不总在 ℕ） | — |
| 有理数 | ℚ | 分数 | **除法**封闭（$a\div b,\ b\neq0$） | — |
| 实数 | ℝ | 无理数 | **极限**闭合（ℚ **不完备**：$\sqrt2$、$\pi$） | **完备序域** |
| 复数 | ℂ | $i$ | **代数**封闭（$x^2+1=0$ 无实根） | **代数闭域**；丢**全序** |
| 四元数 | ℍ | $i,j,k$ | （乘法域之上的自然试步） | 丢**交换律** |
| 八元数 | 𝕆 | $e_0\dots e_7$ | — | 丢**结合律** |

## 二、扩张原理（一句话）

> **每一步扩张，都是「某个运算不再封闭」或「某个方程无解」逼出来的。**

- 减法 → ℤ；除法 → ℚ；极限（完备性）→ ℝ；代数方程 → ℂ。
- **到 ℂ 为止，再无可无损扩张的「域」**；继续扩张必**丢性质**。

## 三、三个转折点

| 转折 | 从 → 到 | 由 … 驱动 |
|:--|:--|:--|
| **算术 → 分析** | ℕ…ℚ → ℝ | **完备性**（柯西列收敛 / 确界原理） |
| **分析 → 代数** | ℝ → ℂ | **代数基本定理**（ℂ 代数闭） |
| **有序 → 结构** | ℂ → ℍ → 𝕆 | **Hurwitz 定理**：**赋范可除代数仅 ℝ · ℂ · ℍ · 𝕆**；性质**逐级丧失**：序 → 交换 → 结合 |

## 四、代数结构阶梯（塔的「骨架」）

| 数系 | 代数结构 | 序 | 关键性质 |
|:--|:--|:--|:--|
| ℕ | 交换**半环**（无加法逆） | **良序** | 归纳原理 |
| ℤ | **整环** · UFD | 全序 | 欧几里得除法 |
| ℚ | **有序域**（特征 0） | **稠密**全序 · 不完备 | 可数（ℵ₀） |
| ℝ | **完备有序域** | **完备**全序 | **唯一**（同构）· 不可数（𝔠） |
| ℂ | **代数闭域** | **不可序化** | 代数基本定理 |
| ℍ | **除环**（非交换） | — | 仍是赋范可除代数 |
| 𝕆 | **非结合**代数 | — | 赋范可除代数之末 |

> **结构升级链**：半环 → 环 → 整环 → 域 →（ℝ 完备化）→ ℂ 代数闭 → ℍ 除环 → 𝕆 非结合。**每加一层能力，就丢一个性质。**

## 五、集合论构造（基础口径）

| 数系 | 构造 |
|:--|:--|
| ℕ | **冯·诺依曼序数**：$\varnothing,\{\varnothing\},\{\varnothing,\{\varnothing\}\},\dots$ |
| ℤ | ℕ×ℕ 的等价类（差的商） |
| ℚ | ℤ×ℤ\* 的等价类（比的商） |
| ℝ | **戴德金分割** / **柯西列**（ℚ 的完备化） |
| ℂ | ℝ² + 乘法 $(a,b)(c,d)=(ac-bd,\,ad+bc)$ |

> 详见 [[510.3-集合论|510.3 集合论]]。**分层建造**：每层是下层的「商 / 完成 / 二次构造」。

## 六、关键定理（含证明骨架）

| 定理 | 内容 | 骨架 |
|:--|:--|:--|
| **$\sqrt2\notin\mathbb Q$** | ℚ 有「洞」 | 反证 $p^2=2q^2$ → $p,q$ 同为偶，矛盾 |
| **ℝ 唯一性** | 完备有序域在同构意义下**唯一** | 戴德金完成 ℚ 后，任何完备序域 ≅ ℝ |
| **代数基本定理** | ℂ 上每个非常数多项式有根 | 复分析（刘维尔）/ 拓扑（环绕数）/ 代数 |
| **Frobenius 定理**（1877） | ℝ 上有限维**可除代数**（结合）仅 ℝ · ℂ · ℍ | 考察极小多项式与共轭 |
| **Hurwitz 定理**（1898） | **赋范可除代数**仅 ℝ · ℂ · ℍ · 𝕆 | 平方和恒等式（1,2,4,8 维） |
| **Ostrowski 定理** | ℚ 的**完备化**仅 ℝ 与 ℚ_p | （见旁支） |

## 七、基数：可数与不可数

| | 基数 | 集 |
|:--|:--|:--|
| 可数 | $\aleph_0$ | ℕ · ℤ · ℚ · **代数数** |
| 不可数 | $\mathfrak c=2^{\aleph_0}$ | ℝ · ℂ · **超越数** |

> 𝔠 的存在由 **[[康托尔对角线法|康托尔对角线法]]** 证；$2^{\aleph_0}$ 是否为 $\aleph_1$ 即 **[[51-数学/510-基础数学/wiki/concepts/连续统假设|连续统假设]]**（与 ZFC 独立）。

## 八、扩张之外（旁支 · 不在这座「塔」上）

| 旁支 | 要点 |
|:--|:--|
| **有限域** $\mathbb F_p$ | 特征 $p$；现代密码 · 编码理论 |
| **p-adic 数** $\mathbb Q_p$ | ℚ 的**非阿基米德**完备化（Ostrowski）|
| **超实数** ${}^*\mathbb R$ | 非标准分析（Robinson, 1960）；无穷小严格化 |
| **超现实数** | Conway（1976）；含序数/实数的新域 |

> 这些**不嵌入** ℕ⊂…⊂ℂ 主干，是「旁枝」而非「上一层」。

## 九、常见误解

- **「0 是自然数吗？」** —— 依约定（ℕ vs ℕ⁺），两种记法并存。
- **「实数最多，复数更多？」** —— ℝ 与 ℂ **等势**（皆 𝔠）；ℂ 的「多」在**代数闭**而非基数。
- **「可以一直无损扩张？」** —— **不可**；ℂ 之后（ℍ/𝕆）必丢交换/结合。
- **「√2 是无理数所以不『存在』？」** —— 无理数是**实数的正常成员**；ℚ 的「洞」正是 ℝ 补上的。
