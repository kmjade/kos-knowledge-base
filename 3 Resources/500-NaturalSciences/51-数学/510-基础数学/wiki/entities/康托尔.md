# 康托尔 Cantor

格奥尔格·康托尔（Georg Cantor，**1845–1918**），德国数学家，生于圣彼得堡，逝于哈勒。**集合论**的创立者，无穷研究的奠基人。

## 核心贡献

| 年份 | 贡献 |
|:--|:--|
| 1874 | 证明**实数不可数**（区间套法） |
| 1878 | 提出**连续统假设**（CH） |
| 1891 | [[康托尔对角线法\|对角线法]]；康托尔定理 $2^S > S$ |
| 1870s–80s | 建立**基数** $\aleph_0,\aleph_1,\dots$ 与**序数**理论 |

## 意义与遭遇

- 把「**无穷有大小之分**」变成严格的数学：可数 $\aleph_0$ 与不可数 $\mathfrak{c}=2^{\aleph_0}$。
- 遭克罗内克等**构造主义**者强烈反对；晚年健康恶化。
- 其集合论正是 20 世纪初[[00-数学基础危机|基础危机]]的起点与震中。
