# 科恩 Cohen

保罗·科恩（Paul Cohen，**1934–2007**），美国数学家。以**力迫法**（forcing）解决希尔伯特第一问而闻名。

## 核心贡献

| 年份 | 贡献 |
|:--|:--|
| 1963 | 创立 **forcing**（力迫法），证明[[51-数学/510-基础数学/wiki/concepts/连续统假设\|连续统假设（CH）]]与 ZFC **独立** |
| 1963 | 证明[[51-数学/510-基础数学/wiki/concepts/选择公理\|AC]]与 ZF **独立** |
| 1966 | 获**菲尔兹奖** |

## 意义

- 哥德尔（1940）证 CH **相容**（不能证伪），科恩（1963）证 CH **独立**（不能证明）—— 二者合起来**闭合**了希尔伯特第一问：CH **不可判定**于 ZFC。
- forcing 成为集合论与模型论的核心技术，催生大量独立性与「大基数」研究。
