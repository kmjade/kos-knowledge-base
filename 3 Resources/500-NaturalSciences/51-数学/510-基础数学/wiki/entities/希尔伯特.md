# 希尔伯特 Hilbert

大卫·希尔伯特（David Hilbert，**1862–1943**），德国数学家，生于柯尼斯堡，逝于哥廷根。20 世纪初数学的领袖，**形式主义纲领**与**哥廷根学派**的代表。

## 核心贡献

| 年份 | 贡献 |
|:--|:--|
| 1899 | 《几何基础》—— 几何的公理化与模型化 |
| 1900 | 巴黎演讲提出 **23 个问题**（第 2 问：算术一致性） |
| 1920s | **希尔伯特纲领**：用有穷方法证明数学一致 |
| 1928 | 波隆那演讲（与阿克曼）提出**判定问题** Entscheidungsproblem |
| 1930 | 柯尼斯堡演讲：「**我们必须知道，我们必将知道**」 |

## 与危机

- 他主张以**形式系统**安放数学，用[[51-数学/510-基础数学/wiki/concepts/证明论|证明论]]证其一致。
- **1931** 哥德尔不完备定理使「以系统自身手段证一致性」落空（详见 [[51-数学/510-基础数学/wiki/concepts/哥德尔不完备定理|哥德尔不完备定理]]）。
- 希尔伯特本人于 1943 年逝于哥廷根，生前未及见纲领后来以修正形式部分挽回。
