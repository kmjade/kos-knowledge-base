# 561 系统古植物学

> **UDC 561** — 系统古植物学（Systematic palaeobotany）。
> 上级：[[3 Resources/500-NaturalSciences/56-古生物学/56-古生物学|56 古生物学]]。

## 定义与依据

权威表在 `582` 的范围注释中给出本类：**「系统古植物学见 `561`（仿 `582` 分）」**。

- **仿 `582` 分** —— 即**沿用 `582` 系统植物学的类目框架**（藻类 / 真菌 / 苔藓 / 蕨类 / 种子植物 / 裸子 / 被子…），只是把对象换成**化石植物**。
- 与 `56:581`（古植物学**总论**）相对：`561` 是**系统分类**一面，`56:581` 是**总论/一般**一面。
