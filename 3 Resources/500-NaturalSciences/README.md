- **形态**：集合节点式 —— 入口页 + `README` + `CLAUDE`(schema) + `raw/articles/` + `wiki/{concepts,entities,sources}/` + `wiki/index.md` + `wiki/log.md`
- **粒度**：类号级建「子库壳」；其下细类（`510.2` · `519.6` · `523.9` · `591.9` 等）建**笔记**（沿用 同类口径）

- **正名（R2 = A）**：既有 DDC 名子库正名为 UDC 名并收编至容器根（`raw/articles/510-Mathematics-数学/` → `51-数学/`，Obsidian link-aware，内容零重写）
