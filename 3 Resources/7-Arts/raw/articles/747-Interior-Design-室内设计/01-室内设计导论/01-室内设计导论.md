# 01 室内设计导论

## 什么是室内设计

室内设计（Interior Design）是对建筑内部空间的规划、设计与美化，兼顾**功能、美学、安全与心理**，涵盖空间、色彩、材料、照明、家具与陈设。

| 维度 | 内容 |
|------|------|
| 功能 | 空间布局、动线、收纳 |
| 美学 | 风格、色彩、比例、质感 |
| 技术 | 材料、照明、施工、规范 |
| 心理 | 舒适、归属、氛围 |

## 历史演进

| 时期 | 特征 |
|------|------|
| 古典 | 对称、装饰、柱式（希腊/罗马/巴洛克） |
| 现代主义 | 形式追随功能、去装饰（包豪斯） |
| 后现代 | 多元、折衷、符号化 |
| 当代 | 极简、生态、智能、个性化 |

## 主要风格流派

| 风格 | 特征 |
|------|------|
| 现代简约 | 少即是多、干净线条、中性色 |
| 北欧（Scandinavian） | 明亮、木材、功能、温暖 |
| 工业风 | 裸露砖墙、金属、混凝土 |
| 侘寂（Wabi-sabi） | 质朴、自然、不完美之美 |
| 新中式 | 传统元素现代化、对称、木作 |
| 极简（Minimalism） | 去冗、留白、克制的色彩 |

## 设计要素

| 要素 | 作用 |
|------|------|
| 空间 | 布局与尺度 |
| 线条 | 引导视线与风格 |
| 形态 | 家具与构件造型 |
| 色彩 | 情绪与氛围 |
| 质感 | 材料的触觉与视觉 |
| 光 | 塑造空间层次 |
