# 05 家具与人体工学

> 人体工学（Ergonomics）让家具与空间贴合人的尺度与行为，是舒适性的基础。

## 关键人体尺度

| 项目 | 常用尺寸 |
|------|---------|
| 坐高（座椅） | 400–450mm |
| 桌面高度 | 720–750mm |
| 餐桌高度 | 720–760mm |
| 床高 | 450–550mm |
| 台面（厨房） | 850–900mm |
| 挂衣高度 | 1400–1600mm |

## 家具尺度与净空

| 家具 | 建议 |
|------|------|
| 沙发 | 深度 800–900mm，前净空 ≥ 600mm |
| 衣柜 | 深 550–600mm，前净空 ≥ 900mm |
| 书桌 | 深 600mm，宽 ≥ 1200mm |
| 床头柜 | 高 ≈ 床垫高 |

## 家具风格

| 风格 | 特征 |
|------|------|
| 北欧 | 浅木色、圆润、功能 |
| 现代 | 简洁线条、金属/玻璃 |
| 中式 | 榫卯、深木、对称 |
| 工业 | 金属框架、皮革、粗犷 |
| 轻奢 | 大理石、黄铜、丝绒 |

## 人体工学原则

- 坐姿：双脚平放、膝盖 90°、腰有支撑
- 工作台：屏幕顶端与视线齐平
- 收纳：常用物品在「触手可及」高度（600–1500mm）
- 照明避免眩光直射屏幕
