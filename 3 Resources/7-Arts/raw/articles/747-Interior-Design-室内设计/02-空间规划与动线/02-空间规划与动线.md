# 02 空间规划与动线

> 空间规划是室内设计的基础——合理分区与流畅动线决定空间的可用性与舒适度。

## 功能分区

| 分区原则 | 说明 |
|------|------|
| 动静分区 | 活动区（客厅/餐厨）与静区（卧室/书房）分离 |
| 干湿分区 | 厨卫等湿区与起居干区隔离 |
| 公私分区 | 公共（玄关/客厅）与私密（卧室）过渡 |
| 洁污分区 | 清洁区与污染区（玄关/洗衣）分开 |

## 动线设计

| 动线 | 路径 | 要点 |
|------|------|------|
| 生活动线 | 起居-餐厨 | 短捷、无交叉 |
| 家务动线 | 洗衣-晾晒-收纳 | 高效省力 |
| 访客动线 | 玄关-客厅-卫生间 | 不穿私密区 |

> 理想动线：**少交叉、少迂回、尺度合理**（主要通道 ≥ 900mm）。

## 空间组织手法

| 手法 | 说明 |
|------|------|
| 开放式 | 打通墙体，空间通透（LDK 一体化） |
| 半开放 | 玻璃隔断、矮墙、屏风 |
| 灵活分隔 | 移门、折叠门、活动家具 |
| 视觉延伸 | 借景、镜面、通透材质 |

## 尺度参考

| 空间 | 常用尺寸 |
|------|---------|
| 主要通道 | ≥ 900mm |
| 次要通道 | ≥ 600mm |
| 餐桌边净空 | ≥ 700mm |
| 衣柜前净空 | ≥ 900mm |
