# 03 色彩与材料

## 色彩基础

| 属性 | 说明 |
|------|------|
| 色相（Hue） | 颜色种类（红/黄/蓝…） |
| 明度（Value） | 明暗程度 |
| 饱和度（Saturation） | 鲜艳程度 |

## 配色原则（60-30-10）

| 比例 | 角色 |
|:----:|------|
| 60% | 主色（墙/地面，奠定基调） |
| 30% | 辅色（家具/窗帘） |
| 10% | 点缀色（饰品/抱枕，制造焦点） |

## 色彩心理

| 色彩 | 心理感受 | 适用 |
|------|---------|------|
| 白 | 纯净、开阔 | 全空间 |
| 灰 | 克制、高级 | 现代/极简 |
| 蓝 | 冷静、专注 | 卧室/书房 |
| 绿 | 放松、自然 | 客厅/书房 |
| 暖黄 | 温馨、食欲 | 餐厅 |
| 深色 | 沉稳、戏剧性 | 点缀/背景墙 |

## 材料类别

| 类别 | 材料 | 特点 |
|------|------|------|
| 木材 | 橡木/胡桃/柚木 | 温暖、自然 |
| 石材 | 大理石/花岗岩/岩板 | 耐久、奢华 |
| 金属 | 不锈钢/黄铜/黑钢 | 工业、精致 |
| 玻璃 | 清玻/磨砂/夹丝 | 通透、轻盈 |
| 织物 | 棉/麻/丝/绒 | 柔软、温馨 |
| 人造板 | 密度板/多层板/颗粒板 | 经济、易加工 |
