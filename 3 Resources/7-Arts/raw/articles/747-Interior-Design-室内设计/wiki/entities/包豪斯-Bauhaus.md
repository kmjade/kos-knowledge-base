# 包豪斯 Bauhaus

1919 年创立于德国魏玛的设计学校与运动，主张「艺术与技术统一」「形式追随功能」，是现代主义设计（含室内与家具）的源头。

## 核心理念

| 理念 | 说明 |
|------|------|
| 形式追随功能 | 去除多余装饰 |
| 艺术与技术统一 | 手工艺 + 工业 |
| 简洁几何 | 方、圆、线构成 |

## 影响

影响了现代简约、北欧风格、极简主义，以及大量经典家具（巴塞罗那椅等）。
