# Revit

Autodesk 的 BIM（建筑信息模型）软件，以信息驱动设计，实现建筑与室内设计的协同与全生命周期管理。

## 核心特点

| 特点 | 说明 |
|------|------|
| BIM | 构件携带信息，一处改处处改 |
| 协同 | 多专业协同（建筑/结构/机电） |
| 出图 | 平立剖自动生成 |
| 统计 | 材料/家具清单自动提取 |
