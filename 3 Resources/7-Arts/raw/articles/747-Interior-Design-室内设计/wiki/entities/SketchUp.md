# SketchUp

室内设计常用的快速 3D 建模软件，以直观的推拉操作著称，适合概念方案与体块推敲。

## 核心特点

| 特点 | 说明 |
|------|------|
| 易上手 | 推拉式建模，学习曲线平缓 |
| 快速 | 快速表达空间体块 |
| 组件库 | 3D Warehouse 海量模型 |
| 插件 | V-Ray 等渲染扩展 |
