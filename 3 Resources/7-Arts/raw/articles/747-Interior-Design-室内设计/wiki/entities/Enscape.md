# Enscape

实时渲染引擎，作为插件嵌入 SketchUp / Revit / Rhino，提供即时的可视化与漫游体验。

## 核心特点

| 特点 | 说明 |
|------|------|
| 实时 | 所见即所得，改动即时呈现 |
| 漫游 | VR / 全景 / 视频 |
| 简单 | 无需复杂参数设置 |
| 集成 | 嵌入 SketchUp / Revit |
