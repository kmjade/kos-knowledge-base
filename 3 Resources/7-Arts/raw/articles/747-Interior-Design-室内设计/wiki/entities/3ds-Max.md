# 3ds Max

Autodesk 的专业三维建模与渲染软件，室内设计效果图的主流制作工具。

## 核心特点

| 特点 | 说明 |
|------|------|
| 建模 | 多边形建模能力强 |
| 渲染 | V-Ray / Corona 高质量渲染 |
| 材质 | 材质与贴图系统完善 |
| 适用 | 效果图、动画、可视化 |
