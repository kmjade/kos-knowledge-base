# 酷家乐 Kujiale

群核科技（原酷家乐）旗下的云设计 SaaS 平台，主打家居/室内设计的云端快速建模与实时渲染，以"拖拽式设计 + 云渲染"降低三维设计的门槛，广泛用于装修、定制家居与房地产行业。国际版品牌为 **Coohom**。

## 核心特点

| 特点 | 说明 |
|------|------|
| 云设计 | 浏览器即可建模，无需本地高性能硬件 |
| 云渲染 | GPU 云渲染，效果图出图快 |
| 户型库 | 海量户型模板与家具/材质模型库 |
| 实时/VR | 实时预览、全景图与 VR 漫游 |
| AI 能力 | AI 布局、智能灯光与风格推荐 |

## 定位对比

| 工具 | 定位 | 部署 |
|------|------|------|
| SketchUp | 通用快速建模 | 本地 |
| 3ds Max | 专业效果图渲染 | 本地 |
| 酷家乐 | 家居云设计一体化 | 云端（SaaS） |
