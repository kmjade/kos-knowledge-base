# 极简主义 Minimalism

## 定义

极简主义（Minimalism）室内设计追求「少即是多」（Less is more），去除多余装饰，以简洁线条、留白与克制的色彩营造纯净空间。

## 特征

| 特征 | 说明 |
|------|------|
| 留白 | 大量呼吸空间 |
| 中性色 | 白、灰、米、黑 |
| 简洁线条 | 无繁复装饰 |
| 功能至上 | 隐藏式收纳 |
| 质感 | 以材质对比替代装饰 |
