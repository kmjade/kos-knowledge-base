# 材料与质感 Materials & Texture

## 定义

材料与质感是室内空间的「肌肤」，通过不同材质的视觉与触觉特性，营造风格、温度与品质感。

## 材料类别

| 类别 | 代表 |
|------|------|
| 木材 | 橡木、胡桃木 |
| 石材 | 大理石、岩板 |
| 金属 | 不锈钢、黄铜 |
| 玻璃 | 清玻、磨砂 |
| 织物 | 棉、麻、丝、绒 |
| 人造板 | 密度板、颗粒板 |

## 搭配原则

软硬对比、冷暖平衡、粗细层次、呼应统一。
