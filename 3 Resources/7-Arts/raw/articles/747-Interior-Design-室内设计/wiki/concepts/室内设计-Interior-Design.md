# 室内设计 Interior Design

## 定义

室内设计是对建筑内部空间的规划、设计与美化，兼顾功能、美学、安全与心理，是建筑设计的内部延伸，涉及空间、色彩、材料、照明、家具与陈设六大要素。

## 核心要素

| 要素 | 说明 |
|------|------|
| 空间 | 布局、尺度、动线 |
| 色彩 | 情绪、氛围、风格 |
| 材料 | 质感、耐久、预算 |
| 照明 | 层次、功能、氛围 |
| 家具 | 人体工学、功能 |
| 陈设 | 软装、个性、艺术 |
