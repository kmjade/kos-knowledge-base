# 空间规划 Space Planning

## 定义

空间规划是按功能需求对室内空间进行分区与组织的过程，是室内设计的起点，决定空间的可用性、效率与舒适度。

## 核心内容

| 原则 | 说明 |
|------|------|
| 功能分区 | 动静、干湿、公私、洁污分离 |
| 动线组织 | 生活/家务/访客动线少交叉 |
| 尺度合理 | 通道、净空满足人体尺度 |
| 空间组织 | 开放/半开放/灵活分隔 |
