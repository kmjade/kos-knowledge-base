# 07 住宅空间

> 住宅是室内设计最核心的场景——围绕居住者的生活习惯，打造舒适、实用、有归属感的家。

## 各空间设计要点

| 空间 | 核心诉求 | 要点 |
|------|---------|------|
| 玄关 | 过渡、收纳 | 鞋柜、挂衣、换鞋凳 |
| 客厅 | 会客、休闲 | 动线、电视墙/投影、充足收纳 |
| 餐厅 | 用餐、交流 | 餐桌尺度、灯光、就近厨房 |
| 厨房 | 高效操作 | 动线「取-洗-切-炒」、台面高度 |
| 卧室 | 休息、私密 | 遮光、安静、衣柜、床头 |
| 卫生间 | 干湿分离 | 三分离/四分离、防滑、通风 |
| 书房 | 专注、工作 | 采光、书桌人体工学、收纳 |

## 小户型设计

| 手法 | 说明 |
|------|------|
| 一体化 | LDK 开放式，打通客厅/餐厅/厨房 |
| 收纳最大化 | 顶天立地柜、榻榻米、床下储物 |
| 多功能家具 | 折叠桌、沙发床、隐形床 |
| 视觉放大 | 浅色、镜面、通透隔断、低矮家具 |

## 收纳系统

| 收纳原则 | 说明 |
|------|------|
| 就近收纳 | 物品放在使用处附近 |
| 分类明确 | 衣物/杂物/工具分区 |
| 直立存放 | 衣物竖放易取 |
| 二八原则 | 20% 展示、80% 隐藏 |
