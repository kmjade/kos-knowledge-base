# 09 设计流程与工具

## 设计流程

```
1. 需求调研 → 2. 概念方案 → 3. 深化设计 → 4. 施工图 → 5. 落地跟进
```

| 阶段 | 产出 |
|------|------|
| 需求调研 | 量房、需求清单、风格意向 |
| 概念方案 | 平面布置、风格定位、意向图（mood board） |
| 深化设计 | 效果图、材料样板、照明方案 |
| 施工图 | 平面/立面/节点图、水电图、材料表 |
| 落地跟进 | 交底、验收、软装摆场 |

## 设计工具链

| 工具 | 用途 | 阶段 |
|------|------|------|
| AutoCAD | 施工图、平面图 | 深化/施工图 |
| SketchUp | 快速 3D 建模 | 概念/方案 |
| 3ds Max | 效果图渲染 | 深化 |
| Revit | BIM 信息建模 | 深化/施工 |
| Enscape / Lumion | 实时渲染 | 方案表达 |
| 酷家乐 Kujiale | 家居云设计一体化 | 概念/方案/出图 |
| Photoshop | 后期、意向图 | 全阶段 |

## 图纸体系

| 图纸 | 内容 |
|------|------|
| 原始结构图 | 承重墙、尺寸 |
| 平面布置图 | 家具布局、动线 |
| 天花布置图 | 吊顶、灯具 |
| 水电定位图 | 插座、开关、水路 |
| 立面图 | 墙面造型、柜体 |

## 设计要点

- 先功能后形式——平面布置是根本
- 材料样板需实物确认（屏幕色差）
- 施工图标注完整（尺寸、材料、工艺）
- 预留隐蔽工程验收（水电/防水）
