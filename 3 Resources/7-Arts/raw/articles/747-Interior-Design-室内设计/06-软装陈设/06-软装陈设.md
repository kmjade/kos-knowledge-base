# 06 软装陈设

> 软装（Soft Decoration）是空间「可移动」的部分——布艺、饰品、绿植与艺术，赋予空间个性与温度。

## 软装要素

| 要素 | 说明 |
|------|------|
| 布艺 | 窗帘、地毯、抱枕、床品 |
| 饰品 | 摆件、挂画、相框、花瓶 |
| 绿植 | 盆栽、干花、花艺 |
| 灯具 | 装饰灯、氛围灯 |
| 艺术品 | 画作、雕塑、装置 |

## 软装搭配原则

| 原则 | 说明 |
|------|------|
| 色彩呼应 | 软装色彩与主色调协调 |
| 材质对比 | 软硬、粗细、冷暖对比 |
| 高低错落 | 避免单一高度，制造层次 |
| 留白 | 不过度堆砌，保留呼吸感 |
| 主题统一 | 围绕风格主线选品 |

## 绿植与花艺

| 类型 | 特点 | 适用 |
|------|------|------|
| 大型盆栽 | 琴叶榕、龟背竹、天堂鸟 | 客厅角落 |
| 垂吊植物 | 绿萝、常春藤 | 高柜、窗边 |
| 桌面小盆栽 | 多肉、仙人掌 | 书桌、茶几 |
| 干花/永生花 | 免养护、持久 | 玄关、卧室 |

## 窗帘与地毯

| 类别 | 要点 |
|------|------|
| 窗帘 | 遮光/纱帘分层，高度顶天立地显高 |
| 地毯 | 界定区域（客厅/卧室），尺寸大于家具组合 |
