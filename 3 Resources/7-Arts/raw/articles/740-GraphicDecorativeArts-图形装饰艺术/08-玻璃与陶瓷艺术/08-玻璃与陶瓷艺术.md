# 08-玻璃与陶瓷艺术

> 火与土、火与砂的艺术——陶瓷与玻璃。

## 陶瓷

| 类型 | 特征 |
|------|------|
| 陶器 | 低温、多孔（瓦、砖） |
| 炻器 | 中温、致密 |
| 瓷器 | 高温、玻化（半透明） |

## 制瓷流程

```
选土 → 练泥 → 成型 → 干燥 → 上釉 → 烧制 → 成品
```

## 成型技法

| 技法 | 说明 |
|------|------|
| 手捏 | 最原始 |
| 泥条盘筑 | 盘绕成型 |
| 拉坯 | 转盘成型 |
| 注浆 | 模具成型 |

## 釉

- 釉料（石英、长石、金属氧化物）
- 青釉、白釉、青花、釉里红
- 窑变（不可控的美）

## 玻璃艺术

| 技法 | 说明 |
|------|------|
| 吹制 | 吹管成型 |
| 铸造 | 模具 |
| 热熔 | 玻璃熔合 |
| 灯工 | 火焰加工 |
| 镶嵌 | 彩色玻璃拼贴 |

## 名窑名瓷

- 景德镇（青花）、龙泉（青瓷）、汝窑、钧窑
- 玻璃：威尼斯、波西米亚
