# 06-纺织艺术

> 织、染、绣——纤维的艺术。

## 纺织技法

| 技法 | 说明 |
|------|------|
| 织 | 经纬交织（平纹、斜纹、缎纹） |
| 染 | 染色（扎染、蜡染、蓝染） |
| 绣 | 刺绣（平绣、十字绣、苏绣） |
| 编 | 编织、蕾丝 |

## 扎染与蜡染

| 技法 | 原理 |
|------|------|
| 扎染 | 扎紧防染 |
| 蜡染 | 蜡防染 |
| 蓝染 | 靛蓝发酵染色 |

## 刺绣

| 类型 | 特征 |
|------|------|
| 苏绣 | 精细、写实 |
| 湘绣 | 浓烈 |
| 蜀绣 | 针法丰富 |
| 十字绣 | 网格、简单 |

## 布艺

- 拼布 (Patchwork)、贴布
- 布偶、壁挂
- 绗缝 (Quilting)

## 材料

- 天然纤维：棉、麻、丝、毛
- 化学纤维：涤纶、锦纶
- 染料：植物染料、化学染料

## 现代纺织艺术

- 纤维艺术装置
- 可持续面料、再生纤维
- 智能纺织品（传感、温控）
