# 05-装饰图案

> 纹样与图案设计——装饰艺术的核心语言。

## 图案构成

| 方式 | 说明 |
|------|------|
| 单独纹样 | 独立图案 |
| 二方连续 | 上下或左右重复 |
| 四方连续 | 上下左右重复 |
| 适合纹样 | 填充特定形状 |

## 传统纹样

| 纹样 | 来源 |
|------|------|
| 云纹 | 中国 |
| 回纹 | 中国 |
| 缠枝纹 | 中西 |
| 阿拉伯纹样 | 伊斯兰 |
| 凯尔特结 | 欧洲 |

## 图案设计方法

- 对称、旋转、平移
- 变形、夸张、抽象
- 写实 → 简化 → 符号化

## 应用领域

- 纺织品（印花、提花）
- 陶瓷、玻璃、漆器
- 建筑装饰、壁纸
- 数字图案（壁纸、UI）

- 纹样承载文化符号

- 现代设计中的传统元素
