# 07-室内装饰

> 空间的美化——室内设计与软装。

## 室内设计要素

| 要素 | 说明 |
|------|------|
| 空间 | 功能分区 |
| 色彩 | 色调、氛围 |
| 光线 | 自然光、人工照明 |
| 材质 | 质感、触感 |
| 家具 | 功能、风格 |

## 设计风格

| 风格 | 特征 |
|------|------|
| 现代简约 | 简洁、留白 |
| 北欧 | 自然、明亮 |
| 工业风 | 裸露、金属 |
| 中式 | 木质、对称 |
| 日式 | 极简、原木 |
| 轻奢 | 精致、金属质感 |

## 软装

- 窗帘、地毯、靠垫
- 装饰画、绿植
- 灯具、摆件
- 色彩搭配（60-30-10 法则）

## 配色法则

- 60% 主色、30% 次要色、10% 点缀色
- 冷暖搭配、明暗层次
- 邻近色和谐、对比色活泼

## 空间照明

| 层次 | 用途 |
|------|------|
| 环境光 | 整体照明 |
| 任务光 | 阅读、工作 |
| 重点光 | 装饰、聚焦 |

## 收纳与动线

- 收纳空间规划
- 生活动线流畅
- 家具尺寸（人体工学）
