# 03-插画与漫画

> 用图像讲故事——插画、漫画与数字绘画。

## 插画类型

| 类型 | 应用 |
|------|------|
| 商业插画 | 广告、包装 |
| 书籍插画 | 绘本、封面 |
| 概念设计 | 游戏、影视 |
| 科普插画 | 教学、医学 |

## 漫画

| 元素 | 说明 |
|------|------|
| 分镜 | 画面安排、节奏 |
| 对话框 | 对白、旁白 |
| 拟声词 | 音效表现 |
| 速度线 | 运动感 |
| 网点/阴影 | 层次、质感 |

## 漫画类型

- 单幅漫画、四格漫画、连环漫画
- 日式漫画（Manga）、美式漫画（Comic）、欧式（Bande dessinée）

## 数字绘画

| 工具 | 说明 |
|------|------|
| 数位板 | 手绘输入 |
| 绘图软件 | Photoshop、Procreate、Clip Studio |
| 笔刷 | 模拟传统媒介 |
| 图层 | 分层绘制 |

## 创作流程

```
构思 → 草图 → 线稿 → 上色 → 后期 → 成稿
```
