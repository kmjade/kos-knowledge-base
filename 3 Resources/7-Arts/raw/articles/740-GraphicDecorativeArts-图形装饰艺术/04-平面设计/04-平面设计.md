# 04-平面设计

> 视觉传达的设计——字体、排版与版式。

## 设计四原则

| 原则 | 说明 |
|------|------|
| 对比 | 突出差异 |
| 重复 | 统一、节奏 |
| 对齐 | 秩序 |
| 亲密性 | 分组、关系 |

## 字体设计

| 类型 | 特征 |
|------|------|
| 衬线体 | 传统、正式（宋体、Times） |
| 无衬线体 | 现代、简洁（黑体、Helvetica） |
| 手写体 | 个性 |
| 装饰体 | 特殊用途 |

## 排版

- 字距、行距、字重
- 层级（标题 → 副标题 → 正文）
- 网格系统

## 版式设计

- 海报、名片、传单
- 品牌 VI（Logo、色彩、字体）
- 包装设计

## 设计工具

| 工具 | 用途 |
|------|------|
| Photoshop | 图像处理 |
| Illustrator | 矢量图形 |
| InDesign | 排版 |
| Figma | UI/协作 |
| Canva | 快速设计 |

## 设计思维

- 需求 → 调研 → 创意 → 草图 → 制作 → 反馈
- 用户体验（UX）、可用性
