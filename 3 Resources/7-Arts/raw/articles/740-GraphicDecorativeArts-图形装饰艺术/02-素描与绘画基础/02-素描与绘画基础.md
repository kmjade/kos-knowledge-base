# 02-素描与绘画基础

> 一切造型艺术的基础——线条、明暗与透视。

## 素描基础

| 要素 | 说明 |
|------|------|
| 线条 | 轮廓、排线 |
| 明暗 | 五大调子（高光、灰面、明暗交界、反光、投影） |
| 透视 | 近大远小 |
| 比例 | 形体关系 |
| 质感 | 材质表现 |

## 透视

| 类型 | 说明 |
|------|------|
| 一点透视 | 一个消失点 |
| 两点透视 | 两个消失点 |
| 三点透视 | 俯视/仰视 |

## 绘画工具

| 工具 | 用途 |
|------|------|
| 铅笔 | 素描（HB–8B） |
| 炭笔 | 深色、强烈对比 |
| 钢笔/针管笔 | 线条、速写 |
| 橡皮 | 修改、提亮 |

## 绘画门类

| 门类 | 媒介 |
|------|------|
| 素描 | 铅笔、炭笔 |
| 水彩 | 水彩颜料 |
| 油画 | 油画颜料 |
| 国画 | 墨、宣纸 |
| 丙烯 | 快干、可覆盖 |

## 人体绘画

- 头身比例（成人约 7.5 头身）
- 骨骼、肌肉结构
- 动态、速写
