# 01-图形装饰艺术概述

> 视觉艺术的基础——元素、色彩与构图。

## 视觉元素

| 元素 | 说明 |
|------|------|
| 点 | 最基础的视觉单位 |
| 线 | 方向、运动、轮廓 |
| 面 | 形状、区域 |
| 体 | 立体感、空间 |
| 质感 | 材质表现 |
| 色彩 | 色相、明度、饱和度 |

## 色彩原理

| 概念 | 说明 |
|------|------|
| 三原色 | 红黄蓝（颜料）/ 红绿蓝（光） |
| 色相环 | 色相关系 |
| 互补色 | 相对的颜色 |
| 冷暖色 | 情感温度 |
| 色彩和谐 | 类似、互补、三角 |

## 构图原则

| 原则 | 说明 |
|------|------|
| 平衡 | 对称/不对称 |
| 对比 | 大小、明暗、色彩 |
| 节奏 | 重复、变化 |
| 焦点 | 视觉中心 |
| 留白 | 呼吸空间 |
| 黄金比例 | 1:1.618 |

## 图形艺术 vs 装饰艺术

| 图形艺术 | 装饰艺术 |
|------|------|
| 平面、传播 | 立体、美化 |
| 设计、插画 | 手工、工艺 |
| 信息传达 | 空间装饰 |
