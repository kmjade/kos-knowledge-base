# 02 建筑设计

## 设计流程

| 阶段 | 说明 |
|------|------|
| 概念设计 | 方案构思、形体推敲 |
| 方案设计 | 平面/立面/剖面、效果图 |
| 初步设计 | 结构/设备配合 |
| 施工图设计 | 详图、节点 |

## 设计表达

| 表达 | 说明 |
|------|------|
| 平面图 | 功能布局 |
| 立面图 | 外观造型 |
| 剖面图 | 空间关系 |
| 效果图/模型 | 视觉呈现 |

## 设计软件

| 软件 | 用途 |
|------|------|
| AutoCAD | 二维制图 |
| SketchUp | 快速建模 |
| Revit | BIM 一体化 |
| Rhino/Grasshopper | 参数化设计 |
