# 01 建筑导论

## 什么是建筑学

建筑学是研究建筑的**设计、结构、材料、历史、理论与技术**的学科，兼具工程与艺术双重属性。

## 建筑三要素（维特鲁威）

| 要素 | 含义 |
|------|------|
| 坚固（firmitas） | 结构安全 |
| 实用（utilitas） | 功能适用 |
| 美观（venustas） | 形式美学 |

## 历史脉络

| 时期 | 代表 |
|------|------|
| 古典 | 古希腊/罗马（柱式） |
| 哥特 | 尖拱、飞扶壁 |
| 文艺复兴 | 比例、古典复兴 |
| 现代主义 | 柯布西耶、密斯、赖特 |
| 当代 | 多元、参数化、绿色 |
