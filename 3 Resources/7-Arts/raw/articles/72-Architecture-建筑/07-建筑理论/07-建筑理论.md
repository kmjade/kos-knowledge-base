# 07 建筑理论

## 核心概念

| 概念 | 说明 |
|------|------|
| 空间 | 建筑的本质是空间 |
| 形式 | 造型与构成 |
| 功能 | 形式服从功能（现代主义） |
| 文脉 | 与环境的对话 |

## 理论流派

| 流派 | 主张 |
|------|------|
| 功能主义 | 形式服从功能 |
| 有机建筑 | 与环境融合（赖特） |
| 极少主义 | 少即是多（密斯） |
| 后现代 | 反纯粹、装饰 |
