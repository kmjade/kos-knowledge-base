# 09 建筑实践与规范

## 设计规范

| 规范 | 说明 |
|------|------|
| 建筑防火规范 | 疏散、防火分区 |
| 无障碍设计 | 坡道、电梯 |
| 节能标准 | 保温、能耗 |
| 结构规范 | 荷载、抗震 |

## 制图标准

| 图 | 说明 |
|----|------|
| 建筑平面/立面/剖面 | 基本图 |
| 节点详图 | 构造细节 |
| 总平面图 | 场地 |

## 实战建议

1. 先学制图（AutoCAD）
2. 再学建模（SketchUp/Rhino）
3. 进阶 BIM（Revit）
4. 熟悉规范
