# 08 建筑类型

## 主要类型

| 类型 | 说明 | 例子 |
|------|------|------|
| 住宅 | 居住 | 公寓、别墅 |
| 公共建筑 | 教育/医疗/文化 | 学校、医院、图书馆 |
| 商业建筑 | 办公/商业 | 写字楼、商场 |
| 文化建筑 | 文化/观演 | 博物馆、剧院 |
| 交通建筑 | 交通枢纽 | 航站楼、车站 |
| 体育建筑 | 运动场馆 | 体育场、体育馆 |

## 设计要点

不同类型有不同的流线、功能、规范要求。
