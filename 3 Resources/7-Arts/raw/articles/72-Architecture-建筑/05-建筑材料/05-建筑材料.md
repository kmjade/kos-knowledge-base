# 05 建筑材料

## 主要材料

| 材料 | 特点 | 用途 |
|------|------|------|
| 混凝土 | 抗压、可塑 | 结构主体 |
| 钢材 | 抗拉、轻质 | 结构/大跨 |
| 木材 | 可再生、温暖 | 结构/装修 |
| 玻璃 | 透光 | 幕墙/采光 |
| 砖石 | 耐久、厚重 | 砌体/饰面 |

## 选材考量

| 因素 | 说明 |
|------|------|
| 强度 | 结构安全 |
| 耐久 | 使用寿命 |
| 保温隔热 | 节能 |
| 环保 | 绿色建材 |
| 经济 | 成本 |
