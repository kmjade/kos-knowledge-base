# 04 建筑结构

## 结构体系

| 体系 | 说明 | 适用 |
|------|------|------|
| 框架结构 | 梁柱承重 | 多层建筑 |
| 剪力墙结构 | 墙体承重抗侧 | 高层住宅 |
| 框架-剪力墙 | 混合 | 高层 |
| 大跨结构 | 桁架/网架/悬索/膜 | 体育场/航站楼 |
| 砌体结构 | 砖石承重 | 低层 |

## 受力概念

| 概念 | 说明 |
|------|------|
| 受压/受拉/受弯 | 基本受力 |
| 荷载 | 恒载/活载/风载/地震 |
| 抗震 | 抗震设防、耗能 |
