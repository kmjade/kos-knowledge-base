# 07 电影类型

## 什么是类型片

类型片是**约定俗成的叙事与风格系统**：共享主题、人物原型、视觉符号与情感预期。类型是「公式 + 变奏」——观众既期待熟悉，也期待新意。

## 主要类型

| 类型 | 核心特征 | 代表作 |
|------|----------|--------|
| 剧情 | 人物与关系、情感冲突 | 《公民凯恩》《花样年华》 |
| 喜剧 | 幽默、误会、身份错位 | 《城市之光》《热情似火》 |
| 惊悚/悬疑 | 悬念、反转、威胁 | 《迷魂记》《惊魂记》 |
| 恐怖 | 恐惧、未知、禁忌 | 《闪灵》《异形》 |
| 科幻 | 未来、技术、哲学命题 | 《2001 太空漫游》《银翼杀手》 |
| 西部 | 边疆、秩序与自由 | 《关山飞渡》《搜索者》 |
| 黑色电影 | 犯罪、道德暧昧、宿命 | 《双重赔偿》《马耳他之鹰》 |
| 音乐剧 | 歌舞叙事 | 《雨中曲》 |
| 动画 | 绘制/数字影像、想象力 | 《千与千寻》 |
| 纪录 | 真实世界、非虚构 | 《持摄影机的人》 |

## 类型的价值

- **商业**：可预期，降低市场风险，利于营销
- **文化**：类型反映并塑造时代焦虑与欲望（如黑色电影之于战后幻灭）
- **作者**：在类型框架内实现个人表达（类型「作者化」）

## 类型混合与颠覆

当代电影常混合类型（科幻 + 西部 =《星球大战》的「太空西部」），或以反类型解构惯例。
