# 08 音乐技术

## 录音与音频

| 概念 | 说明 |
|------|------|
| 采样率 | 44.1kHz / 48kHz |
| 位深 | 16bit / 24bit |
| 音频格式 | WAV / FLAC / MP3 / AAC |

## MIDI

MIDI 是音乐信息的**数字协议**（音符/力度/控制），不是音频本身。

## DAW 与插件

| 工具 | 说明 |
|------|------|
| DAW | Ableton / Logic / FL Studio / Cubase |
| 插件 | VST / AU（合成器、效果器、采样器） |

## AI 音乐

| 工具 | 说明 |
|------|------|
| Suno / Udio | AI 生成歌曲 |
| 智能编曲/混音 | AI 辅助创作 |
