# 06 音乐史

## 西方音乐史

| 时期 | 代表作曲家 |
|------|-----------|
| 巴洛克（1600–1750） | 巴赫、亨德尔、维瓦尔第 |
| 古典（1750–1820） | 海顿、莫扎特、贝多芬 |
| 浪漫（1820–1900） | 肖邦、李斯特、瓦格纳、勃拉姆斯 |
| 20 世纪 | 德彪西、斯特拉文斯基、勋伯格 |

## 中国音乐史

| 时期 | 特点 |
|------|------|
| 先秦 | 编钟、礼乐 |
| 汉唐 | 相和歌、燕乐、歌舞大曲 |
| 宋元 | 词乐、戏曲（杂剧） |
| 明清 | 京剧、地方戏曲 |
| 近现代 | 民乐改革、中西融合 |
