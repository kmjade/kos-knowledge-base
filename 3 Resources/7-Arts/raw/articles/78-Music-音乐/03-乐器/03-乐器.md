# 03 乐器

## 乐器分类

| 类别 | 代表 |
|------|------|
| 弦乐器 | 小提琴、中提琴、大提琴、低音提琴、吉他 |
| 木管乐器 | 长笛、单簧管、双簧管、巴松 |
| 铜管乐器 | 小号、圆号、长号、大号 |
| 打击乐器 | 定音鼓、军鼓、木琴、三角铁 |
| 键盘乐器 | 钢琴、管风琴、电子琴 |
| 民族乐器 | 古筝、二胡、琵琶、笛子、唢呐 |
| 电子乐器 | 合成器、电子鼓 |

## 常见乐器要点

| 乐器 | 说明 |
|------|------|
| 钢琴 | 88 键、十二平均律、键盘乐器之王 |
| 小提琴 | 弦乐家族高音，四根弦 |
| 吉他 | 六弦，民谣/古典/电吉他 |
