# 07 音乐表演

## 演奏

| 形式 | 说明 |
|------|------|
| 独奏 | 单一乐器 |
| 室内乐 | 小型合奏（重奏） |
| 管弦乐 | 交响乐团 |
| 民族乐队 | 民乐合奏 |

## 声乐

| 类型 | 说明 |
|------|------|
| 美声 | 歌剧、艺术歌曲 |
| 民族唱法 | 中国民歌 |
| 通俗/流行 | 流行歌曲 |

## 指挥

指挥负责乐团的**统一与诠释**（速度、力度、表情、声部平衡）。
