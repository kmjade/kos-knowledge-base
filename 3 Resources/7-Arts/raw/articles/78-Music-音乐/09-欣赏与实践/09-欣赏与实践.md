# 09 欣赏与实践

## 聆听与鉴赏

| 维度 | 说明 |
|------|------|
| 旋律 | 跟着哼唱 |
| 和声 | 感受色彩 |
| 节奏 | 打拍子 |
| 曲式 | 结构分析 |

## 学习路径建议

1. 学一门乐器（钢琴/吉他入门成本低）
2. 学乐理（音阶/和弦）
3. 多听多分析（各流派）
4. 尝试作曲/编曲（DAW）

## 实战案例

- 用 DAW 做一首简单的电子音乐
- 学习吉他和弦弹唱
- 用 Suno 生成 AI 歌曲再改编
