# 01 音乐导论

## 什么是音乐

音乐是以**声音为媒介的时间艺术**，通过有组织的声音（音高、节奏、和声、音色）表达情感与思想。

## 音乐四要素

| 要素 | 说明 |
|------|------|
| 旋律（Melody） | 音高的横向进行 |
| 和声（Harmony） | 多个音的纵向结合 |
| 节奏（Rhythm） | 声音的长短与强弱 |
| 音色（Timbre） | 声音的质地/质感 |

## 历史脉络

| 时期 | 特点 |
|------|------|
| 古代 | 仪式、宗教、口传 |
| 中世纪 | 格里高利圣咏、复调萌芽 |
| 文艺复兴 | 复调成熟 |
| 巴洛克 | 巴赫、亨德尔 |
| 古典主义 | 海顿、莫扎特、贝多芬 |
| 浪漫主义 | 肖邦、李斯特、瓦格纳 |
| 20 世纪 | 爵士、摇滚、电子、流行 |
