# 05 作曲与编曲

## 作曲

| 要素 | 说明 |
|------|------|
| 旋律创作 | 动机、乐句、发展 |
| 和声进行 | 和弦选择与连接 |
| 曲式 | 二段体、三段体、奏鸣曲式 |

## 编曲

| 要素 | 说明 |
|------|------|
| 配器 | 为不同乐器分配声部 |
| 织体 | 单旋律/主调/复调 |
| 结构 | 前奏/主歌/副歌/桥段/尾声 |

## 音乐制作（DAW）

| 工具 | 说明 |
|------|------|
| Ableton Live | 电子/现场 |
| Logic Pro | macOS 专业 |
| FL Studio | 电子/嘻哈 |
| Cubase | 专业录音混音 |
