# 02 乐理基础

## 音高与音阶

| 概念 | 说明 |
|------|------|
| 音名 | C D E F G A B（唱名 do re mi fa sol la si） |
| 大调音阶 | 全全半全全全半 |
| 小调音阶 | 自然/和声/旋律小调 |
| 五声音阶 | 宫商角徵羽（中国民族） |

## 和声与和弦

| 概念 | 说明 |
|------|------|
| 三和弦 | 根音+三音+五音（大/小/增/减） |
| 七和弦 | 三和弦+七音 |
| 和声进行 | I–IV–V–I 等 |

## 节奏与记谱

| 概念 | 说明 |
|------|------|
| 拍号 | 4/4、3/4、6/8 等 |
| 音符时值 | 全/二分/四分/八分/十六分 |
| 五线谱 | 谱号、调号、拍号 |
| 简谱 | 数字记谱（中国常用） |
