# 794.8 Unreal Engine

> Unreal Engine 是 **Epic Games** 出品的**实时 3D 创作平台与游戏引擎**（UE5 为当前主版本，5.8 为 UE5 收官版本）。以 Nanite 虚拟化几何、Lumen 全局光照、Blueprints 可视化脚本、C++ 源码与 MetaHuman 数字人为核心，横跨游戏、影视、建筑、汽车与仿真。数据更新至 2026-09。
