# 01 Unreal 导论

## 什么是 Unreal Engine

Unreal Engine 是 **Epic Games** 出品的**实时 3D 创作平台与游戏引擎**，UE5 为当前主版本。它以 Nanite 虚拟化几何、Lumen 全局光照、Blueprints 可视化脚本、C++ 全源码与 MetaHuman 数字人为核心，横跨游戏、影视（虚拟制片）、建筑、汽车与仿真。

## 核心理念

| 特性 | 说明 |
|------|------|
| **实时渲染** | Nanite + Lumen 带来电影级实时画面 |
| **可视化脚本** | Blueprints 无需写代码即可开发 |
| **全源码** | C++ 源码开放（GitHub），可深度定制 |
| **一体化** | 建模/动画/特效/物理/音效全内置 |

## 出品方：Epic Games

Epic Games 是 UE 的出品方，也是《堡垒之夜》（Fortnite，UE 打造）的开发商与 Epic Games Store 的运营方。

## 版本（UE5 系列）

| 版本 | 时间 | 亮点 |
|------|------|------|
| UE 5.0 | 2022-04 | Nanite + Lumen 首发 |
| UE 5.4 | 2024 | 非游戏订阅定价、动画工具 |
| UE 5.7 | 2025-11 | Nanite Foliage、内置 AI 助手 |
| **UE 5.8** | 2026-06 | MegaLights、Lumen Lite、MetaHuman Crowd（UE5 收官） |

> UE5.8 是计划中的最后一个 UE5 大版本，后续转向 **UE6**。

## 定价

| 用户 | 费用 |
|------|------|
| 游戏开发者 | 免费（前 100 万美元收入免版税，超出收 5%） |
| 非游戏公司（年收入 >100 万美元） | $1850/席位/年 订阅 |
| 学生/教育者/爱好者/小公司 | 免费 |
