# World Partition 世界分区

## 定义

World Partition 是 UE 管理并流式加载**超大开放世界**的系统：按区域（grid）流式加载/卸载，支持多人协作编辑。UE5.8 实验性 Mesh Terrain 支持 World Partition 流式。
