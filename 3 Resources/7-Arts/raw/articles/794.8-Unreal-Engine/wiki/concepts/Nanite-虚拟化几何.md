# Nanite 虚拟化几何

## 定义

Nanite 是 UE5 的**虚拟化微多边形几何系统**：支持超高面数网格（电影级资产），自动 LOD 流式渲染，无需手动做 LOD。UE5.7 加 Nanite Foliage，UE5.8 加 Nanite 兼容程序化植被。

## 关键特性

| 特性 | 说明 |
|------|------|
| 超高面数 | 电影级资产直接导入 |
| 自动 LOD | 无需手动 |
| 流式 | 按需加载 |
