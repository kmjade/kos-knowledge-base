# 02 安装与编辑器

## 安装

通过 **Epic Games Launcher** 安装：

1. 下载 Epic Games Launcher
2. 登录 Epic 账号
3. 安装「Unreal Engine」对应版本
4. 启动 UE 编辑器

（源码方式：从 GitHub 获取 UE 源码，需关联 Epic 账号。）

## 编辑器界面

| 面板 | 用途 |
|------|------|
| 视口（Viewport） | 实时 3D 视图 |
| 世界大纲（World Outliner） | 场景对象列表 |
| 细节面板（Details） | 选中对象属性 |
| 内容浏览器（Content Browser） | 资产管理 |
| 蓝图编辑器 | 可视化脚本 |

## 项目创建

支持模板：第一人称/第三人称/俯视角/空白、蓝图或 C++ 项目。
