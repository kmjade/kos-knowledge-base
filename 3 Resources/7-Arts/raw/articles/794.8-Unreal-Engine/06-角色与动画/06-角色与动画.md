# 06 角色与动画

## MetaHuman（数字人）

UE 的**照片级数字人框架**：

| 能力 | 说明 |
|------|------|
| MetaHuman Creator | 云端捏脸 |
| MetaHuman Crowd（UE5.8） | 大规模数字人群体 |
| Mesh to MetaHuman | 网格转数字人 |
| 无标记动捕 | 网络摄像头全身/面部动捕 |

UE 5.8 将 RigLogic/DNA 以 MIT 开源。

## 动画系统

| 组件 | 用途 |
|------|------|
| 骨骼网格（Skeletal Mesh） | 角色模型 |
| 动画蓝图 | 状态机（Idle/Walk/Run） |
| Control Rig | 程序化动画/绑定 |
| Sequencer | 电影级动画/过场 |

## 动捕

支持光学动捕、惯性动捕与 UE5.8 的无标记 webcam 动捕。
