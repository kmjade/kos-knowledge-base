# 09 应用与实战

## 应用领域

| 领域 | 说明 |
|------|------|
| 游戏 | AAA 大作、独立游戏（Fortnite 为旗舰） |
| 影视/虚拟制片 | 实时渲染背景、虚拟制片（Mandalorian 式） |
| 建筑可视化 | Twinmotion、archviz |
| 汽车 | 车载 HMI、设计评审 |
| 仿真 | 数字孪生、训练 |

## 实战案例

### 游戏开发

用蓝图搭玩法 → C++ 做性能关键 → Nanite/Lumen 做画面 → 打包到主机/PC。

### 影视虚拟制片

LED 墙 + 实时渲染 + Sequencer，把 CG 背景实时合成。

### 建筑可视化

导入 CAD/BIM → Twinmotion 或 UE → 实时漫游。

### 数字人（MetaHuman）

MetaHuman Creator 捏脸 → UE 驱动 → 动捕动画 → 影视/游戏。

### 大世界

World Partition 管理开放世界，PCG 程序化生成植被。
