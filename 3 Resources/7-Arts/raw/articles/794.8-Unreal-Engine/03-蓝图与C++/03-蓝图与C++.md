# 03 蓝图与 C++

## Blueprints（可视化脚本）

Blueprints 是 UE 的**可视化脚本系统**，让开发者**无需写代码**即可创建游戏逻辑：

| 类型 | 用途 |
|------|------|
| Level Blueprint | 关卡级逻辑 |
| Blueprint Class | 可复用对象（角色/道具） |
| 函数/宏 | 逻辑封装 |

节点连线表达逻辑：事件 → 函数调用 → 流程控制。

## C++（源码）

UE 基于 C++，**提供完整源码**（GitHub）。开发者可：

- 新建 C++ 类（继承 AActor、UObject 等）
- 自定义 Gameplay 逻辑、性能关键路径
- 用 UE 反射宏（`UPROPERTY` / `UFUNCTION`）暴露给蓝图

## 蓝图 vs C++

| 维度 | Blueprints | C++ |
|------|-----------|-----|
| 上手 | 快 | 慢 |
| 性能 | 较低 | 高 |
| 迭代 | 快（热重载） | 编译 |
| 适用 | 逻辑原型/美术 | 核心/性能/框架 |

## 最佳实践

蓝图做原型与美术友好逻辑，C++ 做性能关键与底层框架，两者通过暴露接口结合。
