# 06 数值设计

## 数值设计是什么

数值设计是设定与平衡游戏中的数值——伤害、成长、经济、难度，让玩法公平、有深度、可持续。

## 数值维度

| 维度 | 说明 |
|------|------|
| 伤害/强度 | 攻击、技能、装备数值 |
| 成长 | 经验、等级、曲线 |
| 经济 | 货币、掉落、通胀 |
| 难度 | 敌人强度、挑战节奏 |
| 概率 | 掉率、暴击、抽卡 |

## 平衡方法

| 方法 | 说明 |
|------|------|
| 数值表 | 中央配置、便于调整 |
| 公式化 | 伤害=基础×系数×暴击 |
| 模拟 | 蒙特卡洛验证掉落/成长 |
| 玩家数据 | 埋点分析实际分布 |

## 难度设计

| 难度 | 说明 |
|------|------|
| 静态难度 | 预设难度等级 |
| 动态难度 | 随玩家表现调整 |
| 自适应 | 心流通道维持 |

## 常见陷阱

- 数值通胀（后期溢出）
- 最优解单一（某流派碾压）
- 概率失实（伪随机 vs 真随机）
