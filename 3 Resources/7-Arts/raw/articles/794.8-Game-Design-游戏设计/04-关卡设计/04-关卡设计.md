# 04 关卡设计

## 关卡设计是什么

关卡设计是安排空间、节奏、挑战与引导，让玩家在场景中获得有节奏的体验。

## 关卡元素

| 元素 | 说明 |
|------|------|
| 空间 | 地形、路径、可探索区域 |
| 挑战 | 敌人、谜题、障碍 |
| 引导 | 光、标识、动线 |
| 奖励 | 宝箱、捷径、剧情 |
| 节奏 | 紧张与放松交替 |

## 设计手法

| 手法 | 说明 |
|------|------|
| 三明治节奏 | 高潮-喘息-高潮 |
| 面包屑引导 | 沿途奖励引导探索 |
| 漏斗式 | 多条路径汇聚主目标 |
| 循环关卡 | 首尾相连的动线（魂系） |

## 关卡流程

```
引入机制 → 训练机制 → 挑战机制 → 组合考验 → 高潮/Boss
```
