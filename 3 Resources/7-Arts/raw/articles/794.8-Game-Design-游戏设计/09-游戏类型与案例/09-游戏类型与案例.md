# 09 游戏类型与案例

## 主要游戏类型

| 类型 | 核心体验 | 代表 |
|------|---------|------|
| ARPG | 刷宝成长 | Diablo、暗黑破坏神 |
| MMORPG | 社交与成长 | 魔兽世界 |
| 动作 | 操作与反应 | 魂系、鬼泣 |
| 射击 | 瞄准与节奏 | CS、使命召唤 |
| 策略 | 决策与规划 | 文明、星际争霸 |
| 模拟 | 创造与管理 | 模拟人生、城市天际线 |
| 平台跳跃 | 操作与探索 | 马里奥、蔚蓝 |
| 解谜 | 思考与洞察 | 传送门、纪念碑谷 |

## 经典设计案例

| 游戏 | 设计启示 |
|------|---------|
| 马里奥 | 关卡教学（1-1 隐性引导） |
| 暗黑破坏神 | 核心循环（刷怪→掉装→变强） |
| 文明 | 回合策略与「再来一回合」 |
| 传送门 | 用谜题教学机制 |
| 塞尔达·荒野之息 | 开放世界涌现式玩法 |
