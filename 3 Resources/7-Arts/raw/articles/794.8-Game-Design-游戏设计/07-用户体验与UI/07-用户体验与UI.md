# 07 用户体验与 UI

## UX vs UI

| 维度 | UX（体验） | UI（界面） |
|------|-----------|-----------|
| 关注 | 整体感受、易用 | 视觉呈现、布局 |
| 问题 | 玩家是否顺畅 | 界面是否清晰美观 |

## 游戏手感（Game Feel）

| 要素 | 说明 |
|------|------|
| 响应 | 输入即时反馈 |
| 打击感 | 帧冻结、屏幕震动、音效 |
| 重量感 | 加减速、惯性 |
| 反馈 | 视觉/听觉/触觉 |

## UI 设计原则

| 原则 | 说明 |
|------|------|
| 清晰 | 信息一目了然 |
| 一致 | 风格统一 |
| 反馈 | 操作有响应 |
| 沉浸 | UI 服务游戏世界 |
| 可达 | 关键操作便捷 |

## 可用性测试

- 观察玩家操作、记录卡点
- 新手引导验证
- A/B 测试界面方案
