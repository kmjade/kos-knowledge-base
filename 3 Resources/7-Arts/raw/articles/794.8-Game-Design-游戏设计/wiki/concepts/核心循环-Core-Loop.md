# 核心循环 Core Loop

## 定义

核心循环是玩家反复执行的最小乐趣单元，是游戏「上瘾」的引擎：行动 → 反馈 → 成长 → 更强行动。

## 示例

| 游戏 | 核心循环 |
|------|---------|
| Diablo | 刷怪→掉装→变强 |
| 俄罗斯方块 | 消除→加速→挑战 |
| MOBA | 对线→团战→推塔 |
