# 心流理论 Flow

## 定义

心流（Flow，米哈里·契克森米哈赖）是挑战与能力匹配时的全神贯注状态，是游戏体验的黄金标准。

## 三状态

| 状态 | 条件 |
|------|------|
| 无聊 | 挑战 < 能力 |
| 心流 | 挑战 ≈ 能力 |
| 焦虑 | 挑战 > 能力 |

## 应用

难度曲线让玩家持续处于「心流通道」。
