# MDA 框架

## 定义

MDA 是游戏设计的经典分析框架：Mechanics（机制）→ Dynamics（动态）→ Aesthetics（美学），设计师从体验（Aesthetics）反推机制。

| 层 | 含义 |
|------|------|
| Mechanics | 规则与系统 |
| Dynamics | 玩家互动产生的行为 |
| Aesthetics | 玩家情感体验 |
