# 玩法机制 Game Mechanics

## 定义

玩法机制是游戏的规则与动作（跳跃、攻击、经济、成长），是 MDA 框架的底层（Mechanics）。

## 类型

| 类型 | 示例 |
|------|------|
| 动作 | 移动、攻击 |
| 经济 | 货币、交易 |
| 成长 | 等级、技能 |
| 竞争 | 胜负、排名 |
