# 任天堂 Nintendo

日本游戏公司，以「玩法优先」的设计哲学著称，打造了马里奥、塞尔达、宝可梦等经典 IP。

## 设计哲学

| 理念 | 说明 |
|------|------|
| 玩法优先 | 先有玩法，再有画面 |
| 全家乐 | 易上手、深耐玩 |
| 创新 | 触控、体感、Switch 双模 |
