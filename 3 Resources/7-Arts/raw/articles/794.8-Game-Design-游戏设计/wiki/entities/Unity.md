# Unity

Unity 是使用最广泛的游戏引擎之一，以跨平台、易上手与庞大资源商店著称，覆盖手游、独立游戏与部分 3A。

## 核心特点

| 特点 | 说明 |
|------|------|
| 跨平台 | 手机/PC/主机/VR |
| 易上手 | C# 脚本 |
| 资源商店 | 海量插件与素材 |
| 2D/3D | 全支持 |
