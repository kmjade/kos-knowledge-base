# 01 游戏设计导论

## 什么是游戏设计

游戏设计是定义游戏「玩什么、怎么玩、为何有趣」的过程，涵盖机制、系统、关卡、叙事与数值，核心是**塑造体验**（而非只写代码或画图）。

## MDA 框架

| 层 | 含义 | 示例 |
|------|------|------|
| Mechanics（机制） | 规则与系统 | 跳跃、攻击、经验值 |
| Dynamics（动态） | 玩家与机制的互动 | 连招、经济循环 |
| Aesthetics（美学） | 玩家情感体验 | 挑战、探索、成就 |

> 设计师从 Aesthetics 出发，反推 Dynamics 与 Mechanics——「体验优先」。

## 心流（Flow）

| 状态 | 说明 |
|------|------|
| 无聊 | 挑战 < 能力 |
| 心流 | 挑战 ≈ 能力（最佳体验） |
| 焦虑 | 挑战 > 能力 |

> 好游戏通过难度曲线让玩家持续处于「心流通道」。

## 游戏设计四要素

| 要素 | 说明 |
|------|------|
| 机制 | 规则与动作 |
| 故事 | 叙事与世界观 |
| 美学 | 视觉与听觉 |
| 技术 | 实现手段 |
