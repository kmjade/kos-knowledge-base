# 03 系统设计

## 系统设计是什么

系统设计把多个机制组织成相互关联的「系统」，驱动长期目标与成长（超出单一核心循环）。

## 常见系统

| 系统 | 说明 |
|------|------|
| 成长系统 | 等级、经验、技能树 |
| 经济系统 | 货币、资源、通胀控制 |
| 装备系统 | 掉落、稀有度、强化 |
| 任务系统 | 主线/支线/每日 |
| 社交系统 | 公会、好友、交易 |

## 成长曲线

| 曲线 | 特点 |
|------|------|
| 线性 | 稳定成长 |
| 指数 | 越后期成长越快（需更多投入） |
| 阶梯 | 关键节点跃升 |

## 经济系统设计

| 要素 | 说明 |
|------|------|
| 产出 | 资源/货币来源 |
| 消耗 | 购买、升级、维修 |
| 平衡 | 防通胀、防囤积 |
| 稀缺 | 制造追求目标 |
