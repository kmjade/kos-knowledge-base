# 08 原型与迭代

## 原型的重要性

原型是用最小成本验证「好不好玩」——游戏设计是迭代出来的，不是一次设计出来的。

## 原型类型

| 类型 | 说明 |
|------|------|
| 纸面原型 | 卡牌/棋盘模拟规则 |
| 数字原型 | 快速可玩的核心机制 |
| 灰盒（Greybox） | 无美术的关卡验证 |
| 垂直切片 | 一段完整高品质内容 |

## 迭代循环

```
设计假设 → 制作原型 → 游玩测试 → 分析反馈 → 修改 → 循环
```

## 游玩测试（Playtest）

| 要点 | 说明 |
|------|------|
| 观察 | 看玩家怎么做（而非只听） |
| 记录 | 卡点、困惑、乐趣点 |
| 提问 | 开放式，不引导 |
| 量化 | 留存、时长、完成率 |
