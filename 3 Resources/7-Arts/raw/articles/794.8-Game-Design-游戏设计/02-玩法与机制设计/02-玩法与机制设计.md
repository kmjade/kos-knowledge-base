# 02 玩法与机制设计

## 核心循环（Core Loop）

核心循环是玩家反复执行的最小乐趣单元：

```
行动（击杀）→ 反馈（掉落）→ 成长（变强）→ 更强行动
```

| 游戏 | 核心循环 |
|------|---------|
| Diablo | 刷怪 → 掉装 → 变强 → 刷更难 |
| 俄罗斯方块 | 消除 → 加速 → 挑战 |
| 王者荣耀 | 对线 → 团战 → 推塔 → 胜利 |

## 机制类型

| 机制 | 说明 | 示例 |
|------|------|------|
| 动作机制 | 移动、跳跃、攻击 | 平台跳跃 |
| 经济机制 | 资源、货币、交易 | 金币、商店 |
| 成长机制 | 等级、技能、装备 | RPG 养成 |
| 竞争机制 | 胜负、排名 | PvP、排行榜 |
| 探索机制 | 地图、谜题、发现 | 开放世界 |

## 规则设计原则

| 原则 | 说明 |
|------|------|
| 简单易学 | 规则少而清晰 |
| 深度耐玩 | 组合产生深度（易学难精） |
| 清晰反馈 | 每个行动有明确结果 |
| 有意义的选择 | 选择影响结果 |
