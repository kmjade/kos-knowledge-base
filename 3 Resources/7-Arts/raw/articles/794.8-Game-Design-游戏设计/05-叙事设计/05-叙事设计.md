# 05 叙事设计

## 叙事设计是什么

叙事设计是把故事与玩法结合，让玩家在「玩」中体验「讲」。

## 叙事方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 线性叙事 | 固定剧情线 | 最后生还者 |
| 分支叙事 | 选择影响结局 | 底特律变人 |
| 环境叙事 | 场景本身讲故事 | 魂系列、生化奇兵 |
| 碎片叙事 | 道具/日志拼凑故事 | 艾尔登法环 |
| 涌现叙事 | 玩家行为生成故事 | 模拟人生、RimWorld |

## 叙事三要素

| 要素 | 说明 |
|------|------|
| 世界 | 世界观、设定 |
| 角色 | 主角、NPC、对手 |
| 情节 | 冲突、起伏、结局 |

## 叙事与玩法的结合

- 用机制表达情感（《兄弟》的协作按键）
- 玩家选择驱动叙事（Mass Effect）
- 环境叙事补充文本
