# Diablo III — 夺魂之镰 (Reaper of Souls)

> 2012 年 5 月 15 日发售，历经拍卖行争议、战利品 2.0 重制，最终成为最具深度的终局刷宝 ARPG。

## 一、核心信息

|    项目    | 内容 |
| :------: | ---- |
|  开发商 | Blizzard Entertainment |
| 资料片 | Reaper of Souls (2014) · Rise of the Necromancer (2017) |
|  章节数 | 5 幕 |
|  职业数 | 7 (原版 5 + RoS 1 + DLC 1) |
| 难度 | Normal → Torment I–XVI |
|  赛季 | 第 1 赛季 (2014) — 第 40 赛季「圣光呼唤」(2026-10-02 开启) |
| 平台 | PC · PS4 · Xbox One · Switch |

## 二、七大职业

| 职业 | 英文 | 来源 | 核心资源 |
|:---:|------|:---:|:------:|
| 野蛮人 | Barbarian | 原版 | 怒气 (Fury) |
| 狩魔猎人 | Demon Hunter | 原版 | 憎恨/戒律 (Hatred/Discipline) |
| 武僧 | Monk | 原版 | 精气 (Spirit) |
| 巫医 | Witch Doctor | 原版 | 魔力 (Mana) |
| 秘术师 | Wizard | 原版 | 奥能 (Arcane Power) |
| 圣教军 | Crusader | RoS | 圣怒 (Wrath) |
| 死灵法师 | Necromancer | DLC | 魂能 (Essence) |

## 三、技能符文系统 (Skill Rune System)

取代 D2 的技能树：每技能 5 种符文，改变效果/属性。

| 符文 | 英文 | 效果示例 |
|:---:|------|---------|
| 无符文 | No Rune | 基础效果 |
| 雪暴 | Snowbound | 降低消耗 |
| 冰霜射线 | Cold Snap | 冰冻伤害 |
| 连锁闪电 | Chain Lightning | 闪电连锁 |
| 火焰 | Conflagration | 火焰燃烧 |

## 四、终局系统

|   系统   |        描述        |
| :---: | :--------------: |
| 涅法雷姆秘境 (Nephalem Rift) | 随机地图，击杀怪物填满进度条 |
| 大秘境 (Greater Rift) | 限时挑战，无限层级 (GR 150 上限) |
| 悬赏任务 (Bounties) | 章节任务，奖励赫拉迪姆宝箱 |
| 卡奈魔方 (Kanai's Cube) | 萃取传奇能力、重铸装备 |

## 五、套装地城与赛季

| 赛季特色 | 描述 |
|---------|------|
| 赛季旅程 | 章节式任务，奖励套装、宠物、头像框 |
| 海德格礼物 | 完成赛季旅程赠送完整职业套装 |
| 赛季主题 | 每季独特机制（如第 27 赛季「圣光呼唤」的天使坩埚与圣化；第 40 赛季为其重跑） |
| 排行榜 | 大秘境职业/团队排名 |

**当前赛季**：第 40 赛季「圣光呼唤」(Light's Calling)，2026-10-02 开启；核心机制为天使坩埚 (Angelic Crucibles)。
