# 07 材料与工具

## 常用材料

| 材料 | 对应工艺 |
|------|----------|
| 纸 | 折纸、剪纸、纸雕 |
| 毛线/纤维 | 编织、钩针、刺绣 |
| 陶土/釉料 | 陶艺 |
| 木材 | 木工 |
| 金属 | 金工、首饰 |
| 皮革 | 皮具 |
| 玻璃 | 玻璃工艺 |
| 珠子/宝石 | 串珠、珠宝 |

## 通用工具

| 工具 | 用途 |
|------|------|
| 剪刀/刻刀/裁刀 | 裁剪 |
| 针/线 | 缝合 |
| 砂纸/锉 | 打磨 |
| 胶/夹具 | 固定 |
| 尺/垫板 | 测量与保护 |

## 安全须知

| 工艺 | 注意 |
|------|------|
| 木工/金工 | 电动工具、粉尘、高温 |
| 陶艺 | 釉料安全、窑温 |
| 玻璃 | 高温、锐利碎片 |
| 皮革 | 染料/胶水通风 |
