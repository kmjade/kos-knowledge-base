# 09 当代与实践

## 当代趋势

| 趋势 | 说明 |
|------|------|
| DIY 文化 | 手作复兴、慢生活 |
| 非遗保护 | 传统工艺数字化传承 |
| 数字制造 | 3D 打印、激光切割与手工艺结合 |
| 手作电商 | Etsy 等平台全球售卖 |

## 平台

| 平台 | 用途 |
|------|------|
| Etsy | 手工艺电商 |
| Ravelry | 编织社区 |
| Instructables | DIY 教程 |
| Pinterest | 灵感发现 |
| Bilibili / YouTube | 视频教程 |

## 实战案例

### 入门选择

材料成本低、工具简单的工艺（折纸/编织/剪纸）最易入门。

### 学习闭环

看教程 → 临摹 → 复盘 → 原创 → 分享。

### 手作变现

Etsy/淘宝开店、定制、教学、参加市集。
