# 04 陶艺与玻璃

## 陶艺（Pottery / Ceramics）

| 要点 | 说明 |
|------|------|
| 成型 | 手捏、泥条盘筑、拉坯（轮制） |
| 修整 | 修坯、装饰（刻花/彩绘） |
| 施釉 | 上釉 |
| 烧制 | 素烧 → 釉烧（窑温） |

## 主要类型

| 类型 | 说明 |
|------|------|
| 陶器（earthenware） | 低温、多孔 |
| 瓷器（porcelain） | 高温、致密（中国景德镇） |
| 炻器（stoneware） | 中温、坚固 |

## 玻璃工艺

吹制、拉丝、热熔、冷加工（刻磨）。

## 材料与工具

陶土、釉料、拉坯机、窑、修坯刀；玻璃料、吹管、窑。
