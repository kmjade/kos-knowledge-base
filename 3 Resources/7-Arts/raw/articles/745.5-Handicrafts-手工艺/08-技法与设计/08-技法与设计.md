# 08 技法与设计

## 基础技法

| 技法 | 说明 |
|------|------|
| 测量与标记 | 精确裁切基础 |
| 切割/裁剪 | 各工艺的裁切 |
| 连接/缝合 | 榫卯、针法、胶合 |
| 表面处理 | 打磨、上色、上釉、封边 |
| 收尾 | 修整、装饰、包装 |

## 设计原则

| 原则 | 说明 |
|------|------|
| 功能优先 | 实用与耐用 |
| 比例与平衡 | 视觉和谐 |
| 色彩 | 配色理论 |
| 材质对比 | 不同材料搭配 |
| 简约 | 少即是多 |

## 学习路径建议

1. 选一门入门工艺（如折纸/编织，材料成本低）
2. 掌握基础技法 → 临摹经典作品
3. 学习设计原则 → 创作原创作品
