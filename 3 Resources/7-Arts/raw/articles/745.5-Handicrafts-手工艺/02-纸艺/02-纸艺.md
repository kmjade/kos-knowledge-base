# 02 纸艺

## 主要子类

| 子类 | 说明 |
|------|------|
| 折纸（Origami） | 折叠成形，符号体系（谷折/山折） |
| 剪纸（Paper Cutting） | 剪刻图案（中国剪纸为非遗） |
| 纸雕 | 多层纸立体造型 |
| 纸模型 | 展开图拼装立体模型 |

## 折纸

| 要点 | 说明 |
|------|------|
| 基础折法 | 谷折、山折、翻转、压平 |
| 符号体系 | 国际折纸图解符号 |
| 经典模型 | 千纸鹤、青蛙、盒子 |
| 现代折纸 | 湿折、复合纸、复杂设计（神谷哲史等） |

## 剪纸

中国剪纸（非遗）：窗花、双喜、皮影风格，用剪刀或刻刀。

## 材料与工具

纸（和纸/彩纸/卡纸）、剪刀、刻刀、折痕笔、垫板。
