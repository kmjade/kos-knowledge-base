# 05 木工与金工

## 木工（Woodworking）

| 要点 | 说明 |
|------|------|
| 选材 | 硬木（橡木/胡桃木）vs 软木（松木） |
| 连接 | 榫卯、胶合、钉接 |
| 表面处理 | 打磨、上油、涂装 |
| 作品 | 家具、木雕、细木工 |

### 木工工具

锯、刨、凿、钻、砂纸、夹具、车床。

## 金工（Metalwork）

| 类型 | 说明 |
|------|------|
| 锻打 | 加热锤打成形 |
| 铸造 | 熔融浇铸 |
| 首饰金工 | 锯、锉、焊（银/铜/金） |
| 珐琅 | 金属胎上釉 |

## 安全

木工注意粉尘与电动工具安全；金工注意高温与焊烟通风。
