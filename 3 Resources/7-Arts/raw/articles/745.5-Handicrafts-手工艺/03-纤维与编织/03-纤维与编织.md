# 03 纤维与编织

## 主要子类

| 子类 | 说明 |
|------|------|
| 棒针编织（Knitting） | 两根针，平针/反针等 |
| 钩针（Crochet） | 一根钩针，锁针/短针等 |
| 刺绣（Embroidery） | 针线绣出图案 |
| 染织 | 扎染、蜡染、织布 |

## 棒针编织

| 要点 | 说明 |
|------|------|
| 基础针法 | 起针、平针（下针）、反针（上针）、收针 |
| 图解符号 | 国际编织图解（符号 vs 文字说明） |
| 作品 | 围巾、帽子、毛衣、袜子 |

## 钩针

锁针、短针、长针、引拔针——可钩玩偶（amigurumi）、蕾丝、毯子。

## 刺绣

| 针法 | 说明 |
|------|------|
| 平绣 | 缎面绣 |
| 十字绣 | 网格计数 |
| 法式结 | 结粒绣 |

## 材料与工具

毛线（羊毛/棉/混纺）、棒针、钩针、绣线、绣绷、针。
