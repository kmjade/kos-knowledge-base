# 01 手工艺导论

## 什么是手工艺

手工艺（Handicrafts）是以**手工技能**制作**实用或装饰性物品**的技艺总称，区别于机器量产。它兼具实用价值与审美价值，涵盖纸艺、纤维编织、陶艺、木工、金工、皮革、珠宝等子类。

## 历史脉络

| 时期 | 特点 |
|------|------|
| 史前 | 陶器、编织、骨器——生存工具 |
| 传统社会 | 行会制度、师徒传承 |
| 工业革命 | 机器量产冲击手工艺 |
| 工艺美术运动 | 19 世纪反抗量产、复兴手作 |
| 当代 | DIY 文化、非遗保护、电商复兴 |

## 主要分类

| 大类 | 子类 |
|------|------|
| 纸艺 | 折纸、剪纸、纸雕、纸模型 |
| 纤维 | 编织、钩针、刺绣、染织 |
| 陶瓷玻璃 | 陶艺、瓷器、玻璃吹制 |
| 木工 | 木雕、家具、细木工 |
| 金工 | 锻打、铸造、首饰 |
| 皮革珠宝 | 皮具、串珠、珠宝 |

## 手工艺的价值

| 价值 | 说明 |
|------|------|
| 实用 | 制作可用的物品 |
| 审美 | 装饰与艺术表达 |
| 疗愈 | 专注与成就感 |
| 文化 | 非遗、地域传统 |
| 经济 | 手作电商、定制 |
