## 建壳规范

- **形态**：集合节点式 —— 入口页 + `README` + `CLAUDE`(schema) + `raw/articles/` + `wiki/{concepts,entities,sources}/` + `wiki/index.md` + `wiki/log.md`
- **粒度**：UDC 类号级建子库壳（本例 **R1 = A**；**2026-10-15 起 7 壳上根至容器根 `<类号>-<名>/`**（`raw/articles/` 仅余深号壳））；细粒度类号建**文件夹笔记**，落于 `<壳>/raw/articles/`
