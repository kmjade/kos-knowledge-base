# 伏羲 Fuxi

伏羲，传说中的上古圣王，被尊为「人文始祖」。相传他「仰观天文，俯察地理」，观物取象而画八卦，开创了易经的符号体系。

## 核心贡献

| 贡献 | 说明 |
|------|------|
| 画八卦 | 观象立卦·创始符号体系 |
| 结绳为网罟 | 教民渔猎 |
| 人文始祖 | 华夏文明的奠基者 |
