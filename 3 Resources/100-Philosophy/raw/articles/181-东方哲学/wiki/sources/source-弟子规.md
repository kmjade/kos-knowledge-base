# 《弟子规》

《弟子规》为清代李毓秀据《论语·学而》「弟子入则孝，出则弟，谨而信，泛爱众，而亲仁，行有余力，则以学文」编撰，三字一句、两句一韵，分八章、共 1080 字，是清代以来童蒙养正的核心读本。

## 关键主题

| 主题 | 内容 |
|------|------|
| 总叙 | 圣人训·孝弟谨信·泛爱众亲仁 |
| 入则孝 | 父母呼应勿缓·晨昏定省·谏不入 |
| 出则弟 | 兄道友弟道恭·长幼序 |
| 谨 | 朝起早·冠必正·缓揭帘 |
| 信 | 凡出言信为先·见人善即思齐 |
| 泛爱众 | 凡是人皆须爱·己有能勿自私 |
| 亲仁 | 同是人类不齐·能亲仁无限好 |
| 余力学文 | 不力行但学文·读书法有三到 |
