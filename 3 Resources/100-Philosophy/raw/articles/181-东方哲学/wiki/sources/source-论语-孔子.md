# 《论语》· 孔子

《论语》是孔子及其弟子言行的记录，儒家思想的奠基经典。它以语录体记载孔子的伦理思想，核心为「仁」与「礼」，是理解中国哲学与东亚文明的入门之作。

## 关键主题

| 主题 | 内容 |
|------|------|
| 仁 | 仁者爱人·忠恕之道 |
| 礼 | 克己复礼·正名 |
| 学 | 学而时习之·温故知新 |
| 君子 | 君子人格的修养 |
