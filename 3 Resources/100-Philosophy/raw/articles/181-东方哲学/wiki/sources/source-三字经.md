# 《三字经》

《三字经》是中国传统启蒙教材，相传为南宋王应麟所著。以三字一句的韵语，浓缩了从教育、名物、伦理到读书、历史、励学的传统文化常识，核心为「仁、义、诚、敬、孝」，是理解儒家启蒙教育与东亚蒙学传统的入门文本。

## 关键主题

| 主题 | 内容 |
|------|------|
| 教育本源 | 人之初性本善·孟母三迁·窦燕山教子 |
| 名物常识 | 三才·四时·五行·五常·六谷·七情·八音 |
| 人伦义理 | 九族·十义·五服·六艺 |
| 读书次第 | 小学→四书→孝经→六经→诸子 |
| 历史兴衰 | 三皇五帝至清末民国的朝代脉络 |
| 勤学励志 | 悬梁刺股·囊萤映雪·苏老泉发愤 |
