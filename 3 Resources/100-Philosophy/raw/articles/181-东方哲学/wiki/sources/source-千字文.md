# 《千字文》

《千字文》为南朝梁周兴嗣编撰，由一千个不重复汉字组成的四言韵文，对仗工整、涵盖自然、历史、修身与处世。与《三字经》《百家姓》并称「三百千」，是中国古代幼儿启蒙的核心读本。

## 关键主题

| 主题 | 内容 |
|------|------|
| 自然天道 | 天地玄黄·寒来暑往·云腾致雨 |
| 历史典故 | 龙师火帝·吊民伐罪·禅位让国 |
| 修身处世 | 知过必改·罔谈彼短·信使可覆 |
| 蒙学 | 「三百千」之一 |
