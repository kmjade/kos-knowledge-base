# Software Architecture Patterns Overview

> Web-clipped reference on common software architecture patterns.

English mirror of [[架构模式概述-剪藏|架构模式概述-剪藏 (CN)]]. See CN version for full content.

## Common Patterns

- **Layered Architecture** — Separation into presentation/business/persistence layers
- **Hexagonal Architecture** (Alistair Cockburn) — Isolating core business logic via ports and adapters
- **CQRS** — Separating read and write operations

## Architecture Quality Attributes

Good architecture considers maintainability, scalability, availability, and security — often involving trade-offs.
