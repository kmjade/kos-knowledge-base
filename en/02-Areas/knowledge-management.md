# Knowledge Management

> **Area:** Ongoing focus on knowledge management methodologies, tools, and practices.

## Overview

Knowledge Management (KM) encompasses the acquisition, organization, storage, sharing, and application of knowledge. This system focuses on **Personal Knowledge Management (PKM)**, using PARA as the core method, UDC as the classification backbone, and Obsidian as the implementation tool.

## Core Principles

1. **Actionability** — Knowledge serves action, not mere collection
2. **Discoverability** — Ensure content is retrievable via classification, tags, and links
3. **Evolvability** — The system evolves as understanding deepens
