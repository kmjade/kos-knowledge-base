# GPT-5

> OpenAI's fifth-generation GPT series large language model.

## Definition

GPT-5 is OpenAI's next-generation LLM, continuing the GPT (Generative Pre-trained Transformer) series. Compared to its predecessor (GPT-4 / GPT-4o), GPT-5 offers significant improvements in reasoning, multimodal processing, context window size, and agent capabilities. It serves as a foundation model for AI coding agents and general-purpose conversational systems.

## Model Comparison

| Model | Developer | Key Features |
|:------|:----------|:-------------|
| GPT-5 | OpenAI | General reasoning, multimodal, agent |
| Claude 4 | Anthropic | Long context, safety alignment, coding |
| Gemini 2 | Google | Multimodal, search integration |
