# Claude Code

> Anthropic's command-line AI coding assistant, powered by the Claude LLM.

## Definition

Claude Code is a command-line (CLI) coding agent developed by Anthropic that allows developers to interact with AI via natural language directly in the terminal for writing, debugging, and refactoring code.

## Core Capabilities

- Natural language code generation and modification
- Context-aware code analysis in the terminal
- Multi-file editing and refactoring
- Git workflow integration
- Persistent session memory
