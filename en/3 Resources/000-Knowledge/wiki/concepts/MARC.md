# MARC

> Machine-Readable Cataloging — Standard bibliographic record format.

## Definition

MARC (Machine-Readable Cataloging) is a metadata standard for encoding and exchanging bibliographic records in libraries. MARC 21, maintained by the Library of Congress, is the most widely used version. Each MARC record consists of fields (e.g., 245 Title), indicators, and subfields.

## Key Fields

| Field | Meaning |
|:------|:--------|
| 020 | ISBN |
| 100 | Main Author |
| 245 | Title Statement |
| 260 | Publication Info |
| 650 | Subject Added Entry |
