# File Format

> Structured storage of data, determining encoding, reading, and interchange.

## Definition

A file format specifies how data is organized and encoded in a file. Different formats serve different purposes — text, image, audio, structured data. In this knowledge base, the core format is Markdown (`.md`), complemented by YAML frontmatter for metadata declaration.

## Common Categories

| Category | Examples |
|:---------|:---------|
| Text Documents | Markdown (.md), TXT, HTML, XML |
| Structured Data | YAML, JSON, CSV |
| Images | PNG, JPEG, SVG |
| Notes/Metadata | Obsidian format, Frontmatter |
