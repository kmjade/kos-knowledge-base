# Linked Data

> **Resource:** An introduction to linked data principles, the Semantic Web stack, and their role in interoperable knowledge systems.
> UDC: 001.8

---

## Core Content
t

Linked Data enables publishing structured data on the Web for interlinking and querying.

**Four Principles (Tim Berners-Lee):**
1. Use URIs as names for things
2. Use HTTP URIs for lookup
3. Provide useful information via standards (RDF, SPARQL)
4. Include links to other URIs

**The Semantic Web Stack:**
URI/IRI RDF RDFS OWL SKOS SPARQL

**Five-Star Data:**
* Available on Web
** Machine-readable structured data
*** Non-proprietary format
**** W3C standards (RDF, SPARQL)
***** Linked to other data
