# Classification in the Digital Age

> **Resource:** How classification evolves in the digital age from rigid taxonomies to flexible tagging and AI-assisted categorization.
> UDC: 025.4

---

## Core Content

The digital age has fundamentally transformed how we classify knowledge:

**From Fixed to Fluid:**
- Traditional: one book, one shelf, one class
- Digital: multiple tags, cross-domain links, dynamic taxonomies

**New Paradigms:**
- **Folksonomy:** User-generated tags
- **AI Classification:** Machine learning assigns categories automatically
- **Semantic Web:** Linked Data transcends classification boundaries

**The KOS_LLM-Wiki Approach:**
1. DDC/UDC folder structure provides a cognitive map
2. Tags enable cross-domain retrieval
3. Wiki links express real knowledge relationships
