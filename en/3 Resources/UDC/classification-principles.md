# Classification Principles

> **Resource:** Core principles of classification including literary warrant, user warrant, hierarchy, and faceted analysis.
> UDC: 025.4

---

## Core Content

Classification principles form the theoretical foundation of all knowledge organization systems. The key principles include:

| Principle | Meaning | Example |
|-----------|---------|---------|
| Literary Warrant | Only create classes for existing bodies of knowledge | DDC does not predefine "exobiology" |
| User Warrant | Class names should match user habits | Public libraries vs. academic libraries |
| Hierarchy | Classes should proceed from general to specific | Kingdom Phylum Class Order |
| Faceted Analysis | Combine independent dimensions for precise classification | UDC's colon notation |

**Additional Principles:**
- **Contextual Integrity:** Classification must preserve meaningful relationships between subjects
- **Hospitality:** A good scheme accommodates new subjects without restructuring
- **Notation:** Symbols should be mnemonic, brief, and expressive
