# Taxonomy Principles

> **Resource:** Taxonomy design principles including enumerative vs. faceted approaches and modern hybrid strategies.
> UDC: 025.4

---

## Core Content

Taxonomy design balances several competing principles:

**Enumerative Classification:**
- Pre-defines all possible classes in a tree structure
- Advantages: Simple to use, consistent
- Limitations: Rigid, struggles with new subjects

**Faceted Classification:**
- Uses independent, orthogonal dimensions that combine at classification time
- Advantages: Extremely flexible, accommodates interdisciplinary subjects
- Examples: UDC's auxiliary tables, Ranganathan's Colon Classification

**Modern Hybrid Strategy:**
- Macro level: Enumerative hierarchy for top-level browsing
- Micro level: Faceted combination for precise specification
- Digital implementation enables dynamic classification that adapts to content
