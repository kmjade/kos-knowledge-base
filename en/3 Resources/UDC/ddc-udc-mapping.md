# DDC-UDC Mapping

> Full four-system mapping see [[en/3 Resources/000-Knowledge/001-PARA/wiki/DDC-分类码总表|DDC Classification Codes Master Table]].

## Key Differences

| Dimension | DDC | UDC |
|-----------|-----|-----|
| Strategy | Enumerative | Faceted (via `:` combinators) |
| Class 4 | 400 Language | **None** (merged into 8) |
| Flexibility | Low — requires Cutter numbers | High — arbitrary class combination |
| AI/ML | 006.3 | 004.8 |
| Knowledge Management | 658.4038 | 001.8:005 |
