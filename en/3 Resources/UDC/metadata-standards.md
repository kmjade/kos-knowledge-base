# Metadata Standards

> **Resource:** A survey of key metadata standards including Dublin Core, MARC, MODS, and their roles in resource discovery.
> UDC: 025.4

---

## Core Content
t

Metadata standards provide structured frameworks for describing, discovering, and managing information resources.

**Key Standards:**
- **Dublin Core:** 15 core elements for basic resource description
- **MARC 21:** Machine-Readable Cataloging for libraries
- **MODS:** XML-based bibliographic description
- **PREMIS:** Preservation metadata

**Metadata Types:**
1. **Descriptive:** Resource identification and discovery (title, author, subject)
2. **Structural:** How compound resources are organized
3. **Administrative:** Technical, preservation, and rights management

Classification numbers (DDC, UDC, LCC) frequently appear as metadata fields, bridging traditional shelf arrangement with digital description.
