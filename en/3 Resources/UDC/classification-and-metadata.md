# Classification & Metadata

> **Resource:** The relationship between classification systems and metadata standards in organizing information.
> UDC: 025.4

---

## Core Content

Classification and metadata are two sides of the same coin in information organization.

**Classification** provides the structural backbone - the shelf where resources live.
**Metadata** provides the descriptive layer - the label that tells you what a resource is about.

**Key Relationships:**
- Classification systems (DDC, UDC, LCC) can serve as controlled vocabularies for metadata fields
- Metadata standards (Dublin Core, MARC) often include classification number fields
- Crosswalks between classification and metadata enable interoperability
- Modern approaches integrate both: semantic tagging combines classification precision with metadata flexibility

DDC 050 (Classification & Metadata) sits at the intersection of library science and information management.
