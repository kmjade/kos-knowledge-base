# Ontology

> **Resource:** An exploration of ontology as a formal knowledge representation method, its components, and applications.
> UDC: 001.8

---

## Core Content
t

An ontology is a formal, explicit specification of a shared conceptualization.

**Components:**
- **Classes (Concepts):** Categories of entities
- **Properties (Relationships):** Attributes and connections
- **Individuals (Instances):** Specific examples
- **Axioms:** Logical rules constraining interpretation

**Spectrum of Formality:**
Informal taxonomy Formal taxonomy Thesaurus Lightweight ontology Full ontology (OWL)

**Applications:**
- Semantic Web (OWL, RDF, SPARQL)
- AI Reasoning (inference engines)
- Data Integration (shared vocabulary)
- Knowledge Management (consistent terminology)
**Spectrum of Formality:**

| Type | Formality | Example |
|------|-----------|---------|
| Informal taxonomy | Low | Website navigation |
| Formal taxonomy | Medium | Corporate classification |
| Thesaurus | Medium-High | AGROVOC |
| Lightweight ontology | High | Dublin Core RDF |
| Full ontology | Very High | OWL, SUMO |
