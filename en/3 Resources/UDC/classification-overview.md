# Classification Overview

> **Resource:** An introduction to classification systems, their elements, types, and role in information organization.
> UDC: 025.4

---

## Core Content

A classification system is a structured framework for organizing knowledge into categories based on shared characteristics. The four essential elements are:

| Element | Description | Example |
|---------|-------------|---------|
| Classes | The categories or divisions of knowledge | Philosophy, Mathematics, Physics |
| Hierarchy | General-to-specific subdivision | Main class Division Section |
| Notation | Symbols (digits/letters) representing classes | 500 = Natural Sciences |
| Index | Alphabetical lookup tool for finding classes | Not classification itself, but its map |

**Types of Classification:**
- **Enumerative (DDC):** All classes are pre-listed
- **Faceted (Colon Classification):** Classes are composed from standard facets
- Modern digital classification favors **hybrid strategies**: macro-level enumeration + micro-level faceting
