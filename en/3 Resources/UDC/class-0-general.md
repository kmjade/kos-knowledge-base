# Class 0 — General Knowledge

> **Resource:** An overview of UDC Class 0 (General Knowledge), covering the structure of the 000-Knowledge repository and its role in knowledge organization.

---

## Core Content

UDC Class 0 (General Knowledge) serves as the **meta-layer** of the entire knowledge management system. Unlike specialized disciplines, it studies how knowledge itself is organized, classified, and retrieved.

**Key Concepts:**

- **Scope:** Class 0 covers generalities, knowledge organization, information science, and bibliography
- **Repository structure:** The 000-Knowledge directory maps directly to UDC Class 0, containing sub-repositories for PARA (001.8), AI/LLM (004.8), UDC classification (025.4), and raw source articles
- **Wiki concepts:** Knowledge Organization Systems (KOS), SKOS, OWL, Dublin Core, and related standards are housed under `wiki/concepts/`
- **Practical value:** KOS_LLM-Wiki's entire architecture (PARA + UDC + trilingual support) is itself a practical implementation of UDC Class 0 principles
