# Knowledge + PARA + LLM-Wiki Fusion System

> **Resource:** A fusion system combining Knowledge base, PARA methodology, and LLM-Wiki.

---

## Core Content

The Fusion System combines three frameworks into a unified PKM architecture:

**The Three Pillars:**
1. **Knowledge (000-Knowledge Repository):** Content layer organized by UDC/DDC
2. **PARA Method:** Workflow layer (Projects, Areas, Resources, Archives)
3. **LLM-Wiki:** AI layer for capture, classification, synthesis, and retrieval

**Integration Benefits:**
- UDC provides universal classification
- PARA provides workflow discipline
- LLM provides automation without losing human oversight
