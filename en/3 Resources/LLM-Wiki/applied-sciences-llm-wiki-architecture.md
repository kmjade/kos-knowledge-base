# Applied Sciences + LLM-Wiki - Architecture Design

> **Resource:** Architecture design for integrating Applied Sciences into LLM-Wiki.

---

## Core Content

The architecture follows established KOS_LLM-Wiki patterns:

**Architecture Layers:**
1. **Classification Layer:** UDC/DDC provides the organizing framework
2. **Storage Layer:** PARA folders (Inbox Projects Areas Resources Archives)
3. **Retrieval Layer:** Wiki links, tags, and full-text search
4. **AI Layer:** LLM-assisted capture, classification, and retrieval

The design maintains separation of concerns: classification for navigation, PARA for workflow, and AI for automation.
