# Claude Code

> Anthropic 推出的命令列 AI 編碼助手，基於 Claude 大語言模型。

## 定義

Claude Code 是 Anthropic 開發的命令列（CLI）編碼代理工具，允許開發者在終端機中直接透過自然語言與 AI 互動來編寫、除錯和重構程式碼。

## 核心能力

- 自然語言程式碼生成與修改
- 終端機內上下文感知的程式碼分析
- 多檔案編輯與重構
- Git 工作流程整合
- 持續對話記憶
