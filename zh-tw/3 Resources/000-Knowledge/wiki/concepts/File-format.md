# 檔案格式 (File Format)

> 資料的結構化儲存方式，決定資訊的編碼、讀寫與交換。

## 定義

檔案格式（File Format）規定了資料如何在檔案中組織和編碼。不同格式適用於不同用途——文字、圖像、音訊、結構化資料等。在本知識庫中，核心檔案格式為 Markdown (`.md`)，輔以 YAML frontmatter 進行元資料宣告。

## 常見格式分類

| 類別 | 範例 |
|:----|:------|
| 文字文件 | Markdown (.md), TXT, HTML, XML |
| 結構化資料 | YAML, JSON, CSV |
| 圖像 | PNG, JPEG, SVG |
| 筆記/元資料 | Obsidian 格式, Frontmatter |
