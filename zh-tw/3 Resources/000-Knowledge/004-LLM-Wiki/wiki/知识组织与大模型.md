## LLM 對知識組織的衝擊

傳統知識組織依賴人工設計的分類體系（UDC、DDC 等），而 LLM 提供了一種語義驅動的組織方式：

### LLM 在知識管理中的應用

### 1. 自動標籤與分類
- 輸入筆記內容 → LLM 推薦 UDC 類號和標籤
- 實現筆記的自動歸類
### 2. 語義搜尋
- 自然語言查詢，而非關鍵詞精確匹配
- 跨語言檢索

### 未來方向

- 個人知識圖譜 — 將筆記轉化為 RDF 三元組
- Agent 輔助研究 — LLM Agent 自動蒐集、整理、關聯知識
- 動態分類 — LLM 根據知識演化自動調整分類結構
