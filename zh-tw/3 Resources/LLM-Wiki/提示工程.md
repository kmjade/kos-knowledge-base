## 什麼是提示工程？

提示工程（Prompt Engineering）是透過精心設計輸入文字（prompt）來引導 LLM 產生預期輸出的實踐。它是目前與 LLM 互動的主要技術手段。

## 核心框架

### CO-STAR 框架
| 要素 | 說明 |
|------|------|
| **C**ontext | 提供背景資訊 |
| **O**bjective | 明確任務目標 |
| **S**tyle | 指定輸出風格 |
| **T**one | 設定語氣 |
| **A**udience | 定義目標受眾 |
| **R**esponse | 規定輸出格式 |

### 提示要素
```
[角色定義]   → 你是一位資深 Python 開發者
[背景描述]   → 我們正在構建一個資料分析管道
[任務說明]   → 請解釋如何使用 pandas 進行資料清洗
[輸出格式]   → 請用程式碼範例 + 文字說明的方式
[約束條件]   → 使用繁體中文，300 字以內
[範例]       → 如下所示：...
```

## 常用技術

| 技術 | 說明 | 適用場景 |
|------|------|---------|
| Zero-shot | 直接給出指令 | 簡單任務 |
| Few-shot | 提供若干範例 | 格式/風格要求高 |
| Chain-of-Thought | 引導逐步推理 | 複雜推理問題 |
| Tree-of-Thought | 多分支探索 | 規劃/搜尋類任務 |
| Self-Consistency | 多次採樣取多數 | 需要可靠答案 |
| ReAct | 推理+行動循環 | Agent / 工具呼叫 |
