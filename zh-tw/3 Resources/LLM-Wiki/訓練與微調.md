## 訓練三階段

```
預訓練（Pre-training）
    ↓
有監督微調（SFT / Instruction Tuning）
    ↓
強化學習對齊（RLHF / DPO）
```

### 1. 預訓練（Pre-training）
- **目標**：下一 token 預測（自迴歸）
- **資料**：TB 級網際網路文字、書籍、程式碼
- **計算**：數千 GPU 平行訓練數週至數月
- **產出**：Base 模型（具備語言能力，但未對齊）

### 2. 有監督微調（SFT）
- **目標**：指令遵循與對話能力
- **資料**：人工標註的指令-回答對
- **方法**：全參數微調或 LoRA/QLoRA

### 3. 對齊（Alignment）
- **RLHF**：基於人類回饋的強化學習
  - 訓練 reward model → PPO 最佳化
- **DPO**：直接偏好最佳化（更簡單，無需 reward model）

## 微調方法對比

| 方法 | 參數量 | 顯存需求 | 效果 | 適用場景 |
|------|--------|---------|------|---------|
| Full Fine-tune | 全部 | 極高 | 最佳 | 有充足資源 |
| LoRA | 0.1-1% | 低 | 良好 | 任務適配 |
| QLoRA | 0.1-1% | 極低 | 良好 | 單卡微調 |
| Adapter | 少量 | 低 | 中等 | 輕量適配 |

## 關鍵概念

| 概念 | 說明 |
|------|------|
| Epoch | 完整遍歷資料集一次 |
| Batch Size | 每次更新的樣本數 |
| Learning Rate | 更新步長 |
| Gradient Accumulation | 累積多個 batch 再更新 |
| Warmup | 逐步增加學習率 |
| Cosine Schedule | 餘弦衰減學習率策略 |
