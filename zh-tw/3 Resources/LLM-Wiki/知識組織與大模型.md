## LLM 對知識組織的衝擊

傳統知識組織依賴**人工設計的分類體系**（UDC、DDC 等），而 LLM 提供了一種**語意驅動的組織方式**：

| 維度 | 傳統 KOS | LLM 增強 KOS |
|------|---------|-------------|
| 分類 | 人工指定類號 | 語意聚類 + 自動分類 |
| 檢索 | 關鍵詞匹配 | 語意搜尋 + 問答 |
| 關聯 | 手動連結 | 自動發現關係 |
| 摘要 | 人工撰寫 | 自動生成 |
| 維護 | 人力驅動 | AI 輔助持續更新 |

## LLM 在知識管理中的應用

### 1. 自動標籤與分類
- 輸入筆記內容 → LLM 推薦 UDC 類號和標籤
- 實現筆記的自動歸類

### 2. 語意搜尋
- 自然語言查詢，而非關鍵詞精確匹配
- 跨語言檢索（中文問，英文答案）

### 3. 知識提取與摘要
- 從長文件中提取關鍵概念
- 自動生成筆記摘要

### 4. 關係發現
- 識別不同筆記之間的潛在關聯
- 推薦雙向連結

### 5. 知識問答
- 基於 Wiki 內容的問答
- RAG（檢索增強生成）實現

## 本系統的 AI 輔助設想

```
┌─────────────────┐

```
