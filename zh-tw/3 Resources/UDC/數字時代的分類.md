# 數字時代的分類

> 源：09-Digital-Age-Classification.md — 編譯整理。

## 核心內容

### 一、從樹到網

| | 物理時代 | 數字時代 |
|------|------|------|
| 一本書的位置 | 排架號——一個位置 | 多個 MOC——多路徑可達 |
| 一種主題 | 一個類號 | 多個標籤 |
| 分類者 | 編目員 | 任何人（folksonomy） |
| 更新速度 | 數十年 | 即時 |
---

### 二、標籤 vs 分類

| | 傳統分類 (DDC) | 大眾分類 (Tag) |
|------|:---:|:---:|
| 結構 | 樹狀·層級 | 扁平·網絡 |
| 分配 | 排他——一個位置 | 包容——多標籤 |
| 維護者 | 權威機構 | 用戶社區 |
| 精度 | 高但死板 | 靈活但混亂 |
| 發現 | 瀏覽排架 | 搜索+關聯 |
> 標籤的問題：#AI #ArtificialIntelligence #人工智慧 三個標籤指向同一概念——沒有人協調一致性。

### 三、AI自動分類

### 優勢
- 速度：文章進入系統→AI自動提取標籤（秒級）
- 規模：人手只能處理幾十篇，AI可處理數萬篇
- 一致性：相同內容→相同標籤（概率上）
### 局限
- 誤解：AI可能誤判領域——"蘋果"是水果還是公司？
- 偏見：訓練數據的偏見會進入標籤
- 黑箱：不知道為什麼被打上某個標籤

### 四、本Vault的數字分類策略

三層混合：
1. DDC — 文件夾結構，提供認知地圖
2. 標籤 — 扁平靈活，跨域檢索
3. wikilink — 表達真實的知識關聯
