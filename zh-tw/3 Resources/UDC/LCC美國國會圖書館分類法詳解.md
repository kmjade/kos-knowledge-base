# LCC 美國國會圖書館分類法詳解

> 源：06-LCC-in-Depth.md — 編譯整理。

## 核心內容

### 一、概況

| 屬性 | 值 |
|------|------|
| 全稱 | Library of Congress Classification |
| 首次出版 | 1901年 |
| 維護方 | 美國國會圖書館 (LC) |
| 使用範圍 | 美國研究型/大學圖書館為主 |
| 類型 | 枚舉式·分卷獨立修訂 |
| 特色 | Cutter號——字母+數字精確到每本書 |

### 二、二十一大類

| 字母 | 大類 | 說明 |
|:---:|------|------|
| A | 總類 | 百科·索引 |
| B | 哲學·心理學·宗教 | |
| C | 歷史輔助科學 | 傳記·考古 |
| D | 世界史 | 歐洲·亞洲·非美 |
| E-F | 美國史 | 獨享兩個大類 |
| G | 地理·人類學·休閒 | 地圖·體育·遊戲 |

### 三、Cutter 號——LCC的靈魂

| 部分 | 含義 |
|------|------|
| 字母前綴 | 大類+學科 (QA=數學·CS, TK=電氣) |
| 數字 | 子類細化 |
| .Cutter | 字母+數字——精確到具體個體 |
> Cutter號讓LCC無需復分表即可精確到每本著作——這是與DDC復分機制的根本差異。
---

### 四、LCC vs DDC

| | DDC | LCC |
|------|------|------|
| 大類 | 10 | 21 |
| 編碼 | 純數字 | 字母+數字+Cutter |
| 設計 | 知識樹——排架號即位置 | 學科分卷——各科獨立 |
| 更新 | 統一版本 (DDC 23) | 分卷獨立修訂 |
| 精度 | 復分表組合 | Cutter號直達個體 |
| 美國史 | 973-979 | 獨佔E+F兩個大類 |
