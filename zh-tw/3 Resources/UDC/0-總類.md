### 為什麼總類重要

UDC 0 是知識管理系統的**元層**——它不直接研究某個具體學科，而是研究知識本身如何被組織、分類和檢索。因此 KOS_LLM-Wiki 的整個架構（PARA + UDC + 三語言）本身就是一個 UDC 0 的實踐案例。
