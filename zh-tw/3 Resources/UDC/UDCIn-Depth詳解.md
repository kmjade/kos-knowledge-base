### 核心定位

| 維度 | 說明 |

### UDC vs DDC 核心差異

| 維度 | DDC | UDC |
|------|-----|-----|
| 分類策略 | 枚舉——每個主題一個數字 | 分面——通過符號組合多個維度 |
| 連接符 | 無（純層級） | 有——+ / : = (…) "…" |
| 靈活性 | 低 | 高——可表達複雜關係 |
| 學習曲線 | 低——直觀 | 高——需學習符號系統 |
| 適用場景 | 公共 / 學校圖書館 | 專業 / 研究圖書館 |
| 核心思維 | 一本書 → 一個號碼 | 一本書 → 一個表達式 |

### 輔助符號體系（UDC 的精髓）

UDC 最偉大的創新：用符號讓類號可以組合。
| 符號 | 功能 | 範例 |
|------|------|------|
| + | 並列（兩主題並存） | 622+669 = 採礦與冶金 |
| / | 範圍（連續類號） | 621.3/.4 = 電氣工程到熱機 |
| : | 關係（主題交叉） | 37:004 = 教育與計算機 |
| = | 語言 | 61=111 = 醫學（英文） |
| (0…) | 形式 | (035) = 手冊、(043) = 論文 |
