關聯數據（Linked Data）是一組在Web上發布結構化數據的準則，使數據可互連和查詢。

**四大原則（Tim Berners-Lee）：**
1. 使用URI作為事物名稱
2. 使用HTTP URI以便查詢
3. 查詢時提供有用信息（RDF, SPARQL）
4. 包含指向其他URI的連結

**語義網技術棧：**
URI/IRI → RDF → RDFS → OWL → SKOS → SPARQL

**五星數據：**
★ 在Web上可用（任意格式）
★★ 機器可讀的結構化數據
★★★ 非專有格式
★★★★ W3C標準（RDF, SPARQL）
★★★★★ 連結到其他數據

關聯數據實現了從孤立分類到全球互聯知識圖譜的轉變。
