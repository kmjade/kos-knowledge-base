# 分類法概述

> 源：01-Classification-Overview.md — 編譯整理。

## 核心內容

### 分類法的要素

| 要素 | 說明 |
|------|------|
| 類目 | 分類的單元——「哲學」「數學」「物理」 |
| 層級 | 大類→中類→小類——從一般到特殊 |
| 標記 | 數字或字母——代表類目——便於排架和檢索 |
| 索引 | 幫助找到類目——不是分類——是「地圖」 |

### 分類法的類型

| 列舉式(DDC): 把所有類目都列出來 / 分面式(冒號分類法): 用標準面組合 |
|------|
