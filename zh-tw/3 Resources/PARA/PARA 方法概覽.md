# PARA 方法概覽

> **資源：** Tiago Forte 提出的個人知識管理方法論。
> UDC: 001.8:005（知識組織與管理方法）

---

## 核心內容

### 什麼是 PARA？

PARA 是四個頂級文件夾的首字母縮寫：

| 層級 | 名稱 | 說明 | 特徵 |
|------|------|------|------|
| **P** | Projects（項目）| 有截止日期的目標 | 短周期、可完成 |
| **A** | Areas（領域）| 持續關注的責任範圍 | 長期、無截止日 |
| **R** | Resources（資源）| 未來可能用到的主題資料 | 持續積累、按主題 |
| **A** | Archives（歸檔）| 已完成或暫不活躍的內容 | 冷存儲、可恢復 |

### 核心原則

1. **項目驅動** — 只有項目才有截止日期，領域和資源沒有
2. **當前優先** — 只保留當前需要的項目，其餘歸檔
3. **按需展開** — 不預先分類，需要時再建立結構
4. **定期清理** — 每周/每月回顧，歸檔已完成項目

### PARA 的信息流

```
採集 → 項目化 → 執行 → 完成 → 歸檔
           ↓
         未啟動則存入資源
```

### 在本系統中的實現

KOS_LLM-Wiki 使用以下文件夾結構對應 PARA：

| PARA 層 | 本系統目錄 | 說明 |
|---------|-----------|------|
| P | `1 Projects/` | 每個項目一個子目錄 |
| A | `2 Areas/` | 持續關注的領域 |
| R | `3 Resources/` | 000-Knowledge 子庫 |
| A | `4 Archives/` | 已完成的項目 |


## 什麼是 PARA？

PARA 是四個頂級資料夾的首字母縮寫：

| 層級 | 名稱 | 說明 | 特徵 |
|------|------|------|------|
| **P** | **Projects**（專案）| 有截止日期的目標 | 有時限，需具體產出 |
| **A** | **Areas**（領域）| 持續關注的責任範圍 | 無截止日期，長期維護 |
| **R** | **Resources**（資源）| 感興趣的主題資料 | 參考用，非當前責任 |
| **A** | **Archives**（歸檔）| 非活躍內容 | 以上三類的休眠內容 |

## 核心原則

### 1. 以可操作性為中心
- 只有**專案**包含待辦任務
- **領域**是持續關注的**標準**，不是任務列表
- **資源**是被動消費的**參考材料**

### 2. 資訊的流動性
- 資訊在 P → A → R → A 之間流動
- 專案完成後可提升為領域，或降級為資源，或直接歸檔
- 歸檔不是刪除，是降低認知負載

### 3. 極簡檔案組織
- 只保留四個頂級目錄 + 一個歸檔
- 每個目錄內部按主題而非檔案類型組織

## PARA 在本系統的應用

```
KOS_LLM-Wiki/
├── 01-Projects/     ← 專案：有明確目標與截止日期
├── 02-Areas/        ← 領域：持續關注的長期主題
├── 03-Resources/    ← 資源：參考資料與知識庫
│   ├── PARA/        ← PARA 方法資料
│   ├── UDC/         ← 分類法資料
│   └── LLM-Wiki/    ← LLM 知識庫
├── 04-Archives/     ← 歸檔：不活躍內容
├── _meta/           ← 系統自身的模板/腳本
└── 06-Daily/        ← 日記：每日筆記與閃念
```

## 與 UDC 的結合

每個筆記的 frontmatter 包含 `udc` 欄位，將 PARA 的資料夾結構與 UDC 的學科分類相結合，實現**雙重組織維度**：

- **PARA** 提供操作上下文（專案/領域/資源）
- **UDC** 提供學科歸屬（知識管理/AI/分類法）
