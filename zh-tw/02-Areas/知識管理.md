# 知識管理

> **領域：** 持續關注知識管理的方法論、工具與實踐。

## 概述

知識管理（Knowledge Management, KM）包含知識的獲取、組織、儲存、分享與應用。本系統聚焦於**個人知識管理（PKM）**，以 PARA 為核心方法、UDC 為分類骨架、Obsidian 為實作工具。

## 核心原則

1. **可操作性** — 知識服務於行動，不做純粹的收藏
2. **可發現性** — 透過分類、標籤與連結確保內容可檢索
3. **可演化性** — 系統隨認知深化而持續重構
