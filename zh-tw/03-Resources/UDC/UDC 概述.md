# UDC 概述

> **資源：** 國際十進分類法（Universal Decimal Classification）的基礎介紹。
> UDC: 025.4（分類法與索引）

---

## 什麼是 UDC？

國際十進分類法（Universal Decimal Classification）由 Paul Otlet 和 Henri La Fontaine 於 1895-1905 年間創立，是最早的通用分類法之一。UDC 使用阿拉伯數字和輔助符號來表示人類知識的全領域。

## UDC 結構

### 主類表

```
0 — 總類（科學知識、資訊、組織）
1 — 哲學、心理學
2 — 宗教、神學
3 — 社會科學
4 — 閒置（原為語言學，後併入 8）
5 — 自然科學
6 — 應用科學、醫學、技術
7 — 藝術、娛樂、體育
8 — 語言、語言學、文學
9 — 地理、歷史
```

### 輔助符號

| 符號 | 含義 | 範例 |
|------|------|------|
| `:` | 關係符號（組合多個類）| 001.8:004.8 → 知識組織與 AI |
| `+` | 並列符號 | 004+005 → 電腦+管理 |
| `/` | 範圍符號 | 004/006 → 電腦到標準化 |
| `-` | 連字號（子類）| 004.8-02 → LLM 的屬性 |
| `(0)` | 文獻類型 | (03) → 百科全書 |
| `(=)` | 語言 | =111 → 英語 |

### 通用複分號

- `.0` — 一般性複分
- `.1` — 理論、原理
- `.2` — 分析、方法
- `.3` — 設備、工具
- `.5` — 管理、組織
- `.8` — 應用

這允許在 Obsidian 中透過 DataView 或搜尋查詢按 UDC 類號篩選筆記。

## 為什麼選用 UDC？

1. **通用性** — 覆蓋所有知識領域
2. **靈活性** — 使用組合符號表達複合主題
3. **層次性** — 從粗到精的粒度控制
4. **國際性** — 語言中立，數字標識
