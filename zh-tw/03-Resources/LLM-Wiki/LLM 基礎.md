# LLM 基礎

> **資源：** 大型語言模型（LLM）的核心概念與知識架構。

---

## 什麼是 LLM？

大型語言模型（Large Language Model）是基於海量文字資料訓練的神經網路模型，能夠理解和生成人類語言。核心特點：

- **規模效應** — 參數規模達到數十億至數千億
- **湧現能力** — 在規模突破後出現小模型不具備的能力
- **上下文學習** — 無需微調即可透過範例完成新任務

## 發展簡史

```
2017 — Transformer 架構提出
2018 — BERT（Google）、GPT-1（OpenAI）
2019 — GPT-2（15億參數）
2020 — GPT-3（1750億參數）
2022 — ChatGPT（對話式 AI 爆發）
2023 — GPT-4、Llama 2、Claude 等
2024+ — 多模態、推理增強、開源生態
```

## 核心能力

| 能力 | 說明 |
|------|------|
| 文字生成 | 對話、寫作、程式碼生成 |
| 推理 | 邏輯推理、數學求解、分析 |
| 知識問答 | 從訓練資料中提取事實 |
| 翻譯 | 多語言翻譯與轉換 |
| 摘要 | 長文字濃縮與提取 |
| 分類 | 文字分類與情感分析 |
| 程式碼 | 程式設計、除錯、解釋 |

## 關鍵模型家族

| 家族 | 代表模型 | 特點 |
|------|---------|------|
| GPT | GPT-4, GPT-4o | 閉源，能力全面 |
| Llama | Llama 2/3 | 開源，社群活躍 |
| Claude | Claude 3/4 | 安全優先，長上下文 |
| Gemini | Gemini 1.5/2 | 多模態，Google 生態 |
| Qwen | Qwen 2/2.5 | 中文能力強，阿里系 |
| DeepSeek | DeepSeek-V2/R1 | 推理增強，高性價比 |

## 局限與挑戰

- **幻覺** — 生成不實資訊
- **知識截止** — 訓練資料有截斷日期
- **上下文限制** — 資訊窗口有限
- **計算成本** — 訓練和推理資源消耗大
- **對齊問題** — 價值觀與安全性
