# 企業管理

> 工作支柱下的個體戶管理子系統

## 模組結構

| 模組 | 路徑 | 更新頻率 |
|:----|:-----|:--------:|
| 經營分類 | `體系/經營分類.md` | 一次性 |
| 模板 | `體系/模板/` | 按需 |
| 客戶管理 | `數據/客戶/` | 按需 |
| 合約歸檔 | `數據/合約/` | 按需 |
| 經營財務 | `數據/經營財務/` | 每日/月 |
| 項目任務 | `數據/項目/` | 按需 |
| 經營復盤 | `數據/復盤/` | 週/月 |

## 日常流程

```
日常
├── 客戶溝通 → 客戶/ 記錄
├── 合約簽署 → 合約/ 歸檔
├── 收支發生 → 經營財務/ 記帳
└── 任務推進 → 項目/ 更新

月末 → 經營財務匯總
季末 → 經營復盤 + 稅務準備
```
