# kos-novel：AI 长篇小说创作系统

> **核心判断**：AI 长篇系统的本质是「记忆与状态管理」，而不是「写得更好」。
> 上下文窗口装不下几十万字，于是人物漂移、伏笔丢失、世界观前后打架。
> 解法：把创作拆成四层，用外部记忆（圣经）+ 逐章增量生成 + 状态回写，让人与 AI 各司其职。

---

## 触发机制

- **主动触发**：用户说"写小说 / 写个长篇 / AI 小说 / 帮我构思世界观"等
- **路由触发**：从 `kos` 入口或 PARA 项目创建时识别到"小说/长篇创作"意图

## 第一步：确定创作底座（先讨论，不定形）

在写任何文件前，先用 AskUserQuestion 或对话确认四件事：

| 维度 | 问题 | 选项示例 |
|------|------|---------|
| 类型 | 什么类型 | 硬科幻 / 软科幻 / 奇幻 / 悬疑 / 现实 |
| 题材 | 什么母题 | 人类与 AI 共存 / 末日求生 / 身份认同 |
| 人在环深度 | 人参与多少 | A 人主导 / B 共同创作 / C AI 主导 |
| 世界观 | 核心设定 | 由用户给方向，AI 提候选，人拍板 |

> **关键**：世界观要「先立宇宙法则，再谈人物与情节」。法则自洽，故事才立得住。

## 四层架构（L0 → L3）

```
L0 圣经 bible/   世界观 · 角色/* · 设定/* · 时间线 · 伏笔清单   ← 人维护 & 审改
L1 大纲 outline/  全书大纲 → 卷 → 章细纲                         ← 人审
L2 生成 draft/    逐章草稿（AI 写，人审改）                       ← 切片驱动
L3 回写           新设定/人物变化/伏笔状态 → 写回 L0              ← 每章一次
```

**一致性校验（每章）**：真实物理 + 幻想点 + 核心铁律（如熵增不可逆）+ 伏笔扫描。

## 圣经契约（L0 五类文件）

| 文件 | 作用 | 关键约定 |
|------|------|---------|
| 世界观.md | 宇宙法则 + 幻想点 + 一致性基准 | 幻想点是唯一"违背真实物理"的许可 |
| 角色/*.md | 人物卡 | **静态与动态分离** |
| 设定/*.md | 关键机制（引擎/魔法/科技） | 规则边界 = 能 / 不能 / 代价 |
| 时间线.md | 事件先后 | 防时间轴打架 |
| 伏笔清单.md | F001 起编号，跨章引用 | 状态：埋下/推进/已回收/已废弃 |

**静态与动态分离（核心）**：
- 静态小节（基础/动机/能力/关系网）—— 回写**绝不改动**
- 动态小节（`当前状态` / `弧光轨迹`）—— 回写**只增不改**（弧光是累积的）

## 切片法（L2 生成输入）

每写一章前，先抽一份「干净输入快照」，让 AI 只看它需要的，不被几十万字淹没：

```
## 生成切片（L2 输入快照）
- 本章目标
- 出场角色（仅本章相关）
- 设定依赖（仅本章用到）
- 伏笔状态（本章埋/收哪条）
- 基调
```

> 见 `templates/切片.md`。切片 = 记忆管理的单位，是这套系统能写长篇的原因。

## 协作模式（人在环深度 B，推荐）

- **人**：定方向 / 定细纲 / 终审 / 拍板（审美与价值观判断）
- **AI**：扩写草稿 / 机械校验（真实物理、伏笔、人物一致性）
- **循环**：AI 写 → 人审 → 人改方向 → AI 重写/续写

## 硬科幻定制（可选模块）

适用于硬科幻。核心纪律：

1. **幻想点（The Big Lie）**：只允许**一个**违背真实物理的设定（如"AI 强到文明级"），其余全部服从真实物理。
2. **一致性基准**：真实物理 + 一条核心铁律（如熵增不可逆）+ AI/异质智能「遵循演化而非优化」。
3. **规则边界量化**：每个关键机制写清"能 / 不能 / 代价"——代价是硬科幻的命门，是冲突与道德的来源。

## 工作流（工作包）

- **WP-01**：落地圣经契约（bible/ 目录 + 五类文件）
- **WP-02**：填充世界观与初始设定库
- **WP-03**：角色卡与故事骨架（三幕大纲，12 beat）
- **WP-04**：章节细纲（beat → 20 章）+ 首章切片 + 首章试写
- **WP-05**：（可选）封装回本 skill / 沉淀方法论

## 模板

- `templates/世界观.md` —— 宇宙法则 + 幻想点 + 一致性基准
- `templates/角色.md` —— 人物卡（静态/动态分离）
- `templates/设定.md` —— 机制卡（能/不能/代价）
- `templates/伏笔清单.md` —— 伏笔登记与回收
- `templates/切片.md` —— 每章生成输入快照
