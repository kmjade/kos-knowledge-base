# 个人财务系统 架构设计

> Life+AI 生活支柱下的财务子系统
> 分支：`Life+AI` | 基于 `2 Areas/生活/个人财务/`

---

## 1. 分层架构

```
体系层 (公开)          数据层 (私有)
┌─────────────┐      ┌──────────────────┐
│  财务分类     │←────│  交易记录          │
│  交易记录模板  │      │  预算执行数据       │
│             │      │  资产负债快照       │
│             │      │  财务回顾           │
└─────────────┘      └──────────────────┘
       ↑                     ↑
   版本控制              .gitignore
```

## 2. 数据结构

### 交易记录

每条记录为一个 `.md` 文件，frontmatter 存储结构化数据：

| 字段 | 类型 | 说明 |
|:----|:----|:-----|
| `date` | date | 交易日期 |
| `type` | enum | 收入 / 支出 / 转账 |
| `category` | string | 取自财务分类树 |
| `amount` | number | 金额 |
| `method` | string | 支付方式 |
| `note` | text | 备注 |

### 预算

月度预算文件使用扁平键名，兼容 Obsidian 属性栏：

| 前缀 | 说明 | 示例 |
|:----|:-----|:-----|
| `income_*` | 收入项 | `income_薪资: 15000` |
| `expense_*` | 支出项 | `expense_餐饮: 2000` |
| `invest_*` | 投资项 | `invest_基金定投: 3000` |

## 3. 数据流

```
每日记账 ──→ 数据/交易记录/{date}.md
   │
月末 ──→ 预算核对：Dataview 汇总月支出 vs 预算
   │
季度 ──→ 财务回顾：支出趋势 + 资产变动
```

## 5. 隐私边界

| 内容 | 存储层 | 访问控制 |
|:----|:------|:--------|
| 分类体系、模板 | `体系/` | 公开（版本控制） |
| 交易记录、预算、资产 | `数据/` | 私有（`.gitignore`） |

## 6. 与 Life+AI 集成

- 三支柱速写：每日笔记 `生活:` 行可摘要当日收支
- 周期回顾：周/月回顾中嵌入财务板块
- AI 角色：分析师可生成月度财务趋势报告
