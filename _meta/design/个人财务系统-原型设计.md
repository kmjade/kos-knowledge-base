# 个人财务系统 原型设计

> 从零体验完整闭环：记账 → 预算 → 资产 → 回顾

---

## 1. 每日记账 — 2 分钟流程

### 操作步骤

1. 打开 `2 Areas/生活/个人财务/数据/交易记录/`
2. 新建 `txn-YYYY-MM-DD.md`（或复制 `<体系/交易记录模板.md>`）
3. 填入内容后保存

### 示例：完整的一天

```yaml
---
created: 2026-06-08
updated: 2026-06-08
udc: 657
tags: [life, finance, transaction]
date: 2026-06-08
type: 支出
category: 餐饮
amount: 35.00
method: 支付宝
note: 午餐 - 兰州拉面
---
```

> 多笔交易 → 在同文件中使用多个 frontmatter 区块？不可行。
> **方案：** 每笔交易一个文件，按时间命名：

```
交易记录/
├── txn-2026-06-08.md       ← 单日合并记录
├── txn-2026-06-08-午餐.md  ← 分笔（可选粒度）
└── txn-2026-06-08-晚餐.md
```

### 快捷流程（推荐）

单日单文件，全部记录在 `note` 字段中概括。适合非重度记账用户。

## 2. 月末汇总 — Dataview 查询

在任一笔记中贴入以下查询即可实时汇总：

### 月支出汇总

```dataview
TABLE sum(rows.amount) AS 合计, rows.category AS 分类
FROM "2 Areas/生活/个人财务/数据/交易记录"
WHERE type = "支出" AND date >= date(2026-06-01) AND date < date(2026-07-01)
GROUP BY category
SORT sum(rows.amount) DESC
```

### 月收入汇总

```dataview
TABLE sum(rows.amount) AS 合计, rows.category AS 分类
FROM "2 Areas/生活/个人财务/数据/交易记录"
WHERE type = "收入" AND date >= date(2026-06-01) AND date < date(2026-07-01)
GROUP BY category
```

### 写入财务回顾

将汇总结果填入 `数据/回顾/月度回顾.md`：

```yaml
---
month: 2026-06
实际收入: 15200
实际支出: 8835
预算执行率: 100.4%
储蓄率: 41.9%
资产变动: 0
负债变动: 0
---
```

## 3. 预算与实际的偏差检查

### 查看当月预算

```dataview
TABLE expense_居住, expense_餐饮, expense_交通, expense_娱乐, expense_日用品, expense_订阅
FROM "2 Areas/生活/个人财务/数据/预算管理/2026-06"
```

### 查看当月实际支出

```dataview
TABLE sum(rows.amount) AS 合计
FROM "2 Areas/生活/个人财务/数据/交易记录"
WHERE type = "支出" AND date >= date(2026-06-01) AND date < date(2026-07-01)
GROUP BY category
SORT sum(rows.amount) DESC
```

> 手动对比预算 vs 实际，偏差率 = (实际 - 预算) / 预算 × 100%

## 4. 资产快照 — 月度更新

### 操作流程

每月 1 日打开 `数据/资产/资产概览.md`，追加一行快照：

```markdown
| 2026-07-01 | 500,000 | 200,000 | 300,000 | +5,000 |
```

### 趋势可视化

```dataview
TABLE 总资产, 总负债, 净资产, 变动
FROM "2 Areas/生活/个人财务/数据/资产/资产概览.md"
SORT 日期 ASC
```
