# 个人财务系统 详细设计

> 数据模型 · 查询库 · 工作流 · 边界处理

## 1. 数据模型

### 1.1 交易记录

**路径：** `数据/交易记录/txn-{YYYY-MM-DD}.md`
**粒度：** 单日单文件，多笔合并或拆分均可。

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----:|:-----|
| `created` | date | ✅ | 文件创建日期（标准字段） |
| `updated` | date | ✅ | 最后更新日期（标准字段） |
| `udc` | string | ✅ | `657` |
| `tags` | list | ✅ | `[life, finance, transaction]` |
| `date` | date | ✅ | 交易发生日期 |
| `type` | enum | ✅ | `收入` / `支出` / `转账` |
| `category` | string | ✅ | 取自 `体系/财务分类.md` |
| `amount` | number | ✅ | 金额（正数） |
| `method` | string | ✅ | `现金` / `银行卡` / `支付宝` / `微信` |
| `note` | text | — | 备注说明 |

**规则：**
- 单日多笔：可在同一文件中用 `note` 分条，或 `txn-2026-06-08-午餐.md` 分文件
- 金额始终为正数；`type: 支出` 表示支出，`type: 收入` 表示收入
- `date` 可能与 `created` 不同（补记场景）

### 1.2 预算

**路径：** `数据/预算管理/{YYYY-MM}.md`
**更新频率：** 每月初创建

| 字段 | 格式 | 示例 |
|:----|:-----|:-----|
| `month` | `YYYY-MM` | `2026-06` |
| `income_薪资` | number | `15000` |
| `income_副业` | number | `0` |
| `income_其它` | number | `200` |
| `expense_居住` | number | `3500` |
| `expense_保险` | number | `500` |
| `expense_订阅` | number | `200` |
| `expense_交通` | number | `300` |
| `expense_餐饮` | number | `2000` |
| `expense_日用品` | number | `500` |
| `expense_衣着` | number | `500` |
| `expense_娱乐` | number | `800` |
| `expense_医疗` | number | `0` |
| `expense_其他` | number | `500` |
| `invest_基金定投` | number | `3000` |
| `invest_备用金` | number | `2000` |

**公式：**
```
预算收入合计 = income_薪资 + income_副业 + income_其它
预算支出合计 = expense_居住 + ... + expense_其他
预算储蓄率  = (invest_基金定投 + invest_备用金) / 预算收入合计
```

### 1.3 资产快照

**路径：** `数据/资产/资产概览.md`
**格式：** Markdown 表格，每月追加一行

| 列 | 说明 |
|:----|:-----|
| 日期 | 快照日期 |
| 总资产 | 所有资产市值合计 |
| 总负债 | 所有负债余额合计 |
| 净资产 | 总资产 − 总负债 |
| 变动 | 相对上月净资产的变动额 |

### 1.4 财务回顾

**路径：** `数据/回顾/{YYYY-MM}-回顾.md`
**更新频率：** 每月（或每周）

| 字段 | 类型 | 说明 |
|:----|:----|:-----|
| `month` / `week` | string | 回顾周期标识 |
| `实际收入` | number | 当月收入合计 |
| `实际支出` | number | 当月支出合计 |
| `预算执行率` | number | 实际支出 / 预算支出 × 100% |
| `储蓄率` | number | (收入 − 支出) / 收入 × 100% |
| `资产变动` | number | 本月净资产 − 上月净资产 |
| `负债变动` | number | 本月负债 − 上月负债 |

## 3. 工作流

### 3.1 每日流程

```
打开 Obsidian → 今日笔记
  → 三支柱速写 生活: 行记录当日大额收支
  → 打开 数据/交易记录/
  → 新建 txn-2026-06-08.md
  → 填写 frontmatter
  → 保存
```

### 3.2 月初流程

```
1日 → 数据/预算管理/{新月份}.md（复制模板）
   → 填写各分类预算金额
   → 数据/资产/资产概览.md → 追加上月快照
   → 数据/回顾/{上月}-回顾.md → 填写上月汇总
```

### 3.3 周末/月末汇总流程

```
周末 → 运行 Q1 + Q2（本月汇总）
   → 对比预算（Q3 vs Q1）
   → 填入 数据/回顾/{当前月}-回顾.md
```

## 4. 边界与异常处理

| 场景 | 处理方式 |
|:----|:---------|
| 补记 | `date` 填写实际发生日，不依赖 `created` |
| 退款 | 建一条 `type: 收入, category: 退款` 或修改原记录 |
| 分类变更 | 新交易使用新分类，旧记录不追溯修改 |
| 多笔合并 | 全部写入同一文件的 `note` 字段，`amount` 填合计 |
| 预算超支 | 不修改预算值；在回顾中记录偏差原因 |
| 跨月交易 | 按交易日期归属，不按入账日期 |
