# KOS Life+AI 架构设计（初稿）

> 分支：`Life+AI` | 基于 `main`（v1.2.0）
> 状态：初稿，待实现

---

## 1. 目录结构

```
2 Areas/
├── 生活/
│   ├── 生活.md          ← 索引页（目标 + 指标 + 链接）
│   └── 日志/            ← AI 周汇总
├── 学习/
│   ├── 学习.md
│   └── 日志/
└── 工作/
    ├── 工作.md
    └── 日志/
```

- 目录命名：纯中文，英文版后续同步
- 内容归类：由内容本身性质决定（生活/学习/工作）
- 知识组织相关：保留在 KOS 分支，不涉及本分支

## 2. AI 角色

| 角色 | 职责 | 触发模式 |
|------|------|---------|
| 简报员 | 晨间提示 + 傍晚提醒 | 会话开始提示"简报已就绪"，会话结束视变化而定 |
| 分析师 | 周/月趋势报告 | 周期末尾提示可生成，用户确认后执行 |
| 协作者 | 目标进度异常提醒 | 时间过半 + 完成 < 50% 时提示 |

- Life 与 KOS：各自独立，互不引用

## 3. _agents/ 目录

```
_agents/
├── life/                    ← 私有三支柱规则
│   ├── 简报员.md
│   ├── 分析师.md
│   └── 协作者.md
└── kos/                     ← KOS 分支合并时
    └── README.md            # 预留占位
```

## 4. Periodic 笔记模板变更

在 `_meta/Templates/每日笔记模板.md` 中：

- 移除 `📝 工作日志` 区块
- 新增 `🏠 三支柱速写` 区块（`生活::` / `学习::` / `工作::`）
- 日志存放：混合模式，用户写入 Periodic，AI 周汇总到 `2 Areas/{支柱}/日志/`
