# v3.0 — KOS-LLM-Wiki 集成系统架构

> 2026-06-09 · 完整实现三平台 Skill 架构、KOS 引擎 7 技能、Canvas 可视层

---

## 核心新增

### KOS 引擎（7 Skills）

| 技能 | 命令 | 功能 |
|------|------|------|
| **kos** | `/kos` | 统一入口，意图分发 |
| **kos-triage** | `KOS-Triage` | Inbox 四维分拣 → 路由入库 |
| **kos-compile** | `KOS-Compile` | raw/ → wiki/ 六步编译（Delta 追踪） |
| **kos-link** | `KOS-Link` | 五级健康检查（Frontmatter/UDC/链接/跨语言/项目） |
| **kos-daily** | `Daily Open` | 每日笔记 + 周期回顾（幂等） |
| **kos-query** | `KOS-Query` | 三级知识库查询（Quick/Standard/Deep） |
| **canvas** | `Canvas-*` | 可视化参考层（新增） |

### 三个知识捕获层

| 层 | 名称 | 输出 | 引擎 |
|:--:|------|:----:|------|
| L1 | **文本综合** | `.md` wiki 页面 | KOS-Compile |
| L2 | **结构化知识** | 索引 + Dataview | KOS-Triage + KOS-Query |
| L3 | **可视化参考** | `.canvas` (JSON Canvas) | **Canvas** |

### Canvas 可视层（新增）

- 设计文档：`_meta/design/canvas-可视层设计.md`
- 三平台 SKILL.md：`.claude/` `.codex/` `.opencode/` 各一套
- 命令集：`Canvas-Status` `Canvas-New` `Canvas-Add-Image` `Canvas-Add-Text` `Canvas-Add-Note` `Canvas-Add-PDF` `Canvas-Zone` `Canvas-List`
- 自动定位算法 + 宽高比自适应 + 文件锁集成
- 目录结构：`_attachments/canvases/` `_attachments/media/`

## 多语言架构

| 语言 | 首页 | 索引 |
|------|------|------|
| English | `en/Home.md` | `en/_meta/Knowledge-Links/Index/_index-en.md` |
| 简体中文 | `Home.md` | `_meta/🔗 知识关联/Index/_index-zh-cn.md` |
| 繁體中文 | `zh-tw/首頁.md` | `zh-tw/_meta/🔗 知识关联/Index/_index.md` |

- 跨语言链接策略：同语言优先 → fallback CN → 共享内容统一指向 CN
- UDC 一致性：三语言版本使用相同类号
