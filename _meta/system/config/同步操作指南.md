# 同步操作指南

> J：（主库）到 F：（从库）双库架构层同步操作手册。

---

## 1. 同步范围

同步脚本自动同步架构层文件：

- _meta/（模板、脚本、配置、日志等）
- .claude/ .codex/ .opencode/（AI 平台配置）
- AGENTS.md CLAUDE.md（AI 行为规范）

内容层（0-4 PARA + Periodic）两库独立，不自动同步。

---

## 2. 同步命令

powershell: python _meta/system/scripts/sync-vaults.py

---

## 3. 编码注意事项

Obsidian 默认 UTF-8 无 BOM。同步时注意编码一致。

---

## 4. 同步清单

存储于 `_meta/.sync-manifest.json`，SHA-256 哈希比对：

```json
{
  "version": 2,
  "updated": "2026-06-10T02:51:56",
  "entries": {
    "_meta/ai/agents/life/简报员.md": {
      "hash": "abc123...",
      "synced_at": "2026-06-10T02:51:56"
    }
  }
}
```

> 哈希一致的已同步文件自动跳过，幂等安全。

---

## 5. 使用场景

### 日常（在家）

AI 操作 J: → 同步到 F: → 你在台式机 Obsidian 实时查看。

### 外出（商铺地下室）

拔 U 盘带走，插入笔记本/平板。F: 保留最新同步版本。

| 场景 | J: 在哪 | F: 状态 |
|:----|:--------|:--------|
| 在家 | 插在台式机 | 实时同步 |
| 外出 | 随身携带 | 保留最后版本 |
| 回家 | 插回台式机 | 继续同步 |

---

## 6. 维护

| 操作 | 方法 |
|:----|:------|
| 增删同步范围 | 编辑 `sync-vaults.py` 的 `EXCLUDE_DIRS` |
| 强制重同步 | 删除 `_meta/.sync-manifest.json` 后运行脚本 |
| 查看同步状态 | `python -c "import json;m=json.load(open('_meta/.sync-manifest.json'));print(len(m['entries']),'files')"` |

---

## 7. 故障排查

| 症状 | 原因 | 解决 |
|:----|:-----|:------|
| Obsidian 看不到新文件 | 文件在 J: 未同步到 F: | 等 AI 同步完成，或手动复制 |
| 中文乱码或空白 | 编码非 UTF-8 无 BOM | 用 `[System.Text.UTF8Encoding]::new($false)` 写入 |
