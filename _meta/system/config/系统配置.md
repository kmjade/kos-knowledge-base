## 5. Frontmatter 模板

```yaml
---
created: YYYY-MM-DD
updated: YYYY-MM-DD
udc: <类号>
tags: [tag1, tag2]
---
```

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `created` | 创建日期 | `2026-06-07` |
| `updated` | 最后更新日期 | `2026-06-07` |
| `udc` | UDC 分类号 | `004.8` |
| `tags` | 标签数组 | `[resource, llm]` |

### 可选字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `aliases` | Obsidian 别名 | `[LLM, Large Language Model]` |
| `compiled` | 编译状态 | `true` / `false` |
| `compiled_at` | 编译时间戳 | `2026-06-07T00:00` |
| `compiled_by` | 编译引擎 | `KOS-Wiki-Compile` |
| `reviewed` | 人工审核状态 | `true` |
| `status` | 项目状态 | `active` / `completed` |
| `priority` | 优先级 | `P1` |

## 6. 日志配置

| 日志文件 | 记录内容 | 格式 |
|----------|----------|------|
| `_meta/system/logs/operations/triage.md` | KOS-Triage 每次执行 | Markdown 表格 + 明细 |
| `_meta/system/logs/operations/compile.md` | KOS-Wiki-Compile 每次执行 | Markdown 表格 + 明细 |
| `_meta/system/logs/reports/` | 审计报告、周报 | 独立文档 |

### 日志表头（triage）

```
| 日期 | 操作 | 处理数 | 成功路由 | 待确认 | 跳过 | 双路路由 |
```

### 日志表头（compile）

```
| 日期 | 操作 | 处理数 | 新建 | 更新 | 跳过 | 冲突 | 交叉引用 |
```

## 7. 编译阈值

| 条件 | 处理方式 |
|------|----------|
| 文件 < 50 字 | 跳过，标记 `too-short` |
| 文件 > 10,000 字 | 跳过，标记 `long-doc` |
| `compiled: true` + `reviewed: true` | 跳过（保护人工审核） |
| `compiled: true` + `reviewed: false` | 重新编译合并 |
