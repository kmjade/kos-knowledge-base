# Periodic 周期笔记

> **设计来源：** LifeOS × LLM-Wiki 融合系统 — 独立于 PARA 的时间轴维度

## 目录结构

```
Periodic/
├── 2026/
│   ├── 01/              # 一月
│   │   ├── 01.md        # 1 日日记
│   │   ├── 02.md        # 2 日日记
│   │   └── ...
│   ├── 02/
│   ├── 03/
│   ├── 04/
│   ├── 05/
│   ├── 06/
│   ├── 07/
│   ├── 08/
│   ├── 09/
│   ├── 10/
│   ├── 11/
│   └── 12/
├── 2027/
└── ...
```

## 结构说明

| 层级 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 年 | `YYYY/` | `2026/` | 四位年份 |
| 月 | `MM/` | `06/` | 两位月份 |
| 日 | `YYYY-MM-DD.md` | `2026-06-06.md` || `YYYY-MM-DD.md` | `06.md` | 两位日期，月度回顾可在此目录创建 `weekly.md`、`monthly.md` |

## 使用方式

- **日记：** `Periodic/2026/06/2026-06-06.md` — 每日记录
- **周记：** `Periodic/2026/06/week-02.md` — 按周回顾（可选）
- **月记：** `Periodic/2026/06/monthly.md` — 月度总结（可选）

## 模板

- 日记模板：`_meta/Templates/每日笔记模板.md`
- 周记模板：`_meta/Templates/weekly-template.md`（待创建）
