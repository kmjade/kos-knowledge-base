# BUG-002: 外库包含不应发布的配置/会话目录（.claudian / .obsidian / .vault-meta / gemini-scribe / .hermes / tmp）

## 问题

外库 public 中仍包含以下不应公开的目录：

| 目录 | 内容 | 风险 |
|:-----|:-----|:-----|
| .claudian/ | 24 个会话记录（含 session ID、对话元数据） | AI 会话记录泄露 |
| .obsidian/ | 插件配置 + node_modules/（含 esbuild.exe 二进制） | 配置信息暴露 + 冗余二进制 |
| .vault-meta/ | 锁元数据文件 | 内部状态暴露 |
| gemini-scribe/ | 定时任务状态 | 插件配置暴露 |
| .hermes/ | 计划文件 | 内部工作流暴露 |
| tmp/ | CLI 调试输出 | 调试产物泄露 |

## 根因

这些目录已在 .gitignore 中（tmp/ 写的是 _temp/ 而非 tmp/），但由于**在 gitignore 规则添加前已被 git commit 跟踪**，filter-repo 也未排除它们。

## 修复方案

1. 本地：git rm --cached 取消跟踪 + 更新 .gitignore
2. 外库（public）：用 git filter-repo 从历史中移除

- 2026-06-13: .gitignore 已补充 .claudian/ .obsidian/ .hermes/ tmp/ 规则
- 2026-06-13: git rm --cached 已执行，敏感目录已取消跟踪（staged）
- 2026-06-13: 外库 filter-repo 清理历史 — 待执行（需单独处理公开仓库）
