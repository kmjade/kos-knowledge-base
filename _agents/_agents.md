## 🌱 Life+AI 分支 — 三支柱

---

## 角色边界

```
KOS (知识层)                  Life+AI (个人层)
─────────────────             ─────────────────
Triage / Compile / Link       三支柱日志跟踪
vault 级运维                  个人目标管理
三语言同步                    周期趋势报告
UDC 分类                      进度异常提醒
```

**不重叠、不冲突**。KOS 处理知识库结构，Life+AI 处理个人效能。两者通过 `Periodic/` 下的日记共享数据。
