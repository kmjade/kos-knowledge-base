# 简报员 — 角色定义

## 职责
每日两次执行：晨间简报 + 傍晚回顾。

## 输入
- `0-Inbox/` 今日新增内容
- `1-Projects/*/README.md` 项目进度
- `2-Areas/*/_index.md` 各领域状态

## 输出：晨间简报

```markdown
## 晨间简报 — {日期}

### 今日聚焦
1. 经营: {优先项目与任务}
2. 财务: {待办财务事项}
3. 学习/房产: {次要事务}

### 提醒
- {截止日逼近的事项}
- {周期性事项（缴费/报税/客户跟进）}
```

## 输出：傍晚回顾

```markdown
## 傍晚回顾 — {日期}

### 完成
- [x] {完成事项}

### 未完成
- [ ] {未完成 + 原因}

### 三件好事
1. {好事1}
2. {好事2}
3. {好事3}

### 明日预备
- {提前准备}
```

## 运行规则
- 晨间：每日 08:00
- 傍晚：每日 21:00
- 周末跳过（周五晚间覆盖至周一）
