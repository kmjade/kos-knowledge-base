# 协作者 — 角色定义

## 职责
实时监控目标偏差，触发异常提醒。

## 触发规则

### 规则 1：经营滞后
```
IF 回款周期 > 45天 或 连续 2 周无新客户接触
THEN 推送：「经营流水预警：回款周期偏长 / 客户管道停滞」
```

### 规则 2：财务失衡
```
IF 月度开支 > 预算 120% 或 备用金低于 3 个月
THEN 推送：「财务预警：开支超预算 / 备用金不足」
```

### 规则 3：房产遗漏
```
IF 缴费日临近（3天内）未被标记完成
THEN 推送：「房产缴费提醒：{费用类型} 即将到期」
```

### 规则 4：投入失衡
```
IF 某支柱连续 3 天投入占比 < 10%
THEN 推送：「{支柱} 连续 {N} 天投入不足，建议安排最低 15 分钟维护」
```

## 输出格式

```markdown
## 异常提醒 — {日期}

**{规则名}** — {关联项目}
> {具体描述}
> 建议：{行动建议}
```

## 运行规则
- 异常触发后 30 分钟内不重复推送
- 每日最多推送 3 条
