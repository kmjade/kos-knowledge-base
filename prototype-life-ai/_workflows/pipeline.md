# Life+AI Pipeline — 原型自动化工作流

## 完整链路

```
[捕获]         [分拣]            [执行]           [回顾]           [分析]
  |              |                 |                |                |
Inbox 新增 ──→ 归类到项目/支柱 ──→ 执行任务 ──→ 简报员晚间回顾 ──→ 分析师周/月报
                                                      ↓
                                                协作者异常检测 ──→ 提醒推送
```

## 每日流程

| 时段 | 操作 | 角色 |
|------|------|------|
| 08:00 | 扫 Inbox → 排今日优先级 | 简报员 |
| 日间 | 按计划执行 | 你 |
| 21:00 | 回顾完成情况 → 三件好事 | 简报员 → 协作者 |

## 每周流程

| 操作 | 角色 |
|------|------|
| 读取 7 天回顾 → 经营健康度分析 | 分析师 |
| 检查回款/预算/缴费异常 | 协作者 |

## 每月流程

| 操作 | 角色 |
|------|------|
| 经营+财务综合月报 | 分析师 |
| 异常项归总 → 下月调整建议 | 协作者 |
