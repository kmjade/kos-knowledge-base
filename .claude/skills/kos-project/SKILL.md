# kos-project：项目管理引擎

> 一次流程完成"项目立项 + 编号分配 + 文件落盘 + 领域关联"

---

## 触发机制

- **主动触发**：用户输入"新建项目 / 启动项目 / 立项 / 创建项目"
- **路由触发**：从 `kos` 入口识别到项目创建意图

## 流程锁定规则

- 用户在回答中提到的"目标/截止日期/领域"等词，默认视为项目信息输入
- 仅在以下情况允许切换：
  - 用户明确输入其他命令
  - 用户明确要求停止本次项目创建
- 流程完成标志：目录已创建 + 主页已写入 + 领域页已同步

---

## 主流程

### 阶段一：收集项目信息

最低必填：
1. 项目名称
2. 所属领域（从 `2 Areas/` 中选择）

建议补充：
- 项目目标
- 截止日期
- 优先级（高/中/低）

### 阶段二：编号分配

1. 扫描 `1 Projects/` 下所有目录
2. 提取同年前缀 `YY-` 的最大序号
3. 新编号 = 最大序号 + 1（两位数补零）

规则：
- 同年内递增，跨年后从 `YY-01` 重新开始
- 若现有项目无编号（历史项目），从 `26-01` 开始首个编号
- 禁止猜测编号，必须基于实际扫描结果

### 阶段三：创建目录与主页

```
目标目录:  1 Projects/{{编号}} {{项目名称}}/
目标文件:  1 Projects/{{编号}} {{项目名称}}/📍 项目总览.md
```

1. 创建项目目录
2. 用 `_meta/Templates/项目模板.md` 生成 `📍 项目总览.md`
3. 填入基础字段：编号、目标、领域、优先级
4. 确保 Dataview 面板正确（项目文件 + 最近更新）

### 阶段四：同步关联

**A — 项目总览**
```
文件: 1 Projects/📍 项目总览.md
```
- 如不存在 → 创建最小结构（标题 + 活跃项目列表）
- 如存在 → 在"活跃项目"区块追加新项目条目
- 链接格式：`[[1 Projects/{{编号}} {{名称}}/📍 项目总览.md|{{编号}} {{名称}}]]`
- 避免重复插入

**B — 领域页**
```
路径: 2 Areas/{{领域名}}/{{领域名}}.md
```
- 在"关联项目"区块追加新项目
- 多领域项目同时关联多个领域页
- 无匹配领域页 → 询问用户是否新建，用 `_meta/Templates/领域模板.md` 创建

### 阶段五：输出结果

固定格式：
```
✅ 项目创建完成

项目编号: {{YY-NN}}
项目路径: [[1 Projects/{{编号}} {{名称}}/📍 项目总览.md]]
已创建:
  - 1 Projects/{{编号}} {{名称}}/📍 项目总览.md
已更新:
  - 1 Projects/📍 项目总览.md
  - 2 Areas/{{领域}}/{{领域}}.md

下一步建议:
  - 完善成功标准与行动计划
  - 添加相关笔记链接
  - 开始第一阶段工作
```

## 快速立项模式

触发：用户只想先开项目框架，细节稍后补。

最小交付：
1. 确定项目名称与所属领域（最低必填）
2. 编号分配与目录创建
3. 生成基础项目主页
4. 更新项目总览与领域页

---

## 重要提醒

- 禁止使用示例数据，编号与名称必须来自真实扫描与用户输入
- 路径操作前先确认目标目录存在，不存在则创建
- 涉及多领域时多点关联，但项目主页路径唯一
- 创建后务必输出可追溯结果（含可点击路径）
