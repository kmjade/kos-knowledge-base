# PARA 方法概览

> **资源：** 由 Tiago Forte 提出的个人知识管理方法论。
> UDC: 001.8:005（知识组织与管理方法）

---

## 什么是 PARA？

PARA 是四个顶级文件夹的首字母缩写：

| 层级 | 名称 | 说明 | 特征 |
|------|------|------|------|
| **P** | **Projects**（项目） | 有截止日期的目标 | 有时间约束，需具体产出 |
| **A** | **Areas**（领域） | 持续关注的责任范围 | 无截止日期，长期维护 |
| **R** | **Resources**（资源） | 感兴趣的主题资料 | 参考用，非当前责任 |
| **A** | **Archives**（归档） | 非活跃内容 | 以上三类的休眠内容 |

## 核心原则

### 1. 以可操作性为中心
- 只有**项目**包含待办任务
- 领域是持续关注的**标准**，不是任务列表
- 资源是被动消费的**参考材料**

### 2. 信息的流动性
- 信息在 P → A → R → A 之间流动
- 项目完成后可提升为领域，或降级为资源，或直接归档
- 归档不是删除，是降低认知负载

### 3. 数字文件组织的最小化
- 只保留四个顶级目录 + 一个归档
- 每个目录内部按主题而非文件类型组织

## PARA 在本系统的应用

```
KOS_LLM-Wiki/
├── 01-Projects/     ← 项目：有明确目标与截止日期
├── 02-Areas/        ← 领域：持续关注的长期主题
├── 03-Resources/    ← 资源：参考资料与知识库
│   ├── PARA/        ← PARA 方法资料
│   ├── UDC/         ← 分类法资料
│   └── LLM-Wiki/    ← LLM 知识库
├── 04-Archives/     ← 归档：不活跃内容
├── 05-Meta/         ← 元：系统自身的模板/脚本
└── 06-Daily/        ← 日记：每日笔记与闪念
```

## 与 UDC 的结合

每个笔记的 frontmatter 包含 `udc` 字段，将 PARA 的文件夹结构与 UDC 的学科分类相结合，实现**双重组织维度**：

- **PARA** 提供操作上下文（项目/领域/资源）
- **UDC** 提供学科归属（知识管理/AI/分类法）
