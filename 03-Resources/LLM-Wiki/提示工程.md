## 什么是提示工程？

提示工程（Prompt Engineering）是通过精心设计输入文本（prompt）来引导 LLM 产生期望输出的实践。它是目前与 LLM 交互的主要技术手段。

## 核心框架

### CO-STAR 框架
| 要素 | 说明 |
|------|------|
| **C**ontext | 提供背景信息 |
| **O**bjective | 明确任务目标 |
| **S**tyle | 指定输出风格 |
| **T**one | 设定语气 |
| **A**udience | 定义目标受众 |
| **R**esponse | 规定输出格式 |

### 提示要素
```
[角色定义]   → 你是一个资深 Python 开发者
[背景描述]   → 我们正在构建一个数据分析管道
[任务说明]   → 请解释如何使用 pandas 进行数据清洗
[输出格式]   → 请用代码示例 + 文字说明的方式
[约束条件]   → 使用中文，300 字以内
[示例]       → 如下所示：...
```

## 常用技术

| 技术 | 说明 | 适用场景 |
|------|------|---------|
| Zero-shot | 直接给出指令 | 简单任务 |
| Few-shot | 提供若干示例 | 格式/风格要求高 |
| Chain-of-Thought | 引导逐步推理 | 复杂推理问题 |
| Tree-of-Thought | 多分支探索 | 规划/搜索类任务 |
| Self-Consistency | 多次采样取多数 | 需要可靠答案 |
| ReAct | 推理+行动循环 | Agent / 工具调用 |

## 结构化提示模板

```
## 角色
[你的角色定义]

## 背景
[任务背景信息]

## 任务
[具体任务描述]

## 要求
- 要求1
- 要求2

## 输出格式
[期望的格式说明]

## 示例
[可选：输入输出示例]
```
