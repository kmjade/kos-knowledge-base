# kos-project：项目管理引擎

> 一次流程完成"项目立项 + 编号分配 + 文件落盘 + 领域关联"

---

## 触发机制

- **主动触发**：用户输入"新建项目 / 启动项目 / 立项 / 创建项目"
- **路由触发**：从 `kos` 入口识别到项目创建意图

## 流程锁定规则

- 用户在回答中提到的"目标/截止日期/领域"等词，默认视为项目信息输入
- 仅在以下情况允许切换：
  - 用户明确输入其他命令
  - 用户明确要求停止本次项目创建
- 流程完成标志：目录已创建 + 主页已写入 + 领域页已同步

---

## 主流程

### 阶段一：收集项目信息

最低必填：
1. 项目名称
2. 所属领域（从 `2 Areas/` 中选择）

建议补充：
- 项目目标
- 截止日期
- 优先级（高/中/低）

### 阶段二：编号分配

1. 扫描 `1 Projects/` 下所有目录
2. 提取同年前缀 `YY-` 的最大序号
3. 新编号 = 最大序号 + 1（两位数补零）

规则：
- 同年内递增，跨年后从 `YY-01` 重新开始
- 若现有项目无编号（历史项目），从 `26-01` 开始首个编号
- 禁止猜测编号，必须基于实际扫描结果

### 阶段三：创建目录与主页

1. 创建项目目录 `1 Projects/{{编号}} {{项目名称}}/`
2. 用 `_meta/Templates/项目模板.md` 生成 `📍 项目总览.md`
3. 填入基础字段：编号、目标、领域、优先级
4. 确保 Dataview 面板正确（项目文件 + 最近更新）

### 阶段四：同步关联

**A — 项目总览**
- 文件: `1 Projects/📍 项目总览.md`
- 如不存在 → 创建最小结构（标题 + 活跃项目列表）
- 如存在 → 在活跃项目区块追加新项目条目

**B — 领域页**
- 路径: `2 Areas/{{领域名}}/{{领域名}}.md`
- 在关联项目区块追加新项目
- 多领域项目同时关联多个领域页
- 无匹配领域页 → 询问用户是否新建

### 阶段五：输出结果

输出项目编号、路径、已创建文件、已更新页面、下一步建议。

---

## 快速立项模式

最小交付：名称 + 领域 → 编号分配 → 目录创建 → 主页生成 → 总览与领域页同步。
